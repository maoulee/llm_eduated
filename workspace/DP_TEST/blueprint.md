## 知识点
- 核心知识点：数据结构-树的遍历与性质、二叉树存储结构、线索二叉树
- 考察范围：二叉树的递归/非递归遍历算法、树的度与高度计算、线索化原理与应用、二叉树遍历序列还原树结构

## 难度
- K值总体目标：K3（中等难度）
- K值范围：K2-K4
- 知识维度：要求掌握二叉树基本性质（K2），理解遍历算法实现（K3），能分析线索二叉树构造过程（K4）
- 计算维度：涉及树节点数、叶子节点数、度为1/2的节点数计算（K3）
- 分析维度：给定遍历序列还原二叉树并判断性质（K4）

## 出题要求
- 题型：综合题（含计算与分析）
- 子问题数量：4个子问题
- 条件设计要求：
  - 提供一棵具体的二叉树结构或遍历序列作为已知条件
  - 条件需保证唯一确定二叉树结构
  - 需包含前序和中序遍历序列，或前序和层序遍历序列
- 参数范围：
  - 二叉树节点数：10-20个
  - 树的高度：4-6层
  - 叶子节点数：3-8个

## 子问题规划
1. 子问题1（4分）- 计算题：根据给定二叉树，计算节点总数、叶子节点数、度为2的节点数
2. 子问题2（5分）- 计算题：写出该二叉树的前序、中序、后序遍历序列
3. 子问题3（4分）- 分析题：将该二叉树进行线索化，指出各节点的前驱和后继关系
4. 子问题4（3分）- 分析题：判断该二叉树是否为完全二叉树/平衡二叉树，并说明理由

## 参数约束
- 二叉树节点总数 n：10 ≤ n ≤ 20
- 树高 h：4 ≤ h ≤ 6
- 叶子节点数 n0：3 ≤ n0 ≤ 8
- 度为1的节点数 n1：0 ≤ n1 ≤ 5
- 度为2的节点数 n2：满足 n0 = n2 + 1 的性质
- 遍历序列中各节点标识使用大写字母（A-T范围内）
- 所有子问题基于同一棵二叉树，保证参数一致性
- 线索化时左/右线索标记明确，中序线索树前后驱关系需准确对应
