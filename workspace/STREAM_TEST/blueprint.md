## 知识点
- 计算机组成原理：分页存储管理、虚拟内存、页面置换算法（LRU/FIFO/Optimal）
- 操作系统：进程管理、地址转换机制、缺页中断处理
- 核心考察：TLB命中率计算、页面置换策略对比、有效访问时间分析

## 难度
- K1（记忆理解）：10-15%，考察基本概念定义
- K2（简单应用）：25-30%，考察基本计算能力
- K3（综合分析）：35-40%，考察多知识点综合应用
- K4（创新设计）：15-20%，考察算法对比与优化分析
- K5（综合评估）：5-10%，考察系统级问题分析

目标K值范围：K2.5 - K3.5（中等偏难，侧重综合分析）

## 出题要求
- 题型：综合计算分析题
- 子问题数量：4个子问题
- 条件设计：
  - 给出页表结构（多级页表或单级页表）
  - 提供访问序列和物理内存块数
  - 给出TLB命中率、页表访问时间、内存访问时间
- 参数范围：
  - 页面大小：4KB固定
  - 物理块数：3-8块
  - 访问序列长度：15-25次
  - 地址位数：32位虚拟地址

## 子问题规划
1. **子问题1（计算，4分）**
   - 给定虚拟地址，计算物理地址（需进行地址转换）
   - 考察页表查找和地址拼接

2. **子问题2（计算，5分）**
   - 计算给定访问序列下的缺页次数（分别使用FIFO和LRU算法）
   - 考察页面置换算法的手工模拟

3. **子问题3（分析，5分）**
   - 计算有效访问时间（考虑TLB命中/未命中情况）
   - 考察公式：EAT = p × (TLB访问时间 + 内存访问时间) + (1-p) × (TLB访问时间 + 2×内存访问时间 + 缺页开销)

4. **子问题4（证明/分析，6分）**
   - 对比不同页面置换算法的缺页率，分析Belady异常现象
   - 证明FIFO算法可能出现的工作集异常

## 参数约束
- 页面大小：4KB（2^12字节），固定不变
- 页面内偏移位数：12位
- 页号位数：20位（32位地址 - 12位偏移）
- 物理内存块数：4块（用于FIFO/LRU模拟）
- 访问序列：[7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2, 1, 2, 0, 1, 7, 0, 1]（20次访问）
- TLB命中率：90%（p = 0.9）
- TLB访问时间：10ns
- 内存访问时间：100ns
- 缺页开销：50000ns
- 页表为单级页表，存储在内存中
- 所有地址均使用十六进制表示
- 初始状态：内存块为空，TLB为空（首次访问）
- 参数一致性：页表项包含有效位、页框号、访问位等信息
