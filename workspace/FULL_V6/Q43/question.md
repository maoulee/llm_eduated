## 题干
某计算机系统的存储器层次结构参数如下：主存容量为64MB，Cache容量为64KB，数据块大小为128B。假设主存地址和Cache地址均采用字节编址，且系统初始时Cache为空。请回答下列问题：

## 子问题
### (1) （3分）
计算主存块数、Cache总行数以及块内地址（Offset）的位数。

### (2) （3分）
若采用直接映射（Direct Mapping）方式，分析主存地址的标记（Tag）、索引（Index）和块内偏移（Offset）各占多少位，并画出主存地址结构图。

### (3) （3分）
若采用2路组相联映射（2-way Set Associative Mapping）方式，分析主存地址的标记、索引和块内偏移各占多少位，并与直接映射方式进行简要对比。

### (4) （3分）
给定如下16进制主存地址访问序列（共15次访问）：
`0x0000000, 0x0000010, 0x0100000, 0x0000000, 0x0100000, 0x0000000, 0x0200000, 0x0200010, 0x0000080, 0x0000090, 0x0000100, 0x0000110, 0x0000200, 0x0000210, 0x0000000`
假设替换算法为LRU（最近最少使用），分别计算在直接映射和2路组相联映射方式下的Cache命中率，并简要说明产生差异的原因。

## 答案
### (1)
- 主存块数 = 64MB / 128B = $2^{26} / 2^7 = 2^{19} = 524288$ 块
- Cache总行数 = 64KB / 128B = $2^{16} / 2^7 = 2^9 = 512$ 行
- 块内偏移（Offset）位数 = $\log_2(128) = 7$ 位

### (2)
- 索引（Index）位数 = $\log_2(\text{Cache行数}) = \log_2(512) = 9$ 位
- 标记（Tag）位数 = 主存地址总位数 - 索引位数 - 块内偏移位数 = $26 - 9 - 7 = 10$ 位
- 主存地址结构图：
  `[ 标记 Tag: 10位 ] | [ 索引 Index: 9位 ] | [ 块内偏移 Offset: 7位 ]`

### (3)
- 组数 = Cache总行数 / 路数 = $512 / 2 = 256$ 组
- 索引（Index）位数 = $\log_2(256) = 8$ 位
- 标记（Tag）位数 = $26 - 8 - 7 = 11$ 位
- 主存地址结构图：
  `[ 标记 Tag: 11位 ] | [ 索引 Index: 8位 ] | [ 块内偏移 Offset: 7位 ]`
- 对比：与直接映射相比，2路组相联映射的索引位减少1位，标记位增加1位；组相联将直接映射的1个Cache行扩展为包含2行的组，主存块可映射到组内任意一行，有效降低了冲突缺失率。

### (4)
- **直接映射命中率**：5/15 ≈ 33.3%
  - 命中访问：第2、8、10、12、14次（均为同一块内的空间局部性访问）
  - 缺失访问：第1、3、4、5、6、7、9、11、13、15次（其中Index=0处发生频繁冲突替换）
- **2路组相联命中率**：9/15 = 60.0%
  - 命中访问：第2、4、5、6、8、10、12、14、15次
  - 缺失访问：第1、3、7、9、11、13次
- **差异原因**：访问序列中多次交替访问映射到同一Cache行（Index=0）的不同主存块（Tag分别为0、1、2）。直接映射下，同一行只能容纳1个块，导致严重冲突替换（乒乓效应）；而2路组相联允许同一组内容纳2个不同标记的块，在LRU策略下可保留Tag=0和Tag=2，显著缓解了冲突，从而提高了命中率。

## 设计说明
- **出题意图**：本题为408计算机组成原理典型综合题（K3难度），旨在全面考察考生对Cache容量参数计算、地址映射原理、地址结构分解以及命中率分析的综合应用能力。通过对比两种映射方式，强化对“冲突缺失”机制的理解。
- **参数选择理由**：主存64MB（26位地址）、Cache 64KB、块大小128B均为2的整数次幂，符合实际体系设计规范且便于位数推导；2路组相联是工业界常用的折中方案；15次访问序列长度适中，兼顾计算量与考察深度，避免繁琐枚举。
- **干扰项与难点设计**：序列特意构造了Index=0处的“Tag 0/1/2交替访问”模式。直接映射下必然产生频繁替换，命中率被压制在33.3%；而2路组相联利用组内2行容纳Tag 0和Tag 2，命中率提升至60%。通过精确控制空间局部性（同块访问）与时间局部性（重复访问）的比例，确保两种映射的命中率均落在0.3~0.9合理区间，且严格满足“直接映射命中率 ≤ 组相联命中率”的理论预期，有效区分考生对映射机制本质的掌握程度。
