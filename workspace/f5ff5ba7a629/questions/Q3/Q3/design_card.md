## core_knowledge_intent

- must_test:
  1. 列优先（列主序）存储地址公式的正确代入计算：给定 m 行 n 列数组、基地址、元素大小，计算 A[i][j] 的存储地址
  2. 下标起始约定的正确处理：题干明确声明下标从 0 或 1 开始，学生在公式中正确使用偏移量
- must_not_shift_to:
  - 不偏到行优先地址计算（行优先仅作为干扰项的错误路径，不是正确考察方向）
  - 不偏到特殊矩阵压缩存储（对称矩阵、三角矩阵等不出现）
  - 不偏到数组抽象数据类型定义或数组的基本操作
- coverage_success_criteria:
  - 正确答案唯一且由列优先公式 BASE + ((j - j_start) × m + (i - i_start)) × s 产生
  - 三个干扰项分别对应"行优先公式混淆""下标起始忽略""行列互换"三种不同错误路径，各自产生不同数值
  - 学生选对正确答案必须同时满足：选对列优先公式 + 正确处理下标起始 + 正确代入行列参数

## design_rationale

**考察意图**：二维数组列优先存储地址计算是数组章节的核心考点之一。本题聚焦"公式选择 + 精确代入"这一基础能力，属于典型的 K2 主导（记忆公式后正确应用）计算题。

**为什么选列优先而非行优先**：列优先存储在国内教材中通常作为行优先的对照出现，学生更容易在公式选择上犯错——这正是 K4 层面的区分点。本题以列优先为正确路径，行优先公式自然成为最高频干扰项。

**区分度设计**：
- 选对答案的学生：完整掌握列优先公式，且正确处理下标起始 → 高掌握度
- 选"行优先混淆"干扰项的学生：未区分行优先/列优先，或混淆了两者的遍历顺序 → 中低掌握度
- 选"下标起始忽略"干扰项的学生：公式记忆正确但忽略下标起始偏移 → 中掌握度，粗心型
- 选"行列互换"干扰项的学生：公式形式正确但 m/n 代反 → 低掌握度，概念模糊

**难度适配**：K2=3 对应"数字非完全友好（非2的幂次乘法）但手算可行"，K4=2 对应"下标起始作为轻量陷阱存在但不隐蔽"，K3=2 对应"单步公式应用无需多步推理"。整体 difficulty=3，与 slot 要求吻合。

**考点融合**：本题难度为 K3 级，不进行考点融合，聚焦单一考点（列优先地址计算），通过三种错误路径的区分度实现考察深度。

## question_structure_plan

- 复用骨架来源：2021_Q3（二维数组行优先存储地址计算，问法为"已知基地址和某元素地址，求另一元素地址"）+ 2020_Q1（列优先存储下标计算，问法为"给定矩阵存储方式，求指定元素的下标"）
- 提炼设问句式：往年题标准句式为"设二维数组 A[m×n] 按[行/列]优先方式存储，每个元素占 s 个存储单元，基地址为 LOC(A[0][0])=BASE，求元素 A[i][j] 的存储地址是（ ）"——本题复用此句式，以列优先为正确路径
- 设问结构：单问单选，4 选项，无子问递进（选择题标准结构）
- dependency_pattern：无依赖（单选题独立作答）

### option_plan（仅选择题）

- 考察的量：二维数组按列优先存储时元素 A[i][j] 的存储地址
- 选项A（正确）：列优先地址公式 BASE + ((j - j_start) × m + (i - i_start)) × s 的计算结果
- 选项B（干扰）：行优先公式混淆——使用行优先公式 BASE + ((i - i_start) × n + (j - j_start)) × s 的计算结果
- 选项C（干扰）：下标起始忽略——列优先公式但未减去下标起始偏移（直接用 i、j 而非 i-i_start、j-j_start）的结果
- 选项D（干扰）：行列互换——列优先公式中行数 m 与列数 n 代反的结果，即 BASE + ((j - j_start) × n + (i - i_start)) × s

## terminology_and_expression_constraints

- 必须用词：
  - "按列优先方式存储" / "以列为主序"——明确存储方式为列优先
  - "每个元素占 s 个存储单元"——明确元素大小
  - "基地址"或"起始地址"——明确 BASE 的含义
  - 下标起始声明：必须显式写出"下标从 0 开始"或"下标从 1 开始"，不留歧义
- 限定语：
  - "存储地址"而非"下标"——本题求的是绝对地址，不是数组下标
  - 目标元素用 A[i][j] 或 a[i][j] 形式表示，行号列号在题干中给出具体数值
- 禁止表述：
  - 不使用"对称矩阵""上三角""下三角"等特殊矩阵术语
  - 不出现"指针""链式""堆"等与顺序存储无关的术语
  - 不说"大约""约为"——地址计算是精确值

## audit_focus

1. **存储方式明确性**：题干必须明确写出"列优先"存储方式，不能模糊或让学生自行推断
2. **下标起始声明**：题干必须显式声明下标从 0 还是 1 开始，这是 K4 的考察点，不能遗漏
3. **四条件齐全**：行数 m、列数 n、基地址 BASE、元素大小 s 四个显式条件必须全部给出
4. **干扰项区分度**：三个干扰项（行优先混淆 / 下标起始忽略 / 行列互换）必须产生三个互不相同的数值，且均与正确答案不同——这是题目成立的核心判据，下游 gen.py 须验证
5. **目标元素非退化**：目标元素 A[i][j] 不能取首元素（会让下标起始干扰项失效）或末元素（可能让某些干扰项重合）
6. **选项唯一性**：四个选项的数值两两不同
7. **参数约束遵守**：m、n 在 3~10 范围内，m×n ≤ 100，BASE 在 100~9999 范围内，s ∈ {2,4,8}
