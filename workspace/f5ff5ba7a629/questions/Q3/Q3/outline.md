## 考点
- **核心考点**：二维数组列优先（column-major）存储的地址公式及其应用
  - 考察侧重点：给定数组维度、基地址、元素大小，按列优先存储推算任意元素 A[i][j] 的存储地址
- **辅助知识点**：
  - 行优先 vs 列优先的区别（作为干扰项区分度来源）
  - 下标从 0 还是从 1 开始对地址公式的影响（作为陷阱/条件路由要素）

## 难度目标
| 维度 | 目标 | 达标理由 |
|------|------|----------|
| K1 基础认知 | 2 | 需记忆列优先地址公式，但属基础名词级别，概念模糊也能从公式直接套用 |
| K2 单步代入 | 3 | 代入常规公式计算，涉及非 2 的幂次的乘法和加法，一步可能算错 |
| K3 机制推演 | 2 | 2 步以内：确定元素在列优先线性序列中的序号 → 计算地址，路径唯一 |
| K4 条件路由 | 2 | 存在常规注意点：下标起始约定（从 0 或从 1 开始），408 考生基本不会踩坑 |
| K5 跨域联动 | 1 | 单一知识点内部解决，不涉及其他子系统 |

## 考察模式
**计算型——地址公式应用**

选定理由：slot 指定 examination_mode 为"计算型——地址公式应用"，此类题目在历年 408 中是数组和特殊矩阵部分的标准考法。核心动作为：识别列优先存储序号公式 → 代入维度参数 → 算出目标地址。历史模式高度一致，适合以选择题形式考查。

## 出题要求
- **题型**：单项选择题，4 选项，1 正确 3 干扰，分值 2 分
- **条件数**：4 个显式条件（数组维度行数、数组维度列数、基地址/起始元素地址、每个元素占用的字节数）
- **隐含条件**：下标起始约定（从 0 或从 1 开始），需在题干中明确给出
- **条件设计原则**：
  - 维度不宜过大，保证手算可行（乘积在两位数×一位数范围内）
  - 基址和元素大小选取应使正确答案与各干扰项数值有明显差异
  - 目标元素的下标不应是边界退化情况（如 [0][0] 或最后一个元素），避免计算退化为平凡结果

## 参数约束
| 参数 | 取值范围 | 约束说明 |
|------|----------|----------|
| 数组行数 m | 3 ~ 10 | 保证列优先序号计算中乘法可手算；与列数 n 无固定比例关系 |
| 数组列数 n | 3 ~ 10 | 同上；m × n 不宜超过 100 |
| 基地址 BASE | 100 ~ 9999 的整数 | 便于手算；避免过大数字导致选项难以区分 |
| 元素大小 s（字节） | 2, 4, 8 中选取 | 使用常见对齐字节数；不建议选 1（区分度不足） |
| 目标元素下标 i, j | 1 ≤ i ≤ m, 1 ≤ j ≤ n（若从 1 开始）| 避免取 [1][1]（退化为基址本身）或末元素 |
| 下标起始 | 0 或 1 | 题干需明确声明，影响公式中是否减 1 |

**参数间一致性约束**：
- 正确答案 = BASE + ((j - j_start) × m + (i - i_start)) × s，其中 j_start、i_start 为下标起始值
- 干扰项必须由"常见错误公式"产生，而非随机数值

## 干扰策略
建议以下干扰路径，各路径须产生**不同**的数值结果以保证区分度：
1. **行优先混淆**：使用行优先公式替代列优先公式
2. **下标起始忽略**：忘记调整下标（从 1 开始时漏减 1，或从 0 开始时多减 1）
3. **行列混淆**：将 m 和 n 互换后代入列优先公式

## 参考经验
- **历史模式**：数组和特殊矩阵的选择题几乎全部为地址计算型，核心区分点在于行优先/列优先的公式选择
- **难度锚点**：此类题目 K2 通常在 2-3（取决于数字是否友好），K4 在 1-2（取决于下标起始是否构成陷阱），与 slot 的 k_radar 一致
- **典型陷阱**：行优先/列优先混淆是最高频干扰项；下标从 0 还是 1 开始是次高频陷阱
