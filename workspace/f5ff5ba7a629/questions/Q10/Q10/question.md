# 快速排序前两趟划分结果（选择题）

## 题目

使用快速排序算法对关键字序列 $S = [74, 87, 35, 29, 57, 30, 79, 77, 10, 86]$（$10$ 个互不相同的正整数）进行升序排序。枢轴选取策略为：**以待排序子表的第一个元素作为枢轴**。Partition 过程采用从枢轴对端（右端）开始的双向扫描方式：先从右端向左扫描找到第一个小于枢轴的元素，再从左端向右扫描找到第一个大于枢轴的元素，交换两者，重复此过程直至两端指针相遇，最后将枢轴与指针相遇位置的元素交换，使枢轴归位。

"一趟"的含义为：对**单个待排序子表**执行一次完整的 Partition。快速排序的递归处理顺序为：**每趟划分完成后，优先对左子表继续执行下一趟 Partition**（若左子表长度 ≥ 2）。

问：对序列 $S$ 经过**前两趟** Partition 后，序列的状态是（　　）。

A. $[29, 10, 30, 35, 57, 74, 79, 77, 87, 86]$

B. $[30, 10, 35, 29, 57, 74, 79, 77, 87, 86]$

C. $[30, 10, 29, 35, 57, 74, 79, 77, 87, 86]$

D. $[30, 10, 35, 29, 57, 74, 77, 79, 87, 86]$

---

## 设计说明（供 design_solve 搜索参数用）

### 参数占位符

| 占位符 | 含义 | 约束 |
|--------|------|------|
| $n$ | 序列长度 | $8 \le n \le 12$ |
| $a_1, \ldots, a_n$ | 序列元素 | 互不相同的正整数，建议值域 10–99 |
| $\text{seq}_A$ | 选项A（正确答案） | 正确执行两趟完整 Partition 后的序列 |
| $\text{seq}_B$ | 选项B | 仅执行第一趟 Partition 后的序列（只做一趟） |
| $\text{seq}_C$ | 选项C | 漏掉某次枢轴归位交换的两趟结果 |
| $\text{seq}_D$ | 选项D | 第一趟正确、第二趟作用于错误子表的结果 |

### 参数搜索约束（hard_constraints）

1. **序列长度**：$8 \le n \le 12$，元素互不相同的正整数（建议 10–99）。
2. **枢轴策略**：取首元素为枢轴。
3. **第一趟划分后左右子表均非空**：第一趟以 $a_1$ 为枢轴划分后，枢轴左侧至少 1 个元素、右侧至少 1 个元素。
4. **第二趟有实际操作内容**：第二趟作用于左子表（优先处理左子表），左子表长度 $\ge 2$（即第一趟划分后枢轴左侧至少 2 个元素），使第二趟 Partition 有实际比较与交换操作。
5. **四路区分度**：选项 A（正确两趟）、B（只做一趟）、C（漏枢轴归位）、D（第二趟错误子表——对右子表操作）产生的四个序列必须**两两互不相同**。gen.py 须验证此约束，若任意两条路径产生相同序列则换参数。
6. **选项D的构造方式**：第一趟正确，第二趟对右子表执行 Partition（而非左子表），产生与 A 不同的序列。

### 干扰项错误路径说明

| 选项 | 错误路径 | 具体含义 |
|------|---------|---------|
| A | 无（正确） | 第一趟对全表 Partition 并枢轴归位 → 第二趟对左子表 Partition 并枢轴归位 |
| B | 只做一趟 | 仅执行第一趟 Partition，未继续第二趟 |
| C | 漏枢轴归位交换 | 在第一趟或第二趟末尾，遗漏枢轴与指针相遇位置元素的交换（枢轴未归位） |
| D | 第二趟错误子表 | 第一趟正确，第二趟对右子表执行 Partition 而非左子表 |

### gen.py 需输出的数据

- 初始序列 $S$（替换 $a_1, \ldots, a_n$）
- 四个选项序列 $\text{seq}_A, \text{seq}_B, \text{seq}_C, \text{seq}_D$（替换选项占位符）
- 验证四个序列两两不同的断言结果
- 每个干扰项与正确答案的具体差异（供 solution.md 使用）
