- examination_mode: 计算型——二叉树性质应用
- expected_form: 题干给出二叉树的总结点数 n 和度为1的结点数 n₁，要求计算叶子结点数 n₀

  - condition_count: 2

## core_knowledge_intent
- must_test:
  1. 二叉树叶子结点数与度为2结点数的关系：n₀ = n₂ + 1
  2. 二叉树总结点数分解公式：n = n₀ + n₁ + n₂
  3. 联立两个公式求解未知量——先由 n 和 n₁ 求出 n₂，再由 n₂ 求出 n₀
- must_not_shift_to:
  - 不偏向完全二叉树的层序性质或编号规律
  - 不偏向具体二叉树的构造/遍历
  - 不偏向树的存储结构
- coverage_success_criteria:
  - 正确路径：n₂ = (n - n₁ - 1) / 2，n₀ = n₂ + 1，两步均须正确
  - 至少3个干扰项各自对应不同的典型错误路径，且结果互不相同
  - 正确答案与所有干扰项的值互不相同

## design_rationale
**考察意图**：本题考察学生对二叉树基本性质的双重公式联立应用能力。仅凭记忆 n₀ = n₂ + 1 不足以解题——学生必须同时掌握总结点数分解公式 n = n₀ + n₁ + n₂，并能正确联立消元。这区分了"仅记住单个结论"与"真正理解二叉树结点度数关系体系"的学生。

**区分度来源**：三个典型错误路径分别捕获不同层次的理解缺陷：
- 混淆 n₀ 与 n₂ 方向（得到 n₀ 比正确值少2，即直接取 n₂ 不加1再算偏）：仅记住公式但方向搞反
- 误将 n₁ 代入 n₂ 公式（n₀ = n₁ + 1）：把不同度的结点数混用
- 遗漏总结点分解步骤（直接用 n - n₁ 或 n - n₁ - 1）：不理解需要减去 n₂ 的份额

**难度适配**：difficulty_level=3 合适——计算量小（一步除法+一步加法），但需要正确选择公式并准确执行两步推理，K2（计算执行）和 K3（路径选择）各占一定权重。

## question_structure_plan
- 复用骨架来源：2018_Q4（满二叉树给叶结点数求总结点数）+ 2009_Q5（完全二叉树给叶结点信息求总结点数）+ 2016_Q42 正则k叉树叶结点数推导
- 提炼设问句式："已知一棵二叉树共有 n 个结点，其中有 n₁ 个度为1的结点，则该二叉树的叶结点数为（ ）。"
- 题干结构（单问选择题）：
  - 条件1：二叉树总结点数 n（一个具体正整数）
  - 条件2：度为1的结点数 n₁（一个具体正整数）
  - 问题：求叶子结点数 n₀
- dependency_pattern：无子问依赖（单问选择题），正确求解路径为 n → n₂ = (n-n₁-1)/2 → n₀ = n₂+1

## option_plan（仅选择题）
- 考察的量：二叉树的叶子结点数 n₀
- 选项A（正确）：n₀ = n₂ + 1，其中 n₂ = (n - n₁ - 1) / 2——正确联立两个公式的结果
- 选项B（干扰）：混淆 n₀ 与 n₂ 方向——取 n₂ 但未加1，得到比正确值少1的结果（直接给 n₂ 的值）
- 选项C（干扰）：误用 n₁ 代入——取 n₀ = n₁ + 1，把度为1的结点数当作度为2的结点数
- 选项D（干扰）：遗漏分解步骤——直接取 (n - n₁ - 1) 或 (n - n₁) 作为叶子结点数，忘记还需除以2或忘记排除n₂
- 约束：四个选项的数值互不相同；正确答案在选项中随机排列

## terminology_and_expression_constraints
- 必须用词："二叉树"（不限定完全/满/正则）、"叶结点"（或"叶子结点"）、"度为1的结点"
- 限定语：题干须明确"一棵二叉树共有 ___ 个结点"，不使用"至少""至多"等模糊修饰
- 禁止表述：不提"完全二叉树""满二叉树""二叉排序树"等特化类型；不给树的图示；不涉及遍历序列
- 干扰项不暗示推理路径（不在选项中标注公式，只给数值）

## audit_focus
1. **公式自洽性**：参数 n 和 n₁ 须满足 (n - n₁ - 1) 为正偶数，确保 n₂ 和 n₀ 均为正整数——若不满足则题目无合法解
2. **选项区分度**：四个选项对应四个不同错误路径，结果必须互不相同；特别检查"混淆方向"的干扰值是否恰好等于正确值（当参数退化时可能重合）
3. **知识点对齐**：题干不得出现完全二叉树/满二叉树等特化类型描述，否则考点偏移到 should_not_be
4. **条件充分性**：仅给 n 和 n₁ 两个条件即可唯一确定 n₀，不得多余给 n₂（否则退化为一步代入，难度降到1）
5. **n₁ ≥ 1**：度为1的结点数须非零正整数，避免 n₁=0 时退化为满二叉树特例
