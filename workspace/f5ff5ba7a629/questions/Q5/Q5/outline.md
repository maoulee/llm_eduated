## 考点
- **核心知识点**：二叉树叶子结点数与度为2结点数的关系（n₀ = n₂ + 1）
  - 考察侧重点：由给定的结点度数信息（如度为1的结点数、总结点数），推算叶子结点数
- **辅助知识点**：二叉树结点总数公式（n = n₀ + n₁ + n₂）
  - 考察侧重点：将总结点数分解为各度数结点数，再利用 n₀ = n₂ + 1 求解

## 难度目标
- **K1=2**：需回忆 n₀ = n₂ + 1 这一核心公式，但属二叉树基础性质，概念辨析要求不高
- **K2=3**：需代入公式做常规整数计算，数字非2的幂次，存在算错可能
- **K3=2**：仅需2步以内推导（代入公式→求值），路径唯一
- **K4=2**：存在常规注意点（需正确识别已知的是哪个度数的结点数），但无深层陷阱
- **K5=1**：单一知识点内部解决，不涉及跨子系统

## 考察模式
**计算型——二叉树性质应用**
理由：slot 明确指定该考察模式。该模式要求学生利用二叉树度数关系公式，从给定的部分结点信息推算未知结点数，属标准计算型选择题，难度可控且区分度好。

## 出题要求
- **题型**：单项选择题（4选项，1正确3干扰）
- **分值**：2分
- **总条件数**：2-3个显式条件
- **条件设计原则**：
  - 给出二叉树的部分度数信息（如总结点数 + 度为1的结点数，或度为2的结点数 + 度为1的结点数）
  - 条件必须充分且唯一确定叶子结点数，不能冗余
  - 条件表述应避免直接暴露解题路径（不出现"求n₀"字样，而用"叶子结点数"表述）
- **参数取值范围要求**：
  - 总结点数 n：取值范围 7~127（保证树有足够规模但计算不过繁）
  - 度为1的结点数 n₁：取值范围 1~n-2（保证 n₂ ≥ 1，使公式有实际意义）
  - 所有数值须为正整数，且满足 n₀ = n₂ + 1 后 n₀ ≥ 2

## 参数约束
- **参数1：总结点数 n**
  - 取值范围：7 ≤ n ≤ 127，正整数
  - 一致性约束：n = n₀ + n₁ + n₂ 必须成立
- **参数2：度为1的结点数 n₁**
  - 取值范围：1 ≤ n₁ ≤ n - 3，正整数
  - 一致性约束：n₁ 与 n 的奇偶性须使得 n₂ 为正整数
- **可调自由度**：Question Agent 可自由选择给 n₁ 还是给 n₂ 作为已知条件，但必须保证条件组能唯一确定 n₀
- **约束关系（求解链）**：
  - 若给 n 和 n₁：n₂ = (n - n₁ - 1) / 2，n₀ = n₂ + 1，要求 (n - n₁ - 1) 为正偶数
  - 若给 n₂ 和 n₁：n₀ = n₂ + 1，n = n₀ + n₁ + n₂，直接可求
- **干扰项设计约束**：各干扰项须对应不同的典型错误路径，且错误路径产生的结果互不相同

## 参考经验
- **历史模式**：二叉树性质计算是选择题高频考法，常以"已知总结点数和度为某值的结点数，求叶子结点数"出现
- **难度锚点**：该类题目 K2 通常为 2-3，计算量适中，区分度好
- **典型陷阱**：
  - 混淆 n₀ 和 n₂（忘记 +1 或 -1 方向错）
  - 误将度为1的结点数代入度为2的公式
  - 忘记总结点数包含所有度数的结点
