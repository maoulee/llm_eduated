## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树遍历
- primary_target_name: 给后序+中序还原二叉树写出先序序列
- question_type: comprehensive
- examination_mode: 推演型——遍历序列还原二叉树

### 难度目标
- k_target: K1=1,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 核心负荷在 K3（多步递归推演还原二叉树，步数 >5 且需维持中间状态），K1/K2/K5 均低，K4 有常规注意点但无明显陷阱。整体难度定位中等偏上，与 target_difficulty=3 吻合。

### 结构要求
- sub_question_count: 2
- sub_question_design:
  - 第1问: 画出还原后的二叉树（分析/推演，6分，串行上游）
  - 第2问: 写出先序遍历序列（执行，4分，依赖第1问结果）
- condition_count: 2（后序遍历序列、中序遍历序列）

### 参数约束
- 节点数 N: 7 ≤ N ≤ 9，建议 7 或 8
- 键值: N 个互不相同的单字符（A-I 或 1-9）
- 后序序列: 长度 N，末尾为根节点
- 中序序列: 长度 N，与后序序列对应同一棵二叉树
- 一致性约束: 两序列元素集合相同；存在唯一二叉树满足两序列分别为其后序和中序遍历
- 树形态约束: 非满二叉树、非完全二叉树、左右子树非对称、树高 ≥3
- 可调自由度: Question Agent 自由选择具体键值、树形态及对应序列

### 参考经验摘要
- 历史模式: 遍历序列还原二叉树为高频考法（2026_Q3、2012_Q3），核心流程为"给定两种遍历序列→还原树→回答结构/遍历问题"
- 难度锚点: K3 典型值 3-4，节点数 5-9，K1/K2/K5 普遍 1-2
- 典型陷阱: 后序根在末尾易与先序混淆；中序左右子树方向不能搞反；递归需正确处理空子树
