## blueprint_contract

- slot_id: comprehensive_tree_traversal
- question_type: comprehensive
- score: 10
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树遍历
- primary_target_name: 给后序+中序还原二叉树写出先序序列
- examination_mode: 推演型——遍历序列还原二叉树
- k_target: K1=1, K2=2, K3=4, K4=2, K5=1
- difficulty_level: 3
- should_be:
  - 节点数 N 在 7~9 之间（建议 7 或 8）
  - 键值为 N 个互不相同的单字符（A-I 或 1-9）
  - 给出后序遍历序列和中序遍历序列
  - 两序列元素集合相同，存在唯一二叉树满足
  - 树形态：非满、非完全、左右非对称、树高 ≥3
  - 两问结构：第1问画出还原后的二叉树（6分），第2问写出先序遍历序列（4分）
  - 第2问依赖第1问结果，串行依赖
- should_not_be:
  - 不要给先序序列（那是要求学生求的结果）
  - 不要给完全二叉树或满二叉树（形态过于规整，降低还原难度）
  - 不要节点数 <7 或 >9
  - 不要左右子树对称（降低推演负荷）
  - 不要单问形式
- hard_constraints:
  - 后序序列末尾元素 = 树根节点
  - 中序序列根节点位置分割左右子树
  - 树高 ≥3，确保递归深度 ≥2 层
  - 两问必须为串行依赖：第2问以第1问还原的树为输入
  - excluded: 先序遍历序列（不能在题干中给出）

## core_knowledge_intent

- must_test:
  1. 后序+中序序列还原二叉树的完整递归过程——从后序定位根、从中序分割左右子树、递归处理子树
  2. 先序遍历序列的正确输出——对还原后的二叉树执行先序遍历（根→左→右）
  3. 递归过程中中间状态的正确维持——每层递归的正确定位根节点与子树区间
- must_not_shift_to:
  - 偏移到仅考先序遍历定义而不需还原树（降低为纯遍历执行）
  - 偏移到线索二叉树 / 哈夫曼树等其他树结构
  - 偏移到完全二叉树性质推断（数组存储推断父子关系）
- coverage_success_criteria:
  - 学生必须完成"还原树 → 写先序"全链条，两问均有实质内容
  - 第1问能区分"能否正确还原树结构"（考察 K3 多步递归推演）
  - 第2问能区分"在已还原树的基础上能否正确执行先序遍历"（考察 K2 执行 + K4 注意左右顺序）

## design_rationale

**考察意图**：后序+中序还原二叉树是数据结构高频核心考点（历年反复出现），本题通过"还原树 + 写先序"两问结构，完整覆盖"序列→树→序列"的核心转换链条。

**为什么两问而非单问**：
- 单问仅写先序序列无法判断学生是在正确还原的树上遍历，还是在错误树上遍历但恰好部分正确——两问结构让还原过程本身可被评分（第1问占6分，是主负荷）。
- 第1问（画树）直接暴露学生的还原推理是否正确，第2问（先序）则在此基础上考察遍历执行。串行依赖确保第2问的考察有实际意义。

**区分度设计**：
- 第1问区分"能否完成多步递归还原"（K3=4 的核心负荷）：7~8 个节点、树高≥3、左右非对称，要求学生至少完成 2~3 层递归才能正确还原。非满非完全避免学生通过补全规律猜树结构。
- 第2问区分"能否在还原树上正确执行先序遍历"（K2=2 + K4=2）：先序遍历本身不难，但在非对称树上容易搞混左右子树顺序。
- 树高 ≥3 + 左右非对称确保递归深度足够、方向判断有区分度。

**为什么难度=3 合适**：核心负荷集中在 K3=4（多步递归推演），K1/K2/K5 低，K4 有常规注意点（左右方向）但无明显陷阱。整体中等偏上，符合 difficulty_level=3。

**考点融合**：无额外融合需求。本题是同一知识点（二叉树遍历与还原）的递进考察，不涉及跨考点融合。

## question_structure_plan

- 复用骨架来源：历年真题（2026_Q3、2012_Q3）——设问模式为"给定后序+中序序列→还原树→回答遍历/结构问题"，提炼设问骨架：第1问还原树结构，第2问基于还原结果回答遍历序列。
- 题干：给出后序遍历序列和中序遍历序列（均为长度 N=7~8 的单字符序列），说明两序列对应同一棵二叉树。
- 子问1：画出由给定后序序列和中序序列还原出的二叉树（基础+核心层，6分）—— 参考往年同类题的问法："根据给定的后序遍历序列和中序遍历序列，画出该二叉树。"
  - 考察：后序定位根节点（末尾元素）、中序分割左右子树、递归处理子区间——完整的多步递归还原过程
  - 评分要点：左右子树结构是否正确还原（树高 ≥3 确保至少 2 层递归）
- 子问2：写出该二叉树的先序遍历序列（进阶层，4分）—— 参考往年同类题的问法："写出该二叉树的先序遍历序列。"
  - 考察：在第1问还原的二叉树上执行先序遍历（根→左→右），输出完整先序序列
  - 评分要点：先序序列是否正确（依赖第1问的树结构正确 + 先序遍历顺序正确）
- dependency_pattern：串行依赖（第2问以第1问还原的二叉树为输入，第1问错误则第2问必然错误）

## terminology_and_expression_constraints

- 必须明确说明"后序遍历序列"和"中序遍历序列"两个术语，不可简称或混用
- 必须说明"两序列对应同一棵二叉树"
- 第1问用"画出"或"还原"明确要求图示，而非仅文字描述
- 第2问用"写出……的先序遍历序列"，明确要求输出序列
- 禁止在题干中出现"先序"相关序列作为已知条件
- 键值用单字符（字母或数字），确保序列无歧义
- 不需要额外解释遍历的定义（默认学生已知先/中/后序的定义）

## audit_focus

1. **树形态约束检查**：确认参数满足非满、非完全、左右非对称、树高 ≥3——若退化则 K3 负荷不足，题目失效
2. **序列一致性检查**：后序序列与中序序列的元素集合是否完全相同——集合不同则无解
3. **唯一性检查**：是否存在唯一二叉树满足两序列——若不唯一则第1问答案不唯一，题目失效
4. **先序序列不可泄露**：题干中不得出现先序遍历序列或可直接推出先序的额外信息
5. **子问依赖合理性**：第2问必须依赖第1问结果（先序序列的获取必须基于还原后的树）
6. **难度匹配**：节点数 7~9、树高 ≥3 确保 K3 ≥3 步递归；若实际参数导致递归步数 <3 则难度不足
7. **评分比重**：第1问 6 分 / 第2问 4 分，分值分配是否与考察负荷匹配（第1问是核心推演，应占多数分）
