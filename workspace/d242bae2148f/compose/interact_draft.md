## 方案 A：侧重线性结构与树

### 选择题（10题·2分）

## Q1（选择题·2分）[complexity: standard]
[ ] 顺序表操作代价 — 顺序表插入/删除的平均移动次数计算
[ ] 静态链表游标 — 静态链表插入删除时的游标更新过程

## Q2（选择题·2分）[complexity: conceptual]
[ ] 栈的应用 — 括号匹配或表达式求值中栈的操作序列
[ ] 共享栈判满 — 共享栈两个栈顶指针的判满条件

## Q3（选择题·2分）[complexity: standard]
[ ] 循环队列计算 — 给定front/rear求元素个数或入队后指针变化
[ ] 双端队列序列判断 — 判断某序列能否由输入/输出受限双端队列产生

## Q4（选择题·2分）[complexity: standard]
[ ] 朴素模式匹配 — 给定主串和模式串，计算匹配过程中的比较次数
[ ] KMP nextval数组 — 给定模式串求解nextval数组的值

## Q5（选择题·2分）[complexity: standard]
[ ] 完全二叉树性质 — 完全二叉树结点编号与双亲/孩子编号的关系
[ ] 二叉树遍历序列合法性 — 判断给定先序+中序序列能否唯一确定二叉树

## Q6（选择题·2分）[complexity: standard]
[ ] 哈夫曼编码长度 — 给定字符集权值，计算哈夫曼编码的总长度或WPL
[ ] 平衡二叉树旋转 — 给定插入序列，判断AVL树需要的旋转类型（LL/RR/LR/RL）

## Q7（选择题·2分）[complexity: standard]
[ ] 拓扑排序 — 给定AOV网，判断合法的拓扑序列
[ ] 图的存储结构 — 邻接矩阵与邻接表的空间复杂度对比

## Q8（选择题·2分）[complexity: standard]
[ ] 关键路径计算 — 给定AOE网，计算事件最早/最迟发生时间
[ ] Floyd算法 — 给定有向网，求所有顶点对最短路径的中间结果

## Q9（选择题·2分）[complexity: standard]
[ ] 散列查找ASL — 给定散列函数和冲突处理方法，计算查找成功/失败ASL
[ ] 拉链法散列表 — 给定关键字序列和散列函数，构造拉链法散列表

## Q10（选择题·2分）[complexity: standard]
[ ] 归并排序一趟结果 — 给定初始序列，求二路归并排序第一趟后的序列
[ ] 堆排序建堆 — 给定初始序列，求初始建堆（大根堆）后的序列

### 应用题（4题·10分）

## Q11（应用题·10分）[complexity: standard]

## Q13（应用题·10分）[complexity: standard]

[ ] 分块查找 — 给定数据和分块方案，画出索引表并计算查找某元素的ASL

## Q14（应用题·10分）[complexity: standard]
[ ] 快速排序+希尔排序 — 模拟快速排序第一趟划分和希尔排序第一趟增量排序的过程
[ ] 冒泡排序+直接插入排序 — 模拟冒泡排序第一趟和直接插入排序插入第k个元素的过程

### 算法分析题（2题·5分）

## Q16（算法分析·5分）[complexity: standard]

[ ] 后序递归遍历代码 — 分析二叉树后序遍历的递归代码，求时间复杂度或递归深度

### 算法设计题（2题·14+16分）

## Q17（算法设计·14分）[complexity: standard]

[ ] 链表合并 — 设计算法将两个有序单链表合并为一个有序单链表，要求分析复杂度

## Q18（算法设计·16分）[complexity: standard]
