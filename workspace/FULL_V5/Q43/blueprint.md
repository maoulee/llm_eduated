## 知识点
- 计算机组成原理 - Cache 系统
- 地址映射方式（直接映射、组相联映射）
- 主存地址结构划分（标记 Tag、索引 Index/行号、块内偏移 Offset）
- Cache 命中率计算

## 难度
- 综合难度：K3
- 计算维度：K3（需要多步位运算和数值换算）
- 逻辑分析：K3（理解不同映射方式下的地址结构变化及替换过程）

## 出题要求
- 题型：综合计算与分析题
- 核心场景：给定主存地址及 Cache 参数，要求解析地址结构，并根据给定的访问序列计算命中率。
- 考察重点：
    1. 熟练掌握直接映射和组相联映射的地址划分方法。
    2. 能够对比两种映射方式下 Tag 和 Index 位数的变化。
    3. 在组相联映射下，通过 LRU 或 FIFO 替换算法计算命中/缺失次数。

## 子问题规划
1. **子问题 1（4 分）**：【计算】假设 Cache 采用直接映射方式，计算 Tag、Index、Offset 的位数，并给出一个具体主存地址（如 12345678H）对应的这三级字段值（十六进制表示）。
2. **子问题 2（4 分）**：【分析/计算】假设 Cache 改为 2 路组相联映射（组内采用 LRU 算法），计算 Tag、Index、Offset 的位数变化。
3. **子问题 3（4 分）**：【计算】给出一串主存地址访问序列（如 5 个地址），在 2 路组相联映射下（初始为空），计算该序列的 Cache 命中率。

## 参数约束
- 主存地址长度：32 bit
- 块大小 (Block Size)：64 Byte（Offset 占 6 bit）
- Cache 总容量：2048 Byte (2KB)
- 直接映射行数：2048 / 64 = 32 行（Index 占 5 bit）
- 组相联路数：2 路（每组 2 行），组数 = 16 组（Index 占 4 bit）
- 访问序列设计：需包含冲突访问（对相同 Set 的不同 Block 的访问）以体现替换算法逻辑。
