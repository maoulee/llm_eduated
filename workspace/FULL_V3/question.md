## 题干
某计算机系统采用字节编址，主存地址长度为32位。Cache容量为64KB，采用4路组相联（4-way set associative）映射方式，数据块大小（Block Size）为128字节。系统Cache访问时间为 $T_c = 10\text{ns}$，主存访问时间为 $T_m = 100\text{ns}$。假设Cache初始状态为空。

## 子问题
（综合题：总分11分）
### (1)（4分）
请根据Cache物理参数，计算主存地址中标记（Tag）、组号（Index）和块内偏移（Offset）的位数；计算Cache的总组数（Sets）；并指出该Cache采用的映射方式。
### (2)（4分）
CPU依次访问主存地址 `0x00001000` 和 `0x00001020`（十六进制）。
① 判断第一次访问 `0x00001000` 是否命中，并说明理由；指出该地址映射到Cache的哪一组（写出组号的十进制值）。
② 判断第二次访问 `0x00001020` 是否命中，并说明理由。
### (3)（3分）
若系统要求平均访存时间（AMAT）不超过 **12ns**，请计算Cache命中率 $H$ 的最小值；并简要分析当Cache块大小翻倍（变为256字节）时，对命中率 $H$ 和 AMAT 可能产生的双向影响。

## 答案
**（1）**
*   **块内偏移（Offset）**：$Block Size = 128 = 2^7$，故 **Offset = 7位**。
*   **总行数**：$Capacity / Block Size = 64\text{KB} / 128\text{B} = 512$ 行。
*   **总组数（Index）**：$Total Lines / Ways = 512 / 4 = 128$ 组。$128 = 2^7$，故 **Index = 7位**。
*   **标记（Tag）**：主存地址32位，$Tag = 32 - 7 - 7 = $ **18位**。
*   **映射方式**：**4路组相联映射**。

**（2）**
*   **① 访问 `0x00001000`**：
    *   **判断**：**缺失（Miss）**。
    *   **理由**：Cache初始为空，首次访问均为冷缺失（Cold Miss）。
    *   **组号计算**：地址 `0x00001000` 二进制低16位为 `0001 0000 0000 0000`。
        末7位为Offset（`0000000`），中间7位为Index（`0100000`）。
        $0100000_2 = 32_{10}$。
        故映射到第 **32** 组。
*   **② 访问 `0x00001020`**：
    *   **判断**：**命中（Hit）**。
    *   **理由**：
        1.  **组号相同**：`0x00001020` = `0x00001000` + 32。由于块大小128B，两地址在同一块内，Index（组号）仍为32。
        2.  **标记相同**：高18位Tag均为0。
        3.  **有效性**：第一次访问已将数据块调入Cache第32组，该行有效。
        组相联映射在组号与标记均匹配时命中，与块内偏移（Offset）无关。

**（3）**
*   **计算 H 最小值**：
    由公式 $AMAT = T_c + (1 - H) \times T_m \le 12$，代入已知参数：
    $$10 + (1 - H) \times 100 \le 12$$
    $$100(1 - H) \le 2$$
    $$1 - H \le 0.02$$
    $$H \ge 0.98$$
    故命中率最小值为 **0.98（或98%）**。
*   **块大小翻倍的影响分析**：
    *   **对命中率 $H$**：
        1.  **正向（提升）**：块增大（128B→256B）能更好地利用程序的**空间局部性**，减少强制性缺失（Compulsory Miss），有利于提高 $H$。
        2.  **负向（降低）**：在Cache总容量不变的情况下，块增大导致Cache可容纳的总行数减半，进而导致组数减半（从128组降至64组）。组数减少会增加冲突缺失（Conflict Miss）的概率，可能降低 $H$。
    *   **对 AMAT**：
        1.  **正向（降低）**：若命中率 $H$ 因空间局部性得到显著提升，缺失率 $(1-H)$ 下降，从而使 AMAT 降低。
        2.  **负向（升高）**：块增大意味着每次缺失时从主存传输的数据量翻倍，导致缺失惩罚 $T_m$ 增加；若组数减半导致的 $H$ 下降超过预期，AMAT 也会升高。

## 设计说明
- **出题意图**：本题综合考查Cache地址映射机制（Tag/Index/Offset计算、映射组号追踪、命中判断）与性能建模分析（AMAT反推、块大小权衡）。
- **参数修正与设计理由**：
    - **AMAT阈值（12ns）**：蓝图设定了严格的阈值12ns。在 $T_c=10\text{ns}$ 的情况下，这要求缺失惩罚项 $(1-H)T_m \le 2\text{ns}$，计算得出命中率门槛为98%。虽然该数值高于常规Cache命中率（通常85%-95%），但这符合K3难度对严密数学建模能力的考察要求，旨在区分仅凭经验答题与严谨推导的考生。
    - **地址追踪（`0x00001020`）**：选用与首地址同块但偏移不同的地址，专门用于测试考生对“组相联映射命中条件（仅由组号和标记决定）”的掌握，排除“Offset变化导致Miss”的常见误区。
- **易错点设计**：
    - **位数计算**：忽略字节编址导致Offset计算错误；混淆组数（Sets）与行数（Lines）的关系。
    - **AMAT计算**：公式应用错误（如忽略 $T_c$ 或在代数运算中出错）。
    - **定性分析**：片面分析块大小影响，未能辩证指出“空间局部性提升”与“冲突缺失增加”的双向矛盾。
