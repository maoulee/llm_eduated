## 知识点

| 编号 | 知识点 | 考察侧重点 |
|------|--------|-----------|
| KP1 | IEEE 754 单精度浮点数格式 | 符号位(1bit)、阶码(8bit)、尾数(23bit)的字段划分；隐含前导1；偏置值127；规格化数与非规格化数的区分边界 |
| KP2 | 对阶操作 | 小阶向大阶看齐原则；尾数右移与阶码递增的同步；右移过程中被移出位的保留（guard/round/sticky） |
| KP3 | 尾数相加 | 带隐含位的24位尾数运算；同号相加与异号相减两种情况；补码/原码表示下的运算方式 |
| KP4 | 规格化处理 | 右规（尾数溢出时）与左规（前导零消除时）的触发条件与执行方式；规格化后阶码的同步调整 |
| KP5 | 舍入与溢出判断 | 就近舍入（round to nearest even）规则；阶码上溢（+∞/溢出标志）与阶码下溢（非规格化/0）的判断条件 |

## 难度

| 维度 | 目标等级 | 达标理由 |
|------|---------|---------|
| K1 基础认知需求 | **3** | 必须准确记忆 IEEE 754 单精度格式的字段定义（1-8-23结构）、偏置值127、隐含前导1规则，模糊记忆无法正确完成转换 |
| K2 单步代入需求 | **3** | 涉及十进制→二进制小数转换、阶码偏置计算、尾数移位等常规单步计算，数字不全是2的幂次友好值，存在算错可能但不会极端复杂 |
| K3 机制推演需求 | **3** | 需按"提取字段→对阶→尾数相加→规格化→舍入→溢出判断"的标准固定流程走完4-5步，路径唯一，步数适中 |
| K4 条件路由需求 | **3** | 存在明确的隐含条件：对阶方向选择、异号相加时的尾数相减处理、规格化方向的判断（左规还是右规），不识别则用错流程 |
| K5 跨域联动需求 | **2** | 题目限定在"数据表示"与"运算器底层执行逻辑"的组内结合，提及运算器实现细节（如舍入位保留）但无跨子系统状态传递 |

## 出题要求

- **题型**：综合大题（计算分析型），无选择题，要求完整解答过程
- **子问题数**：4问
- **总条件数**：给出两个十进制实数作为加法操作数（一正一负，保证尾数相减场景），附带简要运算器上下文描述
- **答案格式**：每问需写出关键中间步骤 + 二进制/十六进制最终结果
- **条件设计原则**：
  - 题干给出两个十进制浮点数，要求学生手动完成 IEEE 754 单精度加法全过程
  - 两个操作数一正一负，触发异号相加（实质为尾数相减），从而引入左规场景
  - 两个操作数阶码不同（差值在2~6之间），触发对阶操作
  - 运算结果应触发舍入（尾数超出23位精度），但不触发阶码溢出
  - 题干可简述"某计算机采用IEEE 754单精度浮点数格式，采用就近舍入（round to nearest even）策略"，为舍入规则提供依据
- **参数取值范围要求**：
  - 两个十进制数绝对值在 1.0 ~ 20.0 范围内
  - 至少一个数为非2的幂次的小数（如含0.1, 0.3, 0.6等小数部分），确保十进制→二进制转换有实际计算量
  - 两数绝对值差值适中（倍数关系在2~16之间），保证对阶移位量在2~6位
  - 两数符号相反且绝对值不完全相等，保证结果非零且需左规

## 子问题规划

### 第1问（分值：3分）
- **类型**：计算
- **考察目标**：将给定的两个十进制实数分别转换为 IEEE 754 单精度浮点数的二进制表示（写出符号位、阶码、尾数三段）
- **与前后问关系**：为第2问的对阶操作提供运算所需的字段拆分基础
- **关键要求**：
  - 学生需写出完整的32位二进制或等价的十六进制表示
  - 必须体现隐含前导1的理解（尾数字段不含整数位的1）
  - 阶码需用偏置形式表示

### 第2问（分值：3分）
- **类型**：计算 + 分析
- **考察目标**：执行对阶操作，写出对阶后两个操作数的阶码值和尾数（含移出位）
- **与前后问关系**：基于第1问的字段拆分结果，确定对阶方向和移位量；为第3问的尾数相加提供对齐后的操作数
- **关键要求**：
  - 明确指出小阶向大阶看齐
  - 写出尾数右移的具体位数
  - 需体现被移出位的保留意识（guard/round/sticky概念，至少口头说明移出位如何处理）

### 第3问（分值：5分）
- **类型**：计算 + 分析
- **考察目标**：完成尾数相加（含符号处理），执行规格化（左规或右规），写出规格化后的阶码与尾数
- **与前后问关系**：基于第2问对齐后的尾数执行相加；本问是全题核心环节，运算步骤最多
- **关键要求**：
  - 由于两数异号，需执行尾数相减（或补码相加）
  - 相减结果必有前导零，需执行左规：尾数左移、阶码递减
  - 写出左规的移位次数及调整后的阶码值
  - 需判断是否需要右规（本题设计中应不需要右规，但学生需说明判断依据）

### 第4问（分值：4分）
- **类型**：计算 + 分析
- **考察目标**：执行舍入操作（就近舍入到偶），判断是否溢出，写出最终结果的 IEEE 754 单精度二进制/十六进制表示
- **与前后问关系**：基于第3问规格化后的尾数，处理超出23位精度的多余位；给出全流程最终输出
- **关键要求**：
  - 应用 round to nearest even 舍入规则
  - 说明舍入是否导致尾数再溢出（需再右规的情况）
  - 判断最终阶码是否溢出（上溢/下溢），本题设计应为不溢出，但学生需给出判断
  - 输出完整的32位最终结果（二进制 + 十六进制）

## 参数约束

### 操作数参数

| 参数 | 约束 | 说明 |
|------|------|------|
| 操作数A（正数） | 绝对值 ∈ [2.0, 20.0]，含非平凡小数部分 | 作为大阶操作数，十进制小数部分转二进制应为无限循环或有限但>8bit的模式 |
| 操作数B（负数） | 绝对值 ∈ [1.0, A的绝对值)，与A符号相反 | 作为小阶操作数，保证对阶时B的尾数右移 |
| 阶码差 d | d ∈ [2, 6] | 控制对阶移位量，不太简单也不太复杂 |
| 尾数相减结果的前导零个数 | ∈ [1, 4] | 保证左规移位量适中，结果非零 |
| 规格化后尾数有效位数 | > 23 bit | 保证第4问舍入有实际内容 |

### 一致性约束

1. **格式约束**：两个操作数均为 IEEE 754 规格化数（非零、非无穷、非NaN），即阶码字段 ∈ [1, 254]
2. **对阶方向约束**：\|A\| > \|B\|（A为大阶），对阶时B的尾数右移d位
3. **符号约束**：A > 0, B < 0（或反之），保证异号相加触发尾数相减
4. **规格化约束**：相减结果产生前导零（因\|A\| ≠ \|B\|），需左规；左规后阶码仍 ≥ 1（不下溢）
5. **舍入约束**：左规后尾数精度超出23位，需执行就近舍入；舍入后不引发再右规（或若引发再右规，阶码仍 ≤ 254，不上溢）
6. **结果非零约束**：\|A\| ≠ \|B\|，最终结果为规格化非零浮点数

### 可调自由度

- 操作数A、B的具体十进制数值（在上述约束范围内自由选择）
- 是否让舍入后触发一次再右规（增加复杂度但仍在K=3范围内，Question Agent可自行决定）
- 题干是否附带运算器硬件背景描述（如ALU寄存器位宽提示）的自由度

## 经验参考说明

参考2020、2013、2011年真题中浮点数运算题的模式：
- 历年真题通常给出两个具体浮点数，要求手算加法全过程
- 考查重点覆盖：格式转换→对阶→尾数运算→规格化→舍入的完整链路
- 本蓝图遵循该模式，但在操作数选择上确保触发异号相减+左规+舍入三个关键机制节点，避免题目退化为简单的同号相加+右规套路
