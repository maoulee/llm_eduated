=== 磁盘参数与I/O模式参数 ===
转速: 7200 RPM
平均寻道时间: 10.0 ms
扇区大小: 512 B
每磁道扇区数: 128
需读取扇区数: 16
DMA每扇区总线占用: 25 μs
DMA中断处理开销: 60 μs
PIO每扇区耗时: 120 μs

=== (1) 磁盘物理访问时间 T_disk 与 DMA 总线占用时间 T_bus ===
1. 旋转周期 T_rot = 60000 / 7200 ≈ 8.33 ms
   平均旋转延迟 T_rot_avg = T_rot / 2 ≈ 4.17 ms
2. 传输时间 T_trans = (16 / 128) × 8.33 ≈ 1.04 ms
3. 磁盘物理访问时间 T_disk = T_seek + T_rot_avg + T_trans
   T_disk = 10.0 + 4.17 + 1.04 = 15.21 ms
4. DMA总线占用总时间 T_bus = 16 × 25 μs = 400 μs = 0.4 ms
   【答案】T_disk = 15.21 ms, T_bus = 0.4 ms

=== (2) 有效吞吐率计算与性能分析 ===
1. DMA模式有效吞吐率:
   - 传输阶段耗时取 max(T_trans, T_bus) = max(1.04, 0.4) = 1.04 ms
   - DMA总耗时 T_DMA = T_seek + T_rot_avg + max(T_trans, T_bus) + T_int
     T_DMA = 10.0 + 4.17 + 1.04 + 0.06 = 15.27 ms
   - 数据总量 D = 16 × 512 = 8192 B
   - 有效吞吐率 Throughput_DMA = 8192 / (15.27 × 10^-3) ≈ 536477 B/s ≈ 0.54 MB/s
2. PIO模式有效吞吐率:
   - PIO每扇区耗时 120 μs，16 扇区总耗时 T_pio_trans = 16 × 120 = 1920 μs = 1.92 ms
   - PIO传输阶段耗时取 max(T_trans, T_pio_trans) = max(1.04, 1.92) = 1.92 ms
   - PIO总耗时 T_PIO = 10.0 + 4.17 + 1.92 = 16.09 ms
   - 有效吞吐率 Throughput_PIO = 8192 / (16.09 × 10^-3) ≈ 509136 B/s ≈ 0.51 MB/s
3. 性能差异分析:
   - 两者吞吐率数值接近（0.54 vs 0.51 MB/s），说明磁盘 I/O 的瓶颈主要在于机械延迟（寻道与旋转），而非 CPU 或总线带宽。
   - DMA 优势：在传输阶段（1.04 ms），DMA 控制器独立搬运数据，CPU 可并行执行其他进程指令，仅在中断时（0.06 ms）介入，CPU 利用率高，系统并发能力强。
   - PIO 劣势：CPU 需全程参与数据搬运（1.92 ms），严重占用 CPU 时间片，导致系统整体吞吐量下降，适用于低速设备或数据量极小的场景。
   【答案】DMA 吞吐率约 0.54 MB/s，PIO 吞吐率约 0.51 MB/s。差异主因在于 DMA 释放了 CPU，提升了系统并发处理能力，而磁盘机械延迟主导了 I/O 总耗时。
