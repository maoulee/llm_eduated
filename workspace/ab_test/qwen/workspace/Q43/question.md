## 题干
某计算机系统采用单磁盘存储设备，磁盘参数如下：转速为 7200 RPM，平均寻道时间为 10 ms，扇区大小为 512 B，每磁道包含 128 个扇区。现需从该磁盘连续读取 16 个扇区的数据（假设这 16 个扇区位于同一磁道且物理地址连续）。系统支持 DMA（直接存储器访问）和 PIO（程序查询）两种 I/O 传输模式，相关机制说明如下：
- **DMA 模式**：磁盘控制器将数据读入内部缓冲区后，通过 DMA 控制器向内存传输。DMA 每传输 1 个扇区需占用系统总线 25 μs。DMA 传输过程与磁盘物理读取过程可并行执行。整个数据块传输完成后，DMA 控制器向 CPU 发送中断请求，中断处理开销为 60 μs。
- **PIO 模式**：CPU 直接参与数据传输，每传输 1 个扇区，CPU 指令执行与总线传输串行进行，共需耗时 120 μs/扇区。PIO 传输过程与磁盘物理读取过程可并行执行，传输阶段总耗时取两者最大值。

注：计算中取 1 MB = 10^6 B，所有时间计算结果保留两位小数。

## 子问题
### (1)（6分）
计算读取该 16 个扇区数据的磁盘物理访问时间 $T_{disk}$（包含寻道时间、平均旋转延迟和传输时间），以及 DMA 控制器完成此次传输占用总线的总时间 $T_{bus}$。请列出计算公式并代入参数求解。

### (2)（4分）
计算 DMA 模式下的有效数据吞吐率（MB/s）。若改用 PIO 模式，计算其有效吞吐率，并简要分析两种模式下系统整体性能差异的主要原因。

## 答案
### (1) 磁盘物理访问时间 $T_{disk}$ 与 DMA 总线占用时间 $T_{bus}$
1. **旋转周期与平均旋转延迟**：
   $T_{rot} = 60000 / 7200 \approx 8.33$ ms
   $T_{rot\_avg} = T_{rot} / 2 \approx 4.17$ ms
2. **传输时间**：
   $T_{trans} = (16 / 128) \times T_{rot} = 0.125 \times 8.33 \approx 1.04$ ms
3. **磁盘物理访问时间**：
   $T_{disk} = T_{seek} + T_{rot\_avg} + T_{trans} = 10 + 4.17 + 1.04 = 15.21$ ms
4. **DMA 总线占用总时间**：
   $T_{bus} = 16 \times 25 \mu s = 400 \mu s = 0.40$ ms

**答案**：$T_{disk} = 15.21$ ms，$T_{bus} = 0.40$ ms。

### (2) 有效吞吐率计算与性能分析
1. **DMA 模式有效吞吐率**：
   - DMA 传输与磁盘物理传输并行，传输阶段耗时取 $	ext{max}(T_{trans}, T_{bus}) = 	ext{max}(1.04, 0.40) = 1.04$ ms。
   - DMA 总耗时 $T_{DMA} = T_{seek} + T_{rot\_avg} + 	ext{max}(T_{trans}, T_{bus}) + T_{int} = 10 + 4.17 + 1.04 + 0.06 = 15.27$ ms。
   - 数据总量 $D = 16 \times 512 = 8192$ B。
   - 有效吞吐率 $Throughput_{DMA} = 8192 / (15.27 \times 10^{-3}) \approx 536476$ B/s $\approx 0.54$ MB/s。

2. **PIO 模式有效吞吐率**：
   - PIO 每扇区耗时 120 μs，16 扇区总耗时 $T_{pio\_trans} = 16 \times 120 = 1920 \mu s = 1.92$ ms。
   - PIO 传输阶段耗时取 $	ext{max}(T_{trans}, T_{pio\_trans}) = 	ext{max}(1.04, 1.92) = 1.92$ ms。
   - PIO 总耗时 $T_{PIO} = 10 + 4.17 + 1.92 = 16.09$ ms。
   - 有效吞吐率 $Throughput_{PIO} = 8192 / (16.09 \times 10^{-3}) \approx 509136$ B/s $\approx 0.51$ MB/s。

3. **性能差异分析**：
   - 两者吞吐率数值接近（0.54 vs 0.51 MB/s），说明磁盘 I/O 的瓶颈主要在于机械延迟（寻道与旋转），而非 CPU 或总线带宽。
   - **DMA 优势**：在传输阶段（1.04 ms），DMA 控制器独立搬运数据，CPU 可并行执行其他进程指令，仅在中断时（60 μs）介入，CPU 利用率高，系统并发能力强。
   - **PIO 劣势**：CPU 需全程参与数据搬运（1.92 ms），严重占用 CPU 时间片，导致系统整体吞吐量下降，适用于低速设备或数据量极小的场景。

**答案**：DMA 吞吐率约 0.54 MB/s，PIO 吞吐率约 0.51 MB/s。差异主因在于 DMA 释放了 CPU，提升了系统并发处理能力，而磁盘机械延迟主导了 I/O 总耗时。

## 设计说明
- **出题意图**：本题聚焦存储系统与 I/O 系统的跨模块性能建模，考察考生对磁盘物理访问时间分解、DMA/PIO 工作机制及总线争用模型的理解。通过定量计算与定性分析结合，检验“机制触发”与“计算稳定性”能力，符合 408 综合题 Q43 的定位。
- **参数选择理由**：
  - 转速 7200 RPM 与寻道 10 ms 为工业标准值，确保 $T_{rot\_avg}$ 与 $T_{seek}$ 量级匹配，突出机械延迟主导特性。
  - 扇区数 16 与每磁道 128 扇区设计，使 $T_{trans}$ 精确落在 1 ms 左右，便于与 DMA/PIO 传输时间形成对比（$T_{trans} > T_{bus}$ 但 $< T_{pio}$），避免逻辑矛盾。
  - DMA 总线占用 25 μs/扇区与中断 60 μs 符合现代控制器开销量级；PIO 设定 120 μs/扇区（含 CPU 指令与总线串行），确保 PIO 传输时间略长于磁盘物理时间，凸显 CPU 参与带来的额外延迟。
- **干扰项设计策略**：
  - 单位换算链（RPM→ms, μs→ms, B→MB）设置多级转换，考察计算稳定性（K2）。
  - 并行/串行条件路由（K4）：明确“传输阶段取最大值”规则，防止考生简单相加导致结果偏大。
  - 吞吐率对比分析（K5）：引导考生跳出“DMA 一定比 PIO 快很多”的误区，认识到机械延迟瓶颈，深化对系统级性能权衡的理解。
