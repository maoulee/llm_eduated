# 组成原理期末卷 — 知识点排布方案

基于往年 A 卷结构（简答4×5 + 计算4×10 + 分析2×10 + 设计2×10 = 100分），生成 3 套知识点组合方案。题型/分值/难度档沿用原卷，知识点主动重组。

---

## 方案A — 侧重数据表示与运算器

**设计理念**：以数据表示（定点/浮点/编码）和运算器为核心，搭配存储层次基础，适合侧重计算能力的考核。

**第1题（简答题·5分·难度：中）**：数据表示
- [ ] 原码/补码/反码的相互转换规则与机器零表示
- [ ] 移位运算（算术移位/逻辑移位）的规则与溢出判断
- [ ] 字符编码（ASCII/BCD/奇偶校验）的概念与编码方法

**第2题（简答题·5分·难度：中）**：运算器
- [ ] ALU 的功能组成与加法器级进位方式（串行进位/超前进位）
- [ ] 运算器的数据通路结构与控制信号
- [ ] 乘法/除法运算器的硬件实现思路（原码一位乘/补码一位除）

**第3题（简答题·5分·难度：中）**：指令系统基础
- [ ] 指令格式设计（操作码+地址码）与寻址方式分类
- [ ] 指令字长固定/可变的特点与适用场景
- [ ] CISC 与 RISC 指令系统的设计哲学对比

**第4题（简答题·5分·难度：中）**：存储系统概念
- [ ] 存储层次结构（Cache-主存-辅存）的设计原理
- [ ] SRAM 与 DRAM 的结构差异与刷新机制
- [ ] 存储器扩展方法（位扩展/字扩展/字位同时扩展）

**第5题（计算题·10分·难度：中高）**：CPU 性能指标
- [ ] 给定指令 mix 和 CPI，计算执行时间、MIPS、MFLOPS
- [ ] Amdahl 定律加速比计算（某指令优化后整体性能提升）
- [ ] 多处理器系统的吞吐率与响应时间计算

**第6题（计算题·10分·难度：中高）**：定点数运算
- [ ] 变形补码加减运算及溢出判断（双符号位）
- [ ] 原码一位乘法的手工计算过程
- [ ] 补码一位除法（恢复余数法）的手工计算过程

**第7题（计算题·10分·难度：中高）**：浮点数运算
- [ ] IEEE754 单精度浮点数的格式转换（十进制→十六进制）
- [ ] 浮点数加减运算的对阶/尾数运算/规格化/舍入过程
- [ ] 浮点数表示范围与精度的计算

**第8题（计算题·10分·难度：中高）**：存储地址计算
- [ ] Cache 映射（直接映射）的地址字段划分（标记/行号/块内偏移）
- [ ] 主存容量扩展的芯片数量与片选译码器计算
- [ ] 虚拟存储器的页表地址转换（虚地址→实地址）

**第9题（分析题·10分·难度：高）**：Cache 分析
- [ ] 直接映射 Cache 的命中/不命中分析与标记计算
- [ ] 组相联映射的 Cache 地址划分与冲突不命中分析
- [ ] 给定访问序列，分析 Cache 命中率及替换策略影响

**第10题（分析题·10分·难度：高）**：I/O 方式分析
- [ ] 中断 I/O 的 CPU 开销分析（给定传输率和中断服务时间）
- [ ] DMA 传输方式的周期窃取分析与 CPU 利用率
- [ ] 通道 I/O 与中断/DMA 的对比分析

**第11题（设计题·10分·难度：高）**：存储器设计
- [ ] 给定容量和芯片规格，设计 RAM+ROM 混合存储系统（画框图）
- [ ] 存储器扩位的片选逻辑设计与地址分配
- [ ] 给定存储映射表，设计 Cache 与主存的连接结构

**第12题（设计题·10分·难度：高）**：指令执行设计
- [ ] 根据数据通路图，填写指令执行周期的微操作与控制信号表
- [ ] 设计简单 ALU 运算指令（ADD/SUB/AND/OR）的微程序流程
- [ ] 根据给定指令格式和数据通路，设计跳转指令的执行流程

## 方案B — 侧重存储系统与 I/O

**设计理念**：以存储层次（Cache/虚拟存储/主存扩展）和 I/O 系统为核心，搭配数据表示基础，适合侧重系统架构理解的考核。

**第1题（简答题·5分·难度：中）**：数据表示基础
- [ ] 定点数的机器数表示（原码/补码/反码/移码）
- [ ] IEEE754 浮点数格式（符号位/阶码/尾数）与特殊值
- [ ] 校验码原理（奇偶校验/海明码/CRC）

**第2题（简答题·5分·难度：中）**：存储系统
- [ ] Cache 三种映射方式（全相联/直接/组相联）的对比
- [ ] 虚拟存储器的页面置换算法（FIFO/LRU/OPT）
- [ ] 主存与 CPU 之间的地址/数据/控制总线接口

**第3题（简答题·5分·难度：中）**：I/O 系统
- [ ] 程序查询/中断/DMA/通道四种 I/O 方式的工作原理与对比
- [ ] I/O 接口的功能组成（数据缓冲/地址译码/控制逻辑）
- [ ] 总线仲裁方式（集中式/分布式）与总线时序

**第4题（简答题·5分·难度：中）**：CPU 基础
- [ ] CPU 的组成（运算器/控制器/寄存器组）与数据通路
- [ ] 指令周期的阶段划分（取指/间址/执行/中断）
- [ ] 硬布线控制器与微程序控制器的设计对比

**第5题（计算题·10分·难度：中高）**：数据表示计算
- [ ] 补码加减运算与溢出判断
- [ ] IEEE754 浮点数格式转换与精度分析
- [ ] 海明码的编码与检错纠错计算

**第6题（计算题·10分·难度：中高）**：Cache 计算
- [ ] 直接映射 Cache 的地址字段划分与标记计算
- [ ] 组相联 Cache 的组号/块内偏移计算与容量设计
- [ ] 给定访问序列计算 Cache 命中率

**第7题（计算题·10分·难度：中高）**：虚拟存储计算
- [ ] 页式管理的虚地址到实地址转换
- [ ] 段式管理的逻辑地址到物理地址转换
- [ ] 段页式管理的地址转换与页表设计

**第8题（计算题·10分·难度：中高）**：存储器扩展计算
- [ ] 给定芯片规格和目标容量，计算所需芯片数与译码器
- [ ] 存储器地址空间分配与片选信号设计
- [ ] 主存扩展后的总线接口与等待周期计算

**第9题（分析题·10分·难度：高）**：存储性能分析
- [ ] Cache 命中/不命中对平均访问时间的影响分析
- [ ] 虚拟存储器的缺页率与有效访问时间计算
- [ ] 不同 Cache 替换策略（FIFO/LRU）对命中率的影响分析

**第10题（分析题·10分·难度：高）**：I/O 性能分析
- [ ] 中断 I/O 的 CPU 时间开销与适用传输率范围
- [ ] DMA 传输的周期窃取对 CPU 利用率的影响
- [ ] 总线带宽瓶颈分析与 I/O 设备匹配

**第11题（设计题·10分·难度：高）**：存储系统设计
- [ ] 设计 Cache-主存系统（映射方式/容量/替换策略）
- [ ] 设计虚拟存储器的页表结构与地址转换硬件
- [ ] 设计多模块交叉存储系统的地址映射与控制器

**第12题（设计题·10分·难度：高）**：I/O 系统设计
- [ ] 设计 I/O 接口电路（数据缓冲/中断请求/DMA 请求）
- [ ] 设计总线接口与仲裁逻辑
- [ ] 设计简单 I/O 控制器的状态机与数据通路

**第1题（简答题·5分·难度：中）**：数据表示
