## 知识点
- 二叉树的先序、中序、后序遍历的定义与递归实现
- 由先序遍历序列和中序遍历序列唯一确定二叉树的方法
- 后序遍历序列的构造
- 二叉树遍历的非递归算法（栈的应用）
- 遍历过程的分析与时间复杂度计算

## 难度
- **K值目标**: K3（中等难度）
- **知识维度**: K2-K3（需要掌握多个知识点并能综合运用）
- **计算维度**: K3（需要中等规模的计算和推导）
- **分析维度**: K3（需要理解遍历过程并进行逻辑分析）
- **设计维度**: K2-K3（可能需要设计简单的遍历算法或分析已有算法）

## 出题要求
- **题型**: 综合题（15分）
- **子问题数量**: 3个子问题
- **条件设计要求**:
  - 给定先序遍历序列和中序遍历序列，序列长度适中
  - 要求考生根据序列还原二叉树结构
  - 要求分析某段遍历代码的功能和正确性
  - 要求设计或分析非递归遍历算法
- **参数范围**:
  - 二叉树节点数：7-10个节点
  - 节点值：1-15范围内的不重复整数
  - 遍历序列长度与节点数一致
  - 确保先序和中序序列能唯一确定一棵二叉树

## 子问题规划

### 子问题1（4分）- 计算/构造类型
根据给定的先序遍历序列和中序遍历序列，画出对应的二叉树结构图。

**考察点**:
- 理解先序遍历"根-左-右"的特性确定根节点
- 利用中序遍历"左-根-右"的特性划分左右子树
- 递归地重建二叉树结构

### 子问题2（5分）- 计算类型
给出上述二叉树的后序遍历序列。

**考察点**:
- 掌握后序遍历"左-右-根"的访问顺序
- 能够正确执行后序遍历算法
- 与先序、中序的对比理解

### 子问题3（6分）- 分析/设计类型
分析以下递归遍历算法的功能，并给出其时间复杂度：
```c
void traverse(BiTree T) {
    if (T == NULL) return;
    printf("%d ", T->data);
    traverse(T->lchild);
    traverse(T->rchild);
}
```
若要求不使用递归实现相同功能，请简要描述利用栈实现非递归算法的基本思路。

**考察点**:
- 识别遍历类型（先序遍历）
- 时间复杂度分析（O(n)，每个节点访问一次）
- 递归到非递归的转换思想
- 栈在二叉树遍历中的应用

## 参数约束

### 数值参数范围
- **二叉树节点数 n**: 7 ≤ n ≤ 10
  - 下限7：确保结构足够复杂，能体现遍历的特点
  - 上限10：确保手工计算可行，不至于过于繁琐
- **节点值**: 1-15之间的不重复正整数
  - 便于区分和计算
  - 避免负数增加理解负担
- **序列长度**: 与节点数n相等

### 一致性要求
1. **序列合法性**: 
   - 先序和中序序列必须来自同一棵二叉树
   - 先序序列的第一个元素必须是根节点
   - 中序序列中根节点左边的元素属于左子树，右边的元素属于右子树
   - 两个序列中的元素集合必须完全相同

2. **唯一性要求**:
   - 给定的先序和中序序列必须能唯一确定一棵二叉树
   - 不能出现空树或单节点树的退化情况（n ≥ 7已满足）

3. **结构合理性**:
   - 二叉树不宜过于平衡（退化为线性结构）或过于不对称
   - 建议构造一棵深度为3-4层的二叉树，左右子树大小有差异

4. **遍历结果验证**:
   - 子问题1画出的二叉树，其后序遍历结果必须与子问题2的正确答案一致
   - 子问题3的代码必须确实实现先序遍历功能

### 参考答案设计约束
- 二叉树结构图必须明确标出根节点、左右子树
- 后序遍历序列必须严格遵循"左-右-根"顺序
- 时间复杂度必须准确给出为O(n)
- 非递归算法思路必须体现栈的使用和访问顺序控制
