第(1)问：计算主存地址结构划分
============================================================
基本参数：
  主存地址长度: 32位
  Cache总容量: 4096B (4KB)
  数据块大小: 64B
  组相联路数: 2路

块内地址(Offset)位数计算：
  块大小 = 64B = 2^6B
  因此 Offset位数 = 6位
  对应地址位范围: [5:0] = [5:0]

Cache总块数计算：
  总块数 = Cache总容量 / 块大小 = 4096B / 64B = 64块

组数计算：
  组数 = 总块数 / 路数 = 64 / 2 = 32组
  32组 = 2^5

组号(Set Index)位数：
  5位
  对应地址位范围: [10:6]

主存标记(Tag)位数：
  Tag位数 = 总地址位数 - Set位数 - Offset位数
  Tag位数 = 32 - 5 - 6 = 21位
  对应地址位范围: [31:11]
