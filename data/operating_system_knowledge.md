# 操作系统知识点名词库 v2（思维导图层级版）

来源：`操作系统思维导图【精简版】.pdf`，26页。  
用途：给出操作系统课程的可出题知识点空间；不提供定义、公式、组合方式或真题风格。  
粒度原则：叶子节点到“可单独成为小题核心或可与其他叶子组合成题”的概念 / 结构 / 操作 / 机制 / 计算任务 / 边界条件。  
属性说明：
- `概念`: 概念、术语、分类、性质
- `结构`: 对象组成、字段、表项、数据结构、系统部件
- `操作`: 创建、切换、分配、回收、读写、打开关闭等动作
- `机制`: 过程性机制、调度流程、同步流程、状态转换、异常处理
- `计算`: 时间、次数、位数、容量、命中率、缺页率、开销等计算任务
- `边界`: 特殊状态、边界条件、异常情况、歧义风险
