# 练习题 Q1 — SRTF调度与上下文切换计数

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
考虑三个 CPU 密集型进程，它们分别需要 10、20 和 30 个时间单位，并且到达时间分别为 0、2 和 6。如果操作系统实现最短剩余时间优先调度算法，需要多少次上下文切换？（不计算时间零点和结束时的上下文切换）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆并理解“最短剩余时间优先（SRTF）”调度算法的核心定义：即在任何时刻，CPU都分配给剩余执行时间最短的进程。同时需要理解“上下文切换”在本题特定语境下的定义（排除初始和结束）。这不是简单的术语回忆，而是对调度规则本质的认知。
- **K2 = 2**: 评分理由。计算过程涉及简单的减法（剩余时间计算）和比较。数字较小（10, 20, 30），且时间轴清晰，没有复杂的幂次运算或多级单位换算，单步计算出错概率低。
- **K3 = 4**: 评分理由。需要在时间轴上进行多步串行推演。考生必须模拟从 t=0 到 t=60 的整个过程，并在每个新进程到达点（t=2, t=6）以及进程完成点（t=10, t=30）检查调度状态。这涉及至少 4-5 个关键时间点的状态判断和逻辑推理，属于中等偏上的推演复杂度。
- **K4 = 3**: 评分理由。存在明显的“暗坑”。首先，SRTF 是抢占式算法，考生容易误用非抢占式的 SJF；其次，题干明确“不计算时间零点和结束时的上下文切换”，这是一个常见的计数陷阱，许多学生会习惯性地加上初始加载或最后退出时的切换；最后，需要判断在 t=2 和 t=6 时，新到达进程是否真的触发了抢占（本题中未触发，因为当前进程剩余时间更短），这需要细致的条件判断。
- **K5 = 1**: 评分理由。本题仅涉及 CPU 调度子系统内部的状态流转，不涉及内存管理、I/O 设备或文件系统等其他子系统的状态传递或耦合。

- **雷达形状**: K3-K4 突出型（推演与陷阱主导）

## 考察模式
- **模式**: 推理型
- **理由**: 虽然包含少量计算，但核心难点不在于算术，而在于根据 SRTF 规则在动态变化的时间轴上推理进程的执行顺序和抢占行为。考生必须构建一个动态的调度模型，而非套用静态公式。

## 选项级分析
- **选项 A (1)**: [干扰] — 针对错误认知：认为只有进程完成时才切换，或者误以为 SRTF 在此场景下退化为 FCFS（先来先服务）。如果学生忽略了 t=10 时 P0 完成切换到 P1，或者忽略了 t=30 时 P1 完成切换到 P2 中的某一次，可能会选此项。更常见的是，学生可能错误地认为 P0 一直运行到结束，或者 P1 和 P2 没有发生切换。
- **选项 B (2)**: [正确] — 正确推理结果。t=10 时 P0 完成，切换给 P1（第1次）；t=30 时 P1 完成，切换给 P2（第2次）。中间 t=2 和 t=6 虽然有新进程到达，但因 P0 剩余时间最短，未发生抢占切换。
- **选项 C (3)**: [干扰] — 针对错误认知：误算了初始或结束时的切换。例如，计算了 t=0 加载 P0（+1）和 t=60 P2 结束（+1），或者误以为在 t=2 或 t=6 发生了抢占。如果学生认为 t=2 时 P1 到达导致切换（错误，因为 8 < 20），则会多算一次，得到 3 次（t=2, t=10, t=30）。
- **选项 D (4)**: [干扰] — 针对错误认知：完全误解 SRTF 为抢占式且每次到达都检查并可能切换，或者错误地计算了所有边界。例如，认为 t=0（初始）、t=2（误判抢占）、t=10（完成）、t=30（完成）都算切换，或者在 t=6 也误判抢占。

- **干扰策略**: 概念混淆（SRTF vs SJF/FCFS）与 计数陷阱（边界条件处理）

## 核心陷阱
- **核心陷阱**: **SRTF 的抢占条件判断与上下文切换计数的边界定义**。
    1.  **抢占判断**：在 t=2 和 t=6 时，新进程到达，但当前运行进程 P0 的剩余时间（分别为 8 和 4）仍然小于新进程的总时间（20 和 30），因此**不发生**抢占。很多学生看到“新进程到达”就下意识认为会发生切换，这是最大的陷阱。
    2.  **计数边界**：题干明确“不计算时间零点和结束时的上下文切换”。如果学生忽略此条件，可能会在 t=0 或 t=60 处额外计数，导致答案偏差。

## 考察能力
本题核心考察考生对**抢占式最短剩余时间优先（SRTF）调度算法动态执行过程的模拟能力**，以及在特定约束条件下**准确识别和计数上下文切换事件**的逻辑推理能力。
