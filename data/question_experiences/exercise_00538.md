# 练习题 Q1 — 组相联映射组号计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 计算机组成原理/存储系统
- **难度**: 待评估

## 题干原文
某计算机的主存有 2cm 块，而缓存有 2c 块。若缓存采用每组 2 块的组相联映射方案，则主存块 k 将映射到缓存的哪一组？（ ）
A: 缓存的 (k mod m) 组
B: 缓存的 (k mod c) 组
C: 缓存的 (k mod 2c) 组
D: 缓存的 (k mod 2cm) 组

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“组相联映射”的核心定义，特别是“主存块号对缓存组数取模”这一基本公式。不是2分因为不能仅靠直觉，必须明确知道映射的目标是“组”而非“块”或“路”；不是4分因为不需要辨析多个易混概念（如直接映射与全相联的区别在此题中不是主要障碍，只要知道是组相联即可）。
- **K2 = 2**: 评分理由。计算过程极其简单，仅涉及一次除法/取模运算的逻辑推导。缓存块数 $2^c$，每组2块，组数 $= 2^c / 2 = 2^{c-1}$？等等，这里需要仔细看题面符号。题面写的是“2cm块”和“2c块”，结合选项中的 `mod c` 和 `mod 2c`，以及参考答案解析中的 $2^C$ 和 $2^C/2=C$（注意：参考答案解析中的符号可能有误，通常 $2^c$ 表示 $2$ 的 $c$ 次方，或者 $c$ 本身就是指数。让我们重新审视题面符号）。
    *   *修正分析*：题面写作“2cm 块”和“2c 块”。在计算机组成原理题目中，通常 $2^n$ 表示 $2$ 的 $n$ 次方。如果题面意思是 $2^{cm}$ 和 $2^c$，那么组数 $= 2^c / 2 = 2^{c-1}$。此时映射应为 $k \mod 2^{c-1}$。
    *   *再次审视参考答案*：参考答案解析写道：“缓存大小 = $2^C$ 块... 缓存组数 = $2^C / 2 = C$”。这在数学上是不成立的，除非 $C$ 代表的是组数本身，或者题面中的 $c$ 和 $m$ 是指数。
    *   *结合选项反推*：选项B是 `k mod c`。如果正确答案是B，意味着**缓存组数等于 c**。
    *   *重新解读题面符号*：很有可能题面中的“2c”并非 $2 \times c$ 或 $2^c$，而是排版错误，原意可能是“缓存有 $c$ 组”或者“缓存有 $2^c$ 块且每组2块导致组数为 $2^{c-1}$”？
    *   *最可能的解释*：这是一道符号定义特殊的题目。让我们看解析：“缓存组数 = 缓存大小 / 组大小 = $2^C / 2 = C$”。这暗示解析认为 $2^C / 2 = C$ 是成立的？这显然数学错误。
    *   *另一种可能*：题面中的 $c$ 和 $m$ 是**指数**。即主存 $2^{cm}$ 块，缓存 $2^c$ 块。每组2块。组数 $= 2^c / 2 = 2^{c-1}$。映射组号 $= k \mod 2^{c-1}$。选项里没有这个。
    *   *再看一种可能*：题面中的 $2c$ 意思是 $2 \times c$？主存 $2cm$ 块，缓存 $2c$ 块。每组2块。组数 $= 2c / 2 = c$。映射组号 $= k \mod c$。这与选项B完美契合。
    *   *结论*：题面中的“2cm”应理解为 $2 \times c \times m$，“2c”应理解为 $2 \times c$。或者更常见的，$c$ 和 $m$ 是变量，$2c$ 表示 $2$ 乘以 $c$。在这种线性代数意义下，组数 $= (2c)/2 = c$。因此映射为 $k \mod c$。
    *   *K2评分维持2*：一旦识别出“组数 = 总块数 / 路数”，计算就是简单的代数除法 $(2c)/2 = c$。

- **K3 = 2**: 评分理由。推演步骤清晰：1. 确定缓存总块数；2. 确定每组块数（路数）；3. 计算组数；4. 应用映射公式。共3步，逻辑线性，无分支。
- **K4 = 3**: 评分理由。存在符号理解的陷阱。学生容易将“2c”误解为 $2^c$（2的c次方），从而陷入复杂的指数运算或发现选项不匹配。此外，需要区分“块号”和“组号”的映射关系，避免直接对总块数取模。
- **K5 = 1**: 评分理由。仅涉及存储系统内部的映射机制，不涉及CPU、I/O或其他子系统。

- **雷达形状**: K4陷阱型（符号歧义导致难度提升，核心逻辑简单）

## 考察模式
- **模式**: 概念型
- **理由**: 本题核心不在于复杂计算，而在于对“组相联映射”定义的理解：主存块映射到缓存的**组**，组号由主存块号对**缓存组数**取模得到。

## 选项级分析
- **选项A**: [干扰] — 针对混淆“主存规模”与“缓存规模”的错误认知。学生可能误以为映射范围与主存大小 $m$ 有关，或者误将 $m$ 当作组数。
- **选项B**: [正确] — 正确推导。缓存总块数 $2c$，每组2块，故组数 $= c$。映射公式为 $k \mod \text{组数}$，即 $k \mod c$。
- **选项C**: [干扰] — 针对混淆“组数”与“总块数”的错误认知。学生可能忘记除以路数（每组块数），直接用主存块号对缓存总块数 $2c$ 取模。这是直接映射或全相联映射中常见的错误迁移。
- **选项D**: [干扰] — 针对完全混乱的认知。将主存和缓存的所有参数相乘，属于无逻辑的凑数选项。

- **干扰策略**: 概念混淆（组数 vs 总块数）、符号歧义（线性乘法 vs 指数幂）

## 核心陷阱
- **核心陷阱**: **组数的计算**。学生必须意识到组相联映射中，映射的目标是“组”，因此分母必须是“组数”（总块数/路数），而不是“总块数”或“路数”。同时，需正确解读题面中“2c”的含义（在此题语境下为 $2 \times c$ 而非 $2^c$，否则无解或选项不符）。

## 考察能力
一句话概括本题核心考察的能力：理解组相联映射中主存块号到缓存组号的映射规则（取模运算的对象是缓存组数）。
