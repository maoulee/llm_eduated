# 2014 Q39 — UDP协议特性与传输层服务

## 基本信息
- **年份**: 2014  **题位**: Q39  **题型**: 选择题
- **知识点**: CN-5 > UDP协议 > UDP特点, CN-5 > 传输层提供的服务 > 复用与分用
- **题位域**: 待标注  **科目**: 计算机网络

## 题干原文
下列关于 UDP 协议的叙述中，正确的是（ ）。
I. 提供无连接服务
II. 提供复用/分用服务
III. 通过差错校验，保障可靠数据传输
UDP

A. 仅 I
B. 仅 I、II
C. 仅 II、III
D. I、II、III

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。本题主要考察对 UDP 协议基本特性的记忆。需要掌握“无连接”、“复用/分用”以及“不可靠传输”这三个核心概念。虽然不需要复杂的推导，但需要准确区分 UDP 与 TCP 在可靠性上的本质区别，属于标准的基础认知需求。不是 2 分因为涉及对“差错校验”与“可靠传输”之间逻辑关系的辨析，不仅仅是死记硬背。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全属于定性分析，因此单步代入需求为微弱。
- **K3 = 1**: 评分理由。解题过程不需要多步串行推演。考生只需根据已知的 UDP 特性，逐一判断 I、II、III 三个陈述的真伪，最后组合选项即可。从输入（题干）到输出（答案）仅需简单的逻辑判断，步骤极少。
- **K4 = 3**: 评分理由。本题存在明显的概念陷阱。陈述 III 中提到了“差错校验”，这是 UDP 确实具备的功能（Checksum），但结论却是“保障可靠数据传输”。考生必须识别出“有校验”不等于“可靠传输”（可靠传输还需要确认、重传、流量控制等机制）。这是一个典型的“部分正确导致整体错误”的陷阱，需要考生避开“校验=可靠”的思维误区，因此条件路由需求为标准偏上。
- **K5 = 1**: 评分理由。本题仅涉及传输层内部 UDP 协议的特性，不需要跨越网络层、应用层或其他子系统传递状态或数据，属于单系统内的概念考察。

- **雷达形状**: K4 陷阱型（K1 基础扎实，K4 存在概念辨析陷阱，其余维度极低）

## 考察模式
- **模式**: 概念型
- **理由**: 题目完全基于对计算机网络协议栈中 UDP 协议定义、功能及服务质量的理论理解，不涉及计算或复杂场景推理，旨在检验考生对基础概念的准确掌握程度。

## 选项级分析
- **选项 A**: [干扰] — 针对认为“复用/分用”仅是 TCP 特有或忽略传输层通用功能的错误认知。这类学生可能记得 UDP 无连接，但忘记了传输层（无论是 TCP 还是 UDP）都需要通过端口号进行复用和分用，从而漏选了 II。
- **选项 B**: [正确] — 正确识别了 UDP 的无连接特性（I）和传输层通用的复用/分用功能（II），同时正确排除了关于可靠性的错误描述（III）。
- **选项 C**: [干扰] — 针对混淆“差错检测”与“可靠传输”的错误认知。这类学生可能知道 UDP 有校验和，误以为这就意味着可靠；或者错误地认为 UDP 不提供无连接服务（这极少见，更可能是误判了 I 和 III 的关系，或者单纯记混了 TCP/UDP 特性）。通常选 C 的学生可能误以为 I 是错的（不可能，UDP 必无连接），或者误以为 III 是对的且 I 是错的（逻辑不通）。更可能的情况是，学生误以为 UDP 不提供复用/分用（错选 A 的反面），或者对 I 的判断失误。但在实际考试中，选 C 往往是因为被 III 迷惑，同时错误地排除了 I（极少）或认为 I 不重要。*修正分析*：更常见的错误路径是，学生知道 UDP 不可靠（排除 III），但误以为 UDP 不提供复用/分用（认为只有 TCP 提供），从而选 A。选 C 的学生通常是概念完全混乱，或者误以为“无连接”是错误的（认为所有传输层都隐含连接？），且被 III 迷惑。
- **选项 D**: [干扰] — 针对“UDP 有校验所以可靠”的典型错误认知。这类学生未能区分“尽力而为”与“可靠交付”的区别，认为只要检查了错误就是可靠的，或者混淆了 UDP 和 TCP 的特性。

- **干扰策略**: 概念混淆（主要混淆“差错校验”与“可靠传输”）、渐进陷阱（通过正确的子句“差错校验”诱导得出错误的结论“可靠传输”）

## 核心陷阱
- **核心陷阱**: **“差错校验” $\neq$ “可靠传输”**。UDP 头部包含校验和字段，用于检测数据在传输过程中是否出错，但如果发现错误，UDP 直接丢弃该数据报，不进行重传。因此，UDP 不能保障可靠数据传输。可靠传输需要应用层自行实现（如 TFTP、QUIC 等）。

## 考察能力
准确辨析 UDP 协议的基本特性，特别是区分“差错检测”与“可靠传输”这两个易混淆概念的能力。
