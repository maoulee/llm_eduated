# 练习题 Q1 — 图论算法逻辑补全与汇点判定

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构

## 题干原文
在有向图中，汇点是指一个顶点 $i$ 满足：所有其他顶点 $j \neq i$ 都有一条边指向 $i$，并且 $i$ 没有任何出边。一个包含 $n$ 个顶点的有向图 $G$ 通过邻接矩阵 $A$ 表示，其中 $A[i][j] = 1$ 表示存在从顶点 $i$ 到 $j$ 的边，否则为 $0$。以下算法用于判断图 $G$ 中是否存在汇点。
```c
i = 0;
do {
    j = i + 1;
    while ((j < n) && E1)
        j++;
    if (j < n)
        E2;
} while (j < n);
flag = 1;
for (j = 0; j < n; j++)
    if ((j != i) && E3)
        flag = 0;
if (flag)
    printf("Sink exists");
else
    printf("Sink does not exist");
```
选择正确的 E3 表达式（ ）：
- 选项:
  A: (A[i][j] 且 !A[j][i])
  B: (!A[i][j] 且 A[j][i])
  C: (!A[i][j] 或 A[j][i])
  D: (A[i][j] 或 !A[j][i])
- 正确答案: D
- 解析（参考）: 以下解释是针对本题前一部分的内容：

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“汇点”的定义（入度为n-1，出度为0）以及邻接矩阵的基本含义。属于标准的基础概念记忆，不涉及复杂公式，但需准确理解定义。不是4分因为不需要辨析多个易混的高级概念，仅是基本定义的应用。
- **K2 = 1**: 评分理由。本题不涉及数值计算，仅涉及逻辑表达式的真值判断。没有算术运算，因此计算需求微弱。
- **K3 = 4**: 评分理由。需要理解整个算法的两阶段逻辑：第一阶段（do-while）是候选者筛选（排除法），第二阶段（for循环）是最终验证。考生必须推演第一阶段如何确定唯一的候选者 $i$，然后才能正确推导第二阶段验证 $i$ 时所需的逻辑条件。这是一个多步串行推演过程，且中间状态（$i$ 的值）依赖于前一步的逻辑结果。
- **K4 = 5**: 评分理由。存在极强的隐含前提和反直觉陷阱。
    1. **隐含前提**：题目只问了 E3，但 E3 的正确性完全依赖于对 E1 和 E2 逻辑的理解（即第一阶段是如何工作的）。如果不知道第一阶段筛选出的 $i$ 具有“对于所有 $k < i$，$i$ 可能是汇点，而对于 $k > i$，$k$ 已被排除”的特性，很难直接选出 E3。
    2. **反直觉/陷阱**：E3 是 `flag = 0` 的条件，即“发现 $i$ **不是**汇点”的条件。很多学生会误选“$i$ 是汇点”的条件（即选项 B 的逻辑）。此外，逻辑运算符“或”与“且”的转换（德摩根定律）是常见的思维陷阱。
- **K5 = 2**: 评分理由。主要涉及图数据结构内部的状态传递（从邻接矩阵到逻辑判断），没有跨越不同的子系统（如操作系统、网络等）。提及无关模块较少，主要是单一模块内的逻辑耦合。
- **雷达形状**: K4陷阱型（K4极高，K3较高，K1中等，K2/K5低）。典型的“逻辑陷阱”题目，难点不在于计算或记忆，而在于对算法整体逻辑流的深层理解和避免逻辑取反错误。

- **模式**: 推理型
- **理由**: 题目要求考生根据给定的算法框架和最终目标，逆向推导缺失的逻辑表达式。这需要理解算法的执行流程、变量的状态变化以及逻辑条件的真值表，而非简单的概念回忆或数值计算。

## 选项级分析
- **选项A**: [干扰] — 针对“混淆汇点定义与逻辑取反”的错误认知。`A[i][j]` 为真表示 $i$ 有出边，`!A[j][i]` 为真表示 $j$ 没有指向 $i$。如果这两个条件之一成立，$i$ 就不是汇点。但这里用的是“且”，意味着只有当“$i$ 有出边 **且** $j$ 没指向 $i$”同时发生时才标记失败。这漏掉了“$i$ 有出边但 $j$ 指向 $i$”或“$i$ 无出边但 $j$ 没指向 $i$”这两种 $i$ 不是汇点的情况。这类学生可能只记住了汇点需要“无出边”和“全入边”，但在组合逻辑时出错。
- **选项B**: [干扰] — 针对“直接匹配定义而非匹配代码逻辑”的错误认知。`!A[i][j]`（无出边）且 `A[j][i]`（有入边）正是汇点的定义。如果学生没有注意到 `if (... && E3) flag = 0;` 这一行代码的含义是“如果满足 E3，则 $i$ **不是**汇点”，他们就会直接选择描述“$i$ 是汇点”的选项 B。这是最常见的错误，即忽略了代码中的否定逻辑。
- **选项C**: [干扰] — 针对“逻辑运算符混淆”的错误认知。`!A[i][j]`（无出边）或 `A[j][i]`（有入边）。如果满足这个条件，$flag$ 变 0。这意味着只要“无出边”或者“有入边”之一成立，就认为 $i$ 不是汇点。这显然逻辑错误，因为汇点必须同时满足这两个条件。这类学生可能试图用“或”来覆盖更多情况，但方向反了。
- **选项D**: [正确] — `A[i][j]`（$i$ 有出边）或 `!A[j][i]`（$j$ 没有指向 $i$）。
    - 汇点的定义是：对所有 $j \neq i$，`!A[i][j]` 且 `A[j][i]`。
    - 代码逻辑是：如果 $i$ **不满足**汇点定义，则 `flag = 0`。
    - 因此，E3 应该是“$i$ 不满足汇点定义”的条件。
    - “$i$ 不满足（无出边 且 全入边）” 等价于 “$i$ 有出边 或 存在某个 $j$ 没有指向 $i$”。
    - 即 `A[i][j] || !A[j][i]`。
    - 这类学生正确应用了德摩根定律，并理解了代码中 `flag=0` 的否定语义。

- **干扰策略**: 概念混淆（选项B直接给出定义，诱导忽略代码上下文）、逻辑取反陷阱（选项A/C在逻辑连接词上设置陷阱）。

## 核心陷阱
**核心陷阱**: **逻辑取反与代码语义的错位**。
考生极易忽略 `if ((j != i) && E3) flag = 0;` 这一行代码中 `flag = 0` 的含义。`flag` 初始为 1（假设存在），只有当发现 $i$ **不符合**汇点特征时，才将其置为 0。因此，E3 必须是“$i$ **不是**汇点”的充分条件。
- 汇点条件：$\forall j \neq i, (\neg A[i][j] \land A[j][i])$
- 非汇点条件（E3）：$\exists j \neq i, \neg (\neg A[i][j] \land A[j][i]) \iff \exists j \neq i, (A[i][j] \lor \neg A[j][i])$
选项 B 是汇点条件，选项 D 是非汇点条件。选 B 的学生犯了“所见即所得”的错误，未进行逻辑取反。
