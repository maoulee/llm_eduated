# 练习题 Q1 — 生产者-消费者信号量同步机制

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/死锁
- **难度**: 待评估

## 题干原文

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题不仅要求记忆信号量的基本概念，还需要辨析题目中给出的**非标准定义**（题目定义 empty 为“可供消费者读取”，即通常的 full；full 为“可供生产者写入”，即通常的 empty）。考生必须准确调用并区分这两个易混概念，且需理解 wait/signal 的语义，属于较高程度的概念辨析。
- **K2 = 1**: 评分理由。本题不涉及数值计算，无需执行任何算术运算或幂次换算。
- **K3 = 3**: 评分理由。解题过程需要多步串行推演：1. 识别题目对 empty/full 的特殊定义；2. 分析生产者逻辑（先申请资源，后释放资源）；3. 分析消费者逻辑；4. 结合初始值验证死锁或饥饿情况。步骤在 3-5 步之间，属于标准推演难度。
- **K4 = 4**: 评分理由。存在明显的“反直觉”陷阱。题目明确说明 `empty` 初始值为 0，`full` 初始值为 N，且定义与常规教材（empty=N, full=0）相反。如果考生依赖肌肉记忆直接套用常规公式，会直接选错。必须意识到“题面定义优先于常识”这一隐含前提，避开定义陷阱。
- **K5 = 2**: 评分理由。虽然涉及生产者和消费者两个进程，但主要考察的是单个进程内部的信号量操作顺序以及它们对共享资源状态的单向影响，并未涉及复杂的跨子系统状态深度耦合或数据传递，属于提及无关或简单交互级别。
- **雷达形状**: K4陷阱型（K1和K4较高，K2极低，呈现明显的概念辨析与陷阱规避特征）

## 考察模式
- **模式**: 推理型
- **理由**: 本题不能通过简单的公式代入得出答案，必须基于信号量的语义（P/V操作或wait/signal操作）进行逻辑推理，分析进程执行流与资源状态变化的因果关系，特别是需要推理出在特定初始值下，错误的信号量选择会导致死锁或饥饿。

## 选项级分析
- **选项A**: [干扰] — 针对“常规记忆混淆”错误认知。常规教材中，生产者通常 wait(empty)，消费者 wait(full)。如果考生忽略题目中特殊的定义（empty=0, full=N），可能会凭直觉认为生产者应该操作 empty（尽管这里初始值为0会导致阻塞，但考生可能未深入思考初始值的影响），或者混淆了 P/Q 的对应关系。此选项让生产者 wait(full)（正确，因为 full=N），但 signal(full)（错误，应 signal(empty) 即通知消费者有数据了，但在本题定义下 empty 是消费者读的，所以生产者应 signal(empty)？不对，让我们重新梳理：
    *   题目定义：`empty` = 可供消费者读取（即已填充数，初值0）；`full` = 可供生产者写入（即空闲数，初值N）。
    *   生产者逻辑：需要空闲位 -> wait(`full`)。生产完后，增加已填充数 -> signal(`empty`)。
    *   消费者逻辑：需要已填充位 -> wait(`empty`)。消费完后，增加空闲位 -> signal(`full`)。
    *   选项A: P=full (对), Q=full (错，应signal empty), R=empty (对), S=empty (错，应signal full)。
    *   错误原因：考生可能认为信号量只用于 wait，忽略了 signal 的配对关系，或者完全搞反了资源释放的逻辑。
- **选项B**: [干扰] — 针对“完全反向”错误认知。P=empty (错，初值0，生产者直接阻塞死锁), Q=empty, R=full, S=full。
    *   错误原因：考生可能完全记反了生产者和消费者的角色，或者没有注意到 `empty` 初始值为 0 这一关键约束，导致生产者一开始就无法运行。
- **选项C**: [正确] — P=full, Q=empty, R=empty, S=full。
    *   分析：
        *   生产者：wait(P=full)。full 初值 N，允许进入。生产后 signal(Q=empty)。empty 初值 0，signal 后变为 1，通知消费者有数据。逻辑正确。
        *   消费者：wait(R=empty)。empty 此时为 1（由生产者 signal），允许进入。消费后 signal(S=full)。full 增加，通知生产者有空位。逻辑正确。
- **选项D**: [干扰] — 针对“部分正确但配对错误”错误认知。P=empty (错，初值0，生产者阻塞), Q=full, R=full, S=empty。
    *   错误原因：考生可能正确识别了消费者应该 wait(full)（如果按常规思维），但忽略了题目定义。或者考生试图让生产者 wait(empty)，导致初始死锁。

**干扰策略**: 概念混淆与定义陷阱。利用考生对“empty/full”名称的惯性思维（通常 empty 代表空位，full 代表满位），与题目中给出的**反向定义**（empty 代表已填充/可读，full 代表空闲/可写）形成冲突，诱导考生选择符合常规直觉但违背题目定义的选项。

## 核心陷阱
**题目定义的“反直觉”映射**：题目明确定义 `empty` 信号量表示“可供消费者读取的可用槽位”（即通常意义上的 `full` 或 `count`），且初始值为 0；`full` 信号量表示“可供生产者写入的可用槽位”（即通常意义上的 `empty` 或 `space`），且初始值为 N。考生若未仔细阅读定义，直接套用“生产者 wait(empty)”的常规口诀，会导致生产者因 wait(0) 而永久阻塞（死锁/饥饿）。

## 考察能力
本题核心考察考生在非标准定义下，准确理解信号量语义（资源申请与释放的配对关系）并结合初始值进行死锁/饥饿逻辑推演的能力。
