# 练习题 Q1 — 嵌套循环时间复杂度分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/算法分析
- **难度**: 待评估

## 题干原文
考虑以下程序：
```c
void function(int n) {
    int i, j, count = 0;
    for (i = n / 2; i <= n; i++)
        for (j = 1; j <= n; j = j * 2)
            count++;
}
```
该程序的时间复杂度是（ ）
- 选项:
  A: O(log n)
  B: O(n^2)
  C: O(n^2 log n)
  D: O(n log n)
- 正确答案: D
- 解析（参考）: 外层循环执行 n/2 次，内层循环执行 log n 次，因此程序的总时间复杂度为 O(n log n)，对应选项 (D)
- 知识标签: ['数据结构/算法分析']
- 知识域: DS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“时间复杂度”的基本定义以及常见循环结构（线性增长、指数增长）对应的复杂度量级。不是1分因为不能仅靠直觉，必须调用大O表示法和循环计数规则；不是4分因为不涉及多个易混概念的深度辨析，只需识别两种基本循环模式。
- **K2 = 2**: 评分理由。计算过程非常直接。外层循环次数为 $n - n/2 + 1 \approx n/2$，内层循环次数为 $\lfloor \log_2 n \rfloor + 1 \approx \log_2 n$。两者相乘得到 $n/2 \cdot \log_2 n$，忽略常数系数后为 $O(n \log n)$。没有复杂的数学推导或非2幂次换算，属于基础代数运算。
- **K3 = 2**: 评分理由。推演步骤清晰且串行：第一步分析外层循环执行次数，第二步分析内层循环执行次数，第三步将两者相乘（因为是嵌套关系）。总共仅需3步逻辑串联，无需记忆中间状态或回溯。
- **K4 = 3**: 评分理由。存在常规注意点（陷阱）。外层循环起始于 `n/2` 而非 `0` 或 `1`，考生需意识到这依然属于 $O(n)$ 级别，而非 $O(n/2)$ 这种非标准写法或误判为其他量级。内层循环 `j = j * 2` 是典型的对数级增长，需识别出这是 $\log n$ 而非线性。若考生误以为外层是 $n/2$ 所以复杂度减半从而改变量级，或误判内层为线性，则会掉入陷阱。属于“常规注意点”级别。
- **K5 = 1**: 评分理由。单系统问题。仅涉及单一代码片段的时间复杂度分析，无需跨越不同数据结构模块或传递状态。

- **雷达形状**: K4陷阱型（K1-K3均衡偏低，K4略高，K5极低）。整体难度较低，主要考察对基本循环模式的识别和对常数因子的忽略能力。

## 考察模式
- **模式**: 计算型
- **理由**: 本题核心在于通过数学计算确定循环体的执行次数，并将其转换为大O表示法。虽然涉及概念理解，但最终落脚点在于具体的次数统计和代数简化。

## 选项级分析
- **选项A**: [干扰] — 针对只关注内层循环或误以为外层循环可忽略的错误认知。这类学生可能只看到了 `j = j * 2` 这一显著特征，记住了“乘2就是对数”，而忽略了外层循环的存在，或者错误地认为外层循环的 $n/2$ 起始点使得循环次数极少。
- **选项B**: [干扰] — 针对将内层循环误判为线性循环的错误认知。这类学生可能忽略了 `j = j * 2` 的步长变化，将其视为 `j++`，从而得出 $O(n) \times O(n) = O(n^2)$ 的结论。这是最常见的初学者错误。
- **选项C**: [干扰] — 针对过度复杂化或混淆嵌套关系的错误认知。这类学生可能错误地认为外层循环也是某种对数或平方关系，或者在乘法运算上出现严重失误（如将 $n$ 和 $\log n$ 的关系搞混，误以为总次数是 $n^2 \log n$）。也可能源于对 $O(n^2)$ 和 $O(\log n)$ 的某种错误组合记忆。
- **选项D**: [正确] — 正确识别外层为 $O(n)$，内层为 $O(\log n)$，相乘得 $O(n \log n)$。

- **干扰策略**: 概念混淆（线性vs对数）与 计算陷阱（忽略常数因子或错误相乘）。

## 核心陷阱
- **核心陷阱**: 内层循环步长为 `j = j * 2` 导致的对数复杂度识别，以及外层循环起始点 `n/2` 对量级无影响的判断。考生容易将内层误判为 $O(n)$，从而选B；或只关注内层而选A。

## 考察能力
一句话概括本题核心考察的能力：准确识别不同步长循环的时间复杂度量级，并正确计算嵌套循环的总执行次数。
