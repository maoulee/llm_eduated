# 模拟题 Q1 — 无向图边数与环的关系判定

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: DS-6 > 6.1 图的基本概念 > 图的定义和术语
- **难度**: 待评估

## 题干原文
一个有 n 个顶点和 n 条边的无向图一定是（ ）。

A. 连通的
B. 不连通的
C. 无环的
D. 有环的

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“树”、“森林”、“连通分量”以及“无环图”的核心定义。不是2分因为仅靠直觉无法判断，必须调用“无环图边数上限为 n-1”这一核心定理；不是4分因为不需要辨析多个易混概念，只需回忆一个关键性质。
- **K2 = 1**: 评分理由。本题不涉及数值计算，无需执行任何算术运算或单位换算。
- **K3 = 2**: 评分理由。推演步骤较少。主要逻辑为：假设无环 -> 推导最大边数 n-1 -> 对比题目条件 n -> 得出矛盾 -> 结论有环。这是一个标准的反证法逻辑链，步骤清晰且短。
- **K4 = 3**: 评分理由。存在常规注意点。考生容易忽略“图不一定连通”这一隐含前提，从而错误地认为 n 个顶点 n 条边必然构成一个单环（即连通）。需要识别出“连通性”是不确定的，而“有环”是必然的。这属于中等程度的隐含前提识别。
- **K5 = 1**: 评分理由。本题仅涉及图论基础概念内部逻辑，无需跨越操作系统、计算机网络等其他科目或子系统。
- **雷达形状**: K1-K3 均衡偏低型，K4 略有突出。整体属于基础概念辨析题，陷阱在于对连通性的过度推断。

## 考察模式
- **模式**: 推理型
- **理由**: 题目并非直接询问定义，而是给出一个具体条件（n顶点n边），要求考生通过逻辑推理（反证法或性质对比）得出必然结论。虽然依赖概念记忆，但核心在于逻辑推导过程。

## 选项级分析
- **选项A**: [干扰] — 针对“默认图是连通的”这一错误认知。许多初学者在脑海中构建图时，默认所有顶点都连在一起。如果图是连通的且 n 顶点 n 边，确实是一个单环，但这只是特例。这类学生忽略了图可能由多个连通分量组成（例如两个独立的三角形）。
- **选项B**: [干扰] — 针对“认为边多了就会断开”或“随机猜测”的错误认知。同样，图也可以是连通的（如一个大的环），所以“一定不连通”也是错误的。
- **选项C**: [干扰] — 针对“混淆树与一般图性质”的错误认知。学生可能记得树是无环的，但忘记了树必须满足边数 = 顶点数 - 1。如果误以为 n 条边也可以构成某种特殊的无环结构，就会选此项。
- **选项D**: [正确] — 基于图论基本定理：无向无环图（森林）的最大边数为 n - k（k为连通分量数），当 k >= 1 时，最大边数 <= n - 1。既然边数为 n，必然超过无环图的上限，因此必有环。
- **干扰策略**: 概念混淆与特例泛化。利用“连通图”的特例（单环）来干扰对“一般图”性质的判断，同时利用“树”的无环特性制造反向干扰。

## 核心陷阱
- **核心陷阱**: **连通性的不确定性**。考生极易将“n 个顶点 n 条边”等同于“一个单一的环”，从而误选 A。实际上，图可以是连通的（一个环），也可以是不连通的（多个环的组合，如两个三角形），但无论是否连通，只要边数 >= 顶点数，就一定存在环。

## 考察能力
一句话概括本题核心考察的能力：掌握无向图中顶点数、边数与连通性、环存在性之间的数量关系及逻辑推导能力。
