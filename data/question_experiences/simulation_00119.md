# 模拟题 Q1 — IPv4子网划分与默认路由配置

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: CN-4 > IPv4 > 子网划分与IP地址计算, CN-4 > 网络层功能 > 分组转发
- **难度**: 待评估

## 题干原文
一台主机的 IP 地址为 11.1.1.100，子网掩码为 255.0.0.0。现在用户需要配置该主机的默认路由。经过观察发现，与该主机直接相连的路由器具有如下 4 个 IP 地址和子网掩码：
I. IP 地址：11.1.1.1，子网掩码：255.0.0.0
II. IP 地址：11.1.2.1，子网掩码：255.0.0.0
III. IP 地址：12.1.1.1，子网掩码：255.0.0.0
IV. IP 地址：13.1.2.1，子网掩码：255.0.0.0
问 IP 地址和子网掩码可能是该主机默认路由的是（ ）。
- 选项:
  A: I 和 II
  B: I 和 III
  C: I、III 和 IV
  D: III 和 IV
- 正确答案: A
- 解析（参考）: 【解析】
主机的 IP 地址为 11.1.1.100，子网掩码为 255.0.0.0，其网络地址通过按位与运算得到 11.0.0.0/8。默认路由的网关必须与主机在同一子网内，即网关的网络地址也应为 11.0.0.0/8，这样主机才能直接通信。
逐一分析路由器选项：
I：IP 地址 11.1.1.1，子网掩码 255.0.0.0，网络地址为 11.0.0.0，与主机相同。
II：IP 地址 11.1.2.1，子网掩码 255.0.0.0，网络地址为 11.0.0.0，与主机相同。
III：IP 地址 12.1.1.1，子网掩码：255.0.0.0，网络地址为 12.0.0.0，与主机不同。
IV：IP 地址 13.1.2.1，子网掩码：255.0.0.0，网络地址为 13.0.0.0，与主机不同。
因此，只有 I 和 II 与主机在同一子网，可以作为默认网关。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“默认网关必须与主机在同一子网”这一核心概念，以及“网络地址 = IP & 掩码”的基本定义。不是4分因为不需要辨析多个易混概念（如广播地址、主机号范围等），只需应用单一核心规则。
- **K2 = 2**: 评分理由。计算极其简单，掩码为 255.0.0.0（/8），只需比较IP地址的第一段（第一个字节）。11.x.x.x 的网络号均为 11，12.x.x.x 为 12，13.x.x.x 为 13。无需复杂二进制运算，属于“2的幂友好”且直观的比较。
- **K3 = 1**: 评分理由。逻辑链条极短：计算主机网络号 -> 计算候选网关网络号 -> 比较是否相等。属于1-2步的直接判断，无多步串行推演。
- **K4 = 2**: 评分理由。存在常规注意点：必须确认网关和主机的掩码一致且网络号相同。题目中所有选项掩码均相同，降低了陷阱深度。若掩码不同则需更深层判断，但此处为常规注意点，故给2分。
- **K5 = 1**: 评分理由。仅涉及网络层IP地址计算子系统，不涉及传输层、链路层或应用层的状态传递或耦合。

- **雷达形状**: K1主导的概念理解型，K2/K3极低，整体呈现扁平化，偏向基础概念验证。

## 考察模式
- **模式**: 概念型
- **理由**: 本题核心不在于复杂的数值计算，而在于考察考生对“默认网关配置原则”（同一子网）这一网络层基本概念的理解。计算部分仅为验证概念的手段。

## 选项级分析
- **选项A**: [正确] — I (11.1.1.1) 和 II (11.1.2.1) 的第一段均为11，与主机 (11.1.1.100) 在同一 /8 网络中，符合网关配置要求。
- **选项B**: [干扰] — 包含 III (12.1.1.1)。针对错误认知：学生可能误以为只要前两段相同（11.1）或者只要看起来像“邻居”IP就可以，忽略了掩码 /8 意味着只有第一段决定网络归属。
- **选项C**: [干扰] — 包含 III 和 IV。针对错误认知：完全忽略网络号计算，或者误以为所有列出的路由器IP都可以作为网关，缺乏基本的子网隔离概念。
- **选项D**: [干扰] — 仅包含 III 和 IV。针对错误认知：可能误以为网关必须在不同网段（混淆了网关的作用），或者完全随机猜测。

- **干扰策略**: 概念混淆。利用 IP 地址的视觉相似性（如 11.1.1.1 和 11.1.2.1 看起来很像，而 12.1.1.1 看起来稍远但仍在同一C类子网直觉下）来干扰对 /8 大网段的判断。

## 核心陷阱
- **核心陷阱**: **掩码长度对网络范围的界定**。
  许多学生习惯于 /24 (255.255.255.0) 的C类子网思维，看到 11.1.1.100 和 11.1.2.1 可能会下意识认为它们不在同一个“小”子网（如果掩码是/24，11.1.1.x 和 11.1.2.x 确实不同）。但本题掩码为 255.0.0.0 (/8)，这意味着只要第一个字节相同（都是11），就在同一网络。陷阱在于**直觉上的“近距离”与协议规定的“网络号”之间的冲突**。

## 考察能力
准确理解子网掩码对IP地址网络部分的划分作用，并应用“网关与主机同网段”原则进行配置判断。
