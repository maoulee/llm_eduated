# 练习题 Q1 — 循环结构时间复杂度分析

## 基本信息
- **来源**: 练习题  **题型**: 综合题
- **科目**: 数据结构
- **知识点**: 数据结构/算法分析
- **难度**: 待评估

## 题干原文
在一场竞赛中，观察到四个不同的函数。所有函数都使用单个 for 循环，且循环内部执行相同的语句集。考虑以下 for 循环：
A)
for(i=0;i<n;i++)
B)
for(i=0;i<n;i+=2)
C)
for(i=1;i<n;i*=2)
D)
for(i=n;i<=n;i/=2)
若
n
是输入规模（正数），哪个函数最高效（假设任务本身不是问题）？（ ）
A
B
C
D

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握时间复杂度的基本定义以及常见循环结构（线性、对数、常数）对应的复杂度公式。不是2分因为需要区分 $O(n)$ 和 $O(\log n)$ 的概念差异，不仅仅是记忆。
- **K2 = 2**: 评分理由。计算过程非常直观，主要是识别循环变量的变化规律（+1, +2, *2, /2），无需复杂的数学推导或多级换算，属于2的幂次友好型判断。
- **K3 = 2**: 评分理由。从输入到输出只需两步：1. 识别每个选项的迭代次数规律；2. 比较复杂度大小。不需要多步串行推演或记忆中间状态。
- **K4 = 4**: 评分理由。存在明显的“陷阱词”和隐含前提。选项D是一个典型的逻辑陷阱（无限循环），考生必须意识到 `i<=n` 在 `i` 递减时永远成立这一反直觉或易忽略的条件。若未识别出D是死循环，可能会错误地将其视为 $O(\log n)$ 或 $O(1)$。此外，需理解“最高效”意味着时间复杂度最低。
- **K5 = 1**: 评分理由。本题仅涉及单一子系统（循环控制结构），无需在不同模块间传递数据或状态。
- **雷达形状**: 呈现“左低右高”的偏态分布，K4（条件路由/陷阱识别）显著突出，表明本题难点不在于计算或推导，而在于对边界条件和逻辑陷阱的敏锐识别。

## 考察模式
- **模式**: 分析论证型
- **理由**: 题目要求对给定的代码片段进行静态分析，论证其执行效率（时间复杂度），并基于分析结果进行比较和选择，而非设计新算法或进行数值计算。

## 解题思路分析
- **核心思路**: 分别分析四个选项中循环变量的变化规律，确定各自的迭代次数（即时间复杂度），然后比较复杂度阶数，找出最低者。同时需警惕逻辑错误导致的死循环。
- **关键步骤**:
    1.  **分析选项A**: `i` 从 0 开始，每次 +1，直到 `i < n`。迭代次数为 $n$。时间复杂度 $T(n) = O(n)$。
    2.  **分析选项B**: `i` 从 0 开始，每次 +2，直到 `i < n`。迭代次数约为 $n/2$。在渐近分析中，常数因子忽略，时间复杂度 $T(n) = O(n)$。
    3.  **分析选项C**: `i` 从 1 开始，每次 *2，直到 `i < n`。迭代次数满足 $2^k < n$，即 $k < \log_2 n$。时间复杂度 $T(n) = O(\log n)$。
    4.  **分析选项D**: `i` 初始为 $n$，条件为 `i <= n`。第一次判断 $n \le n$ 成立，进入循环。执行 `i /= 2` 后，$i$ 变为 $n/2$。下一次判断 $n/2 \le n$ 依然成立（因为 $n$ 为正数）。此后 $i$ 不断减小，始终满足 $\le n$。因此，这是一个**无限循环**，时间复杂度可视为无穷大或程序无法终止。
    5.  **比较**: $O(\log n) < O(n) < \text{无限循环}$。因此 C 最高效。
- **易错点**:
    1.  误判选项D：可能误以为 `i` 减小会很快退出循环，或者误读条件为 `i >= 1` 等，从而错误地认为D也是 $O(\log n)$。
    2.  混淆“最高效”含义：误以为循环次数越多越高效，或者混淆时间复杂度与空间复杂度。
    3.  忽略常数因子：虽然B是 $n/2$，但在大O表示法中与A同级，需明确知道它们都比C慢。

## 核心陷阱
- **核心陷阱**: 选项D的**无限循环**陷阱。题目利用 `i <= n` 这一宽松的下界条件配合递减操作，构造了一个永远不会终止的循环。考生若缺乏对循环终止条件的严格检查，极易将其误判为正常的对数级循环，从而在C和D之间犹豫或选错。

## 考察能力
本题核心考察考生对基本循环结构时间复杂度的快速识别能力，以及对代码逻辑边界条件（特别是循环终止条件）的严谨分析能力。
