# 练习题 Q1 — 抢占式与非抢占式优先级调度周转时间计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
我们希望在一个单处理器系统上调度三个进程 P1、P2 和 P3。进程的优先级（最高为最大）、CPU 时间需求和到达时间如下表所示：

CPU 时间需求
到达时间（hh:mm:ss）

10（最高）
20 秒
00:00:05
P2
9
10 秒
00:00:03
P3
8（最低）
15 秒
00:00:00
我们可以选择使用
抢占式
或
非抢占式
调度策略。在
抢占式调度
中，后到达的高优先级进程可以中断当前正在运行的低优先级进程；而在
非抢占式调度
中，后到达的高优先级进程必须等待当前正在执行的进程完成后才能被调度到处理器上。
问题：使用
抢占式
和
非抢占式
调度时，P2 的周转时间（从到达时间到完成时间）分别是多少？（ ）
- 选项:
  A: 30 秒，30 秒
  B: 30 秒，10 秒
  C: 42 秒，42 秒
  D: 30 秒，42 秒
- 正确答案: D
- 解析（参考）: 非抢占式调度分析：
执行顺序：P3 → P1 → P2
时间线：
0 → 15（P3 完成）
15 → 35（P1 完成）
35 → 45（P2 完成）
周转时间 = 45 - 3 =
42 秒
抢占式调度分析：
执行顺序：P3 → P3 → P3 → P2 → P2 → P1 → P2 → P3

0 → 1（P3）
1 → 2（P3）
2 → 3（P2 开始）
3 → 4（P2 被 P1 抢占）
4 → 5（P1 开始）
5 → 25（P1 完成）
25 → 33（P2 完成）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“周转时间”定义（完成时间-到达时间）、“优先级调度”基本概念以及“抢占式”与“非抢占式”的核心区别。属于标准的基础概念记忆，不涉及深层辨析，但需准确理解术语。
- **K2 = 2**: 评分理由。计算过程仅为简单的加减法（如 45-3=42, 33-3=30），数值较小且为整数，不涉及复杂换算或多级幂次计算，单步代入难度较低。
- **K3 = 4**: 评分理由。这是本题的核心难点。考生需要在脑海中或草稿纸上构建时间轴，模拟 CPU 调度过程。特别是抢占式调度，涉及多次状态切换（P3运行->P2到达抢占->P1到达抢占->P1完成->P2继续->P2完成->P3继续），步骤超过5步，且需记忆每个时刻就绪队列中的进程状态，推演链条较长。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。例如：非抢占式中，P3先到达并运行，即使P2、P1优先级更高，P3也必须运行完；抢占式中，P2在t=3到达抢占P3，但t=5时P1到达又抢占P2。考生容易忽略“到达时间”对调度顺序的影响，或者混淆“优先级数值大小”与“优先级高低”（题目明确最高为最大，若误判为数值小优先级高则全错）。
- **K5 = 1**: 评分理由。本题仅涉及CPU调度子系统，不涉及内存管理、I/O调度或文件系统等其他子系统的状态传递，属于单系统内部逻辑。
- **雷达形状**: K3推演主导型（K3显著高于其他维度，K4有一定陷阱性）

## 考察模式
- **模式**: 推理型
- **理由**: 虽然最终结果是数值，但解题的关键不在于公式套用，而在于根据调度算法规则（抢占/非抢占、优先级、到达时间）对系统状态进行动态模拟和逻辑推演。考生必须一步步推导时间线，属于典型的机制推演推理。

## 选项级分析
- **选项A**: [干扰] — 针对“认为两种调度策略结果相同”或“计算错误”的认知。这类学生可能忽略了抢占式调度中P1对P2的抢占，或者错误地认为P2能连续运行。
- **选项B**: [干扰] — 针对“非抢占式计算严重错误”的认知。10秒是P2的CPU时间需求，选此项的学生可能误以为周转时间等于CPU时间，或者在非抢占式中错误地让P2立即运行（忽略了P3和P1的阻塞）。
- **选项C**: [干扰] — 针对“抢占式计算错误”的认知。42秒是非抢占式的结果，选此项的学生可能在计算抢占式时，错误地认为P2没有被P1抢占，或者P1没有抢占P2，导致P2的完成时间推迟到了45秒（即P3完成后P2才运行，或者P2一直等到最后）。
- **选项D**: [正确] — 正确计算了抢占式（30秒）和非抢占式（42秒）下的P2周转时间。
- **干扰策略**: 概念混淆与计算陷阱。通过混合两种调度策略的正确/错误结果，考察考生是否清晰区分两种机制下的执行序列。

## 核心陷阱
- **核心陷阱**: **抢占式调度中的“二次抢占”与“就绪队列状态维护”**。
  1. **非抢占式陷阱**：容易忽略P3虽然优先级最低，但因为最先到达且非抢占，必须独占CPU直到完成（0-15s），导致P1和P2即使优先级高也要等待。
  2. **抢占式陷阱**：
     - P2在t=3到达，抢占P3，开始运行。
     - P1在t=5到达，优先级高于P2，**再次抢占**P2。此时P2已运行2秒，剩余8秒。
     - P1运行20秒（5-25s）。
     - P1完成后，P2继续运行剩余8秒（25-33s）。
     - 很多考生会忘记P2在t=3到t=5之间已经运行了2秒，或者忘记P1抢占P2这一环节，导致P2完成时间计算错误。

## 考察能力
本题核心考察考生对**优先级调度算法（抢占式与非抢占式）执行流程的动态模拟能力**，以及在多进程并发环境下准确追踪**进程状态变化**和**时间轴推演**的逻辑思维能力。
