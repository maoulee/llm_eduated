# 练习题 Q1 — 信号量PV操作数值计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/进程管理
- **难度**: 待评估

## 题干原文
在某一计算时刻，计数信号量的值为 7。随后对该信号量执行了 20 次 P 操作和 x 次 V 操作。若信号量的新值为 5，则 x 的值为（ ）：
A: 18
B: 22
C: 15
D: 13

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆信号量P操作（减1）和V操作（加1）的核心定义。不是4分因为不需要辨析易混概念（如记录型信号量与整型信号量的区别在此题数值计算中不影响结果），只需调用一个核心定义即可入题。
- **K2 = 2**: 评分理由。涉及简单的加减法运算（7 - 20 + x = 5），属于基础算术，非2的幂次但计算量极小，几乎不可能算错，故为较低难度。
- **K3 = 2**: 评分理由。从输入到输出仅需两步逻辑：先理解P/V对数值的影响，再列方程求解。步骤少于3步，无需记忆复杂的中间状态。
- **K4 = 1**: 评分理由。无隐含前提或暗坑。题目直接给出了初始值、操作次数和最终值，逻辑线性且透明，没有“题面没说但解题必须意识到的条件”。
- **K5 = 1**: 评分理由。仅涉及进程管理中的信号量机制，未跨越文件系统、内存管理或I/O等其他子系统，属于单系统内部的状态变化。
- **雷达形状**: K1主导型（基础概念记忆型），整体难度偏低，呈现扁平化特征，无明显短板或长板。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于根据信号量操作的数学定义（P: S-1, V: S+1）建立线性方程并求解未知数，侧重于对机制数值影响的直接应用。

## 选项级分析
- **选项A**: [正确] — 正确计算结果。7 - 20 + x = 5 => x = 18。
- **选项B**: [干扰] — 针对符号错误认知。学生可能误以为P操作是加1，V操作是减1，或者在列方程时搞错正负号（如 7 + 20 - x = 5 => x = 22）。这类学生混淆了P/V操作对信号量值的增减方向。
- **选项C**: [干扰] — 针对计算失误或逻辑跳跃。可能是学生忽略了初始值7，直接计算 20 - x = 5 => x = 15；或者是 20 - 5 = 15，误以为V操作次数等于P操作次数与最终值的差，忽略了初始状态。
- **选项D**: [干扰] — 针对严重逻辑错误。可能是学生认为信号量值不能为负，因此在P操作导致值为负时停止计算或错误截断，或者完全随机猜测。也可能是计算 20 - 7 = 13，误以为V操作次数等于P操作次数减去初始值。
- **干扰策略**: 概念混淆（P/V方向搞反）与计算陷阱（忽略初始值或符号错误）。

## 核心陷阱
- **核心陷阱**: 无显著陷阱。本题为直白的基础概念应用题，主要陷阱在于对P操作（减1）和V操作（加1）的基本定义记忆不清，或在简单代数运算中出错。

## 考察能力
一句话概括本题核心考察的能力：掌握信号量P/V操作对信号量整数值的具体影响，并能进行简单的状态变迁计算。
