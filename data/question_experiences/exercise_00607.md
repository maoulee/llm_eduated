# 练习题 Q排序算法最坏情况 — 排序算法时间复杂度对比

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/排序
- **难度**: 待评估

## 题干原文
考虑以下排序算法：
I. 快速排序（Quicksort）
II. 堆排序（Heapsort）
III. 归并排序（Mergesort）
在最坏情况下，哪些算法的执行时间最少？

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆三种经典排序算法在最坏情况下的时间复杂度公式。不是2分因为涉及三个不同算法的对比，需准确回忆而非单一概念；不是4分因为这是数据结构中最基础的核心考点，无需辨析极度易混的深层概念。
- **K2 = 1**: 评分理由。无需任何数值计算，仅需对 $O(n^2)$ 和 $O(n \log n)$ 进行阶数比较，属于概念性判断，无计算负担。
- **K3 = 1**: 评分理由。无需多步推演，直接调用已知结论即可得出结论，逻辑链条极短。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。题目强调“最坏情况”，若考生混淆“平均情况”或“最好情况”，或误以为快速排序总是 $O(n \log n)$，则会掉入陷阱。这属于对限定条件（最坏情况）的敏感度考察。
- **K5 = 1**: 评分理由。仅涉及排序算法这一单一知识域内的概念对比，无需跨越不同子系统或模块。
- **雷达形状**: K1主导型（记忆与辨析为主），K4中等（条件限制敏感），其余维度极低。整体呈现“基础概念辨析”特征。

## 考察模式
- **模式**: 概念型
- **理由**: 本题不考察具体代码实现或复杂计算，而是考察对经典算法性能指标（时间复杂度）的理论记忆与对比能力，属于典型的概念辨析题。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：认为快速排序效率高，忽略其最坏情况退化。这类学生可能只记得快速排序平均性能最好，而忽略了题目中的“最坏情况”限定，或者误以为堆排序和快排都是基于比较的高效排序，未区分其稳定性与最坏界限。
- **选项B**: [正确] — 堆排序和归并排序的最坏时间复杂度均为 $O(n \log n)$，优于快速排序的 $O(n^2)$。
- **选项C**: [干扰] — 针对错误认知：认为只有归并排序稳定或最优。这类学生可能混淆了“稳定性”与“时间复杂度”，或者错误地认为堆排序的最坏情况比归并排序差（实际上两者同阶）。
- **选项D**: [干扰] — 针对错误认知：认为所有 $O(n \log n)$ 级别的算法在最坏情况下表现一致。这类学生可能完全忽略了快速排序在最坏情况（如已有序数组且选取首/尾元素为基准）下会退化为 $O(n^2)$ 的事实。
- **干扰策略**: 概念混淆（平均 vs 最坏）、忽略限定条件（最坏情况）。

## 核心陷阱
- **核心陷阱**: **快速排序的最坏情况退化**。许多考生对快速排序的印象停留在“平均 $O(n \log n)$”和“实际运行最快”，容易忽略其在特定输入（如已排序、逆序）且基准选择不佳时，时间复杂度会退化为 $O(n^2)$，从而错误地将其与堆排序、归并排序归为一类。

## 考察能力
准确记忆并区分经典排序算法在不同场景（特别是极端情况）下的时间复杂度界限。
