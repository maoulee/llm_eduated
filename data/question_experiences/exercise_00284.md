# 练习题 Q1 — 选择性重复协议窗口大小限制

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/传输层
- **难度**: 待评估

## 题干原文
使用 n 位帧序列号的选择性拒绝协议的数据传输最大窗口大小是（ ）：
A: $2^n$
B: $2^n - 1$
C: $2^n - 1$
D: $2^n - 2$

*(注：原题选项B和C在文本中显示重复，通常此类题目选项设置为 $2^n$, $2^n-1$, $2^{n-1}$, $2^{n-1}-1$ 等变体。根据参考答案B为 $2^n-1$，此处假设B为正确选项，C可能为排版错误或另一干扰项如 $2^{n-1}$。基于标准408考点，正确结论为 $2^n-1$)*

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。需要辨析“停止等待”、“回退N帧（GBN）”和“选择性重复（SR）”三种协议在窗口大小限制上的核心区别。仅记忆单一概念得3分，但本题需明确SR协议特有的“发送窗口+接收窗口 $\le$ 序列号空间”这一深层约束，属于易混概念辨析，故为4。
- **K2 = 2**: 评分理由。涉及简单的幂运算和减法（$2^n - 1$），计算量极小，属于基础代数代入，几乎不会算错。
- **K3 = 3**: 评分理由。需要理解SR协议避免歧义的基本逻辑：如果窗口过大，接收方无法区分当前收到的包是“新周期的旧包”还是“上一周期的新包”。这需要从序列号空间覆盖的角度进行逻辑推演，步骤约为：确定序列号空间大小 -> 确定SR窗口约束条件 -> 推导最大窗口值。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。学生容易混淆GBN协议（最大窗口 $2^n-1$）和SR协议（最大窗口 $2^{n-1}$ 或 $2^n-1$ 取决于具体教材定义，但在408标准中，SR通常要求 $W_s + W_r \le 2^n$，若 $W_s=W_r$，则 $W_s \le 2^{n-1}$；但若题目问的是“最大窗口大小”且未指定 $W_s=W_r$，或者参考某些特定教材（如谢希仁版早期版本或特定语境）认为只要不重叠即可，则可能指向 $2^n-1$。**修正分析**：在408考研标准中，SR协议通常要求发送窗口 $W_T$ 和接收窗口 $W_R$ 满足 $W_T + W_R \le 2^n$。若题目问的是“最大窗口大小”通常指发送窗口。若 $W_T = W_R$，则 $W_T \le 2^{n-1}$。然而，许多经典习题和旧版教材中，对于SR协议，为了避免接收方混淆，要求发送窗口和接收窗口之和不超过序列号空间。如果题目选项中有 $2^{n-1}$，那通常是更严谨的答案。但本题正确答案给的是 $2^n-1$，这通常对应的是**回退N帧（GBN）**协议的最大发送窗口，或者是SR协议中**不强制** $W_s=W_r$ 时的理论上限（即 $W_s$ 可以接近 $2^n$，只要 $W_r=1$，但这违背SR初衷）。**深度辨析**：实际上，408真题中关于SR窗口的经典结论是 $W_s \le 2^{n-1}$。但若本题答案确认为 $2^n-1$，则极有可能是题目将“选择性拒绝”与“回退N帧”混淆，或者考察的是**序列号空间本身**的限制而非对称窗口。鉴于参考答案为B ($2^n-1$)，这实际上是**GBN协议**的最大发送窗口限制。若题目明确说是“选择性拒绝（SR）”，标准答案应为 $2^{n-1}$。此处存在题目与答案的潜在冲突或特定教材定义。*但在本分析中，我们依据给出的正确答案B进行逆向推导*：出题人可能考察的是“序列号空间总数减1”这一通用上限概念，或者题目本身有误将GBN的结论安在了SR上。无论如何，识别出“不同协议窗口限制不同”这一隐含前提是高难度所在。
- **K5 = 1**: 评分理由。仅涉及传输层协议内部的机制，不涉及网络层或应用层的跨域联动。

- **雷达形状**: K1/K4 高位型（概念辨析与陷阱识别主导）

## 考察模式
- **模式**: 概念型
- **理由**: 本题核心不在于复杂计算，而在于对传输层可靠传输协议（特别是SR和GBN）窗口大小限制原理的记忆和理解。

## 选项级分析
- **选项A ($2^n$)**: [干扰] — 针对认为窗口可以等于序列号空间总数的错误认知。如果窗口等于 $2^n$，则无法区分新旧周期，必然导致歧义。
- **选项B ($2^n - 1$)**: [正确] — 根据题目给出的参考答案。*注：在标准408教学中，GBN的最大发送窗口为 $2^n-1$，SR的最大发送窗口通常为 $2^{n-1}$。若此题答案确为B，则可能题目意指GBN，或考察的是序列号空间的非零上限。* 针对正确理解协议窗口限制边界的学生。
- **选项C ($2^n - 1$)**: [干扰/重复] — 若为排版错误，原意可能是 $2^{n-1}$。若为 $2^{n-1}$，则是SR协议更严谨的答案。针对混淆SR和GBN窗口公式的学生。
- **选项D ($2^n - 2$)**: [干扰] — 无明确理论依据，属于凑数选项，针对随机猜测的学生。

- **干扰策略**: 概念混淆（SR vs GBN）、数值边界陷阱（$2^n$ vs $2^n-1$）

## 核心陷阱
- **核心陷阱**: **协议混淆与窗口定义歧义**。
    1.  **协议混淆**：学生容易将“回退N帧（GBN）”的最大窗口 $2^n-1$ 与“选择性重复（SR）”的最大窗口 $2^{n-1}$ 记混。
    2.  **题目与答案的潜在冲突**：在主流408教材（如谢希仁《计算机网络》）中，SR协议为避免接收方歧义，要求 $W_s + W_r \le 2^n$。若 $W_s = W_r$，则 $W_s \le 2^{n-1}$。若题目答案给的是 $2^n-1$，这通常是GBN的特征。考生需警惕题目是否将“选择性拒绝”误写，或考察的是非对称窗口的极端情况。但在考试现场，若必须选B，需意识到出题人可能沿用了旧题库或特定简化模型。

## 考察能力
一句话概括本题核心考察的能力：准确区分并记忆不同可靠传输协议（GBN与SR）在序列号空间约束下的最大窗口大小限制。
