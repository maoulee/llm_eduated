# 练习题 Q1 — 滑动窗口协议最大利用率与序列号位数

## 题干原文
两站 M 和 N 之间的距离为 L 公里。所有帧的长度为 K 位。每公里的传播延迟为 t 秒。设信道容量为 R 位/秒。假设处理延迟可忽略不计，当使用滑动窗口协议时，为了实现最大利用率，帧中序列号字段所需的最小位数是（ ）。
- 选项:
  A: ⌈log2(K/(2LtR) + 2K)⌉
  B: ⌈log2(K/(2LtR))⌉
  C: ⌈log2(K/(2LtR) + K)⌉
  D: ⌈log2((2K)/(2LtR) + K)⌉
- 正确答案: C
- 解析（参考）: 可以发送 Transmission Time / RTT 数量的数据包，以最大化信道利用率，因为在这段时间内，我们收到第一个 ACK，在此之前，我们可以继续发送数据包。
因此，应该发送 (Transmission Time + 2×Propagation Time) / Transmission Time 数量的数据包。
因此，序列号字段所需的比特数：⌈log2((K/R + 2Lt) / (K/R))⌉ = ⌈log2(1 + 2LtR/K)⌉
注意：这里询问的是通用的滑动窗口协议，而不是 GBN 或 SR。
在通用滑动窗口协议中：
- 知识标签: ['计算机网络/数据链路层']
- 知识域: CN-1

- **K4 = 4**: 评分理由。存在隐含前提和陷阱。
    1. **陷阱1**：题目问的是“通用滑动窗口协议”而非GBN或SR。在通用理论中，为了达到100%利用率，发送窗口 $W$ 至少需要覆盖 RTT 内能发送的帧数，即 $W \ge \frac{RTT}{T_{trans}}$。序列号空间大小 $2^n$ 必须大于等于 $W$（对于通用协议，通常认为 $2^n \ge W$ 即可，或者更严格地 $2^n > W$ 以避免歧义，但在考研语境下，通常考察 $2^n \ge W_{min}$）。

    3. **陷阱3**：注意题目中的 $t$ 是“每公里”的延迟，总传播延迟是 $L \times t$，而非 $t$。这是常见的单位陷阱。
