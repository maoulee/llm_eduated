# 练习题 Q1 — 双栈共享空间满条件判定

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/栈
- **难度**: 待评估

## 题干原文
使用一个单数组
A[1..MAXSIZE]
实现两个栈。这两个栈从数组的两端向中间增长。变量
top1
和
top2
（
top1 < top2
）分别指向每个栈的栈顶元素位置。若要高效利用空间，则“栈满”的条件是（ ）：
- 选项:
  A: (top1 = MAXSIZE/2)
且
(top2 = MAXSIZE/2+1)
  B: top1 + top2 + 1 = MAXSIZE
  C: (top1 = MAXSIZE/2)
或
(top2 = MAXSIZE)
  D: top1 = top2 -1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握栈的基本定义（栈顶指针含义）以及双栈共享数组的基本模型。不是4分因为不需要辨析多个易混的高级概念，只需理解“栈顶指针指向当前元素”这一核心定义即可。
- **K2 = 2**: 评分理由。涉及简单的整数关系判断（相邻关系），无需复杂计算。最复杂的单步计算仅为判断两个变量是否相差1，属于2的幂友好或极简单的算术逻辑。
- **K3 = 2**: 评分理由。从输入到输出只需1-2步推演：1. 理解栈1向右增长，栈2向左增长；2. 判断两者相遇（相邻）即为满。无需多步串行推演或记忆中间状态。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。题面明确给出 `top1 < top2` 且 `top1, top2` 指向**栈顶元素**（而非空位）。许多学生容易混淆“指向栈顶元素”与“指向栈顶下一个空位”两种实现方式，或者忽略 `top1 < top2` 这一约束导致的边界情况。若未意识到指针指向的是有效数据而非空位，极易选错。
- **K5 = 1**: 评分理由。单系统问题，仅涉及栈这一种数据结构在数组中的映射，无需跨越不同子系统或模块传递状态。
- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要考察对隐含条件和定义细节的敏感度）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非直接记忆公式，而是需要根据栈的增长方向、指针定义以及空间共享的逻辑，推导出两个指针在空间耗尽时的相对位置关系。

## 选项级分析
- **选项A**: [干扰] — 针对“平均分配空间”的错误认知。这类学生认为双栈应该各占一半空间，当各自达到一半时即为满。这忽略了双栈动态共享空间的特性，导致空间利用率低下，不符合“高效利用空间”的要求。
- **选项B**: [干扰] — 针对“指针定义混淆”的错误认知。如果 `top1` 和 `top2` 指向的是**栈顶下一个空位**，且栈1从0开始，栈2从MAXSIZE-1开始，满的条件可能是 `top1 == top2` 或类似求和关系。但本题指针指向**元素**，且下标从1开始，该公式无几何意义，属于凑数的数学陷阱。
- **选项C**: [干扰] — 针对“独立栈满”的错误认知。这类学生将两个栈视为独立实体，认为只要其中一个栈满了（达到边界）整个结构就满了。这同样忽略了共享空间的动态特性，且 `top2 = MAXSIZE` 甚至可能越界（取决于具体实现，通常栈2向左增长，初始值较大）。
- **选项D**: [正确] — 正确理解了双栈共享空间的本质。栈1向右增长（top1递增），栈2向左增长（top2递减）。当两个栈顶指针相邻时，即 `top1` 的下一个位置就是 `top2`，或者说 `top2` 的前一个位置是 `top1`，此时中间无空隙，空间已满。结合 `top1 < top2`，即 `top1 + 1 = top2` 或 `top1 = top2 - 1`。

**干扰策略**: 概念混淆（指针指向元素vs空位）、静态思维（固定分区vs动态共享）

## 核心陷阱
- **核心陷阱**: **指针语义的混淆**。题目明确指出 `top1` 和 `top2` 指向**栈顶元素**。
    - 若指向栈顶元素：栈满时，两个栈顶元素相邻，即 `top1 + 1 == top2` (即 `top1 = top2 - 1`)。
    - 若指向栈顶下一个空位：栈满时，两个空位指针相遇，即 `top1 == top2`。
    - 考生若未仔细审题，默认使用常见的“指向空位”模型，可能会寻找 `top1 == top2` 的选项（本题无此选项，但易导致对D选项的犹豫或误判B选项）。此外，`top1 < top2` 的约束排除了 `top1 > top2` 的溢出情况，强化了相邻即满的逻辑。

## 考察能力
一句话概括本题核心考察的能力：对栈底层存储结构（数组实现）中指针语义及空间共享机制的逻辑推理能力。
