# 练习题 Q1 — C类子网划分与数量计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/网络层
- **难度**: 待评估

## 题干原文
在 C 类网络中，如果子网掩码为 255.255.255.224，则计算子网数量（ ）？

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆C类地址的默认掩码（255.255.255.0）以及子网划分的基本概念（借位）。不是4分因为不需要辨析多个易混的高级概念，只需掌握基础定义。
- **K2 = 2**: 评分理由。涉及将十进制224转换为二进制，识别借位数量（3位），并计算 $2^3$。2的幂次计算非常友好，属于低难度单步代入。
- **K3 = 1**: 评分理由。解题路径线性且短：识别默认掩码 -> 对比给定掩码 -> 确定借位数 -> 计算子网数。仅需1-2步逻辑串联，无需复杂的状态记忆或多步推演。
- **K4 = 2**: 评分理由。存在常规注意点，即是否考虑全0和全1子网。但在现代网络环境及408考研主流观点中，通常默认支持全0/全1子网（即直接 $2^n$），除非题目明确提及“传统IP”或“排除全0全1”。此处为常规注意点，非深层陷阱。
- **K5 = 1**: 评分理由。本题仅涉及网络层IP地址划分的单一知识点，不涉及传输层、应用层或其他子系统的状态传递或耦合。
- **雷达形状**: K2计算型（低K3/K5，中等K1/K4）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过数值转换（十进制转二进制）和简单指数运算来得出结果，侧重于对子网掩码二进制结构的量化分析。

## 选项级分析
- **选项A**: [干扰] — 针对“排除全0和全1子网”的错误认知或旧标准记忆。这类学生可能记得早期RFC规定全0和全1子网不可用，因此计算 $2^3 - 2 = 6$。
- **选项B**: [正确] — 正确计算了借位数为3，且采用现代标准 $2^3 = 8$。
- **选项C**: [干扰] — 针对计算错误或借位数判断错误。例如误以为224对应借2位（$2^2=4$），或者混淆了主机位数与子网位数。
- **选项D**: [干扰] — 针对完全无法计算或认为题目条件不足的学生。
- **干扰策略**: 概念混淆（新旧标准差异）与计算陷阱（借位数误判）

## 核心陷阱
- **核心陷阱**: **全0和全1子网的可用性判断**。这是本题最大的潜在争议点。在408考研及现代网络工程中，默认子网划分包含全0和全1子网（即 $2^n$）；若按极老旧的标准（如某些早期教材或特定厂商默认配置），则需减去2（即 $2^n - 2$）。考生需明确当前考试体系下的默认规则。

## 考察能力
一句话概括本题核心考察的能力：掌握IP地址子网划分原理，能熟练进行十进制掩码与二进制位的转换，并准确应用子网数量计算公式。
