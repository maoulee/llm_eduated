# 练习题 Q1 — 分段存储地址合法性检查

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/存储管理
- **难度**: 待评估

## 题干原文
在分段方案中考虑以下段表：
SegmentID
Base
Limit
0
200
200
1
500
12510
2
1527
498
3
2500
50
当请求的逻辑地址为段号 2 且偏移量为 1000 时会发生什么？（ ）
- 选项:
  A: 从段号 2 的物理地址 2527 处获取条目
  B: 生成一个陷阱（trap）
  C: 死锁
  D: 从段号 3 的偏移量 27 处获取条目
- 正确答案: B
- 解析（参考）: 解析：
段 2 的基地址 = 1527
段 2 的限长 = 498
可访问的有效地址范围：1527 至 1527 + 498 =
2025
请求的偏移量 1000 对应的物理地址：1527 + 1000 =
2527
由于 2527 > 2025，该访问超出了段 2 的合法范围
因此操作系统会触发
分段错误陷阱（Segmentation Fault Trap）
- 知识标签: ['操作系统/存储管理']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握分段存储管理的基本概念，包括段表结构（基址 Base、限长 Limit）以及逻辑地址到物理地址的转换规则。属于标准的核心定义记忆，不涉及复杂概念辨析。
- **K2 = 2**: 评分理由。计算过程极其简单，仅需一次加法（1527 + 1000）和一次比较（1000 > 498 或 2527 > 2025）。数字均为整数，无2的幂次换算或多级换算，计算出错概率极低。
- **K3 = 2**: 评分理由。推演步骤清晰且简短：1. 查表获取段2的Base和Limit；2. 判断偏移量是否越界；3. 若越界则触发异常。属于标准的2步串行推演。
- **K4 = 3**: 评分理由。存在明显的“陷阱词”和隐含前提。陷阱在于选项A给出了错误的物理地址计算结果，诱导学生忽略“限长检查”这一前置条件。学生必须意识到“地址转换前必须先进行合法性检查”这一隐含规则，否则容易落入计算陷阱。
- **K5 = 1**: 评分理由。本题仅涉及存储管理子系统内部的地址转换机制，不涉及CPU调度、I/O管理或其他子系统的状态传递，属于单系统内部逻辑。
- **雷达形状**: K4陷阱型（K4相对较高，K2/K3较低，呈现明显的陷阱特征）

## 考察模式
- **模式**: 推理型
- **理由**: 虽然包含简单的计算，但核心不在于计算结果的正确性，而在于对“地址合法性检查机制”的逻辑推理。学生需要推理出“偏移量 > 限长”这一条件会导致硬件异常（Trap），而不是继续执行地址映射。

## 选项级分析
- **选项A**: [干扰] — 针对“忽略限长检查，直接进行地址映射”的错误认知。这类学生知道物理地址 = Base + Offset，计算出 1527 + 1000 = 2527，但忘记了在分段系统中，MMU（内存管理单元）会先检查 Offset < Limit。如果检查失败，根本不会生成物理地址，而是产生异常。
- **选项B**: [正确] — 正确识别了越界访问导致的硬件异常。在分段系统中，当偏移量超过段长时，硬件会触发中断/陷阱（Trap），交由操作系统处理（通常导致Segmentation Fault）。
- **选项C**: [干扰] — 针对“概念混淆”的错误认知。死锁是进程同步与互斥中的概念，与存储地址访问无关。这类学生可能对操作系统核心概念缺乏清晰界限，看到“错误”就联想到严重的系统故障如死锁。
- **选项D**: [干扰] — 针对“完全错误的地址映射逻辑”的认知。2527 - 2500 = 27，这暗示学生可能错误地认为地址可以跨段连续访问，或者错误地使用了段3的基址进行某种错误的减法运算。这是典型的无逻辑干扰项，用于排除完全不懂地址映射的学生。
- **干扰策略**: 计算陷阱（选项A）+ 概念混淆（选项C）

## 核心陷阱
- **核心陷阱**: **先检查后映射**。许多学生习惯于直接计算物理地址（Base + Offset），而忽略了分段存储管理中至关重要的“限长寄存器（Limit Register）”检查机制。题目通过给出一个看似合理的物理地址计算结果（选项A），诱导学生跳过合法性检查步骤。

## 考察能力
一句话概括本题核心考察的能力：掌握分段存储管理中逻辑地址到物理地址转换时的**越界检查机制**及**异常处理流程**。
