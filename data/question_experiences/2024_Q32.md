# 2024 Q32 — 磁盘调度算法 CSCAN 机制推演

## 基本信息
- **年份**: 2024  **题位**: Q32  **题型**: 选择题
- **知识点**: 磁盘调度算法, CSCAN, 操作系统>磁盘调度算法
- **题位域**: 待标注  **科目**: 操作系统

## 题干原文
某磁盘的磁道数为 400（磁道号为 0~399），采用循环扫描算法 (CSCAN) 进行磁盘调度，完成对 200 号磁道的请求后，磁头向磁道号减小的方向移动，若还有 7 个请求，对应的磁道号分别为 300, 120, 110, 0, 160, 210, 399，则完成上述磁盘请求后磁头移动的距离是（ ）。

A. 599
B. 619
C. 788
D. 799

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆 CSCAN（循环扫描）算法的核心定义，特别是其“单向扫描+瞬间回绕”的特性。如果混淆为 SCAN（电梯算法）或 SSTF，则无法解题。属于标准的核心概念记忆需求。
- **K2 = 3**: 评分理由。涉及多次整数减法运算（如 200-160, 160-110 等）以及最后的累加。虽然单步计算简单，但步骤较多，且涉及跨越 0/399 边界的逻辑处理，非简单的 2 的幂次友好计算，存在一定计算出错风险。
- **K3 = 4**: 评分理由。需要在明确规则下进行多步串行推演。首先确定当前方向（减小），然后筛选出该方向上小于 200 的请求并排序（160, 120, 110, 0），接着处理边界回绕（从 0 瞬间跳至 399），最后处理剩余请求（399, 300, 210）。整个过程包含状态判断、排序、边界处理、再次排序，步骤超过 5 步且需记忆中间磁头位置，推演复杂度较高。
- **K4 = 4**: 评分理由。存在显著的隐含前提和陷阱。
    1. **方向陷阱**：题干明确“向磁道号减小的方向移动”，这决定了第一轮扫描是向下（200->0），而非默认的向上。
    2. **回绕陷阱**：CSCAN 在到达一端后，是“立即返回”到另一端，这个返回过程是否计入距离？通常 CSCAN 定义中，回绕是瞬间的（不计距离）或者计为最大跨度。本题解析中 `399-0=399` 暗示了从 0 到 399 的回绕被计入了移动距离（或者理解为从 0 走到 399 的路径，但在 CSCAN 中通常指磁头复位）。*修正分析*：仔细看解析 `399-0=399`，这实际上是将“从 0 回到 399”这段空跑的距离计入了总距离。这是 CSCAN 与 SCAN 的关键区别之一（SCAN 回扫也服务请求，CSCAN 回扫通常不服务或瞬间复位，但距离计算上，若视为物理移动则需加上跨度）。本题的关键陷阱在于理解“完成请求后磁头移动的距离”是否包含回绕距离。解析显示包含。
    3. **排序陷阱**：必须对请求队列进行正确的分区和排序。
- **K5 = 1**: 评分理由。本题仅涉及操作系统中的磁盘调度子系统，不涉及内存管理、进程调度等其他子系统的状态传递或耦合，属于单系统内部逻辑。
- **雷达形状**: K3/K4 双高型（推演与陷阱主导）。K1 基础适中，K2 计算中等，K3 和 K4 显著突出，表明题目难点不在于计算本身，而在于对算法机制的精确理解和多步逻辑执行中的防错。

## 考察模式
- **模式**: 推理型
- **理由**: 虽然包含计算，但核心难点在于根据 CSCAN 的规则（方向、边界、回绕）对请求序列进行逻辑重组和路径规划。考生必须“推理”出磁头的实际移动轨迹，而不仅仅是代入公式。

## 选项级分析
- **选项 A (599)**: [干扰] — 针对**忽略回绕距离**或**错误理解 CSCAN 回绕机制**的学生。如果学生认为从 0 到 399 是瞬间复位（距离为 0），或者错误地只计算了服务请求间的距离而忽略了从 0 到 399 的空跑距离，可能会得到较小的数值。具体计算：若不计 0->399 的回绕，距离为 40+50+110+90+90 = 380，不对。若误用 SCAN 算法（回扫时服务请求），路径为 200->160->120->110->0->210->300->399，距离为 200 + 399 = 599。这正是 SCAN 算法的结果！因此，选 A 的学生混淆了 CSCAN 和 SCAN。
- **选项 B (619)**: [干扰] — 针对**排序错误**或**方向判断失误**的学生。例如，如果在向下扫描时漏掉了某个请求，或者在向上扫描时顺序搞错。具体来源可能是计算错误，如将 399-0 算错，或者在累加时出错。另一种可能是误以为从 200 直接去 399 再回来，逻辑混乱。
- **选项 C (788)**: [正确] — 正确执行 CSCAN 逻辑：
    1. 当前 200，方向减小。
    2. 小于 200 的请求：160, 120, 110, 0。排序后：160, 120, 110, 0。
    3. 路径段 1：200 -> 160 -> 120 -> 110 -> 0。距离：(200-160) + (160-120) + (120-110) + (110-0) = 40 + 40 + 10 + 110 = 200。
       *注意：解析中的计算方式略有不同，它分段计算：200-160=40, 160-110=50 (这里跳过了120? 不，160->120->110 是 40+10=50，解析写 160-110=50 是合并了中间步，没问题), 110-0=110。小计 40+50+110=200。*
    4. 到达 0 后，CSCAN 回绕至另一端 399。距离：399 - 0 = 399。
    5. 大于 200 的请求（剩余）：300, 210, 399。注意 399 是端点，通常也被视为请求。排序后（从 399 向下？不，CSCAN 是单向的。既然第一轮是向下，第二轮应该是从 399 开始向下扫描吗？
       *关键点辨析*：CSCAN 的定义是“在一个方向上移动...然后立即返回到另一端，再次开始扫描”。
       如果第一轮是 200 -> 0 (向下)，那么回绕到 399 后，第二轮扫描方向应该保持一致，即**继续向下**（从 399 向 0 的方向）。
       剩余请求：300, 210, 399。
       从 399 开始向下扫描，遇到的请求依次是：399 (当前位置), 300, 210。
       路径段 2：399 -> 300 -> 210。
       距离：(399-300) + (300-210) = 99 + 90 = 189。
       总距离 = 200 (第一段) + 399 (回绕) + 189 (第二段) = 788。
       解析中的计算：40+50+110 (第一段200) + 399 (回绕) + 99 (399-300) + 90 (300-210) = 788。逻辑一致。
- **选项 D (799)**: [干扰] — 针对**边界处理错误**的学生。例如，将回绕距离算作 400 (0 到 400?) 或者在累加时多算了一个磁道间距。或者误以为最后还要回到某个位置。

- **干扰策略**: 概念混淆（SCAN vs CSCAN，选项 A）、计算陷阱（累加错误，选项 B/D）。

## 核心陷阱
- **核心陷阱**: **CSCAN 与 SCAN 的混淆**以及**回绕距离的计算**。
    1. 许多学生容易将 CSCAN 误记为 SCAN（电梯算法），SCAN 在回扫过程中会服务请求，而 CSCAN 在回绕后重新从另一端开始单向扫描。本题中，若按 SCAN 计算（200->0->399），总距离为 200 + 399 = 599，直接对应选项 A，这是最强的干扰项。
    2. 必须明确 CSCAN 中“回绕”是否计入距离。本题解析明确计入了从 0 到 399 的 399 个磁道距离。

## 考察能力
本题核心考察考生对 **CSCAN 磁盘调度算法执行流程的精确模拟能力**，特别是区分其与 SCAN 算法在回绕机制和服务顺序上的差异，以及在多步路径规划中准确计算磁头移动总距离的能力。
