# 练习题 Q1 — 并发执行与数据竞争条件

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/存储管理
- **难度**: 待评估

## 题干原文
设 Pi 和 Pj 是两个进程，R 表示从内存中读取的变量集合，W 表示写入内存的变量集合。对于这两个进程的并发执行，以下哪项条件不成立？（ ）
A: R(Pi) ∩ W(Pj) = Ф
B: W(Pi) ∩ R(Pj) = Ф
C: R(Pi) ∩ R(Pj) = Ф
D: W(Pi) ∩ W(Pj) = Ф

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“数据竞争（Data Race）”或“并发安全性”的核心定义。考生必须明确知道哪些操作组合会导致冲突（读-写、写-读、写-写），而哪些不会（读-读）。这属于标准的核心概念记忆，不涉及复杂辨析，但必须准确理解集合交集在并发语境下的含义。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、幂次运算或单位换算。仅涉及集合论符号的逻辑判断，无计算负担。
- **K3 = 2**: 评分理由。推演步骤较少。只需将四个选项分别代入并发安全性的规则中：
    1. 检查 A：Pj 写，Pi 读 -> 冲突，需互斥（条件成立）。
    2. 检查 B：Pi 写，Pj 读 -> 冲突，需互斥（条件成立）。
    3. 检查 C：Pi 读，Pj 读 -> 无冲突，无需互斥（条件不成立/非必须）。
    4. 检查 D：Pi 写，Pj 写 -> 冲突，需互斥（条件成立）。
    整个过程为简单的逻辑映射，无需多步串行推演。
- **K4 = 4**: 评分理由。存在明显的“反直觉”陷阱和“隐含前提”。
    1. **陷阱词**：“不成立”。考生容易惯性思维寻找“正确的条件”，从而选出 A、B、D 中的一个，或者因为 C 看起来“太简单”而排除。
    2. **隐含前提**：题目问的是“对于并发执行...条件不成立”，这里的语境通常指“为了保证并发执行的正确性（无数据竞争），以下哪个互斥条件是不必要的”。如果考生没有意识到这是在讨论“互斥必要性”，可能会纠结于“是否允许并发”本身。
    3. **反直觉**：初学者常误以为“共享变量必须完全隔离”，即认为读-读也需要互斥，从而错误地认为 C 也是必须满足的条件。
- **K5 = 1**: 评分理由。本题仅涉及操作系统中进程同步与互斥的基础理论，未跨越到存储管理的具体硬件机制、文件系统或网络模块，属于单系统内的纯逻辑概念题。

- **雷达形状**: K4 陷阱型（高 K4，低 K2/K5，中等 K1/K3）

## 考察模式
- **模式**: 概念型
- **理由**: 题目核心在于考察对“数据竞争”这一基本概念的理解，即识别哪些内存访问模式会导致状态不一致。不需要计算，主要依赖对并发安全规则的记忆和逻辑判断。

## 选项级分析
- **选项 A**: [干扰] — 针对“读-写冲突”认知。R(Pi) ∩ W(Pj) ≠ ∅ 意味着 Pj 写入的变量被 Pi 读取，若不加同步，Pi 可能读到旧值或中间态，导致错误。因此，为了保证安全，通常要求此交集为空（或通过同步机制解决，但在本题语境下，若要求无条件并发安全，则需互斥）。考生若理解正确，会认为该条件是“成立/必要”的，故不选。
- **选项 B**: [干扰] — 针对“写-读冲突”认知。W(Pi) ∩ R(Pj) ≠ ∅ 意味着 Pi 写入的变量被 Pj 读取，同理存在数据竞争风险。该条件也是保证安全所“成立/必要”的，故不选。
- **选项 C**: [正确] — 针对“读-读无冲突”认知。R(Pi) ∩ R(Pj) ≠ ∅ 意味着两个进程同时读取同一变量。读取操作不改变内存状态，因此并发读取不会导致数据不一致或丢失更新。**因此，要求“R(Pi) ∩ R(Pj) = ∅”（即禁止同时读取）是不必要的，该条件对于并发安全性来说“不成立”（非必须）**。这是本题的正确答案。
- **选项 D**: [干扰] — 针对“写-写冲突”认知。W(Pi) ∩ W(Pj) ≠ ∅ 意味着两个进程同时写入同一变量，必然导致其中一个写入被覆盖或数据损坏（丢失更新）。因此，必须互斥，该条件是“成立/必要”的，故不选。

- **干扰策略**: 概念混淆。利用考生对“共享资源必须互斥”的过度泛化理解，诱导考生认为所有共享访问（包括读-读）都需要互斥，从而误判 C 为必要条件。同时利用“不成立”这一否定提问方式，增加审题难度。

## 核心陷阱
- **核心陷阱**: **审题陷阱（否定提问）+ 概念泛化陷阱**。
    1. 题目问的是“**不成立**”（即哪个条件不是必须的），而非“哪个会导致错误”。
    2. 考生容易错误地认为“只要涉及共享变量，就必须互斥”，从而误以为读-读也需要互斥，导致排除 C。实际上，读-读操作是并发安全的，不需要互斥条件。

## 考察能力
本题核心考察考生对**并发执行中数据竞争（Data Race）产生条件**的精准辨析能力，特别是区分“读-读”操作的非冲突特性与“读-写/写-写”操作的冲突特性。
