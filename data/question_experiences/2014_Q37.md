# 2014 Q37 — CDMA码片序列内积计算

## 基本信息
- **年份**: 2014  **题位**: Q37  **题型**: 选择题
- **知识点**: CN-3 > 介质访问控制 > 码分多址 CDMA
- **题位域**: 待标注  **科目**: 计算机网络

## 题干原文
站点 A、B、C 通过 CDMA 共享链路，A、B、C 的码片序列 (chipping sequence) 分别是 (1,1,1,1)、(1,-1,1,-1) 和 (1,1,-1,-1) 。若 C 从链路上收到的序列是 (2,0,2,0,0,-2,0,-2,0,2,0,2)，则 C 收到 A 发送的数据是（ ）。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆CDMA的核心定义：正交码片序列、内积运算规则以及数据比特（1/0或1/-1）与码片序列的映射关系。不记忆这些核心概念无法入题，但无需辨析多个易混概念，属于标准的基础认知需求。
- **K2 = 3**: 评分理由。涉及向量内积计算（对应元素相乘后求和）以及除以码片长度（归一化）。虽然数字较小（2的幂友好），但涉及负数运算和除法，若粗心容易算错符号或数值，属于标准的单步代入计算需求。
- **K3 = 3**: 评分理由。解题过程包含明确的串行步骤：1. 识别码片长度（4）；2. 将长序列分割为多个短序列（分组）；3. 对每组序列与目标站点码片序列做内积；4. 将内积结果映射回数据比特。共3-4步，属于标准的机制推演需求。
- **K4 = 2**: 评分理由。存在常规注意点：必须知道CDMA中比特1通常映射为码片序列本身，比特0映射为码片序列的负值（即-1倍），或者内积结果为正代表1，为负代表0（或-1，取决于教材定义，408通常规定内积>0为1，<0为0，或者内积结果为1/-1对应1/0）。这里需要意识到“0”在CDMA发送端通常对应“-1”倍的码片序列，而在接收端内积结果为0表示未发送或干扰抵消，但本题中内积结果非0。主要陷阱在于对“0”比特的映射理解，属于常规注意点。
- **K5 = 1**: 评分理由。本题仅涉及CDMA单一子系统内的信号解调过程，无需跨越不同网络层或子系统传递状态，属于单系统内部计算。
- **雷达形状**: K2/K3主导的计算推演型。K1基础扎实，K4陷阱较少，主要考察对CDMA解调算法的机械执行能力。

## 考察模式
- **模式**: 计算型
- **理由**: 题目给出了具体的数值序列，要求考生通过特定的数学运算（内积）得出结果。虽然基于概念，但解题的核心动作是计算，而非纯逻辑推理或概念辨析。

## 选项级分析
- **选项A (000)**: [干扰] — 针对完全不懂CDMA原理，或者误以为内积结果为0代表数据0，且计算错误导致全0的学生。也可能针对那些认为“收到序列中有0，所以数据就是0”的直觉错误。
- **选项B (101)**: [正确] — 正确执行了分组、内积、归一化及比特映射的全过程。
  - 第一组 (2,0,2,0)·(1,1,1,1)/4 = 4/4 = 1 → 比特1
  - 第二组 (0,-2,0,-2)·(1,1,1,1)/4 = -4/4 = -1 → 比特0 (注：408中通常规定内积为-1对应比特0，或内积为负对应0)
  - 第三组 (0,2,0,2)·(1,1,1,1)/4 = 4/4 = 1 → 比特1
  - 结果：101
- **选项C (110)**: [干扰] — 针对第二组数据计算错误，或者对比特映射规则记忆颠倒（如认为-1对应1，1对应0）的学生。如果学生误将第二组内积结果-1映射为1，而第三组算错或映射错，可能得到此结果。更常见的是，学生可能混淆了A、B、C的码片序列，用错了码片进行计算。
- **选项D (111)**: [干扰] — 针对忽略负号，或者认为所有非零内积都代表1的学生。如果学生计算第二组内积时忽略负号得到1，则会得出111。这是典型的计算粗心陷阱。

- **干扰策略**: 计算陷阱（符号错误、映射错误）与概念混淆（码片序列用错）。

## 核心陷阱
- **核心陷阱**: **比特0的映射规则与内积结果的符号对应关系**。
  在CDMA中，发送比特1时发送码片序列 $S$，发送比特0时发送 $-S$。接收端通过计算内积 $S \cdot R / m$ 来解调。
  - 若内积结果为 $1$，则发送的是 $1$。
  - 若内积结果为 $-1$，则发送的是 $0$。
  - 若内积结果为 $0$，则未发送该站点的数据（或干扰完全抵消）。
  本题中第二组内积结果为 $-1$，对应比特 $0$。许多考生容易忽略负号，或者记反映射关系，从而误选D或C。

## 考察能力
本题核心考察考生对CDMA多址接入技术中**信号解调算法（内积运算）**的准确执行能力，以及对**比特与码片序列映射关系**的理解。
