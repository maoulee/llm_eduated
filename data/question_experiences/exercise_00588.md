# 练习题 Q1 — 快速排序主元选择与复杂度分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/排序
- **难度**: 待评估

## 题干原文
假设我们有一个 O(n) 时间的算法可以找到一个未排序数组的中位数。现在考虑一个快速排序的实现：我们首先使用上述算法找到中位数，然后将该中位数作为主元。这种修改后的快速排序的最坏情况时间复杂度是多少？

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握快速排序的基本原理、递归树模型以及主定理（Master Theorem）或递归式求解的基本概念。不是2分因为仅靠记忆无法直接得出答案，需要理解“中位数作为主元”对递归深度的影响；不是4分因为不需要辨析多个易混的高级排序算法细节，核心概念较为单一。
- **K2 = 2**: 评分理由。计算过程非常标准且友好。核心计算是识别递归式 $T(n) = 2T(n/2) + O(n)$ 并应用主定理 Case 2 得出 $O(n \log n)$。没有复杂的数值换算或非2幂次计算，属于标准的理论推导代入。
- **K3 = 3**: 评分理由。推演步骤清晰但需多步逻辑串联：1. 理解中位数分割意味着左右子数组大小均为 $n/2$；2. 建立递归关系式 $T(n) = 2T(n/2) + O(n)$（其中 $O(n)$ 包含找中位数的时间和划分时间）；3. 求解递归式。这属于3-5步的标准逻辑推演。
- **K4 = 2**: 评分理由。题目条件明确，没有明显的隐含陷阱或反直觉条件。唯一的“注意点”是确认找中位数的 $O(n)$ 开销不会改变整体复杂度量级（即 $O(n)$ 在 $O(n \log n)$ 中占主导或同等量级，不破坏对数因子）。这属于常规的理论注意点，非深层陷阱。
- **K5 = 1**: 评分理由。本题完全局限于“排序算法”这一单一子系统内部，不涉及与其他数据结构（如堆、树）或操作系统、网络等跨域知识的联动。

- **雷达形状**: 均衡偏推理型（K3略高，K1/K2/K4中等，K5极低）。

## 考察模式
- **模式**: 推理型
- **理由**: 本题不侧重于具体的代码实现或数值计算，而是侧重于对算法行为机制的理论推导。考生需要理解“选择中位数作为主元”这一操作如何改变快速排序的递归结构，进而推导出时间复杂度。

## 选项级分析
- **选项A**: [干扰] — 针对对递归深度和每层开销乘积关系的错误认知。这类学生可能误以为每层开销是 $n^2$ 或者递归深度是 $n \log n$，导致得出 $n^2 \log n$ 这种荒谬的高阶复杂度。
- **选项B**: [干扰] — 针对对“最坏情况”定义的僵化理解。这类学生可能记得标准快速排序的最坏情况是 $O(n^2)$，而忽略了题目中“使用中位数作为主元”这一关键修改条件，未能意识到该修改消除了导致 $O(n^2)$ 的不平衡分割。
- **选项C**: [干扰] — 针对对主定理应用或递归树层数计算的混淆。这类学生可能正确识别了 $O(n \log n)$ 的基础，但错误地认为找中位数的 $O(n)$ 操作会在每一层额外增加一个 $\log n$ 因子，或者混淆了 $O(n \log n)$ 与 $O(n \log^2 n)$ 的区别。
- **选项D**: [正确] — 正确推导。使用中位数作为主元保证了每次划分都将数组均匀分为两半，递归深度为 $\log n$，每层处理时间为 $O(n)$，总时间为 $O(n \log n)$。

- **干扰策略**: 概念混淆（混淆标准快排与优化快排的最坏情况）、记忆依赖（死记硬背标准快排最坏情况而忽略题干条件）。

## 核心陷阱
- **核心陷阱**: **忽略题干中的关键约束条件**。最大的陷阱在于考生容易直接调用“快速排序最坏情况是 $O(n^2)$”这一固有知识，而忽视了题目中“使用中位数作为主元”这一前提彻底改变了快速排序的分割平衡性，从而将最坏情况转化为平均情况（即最优的平衡分割）。

## 考察能力
一句话概括本题核心考察的能力：
**考察考生对快速排序算法复杂度决定因素（分割平衡性）的理解，以及在特定约束条件下建立并求解递归关系式的能力。**
