# 练习题 Q1 — 树性质与节点度数关系推导

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/二叉树
- **难度**: 待评估

## 题干原文
一棵有 n 个节点的根树中，每个节点有 0 或 3 个子节点。该树的叶节点数量为（ ）：
A: n/2
B: (n−1)/3
C: (n−1)/2
D: (2n+1)/3

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握树的基本定义（节点、子节点、叶节点、内部节点）以及“节点数与边数关系”或“度数与节点数关系”这一核心概念。不需要辨析多个易混概念，但必须准确理解“0或3个子节点”意味着这是一棵严格的三叉树（Strict Ternary Tree）。
- **K2 = 3**: 评分理由。涉及简单的代数运算。需要建立方程组 $n = L + I$ 和 $n = 3I + 1$（或 $L = 2I + 1$），然后解出 $L$ 关于 $n$ 的表达式。计算过程包含分数运算，非2的幂次，属于标准难度的代数变换。
- **K3 = 3**: 评分理由。推演步骤清晰但需多步串行：1. 定义变量（叶节点L，内部节点I）；2. 利用总节点数建立第一个方程；3. 利用子节点总数（即边数）或度数关系建立第二个方程；4. 联立消元求解。共3-4步逻辑推演，属于标准复杂度。
- **K4 = 2**: 评分理由。题目条件明确（0或3个子节点），没有明显的隐含前提或反直觉陷阱。唯一的“暗坑”在于是否记得树中边数等于节点数减1，或者是否知道严格m叉树的叶节点公式。对于熟悉公式的学生是2，对于需要推导的学生也是常规逻辑，无深层陷阱。
- **K5 = 1**: 评分理由。本题完全局限于数据结构中的“树”这一单一子系统内部，不涉及操作系统、计算机网络或组成原理等其他领域的知识联动。

- **雷达形状**: K2/K3主导的均衡偏计算型。K1基础适中，K4陷阱较低，整体呈现标准的理论推导特征。

## 考察模式
- **模式**: 推理型
- **理由**: 虽然最终结果是代数表达式，但解题核心不在于记忆公式（尽管有公式），而在于理解树的结构性质（边数与节点数的关系，或度数与节点数的关系）并进行逻辑推导。它考察的是从结构定义到数量关系的映射能力。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：混淆二叉树与三叉树。在满二叉树中，叶节点数 $L = (n+1)/2$，近似 $n/2$。学生可能惯性思维套用二叉树结论。
- **选项B**: [干扰] — 针对错误认知：计算错误或公式记反。可能是将内部节点数 $I = (n-1)/3$ 误认为是叶节点数，或者在解方程时符号处理错误。
- **选项C**: [干扰] — 针对错误认知：混淆二叉树公式。满二叉树叶节点公式为 $(n+1)/2$，若记错为 $(n-1)/2$ 可能会选此项。这是典型的“似曾相识”干扰项。
- **选项D**: [正确] — 正确推导结果。由 $n = 3I + 1$ 得 $I = (n-1)/3$，又 $L = n - I = n - (n-1)/3 = (3n - n + 1)/3 = (2n+1)/3$。

- **干扰策略**: 概念混淆（二叉树vs三叉树）与计算陷阱（内部节点与叶节点混淆）。

## 核心陷阱
- **核心陷阱**: **内部节点数与叶节点数的混淆**。
  许多学生能正确推导出内部节点数 $I = (n-1)/3$，但在最后一步忘记求叶节点 $L$，直接选择了B选项。或者错误地认为叶节点数与内部节点数有简单的线性比例而忽略常数项。

## 考察能力
一句话概括本题核心考察的能力：
掌握树结构中节点度数与节点总数之间的代数关系，并能通过建立方程组推导特定类型树（严格m叉树）的叶节点数量公式。
