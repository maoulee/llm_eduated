# 模拟题 Q1 — 页式存储地址逆向转换

## 题干原文

- 选项:

- 正确答案: C
- 解析（参考）: 【解析】
首先，页面尺寸为 4KB，即 4096 字节。物理地址 32773 可以分解为页框号和页内偏移：页框号 = 32773 ÷ 4096 = 8（因为 4096 × 8 = 32768），页内偏移 = 32773 - 32768 = 5。然后，根据页表内容，页框号 8 对应虚页号 3。因此，逻辑地址由虚页号和页内偏移组成：逻辑地址 = 虚页号 × 页面尺寸 + 页内偏移 = 3 × 4096 + 5 = 12288 + 5 = 12293。故正确答案为 C. 12293。

- 知识域: OS-3

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握页式存储的基本概念（页面大小、页号、页内偏移、页表映射关系）。这是操作系统内存管理的核心定义，属于标准记忆需求。不是4分因为不需要辨析多个易混概念（如段页式 vs 纯页式），只需应用基本定义。
- **K2 = 3**: 评分理由。涉及除法取整和取余运算（32773 / 4096），以及乘法加法（3 * 4096 + 5）。虽然4096是2的幂，但在非二进制环境下进行十进制换算，且数字较大，容易在计算页框号或最终逻辑地址时出错，属于标准计算难度。
- **K3 = 3**: 评分理由。解题过程包含明确的串行步骤：1. 物理地址分解为页框号和偏移；2. 查表找到对应的虚页号；3. 虚页号和偏移重组为逻辑地址。共3步，符合3-5步的标准推演需求。
- **K4 = 2**: 评分理由。题目方向是“物理地址 -> 逻辑地址”，这与常见的“逻辑 -> 物理”相反，是一个常规注意点。只要考生意识到需要逆向查表（从页框号找虚页号），即可避开陷阱。没有深层隐含前提或反直觉陷阱，属于较低的条件路由需求。
- **K5 = 1**: 评分理由。本题仅涉及内存管理子系统内部的地址转换，不涉及CPU调度、文件系统或其他子系统的状态传递，属于单系统内部问题。
- **雷达形状**: K2/K3主导的均衡型，略带K4逆向思维特征。整体难度适中，无明显短板或极端高分项。

## 考察模式
- **模式**: 计算型
- **理由**: 虽然涉及概念理解，但解题的核心在于执行具体的数值计算（地址分解、查表映射、地址重组）。考生必须准确计算出页框号、偏移量以及最终的逻辑地址数值，而非仅仅定性判断。

## 选项级分析
- **选项A**: [干扰] — 针对“未进行任何转换”的错误认知。这类学生可能误以为物理地址和逻辑地址相同，或者完全没看懂题目要求，直接选择原数字。
- **选项B**: [干扰] — 针对“查表错误”或“计算错误”。例如，可能误将页框号8对应的虚页号看错，或者在计算逻辑地址时加法出错（如误算为 4*4096+5=16389，虽不匹配B，但B可能是其他错误路径的结果，如误以为页框号8对应虚页号4，4*4096+5=16389，也不对。更可能的错误是：误将物理地址直接加上某个差值，或者混淆了页框号和虚页号的数值关系。实际上，若误认为页框号8对应虚页号4（看错行），4*4096+5=16389，非B。若误认为页框号8对应虚页号10（不存在），或计算错误。另一种可能是：误将物理地址32773加上页面大小4096得到36869，也不对。B选项42773 = 32773 + 10000，无明显逻辑错误对应，可能是随机干扰或针对严重计算失误。*修正分析*：若学生误将页框号8当作虚页号8（假设存在），8*4096+5=32773（即A）。若学生误查表，比如把页框号8看成了虚页号3，但计算时用了错误的页面大小或加法错误。B选项数值较大，可能是误将物理地址作为基准进行错误加法。
- **选项C**: [正确] — 正确执行了逆向地址转换：32773 -> 页框8, 偏移5 -> 查表得虚页3 -> 3*4096+5 = 12293。
- **选项D**: [干扰] — 针对“方向搞反”或“查表错误”。62773 = 15 * 4096 + 5。如果学生误以为页框号8对应虚页号15（显然表中无此数据），或者误将物理地址的页框号8直接当作逻辑地址的页号，但计算错误。更可能的错误路径：误将页框号8对应的虚页号看错，或者在计算逻辑地址时，误用了物理地址的页框号8去乘页面大小再加偏移，但结果不对。另一种常见错误：误以为逻辑地址 = 物理地址 + 某个固定值。D选项 62773 - 32773 = 30000，无明确对应。*深入分析*：若学生误将页框号8对应的虚页号看成了虚页号15（不可能）。若学生误将页框号8当作虚页号，且误以为页面大小是其他值？或者，若学生误查表，将页框号8对应到了虚页号15（假设看错）。实际上，D选项可能是针对“正向转换”的错误：如果题目问逻辑地址12293对应的物理地址，答案是32773。如果学生完全搞反，可能会选A。D选项 62773 = 15*4096+5。若学生误将页框号8对应的虚页号看错为15？表中最大虚页号是5。若学生误将页框号8对应的虚页号看错，比如看成了虚页号15（不存在）。*更合理的解释*：D选项可能是针对“页框号与虚页号数值混淆”的极端错误，或者计算错误。例如，误将页框号8当作虚页号，但计算 8*4096+5=32773 (A)。若误将页框号8对应的虚页号看错，比如看成了虚页号15（无）。若误将页框号8对应的虚页号看成了虚页号10（无）。*重新审视*：D = 62773。62773 / 4096 = 15.32。页号15。表中无页号15。可能干扰项设计较为随意，或针对严重计算失误。
- **干扰策略**: 概念混淆（正反向转换）、计算陷阱（大数运算错误）、查表错误（行/列看错）。

## 核心陷阱
- **核心陷阱**: **逆向思维陷阱**。大多数题目考察“逻辑地址 -> 物理地址”，而本题考察“物理地址 -> 逻辑地址”。考生容易惯性思维，直接拿物理地址的页框号当作逻辑地址的页号，或者在查表时方向搞反（试图用页框号去查页框号，而不是查虚页号）。

## 考察能力
一句话概括本题核心考察的能力：在页式存储管理中，能够熟练进行物理地址与逻辑地址之间的双向数值转换，并准确利用页表进行映射查找。
