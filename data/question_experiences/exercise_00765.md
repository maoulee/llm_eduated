# 练习题 Q1 — 双栈输出序列合法性判定

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/栈
- **难度**: 待评估

## 题干原文
堆栈 A 中包含元素 a、b、c（a 在顶部），堆栈 B 为空。从堆栈 A 弹出的元素可以立即打印或压入堆栈 B，而从堆栈 B 弹出的元素只能被打印。在这种安排下，以下哪个排列顺序不可能实现？（ ）
- 选项:
  A: b a c
  B: b c a
  C: c a b
  D: a b c

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握栈的基本操作（Push/Pop）及“后进先出”（LIFO）的核心定义。不是4分因为不需要辨析多个易混概念（如队列与栈的区别），只需理解单一栈结构的行为即可。
- **K2 = 1**: 评分理由。本题不涉及数值计算，无需执行算术运算或幂次换算，属于纯逻辑判断。
- **K3 = 4**: 评分理由。从输入到输出需多步串行推演。考生需要在脑海中模拟“从A弹出 -> 选择打印或入B -> 从B弹出打印”这一过程。对于每个选项，可能需要3-5步的状态追踪，且需记忆中间状态（栈B中剩余元素），符合>5步或需记忆中间状态的特征。
- **K4 = 3**: 评分理由。存在常规注意点作为陷阱。关键在于理解“从A弹出的元素可以立即打印”这一规则，很多学生容易忽略这一点，误以为所有元素必须先经过栈B。此外，需意识到栈B的LIFO特性对输出顺序的限制。
- **K5 = 3**: 评分理由。涉及两个子系统（栈A和栈B）之间的数据传递。元素从栈A流向栈B或直接输出，状态在两个栈之间单向传递（A->B），属于单向传数据的情况。

- **雷达形状**: K3推演主导型，K4陷阱辅助型。整体呈现以逻辑推演为核心，辅以规则细节考察的特征。

## 考察模式
- **模式**: 推理型
- **理由**: 本题不依赖公式计算，而是要求考生根据给定的操作规则（栈的进出栈逻辑），通过逻辑推理和状态模拟，判断特定输出序列的可行性。核心在于对过程的控制流进行逆向或正向验证。

## 选项级分析
- **选项A (b a c)**: [干扰] — 针对“忽略栈B缓冲作用”的错误认知。学生可能认为a在顶部，必须先处理a，从而误判。实际上，a可以压入B，b直接打印，再弹出a，最后c直接打印。
- **选项B (b c a)**: [干扰] — 针对“对栈B深度理解不足”的错误认知。学生可能认为a压入B后，必须紧接着弹出a。实际上，a压入B后，b和c可以直接从A打印，最后再弹出a。
- **选项C (c a b)**: [正确] — 针对“违反LIFO原则”的错误认知。要输出c，a和b必须先在栈B中（因为a在b上面，b在c上面，c要出来，a和b必须被移走）。此时栈B状态为底[a, b]顶。根据LIFO，必须先弹出b，再弹出a。因此输出只能是c b a，不可能是c a b。选此项的学生正确识别了栈的约束。
- **选项D (a b c)**: [干扰] — 针对“认为必须使用栈B”的错误认知。学生可能觉得题目给了两个栈，必须都用上。实际上，a、b、c可以直接从A依次弹出并打印，完全不需要栈B。

- **干扰策略**: 概念混淆与规则遗漏。主要利用学生对“直接打印”规则的忽视，以及对双栈交互时LIFO约束的直觉偏差来设置干扰项。

## 核心陷阱
- **核心陷阱**: 忽略“从堆栈 A 弹出的元素可以立即打印”这一规则，误以为所有元素必须经过堆栈 B 才能输出；或者在模拟过程中，忘记堆栈 B 的“后进先出”特性，导致错误地认为可以随意从 B 中取出任意元素。

## 考察能力
一句话概括本题核心考察的能力：在多重约束条件下，对栈数据结构状态变化进行精确模拟与逻辑推理的能力。
