# 练习题 Q1 — IP头部字段在路由过程中的修改机制

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/网络层
- **难度**: 待评估

## 题干原文
以下哪一项 IP 头部字段不会被典型的 IP 路由器（非 NAT 路由器）修改？（ ）
A: 校验和
B: 源地址
C: 生存时间（TTL）
D: 长度

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆 IP 数据报头部各字段的基本功能及路由器处理数据报时的标准行为。属于核心定义记忆，但需区分“典型路由器”与“NAT路由器”的概念边界，非单纯死记硬背，需理解字段含义。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全基于概念判断。
- **K3 = 2**: 评分理由。推演步骤较少。只需模拟数据包经过一个普通路由器时的处理流程：检查TTL（递减）、检查分片（可能修改长度和校验和）、转发。无需多步复杂状态追踪。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱词。题干强调“典型的 IP 路由器（非 NAT 路由器）”，这是解题的关键约束。若忽略此条件，考虑到 NAT 场景，源地址会被修改，导致误判。此外，需识别“长度”字段在分片场景下会被修改这一易错点，属于典型的条件路由型陷阱。
- **K5 = 1**: 评分理由。本题仅涉及网络层内部机制，未涉及传输层（如端口号）、链路层（如MAC地址）或应用层的跨层联动，属于单系统内部逻辑判断。
- **雷达形状**: K4陷阱型（K4显著高于其他维度，K2极低）

## 考察模式
- **模式**: 概念型
- **理由**: 题目核心在于考察对 IP 协议头部字段定义及路由器转发机制的理论理解，而非通过计算或复杂逻辑推理得出结论。重点在于辨析不同字段在特定网络环境（非NAT）下的可变性。

## 选项级分析
- **选项A**: [干扰] — 针对“校验和仅用于端到端验证”的错误认知。许多学生误以为校验和只在源端计算、目的端验证，中间节点不碰。实际上，由于 TTL 递减或分片导致头部变化，路由器必须重新计算并修改 IP 头部校验和。
- **选项B**: [正确] — 符合“典型路由器不修改源地址”的定义。在非 NAT 环境下，IP 路由基于目的地址转发，源地址保持不变，以确保回包路径正确。
- **选项C**: [干扰] — 针对“TTL 仅用于防止环路，路由器不修改”的误解。TTL 是路由器每跳必减的字段，这是 IP 协议防止数据包无限循环的核心机制，属于基础知识点，容易排除。
- **选项D**: [干扰] — 针对“IP 数据报长度固定”的错误认知。当 MTU 限制导致分片时，每个分片的“总长度”字段都会改变，且分片偏移量也会变化。虽然并非每个包都分片，但“可能被修改”即意味着它不是“绝对不会被修改”的字段。

- **干扰策略**: 概念混淆与条件限定陷阱。利用 NAT 场景下源地址可变的常识干扰对“典型路由器”定义的判断；利用分片场景下长度和校验和的可变性干扰对“绝对不变”字段的筛选。

## 核心陷阱
- **核心陷阱**: 忽略题干中“非 NAT 路由器”这一关键限定条件，或者混淆“IP 头部校验和”与“TCP/UDP 校验和”的作用范围。学生容易误选 A（认为校验和不变）或误选 D（认为长度不变），而最深层的陷阱在于若未注意到“非 NAT”，可能会犹豫 B（因为 NAT 会改源地址）。

## 考察能力
本题核心考察考生对 IP 数据报头部字段在路由转发过程中动态变化机制的精准辨析能力，特别是对“典型路由行为”与“特殊网络功能（如NAT、分片）”边界的界定能力。
