# 2015 Q8 — KMP算法next数组计算与失配处理

## 基本信息
- **年份**: 2015  **题位**: Q8  **题型**: 选择题
- **知识点**: DS-4 > 串的模式匹配 > KMP 模式匹配, DS-4 > 串的模式匹配 > next 数组
- **题位域**: DS-4  **科目**: 数据结构

## 题干原文
已知字符串 s 为 “abaabaabacacaabaabcc”，模式串 t 为 “abaabc”。采用 KMP 算法进行匹配，第一次出现“失配”（s[i] ≠ t[j]）时，i = j = 5，则下次开始匹配时，i 和 j 的值分别是（ ）。

A. i = 1, j = 0
B. i = 5, j = 0
C. i = 5, j = 2
D. i = 6, j = 2

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握KMP算法的核心概念，特别是`next`数组的定义以及失配时指针移动的规则。如果不记忆KMP的基本机制，完全无法入题；但只需掌握一个核心定义（next数组含义及跳转规则），无需辨析多个易混概念，故为标准难度。
- **K2 = 3**: 评分理由。涉及`next`数组的具体数值计算。虽然模式串较短（长度6），但计算`next[5]`需要回顾前缀后缀匹配逻辑，属于非2幂次的离散计算，容易因对“最长相等前后缀”理解偏差而算错，故为标准难度。
- **K3 = 2**: 评分理由。从输入到输出步骤较少。主要步骤为：1. 确定索引从0开始；2. 计算或查表得到`next[5]`；3. 应用规则`j = next[j]`, `i`不变。总共约3步串行推演，无需记忆大量中间状态，故为较低难度。
- **K4 = 4**: 评分理由。存在显著的隐含前提和陷阱。题面给出`i=j=5`，考生必须敏锐意识到这意味着字符串索引是从0开始的（因为模式串`abaabc`长度为6，若从1开始，`j`最大为6，且通常教材中`next`数组定义与索引起始强相关）。若误判为从1开始，会导致`next`数组取值错误。此外，需避开“失配时i也要回退”的朴素匹配思维陷阱。故为较高难度。
- **K5 = 1**: 评分理由。本题仅涉及数据结构中的串匹配子系统，不涉及与其他模块（如树、图、排序等）的状态传递或耦合，故为微弱难度。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要难点在于对索引起始位置和算法细节的隐含条件识别）

## 考察模式
- **模式**: 综合型（偏向推理与概念应用）
- **理由**: 本题不仅要求记忆`next`数组的计算公式（概念），还需要根据题设条件推断索引体系（推理），最后结合KMP算法的指针移动规则得出结果（应用）。它不是单纯的公式代入，也不是纯逻辑推理，而是对算法执行过程片段的精准还原。

## 选项级分析
- **选项A**: [干扰] — 针对“朴素匹配算法”或“完全重置”的错误认知。这类学生可能认为失配后需要从头开始匹配，或者混淆了KMP与BF算法，认为`i`也要回退到起始位置附近，或者误以为`j`回退到0且`i`也发生了某种重置。
- **选项B**: [干扰] — 针对“KMP规则记忆模糊”的错误认知。这类学生知道`i`不变，但错误地认为`j`应该回退到0（即`next[j]=0`），可能是误算了`next[5]`的值，或者混淆了`next`数组与`nextval`数组在某些特定情况下的表现，亦或是记错了回退规则。
- **选项C**: [正确] — 正确应用了KMP算法规则。识别出索引从0开始，计算出`next[5]=2`，并正确执行`i`不变，`j`变为`next[5]`。
- **选项D**: [干扰] — 针对“索引从1开始”或“i随j移动”的错误认知。这类学生可能误以为字符串索引从1开始，导致`next`数组计算偏移，或者错误地认为失配后`i`也要向前移动一位（即`i`变为6），这是将KMP与某些变体算法或理解偏差混合的结果。

- **干扰策略**: 概念混淆（KMP vs BF）、计算陷阱（next值算错）、隐含条件陷阱（索引起始位）

## 核心陷阱
- **核心陷阱**: **索引起始位的隐含判断**与**next数组值的准确计算**。
  1. 题面给出`i=j=5`，模式串`t`为`abaabc`（长度6）。若索引从1开始，`j`最大为6，`j=5`对应字符`b`，但此时`s[5]`与`t[5]`是否失配需结合具体字符串判断，且通常考研教材（如严蔚敏版）中KMP的`next`数组定义与索引从1开始紧密相关（`next[1]=0`等）。然而，若索引从0开始，`j=5`对应`t`的最后一个字符`c`。题目中`s`在索引5处的字符是`a`（`abaaba...`，索引0-5为`a,b,a,a,b,a`），`t`在索引5处的字符是`c`（`abaabc`，索引0-5为`a,b,a,a,b,c`）。`a != c`，确实失配。这确认了索引是从0开始的。
  2. 若考生未意识到索引从0开始，可能会套用从1开始的`next`数组计算逻辑，导致`next`值错误。
  3. 即使知道索引从0开始，计算`next[5]`时，需找`t[0..4]`即`abaab`的最长相等前后缀。前缀`a`, `ab`, `aba`, `abaa`；后缀`b`, `ab`, `aab`, `baab`。最长相等的是`ab`，长度为2。故`next[5] = 2`。若计算错误（如算成1或0），则会选错。

## 考察能力
一句话概括本题核心考察的能力：在特定边界条件下（隐含索引体系），准确计算KMP算法next数组值并应用失配跳转规则的能力。
