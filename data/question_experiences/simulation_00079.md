# 模拟题 Q1 — RIP协议距离向量更新机制

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: CN-4 > 路由协议 > RIP协议, CN-4 > 路由算法 > 距离向量算法
- **难度**: 待评估

## 题干原文
R1 和 R2 是一个自治系统中采用 RIP 路由协议的两个相邻路由器，R1 的路由表如表 1 所示，当 R1 收到 R2 发送的报文（见表 2）后，R1 更新后的 3 个路由表项中距离值从上到下依次为（ ）。
表 1 R1 的路由表

| 目的网络 | 距离 | 路由 |
| :--- | :--- | :--- |
| 10.0.0.0 | 0 | 直接 |
| 20.0.0.0 | 7 | R2 |
| 30.0.0.0 | 4 | R2 |

表 2 R2 发送的报文

| 目的网络 | 距离 |
| :--- | :--- |
| 10.0.0.0 | 3 |
| 20.0.0.0 | 4 |
| 30.0.0.0 | 3 |

- 选项:
  A: 0、4、3
  B: 0、4、4
  C: 0、5、3
  D: 0、5、4
- 正确答案: D
- 解析（参考）: 【解析】
RIP 协议采用距离向量算法，路由器根据邻居发来的路由更新报文更新自己的路由表。更新时，对于每个目的网络，计算通过邻居的新距离：邻居报告的距离加上从本路由器到邻居的跳数（相邻路由器跳数为 1），然后与当前距离比较，若新距离更小则更新，若相等或更大则保持原路由。
对于目的网络 10.0.0.0，R1 当前为直接连接，距离 0；R2 报告距离 3，新距离为 3+1=4，大于 0，因此保持距离 0 不变。
对于目的网络 20.0.0.0，R1 当前距离 7 通过 R2；R2 报告距离 4，新距离为 4+1=5，小于 7，因此更新为距离 5。
对于目的网络 30.0.0.0，R1 当前距离 4 通过 R2；R2 报告距离 3，新距离为 3+1=4，等于 4，因此保持距离 4 不变（注意：RIP中若下一跳相同，即使距离相等也不更新，或者视为无改善；若下一跳不同且距离相等，通常也不更新或随机选择，但在本题语境下，下一跳均为R2，故维持原状）。
- 知识标签: ['CN-4 > 路由协议 > RIP协议', 'CN-4 > 路由算法 > 距离向量算法']
- 知识域: CN-4

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆RIP协议的核心机制：距离向量算法、跳数计算规则（邻居距离+1）、以及路由更新的基本逻辑（更短则更新，否则保持）。这是计算机网络中的核心定义，属于标准记忆需求。不是4分因为不需要辨析多个易混协议（如OSPF与RIP的深层区别），只需掌握RIP单一协议规则。
- **K2 = 2**: 评分理由。计算过程极其简单，仅为整数加法（3+1, 4+1, 3+1）和大小比较。没有复杂的幂次或单位换算，属于较低的计算需求。
- **K3 = 3**: 评分理由。需要对三个不同的目的网络分别执行“计算新距离 -> 比较旧距离 -> 决定更新”这一串行逻辑。虽然每步简单，但涉及三个独立对象的并行处理逻辑，且需结合“下一跳”信息进行判断（特别是30.0.0.0的情况），属于标准的机制推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。
    1. **陷阱1**：对于10.0.0.0，考生容易忽略“直接连接”距离为0且优先级最高，误以为要比较4和0。
    2. **陷阱2（核心）**：对于30.0.0.0，新计算距离为4，原距离为4。考生容易误以为“相等也要更新”或者“相等就更新为邻居的值”，而忽略了RIP中若下一跳相同（都是R2），距离无改善则不更新；或者即使下一跳不同，RIP通常也不在距离相等时盲目切换（除非有特定策略，但考研默认不更新）。这里考察了对“更新条件”的精确理解，即“严格小于”才更新，或者结合下一跳判断。这是一个典型的“题面没说但解题必须意识到的条件”（即下一跳一致时的稳定性原则）。
- **K5 = 1**: 评分理由。本题仅涉及单个自治系统内的两个路由器交互，属于单系统内的局部状态更新，不涉及跨子系统（如TCP与IP联动、应用层与传输层联动）的状态传递。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，尤其是K2极低，说明计算不是难点，逻辑陷阱是难点）

## 考察模式
- **模式**: 推理型
- **理由**: 虽然包含简单的加法计算，但题目的核心不在于计算结果，而在于根据RIP协议的规则（距离向量算法的更新逻辑）进行逻辑推理和状态判断。考生必须理解“为什么更新”和“为什么不更新”背后的协议机制，而非单纯代入公式。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：认为所有路由都要更新，且对于30.0.0.0，误以为新距离3（直接取R2的值，忘记+1）或者误以为相等时更新为更小的值（如果误算成3）。或者认为20.0.0.0更新为4（忘记+1）。这类学生可能混淆了“邻居报告的距离”和“本路由器到目的地的距离”。
- **选项B**: [干扰] — 针对错误认知：对于20.0.0.0，误以为新距离是4（忘记+1）；对于30.0.0.0，误以为相等时不更新（正确），但20.0.0.0算错。或者认为20.0.0.0更新为4（错误计算），30.0.0.0保持4。
- **选项C**: [干扰] — 针对错误认知：对于20.0.0.0，正确更新为5；但对于30.0.0.0，误以为新距离3（忘记+1）或者误以为相等时更新为3（如果误算）。或者认为30.0.0.0应该更新，因为R2说距离是3，所以R1认为是3。这类学生忽略了“跳数+1”的规则。
- **选项D**: [正确] — 10.0.0.0保持0（直接连接最优）；20.0.0.0更新为5（4+1 < 7）；30.0.0.0保持4（3+1 = 4，无改善，且下一跳相同，不更新）。

- **干扰策略**: 计算陷阱（忘记+1）与逻辑陷阱（相等是否更新）混合。

## 核心陷阱
- **核心陷阱**: **30.0.0.0路由项的更新判断**。
    1. 计算陷阱：忘记将邻居报告的距离加1（即误认为新距离是3而不是4）。
    2. 逻辑陷阱：当新计算距离（4）等于原距离（4）时，是否更新？在RIP中，如果下一跳相同（都是R2），距离没有变短，则不更新路由表，以保持路由稳定。如果考生误以为“相等也要更新”或者“只要收到报文就更新”，就会选错。此外，10.0.0.0作为直连路由，距离为0，任何通过邻居的路径（距离>=1）都不会覆盖它，这也是一个基础但易被匆忙忽略的点。

## 考察能力
本题核心考察考生对RIP协议距离向量算法中**路由更新规则**（特别是“下一跳相同且距离无改善时不更新”以及“直连路由优先级”）的精确理解和应用能力。
