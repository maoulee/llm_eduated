# 练习题 Q1 — 进程同步与信号量机制

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/进程管理
- **难度**: 待评估

## 题干原文
两个并发进程 P1 和 P2 使用四个共享资源 R1、R2、R3 和 R4，如下所示：
Compute;
Use R1;
Use R2;
Use R3;
Use R4;
P1
Compute;
Use R1;
Use R2;
Use R3;
Use R4;
P2
两个进程同时启动，每个资源一次只能被一个进程访问。进程间存在以下资源调度约束：
P2 必须在 P1 访问 R1 之前完成对 R1 的使用
P1 必须在 P2 访问 R2 之前完成对 R2 的使用
P2 必须在 P1 访问 R3 之前完成对 R3 的使用
P1 必须在 P2 访问 R4 之前完成对 R4 的使用
除此之外没有其他调度约束。若仅使用二进制信号量来强制执行上述调度约束，至少需要多少个二进制信号量？（ ）
- 选项:
  A: 1
  B: 2
  C: 3
  D: 4
- 正确答案: B
- 解析（参考）: 解析
需要使用两个信号量 A 和 B，其中 A 的初始值为 0，B 的初始值为 1。
semaphore A = 0;
semaphore B = 1;

 Compute;
 Wait(A);

 Use R2;

 Use R4;

}

 Use R3;

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握二进制信号量的基本概念（Wait/Signal操作、初始值含义）以及进程同步的基本定义。不是4分因为不需要辨析多个易混概念（如管程、自旋锁等），只需核心信号量知识即可入题。
- **K2 = 1**: 评分理由。本题不涉及数值计算，无需执行任何算术运算或单位换算。
- **K3 = 4**: 评分理由。需要在明确规则下进行多步串行推演。考生必须将文字描述的先后顺序约束转化为具体的信号量操作序列，并验证该序列是否满足所有约束且无死锁。这涉及对P1和P2执行流的交替模拟，步骤较多且需保持中间状态（信号量值）的一致性。
- **K4 = 4**: 评分理由。存在隐含前提和反直觉陷阱。常规思维可能认为4个资源或4个约束需要4个信号量，或者认为每个资源互斥需要额外信号量。但题目强调“仅使用二进制信号量来强制执行上述调度约束”，且资源互斥可通过串行化访问自然满足（因为约束强制了严格的交替顺序）。识别出“交替执行”模式并意识到可以用两个信号量实现“乒乓”同步是解题关键，属于较深的隐含前提。
- **K5 = 2**: 评分理由。仅在进程管理子系统内部进行状态传递，不涉及内存管理、文件系统等其他子系统的联动。

- **雷达形状**: K3-K4 双高型（推理与陷阱主导）

## 考察模式
- **模式**: 推理型
- **理由**: 题目不直接考查公式或定义记忆，而是要求考生根据给定的逻辑约束，设计并验证同步机制。核心在于逻辑推导和状态机建模，而非简单的知识回忆或计算。

## 选项级分析
- **选项A**: [干扰] — 针对认为“所有约束可以合并为一个全局锁”的错误认知。这类学生可能误以为只需要一个信号量来控制整体顺序，但无法实现P1和P2的交替执行（一个信号量只能实现单向等待，无法实现双向交替）。
- **选项B**: [正确] — 正确识别出P1和P2是严格的交替执行模式（P2->R1, P1->R2, P2->R3, P1->R4），这种“乒乓”同步模式经典地需要两个信号量（一个初始为0，一个初始为1）来实现。
- **选项C**: [干扰] — 针对认为“需要为每个资源或每对约束单独设置信号量”但未能优化组合的学生。或者误以为需要3个信号量来处理某种不对称性。
- **选项D**: [干扰] — 针对线性思维的学生。看到4个资源或4条约束，直接对应4个信号量。这类学生没有意识到约束之间的连锁反应和交替模式，未能进行逻辑抽象和简化。

- **干扰策略**: 线性映射陷阱（选项D）与 概念混淆（选项A/C）。利用考生对“资源数量”与“信号量数量”之间关系的直觉错误进行干扰。

## 核心陷阱
- **核心陷阱**: 将“资源互斥”与“执行顺序同步”混淆，以及未能识别出“交替执行”模式。
  1. **资源互斥的误导**：题目提到“每个资源一次只能被一个进程访问”，考生容易误以为需要额外的信号量来保证互斥。但实际上，由于调度约束强制了P1和P2在访问特定资源时的严格先后顺序，互斥性已经由同步顺序自然保证，无需额外互斥信号量。
  2. **信号量数量的直觉错误**：考生容易根据约束数量（4条）或资源数量（4个）线性推断信号量数量，而忽略了P1和P2是交替执行的，这种交替模式可以通过两个信号量（类似生产者-消费者中的空/满缓冲区信号量，或乒乓信号量）高效实现。

## 考察能力
本题核心考察考生将自然语言描述的进程同步约束转化为信号量操作序列的逻辑建模能力，以及对“交替执行”同步模式的识别与优化能力。
