# 2013年 Q18 — 流水线吞吐率计算

## 基本信息
- **年份**: 2013  **题位**: Q18  **题型**: 选择题
- **知识点**: 指令流水线性能指标, 流水线吞吐率, 流水线执行时间
- **考纲对应**: 第五章 中央处理器 → 指令流水线 → 流水线性能指标

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆“流水线吞吐率”的定义（指令数/总时间）以及流水线执行周期的计算公式 $(k + n - 1)$。若混淆为“加速比”或“效率”，则无法入题。高于2分是因为仅靠模糊概念无法确定具体公式；低于4分是因为无需辨析极易混淆的冷门细节，属于标准核心概念。
- **K2 = 3**: 3 — 需代入公式 $T = (k + n - 1) / f$ 进行计算。涉及单位换算（GHz 到 Hz）和简单的分数/小数运算。数字虽然友好（1.03G 与 103 个周期抵消），但仍需执行标准的公式代入步骤。高于2分是因为涉及量纲转换和具体数值计算；低于4分是因为计算过程不涉及繁杂的多级换算或极易算错的复杂运算。
- **K3 = 1**: 1 — 题目明确说明“没有发生任何流水线阻塞”，因此无需进行动态的状态更新或多步串行推演（如判断冒险、计算气泡等）。直接套用静态公式即可，无需推演流程。
- **K4 = 3**: 3 — 存在明确的陷阱词和易错点：一是“主频”与“时钟周期”的倒数关系容易搞反；二是“吞吐率”的单位（条/秒）容易与“总时间”混淆；三是流水线周期计算公式 $(k+n-1)$ 容易记错为 $k \times n$ 或 $n$。不触发这些陷阱就会用错公式或量级错误。低于4分是因为这些是常规考点，并非深层隐含前提。
- **K5 = 1**: 1 — 单一知识点内部解决，仅涉及流水线性能指标计算，不涉及与其他子系统（如Cache、中断）的状态传递或逻辑关联。
- **雷达形状**: K2计算型

## 考察模式
- **模式**: 计算型
- **理由**: 题干提供了具体的数值参数（主频、级数、指令数），选项为具体的计算结果，考生需通过正确的公式计算得出唯一匹配项。

## 选项级分析
- **选项A**: 干扰 — 针对认知错误：认为吞吐率等于单条指令的执行时间倒数，或者误以为流水线的最大吞吐率（$1/\Delta t$）就是实际执行这批指令的吞吐率。这类学生忽略了启动开销。
- **选项B**: 干扰 — 针对认知错误：计算近似错误或公式记忆错误（例如误用总周期为 $k \times n = 400$，导致结果偏小）。或者在单位换算上出现数量级错误。
- **选项C**: 正确 — 正确应用公式：总周期 $T_{cycles} = k + n - 1 = 4 + 100 - 1 = 103$。总时间 $T_{real} = 103 / (1.03 \times 10^9) s$。吞吐率 $TP = 100 / T_{real} = 100 \times 1.03 \times 10^9 / 103 = 1.0 \times 10^9$ 条/秒。
- **选项D**: 干扰 — 针对认知错误：直接用主频 $1.03 \times 10^9$ 作为吞吐率。这类学生混淆了“时钟频率”与“指令吞吐率”，忽略了流水线填充期和指令数量的限制，误以为任何情况下吞吐率都等于主频。
- **干扰策略**: 并行陷阱（各干扰项独立）

## 核心陷阱
- **核心陷阱**: 量纲转换与公式细节的双重陷阱。一是将 GHz 转换为 Hz 的数量级容易出错；二是流水线总周期公式 $(k+n-1)$ 中的 $-1$ 容易遗漏，或误将最大吞吐率当作实际吞吐率。
- **错误路径**: 学生可能直接看到 1.03GHz 和 103 个周期，直觉上认为两者抵消得 1G，但若公式记错为 100 个周期（忽略启动）或 400 个周期（串行），则结果完全不同。此外，容易忽略 $10^9$ 的量级，导致选项选择错误。

## 考察能力
本题考察考生对指令流水线性能指标（特别是吞吐率）定义的理解，以及在理想无阻塞条件下，准确计算流水线执行总时间并进行单位换算的能力。
