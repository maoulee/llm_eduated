# 练习题 Q1 — 卫星信道时延计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/数据链路层
- **难度**: 待评估

## 题干原文
考虑一个带宽为 50 kbps、往返传播延迟为 500 ms 的卫星信道。如果发送方要传输 1000 位的帧，接收方接收到该帧需要多长时间？（ ）
- 选项:
  A: 250 ms
  B: 20 ms
  C: 520 ms
  D: 270 ms
- 正确答案: D
- 解析（参考）: 已知条件
：
带宽 = 50 kbps
往返时间 = 500 ms = 2 × 传播时间
计算步骤
：
传播时间
= 500 ms ÷ 2 =
250 ms
传输时间
= 数据大小 ÷ 带宽 = 1000 位 ÷ 50 kbps =
20 ms
总接收时间
= 传播时间 + 传输时间 = 250 ms + 20 ms =
270 ms
结论
：接收方需等待传播时间与传输时间之和，故选择 D（270 ms）。
- 知识标签: ['计算机网络/数据链路层']
- 知识域: CN-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要调用“传播时延”、“发送时延（传输时延）”以及“往返时延（RTT）”这三个核心概念的定义。不是2分因为涉及单位换算（kbps到bps或ms到s的隐含逻辑）和RTT与单程传播时延的关系辨析；不是4分因为不需要辨析复杂的协议交互或易混的高级概念。
- **K2 = 3**: 评分理由。涉及两级计算：一是RTT除以2得到单程传播时延，二是数据量除以带宽得到发送时延，最后求和。不是2分因为存在单位不统一的风险（kbps vs 位，ms vs s），若不注意单位换算容易出错；不是4分因为计算过程本身不涉及复杂的对数、指数或多级嵌套换算。
- **K3 = 2**: 评分理由。从输入到输出只需两步串行推演：先拆解时延组成，再代入公式计算。步骤清晰，无需记忆中间状态或进行多分支逻辑判断。
- **K4 = 3**: 评分理由。存在明显的“陷阱词”和隐含前提。陷阱1：“往返传播延迟”需转换为“单程传播延迟”；陷阱2：“接收方接收到该帧”指的是第一个比特到达还是最后一个比特到达？在计算机网络标准定义中，通常指整个帧传输完毕并到达接收端，即 $T_{prop} + T_{trans}$。若理解为第一个比特到达，则答案不同。这属于常规注意点中的陷阱，需考生具备清晰的物理层/链路层时延模型认知。
- **K5 = 1**: 评分理由。本题仅涉及单一子系统（数据链路层/物理层信道特性）内的时延计算，无需跨越不同子系统（如网络层路由、传输层拥塞控制）传递状态或数据。
- **雷达形状**: K4陷阱型（K4略高，K2中等，其余较低，呈现针对概念细节和隐含条件的考察特征）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过给定的参数（带宽、RTT、帧长），利用时延公式进行数值计算。虽然涉及概念理解，但最终落脚点在于正确的数值推导。

## 选项级分析
- **选项A**: [干扰] — 针对“忽略发送时延”的错误认知。这类学生可能认为卫星信道距离远，传播时延占主导，或者误以为“接收到”是指第一个比特到达（$T_{prop} = 250$ ms）。这是最常见的错误，混淆了“首比特到达”与“帧接收完成”的概念。
- **选项B**: [干扰] — 针对“忽略传播时延”的错误认知。这类学生只计算了发送时延（$1000 / 50000 = 0.02s = 20ms$），完全忽略了卫星信道巨大的传播延迟。这反映出对卫星信道特性（高延迟）缺乏直观认识。
- **选项C**: [干扰] — 针对“混淆往返时延与单程时延”的错误认知。这类学生直接将RTT（500ms）当作单程传播时延，计算为 $500 + 20 = 520$ ms。这是典型的审题不清，未注意到“往返”二字。
- **选项D**: [正确] — 正确计算了单程传播时延（250ms）与发送时延（20ms）之和。
- **干扰策略**: 概念混淆（首比特vs末比特）、审题陷阱（往返vs单程）、忽略次要因素（在长距离信道中忽略发送时延）

## 核心陷阱
- **核心陷阱**: **“往返传播延迟”与“单程传播延迟”的转换**，以及**“接收方接收到该帧”的定义**（是首比特到达还是末比特到达）。在408考研及标准计算机网络教材中，除非特别说明“第一个比特”，否则“传输/接收时间”通常指整个数据块从开始发送到完全到达接收端的时间，即 $T_{total} = T_{trans} + T_{prop}$。

## 考察能力
一句话概括本题核心考察的能力：准确区分并计算网络时延的组成部分（发送时延与传播时延），并正确处理往返时延与单程时延的关系。
