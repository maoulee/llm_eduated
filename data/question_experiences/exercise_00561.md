# 练习题 Q1 — DMA传输对CPU性能的影响计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机组成原理/存储系统
- **难度**: 待评估

## 题干原文
一个处理器以 1 MIPS 的速度获取指令。使用 DMA 模块从以 9600 bps 传输的设备向 RAM 传输字符。由于 DMA 活动，处理器会减慢多少时间（ ）？

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握两个核心概念：MIPS（每秒百万条指令）的定义以及DMA（直接存储器访问）的基本工作原理（即DMA传输期间CPU不占用总线，但题目语境下通常考察的是“如果CPU参与”或“等效时间损失”的对比，或者更准确地说是考察单位换算和吞吐量概念）。这里主要考察对MIPS和bps单位的记忆与理解，属于标准的基础认知需求。不是4分因为不需要辨析复杂的易混概念（如PIO与DMA的详细区别），只需知道DMA传输数据量与CPU指令执行时间的对应关系即可。
- **K2 = 4**: 评分理由。涉及多级单位换算。首先需将bps（比特/秒）转换为Bps（字节/秒），除以8；其次需理解1 MIPS = $10^6$ 指令/秒，隐含假设每条指令对应一个字节的数据处理或时间单位对齐（题目简化模型）；最后需将秒转换为毫秒。非2的幂次换算（9600/8=1200，1200/$10^6$）容易在数量级上出错，属于较高难度的单步代入计算。
- **K3 = 2**: 评分理由。推演步骤较少。逻辑链条为：数据速率 -> 字节速率 -> 对应CPU指令数（或时间占比） -> 时间值。仅需2-3步直接计算，无需复杂的状态推演。
- **K4 = 3**: 评分理由。存在隐含前提和陷阱。题目问“处理器会减慢多少时间”，在严格的DMA定义中，CPU在数据传输期间是空闲的，不应减慢。但此类经典题目通常考察的是“等效时间损失”或假设CPU需要处理中断/初始化，或者更常见的是考察**PIO（程序控制I/O）与DMA的对比**，或者题目本身表述不够严谨，实际意图是计算“传输这些数据如果由CPU处理需要多少时间”或者“DMA传输占用的总线时间等效于CPU多少时间”。考生必须识别出题目是在考察**数据吞吐量与CPU指令吞吐量的比率**，即 $Time = Data / CPU\_Speed$。这是一个典型的“题面表述与严格理论有出入，需按经典解题套路处理”的陷阱。
- **K5 = 3**: 评分理由。涉及I/O子系统（设备、DMA控制器）与CPU子系统之间的数据传递。需要理解I/O传输速率如何映射到CPU的时间成本上，属于单向数据传递导致的性能影响评估。

- **雷达形状**: K2计算型偏高，K4陷阱型中等。整体呈现“计算主导，隐含条件辅助”的形状。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过给定的速率参数（9600 bps, 1 MIPS）进行单位换算和数值计算，得出时间值。虽然涉及DMA概念，但最终落脚点是一个具体的数值计算结果。

## 选项级分析
- **选项A**: [干扰] — 针对未进行比特到字节转换的错误。如果直接用 9600 / $10^6$ = 0.0096 s = 9.6 ms。这类学生忽略了1 Byte = 8 bits的基本常识。
- **选项B**: [干扰] — 针对计算错误或单位换算错误的组合。可能是 9600 / 2 / $10^6$ 或其他错误路径。或者误以为1 MIPS = $10^3$ 等。
- **选项C**: [干扰] — 针对除以2的错误。可能误以为DMA每次传输2字节，或者在换算过程中多除了一次2。
- **选项D**: [正确] — 正确计算路径：9600 bps / 8 = 1200 Bps。1 MIPS = $10^6$ 指令/秒。假设每条指令处理1字节（或时间等效），则每秒占用CPU时间为 $1200 / 10^6$ 秒 = $1.2 \times 10^{-3}$ 秒 = 1.2 ms。

- **干扰策略**: 计算陷阱。主要陷阱在于单位换算（bps到Bps）和数量级处理（秒到毫秒）。

## 核心陷阱
- **核心陷阱**: **单位换算遗漏**与**概念理解偏差**。
    1.  **单位陷阱**：最容易犯的错误是忘记将比特（bit）转换为字节（Byte），直接导致结果扩大8倍（选A）。
    2.  **概念陷阱**：题目问“DMA活动导致处理器减慢”，严格来说DMA不占用CPU时间（除中断外）。但在此类经典考题中，通常将其理解为“传输这些数据所花费的时间，如果由CPU执行指令来等效衡量是多少”，或者考察的是**总线占用时间**对CPU取指的影响（尽管1 MIPS通常指指令执行速率，此处简化为时间占比）。考生需识别出这是计算**数据量与CPU处理能力的比率**。

## 考察能力
一句话概括本题核心考察的能力：
**掌握I/O传输速率与CPU指令执行速率之间的单位换算及性能影响评估能力。**
