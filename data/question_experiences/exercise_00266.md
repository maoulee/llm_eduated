# 练习题 Q1 — AVL树插入与旋转调整

## 基本信息
- **来源**: 练习题  **题型**: 综合题
- **科目**: 数据结构
- **知识点**: 数据结构/二叉树
- **难度**: 待评估

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握AVL树的定义（平衡因子绝对值不超过1）以及四种旋转类型（LL, RR, LR, RL）的基本概念。仅记忆概念不足以解题，需理解其结构含义，故为标准难度。
- **K2 = 2**: 评分理由。本题不涉及复杂的数值计算，主要是树结构的形态变换。虽然需要计算平衡因子，但数值极小且直观，属于较低的计算/转换需求。
- **K3 = 4**: 评分理由。解题过程需要多步串行推演：1. 执行BST插入；2. 向上回溯检查平衡因子；3. 识别失衡类型（RL型）；4. 执行右旋（针对子树）；5. 执行左旋（针对失衡节点）；6. 验证最终结构。步骤超过3步且需保持中间状态清晰，故为较高难度。
- **K4 = 3**: 评分理由。存在常规注意点，即必须准确识别是“右左（RL）”型失衡而非其他类型，并知道RL型需要双旋转。若误判为单旋转或旋转方向错误，会导致全盘皆错。属于有陷阱词/隐含规则的情况。
- **K5 = 1**: 评分理由。本题完全局限于数据结构中的二叉树子系统内部，不涉及操作系统、计算机网络等其他领域的知识联动，为单系统问题。
- **雷达形状**: 呈现“推演主导型”特征。K3（机制推演）和K4（条件路由）较高，K1（基础认知）中等，K2（计算）和K5（跨域）较低。图形偏向右侧（推演与逻辑判断维度）。

## 考察模式
- **模式**: 计算推导型
- **理由**: 题目要求根据给定的初始状态和操作（插入70），通过严格的算法步骤（BST插入+AVL平衡调整）推导出最终的状态。这属于典型的基于规则的状态变换推导。

## 解题思路分析
- **核心思路**: 先按照二叉搜索树（BST）的规则插入节点，然后从插入点向上回溯，找到第一个平衡因子绝对值大于1的节点（失衡点），根据失衡类型执行相应的旋转操作以恢复平衡。
- **关键步骤**:
    1.  **插入**: 在初始树中插入70。70 < 100, 70 < 80? 否, 70 > 80? 否。等等，初始树结构为：60的右孩子是100，100的左孩子是80。70 < 100，进入左子树；70 < 80，进入80的左子树。所以70成为80的左孩子。
        *   此时树结构：
            ```
              60
             /  \
           20    100
               /   \
              80    120
             /
            70
            ```
    2.  **检测失衡**:
        *   节点70: BF=0
        *   节点80: 左高1，右高0，BF=1
        *   节点100: 左子树(80)高度2，右子树(120)高度1，BF=1
        *   节点60: 左子树(20)高度1，右子树(100)高度3，BF = 1 - 3 = -2。**失衡！**
    3.  **确定类型**: 失衡节点为60。其右孩子为100，100的左孩子为80（插入发生在80的左子树）。路径为：右 -> 左。属于 **RL型（右左型）** 失衡。
    4.  **执行旋转**: RL型需要双旋转。
        *   **第一步（右旋）**: 对失衡节点的右孩子（100）进行右旋。
            *   100的左孩子80上移，100下移成为80的右孩子。
            *   80的右子树（空）变为100的左子树。
            *   此时局部结构：80为根，左70，右100（100左空，右120）。
            *   整棵树变为：
                ```
                  60
                 /  \
               20    80
                   /  \
                  70   100
                       \
                       120
                ```
        *   **第二步（左旋）**: 对失衡节点（60）进行左旋。
            *   60的右孩子80上移成为新根。
            *   60下移成为80的左孩子。
            *   80的左子树（70）变为60的右孩子。
            *   最终结构：
                ```
                  80
                 /  \
               60    100
              /  \      \
            20    70     120
                ```
    5.  **比对选项**: 最终结构与选项C完全一致。
- **易错点**:
    1.  插入位置错误：误以为70插在100的左子树根节点或其他位置。
    2.  失衡点判断错误：可能只检查了局部，未回溯到根节点60发现失衡。
    3.  旋转类型混淆：将RL型误判为RR型或LR型，导致旋转方向错误。
    4.  双旋转顺序错误：RL型应先对子节点右旋，再对父节点左旋。

## 核心陷阱
- **核心陷阱**: **RL型失衡的双旋转细节**。很多学生知道RL型需要双旋转，但在执行第一步右旋时，容易忽略子节点（80）的右子树（原本为空）与父节点（100）的左子树之间的重新连接关系，或者在第二步左旋时，错误地处理了中间节点（80）的左子树（70）的归属，导致最终树中70的位置错误（如选项B中70在60的右孩子，但80的左孩子为空，这是错误的；选项C中70是60的右孩子，正确）。此外，选项A和B的结构明显不符合BST性质或平衡性质，但C和D（如果D存在干扰项）可能在结构上非常相似，需仔细核对父子关系。

## 考察能力
本题核心考察学生对AVL树插入算法中**失衡检测**与**双旋转（RL型）调整机制**的精确推演与执行能力。
