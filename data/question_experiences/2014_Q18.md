# 2014年 Q18 — 微指令下地址字段位数计算

## 基本信息
- **年份**: 2014  **题位**: Q18  **题型**: 选择题
- **知识点**: 微程序控制器原理, 微指令格式, 下地址字段(断定法), 控制存储器容量计算
- **考纲对应**: 第五章 中央处理器 → 控制器（功能/原理） → 微程序控制器 → 微指令设计与地址形成

## 题干原文
[2014年考研真题第18题]某计算机采用微程序控制器，共有32条指令，公共的取指令微程序包含2条微指令，各指令对应的微程序平均由4条微指令组成，采用断定法（下地址字段法）确定下条微指令地址，则微指令

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆“微程序控制器”中“微指令”与“机器指令”的数量关系，以及“下地址字段”用于寻址控制存储器（CM）中微指令的概念。若概念模糊（如混淆指令寄存器IR位数与微指令地址位数），则无法入题。不是2分是因为不能靠常识或模糊直觉解题；不是4分是因为不需要辨析极易混淆的冷门细节，核心定义明确。
- **K2 = 3**: 3 — 需进行两级计算：第一步是算术求和（$32 \times 4 + 2$），第二步是对数取上界（$\lceil \log_2 130 \rceil$）。涉及非2的幂次数的对数估算，属于标准难度的公式代入与计算。不是2分是因为数字130不是2的幂，需心算或笔算对数；不是4分是因为计算量极小，不易算错。
- **K3 = 1**: 1 — 无需多步串行推演流程。题目直接给出了所有必要参数（指令数、公共微指令数、平均微指令数、寻址方式），解题路径是直接的逻辑映射：总微指令数 -> 寻址位数。
- **K4 = 3**: 3 — 存在明确的陷阱词：“公共的取指令微程序”和“平均由4条微指令组成”。若不触发“累加公共部分”和“取平均值求总数”的逻辑，就会用错基数。例如只算特定指令或忽略公共头，即落入陷阱。不是4分因为陷阱相对直观，属于常规建模遗漏。
- **K5 = 1**: 1 — 单一知识点内部解决（控制器设计中的微程序编制），不涉及与其他子系统（如Cache、中断、流水线）的深度耦合或状态传递。
- **雷达形状**: K1K2计算概念型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给出明确参数，选项为不同计算结果，核心在于正确建立计算模型并执行计算。

## 考察能力
本题考察考生对微程序控制器底层存储结构（控制存储器CM）的物理容量需求的建模能力，以及对“微指令”与“机器指令”数量层级关系的精准辨析能力。
