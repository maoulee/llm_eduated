# 练习题 Q路由转发 — 最长前缀匹配原则

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/网络层
- **难度**: 待评估

## 题干原文
考虑以下路由器的路由表：
Prefix
Next Hop
192.24.0.0/18
D
192.24.12.0/22
B
考虑以下三个 IP 地址：
192.24.0.0/18
192.24.12.0/22
192.24.54.0
这三个目标 IP 地址对应的分组将如何转发？（ ）
- 选项:
  A: 1→D, 2→B, 3→B
  B: 1→D, 2→B, 3→D
  C: 1→B, 2→D, 3→D
  D: 1→D, 2→D, 3→D
- 正确答案: B
- 解析（参考）: 解释：
选项 I
匹配第一个和第三个 IP 地址，因为它们属于其子网掩码定义的范围。
选项 II
匹配第二个 IP 地址，因为它属于其子网掩码定义的范围。
选项 III
不匹配任何 IP 地址，因为它们超出其子网掩码定义的范围。
因此正确答案是
B
。
- 知识标签: ['计算机网络/网络层']
- 知识域: CN-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“最长前缀匹配（Longest Prefix Match）”这一核心概念以及CIDR子网划分的基本定义。如果不记忆该概念，无法解题；但只需辨析一个核心规则，无需对比多个易混概念，故为3。
- **K2 = 3**: 评分理由。涉及IP地址与子网掩码的二进制比对或十进制范围计算。虽然/18和/22不是最复杂的掩码，但需要准确判断IP是否落在特定范围内（特别是192.24.54.0是否属于192.24.0.0/18），存在计算出错的可能，故为3。
- **K3 = 2**: 评分理由。推演步骤较少。对于每个IP，只需执行“检查是否匹配条目1”、“检查是否匹配条目2”、“应用最长前缀规则”这三个简单步骤。没有复杂的多步串行状态依赖，故为2。
- **K4 = 3**: 评分理由。存在常规注意点/陷阱。主要陷阱在于第三个IP地址192.24.54.0，它不匹配更具体的/22路由，但匹配较宽泛的/18路由。考生容易误以为不匹配具体路由就丢弃或匹配默认路由（若存在），或者错误地认为它不属于/18。需要意识到“部分匹配”也是匹配，且遵循最长前缀原则，故为3。
- **K5 = 1**: 评分理由。单系统问题。仅涉及网络层路由表查找机制，无需跨越传输层、应用层或其他子系统传递状态，故为1。
- **雷达形状**: K4陷阱型（K1、K2、K4略高，K3、K5较低，呈现中间凸起或右侧略高的形态，主要难点在于对匹配规则的准确理解和边界情况的判断）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非简单的概念回忆，也不是纯粹的数值计算，而是要求考生根据给定的路由表规则（最长前缀匹配），对具体的IP地址进行逻辑推理和归属判断。需要结合CIDR知识进行“匹配-比较-决策”的推理过程。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：认为192.24.54.0匹配192.24.12.0/22。这类学生可能没有仔细计算/22的范围，或者误以为只要前两个字节相同就匹配，忽略了第三个字节的限制。192.24.12.0/22的范围是192.24.12.0 - 192.24.15.255，54显然不在其中。
- **选项B**: [正确] — 正确应用了最长前缀匹配原则。192.24.0.0/18精确匹配第一条（或作为网络地址匹配），192.24.12.0/22精确匹配第二条，192.24.54.0不匹配第二条但匹配第一条（192.24.0.0/18范围是192.24.0.0 - 192.24.63.255，54在范围内），故转发给D。
- **选项C**: [干扰] — 针对错误认知：完全混淆了路由条目的对应关系，或者认为所有地址都匹配更具体的路由（如果存在误解）。或者认为192.24.0.0/18这个网络地址本身应该被更具体的路由覆盖（但这里没有更具体的覆盖0.0的路由）。
- **选项D**: [干扰] — 针对错误认知：认为192.24.12.0/22也匹配192.24.0.0/18，且由于某种原因（如错误地认为/18优先级更高，或忽略了最长前缀匹配）选择了D。或者认为192.24.12.0/22这个地址本身作为网络地址，在某些实现中可能被特殊处理，但标准最长前缀匹配下，它匹配/22更精确。实际上，192.24.12.0/22既匹配/18也匹配/22，但/22更长，所以选B。选D的学生可能忽略了“最长”前缀，或者误以为/18是默认路由。

**干扰策略**: 概念混淆（最长前缀匹配 vs 任意匹配）、计算陷阱（子网范围边界判断错误）

## 核心陷阱
- **核心陷阱**: **最长前缀匹配原则的应用与子网范围边界的精确判断**。
    1.  对于IP 192.24.12.0/22，它同时匹配192.24.0.0/18和192.24.12.0/22，必须选择前缀更长的/22（Next Hop B），而非/18（Next Hop D）。
    2.  对于IP 192.24.54.0，它不匹配192.24.12.0/22（因为54 > 15），但匹配192.24.0.0/18（因为0 <= 54 <= 63），因此转发给D。容易误判为不匹配任何路由或匹配错误路由。

## 考察能力
一句话概括本题核心考察的能力：准确应用CIDR最长前缀匹配原则进行路由表查找及子网范围边界判断的能力。
