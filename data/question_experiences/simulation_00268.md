# 模拟题 Q1 — 补码最小值构造与位权分析

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 数据的机器级表示（补码）、数值范围与极值
- **难度**: 中等偏难（需结合位权逻辑推理）

## 题干原文
一个 8 位的二进制整数，若采用补码表示，且由 3 个“1”和 5 个“0”组成，则最小值为（ ）。
A: -127
B: -32
C: -125
D: -3

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握补码的基本定义（符号位含义、负数补码的构成）以及8位补码的表示范围。不是4分因为不需要辨析原码、反码、补码之间的复杂转换细节，只需知道补码负数的结构即可。
- **K2 = 2**: 评分理由。计算过程非常直接，主要是二进制到十进制的简单转换（$-128 + 3$ 或 $-128 + 2 + 1$），属于2的幂次友好型计算，不易出错。
- **K3 = 3**: 评分理由。解题需要多步串行推演：1. 确定符号位为1（因为是负数且求最小）；2. 分配剩余的2个“1”和5个“0”；3. 根据补码负数数值公式（$-2^{n-1} + \text{数值部分}$）判断如何放置剩余的“1”才能使总值最小；4. 计算最终结果。步骤在3-5步之间。
- **K4 = 4**: 评分理由。存在显著的隐含前提和反直觉陷阱。
    1. **隐含前提**：求“最小值”意味着必须是负数，且绝对值尽可能大。
    2. **反直觉/陷阱**：在补码负数中，数值大小与二进制位的“数值部分”成反比关系（即数值部分越小，真值越小/越负）。很多学生会误以为要让数值最小，就要让二进制位代表的数值最大（即把1放在高位），这是原码/反码的思维惯性，或者是混淆了“绝对值最大”与“代数值最小”在补码位权上的体现。必须意识到补码负数的公式是 $-128 + X$，要使结果最小，$X$ 必须最小。
- **K5 = 1**: 评分理由。本题仅涉及计算机组成原理中的数据表示子系统，不涉及操作系统、网络或软件工程的跨域联动。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要考察对补码负数位权逻辑的深度理解和避坑能力）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非简单的公式代入或概念记忆，而是需要根据“最小值”这一目标，结合补码的数学定义，推理出二进制位的具体排列方式。核心在于理解补码负数的位权特性（符号位权重为负，其余位权重为正），从而推导出“剩余1应放在最低位”这一结论。

## 选项级分析
- **选项A**: [干扰] — 针对“绝对值最大即最小”的错误认知。学生可能认为最小负数应该是绝对值最大的负数，即 $-127$（对应补码 `10000001`，只有2个1，不符合题意；或者误以为 `11111111` 是 -127 等错误记忆）。更可能的情况是，学生试图构造绝对值最大的负数，误将剩余的1放在高位，如 `11100000`（这是 -32，见选项B），或者混淆了补码范围边界（-128需要8个1或特定结构，这里只有3个1，无法达到-128）。此选项主要吸引那些对补码极值边界模糊的学生。
- **选项B**: [干扰] — 针对“高位权重高，放1数值大”的错误直觉。学生可能错误地认为，要让负数“最小”（即最负），应该让二进制数的“数值部分”尽可能大，从而把剩余的2个“1”放在最高有效位（第6位和第5位），得到 `11100000`。计算其值：$-128 + 64 + 32 = -32$。这是最常见的错误路径，混淆了“代数值最小”与“无符号数值最大”在补码负数中的关系。
- **选项C**: [正确] — 正确推理。符号位为1（占用1个“1”），剩余2个“1”和5个“0”。补码负数真值 $V = -128 + \sum_{i=0}^{6} b_i 2^i$。要使 $V$ 最小，需使 $\sum b_i 2^i$ 最小。将2个“1”放在最低位（$2^0$ 和 $2^1$），得到数值部分 $1+2=3$。真值 $= -128 + 3 = -125$。二进制为 `10000011`。
- **选项D**: [干扰] — 针对“正数思维”或“原码思维”。学生可能忽略了符号位，或者误以为这是正数，直接计算 `00000011` 为 3，或者误以为补码负数直接按原码看是 -3（`10000011` 原码是 -3，但题目问的是补码表示下的值，且 `10000011` 作为补码是 -125，作为原码是 -3。如果学生误以为题目给的是原码形式或者混淆了编码方式，可能会选 -3。另外，如果学生认为最小值是 -3（即绝对值最小），也会选此项，但这与“最小值”通常指代数值轴最左端矛盾，除非学生完全搞反了大小关系）。更可能的情况是，学生计算出二进制 `10000011`，然后错误地将其解读为原码 -3。

- **干扰策略**: 概念混淆（补码负数的位权逻辑 vs 原码/无符号数的位权逻辑）

## 核心陷阱
**补码负数的“最小值”构造逻辑**：
在补码表示中，负数的真值公式为 $-2^{n-1} + \text{数值部分}$。
- **陷阱点**：要使真值**最小**（即越负越好），需要**数值部分越小**。
- **错误直觉**：许多学生习惯于“位越高，值越大”的无符号数思维，误以为要把“1”放在高位才能让数“更大”（从而误以为负数绝对值更大就是最小，或者混淆了方向）。实际上，在补码负数中，高位（除符号位外）的“1”会增加真值（使其向0靠近，变大），而低位的“1”对真值的增加贡献最小。因此，为了得到最小的负数，应将有限的“1”尽可能放在低位。

## 考察能力
本题核心考察考生对**补码负数位权机制**的深度理解，以及在约束条件下（固定1和0的个数）进行**逆向构造极值**的逻辑推理能力。
