# 2011 Q4 — 完全二叉树叶子节点计算

## 基本信息
- **年份**: 2011  **题位**: Q4  **题型**: 选择题
- **知识点**: DS-5 > 5.2 二叉树的概念 > 完全二叉树
- **题位域**: DS-2  **科目**: 数据结构

## 题干原文
若一棵完全二叉树有 768 个结点，则该二叉树中叶结点的个数是（）
完全二叉树

A. 257
B. 258
C. 384
D. 385

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆完全二叉树的一个核心性质：对于具有 $n$ 个结点的完全二叉树，最后一个分支结点的序号为 $\lfloor n/2 \rfloor$，或者知道叶子节点数 $n_0 = \lceil n/2 \rceil$。不记忆此特定性质或公式无法直接解题，属于标准的基础概念调用。
- **K2 = 2**: 评分理由。计算过程极其简单，仅涉及一次除法（$768/2$）或一次取整运算。数字 768 是偶数，计算友好，几乎不可能算错，属于较低的计算需求。
- **K3 = 1**: 评分理由。从输入（节点总数）到输出（叶子节点数）只需一步直接代入公式或性质，无需多步串行推演。
- **K4 = 2**: 评分理由。存在常规注意点，即必须确认是“完全二叉树”而非普通二叉树。普通二叉树无法仅凭节点总数确定叶子数，但题干明确给出了“完全二叉树”这一强约束条件，无深层隐含前提或反直觉陷阱。
- **K5 = 1**: 评分理由。本题仅涉及数据结构中二叉树这一单一子系统内的性质应用，无需跨越不同模块（如算法复杂度、操作系统内存管理等）进行状态传递。
- **雷达形状**: K2/K3 低分型（基础概念直接应用型）。整体难度较低，主要考察对特定性质的记忆和简单代入。

## 考察模式
- **模式**: 概念型
- **理由**: 虽然涉及数字计算，但核心在于对“完全二叉树节点编号与性质”这一概念的理解。解题的关键不在于复杂的算术，而在于是否掌握 $n_0 = \lceil n/2 \rceil$ 或 $n_{branch} = \lfloor n/2 \rfloor$ 这一特定结论。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：可能误用了满二叉树的某些层级公式，或者在计算 $\lfloor n/2 \rfloor$ 时出现严重偏差，亦或是混淆了 $n_0$ 与 $n_1$ 的关系。这类学生可能对完全二叉树的性质记忆模糊，随意猜测。
- **选项B**: [干扰] — 针对错误认知：可能误以为叶子节点数是 $\lfloor n/2 \rfloor + 1$ 或其他错误变体。或者在计算 $768/2 = 384$ 后，错误地认为需要加 1 或减 1 来调整奇偶性，但未理解偶数节点时叶子数正好是一半。
- **选项C**: [正确] — 正确应用完全二叉树性质。$n=768$ 为偶数，叶子节点数 $n_0 = n/2 = 384$。或者通过分支节点数 $n_1 = \lfloor 768/2 \rfloor = 384$，则 $n_0 = n - n_1 = 768 - 384 = 384$。
- **选项D**: [干扰] — 针对错误认知：可能误用了 $n_0 = \lfloor n/2 \rfloor + 1$ 的公式（该公式通常用于 $n$ 为奇数的情况，或者混淆了 $n_0 = n_2 + 1$ 的性质）。当 $n$ 为偶数时，$n_0 = n/2$；当 $n$ 为奇数时，$n_0 = (n+1)/2$。选 D 的学生可能机械记忆了“叶子数等于分支数加1”（这是针对度为2的节点和叶子节点的关系 $n_0 = n_2 + 1$，但在完全二叉树中 $n_1$ 可能为 0 或 1，不能直接简单套用 $n_0 = n_{branch} + 1$ 除非明确 $n_1=0$ 且 $n_{branch}=n_2$，这里容易混淆）。更常见的错误是认为 $n_0 = \lfloor n/2 \rfloor + 1$ 是通用公式。

- **干扰策略**: 概念混淆。利用考生对 $n_0, n_1, n_2$ 之间关系（$n_0 = n_2 + 1$）与完全二叉树节点总数公式（$n_0 = \lceil n/2 \rceil$）之间的混淆，设置接近的数值干扰项。

## 核心陷阱
- **核心陷阱**: 混淆完全二叉树叶子节点数的通用公式与普通二叉树性质。考生容易错误地认为所有二叉树都满足 $n_0 = n_2 + 1$ 从而试图去求 $n_2$，或者错误地记忆了叶子节点数的计算公式（如误以为总是 $\lfloor n/2 \rfloor + 1$）。实际上，对于完全二叉树，若 $n$ 为偶数，$n_0 = n/2$；若 $n$ 为奇数，$n_0 = (n+1)/2$。本题 $n=768$ 为偶数，故直接除以 2。

## 考察能力
一句话概括本题核心考察的能力：掌握完全二叉树节点总数与叶子节点数之间的定量关系及快速计算能力。
