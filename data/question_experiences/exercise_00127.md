# 练习题 Q1 — 加权平均完成时间最小化（Smith规则）

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
考虑 $n$ 个作业 $J_1, J_2, \cdots, J_n$，其中作业 $J_i$ 的执行时间为 $t_i$，且具有非负整数权重 $w_i$。作业的加权平均完成时间定义为 $\frac{\sum_{i=1}^{n} w_i T_i}{\sum_{i=1}^{n} w_i}$，其中 $T_i$ 是作业 $J_i$ 的完成时间。假设只有一个处理器可用，为了最小化作业的加权平均完成时间，必须按照什么顺序执行这些作业？

- 选项:
  A: $t_i$ 的非递减顺序
  B: $w_i$ 的非递增顺序
  C: $w_i t_i$ 的非递增顺序
  D: $w_i / t_i$ 的非递增顺序

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题考察的是调度算法中的经典结论——Smith规则（或称加权最短作业优先 WSJF 的变体）。虽然“最短作业优先 SJF”是基础概念（K1=3），但引入“权重”后，需要考生记忆或推导更复杂的排序准则 $w_i/t_i$。这属于对易混概念（SJF vs WSJF）的辨析，且该公式并非所有教材都作为核心定义强调，部分考生可能仅记得 SJF 而忽略权重影响，因此认知需求较高。
- **K2 = 2**: 评分理由。题目本身不涉及具体的数值计算，而是考察排序规则的定性判断。即使进行简单的代数推导（如交换相邻两项比较代价），也仅涉及基础的不等式变换，计算量极小，属于低难度单步代入或逻辑判断。
- **K3 = 3**: 评分理由。若考生未直接记忆结论，需通过“相邻交换法”进行逻辑推演：假设两个作业 $i$ 和 $j$ 相邻，比较先执行 $i$ 再执行 $j$ 与先执行 $j$ 再执行 $i$ 的加权完成时间总和差异。这一过程涉及 3-4 步的逻辑推导（列出两种情况的代价 -> 做差 -> 分析符号 -> 得出结论），属于标准的机制推演。
- **K4 = 3**: 评分理由。存在明显的“直觉陷阱”。直觉上，权重大的应该先做（选项B），或者时间短的先做（选项A）。考生需要识别出“单位时间内的权重贡献”才是关键，即需要避开“只看权重”或“只看时间”的片面思维，识别出隐含的“性价比”前提。
- **K5 = 1**: 评分理由。本题完全局限于 CPU 调度这一单一子系统内部，不涉及内存管理、I/O 或其他模块的状态传递，属于单系统问题。

- **雷达形状**: K1-K4 偏高，K2-K5 偏低。呈现“概念辨析与逻辑推理主导型”特征，特别是 K1（概念记忆/辨析）和 K4（陷阱识别）较高，说明题目重在考察对调度准则深层逻辑的理解而非计算。

## 考察模式
- **模式**: 推理型
- **理由**: 虽然本题有标准答案（Smith规则），但其本质是要求考生理解“为什么”要这样排序。如果考生没有死记硬背公式，必须通过数学推理（相邻交换论证）来排除错误选项。它考察的是对调度目标函数（加权平均完成时间）与调度策略之间因果关系的逻辑推导能力。

## 选项级分析
- **选项A**: [干扰] — 针对“最短作业优先（SJF）”的惯性思维。这类学生知道 SJF 能最小化*平均*完成时间，但忽略了题目中的*权重* $w_i$。当权重存在时，单纯看时间 $t_i$ 是错误的。
- **选项B**: [干扰] — 针对“权重优先”的直觉错误。这类学生认为权重代表重要性，所以权重大的必须先做。但他们忽略了如果高权重作业执行时间极长，会导致后续所有作业（包括其他高权重作业）的等待时间大幅增加，从而增加总代价。
- **选项C**: [干扰] — 针对“乘积关系”的混淆。这类学生可能混淆了“加权完成时间”与“加权周转时间”或其他指标，或者错误地认为权重和时间是正相关累加关系。实际上，我们希望时间短、权重大的作业先执行，因此 $t_i$ 应在分母。
- **选项D**: [正确] — 符合 Smith 规则。为了最小化 $\sum w_i T_i$，应优先执行 $w_i/t_i$ 比值最大的作业。这保证了单位执行时间内产生的“权重收益”最大，或者说，每单位时间延迟所损失的权重代价最小。

- **干扰策略**: 概念混淆与直觉陷阱。选项 A 和 B 分别代表了两个极端（只看时间、只看权重），选项 C 则是常见的数学关系误用。通过组合这些常见错误认知，构建强干扰项。

## 核心陷阱
- **核心陷阱**: **直觉误导与概念泛化**。最大的陷阱在于考生容易将“最小化平均完成时间”（SJF，按 $t_i$ 排序）的经验直接迁移到“最小化*加权*平均完成时间”上，或者简单地认为“权重越大越优先”。考生必须意识到，最优策略是权衡“执行时间”与“权重”的比值，即追求“单位时间的权重密度”最大化。

## 考察能力
本题核心考察考生对 CPU 调度算法目标函数的数学理解能力，以及通过相邻交换法推导最优调度策略的逻辑推理能力。
