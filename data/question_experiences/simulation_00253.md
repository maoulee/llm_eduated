# 模拟题 Q综合题 — 存储器扩展与地址译码设计

## 基本信息
- **来源**: 模拟题  **题型**: 综合题
- **科目**: 操作系统
- **知识点**: OS-3 > 3.1 内存管理概念 > 内存空间分配
- **难度**: 待评估

## 题干原文
（10 分）设某机中，CPU 的地址总线 A₁₅～A₀，数据总线 D₇～D₀（A₀、D₀为最低位），存储器地址空间为 3000H～67FFH。其中 3000H～4FFFH 为 ROM 区，选用 4K×2 的 ROM 芯片；5000H～67FFH 为 RAM 区，选用 2K×4 的 SRAM 芯片。请问：
（1）组成该存储器需要多少片 ROM 芯片和 SRAM 芯片？
（2）ROM 芯片、SRAM 芯片各需连接 CPU 的哪几根地址线和数据线？
（3）应如何设置片选信号，分别写出各片选信号的逻辑表达式。

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题不仅要求记忆“位扩展”、“字扩展”等基本概念，还需要深入理解存储芯片容量表示法（如 4K×2 的含义）、地址总线与数据总线的对应关系，以及片选信号（CS）在存储器映射中的作用。需辨析多个易混概念（如地址线连接低位还是高位、数据线如何并联），属于较高程度的概念调用。
- **K2 = 3**: 评分理由。涉及十六进制地址范围到十进制容量的转换（如 4FFFH - 3000H + 1），以及芯片数量的除法运算。虽然计算本身不复杂，但涉及非连续地址空间的容量计算（ROM 和 RAM 中间有空隙），且需处理 2 的幂次换算，属于标准难度的计算。
- **K3 = 4**: 评分理由。解题过程需要多步串行推演：首先计算各区域容量 -> 确定芯片分组（位扩展）-> 确定每组内的地址线连接 -> 确定组间的片选逻辑（字扩展）。特别是第（3）问，需要根据地址范围推导高位地址线的组合逻辑，步骤较多且环环相扣，超过 5 步逻辑推导。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。首先，地址空间 3000H～67FFH 并非连续满块，中间 4FFFH 到 5000H 之间有空隙，且 RAM 起始地址 5000H 不是 2K 的整数倍边界（相对于 0 地址），这导致片选逻辑不能简单使用高位地址线直接译码，必须仔细分析地址位的变化规律。其次，数据线连接需考虑位扩展时的分组（ROM 4 片一组，RAM 2 片一组），容易忽略数据线的高低位分配。
- **K5 = 3**: 评分理由。本题主要涉及 CPU 总线与存储器芯片之间的接口设计，属于计算机组成原理与操作系统内存管理的交叉领域。虽然主要聚焦于存储子系统，但需要理解 CPU 地址/数据总线如何映射到物理芯片，涉及子系统间的数据传递（地址译码），属于单向传数据/状态的控制逻辑设计。
- **雷达形状**: 偏向“推演与陷阱”型。K3（机制推演）和 K4（条件路由）得分较高，K1（基础认知）也较高，K2（计算）中等，K5（跨域）中等。整体呈现一个在逻辑推导和细节陷阱上要求较高的形状。

## 考察模式
- **模式**: 计算推导型
- **理由**: 题目要求通过具体的地址范围和芯片规格，计算出芯片数量，并推导出硬件连接的具体逻辑表达式。核心在于通过数学计算和逻辑推导得出硬件设计方案，而非单纯的理论论述或算法设计。

## 解题思路分析
- **核心思路**: 
  1. **容量计算与芯片选型**：根据地址范围计算 ROM 和 RAM 的总容量，结合芯片规格计算所需芯片总数及分组情况（位扩展）。
  2. **地址线连接**：根据芯片容量确定片内地址线数量，连接 CPU 地址总线的低位。
  3. **片选逻辑设计**：分析地址空间的高位地址线，利用译码器或逻辑门生成片选信号，实现字扩展。

- **关键步骤**:
  1. **计算 ROM 区**：
     - 地址范围：3000H ~ 4FFFH。
     - 容量：4FFFH - 3000H + 1 = 2000H = 8KB = 8K × 8 bit。
     - 芯片：4K × 2 bit。
     - 数量：(8K × 8) / (4K × 2) = 8 片。
     - 分组：位扩展需 4 片组成 8 位数据宽度，共 2 组（字扩展）。
  2. **计算 RAM 区**：
     - 地址范围：5000H ~ 67FFH。
     - 容量：67FFH - 5000H + 1 = 1800H = 6KB = 6K × 8 bit。
     - 芯片：2K × 4 bit。
     - 数量：(6K × 8) / (2K × 4) = 6 片。
     - 分组：位扩展需 2 片组成 8 位数据宽度，共 3 组（字扩展）。
  3. **地址线连接**：
     - ROM (4K)：需 12 根地址线 (A11~A0)。
     - RAM (2K)：需 11 根地址线 (A10~A0)。
     - 数据线：ROM 每组 4 片分别接 D7-D6, D5-D4, D3-D2, D1-D0；RAM 每组 2 片分别接 D7-D4, D3-D0。
  4. **片选信号逻辑**：
     - 分析高位地址线 A15~A12 (或 A15~A11) 的状态。
     - ROM 组 1 (3000H-3FFFH)：A15=0, A14=0, A13=1, A12=1 (0x3xxx)。
     - ROM 组 2 (4000H-4FFFH)：A15=0, A14=0, A13=1, A12=0 (0x4xxx)。
     - RAM 组 1 (5000H-57FFH)：A15=0, A14=0, A13=1, A12=0, A11=1 (0x5xxx, 注意 5000H 是 0101 0000 0000 0000，A11=1)。*修正：5000H = 0101 0000 0000 0000。A15-A12 = 0101。A11=0。*
     - 需仔细写出每个组的片选逻辑表达式，通常使用与非门或译码器输出。

- **易错点**:
  1. **地址范围计算错误**：忘记加 1，或十六进制减法出错。
  2. **位扩展与字扩展混淆**：不清楚数据线如何并联，导致芯片数量计算错误或连接方式错误。
  3. **片选逻辑地址位判断错误**：特别是 RAM 起始地址 5000H 不是 2K 对齐的边界（2K 是 0x0800），导致片选信号不仅依赖高位地址线，还可能涉及低位地址线（如 A11）的组合，容易遗漏。
  4. **数据线连接细节**：ROM 是 2 位宽，需 4 片凑 8 位；RAM 是 4 位宽，需 2 片凑 8 位。容易搞反或连接错位。

## 核心陷阱
- **核心陷阱**: **非对齐地址空间的片选逻辑设计**。
  RAM 区从 5000H 开始，而 2K 芯片的字长是 2048 字节。5000H (20480) 并不是 2048 的整数倍（20480 / 2048 = 10，是整数倍，但地址位 A11 在 5000H 处为 0，而在 5800H 处变为 1）。更关键的是，5000H ~ 67FFH 跨越了多个 2K 块。
  具体来看：
  - 5000H ~ 57FFH (2K): A15-A12 = 0101, A11=0
  - 5800H ~ 5FFFH (2K): A15-A12 = 0101, A11=1
  - 6000H ~ 67FFH (2K): A15-A12 = 0110, A11=0
  因此，RAM 的 3 个组不能仅用 A15-A12 译码，必须结合 A11。如果学生只关注高位地址线，会得出错误的片选逻辑。这是本题最大的陷阱。

## 考察能力
本题核心考察考生对存储器扩展技术（位扩展、字扩展）的理解，以及根据具体地址空间设计硬件连接（地址线、数据线、片选逻辑）的综合应用能力。
