# 练习题 Q1 — 嵌套循环时间复杂度分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/算法分析
- **难度**: 待评估

## 题干原文
考虑以下 C 函数。
```c
int fun1(int n) {
    int i, j, k, p, q = 0;
    for (i = 1; i < n; ++i) {
        p = 0;
        for (j = n; j > 1; j = j / 2)
            ++p;
        for (k = 1; k < p; k = k * 2)
            ++q;
    }
    return q;
}
```
下列哪一项是函数 `fun1` 的时间复杂度？（ ）
- 选项:
  A: $\Theta(n^3)$
  B: $\Theta(n(\log n)^2)$
  C: $\Theta(n \log n)$
  D: $\Theta(n \log(\log n))$

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握基本的循环结构时间复杂度分析规则（如线性循环、对数循环），属于标准的基础概念记忆。不是4分因为不需要辨析多个易混的高级概念，只需识别常见的循环模式。
- **K2 = 3**: 评分理由。涉及对数函数的嵌套计算（$\log(\log n)$）以及多项式与对数项的乘积比较。虽然计算步骤不复杂，但需要准确理解 $\log p$ 当 $p=\log n$ 时的含义，存在轻微的计算/推导门槛。
- **K3 = 3**: 评分理由。推演步骤清晰：1. 分析外层循环次数；2. 分析中间循环确定 $p$ 的值；3. 分析内层循环次数；4. 综合计算总复杂度。共3-4步串行推演，符合标准难度。
- **K4 = 4**: 评分理由。存在明显的“隐含前提”陷阱。学生容易忽略中间循环和内层循环之间的变量依赖关系（$p$ 是中间循环的结果，也是内层循环的边界）。如果未能识别 $p$ 的值随 $n$ 变化但相对于 $n$ 是“小量”这一特性，或者错误地认为内层循环也是 $\log n$，就会掉入陷阱。此外，需要意识到 $\log(\log n)$ 在渐进意义下远小于 $\log n$，从而进行主导项简化，这需要一定的直觉和隐含条件判断。
- **K5 = 2**: 评分理由。主要是在单一算法逻辑内部的状态传递（$p$ 从中间循环传递到内层循环），没有跨越不同的数据结构子系统或复杂的模块耦合。提及无关信息较少，主要是单向的数据流依赖。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，表明题目难点在于识别变量依赖和渐进阶的简化陷阱，而非单纯的计算或记忆）。

## 考察模式
- **模式**: 推理型
- **理由**: 本题不能通过直接套用公式得出答案，必须通过逻辑推理分析代码执行流程，特别是变量 $p$ 的动态变化及其对后续循环的影响，进而推导出整体的时间复杂度。

## 选项级分析
- **选项A**: [干扰] — 针对完全不懂对数循环的学生。这类学生可能将所有循环都误判为线性 $O(n)$，从而得出 $n \times n \times n = n^3$ 的错误结论。
- **选项B**: [干扰] — 针对未能正确简化或错误估算内层循环的学生。这类学生可能正确识别出外层是 $n$，中间是 $\log n$，但错误地认为内层循环也是 $\log n$（忽略 $k$ 是指数增长且边界是 $p$），或者错误地将 $\log p$ 当作 $\log n$ 处理，导致得出 $n \cdot \log n \cdot \log n$ 的结果。
- **选项C**: [正确] — 正确分析了各层循环：外层 $n$，中间 $\log n$（决定 $p$），内层 $\log p = \log(\log n)$。总操作数为 $n(\log n + \log \log n)$。由于 $\log n$ 主导 $\log \log n$，故简化为 $\Theta(n \log n)$。
- **选项D**: [干扰] — 针对过度简化或混淆主导项的学生。这类学生可能正确计算出内层是 $\log \log n$，但错误地忽略了中间循环本身的开销（$\log n$），或者错误地认为 $\log \log n$ 是主导项，从而得出 $n \log \log n$。

- **干扰策略**: 概念混淆与计算陷阱。主要利用学生对嵌套对数 $\log(\log n)$ 的不熟悉，以及对“主导项”简化规则的误用（是忽略小的项，还是错误地只保留最小的项）。

## 核心陷阱
- **核心陷阱**: 变量依赖与渐进阶简化。
  1. **变量依赖**：内层循环的边界 $p$ 不是常数，也不是 $n$，而是中间循环的结果 $\log n$。因此内层循环次数是 $\log(\log n)$ 而非 $\log n$ 或常数。
  2. **主导项简化**：总复杂度是 $n \times (\text{中间循环开销} + \text{内层循环开销}) = n(\log n + \log \log n)$。许多学生会错误地只计算内层循环的开销而忽略中间循环的开销，或者错误地认为 $\log \log n$ 比 $\log n$ 更重要（实际上 $\log n$ 增长更快，是主导项）。

## 考察能力
本题核心考察考生对嵌套循环中变量依赖关系的追踪能力，以及对对数函数嵌套（$\log \log n$）与多项式/对数混合项进行渐进阶（Big-Theta）简化的准确判断能力。
