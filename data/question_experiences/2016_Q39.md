# 2016 Q39 — IPv4子网划分与网关配置逻辑

## 基本信息
- **年份**: 2016  **题位**: Q39  **题型**: 选择题
- **知识点**: CN-4 > IPv4 > 子网划分
- **题位域**: 待标注  **科目**: 计算机网络

## 题干原文
假设 H1 与 H2 的默认网关和子网掩码均分别配置为 192.168.3.1 和 255.255.255.128，H3 与 H4 的默认网关和子网掩码均分别配置为 192.168.3.254 和 255.255.255.128，则下列现象中可能发生的是（ ）。

A. H1 不能与 H2 进行正常 IP 通信
B. H2 与 H4 均不能访问 Internet
C. H1 不能与 H3 进行正常 IP 通信
D. H3 不能与 H4 进行正常 IP 通信

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握子网掩码、网络地址计算、默认网关作用等核心概念。不是4分因为不需要辨析极其晦涩的协议细节，属于计算机网络基础中的标准知识点。
- **K2 = 3**: 评分理由。需要进行二进制与十进制的转换以及按位与运算来计算网络号。虽然255.255.255.128是常见的掩码（/25），但涉及两个不同网段的计算，且需判断IP是否在同一网段，计算量适中，非2的幂次友好型（如/24, /16）但也不复杂。
- **K3 = 4**: 评分理由。推演步骤较多：1. 计算H1/H2的网络号；2. 计算H3/H4的网络号；3. 判断H1/H2内部通信可行性；4. 判断H3/H4内部通信可行性；5. 判断H1/H2与H3/H4跨网段通信的路径及网关有效性；6. 判断访问Internet的网关可达性。每一步都依赖前一步的结果，且涉及“网关IP是否属于本机所在网段”这一关键逻辑判断。
- **K4 = 5**: 评分理由。存在极深的隐含前提和反直觉陷阱。
    1. **陷阱1**：H1/H2配置的网关是192.168.3.1，而H3/H4配置的网关是192.168.3.254。学生容易忽略“网关IP必须与主机IP在同一子网”这一硬性规则。
    2. **陷阱2**：H1/H2的网关192.168.3.1实际上位于H3/H4所在的子网（192.168.3.128/25）中，这意味着H1/H2配置的网关对于它们自己来说是“不可达”的（不在同一广播域），或者更准确地说，H1/H2认为网关在本地，但实际物理连接或逻辑上网关接口可能在另一侧。
    3. **陷阱3**：题目未给出拓扑图，但通过IP地址分布暗示了网络结构。H1/H2在低地址段，H3/H4在高地址段。H1/H2的网关指向低地址段的广播地址（192.168.3.127是广播，1是网络号？不，192.168.3.0/25的网络号是0，广播是127。192.168.3.1是有效主机IP）。等等，重新计算：
       - 掩码 255.255.255.128 (/25)。
       - H1/H2 假设IP在 192.168.3.0 - 192.168.3.127 范围（通常H1/H2指代该网段主机）。网络号：192.168.3.0。广播：192.168.3.127。
       - H3/H4 假设IP在 192.168.3.128 - 192.168.3.255 范围。网络号：192.168.3.128。广播：192.168.3.255。
       - H1/H2 网关设为 192.168.3.1。该IP在 192.168.3.0/25 网段内。合法。
       - H3/H4 网关设为 192.168.3.254。该IP在 192.168.3.128/25 网段内。合法。
       - **关键冲突**：H1/H2 要访问 H3/H4，需要路由。H1/H2 的网关是 192.168.3.1。如果路由器接口在 192.168.3.1，那么路由器必须连接在 192.168.3.0/25 网段。
       - H3/H4 要访问 H1/H2，需要路由。H3/H4 的网关是 192.168.3.254。如果路由器接口在 192.168.3.254，那么路由器必须连接在 192.168.3.128/25 网段。
       - 题目隐含了一个典型的双臂路由器或单臂路由器场景。如果是一个路由器连接这两个网段，它通常有两个接口，或者一个接口配置主IP和辅助IP。
       - **真正的陷阱在于选项C的分析**：H1与H3通信。H1发送包给H3，发现H3不在同一网段，发给网关192.168.3.1。路由器收到后，查路由表，发现H3在192.168.3.128/25网段，从连接该网段的接口（IP 192.168.3.254）转发。H3收到包，回复时，发现H1不在同一网段，发给网关192.168.3.254。路由器收到，查路由表，从192.168.3.1接口转发给H1。
       - **为什么C是正确答案（即“可能发生”的现象是H1不能与H3正常通信）？**
         - 让我们仔细看解析中的逻辑。解析提到“R2的E1接口IP为192.168.3.254... H2的默认网关为192.168.3.1”。这暗示了拓扑结构。
         - 如果H1/H2的网关是192.168.3.1，而H3/H4的网关是192.168.3.254。
         - 如果路由器只有一个接口连接这个物理网络（例如交换机），且配置了192.168.3.1和192.168.3.254作为辅助IP？或者路由器有两个接口分别连接两个VLAN？
         - 题目没有给图，但根据2016年真题的完整上下文（通常Q39-Q40是一组题，有图），图中显示路由器R1连接H1/H2，R2连接H3/H4，或者是一个路由器连接两个网段。
         - **修正理解**：这是一道基于特定拓扑图的题目（虽然题干文字未完全展示图，但解析提到了R2的E1接口）。在没有图的情况下，仅凭文字，我们通常假设标准的双网段路由。
         - 如果H1/H2网关是192.168.3.1，H3/H4网关是192.168.3.254。
         - H1访问H3：H1 -> GW(192.168.3.1) -> Router -> H3。
         - H3访问H1：H3 -> GW(192.168.3.254) -> Router -> H1。
         - 看起来应该能通。为什么C说“不能”？
         - **重新审视解析**：解析说“H1、H2和H3、H4处于不同的网段... H1和H2的默认网关为192.168.3.1...”。解析中断了。
         - 让我们看选项B：H2不能访问Internet，H4可以。解析说H2网关192.168.3.1，而R2的E1接口是192.168.3.254。这暗示H2的网关192.168.3.1可能**不存在**或者**不可达**？或者H2的网关配置错误？
         - 如果H1/H2所在的网段是192.168.3.0/25，网关192.168.3.1是合法的。
         - 如果H3/H4所在的网段是192.168.3.128/25，网关192.168.3.254是合法的。
         - **关键点**：题目问的是“可能发生”。
         - 如果路由器配置不当，或者网关IP实际上并不在对应的物理接口上？
         - 让我们看回标准答案C。如果C是正确答案，意味着H1和H3**不能**通信。
         - 什么情况下不能通信？
           1. 路由不对称？
           2. 网关不可达？
           3. **最可能的解释**：结合原题图（2016年408真题Q39-40共用一张图），图中显示H1/H2连接在路由器R1的接口，H3/H4连接在路由器R2的接口，R1和R2之间相连。或者H1/H2和H3/H4连接在同一个交换机的不同VLAN，由一个路由器路由。
           - 根据解析片段：“R2的E1接口的IP地址为192.168.3.254... H2的默认网关为192.168.3.1”。这说明H2的网关192.168.3.1**不在**R2上，而在R1上（假设）。
           - 如果H1/H2的网关是192.168.3.1，H3/H4的网关是192.168.3.254。
           - 如果H1和H3通信，H1发给192.168.3.1，H3发给192.168.3.254。
           - 如果这两个网关属于**不同的路由器**，且这两台路由器之间没有正确的路由配置，或者中间链路不通，则无法通信。
           - 但更常见的考点是：**网关IP与主机不在同一子网**。
           - 检查：H1/H2掩码255.255.255.128。假设H1 IP为192.168.3.x (x<128)。网关192.168.3.1。在同一子网。OK。
           - H3/H4掩码255.255.255.128。假设H3 IP为192.168.3.y (y>=128)。网关192.168.3.254。在同一子网。OK。
           - 那么为什么C对？
           - 让我们看解析的另一部分：“H2不能访问Internet... H4可以”。这说明H2的网关192.168.3.1可能**没有**通往Internet的路由，或者192.168.3.1这个网关本身配置有问题？
           - 实际上，2016年这道题的图显示：H1, H2, H3, H4 连接在同一个交换机上？不，通常是两个网段。
           - **真相**：这道题的陷阱在于**网关的可达性**和**路由的完整性**。
           - 如果H1/H2的网关是192.168.3.1，而H3/H4的网关是192.168.3.254。
           - 如果192.168.3.1和192.168.3.254是**同一台路由器**的两个接口IP（分别连接两个网段），那么通信应该正常。
           - 但如果192.168.3.1是路由器R1的接口，192.168.3.254是路由器R2的接口，且R1和R2之间没有直连或路由，则不通。
           - **但是**，题目问的是“可能发生”。
           - 选项A：H1不能与H2通信。H1/H2同网段，直接二层通信，除非ARP失败，否则通常能通。
