# 练习题 Q1 — 内存地址寄存器（MAR）功能辨析

- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
内存地址寄存器（MAR）（ ）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。本题属于标准的基础概念记忆题。考生需要准确记忆 MAR（Memory Address Register）的定义。虽然不需要辨析多个易混概念（如区分 MAR 和 MDR 的具体细节可能涉及 K4），但必须掌握“MAR 存地址”这一核心定义，符合“需一个核心定义则3”的锚点。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全属于定性判断，计算需求微弱。
- **K3 = 1**: 评分理由。解题过程无需多步推演，直接根据定义匹配选项即可，逻辑链条极短。
- **K4 = 2**: 评分理由。存在轻微的干扰项，主要考察对 CPU 内部寄存器功能的精确区分。虽然选项 D 描述了 MDR（数据寄存器）的功能，但对于基础扎实的学生来说，这是常规注意点，而非深层隐含前提或反直觉陷阱。
- **K5 = 1**: 评分理由。本题仅涉及 CPU 与内存接口处的单一寄存器功能，未涉及进程调度、内存管理算法或 I/O 子系统之间的状态传递或耦合。

- **雷达形状**: K1 主导型（基础概念记忆型），K4 略有凸起（概念辨析）。

## 考察模式
- **模式**: 概念型
- **理由**: 题目直接询问硬件组件的定义和功能，不涉及计算过程或复杂逻辑推理，纯粹考察对操作系统底层硬件基础知识的记忆和理解。

## 选项级分析
- **选项 A**: [干扰] — 针对“程序计数器（PC）”功能的混淆。PC 才是保存当前正在执行指令地址或下一条指令地址的寄存器。这类学生可能混淆了“地址”相关的寄存器，误以为所有存地址的都是 MAR。
- **选项 B**: [干扰] — 针对“指令译码器/控制单元”功能的混淆。执行指令意图的是控制单元（CU）或算术逻辑单元（ALU），而非寄存器本身。这类学生可能对 CPU 内部各部件分工模糊，将“存储”与“执行”概念混为一谈。
- **选项 C**: [正确] — 准确描述了 MAR 的核心功能：在访存操作（读/写）前，MAR 存放目标内存单元的地址。
- **选项 D**: [干扰] — 针对“内存数据寄存器（MDR/MAR）”功能的混淆。MDR（Memory Data Register）才存放从内存读出的数据副本或准备写入内存的新数据。这类学生容易将“地址”与“数据”两个寄存器搞混，这是 CPU 访存机制中最常见的易错点。

- **干扰策略**: 概念混淆。通过列举 CPU 中其他关键寄存器（PC, CU, MDR）的功能作为干扰项，考察考生对 MAR 专属功能的精确识别能力。

## 核心陷阱
- **核心陷阱**: **MAR 与 MDR 的功能混淆**。考生极易将“存放地址”的 MAR 与“存放数据”的 MDR 弄混，或者将 MAR 与存放指令地址的 PC 混淆。选项 D 是典型的 MDR 定义，是本题最大的干扰源。

## 考察能力
本题核心考察考生对 CPU 访存机制中关键寄存器（MAR 和 MDR）功能的精确记忆与区分能力。
