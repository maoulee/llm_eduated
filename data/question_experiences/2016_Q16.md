# 2016年 Q16 — 存储器字扩展与地址计算

## 基本信息
- **年份**: 2016  **题位**: Q16  **题型**: 选择题
- **知识点**: 存储器地址范围计算, 存储器容量扩展设计, 位扩展与字扩展
- **考纲对应**: 第三章 存储系统 -> 主存储器和 CPU 的连接 -> 主存容量扩展

## 题干原文
[2016年考研真题第16题]某存储器容量为64KB,按字节编址，地址4000H～5FFFH位ROM区，其余为RAM 区。若采用8K×4位的SRAM芯片进行设计，则需要该芯片的数量是______。


## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆存储器扩展设计中“位扩展”与“字扩展”的概念，以及SRAM芯片容量的表示方法（如 8K×4位 的含义）。若混淆位/字概念或不知容量计算公式，无法入题。低于3分是因为不能仅靠常识或模糊概念解题；高于3分是因为不涉及极冷门的芯片内部结构细节，核心概念在计组基础教学中非常标准。
- **K2 = 3**: 3 — 涉及十六进制地址范围到十进制容量的换算，以及除法和乘法运算。虽然数字是2的幂次，但包含“加1”处理地址边界、单位统一（KB vs K×bit）等多步简单计算，不属于极简单心算（K2=2），也不算极其繁杂易错（K2=4）。
- **K3 = 2**: 2 — 解题路径固定且短：1.计算ROM容量 -> 2.计算RAM总需求 -> 3.计算单片芯片容量 -> 4.除法求片数。无需多步串行推演或状态维持，路径唯一，符合“仅需2步以内的极简推导”或简单的线性流程。
- **K4 = 3**: 3 — 存在明确的陷阱词和隐含前提：1. “按字节编址”与芯片“4位”位宽的匹配（隐含需要位扩展）；2. 地址范围计算需“+1”（5FFFH - 4000H + 1）；3. “其余为RAM”意味着要从总容量中减去ROM。若不触发这些注意点，会直接用64KB计算或忽略位扩展，导致选错。
- **K5 = 2**: 2 — 题目虽然提及ROM和RAM两个区域，但它们在存储地址空间上是静态划分的，ROM区不参与RAM芯片的计算，两者之间没有动态的数据/逻辑交互。只需计算RAM部分的静态需求，属于“提及其他系统名词，但无数据/逻辑实质性关联”或简单的减法关系，跨域联动需求较低。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给定了具体的存储器参数和芯片规格，选项是具体的数字结果，核心在于通过正确的公式和逻辑计算出唯一数值。

## 选项级分析
- **选项A**: [干扰] — 针对“未进行地址加1计算”或“ROM容量计算错误”的认知错误。例如计算ROM为 5FFF-4000 = 1FFF = 8KB-1KB=7KB，导致剩余RAM容量计算偏差，进而导致芯片数量错误。适合基础概念不清、对十六进制减法边界不敏感的学生。
- **选项B**: [干扰] — 针对“忽略位扩展”或“混淆芯片位宽”的认知错误。学生可能直接用 64KB / 8K = 8 或者 56KB / 8K = 7，忘记了芯片是4位而编址是8位（1字节），需要2片进行位扩展。适合对“按字节编址”与“芯片位宽”关系理解不足的学生。
- **选项C**: [正确] — 正确执行了所有步骤：ROM容量 8KB，RAM需求 56KB，单片 4KB (8K×4bit = 4K×8bit = 4KB)，56/4 = 14。
- **选项D**: [干扰] — 针对“忽略ROM区占用”或“全按RAM计算”的认知错误。直接用 64KB / 4KB = 16。适合审题不仔细，未注意到“其余为RAM”这一关键约束，或者误以为64KB全由SRAM构成的学生。
- **干扰策略**: 并行陷阱（各干扰项独立）

## 核心陷阱
- **核心陷阱**: 1. 地址范围计算忘记“+1”；2. 忽略“按字节编址”与“4位芯片”之间的位扩展需求（即2片4位拼成1字节）；3. 忘记从总容量中扣除ROM占用的空间。
- **错误路径**: 直接计算 64KB / (8K×4bit) 导致单位不匹配或数量错误；或计算RAM容量时未扣除ROM，导致分子偏大。

## 考察能力
本题考察考生对存储器层次结构中主存扩展设计的综合计算能力，特别是地址空间换算、位/字扩展概念的应用以及审题中对隐含条件（ROM占用、字节编址）的捕捉能力。
