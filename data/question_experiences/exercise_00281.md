# 练习题 Q1 — 传输层协议与应用层映射

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/传输层
- **难度**: 待评估

## 题干原文
以下哪一项使用 UDP 作为传输协议？（ ）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。本题属于标准的基础概念记忆。考生需要准确记忆常见应用层协议（HTTP, Telnet, DNS, SMTP）与其底层传输层协议（TCP/UDP）的对应关系。不需要辨析复杂的易混概念，只需调用核心定义即可，因此定为标准难度。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全属于定性判断，计算需求微弱。
- **K3 = 1**: 评分理由。解题过程为直接的“协议名称 -> 传输层协议”映射，无需多步串行推演或状态记忆，一步到位。
- **K4 = 2**: 评分理由。存在常规注意点，即 DNS 既可以使用 UDP（默认，端口53）也可以使用 TCP（区域传输或响应过大时）。但题目问的是“使用 UDP”，且其他选项均强制使用 TCP，因此不存在深层隐含前提或反直觉陷阱，仅需注意 DNS 的主要特性即可。
- **K5 = 1**: 评分理由。本题仅涉及应用层与传输层的直接映射，不涉及网络层、链路层或其他子系统的状态传递或深度耦合，属于单系统内的知识点考察。
- **雷达形状**: K1主导型（基础记忆型）。雷达图在K1维度突出，其余维度极低，呈现典型的“概念回忆”特征。

## 考察模式
- **模式**: 概念型
- **理由**: 题目直接考察计算机网络中常见应用层协议与传输层协议的绑定关系，属于对教材核心知识点的直接回忆与识别，不涉及复杂逻辑推理或数值计算。

## 选项级分析
- **选项A**: [干扰] — 针对“所有Web相关服务都类似”的错误认知。HTTP 是典型的请求-响应模型，要求数据完整有序，必须使用 TCP。学生若混淆 HTTP 与 DNS 的查询性质，可能误选。
- **选项B**: [干扰] — 针对“远程登录需要交互”的认知偏差。Telnet 是交互式字节流协议，对可靠性要求极高，必须使用 TCP。学生若未区分“查询”与“会话”的区别，可能误选。
- **选项C**: [正确] — DNS 查询报文通常很短，且对实时性要求高，允许少量丢包（可重试），因此主要使用 UDP。这是计算机网络中少数几个主要使用 UDP 的重要应用层协议之一。
- **选项D**: [干扰] — 针对“邮件发送看似简单”的误解。SMTP 用于邮件传输，必须保证邮件内容完整无误，且涉及复杂的握手过程，必须使用 TCP。学生若认为邮件发送是“一次性动作”而忽略可靠性，可能误选。
- **干扰策略**: 概念混淆。通过列举三个必须使用 TCP 的常见协议（HTTP, Telnet, SMTP）来干扰考生，利用考生对“网络应用”整体印象的模糊性，考察对特定协议传输需求的精确记忆。

## 核心陷阱
- **核心陷阱**: DNS 的双协议特性。虽然 DNS 主要使用 UDP，但在特定场景（如响应超过 512 字节、区域传输 AXFR）下会使用 TCP。本题陷阱在于考生是否知道 DNS **主要/默认** 使用 UDP，而其他选项 **绝对** 不使用 UDP。若考生死记“DNS 也用 TCP”而忽略其 UDP 的主导地位，可能会犹豫；但相比之下，其他选项完全排除 UDP，因此 C 是唯一正确选项。

## 考察能力
准确记忆并区分常见应用层协议（HTTP, Telnet, DNS, SMTP）对传输层可靠性与连接特性的需求差异。
