# 练习题 Q1 — AVL树平衡因子判定

## 基本信息
- **来源**: 练习题  **题型**: 选择题

- 解析（参考）: 定义

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆 AVL 树的核心定义（平衡因子绝对值不超过 1）以及平衡因子的计算公式（左高-右高）。这属于标准的核心概念记忆，不涉及复杂辨析，但必须精确。不是 2 分因为需要同时调用“二叉搜索树性质”和“AVL平衡性质”两个概念进行双重验证。
- **K2 = 2**: 评分理由。计算过程主要是数层数（高度），属于简单的整数加减。最复杂的单步计算是计算某个节点的左右子树高度差，数值很小，不易出错。
- **K3 = 3**: 评分理由。需要对树中的每一个节点（或关键节点）进行串行推演：先判断是否为 BST，再计算每个节点的平衡因子。对于树 A、B、C，需要遍历多个节点的状态，步骤在 3-5 步之间（例如检查根节点、左子节点、右子节点等）。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。首先，AVL 树必须是二叉搜索树（BST），很多学生只检查平衡因子而忽略 BST 性质（虽然本题中三个图看起来都符合 BST，但这是隐含前提）。其次，最大的陷阱在于**参考解析与正确答案的逻辑矛盾**（见下文分析），或者题目本身存在印刷/逻辑错误，导致学生需要识别“哪个选项描述符合 AVL 定义”而非单纯看图。此外，容易忽略叶子节点或空子树的高度定义（通常空树高度为-1或0，需统一标准）。
- **K5 = 1**: 评分理由。本题仅涉及二叉树这一单一数据结构子系统，无需跨越操作系统、计网等其他模块。

- **雷达形状**: K4 陷阱型（高条件路由需求，中等推演需求）

## 考察模式
- **模式**: 概念型 + 推理型
- **理由**: 题目核心在于对 AVL 树定义的概念理解（平衡因子限制），并通过推理（计算各节点高度差）来验证具体实例。

## 选项级分析
*注：此处需指出题目数据中存在的严重逻辑矛盾。根据提供的“解析”，树 B 不是 AVL 树，树 A 和 C 是 AVL 树。因此正确答案应包含 A 和 C。选项 B 是 "A 和 C"。这与提供的“正确答案: B”一致。但是，我们需要仔细检查树 A 和 C 是否真的符合 AVL 定义。*

**重新校验题目数据：**
*   **树 A**:
    *   根 100: 左子树(50)高度1, 右子树(200)高度1 (200有左孩子10? 不，看图：200的左孩子是10? 不，图A结构：100->50, 200; 50->10, 300? 不，图A显示 50 的右孩子是 300? 让我们仔细看图A的文本表示：
        ```
          100
         /   \
       50     200
      / \
     10  300  <-- 这里有问题。50的右孩子是300？如果是BST，300 > 50，合法。但300 > 100吗？是的。但是300在50的右子树，意味着 300 > 50。同时300在100的左子树，意味着 300 < 100。矛盾！300 不可能既大于 50 又小于 100 且作为 50 的右孩子？不，50 < 300 < 100 是可能的。等等，BST性质：左子树所有节点 < 根 < 右子树所有节点。
        根 100。左子树根 50。50 的右孩子 300。300 > 50 (OK)。但是 300 必须在 100 的左子树范围内，即 300 < 100。**300 < 100 为假**。
        因此，**树 A 不是二叉搜索树 (BST)**。既然不是 BST，它绝对不是 AVL 树。
    *   结论：树 A 不是 AVL 树。

*   **树 B**:
    *   结构：
        ```
          100
         /   \
       50     200
      /      /   \
     10    150    300
    /
   5
        ```
    *   BST 检查：
        *   100: 左<100, 右>100. OK.
        *   50: 左(10)<50, 右(null). OK.
        *   10: 左(5)<10. OK.
        *   200: 左(150)<200, 右(300)>200. OK.
        *   是 BST。
    *   AVL 检查 (平衡因子 BF = H_left - H_right):
        *   Node 5: H=0 (叶子). BF=0.
        *   Node 10: Left(5) H=0, Right(null) H=-1 (或0，取决于定义，通常空为-1或0，差值为1). 若空为0，H(5)=1, H(null)=0, BF=1. OK.
        *   Node 50: Left(10) H=1 (或2), Right(null) H=0.
            *   若叶子高度为0: H(5)=0, H(10)=1, H(50)=2.
            *   Node 50: Left H=1, Right H=0 (空). BF = 1 - 0 = 1. OK.
            *   Node 200: Left(150) H=0, Right(300) H=0. BF=0. OK.
            *   Node 100: Left(50) H=2, Right(200) H=1. BF = 2 - 1 = 1. OK.
        *   **等等，参考解析说 B 不是 AVL 树，因为 50 的 BF 为 2。**
        *   让我们重新看树 B 的图：
            ```
              100
             /   \
           50     200
          /      /   \
         10    150    300
        /
       5
            ```
        *   如果 50 的右子树为空，左子树是 10->5。
        *   H(5) = 0 (叶子).
        *   H(10) = 1.
        *   H(50) = 2.
        *   Node 50 的 BF = H(Left) - H(Right) = 1 - (-1) = 2? 或者 1 - 0 = 1?
        *   通常 AVL 定义中，空树高度为 -1，叶子高度为 0。
            *   H(5) = 0.
            *   H(10) = max(H(5), H(null)) + 1 = max(0, -1) + 1 = 1.
            *   H(50) = max(H(10), H(null)) + 1 = max(1, -1) + 1 = 2.
            *   Node 50 的 BF = H(Left Child) - H(Right Child) = H(10) - H(null) = 1 - (-1) = 2.
            *   **BF = 2 > 1**。所以 **树 B 不是 AVL 树**。参考解析正确。

*   **树 C**:
    *   结构：
        ```
          100
         /   \
       50     200
      / \    /   \
     10 60  150   300
    / \    \
   5  180  400   <-- 等等，180 在 10 的右孩子？180 > 10 (OK). 但 180 在 50 的左子树，必须 < 50. **180 < 50 为假**。
        ```
    *   **树 C 不是 BST**。因为 180 在 50 的左子树中，但 180 > 50。
    *   因此，**树 C 不是 AVL 树**。

*   **综合结论**：
    *   树 A: 不是 BST (300 > 100 但在左子树)。
    *   树 B: 是 BST，但不是 AVL (Node 50 BF=2)。
    *   树 C: 不是 BST (180 > 50 但在左子树)。
    *   **没有一个是 AVL 树**。

*   **然而**，题目给出的正确答案是 **B (A 和 C)**。
    *   这暗示题目中的图可能存在**印刷错误**或者**我对图的理解有误**，或者**题目本身是错的**。
    *   让我们重新审视“参考解析”：“其他选项中的树均满足所有节点平衡因子在 [-1, 1] 范围内。”
    *   如果解析认为 A 和 C 是 AVL 树，那么解析忽略了 BST 性质，或者图中的数字位置有误。
    *   假设题目意图是考察**平衡因子计算**，而忽略 BST 性质（这在某些不严谨的练习题中可能出现，或者图中的数字只是标签而非值？不，AVL 树定义基于 BST）。
    *   如果忽略 BST 性质，仅看平衡因子：
        *   **树 A**:
            *   100: L(50), R(200).
            *   50: L(10), R(300).
            *   200: L(null), R(null)? 图中 200 下面没有孩子？图A显示 `200` 下面没有分支。
            *   10: L(null), R(null).
            *   300: L(null), R(null).
            *   H(10)=0, H(300)=0, H(50)=1.
            *   H(200)=0.
            *   H(100)=2.
            *   BF(50) = 0 - 0 = 0.
            *   BF(100) = 1 - 0 = 1.
            *   所有 BF 在 [-1, 1]。**若忽略 BST，A 是平衡的**。
        *   **树 C**:
            *   100: L(50), R(200).
            *   50: L(10), R(60).
            *   200: L(150), R(300).
            *   10: L(5), R(180).
