# 练习题 Q1 — 页面置换算法等效性分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/存储管理
- **难度**: 待评估

## 题干原文
一台计算机有二十个物理页框，初始时包含编号为 101 到 120 的页面。现在一个程序按顺序访问编号为 1、2、…、100 的页面，并重复该访问序列三次。以下哪种页面置换策略与最优页面置换策略在该程序中经历的页面错误次数相同？（ ）
A: 最近最少使用
B: 先进先出
C: 后进先出
D: 最近最多使用

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握 OPT、LRU、FIFO、MRU 四种页面置换算法的基本定义。不是 4 分因为不需要辨析极其细微的边界条件，只需知道核心逻辑即可。
- **K2 = 1**: 评分理由。本题不涉及具体的数值计算，而是逻辑推导。没有复杂的算术运算。
- **K3 = 4**: 评分理由。需要在明确规则下进行多步串行推演。考生必须模拟或推导在“页框数 < 页面总数”且“访问序列为线性重复”这一特定场景下，OPT 算法的具体行为（即总是淘汰刚访问过的页面），并将其与其他算法的行为进行对比。这需要构建一个动态的状态变化模型。
- **K4 = 5**: 评分理由。存在极强的反直觉陷阱。通常教学中强调 LRU 是 OPT 的良好近似，但在此特定条件下（线性扫描且容量不足），OPT 的行为退化为 MRU。考生若仅凭“LRU 接近 OPT”的常识性记忆，极易误选 A。这是一个典型的隐含前提深且反直觉的陷阱。
- **K5 = 1**: 评分理由。仅涉及存储管理子系统内部的页面置换逻辑，无需跨越 CPU 调度、文件系统等其他模块。

- **雷达形状**: K4 陷阱型（K4 极高，K3 较高，其余较低）

## 考察模式
- **模式**: 推理型
- **理由**: 题目不要求记忆死板的结论，也不涉及复杂计算，而是要求考生根据给定的特定约束条件（20个页框，1-100线性访问，重复3次），推导出 OPT 算法在该特定场景下的实际执行轨迹，并识别出与其行为一致的另一种算法。

## 选项级分析
- **选项A**: [干扰] — 针对“LRU 是 OPT 的最佳近似”这一常见误解。这类学生通常记住了 LRU 在大多数随机访问模式下表现良好，且接近 OPT，因此下意识选择 LRU，忽略了本题特殊的“线性顺序访问”场景。
- **选项B**: [干扰] — 针对对 FIFO 机制的简单理解。FIFO 淘汰最早进入的页面。在本题中，FIFO 会形成循环置换，虽然错误次数可能很高，但其淘汰逻辑（基于进入时间）与 OPT（基于未来使用）在本题特定序列下并不完全等效（尽管在某些极端线性情况下 FIFO 和 MRU 可能相似，但 OPT 的核心特征是“淘汰最近刚用过的”，这与 FIFO 的“淘汰最久未用/最早进入”在逻辑根源上不同，且 FIFO 在本题中表现通常不如 MRU 与 OPT 的等效性那么直接和典型，或者说 MRU 是更精确的描述）。*注：在严格的线性扫描且 N < M 时，FIFO、LRU、MRU 的缺页率往往是一样的（都是每次访问都缺页），但题目问的是“策略等效”，即决策逻辑的一致性。OPT 在此场景下决策是“淘汰最近访问的”，这与 MRU 的定义完全一致，而与 FIFO（淘汰最早进入）和 LRU（淘汰最久未用）的定义逻辑不同。*
- **选项C**: [干扰] — 后进先出（LIFO）通常不是标准的页面置换算法考点，作为凑数选项，干扰性较弱。
- **选项D**: [正确] — 针对对 OPT 算法在特定序列下行为的深度理解。在访问序列 1, 2, ..., 100 且页框只有 20 个时，当访问页面 $i$ ($i > 20$) 时，内存中已有 $i-20$ 到 $i-1$。OPT 需要淘汰一个未来最久不用的页面。由于序列是线性的，页面 $i-20$ 将在第 $i-20+100$ 次访问时才再次被用到，而页面 $i-1$ 将在第 $i-1+100$ 次访问时被用到... 等等，这里需要仔细推导：
    *   当前访问 $i$。内存中有 $\{i-20, ..., i-1\}$。
    *   未来访问序列是 $i+1, ..., 100, 1, 2, ..., i-20, ...$
    *   页面 $i-20$ 下一次被访问是在第二轮的开头附近（距离当前很远）。
    *   页面 $i-1$ 下一次被访问是在第二轮的 $i-1$ 处。
    *   实际上，对于线性序列 $1..N$，重复 $K$ 次，且 $M < N$。
    *   当访问 $i$ 时，内存里是 $i-20 \dots i-1$。
    *   OPT 看未来：$i+1, i+2 \dots$。
    *   内存中的页面 $i-20$ 下一次出现是在第二轮的 $i-20$。
    *   内存中的页面 $i-1$ 下一次出现是在第二轮的 $i-1$。
    *   显然 $i-20$ 的下一次访问时间比 $i-1$ 更早（在第二轮中，$i-20$ 排在 $i-1$ 前面）。
    *   等等，OPT 是淘汰**下一次使用时间最远**的。
    *   在第二轮中，访问顺序是 $1, 2, \dots$。所以 $1$ 最先被访问，$100$ 最后被访问。
    *   内存中的页面集合 $S = \{i-20, \dots, i-1\}$。
    *   这些页面在第二轮的访问顺序是 $i-20, i-19, \dots, i-1$。
    *   所以 $i-20$ 是**最近**会被访问到的（在第二轮中最早出现）。
    *   $i-1$ 是**最远**会被访问到的（在第二轮中最晚出现，或者如果 $i-1$ 很大，它可能在第二轮末尾）。
    *   因此，OPT 应该淘汰**下一次访问时间最远**的页面，即 $i-1$（刚访问过的那个，或者说在内存中“最新”进入的那个，因为它在第二轮中排得最靠后）。
    *   淘汰 $i-1$ 正是 **MRU (Most Recently Used)** 的行为。
    *   所以 OPT 在此场景下等效于 MRU。

- **干扰策略**: 概念混淆。利用考生对“LRU 近似 OPT”的刻板印象，掩盖了在特定线性访问模式下 OPT 退化为 MRU 的事实。

## 核心陷阱
**反直觉的算法退化**：考生普遍认为 LRU 是 OPT 的最佳近似，但在“页框数远小于页面总数”且“访问序列为线性重复”的极端情况下，OPT 算法为了保留那些即将在第二轮早期被访问的页面（即内存中编号较小的页面），必须淘汰那些在第二轮晚期才被访问的页面（即内存中编号较大、刚刚被访问过的页面）。这导致 OPT 的行为与 MRU（淘汰最近使用的）完全一致，而与 LRU（淘汰最久未使用的）截然相反。

## 考察能力
在特定约束条件下，通过推演算法执行轨迹，识别不同页面置换策略行为等效性的深度逻辑推理能力。
