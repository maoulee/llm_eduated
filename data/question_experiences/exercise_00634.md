# 练习题 Q1 — 定点数表示与二进制转换

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机组成原理/数制
- **难度**: 待评估

## 题干原文
考虑无符号的 8 位定点二进制数表示形式：b7b6b5b4b3⋅b2b1b0，其中二进制小数点位于 b3 和 b2 之间。假设 b7 是最高有效位。下列十进制数中有些无法用上述表示形式精确表示：
(i) 31.500
(ii) 0.875
(iii) 12.100
(iv) 3.001。
以下哪个说法是正确的？
- 选项:
  A: (i)、(ii)、(iii)、(iv) 都无法精确表示
  B: 只有 (ii) 无法精确表示
  C: 只有 (iii) 和 (iv) 无法精确表示
  D: 只有 (i) 和 (ii) 无法精确表示

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握定点数的基本概念（整数位、小数位、权值）以及十进制转二进制的核心定义。不是4分因为不需要辨析多个易混概念（如补码、移码等），仅需理解定点数格式。
- **K2 = 3**: 评分理由。涉及十进制小数转二进制（乘2取整法）和整数转二进制（除2取余法）。虽然计算量不大，但小数部分（如0.1, 0.001）的转换需要一定的计算步骤，且容易因精度问题出错，属于标准难度的计算。
- **K3 = 2**: 评分理由。推演步骤较少。对于每个数，只需判断其整数部分是否超出5位范围，小数部分是否能用3位二进制精确表示。逻辑链条短，无需多步串行推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。
    1. **格式陷阱**：题目给出的是 `b7...b3 . b2...b0`，意味着整数部分占5位（$2^0$到$2^4$），小数部分占3位（$2^{-1}$到$2^{-3}$）。很多学生容易误以为小数点在中间（4位整数4位小数）或忽略位数限制。
    2. **精度陷阱**：(iii) 12.100 和 (iv) 3.001 的小数部分 0.1 和 0.001 在二进制中是无限循环小数，无法用有限的3位小数位精确表示。这是本题最大的暗坑，需要意识到“有限位定点数无法精确表示所有十进制小数”。
- **K5 = 1**: 评分理由。单系统问题，仅涉及数制转换和定点数表示，不涉及指令系统、存储层次或I/O等其他子系统。
- **雷达形状**: K4陷阱型。主要难度不在于计算复杂度（K2中等），而在于对题目隐含条件（位数分配）和二进制精度本质（K4高）的识别。

## 考察模式
- **模式**: 综合型（概念+计算+陷阱识别）
- **理由**: 本题不仅要求考生会做进制转换（计算），还要求考生理解定点数的存储格式限制（概念），并能识别出哪些十进制小数在二进制下是无限循环的（陷阱识别）。

## 选项级分析
- **选项A**: [干扰] — 针对完全不懂定点数表示或认为所有小数都无法精确表示的错误认知。这类学生可能误以为只要有小数就无法精确表示，或者误判了(i)和(ii)的可表示性。
- **选项B**: [干扰] — 针对混淆了整数位和小数位权值，或者错误计算了(ii) 0.875的二进制表示。0.875 = $2^{-1} + 2^{-2} + 2^{-3} = 0.111_2$，正好占满3位小数，是可以精确表示的。选此项的学生可能误以为0.875需要更多位数。
- **选项C**: [正确] — 正确识别了(i) 31.5 = $11111.1_2$（5位整数+1位小数，符合格式）和(ii) 0.875 = $0.111_2$（0位整数+3位小数，符合格式）可以精确表示；而(iii) 12.1 和 (iv) 3.001 的小数部分 0.1 和 0.001 在二进制中是无限循环小数，无法用3位小数位精确截断表示。
- **选项D**: [干扰] — 针对错误判断(i)和(ii)无法表示的学生。可能误以为31.5超出了范围（实际上最大整数为$2^5-1=31$，31.5在范围内），或者误以为0.875无法表示。

**干扰策略**: 概念混淆与精度陷阱。利用学生对“十进制小数转二进制”时，哪些能精确表示、哪些不能的模糊认知，结合定点数位数限制，设置多重干扰。

## 核心陷阱
- **核心陷阱**: **二进制小数的有限表示性**。
    1. **位数限制**：必须明确整数部分5位，小数部分3位。
    2. **无限循环小数**：十进制的 0.1 和 0.001 在二进制中是无限循环小数（$0.1_{10} = 0.000110011..._2$），因此无法用有限的3位小数位精确表示。这是本题区分度的关键。

## 考察能力
一句话概括本题核心考察的能力：
**在给定定点数格式约束下，判断十进制数能否被有限位二进制精确表示的能力，特别是对二进制小数精度本质的理解。**
