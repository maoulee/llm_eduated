# 2014 Q11 — 快速排序阶段性特征判定

## 基本信息
- **年份**: 2014  **题位**: Q11  **题型**: 选择题
- **知识点**: DS-8 > 8.3 交换排序 > 快速排序
- **题位域**: DS-5  **科目**: 数据结构

## 题干原文
下列选项中，不可能是快速排序第 2 趟排序结果的是（）
排序算法
快速排序

A. 2,3,5,4,6,7,9
B. 2,7,5,6,4,3,9
C. 3,2,5,4,7,6,9
D. 4,2,3,5,7,6,9

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握快速排序的核心定义，特别是“基准元素归位”这一关键特性。不是4分因为不需要辨析多个易混排序算法的复杂差异，只需抓住快排的一个核心性质即可。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算，无需执行加法、乘法或幂运算，完全属于逻辑判断。
- **K3 = 3**: 评分理由。解题过程需要多步串行推演：首先理解“第i趟至少有i个元素归位”的定理，然后对每个选项逐一检查哪些元素满足“左边全小、右边全大”的条件，最后统计归位元素的数量是否 $\ge 2$。这涉及对四个选项分别进行状态验证，步骤在3-5步之间。
- **K4 = 4**: 评分理由。存在显著的隐含前提和反直觉陷阱。
    1. **隐含前提**：考生必须知道“第 $i$ 趟排序结束后，至少有 $i$ 个元素处于最终有序位置”这一性质。如果不知道这个性质，无法解题。
    2. **反直觉/陷阱**：很多学生误以为“第2趟”意味着只进行了2次划分，或者误以为只有基准元素归位。实际上，快排的递归特性可能导致某些子序列在之前的趟数中已经部分有序，或者在当趟划分中多个元素恰好归位。更关键的陷阱在于，学生容易忽略“归位元素”的定义是全局的（左边所有元素<它<右边所有元素），而不仅仅是局部子数组的基准。选项C中只有9归位，看似合理（因为9最大），但忽略了第2趟必须至少有2个元素归位的硬性约束。
- **K5 = 1**: 评分理由。本题仅涉及数据结构中的排序算法模块，不涉及操作系统、计算机网络或计算机组成原理等其他科目的知识联动。
- **雷达形状**: K4陷阱型（K4显著高于其他维度，K2极低）

## 考察模式
- **模式**: 推理型
- **理由**: 题目不要求考生手动模拟具体的快排过程（因为快排的基准选择策略未定，无法唯一确定过程），而是要求考生基于快排的**不变式（Invariant）**性质进行逻辑推理和排除。考生需要利用“归位元素数量”这一抽象性质来反推结果的可能性。

## 选项级分析
- **选项A**: [干扰] — 针对“认为归位元素必须连续”或“计算错误”的错误认知。
    - 分析：在序列 `2,3,5,4,6,7,9` 中，检查每个元素：
        - 2: 左空，右全大 -> 归位
        - 3: 左2<3，右全大 -> 归位
        - 5: 左2,3<5，右4<5 (不满足右边全大) -> 未归位
        - 4: 左5>4 -> 未归位
        - 6: 左2,3,5,4<6，右7,9>6 -> 归位
        - 7: 左全小，右9>7 -> 归位
        - 9: 左全小，右空 -> 归位
    - 归位元素有：2, 3, 6, 7, 9，共5个。$5 \ge 2$，可能是第2趟结果。
    - 学生可能因为看到5和4没排好就误以为不可能，或者数错了归位元素个数。

- **选项B**: [干扰] — 针对“只关注基准元素”的错误认知。
    - 分析：在序列 `2,7,5,6,4,3,9` 中：
        - 2: 左空，右全大 -> 归位
        - 7: 左2<7，右5,6,4,3<7 (不满足右边全大) -> 未归位
        - ...
        - 9: 左全小，右空 -> 归位
    - 归位元素有：2, 9，共2个。$2 \ge 2$，可能是第2趟结果。
    - 学生可能认为中间乱序太严重不可能是快排结果，忽略了只要满足归位数量即可。

- **选项C**: [正确] — 针对“忽略第i趟至少i个元素归位”这一核心性质的错误认知。
    - 分析：在序列 `3,2,5,4,7,6,9` 中：
        - 3: 左空，右2<3 (不满足右边全大) -> 未归位
        - 2: 左3>2 -> 未归位
        - 5: 左3,2<5，右4<5 -> 未归位
        - 4: 左5>4 -> 未归位
        - 7: 左3,2,5,4<7，右6<7 -> 未归位
        - 6: 左7>6 -> 未归位
        - 9: 左全小，右空 -> 归位
    - 归位元素仅有：9，共1个。$1 < 2$，**不可能**是第2趟结果。
    - 这类学生通常没有掌握快排趟数与归位元素数量的关系，或者误以为只要最大/最小元素归位就算一趟。

- **选项D**: [干扰] — 针对“认为归位元素必须是基准”的错误认知。
    - 分析：在序列 `4,2,3,5,7,6,9` 中：
        - 4: 左空，右2,3<4 (不满足右边全大) -> 未归位
        - 2: 左4>2 -> 未归位
        - 3: 左4>3 -> 未归位
        - 5: 左4,2,3<5，右7,6,9>5 -> 归位
        - 7: 左...5<7，右6<7 -> 未归位
        - 6: 左7>6 -> 未归位
        - 9: 左全小，右空 -> 归位
    - 归位元素有：5, 9，共2个。$2 \ge 2$，可能是第2趟结果。
    - 学生可能因为4,2,3,7,6的混乱顺序而排除，忽略了5和9已经归位的事实。

- **干扰策略**: 概念混淆。利用快排过程中局部无序的表象，干扰考生对“全局归位元素”这一抽象性质的判断。同时，通过构造归位元素数量刚好等于2（B、D）或远大于2（A）的选项，与归位元素数量不足2（C）的选项形成对比，考察考生对临界条件的敏感度。

## 核心陷阱
**核心陷阱**: 考生容易陷入“模拟具体排序过程”的思维定势，试图还原第一趟和第二趟的具体基准选择。然而，由于快排的基准选择策略（首元素、尾元素、三数取中等）未定，具体过程不唯一。真正的解题钥匙是**快排的宏观性质**：第 $i$ 趟排序结束后，**至少**有 $i$ 个元素处于其最终有序位置（即该元素左侧所有元素均小于它，右侧所有元素均大于它）。选项C中只有1个元素（9）满足此条件，不满足“至少2个”的要求，因此不可能。

## 考察能力
本题核心考察考生对快速排序算法**不变式性质（第i趟至少i个元素归位）**的理解与应用能力，以及通过逻辑推理排除不可能情况的能力，而非机械的算法模拟能力。
