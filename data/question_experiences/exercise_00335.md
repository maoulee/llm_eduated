# 练习题 Q1 — 双重哈希探测序列计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/哈希表
- **难度**: 待评估

## 题干原文
考虑一个双重哈希方案，其中主哈希函数为 $h_1(k) = k \% 23$，次哈希函数为 $h_2(k) = 1 + (k \% 19)$。假设表的大小为 23。那么对于键值 $k = 90$，在探测序列中第 1 次探测（假设探测序列从第 0 次探测开始）返回的地址是（ ）。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆双重哈希（Double Hashing）的标准公式 $H(k, i) = (h_1(k) + i \cdot h_2(k)) \mod m$。如果不熟悉该公式，无法入题；但只需调用这一个核心定义，无需辨析多个易混概念（如线性探测、平方探测的区别细节），故为标准难度。
- **K2 = 3**: 评分理由。涉及取模运算（Modulo），且除数（23, 19）均为非2的幂次素数，计算过程（90%23, 90%19）不能通过简单的位运算或心算快速得出，需要执行标准的除法取余步骤，存在一定计算量，属于标准计算难度。
- **K3 = 2**: 评分理由。推演步骤清晰且固定：1. 计算 $h_1$；2. 计算 $h_2$；3. 代入 $i=1$ 计算最终地址。总共3步串行计算，无需记忆中间状态或进行复杂的状态回溯，属于较低推演需求。
- **K4 = 3**: 评分理由。存在常规注意点（陷阱）：1. 探测次数的定义（题目明确 $i=1$，若误以为第1次是 $i=0$ 则错）；2. 次哈希函数 $h_2$ 必须保证与表长互质且不为0（题目给出的 $1 + k\%19$ 结构符合规范，但考生需意识到 $h_2$ 不能直接等于 $k\%m$ 否则可能为0）。这些属于常规考点中的“暗坑”，需细心识别。
- **K5 = 1**: 评分理由。本题仅涉及哈希表内部的地址计算逻辑，不涉及与其他数据结构（如树、图）或系统模块（如内存管理、操作系统调度）的状态传递或联动，属于单系统独立计算。
- **雷达形状**: K2计算型/K4陷阱型。整体呈现计算与细节识别并重的特征，K1基础要求适中，K3推演简单，K5无跨域需求。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于根据给定的数学公式和参数，通过具体的算术运算得出数值结果。虽然涉及概念（双重哈希），但解题的关键路径是准确的数值代入与计算，而非逻辑推理或概念辨析。

## 选项级分析
- **选项A**: [正确] — 正确执行了 $h_1(90)=21$, $h_2(90)=15$, $(21+1\times15)\%23 = 36\%23 = 13$ 的全过程。
- **选项B**: [干扰] — 针对**混淆 $h_2$ 计算或忽略 $i$ 的权重**的错误认知。例如，若考生误算 $h_2(90) = 90\%19 = 14$（忘记加1），则 $(21+14)\%23 = 35\%23 = 12$（非选项）；或者若考生误将 $i$ 当作0（第0次探测），结果为21（选项C）；若考生误以为 $h_2$ 直接参与加法而不乘 $i$（即 $i=1$ 但逻辑混乱），或者计算 $h_2$ 时出错得到其他值。更可能的错误路径是：误算 $90\%23$ 为其他值，或者在最终取模前加法出错。实际上，若考生误以为 $h_2(k) = k\%19 = 14$，且 $i=1$，则 $(21+14)\%23=12$。若考生误算 $90\%19=15$（计算错误），则 $h_2=16$，$(21+16)\%23=14$。此选项可能是针对 $h_2$ 计算中 $1+(k\%19)$ 的 $1$ 被忽略，且后续取模计算出现偏差的混合错误，或者是针对 $i$ 的理解偏差（如认为第1次探测是 $i=2$？$(21+30)\%23=28\%23=5$ 不对）。*修正分析*：若考生误将 $h_2$ 算作 $15$（正确），但误以为公式是 $h_1 + h_2$ 而不乘 $i$（即 $i=1$ 时结果一样），或者误算 $90\%23$。让我们看一个常见错误：$90 = 4 \times 23 + 18$，若误算余数为18，则 $h_1=18$。$h_2=15$。$(18+15)\%23 = 33\%23 = 10$。若误算 $90\%19$：$90 = 4 \times 19 + 14$，余数14，$h_2=15$。若考生忘记 $h_2$ 公式里的 $+1$，即 $h_2=14$，则 $(21+14)\%23=12$。若考生将 $i$ 误认为是探测的“第几次”即 $i=1$ 对应第一次冲突后的位置，但题目说“第1次探测（从0开始）”，通常 $i=0$ 是第0次，$i=1$ 是第1次。如果考生误以为“第1次探测”指的是 $i=0$（即初始位置），则答案是21（选项C）。如果考生误以为“第1次探测”指的是 $i=1$（正确），但计算 $h_1$ 时出错。选项B (15) 可能是 $h_2$ 的值本身，考生可能混淆了“返回的地址”和“步长”。
- **选项C**: [干扰] — 针对**混淆探测次数索引**的错误认知。考生可能认为“第1次探测”指的是初始哈希位置（即 $i=0$ 的情况）。此时地址为 $h_1(90) = 21$。这是最常见的概念混淆，即对“第0次”和“第1次”的定义不清。
- **选项D**: [干扰] — 针对**忽略取模运算或表长限制**的错误认知。考生可能计算出 $21 + 15 = 36$，然后错误地认为地址可以是36，或者在取模时出错（如 $36-23=13$，若误减为 $36-11=25$? 不对）。更可能的是，考生误以为表大小是其他值，或者完全忘记取模，直接输出中间值（但36不在选项中）。另一种可能是，考生误算 $h_1=21, h_2=15$，然后错误地执行 $(21+15)/2$ 或其他无意义运算。或者，考生误以为 $h_2$ 的模是23，即 $h_2 = 1 + 90\%23 = 1+21=22$，则 $(21+22)\%23 = 43\%23 = 20$。若考生误算 $h_1=90\%23=21$， $h_2=90\%19=14$（忘加1），且 $i=1$，结果12。选项D (23) 是一个典型的“越界”或“模数本身”的干扰项，暗示考生可能忘记取模，或者错误地认为最大地址是表大小（实际是 $m-1$）。

- **干扰策略**: 概念混淆（探测索引 $i$ 的定义）、计算陷阱（取模运算错误）、数值混淆（将步长 $h_2$ 误认为地址）。

## 核心陷阱
**探测序列索引的定义**：题目明确指出“探测序列从第 0 次探测开始”，问“第 1 次探测”。这要求考生准确理解 $i=1$ 而非 $i=0$。若误选 $i=0$，则得到初始哈希地址 21（选项C）。此外，次哈希函数 $h_2(k)$ 必须保证结果不为0且与表长互质，题目中 $1 + (k\%19)$ 的设计正是为了满足这一条件，考生需识别出 $h_2$ 的计算细节（加1）。

## 考察能力
本题核心考察考生对**双重哈希冲突解决机制**中地址计算公式的准确记忆，以及在非2的幂次表长下进行**多步取模运算**的准确性与细心程度。
