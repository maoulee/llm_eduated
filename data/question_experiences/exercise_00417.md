# 练习题 Q1 — 递归算法时间复杂度分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/算法分析
- **难度**: 待评估

## 题干原文
下面 C 函数的时间复杂度是（假设 n > 0）（ ）
```c
int recursive (int n) {
    if (n == 1) return (1);
    else return (recursive (n - 1) + recursive (n - 1));
}
```
- 选项:
  A: O(n)
  B: O(n log n)
  C: O(n^2)
  D: O(2^n)
- 正确答案: D
- 解析（参考）: 代码的递归关系式为 T(n) = 2T(n-1) + k。我们可以通过代入法求解该递归式：
初始递归式：
T(n) = 2T(n-1) + k
代入展开：
= 2(2T(n-2) + k) + k
= 2(2(2T(n-3) + k) + k) + k
⋮
= 2^x · T(n-x) + k(2^x - 1)
当满足基本情况时（n=1），令 x = n-1：
T(n) = 2^(n-1) · T(1) + k(2^(n-1) - 1)
= O(2^n)
因此，选项 (D) 正确。
- 知识标签: ['数据结构/算法分析']
- 知识域: DS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握递归树或递归方程求解的基本概念。不是2分因为仅靠直觉容易误判，需要明确“时间复杂度”在递归中的定义（即节点总数或执行次数）；不是4分因为不需要辨析多个易混的高级概念，只需掌握基本的递归展开或递归树模型。
- **K2 = 3**: 评分理由。涉及等比数列求和或递归树的层级计算。不是2分因为涉及指数级的增长计算，容易在系数或阶数上出错；不是4分因为计算过程相对标准，没有复杂的非整数幂或多级换算。
- **K3 = 3**: 评分理由。需要建立递归方程 T(n) = 2T(n-1) + O(1) 并进行多步推演（展开或画树）。从代码到方程是1步，从方程到解是2-3步，总共3-4步逻辑链条，属于标准推演难度。
- **K4 = 2**: 评分理由。题目陷阱较少，主要难点在于对递归调用次数的直观理解。没有明显的隐含前提或反直觉陷阱，只要正确识别出每次调用产生两个子调用即可。
- **K5 = 1**: 评分理由。单系统问题，仅涉及算法分析模块，无需跨越数据结构、操作系统等其他领域。

- **雷达形状**: K1-K3均衡型，略微偏向计算与推演（K2/K3略高），无明显短板或极端高分项。

## 考察模式
- **模式**: 推理型
- **理由**: 本题不能通过简单的公式记忆直接得出答案（如二分查找是O(log n)），也不能通过单次代入计算得出。它要求考生将代码逻辑转化为数学模型（递归方程或递归树），并通过逻辑推演（展开或求和）得出最终的时间复杂度阶数。

## 选项级分析
- **选项A**: [干扰] — 针对“线性递归”的错误认知。这类学生可能看到 `n-1` 就认为是线性递减，误以为复杂度与 n 成正比，忽略了每次递归调用了两次自身。
- **选项B**: [干扰] — 针对“分治算法”的刻板印象。这类学生可能看到递归就联想到归并排序或二分查找，误以为复杂度是 O(n log n)，忽略了本题并非将问题规模减半，而是减1。
- **选项C**: [干扰] — 针对“嵌套循环”的类比错误。这类学生可能将递归深度 n 与每层的工作量混淆，或者错误地认为总工作量是 1+2+...+n 的累加，从而得出 O(n^2)。
- **选项D**: [正确] — 正确识别出递归树是一棵满二叉树，节点总数随深度指数增长。

- **干扰策略**: 概念混淆（将线性递归与分治递归混淆）、直觉误导（低估指数爆炸的速度）。

## 核心陷阱
- **核心陷阱**: **递归调用的分支因子**。考生容易只关注递归深度（n-1），而忽略每次递归产生的分支数（2个）。如果误以为每次只调用一次 `recursive(n-1)`，则会得出 O(n) 的错误结论；如果误以为规模减半，则会得出 O(log n) 或 O(n log n) 的错误结论。关键在于识别出 T(n) = 2T(n-1) 这一指数增长模型。

## 考察能力
一句话概括本题核心考察的能力：将递归代码转化为递归方程或递归树模型，并准确求解其渐近时间复杂度的能力。
