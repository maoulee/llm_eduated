# 模拟题 Q综合题 — 定点数与浮点数表示及移位运算

## 基本信息
- **来源**: 模拟题  **题型**: 综合题
- **科目**: 计算机组成原理
- **知识点**: CO-2 > 数制与编码 > 真值和机器数, CO-2 > 定点数的表示 > 补码表示, CO-2 > 定点数的运算 > 移位运算, CO-2 > 浮点数的表示和运算 > IEEE 754浮点数
- **难度**: 待评估

## 题干原文
（12 分）已知 32 位寄存器中存放的变量 x 的机器码为 C000004H，请问：
（1）当 x 是无符号整数时：
x 的真值是多少？
x/2 的真值是多少？
x/2 存放在 R1 中的机器码是什么？
2x 的真值是多少？
2x 存放在 R1 中的机器码是什么？
（2）当 x 是带符号整数（补码）时：
x 的真值是多少？
x/2 的真值是多少？
x/2 存放在 R1 中的机器码是什么？
2x 的真值是多少？
2x 存放在 R1 中的机器码是什么？
（3）当 x 是 float 型浮点数时：
x 的真值是多少？
x/2 的真值是多少？
x/2 存放在 R1 中的机器码是什么？
2x 的真值是多少？
2x 存放在 R1 中的机器码是什么？

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题需要考生精准区分并调用三种完全不同的数据表示体系（无符号整数、补码整数、IEEE 754浮点数）的定义。特别是浮点数的阶码偏移量（127）、隐藏位（1.M）以及规格化规则，属于易混概念辨析，记忆负荷较高。
- **K2 = 3**: 评分理由。涉及十六进制到二进制的转换、真值计算（$2^{31}$等幂次运算）、浮点数阶码与尾数的分离计算。虽然主要是2的幂次运算，但浮点数部分涉及小数点定位和科学计数法转换，计算步骤多于简单的定点数加减。
- **K3 = 3**: 评分理由。解题过程包含多个串行步骤：首先解析机器码 -> 根据类型选择解释规则 -> 计算真值 -> 执行移位或阶码调整 -> 重新编码为机器码。每一步都依赖上一步的结果，且不同子问题的逻辑链条独立但结构相似，属于标准的3-5步推演。
- **K4 = 4**: 评分理由。存在多个隐含前提和陷阱。例如：无符号数左移溢出后的机器码变化（高位丢失）；补码算术右移时的符号位扩展规则；浮点数除以2时是尾数右移还是阶码减1（需判断是否非规格化或下溢，本题中为规格化数，故为阶码减1）；浮点数乘以2时阶码加1是否溢出。这些“题面没说但必须意识到的规则”构成了主要难度。
- **K5 = 3**: 评分理由。题目要求在三个不同的数据子系统（无符号、补码、浮点）之间进行状态切换。虽然每个子系统内部是独立的，但考生需要在同一组机器码（C000004H）下，动态切换解释视角，属于单向的数据重解释，而非深度耦合的状态传递。
- **雷达形状**: 偏向于“高认知、高条件路由”的菱形或盾形。K1和K4较高，K2和K3中等，K5中等。表明题目难点不在于复杂计算，而在于对规则细节的精准把握和不同语境下的规则切换。

## 考察模式
- **模式**: 计算推导型
- **理由**: 题目给定具体的机器码输入，要求通过一系列确定的编码规则和运算规则，推导出真值和新的机器码输出。整个过程依赖于对底层数据表示格式的严格解析和数学计算，而非算法设计或逻辑论证。

## 解题思路分析
- **核心思路**: “一码多解”与“逆向重构”。首先将十六进制机器码 `C000004H` 转换为32位二进制串。然后针对三种不同的数据类型，分别应用对应的解释规则（无符号权值求和、补码符号位处理、IEEE 754阶码尾数分离）计算真值。最后，根据运算要求（除以2或乘以2），在二进制层面执行移位或阶码调整，再转换回十六进制机器码。
- **关键步骤**:
    1.  **二进制转换**: `C000004H` -> `1100 0000 0000 0000 0000 0000 0000 0100`。
    2.  **无符号整数**:
        -   真值：直接按权展开，$2^{31} + 2^{30} + 2^2$。
        -   除以2：逻辑右移1位，高位补0。
        -   乘以2：逻辑左移1位，低位补0，注意最高位溢出丢弃。
    3.  **补码整数**:
        -   真值：最高位为1，是负数。取反加1求原码，或直接用公式 $-2^{31} + \sum$。
        -   除以2：算术右移1位，高位补符号位（1）。
        -   乘以2：算术左移1位，低位补0，注意溢出判断（本题中左移后符号位改变，发生溢出，但题目问的是存放在R1中的机器码，即物理移位结果）。
    4.  **IEEE 754 浮点数**:
        -   解析：符号位S=1，阶码E=`1100 0000` (192)，尾数M=`000...00100`。
        -   真值：$(-1)^1 \times 2^{192-127} \times (1 + 2^{-29})$。
        -   除以2：阶码减1（191），尾数不变。
        -   乘以2：阶码加1（193），尾数不变。
        -   重构：将新的S, E, M组合回32位二进制，转十六进制。
- **易错点**:
    1.  **补码真值计算**: 容易忘记补码最高位的负权值，或者在取反加1时出错。
    2.  **移位方向与类型**: 混淆逻辑移位和算术移位。无符号数用逻辑移位，补码用算术移位。
    3.  **浮点数阶码偏移**: 忘记减去偏移量127，或者在调整阶码时忘记加回偏移量。
    4.  **浮点数隐藏位**: 计算真值时忘记加上隐含的“1.”。
    5.  **溢出处理**: 对于定点数乘法（左移），题目问的是“存放在R1中的机器码”，通常指物理移位后的结果（截断），而非数学真值。学生容易纠结于溢出错误而不敢写出机器码。

## 核心陷阱
- **核心陷阱**: **浮点数运算的“阶码调整”与定点数“移位”的本质区别**。
    许多学生习惯于用“移位”来思考所有除法/乘法。对于浮点数，`x/2` 和 `2x` 通常通过**修改阶码**来实现，而不是修改尾数（除非发生非规格化或溢出）。如果学生试图对浮点数的尾数进行移位，不仅计算复杂，而且极易出错。此外，补码左移溢出后的机器码表示也是一个常见陷阱，学生可能认为溢出后结果无效，从而无法给出机器码，但实际上寄存器中会保留移位后的位模式。

## 考察能力
本题核心考察考生对计算机底层数据表示格式（定点数与浮点数）的深刻理解，以及在特定硬件约束下（如寄存器宽度、移位规则）进行精确数值转换和运算推导的能力。
