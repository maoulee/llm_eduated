# 练习题 Q1 — 二叉树度数性质与握手定理

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/二叉树
- **难度**: 待评估

## 题干原文
一棵包含 $n>1$ 个节点的二叉树中，分别有 $n_1$、$n_2$ 和 $n_3$ 个度数为一、二和三的节点。节点的度数定义为其相邻节点的数量。$n_3$ 可以表示为（ ）。
A: $n_1 + n_2 - 1$
B: $n_1 - 2$
C: $2n_1 + n_2$
D: $n_2 - 1$

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“树的度数之和等于边数两倍（握手定理）”以及“二叉树节点度数最大为2”这两个核心概念。如果不知道握手定理，无法入题；如果混淆了二叉树度数的定义（子节点数 vs 相邻节点数），则无法解题。属于标准的基础概念调用。
- **K2 = 2**: 评分理由。计算过程涉及简单的代数代入和化简：$1\cdot n_1 + 2\cdot n_2 + 3\cdot n_3 = 2(n-1)$。虽然步骤不多，但涉及系数运算，对于心算能力弱的学生可能存在轻微计算风险，但整体属于低难度计算。
- **K3 = 2**: 评分理由。推演步骤清晰：1. 确定总节点数 $n$ 的表达式；2. 列出度数总和方程；3. 代入并化简。仅需2-3步逻辑串联，无需复杂的状态记忆或多步串行推演。
- **K4 = 4**: 评分理由。**这是本题最大的陷阱所在**。题干明确定义“节点的度数定义为其相邻节点的数量”。在二叉树中，根节点没有父节点，叶子节点没有子节点，内部节点有父节点和子节点。
    - 常规二叉树性质中，$n_0$（叶子）、$n_1$（度1）、$n_2$（度2）通常指**子节点**的数量。
    - 但本题定义的“度数”是图论中的**相邻节点数**（即图论度数）。
    - 在二叉树（作为树结构）中：
        - 叶子节点：只有1个相邻节点（父节点），度数为1。
        - 度为1的子节点节点（只有一个孩子）：有2个相邻节点（1父1子），度数为2。
        - 度为2的子节点节点（有两个孩子）：有3个相邻节点（1父2子），度数为3。
        - **根节点**：如果没有孩子，度数为0；如果有一个孩子，度数为1；如果有两个孩子，度数为2。
    - **关键隐含前提**：题目中出现了 $n_3$（度数为3的节点）。在二叉树中，只有非根节点且拥有两个孩子的节点，其相邻节点数才为3（1父+2子）。根节点最多只有2个相邻节点（2子）。因此，$n_3$ 实际上对应的是传统二叉树中度为2的非根节点。
    - 然而，更深层的陷阱在于：**题目给出的选项和解析基于一个特定的假设或简化模型，或者题目本身存在表述上的歧义/错误**。
    - 让我们重新审视标准二叉树性质：
        - 传统定义：$n_0$ (0子), $n_1$ (1子), $n_2$ (2子)。
        - 关系：$n_0 = n_2 + 1$。
    - 本题定义：
        - $n_1$: 相邻节点数为1。这包括：传统叶子节点（1父0子）和 传统度1的根节点（0父1子）。
        - $n_2$: 相邻节点数为2。这包括：传统度1的非根节点（1父1子）和 传统度2的根节点（0父2子）。
        - $n_3$: 相邻节点数为3。这包括：传统度2的非根节点（1父2子）。
    - 如果按照图论度数严格推导：
        - 总度数 $\sum deg = 2(n-1)$。
        - $\sum deg = 1\cdot n_1 + 2\cdot n_2 + 3\cdot n_3$。
        - $n = n_0' + n_1' + n_2' + n_3'$? 不，题目只给了 $n_1, n_2, n_3$。这意味着**不存在度数为0的节点**？
        - 如果 $n>1$，根节点度数至少为1（除非 $n=1$，但题目说 $n>1$）。
        - 如果树中所有节点度数都 $\ge 1$，则没有孤立点。
        - 但是，传统二叉树的叶子节点（0子）在图论中度数为1（连向父节点）。
        - 传统度为2的节点（2子），若非根，度数为3；若为根，度数为2。
        - 传统度为1的节点（1子），若非根，度数为2；若为根，度数为1。
        - 题目中 $n_3$ 存在，说明有节点度数为3。
        - 让我们看解析给出的答案 $n_3 = n_1 - 2$。
        - 代入握手定理：$n_1 + 2n_2 + 3n_3 = 2(n_1+n_2+n_3 - 1)$
        - $n_1 + 2n_2 + 3n_3 = 2n_1 + 2n_2 + 2n_3 - 2$
        - $n_3 = n_1 - 2$。
        - 这个推导**完全依赖于** $n = n_1 + n_2 + n_3$ 这一前提。
        - **陷阱核心**：题目隐含假设了**所有节点的度数都大于0**，即**没有度数为0的节点**。在 $n>1$ 的树中，确实没有度数为0的节点（孤立点）。但是，是否所有节点都被 $n_1, n_2, n_3$ 覆盖？
        - 在二叉树中，节点度数（相邻数）可能为 0, 1, 2, 3。
        - 度数为0：仅当 $n=1$ 时存在。题目 $n>1$，故无度数0节点。
        - 度数为1：叶子节点（1父0子）或 根节点（0父1子）。
        - 度数为2：度1非根节点（1父1子）或 根节点（0父2子）。
        - 度数为3：度2非根节点（1父2子）。
        - 所以，$n = n_1 + n_2 + n_3$ 是成立的（因为 $n>1$，无度数0节点，且二叉树节点度数最大为3）。
        - 因此，推导逻辑是自洽的。
        - **K4评分理由修正**：陷阱在于学生是否意识到 $n = n_1 + n_2 + n_3$ 成立（即排除度数0的情况），以及是否会被“二叉树”这个标签误导去使用 $n_0 = n_2 + 1$ 等传统公式，而不是使用通用的图论握手定理。需要识别出“度数”定义的变化。这是一个典型的**概念定义陷阱**。

- **K5 = 1**: 评分理由。仅在数据结构/图论基础理论内部，不涉及操作系统、计网等其他科目。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要考察对定义细节的敏感度和隐含条件的识别）

## 考察模式
- **模式**: 推理型
- **理由**: 题目并非直接考查记忆公式，而是要求考生根据给定的“度数”新定义，结合图论基本定理（握手定理）进行代数推导。虽然计算简单，但核心在于逻辑构建和定义辨析。

## 选项级分析
- **选项A**: [干扰] — 针对试图通过复杂线性组合凑答案的学生，或者错误地认为 $n_3$ 与 $n_2$ 有强线性关系。
- **选项B**: [正确] — 通过握手定理 $1\cdot n_1 + 2\cdot n_2 + 3\cdot n_3 = 2(n_1+n_2+n_3-1)$ 化简得到 $n_3 = n_1 - 2$。
- **选项C**: [干扰] — 针对完全不懂推导，随机猜测或混淆系数关系的学生。
- **选项D**: [干扰] — 针对混淆了 $n_1$ 和 $n_2$ 的角色，或者错误记忆了二叉树性质 $n_0 = n_2 + 1$ 并试图强行映射的学生。

- **干扰策略**: 概念混淆（传统二叉树度数 vs 图论相邻度数）、计算陷阱（代数化简错误）。

## 核心陷阱
**核心陷阱**: **度数的定义差异与隐含的节点覆盖假设**。
1.  **定义陷阱**：题目定义的“度数”是图论中的相邻节点数，而非二叉树中常见的“子节点数”。这导致传统二叉树中的叶子节点（0子）在本题中度数为1，传统度2节点（2子）若非根则度数为3。
2.  **隐含前提**：解题必须意识到在 $n>1$ 的二叉树中，不存在度数为0的节点，因此总节点数 $n$ 恰好等于 $n_1 + n_2 + n_3$。如果学生遗漏这一点，或者试图引入 $n_0$（度数0节点），会导致方程建立错误。
3.  **思维定势**：学生容易直接套用二叉树经典结论 $n_0 = n_2 + 1$，而忽略了题目中变量符号 $n_1, n_2, n_3$ 对应的是图论度数，导致张冠李戴。

## 考察能力
本题核心考察考生**在特定定义约束下，灵活运用图论基本定理（握手定理）进行代数建模与推导的能力**，以及对**概念定义细节的敏锐辨析能力**。
