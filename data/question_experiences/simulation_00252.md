# 模拟题 Q1 — 单链表判环算法设计

## 题干原文
单链表有环，是指单链表的最后一个结点的指针指向了链表中的某个结点（通常单链表的最后一个结点的指针域是为空的）。试编写算法判断单链表是否存在环。
（1）给出算法的基本设计思想。
（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
（3）说明你所设计算法的时间复杂度和空间复杂度。

## K1-K5 评分与解析
- **K1 = 2**: 评分理由。虽然题目归类在操作系统，但核心考察的是数据结构中的链表操作。对于408考生而言，链表是基础数据结构，快慢指针（Floyd判圈算法）是经典算法，属于“较低”的认知需求，只需回忆该特定算法即可，无需辨析多个易混概念。
- **K2 = 1**: 评分理由。本题不涉及数值计算，而是逻辑判断和指针操作。没有复杂的数学换算或幂次计算，单步操作仅为指针移动和比较，计算难度极低。
- **K3 = 3**: 评分理由。解题过程需要多步串行推演：初始化指针 -> 循环条件判断 -> 指针移动 -> 相遇判断 -> 终止条件判断。这属于标准的3-5步逻辑推演，需要清晰地理解快慢指针在环内外的运动状态变化。
- **K4 = 3**: 评分理由。存在常规注意点（陷阱词/边界条件）。例如：空链表、只有一个节点、快指针移动两步时需检查 `fast->next` 是否为空以防止段错误。这些是算法实现中的常规陷阱，需要考生具备基本的代码健壮性意识。
- **K5 = 1**: 评分理由。本题完全局限于单链表这一单一数据结构内部，不涉及操作系统其他子系统（如进程管理、内存管理、文件系统等）的状态传递或联动，属于单系统问题。

## 解题思路分析
- **核心思路**: 采用快慢指针法（Floyd判圈算法）。利用两个指针以不同速度遍历链表，若存在环，快指针必然在环内追上慢指针；若无环，快指针必先到达链表尾部。
- **关键步骤**:
    1.  **边界处理**: 检查链表是否为空或只有一个节点，若是则直接返回无环。
    2.  **指针初始化**: 设置慢指针 `slow` 和快指针 `fast` 均指向头节点。
    3.  **循环遍历**: 当 `fast` 和 `fast->next` 均不为空时，执行循环。
    4.  **指针移动**: `slow` 移动一步 (`slow = slow->next`)，`fast` 移动两步 (`fast = fast->next->next`)。
    5.  **相遇判断**: 每次移动后检查 `slow == fast`，若相等则返回 `true`（有环）。
    6.  **终止返回**: 若循环结束仍未相遇，返回 `false`（无环）。
- **易错点**:
    1.  **空指针异常**: 在移动快指针两步时，未检查 `fast->next` 是否为 `NULL`，导致访问非法内存。
    2.  **初始化错误**: 将快慢指针初始化为不同位置（如一个头一个头->next），虽然也可行但逻辑更复杂，标准做法是均从头开始。
    3.  **复杂度分析错误**: 误认为时间复杂度为 O(n^2) 或空间复杂度为 O(n)（若使用哈希表法）。

## 核心陷阱
- **核心陷阱**: 快指针移动两步时的边界检查。许多考生会写成 `while(fast != NULL)` 然后在循环内执行 `fast = fast->next->next`，这会在 `fast` 指向最后一个节点时，尝试访问 `NULL->next`，导致程序崩溃。正确的写法必须在循环条件中同时保证 `fast` 和 `fast->next` 非空。
