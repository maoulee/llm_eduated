# 模拟题 Q综合题 — 补码表示、运算及标志位判断

## 基本信息
- **来源**: 模拟题  **题型**: 综合题
- **科目**: 计算机组成原理
- **知识点**: CO-2 > 定点数的表示 > 补码表示, CO-2 > 定点数的运算 > 补码加减运算, CO-2 > 定点数的运算 > 溢出判断
- **难度**: 待评估

## 题干原文
（12 分）假设有两个整数 x 和 y，x = −68，y = −80。采用补码形式（含 1 位符号位）表示，x 和 y 分别存放在寄存器 A 和 B 中。另外，还有两个寄存器 C 和 D。A、B、C、D 都是 8 位的寄存器。请回答下列问题：（要求最终用十六进制表示二进制序列）
（1）寄存器 A 和 B 中的内容分别是什么？
（2）x 和 y 相加后的结果存放在 C 寄存器中，寄存器 C 中的内容是什么？此时，溢出标志位 OF 是什么？符号标志位 SF 是什么？进位标志位 CF 是什么？
（3）x 和 y 相减后的结果存放在 D 寄存器中，寄存器 D 中的内容是什么？此时，溢出标志位 OF 是什么？符号标志位 SF 是什么？进位标志位 CF 是什么？

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆补码的定义（负数取反加一）、8位有符号数的表示范围（-128~127）以及三个标志位（OF, SF, CF）的具体定义。属于标准的基础概念调用，不涉及复杂概念辨析。
- **K2 = 3**: 评分理由。涉及十进制转二进制、求补码、二进制加减法运算以及二进制转十六进制。虽然数字较小（68, 80），但非2的幂次，且涉及负数运算，计算步骤稍多，存在算错风险，属于标准难度的单步代入。
- **K3 = 3**: 评分理由。解题过程包含“真值->原码->反码->补码”、“补码加法/减法”、“根据结果判断标志位”等多个串行步骤。每一步依赖上一步的结果，且需同时处理数值计算和状态位判断，属于3-5步的标准推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和易错陷阱。首先，题目未明确说明是“有符号”还是“无符号”运算，但通过“补码”、“溢出标志OF”暗示了有符号运算语境，学生需自行切换判断逻辑（OF看符号位进位异或，CF看最高位进位）。其次，减法运算需转化为加法（加负数的补码），且需正确判断溢出（两个负数相加得正数必溢出）。这些“题面没说但必须意识到的条件”构成了较高的条件路由需求。
- **K5 = 2**: 评分理由。主要考察定点数运算子系统内部的状态传递。虽然涉及寄存器A/B到C/D的数据流动，但这属于同一模块内的常规数据通路，不涉及跨子系统（如内存、I/O、控制单元）的深度耦合或状态互影响。

- **雷达形状**: 整体呈均衡偏高的形状，K4（条件路由）突出，表明本题难点不在于计算复杂度，而在于对运算规则细节（特别是标志位判断逻辑）的精准把握。

## 考察模式
- **模式**: 计算推导型
- **理由**: 题目要求给出具体的数值结果（十六进制）和状态位（0/1），解题过程依赖于严格的数学定义和二进制运算规则进行逐步推导，而非开放性的设计或论证。

## 解题思路分析
- **核心思路**: 遵循“真值转换 -> 补码运算 -> 结果解析 -> 标志位判定”的流程。关键在于区分有符号数运算中的溢出（OF）与无符号数运算中的进位（CF）。
- **关键步骤**:
    1.  **求补码**: 将 $x=-68$ 和 $y=-80$ 转换为8位补码。
        -   $68 = 01000100_2 \rightarrow [x]_{补} = 10111100_2 = \text{BCH}$
        -   $80 = 01010000_2 \rightarrow [y]_{补} = 10110000_2 = \text{B0H}$
    2.  **加法运算 ($x+y$)**:
        -   $[x]_{补} + [y]_{补} = 10111100 + 10110000 = 101101100_2$
        -   保留低8位存入C: $01101100_2 = \text{6CH}$
        -   **标志位判断**:
            -   **CF (进位)**: 最高位（第7位）向第8位有进位，故 CF=1。
            -   **SF (符号)**: 结果最高位为0，故 SF=0。
            -   **OF (溢出)**: 两个负数相加，结果为正（符号位由1变0），发生溢出；或使用公式 $OF = C_7 \oplus C_6$（第7位进位异或第6位进位）。此处 $C_7=1$ (进位出), $C_6=0$ (第6位向第7位无进位? 需仔细检查: $1+0=1$无进位, $1+0=1$无进位... 实际上看符号位进位 $C_{out}$ 和次高位进位 $C_{in}$。$1+1=0$进1, $1+0+1=0$进1... 更简单的判断：负+负=正，必溢出，OF=1)。
    3.  **减法运算 ($x-y$)**:
        -   转化为 $[x]_{补} + [-y]_{补}$。
        -   $[-y]_{补}$: $y=\text{B0H} \rightarrow$ 取反 $\text{4FH} \rightarrow$ 加1 $\text{50H}$ ($01010000_2$)。
        -   $[x]_{补} + [-y]_{补} = 10111100 + 01010000 = 100001100_2$
        -   保留低8位存入D: $00001100_2 = \text{0CH}$
        -   **标志位判断**:
            -   **CF**: 最高位向更高位有进位（$1+0=1$无进位? 等等，$10111100 + 01010000$。最高位 $1+0=1$，无进位出？不对，$10111100$是负数，$01010000$是正数。$1+0$在最高位。让我们重新算二进制：
                $10111100$
              + $01010000$
              -----------
              $100001100$
              最高位是第7位。$1+0=1$，没有产生第8位的进位？
              检查：$10111100$ (BCH) + $01010000$ (50H) = $100001100$ (10CH)。
              是的，产生了第8位进位（第7位是符号位，第8位是进位位）。
              等等，8位寄存器，位索引0-7。
              Bit 7: $1+0=1$。
              Bit 6: $1+1=0$ (进位1)。
              ...
              让我们仔细加一下：
              $10111100$
              $01010000$
              ---------
              $00001100$ (低8位)
              进位链：
              Bit 0: 0+0=0
              Bit 1: 0+0=0
              Bit 2: 1+0=1
              Bit 3: 1+0=1
              Bit 4: 1+0=1
              Bit 5: 1+1=0, C=1
              Bit 6: 1+0+1=0, C=1
              Bit 7: 1+0+1=0, C=1  <-- 这里！
              所以结果是 $00001100$，且向Bit 8有进位。
              因此 CF=1。
            -   **SF**: 结果最高位（Bit 7）为0，故 SF=0。
            -   **OF**: 正数减负数（或负数加正数），若结果符号与加数符号不一致则溢出？
              $x$是负，$-y$是正。结果 $00001100$ 是正。
              真值：$-68 - (-80) = 12$。结果正确，无溢出。
              公式法：$C_7$ (Bit 7向Bit 8的进位) = 1。$C_6$ (Bit 6向Bit 7的进位) = 1。
              $OF = C_7 \oplus C_6 = 1 \oplus 1 = 0$。
              故 OF=0。

- **易错点**:
    1.  **补码转换错误**: 负数求补码时忘记“取反加一”或加一后忘记处理进位。
    2.  **减法转化错误**: 忘记将减法转化为加法，或者求 $[-y]_{补}$ 时出错。
    3.  **标志位混淆**:
        -   混淆 CF 和 OF 的定义。CF 仅看最高位进位（无符号溢出），OF 看符号位进位与次高位进位的异或（有符号溢出）。
        -   在加法中，两个负数相加得到正数，直观判断 OF=1，但学生可能误判 CF。
        -   在减法中，容易忽略进位链的传递，导致 CF 判断错误。

## 核心陷阱
- **核心陷阱**: **标志位 OF 与 CF 的语义混淆及计算细节**。
    题目特意设置了两个负数相加（必然溢出，OF=1，但CF可能为1也可能为0，取决于具体数值，本题中CF=1）和一个负数减负数（无溢出，OF=0，但CF=1）。学生极易在“有符号溢出”和“无符号进位”之间切换失败，或者在计算进位链时出错，导致标志位判断全错。特别是减法运算中，$x-y$ 转化为 $[x]_{补} + [-y]_{补}$ 后，最高位产生了进位（CF=1），但因为是异号相加且结果在范围内，所以没有溢出（OF=0），这一反直觉的组合（CF=1, OF=0）是主要陷阱。

## 考察能力
本题核心考察学生对定点数补码表示机制的理解、二进制加减运算的熟练度，以及在有符号数运算环境下准确判断溢出（OF）与进位（CF）标志位的逻辑思维能力。
