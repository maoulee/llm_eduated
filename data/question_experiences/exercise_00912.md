# 练习题 Q1 — IP子网掩码与网络地址判定

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/网络层
- **难度**: 待评估

## 题干原文
两台计算机 C1 和 C2 的配置如下：C1 的 IP 地址为 203.197.2.53，子网掩码为 255.255.128.0；C2 的 IP 地址为 203.197.75.201，子网掩码为 255.255.192.0。以下哪项陈述是正确的（ ）？
- 选项:
  A: C1 和 C2 都认为它们在同一个网络中
  B: C2 认为 C1 在同一个网络中，但 C1 认为 C2 在不同网络中
  C: C1 认为 C2 在同一个网络中，但 C2 认为 C1 在不同网络中
  D: C1 和 C2 都认为它们在不同网络中

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“网络地址 = IP地址 AND 子网掩码”这一核心定义，以及“判断是否同网段需使用本地子网掩码”的基本规则。属于标准的基础概念记忆，不涉及复杂概念辨析。
- **K2 = 3**: 评分理由。涉及非标准子网掩码（/17 和 /18）的二进制与运算。虽然255.255.128.0和255.255.192.0是常见掩码，但需要准确计算第三个字节的二进制值（2 vs 75，128 vs 192），存在计算出错的可能，属于标准难度的单步计算。
- **K3 = 3**: 评分理由。解题过程包含两个独立的推演分支：1. C1视角：用C1掩码算C1网段，用C1掩码算C2网段，比较；2. C2视角：用C2掩码算C2网段，用C2掩码算C1网段，比较。共需4次与运算和2次比较，步骤清晰但需串行执行，属于3-5步的标准推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提陷阱：判断“是否在同一网络”是**本地主机**的行为，必须使用**本地**的子网掩码去解析对方的IP地址。许多学生容易误以为需要双方掩码一致，或者试图寻找一个“客观”的网络归属，而忽略了网络层通信中“视角”的主观性（即本地配置决定本地判断）。这是一个典型的机制理解陷阱。
- **K5 = 1**: 评分理由。本题仅涉及网络层IP地址计算，不涉及传输层、链路层或其他子系统的状态传递，属于单系统内部逻辑。
- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要难点在于对“本地视角”这一隐含条件的识别）

## 考察模式
- **模式**: 推理型
- **理由**: 虽然包含计算成分，但核心难点不在于计算的复杂度，而在于理解“网络归属判断”的逻辑机制。考生需要推理出“判断同网段”这一动作是由本地主机发起的，因此必须应用本地的子网掩码规则，而非寻找全局统一的网络定义。

## 选项级分析
- **选项A**: [干扰] — 针对“客观网络观”错误认知。这类学生可能计算出C1的网段是203.197.0.0，C2的网段是203.197.64.0，发现不同，但可能错误地认为只要IP前缀相似就在同一网络，或者误以为C2的掩码能覆盖C1（实际上C2掩码更短，范围更小，无法覆盖C1的低位变化，但此处主要是逻辑错误）。更常见的是，学生可能只算了C1看C2（同网），忘了算C2看C1，或者错误地认为只要有一方认为同网就算同网。
- **选项B**: [干扰] — 针对“反向逻辑”或“计算错误”。这类学生可能正确计算了C2看C1（不同网），但在计算C1看C2时出错，或者混淆了谁看谁。例如，误以为C1的掩码（/17）比C2（/18）短，所以C1范围大，应该包含C2，但反过来C2范围小，不包含C1。如果学生搞反了掩码长度与网络范围的关系，可能会选此项。
- **选项C**: [正确] — 符合逻辑推演结果。C1使用/17掩码，将C2的IP（203.197.75.201）映射到203.197.0.0，与自身网段一致，故认为同网；C2使用/18掩码，将C1的IP（203.197.2.53）映射到203.197.0.0，而自身网段为203.197.64.0，两者不同，故认为不同网。
- **选项D**: [干扰] — 针对“完全隔离”或“计算全错”。这类学生可能正确计算出C2看C1不同网，但在计算C1看C2时，错误地使用了C2的掩码，或者错误地进行了二进制运算，导致认为C1也看C2不同网。

- **干扰策略**: 概念混淆（混淆“客观网络地址”与“本地判断逻辑”）+ 计算陷阱（非标准掩码的二进制运算易错）

## 核心陷阱
**“本地视角”原则的忽视**：判断两个IP是否在同一子网，不是由一个上帝视角决定的，而是由**发起判断的主机**根据其**本地配置**（子网掩码）决定的。C1和C2拥有不同的子网掩码，因此它们对“同一网络”的定义不同，导致对彼此归属的判断出现不对称性。

## 考察能力
掌握IP地址与子网掩码的位运算规则，并能深刻理解网络层中“子网判断”是基于本地配置的相对概念而非绝对概念。
