# 练习题 Q1 — 快速排序最坏情况下的比较次数对称性

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/排序
- **难度**: 待评估

## 题干原文
对以下两个输入使用快速排序进行升序排列，且每次都将第一个元素选为主元：
(i) 1, 2, 3, …, n
(ii) n, n-1, n-2, …, 2, 1
设 C1 和 C2 分别为处理输入 (i) 和 (ii) 时的比较次数。则：
- 选项:
  A: C1 < C2
  B: C1 > C2
  C: C1 = C2
  D: 对任意 n 都无法确定两者关系

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握快速排序的基本定义、主元选择策略（第一个元素）以及“最坏情况”的概念。不是4分因为不需要辨析多个易混的排序算法细节，只需聚焦快排本身。
- **K2 = 1**: 评分理由。本题不涉及具体的数值计算，无需执行乘法或加法运算，仅涉及逻辑判断。
- **K3 = 3**: 评分理由。需要在脑海中推演快速排序在正序和逆序输入下的划分过程。虽然不需要写出完整代码，但需要理解递归树的结构和每一层比较次数的累加逻辑，属于中等程度的机制推演。
- **K4 = 4**: 评分理由。存在明显的反直觉陷阱。许多学生直觉认为“逆序比正序更乱”或“正序已经有序可能更快”，从而误判 C1 和 C2 的大小。解题必须意识到：当主元固定为第一个元素时，正序和逆序都会导致极不平衡的划分（一边为空，一边为 n-1），且这种不平衡的结构在数学上是完全对称的。识别这一隐含的对称性是解题关键。
- **K5 = 1**: 评分理由。本题仅涉及数据结构中的排序模块，不涉及操作系统、计算机网络或组成原理等其他领域的知识联动。

- **雷达形状**: K4陷阱型（高K4，低K2/K5，中等K1/K3）

## 考察模式
- **模式**: 推理型
- **理由**: 本题不依赖死记硬背的公式，也不依赖复杂的数值计算，而是要求考生基于快速排序的算法逻辑，推演两种极端输入情况下的行为模式，并通过逻辑对称性得出结论。

## 选项级分析
- **选项A**: [干扰] — 针对认为“逆序排列比正序排列更混乱，因此比较次数更多”的错误认知。这类学生可能混淆了“逆序对数量”与“快排比较次数”的关系，或者误以为逆序会导致更多的交换操作从而增加比较（实际上比较次数由划分过程决定，与交换无关）。
- **选项B**: [干扰] — 针对认为“正序已经有序，快排应该能优化”的错误认知。这类学生可能混淆了快速排序与插入排序（插入排序在正序时效率极高），或者误以为快排有检测有序性的机制。
- **选项C**: [正确] — 正确识别出在固定主元策略下，正序和逆序输入均导致最坏情况，且递归树结构完全同构，因此比较次数相等。
- **选项D**: [干扰] — 针对对算法确定性缺乏信心的学生，或者认为 n 的奇偶性会影响结果的错误认知。

- **干扰策略**: 概念混淆（混淆不同排序算法对有序数据的敏感性）与 反直觉陷阱（认为正逆序不对称）。

## 核心陷阱
**核心陷阱**: 误以为快速排序对“正序”和“逆序”的处理效率不同。
实际上，当主元固定选取第一个元素时：
1. 对于正序 `1, 2, ..., n`，主元 `1` 是最小值，划分后左子数组为空，右子数组为 `2, ..., n`。
2. 对于逆序 `n, n-1, ..., 1`，主元 `n` 是最大值，划分后左子数组为 `n-1, ..., 1`，右子数组为空。
这两种情况在递归深度、每层的比较次数（均为 $n-1, n-2, ..., 1$）上完全一致，只是左右子树的位置互换，不影响总的比较次数。

## 考察能力
考察对快速排序算法在最坏情况下时间复杂度成因的深刻理解，以及识别算法行为对称性的逻辑推理能力。
