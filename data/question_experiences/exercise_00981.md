# 练习题 Q1 — 信号量同步与进程执行序列推演

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/进程管理
- **难度**: 待评估

## 题干原文
考虑以下三个线程 T1、T2 和 T3 在单处理器上执行，使用三个二进制信号量变量 S1、S2 和 S3 进行同步，通过标准的 wait() 和 signal() 操作。线程可以在任何顺序和任何时间进行上下文切换。哪种信号量初始化方式会打印出序列 BCABCABCA…？

```c
// T1
while(true) {
    wait(S3);
    print("C");
    signal(S2);
}

// T2
while(true) {
    wait(S1);
    print("B");
    signal(S3);
}

// T3
while(true) {
    wait(S2);
    print("A");
    signal(S1);
}
```

- 选项:
  A: S1=1; S2=1; S3=1
  B: S1=1; S2=1; S3=0
  C: S1=1; S2=0; S3=0
  D: S1=0; S2=1; S3=1
- 正确答案: C
- 解析（参考）: 若初始时 S1 = 1，S2 = 0，S3 = 0，则进程 T2 可成功执行 wait(S1);，而 T1 和 T3 分别卡在 wait(S3); 和 wait(S2); 上。T2 打印 B 后执行 signal(S3)，随后卡在 wait(S1);（此过程中打印 B）。此时进程 T1 可成功执行 wait(S3);，然后打印“C”，接着执行 signal(S2); 并卡在 wait(S3);（此过程中打印 C）。之后进程 T3 可成功执行 wait(S2);，打印“A”，再执行 signal(S1); 并卡在 wait(S2);（此过程中打印 A）。此后 T2 又可成功执行 wait(S1);...
- 知识标签: ['操作系统/进程管理']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握信号量 wait/signal 的基本语义（P/V操作）以及二进制信号量的特性（互斥或同步）。不是4分因为不需要辨析复杂的死锁条件或优先级反转等高级概念，只需基础定义。
- **K2 = 1**: 评分理由。本题不涉及数值计算，仅涉及状态值的逻辑判断（0或1），无计算负担。
- **K3 = 4**: 评分理由。需要从初始状态开始，模拟至少一个完整周期（B->C->A）的执行流程。每一步都依赖上一步的状态改变（signal释放资源，wait阻塞进程），涉及多步串行推演，且需跟踪三个线程的状态变化，步骤超过5步且需记忆中间状态。
- **K4 = 3**: 评分理由。存在隐含前提：必须理解“单处理器”意味着同一时刻只有一个线程运行，且“任何顺序上下文切换”意味着只要信号量允许，线程即可运行。陷阱在于如果初始化不当（如全1），会导致并发竞争，输出序列不确定，而非固定的BCA循环。
- **K5 = 4**: 评分理由。三个线程通过信号量紧密耦合，T2的输出依赖T3的signal，T1依赖T2，T3依赖T1，形成闭环依赖。状态在三个子系统（线程）间传递，属于深度耦合的状态联动。
- **雷达形状**: K3-K5 高推演联动型（K3、K4、K5较高，K1中等，K2极低）

## 考察模式
- **模式**: 推理型
- **理由**: 题目不要求记忆特定公式或进行数值计算，而是要求考生根据给定的代码逻辑和信号量机制，推演系统在不同初始条件下的动态行为，并验证其是否符合目标序列。

## 选项级分析
- **选项A**: [干扰] — 针对“信号量全1表示无限制”的错误认知。若 S1=S2=S3=1，三个线程均可立即通过 wait 操作。由于是单处理器且调度顺序任意，可能出现 T1先运行打印C，或 T3先运行打印A，导致序列不固定为 BCA...，甚至可能出现乱序。这类学生可能认为全1是最“自由”的状态，忽略了同步约束。
- **选项B**: [干扰] — 针对“部分初始化”的模糊认知。S1=1, S2=1, S3=0。T2和T3可立即运行，T1阻塞。T2打印B后signal(S3)，T1可运行；T3打印A后signal(S1)，T2可再次运行。但初始时T3也能运行，可能导致先打印A，序列变为 ABC... 或 ACB...，无法保证以B开头。这类学生可能没注意到T3也能立即启动，破坏了B开头的确定性。
- **选项C**: [正确] — 唯一能强制确定执行顺序的初始化。S1=1 允许 T2 启动（打印B），S2=0 阻塞 T3，S3=0 阻塞 T1。T2 执行后 signal(S3) 唤醒 T1，T1 打印C后 signal(S2) 唤醒 T3，T3 打印A后 signal(S1) 唤醒 T2。形成严格的 B->C->A 循环。
- **选项D**: [干扰] — 针对“反向依赖”的误解。S1=0, S2=1, S3=1。T1和T3可立即运行，T2阻塞。T1打印C或T3打印A先发生，无法保证以B开头。这类学生可能混淆了信号量与线程的对应关系，或者误以为S1=0能阻止T2从而让其他线程先跑，但忽略了题目要求序列以B开头。

- **干扰策略**: 概念混淆（并发竞争导致的不确定性 vs 严格同步导致的确定性）

## 核心陷阱
- **核心陷阱**: 忽略“确定性序列”对初始状态的严格要求。考生容易误以为只要信号量不为0就能运行，而忽略了在单处理器环境下，若多个线程同时就绪，调度顺序的不确定性会导致输出序列不固定。只有当初始状态使得**仅有一个**线程就绪时，才能保证序列的起始字符固定，进而通过信号量传递保证后续顺序。

## 考察能力
本题核心考察考生对信号量同步机制的动态推演能力，以及在并发环境下通过初始状态控制执行顺序的逻辑分析能力。
