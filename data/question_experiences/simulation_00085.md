# 模拟题 Q综合题 — IPv4最长前缀匹配与子网划分

## 基本信息
- **来源**: 模拟题  **题型**: 综合题
- **科目**: 计算机网络
- **知识点**: CN-4 > IPv4 > 最长前缀匹配, CN-4 > 网络层设备 > 路由表, CN-4 > 网络层设备 > 分组转发
- **难度**: 中等

## 题干原文
（9 分）考虑某路由器具有下列路由表项：
网络前缀
142.150.64.0/24
142.150.71.128/28
142.150.71.128/30
142.150.0.0/16
​
下一跳
A
B
C
D
​
​
（1）假设路由器接收到一个目的地址为 142.150.71.132 的 IP 分组，请确定该路由器为该 IP 分组选择的下一跳，并解释说明。
（2）在上面的路由器表中增加一条路由表项，该路由表项使以 142.150.71.132 为目的地址的 IP 分组选择“A”作为下一跳，而不影响其他目的地址的 IP 分组转发。
（3）在上面的路由表中增加一条路由表项，使所有目的地址与该路由表中任何路由表项都不匹配的 IP 分组被转发到下一跳“E”。
（4）将 142.150.64.0/24 划分为 4 个规模尽可能大的等长子网，给出子网掩码及每个子网的可分配地址范围。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握CIDR、最长前缀匹配原则、默认路由概念以及子网划分的基本定义。属于标准的基础概念记忆，不涉及复杂概念辨析。
- **K2 = 3**: 评分理由。涉及IP地址与二进制转换、前缀长度计算、子网掩码计算。虽然2的幂次运算相对友好，但需要处理多位二进制比对和地址范围边界计算，存在一定计算量，属于标准难度。
- **K3 = 3**: 评分理由。第(1)问需对4个路由表项逐一进行前缀匹配比对，属于3-5步的串行推演；第(4)问需先确定借位位数，再计算掩码，最后列出4个子网的范围，步骤清晰但需多步执行。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。第(2)问要求“不影响其他”，意味着新增路由必须是原地址的超集或精确匹配且优先级更高，需深刻理解最长前缀匹配的优先级逻辑（/32 > /28 > /16等）；第(3)问考察默认路由的特殊表示法（0.0.0.0/0）；第(4)问需注意“可分配地址范围”需排除网络地址和广播地址，这是常见的暗坑。
- **K5 = 1**: 评分理由。本题完全局限于网络层IP路由与子网划分内部，不涉及传输层、应用层或链路层的跨域联动，属于单系统问题。
- **雷达形状**: 偏向K4（条件路由）和K2/K3（计算与推演）的均衡型，K1基础扎实，K5无跨域需求。整体呈现中间高、两端低的橄榄球状或菱形。

## 考察模式
- **模式**: 计算推导型
- **理由**: 题目核心在于通过二进制运算和逻辑比对，推导出具体的路由选择结果和子网参数。虽然包含概念解释，但主要得分点依赖于准确的数值计算和规则应用。

## 解题思路分析
- **核心思路**: 基于CIDR的最长前缀匹配原则（Longest Prefix Match）进行路由查找；利用子网划分原理（借位法）计算子网掩码和地址范围；掌握默认路由的特殊表示。
- **关键步骤**:
    1.  **路由查找**：将目的IP `142.150.71.132` 转换为二进制，依次与路由表中的网络前缀进行按位与运算或前缀比对。
        -   比对 `/16`: `142.150` 匹配。
        -   比对 `/24`: `142.150.64` vs `142.150.71`，不匹配。
        -   比对 `/28`: `142.150.71.128` 的前28位。`132` 的二进制 `10000100`，`128` 的二进制 `10000000`。前4位 `1000` 相同，匹配。
        -   比对 `/30`: `142.150.71.128` 的前30位。`132` 的第5位是 `0`，`128` 的第5位是 `0`，第6位 `132` 是 `1`，`128` 是 `0`。不匹配（或者更简单地：`128/30` 范围是 `128-131`，`132` 不在其中）。
        -   结论：匹配 `/28` 和 `/16`，选最长前缀 `/28`，下一跳 B。
    2.  **添加特定路由**：要使 `142.150.71.132` 走 A，且不影响其他。由于原表中 `/28` (B) 和 `/16` (D) 都匹配该地址，且 `/28` 优先级高于 `/16`。若要覆盖 B，需添加一个比 `/28` 更长的前缀，即 `/32`（主机路由）。添加 `142.150.71.132/32` 指向 A。因为 `/32` 最长，它将优先于 `/28` 被选中。对于其他地址，只要它们不是 `142.150.71.132`，就不会匹配 `/32`，从而保持原有转发行为。
    3.  **添加默认路由**：默认路由用于匹配所有未明确指定的地址。格式为 `0.0.0.0/0`，下一跳 E。
    4.  **子网划分**：
        -   原网络 `142.150.64.0/24`。
        -   划分为 4 个等长子网，需借 $\log_2 4 = 2$ 位。
        -   新掩码长度：$24 + 2 = 26$ 位。掩码：`255.255.255.192`。
        -   子网块大小：$2^{(32-26)} = 2^6 = 64$ 个地址。
        -   子网1: `142.150.64.0` - `142.150.64.63` (可用: `.1` - `.62`)
        -   子网2: `142.150.64.64` - `142.150.64.127` (可用: `.65` - `.126`)
        -   子网3: `142.150.64.128` - `142.150.64.191` (可用: `.129` - `.190`)
        -   子网4: `142.150.64.192` - `142.150.64.255` (可用: `.193` - `.254`)
- **易错点**:
    1.  二进制转换错误，导致前缀匹配判断失误。
    2.  第(2)问中，错误地添加 `/24` 或 `/16` 路由，这会改变其他地址的转发路径（违反“不影响其他”的条件）。必须使用 `/32`。
    3.  第(4)问中，忘记排除网络地址和广播地址，直接给出全范围。
    4.  默认路由写成 `255.255.255.255` 或其他错误形式。

## 核心陷阱
- **核心陷阱**: 第(2)问中的“不影响其他目的地址”约束。学生容易直觉地认为添加一个包含该IP的较大子网（如 `/24`）即可，但这会覆盖原有的 `/24` (A) 和 `/16` (D) 中属于该子网的其他IP，改变它们的下一跳。唯一解是使用精确的主机路由 `/32`，利用最长前缀匹配原则，仅针对该特定IP生效，对其他IP无干扰。

## 考察能力
本题核心考察考生对CIDR路由转发机制（最长前缀匹配）的深度理解、二进制地址运算能力以及子网划分的工程实践能力。
