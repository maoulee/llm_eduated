## 题干原文
考虑一个磁盘队列，请求访问柱面号为 47、38、121、191、87、11、92 和 10 的块。使用 C-LOOK 调度算法。初始时磁头位于柱面 63 号，正在向更高柱面号方向移动。柱面编号范围是 0 到 199。在服务这些请求时产生的总磁头移动量（以柱面数计算）是（ ）。
- 选项:
  A: 346
  B: 165
  C: 154
  D: 173
- 正确答案: A
- 解析（参考）: 磁头移动路径如下：
63 → 87（24 次移动）
87 → 92（5 次移动）
92 → 121（29 次移动）
121 → 191（70 次移动）
191 → 10（181 次移动）
10 → 11（1 次移动）
11 → 38（27 次移动）
38 → 47（9 次移动）
总磁头移动次数：

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。需要辨析 C-LOOK 与 LOOK、C-SCAN、SCAN 等易混概念。C-LOOK 的核心特征是“只访问有请求的柱面”且“循环时直接跳回最小请求柱面而非磁盘边界”。若仅记忆 SCAN 或 C-SCAN 的定义，极易出错。
- **K2 = 3**: 评分理由。涉及多次绝对值减法运算（如 |191-10|=181），虽然单步简单，但步骤多，容易在累加过程中出现算术错误，属于标准难度的计算。
- **K3 = 4**: 评分理由。推演步骤较多：1. 排序请求；2. 确定当前方向上的服务序列；3. 确定回跳后的服务序列；4. 分段计算距离并求和。整个过程需要保持中间状态（当前磁头位置、剩余请求集合），步骤超过5步。
- **K4 = 5**: 评分理由。存在极强的隐含前提和反直觉陷阱。
    1. **陷阱1（算法定义）**：C-LOOK 是“Circular LOOK”，它不像 C-SCAN 那样移动到磁盘物理边界（0或199），而是移动到**下一个方向上的最小/最大请求柱面**。
    2. **陷阱2（题目与解析的矛盾/特殊性）**：标准 C-LOOK 算法中，当磁头到达最大请求柱面（191）后，应直接跳回最小请求柱面（10），移动量为 |191-10|=181。解析中给出的路径 `191 -> 10` 符合 C-LOOK 定义。但是，如果学生误以为是 C-SCAN，会计算 `191 -> 199 -> 0 -> 10`，移动量巨大。如果误以为是 LOOK，则不会回跳。本题解析中的 `191 -> 10` 是 C-LOOK 的关键特征（直接跳跃）。然而，需注意有些教材或题目对 C-LOOK 的定义可能略有差异（是否包含边界），但主流 408 考点中 C-LOOK 不碰边界。本题解析明确展示了 `191->10` 的大跨度跳跃，这是区分 C-LOOK 和 C-SCAN 的核心。
- **K5 = 1**: 评分理由。纯操作系统内部 I/O 调度逻辑，不涉及文件系统、内存管理或其他子系统联动。
- **雷达形状**: K4 陷阱型（高 K1/K4，中高 K3）

## 考察模式
- **模式**: 综合型（概念辨析 + 多步计算）
- **理由**: 题目不仅要求考生记住 C-LOOK 的定义（概念），还需要根据定义构建具体的服务序列（推理），最后进行数值计算（计算）。任何一个环节出错都会导致答案错误。

## 选项级分析
- **选项 A (346)**: [正确] — 正确应用 C-LOOK 算法。路径：63→87→92→121→191 (正向服务完) → 10 (跳回最小请求) → 11→38→47 (反向服务完)。计算：(87-63)+(92-87)+(121-92)+(191-121) + (191-10) + (11-10)+(38-11)+(47-38) = 24+5+29+70 + 181 + 1+27+9 = 346。
