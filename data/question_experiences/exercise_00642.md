# 练习题 Q1 — 八进制小数转十进制

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机组成原理/数制
- **难度**: 待评估

## 题干原文
将八进制数 0.4051 转换为对应的十进制数（ ）。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆“八进制小数位权展开公式”这一核心定义。不记忆该公式无法入题，但无需辨析多个易混概念（如补码、移码等），属于标准的基础概念调用。
- **K2 = 4**: 评分理由。涉及非2的幂次（8的负幂）计算，且包含4项乘法与加法运算。虽然单步计算简单，但 $8^{-3}$ 和 $8^{-4}$ 的结果不是整数，需要处理小数除法或分数转换，计算量适中但容易因精度或计算失误出错，高于简单的2的幂次转换。
- **K3 = 3**: 评分理由。解题过程为串行推演：确定位权 -> 逐项相乘 -> 累加求和。共需4次乘法和3次加法，步骤在3-5步之间，属于标准的机制推演，无需记忆复杂的中间状态。
- **K4 = 2**: 评分理由。常规注意点。主要陷阱在于小数点的处理（整数部分为0，仅处理小数部分）以及位权的指数符号（负指数）。没有深层隐含前提或反直觉陷阱，属于常规的小数转换注意点。
- **K5 = 1**: 评分理由。单系统内部运算。仅涉及数制转换这一单一知识点，无需跨越不同子系统（如CPU、内存、I/O）传递数据或状态。
- **雷达形状**: K2计算型。K2（计算需求）和K3（推演步骤）相对较高，K1（概念）中等，K4（陷阱）和K5（跨域）较低。整体呈现以计算和步骤推演为主的特征。

## 考察模式
- **模式**: 计算型
- **理由**: 本题核心在于执行具体的数值转换计算，而非概念辨析或逻辑推理。考生必须准确执行位权展开和算术运算才能得出正确结果。

## 选项级分析
- **选项A**: [正确] — 精确计算结果。$4/8 + 0/64 + 5/512 + 1/4096 = 0.5 + 0 + 0.009765625 + 0.000244140625 = 0.510009765625$，四舍五入或截断后与选项匹配。
- **选项B**: [干扰] — 针对位权混淆或计算严重失误。可能是将八进制误当作十进制直接读取（0.4051），或者在计算 $4 \times 8^{-1}$ 时出错，亦或是完全错误的随机猜测。数值 0.2096 与正确答案差距较大，可能源于对位权指数符号的错误理解（如误用正指数但数值极小）或完全的计算混乱。
- **选项C**: [干扰] — 针对粗略估算或忽略低位。$0.4_8 = 0.5_{10}$，$0.40_8 = 0.5_{10}$，$0.405_8 \approx 0.51_{10}$。如果学生只计算前两位 $4 \times 8^{-1} + 0 \times 8^{-2} = 0.5$，然后粗略估计后面两位的影响，可能会误选接近 0.5 的选项。0.52 可能是将 $5 \times 8^{-3}$ 估算过大，或者误将八进制位权当作十进制位权进行某种错误加权。更可能的错误路径是：误以为 $0.4051_8$ 接近 $0.41_{10}$ 或其他错误换算。实际上，0.52 与 0.51 非常接近，可能是计算 $5/512$ 时出现数量级错误（如误算为 $5/100 \approx 0.05$ 导致总和偏大）。
- **选项D**: [干扰] — 针对位权指数错误。如果学生错误地认为小数点后第一位是 $8^0$ 或混淆了进制基数，可能会得到类似结果。例如，若误用十进制位权计算 $0.4051$，结果是 0.4051，不匹配。若误将八进制数当作二进制数转换（$0.100000101001_2$），结果会不同。0.4192 可能是将 $4 \times 8^{-1}$ 算对（0.5），但后续项计算出现严重偏差，或者混淆了八进制与十六进制的某些特性。另一种可能是计算 $4/8 + 5/64 + 1/512$（跳过了0位但指数错位），$0.5 + 0.078125 + 0.001953125 = 0.58...$ 也不对。最可能的错误是：将八进制小数直接按十进制理解并做了某种错误的缩放，或者在计算 $5 \times 8^{-3}$ 时误用 $8^{-2}$ 的位权（$5/64 = 0.078125$），$0.5 + 0.078125 = 0.578...$ 仍不匹配。实际上，0.4192 接近 $0.4 + 0.0192$，可能是将首位 4 当作 $4 \times 10^{-1}$ 处理，后续项也按十进制处理但基数错误。无论具体错误路径如何，它是一个典型的计算错误干扰项。

- **干扰策略**: 计算陷阱。选项B、C、D均通过提供与正确答案数量级相近但数值不同的结果，来捕捉学生在位权计算、小数点位置或算术运算中的细微错误。

## 核心陷阱
- **核心陷阱**: 非2的幂次小数位权的精确计算。学生容易在计算 $8^{-3}$ 和 $8^{-4}$ 时出现除法错误，或者在累加时忽略低位小数的贡献，导致结果精度不足。

## 考察能力
准确执行八进制小数到十进制小数的位权展开与算术运算能力。
