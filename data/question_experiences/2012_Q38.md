# 2012 Q38 — ARP协议功能定义

## 基本信息
- **年份**: 2012  **题位**: Q38  **题型**: 选择题
- **知识点**: CN-3 > 局域网 > ARP协议
- **题位域**: 待标注  **科目**: 计算机网络

## 题干原文
ARP 协议的功能是（ ）。

A. 根据 IP 地址查询 MAC 地址
B. 根据 MAC 地址查询 IP 地址
C. 根据域名查询 IP 地址
D. 根据 IP 地址查询域名

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。本题属于标准的基础概念记忆题。考生需要准确记忆 ARP（Address Resolution Protocol）的核心定义，即“地址解析”。虽然不需要辨析多个易混概念（如 RARP、DNS 等同时出现进行对比），但必须掌握“IP 到 MAC”这一核心映射关系，符合“需一个核心定义则3”的锚点。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全属于定性判断，计算需求微弱。
- **K3 = 1**: 评分理由。解题过程无需多步推演，直接调用定义即可得出结论，从输入（题干）到输出（选项）仅需一步认知匹配。
- **K4 = 1**: 评分理由。题干表述清晰，无隐含前提、无陷阱词、无反直觉逻辑。只要知道 ARP 是什么，就能直接选出答案，不存在需要避开暗坑的情况。
- **K5 = 1**: 评分理由。本题仅考察 ARP 协议本身的定义，未涉及与其他子系统（如 DNS、DHCP、路由协议）的状态传递或深度耦合，属于单系统内的概念考察。
- **雷达形状**: K1 主导型（基础概念型）。雷达图在 K1 维度突出，其余维度极低，呈现典型的“记忆/定义”特征。

## 考察模式
- **模式**: 概念型
- **理由**: 题目直接询问协议的功能定义，不涉及复杂场景应用、数值计算或逻辑推理，纯粹考察对计算机网络核心协议基本功能的记忆和理解。

## 选项级分析
- **选项A**: [正确] — 正确描述了 ARP 协议的核心功能：将网络层的 IP 地址解析为数据链路层的物理地址（MAC 地址）。
- **选项B**: [干扰] — 针对“反向地址解析协议（RARP）”的功能。这类学生可能混淆了 ARP 和 RARP 的方向，或者对“解析”一词的方向性理解模糊，误以为是从硬件地址查逻辑地址。
- **选项C**: [干扰] — 针对“域名系统（DNS）”的功能。这类学生可能将“地址解析”泛化，混淆了域名与 IP 的映射关系，未能区分不同层级（应用层 vs 网络/链路层）的地址解析协议。
- **选项D**: [干扰] — 针对“反向 DNS 查询”的功能。这类学生可能完全混淆了域名、IP 和 MAC 地址之间的层级关系，或者对网络分层模型缺乏清晰认知。
- **干扰策略**: 概念混淆。通过列举其他常见地址解析协议（RARP、DNS）的功能作为干扰项，考察考生对特定协议名称与其具体功能对应关系的精确记忆。

## 核心陷阱
- **核心陷阱**: 协议名称与功能方向的混淆。主要陷阱在于区分 ARP（IP→MAC）与 RARP（MAC→IP）以及 DNS（域名→IP）的功能差异，特别是容易记反 ARP 的解析方向。

## 考察能力
准确记忆并区分计算机网络中不同地址解析协议（ARP、RARP、DNS）的核心功能及作用层级。
