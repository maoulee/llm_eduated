# 练习题 Q1 — CPU调度算法周转时间计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
考虑以下一组进程，假设它们在时间 0 到达。考虑 CPU 调度算法最短作业优先（SJF）和轮转法（RR）。对于 RR，假设进程按 P1、P2、P3、P4 的顺序调度。如果 RR 的时间片为 4ms，则 SJF 和 RR 的平均周转时间（以ms为单位）的绝对差值（四舍五入到小数点后两位）是（  ）。
进程 P1 P2 P3 P4
执行时间（ms） 8 7 2 4

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆并区分 SJF（非抢占式，通常默认）和 RR（抢占式）的定义及周转时间计算公式。不是4分因为不涉及易混概念辨析（如SJF与SRTF的区别，题目未提及抢占，默认非抢占SJF是标准考法），只需调用核心定义。
- **K2 = 3**: 评分理由。涉及多次加法运算和除法求平均值。虽然不是复杂的数学公式，但数据量适中（4个进程），且RR调度中需要处理剩余时间的累加，计算步骤多于简单的单步代入，存在算错风险。
- **K3 = 4**: 评分理由。RR算法的推演需要多步串行执行。需要模拟时间片轮转的过程：P1运行4ms->P2运行4ms->P3运行2ms->P4运行4ms->P1剩余4ms->P2剩余3ms。每一步都需要更新当前时间和各进程剩余时间，步骤超过5步且需记忆中间状态（谁在队列中，剩余多少时间），符合K4-5的特征，此处定为4分。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。1. SJF默认是非抢占式的（除非特别说明SRTF）；2. RR的初始队列顺序由题目给定（P1, P2, P3, P4），而非按到达时间或ID排序（虽然本题同时到达，但顺序指定很重要）；3. 周转时间=完成时间-到达时间（本题到达时间为0，故等于完成时间）。这些是常规考点，非深层隐含前提。
- **K5 = 1**: 评分理由。本题仅涉及CPU调度子系统内部的状态流转，不涉及内存、I/O或其他子系统的状态传递。

- **雷达形状**: K3推演主导型（K3较高，K1/K2中等，K4有轻微陷阱，K5极低）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过模拟调度过程，计算具体的数值（周转时间），最终通过算术运算得出答案。虽然需要理解算法逻辑，但最终落脚点是精确计算。

## 选项级分析
- **选项A (5.0)**: [干扰] — 针对计算错误或概念混淆。可能源于RR调度模拟错误，例如错误地认为P3在P1之前运行，或者在计算RR完成时间时漏掉了某些时间片。也可能是SJF计算错误。
- **选项B (5.25)**: [正确] — SJF平均周转时间10.5，RR平均周转时间15.75，差值5.25。
- **选项C (5.50)**: [干扰] — 针对RR调度顺序或时间片处理错误。例如，如果在RR中错误地处理了P3（运行2ms后直接结束，但可能错误地认为它占用了完整时间片导致后续进程延迟计算错误），或者在SJF中排序错误（如按P1, P2, P4, P3而非按长度排序）。
- **选项D (5.75)**: [干扰] — 针对RR调度中队列管理错误。例如，在RR中，当P3运行完2ms后，队列中剩余P4, P1, P2。如果错误地将P1再次放入队尾的位置搞错，或者在计算P2的完成时间时出错，可能导致平均周转时间偏差，从而产生此选项。

- **干扰策略**: 计算陷阱（RR模拟步骤多，易出错）+ 概念混淆（SJF排序规则）

## 核心陷阱
- **核心陷阱**: RR算法的队列动态变化与时间片剩余处理。
  1. **SJF排序**: 必须按执行时间升序排列：P3(2) -> P4(4) -> P2(7) -> P1(8)。很多学生容易忽略排序，直接按P1-P4顺序计算SJF，导致SJF平均周转时间算错。
  2. **RR模拟细节**: 
     - 初始队列: [P1, P2, P3, P4]
     - T=0-4: P1运行4ms (剩4), 队列: [P2, P3, P4, P1]
     - T=4-8: P2运行4ms (剩3), 队列: [P3, P4, P1, P2]
     - T=8-10: P3运行2ms (剩0, 完成), 队列: [P4, P1, P2]  *(注意：P3只用了2ms，不占满时间片，不重新入队)*
     - T=10-14: P4运行4ms (剩0, 完成), 队列: [P1, P2]
     - T=14-18: P1运行4ms (剩0, 完成), 队列: [P2]
     - T=18-21: P2运行3ms (剩0, 完成), 队列: []
     - 完成时间: P1=18, P2=21, P3=10, P4=14。
     - 易错点：P3运行结束后，是否错误地认为它占用了4ms导致时间轴偏移？或者P1第二次运行时剩余时间计算错误？

## 考察能力
本题核心考察考生对CPU调度算法（SJF和RR）执行过程的精确模拟能力，以及在多步推演中保持状态一致性和计算准确性的能力。
