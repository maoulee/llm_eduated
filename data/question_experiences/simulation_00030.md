# 模拟题 Q1 — 磁盘交叉存取与传输率计算

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: OS-5 > 5.3 磁盘组织与管理 > 磁盘访问时间, OS-5 > 5.3 磁盘组织与管理 > 磁盘数据传输率
- **难度**: 待评估

## 题干原文
一个交叉存放信息的磁盘，信息存放方式如图所示，磁盘旋转方向为逆时针方向。每个磁道有 8 个扇区，每个扇区 512 字节，旋转速度为 3000 转/分。假定磁头已在读取信息的磁道上，0 扇区转到磁头下需要 1/2 转，且设备对应的控制器不能同时进行输入/输出，在数据从控制器传送至内存的这段时间内，从磁头下通过的扇区数为 2，问依次读取一个磁道上所有的扇区所需时间和该磁盘的数据传输速度依次是（ ）。
- 选项:
  A: 0.07s，58.5KB/s
  B: 0.07s，57.1KB/s
  C: 0.08s，57.1KB/s
  D: 0.08s，58.5KB/s
- 正确答案: A
- 解析（参考）: 【解析】
本题考查磁盘读取的速度。首先注意磁盘旋转方向为逆时针方向，对于磁头和磁盘的运动实际上是磁头不动，磁盘转的，而磁盘逆时针方向旋转按扇区来看即 0、3、6……这个顺序。而每个号码连续的扇区正好相隔 2 个扇区，即是数据从控制器传送到内存的时间，所以相当于磁头连续工作。
由题中条件知，旋转速度为 3000 转/分 = 50 转/秒，即 20ms/转。
读一个扇区需要时间为 20/8 = 2.5ms。
读一个扇区并将扇区数据送入内存需要时间为 2.5 × 3 = 7.5ms。
读出一个磁道上的所有扇区需要时间为 20/2 + 8 × 7.5 = 70ms = 0.07s。
每磁道数据量为 8
- 知识标签: ['OS-5 > 5.3 磁盘组织与管理 > 磁盘访问时间', 'OS-5 > 5.3 磁盘组织与管理 > 磁盘数据传输率']
- 知识域: OS-5

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握磁盘旋转速度、扇区大小、平均寻道时间（本题简化为固定等待）、数据传输率等基础概念。不是4分因为不需要辨析多个易混的高级概念，核心定义明确。
- **K2 = 4**: 评分理由。涉及多级单位换算（RPM转ms，字节转KB）以及非整数倍的计算（512*8/0.07）。计算步骤较多，且最终结果58.5KB/s并非整数，容易因精度或单位换算错误导致偏差。
- **K3 = 4**: 评分理由。解题过程包含多个串行步骤：1.计算旋转周期；2.计算单扇区读取时间；3.理解“传送期间通过2个扇区”意味着逻辑扇区间隔为3个物理扇区位置（读取1个+传送占用2个位置）；4.计算总时间（初始等待+8个扇区的连续读取时间）；5.计算传输率。步骤超过3步，且需保持中间状态（如每个逻辑扇区占用的时间窗口）。
- **K4 = 5**: 评分理由。存在极深的隐含前提和反直觉陷阱。
    1. **交叉存取的隐含逻辑**：题目未直接给出扇区编号图，但通过“传送期间通过2个扇区”暗示了物理扇区与逻辑扇区的映射关系。考生必须意识到，为了连续读取，逻辑上相邻的扇区在物理上必须间隔开，间隔大小等于“读取时间+传送时间”对应的扇区数。
    2. **“连续工作”的判定**：题目说“相当于磁头连续工作”，这意味着没有额外的旋转等待时间（Rotational Latency）在扇区之间。如果考生误以为每个扇区读完都要重新等待，或者误解了“通过2个扇区”的含义，就会陷入死胡同。
    3. **初始等待时间**：题目明确给出“0扇区转到磁头下需要1/2转”，这是一个特定的初始条件，而非平均等待时间（1/4转），容易混淆。
- **K5 = 2**: 评分理由。主要涉及磁盘子系统内部的时间计算，虽然提到了“控制器传送至内存”，但这只是作为确定扇区间隔的条件，并未涉及内存管理、CPU调度等其他子系统的状态交互，属于单向的条件引用。
- **雷达形状**: K4陷阱型（高K4，中高K2/K3）。本题的核心难点不在于计算复杂度，而在于对磁盘交叉存取机制和题目隐含条件的深度解读。

## 考察模式
- **模式**: 综合型
- **理由**: 本题结合了概念理解（交叉存取原理）、机制推演（扇区间隔与传送时间的关系）以及精确计算（时间与速率）。它不是单纯的概念记忆，也不是简单的公式代入，而是需要构建一个完整的磁盘读取时序模型。

## 选项级分析
- **选项A**: [正确] — 正确计算了总时间0.07s和传输率58.5KB/s。
- **选项B**: [干扰] — 时间正确，但传输率计算错误。可能使用了错误的单位换算（如将512B误算，或除法精度问题），或者使用了错误的总数据量。57.1KB/s接近 4096/0.0714，可能是误用了平均等待时间或其他错误的时间分母。
- **选项C**: [干扰] — 时间错误（0.08s），传输率错误。0.08s可能是误将初始等待时间算错，或者误以为每个扇区之间有额外的等待时间。例如，如果误认为每个扇区读取后需要等待1个扇区的时间，总时间会增加。
- **选项D**: [干扰] — 时间错误（0.08s），传输率正确。这种组合通常出现在考生正确计算了传输率（可能通过总数据/总时间反推，或者巧合），但在时间计算上犯了系统性错误，比如忽略了交叉存取带来的“连续工作”特性，而是按非交叉存取计算（即每个扇区读完都要等下一个扇区转到磁头下，但这在交叉存取中是不成立的，或者反之）。更可能的情况是，考生正确理解了交叉存取，但在计算总时间时，错误地加上了额外的旋转延迟，或者对“1/2转”的理解有误（例如误以为是平均等待时间1/4转，但1/4转是5ms，5+60=65ms=0.065s，也不对）。另一种可能是误将“通过2个扇区”理解为间隔2个扇区（即间隔3个物理位置），但计算总时间时逻辑混乱。实际上，0.08s = 80ms。如果初始等待是1/2转(10ms)，剩下70ms。如果考生误以为每个扇区占用时间是 20/8 * (1+2) = 7.5ms，8个扇区60ms，总共70ms。如果考生误以为每个扇区读取后还需要等待，或者对“通过2个扇区”理解偏差，可能导致时间计算偏差。
- **干扰策略**: 计算陷阱与概念混淆。主要利用单位换算的细微差别（KB vs kB, 1000 vs 1024，虽然本题中58.5暗示使用1000进制或近似值，408通常1KB=1024B，但此处512*8=4096B=4KB。4KB/0.07s ≈ 57.14 KB/s (若1KB=1024B)。等等，让我们重新核算一下标准答案的逻辑。
    *   总数据量 = 8 * 512 B = 4096 B = 4 KB (1KB=1024B)。
    *   总时间 = 0.07 s。
    *   传输率 = 4 KB / 0.07 s ≈ 57.14 KB/s。
    *   **注意**：参考答案给的是A (58.5KB/s)。让我们检查58.5的来源。
    *   如果 1KB = 1000B (SI单位)，则 4096 B = 4.096 KB。 4.096 / 0.07 ≈ 58.51 KB/s。
    *   **关键点**：408考研中，通常 1KB = 1024B。但在某些模拟题或特定语境下，可能会混用。或者，题目中的“58.5”是基于 1KB=1000B 计算的。而 57.1 是基于 1KB=1024B 计算的 (4/0.07 = 57.14)。
    *   如果按照408标准（1KB=1024B），答案应该是 57.1KB/s，即选项B。
    *   但是参考答案选A。这说明该模拟题可能采用了 1KB=1000B 的标准，或者题目数据有微调。
    *   **修正分析**：在408真题中，通常严格区分。如果这是模拟题，可能存在出题不严谨。但根据选项分布，A和D是58.5，B和C是57.1。这明显是在考察 **KB的定义** 或者 **计算精度**。
    *   如果按照 1KB=1024B，4096B = 4KB。4/0.07 = 57.14。选B。
    *   如果按照 1KB=1000B，4096B = 4.096KB。4.096/0.07 = 58.51。选A。
    *   **通常408考试中，存储容量计算 1KB=1024B，但数据传输率有时会用 10^3 进制，或者题目会明确说明。若无说明，408惯例倾向于 1024。但此处参考答案为A，暗示本题可能遵循 1KB=1000B 或出题人计算习惯。**
    *   **干扰策略更新**：本题最大的干扰在于 **KB的定义** 以及 **时间计算的准确性**。选项B是针对使用 1KB=1024B 的学生的“正确”答案（在标准408语境下），而选项A是针对使用 1KB=1000B 或特定计算路径的答案。鉴于参考答案是A，我们需要指出这一点。

## 核心陷阱
1.  **交叉存取的物理间隔推导**：必须理解“传送期间通过2个扇区”意味着逻辑扇区 $i$ 和 $i+1$ 在物理位置上相隔 $1(\text{读取}) + 2(\text{传送占用}) = 3$ 个扇区的位置。因此，读取一个逻辑扇区并准备好读取下一个逻辑扇区，磁盘需要旋转 $3/8$ 圈。
2.  **总时间的构成**：总时间 = 初始等待时间（1/2转） + 8个逻辑扇区的连续读取时间。由于是交叉存取且设计合理，扇区之间没有额外的旋转等待，所以是 $8 \times (3/8 \text{转}) = 3 \text{转}$ 的时间？不对。
    *   单扇区读取时间 $T_{read} = 1/8$ 转。
    *   传送时间 $T_{trans} = 2/8$ 转（通过2个扇区）。
    *   所以，处理一个逻辑扇区（读+传）占用的磁盘旋转时间是 $T_{read} + T_{trans} = 3/8$ 转。
    *   8个扇区总共占用 $8 \times 3/8 = 3$ 转。
    *   初始等待 $1/2$ 转。
    *   总转数 = $0.5 + 3 = 3.5$ 转。
    *   总时间 = $3.5 \times 20\text{ms} = 70\text{ms} = 0.07\text{s}$。
    *   这个推导验证了时间的正确性。
3.  **KB的定义陷阱**：如前所述，57.1 vs 58.5 的区别在于 1KB 是 1024B 还是 1000B。在408中，这通常是一个争议点或特定约定。如果参考答案是A，则必须按 1KB=1000B 计算，或者题目隐含了此条件。
