# 练习题 Q1 — 信号量PV操作与状态推演

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/进程管理
- **难度**: 待评估

## 题干原文
有三个进程 P1、P2 和 P3 共享一个信号量以同步某个变量。
信号量的初始值为 1。假设信号量的负值表示当前有多少个进程在等待队列中。
进程按以下顺序访问该信号量：
(a) P2 需要访问
(b) P1 需要访问
(c) P3 需要访问
(d) P2 退出临界区
(e) P1 退出临界区
最终信号量的值将是（ ）。
- 选项:
  A: 0
  B: 1
  C: -1
  D: -2
- 正确答案: A
- 解析（参考）: 解析过程
：
初始值 S = 1
P2 访问时，S -= 1 → S = 0（无进程等待）
P1 访问时，S -= 1 → S = -1（1 个进程等待）
P3 访问时，S -= 1 → S = -2（2 个进程等待）
P2 退出时，S += 1 → S = -1（1 个进程等待）
P1 退出时，S += 1 → S = 0（无进程等待）
结论
：最终信号量值为 0，因此选项 (A) 正确。
- 知识标签: ['操作系统/进程管理']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握信号量（Semaphore）的核心定义，特别是 P操作（wait/down）和 V操作（signal/up）对信号量值的具体影响规则（S-1 和 S+1），以及信号量值正负号的物理意义。这属于操作系统进程同步中的标准核心概念，非微弱记忆，但也无需辨析多个易混概念。
- **K2 = 2**: 评分理由。计算过程仅为简单的整数加减法（1-1-1-1+1+1），不涉及复杂的数学公式、幂次运算或多级单位换算，计算出错概率极低。
- **K3 = 3**: 评分理由。题目给出了5个离散的时间步骤（a-e），考生需要按照时间顺序串行执行5次状态更新。每一步的状态依赖于上一步的结果，属于典型的3-5步串行推演，需要保持中间状态的准确性。
- **K4 = 2**: 评分理由。题干逻辑清晰，没有明显的隐含前提或反直觉陷阱。唯一的“注意点”是理解“退出临界区”对应的是V操作（S+1），而“需要访问”对应的是P操作（S-1），这是常规考点，不属于深层陷阱。
- **K5 = 1**: 评分理由。本题完全局限于操作系统进程管理模块内的信号量机制，不涉及内存管理、文件系统或I/O等其他子系统的状态传递或耦合。

- **雷达形状**: K3推演主导型（K1基础扎实，K3步骤清晰，K2/K4/K5较低）

## 考察模式
- **模式**: 推理型
- **理由**: 虽然涉及数值计算，但核心不在于计算本身，而在于根据进程行为的时序逻辑，推理出信号量状态的变化轨迹。考生必须理解“访问”与“退出”在信号量机制下的语义映射，并按顺序执行逻辑推演。

## 选项级分析
- **选项A**: [正确] — 正确执行了5步PV操作：P2(P)→0, P1(P)→-1, P3(P)→-2, P2(V)→-1, P1(V)→0。
- **选项B**: [干扰] — 针对认为“信号量值永远非负”或“最后两个V操作抵消了所有P操作且初始值保留”的错误认知。可能误以为P3的访问被阻塞后不计入信号量值的减少，或者错误地认为V操作会将信号量恢复到初始值1。
- **选项C**: [干扰] — 针对漏算最后一步V操作，或误以为P3退出（题目未提及P3退出）的情况。如果考生只计算到P2退出，或者忘记P1退出后的V操作，会得到-1。
- **选项D**: [干扰] — 针对只计算了P操作（进入临界区），完全忽略V操作（退出临界区）的情况。即 1 - 1 - 1 - 1 = -2。这类学生可能只关注了“需要访问”的动作，忽略了“退出”对信号量的释放作用。

- **干扰策略**: 计算陷阱（漏算步骤）与概念混淆（忽略V操作的作用）

## 核心陷阱
- **核心陷阱**: 忽略“退出临界区”对应的V操作（S+1）。许多初学者容易只关注进程进入临界区时的阻塞（P操作导致S减小），而忘记进程离开时会对信号量进行释放（V操作导致S增大），从而错误地选择D。

## 考察能力
一句话概括本题核心考察的能力：准确理解信号量PV操作的语义，并能按时序逻辑正确推演多进程并发下的信号量状态变化。
