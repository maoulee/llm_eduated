# 2019 Q41 — 链表重排与原地逆置

## 基本信息
- **年份**: 2019  **题位**: Q41  **题型**: 综合题
- **知识点**: DS-2 > 2.3 链表的链式表示 > 链表共同概念, DS-2 > 2.3 链表的链式表示 > 链表类型与结构, DS-2 > 2.3 链表的链式表示 > 结点指针域, DS-2 > 2.3 链表的链式表示 > 头结点
- **题位域**: 待标注  **科目**: 数据结构

## 题干原文
设线性表 $L=(a_1, a_2, a_3, \cdots, a_{n-1}, a_n)$ 采用带头结点的单链表保存，链表中的结点定义如下：
```c
typedef struct node {
    int data;
    struct node *next;
} NODE;
```
请设计一个空间复杂度为 $O(1)$ 且时间上尽可能高效的算法，重新排列 $L$ 中的各结点，得到线性表 $L'=(a_1, a_n, a_2, a_{n-1}, a_3, a_{n-2}, \cdots)$。要求：
(1) 给出算法的基本设计思想。
(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
(3) 说明你所设计算法的时间复杂度。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握单链表的基本结构、头结点概念、快慢指针找中点、链表逆置等核心数据结构概念。不是4分因为不需要辨析多个易混的高级概念，属于数据结构基础核心考点。
- **K2 = 2**: 评分理由。本题不涉及数值计算，主要是指针操作。指针赋值和移动属于基础操作，单步出错概率低，但逻辑组合较多。
- **K3 = 4**: 评分理由。解题过程包含三个主要串行步骤：1. 快慢指针找中点；2. 后半段链表原地逆置；3. 前后两段交替合并。每一步内部又有循环和指针调整，整体推演步骤超过5步，且需要维护多个指针状态（p, q, pre, curr等），中间状态记忆要求较高。
- **K4 = 4**: 评分理由。存在多个隐含前提和陷阱：1. 必须处理“带头结点”的情况，头结点不参与数据重排；2. 找中点时，奇偶长度链表的中点位置不同，需确保后半段逆置正确；3. 逆置时需注意断链，防止丢失后续节点；4. 合并时需注意后半段可能比前半段多一个节点（奇数长度情况），需处理剩余节点。这些细节若未意识到会导致算法错误。
- **K5 = 3**: 评分理由。主要在单链表这一子系统内操作，但需要在“找中点”、“逆置”、“合并”三个子任务间传递状态（如中点指针、逆置后的头指针）。虽然未跨越不同数据结构模块，但子任务间耦合紧密，状态传递是关键。
- **雷达形状**: 呈不规则多边形，K3和K4较高，K1中等，K2较低，K3/K4突出，显示本题重在逻辑推演和细节处理。

## 考察模式
- **模式**: 算法设计型
- **理由**: 题目要求设计一个满足特定时间/空间复杂度约束的算法，并给出设计思想、代码实现和复杂度分析，是典型的算法设计题。

## 解题思路分析
- **核心思路**: 将问题分解为三个子问题：定位中点、逆置后半段、交替合并。利用快慢指针在 $O(n)$ 时间内找到中点，利用头插法或指针反转在 $O(1)$ 空间内逆置后半段，最后双指针交替插入完成重排。
- **关键步骤**:
    1.  **找中点**: 使用快慢指针 `slow` 和 `fast`，`slow` 每次走一步，`fast` 每次走两步。当 `fast` 到达末尾时，`slow` 指向中点（或中点前一个，取决于实现细节，通常让 `slow` 指向后半段起始位置的前驱，方便断开）。
    2.  **断链与逆置**: 将链表从中点断开，得到两个子链表。对后半段子链表进行原地逆置（头插法或指针反转法）。
    3.  **合并**: 使用两个指针分别指向前半段和逆置后的后半段的第一个数据节点。依次将后半段的节点插入到前半段对应节点之后，直到后半段为空。
- **易错点**:
    1.  忽略头结点，导致头结点被错误地参与重排或丢失。
    2.  找中点时，对于偶数长度链表，中点划分错误，导致前后段长度不均或逆置错误。
    3.  逆置时未正确保存 `next` 指针，导致链表断裂。
    4.  合并时未处理奇数长度链表后半段多出一个节点的情况，导致该节点丢失或形成环。
    5.  空间复杂度未严格控制在 $O(1)$，例如使用了递归或额外数组。

## 核心陷阱
- **核心陷阱**: **奇偶长度链表的中点处理与合并终止条件**。当链表长度为奇数时，前半段比后半段多一个节点，合并循环结束后，后半段指针可能不为空（如果逆置逻辑或合并逻辑不当），或者前半段指针提前为空。必须确保合并逻辑能正确处理后半段剩余节点（如果有）或自然终止。此外，**头结点的处理**是另一个常见陷阱，头结点不应被移动或逆置，仅作为链表的入口。

本题核心考察考生对单链表指针操作的熟练程度、分治思想的应用能力以及在严格空间复杂度约束下设计高效算法的逻辑思维能力。
