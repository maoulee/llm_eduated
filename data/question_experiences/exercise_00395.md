# 练习题 Q1 — 嵌套循环时间复杂度分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/算法分析
- **难度**: 待评估

## 题干原文
函数 `fun()` 的时间复杂度是多少？（ ）
```c
int fun(int n) {
    int count = 0;
    for (int i = n; i > 0; i /= 2)
        for (int j = 0; j < i; j++)
            count += 1;
    return count;
}
```
- 选项:
  A: $O(n^2)$
  B: $O(n \times \log(n))$
  C: $O(n)$
  D: $O(n \times \log(n \times \log_2 n))$
- 正确答案: C
- 解析（参考）: 这是一个嵌套循环，外层是一个以 2 为因子的递减（即对数级别），内层是线性地跑 $j < i$。
我们可以将整个过程看成：
第1轮：$i = n$，执行 $n$ 次
第2轮：$i = n/2$，执行 $n/2$ 次
第3轮：$i = n/4$，执行 $n/4$ 次
…
直到 $i <= 0$
因此，总执行次数是：
$n + \frac{n}{2} + \frac{n}{4} + \dots + 1$
这是一个等比数列，其和趋近于：
$n(1 + \frac{1}{2} + \frac{1}{4} + \dots) = 2n$
所以函数 `fun(n)` 的时间复杂度是 $O(n)$。
- 知识标签: ['数据结构/算法分析']
- 知识域: DS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握时间复杂度的基本定义、大O表示法以及等比数列求和公式。不是2分因为仅靠直觉无法准确判断嵌套循环的总次数，需要调用“等比数列收敛”这一核心数学概念。
- **K2 = 2**: 评分理由。计算过程相对简单，主要是识别出 $n, n/2, n/4...$ 的序列并求和。2的幂次友好，不涉及复杂的代数变换或多级换算，不易算错。
- **K3 = 2**: 评分理由。推演步骤较少：1. 分析外层循环变量变化；2. 分析内层循环执行次数与外层变量的关系；3. 累加求和。属于标准的2-3步串行推演，无需记忆大量中间状态。
- **K4 = 3**: 评分理由。存在常规注意点/陷阱。许多学生会惯性思维认为“嵌套循环=乘法”，从而误选 $O(n \log n)$ 或 $O(n^2)$。需要识别出内层循环次数随外层递减这一隐含前提，避开“直接相乘”的陷阱。
- **K5 = 1**: 评分理由。单系统问题。仅涉及单一函数内的循环结构分析，无需跨越不同子系统或模块传递状态。
- **雷达形状**: K4陷阱型（K4略高，其余较低，呈现轻微凸起，主要考察对常见陷阱的规避能力）

## 考察模式
- **模式**: 推理型
- **理由**: 本题不能通过简单的公式代入直接得出答案，需要考生通过逻辑推理，分析循环变量的变化规律，构建数学模型（等比数列），进而推导出总执行次数的渐近界。

## 选项级分析
- **选项A**: [干扰] — 针对“完全忽略外层循环递减特性”的错误认知。这类学生可能误以为内层循环每次都执行 $n$ 次，或者将两层循环简单视为 $n \times n$ 的暴力枚举，属于基础概念混淆。
- **选项B**: [干扰] — 针对“机械套用嵌套循环复杂度公式”的错误认知。这是最强的干扰项。学生知道外层是 $O(\log n)$，内层是 $O(n)$，于是直接相乘得到 $O(n \log n)$。这类学生没有深入分析内层循环次数是动态变化的，而是将其视为常数或最大值。
- **选项C**: [正确] — 正确识别了内层循环次数随外层递减，构成等比数列，总和收敛于 $2n$，故为 $O(n)$。
- **选项D**: [干扰] — 针对“过度复杂化”或“公式乱凑”的错误认知。这类学生可能对对数运算不熟悉，试图通过复杂的对数组合来凑出一个看起来“高级”的答案，或者在计算过程中出现了严重的代数错误。
- **干扰策略**: 概念混淆（主要利用“嵌套循环通常复杂度相乘”的刻板印象）与计算陷阱（诱导学生忽略变量依赖性）。

## 核心陷阱
- **核心陷阱**: **“嵌套循环复杂度直接相乘”的刻板印象**。
  考生容易看到两层循环，外层 $O(\log n)$，内层看似 $O(n)$，便直接得出 $O(n \log n)$。实际上，内层循环的执行次数依赖于外层循环变量 $i$，且 $i$ 在快速减小，导致总次数并非乘积关系，而是等比数列求和关系。

## 考察能力
一句话概括本题核心考察的能力：
**能够突破“嵌套循环即乘法”的思维定势，通过动态分析循环变量依赖关系，利用等比数列求和准确评估非均匀嵌套循环的时间复杂度。**
