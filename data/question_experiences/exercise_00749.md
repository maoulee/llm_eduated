# 练习题 Q1 — 数组循环移位与取模运算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/数组
- **难度**: 待评估

## 题干原文
考虑以下程序，该程序基本上在做什么？
```cpp
#include<bits/stdc++.h>
using namespace std;
void print(char a[], int n, int ind)
{
    for (int i = ind; i < n + ind; i++)
        cout << a[(i % n)] << " ";
}
int main()
{
    char a[] = {'A', 'B', 'C', 'D', 'E', 'F'};
    int n = sizeof(a) / sizeof(a[0]);
    print(a, n, 3);
    return 0;
}
```
- 选项:
  A: 它正在打印普通数组
  B: 它正在打印循环右移 3 位的数组
  C: 语法错误
  D: 无
- 正确答案: B
- 解析（参考）: 在上述程序中，我们只是将数组元素循环右移 3 位。循环从 i=3 运行到 9，在循环内部：
a[3%6] = a[3] = 'D'
a[4%6] = a[4] = 'E'
a[5%6] = a[5] = 'F'
a[6%6] = a[0] = 'A'
a[7%6] = a[1] = 'B'
a[8%6] = a[2] = 'C'
因此选项 (B) 正确。
- 知识标签: ['数据结构/数组']
- 知识域: DS-1

## K1-K5 评分与解析
- **K1 = 2**: 评分理由。需要掌握数组下标访问、`sizeof` 运算符以及取模运算 `%` 的基本概念。不需要记忆复杂的数据结构定义，属于基础语法和运算规则的记忆调用。不是1分因为需要理解 `sizeof` 在数组名作为参数传递时的行为（虽然这里是在 main 中计算，但也涉及数组长度概念）以及取模在索引中的作用。
- **K2 = 3**: 评分理由。需要进行具体的数值代入计算。计算 `n=6`，循环范围 `i` 从 3 到 8（注意 `< n+ind` 即 `<9`，所以是 3,4,5,6,7,8 共6次），并计算 `i % 6` 的值。涉及非2的幂次的取模运算，且需要多次执行，容易在边界或中间步骤出错。
- **K3 = 3**: 评分理由。从输入到输出需要多步串行推演。步骤包括：1. 确定数组长度 n；2. 确定循环起始和终止条件；3. 逐次计算索引 `i % n`；4. 映射到数组元素；5. 观察输出序列规律。总共约 6 次迭代，属于中等复杂度的推演。
- **K4 = 3**: 评分理由。存在隐含前提和易错点。陷阱在于理解 `i % n` 如何实现“循环”效果，以及循环边界 `i < n + ind` 确保恰好打印 n 个元素。如果学生不熟悉取模运算在循环缓冲中的应用，可能会误以为会越界或打印错误数量。属于常规注意点但需警惕陷阱。
- **K5 = 1**: 评分理由。单系统问题。仅涉及数组和简单的算术运算，没有跨越不同子系统或模块的状态传递。

- **雷达形状**: K3/K4 主导型（推演与陷阱并重），K2 中等，K1/K5 较低。

## 考察模式
- **模式**: 推理型
- **理由**: 本题不是单纯的概念记忆，也不是复杂的数学计算，而是要求考生通过模拟代码执行过程（Trace），理解取模运算在数组索引中的逻辑意义，从而推导出程序的整体行为（循环移位）。

## 选项级分析
- **选项A**: [干扰] — 针对认为 `ind` 参数无效或取模运算不起作用的学生。这类学生可能忽略了 `i` 从 `ind` 开始，或者误以为 `i % n` 总是等于 `i`（当 `i < n` 时），从而认为只是打印了数组的一部分或原样打印。
- **选项B**: [正确] — 正确识别了 `i % n` 实现的循环索引机制，以及起始偏移量 `ind` 导致的右移效果。
- **选项C**: [干扰] — 针对对 C++ 语法不熟悉的学生。可能误以为 `sizeof(a)/sizeof(a[0])` 在函数参数中无效（虽然这里是在 main 中，但学生可能混淆），或者认为 `char` 数组初始化方式有误。实际上语法完全正确。
- **选项D**: [干扰] — 针对完全无法理解代码逻辑，或者认为输出结果无规律的学生。

- **干扰策略**: 概念混淆（A与B之间，是否理解循环移位）、语法误判（C）、逻辑放弃（D）。

## 核心陷阱
- **核心陷阱**: 对 `i % n` 在循环索引中作用的误解，以及循环边界 `i < n + ind` 的理解。学生可能没有意识到 `i` 会超过 `n-1`，从而担心越界，或者没有意识到取模运算会将超过 `n-1` 的索引“折返”到数组开头，形成循环效果。

## 考察能力
一句话概括本题核心考察的能力：通过模拟代码执行，理解取模运算在实现数组循环访问（循环缓冲区）中的逻辑机制。
