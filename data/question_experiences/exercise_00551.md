# 练习题 Q1 — 硬盘CHS地址线性化计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 计算机组成原理/存储系统
- **难度**: 待评估

## 题干原文
一个硬盘每条磁道有 63 个扇区，每个盘片有 2 个记录面，共有 10 个盘片和 1000 个柱面。扇区的地址表示为三元组 (c, h, s)，其中 c 是柱面号，h 是表面号，s 是扇区号。因此，第 0 个扇区的地址为 (0, 0, 0)，第 1 个扇区为 (0, 0, 1)，依此类推。
地址<400,16,29>对应的扇区号是（ ）：
- 选项:
  A: 505035
  B: 505036
  C: 505037
  D: 505038
- 正确答案: C
- 解析（参考）: 解析
硬盘中的数据按如下方式排列。最小的存储单位是扇区。多个扇区组合成一条磁道。柱面由位于相同半径位置的磁道组合而成。
读写头访问磁盘时，需要先移动到特定磁道，然后等待盘片旋转使目标扇区位于其下方。
此处，每个盘片有两个表面（即读写头可以从盘片的上下两面访问）。
因此，<400,16,29>表示已通过了 0-399 号柱面。每个柱面包含 20 个表面（10 个盘片 × 每个盘片 2 个表面），每个表面有 63 个扇区。
计算过程如下：
已通过 0-399 号柱面：
400 × 20 × 63 = 504000
扇区
在第 400 号柱面中，已通过 0-15 号表面（共 16 个表面）：
16

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握CHS（柱面-磁头-扇区）寻址的基本概念，特别是“表面号”与“磁头号”的对应关系，以及硬盘物理结构（盘片、磁头、柱面）的逻辑映射。属于标准的基础概念记忆，不涉及复杂辨析。
- **K2 = 4**: 评分理由。计算涉及多级乘法（柱面数×表面数×扇区数）和加法。虽然数字本身不大，但中间结果（504000）较大，且最后一步涉及 `16 * 63 + 29` 的混合运算，非2的幂次友好，容易在手工计算或心算时出现进位错误，属于较高难度的单步/多步代入计算。
- **K3 = 2**: 评分理由。推演步骤清晰且固定：先算完整柱面的扇区总数，再算当前柱面内完整磁道的扇区总数，最后加上当前磁道内的扇区偏移。逻辑线性，无需回溯或状态记忆，步骤较少。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。主要陷阱在于“表面号”的范围理解（0-19）以及是否包含当前扇区本身（从0开始计数）。如果误以为表面号是1-based或者忘记加最后的扇区偏移，会落入陷阱。属于中等程度的隐含前提识别。
- **K5 = 1**: 评分理由。本题仅涉及存储系统的物理寻址逻辑，不涉及CPU、内存、I/O控制器等其他子系统的状态传递或耦合，属于单系统内部计算。
- **雷达形状**: K2计算主导型，K4陷阱辅助型。整体呈现计算量较大但逻辑简单的特征。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于将三维逻辑地址（CHS）转换为一维线性物理地址（扇区号）。解题过程主要依赖公式代入和算术运算，而非复杂的机制推理或概念辨析。

## 选项级分析
- **选项A**: [干扰] — 针对**漏加当前扇区偏移**或**计算错误**的认知。
  - 错误路径1：计算了前400个柱面和前16个磁道，但忘记加上最后的扇区号29，或者在计算 `16 * 63` 时出错。
  - 错误路径2：误以为扇区号从1开始，导致最终结果少1（505036-1=505035，但这通常对应B的变体，A更可能是纯计算失误）。
  - 这类学生可能忽略了地址 `<c, h, s>` 中 `s` 是相对于当前磁道起始位置的偏移量，需要累加。
- **选项B**: [干扰] — 针对**边界理解错误（Off-by-one）**的认知。
  - 错误路径：正确计算了前400个柱面（504000）和前16个磁道（16*63=1008），但在处理扇区号时，误以为扇区号29表示“已经过了29个扇区”，从而只加了28；或者误以为地址是1-based，导致计算偏差。
  - 更常见的错误是：计算 `504000 + 16 * 63 + 29` 时，算术错误导致少1。例如 `16*63=1008`, `1008+29=1037`, `504000+1037=505037`。如果算成505036，可能是 `16*63` 算错或 `29` 处理错误。
  - 另一种可能：误认为表面号16是第17个表面，但计算时用了16，却在扇区部分搞错了基准。
- **选项C**: [正确] — 正确计算结果。
  - 计算过程：
    1. 完整柱面数：400个（0-399）。
    2. 每个柱面扇区数：10盘片 * 2面/盘片 * 63扇区/面 = 1260扇区。
    3. 前400柱面总扇区：400 * 1260 = 504,000。
    4. 当前柱面（400）内完整磁道数：16个（0-15）。
    5. 当前柱面内完整磁道扇区：16 * 63 = 1,008。
    6. 当前磁道内扇区偏移：29。
    7. 总计：504,000 + 1,008 + 29 = 505,037。
- **选项D**: [干扰] — 针对**多算一个扇区**或**边界理解错误**的认知。
  - 错误路径：误以为扇区号29表示“第30个扇区”，从而加了30；或者在计算表面数时，误以为表面号16表示已经过了17个表面（0-16），导致多加了63个扇区中的部分或全部。
  - 具体计算：505037 + 1 = 505038。这通常是因为将扇区号视为1-based索引，或者在累加时多算了一次。

- **干扰策略**: 计算陷阱与边界混淆。选项分布紧密（差值为1），旨在惩罚计算粗心和对0-based索引理解不深的学生。

## 核心陷阱
- **核心陷阱**: **0-based索引的累加逻辑**与**大数计算的准确性**。
  1. 必须明确 `(c, h, s)` 中，`c` 表示前面有 `c` 个完整柱面，`h` 表示在当前柱面中有 `h` 个完整磁道，`s` 表示在当前磁道中有 `s` 个完整扇区。
  2. 容易在 `16 * 63` 或最终加法时出现算术错误。
  3. 容易混淆“表面号”与“磁头号”的数量关系（10盘片*2面=20头，表面号0-19）。

## 考察能力
本题核心考察考生对硬盘物理结构（CHS寻址）的理解以及将多维逻辑地址转换为一维线性地址的精确计算能力。
