# 模拟题 Q1 — RISC与CISC基本概念辨析

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: CO-4 > CISC 和 RISC > 基本概念, CO-4 > CISC 和 RISC > CISC与RISC比较
- **难度**: 待评估

## 题干原文
下面关于 RISC 技术的描述中，正确的是（ ）。

A. 采用 RISC 技术后，计算机的体系结构又恢复到早期的比较简单的情况
B. 为了实现兼容，新设计的 RISC 是从原来的 CISC 系统的指令系统中挑选一部分实现的
C. RISC 的主要目标是减少指令数
D. RISC 设有乘、除法指令和浮点运算指令，只是很少使用

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。本题主要考察对 RISC（精简指令集计算机）核心设计原则的记忆与理解。考生需要掌握 RISC 与 CISC 的基本定义及区别，属于标准的基础概念记忆范畴。不是 2 分因为仅靠模糊印象容易误选，需要明确“精简”的具体含义（指令格式规整、数量少、执行快等）；不是 4 分因为不需要辨析多个极易混淆的深层机制，只需识别核心特征。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全属于定性分析。
- **K3 = 1**: 评分理由。解题过程不需要多步串行推演，只需将选项描述与 RISC 的定义进行直接比对即可得出结论，逻辑链条极短。
- **K4 = 2**: 评分理由。存在常规的概念陷阱。选项 A 和 B 利用了考生对“历史演进”和“兼容性”的直觉误解（如认为新技术是旧技术的简单回归或子集），属于常规注意点，需要考生具备清晰的架构演进观，但并非深奥的隐含前提或反直觉陷阱。
- **K5 = 1**: 评分理由。本题仅涉及指令集架构（ISA）层面的单一知识点，不需要跨越 CPU 内部其他子系统（如 Cache、中断、总线等）进行状态传递或联动分析。
- **雷达形状**: K1 主导型（概念记忆型）。雷达图在 K1 维度突出，其余维度极低，呈现典型的“知识回忆”特征。

## 考察模式
- **模式**: 概念型
- **理由**: 题目直接询问技术描述的正确性，核心在于对 RISC 设计哲学（Hardwired Control, Load/Store Architecture, Fixed Length Instructions 等）的概念性掌握，而非通过计算或复杂逻辑推理得出结果。

## 选项级分析
- **选项A**: [干扰] — 针对“技术倒退论”的错误认知。这类学生可能误以为“精简”意味着“简陋”或“回到过去”。实际上，RISC 是在现代复杂硬件技术（如流水线、超标量）基础上，通过简化指令集来换取更高的执行效率，是架构设计的优化而非退化。
- **选项B**: [干扰] — 针对“兼容即子集”的错误认知。这类学生容易将软件兼容性等同于指令集的子集关系。事实上，RISC 指令集通常是独立设计的，强调正交性和规整性，并非从 CISC 中挑选指令。若为了兼容 CISC，通常需要通过微码模拟或二进制翻译，而非直接选取指令。
- **选项C**: [正确] — RISC 的核心特征之一确实是减少指令数量（尤其是复杂指令），保留使用频率高、执行时间短的指令，从而简化控制逻辑，提高主频和流水线效率。
- **选项D**: [干扰] — 针对“RISC 功能弱”的错误认知。这类学生可能认为 RISC 因为“精简”所以不支持复杂运算。实际上，现代 RISC 处理器（如 ARM, MIPS, RISC-V）均支持乘除法和浮点运算，只是可能通过多条简单指令组合实现，或作为可选扩展模块，而非“很少使用”或“不设”。
- **干扰策略**: 概念混淆。利用“精简”一词的字面歧义（简单 vs 精简）以及“兼容”的常见误区来构建干扰项。

## 核心陷阱
- **核心陷阱**: 对“精简（Reduced）”一词的误解。考生容易将“指令集精简”误解为“功能简化”或“历史倒退”，从而误选 A 或 D；或者将“指令集设计”与“软件兼容”混淆，误选 B。

## 考察能力
一句话概括本题核心考察的能力：准确区分 RISC 与 CISC 在设计理念、指令集构成及演进逻辑上的本质差异。
