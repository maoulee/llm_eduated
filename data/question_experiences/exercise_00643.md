# 练习题 Q1 — 补码特殊值与符号位特性

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机组成原理/数制
- **难度**: 待评估

## 题干原文
以下哪个二进制数与其二进制补码相同？（ ）
A: 1010
B: 0101
C: 1000
D: 1001

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“补码”的核心定义及求补规则（取反加1）。虽然概念基础，但必须明确区分原码、反码和补码的定义，特别是负数补码的生成机制。不记忆定义无法解题，故为3。
- **K2 = 2**: 评分理由。计算过程仅为简单的4位二进制取反和加1操作，属于2的幂次友好型计算，几乎不可能算错，计算负荷极低。
- **K3 = 2**: 评分理由。从输入到输出仅需两步：1. 按位取反；2. 末位加1。步骤清晰且串行，无需记忆中间复杂状态。
- **K4 = 4**: 评分理由。存在显著的隐含前提和反直觉陷阱。
    1. **隐含前提**：题目未指定字长，但选项均为4位，隐含考察4位定点整数的表示范围。
    2. **反直觉/陷阱**：通常正数（符号位0）的补码等于原码，但选项中唯一的正数B（0101）其补码显然不等于自身（因为正数补码定义即为原码，但题目问的是“数值”是否相同，这里有一个逻辑陷阱：如果按定义，正数补码=原码，那么0101的补码就是0101，应该选B？）。
    *修正分析*：这里需要仔细辨析题意。通常“补码相同”指的是**机器数表示**相同。
    - 对于正数（符号位0）：补码 = 原码。所以 0101 的补码确实是 0101。
    - 对于负数（符号位1）：补码 = 反码 + 1。
    - 让我们重新审视选项B：0101。如果是正数，其补码就是它本身。那为什么答案选C？
    - **关键陷阱识别**：这道题的题干表述可能存在歧义，或者考察的是**“数值”**与**“编码”**的区别，亦或是考察**最小负数**的特殊性。
    - 在4位补码系统中：
        - A: 1010 (原码-5) -> 补码: 0101+1=0110 (+6)。不同。
        - B: 0101 (原码+5) -> 补码: 0101 (+5)。**相同**。
        - C: 1000 (原码-0? 不，补码中1000表示-8) -> 求补: 0111+1=1000。**相同**。
        - D: 1001 (原码-7) -> 补码: 0110+1=0111 (+7)。不同。
    - **矛盾点**：如果B和C都满足“二进制数与其补码相同”，为什么单选C？
    - **深度解析**：在计算机组成原理中，通常讨论“补码与原码相同”时，正数是显然的。但本题可能隐含考察**负数**中是否存在补码等于自身的数，或者题目语境下“二进制数”特指**机器数编码**，且往往这类题目旨在考察**最小负数（100...0）**的特殊性质，即它是唯一一个**负数**中补码等于自身的数（或者说，它是补码系统中唯一的“自反”负数，而正数天然自反）。
    - 然而，更常见的考法是：**“下列哪个数的补码与原码相同？”** 答案通常是正数和0。
    - 但本题问的是**“与其二进制补码相同”**。
    - 让我们看参考解析：参考解析对B的计算是 `1010 + 1 = 1011`。这意味着参考解析**错误地**将B（0101）当作负数处理了（先取反得1010，再加1）。或者，参考解析认为B是负数？不，0101符号位是0，是正数。
    - **重新评估参考解析的逻辑**：参考解析对B的操作是 `1010 + 1`。这说明它先对 `0101` 取反得到了 `1010`。这只有在 `0101` 被当作**负数**或者题目隐含要求对**所有数**执行“求补运算”（即求相反数的补码，或者求补操作定义为取反加1）时才成立。
    - **标准定义**：
        - 若x为正，[x]补 = x。
        - 若x为负，[x]补 = ~x + 1。
        - 若题目意思是“对给定的二进制串执行‘求补’操作（即取反加1），结果是否与原串相同？”
            - A: 1010 -> ~1010=0101 -> +1=0110 != 1010
            - B: 0101 -> ~0101=1010 -> +1=1011 != 0101
            - C: 1000 -> ~1000=0111 -> +1=1000 == 1000
            - D: 1001 -> ~1001=0110 -> +1=0111 != 1001
    - **结论**：题目的真实意图是考察**“求补运算”（Two's Complement Operation）**的自反性，即 `~x + 1 == x` 的解。在n位二进制中，只有 `100...0` 满足此条件。正数不满足此“运算”结果等于自身（因为正数求补会变成负数）。
    - 因此，K4评分为4，因为学生必须识别出题目不是在问“正数补码定义”，而是在问“执行取反加1操作后是否不变”，这是一个隐含的运算规则陷阱。

- **K5 = 1**: 评分理由。仅涉及数制转换和位运算，不涉及跨子系统联动。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要难点在于对题意的隐含规则解读）

## 考察模式
- **模式**: 概念型/推理型
- **理由**: 表面是计算，实则是考察对“补码运算规则”（取反加1）在特定边界条件（最小负数）下的数学性质理解。需要推理出只有 `100...0` 满足 `~x + 1 = x`。

## 选项级分析
- **选项A**: [干扰] — 针对未掌握求补规则的学生。1010取反加1得0110，变化明显，容易排除。
- **选项B**: [干扰] — **最强干扰项**。针对混淆“正数补码定义”与“求补运算”的学生。
    - 错误认知1：认为正数补码等于原码，所以0101的补码是0101，选B。
    - 错误认知2：不知道如何对正数执行“求补”操作（如果题目意指求相反数的补码）。
    - 这类学生通常死记硬背“正数补码=原码”，而忽略了题目可能是在考察位运算层面的 `~x+1` 恒等式。
- **选项C**: [正确] — 针对掌握补码特殊值（最小负数）性质的学生。1000取反得0111，加1得1000，自身不变。
- **选项D**: [干扰] — 针对计算错误的学生。1001取反加1得0111，变化明显。

- **干扰策略**: 概念混淆。利用“正数补码等于原码”这一常识性知识点，诱导学生选择B，从而掩盖题目实际考察的是“取反加1”这一运算过程的自反性。

## 核心陷阱
- **核心陷阱**: **题意歧义与运算定义的混淆**。
    - 陷阱在于：学生容易将“补码”理解为一种**表示法**（Representation），此时正数的补码确实等于其原码（即二进制串本身）。
    - 但题目实际考察的是**求补运算**（Operation）：即对任意二进制串执行“按位取反，末位加1”的操作，结果是否与原串相同。
    - 在4位系统中，只有 `1000`（即-8的补码表示）满足 `~1000 + 1 = 1000`。正数 `0101` 执行该操作后变为 `1011`（即-5的补码），并不等于自身。

## 考察能力
一句话概括本题核心考察的能力：
**辨析补码表示法与求补运算规则的区别，并掌握最小负数（100...0）在取反加1运算下的自反特性。**
