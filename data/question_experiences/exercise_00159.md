# 练习题 Q1 — 磁盘I/O时间计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/I/O管理
- **难度**: 待评估

## 题干原文
一个应用程序在启动时加载 100 个库。每个库的加载需要一次磁盘访问。磁盘的随机位置寻道时间为 10 毫秒，磁盘的旋转速度为 6000 转/分钟。如果所有 100 个库都从磁盘上的随机位置加载，加载所有库需要多长时间？（一旦磁头定位到块的起始位置，从磁盘块传输数据的时间可以忽略不计）（ ）
- 选项:
  A: 0.50 秒
  B: 1.50 秒
  C: 1.25 秒
  D: 1.00 秒
- 正确答案: B
- 解析（参考）: 解析
计算逻辑：
平均寻道时间 = 10ms
平均旋转延迟 = (60s/6000 转)/2 = 5ms
单次 I/O 总耗时 = 10ms + 5ms = 15ms
100 次 I/O 总耗时 = 100 × 15ms = 1500ms = 1.50 秒
- 知识标签: ['操作系统/I/O管理']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆磁盘I/O时间的三个组成部分（寻道时间、旋转延迟、传输时间）及其定义。不是4分因为不需要辨析多个易混概念，只需调用核心定义。
- **K2 = 3**: 评分理由。涉及单位换算（RPM转ms）和简单的乘法加法。不是2分因为涉及非2幂次的单位换算（6000转/分 -> 10ms/转 -> 5ms平均延迟），容易在换算过程中出错；不是4分因为计算步骤并不复杂。
- **K3 = 2**: 评分理由。从输入到输出只需两步：计算单次I/O时间，然后乘以次数。属于标准的串行推演，无需记忆中间状态或复杂逻辑分支。
- **K4 = 3**: 评分理由。存在隐含前提：“随机位置”意味着必须考虑平均旋转延迟，且每次访问都是独立的（串行）。陷阱在于学生可能忽略旋转延迟，或者误以为“随机”只影响寻道而不影响旋转等待。
- **K5 = 1**: 评分理由。本题仅涉及磁盘子系统内部的物理特性计算，不涉及文件系统、内存管理或CPU调度等其他子系统的状态传递或耦合。
- **雷达形状**: K2计算主导型，伴随K4条件识别。整体呈现为典型的“公式应用+单位换算”特征，K1和K3处于标准水平，K5极低。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过给定的物理参数（寻道时间、转速）和访问模式（随机、次数），利用公式计算出总时间。虽然涉及概念理解，但最终落脚点在于数值计算的准确性。

## 选项级分析
- **选项A**: [干扰] — 针对只计算寻道时间的错误认知。学生可能认为“随机位置”主要考验寻道，忽略了旋转延迟。计算：100 * 10ms = 1000ms = 1.0s (接近D，但若误算为0.5s可能是其他错误)。或者，如果学生错误地认为平均旋转延迟是0（理想情况），且只算了一半？不太可能。更可能的错误路径是：只算了寻道时间10ms，然后误以为100次是0.5秒？或者混淆了转速换算。实际上，如果只算寻道时间是1.0s (D)。如果只算旋转延迟是0.5s (A)。所以A是针对**只计算平均旋转延迟**或**严重低估总时间**的干扰项。
- **选项B**: [正确] — 正确计算了寻道时间(10ms) + 平均旋转延迟(5ms) = 15ms，再乘以100次 = 1500ms = 1.5s。
- **选项C**: [干扰] — 针对计算错误的干扰项。可能是学生将旋转延迟算错，例如误以为平均旋转延迟是2.5ms（误除以4？），或者在单位换算时出错（如将6000转/分误算为其他值）。也可能是将15ms误算为12.5ms（10+2.5?）。
- **选项D**: [干扰] — 针对忽略旋转延迟的错误认知。学生可能认为“随机访问”主要耗时在寻道，或者误以为题目中“传输时间忽略不计”暗示其他等待时间也可忽略，从而只计算了寻道时间：100 * 10ms = 1000ms = 1.0s。这是最常见的错误之一。

**干扰策略**: 概念混淆（忽略旋转延迟）与计算陷阱（单位换算错误）。选项D是强干扰项，针对那些知道寻道时间但忘记旋转延迟概念的学生；选项A针对完全搞错公式或只计算部分时间的学生。

## 核心陷阱
- **核心陷阱**: **忽略平均旋转延迟**。许多学生容易记住“寻道时间”是随机访问的主要瓶颈，从而下意识忽略“旋转延迟”。题目明确指出“随机位置”，这不仅意味着寻道时间是平均值，也意味着数据块出现在磁头下的时间是随机的，因此必须加上平均旋转延迟（即半圈的时间）。此外，单位换算（RPM到ms）也是一个常见的计算陷阱。

## 考察能力
一句话概括本题核心考察的能力：
考生对磁盘I/O时间组成（寻道+旋转+传输）的理解，以及在随机访问场景下正确应用平均旋转延迟公式并进行单位换算的能力。
