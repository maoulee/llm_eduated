# 练习题 Q1 — CSMA/CD最小帧长计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/数据链路层
- **难度**: 待评估

## 题干原文
在 MAC 层使用 CSMA/CD 协议的网络通过无中继器的 1 公里电缆以 1 Gbps 运行。电缆中的信号速度为 2×10⁸ 米/秒。该网络的最小帧大小应为（ ）。
- 选项:
  A: 10000 bits
  B: 10000 bytes
  C: 5000 bits
  D: 5000 bytes
- 正确答案: A

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆 CSMA/CD 协议中“最小帧长”与“争用期（2τ）”的核心关系公式 $L_{min} \ge R \times 2\tau$。这属于标准的核心定义记忆，不涉及复杂概念辨析，但必须准确回忆公式结构。
- **K2 = 3**: 评分理由。计算过程涉及单位换算（km 到 m，Gbps 到 bps）和简单的乘除运算。虽然数值（$10^9$, $2 \times 10^8$）较为规整，但涉及科学计数法的指数运算，对于不熟练的学生存在计算失误风险，属于标准难度的单步代入。
- **K3 = 1**: 评分理由。解题逻辑线性且直接：先算传播时延 $\tau$，再算争用期 $2\tau$，最后乘以带宽得到比特数。无需多步串行推演或状态记忆。
- **K4 = 2**: 评分理由。存在常规注意点，即单位一致性（米/秒 vs 公里，bps vs Gbps）以及最终结果的单位（bits vs bytes）。题干中“无中继器”排除了额外延迟的干扰，属于常规注意点，无深层隐含前提。
- **K5 = 1**: 评分理由。本题仅涉及数据链路层 MAC 子层的物理参数计算，不涉及网络层、传输层或其他子系统的状态传递或耦合。
- **雷达形状**: K2计算型（K1、K2 略高，其余维度低，呈现以计算和基础记忆为主的形态）

## 考察模式
- **模式**: 计算型
- **理由**: 题目给出了明确的物理参数（距离、速度、带宽），要求考生应用特定公式进行数值计算，核心考点在于公式的正确应用和单位换算，而非复杂的逻辑推理或概念辨析。

## 选项级分析
- **选项A**: [正确] — 正确应用公式 $L_{min} = 2 \times \frac{L}{v} \times R$ 计算得出 $10000$ bits。
- **选项B**: [干扰] — 针对单位混淆错误。学生可能正确计算出数值 10000，但忽略了题目问的是“帧大小”通常以 bit 为基本单位进行理论计算，或者误以为以太网帧长通常用 Byte 表示而强行转换（尽管 10000 bits 不是 8 的倍数，无法整除为 Byte，但考生可能忽略此细节直接选数值匹配的 Byte 选项）。
- **选项C**: [干扰] — 针对公式记忆错误。学生可能只计算了单程传播时延 $\tau$ 对应的比特数（即 $R \times \tau$），忘记了 CSMA/CD 需要检测冲突的最坏情况是往返时延 $2\tau$。
- **选项D**: [干扰] — 针对双重错误。既只计算了单程时延（导致数值减半），又混淆了单位（bits 变 bytes）。
- **干扰策略**: 计算陷阱（漏乘2）与单位混淆（bits/bytes）的组合干扰。

## 核心陷阱
- **核心陷阱**: 忘记乘以 2（即混淆单程传播时延与争用期/往返时延）以及单位换算错误（bits 与 bytes 的混淆）。

## 考察能力
本题核心考察考生对 CSMA/CD 协议中“最小帧长”物理意义的理解（即发送时延必须大于等于往返传播时延）以及相关的数值计算与单位换算能力。
