# 练习题 Q1 — 栈应用与算法逻辑缺陷分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/栈
- **难度**: 待评估

## 题干原文
以下是一个错误的伪代码，该算法本应判断括号序列是否平衡：
创建一个字符栈
while(还有输入可用) {
 读取一个字符
 if(该字符是 '(')
 将其压入栈中
 else if(该字符是 ')' 且栈不为空)
 弹出栈顶字符
 else
 打印 "unbalanced" 并退出
}
打印 "balanced"
上述代码会将下列哪个不平衡序列误判为平衡？（ ）
- 选项:
  A: ((())
  B: ())(()
  C: (()()))
  D: (()))()
- 正确答案: A
- 解析（参考）: 关键问题
：在
while
循环结束后，必须检查栈是否为空。
示例分析
：对于输入
((())
，循环结束后栈不为空（剩余一个未匹配的
'('
），但代码未执行此检查，导致误判为平衡。
- 知识标签: ['数据结构/栈']
- 知识域: DS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握栈的基本操作（Push/Pop）以及括号匹配的基本概念。不是2分因为仅靠直觉无法准确判断所有选项，需要明确“栈非空”在括号匹配中的语义（即左括号未闭合）。
- **K2 = 1**: 评分理由。本题不涉及数值计算，仅涉及字符状态的跟踪，无计算负担。
- **K3 = 4**: 评分理由。需要对每个选项进行多步串行推演。以选项A为例，需模拟5次循环迭代，跟踪栈内元素的变化（Push, Push, Push, Pop, Pop），最后检查栈状态。步骤超过5步且需记忆中间状态（栈内剩余元素），符合K4标准。
- **K4 = 4**: 评分理由。存在明显的隐含前提陷阱。题目给出的代码是“错误”的，考生必须识别出代码缺失了“循环结束后检查栈是否为空”这一关键逻辑。如果考生只关注循环内的逻辑，会误以为代码能处理所有情况。这是一个典型的“反直觉”或“隐含前提深”的陷阱，因为常规思维会认为代码既然写了else分支处理错误，就是完整的。
- **K5 = 1**: 评分理由。本题仅涉及栈这一单一数据结构的内部状态变化，不涉及与其他子系统（如队列、树、图等）的状态传递或耦合。
- **雷达形状**: K4陷阱型（K3推演与K4陷阱双高，K1中等，K2/K5低）。

## 考察模式
- **模式**: 推理型
- **理由**: 本题不要求记忆公式或进行复杂计算，而是要求考生通过模拟算法执行过程（推理），发现算法逻辑与预期行为之间的偏差，并据此判断特定输入下的输出结果。

## 选项级分析
- **选项A**: [正确] — 针对“忽略循环后栈状态检查”的错误认知。序列 `((())` 包含3个左括号和2个右括号。执行过程：Push, Push, Push, Pop, Pop。循环结束时，栈中剩余1个 `'('`。由于代码在循环外直接打印 "balanced"，未检查栈空，故误判。这类学生能正确模拟过程并识别代码缺陷。
- **选项B**: [干扰] — 针对“只关注右括号匹配失败”的认知。序列 `())(()`。执行到第3个字符 `)` 时，栈已空（前两个 `()` 已抵消），触发 `else` 分支（因为 `栈不为空` 条件为假，进入 `else`），打印 "unbalanced" 并退出。代码能正确识别其不平衡。
- **选项C**: [干扰] — 针对“复杂嵌套匹配”的认知。序列 `(()()))`。执行到第6个字符 `)` 时，栈已空（前5个字符 `(()()` 处理后栈空？不，`(()()` -> Push, Push, Pop, Push, Pop -> 栈空。第6个 `)` 触发 `else`，打印 "unbalanced" 并退出。代码能正确识别。
- **选项D**: [干扰] — 针对“中间出现右括号多于左括号”的认知。序列 `(()))()`。执行到第4个字符 `)` 时，栈已空（前3个 `(()` -> Push, Push, Pop -> 栈剩1个 `(`？不，`(()` -> Push, Push, Pop -> 栈剩1个 `(`。第4个 `)` -> Pop -> 栈空。第5个 `)` -> 栈空，触发 `else`，打印 "unbalanced" 并退出。代码能正确识别。
- **干扰策略**: 渐进陷阱。选项B、C、D均在循环过程中触发了显式的错误处理分支（`else`），因此代码能正确报错。只有选项A在循环过程中没有触发任何错误分支，错误隐藏在循环结束后的状态中。这种设计让考生容易忽略“静默失败”的情况。

## 核心陷阱
- **核心陷阱**: 算法完整性缺失。代码仅处理了“右括号多余”或“右括号出现时栈空”的情况，但遗漏了“左括号多余”（即循环结束后栈非空）的情况。考生需意识到括号平衡的两个必要条件：1. 遍历过程中右括号不能多于左括号；2. 遍历结束后左括号不能多于右括号（栈必须为空）。

## 考察能力
本题核心考察考生对栈在括号匹配问题中应用逻辑的深刻理解，特别是识别算法边界条件缺失（循环后状态检查）的能力。
