# 练习题 Q1 — CSMA/CD最小帧长计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/数据链路层
- **难度**: 待评估

## 题干原文
在一条 200 米长的电缆上运行速率为 1 Gbps、链路传播速度为 2 × 10⁸ m/s 的 CSMA/CD 网络中，所需的最小帧长度是（ ）：
A: 125 字节
B: 250 字节
C: 500 字节
D: 以上都不是

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要调用CSMA/CD协议的核心概念“争用期”（或往返时延RTT）与“最小帧长”的关系公式。不是4分因为不需要辨析多个易混概念（如CSMA/CA或令牌环），只需掌握一个核心定义：传输时延 ≥ 2倍传播时延。
- **K2 = 3**: 评分理由。涉及单位换算（bps到Bps，米到秒）和数量级计算（10^9, 10^8）。不是2分因为涉及非2的幂次换算（10^9/10^8=10）以及字节与比特的转换（/8），容易在数量级上出错；不是4分因为计算步骤相对直接，没有多级复杂嵌套。
- **K3 = 2**: 评分理由。从输入到输出只需两步：1. 计算往返时延（RTT）；2. 根据带宽计算比特数并转换为字节。属于标准的单步代入后简单转换，无需多步串行推演或记忆中间状态。
- **K4 = 2**: 评分理由。存在常规注意点，即“往返时延”是单程传播时延的2倍，以及“帧长度”通常以字节为单位而速率以bps为单位。没有深层隐含前提或反直觉陷阱，属于常规考点。
- **K5 = 1**: 评分理由。本题仅涉及数据链路层的介质访问控制子层，不涉及网络层、传输层或其他子系统的状态传递或耦合，属于单系统内部计算。
- **雷达形状**: K2计算型（K1、K2略高，K3、K4、K5较低，呈现以计算和基础概念为主的形态）

## 考察模式
- **模式**: 计算型
- **理由**: 题目给出了具体的物理参数（长度、速率、传播速度），要求通过公式代入计算得出具体数值结果。虽然基于概念（CSMA/CD原理），但解题核心在于准确执行单位换算和数值计算。

## 选项级分析
- **选项A**: [干扰] — 针对“忘记乘以2”或“单位换算错误”的错误认知。如果学生只计算了单程传播时延对应的比特数（125字节），或者在计算比特数时忘记除以8得到字节数（若误算为125比特则更离谱，此处125字节恰好是250字节的一半，暗示可能漏乘2或漏除8的组合错误，最可能是只算了单程时延对应的字节数：$200/(2\times10^8) \times 10^9 / 8 = 125$ B）。这类学生可能混淆了“传播时延”和“往返时延”。
- **选项B**: [正确] — 正确计算了往返时延（RTT = 2 * 200 / 2e8 = 2us），然后计算最小比特数（1e9 * 2e-6 = 2000 bits），最后转换为字节（2000 / 8 = 250 Bytes）。
- **选项C**: [干扰] — 针对“单位换算错误”或“公式记忆偏差”的错误认知。如果学生忘记将比特转换为字节（2000 bits 误认为是 2000 Bytes，接近但不完全匹配，或者误以为1Gbps=10^9 Bps? 不太可能）。更可能的错误是：计算RTT时误用了其他系数，或者在字节转换时出错（例如误乘8？2000*8=16000，不对）。另一种可能是学生记错了公式，认为最小帧长是RTT的2倍？或者在计算传播时延时出错。实际上，如果学生算出2000比特，然后错误地认为1字节=4比特（极少见）或者单纯看错选项。更常见的干扰逻辑是：如果学生忘记除以8，得到2000，选项里没有。如果学生把1Gbps当成100Mbps算？100Mbps * 2us = 200 bits = 25 Bytes。如果学生把传播速度当成光速3e8？RTT = 400/3e8 = 1.33us, 1.33us * 1Gbps = 1333 bits = 166 Bytes。选项C 500字节可能是针对那些在数量级上完全搞混，或者误以为最小帧长是标准以太网1518字节的一半等无关联想。但在本题语境下，C通常是作为“计算结果偏大”的干扰项，可能源于将比特数直接当作字节数且计算有误，或者误以为需要更大的余量。
- **选项D**: [干扰] — 针对“不确定”或“认为标准以太网最小帧长64字节是绝对真理”的错误认知。部分学生可能死记硬背“以太网最小帧长64字节”，看到计算结果250字节与64不符，从而怀疑题目或选择“以上都不是”。这类学生缺乏对“理论最小帧长”与“协议规定最小帧长”区别的理解，或者不知道CSMA/CD理论计算值可以大于64字节（取决于带宽和距离）。

**干扰策略**: 计算陷阱（单位换算、单程vs往返）与概念混淆（理论值vs标准值）相结合。

## 核心陷阱
- **核心陷阱**: **单位换算与往返时延的双重陷阱**。
    1.  **往返时延（RTT）**：必须使用 $2 \times$ 单程传播时延，而非单程。
    2.  **单位一致性**：速率是 bps (bits per second)，长度是 Bytes (bytes)，必须除以 8 进行转换。
    3.  **数量级敏感度**：1 Gbps ($10^9$) 和 $2 \times 10^8$ m/s 的数量级处理容易出错。

## 考察能力
本题核心考察考生对CSMA/CD协议中“最小帧长与争用期关系”的理论理解，以及在高速网络环境下进行精确单位换算和数值计算的能力。
