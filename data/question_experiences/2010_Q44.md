# 2010年 Q44 — Cache直接映射与命中率计算

## 基本信息
- **年份**: 2010  **题位**: Q44  **题型**: 综合应用题
- **知识点**: Cache 直接映射地址结构, Cache 命中率计算, Cache 颠簸 (Thrashing)
- **考纲对应**: 第三章 存储器层次结构 -> Cache（原理/映射/替换/写策略）

## 题干原文
[2010年考研真题第44题]某计算机的主存地址空间大小为256MB,按字节编址。指令Cache 和数据Cache 分离，均有8个Cache 行，每个Cache 行大小为64B,数据Cache 采用直

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆 Cache 直接映射（Direct Mapping）的地址划分规则（标记/行号/块内偏移）及命中率定义。虽然概念基础，但若对“块大小”与“行大小”、“主存地址位数”与“索引位数”的对应关系模糊，无法确定分界线，则无法入题。非 2 分是因为不能仅靠常识，非 4 分是因为直接映射是 Cache 中最简单的映射方式，不涉及组相联的复杂索引计算。
- **K2 = 2**: 2 — 计算过程极为简单，主要涉及 $2$ 的幂次转换（如 $256MB = 2^8 MB$，$64B = 2^6 B$）和简单的加法/减法运算。数字均为友好整数，无复杂浮点或大数运算，非 3 分是因为没有非 2 的幂次干扰，非 1 分是因为需要执行明确的位宽切割计算。
- **K3 = 4**: 4 — 需要模拟程序的执行轨迹，特别是程序 B 的列访问模式。考生需模拟多个数组元素在有限 Cache 行（8行）中的映射与替换过程，涉及动态状态更新（Cache 内容随时间变化）。路径虽唯一，但步数多（需遍历数组访问序列），且容易因中间某一步替换错误导致后续全错，符合 >5 步且需维持动态状态的特征。非 5 分是因为规则明确，无需处理极长程的复杂依赖或模糊状态。
- **K4 = 4**: 4 — 存在深层隐含前提：程序 B 的列访问会导致严重的 Cache 颠簸（Thrashing）。若考生未识别出“列访问”与“直接映射”结合产生的冲突失效（Conflict Miss），可能会误以为命中率与程序 A 相同或仅略低，从而掉入陷阱。这需要对 Cache 局部性原理及直接映射缺陷的本质理解才能正确路由。非 3 分是因为陷阱不仅仅是“陷阱词”，而是基于架构特性的反直觉现象；非 5 分是因为只要掌握冲突失效原理，即可正向推导。
- **K5 = 1**: 1 — 题目仅在 Cache 子系统内部解决，涉及主存地址到 Cache 行的映射，不涉及流水线、中断或 I/O 等其他子系统的状态联动。
- **雷达形状**: 机制推演型

## 子问依赖
- **子问数**: 1 (综合应用题通常合并为一个大问，但内部包含两个程序的独立计算)
- **依赖类型**: parallel (程序A和程序B的计算逻辑相对独立，虽然共用相同的 Cache 配置参数)
- **子问1**: 计算程序 A（按行访问）的命中率 — 基于顺序访问的局部性，模拟填充过程 — 不依赖前置子问
- **子问2**: 计算程序 B（按列访问）的命中率 — 基于冲突失效的颠簸效应，模拟替换过程 — 不依赖前置子问

## 条件利用映射
- **条件1**: "主存地址空间大小为256MB" — 用于确定主存地址总位数 (29位)，从而确定 Tag 位数，但在仅计算 Index 时非必须，属于背景约束。
- **条件2**: "按字节编址" — 确定地址单位，用于计算块内偏移和块号。
- **条件3**: "指令Cache 和数据Cache 分离" — 简化问题，只需考虑数据 Cache 的行为，无需考虑指令与数据竞争。
- **条件4**: "8个Cache 行" — 确定 Index 位数 (3位)，决定映射周期和冲突概率。
- **条件5**: "每个Cache 行大小为64B" — 确定 Block Offset (6位) 和每块容纳元素数，是计算空间局部性的关键。
- **条件6**: "数据Cache 采用直接映射" — 核心机制，决定了地址到行的映射是模运算，极易产生冲突失效。
- **未使用条件**: 无

## 关键考察点
考生是否理解**直接映射**机制下，**访问步长（Stride）**与 **Cache 行数** 的倍数关系会导致严重的**冲突失效（Conflict Miss/Thrashing）**，从而区别于拥有良好空间局部性的顺序访问。

## 核心陷阱
- **核心陷阱**: 误认为只要 Cache 够大或访问的是同一个数组，命中率就应该差不多；或者错误地计算了地址映射，忽略了按列访问时地址间隔导致的周期性映射冲突。
- **错误路径**: 学生可能只计算了程序 A 的命中率，然后凭直觉认为程序 B 也会因为数据相关性而有较高命中率，或者错误地认为直接映射会自动处理冲突（如组相联那样）。

## 考察能力
评估考生对 Cache 层次结构中**地址映射机制**与**程序访问模式**之间耦合关系的深度理解及模拟推演能力。
