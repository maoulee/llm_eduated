# 2016 Q38 — IP转发中的源/目的地址不变性

## 基本信息
- **年份**: 2016  **题位**: Q38  **题型**: 选择题
- **知识点**: 网络号和主机号, 计算机网络>网络号和主机号

## 题干原文
假设连接 R1、R2 和 R3 之间的点对点链路使用 201.1.3.x/30 地址，当 H3 访问 Web 服务器 S 时，R2 转发出去的封装 HTTP 请求报文的 IP 分组的源 IP 地址和目的 IP 地址分别是（ ）。
网络号和主机号

A. 192.168.3.251，130.18.10.1
B. 192.168.3.251，201.1.3.9
C. 201.1.3.8，130.18.10.1
D. 201.1.3.10，130.18.10.1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握IP地址分类、子网掩码计算、网络地址与广播地址的定义，以及IP转发过程中源/目的IP地址不变的核心概念。属于标准的基础概念记忆，不涉及深层辨析。
- **K2 = 2**: 评分理由。涉及/30子网掩码的计算（255.255.255.252）以及可用主机IP的推导。计算量极小，只需判断最后两位二进制不为00或11即可，属于2的幂友好型简单计算。
- **K3 = 2**: 评分理由。推演步骤较少：1. 确定R2接口的IP；2. 确认目的IP为服务器S的IP；3. 应用IP转发规则（源目的IP不变）。逻辑链条短，无需复杂的状态记忆。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。陷阱1：学生容易混淆“数据链路层帧的源/目的MAC地址”与“网络层IP分组的源/目的IP地址”，误以为经过路由器后IP地址会改变（类似NAT或MAC重写）。陷阱2：需要识别出R2连接R3的接口IP是201.1.3.10而非其他地址，需排除网络地址和广播地址。
- **K5 = 3**: 评分理由。需要跨越数据链路层（MAC地址变化）和网络层（IP地址不变）两个子系统的知识。虽然主要是单向传递（理解IP层封装在MAC层之上），但需要明确两层在转发过程中的不同行为，属于典型的跨层联动考察。
- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要考察对隐含规则和易混概念的辨析）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非单纯的公式计算，而是要求考生基于IP协议的工作原理（无连接、尽力而为、逐跳转发但端到端IP不变）进行逻辑推理，并结合子网划分知识确定具体接口IP。
