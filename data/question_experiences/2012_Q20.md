# 2012年 Q20 — USB总线特性

## 基本信息
- **年份**: 2012  **题位**: Q20  **题型**: 选择题
- **知识点**: USB总线特性, 总线分类, 串行与并行传输区别
- **考纲对应**: 第七章 输入输出系统 → 总线标准 → 设备总线标准 (USB)

## 题干原文
[2012年考研真题第20题]下列关于USB总线特性的描述中，错误的是。
A.可实现外设的即插即用和热拔插
B.可通过级联方式连接多台外设
C.是一种通信总线，连接不同外设
D.同时可传输2位数

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆 USB 总线的基本定义（串行 vs 并行）及核心特性（热插拔、拓扑结构）。虽然 USB 是常见外设接口，但“串行”这一底层物理特性容易被“高速”表象迷惑，需调用专业知识记忆，非纯常识。比 2 分高是因为如果概念模糊（如混淆并行/串行），无法通过逻辑推导排除 D；比 4 分低是因为不涉及冷门细节或极易混淆的深层机制辨析。
- **K2 = 1**: 1 — 无计算需求。
- **K3 = 1**: 1 — 无流程推演需求。
- **K4 = 2**: 2 — 存在常规注意点（USB 的高速特性常让人误以为其带宽大故为并行），但 408 考生对总线分类（系统总线、通信总线、设备总线）及传输方式（串行、并行）有基本认知后，基本不会踩坑。属于标准定义题，陷阱较浅。
- **K5 = 1**: 1 — 单一知识点内部解决，仅涉及总线特性，不涉及与其他子系统（如 CPU 流水线、Cache 映射）的联动。
- **雷达形状**: K1 概念型

## 考察模式
- **模式**: 概念辨析型
- **理由**: 选项均为对 USB 总线特性的陈述命题，考生需基于定义判断正误，不涉及数值计算或复杂机制推演。

## 选项级分析
- **选项A**: [干扰] — 描述正确。USB 支持即插即用（Plug and Play）和热拔插（Hot Swapping）。针对认知错误：无，这是 USB 的核心卖点，学生通常能正确识别。若选此项为错，说明完全未学习 USB 基础特性。
- **选项B**: [干扰] — 描述正确。USB 支持通过 Hub 进行级联（菊花链式）连接，最多连接 127 个设备。针对认知错误：无，这是 USB 拓扑结构的标准知识。
- **选项C**: [干扰] — 描述正确。USB 属于通信总线（或设备总线），用于连接主机与外部低速/中速/高速外设。针对认知错误：部分学生可能混淆“系统总线”与“通信总线”的定义，但通常知道 USB 是连外设的，故不易误判。
- **选项D**: [正确] — 描述错误。**USB 是串行总线**，数据是一位一位按时间顺序传输的，而非并行（同时传输多位）。针对认知错误：**“高速=并行”的直觉误区**。许多学生因为知道 USB 3.0/3.1 速度很快，潜意识里认为并行才能快，从而误以为 USB 是并行传输。这是典型的名称/表象与实质机制的反差陷阱。
- **干扰策略**: 并行陷阱（各干扰项独立）

## 核心陷阱
- **核心陷阱**: **高速串行 vs 低速并行** 的认知偏差。
- **错误路径**: 学生看到 USB 传输速度快 -> 联想到并行总线带宽大 -> 误以为 USB 是并行传输 -> 认为 D 选项“同时可传输2位数”（暗示并行）是正确的描述 -> 导致未选出 D（因为题目问错误的）。或者，学生直接误记 USB 为并行总线。实际上，USB 通过提高时钟频率和编码效率实现高速，但其物理层本质是串行。

## 考察能力
本题考查考生对计算机系统中**通信总线分类及传输机制**的基础概念记忆，特别是区分“串行”与“并行”的本质差异，并能抵御“速度表象”带来的直觉干扰。
