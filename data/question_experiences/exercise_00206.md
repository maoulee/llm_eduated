## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“大端序”和“小端序”的核心定义，以及十六进制数值与字节排列的对应关系。这属于操作系统基础概念中的标准记忆点，不涉及复杂辨析，但必须准确理解LSB/MSB在内存中的存储位置。
- **K2 = 4**: 评分理由。需要进行十六进制到十进制的转换，或者更优地，进行十六进制位权差的代数计算。虽然计算量不大，但涉及非2的幂次（255即0xFF）的差值匹配，且需要处理两个不同字节序下的数值重构，单步代入容易因位权搞错而出错。
- **K3 = 2**: 评分理由。推演步骤较少：1. 设内存字节为 $B_1 B_0$；2. 写出小端值 $V_L$ 和大端值 $V_B$；3. 建立方程 $V_L - V_B = 255$；4. 求解或验证选项。逻辑链条短，无需多步串行推演。
- **K4 = 4**: 评分理由。存在显著的隐含前提和易错点。首先，题目问的是“小端序计算机上的表示”，通常指该数值在内存中的字节序列对应的十六进制字面值，还是指该数值本身？结合选项和常规考法，这里指的是**内存中存储的字节序列所构成的十六进制数**（即如果内存是 `00 01`，小端解读为 `0x0100`，大端解读为 `0x0001`）。其次，学生容易混淆“数值”与“内存表示”，或者搞反大小端的定义（谁在前谁在后）。这是一个典型的“反直觉”陷阱，因为小端序下高位字节在内存高地址，但数值计算时高位权重高，容易弄混。
- **K5 = 1**: 评分理由。本题仅涉及数据表示（Data Representation）这一单一知识点，不涉及进程调度、内存管理、文件系统等其他子系统的联动。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，K2较高，K1中等，K3/K5低）

## 考察模式
- **模式**: 推理型
- **理由**: 虽然涉及数值计算，但核心在于理解字节序对数值解释的影响机制。学生不能仅靠死记硬背，必须通过建立数学模型（位权公式）来推导或验证选项，属于基于规则的定义推理。

## 选项级分析
- **选项A**: [干扰] — 针对**计算错误**或**盲目代入**的学生。如果学生不仔细计算，或者错误地认为高位字节差值直接对应255，可能会误选。实际上 $0x6665$ (小端值) 与 $0x6566$ (大端值) 的差值确实是255，但题目问的是“小端序计算机上的表示”。这里有一个巨大的歧义陷阱：如果内存是 `65 66`，小端序解读出的数值是 $0x6665$，大端序解读出的数值是 $0x6566$。差值 $0x6665 - 0x6566 = 0x00FF = 255$。等等，让我们重新审视题目和参考答案。
    *   **深度纠错与再分析**：
        *   题目问：哪个选项代表该无符号整数在**小端序计算机上的表示**？
        *   通常，“表示”指的是内存中的字节序列。但在选择题中，选项给出的是 `0xXXXX` 这种形式。
        *   假设内存字节为 $H$ (高地址) 和 $L$ (低地址)。
        *   小端序 (Little-Endian, LE): 低字节存低地址。内存布局: `[L] [H]`。数值 $V_{LE} = H \times 256 + L$。
        *   大端序 (Big-Endian, BE): 高字节存低地址。内存布局: `[H] [L]`。数值 $V_{BE} = H \times 256 + L$。
        *   **关键点**：题目说的是“同一个2字节无符号整数”。这意味着**内存中的字节序列是固定的**，只是不同计算机解读方式不同。
        *   设内存中的两个字节为 $B_0$ (低地址) 和 $B_1$ (高地址)。
        *   在小端序机器上，数值 $N_L = B_1 \times 256 + B_0$。
        *   在大端序机器上，数值 $N_B = B_0 \times 256 + B_1$。
        *   题目条件：$N_L - N_B = 255$。
        *   即 $(B_1 \times 256 + B_0) - (B_0 \times 256 + B_1) = 255$
        *   $255 \times B_1 - 255 \times B_0 = 255$
        *   $255 \times (B_1 - B_0) = 255$
        *   $B_1 - B_0 = 1$
        *   即：高地址字节比低地址字节大1。
        *   题目问：“该无符号整数在小端序计算机上的表示”。这通常指**该数值本身**，或者**内存内容的十六进制表示**？
        *   如果指**数值**：$N_L = B_1 \times 256 + B_0$。
        *   如果指**内存表示**：通常写作 `B0 B1` 或 `0xB0B1` (取决于上下文，但通常选项给出的 `0x0100` 这种形式是指数值，或者是指将内存字节按地址顺序拼成的字)。
        *   让我们看选项D: `0x0100`。
            *   如果这是**小端序下的数值** $N_L = 0x0100 = 256$。
            *   则 $B_1 \times 256 + B_0 = 256 \Rightarrow B_1=1, B_0=0$。
            *   此时内存低地址是0，高地址是1。
            *   大端序数值 $N_B = B_0 \times 256 + B_1 = 0 \times 256 + 1 = 1$。
            *   差值 $N_L - N_B = 256 - 1 = 255$。符合题意！
            *   所以，选项D `0x0100` 代表的是**小端序计算机解读出的数值**。
        *   让我们看选项A: `0x6665`。
            *   如果 $N_L = 0x6665$，则 $B_1=0x66, B_0=0x65$。
            *   $B_1 - B_0 = 1$。符合 $B_1 - B_0 = 1$ 的条件。
            *   此时 $N_B = 0x6566$。
            *   差值 $0x6665 - 0x6566 = 255$。也符合题意！
            *   **为什么A不对？** 题目问的是“哪个选项代表...表示”。通常如果没有特殊说明，且选项是唯一的，我们需要看是否有其他限制。
            *   等等，参考解析中说 A 是“有效”的，但正确答案是 D。这说明题目可能存在多解，或者我对“表示”的理解有误，或者题目隐含了“最小正整数”或其他约束？
            *   再读题：“如果一个 2 字节无符号整数...”。
            *   让我们重新检查参考解析的逻辑。参考解析似乎认为 A 是有效的，但最后选了 D？不，参考解析里写的是“选项1... (有效)”，然后“选项2... (无效)”，最后正确答案给的是 D。这通常意味着 A 和 D 都满足数学条件，但 D 是更“标准”或“典型”的答案？或者 A 选项的解析有误？
            *   让我们仔细看参考解析对 A 的描述：“小端序表示：内存为 65 66... 数值 N_l = 0x6665... 差值 255 (有效)”。
            *   如果 A 和 D 都满足数学条件，为什么选 D？
            *   可能原因1：题目问的是“表示”，在某些语境下，`0x0100` 这种边界情况更常作为考点。
            *   可能原因2：我对“表示”的理解。如果“表示”指的是**内存中的字节序列**，那么对于 D ($N_L=0x0100$)，内存是 `00 01`。对于 A ($N_L=0x6665$)，内存是 `65 66`。
            *   如果选项指的是**内存字节的十六进制拼接**（即 `0xB0B1`）：
                *   D 选项 `0x0100` 若指内存 `01 00`，则 $B_0=01, B_1=00$。$N_L = 0x0001 = 1$。$N_B = 0x0100 = 256$。$1-256 = -255$。不符。
                *   D 选项 `0x0100` 若指内存 `00 01` (即 $B_0=00, B_1=01$)，则数值为 $0x0100$。这符合前面的推导。但通常 `0x0100` 这个写法本身就是一个数值。
            *   **结论**：在408考研中，这类题目通常考察的是**位权差**。$N_L - N_B = 255(B_1 - B_0)$。要使差为255，必须 $B_1 - B_0 = 1$。
            *   选项D: $0x0100$。分解为字节 $01, 00$。若这是小端数值，则 $B_1=01, B_0=00$。$B_1-B_0=1$。成立。
            *   选项A: $0x6665$。分解为字节 $66, 65$。若这是小端数值，则 $B_1=66, B_0=65$。$B_1-B_0=1$。成立。
