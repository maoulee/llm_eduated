# 2014年 Q13 — 定点补码加减法溢出判断

## 基本信息
- **年份**: 2014  **题位**: Q13  **题型**: 选择题
- **知识点**: 定点补码表示范围, 补码加减运算规则, 溢出判断
- **考纲对应**: 第二章 数据的表示和运算 → 定点数的运算 → 补码加减运算 / 溢出判断

## 题干原文
[2014年考研真题第13题]若x=103,y=-25,则下列表达式采用8位定点补码运算实现时，会发生溢出的是。
A.x+y 
B. - X+y 
C. x-y 
D.-X-y

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆8位补码的表示范围（-128 ~ +127）以及补码加减运算的基本规则（如减法变加法、负数的补码表示），仅凭常识或模糊概念无法准确判断边界值。若记忆不牢，容易混淆127和128的边界。
- **K2 = 2**: 2 — 仅需进行简单的十进制加减运算或一步补码转换，数字较小且友好，无复杂计算。
- **K3 = 1**: 1 — 无需多步串行推演，每个选项独立计算，路径极其简短。
- **K4 = 4**: 4 — 隐含前提极深：考察对“溢出”定义的精确理解，特别是边界值（127/128 和 -128）的处理。B选项 -128 是合法的最小值而非溢出，这是典型的反直觉陷阱；若未深入理解补码非对称性，极易误判。
- **K5 = 1**: 1 — 单一知识点（数据表示与运算）内部解决，不涉及其他系统。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给出具体数值参数，选项对应四个不同的运算结果状态，需通过计算判断哪个结果超出了数据类型的表示范围。

## 选项级分析
- **选项A**: [干扰] — 针对基础计算错误。$103 + (-25) = 78$，在 $[-128, 127]$ 范围内，未溢出。粗心学生可能误算或误以为正负相加必溢出。
- **选项B**: [干扰] — 针对边界值认知错误（核心陷阱）。$-103 + (-25) = -128$。8位补码最小值为 $-128$ ($10000000_2$)，该结果是合法的，**未溢出**。考生常误认为“达到最小值即溢出”或混淆补码与源码的边界。
- **选项C**: [正确] — 考察溢出本质。$103 - (-25) = 103 + 25 = 128$。8位补码最大值为 $127$，$128$ 超出了表示范围，发生**正溢出**。
- **选项D**: [干扰] — 针对符号处理错误。$-103 - (-25) = -103 + 25 = -78$，在范围内，未溢出。
- **干扰策略**: 边界值迷惑

## 核心陷阱
- **核心陷阱**: 补码表示范围的边界特殊性（$-2^{n-1}$ 是合法值，而 $+2^{n-1}$ 是溢出值）。
- **错误路径**: 学生可能错误地认为 $\pm 128$ 在8位系统中都溢出，或者误以为 $-128$ 是溢出标志，从而在B和C之间犹豫或选错。

## 考察能力
精准掌握定点补码的表示范围边界及加减法溢出判定机制，特别是区分“合法边界值”与“溢出值”的能力。
