# 2014年 Q13 — 定点补码加减法溢出判断

## 基本信息
- **年份**: 2014  **题位**: Q13  **题型**: 选择题
- **知识点**: 定点补码表示范围, 补码加减运算, 溢出判断
- **考纲对应**: 第二章 数据的表示和运算 → 定点数的运算 → 补码加减运算及溢出判断

## 题干原文
[2014年考研真题第13题]若x=103,y=-25,则下列表达式采用8位定点补码运算实现时，会发生溢出的是。
A.x+y 
B. - X+y 
C. x-y 
D.-X-y

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆8位补码的表示范围（-128 ~ +127）以及溢出判断的基本规则才能入题。若仅知概念不知具体数值范围（N-1），无法判断是否溢出；若需辨析双符号位等复杂机制（N+1），此题并未涉及，属于标准核心概念记忆。
- **K2 = 3**: 3 — 需代入加减法公式进行计算，涉及负数补码转换或符号处理，且结果触及边界值（128）。虽然计算量不大，但涉及非2的幂次的具体数值运算，且需警惕边界，符合标准难度；并非极度繁杂计算（N-4）。
- **K3 = 1**: 1 — 无需多步串行推演。确定表达式值后，直接比对范围即可得出是否溢出的结论，路径唯一且简短。
- **K4 = 3**: 3 — 存在明确的“边界值陷阱”。8位补码范围不对称（-128到127），考生若误以为范围是对称的（-127到+127）或忽略-128这个特殊值，就会在B选项上犯错；同时需识别“溢出”定义（结果超出表示范围），这是典型的明确陷阱词。
- **K5 = 1**: 1 — 单一知识点（数据表示与运算）内部解决，不涉及指令系统、存储器等其他系统联动。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给定具体数值和运算表达式，四个选项分别代表四种不同的运算结果状态，考生需通过计算验证哪个结果超出了表示范围。

## 选项级分析
- **选项A**: [干扰] — x+y = 103 + (-25) = 78。考察基础混合运算。针对未掌握补码减法转化为加法，或简单算术错误的学生。结果在范围内，不溢出。
- **选项B**: [干扰] -x+y = -103 + (-25) = -128。考察**边界值认知**。8位补码最小值为-128，该结果刚好能表示，**不溢出**。这是最强干扰项，针对误以为-128会溢出（以为范围是-127~127）或记错最小值的学生。
- **选项C**: [正确] x-y = 103 - (-25) = 128。考察**正溢出**。8位补码最大值为127，128超出范围，发生溢出。针对能准确计算并熟知+127边界的学生。
- **选项D**: [干扰] -x-y = -103 - (-25) = -78。考察基础混合运算。结果在范围内，不溢出。
- **干扰策略**: 边界值迷惑

## 核心陷阱
- **核心陷阱**: 8位补码表示范围的不对称性（-128 ~ +127）。

## 考察能力
准确记忆定点补码的数值表示范围，并能快速进行整数加减运算及边界溢出判断的能力。
