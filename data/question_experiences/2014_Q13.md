# 2014年 Q13 — 定点补码加减法溢出判断

## 基本信息
- **年份**: 2014  **题位**: Q13  **题型**: 选择题
- **知识点**: 定点补码表示范围, 补码加减法溢出判断
- **考纲对应**: 第二章 数据的表示和运算 → 运算方法和电路 → 补码加减

## 题干原文
[2014年考研真题第13题]若x=103,y=-25,则下列表达式采用8位定点补码运算实现时，会发生溢出的是。
A.x+y 
B. - X+y 
C. x-y 
D.-X-y

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆8位补码的表示范围（-128 ~ +127）以及溢出判定规则（同号相加/异号相减可能溢出）。若不知道范围上限是127而非255或128，无法解题；若仅知概念不知具体数值边界，也无法判断C选项是否溢出。
- **K2 = 2**: 2 — 仅需进行简单的整数加减法心算（103+25, 103-25等），数字友好，无复杂计算步骤。
- **K3 = 1**: 1 — 无需多步串行推演，每个选项对应独立的算术运算，得出结果后直接比对范围即可。
- **K4 = 4**: 4 — 存在极深的隐含前提陷阱：
- **K5 = 1**: 1 — 单一知识点内部解决，仅涉及定点数运算，不涉及浮点、逻辑运算或其他子系统。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给定具体数值，要求通过计算判断哪个运算结果会导致溢出，本质是数值计算与范围比对的结合。

## 选项级分析
- **选项A**: [干扰] — $x+y = 103 + (-25) = 78$。结果在[-128, 127]内，不溢出。针对计算粗心或符号处理错误的学生。
- **选项B**: [干扰] — $-x+y = -103 + (-25) = -128$。结果为-128，恰好是8位补码的最小值（$10000000_2$），**在表示范围内，不溢出**。这是本题最大陷阱，针对误以为“-128溢出”或“绝对值超过127即溢出”的学生。
- **选项C**: [正确] — $x-y = 103 - (-25) = 103 + 25 = 128$。8位补码最大值为127（$01111111_2$），128超出范围，发生正向溢出。
- **选项D**: [干扰] — $-x-y = -103 - 25 = -128$。同B选项，结果-128不溢出。针对符号处理错误（如算成-78或其他）的学生。
- **干扰策略**: 嵌套陷阱

## 考察能力
精准掌握8位补码表示范围边界（-128至127）及溢出严格定义，并能在正负号混合运算中快速定位越界值。
