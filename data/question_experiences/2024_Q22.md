# 2024 Q22 — DMA数据传输通路定位

## 基本信息
- **年份**: 2024  **题位**: Q22  **题型**: 选择题
- **知识点**: DMA, 组成原理>DMA
- **题位域**: 待标注  **科目**: 组成原理

## 题干原文
DMA 方式中，DMA 控制器控制的数据传输通路位于（ ）。
A: CPU 和主存之间
B: CPU 和 DMA 控制器之间
C: 设备接口和主存之间
D: 设备接口和 DMA 控制器之间

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。本题属于标准的基础概念记忆题。考生需要准确回忆 DMA（直接存储器访问）的核心定义，即“外设与主存之间直接进行数据交换，无需 CPU 干预”。不需要辨析多个易混概念（如与中断方式的区别细节），只需掌握核心定义即可得分，故为 3 分。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全属于定性分析，故为 1 分。
- **K3 = 1**: 评分理由。解题过程无需多步推演，直接从“DMA 的定义”映射到“数据传输路径”，一步到位，故为 1 分。
- **K4 = 2**: 评分理由。存在轻微的隐含前提，即考生需理解“控制”与“传输”的区别。DMA 控制器虽然发起请求并管理总线，但实际的数据通路是绕过 CPU 的。若考生误以为 DMA 控制器本身是数据中转站（类似 CPU 的角色），可能会选 D。这是一个常规的概念注意点，故为 2 分。
- **K5 = 2**: 评分理由。题目涉及 CPU、主存、设备接口、DMA 控制器四个组件，但仅考察其中两两之间的直接连接关系（设备接口 <-> 主存），并未涉及复杂的跨子系统状态传递或深度耦合逻辑，故为 2 分。
- **雷达形状**: K1 主导型（概念记忆型）。K1 分数最高，其他维度极低，呈现典型的“基础概念考察”特征。

## 考察模式
- **模式**: 概念型
- **理由**: 本题直接考察计算机组成原理中 DMA 方式的基本工作原理和系统结构连接关系，不涉及计算或复杂逻辑推理，完全依赖对教材核心定义的识记和理解。

## 选项级分析
- **选项 A**: [干扰] — 针对“程序查询/中断方式”的错误认知。在程序查询或中断方式中，数据确实经过 CPU 寄存器在 CPU 和主存之间传输。选此项的学生可能混淆了 DMA 与传统 I/O 方式的区别，未意识到 DMA 的核心优势就是绕过 CPU。
- **选项 B**: [干扰] — 针对“控制流与数据流混淆”的错误认知。CPU 和 DMA 控制器之间确实存在交互（如 DMA 请求、CPU 响应、参数设置），但这属于控制信号或配置信息的传递，而非 DMA 方式下主要的“数据传输通路”。选此项的学生可能将“控制关系”误认为是“数据传输路径”。
- **选项 C**: [正确] — DMA 的核心定义。DMA 控制器接管总线后，直接在 I/O 设备接口（外设）和主存之间建立数据通路，实现高速数据传输。
- **选项 D**: [干扰] — 针对“DMA 控制器作为中转站”的错误认知。部分学生可能认为数据先传到 DMA 控制器，再由 DMA 控制器写入内存。实际上，DMA 控制器只是仲裁者和计数器，数据并不经过 DMA 控制器内部的寄存器缓冲（除非特定架构，但通用模型中不经过），而是直接通过系统总线在设备和内存间传输。选此项的学生对 DMA 控制器的硬件角色理解有误。
- **干扰策略**: 概念混淆。通过列举系统中存在的其他连接关系（如 CPU-DMA 的控制连接、CPU-主存的传统连接）来干扰考生对“DMA 特有数据通路”的识别。

## 核心陷阱
- **核心陷阱**: 混淆“控制通路”与“数据通路”，以及混淆“DMA 方式”与“中断/程序查询方式”的数据流向。考生容易误以为 DMA 控制器像 CPU 一样参与数据的搬运（选 D），或者忘记 DMA 绕过 CPU 这一核心特征（选 A）。

## 考察能力
本题核心考察考生对 DMA 方式基本工作原理及系统总线连接结构的准确记忆与理解能力。
