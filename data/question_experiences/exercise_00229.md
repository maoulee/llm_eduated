# 练习题 Q1 — 完全n叉树节点数关系

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/二叉树
- **难度**: 待评估

## 题干原文
在完全 n 叉树中，每个节点要么有 n 个子节点，要么没有子节点。设 I 为内部节点数，L 为叶子节点数。若 L = 41 且 I = 10，求 n 的值（ ）。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆完全 n 叉树中叶子节点数与内部节点数的核心公式 $L = (n-1)I + 1$。如果不记忆该公式，仅靠二叉树经验（$L=I+1$）无法解题，需调用特定概念定义，故为标准难度。
- **K2 = 2**: 评分理由。计算过程为简单的线性方程求解：$41 = 10(n-1) + 1 \Rightarrow 40 = 10(n-1) \Rightarrow n-1=4 \Rightarrow n=5$。数字友好，无复杂运算，不易出错。
- **K3 = 1**: 评分理由。解题路径极短，识别公式后直接代入计算即可，无需多步串行推演或状态维护。
- **K4 = 2**: 评分理由。题干明确给出了“完全 n 叉树”及“每个节点要么有 n 个子节点，要么没有子节点”的定义，排除了普通 n 叉树的歧义。唯一的潜在陷阱是混淆二叉树公式，但题干条件清晰，属于常规注意点。
- **K5 = 1**: 评分理由。本题仅涉及数据结构中树的静态性质，不涉及算法流程、内存管理或其他子系统，为单系统内部问题。
- **雷达形状**: K1主导型（概念记忆型）。K1分数中等，其余维度分数较低，呈现典型的“公式记忆+简单代入”特征。

## 考察模式
- **模式**: 计算型
- **理由**: 虽然核心在于公式记忆，但最终落脚点是通过代数计算求解未知数 $n$，且计算过程简单直接，符合计算型题目的特征。

## 选项级分析
- **选项 A (6)**: [干扰] — 针对计算错误或对公式变形错误的学生。例如误以为 $L = n \times I + 1$，则 $41 = 60 + 1$ 不成立；或者在解方程 $10(n-1)=40$ 时算错。也可能是随机猜测。
- **选项 B (3)**: [干扰] — 针对混淆二叉树性质的学生。若学生错误地套用二叉树公式 $L = I + 1$，会发现 $41 \neq 10 + 1$，从而意识到不是二叉树。若强行用 $L = nI$ 估算，$41 \approx 3 \times 10$ 可能误导部分学生。
- **选项 C (4)**: [干扰] — 针对公式记忆偏差的学生。例如记成 $L = nI - 1$ 或其他变体，或者在计算 $n-1=4$ 后忘记加 1，直接选 4。这是最常见的“差一错误”陷阱。
- **选项 D (5)**: [正确] — 正确应用公式 $L = (n-1)I + 1$ 并正确求解的结果。
- **干扰策略**: 概念混淆（二叉树 vs n叉树）与计算陷阱（忘记加1或公式记错）。

## 核心陷阱
- **核心陷阱**: 混淆二叉树与完全 n 叉树的节点关系公式。二叉树中 $L = I + 1$，而完全 n 叉树中 $L = (n-1)I + 1$。学生若未区分清楚，可能无法建立正确的方程，或在解出 $n-1$ 后忘记还原 $n$。

## 考察能力
本题核心考察对完全 n 叉树结构性质公式的记忆及其在简单代数情境下的应用能力。
