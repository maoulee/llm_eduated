# 2012 Q37 — IP路由器功能辨析

## 基本信息
- **年份**: 2012  **题位**: Q37  **题型**: 选择题
- **知识点**: CN-4 > 网络层设备 > 路由器, CN-4 > 网络层功能 > 路由选择, CN-4 > 网络层功能 > 分组转发, CN-4 > 网络层功能 > 拥塞控制, CN-4 > IPv4 > 首部校验和
- **题位域**: 待标注  **科目**: 计算机网络

## 题干原文
下列关于 IP 路由器功能的描述中，正确的是（ ）。
I. 运行路由协议，设置路由表
II. 监测到拥塞时，合理丢弃 IP 分组
III. 对收到的 IP 分组头进行差错校验，确保传输的 IP 分组不丢失
IV. 根据收到的 IP 分组的目的 IP 地址，将其转发到合适的输出线路上
路由器

A. 仅 III、IV
B. 仅 I、II、III
C. 仅 I、II、IV
D. I、II、III、IV

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题需要考生准确记忆并区分路由器的四大核心功能（路由选择、分组转发、拥塞控制、差错处理）。特别是需要辨析“差错校验”与“可靠传输”的区别，这涉及对IP协议无连接、不可靠特性的深层概念记忆，属于易混概念辨析。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算或单位换算，完全基于概念判断。
- **K3 = 2**: 评分理由。推演过程较短，主要是对四个陈述句逐一进行真伪判断。虽然需要结合IP协议特性进行逻辑验证，但不需要多步串行推演，属于直接的概念映射。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。陈述III中的“确保传输的IP分组不丢失”是典型的反直觉陷阱，因为IP层本身不提供可靠性保证（那是TCP层的事）。考生必须意识到“校验和仅用于检测首部错误，发现错误即丢弃，而非重传或保证不丢失”这一隐含前提，否则极易误选。
- **K5 = 2**: 评分理由。主要考察网络层内部功能，虽然提及拥塞控制（涉及网络状态）和差错校验（涉及数据完整性），但不需要跨越多个子系统（如从应用层到物理层）进行复杂的状态传递或耦合分析，仅涉及网络层设备的基本职责界定。
- **雷达形状**: K4陷阱型（K1较高，K4显著突出，K2极低）

## 考察模式
- **模式**: 概念型
- **理由**: 题目完全基于对计算机网络体系结构中网络层设备（路由器）功能的定义、特性及局限性的理解，不涉及计算或复杂逻辑推理，核心在于辨析概念的正误。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：认为路由器不负责路由表维护（I）和拥塞控制（II），只负责转发和校验。这类学生可能混淆了交换机（二层）和路由器（三层）的功能，或者误以为拥塞控制完全是传输层（TCP）的任务。
- **选项B**: [干扰] — 针对错误认知：认为路由器能保证分组不丢失（III）。这类学生可能将IP层的“差错检测”误解为“差错纠正”或“可靠传输”，混淆了网络层与传输层（TCP）的职责边界。
- **选项C**: [正确] — 正确组合。I（路由选择）、II（拥塞控制/源抑制）、IV（分组转发）均为路由器标准功能。III错误，因为IP校验和仅保证首部正确，且IP协议本身是不可靠的，不保证不丢失。
- **选项D**: [干扰] — 针对错误认知：认为所有描述都正确。这类学生通常对IP协议的“不可靠性”理解不深，容易被“差错校验”这个词误导，认为校验了就能保证不丢失。
- **干扰策略**: 概念混淆（主要混淆“差错检测”与“可靠传输”）、渐进陷阱（通过看似合理的描述III诱导全选）

## 核心陷阱
- **核心陷阱**: 陈述III中的“确保传输的 IP 分组不丢失”。这是本题最大的陷阱。IP协议提供的是**尽力而为（Best Effort）**的服务，其首部校验和仅用于检测**首部**在传输过程中是否出错。如果校验失败，路由器直接丢弃该分组，**不会**重传，也**不保证**分组最终能到达目的地（不丢失）。保证不丢失是上层协议（如TCP）的职责。考生若未深刻记忆IP协议的“不可靠”特性，极易在此处失分。

## 考察能力
一句话概括本题核心考察的能力：准确辨析IP路由器在网络层的核心功能及其局限性，特别是区分“差错检测”与“可靠传输”的概念边界。
