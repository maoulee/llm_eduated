# 练习题 Q1 — 二叉树节点度与边数变换分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/二叉树
- **难度**: 待评估

## 题干原文
一棵具有 $n>1$ 个节点的二叉树中，分别有 $n_1$、$n_2$ 和 $n_3$ 个度为一、二和三的节点。节点的度定义为其相邻节点的数量。从上述树开始，在树中仍存在度为二的节点时，添加一条边连接该节点的两个相邻节点，然后移除该节点。最终将剩下多少条边？（ ）
A: $2n_1 - 3$
B: $n_2 + 2n_1 - 2$
C: $n_3 - n_2$
D: $n_2 + n_1 - 2$

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握二叉树的基本定义（节点度、边数与节点数的关系 $E=N-1$）。虽然涉及“度为3”这一在标准二叉树中不存在的概念，但题目明确定义了“节点的度定义为其相邻节点的数量”，因此考生需具备将通用图论概念映射到树结构上的基础认知，属于标准难度。不是4分因为题目给出了度的明确定义，无需辨析易混概念。
- **K2 = 3**: 评分理由。涉及代数表达式的推导。需要计算初始边数，并建立关于操作次数 $k$ 的方程。计算过程涉及简单的加减法和代数变形，非2的幂次友好，但也不复杂，属于标准计算难度。
- **K3 = 4**: 评分理由。推演步骤较多且逻辑链条长。
    1. 识别初始状态（边数 $n-1$）。
    2. 分析单次操作对边数的影响（+1 -2 = -1）。
    3. 确定操作终止条件（无度为2节点）。
    4. 关键推演：分析操作过程中 $n_1, n_2, n_3$ 的变化规律，或者利用不变量（如叶子节点数或总度数关系）来求解最终状态。
    5. 结合二叉树性质（$n_0 = n_2 + 1$ 的变体或通用树的度数公式）进行最终代数化简。
    由于需要多步串行推演，且中间状态（操作后的树结构）需要抽象理解，故评为4。
- **K4 = 4**: 评分理由。存在隐含前提和反直觉陷阱。
    1. **陷阱1**：题目提到“度为3的节点”，这违背了常规二叉树（最大度为2）的定义，考生需意识到这是一棵“广义树”或题目重新定义了度，不能直接套用 $n_0 = n_2 + 1$ 而不加验证。
    2. **陷阱2**：操作“连接两个相邻节点并移除中间节点”实际上是将路径 $A-B-C$ 变为 $A-C$。考生需意识到这不会改变树的连通性，且最终剩下的结构依然是一棵树（或森林，但题目暗示连通）。
    3. **陷阱3**：最终剩下的节点中，原度为1的节点可能变成度为2（如果其邻居被移除），原度为3的节点可能变成度为2或1。直接假设 $n_1$ 不变是常见错误。需要识别出“最终剩下的边数”与“初始 $n_1$”之间的深层代数关系，而非简单的计数。
- **K5 = 2**: 评分理由。主要局限于数据结构中的树与图的基本性质。虽然涉及图的操作（加边删点），但未跨越到操作系统、网络或组成原理等其他子系统，属于单系统内的深度应用。

- **雷达形状**: K3/K4 双高型（推理与陷阱主导）

## 考察模式
- **模式**: 综合型
- **理由**: 本题结合了概念理解（度的定义）、机制推演（操作对图结构的影响）和代数计算（利用度数公式求解）。它不是单纯的记忆题，也不是简单的公式代入，而是需要通过逻辑推演建立初始状态与最终状态之间的数学关系。

## 选项级分析
- **选项A**: [正确] — 正确答案。
    *推导简述*：
    设初始节点总数 $N = n_0 + n_1 + n_2 + n_3$（注意：题目只给了 $n_1, n_2, n_3$，隐含 $n_0$ 为度为0的节点，即叶子。但在题目语境下，通常 $n_1$ 指度为1，$n_2$ 指度为2，$n_3$ 指度为3。若题目未提及 $n_0$，需考虑是否 $n_1$ 包含了叶子？不，通常 $n_i$ 表示度为 $i$ 的节点数。对于树，$\sum n_i = N$。
    通用树的性质：$\sum_{i} i \cdot n_i = 2(N-1)$。
    即 $1\cdot n_1 + 2\cdot n_2 + 3\cdot n_3 + 0\cdot n_0 = 2(n_0 + n_1 + n_2 + n_3 - 1)$。
    化简得：$n_1 + 2n_2 + 3n_3 = 2n_0 + 2n_1 + 2n_2 + 2n_3 - 2 \Rightarrow n_3 + 2 = n_0 + n_1$。
    
    操作分析：每次移除一个度为2的节点，边数减1。共移除 $n_2$ 个节点（假设所有度为2的节点最终都被移除，或者操作直到没有度为2的节点为止。注意：移除一个度为2的节点可能会产生新的度为2的节点，也可能消除度为2的节点。但题目说“在树中仍存在度为二的节点时...移除该节点”，这暗示了一个过程。
    
    更巧妙的视角：
    最终剩下的树中，没有度为2的节点。
    设最终剩下的节点数为 $N'$，边数为 $E'$。
    由于每次操作边数减1，且共进行了 $k$ 次操作。
    关键在于确定 $k$。
    
    让我们重新审视题目中的“度为3”。在标准二叉树中不存在度为3。这说明题目中的“二叉树”可能指“每个节点最多有两个孩子”的二叉树，但“度”定义为“相邻节点数”（即图论中的度）。在二叉树中，根节点度最大为2（左右孩子），非根节点度最大为3（父+左+右）。
    所以，$n_3$ 是内部节点（非根，且有左右孩子），$n_2$ 可能是根（有1或2孩子）或内部节点（只有1个孩子），$n_1$ 可能是叶子（只有父）或根（只有1孩子）。
    
    操作：移除度为2的节点 $v$，连接其两个邻居 $u, w$。
    这相当于在图中收缩边。
    
    让我们使用不变量法。
    对于任意树，边数 $E = N - 1$。
    初始边数 $E_{start} = n_0 + n_1 + n_2 + n_3 - 1$。
    每次操作：$N$ 减 1，$E$ 减 1。
    所以 $E_{final} = N_{final} - 1$ 依然成立。
    
    我们需要求 $E_{final}$。
    最终状态：没有度为2的节点。
    这意味着最终树中，所有节点的度只能是 0, 1, 3 (或更高，但原树最大度3，操作不会增加最大度，只会减少或保持，连接两个邻居，新节点的度是 $deg(u)-1 + deg(w)-1$? 不，是 $u$ 和 $w$ 直接相连。$u$ 的度变为 $deg(u)-1+1=deg(u)$? 不。
    原结构 $u-v-w$。$v$ 度为2。
    移除 $v$，添加边 $(u,w)$。
    $u$ 的度数变化：失去邻居 $v$，获得邻居 $w$。度数不变。
    $w$ 的度数变化：失去邻居 $v$，获得邻居 $u$。度数不变。
    其他节点度数不变。
    **关键发现**：该操作**不改变**除被移除节点外其他所有节点的度数！
    
    因此，最终剩下的节点集合中，每个节点的度数等于其在原树中的度数。
    但是，被移除的节点是度为2的节点。
    题目说“在树中仍存在度为二的节点时...移除”。
    这意味着所有**初始**度为2的节点都会被移除吗？
    不一定。移除一个度为2的节点，不会改变其他节点的度数。
    所以，如果初始有一个度为2的节点，它会被移除。移除后，其他节点度数不变。
    因此，**所有初始度为2的节点 $n_2$ 都会被移除**。
    而且，操作过程中**不会生成**新的度为2的节点（因为其他节点度数不变）。
    也不会**消除**其他度为2的节点（因为其他节点度数不变）。
    所以，操作次数 $k = n_2$。
    
    最终边数 $E_{final} = E_{start} - k = (N - 1) - n_2$。
    $N = n_0 + n_1 + n_2 + n_3$。
    $E_{final} = n_0 + n_1 + n_2 + n_3 - 1 - n_2 = n_0 + n_1 + n_3 - 1$。
    
    我们需要用 $n_1, n_2, n_3$ 表示 $n_0$。
    利用树的度数公式：$\sum deg(v) = 2(N-1)$。
    $0\cdot n_0 + 1\cdot n_1 + 2\cdot n_2 + 3\cdot n_3 = 2(n_0 + n_1 + n_2 + n_3 - 1)$。
    $n_1 + 2n_2 + 3n_3 = 2n_0 + 2n_1 + 2n_2 + 2n_3 - 2$。
    $n_3 + 2 = n_0 + n_1$。
    所以 $n_0 = n_3 + 2 - n_1$。
    
    代入 $E_{final}$：
    $E_{final} = (n_3 + 2 - n_1) + n_1 + n_3 - 1$
    $E_{final} = 2n_3 + 1$。
    
    等等，选项里没有 $2n_3 + 1$。
    让我们检查选项 A: $2n_1 - 3$。
    如果 $E_{final} = 2n_3 + 1$，且 $n_0 = n_3 + 2 - n_1$。
    这似乎与选项不符。让我重新检查“度数不变”的结论。
    
    操作：移除 $v$ (deg=2)，连接 $u, w$。
    $u$ 原邻居：$v, ...$。新邻居：$w, ...$。
    如果 $u$ 和 $w$ 原本不相连，则 $u$ 的度数：$-1 (v) + 1 (w) = 0$ 变化。
    是的，度数不变。
    
    那么 $E_{final} = 2n_3 + 1$ 应该是对的。
