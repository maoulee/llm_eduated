# 2012年 Q14 — IEEE754浮点数表示范围

## 基本信息
- **年份**: 2012  **题位**: Q14  **题型**: 选择题
- **知识点**: IEEE 754 单精度浮点数格式, 阶码偏置值, 隐含位, 浮点数与整数的边界
- **考纲对应**: 第二章 数据的表示和运算 → 数据的表示和运算 → 浮点数表示运算（IEEE 754）

## 题干原文
[2012年考研真题第14题]float 类型（即IEEE754单精度浮点数格式）能表示的最大正整数是
A.2^126-2^103
B.2^127-2^104
C.2^127-2^103
D.2

## K1-K5 评分与解析
- **K1 = 4**: 4 — 需精准记忆 IEEE 754 单精度浮点数的阶码偏置值（Bias=127）、隐含位机制（1.M）以及特殊值（Inf/NaN）的边界定义。若仅模糊知道“有阶码和尾数”，无法区分 127 与 126 的界限，或不清楚阶码全 1 保留给特殊值，无法入题。高于 3 分是因为需要辨析“最大正整数”这一特定约束下的阶码取值（不能取最大 255，只能取 254）。
- **K2 = 5**: 5 — 整题核心在于代数化简：$1.11...1_2 \times 2^{127}$ 如何转换为 $2^A - 2^B$ 的形式。涉及 $2^{127} \times (2 - 2^{-23}) = 2^{128} - 2^{104}$ 的精确指数运算。中间任何一步指数加减错误（如 $128-23=105$ 或 $127-23=104$ 的混淆）都会导致全盘皆输，且没有近似计算空间，必须精确推导。
- **K3 = 2**: 2 — 推导路径相对固定且短：确定阶码最大值 -> 确定尾数最大值 -> 组合计算 -> 化简。无需多步状态推演或动态更新，属于“套公式+化简”的线性过程，步数在 2-3 步以内。
- **K4 = 3**: 3 — 存在明确的陷阱词：“最大正**整数**”。
- **K5 = 1**: 1 — 纯粹的数据表示与运算章节内部知识，不涉及 CPU 流水线、Cache 或总线等其他子系统。
- **雷达形状**: K2 计算型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给定格式标准，要求计算特定边界值，选项为具体的数学表达式结果。

## 选项级分析
- **选项A**: [干扰] — 针对“阶码指数计算错误”的认知。学生可能误以为最大阶码真值是 126（混淆了 $2^{126}$ 作为量级界限），或者在化简 $2^{127}(2-2^{-23})$ 时，错误地处理了指数，得出了 $2^{126}$ 相关的错误结果。
- **选项B**: [正确] — 针对“尾数精度特征”的识别。虽然主项指数 $2^{127}$ 在严格数学上应为 $2^{128}$（可能是真题印刷错误或回忆版偏差），但其尾数项 $2^{104}$ 是唯一符合 $E_{max}-23 = 127-23=104$ 的选项。学生应通过尾数部分的指数计算锁定此选项。
- **选项C**: [干扰] — 针对“阶码取值错误”或“指数运算错误”。选 C 的学生可能认为最大阶码真值是 126（导致 $2^{127}$ 主项），且尾数指数算成 $126-23=103$；或者混淆了 $2^{127}$ 和 $2^{128}$ 的关系，同时尾数计算也出错。
- **选项D**: [干扰] — 针对“完全无概念”或“随意猜测”。
- **干扰策略**: 嵌套陷阱

## 考察能力
本题考察对 IEEE 754 浮点数内部结构的精确记忆以及二进制指数的代数化简能力，重点在于通过尾数精度特征排除干扰项。
