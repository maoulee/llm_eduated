# 练习题 Q1 — 存储扩展容量计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 计算机组成原理/存储系统
- **难度**: 待评估

## 题干原文
需要多少个 32K×1 的 RAM 芯片才能提供 256K 字节的存储容量？（ ）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握存储芯片规格表示法（地址线×数据线）以及“字节”与“位”的基本换算关系。属于标准的基础概念记忆，不涉及复杂概念辨析。
- **K2 = 2**: 评分理由。计算过程涉及简单的除法运算，且数值均为2的幂次（32, 256, 8），计算友好，不易出错。只需执行一次总容量除以单片容量的操作。
- **K3 = 1**: 评分理由。解题逻辑为单步直接推导：总需求容量 / 单芯片容量 = 芯片数量。无需多步串行推演或中间状态记忆。
- **K4 = 3**: 评分理由。存在一个关键的隐含前提/陷阱：题干中目标容量单位是“字节（Byte）”，而芯片规格中的“1”代表“位（bit）”。考生必须意识到需要进行 1 Byte = 8 bits 的单位换算，否则极易漏乘8导致错误。这是一个典型的单位陷阱。
- **K5 = 1**: 评分理由。本题仅涉及存储系统内部的容量计算，不涉及CPU、总线、中断等其他子系统的状态传递或联动。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要难点在于识别单位差异）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过给定的参数进行数值计算，虽然涉及概念理解，但最终落脚点是通过公式得出具体数值。

## 选项级分析
- **选项A**: [干扰] — 针对**完全忽略位/字节换算且计算错误**的认知。如果考生误以为 256K / 32K = 8，且忽略了位宽差异，可能会选此项。或者考生正确进行了位宽扩展（8片位扩展），但错误地认为地址扩展不需要额外芯片（逻辑混乱）。
- **选项B**: [干扰] — 针对**仅进行位扩展，忽略地址扩展**的认知。考生知道 1 Byte = 8 bits，所以用 8 片芯片并联实现 32K×8（即32KB），但误以为 32KB 就是 256KB，或者混淆了 K 的含义，认为 32K 到 256K 只需要简单的倍数关系而未正确计算地址线扩展倍数（256/32=8，8*8=64，若只算位扩展则是8，若只算地址扩展则是8，这里B选项32可能是 4*8 的错误组合，或者误算 256/8=32）。更常见的错误路径是：先做位扩展得到 32K×8，此时容量为32KB。目标256KB。256/32 = 8组。每组8片。总共 8*8=64。如果考生算成 256/8 = 32，则是混淆了总位宽和组数。
- **选项C**: [正确] — 正确计算。总容量 256KB = 256 * 1024 * 8 bits。单片 32K * 1 = 32 * 1024 bits。数量 = (256 * 8) / 32 = 2048 / 32 = 64。
- **选项D**: [干扰] — 针对**重复换算或过度计算**的认知。例如，考生可能先算出需要 64 片，然后错误地认为还需要再乘以某个系数（如误以为地址线和数据线都要单独算两次），或者将 256K 误认为是 256 * 1024 * 8 * 2 等错误逻辑。另一种可能是将 32K 误读为 32 * 8 bits 进行计算导致偏差。

- **干扰策略**: 单位混淆陷阱（Byte vs bit）与 分步计算遗漏（位扩展 vs 字扩展）。

## 核心陷阱
- **核心陷阱**: **单位不一致**。题干目标容量为“字节（Byte）”，芯片数据位宽为“1位（bit）”。考生必须首先将目标容量转换为“位”，或者将芯片容量转换为“字节”（即 32K×1 芯片组成 32K×8 的模块，每个模块 32KB），否则直接相除会得到错误结果（8片）。

## 考察能力
一句话概括本题核心考察的能力：
考察考生对存储芯片位宽与字长关系的理解，以及在存储扩展设计中正确处理“位扩展”与“字扩展”及单位换算的能力。
