# 练习题 Q1 — fork()进程创建与地址空间独立性

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/进程管理
- **难度**: 待评估

## 题干原文
考虑以下代码片段：
```c
if (fork() == 0) {
    a = a + 5;
    printf("%d,%d\n", a, &a);
} else {
    a = a – 5;
    printf("%d, %d\n", a, &a);
}
```
设父进程打印的值为 u、v，子进程打印的值为 x、y。以下哪一项是正确的？
- 选项:
  A: u = x + 10 且 v = y
  B: u = x + 10 且 v != y
  C: u + 10 = x 且 v = y
  D: u + 10 = x 且 v != y

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握 `fork()` 系统调用的基本行为（返回值差异）以及虚拟内存的基本概念（虚拟地址与物理地址的区别）。这属于操作系统进程管理的核心定义，非零基础即可理解，但需准确记忆 `fork` 在父子进程中的不同返回值。
- **K2 = 2**: 评分理由。涉及简单的整数加减运算（`a+5` 和 `a-5`），计算量极小，几乎不可能出错，属于低难度计算。
- **K3 = 3**: 评分理由。需要执行多步逻辑推演：1. 识别 `fork` 分支；2. 分别追踪父子进程中变量 `a` 的值变化；3. 推导数值关系；4. 分析地址 `&a` 在虚拟内存层面的表现。步骤清晰但需串行执行，符合标准推演难度。
- **K4 = 4**: 评分理由。存在显著的“反直觉”陷阱。初学者常误以为 `fork` 后父子进程共享数据或地址，或者混淆虚拟地址与物理地址。题目未明确说明是虚拟地址还是物理地址，但 `printf("%p")` 或 `&a` 默认输出的是虚拟地址。识别“虚拟地址相同但物理地址不同”这一隐含前提是关键，属于较深的隐含前提陷阱。
- **K5 = 2**: 评分理由。主要考察进程管理模块内部的状态复制机制，虽然涉及内存管理（地址空间），但主要是进程创建时的标准行为，不涉及复杂的跨子系统状态传递或深度耦合。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要难点在于对虚拟地址概念的辨析和陷阱规避）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非单纯考察记忆或计算，而是要求考生根据 `fork()` 的语义规则，推理出父子进程在数据值和地址空间上的具体状态差异，特别是区分虚拟地址与物理地址的逻辑推理。

## 选项级分析
- **选项A**: [干扰] — 针对数值关系计算错误的学生。如果学生搞反了父子进程的加减操作（例如认为父进程加5，子进程减5），或者在推导 `u` 和 `x` 的关系时符号搞错，可能会得出 `u = x + 10`。同时，如果学生正确理解了虚拟地址相同，就会选A。
- **选项B**: [干扰] — 针对数值关系错误且地址概念错误的学生。既算错了数值关系，又错误地认为 `fork` 后地址不同（可能混淆了物理地址或认为完全独立导致地址随机化，尽管现代OS有ASLR，但在经典408考题语境下，`fork` 复制页表，虚拟地址通常视为一致）。
- **选项C**: [正确] — 正确推导了数值关系：设初始 `a` 为 `A`。子进程 `x = A + 5`，父进程 `u = A - 5`。则 `x - u = (A + 5) - (A - 5) = 10`，即 `x = u + 10` 或 `u + 10 = x`。同时正确识别了 `&a` 输出的是虚拟地址，`fork` 复制了父进程的页表，因此虚拟地址 `v` 和 `y` 相同。
- **选项D**: [干扰] — 针对数值关系正确但地址概念错误的学生。这类学生正确计算了数值，但错误地认为 `fork` 后父子进程的变量地址不同。这通常是因为混淆了“数据独立”（物理内存不同）与“地址独立”（虚拟地址不同）。在经典OS理论题中，`fork` 后虚拟地址空间是复制的，故虚拟地址相同。

- **干扰策略**: 概念混淆（数值计算陷阱 + 虚拟/物理地址概念混淆）

## 核心陷阱
- **核心陷阱**: **虚拟地址与物理地址的混淆**。
  许多考生知道 `fork` 后父子进程数据独立（修改互不影响），因此直觉上认为“地址也应该不同”。然而，`printf` 打印的 `&a` 是**虚拟地址**。`fork()` 通过复制页表实现地址空间隔离，子进程继承父进程的虚拟地址布局，因此虚拟地址相同。只有当发生写时复制（Copy-on-Write）并实际写入时，物理页才会分离，但虚拟地址保持不变。这是本题最大的认知陷阱。

## 考察能力
一句话概括本题核心考察的能力：
考生对 `fork()` 系统调用后进程地址空间复制机制（虚拟地址一致性 vs 物理地址独立性）及进程执行流分支逻辑的综合理解能力。
