# 2016 Q37 — RIP协议坏消息传播慢

## 基本信息
- **年份**: 2016  **题位**: Q37  **题型**: 选择题
- **知识点**: CN-4 > 路由协议 > RIP协议, CN-4 > 路由算法 > 距离向量算法, CN-4 > 路由算法 > 坏消息传播慢
- **题位域**: 待标注  **科目**: 计算机网络

## 题干原文
假设 R1、R2、R3 采用 RIP 协议交换路由信息，且均已收敛。若 R3 检测到网络 201.1.2.0/25 不可达，并向 R2 通告一次新的距离向量，则 R2 更新后，其到达该网络的距离是（ ）。

A. 2
B. 3
C. 16
D. 17

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握 RIP 协议的核心概念，特别是“距离为 16 表示不可达”这一特定定义，以及距离向量算法的基本工作原理。属于标准的基础认知需求，需记忆核心定义。
- **K2 = 2**: 评分理由。计算过程极其简单，仅涉及 `1 + 2 = 3` 的加法运算。没有复杂的数学换算或幂次计算，属于较低的单步代入需求。
- **K3 = 4**: 评分理由。推演过程涉及多步状态变化：1. R3 检测到故障并更新自身表项（距离变16）；2. R3 向 R2 发送更新；3. R2 接收更新，判断来自 R3 的路径不可达；4. R2 检查其他邻居（R1）的路由表项；5. R2 发现 R1 仍认为可达（距离2），且 R1 不是该路由的下一跳（隐含前提）；6. R2 根据 R1 的信息更新自身距离为 `1+2=3`。这需要考生在大脑中模拟路由表的动态更新过程，步骤较多且需保持中间状态，属于较高的机制推演需求。
- **K4 = 5**: 评分理由。本题最大的难点在于识别隐含前提和反直觉现象。题干只说了“R3 向 R2 通告”，并未明确说明 R1 的状态。考生必须意识到“坏消息传播慢”的机制，即 R1 尚未收到 R3 的故障通知，因此 R1 仍持有旧的正确路由（距离2）。如果考生没有意识到 R1 的状态滞后性，或者误以为 R2 会直接继承 R3 的不可达状态，就会出错。这是一个典型的反直觉陷阱，属于极高的条件路由需求。
- **K5 = 3**: 评分理由。需要在 R3、R2、R1 三个路由器之间传递路由状态信息。R3 的状态变化影响 R2，而 R2 的最终决策依赖于 R1 的旧状态。涉及单向的数据传递和状态依赖，属于标准的跨域联动需求。

- **雷达形状**: K4 陷阱型（K4 极高，K3 较高，K1 中等，K2 低）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非简单的概念记忆或公式计算，而是要求考生基于 RIP 协议的距离向量算法规则，结合“坏消息传播慢”这一特定现象，推演网络拓扑变化后各节点路由表的动态更新过程。重点在于逻辑推理和对协议行为机制的理解。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：认为 R2 到 R1 距离为 1，R1 到目标距离为 1（误记或误算），或者认为 R2 直接通过 R1 转发，距离为 1+1=2。这类学生可能忽略了 R1 到目标的实际距离是 2（R1->R3->目标，原距离为2，但R1不知道R3断了，所以R1认为距离是2？不对，原题解析说R1距离为2。如果R1直接连目标，距离是1。根据解析，R1到目标距离是2，说明R1->R3->目标。R2->R1->R3->目标。R2到R1是1，R1到目标是2，所以R2到目标是3。选A的学生可能误以为R1到目标距离是1，或者计算错误。
- **选项B**: [正确] — 正确推理结果。R3 通告不可达（16），R2 忽略来自 R3 的路由。R2 查看 R1 的路由，R1 仍认为可达且距离为 2。R2 更新距离为 `1 (R2->R1) + 2 (R1->目标) = 3`。
- **选项C**: [干扰] — 针对错误认知：认为 R2 直接继承了 R3 的不可达状态，但误以为不可达的值是 16，而题目问的是“距离”，有些学生可能混淆了“不可达”和“最大跳数+1”。或者，学生可能认为 R2 更新后距离变为 16（不可达），但选项里没有 16 作为最终答案的干扰项？等等，选项C是16。选C的学生认为 R2 收到 R3 的不可达通告后，直接将距离更新为 16。这是忽略了距离向量算法中“水平分割”或“毒性逆转”之外的另一种情况：如果 R2 是通过 R1 到达该网络的，它不会仅仅因为 R3 说不可达就把自己设为不可达，除非 R2 是通过 R3 到达该网络的。题目隐含 R2 是通过 R1 到达该网络的（否则如果 R2 是通过 R3 到达，R2 会直接设为 16）。解析中提到“记录 R1 可达”，暗示 R2 有另一条路径。选 C 的学生忽略了 R2 有其他邻居 R1 提供有效路由这一事实。
- **选项D**: [干扰] — 针对错误认知：认为 R2 更新后距离为 17。这可能是将不可达值 16 加上 1 得到的，或者是对 RIP 最大跳数 15 和不可达值 16 的混淆。这类学生可能对 RIP 的数值定义记忆模糊。

- **干扰策略**: 概念混淆（混淆不可达值与计算后的距离）、计算陷阱（忽略多路径选择）、隐含前提缺失（未意识到 R1 状态滞后）

## 核心陷阱
- **核心陷阱**: **“坏消息传播慢”导致的计数到无穷大（Count-to-Infinity）的前兆**。考生容易误以为一旦某个节点通告不可达，所有邻居都会立即变为不可达。实际上，在距离向量算法中，如果 R2 不是通过 R3 到达目标网络（即 R2 的下一跳是 R1），R2 会忽略 R3 的不可达通告，并继续信任 R1 的旧路由信息。由于 R1 尚未收到 R3 的故障通知，R1 仍认为路径可达，从而导致 R2 更新出一个错误的、较小的距离值（3），而不是不可达（16）。

## 考察能力
一句话概括本题核心考察的能力：理解并推演 RIP 协议中距离向量算法在链路故障时的动态更新过程，特别是识别“坏消息传播慢”现象及其对路由表项的影响。
