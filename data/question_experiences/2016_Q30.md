# 2016 Q30 — 进程地址空间隔离与临界区互斥

## 基本信息
- **年份**: 2016  **题位**: Q30  **题型**: 选择题
- **知识点**: 进程的互斥, 操作系统>进程的互斥
- **题位域**: 待标注  **科目**: 操作系统

## 题干原文
进程 P1 和 P2 均包含并发执行的线程，部分伪代码描述如下所示。
进程 P1
int x = 0;
Thread1() {
    int a;
    a = 1;
    x += 1;
}
Thread2() {
    int a;
    a = 2;
    x += 2;
}
进程 P2
int x = 0;
Thread3() {
    int a;
    a = x;
    x += 3;
}
Thread4() {
    int b;
    b = x;
    x += 4;
}
下列选项中，需要互斥执行的操作是（ ）。
进程的互斥
- 选项:
  A: a=1 与 a=2
  B: a=x 与 b=x
  C: x+=1 与 x+=2
  D: x+=1 与 x+=3
- 正确答案: C
- 解析（参考）: P1 中对 a 进行赋值，并不影响最终的结果，故 a = l 与 a = 2 不需要互斥执行；a = x 与 b = x 执行先后不影响 a 与 b 的结果，无须互斥执行；x+=1 与 x+=2 执行先后会影响 x 的结果，需要互斥执行；P1 中的 x 和 P2 中的 x 是不同范围中的 X，互不影响，不需要互斥执行。
- 知识标签: ['进程的互斥', '操作系统>进程的互斥']
- 知识域: CO-1

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题不仅考察“互斥”的定义，更核心的是考察“进程地址空间隔离”这一基础概念。如果考生混淆了进程（Process）与线程（Thread）在内存资源上的区别，认为所有变量都是全局共享的，就会直接误选D。需要辨析“进程间隔离”与“线程间共享”两个易混概念，故难度较高。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算，无需执行算术运算或单位换算。
- **K3 = 3**: 评分理由。推演步骤约为3-4步：1. 识别变量作用域（P1的x vs P2的x）；2. 识别线程共享资源（P1内Thread1/2共享x）；3. 分析操作原子性（x+=1非原子操作）；4. 判断并发冲突。逻辑链条清晰但需多步判断。
- **K4 = 4**: 评分理由。存在明显的隐含前提陷阱。题干明确标注“进程 P1”和“进程 P2”，但很多考生会惯性思维认为代码块中的变量名相同即为同一变量。必须意识到“进程拥有独立地址空间”这一隐含前提，才能排除D选项。这是一个典型的“反直觉”或“隐含前提深”的陷阱。
- **K5 = 2**: 评分理由。主要考察单系统（操作系统进程管理）内的概念。虽然涉及P1和P2两个进程，但它们之间没有数据传递或状态耦合，只是通过对比来考察隔离性，属于提及无关或弱关联。
- **雷达形状**: K4陷阱型（K1和K4较高，K2极低，呈现明显的概念辨析与陷阱规避特征）

## 考察模式
- **模式**: 概念型
- **理由**: 本题不依赖计算，而是依赖对操作系统核心概念（进程隔离、线程共享、临界区）的准确理解。解题关键在于识别代码结构背后的内存模型，而非执行具体的算法步骤。

## 选项级分析
- **选项A**: [干扰] — 针对“局部变量无需互斥”的认知。a是Thread1和Thread2各自的局部变量（栈空间独立），即使同名也不冲突。这类学生可能误以为同名变量即冲突，或者不理解局部变量的线程私有性。
- **选项B**: [干扰] — 针对“读操作无需互斥”的认知。a=x和b=x都是读操作，且分别位于P1和P2（不同进程），即使在同一进程内，纯读操作通常也不需要互斥（除非涉及可见性问题，但此处主要考察写冲突）。这类学生可能混淆了读写冲突与读读冲突。
- **选项C**: [正确] — 针对“临界区互斥”的正确认知。Thread1和Thread2属于同一进程P1，共享变量x。`x += 1` 和 `x += 2` 都是非原子操作（读-改-写），并发执行会导致竞态条件（Race Condition），因此必须互斥。
- **选项D**: [干扰] — 针对“进程间隔离”的认知盲区。x+=1在P1，x+=3在P2。由于进程地址空间隔离，P1的x和P2的x是两个完全不同的内存地址，互不影响。这类学生忽略了“进程”二字，误以为所有代码在一个全局上下文中运行。

- **干扰策略**: 概念混淆（进程vs线程）、作用域陷阱（局部变量vs全局变量）、原子性陷阱（复合操作vs原子操作）。

## 核心陷阱
- **核心陷阱**: **进程地址空间隔离**。考生极易忽略题干中“进程 P1”和“进程 P2”的界定，误以为变量 `x` 是全局共享的，从而错误地认为 P1 和 P2 中的操作存在竞争关系（误选D）。同时，需区分线程内局部变量（栈私有）与进程内全局变量（堆/数据区共享）的区别。

## 考察能力
一句话概括本题核心考察的能力：
准确区分进程与线程的资源共享边界，并识别非原子操作在共享资源上的竞态条件。
