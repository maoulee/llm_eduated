# 练习题 Q1 — 两级分页与TLB命中率下的EAT计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/存储管理
- **难度**: 待评估

## 题干原文
考虑一个采用两级分页机制的系统，常规内存访问耗时 150 ns，处理页面错误需 8 ms。平均指令需要 100 ns 的 CPU 时间和两次内存访问。TLB 命中率为 90%，页面错误率为每 10000 条指令发生一次。求有效平均指令执行时间（ ）？
- 选项:
  A: 645 ns
  B: 1050 ns
  C: 1215 ns
  D: 1260 ns
- 正确答案: D
- 解析（参考）: 请注意题目中页面错误率是每 10000 条指令发生一次页面错误。由于每条指令需要两次内存访问，因此计算平均指令执行时间时需要双倍的地址转换时间。当 TLB 未命中时，需要访问两次页表。假设 TLB 访问时间为 0。
因此：
计算公式分解：
平均 CPU 执行时间
= 100 ns
地址转换时间
TLB 命中（90%）：无需访问页表 →
0
TLB 未命中（10%）：需访问两级页表 →
2 × 150 ns = 300 ns
单次内存访问的地址转换时间：
0.9 × 0 + 0.1 × 300 = 30 ns
两次内存访问总地址转换时间：
2 × 30 = 60 ns
内存获取时间
每次内存访问
- 知识标签: ['操作系统/存储管理']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“两级分页”、“TLB命中/未命中”、“页面错误”、“有效访问时间（EAT）”等核心概念。不是4分因为不需要辨析多个易混概念，只需准确调用定义。
- **K2 = 4**: 评分理由。涉及多级时间单位换算（ms转ns）、加权平均计算、以及乘法分配律的应用。非2的幂次友好计算，且步骤较多，容易在数值计算上出错。
- **K3 = 4**: 评分理由。推演步骤超过5步：1.计算单次地址转换开销；2.计算指令内两次访问的总转换开销；3.计算指令内两次数据访问开销；4.计算页面错误带来的额外开销；5.汇总CPU时间、内存访问时间、页表访问时间、缺页开销。需记忆中间状态（如单次转换时间）。
- **K4 = 5**: 评分理由。存在极深的隐含前提和反直觉陷阱。1. “两级分页”意味着TLB未命中时需访问2次内存（而非1次）；2. “两次内存访问”意味着地址转换开销需乘以2；3. 页面错误率极低，但开销极大，需正确加权；4. 题目未明确说明TLB访问时间，需默认忽略或包含在命中时间内（参考解析暗示忽略或已包含）。这些条件若识别错误，结果偏差巨大。
- **K5 = 3**: 评分理由。主要涉及存储管理子系统内部的状态传递（TLB->页表->内存），属于单向数据流计算，未深度耦合CPU调度或I/O子系统，但需理解指令执行与内存访问的时序关系。
- **雷达形状**: K4陷阱型（高K4，中高K2/K3，中等K1/K5）

## 考察模式
- **模式**: 综合型
- **理由**: 本题不仅考察单一公式的代入，而是要求考生构建完整的指令执行时间模型，综合考量CPU计算、TLB加速、多级页表查找、数据访问以及异常处理（缺页）等多个维度的时间开销，属于典型的操作系统性能分析综合题。

## 选项级分析
- **选项A**: [干扰] — 针对**忽略两级分页特性**的错误认知。学生可能误以为TLB未命中只需访问1次页表（即150ns），或者忽略了“两次内存访问”带来的双倍转换开销。若按单次转换150ns*0.1=15ns，总转换30ns，加上其他项，结果会偏小。
- **选项B**: [干扰] — 针对**忽略页面错误开销**或**计算严重失误**的错误认知。1050ns接近纯CPU+内存访问的时间（100 + 2*150 + 2*30 = 460? 不对，可能是忽略了TLB未命中的页表访问开销，或者错误地认为TLB命中时间为0且未命中开销极小）。更可能的错误路径是：只计算了CPU时间和数据访问时间，完全忽略了地址转换的额外开销（100 + 2*150 = 400? 也不对）。另一种可能是：计算了EAT但漏掉了缺页开销，且对TLB未命中开销计算错误。实际上，1050ns可能是将缺页开销算错或漏算，且对TLB开销估算偏低的结果。
- **选项C**: [干扰] — 针对**忽略“两次内存访问”对地址转换的影响**的错误认知。学生可能正确计算了单次地址转换开销（30ns），但只加了一次（30ns）而不是两次（60ns）。或者，他们可能正确计算了数据访问（300ns）和CPU（100ns），但在地址转换上只算了一次指令级别的转换，而非每次内存访问都需转换。
- **选项D**: [正确] — 正确综合了所有因素：CPU时间(100) + 数据访问(2*150) + 地址转换(2*30) + 缺页开销(0.0001*8,000,000) = 100 + 300 + 60 + 800 = 1260 ns。
- **干扰策略**: 渐进陷阱。通过设置不同的遗漏项（漏掉两级页表、漏掉双倍转换、漏掉缺页开销）来生成干扰项，考察学生对每个时间组件贡献度的敏感度。

## 核心陷阱
- **核心陷阱**: **“两级分页”与“两次内存访问”的双重叠加效应**。
    1.  **两级分页**：TLB未命中时，不是访问1次内存查页表，而是访问**2次**内存（一级页表+二级页表）才能完成地址转换。
    2.  **两次内存访问**：一条指令执行过程中，取指和取操作数（或存结果）共需2次内存访问，因此**地址转换开销也要发生2次**。
    3.  **单位换算**：缺页处理时间8ms = 8,000,000ns，极易因单位未统一导致数量级错误。

## 考察能力
本题核心考察考生对**虚拟内存系统多层次访问时间开销的建模能力**，特别是能否准确识别并量化TLB命中率、页表层级结构、指令内存访问频率以及缺页异常对整体指令执行时间（EAT）的加权影响。
