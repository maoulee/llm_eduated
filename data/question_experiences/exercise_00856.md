# 练习题 Q1 — IP数据报首部字段在传输中的变化机制

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/网络层
- **难度**: 待评估

## 题干原文
主机 A（位于 TCP/IP v4 网络 A）向主机 B（位于 TCP/IP v4 网络 B）发送 IP 数据报 D。假设在传输过程中未发生错误。当 D 到达 B 时，以下哪些 IP 首部字段可能与原始数据报 D 不同？
(i) TTL
(ii) 校验和
(iii) 分片偏移
- 选项:
  A: (i) 仅
  B: (i) 和 (ii) 仅
  C: (ii) 和 (iii) 仅
  D: (i), (ii) 和 (iii)
- 正确答案: D
- 解析（参考）: 解析
所有 (i), (ii) 和 (iii) 都会变化
(i)
每经过一个路由跳点，TTL 都会递减，因此 TTL 值与原始值不同。
(ii)
由于 TTL 发生变化，数据包的校验和也会随之改变。
(iii)
如果数据包大小超过网络的最大传输单元（MTU），则会被分片。中间网络可能会通过分片修改分片偏移量。
- 知识标签: ['计算机网络/网络层']
- 知识域: CN-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆 IP 首部中 TTL、校验和、分片偏移这三个字段的基本定义及功能。属于标准的基础概念记忆，不涉及复杂辨析，但需准确知道哪些字段是“可变”的。不是4分因为不需要辨析多个易混概念（如区分源IP和目的IP的变化规则），只需回忆字段属性。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算或公式代入。无需执行计算步骤。
- **K3 = 3**: 评分理由。需要进行多步串行推演：首先判断 TTL 是否变化（经过路由器必变）；其次推导 TTL 变化对校验和的影响（首部变化导致校验和重算）；最后推导分片场景下分片偏移的变化（若发生分片，后续分片的偏移量非零）。这是一个包含条件分支（是否分片）和因果链（TTL变->校验和变）的3-5步推演过程。
- **K4 = 4**: 评分理由。存在隐含前提和陷阱。陷阱1：“未发生错误”容易让学生误以为“一切保持不变”，忽略了协议机制本身导致的正常变化（如TTL递减）。陷阱2：题目问的是“可能”不同，而非“一定”不同。对于分片偏移，只有当发生分片时才不同，但题目问的是可能性，因此必须考虑到分片场景。学生需识别出“可能”这一关键词，并意识到即使无错误，协议机制也会修改首部。
- **K5 = 2**: 评分理由。主要局限于网络层内部机制。虽然涉及路由（网络层）和分片（网络层），但不需要跨越到传输层或链路层进行深度状态联动。提及无关子系统较少，主要是网络层内部字段间的依赖关系（TTL与校验和）。

- **雷达形状**: K4陷阱型（K4显著高于K2，K1/K3中等，K5较低）

## 考察模式
- **模式**: 推理型
- **理由**: 本题不是简单的概念回忆（如“TTL的作用是什么”），而是要求考生根据网络传输过程（经过路由器、可能分片）推演首部字段的状态变化。特别是校验和的变化依赖于TTL的变化，分片偏移的变化依赖于MTU限制，这需要逻辑推理而非单纯记忆。

## 选项级分析
- **选项A**: [干扰] — 针对“只关注显式变化，忽略隐式依赖”的错误认知。这类学生知道TTL会递减，但忘记了IP首部校验和覆盖整个首部，TTL变了校验和必须重算；同时也忽略了分片的可能性。
- **选项B**: [干扰] — 针对“知道TTL和校验和联动，但忽略分片场景”的错误认知。这类学生正确推导了TTL->校验和的因果链，但认为“未发生错误”意味着数据完整传输，从而排除了分片（认为分片是异常或错误，或者认为题目暗示不分片）。他们未能理解“可能”一词涵盖了分片的情况。
- **选项C**: [干扰] — 针对“概念混淆”的错误认知。这类学生可能错误地认为TTL在传输中不变（误解为只有超时才检查TTL），或者认为校验和只保护数据部分。同时他们意识到了分片偏移可能变化。这种组合较少见，通常是对TTL机制理解偏差。
- **选项D**: [正确] — 正确识别了所有可能变化的字段。TTL因路由递减；校验和因TTL变化而重算；分片偏移因可能的分片操作而改变（即使原始数据报偏移为0，若被分片，后续分片偏移非0，且题目问的是到达B时的数据报D——若D被重组，则偏移恢复为0？注意：题目问的是“IP数据报D”，若D被分片，到达B的是多个分片，每个分片的偏移量与原始D（偏移0）不同；若D未被分片，则偏移不变。但题目问“可能”，故只要存在分片场景，偏移就可能不同。实际上，更严谨的理解是：如果D被分片，到达B的是分片，其偏移字段与原始D（偏移0）不同。如果D未被分片，偏移相同。因为问“可能”，所以(iii)入选。）

- **干扰策略**: 渐进陷阱。先通过“未发生错误”诱导学生认为首部不变；再通过“TTL变化”诱导学生只选(i)；最后通过“校验和联动”诱导学生选(i)(ii)；最终通过“分片可能性”和“可能”一词筛选出正确答案。

## 核心陷阱
- **核心陷阱**: 
  1. **“未发生错误”的误导**：学生容易将“无传输错误”等同于“首部字段不变”，忽略了IP协议设计中TTL递减和校验和重算是正常机制，而非错误。
  2. **“可能” vs “一定”**：分片偏移只有在发生分片时才变化。题目问“可能”，因此必须考虑MTU小于数据报长度的场景。若题目问“一定”，则(iii)不选。
  3. **校验和的覆盖范围**：学生可能误以为校验和只覆盖数据部分，从而认为TTL变化不影响校验和。实际上IP校验和覆盖整个IP首部。

## 考察能力
本题核心考察考生对IP数据报首部字段在路由转发和分片重组过程中的动态变化机制的理解，特别是字段间的依赖关系（TTL与校验和）及条件性变化（分片偏移）。
