# 练习题 Q1 — 信号周期与频率换算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/数据链路层
- **难度**: 待评估

## 题干原文
一个信号的周期为 100 ms。它的频率是（  ）。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆频率与周期的基本定义公式 $f = 1/T$ 以及赫兹（Hz）与千赫（kHz）的单位换算关系。属于计算机网络物理层/数据链路层基础概念，需调用核心定义，故为标准难度。不是1分因为不能仅靠常识直觉得出精确数值，必须调用公式。
- **K2 = 4**: 评分理由。涉及多级单位换算。首先需将毫秒（ms）转换为秒（s），计算得到赫兹（Hz），再将赫兹转换为千赫（kHz）。虽然数值简单（100ms -> 0.1s -> 10Hz -> 0.01kHz），但涉及两次量级转换（$10^{-3}$ 和 $10^3$），容易在指数运算上出错，属于多级换算，故评分较高。
- **K3 = 1**: 评分理由。从输入（周期）到输出（频率）仅需一步公式代入和后续的单位换算，无需多步串行推演或状态记忆。
- **K4 = 2**: 评分理由。存在常规注意点，即单位不统一的问题（ms vs Hz/kHz）。没有深层隐含前提或反直觉陷阱，主要是对单位前缀（milli, kilo）的敏感度测试。
- **K5 = 1**: 评分理由。本题仅涉及信号基础物理量的计算，不涉及不同子系统（如网络层、传输层）之间的状态传递或耦合，属于单系统内部计算。
- **雷达形状**: K2计算型（K2突出，K1中等，其余较低）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过公式 $f=1/T$ 进行数值计算，并重点考察物理单位之间的换算能力，而非复杂的逻辑推理或机制辨析。

## 选项级分析
- **选项A**: [干扰] — 针对**数量级混淆**错误认知。学生可能错误地将 $100$ 直接参与运算或混淆 $10^3$ 的位置，误以为频率是 $1000$ Hz 或类似数量级，或者在计算 $1/0.1$ 时出错。这类学生通常对科学计数法不敏感。
- **选项B**: [正确] — $10^{-2}$ 千赫。计算过程：$T=100ms=0.1s \rightarrow f=1/0.1=10Hz$。$10Hz = 10 \times 10^{-3} kHz = 10^{-2} kHz$。符合计算结果。
- **选项C**: [干扰] — 针对**单位换算方向错误**认知。学生可能正确计算出 $10Hz$，但在转换为 kHz 时，错误地乘以 $10^{-3}$ 而不是除以 $1000$（或混淆了 $10^{-3}$ 和 $10^{-2}$ 的关系），或者误以为 $10Hz = 10^{-3} kHz$（实际上 $1Hz = 10^{-3}kHz$，所以 $10Hz = 10 \times 10^{-3} = 10^{-2}kHz$）。这是最常见的计算陷阱。
- **选项D**: [干扰] — 针对**完全颠倒逻辑**错误认知。学生可能误用公式 $T=1/f$ 但代入错误，或者将 $100$ 直接当作频率，再错误地放大数量级至 $10^5$。这类学生完全未掌握周期与频率的反比关系。
- **干扰策略**: 计算陷阱（主要考察单位换算中的指数运算错误）

## 核心陷阱
- **核心陷阱**: **单位换算中的指数运算错误**。具体表现为在将 Hz 转换为 kHz 时，混淆 $10^{-3}$ 的系数处理，导致结果偏差一个数量级（如误选 C）。

## 考察能力
一句话概括本题核心考察的能力：掌握信号周期与频率的倒数关系，并能准确进行时间单位（ms/s）和频率单位（Hz/kHz）之间的多级换算。
