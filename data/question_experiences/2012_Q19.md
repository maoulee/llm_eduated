# 2012年 Q19 — 总线突发传输时间计算

## 基本信息
- **年份**: 2012  **题位**: Q19  **题型**: 选择题
- **知识点**: 总线性能指标, 同步总线定时, 地址/数据复用机制
- **考纲对应**: 第六章 总线 → 总线操作和定时 → 同步定时方式

## 题干原文
[2012年考研真题第19题]某同步总线的时钟频率为100MHz,宽度为32位，地址/数据线复用，每传输一个地址或数据占用一个时钟周期。若该总线支持突发（猝发）传输方式，则一次“主存写”总线事务传输1

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆“同步总线”、“时钟频率与周期换算”、“总线宽度”、“地址/数据线复用”以及“突发传输”的基本定义。若不清楚“地址/数据复用”意味着地址和数据不能同时传输，或不懂“突发传输”是连续多个周期传数据，则无法入题。属于标准核心概念记忆。
- **K2 = 2**: 2 — 仅需两步简单计算：1) 周期 $T = 1/f$，2) 数据周期数 $N = \text{DataSize} / \text{Width}$。数字友好（100MHz, 32bit, 128bit），无复杂单位换算或非2的幂次，属于较低难度的单步代入。
- **K3 = 2**: 2 — 仅需两步极简推导：总时间 = (地址周期 + 数据周期) $\times$ 时钟周期。路径唯一，无需多步状态更新或动态推演。
- **K4 = 3**: 3 — 存在明确的陷阱词“地址/数据线复用”。若不触发这一条件（即误以为地址和数据可并行，或忘记地址传输也需要占用总线周期），就会用错公式（漏加地址周期）。这是典型的条件路由需求。
- **K5 = 1**: 1 — 单一知识点内部解决，仅涉及总线传输机制，不涉及CPU、存储器等其他系统的复杂交互状态传递。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给出明确的物理参数（频率、宽度、数据量），选项为四个不同的计算结果，仅有一个符合总线定时逻辑。

## 选项级分析
- **选项A**: [干扰] — 20ns。针对错误认知：仅计算了数据传送时间且算错了倍数（可能误以为128位只需2个周期，或者混淆了位和字节），或者完全误解了总线事务结构。通常不会选此项，除非计算极度失误。
- **选项B**: [干扰] — 40ns。针对错误认知：**漏算地址传输周期**。学生正确计算了数据需要4个周期 ($128/32=4$)，但忽略了“地址/数据线复用”意味着在传送数据前，必须先占用一个周期传送地址。这是最常见的错误路径，对应干扰模式“条件遗漏”。
- **选项C**: [正确] — 50ns。正确路径：时钟周期 $10ns$；地址占1个周期；数据 $128bit / 32bit = 4$ 个周期；总周期 $1+4=5$；总时间 $5 \times 10ns = 50ns$。
- **选项D**: [干扰] — 80ns。针对错误认知：**计算偏差或误判周期数**。可能错误地认为需要传输更多周期，或者将地址和数据视为独立非复用但计算错误，亦或是误将128位当作需要8个周期（误用16位宽度？）。也可能是将地址周期算作2个？此项主要考察计算的精确性。
- **干扰策略**: 渐进陷阱

## 核心陷阱
- **核心陷阱**: **地址/数据线复用的时间开销**。考生容易只关注数据量的计算，而忽略总线建立阶段（发送地址）所占用的一个时钟周期。
- **错误路径**: 直接计算 $128 / 32 = 4$ 个数据周期 $\rightarrow$ $4 \times 10ns = 40ns$ $\rightarrow$ 选择B。未意识到“写事务”必须先发地址，且因复用，地址和数据串行传输。

## 考察能力
本题核心考察学生对**同步总线突发传输时序机制**的理解，特别是**地址/数据复用**对总线事务总耗时（地址周期+数据周期）的影响，以及基本的总线带宽与时钟周期换算能力。
