# 模拟题 Q1 — IPv4子网归属判定与CIDR范围计算

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: CN-4 > IPv4 > 子网划分, CN-4 > IPv4 > CIDR表示法
- **难度**: 待评估

## 题干原文
路由器收到一个数据包，其目地址为 195.26.17.4，该地址属于（ ）子网。
- 选项:
  A: 195.26.0.0/21
  B: 195.26.8.0/22
  C: 195.26.16.0/20
  D: 195.26.20.0/22

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握CIDR表示法的基本概念、子网掩码与网络地址的关系，以及IP地址属于某个子网的判定规则（按位与运算或范围比较）。这属于计算机网络中的核心基础定义，非记忆即可解题，但也不涉及复杂概念辨析。
- **K2 = 3**: 评分理由。需要进行二进制转换或十进制范围计算。虽然涉及2的幂次（/20, /21, /22），但需要针对每个选项计算其网络地址和广播地址（或子网掩码），涉及多次简单的算术运算（如 $256 - 2^{8-4} = 240$ 等），计算量适中，容易因粗心出错。
- **K3 = 2**: 评分理由。解题步骤清晰且线性：1. 解析目标IP；2. 对每个选项计算其地址范围；3. 判断目标IP是否在范围内。无需多步串行推演或记忆中间状态，属于标准的“代入验证”流程。
- **K4 = 2**: 评分理由。题目条件明确，无隐含前提或反直觉陷阱。唯一的“坑”在于计算错误，而非逻辑陷阱。学生需意识到只需检查第三字节（因为前两个字节195.26在所有选项中均相同），这属于常规解题技巧。
- **K5 = 1**: 评分理由。本题仅涉及IPv4子网划分单一知识点，无需跨越网络层其他模块（如路由协议、ARP等）或与其他科目联动。

- **雷达形状**: K2计算主导型（K1、K2略高，K3、K4、K5较低，呈现以计算和基础概念为核心的均衡偏计算形态）

## 考察模式
- **模式**: 计算型
- **理由**: 本题的核心解题过程依赖于对CIDR前缀长度转换为子网掩码、网络地址和广播地址的数值计算。虽然基于概念，但区分度主要来自于计算的准确性和速度。

## 选项级分析
- **选项A**: [干扰] — 针对**前缀长度与块大小对应关系不清**的错误认知。/21 的块大小为 $2^{8-5}=32$（第三字节），范围是 0-31。如果学生误以为 /21 对应更小的块（如16或8），或者错误计算掩码，可能会误选。实际上 17 在 0-31 范围内，**等等，这里需要重新检查题目逻辑**。
    - *修正分析*：
        - A: 195.26.0.0/21。掩码 255.255.248.0。第三字节块大小 $2^{8-(21-16)} = 2^5 = 32$。范围：0 ~ 31。17 在 0-31 之间。**A 也是正确的？**
        - 让我们仔细检查题目和选项。
        - 目标 IP: 195.26.17.4
        - A: 195.26.0.0/21 -> 网络地址 195.26.0.0, 广播 195.26.31.255。17.4 在此范围内。
        - B: 195.26.8.0/22 -> 掩码 255.255.252.0。块大小 $2^{8-(22-16)} = 2^4 = 16$。起始 8。范围：8 ~ 23 (8+16-1)。17 在 8-23 之间。**B 也是正确的？**
        - C: 195.26.16.0/20 -> 掩码 255.255.240.0。块大小 $2^{8-(20-16)} = 2^6 = 64$。起始 16。范围：16 ~ 79 (16+64-1)。17 在 16-79 之间。**C 也是正确的？**
        - D: 195.26.20.0/22 -> 掩码 255.255.252.0。块大小 16。起始 20。范围：20 ~ 35。17 不在范围内。

    - **严重问题发现**：根据标准的CIDR规则，A、B、C 三个选项的子网范围都包含 195.26.17.4。
        - A (/21): 0-31. 包含 17.
        - B (/22): 8-23. 包含 17.
        - C (/20): 16-79. 包含 17.
        - D (/22): 20-35. 不包含 17.

    - 通常这类题目考察的是**最长前缀匹配（Longest Prefix Match）**，即路由器会选择最具体的路由（掩码最长）。
        - A: /21
        - B: /22
        - C: /20
        - D: /22
        - 如果考察最长前缀匹配，B (/22) 比 A (/21) 和 C (/20) 更具体。但是 B 和 D 都是 /22。
        - 如果题目问的是“属于哪个子网”，通常意味着只有一个选项是合法的子网定义，或者考察的是**精确匹配**？
        - 不，子网划分中，一个IP可以属于多个嵌套的子网。但在路由表中，路由器会选择最长匹配。
        - 然而，题目给出的正确答案是 **C**。这与标准网络原理相悖，除非题目有隐含条件，例如“该地址属于哪个**特定**子网”或者选项中的网络地址本身有错误？
        - 让我们重新检查选项C: 195.26.16.0/20。
            - 网络地址: 195.26.16.0
            - 掩码: /20 -> 255.255.240.0
            - 第三字节: 16 (00010000). 掩码第三字节: 240 (11110000).
            - 17 (00010001) & 240 (11110000) = 16 (00010000). 匹配。
        - 让我们重新检查选项A: 195.26.0.0/21。
            - 掩码: /21 -> 255.255.248.0
            - 第三字节: 0. 掩码第三字节: 248 (11111000).
            - 17 (00010001) & 248 (11111000) = 16 (00010000).
            - **注意！** 17 & 248 = 16. 而网络地址的第三字节是 0.
            - **16 != 0**. 所以 **A 不匹配！**
            - 我的快速估算错了。/21 的块大小是 32。
            - 子网 195.26.0.0/21 的范围是 0-31 吗？
            - 网络地址必须是块大小的倍数。
            - 0 是 32 的倍数。范围 0-31。
            - 17 在 0-31 之间。
            - 为什么按位与不匹配？
            - 17 = 00010001
            - 248 = 11111000
            - 17 & 248 = 00010000 = 16.
            - 网络地址是 195.26.**0**.0.
            - 16 != 0.
            - **啊，我发现了。**
            - 如果网络地址是 195.26.0.0/21，那么该子网的范围确实是 195.26.0.0 到 195.26.31.255。
            - 但是，IP 195.26.17.4 属于这个子网吗？
            - 是的，它在数值范围内。
            - 但是，按位与运算的结果是 195.26.16.0。
            - 这意味着 195.26.17.4 的**网络地址**是 195.26.16.0/21，而不是 195.26.0.0/21。
            - **关键点**：CIDR 表示法 `Network_Address/Prefix` 中，`Network_Address` 必须是该前缀长度下的合法网络号（即主机位全0）。
            - 对于 /21，块大小是 32。合法的网络号第三字节必须是 0, 32, 64...
            - 195.26.0.0/21 是一个合法的网络号。范围 0-31。
            - 195.26.17.4 在这个范围内。
            - 但是，通常我们说“IP属于子网 X”，是指 IP 按位与掩码后等于 X 的网络地址。
            - 195.26.17.4 & 255.255.248.0 = 195.26.16.0.
            - 195.26.16.0 != 195.26.0.0.
            - **所以 A 是错误的。** 195.26.17.4 属于 195.26.16.0/21 子网，而不是 195.26.0.0/21 子网。虽然 195.26.16.0/21 是 195.26.0.0/20 的子集... 不对，/21 比 /20 更具体。
            - 让我们理清层级：
                - /20 (块64): 0-63, 64-127...
                - /21 (块32): 0-31, 32-63...
                - /22 (块16): 0-15, 16-31...
            - IP: 17.
            - A: 195.26.0.0/21. 范围 0-31. 17 在范围内。但是，该子网的网络号是 0. IP 17 映射到的网络号是 16 (对于/21来说，17//32 = 0? 不，17/32 = 0.53. 整数部分是0. 所以网络号是0?
            - 让我们用二进制再算一次。
            - 17 = 00010001.
            - /21 掩码第三字节: 11111000 (248).
            - 17 & 248 = 00010000 = 16.
            - 所以 195.26.17.x 在 /21 下的网络地址是 195.26.16.0.
            - 选项 A 给的是 195.26.0.0/21.
            - 195.26.0.0/21 的范围是 0-31.
            - 195.26.16.0/21 的范围是 16-47.
            - **等等，/21
