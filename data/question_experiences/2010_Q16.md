# 2010年 Q16 — RAM与ROM的特性

## 基本信息
- **年份**: 2010  **题位**: Q16  **题型**: 选择题
- **知识点**: RAM与ROM的特性对比, 随机存取概念, 存储器刷新机制
- **考纲对应**: 第三章 存储系统 → 半导体随机存储器 → SRAM与DRAM比较, 第三章 存储系统 → 只读存储器 → ROM特点

## 题干原文
下列有关 RAM 和 ROM 的叙述中，正确的是（ ）。
I. RAM 是易失性存储器，ROM 是非易失性存储器
II. RAM 和 ROM 都采用随机存取方式进行信息访问
III. RAM 和 ROM 都可用作 Cache
IV. RAM 和 ROM 都需要进行刷新
存储器概念

A. 仅 I 和 II
B. 仅 II 和 III
C. 仅 I,II 和 IV
D. 仅 II，III 和 IV

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆 RAM/ROM 的易失性、存取方式及刷新机制等基础定义。虽然概念基础，但属于 408 计组模块的“基石级”记忆，模糊概念无法做题，但无需复杂推导。不是 2（因为涉及多个易混淆属性对比），不是 4（因为不涉及冷门细节或极难辨析的边缘概念）。
- **K2 = 1**: 1 — 纯定性概念判断，无任何计算过程。
- **K3 = 1**: 1 — 无需多步串行推演，基于静态属性直接判断。
- **K4 = 3**: 3 — 存在明确的“术语陷阱”：将“随机存取（Random Access）”误解为“随机存取存储器（RAM）”特有的属性，或将“刷新”特性错误迁移给 ROM。需要识别这些隐含的语义陷阱才能正确路由。
- **K5 = 1**: 1 — 仅涉及存储器基本分类内部知识，不涉及 CPU、总线或 I/O 等其他子系统的联动。
- **雷达形状**: K1-K4 概念辨析型

## 考察模式
- **模式**: 组合判断型
- **理由**: 题干列出多个独立陈述（I/II/III/IV），选项为这些陈述的真值组合，考生需先判断每个陈述的真伪，再匹配选项。

## 选项级分析
- **选项A**: [正确] — 仅包含正确陈述。考察对 RAM/ROM 基础属性的精准记忆。
- **选项B**: [干扰] — 针对认知错误：误以为 ROM 可作为 Cache。这类学生可能混淆了“存储器”和“Cache 的构成材料”，忽略了 Cache 的高写入频率需求与 ROM 的只读/难写特性冲突。
- **选项C**: [干扰] — 针对认知错误：可能混合了其他错误认知（如根据用户分析，C 包含错误的 III，若 III 是 Cache 相关，则同上；若用户参考中 C 对应其他错误，需灵活调整。根据用户参考 `{'B': '误以为ROM可做Cache', 'C': '包含错误的III', 'D': '误以为ROM需要刷新'}`，C 选项包含了陈述 III。若 III 是“ROM需要刷新”或“Cache用ROM”，则 C 也是错在概念混淆。通常 C 是 I, II, IV 组合，若 IV 是错的，则 C 错。这里假设 C 选项诱使选择了错误的陈述 III 或 IV)。*根据用户参考，C 包含错误的 III。*
- **选项D**: [干扰] — 针对认知错误：误以为 ROM 需要刷新。这类学生将 DRAM 的电容刷新特性错误类比到 ROM 上，缺乏对半导体存储原理（晶体管 vs 电容 vs 熔丝/浮栅）的区分。
- **干扰策略**: 并行陷阱（各干扰项独立）

## 核心陷阱
- **核心陷阱**: 术语定义的精确性与特性迁移错误。

## 考察能力
本题考察学生对计算机系统中基础存储介质（RAM/ROM）物理特性、访问机制及应用场景的本质理解与辨析能力，特别是排除表面相似性（如都是半导体、都能存数据）下的核心差异。
