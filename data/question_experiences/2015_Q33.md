# 2015 Q33 — POP3协议与传输层服务类型映射

## 基本信息
- **年份**: 2015  **题位**: Q33  **题型**: 选择题
- **知识点**: CN-6 > 电子邮件 > POP3
- **题位域**: 待标注  **科目**: 计算机网络

## 题干原文
通过 POP3 协议接收邮件时，使用的传输层服务类型是（ ）。

A. 无连接不可靠的数据传输服务
B. 无连接可靠的数据传输服务
C. 有连接不可靠的数据传输服务
D. 有连接可靠的数据传输服务

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆 POP3 协议所属的应用层协议栈及其底层传输协议（TCP）。这属于计算机网络中的核心基础定义，考生必须知道 POP3/SMTP/HTTP 等应用层协议通常基于 TCP，而 DNS/TFTP 等基于 UDP。不需要辨析多个易混概念，只需调用一个核心知识点。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全属于定性判断。
- **K3 = 1**: 评分理由。解题过程为单步映射：POP3 -> TCP -> 有连接可靠。无需多步串行推演或中间状态记忆。
- **K4 = 2**: 评分理由。存在常规注意点，即区分“应用层协议”与“传输层服务”的概念层级。虽然题干直接问传输层服务，但考生需隐含意识到 POP3 本身不直接提供传输服务，而是依赖下层。没有复杂的隐含前提或反直觉陷阱，属于常规考点。
- **K5 = 2**: 评分理由。涉及应用层（POP3）与传输层（TCP）之间的接口关系，属于典型的分层模型中的相邻层交互。虽然涉及两层，但关系是单向依赖（应用层依赖传输层），不涉及复杂的状态互影响或深度耦合。
- **雷达形状**: K1主导型（基础记忆型）。K1分数中等偏高，其余维度极低，呈现明显的“概念记忆”特征，无计算和复杂推理负担。

## 考察模式
- **模式**: 概念型
- **理由**: 题目直接考察协议栈中各层协议的对应关系及服务特性，无需计算或逻辑推演，完全依赖对计算机网络体系结构及常见应用协议底层实现的记忆。

## 选项级分析
- **选项A**: [干扰] — 针对“无连接不可靠”的认知。这类学生可能混淆了 UDP 的特性，或者误以为邮件传输像广播一样不需要建立连接。常见于对 TCP/UDP 基本特性记忆模糊的考生。
- **选项B**: [干扰] — 针对“无连接可靠”的认知。这是一个理论上存在但实际极少使用的组合（如某些拥塞控制算法在UDP上实现，但标准传输层服务中无此典型代表）。这类学生可能知道“可靠”是邮件传输必须的，但错误地认为不需要“有连接”（即三次握手等开销），或者混淆了某些特定场景下的协议行为。
- **选项C**: [干扰] — 针对“有连接不可靠”的认知。这类学生可能知道 TCP 是“有连接”的，但错误地认为其“不可靠”（可能混淆了“可靠”与“快速”或“实时”的概念，或者误以为 TCP 也会丢包所以不可靠，忽略了 TCP 的确认重传机制保证了端到端的可靠性）。
- **选项D**: [正确] — POP3 基于 TCP 协议，TCP 提供面向连接的、可靠的字节流服务。
- **干扰策略**: 概念混淆。通过排列组合“有/无连接”和“可靠/不可靠”四个基本属性，构建出所有可能的传输服务类型，考察考生对 TCP 和 UDP 核心特性的精准区分。

## 核心陷阱
- **核心陷阱**: 混淆传输层协议特性。考生若不清楚 POP3 底层使用的是 TCP 而非 UDP，或者不清楚 TCP 的“可靠”与“有连接”特性，极易选错。特别是选项 B 和 C 是典型的属性错位干扰项。

## 考察能力
一句话概括本题核心考察的能力：准确记忆并映射常见应用层协议（如 POP3）所依赖的传输层协议（TCP）及其服务特性（有连接、可靠）。
