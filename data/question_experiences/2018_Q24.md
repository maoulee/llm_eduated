# 2018 Q24 — 非抢占式优先级调度与系统开销计算

## 基本信息
- **年份**: 2018  **题位**: Q24  **题型**: 选择题
- **知识点**: 处理机调度算法, 非抢占式优先级调度, 操作系统>处理机调度算法

## 题干原文
某系统采用基于优先权的非抢占式进程调度策略，完成一次进程调度和进程切换的系统时间开销为 1us。在 T 时刻就绪队列中有 3 个进程 P1、P2 和 P3，其在就绪队列中的等待时间、需要的 CPU 时间和优先权如下表所示。若优先权值大的进程优先获得 CPU，从 T 时刻起系统开始进程调度，则系统的平均周转时间为（）。

- 选项:

- 正确答案: D
- 解析（参考）: 本题考察
非抢占式优先级调度
，由优先权可知，进程的执行顺序为 P2 → P3 → P1。
P2 的周转时间：1 +15+24= 40μs
P3 的周转时间：18+1+24+1 +36= 80μs
P1 的周转时间：30+1+24 +1 +36+1 +12=105μs
平均周转时间： (40+80+105) /3= 225/3= 75μs, 故选 D。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“非抢占式优先级调度”的核心定义（高优先级先执行，一旦开始执行直到结束或阻塞），以及“周转时间”的定义（完成时间 - 到达时间）。虽然概念基础，但涉及“系统开销”这一特定细节，属于标准认知需求。不是4分因为不需要辨析多个易混调度算法（如SJF与优先级混合），只需应用单一规则。
- **K2 = 3**: 评分理由。计算过程涉及多次加法运算，且数字并非简单的2的幂次，需要仔细累加。特别是周转时间的计算包含“等待时间+调度开销+前序进程执行时间+当前进程执行时间”，单步计算量适中，但容易因粗心出错。
- **K3 = 4**: 评分理由。推演步骤较多且串行依赖强。步骤包括：1. 根据优先级确定执行顺序（P2->P3->P1）；2. 计算P2的完成时刻及周转时间；3. 基于P2的完成时刻，加上调度开销，计算P3的完成时刻及周转时间；4. 基于P3的完成时刻，加上调度开销，计算P1的完成时刻及周转时间；5. 求平均值。每一步都依赖上一步的结果，且需时刻记住插入“1us”的系统开销，属于多步串行推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。陷阱1：“系统时间开销”在每次调度切换时发生，包括第一次从就绪队列取出进程时的开销，以及后续进程切换时的开销。很多考生会忽略第一次的1us，或者忽略进程间的切换开销。陷阱2：周转时间的定义是“完成时刻 - 到达时刻”，而题目给出的是“T时刻的等待时间”，这意味着到达时刻是 T - 等待时间。考生必须意识到“周转时间 = 等待时间 + 响应时间（含开销） + 执行时间”或者直接通过时间轴推导。这种对“等待时间”与“到达时间”关系的转换以及对“开销”插入点的识别，属于较深的隐含前提。
- **K5 = 1**: 评分理由。本题仅涉及处理机调度子系统内部的状态流转，不涉及内存管理、I/O调度或其他子系统的状态传递，属于单系统内部计算。

- **雷达形状**: K3/K4 突出型（推演与陷阱主导）

## 考察模式
- **模式**: 综合型
- **理由**: 本题结合了概念理解（非抢占、优先级）、机制推演（执行顺序、时间轴构建）和精确计算（含系统开销的累加）。它不仅仅是套用公式，还需要构建完整的时间执行序列，并处理额外的系统开销变量，属于典型的综合应用题。

## 选项级分析
- **选项A**: [干扰] — 针对完全忽略“系统开销”且可能误算周转时间的学生。如果忽略所有1us开销，且错误地认为周转时间仅等于执行时间之和的某种简单平均，或者计算逻辑严重偏差，可能得到较小数值。更可能的情况是，如果忽略开销，P2周转=15+24=39, P3=18+24+36=78, P1=30+24+36+12=102, 平均=(39+78+102)/3=73。哎，等等，73是选项B。那A可能是怎么来的？可能是忽略了等待时间，只算执行时间？(24+36+12)/3 = 24，不对。可能是忽略了等待时间，只算从T时刻开始的执行时间+开销？P2: 1+24=25, P3: 1+24+1+36=62, P1: 1+24+1+36+1+12=75, 平均=(25+62+75)/3=54。对，选项A是忽略了“等待时间”对周转时间的贡献，只计算了从T时刻起经过的时间（即带权周转时间的分子部分但未除以权重，或者误解了周转时间定义）。这类学生认为周转时间就是“在CPU上花的时间+等待CPU的时间（从T开始算）”，而忘记了进程在T时刻之前已经等待了很长时间。
- **选项B**: [干扰] — 针对忽略“系统开销”的学生。如果完全忽略1us的调度开销，计算如下：
  P2周转 = 15 + 24 = 39
  P3周转 = 18 + 24 + 36 = 78
  P1周转 = 30 + 24 + 36 + 12 = 102
  平均 = (39 + 78 + 102) / 3 = 219 / 3 = 73。
  这是最常见的错误，即知道要按优先级执行，也知道周转时间包含等待时间，但忘记了题目中强调的“系统时间开销”。
- **选项C**: [干扰] — 针对部分忽略“系统开销”或计算错误的学生。例如，可能只计算了进程间的切换开销（2次），而忽略了第一次调度开销（1次），或者在累加时出现算术错误。
  若只算2次开销：
  P2: 15+24=39
  P3: 18+1+24+36=79
  P1: 30+1+24+1+36+12=104
  平均: (39+79+104)/3 = 222/3 = 74。
  这类学生意识到了有开销，但错误地认为第一次从就绪队列取进程不需要开销，或者漏算了一次。
- **选项D**: [正确] — 正确考虑了所有系统开销（共3次：P2启动前，P2->P3切换，P3->P1切换）以及正确的周转时间定义。

- **干扰策略**: 渐进陷阱。从完全忽略开销（B），到部分忽略开销（C），到概念性误解周转时间定义（A），层层递进，考察学生对细节的把控能力。

## 核心陷阱
- **核心陷阱**: **系统开销的插入点与次数**。
  1. **次数陷阱**：3个进程依次执行，需要3次调度动作（T时刻调度P2，P2结束调度P3，P3结束调度P1），因此共有3个1us的开销。很多考生只算进程间的2次切换，漏掉第一次。
  2. **定义陷阱**：周转时间 = 完成时刻 - 到达时刻。题目给出的是T时刻的“等待时间”，隐含了到达时刻 = T - 等待时间。因此，周转时间 = 等待时间 + (从T时刻到完成时刻的时间)。从T时刻到完成时刻的时间包含了：调度开销 + 前序进程执行时间 + 当前进程执行时间。

## 考察能力
本题核心考察学生在复杂约束条件（非抢占、优先级、系统开销）下，构建精确进程执行时间轴并正确应用周转时间定义的综合计算能力。
