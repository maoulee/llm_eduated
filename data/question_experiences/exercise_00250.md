# 练习题 Q1 — 严格二叉树最大高度推导

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/二叉树
- **难度**: 待评估

## 题干原文
假设你被给定一个包含 n 个节点的二叉树，其中每个节点恰好有零个或两个子节点。该树的最大高度将是（ ）
A: n/2−1
B: n/2+1
C: (n–1)/2
D: (n+1)/2

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“严格二叉树”（或满二叉树/正则二叉树）的定义，即节点度数为0或2。若不知道此定义，无法建立节点数与高度的关系。属于标准的核心概念记忆。
- **K2 = 3**: 评分理由。涉及简单的代数推导：由 $n = 2h - 1$ 反解 $h$。虽然计算简单，但需要处理奇偶性隐含条件（n必为奇数），且结果涉及分数形式，非直接整数幂次，故为标准难度。
- **K3 = 2**: 评分理由。推演步骤较少。只需构建“最不平衡”的极端模型（每层仅1个非叶子节点，2个叶子节点），即可列出线性方程。属于2步以内的逻辑推演。
- **K4 = 4**: 评分理由。存在显著的隐含前提和陷阱。
    1. **隐含前提**：题目未直接给出高度定义（是从0开始还是从1开始？），也未直接给出n与h的公式，需要考生自行构建极端情况模型。
    2. **陷阱**：容易混淆“最大高度”与“最小高度”。最小高度对应完全二叉树（$\log_2 n$），最大高度对应链状结构（但受限于严格二叉树定义，不能是单链，而是“之”字形或每层挂两个叶子）。
    3. **定义歧义**：408中高度通常指层数（根为第1层），若按边数计算（根为0层），答案会不同。需根据选项反推定义。
- **K5 = 1**: 评分理由。仅涉及二叉树单一数据结构内部性质，无需跨越操作系统、计网等其他领域。
- **雷达形状**: K4陷阱型（高条件路由需求，中等概念与计算需求）

## 考察模式
- **模式**: 推理型
- **理由**: 本题不是直接套用公式，而是要求考生根据“每个节点恰好有零个或两个子节点”这一约束条件，推理出使得高度最大的树结构形态（即最不平衡的严格二叉树），进而推导节点数与高度的关系。

## 选项级分析
- **选项A**: [干扰] — 针对计算错误。若考生误以为 $n = 2h + 1$ 或代数移项错误，可能得出此结果。或者混淆了叶子节点数与高度的关系。
- **选项B**: [干扰] — 针对概念混淆。可能将高度定义为边数，或者在代数推导中符号处理错误（如 $h = (n+1)/2$ 误算为 $n/2 + 1$ 当n为偶数时的近似，但n必为奇数）。
- **选项C**: [正确] — 正确推导结果。
    - 推导：设高度为 $h$（根节点在第1层）。
    - 为了使高度最大，树应尽可能“瘦”。
    - 第1层：1个节点（根，非叶子）。
    - 第2层：2个节点（均为叶子，因为若继续延伸，需选其中一个作为非叶子，但为了最大化高度，我们让每一层只有一个非叶子节点向下延伸，其余均为叶子？不对，严格二叉树要求非叶子必须有2个子节点。
    - **修正模型**：
        - 根节点（第1层）：1个，非叶子。
        - 第2层：2个节点。为了高度最大，其中一个继续作为非叶子节点向下，另一个必须是叶子（因为非叶子必须有2个子节点，不能只有一个）。
        - 第3层：由第2层的那个非叶子节点生出2个子节点。其中一个继续向下，另一个为叶子。
        - ...
        - 第 $h-1$ 层：1个非叶子节点，1个叶子节点（来自上一层的兄弟）。
        - 第 $h$ 层：2个叶子节点。
    - 统计节点数：
        - 非叶子节点数：$h-1$ 个（第1层到第$h-1$层各1个）。
        - 叶子节点数：
            - 第2层到第$h-1$层，每层有1个叶子（作为非叶子节点的兄弟）。共 $h-2$ 个。
            - 第 $h$ 层有2个叶子。
            - 总叶子数 = $(h-2) + 2 = h$ 个。
        - 总节点数 $n = (h-1) + h = 2h - 1$。
    - 解得 $h = (n+1)/2$。
    - **等等，参考答案给的是C: (n-1)/2？**
    - 让我们重新审视高度定义。
    - 如果高度 $h$ 定义为**边数**（根节点深度为0）：
        - 最大深度为 $h$。
        - 非叶子节点数：$h$ 个（深度0到$h-1$）。
        - 叶子节点数：$h+1$ 个？
        - 让我们用具体例子验证。
        - $n=1$: 只有根。高度（边数）=0。公式C: $(1-1)/2 = 0$。公式D: $(1+1)/2 = 1$。
        - $n=3$: 根+2叶子。高度（边数）=1。公式C: $(3-1)/2 = 1$。公式D: $(3+1)/2 = 2$。
        - $n=5$: 根->左(非叶)->左(叶), 右(叶); 右(叶)。结构：根(1) -> 左(2) -> 左(4), 右(5); 右(3)。
            - 节点：1,2,3,4,5。
            - 高度（边数）：1->2->4，长度为2。
            - 公式C: $(5-1)/2 = 2$。公式D: $(5+1)/2 = 3$。
    - **结论**：本题中的“高度”指的是**边数**（或层数减1，即深度）。在408考研中，有时高度定义为层数（根为1），有时定义为边数（根为0）。根据选项C为正确答案，可以反推本题采用**高度=边数**的定义，或者题目中的“高度”指代的是**非叶子节点的最大层数**？
    - 通常408中，若未特别说明，高度多指层数。但若按层数算，$h_{layer} = (n+1)/2$，对应选项D。
    - 既然参考答案是C，说明本题定义高度 $H$ 满足 $n = 2H + 1$。
    - 这意味着 $H$ 是**从根到最远叶子节点的路径长度（边数）**。
    - 干扰项D $(n+1)/2$ 是如果考生按“层数”计算得出的结果，这是最常见的混淆点。
- **选项D**: [干扰] — 针对高度定义混淆。如果考生将高度定义为层数（根为第1层），则 $h = (n+1)/2$。这是最强烈的干扰项，考察考生对“高度”定义的敏感度或根据选项反推定义的能力。

**干扰策略**: 定义混淆（层数 vs 边数）

## 核心陷阱
- **核心陷阱**: **高度的定义歧义**。
    - 在数据结构中，树的高度（Height）有时定义为节点数（层数，根为1），有时定义为边数（深度，根为0）。
    - 对于严格二叉树，最大高度（最不平衡）时，节点数 $n$ 与高度 $h$ 的关系为：
        - 若 $h$ 为层数：$n = 2h - 1 \Rightarrow h = (n+1)/2$ （选项D）
        - 若 $h$ 为边数：$n = 2h + 1 \Rightarrow h = (n-1)/2$ （选项C）
    - 考生若未注意选项分布或默认层数定义，极易选错。本题通过正确答案C暗示了采用“边数”定义。

## 考察能力
本题核心考察考生对**严格二叉树极端形态（最大高度）的结构建模能力**，以及在**高度定义存在歧义时通过选项反推或辨析定义的能力**。
