## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“时间复杂度”、“空间复杂度”以及“算法优化”的基本概念。虽然不涉及复杂的数学公式推导，但需要理解 $O(n)$ 与 $O(n^2)$ 的区别，以及为何要追求“尽可能高效”。不是4分因为不需要辨析多个易混的高级算法概念，核心定义明确。
- **K2 = 2**: 评分理由。计算过程主要是简单的整数比较和乘法，没有复杂的数值计算或多级换算。最复杂的单步操作是 `max(A[i]*maxVal, A[i]*minVal)`，属于基础算术逻辑，不易出错。
- **K3 = 3**: 评分理由。解题需要多步串行推演：首先识别暴力解法 $O(n^2)$ 的低效，然后推导出从右向左遍历的状态转移逻辑（维护后缀最大/最小值），最后将逻辑转化为代码。步骤清晰但需要一定的逻辑链条构建能力。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。题面要求 $i \le j$，这意味着对于 $A[i]$，只能看它右边的元素（包括自己）。更关键的陷阱在于**负数处理**：如果 $A[i]$ 是负数，乘积最大值可能由后缀中的**最小值**（负数）产生，而非最大值。考生必须意识到“正负号翻转”这一隐含条件，否则只能得到部分正确或错误答案。这是典型的“反直觉”或“隐含前提深”的情况。
- **K5 = 2**: 评分理由。本题主要涉及单一的数据结构（数组）和简单的状态变量（maxVal, minVal）。虽然需要在遍历过程中维护状态，但不涉及不同子系统（如树与图、栈与队列混合）之间的深度耦合或复杂的状态传递。

- **雷达形状**: 偏向于“条件路由”和“机制推演”的中间型雷达。K4（条件路由）突出，表明题目难点不在于计算或记忆，而在于对边界条件和数据特性（正负性）的逻辑判断。

## 解题思路分析
- **核心思路**: 
  1. **暴力法分析**：对于每个 $A[i]$，遍历 $j$ 从 $i$ 到 $n-1$，计算乘积取最大。时间复杂度 $O(n^2)$，不符合“尽可能高效”的要求。
  2. **优化策略**：观察发现，对于固定的 $i$，我们需要在子数组 $A[i \dots n-1]$ 中找到一个 $A[j]$，使得 $A[i] \times A[j]$ 最大。
     - 若 $A[i] > 0$，则需 $A[j]$ 最大，即 $A[j] = \max(A[i \dots n-1])$。
     - 若 $A[i] < 0$，则需 $A[j]$ 最小（绝对值最大的负数），即 $A[j] = \min(A[i \dots n-1])$。
     - 若 $A[i] = 0$，结果恒为0。
  3. **状态维护**：为了在 $O(1)$ 时间内获取 $A[i \dots n-1]$ 的最大值和最小值，可以从右向左遍历数组。维护两个变量 `maxVal` 和 `minVal`，分别记录当前遍历位置右侧（含当前位置）的最大值和最小值。
  4. **计算结果**：对于每个 $i$，`res[i] = max(A[i] * maxVal, A[i] * minVal)`。

- **关键步骤**:
  1. 初始化 `maxVal` 和 `minVal` 为 `A[n-1]`。
  2. 设置 `res[n-1] = A[n-1] * A[n-1]`。
  3. 循环变量 $i$ 从 $n-2$ 递减到 $0$：
     - 更新 `maxVal = max(maxVal, A[i])`
     - 更新 `minVal = min(minVal, A[i])`
     - 计算 `res[i] = max(A[i] * maxVal, A[i] * minVal)`
  4. 注意：题目要求 $i \le j$，所以在计算 `res[i]` 时，`maxVal` 和 `minVal` 必须包含 $A[i]$ 本身。因此，**先更新 max/min，再计算 res** 或者 **在计算 res 时确保范围正确** 是关键。
     *修正逻辑*：如果从右向左遍历，当处理到 $i$ 时，`maxVal` 和 `minVal` 应该代表 $A[i \dots n-1]$ 的最值。
     - 初始：$i=n-1$，`maxVal=A[n-1]`, `minVal=A[n-1]`, `res[n-1]=A[n-1]*A[n-1]`。
     - 下一步 $i=n-2$：先更新 `maxVal = max(maxVal, A[n-2])`，`minVal = min(minVal, A[n-2])`。此时 `maxVal` 是 $A[n-2 \dots n-1]$ 的最大值。然后 `res[n-2] = max(A[n-2]*maxVal, A[n-2]*minVal)`。
     - 这样逻辑是通顺的。

- **易错点**:
  1. **遍历方向错误**：从左向右遍历无法高效获取后缀最值，除非预处理，但预处理也需要空间或额外时间，且从右向左更直观。
  2. **忽略负数情况**：只考虑 `A[i] * maxVal`，导致当 $A[i]$ 为负数时结果错误。
  3. **范围界定错误**：题目要求 $j \ge i$。如果在更新 `maxVal/minVal` 和计算 `res[i]` 的顺序上搞反，可能导致使用了 $A[i-1]$ 的信息（如果从左向右）或者未包含 $A[i]$ 本身（如果逻辑不当）。
  4. **初始化错误**：`maxVal` 和 `minVal` 的初始值应设为最后一个元素，而不是0或无穷大，因为数组元素可能为负。

## 核心陷阱
- **核心陷阱**: **负数乘积的最大值问题**。
  很多考生会直觉地认为“最大值乘以最大值”就是最大乘积。但在存在负数的情况下，**负数乘以最小值（负数）** 可能会得到更大的正数。例如 $A[i]=-9$，后缀为 $\{-9, 6\}$，最大值是6，最小值是-9。$-9 \times 6 = -54$，而 $-9 \times (-9) = 81$。必须同时维护后缀的最大值和最小值，并取两者乘积的较大者。
