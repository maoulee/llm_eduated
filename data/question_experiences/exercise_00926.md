# 练习题 Q1 — 信号量同步与进程执行序列推演

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/进程管理
- **难度**: 待评估

## 题干原文
以下程序包含 3 个并发进程和 3 个二进制信号量。信号量初始化为 S0 = 1，S1 = 0，S2 = 0。进程 P0 将打印 ‘0’ 多少次？（ ）

```c
Process P0
while (true) {
    wait(S0);
    print '0';
    signal(S1);
    signal(S2);
}

Process P1
wait(S1);
signal(S0);

Process P2
wait(S2);
signal(S0);
```

- 选项:
  A: 至少两次
  B: 正好两次
  C: 正好三次
  D: 正好一次
- 正确答案: C
- 解析（参考）: 解析
P1 和 P2 都只有一条语句，会各执行一次就结束。每次 P0 运行后，它会分别 signal S1 和 S2，允许一次 P1 和一次 P22的执行，每次分别只增加一个 S0。所以每执行完一次 P0，P2 和 P3 都必须各执行一次才能再次唤醒 P0。
但问题是 P2 和 P3 各只有一次机会，执行完之后就无法再次执行。
所以 P1 一共会执行三次循环，然后就在
wait(S0)
的地方阻塞住，答案是正好三次，选择 C。
- 知识标签: ['操作系统/进程管理']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握信号量 `wait` (P操作) 和 `signal` (V操作) 的基本语义，以及二进制信号量的特性。不是4分因为不需要辨析复杂的死锁或饥饿概念，只需知道基本操作即可入题。
- **K2 = 2**: 评分理由。本题不涉及数值计算，而是状态计数。最复杂的“计算”是统计信号量值的增减，属于简单的整数加减，难度较低。
- **K3 = 4**: 评分理由。需要从初始状态开始，串行推演多个进程的执行顺序。步骤包括：P0初始执行 -> 释放S1/S2 -> P1/P2执行并释放S0 -> P0再次执行。由于涉及三个进程间的交互和状态依赖，且需要追踪信号量值的变化以判断阻塞/唤醒，推演步骤超过5步，且需记忆中间状态（S0, S1, S2的值），故评为4。
- **K4 = 4**: 评分理由。存在隐含前提和反直觉陷阱。陷阱在于P1和P2是**非循环**的，它们执行一次后便终止，不再参与后续同步。许多学生容易惯性思维认为P1/P2也会循环或持续存在，从而误判P0可以无限执行或执行更多次。识别“进程终止”这一隐含条件是解题关键。
- **K5 = 4**: 评分理由。需要在P0、P1、P2三个进程间传递状态（通过信号量S0, S1, S2）。P0的状态变化触发P1/P2，P1/P2的状态变化又反馈给P0，形成闭环依赖，属于状态互影响的深度耦合。

- **雷达形状**: K3/K4/K5 高位型（推演与陷阱主导）

## 考察模式
- **模式**: 推理型
- **理由**: 本题无法通过直接公式计算得出答案，必须根据信号量的同步机制，模拟进程的执行流程，逻辑推演每一步的状态变化，从而确定最终结果。

## 选项级分析
- **选项A**: [干扰] — 针对认为P0可以执行多次但不确定具体次数的学生。如果学生意识到P1/P2会终止，但错误地认为P0在P1/P2终止后还能再执行一次（例如误以为初始S0=1能多支持一次），可能会选“至少两次”。
- **选项B**: [干扰] — 针对推演步骤遗漏的学生。可能只推演了第一轮：P0执行1次 -> P1/P2执行 -> P0执行第2次 -> P1/P2已死 -> P0阻塞。如果学生错误地认为P1/P2执行后S0只增加1（而非2），或者忽略了初始S0=1的作用，可能会得出2次的结论。
- **选项C**: [正确] — 正确推演结果。初始S0=1，P0执行第1次，S1=1, S2=1。P1执行，S0变为1；P2执行，S0变为2。P0执行第2次，S1=1, S2=1。P1已死，P2已死，S0保持为2。P0执行第3次，S1=1, S2=1。P1/P2均死，S0保持为2。P0尝试执行第4次，wait(S0)阻塞。共打印3次。
- **选项D**: [干扰] — 针对对信号量机制理解极浅的学生。可能认为P0执行一次后，S1/S2被释放，但P1/P2执行后没有正确理解S0的累加效应，或者认为P1/P2执行后系统就彻底卡死，忽略了S0的初始值和累加带来的额外执行机会。

- **干扰策略**: 概念混淆（循环vs非循环进程）、计算陷阱（信号量值的累加与消耗）

## 核心陷阱
- **核心陷阱**: **P1和P2是非循环进程，执行一次后即终止**。这是解题的最关键隐含条件。如果误以为P1/P2也在while循环中，或者误以为它们会持续响应signal，就会得出P0可以无限执行或执行更多次的错误结论。此外，需准确追踪S0的累加过程：初始1 + P1贡献1 + P2贡献1 = 3次执行机会。

## 考察能力
一句话概括本题核心考察的能力：在并发环境下，基于信号量机制进行多进程执行序列的逻辑推演与状态追踪能力。
