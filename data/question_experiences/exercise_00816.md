# 练习题 Q1 — 流水线峰值时钟频率计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机组成原理/流水线
- **难度**: 待评估

## 题干原文
考虑以下处理器（ns 表示ns）。假设流水线寄存器的延迟为零。
P1
：四阶段流水线，各阶段延迟分别为 1 ns、2 ns、2 ns、1 ns。
P2
：四阶段流水线，各阶段延迟分别为 1 ns、1.5 ns、1.5 ns、1.5 ns。
P3
：五阶段流水线，各阶段延迟分别为 0.5 ns、1 ns、1 ns、0.6 ns、1 ns。
P4
：五阶段流水线，各阶段延迟分别为 0.5 ns、0.5 ns、1 ns、1 ns、1.1 ns。
哪个处理器具有最高的峰值时钟频率？（ ）
- 选项:
  A: P1
  B: P2
  C: P3
  D: P4

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握流水线时钟周期的核心定义：时钟周期由流水线中最长阶段（瓶颈阶段）决定。这是计算机组成原理中的标准核心概念，不属于生僻知识，但必须准确记忆“最大延迟决定周期”这一规则，而非平均延迟或总延迟。
- **K2 = 3**: 评分理由。涉及简单的比较和倒数计算。虽然计算本身（1/1, 1/1.1等）不复杂，但数据包含小数（1.5, 0.6, 1.1），非整数幂次，且需要对比四个对象的最大值，属于标准的单步代入与比较，存在轻微的计算/比较负担。
- **K3 = 1**: 评分理由。解题过程是线性的：找出每个处理器的最大延迟 -> 比较大小 -> 得出结论。无需多步串行推演，也没有中间状态需要记忆。
- **K4 = 2**: 评分理由。题干明确说明“流水线寄存器的延迟为零”，排除了常见的寄存器开销陷阱。主要的注意点在于识别“峰值时钟频率”对应的是“最小时钟周期”，进而对应“最小最大延迟”。这是一个常规的概念转换，没有深层隐含前提或反直觉陷阱。
- **K5 = 1**: 评分理由。本题仅涉及流水线内部阶段延迟的计算，不涉及指令集架构、存储器层次结构或中断等其他子系统的联动，属于单系统内部问题。
- **雷达形状**: K2计算主导型（K1和K2略高，其余维度较低，呈现扁平偏右的形状，强调基础概念的直接应用和简单数值比较）。

## 考察模式
- **模式**: 计算型
- **理由**: 题目虽然基于概念（流水线时钟周期定义），但解题的关键步骤在于从给定的数据中提取关键数值（最大延迟），并进行数值比较和倒数运算以得出频率。它不是纯粹的概念辨析，也不是复杂的逻辑推理，而是基于公式的直接数值处理。

## 选项级分析
- **选项A (P1)**: [干扰] — 针对错误认知：可能误以为阶段数少（4段）或者总延迟小（6ns）就快。P1的最大延迟为2ns，周期最长，频率最低（0.5GHz）。这类学生可能混淆了“总执行时间”与“时钟频率”的概念，或者没有正确识别瓶颈阶段。
- **选项B (P2)**: [干扰] — 针对错误认知：P2的最大延迟为1.5ns，频率约为0.67GHz。这是一个中等水平的干扰项，对于计算不仔细或比较能力弱的学生，可能会在P2和P4之间犹豫，或者误以为阶段均衡（1.5, 1.5, 1.5）意味着性能更好，而忽略了P3有更小的最大延迟。
- **选项C (P3)**: [正确] — P3的各阶段延迟为0.5, 1, 1, 0.6, 1。最大延迟为1ns。时钟周期T=1ns，频率f=1/1ns=1GHz。这是所有选项中最大延迟最小的，因此频率最高。
- **选项D (P4)**: [干扰] — 针对错误认知：P4的最大延迟为1.1ns，频率约为0.91GHz。这个选项非常接近正确答案，旨在测试学生是否能精确比较1.0和1.1的区别。如果学生粗略估算或看错数字，容易选错。

- **干扰策略**: 数值接近陷阱。P3（1.0ns）和P4（1.1ns）的最大延迟非常接近，P2（1.5ns）次之，P1（2.0ns）最差。通过设置接近的数值，考察学生对“最大延迟决定周期”这一规则的精确应用，而非模糊感觉。

## 核心陷阱
- **核心陷阱**: 混淆“总延迟”、“平均延迟”与“最大阶段延迟”。学生容易误将各阶段延迟相加求和，或者求平均值来计算时钟周期。必须明确：流水线时钟周期 = max(各阶段延迟) + 寄存器延迟（本题为0）。只有找到每个处理器中**最大**的那个阶段延迟，才能确定其时钟周期，进而确定频率。

## 考察能力
本题核心考察学生准确理解流水线时钟周期由瓶颈阶段（最大延迟）决定的概念，并能通过比较不同流水线配置的最大延迟来评估其峰值时钟频率的能力。
