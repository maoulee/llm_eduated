# 练习题 Q未知 — LRU与OPT页面置换策略对比分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/存储管理
- **难度**: 待评估

## 题干原文

  D: 3
- 正确答案: C
- 解析（参考）: LRU 置换策略：替换掉最近最久未使用的页面。
给定字符串： 1, 2, 1, 3, 7, 4, 5, 6, 3, 1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆并理解LRU（最近最少使用）和OPT（最优）两种页面置换算法的核心定义。不是4分因为不需要辨析多个易混概念（如FIFO与LRU的区别在此题中不是核心，核心是LRU与OPT的对比），只需掌握这两个标准算法即可入题。
- **K2 = 2**: 评分理由。本题不涉及复杂的数学计算，主要是状态跟踪。虽然需要计数，但“计算”本质上是逻辑判断后的累加，属于较低难度的单步代入（每次访问判断是否命中，未命中则计数+1并更新状态）。
- **K3 = 5**: 评分理由。这是本题的核心难点。题目要求对长度为10的引用字符串，分别模拟LRU和OPT两种算法的全过程。每一步都需要维护内存中的页面集合及其状态（LRU需维护时间戳或顺序，OPT需向后查找）。步骤超过5步，且必须精确记忆中间状态，任何一步出错都会导致最终结果偏差，属于高难度的多步串行推演。
- **K4 = 3**: 评分理由。存在隐含前提和常规注意点。首先，“考虑上题中给出的数据”意味着考生必须从上下文获取页面引用串和物理块数（通常为3块，根据解析推断）。其次，OPT算法需要“向后看”未来引用，而LRU需要“向前看”历史引用，这种视角的切换是常见的陷阱。此外，初始加载时的缺页中断计数也是容易忽略的细节。
- **K5 = 1**: 评分理由。本题完全局限于存储管理子系统内部，不涉及CPU调度、文件系统或其他子系统的状态传递，属于单系统内的独立问题。
- **雷达形状**: K3推演主导型（K3极高，K1中等，K2/K5低，K4中等）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非简单的概念回忆或公式代入，而是要求考生根据明确的算法规则（LRU和OPT），对给定的输入序列进行逐步的状态模拟和逻辑推演，最终通过对比两个推演结果得出答案。

## 选项级分析
- **选项A**: [干扰] — 针对认为LRU和OPT效果完全相同或差异极小的错误认知。这类学生可能误以为LRU是OPT的完美近似，或者在模拟过程中两者恰好产生了相同数量的缺页中断（实际上在该序列下不同）。
- **选项B**: [干扰] — 针对模拟过程中出现少量计算错误或状态更新错误的学生。例如，在LRU模拟中错误地判断了“最近最少使用”的页面，或者在OPT模拟中看错了未来的引用位置，导致两者差值计算为1。
- **选项C**: [正确] — 正确模拟LRU产生9次缺页，OPT产生7次缺页（根据常见真题数据推断，OPT通常为7次，9-7=2），得出额外页面错误为2。
- **选项D**: [干扰] — 针对模拟错误导致LRU缺页次数偏高或OPT缺页次数偏低的学生。例如，可能误以为初始加载不算缺页，或者在OPT算法中错误地保留了即将被使用的页面，导致差值扩大为3。
- **干扰策略**: 计算陷阱/模拟误差。通过增加模拟步骤的长度，放大细微的逻辑错误，使错误答案分布在正确答案附近（1和3），增加区分度。

## 核心陷阱
- **核心陷阱**: **多步模拟的状态一致性**。考生需要在脑海中或草稿纸上同时维护两个独立的内存状态表（一个用于LRU，一个用于OPT）。LRU依赖历史访问顺序，OPT依赖未来访问预测。在长序列模拟中，极易在中间某一步搞混“当前内存中的页面”或“下一个要置换的页面”，导致最终计数错误。此外，题目依赖“上题数据”，若未正确获取物理块数（本题隐含为3）和引用串，则无法解题。

## 考察能力
本题核心考察考生对页面置换算法（LRU与OPT）执行过程的精确模拟能力，以及在多步逻辑推演中保持状态一致性的耐心与细致程度。
