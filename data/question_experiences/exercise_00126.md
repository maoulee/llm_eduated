# 练习题 Q1 — SRTF调度算法与周转时间计算

- **来源**: 练习题  **题型**: 选择题

- 正确答案: A
- 解析（参考）: 抢占式最短剩余时间优先调度算法意味着将选择当前剩余执行时间最短的进程在 CPU 上运行。根据下图 Gantt 图的调度和执行情况，周转时间（TAT）= 完成时间（CT）- 到达时间（AT）。
P1 的 TAT
= 20 - 0 = 20
P2 的 TAT
= 10 - 3 = 7
P3 的 TAT
= 8 - 7 = 1

因此，平均 TAT = 所有进程的总 TAT / 进程数量 = (20 + 7 + 1 + 5)/4 = 33/4 = 8.25
故选项（A）为正确答案。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆“抢占式最短剩余时间优先（SRTF）”的定义及其与“非抢占式SJF”的区别。若混淆两者概念（如误以为一旦开始执行就不中断），则无法解题。属于标准的核心概念记忆需求。
- **K2 = 3**: 评分理由。涉及多次减法（计算剩余时间）和一次除法（计算平均值）。虽然数字较小，但中间步骤多，容易在算术上出错（如20-0, 10-3等），且最终结果为小数，需精确计算。
- **K3 = 4**: 评分理由。这是本题的核心难点。需要在时间轴上动态推演进程状态。从t=0到t=13，经历了多次上下文切换（P1->P2->P3->P4->P2->P1）。每一步都需要判断当前就绪队列中哪个进程剩余时间最短，并更新所有进程的剩余时间。推演步骤超过5步，且需记忆中间状态（各进程剩余时间），属于较高难度的机制推演。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。主要陷阱在于“抢占”的触发条件：只有当新到达进程的**剩余时间**（即其突发时间，因为刚到达）小于当前运行进程的**剩余时间**时，才会发生抢占。例如t=7时，P3到达，剩余1ms，而P2剩余3ms，故P2被抢占。若忽略“剩余时间”对比而仅看“到达时间”或“总突发时间”，则会出错。
- **K5 = 1**: 评分理由。本题仅涉及CPU调度子系统，不涉及内存管理、I/O调度或文件系统等跨域联动，状态传递仅在调度器内部进行。

- **雷达形状**: K3推演主导型（K3高，K1/K2中等，K4中等，K5低）。图形呈现为以K3为顶点的三角形或菱形，强调动态过程模拟能力。

## 考察模式
- **模式**: 综合型（计算+推理）
- **理由**: 本题不仅要求考生理解SRTF算法的概念（推理），还要求通过绘制甘特图或列表法进行多步动态模拟（推理），最后进行数值计算（计算）。它不是单纯的概念辨析，也不是简单的公式代入，而是典型的“算法执行过程模拟”类题目。

## 选项级分析
- **选项A**: [正确] — 正确执行SRTF调度，得出各进程完成时间分别为20, 10, 8, 13，计算平均周转时间为8.25。
- **选项B**: [干扰] — 可能源于非抢占式SJF的错误计算，或者在计算P1的周转时间时出错（例如误以为P1最后完成时间是其他值）。若使用非抢占式SJF，P1(0-10), P2(10-16), P3(16-17), P4(17-20)，TAT分别为10, 13, 10, 12，平均11.25，不匹配。另一种可能是计算平均等待时间而非周转时间，或者在某个时间点错误地没有抢占。例如，若在t=8时未让P4抢占P2（错误认为P2剩余3>P4剩余3不抢占，或计算错误），会导致结果偏差。实际上，若误算P1完成时间为23等，可能凑出此数。更可能的错误是：将周转时间误算为等待时间+突发时间，但计算过程中某处加法错误。
- **选项C**: [干扰] — 数值较小，可能源于混淆了“平均等待时间”和“平均周转时间”。平均等待时间 = 平均周转时间 - 平均突发时间。平均突发时间 = (10+6+1+3)/4 = 5。若平均周转时间为8.25，则平均等待时间为3.25。此选项6.35与常见错误结果不符，可能是随机干扰或特定错误路径（如漏算某个进程的等待时间）。
- **选项D**: [干扰] — 数值极小，接近平均等待时间（3.25）或平均响应时间。可能是考生完全混淆了周转时间、等待时间和响应时间的概念，或者仅计算了部分进程的指标。

- **干扰策略**: 概念混淆（周转时间vs等待时间）与计算陷阱（动态推演中的状态更新错误）。

## 核心陷阱
- **核心陷阱**: **动态剩余时间的实时比较与抢占判断**。
  考生最容易在t=7和t=8时刻出错。
  1. t=7时，P3到达（剩余1），P2正在运行（已运行4ms，剩余2ms? 不，P2从3开始运行到7，运行了4ms，剩余6-4=2ms）。此时P3剩余1 < P2剩余2，P2被抢占。
  2. t=8时，P4到达（剩余3），P3正在运行（已运行1ms，剩余0? 不，P3从7开始运行到8，运行了1ms，剩余1-1=0，P3完成）。此时就绪队列有P2(剩余2), P4(剩余3)。P2剩余2 < P4剩余3，P2继续运行。
  若考生未仔细计算“剩余时间”，而是直接比较“突发时间”或“到达时间”，就会选错调度顺序，导致甘特图错误，进而导致最终答案错误。

## 考察能力
本题核心考察考生对**抢占式调度算法动态执行过程的模拟能力**，以及在复杂时间轴上准确追踪进程状态（剩余时间）并进行精确计算的能力。
