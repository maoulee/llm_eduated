# 练习题 Q1 — 组相联缓存映射与LRU替换模拟

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 计算机组成原理/存储系统
- **难度**: 待评估

## 题干原文
考虑一个总共有 16 个缓存块的 4 路组相联缓存（初始为空）。主内存包含 256 个块，内存块请求顺序如下：
0, 255, 1, 4, 3, 8, 133, 159, 216, 129, 63, 8, 48, 32, 73, 92, 155.
使用最近最少使用（LRU）页面替换算法时，缓存中发生的命中次数是多少？（ ）
- 选项:
  A: 0
  B: 1
  C: 2
  D: 3
- 正确答案: B
- 解析（参考）: 已知这是一个总共有 16 个缓存块的 4 路组相联缓存（初始为空），因此可以形成编号为 0 到 3 的 4 个组。每个组包含 4 个块。
给定的内存块对 4 取模后得到：0, 1, 0, 3, 0, 1, 3, 1, 3, 0, 0, 0, 1, 3。
第 0 组
请求序列：{0, 4, 8, 8, 48, 32}
命中分析：
第一次访问 0 → 缺页
第一次访问 4 → 缺页
第一次访问 8 → 缺页
第二次访问 8 →
命中
后续访问 48/32 → 缺页
第 1 组
请求序列：{1, 133, 129, 73}
所有访问均为首次 → 全部缺页
第 2 组
无请求 → 无命中
第 3 组

- 知识标签: ['计算机组成原理/存储系统']
- 知识域: CO-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“组相联缓存”的基本结构定义（路数、组数、块数关系）以及“LRU”替换算法的核心概念。不记忆这些核心定义无法入题，但无需辨析多个易混的高级概念，属于标准的基础认知需求。
- **K2 = 2**: 评分理由。主要计算为内存块号对组数（4）取模，以及简单的计数。计算量极小，且数字均为2的幂次友好型，几乎不可能算错，属于较低的单步代入需求。
- **K3 = 4**: 评分理由。这是本题的核心难点。考生需要在脑海中或草稿纸上维护4个组、每组4个块的LRU状态栈。随着17次请求的串行推进，必须准确跟踪每个组内块的“最近使用”顺序，并在发生冲突时正确执行替换。步骤多（>5步）且需记忆中间状态，属于较高的机制推演需求。
- **K4 = 3**: 评分理由。存在常规注意点作为陷阱。例如：容易忽略“初始为空”导致前几次访问必缺页；容易混淆“组号”计算（取模）与“块内偏移”；容易在LRU替换时搞错“最近最少使用”的判断逻辑（是淘汰最久未用的，还是保留最近用的）。这些属于常规陷阱，非反直觉，故评为3。
- **K5 = 1**: 评分理由。本题仅涉及缓存子系统内部的映射和替换逻辑，不涉及CPU指令执行、中断处理或磁盘I/O等其他子系统的状态传递，属于单系统内部推演。

- **雷达形状**: K3推演主导型（K3显著高于其他维度，K1中等，K2/K5低）

## 考察模式
- **模式**: 推理型
- **理由**: 虽然包含简单的取模计算，但题目的核心不在于计算结果本身，而在于对缓存映射机制和LRU算法动态过程的逻辑推演。考生必须模拟计算机硬件的行为过程，而非直接套用公式。

## 选项级分析
- **选项A**: [干扰] — 针对完全未理解缓存命中机制或认为所有访问都不同的学生。如果学生错误地认为每次访问的块号不同就必然缺页，或者在模拟过程中过早淘汰了块8，可能会得出0次命中。
- **选项B**: [正确] — 正确模拟了整个过程，识别出只有块8在第二次访问时命中。
- **选项C**: [干扰] — 针对LRU状态维护错误的学生。例如，可能错误地认为块0或块1在后续访问中命中（实际上它们所在的组被其他块填满或替换，或者访问序列中并没有重复访问这些块导致命中）。或者误以为块48或32命中（实际上它们是新块，且可能替换了旧块，但自身首次访问必缺页）。另一种可能是误算了组号，导致将不同组的块误判为同一组从而产生虚假命中。
- **选项D**: [干扰] — 针对严重误解映射规则的学生。例如，误以为是直接相联映射（16组，每组1块），或者误以为是全相联映射（1组，16块），导致命中次数计算偏差。在全相联情况下，前16个不同块都缺页，第17个块155若替换了某个块，后续无重复，命中仍为0；若序列中有更多重复，命中数会增加。此选项主要干扰那些对“组相联”结构理解模糊，随意猜测的学生。

- **干扰策略**: 计算陷阱（模拟过程中的状态丢失）与概念混淆（映射方式错误）结合。

## 核心陷阱
- **核心陷阱**: **LRU状态的动态维护与组映射的精确对应**。
  1. **映射陷阱**：必须准确计算 `Block % 4` 来确定组号。例如，块255 % 4 = 3，块133 % 4 = 1。一旦组号算错，后续所有该组的模拟全部错误。
  2. **LRU陷阱**：在组0中，序列为 0, 4, 8, 8, 48, 32。
     - 访问0: [0]
     - 访问4: [4, 0] (4最近)
     - 访问8: [8, 4, 0] (8最近)
     - 访问8: **命中**，更新状态 [8, 4, 0] (8仍最近)
     - 访问48: 组满，淘汰最久未用的0。状态变为 [48, 8, 4]
     - 访问32: 组满，淘汰最久未用的4。状态变为 [32, 48, 8]
     很多学生可能在访问48或32时，错误地认为它们会命中，或者错误地淘汰了8，导致后续判断失误。本题中唯一的命中点非常隐蔽，仅有一次。

## 考察能力
本题核心考察考生对**组相联缓存映射机制**的理解以及在**LRU替换策略**下进行多步状态模拟与逻辑推演的能力。
