# 练习题 Q1 — CPU调度算法执行序列推演

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
考虑表中的三个进程 P1、P2 和 P3。
Process
Arrival time
Time Units Required
P1
0
5
P2
1
7
P3
3
4
在 FCFS（先来先服务）和 RR2（时间片为 2 个时间单位的轮转调度）策略下，这三个进程的完成顺序是（ ）？
- 选项:
  A: FCFS：P1，P2，P3，RR2：P1，P2，P3
  B: FCFS：P1，P3，P2， RR2：P1，P3，P2
  C: FCFS：P1，P2，P3， RR2：P1，P3，P2
  D: FCFS：P1，P3，P2， RR2：P1，P2，P3

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握FCFS和RR两种调度算法的基本定义及就绪队列的管理规则（如新进程到达时的插入位置、时间片用完后的处理）。不是4分因为不需要辨析多个易混的高级调度概念（如多级反馈队列），仅涉及基础算法。
- **K2 = 2**: 评分理由。计算过程主要是简单的整数加减法（时间累加），没有复杂的幂次或浮点运算，属于低难度计算。
- **K3 = 4**: 评分理由。RR2的推演过程较长，涉及多个时间片切换和进程到达事件的交织。从t=0到t=16左右，需要跟踪P1、P2、P3在就绪队列中的动态变化，步骤超过5步，且需记忆中间状态（如P1剩余时间、队列顺序），符合K4的标准。
- **K4 = 3**: 评分理由。存在常规注意点陷阱，即“新进程到达时，当前正在执行的进程是否立即让出”以及“时间片用完时，新到达进程与当前进程谁先入队”。通常规则是：若时间片恰好在进程到达时刻用完，新进程先入队，当前进程后入队（或反之，取决于具体教材约定，但408通常遵循：时间片结束瞬间，若新进程到达，新进程排在当前进程之前进入就绪队列，或者当前进程先出队再与新进程比较，需明确具体实现细节，本题中t=2时P1时间片用完，P2已在队列，P3未到达；t=3时P3到达，此时P1正在执行，P3加入队尾。关键在于t=4时P1再次执行，t=6时P1时间片用完，此时P3已在队列中。陷阱在于对“完成顺序”的判断，容易误以为执行时间长的P2会先完成或后完成，需仔细推演）。
- **K5 = 1**: 评分理由。仅涉及CPU调度子系统，不涉及内存、I/O等其他子系统的状态传递。
- **雷达形状**: K3推演主导型，K4陷阱辅助型。

## 考察模式
- **模式**: 推理型
- **理由**: 本题核心不在于记忆公式，而在于根据调度算法的规则，逐步模拟CPU的时间片分配和进程状态转换，推导出最终的完成顺序。

## 选项级分析
- **选项A**: [干扰] — 针对认为RR调度下长进程P2可能因为某种原因先完成的错误认知，或者完全未进行RR推演，仅凭直觉认为FCFS和RR顺序可能相同。这类学生可能忽略了RR的时间片轮转特性对短进程P3的优先完成影响。
- **选项B**: [干扰] — 针对FCFS理解错误的学生。FCFS严格按照到达时间排序，P1(0) -> P2(1) -> P3(3)，完成顺序必然是P1, P2, P3。选B的学生可能误以为FCFS会考虑服务时间或存在其他排序逻辑。
- **选项C**: [正确] — FCFS顺序为P1, P2, P3；RR2推演如下：
    - t=0: P1到达，执行P1。
    - t=1: P2到达，进入就绪队列 [P2]。P1继续执行。
    - t=2: P1时间片(2)用完，P1剩余3。P1进入就绪队列 [P2, P1]。CPU选P2执行。
    - t=3: P3到达，进入就绪队列 [P1, P3]。P2继续执行。
    - t=4: P2时间片(2)用完，P2剩余5。P2进入就绪队列 [P1, P3, P2]。CPU选P1执行。
    - t=6: P1时间片(2)用完，P1剩余1。P1进入就绪队列 [P3, P2, P1]。CPU选P3执行。
    - t=8: P3时间片(2)用完，P3剩余2。P3进入就绪队列 [P2, P1, P3]。CPU选P2执行。
    - t=10: P2时间片(2)用完，P2剩余3。P2进入就绪队列 [P1, P3, P2]。CPU选P1执行。
    - t=11: P1执行1个单位后完成（剩余1）。**P1完成**。就绪队列 [P3, P2]。CPU选P3执行。
    - t=13: P3时间片(2)用完，P3剩余0。**P3完成**。就绪队列 [P2]。CPU选P2执行。
    - t=15: P2时间片(2)用完，P2剩余1。P2进入就绪队列 [P2]。CPU选P2执行。
    - t=16: P2执行1个单位后完成。**P2完成**。
    - 完成顺序：P1, P3, P2。
- **选项D**: [干扰] — 针对FCFS理解错误（同B）且RR推演错误的学生。可能误以为P2因为总时间长，在RR中会一直占据CPU直到完成，或者错误地认为P2在RR中会比P3先完成。

**干扰策略**: 概念混淆（FCFS顺序）+ 计算陷阱（RR推演步骤多，易出错）。

## 核心陷阱
- **核心陷阱**: RR调度中，**新进程到达与时间片结束的时序关系**以及**就绪队列的动态更新**。特别是t=3时P3到达，此时P2正在执行，P3加入队尾；t=4时P2时间片结束，P2加入队尾，此时队列为P1, P3, P2。很多学生会错误地认为P2时间片结束后，P1先执行，然后P2再执行，而忽略了P3已经在队列中等待。此外，P1在t=11完成，P3在t=13完成，P2在t=16完成，这个顺序与直觉（P2最长）相反，是主要陷阱。

## 考察能力
本题核心考察学生对CPU调度算法（特别是轮转调度）的动态执行过程进行逐步模拟和状态跟踪的能力。
