# 练习题 Q1 — 汉诺塔递归关系式

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/算法分析
- **难度**: 待评估

## 题干原文
汉诺塔问题中，n 个圆盘的最优时间递推关系式是（ ）
A: T(n) = 2T(n−2) + 2
B: T(n) = 2T(n−1) + n
C: T(n) = 2T(n/2) + 1
D: T(n) = 2T(n−1) + 1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆汉诺塔问题的标准递归解法步骤。不是1分因为不能仅靠常识猜测，必须知道“移动n-1个盘子”这一核心逻辑；不是4分因为这是数据结构中最经典的递归案例之一，属于基础核心概念，无需辨析多个易混概念。
- **K2 = 1**: 评分理由。本题不涉及数值计算，仅涉及公式形式的匹配。没有复杂的算术运算，不存在计算错误的可能。
- **K3 = 2**: 评分理由。推演步骤较少。只需理解递归的三步走策略：1. 移走n-1个；2. 移动最大的；3. 移回n-1个。这是一个标准的2步逻辑映射（子问题规模减半/减1 + 常数操作），不需要多步串行推演或记忆中间状态。
- **K4 = 2**: 评分理由。存在常规注意点。需要识别“最优”意味着每次只移动一个盘子，且必须遵循大小规则。陷阱在于选项B中的`+n`，容易让误以为移动n个盘子需要n次操作的学生中招，但这属于常规的逻辑误区，并非深层隐含前提。
- **K5 = 1**: 评分理由。单系统问题。仅涉及递归算法的时间复杂度分析，不涉及与其他数据结构或系统模块的状态传递或耦合。
- **雷达形状**: K1主导型（概念记忆型）。K1较高，其他维度较低，呈现典型的“知识点回忆”特征。

## 考察模式
- **模式**: 概念型
- **理由**: 本题核心在于考察考生对汉诺塔问题递归算法逻辑结构的理解，即如何将大问题分解为子问题。它不要求考生进行复杂的数学推导或代码实现，而是要求识别出标准的递归关系式，属于对经典算法模型的概念性考察。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：误以为递归步长是2。这类学生可能混淆了分治策略中的某些特定情况（如某些归并变种），或者错误地认为一次可以处理两个盘子。
- **选项B**: [干扰] — 针对错误认知：混淆“移动次数”与“操作代价”。这类学生可能认为移动n个盘子需要n次基本操作，或者误以为递归的合并步骤（Combine）代价是线性的。这是最常见的干扰项，利用了学生对“n”这个变量的直觉依赖。
- **选项C**: [干扰] — 针对错误认知：混淆汉诺塔与分治算法（如二分查找、归并排序）。这类学生可能机械地套用 `T(n) = aT(n/b) + f(n)` 的通用分治模板，误以为汉诺塔也是将问题规模减半（n/2），忽略了汉诺塔必须逐个移动的特性。
- **选项D**: [正确] — 符合汉诺塔的标准递归逻辑：解决n个盘子的问题，需要先解决n-1个盘子（T(n-1)），移动最大盘子（1次操作），再解决剩下的n-1个盘子（T(n-1)），故为 2T(n-1) + 1。
- **干扰策略**: 概念混淆。主要通过提供其他常见算法（如分治、线性扫描）的递推式作为干扰，考察考生是否真正理解汉诺塔“必须移动n-1个盘子才能移动第n个”这一核心约束。

## 核心陷阱
- **核心陷阱**: 选项B的 `+n`。考生容易直觉性地认为处理n个元素需要n的代价，或者误以为递归的“合并”阶段需要遍历所有元素。实际上，汉诺塔中移动最大盘子仅需1次操作，其余工作全部由递归子问题承担。

## 考察能力
一句话概括本题核心考察的能力：对经典递归算法（汉诺塔）问题分解逻辑及时间复杂度递推关系的建模能力。
