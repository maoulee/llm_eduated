# 练习题 Q1 — 汇编寻址模式辨析

- **来源**: 练习题  **题型**: 选择题

## 题干原文
考虑以下汇编代码：
(P1) :
 BYTE_VALUE DB 150 // 定义一个字节值
 WORD_VALUE DW 300 // 定义一个字值
 ADD BYTE_VALUE, 65 // 立即操作数 65 被相加
 MOV AX, 45H    // 立即常量 45H 被传送到 AX
(P2) :
 MY_TABLE TIMES 10 DW 0 // 分配 10 个字（每个 2 字节），初始化为 0
 MOV EBX, [MY_TABLE] // 将 MY_TABLE 的有效地址存入 EBX
 MOV [EBX], 110   // MY_TABLE[0] = 110
 ADD EBX, 2     // EBX = EBX + 2
 MOV [EBX], 123   // MY_TABLE[1] = 123
以下哪个选项是正确的？（ ）
- 选项:
  A: P1 使用立即寻址，而 P2 使用间接内存寻址模式。
  B: P1 使用立即寻址，而 P2 使用直接内存寻址模式。
  C: P1 使用直接内存寻址，而 P2 使用直接内存寻址模式。
  D: 以上都不是
- 正确答案: A

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。需要辨析“立即寻址”、“直接寻址”和“间接寻址”三个易混概念。虽然基础，但题目中P2的代码写法（`MOV EBX, [MY_TABLE]` 后接 `MOV [EBX], ...`）具有误导性，需要考生准确识别寄存器间接寻址的特征，而非简单的定义记忆。
- **K2 = 1**: 评分理由。本题不涉及数值计算，无需执行算术或逻辑运算。
- **K3 = 3**: 评分理由。需要分步推演P2的执行流程：首先理解`MOV EBX, [MY_TABLE]`是将内存地址处的值（或地址本身，取决于具体汇编器语义，此处语境暗示获取地址或基址）放入寄存器，随后`MOV [EBX], 110`是利用寄存器EBX中的内容作为地址去访问内存。这需要2-3步的逻辑串联。
- **K4 = 4**: 评分理由。存在明显的“陷阱词”和隐含前提。P2中的`MOV EBX, [MY_TABLE]`在标准x86汇编中通常表示将MY_TABLE指向的内存单元的值加载到EBX，但结合后续`MOV [EBX], 110`及题目意图，这里考察的是“寄存器间接寻址”的概念模型。考生必须意识到题目是在考察寻址模式的*分类*，而非严格汇编语法的正确性（因为严格来说`MOV EBX, [MY_TABLE]`若MY_TABLE是数组首地址，通常用`LEA`或`MOV EBX, OFFSET MY_TABLE`来获取地址，若用`[]`则是取值）。这种语义上的模糊性是主要的暗坑。
- **K5 = 2**: 评分理由。主要涉及CPU指令执行单元与内存单元的交互，属于单系统内的机制，但需要理解指令格式中操作数来源（立即数 vs 内存地址 vs 寄存器内容）的区别。
- **雷达形状**: K1/K4高位型（概念辨析与陷阱规避型）

## 考察模式
- **模式**: 概念型
- **理由**: 题目核心在于识别汇编指令中操作数的获取方式（寻址模式），而非计算结果或复杂系统行为。重点在于对“立即数”、“直接地址”、“间接地址”定义的准确理解和应用。

## 选项级分析
- **选项A**: [正确] — P1中`ADD BYTE_VALUE, 65`和`MOV AX, 45H`的操作数65和45H直接包含在指令中，属于立即寻址。P2中`MOV [EBX], 110`的操作数地址存储在寄存器EBX中，属于寄存器间接寻址（广义上的间接内存寻址）。
- **选项B**: [干扰] — 针对认为P2是直接寻址的学生。这类学生可能忽略了`[EBX]`中的EBX是寄存器，误以为只要涉及内存访问就是直接寻址，或者混淆了“直接寻址”（地址在指令中）和“间接寻址”（地址在寄存器/内存中）的区别。
- **选项C**: [干扰] — 针对完全混淆P1和P2寻址模式的学生。可能误以为P1中`BYTE_VALUE`是内存地址所以是直接寻址（忽略了第二个操作数65是立即数，且题目问的是整体特征或主要特征，通常以源操作数或复杂操作数为准，但此处P1两指令均为立即数源），且误判P2为直接寻址。
- **选项D**: [干扰] — 针对对汇编语法极度严谨或感到困惑的学生。由于P2代码在严格x86语法下可能存在歧义（如前所述，`MOV EBX, [MY_TABLE]`通常取值而非取址），部分学生可能认为题目代码错误从而选D。

**干扰策略**: 概念混淆（直接 vs 间接）与 语法陷阱（汇编语法的严格性 vs 概念考察的意图）

## 核心陷阱
**核心陷阱**: P2代码中`MOV EBX, [MY_TABLE]`的语义歧义。在标准汇编中，`[]`表示内存引用。如果MY_TABLE是变量名，`[MY_TABLE]`通常指该变量存储的值。若题目意图是获取地址，应使用`OFFSET`或`LEA`。然而，题目后续使用`[EBX]`进行内存写入，明确展示了“寄存器内容作为地址”的间接寻址特征。考生需透过可能的语法不严谨，抓住“寄存器间接寻址”这一核心考点，而非纠结于代码是否能直接编译运行。

## 考察能力
准确辨析汇编指令中不同寻址模式（立即、直接、间接）的定义及其在代码中的具体表现形式。
