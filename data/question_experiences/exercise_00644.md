# 练习题 Q1 — IEEE-754浮点数解码

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机组成原理/数制
- **难度**: 待评估

## 题干原文
以下哪个数字的 IEEE-754 32 位浮点数表示为
0 10000000 110 0000 0000 0000 0000 0000
？（ ）
- 选项:
  A: 2.5
  B: 3.0
  C: 3.5
  D: 4.5

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆IEEE-754单精度浮点数的标准格式（1位符号、8位指数、23位尾数）以及移码偏置值（127）。这是计算机组成原理中的核心定义，属于标准记忆需求。不是4分因为不需要辨析多个易混概念（如双精度或特殊值处理），只需调用单一核心定义。
- **K2 = 2**: 评分理由。计算过程非常友好。指数部分 `10000000` 是 $2^7=128$，减去127得1，无需复杂换算；尾数部分 `1.11` 转换为十进制 $1 + 1/2 + 1/4 = 1.75$，最后乘以 $2^1$ 得 3.5。所有数值均为2的幂次或简单分数，不易算错。
- **K3 = 2**: 评分理由。解题步骤清晰且串行：1. 拆分位域；2. 计算指数真值；3. 还原尾数（含隐含位）；4. 组合计算。总共约4步，逻辑线性，无需回溯或复杂的状态记忆。
- **K4 = 3**: 评分理由。存在一个关键的隐含前提：**隐含的前导1**。如果考生忘记规范化浮点数在尾数前隐含一个“1”，会误将尾数视为 `0.11` 或 `110...` 直接转换，导致结果错误。这是一个经典的“题面没说但解题必须意识到的条件”，属于常规注意点中的陷阱。
- **K5 = 1**: 评分理由。本题完全局限于“数制与编码”这一单一子系统内部，不涉及指令执行、数据通路、缓存或其他硬件模块的状态传递。

- **雷达形状**: K4陷阱型（K1/K2/K3较低，K4中等偏高，主要考察对隐含规则的意识）

## 考察模式
- **模式**: 计算型
- **理由**: 虽然涉及概念记忆，但解题的核心动作是将二进制位域转换为十进制数值，依赖于具体的算术运算（移码还原、二进制小数转十进制、乘法），而非纯逻辑推理或概念辨析。

## 选项级分析
- **选项A (2.5)**: [干扰] — 针对**指数计算错误**或**尾数理解偏差**。如果考生误以为指数是0（即 $2^0$），或者误将尾数 `1.11` 看作 `1.01` ($1.25 \times 2^1 = 2.5$)，可能会选此项。也可能是混淆了 $2.5 = 1.01 \times 2^1$ 的位模式。
- **选项B (3.0)**: [干扰] — 针对**尾数精度忽略**。3.0 的二进制是 `11.0`，即 $1.1 \times 2^1$。如果考生看错了尾数部分的最后一位（将 `110` 看错为 `100` 或忽略最后一位1），或者误以为 `1.11` 近似为 `1.1`，可能会选此项。
- **选项C (3.5)**: [正确] — 正确解码结果。符号正，指数 $128-127=1$，尾数 $1.11_2 = 1.75_{10}$，$1.75 \times 2^1 = 3.5$。
- **选项D (4.5)**: [干扰] — 针对**指数偏移错误**。如果考生忘记减去偏置值127，直接使用指数128，或者误以为指数是2（$1.11 \times 2^2 = 7$ 不对，可能是 $1.011 \times 2^2 = 4.5$）。更可能的情况是，考生正确计算了尾数 $1.75$，但错误地认为指数是2（例如误读指数位或偏置值记错），导致 $1.75 \times 4 = 7$（非选项），或者混淆了 $4.5 = 1.011 \times 2^2$ 的位模式。另一种常见错误是忘记隐含位，将尾数视为 $0.11$，则 $0.75 \times 2^? $ 难以凑出4.5，故此项更多是作为数量级较大的干扰项。

- **干扰策略**: 概念混淆（隐含位）与计算陷阱（指数偏置）结合。

## 核心陷阱
- **核心陷阱**: **隐含的前导1（Hidden Bit）**。
  在IEEE-754规范化浮点数中，尾数部分存储的是小数点后的部分，而整数部分的“1”是隐含的，不存储在23位尾数字段中。
  - 错误做法：直接将 `110...` 视为 $0.110..._2$ 或 $110..._2$。
  - 正确做法：构造 $1.110..._2$。
  此外，**指数偏置值127**的减法也是易错点，但相比隐含位，指数计算更为直观。

## 考察能力
本题核心考察考生对IEEE-754单精度浮点数存储格式（符号、指数、尾数）的解码能力，特别是对**隐含前导1**机制和**移码偏置**规则的应用熟练度。
