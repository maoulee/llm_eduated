# 练习题 Q1 — 存储器扩展与译码器选择

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 计算机组成原理/存储系统
- **难度**: 待评估

## 题干原文
假设你想要构建一个以 4 字节为单位、容量为 $2^{21}$ 位的存储器。如果该存储器由 2K×8 的 RAM 芯片组成，那么需要哪种类型的译码器？（ ）
A: 5 到 32
B: 6 到 64
C: 4 到 64
D: 7 到 128

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握存储器扩展的基本概念（位扩展、字扩展）、RAM芯片规格含义（2K×8表示地址线和数据线数量）以及译码器在片选中的作用。属于标准的基础概念记忆，不涉及深层辨析。
- **K2 = 3**: 评分理由。涉及单位换算（位到字节/字）、容量计算（$2^{21}$位转字数）、芯片数量计算（总容量/单片容量）以及行/列分组计算。虽然都是2的幂次，但步骤较多，容易在“字长”定义上出错，属于标准难度的计算。
- **K3 = 3**: 评分理由。解题逻辑链条清晰：确定目标存储器规格 -> 确定单片规格 -> 计算所需芯片总数 -> 确定扩展方式（位扩展+字扩展）-> 确定字扩展所需的行数 -> 确定译码器输入输出。共4-5步串行推演，属于标准机制推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和易错点。首先，题干给出的是“位”容量，而字长是“4字节”，必须先将总容量转换为“字数”才能与芯片的“字”概念对应；其次，必须意识到译码器仅用于“字扩展”（选择哪一行/哪一组芯片），而“位扩展”（增加数据宽度）是通过并联数据线实现的，不需要译码器参与选择。若忽略字长单位或混淆位/字扩展，极易选错。
- **K5 = 2**: 评分理由。主要考察存储系统内部的结构设计，虽然涉及CPU地址总线与存储器的连接（隐含），但题目聚焦于存储器本身的构建，跨域联动需求较低，仅涉及存储子系统内部模块（芯片、译码器）的关系。
- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要难点在于识别隐含条件和避免概念混淆）

## 考察模式
- **模式**: 综合型
- **理由**: 本题结合了概念理解（存储器扩展原理）、数值计算（容量与芯片数量）和逻辑推理（译码器作用范围）。它不是单纯的公式代入，也不是纯概念辨析，而是需要在一个具体的工程场景下综合运用多个知识点。

## 选项级分析
- **选项A**: [正确] — 正确计算了字扩展所需的行数。总字数为 $2^{16}$，单片字数为 $2^{11}$ (2K)，故需要 $2^{16}/2^{11} = 2^5 = 32$ 组芯片进行字扩展。每组芯片通过位扩展达到4字节宽度。因此需要选择32组中的一组，即需要5-32译码器。
- **选项B**: [干扰] — 针对未进行位扩展或误算总容量的学生。如果学生错误地认为总容量是 $2^{21}$ 字（忽略4字节字长），或者错误地计算芯片总数为64片且全部用于字扩展，可能会选此项。$2^{21} / 2^{11} = 2^{10} = 1024$，这显然不对。另一种可能是误以为需要64个片选信号，对应6-64译码器。
- **选项C**: [干扰] — 针对混淆位扩展和字扩展比例的学生。如果学生计算出总共需要128片芯片（$2^{16} \times 32 \text{ bits} / 8 \text{ bits} = 2^{16} \times 4 = 2^{18}$ bits? 不对，重新计算：总容量 $2^{21}$ bits，单片 $2^{11} \times 8$ bits。总片数 $2^{21} / (2^{11} \times 8) = 2^{10} / 8 = 128$ 片。如果学生认为这128片都需要独立片选，或者错误地认为位扩展也需要译码器，可能会寻找与128相关的选项，但C是4-64。更可能的错误路径是：计算出需要32组，每组4片。如果误以为译码器要选到具体的芯片（32组*4片=128片），则需7-128。如果误算组数为64，则需6-64。C选项4-64可能源于对2K=1024和4字节=32bit的混淆，导致计算出的组数错误。
- **选项D**: [干扰] — 针对认为译码器需要选择每一个具体芯片的学生。总芯片数为128片（$2^{21}$ bits / ($2^{11} \times 8$ bits) = 128）。如果学生错误地认为每个芯片都需要独立的片选信号，则会选择7-128译码器。这是最常见的错误，混淆了“组选”和“片选”。

**干扰策略**: 概念混淆（位扩展vs字扩展）、计算陷阱（单位换算错误）、逻辑错误（译码器作用范围）。

## 核心陷阱
- **核心陷阱**: **混淆位扩展与字扩展对译码器的需求**。学生容易计算出总芯片数（128片），然后误以为需要译码器来选择这128片中的每一片。实际上，位扩展（将8位扩展到32位）是通过数据线并联实现的，同一组的4片芯片同时被选中；只有字扩展（选择哪一组地址空间）才需要译码器。因此，译码器的输出端数等于“组数”（32组），而非“总芯片数”（128片）。此外，题干给出的容量单位是“位”，而字长是“字节”，必须进行单位统一，这也是一个关键陷阱。

## 考察能力
本题核心考察学生在存储器扩展设计中，准确区分位扩展与字扩展机制，并能根据目标存储器的字长和容量，正确计算所需芯片分组及对应译码器规格的能力。
