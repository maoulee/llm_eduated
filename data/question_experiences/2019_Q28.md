# 2019 Q28 — 段式内存管理中的共享机制

## 基本信息
- **年份**: 2019  **题位**: Q28  **题型**: 选择题
- **知识点**: 段式内存管理, 段式管理, 操作系统>段式内存管理
- **题位域**: 待标注  **科目**: 操作系统

## 题干原文
在分段存储管理系统中，用共享段表描述所有共享的段。若进程 P1 和 P2 共享段 S，下列叙述中，错误的是（ ）。

A. 在物理内存中仅保存一份段 S 的内容
B. 段 S 在 P1 和 P2 中应该具有相同的段号
C. P1 和 P2 共享段 S 在共享段表中的段表项
D. P1 和 P2 都不再使用段 S 时才回收段 S 所占的内存空间

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“段式管理”、“共享段表”、“逻辑段号”与“物理地址”的核心定义。不是4分因为不需要辨析多个易混的高级概念，只需理解共享的基本原理。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算或公式代入，属于纯概念判断。
- **K3 = 2**: 评分理由。推演步骤较少，主要逻辑为：共享 -> 物理内存一份 -> 逻辑地址独立。只需理解“逻辑空间”与“物理空间”的映射关系，无需多步串行推演。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。学生容易直觉认为“共享的东西应该长得一样（包括编号）”，但操作系统中逻辑地址空间是私有的，段号是逻辑概念，可以不同。这是一个典型的“反直觉”或“隐含前提”陷阱，即逻辑独立性。
- **K5 = 2**: 评分理由。主要涉及内存管理子系统内部的状态（段表、物理内存），虽然涉及两个进程，但并未跨越到文件系统或I/O等其他子系统，属于单系统内的状态关联。
- **雷达形状**: K4陷阱型（概念辨析为主，无明显计算，但在逻辑独立性上设有陷阱）

## 考察模式
- **模式**: 概念型
- **理由**: 题目完全基于操作系统内存管理的理论机制进行判断，不涉及具体数值计算，重点考察对“逻辑地址”与“物理地址”分离以及“共享”实现机制的理解。

## 选项级分析
- **选项A**: [正确叙述] — 针对“共享”的本质认知。共享的核心目的就是为了节省内存，因此在物理内存中确实只保存一份副本。学生若理解共享机制，此选项极易判断为正确。
- **选项B**: [错误叙述/本题答案] — 针对“逻辑地址独立性”的错误认知。许多学生误以为共享意味着“完全一致”，包括段号。实际上，段号是进程逻辑地址空间的一部分，P1和P2可以将同一个物理段映射到自己逻辑空间的不同段号上（例如P1中是段2，P2中是段5）。这是本题的核心考点。
- **选项C**: [正确叙述] — 针对“共享段表”的结构认知。共享段表的作用就是记录共享段的物理信息，P1和P2的私有段表项会指向共享段表中的同一个表项（或通过某种机制关联到同一物理块），因此它们共享该表项描述的物理属性。
- **选项D**: [正确叙述] — 针对“资源回收”的安全机制认知。这是引用计数或类似机制的基本逻辑，只有当所有使用者都释放后，资源才能回收，否则会导致悬空指针或数据丢失。

- **干扰策略**: 概念混淆。利用“共享”一词带来的“一致性”心理暗示，诱导学生认为逻辑属性（段号）也必须一致，从而忽略逻辑地址空间的私有性。

## 核心陷阱
**逻辑段号的私有性 vs 物理内容的共享性**。
陷阱在于学生容易混淆“逻辑视图”和“物理视图”。虽然物理内容（选项A）和物理地址描述（选项C）是共享的，但逻辑段号（选项B）属于进程私有的逻辑地址空间，完全可以不同。题目要求选“错误”的，因此B是答案。

## 考察能力
考察考生对段式存储管理中“逻辑地址与物理地址分离”以及“共享机制实现原理”的深度理解能力，特别是区分逻辑属性与物理属性的能力。
