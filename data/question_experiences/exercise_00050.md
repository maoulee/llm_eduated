# 练习题 Q1 — 存储器扩展与位扩展计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
要提供 256K 字节的内存容量，需要多少个 32K×1 的 RAM 芯片？（ ）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要调用“字节与位的换算关系（1 Byte = 8 bits）”以及“存储器容量表示法（K代表1024，×1代表位宽）”这两个核心概念。不是4分因为不需要辨析复杂的易混概念（如SRAM与DRAM的区别、Cache映射方式等），仅需基础定义记忆。
- **K2 = 3**: 评分理由。涉及多级单位换算（KB转Bit，K转1024）和除法运算。虽然都是2的幂次，但需要处理“字节”到“位”的8倍转换，属于标准难度的计算，非简单的直接代入。
- **K3 = 1**: 评分理由。从输入到输出仅需一步逻辑：总需求位数 / 单芯片位数。无需多步串行推演或记忆中间状态。
- **K4 = 2**: 评分理由。存在常规注意点，即必须意识到题目要求的是“字节”容量，而芯片提供的是“位”容量，必须进行位宽扩展。没有深层隐含前提或反直觉陷阱，属于常规考点。
- **K5 = 1**: 评分理由。本题仅涉及存储器子系统内部的容量计算，不涉及CPU调度、中断、进程管理等其他子系统的状态传递或联动。

- **雷达形状**: K2计算主导型（K1、K2略高，K3-K5极低）

## 考察模式
- **模式**: 计算型
- **理由**: 解题核心在于通过公式 `芯片数量 = (目标容量 × 8) / (单芯片地址数 × 单芯片位宽)` 进行数值计算，而非概念辨析或逻辑推理。

## 选项级分析
- **选项A (8)**: [干扰] — 针对**忽略位宽扩展**的错误认知。这类学生可能只计算了地址空间的扩展倍数：$256K / 32K = 8$。他们误以为只需要8个芯片来覆盖地址空间，忽略了每个地址需要8位数据，而芯片只有1位宽。
- **选项B (32)**: [干扰] — 针对**单位换算错误**的错误认知。这类学生可能混淆了K的含义，或者在计算 $256 \times 8 / 32$ 时出错，或者误以为 $256K$ 字节等于 $256K$ 位（少乘8），然后 $256/32=8$ 也不对，可能是 $256/8=32$ 这种无逻辑的凑数，或者误算为 $256K \text{ bits} / 32K \text{ bits} = 8$ 后再乘以4（错误逻辑）。更可能的错误路径是：认为 $256K$ 字节 $= 256 \times 1024$ 字节，芯片 $32K \times 1$，误将 $32K$ 当作 $32$ 字节或其他错误换算。实际上，若学生忘记乘8，得到8；若学生错误地认为 $1K=1000$ 且计算混乱，可能得出此结果。但在408语境下，B选项通常作为 $256/8=32$ 这种错误除法（用字节数除以位宽8，却忘了除以芯片地址深度32K）的干扰项，即 $256K \text{ Bytes} / 8 \text{ bits/Byte} = 32K \text{ bits}$? 不对。最可能的错误是：$256K / 32K = 8$，然后 $8 \times 4 = 32$（无依据）。或者，学生计算总位数为 $256 \times 8 = 2048K$ 位，单芯片 $32K$ 位，$2048/32 = 64$。若学生算成 $256/8 = 32$，则是完全忽略了芯片的地址深度 $32K$。
- **选项C (64)**: [正确] — 正确计算：总需求 $256K \times 8$ 位，单芯片 $32K \times 1$ 位。数量 $= (256 \times 8) / 32 = 2048 / 32 = 64$。
- **选项D (128)**: [干扰] — 针对**重复计算或倍数错误**的错误认知。这类学生可能在计算位宽扩展时，错误地认为需要 $256K / 32K = 8$ 组，每组需要 $8$ 个芯片（位扩展），但错误地计算为 $8 \times 16 = 128$，或者在单位换算中多乘了一个2。例如，误以为 $1K=2048$ 或其他错误换算。

- **干扰策略**: 概念混淆（忽略位宽扩展，选A）与计算陷阱（单位换算错误，选B/D）

## 核心陷阱
- **核心陷阱**: **位宽扩展与字扩展的混淆**。考生最容易犯的错误是只计算了地址空间的扩展倍数（$256K/32K=8$），而忘记了目标内存是“字节”寻址（8位），而芯片是“1位”宽，因此还需要进行8倍的位扩展。即：总芯片数 = 字扩展倍数 × 位扩展倍数 = $8 \times 8 = 64$。

## 考察能力
一句话概括本题核心考察的能力：掌握存储器扩展技术中，基于字节/位单位换算进行字扩展和位扩展的综合计算能力。
