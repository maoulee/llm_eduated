# 模拟题 Q1 — 二叉树性质与结点度数关系

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: DS-5 > 5.2 二叉树的概念 > 二叉树性质
- **难度**: 待评估

## 题干原文
若一棵二叉树中有 24 个叶结点，有 28 个仅有一个孩子的结点，则该二叉树的总结点数为（ ）。

A. 70
B. 73
C. 75
D. 77

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆二叉树的核心性质公式 $n_0 = n_2 + 1$。不是2分因为这不是常识，必须调用特定知识点；不是4分因为不需要辨析多个易混概念（如满二叉树、完全二叉树的区别），只需调用一个核心定义。
- **K2 = 2**: 评分理由。计算过程极其简单，仅为一次减法（$24-1$）和两次加法（$24+28+23$）。数字均为整数且无复杂进位或幂次运算，属于“2的幂友好”之外的简单算术，不易出错。
- **K3 = 2**: 评分理由。解题步骤清晰且串行：1. 识别已知量 $n_0, n_1$；2. 利用性质求 $n_2$；3. 求和。总共3步，逻辑线性，无需回溯或复杂的状态维护。
- **K4 = 2**: 评分理由。题干表述清晰，“叶结点”对应 $n_0$，“仅有一个孩子”对应 $n_1$。没有明显的隐含前提或反直觉陷阱。常规注意点在于确认“仅有一个孩子”确实指度为1的结点，这是标准术语，不属于深坑。
- **K5 = 1**: 评分理由。本题完全局限于二叉树的基本性质子系统内，不涉及图、树的其他遍历算法或存储结构转换，无跨域联动需求。
- **雷达形状**: K1主导型（基础概念记忆型）。K1略高，其余维度均较低，呈现典型的“公式代入”特征。

## 考察模式
- **模式**: 计算型
- **理由**: 虽然基于概念（二叉树性质），但解题的核心动作是将已知数值代入公式进行算术运算，最终得出一个具体的数值结果。

## 选项级分析
- **选项A (70)**: [干扰] — 针对**忽略 $n_1$** 的错误认知。学生可能误以为总结点只与叶子和度为2的结点有关，或者错误地认为 $n = n_0 + n_2 = 24 + 23 = 47$（此选项数值不对，可能是另一种错误：$n_0 + n_1 = 24+28=52$ 也不对）。更可能的错误路径是：误用公式 $n = 2n_0 - 1$（这是满二叉树或特定情况下的近似，或者混淆了边数与结点数关系），$2 \times 24 - 1 = 47$ 也不对。让我们重新推导常见错误：如果学生忘记加 $n_1$，算出 $24+23=47$，选项里没有。如果学生误以为 $n_2 = n_0$，则 $n_2=24$，总和 $24+28+24=76$，接近D。如果学生误以为 $n_1$ 不影响总数，或者计算 $n_2$ 时出错。
    *修正分析*：A选项 70 可能是通过 $n_0 + n_1 + (n_0 - 2)$? 或者 $24 + 28 + (24-1) = 75$ 是正确答案。若选A，可能是计算错误：$24+28+23$ 算错？或者误以为 $n_2 = n_0 - 2 = 22$，则 $24+28+22=74$。
    *更可能的干扰逻辑*：有些学生可能记错公式为 $n_2 = n_0$，则 $n_2=24$，总和 $24+28+24=76$（接近D）。若记错为 $n_0 = n_2$，且忽略 $n_1$ 的贡献权重？
    实际上，A选项 70 可能是 $24 \times 3 - 2$? 不太像。
    让我们看一个常见错误：认为总结点数 $n = 2n_0 + n_1 - 1$? $48+28-1=75$ (正确)。
    如果学生误以为 $n_2 = n_0 - 1$ 是错的，直接用 $n_0 + n_1 = 52$，再加个什么？
    *重新审视干扰项设计*：
    A: 70. 可能是 $24 + 28 + (24-1) - 5$? 或者是 $n_0 + n_1 + n_2$ 中 $n_2$ 算错。若 $n_2 = 18$?
    其实 A 选项 70 可能是针对 **$n = n_0 + n_1 + n_2$** 中，误将 $n_2$ 算为 $n_0 - 1 - 5$? 
    或者，学生可能使用边数公式：总度数 = 边数 = $n-1$。
    $0 \cdot n_0 + 1 \cdot n_1 + 2 \cdot n_2 = n - 1$
    $28 + 2n_2 = n - 1$
    $n = 29 + 2n_2$
    又 $n = n_0 + n_1 + n_2 = 52 + n_2$
    $52 + n_2 = 29 + 2n_2 \Rightarrow n_2 = 23$。
    如果学生在这里列方程出错，比如 $28 + 2n_2 = n$ (忘记-1)，则 $n = 28 + 46 = 74$。
    如果学生认为 $n_2 = n_0 = 24$，则 $n = 24+28+24=76$。
    如果学生认为 $n_2 = n_0 - 1 = 23$，但加法算错 $24+28+23 = 75$。
    A选项 70 可能是 $24 + 28 + 18$? 为什么 $n_2=18$? 也许误以为 $n_0 = n_2 + 6$?
    *结论*：A选项的具体错误路径较难唯一确定，但通常作为**计算失误**或**公式记忆偏差**（如记错常数项）的干扰项。

- **选项B (73)**: [干扰] — 针对**公式记忆偏差**或**计算失误**。例如，误以为 $n_2 = n_0 - 2 = 22$，则 $24+28+22=74$（接近）。或者误以为 $n_2 = n_0 - 1$ 但算成 $24-1=23$，然后加法 $24+28+23$ 时少加了2？或者误用 $n = 2n_0 + n_1 - 3$?
    另一种可能：学生正确算出 $n_2=23$，但在求和时，$24+28=52$， $52+23=75$。如果算成 $52+21=73$?
    或者，学生误以为 $n_1$ 的结点数不计入总结点？$24+23=47$。
    或者，学生误以为 $n_0 = n_2$，则 $n_2=24$，总和 $76$。
    B选项 73 可能是 $75 - 2$，典型的**粗心计算错误**干扰项。

- **选项C (75)**: [正确] — 正确应用性质 $n_0 = n_2 + 1$ 得出 $n_2 = 23$，并正确求和 $24 + 28 + 23 = 75$。

- **选项D (77)**: [干扰] — 针对**公式方向记反**或**多算**。
    1. 记反公式：误以为 $n_2 = n_0 + 1 = 25$。则 $n = 24 + 28 + 25 = 77$。这是最常见的错误之一，混淆了叶子结点和度为2结点的数量关系。
    2. 或者误以为 $n_1$ 也要满足某种对称性？
    3. 或者计算 $24+28+23$ 时多加了2。
    *主要干扰策略*：公式方向记反（$n_2 = n_0 + 1$）。

- **干扰策略**: 概念混淆（公式方向记反导致D）、计算陷阱（加减错误导致B或A）。

## 核心陷阱
- **核心陷阱**: **二叉树性质公式的方向性**。学生极易混淆 $n_0 = n_2 + 1$ 和 $n_2 = n_0 + 1$。由于叶结点（$n_0$）通常比度为2的结点（$n_2$）多1个，记反会导致 $n_2$ 计算错误，进而导致最终结果偏差（如选D）。

## 考察能力
一句话概括本题核心考察的能力：准确记忆并应用二叉树中叶子结点与度为2结点数量关系（$n_0 = n_2 + 1$）进行基础数值计算的能力。
