# 练习题 Q1 — 循环队列满空判断条件

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/队列
- **难度**: 待评估

## 题干原文
假设一个容量为 (n-1) 的循环队列使用大小为 n 的数组实现。插入和删除操作分别通过 REAR 和 FRONT 作为数组索引变量完成。初始时， REAR = FRONT = 0 。检测队列满和队列空的条件是（ ）：
A: 满： (REAR+1) mod n == FRONT ，空： REAR == FRONT
B: 满： (REAR+1) mod n == FRONT ，空： (FRONT+1) mod n == REAR
C: 满： REAR == FRONT ，空： (REAR+1) mod n == FRONT
D: 满： (FRONT+1) mod n == REAR ，空： REAR == FRONT

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆循环队列中“牺牲一个存储单元”以区分满和空的经典定义。这不是简单的术语回忆，而是对特定实现策略（牺牲空间换时间/逻辑简化）的概念掌握。不记忆该特定实现细节无法直接作答，但属于数据结构核心基础概念。
- **K2 = 2**: 评分理由。涉及简单的取模运算逻辑 `(REAR+1) % n`，计算量极小，属于基础算术逻辑，几乎不会出错。
- **K3 = 2**: 评分理由。推演步骤较少。只需理解初始状态 `REAR=FRONT` 为空，以及当 `REAR` 追上 `FRONT` 前一步时为满的逻辑。无需多步复杂的状态追踪。
- **K4 = 4**: 评分理由。存在明显的隐含前提和易混淆点。
    1. **隐含前提**：题目明确指出容量为 `n-1`，这意味着采用了“牺牲一个单元”的策略，而非使用额外标志位或计数器。如果考生未意识到这一点，可能会误选 `REAR == FRONT` 为满（那是容量为 n 且无牺牲单元时的歧义状态，或者误以为满时指针重合）。
    2. **陷阱**：容易混淆“满”和“空”的条件，特别是当 `REAR` 和 `FRONT` 在循环数组中相遇时的语义差异。
- **K5 = 1**: 评分理由。仅涉及队列单一数据结构内部的状态判断，不涉及与其他子系统（如栈、树、图）的联动。
- **雷达形状**: K4陷阱型。基础概念（K1）和计算（K2）要求不高，但对隐含条件（牺牲单元策略）的识别（K4）要求较高，是典型的“概念辨析+陷阱规避”题型。

## 考察模式
- **模式**: 概念型
- **理由**: 本题不侧重于复杂的代码实现或数值计算，而是侧重于对循环队列特定实现机制（牺牲一个存储单元以解决满空歧义）的理论理解和条件记忆。

## 选项级分析
- **选项A**: [正确] — 符合“牺牲一个单元”策略的标准定义。空时 `REAR == FRONT`；满时，`REAR` 的下一个位置是 `FRONT`，即 `(REAR+1) % n == FRONT`。
- **选项B**: [干扰] — 针对混淆“满”和“空”条件的错误认知。学生可能记得满的条件是 `(REAR+1)%n == FRONT`，但错误地认为空的条件也是某种“差1”的关系，或者混淆了 `FRONT` 和 `REAR` 的角色。
- **选项C**: [干扰] — 针对完全颠倒满空条件的错误认知。这是最典型的错误，学生可能记得 `REAR == FRONT` 是某种边界状态，但记反了哪一个是空，哪一个是满。在牺牲单元策略中，`REAR == FRONT` 只能是空。
- **选项D**: [干扰] — 针对对指针移动方向或满条件公式记忆错误的认知。`(FRONT+1) % n == REAR` 通常表示队列中只有一个元素（当 `FRONT` 指向队头元素，`REAR` 指向队尾元素时，若只有一元素，`REAR` 在 `FRONT` 后一位），或者是对满条件公式的胡乱拼凑。

- **干扰策略**: 概念混淆。主要通过交换“满”和“空”的判断条件，以及提供看似合理但逻辑错误的指针关系公式来干扰考生。

## 核心陷阱
- **核心陷阱**: **满空状态的歧义性及其解决方案**。
    在循环队列中，`REAR == FRONT` 既可能表示队列为空，也可能表示队列已满（如果数组被完全填满）。题目明确指出容量为 `n-1`，暗示了采用“牺牲一个存储单元”的策略来消除这种歧义。考生必须明确：在此策略下，`REAR == FRONT` **永远**表示空，而满的条件是 `REAR` 的下一个位置等于 `FRONT`。如果考生忽略了“容量为 n-1”这一关键约束，可能会误以为 `REAR == FRONT` 可以是满，从而选错。

## 考察能力
一句话概括本题核心考察的能力：
掌握循环队列在“牺牲一个存储单元”策略下，区分队列满与队列空的逻辑条件及指针关系。
