# 练习题 Q1 — 数据传输时间计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 计算机网络/传输层
- **难度**: 待评估

## 题干原文
一个设备以 2000 bps 的速率发送数据。发送包含 100,000 个字符的文件需要多长时间？（ ）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要调用“字符与位的换算关系（1字符=8位）”以及“bps定义”这两个核心概念。不是2分因为仅靠直觉无法直接得出，必须明确知道计算机中字符通常按8位存储这一基础定义。
- **K2 = 3**: 评分理由。涉及两级单位换算（字符->位，位->时间）和一次除法运算。不是2分因为数字较大（100,000和2000），虽然计算简单，但属于非2的幂次友好型计算，且涉及数量级转换，容易因小数点或零的个数出错。
- **K3 = 1**: 评分理由。从输入到输出仅需“总位数计算”和“时间计算”两步直接串行操作，无需复杂的状态推演或中间变量记忆。
- **K4 = 2**: 评分理由。存在常规注意点，即“字符”到“位”的隐含转换。不是1分因为如果忽略8位/字符这一隐含前提，直接计算会得到错误答案；但也不是3分因为这是计算机网络最基础的常识，不属于深层陷阱或反直觉条件。
- **K5 = 1**: 评分理由。本题仅涉及单一的数据传输计算模型，不涉及操作系统、网络层、应用层等其他子系统的状态传递或耦合。
- **雷达形状**: K2/K1主导型（基础计算型）。K1和K2得分中等，K3/K4/K5得分较低，呈现典型的“基础概念+简单计算”特征。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过已知速率和数据量，利用公式 $T = L / R$ 进行数值计算。虽然涉及概念（字符转位），但最终落脚点在于数值的准确运算。

## 选项级分析
- **选项A**: [干扰] — 针对“单位换算错误”或“数量级估算错误”。这类学生可能误以为1字符=1位，或者在计算 $800,000 / 2000$ 时少算了一个零，或者误将bps理解为KB/s等。
- **选项B**: [干扰] — 针对“忽略字符到位的转换”。这类学生直接用 $100,000 / 2000 = 50$，然后可能因为某种原因（如误以为需要乘以4或其他系数）或者单纯计算失误得到200。更可能的情况是，学生正确计算了位数为800,000，但在除法时出错，或者误将速率理解为其他单位。*修正分析*：若学生忘记乘以8，得到50秒（选项A）。若学生误以为1字符=16位（某些编码），则 $1,600,000 / 2000 = 800$（选项D）。选项B (200) 可能是 $100,000 / 500$ 或其他错误逻辑，或者是 $800,000 / 4000$（误读速率）。最常见的错误路径是：忘记乘8得50（A），或者误算 $800,000 / 2000$ 为 200（计算粗心）。
- **选项C**: [正确] — 正确执行了 $100,000 \times 8 = 800,000$ bits，然后 $800,000 / 2000 = 400$ seconds。
- **选项D**: [干扰] — 针对“位宽认知错误”或“计算翻倍错误”。这类学生可能误以为1字符=16位（如Unicode常见误解），导致总位数翻倍，时间也翻倍；或者在计算 $800,000 / 2000$ 时多算了一个零。
- **干扰策略**: 概念混淆（字符vs位）与计算陷阱（数量级/零的个数）相结合。

## 核心陷阱
- **核心陷阱**: **单位不一致导致的隐含转换缺失**。题干给出的是“字符”数，而速率单位是“bps”（bits per second）。考生必须意识到1个字符通常等于8个bit，否则直接相除会得到错误答案（50秒，即选项A）。

## 考察能力
本题核心考察考生对**数据单位换算（字符与位）**的敏感度以及**基本数据传输时间公式**的应用能力。
