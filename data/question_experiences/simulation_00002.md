# 模拟题 Q1 — 表达式求值栈深度分析

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: OS-1 > 操作系统概述 > 操作系统的基本概念
- **难度**: 待评估

## 题干原文
利用栈求表达式的值时，设立运算数栈 OPEN。假设 OPEN 只有两个存储单元，则在下列表达式中，不会发生溢出的是（ ）。
A: A-B*(C-D)
B: (A-B)*C-D
C: (A-B*C)-D
D: (A-B)*(C-D)

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“利用栈求表达式值”的基本机制，即中缀转后缀（逆波兰表达式）以及后缀表达式求值时运算数栈的操作规则。这属于操作系统或编译原理中的基础概念记忆，非核心定义辨析，但需准确回忆栈的压入/弹出逻辑。
- **K2 = 2**: 评分理由。本题不涉及复杂的数值计算，而是对栈深度的计数。单步操作仅为“压栈+1”或“弹栈-1”，计算量极小，属于低难度代入。
- **K3 = 4**: 评分理由。需要对每个选项的表达式进行多步串行推演。具体步骤包括：1. 将中缀表达式转换为后缀表达式；2. 模拟后缀表达式求值过程，跟踪栈中元素数量的变化；3. 找出最大栈深度。每个选项至少需要3-5步逻辑推演，且需保持中间状态（当前栈深度）的记忆，符合K3的高分特征。
- **K4 = 3**: 评分理由。存在隐含前提和常规注意点。考生必须意识到“运算数栈”仅存储操作数和中间结果，不存储运算符（运算符通常由另一个栈处理，或在后缀求值时直接执行）。此外，需识别括号对运算顺序及栈深度的影响，这是常见的“暗坑”，若忽略括号优先级直接按从左到右扫描，会导致错误。
- **K5 = 1**: 评分理由。本题仅涉及单一子系统（表达式求值算法/栈数据结构），无需跨越不同操作系统模块（如进程管理、内存管理、文件系统等）进行状态传递或联动。

- **雷达形状**: K3推演主导型（K3显著高于其他维度，K1中等，K2/K5低）

## 考察模式
- **模式**: 推理型
- **理由**: 题目并非直接考查概念定义或简单公式代入，而是要求考生根据给定的约束条件（栈容量为2），通过模拟算法执行过程（中缀转后缀、栈操作模拟），逻辑推导出哪个表达式满足条件。核心在于过程模拟与状态跟踪。

## 选项级分析
- **选项A**: [干扰] — 针对“忽略括号优先级”或“栈深度计算错误”的认知。表达式 `A-B*(C-D)` 的后缀形式为 `A B C D - * -`。求值过程：Push A(1), Push B(2), Push C(3) -> **溢出**。这类学生可能误以为减法先算，或者在转换后缀表达式时出错，导致低估栈深度。
- **选项B**: [正确] — 表达式 `(A-B)*C-D` 的后缀形式为 `A B - C * D -`。求值过程：Push A(1), Push B(2), Pop 2 Push Result(1), Push C(2), Pop 2 Push Result(1), Push D(2), Pop 2 Push Result(1)。最大深度始终为2，未溢出。
- **选项C**: [干扰] — 针对“括号内运算顺序混淆”的认知。表达式 `(A-B*C)-D` 的后缀形式为 `A B C * - D -`。求值过程：Push A(1), Push B(2), Push C(3) -> **溢出**。学生可能误以为先算 `A-B`，从而认为栈深度较小，但实际上乘法优先级高，需先压入B和C。
- **选项D**: [干扰] — 针对“复杂括号嵌套处理不当”的认知。表达式 `(A-B)*(C-D)` 的后缀形式为 `A B - C D - *`。求值过程：Push A(1), Push B(2), Pop 2 Push Result(1), Push C(2), Push D(3) -> **溢出**。学生在处理第二个括号 `(C-D)` 时，容易忘记此时栈中已有一个中间结果，导致误判最大深度。

- **干扰策略**: 渐进陷阱。通过不同括号位置和运算符优先级组合，制造相似的栈深度变化曲线，但关键步骤（如连续压入两个操作数）的深度峰值不同，诱导考生因粗心或优先级判断失误而选错。

## 核心陷阱
- **核心陷阱**: **中缀转后缀时的优先级处理与栈深度峰值的对应关系**。考生容易忽略运算符优先级对后缀表达式序列的影响，从而错误模拟栈的压入顺序；或者在模拟过程中，忘记“中间结果”也占用栈空间，导致低估最大栈深度。特别是当表达式包含嵌套括号或混合运算符时，需精确跟踪每一步的栈状态。

## 考察能力
本题核心考察考生对**栈数据结构在表达式求值算法中应用机制的理解**，以及**在有限资源约束下进行算法过程模拟与状态跟踪的逻辑推理能力**。
