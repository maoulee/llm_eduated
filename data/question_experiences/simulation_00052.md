# 模拟题 Q1 — 堆与BST路径性质辨析

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: DS-5 > 5.5 树与二叉树的应用 > 二叉搜索树 BST, DS-5 > 5.5 树与二叉树的应用 > 平衡二叉树 AVL, DS-8 > 8.4 选择排序 > 堆定义
- **难度**: 待评估

## 题干原文
从二叉树的任一结点出发到根的路径上，所经过的结点序列必按其关键字降序排列的是（ ）。

A. 二叉排序树
B. 大顶堆
C. 小顶堆
D. 平衡二叉树

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题需要辨析三个易混概念（BST、AVL、堆）的定义及其局部/全局性质。仅记忆单一概念（如只知BST左小右大）不足以解题，必须同时掌握堆的父子节点大小关系（局部有序性）与BST的排序性质（全局有序性但路径无序），属于高概念辨析需求。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、幂次运算或复杂转换，纯粹是逻辑性质的判断。
- **K3 = 2**: 评分理由。推演步骤较少。只需根据定义推导“子节点 -> 父节点”的大小关系。对于堆，只需一步逻辑：子 <= 父（小顶堆）或 子 >= 父（大顶堆），即可得出路径单调性。对于BST，需意识到路径方向不固定（可能先左后右），导致大小关系不单调，这也只需简单的逻辑否定。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。考生容易混淆“从根到叶子”与“从叶子到根”的方向，或者混淆“升序”与“降序”。此外，容易误以为BST的路径也是有序的（因为BST整体有序），这是常见的认知陷阱。
- **K5 = 1**: 评分理由。本题仅涉及树结构的静态性质定义，不需要在不同子系统（如排序算法过程、内存管理等）之间传递状态或数据。
- **雷达形状**: K1概念辨析主导型，K4陷阱辅助型。整体呈现“高概念、低计算、中陷阱”的特征。

## 考察模式
- **模式**: 概念型
- **理由**: 题目核心在于对数据结构定义（Definition）及其隐含性质（Property）的理解，而非算法执行过程或数值计算。

## 选项级分析
- **选项A**: [干扰] — 针对“BST整体有序，所以路径也有序”的错误认知。这类学生知道BST中序遍历有序，但忽略了从任意节点到根的路径可能包含“向左”和“向右”两种移动，导致关键字大小关系交替变化（例如：根10，左子5，5的右子8。路径 8->5->10，序列为8,5,10，非单调）。
- **选项B**: [干扰] — 针对“方向搞反”或“大小关系记反”的错误认知。大顶堆中，父节点 >= 子节点。从子节点到根，关键字是递增（或不变）的，即升序。若考生未注意题干要求的“降序”，或混淆了大/小顶堆定义，易选此项。
- **选项C**: [正确] — 小顶堆定义：任意节点的关键字 <= 其子节点的关键字。反之，子节点 >= 父节点？不对，小顶堆是 **父节点 <= 子节点**。
    *   *修正思考*：小顶堆定义是 `Parent <= Child`。
    *   从任意节点 `Node` 出发到根 `Root`：
    *   `Node` 是 `Parent(Node)` 的子节点，所以 `Parent(Node) <= Node`。
    *   `Parent(Node)` 是 `GrandParent` 的子节点，所以 `GrandParent <= Parent(Node)`。
    *   序列为：`Node`, `Parent(Node)`, `GrandParent`, ..., `Root`。
    *   大小关系：`Node >= Parent(Node) >= GrandParent >= ... >= Root`。
    *   这是一个**降序**（非严格）序列。符合题意。
- **选项D**: [干扰] — 针对“平衡二叉树也是排序树”的模糊认知。AVL树本质是BST，因此具有BST的所有性质（包括路径无序性）。此选项主要考察考生是否知道AVL是BST的一种特例，从而排除其特殊性。

- **干扰策略**: 概念混淆（BST vs 堆）、方向陷阱（升序 vs 降序）、特例泛化（AVL vs BST）。

## 核心陷阱
**核心陷阱**: 误认为二叉排序树（BST）的路径具有单调性。
许多考生潜意识里认为BST是“有序”的，因此任何路径都应该是有序的。实际上，BST的有序性体现在**中序遍历**序列上，而非任意路径上。从节点到根的路径中，可能先经过左孩子（值变小），再经过右孩子（值变大），导致序列波动。只有堆（Heap）这种基于父子节点局部大小关系的结构，才能保证从叶子到根（或根到叶子）的路径单调。

## 考察能力
准确区分二叉排序树（全局有序但路径无序）与堆（局部有序且路径单调）的结构性质，并能根据遍历方向正确推导关键字的大小变化趋势。
