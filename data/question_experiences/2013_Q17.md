# 2013年 Q17 — 变址寻址的地址计算过程

## 基本信息
- **年份**: 2013  **题位**: Q17  **题型**: 选择题
- **知识点**: 变址寻址机制, 有效地址计算, 操作数获取流程
- **考纲对应**: 第四章 指令系统 → 基本概念、指令格式、寻址方式

## 题干原文
[2013年考研真题第17题]假设变址寄存器R的内容为1000H,指令中的形式地址为2000H;地址1000H中的内容为2000H,地址2000H中的内容为3000H,地址3000H中的内容为4000

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆“变址寻址”的有效地址计算公式 $EA = (I) + D$，且明确区分“形式地址 $D$”与“变址寄存器内容 $(I)$”的角色。若概念模糊（如混淆相对寻址或基址寻址的公式变量），无法正确代入。不是4，因为公式本身不涉及冷门细节，是标准定义。
- **K2 = 2**: 2 — 仅需一步十六进制加法 ($1000H + 2000H$)，数字友好且无进位复杂性。不是3，因为计算量极小，不属于常规复杂计算。
- **K3 = 3**: 3 — 需走完“计算有效地址 -> 访问内存读取操作数”这一标准流程。路径唯一，但包含两个明确的串行步骤（算术运算+内存访问）。不是2，因为涉及两次不同的动作（计算和访存），且容易在第二步停止（选C）；不是4，因为不涉及动态状态或多分支推演。
- **K4 = 3**: 3 — 存在明确的陷阱：“题目问的是操作数”而非“有效地址”。若不触发“操作数 = 内存[EA]”这一层级转换，极易停留在EA计算结果上。不是4，因为陷阱相对直观，属于经典的“问果非问因”或“问内容非问地址”的逻辑陷阱，资深考生不易掉坑。
- **K5 = 1**: 1 — 纯指令系统内部概念，仅涉及CPU内部寄存器与主存的一次交互，不涉及存储层次（Cache/TLB）或多系统耦合。
- **雷达形状**: K3推演型

## 考察模式
- **模式**: 计算型
- **理由**: 题干提供具体参数，四个选项均为数值结果，通过公式计算和查表得出唯一正确数值。

## 选项级分析
- **选项A**: [干扰] — 针对认知错误：直接选取变址寄存器内容 $1000H$。这类学生可能完全误解变址寻址定义，或误以为题目问的是基址。
- **选项B**: [干扰] — 针对认知错误：选取形式地址 $2000H$ 或地址 $1000H$ 中的内容。这类学生可能混淆了“形式地址”与“变址寄存器”的角色，或者误以为变址寻址是直接跳转。
- **选项C**: [干扰] — 针对认知错误：选取有效地址 $3000H$。这是本题最强的干扰项。学生正确计算了 $EA = (I) + D = 1000H + 2000H = 3000H$，但**止步于此**，未执行“读取操作数”这一步，混淆了“地址”与“数据”。
- **选项D**: [正确] — 针对正确认知：先计算 $EA=3000H$，再访问内存地址 $3000H$ 获取内容 $4000H$（题目原文未带H，但隐含为16位数据，通常理解为4000H或整数4000，选项D通常对应此值）。
- **干扰策略**: 嵌套陷阱

## 考察能力
本题核心考察考生对**寻址方式中“地址生成”与“数据访问”两个独立阶段**的清晰界定，以及从“形式地址”到“物理/逻辑地址”再到“实际数据”的完整指令执行流的理解。
