# 练习题 Q1 — 汇编指令执行与位操作逻辑推演

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
考虑以下针对假设处理器的汇编语言程序。A、B 和 C 是 8 位寄存器。各种指令的含义如注释所示。
MOV B, #0 ; B ← 0
MOV C, #8 ; C ← 8
Z: CMP C, #0 ; 比较C与0
JZX ; 如果零标志被设置则跳转到X
SUB C, #1 ; C ← C - 1
RRC A, #1 ; 通过进位向右旋转A一位。因此：
; 若A的初始值和进位标志分别为a7...a0和c0，
; 执行此指令后它们的值将变为c0a7...a1和a0。
JC Y ; 如果进位标志被设置则跳转到Y
JMP Z ; 跳转到Z
Y: ADD B, #1 ; B ← B + 1
JMP Z ; 跳转到Z
X:
当程序执行结束时，变量 B 中的含义是（ ）。
- 选项:
  A: A0 中 0 位的数量
  B: A0 中 1 位的数量
  C: A0
  D: 8
- 正确答案: B
- 解析（参考）: 解析：
核心逻辑
：只有当进位标志为 1 时，
B
会递增 1。
RRC 指令行为
：
RRC A, #1
将累加器
A
的每一位向右旋转一位。
最低位（D0）会被复制到进位标志（CY），同时作为高位插入 D7 位置。
执行过程
：
初始
C = 8
，循环 8 次（对应 A 的 8 位）。
每次
RRC
后，若进位标志为 1（即当前位为 1），则跳转至
Y
执行
B = B + 1
。
最终
B
的值等于
A0
中 1 的数量。
结论
：程序统计了
A0
中二进制 1 的个数，因此选项 (B) 正确。
- 知识标签: ['操作系统/CPU调度']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握基本的汇编指令含义（MOV, CMP, SUB, JMP, JC）以及标志位（Zero Flag, Carry Flag）的基本概念。虽然题目给出了RRC的详细注释，但理解“进位标志”、“跳转条件”等基础术语是解题前提，属于标准的基础认知需求。不是4分因为题目对核心难点指令RRC做了详细解释，降低了对特定指令集记忆的依赖。
- **K2 = 2**: 评分理由。计算过程非常直观，主要是简单的减法（C-1）和加法（B+1），没有复杂的数值换算或多级计算。最复杂的单步操作是判断标志位，属于布尔逻辑判断，不易算错。
- **K3 = 4**: 评分理由。本题核心在于多步串行推演。考生需要在脑海中模拟一个循环结构：初始化 -> 判断循环结束 -> 计数器递减 -> 执行位操作 -> 判断标志位 -> 分支跳转 -> 累加器更新 -> 返回循环头。这个过程涉及状态（寄存器A, B, C及标志位）在8次迭代中的变化追踪，步骤超过5步且需记忆中间状态（特别是进位标志的变化），因此推演难度较高。
- **K4 = 3**: 评分理由。存在常规注意点作为陷阱。主要陷阱在于对RRC指令方向的理解（向右旋转，最低位进位）以及JC指令的条件（进位为1跳转）。如果考生误以为RRC是向左旋转，或者误以为JC是进位为0跳转，就会得出错误结论。这属于需要识别隐含前提（指令具体行为）和避开常规陷阱的情况。
- **K5 = 2**: 评分理由。虽然涉及寄存器A、B、C和标志位之间的交互，但这属于同一CPU核心内的数据通路操作，并未跨越不同的子系统（如内存、I/O、中断控制器等）。状态互影响仅限于指令执行单元内部，耦合度较低。

- **雷达形状**: K3推演主导型，K4陷阱辅助型。整体呈现以逻辑推演为核心，辅以基础概念理解和陷阱规避的特征。

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非直接考查某个公式或定义的记忆，也不是单纯的数值计算，而是要求考生根据给定的指令集规则，通过逻辑推理模拟程序的执行流程，从而归纳出程序的功能。它考察的是对计算机底层执行机制的理解和动态过程的分析能力。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：混淆了进位标志的含义或跳转条件。如果考生误以为JC是“进位为0跳转”或者误以为RRC移出的是0位时进位为1，就会选择统计0的数量。这类学生可能没有仔细区分“进位”与“借位”或“零标志”的区别，或者对RRC指令的具体行为记忆模糊。
- **选项B**: [正确] — 正确理解了RRC指令将最低位移入进位标志，且JC指令在进位为1时跳转执行B加1，从而统计了1的个数。
- **选项C**: [干扰] — 针对错误认知：完全误解程序功能，认为程序只是简单地将A的值赋给B或进行某种直接映射。这类学生可能忽略了循环结构和条件判断，或者认为B最终存储的是A的原始值。
- **选项D**: [干扰] — 针对错误认知：认为循环次数固定为8，所以结果就是8。这类学生可能忽略了循环体内的条件分支（JC Y），误以为每次循环B都会加1，或者完全没看懂程序逻辑，仅凭循环次数猜测答案。

- **干扰策略**: 概念混淆（A与B的混淆）、逻辑简化（D选项忽略条件分支）、完全误解（C选项）。

## 核心陷阱
- **核心陷阱**: RRC指令的具体行为细节与JC跳转条件的结合。考生必须准确理解“向右旋转”意味着最低位（LSB）被移出并进入进位标志（CY），且只有当CY=1时才执行累加。任何对旋转方向、进位来源或跳转条件的误解都会导致答案错误。

## 考察能力
本题核心考察考生对汇编语言程序执行流程的模拟能力，特别是对位操作指令（如循环移位）及其对状态标志位影响的深入理解。
