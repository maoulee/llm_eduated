# 2015 Q31 — 位图法地址映射计算

## 基本信息
- **年份**: 2015  **题位**: Q31  **题型**: 选择题
- **知识点**: 位图法, 操作系统>位图法
- **题位域**: 待标注  **科目**: 操作系统

## 题干原文
文件系统用位图法表示磁盘空间的分配情况，位图存于磁盘的 32～127 号块中，每个盘块占 1024 个字节，盘块和块内字节均从 0 开始编号。假设要释放的盘块号为 409612，则位图中要修改的位所在的盘块号和块内字节序号分别是（ ）。

A. 81、1
B. 81、2
C. 82、1
D. 82、2

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握位图法的基本定义（1位代表1个盘块）以及位图在磁盘上的存储结构（位图本身也占用盘块）。属于标准的核心概念记忆，不涉及复杂概念辨析。
- **K2 = 4**: 评分理由。涉及多级单位换算和除法取整运算。具体包括：将盘块号映射到位图索引（除以每块能表示的盘块数 $1024 \times 8$），再将位索引映射到字节索引（除以8）。数字较大（409612），且非2的幂次友好数字，容易在计算商和余数时出错，属于较高难度的单步/多步计算。
- **K3 = 3**: 评分理由。解题过程需要串行推演：1. 计算位图每个块能管理的盘块数；2. 计算目标盘块在位图中的全局位偏移量；3. 计算该位偏移量位于位图的哪个盘块（相对偏移+起始块号）；4. 计算该位在所在盘块内的字节偏移。共4-5步逻辑推导，属于标准的多步推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。陷阱1：位图本身存储在磁盘块中，因此计算位图所在块号时，必须加上位图起始块号（32），而非从0开始。陷阱2：题目问的是“块内字节序号”，而非“位序号”，最后一步必须除以8并取整，这是极易忽略的细节。
- **K5 = 1**: 评分理由。本题仅涉及文件系统磁盘空间管理这一单一子系统内部的数据结构映射，不涉及与其他子系统（如内存管理、进程调度）的状态传递或耦合。
- **雷达形状**: K4陷阱型/K2计算型。K4和K2得分较高，表明题目主要难度在于识别隐含条件（起始块号、字节vs位）和执行精确计算。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过给定的参数（盘块大小、位图起始位置、目标盘块号），利用数学公式进行地址映射计算。虽然涉及概念，但最终答案完全依赖于计算结果的准确性。

## 选项级分析
- **选项A**: [干扰] — 针对“忘记加起始块号”且“混淆位与字节”的错误。如果考生忘记位图从32号块开始，算出相对块号为50，再错误地认为字节号是1（或者计算错误），可能凑出此选项。更可能是计算相对块号时出错。
- **选项B**: [干扰] — 针对“忘记加起始块号”且“正确计算字节号”的错误。考生算出相对块号为50，字节号为1。如果误以为位图从0开始，或者计算块号时未加32，可能会选类似50,1的选项，但此处是81,2。实际上，若考生算出相对块号50，字节号1，若误将块号计算为 $32+49=81$（off-by-one错误）且字节号算错为2，则可能选B。或者，考生正确算出块号82，但字节号计算错误（如未取整或余数处理错误）得到2。
- **选项C**: [正确] — 正确计算了位图所在块号（$32 + \lfloor 409612 / 8192 \rfloor = 32 + 50 = 82$）和块内字节序号（$\lfloor (409612 \% 8192) / 8 \rfloor = \lfloor 1524 / 8 \rfloor = 190$... 等等，让我重新核算一下参考解析的逻辑）。
    *   *修正核算*：
        1. 每块位图能表示的盘块数：$1024 \text{ Bytes} \times 8 \text{ bits/Byte} = 8192$ 个盘块。
        2. 目标盘块号 409612 在位图中的位索引（从0开始）：409612。
        3. 该位位于位图的第几个块（相对位图起始）：$\lfloor 409612 / 8192 \rfloor = 50$。
        4. 位图起始块号为32，所以绝对块号为 $32 + 50 = 82$。
        5. 该位在所在块内的位偏移：$409612 \% 8192 = 409612 - 50 \times 8192 = 409612 - 409600 = 12$。
        6. 该位所在的字节序号：$\lfloor 12 / 8 \rfloor = 1$。
        7. 结果：块号82，字节号1。选项C正确。
- **选项D**: [干扰] — 针对“正确计算块号”但“错误计算字节号”的错误。考生正确算出块号82，但在计算字节号时，可能误将位偏移12直接当作字节号，或者计算 $\lfloor 12/8 \rfloor$ 时出错，或者混淆了位偏移和字节偏移的关系，得出2。例如，如果误以为位偏移是16-23之间，或者计算余数错误。

- **干扰策略**: 计算陷阱。主要利用大数除法取整的易错性，以及“位”与“字节”单位换算的疏忽，还有“相对地址”与“绝对地址”（起始块号）的混淆。

## 核心陷阱
1. **起始块号偏移**：位图并非从磁盘0号块开始，而是从32号块开始，计算位图所在物理块号时必须加上32。
2. **位与字节的换算**：题目问的是“块内字节序号”，而非“位序号”。计算出位偏移后，必须除以8并向下取整。
3. **大数取模运算**：$409612 \% 8192$ 的计算容易出错，需仔细计算余数。

## 考察能力
本题核心考察考生对文件系统位图法地址映射机制的理解，以及在复杂参数下进行多级地址转换（盘块号->位图块号->块内字节号）的精确计算能力。
