# 2013年 Q14 — 补码移位与加法运算

## 基本信息
- **年份**: 2013  **题位**: Q14  **题型**: 选择题
- **知识点**: 补码的算术移位运算, 补码的加减法运算, 溢出判断
- **考纲对应**: 第二章 数据的表示和运算 → 定点数的运算 → 移位运算 / 补码加减运算

## 题干原文
[2013年考研真题第14题]某字长为8位的计算机中，已知整型变量x、y的机器数分别为[x]=11110100,[y]=10110000。若整型变量z=2*x+y/2,则的机器数为
A.1100000

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆“算术左移”和“算术右移”的定义及补位规则（左移补0，右移补符号位），若混淆为逻辑移位则全盘皆输。不是4分因为概念本身基础，不涉及冷门细节；不是2分因为概念模糊无法通过常识推导。
- **K2 = 3**: 3 — 涉及具体的二进制移位操作和8位二进制加法运算，数字虽友好（8位），但需严格执行位运算，非简单心算。不是4分因为计算量较小，不涉及复杂进位链或多级换算。
- **K3 = 3**: 3 — 需按固定流程执行：解析表达式 -> 对x算术左移 -> 对y算术右移 -> 执行补码加法 -> 检查溢出。路径唯一，步骤清晰（约3-4步）。不是4分因为状态更新不复杂，无需维持动态上下文。
- **K4 = 4**: 4 — 隐含前提极深：1. 题目给定的是“机器数”（即补码形式），而非真值，因此不能先转真值再算（虽然结果一样，但考察的是机器数直接运算能力）；2. 需精准识别“算术移位”与“逻辑移位”的区别，特别是负数右移时高位补1；3. 需判断最终结果是否溢出（本题未溢出，但学生易误判）。这要求对补码运算机制的本质有深刻理解，否则极易掉坑。
- **K5 = 1**: 1 — 单一知识点（定点数运算）内部解决，不涉及存储器、CPU其他部件或OS层面的联动。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给定了具体的二进制数值和运算表达式，选项为四个不同的二进制计算结果，考生需通过精确计算得出唯一正确答案。

## 选项级分析
- **选项A**: [正确] — 正确执行了算术左移、算术右移及补码加法，且正确判断未溢出。
- **选项B**: [干扰] — 针对**逻辑移位**认知错误。若将y的算术右移误作逻辑右移（高位补0），y/2变为01011000，相加后结果不同。此类学生混淆了有符号数和无符号数的移位规则。
- **选项C**: [干扰] — 针对**真值转换后计算但未转回补码**或**移位方向/位数错误**。例如，可能误将x左移为逻辑左移但处理符号位错误，或在加法时进位处理错误。
- **选项D**: [干扰] — 针对**溢出误判**或**符号位处理错误**。学生可能认为负数运算必然溢出，或者在加法时丢弃了正确的符号位扩展，导致结果符号错误。
- **干扰策略**: 并行陷阱

## 核心陷阱
- **核心陷阱**: **算术右移的补位规则**（负数右移高位补1）与**补码溢出判断**的干扰。

## 考察能力
本题核心考察考生对**补码机器数**直接进行**算术移位**和**加减运算**的规则掌握程度，以及在多步位运算中保持**符号位正确性**和**溢出敏感度**的能力。
