# 2011年 Q15 — 主存地址寄存器位数计算

## 基本信息
- **年份**: 2011  **题位**: Q15  **题型**: 选择题
- **知识点**: 主存地址空间, 存储器地址寄存器(MAR)位数, 存储器容量扩展
- **考纲对应**: 计算机组成原理 → 第三章 存储系统 → 主存储器和CPU的连接

## 题干原文
[2011年考研真题第15题]某计算机存储器按字节编址，主存地址空间大小为64MB,现用4Mx8位的RAM芯片组成32MB的主存储器，则存储器地址寄存器MAR的位数至少是()。
A.22位
B.2

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆“MAR位数由主存地址空间决定”这一核心概念，而非由实际安装的芯片容量决定。若概念模糊（认为是芯片决定），则无法入题。
- **K2 = 2**: 2 — 仅需一步简单的对数计算或幂次对应（64MB = 2^6 * 2^20 = 2^26），数字友好（均为2的幂），无繁杂运算。
- **K3 = 1**: 1 — 无需多步串行推演，得出答案只需一个直接映射关系，路径唯一且极短。
- **K4 = 3**: 3 — 存在明确的陷阱词“4Mx8位的RAM芯片组成32MB...”。若被“32MB实际容量”或“芯片规格”误导，就会用错计算依据。需要识别出“MAR对应的是CPU寻址范围（地址空间），而非物理安装容量”。
- **K5 = 1**: 1 — 单一知识点（存储器接口与地址空间）内部解决，不涉及CPU内部数据通路或Cache等其他系统的状态传递。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给出具体参数（64MB地址空间，4M芯片，32MB装机），选项为不同的计算结果，核心在于选择正确的输入参数进行幂次计算。

## 选项级分析
- **选项A**: [干扰] — 针对“以局部代整体”的认知错误。学生看到“4Mx8位芯片”，计算 4M = 2^22，误以为MAR位数取决于单个芯片的地址引脚数或芯片容量对应的地址位数。这类学生混淆了“芯片片内地址”与“系统物理地址”。
- **选项B**: [干扰] — 针对“半字编址”或“单位换算错误”的认知错误。可能误以为64MB是64M字（若字长32位则需23位？不，64MB=2^26B，若误算为2^23即8MB? 或者误以为32MB=2^25，这里选项B具体数值题干未给全，但通常此类选项对应 2^22 或 2^23 附近的错误计算，如误将32MB当作地址空间上限但算错幂次，或误以为MAR只覆盖已安装内存且计算错误）。*注：根据常规真题选项分布，B通常为23位或24位，对应32MB(2^25)的某种错误推导或16MB(2^24)的误判。此处假设B为23位或24位等干扰值。* 根据题目常见干扰项，B往往对应 32MB (2^25) 的错误计算结果（如误以为MAR只需覆盖已建成的32MB，但算成了23位？不，32MB是25位。若B是22位则与A重复。通常B可能是23位，对应某种混淆）。*修正：根据题干提供的错误选项分析{'B': '误根据某种半字编址或32MB得出23位'}，B针对的是将32MB地址空间错误折算（例如误以为字节编址但按字长折算，或单纯计算错误）。*
- **选项C**: [干扰] — 针对“以实际物理容量代替逻辑地址空间”的认知错误。学生正确计算出已安装主存32MB = 2^25，认为MAR只需25位即可寻址现有内存。这类学生忽略了“地址空间”是CPU的寻址能力上限，而MAR是配合CPU地址总线的，必须满足最大寻址需求。
- **选项D**: [正确] — 正确识别MAR位数由“主存地址空间大小”决定。64MB = 2^6 * 2^20 B = 2^26 B，故需26位地址线。
- **干扰策略**: 嵌套陷阱（核心误解层层递进）

## 核心陷阱
- **核心陷阱**: 概念混淆——将“MAR的位数”与“已安装内存容量的地址位数”或“单个芯片的地址位数”混淆。MAR（Memory Address Register）的位数取决于CPU的地址总线宽度，即系统的**最大寻址范围（地址空间）**，而不是当前实际插了多少内存条。即使只装了1KB内存，如果CPU寻址范围是64MB，MAR仍需26位（高位地址线可能全为0，但位宽必须够）。
- **错误路径**: 看到“32MB” -> 计算 log2(32MB) = 25 -> 选C；或看到“4M芯片” -> 计算 log2(4M) = 22 -> 选A。

## 考察能力
考察学生区分“系统寻址能力（Address Space）”与“物理存储容量（Physical Memory Size）”的能力，以及理解MAR作为CPU与主存接口寄存器，其位宽由CPU地址总线（即最大地址空间）决定的本质。
