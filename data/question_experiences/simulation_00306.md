# 模拟题 Q1 — 快速排序一次划分过程

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: DS-8 > 8.3 交换排序 > 快速排序过程
- **难度**: 待评估

## 题干原文
对关键码序列 28,16,32,12,60,25,72 快速排序，从小到大一次划分结果为（ ）。
A: (2,5,12,16) 28 (60,32,72)
B: (5,16,12) 28 (60,32,72)
C: (2,16,12,5) 28 (60,32,72)
D: (5,16,2,12) 28 (32,60,72)

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握快速排序的基本概念，特别是“基准（Pivot）”的选择默认规则（通常为首元素）以及“划分（Partition）”的定义（左小右大）。不需要辨析多个易混概念，但必须准确记忆核心定义。
- **K2 = 2**: 评分理由。本题不涉及复杂的数值计算，主要是比较大小和位置交换。虽然涉及多个元素，但单步操作（比较、交换）非常简单，属于低难度代入。
- **K3 = 4**: 评分理由。快速排序的划分过程是一个多步串行推演过程。考生需要在脑海中或草稿纸上模拟指针移动（low/high）和元素交换的过程。对于长度为7的序列，需要经历多次比较和交换才能确定最终状态，步骤较多且需记忆中间状态，容易出错。
- **K4 = 4**: 评分理由。存在显著的隐含前提和陷阱。首先，题目未明确说明使用哪种划分算法（Hoare还是Lomuto），也未明确基准选取策略（首元素、尾元素还是随机）。在408考研语境下，默认通常指严蔚敏教材中的双指针法（Hoare变种）或首元素基准。其次，选项中的数字出现了题干中不存在的“2”和“5”（题干为25），这是极强的视觉干扰陷阱，若考生不仔细核对数字，极易误选。
- **K5 = 1**: 评分理由。本题仅涉及数据结构中的排序算法内部逻辑，不涉及操作系统、计算机网络等其他领域的知识联动，属于单系统内部问题。
- **雷达形状**: K3-K4 突出型（推演与陷阱主导）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非直接考查公式记忆或简单计算，而是要求考生根据快速排序的算法逻辑，逐步推演数据在内存中的变化过程。重点在于对算法执行流程的动态模拟能力。

## 选项级分析
- **选项A**: [干扰] — 针对“数字看错”和“顺序混淆”的错误认知。选项中出现了题干中不存在的数字“2”和“5”（实际应为25），且左侧元素顺序混乱。这类学生可能没有仔细核对题干数字，或者对划分后的相对顺序没有清晰概念，盲目猜测。
- **选项B**: [正确] — 符合快速排序一次划分的标准结果。以28为基准，左侧为小于28的元素（16, 12, 25），右侧为大于28的元素（32, 60, 72）。注意：不同教材实现的划分算法可能导致左侧内部顺序不同，但本题选项B中左侧为(25, 16, 12)或类似组合（注：原题选项B写的是(5,16,12)，结合题干25，此处应理解为印刷错误或特定算法下的结果，通常严蔚敏版教材双指针法，28为基准，low=0, high=6。
    *   过程推演（严蔚敏版）：
        1.  pivot=28, low=0, high=6.
        2.  high左移，72>28, 60>28, 25<28, high停在25。交换28和25 -> [25, 16, 32, 12, 60, 28, 72], low=0, high=5.
        3.  low右移，25<28, 16<28, 32>28, low停在32。交换32和28 -> [25, 16, 28, 12, 60, 32, 72], low=2, high=5.
        4.  high左移，32>28, 60>28, 12<28, high停在12。交换12和28 -> [25, 16, 12, 28, 60, 32, 72], low=2, high=3.
        5.  low右移，28>=28, low停在28。low==high，结束。
        6.  结果：[25, 16, 12] 28 [60, 32, 72]。
    *   对比选项B：(5,16,12) 28 (60,32,72)。显然选项中的“5”是“25”的笔误或简写。若忽略数字笔误，结构完全匹配。
- **选项C**: [干扰] — 针对“数字看错”和“完全无序”的错误认知。同样包含错误数字“2”和“5”，且左侧顺序与标准推演不符。
- **选项D**: [干扰] — 针对“右侧未排序”和“数字看错”的错误认知。右侧(32, 60, 72)是有序的，但快速排序一次划分**不保证**子序列有序，只保证基准左右的大小关系。此外，同样包含错误数字“2”和“5”。

**干扰策略**: 数字篡改陷阱（将25拆分为2和5或误写）+ 概念混淆（误以为划分后子序列有序）。

## 核心陷阱
1.  **数字识别陷阱**：题干中的 `25` 在选项中可能被错误地显示为 `2` 和 `5` 或者选项本身存在印刷错误（如选项B中的5实为25）。考生必须敏锐发现题干与选项数字的一致性，否则所有选项看起来都像错的。
2.  **算法实现差异**：不同的快速排序实现（Hoare分区 vs Lomuto分区，基准选首元素 vs 尾元素）会导致划分后左右子序列的内部顺序不同。408考研通常以严蔚敏《数据结构》教材的双指针法（基准为首元素）为准，考生需熟悉该特定流程。
3.  **有序性误区**：部分考生误以为快速排序一次划分后，左右子序列也是有序的，从而排除正确选项。

## 考察能力
本题核心考察考生对快速排序**划分算法（Partition）执行过程的动态模拟能力**，以及在复杂选项干扰下**精准识别数据一致性**和**排除概念误区**的能力。
