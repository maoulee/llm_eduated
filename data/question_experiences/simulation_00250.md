# 模拟题 Q1 — IPv4分片计算

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: CN-4 > IPv4 > IPv4分片
- **难度**: 待评估

## 题干原文
一个长度为 3000 字节的 UDP 数据报，在数据链路层使用以太网进行传输，为了正确传输，则需要将其拆分成（ ）个 IP 数据片。

A. 2
B. 3
C. 4
D. 不拆分

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆两个核心概念：以太网默认 MTU 为 1500 字节，以及 IP 头部标准长度为 20 字节。不是 2 分因为仅靠直觉无法得出 MTU 具体数值，需调用标准协议定义；不是 4 分因为不涉及复杂概念辨析（如 IPv6 不分片等）。
- **K2 = 3**: 评分理由。涉及多级换算和除法取整。计算过程包括：总长度计算（3000+20）、有效载荷上限计算（1500-20）、分片数量计算（3000/1480 向上取整）。不是 2 分因为 1480 不是 2 的幂，且涉及向上取整逻辑，容易算错；不是 4 分因为计算步骤线性，无复杂嵌套。
- **K3 = 3**: 评分理由。需要串行推演：UDP封装IP -> 检查MTU -> 计算每片最大数据量 -> 循环分片。步骤约为 3-4 步。不是 2 分因为不能一步得出结果；不是 4 分因为不需要记忆中间状态或回溯。
- **K4 = 4**: 评分理由。存在明显的隐含前提和易错点。1. 必须意识到 UDP 数据报整体作为 IP 数据部分，需加上 IP 头才构成 IP 数据报总长。2. 必须意识到分片后，每个分片都要加 IP 头，因此每片有效载荷是 MTU - IP头。3. 必须知道分片数据长度必须是 8 的倍数（虽然本题 1480 恰好是 8 的倍数，但若忽略此规则在更复杂题目中会出错，此处主要考察是否扣除 IP 头）。这是典型的“题面没说但解题必须意识到的条件”。
- **K5 = 3**: 评分理由。涉及应用层/传输层（UDP）到网络层（IP）再到数据链路层（以太网）的跨层数据封装与限制传递。单向传数据，状态互影响较小（主要是长度限制）。

- **雷达形状**: K4陷阱型（K4显著高于K1/K2，主要难点在于对协议封装细节和隐含条件的识别）

## 考察模式
- **模式**: 综合型（计算+规则应用）
- **理由**: 本题既需要记忆协议参数（MTU, IP头长），又需要进行具体的数值计算，同时需要理解分层封装的逻辑关系。

## 选项级分析
- **选项A**: [干扰] — 针对“忽略IP头部开销”或“计算错误”的认知。如果学生直接用 3000 / 1500 = 2，或者认为分片不需要加头，可能会选A。这类学生通常忽略了分片后每个片段都需要独立的IP头部，导致可用空间计算错误。
- **选项B**: [正确] — 正确计算结果。3020字节总长，MTU 1500。第一片：IP头20 + 数据1480 = 1500。剩余数据 3000 - 1480 = 1520。第二片：IP头20 + 数据1480 = 1500。剩余数据 1520 - 1480 = 40。第三片：IP头20 + 数据40 = 60 < 1500。共3片。
- **选项C**: [干扰] — 针对“过度拆分”或“混淆分片与帧”的认知。如果学生误以为每个分片还要考虑以太网帧头（14字节）和FCS（4字节）占用MTU内的空间（实际上MTU通常指IP层最大长度，不包含链路层帧头，但有些教材定义不同，若按MTU=1496算，结果可能变化，但通常408标准MTU=1500指IP包最大长度），或者计算失误导致多算一片。
- **选项D**: [干扰] — 针对“概念混淆”的认知。认为UDP数据报小，不需要分片，或者混淆了IPv6（不分片）与IPv4。

- **干扰策略**: 计算陷阱（忽略IP头导致少算一片）、概念混淆（IPv6不分片特性迁移到IPv4）

## 核心陷阱
- **核心陷阱**: **分片有效载荷的计算基准**。
  1.  **总长度陷阱**：UDP数据报长度是IP数据部分，计算是否分片时，要看 **IP数据报总长度**（UDP + IP头）是否超过MTU。
  2.  **分片空间陷阱**：分片后，**每个分片**都必须包含IP头部。因此，每个分片能携带的最大UDP数据量 = MTU - IP头部长度（1500 - 20 = 1480字节），而不是1500字节。
  3.  **8字节对齐陷阱**：虽然本题1480恰好是8的倍数，但严格来说，除最后一个分片外，其他分片的数据长度必须是8的倍数。

## 考察能力
一句话概括本题核心考察的能力：掌握IPv4分片机制中MTU限制、IP头部开销对有效载荷的影响及分片数量的精确计算能力。
