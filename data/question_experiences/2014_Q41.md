# 2014 Q41 — 二叉树WPL计算与递归遍历算法设计

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握二叉树的基本定义、二叉链表存储结构以及WPL（带权路径长度）的概念。虽然WPL是哈夫曼树章节的重点，但在此处仅作为计算目标，属于标准的基础概念记忆。不是4分因为不需要辨析多个易混概念（如不同遍历方式的差异），只需知道WPL=∑(叶子权值×路径长度)。
- **K2 = 2**: 评分理由。算法中涉及的核心计算仅为 `wpl += weight * depth`，这是简单的乘法与累加，属于非常基础的算术运算，几乎不可能出错。
- **K3 = 3**: 评分理由。解题过程需要多步串行推演：首先定义结构体，其次设计递归函数框架，然后在递归过程中处理“叶子节点累加”和“非叶子节点递归调用并深度+1”两个分支逻辑。这涉及3-5步的逻辑构建，属于标准难度。
- **K4 = 3**: 评分理由。存在常规注意点：1. 必须正确判断叶子节点（左右子树均为空）；2. 递归时深度参数需要正确传递（depth+1）；3. 全局变量或引用传参的使用以避免重复计算或状态丢失。这些是算法设计中的常规陷阱，非反直觉，但需细心。
- **K5 = 2**: 评分理由。本题主要局限于二叉树这一单一数据结构内部的操作，不涉及与其他子系统（如操作系统、网络、数据库）的深度耦合。虽然递归涉及栈帧的状态传递，但这属于语言机制层面，而非跨域联动。提及无关则2，此处为单系统内的状态传递，故评为2。

## 解题思路分析
- **核心思路**: 利用二叉树的遍历特性（通常选用先序遍历，因其递归结构清晰），在遍历过程中记录当前节点的深度。当访问到叶子节点时，将其权值与当前深度相乘并累加到总WPL中；当访问到非叶子节点时，递归遍历其左右子树，并将深度参数加1。
- **关键步骤**:
    1.  **定义结构体**: 定义包含 `weight`、`lchild`、`rchild` 的 `BiTNode` 结构体。
    2.  **设计递归函数**: 函数签名通常为 `int WPL(BiTree root, int depth)` 或使用全局变量/引用。
    3.  **基准情况**: 若节点为空，返回0。
    4.  **叶子节点处理**: 若 `root->lchild == NULL && root->rchild == NULL`，则 `wpl += root->weight * depth`。
    5.  **递归步骤**: 若左子树非空，递归调用 `WPL(root->lchild, depth + 1)`；若右子树非空，递归调用 `WPL(root->rchild, depth + 1)`。
    6.  **返回结果**: 返回累加的WPL值。
- **易错点**:
    1.  **深度初始化**: 根节点的深度通常定义为0或1，需保持一致。若定义为0，则路径长度即为深度；若定义为1，则需注意题目对路径长度的定义（通常根节点深度为0，路径长度为边数）。
    2.  **叶子节点判断**: 必须同时判断左右子树为空，仅判断一个为空可能误判。
    3.  **变量作用域**: 若使用局部变量累加，需确保递归返回值正确累加；若使用全局变量，需注意初始化。
    4.  **空树处理**: 需考虑根节点为空的情况。

## 核心陷阱
- **核心陷阱**: **深度参数的传递与累加逻辑**。许多考生容易忘记在递归调用时增加深度（`depth + 1`），或者错误地在非叶子节点也进行累加。此外，对于“路径长度”的定义（从根到该节点的边数）需与深度参数对应，若根节点深度设为0，则叶子节点的路径长度即为当前深度值。
