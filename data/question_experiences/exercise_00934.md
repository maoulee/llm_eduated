# 练习题 Q1 — 信号量同步与进程交替执行

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/进程管理
- **难度**: 待评估

## 题干原文
假设我们想使用二进制信号量 S 和 T 同步两个并发进程 P 和 Q。进程 P 和 Q 的代码如下所示：
进程 P
```c
while (1) {
    W: print '0'; print '0';
    X:
}
```
进程 Q
```c
while (1) {
    Y: print '1'; print '1';
    Z:
}
```
同步语句只能插入在 W、X、Y 和 Z 这四个位置。以下哪一项操作序列**始终**会导致输出以 `'001100110011...'` 开头？

- 选项:
  A: 在 W 处执行 P(S)，在 X 处执行 V(S)，在 Y 处执行 P(T)，在 Z 处执行 V(T)，S 和 T 初始值为 1
  B: 在 W 处执行 P(S)，在 X 处执行 V(T)，在 Y 处执行 P(T)，在 Z 处执行 V(S)，S 初始值为 1，T 初始值为 0
  C: 在 W 处执行 P(S)，在 X 处执行 V(T)，在 Y 处执行 P(T)，在 Z 处执行 V(S)，S 和 T 初始值为 1
  D: 在 W 处执行 P(S)，在 X 处执行 V(S)，在 Y 处执行 P(T)，在 Z 处执行 V(T)，S 初始值为 1，T 初始值为 0

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握信号量 P/V 操作的基本定义（P 减 1 阻塞，V 加 1 唤醒）以及二进制信号量的特性。不需要记忆复杂公式，但必须清晰区分 P 和 V 的作用，属于标准的基础概念认知。
- **K2 = 1**: 评分理由。本题不涉及数值计算，仅涉及状态值的增减（0 和 1 之间的切换），计算复杂度极低，属于微弱计算需求。
- **K3 = 4**: 评分理由。需要在明确规则下进行多步串行推演。考生必须模拟进程 P 和 Q 的交替执行过程，跟踪 S 和 T 的状态变化，并验证每一步是否满足“始终”产生特定序列的要求。这涉及至少 3-5 步的状态流转推演，且需记忆中间状态（S=0, T=1 等），因此推演难度较高。
- **K4 = 4**: 评分理由。存在隐含前提和陷阱。题目要求“始终”导致特定输出，这意味着必须排除死锁、饥饿以及非确定性调度导致的乱序。考生必须意识到初始值对执行顺序的决定性作用（谁先跑），以及 P/V 配对的正确性（P 对应 V 的跨进程传递）。若忽略“始终”二字或误判初始值影响，极易掉入陷阱。
- **K5 = 4**: 评分理由。需要在两个进程（子系统）之间传递状态。进程 P 通过信号量 T 唤醒进程 Q，进程 Q 通过信号量 S 唤醒进程 P，形成了深度的状态互影响和耦合。这种跨进程的控制流同步是典型的跨域联动。

- **雷达形状**: K3/K4/K5 高维型（推演与逻辑陷阱主导）

## 考察模式
- **模式**: 推理型
- **理由**: 本题核心不在于记忆某个定义或进行数学计算，而在于根据给定的代码结构和信号量操作规则，逻辑推演进程的执行顺序和状态变化，从而判断哪个选项能满足严格的同步约束。

## 选项级分析
- **选项 A**: [干扰] — 针对“互斥锁”思维定势的错误认知。学生可能认为 S 和 T 各自独立管理 P 和 Q 的互斥，或者认为初始值都为 1 时两个进程可以并发运行。实际上，若 S=1, T=1，P 和 Q 都可能通过 P(S) 和 P(T) 进入临界区，导致输出交错（如 0101...），无法保证严格的 0011 交替。这类学生忽略了“同步”与“互斥”的区别，以及初始值对启动顺序的控制。
- **选项 B**: [正确] — 正确配置。S=1 允许 P 先执行，P 执行完打印后 V(T) 唤醒 Q；T=0 阻止 Q 先执行，Q 必须等待 P 释放 T。P 执行完 V(T) 后 T=1，Q 执行 P(T) 成功，打印后 V(S) 唤醒 P。形成完美的 P->Q->P 循环。
- **选项 C**: [干扰] — 针对“初始值无关论”的错误认知。操作位置与 B 相同，但 S=1, T=1。由于 T 初始为 1，进程 Q 在启动时可能直接通过 P(T)（如果调度器先调度 Q），导致 Q 先打印 '11'，输出以 '11...' 开头，不符合题目要求的 '00...' 开头。这类学生忽略了初始值对“谁先执行”的决定性作用。
- **选项 D**: [干扰] — 针对“信号量配对错误”的认知。P 处 P(S)，X 处 V(S)，这是典型的互斥锁用法，P 进程自己锁自己，无法通知 Q。Y 处 P(T)，Z 处 V(T)，Q 进程自己锁自己。由于 T=0，Q 永远无法通过 P(T)（除非有外部 V(T)，但这里没有），导致 Q 死锁或永远无法执行。这类学生混淆了同步（跨进程通信）和互斥（保护临界区）的信号量使用模式。

- **干扰策略**: 概念混淆（互斥 vs 同步）、初始值陷阱（忽略启动顺序）、死锁陷阱（错误的 P/V 配对）

## 核心陷阱
- **核心陷阱**: **初始值对执行顺序的决定性作用** 以及 **同步信号量的跨进程配对逻辑**。
  1. 必须通过初始值（S=1, T=0）强制规定 P 先于 Q 执行，否则无法保证输出以 '00' 开头。
  2. 必须理解 P 进程结束时应 V(唤醒 Q 的信号量)，Q 进程结束时应 V(唤醒 P 的信号量)，形成闭环，而不是各自 V 自己的信号量（那是互斥）。

## 考察能力
一句话概括本题核心考察的能力：
**在并发环境下，利用信号量机制设计并验证严格的进程交替执行同步逻辑的能力。**
