# 练习题 Q1 — 主机子网掩码的作用与路由决策

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/网络层
- **难度**: 待评估

## 题干原文
IPv4 地址系统已经包含了网络和主机的信息。为了将数据包正确路由到目标网络，路由器除了需要主机的 IP 地址外，还需要子网掩码。主机本身不会转发数据包，那么为什么主机也需要子网掩码呢？（ ）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“子网掩码”、“本地网络判断”、“默认网关”等核心概念的定义及其在主机通信中的具体作用。不是4分因为不需要辨析多个易混的高级概念，属于网络层基础核心知识。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、二进制转换或幂次运算，完全属于定性分析。
- **K3 = 2**: 评分理由。推演步骤较少：主机获取目标IP -> 与掩码做与运算 -> 比较网络号 -> 决定直连还是转发。这是一个标准的2-3步逻辑判断过程，无需复杂的状态记忆或多步串行推演。
- **K4 = 3**: 评分理由。存在隐含前提和易错点。题干特意强调“主机本身不会转发数据包”，这是一个反直觉的提示（通常认为只有路由器才处理路由），考生需要意识到主机虽然不转发，但必须做出“是否交给路由器”的第一次路由决策。若忽略这一层，容易误选A或认为主机不需要掩码。
- **K5 = 2**: 评分理由。主要涉及网络层内部的主机通信逻辑，虽然提到了DNS（选项D）和路由器，但核心逻辑未跨越到传输层或应用层的深度耦合，仅涉及网络层内主机与网关的交互。
- **雷达形状**: K4陷阱型（K1基础扎实，K4条件识别要求较高，K2计算极低）

## 考察模式
- **模式**: 推理型
- **理由**: 题目并非直接询问定义，而是通过“主机不转发”这一前提，要求考生推理出主机在通信发起阶段的具体行为逻辑（即如何决定下一跳），属于机制原理的逻辑推理。

## 选项级分析
- **选项A**: [干扰] — 针对“掩码用于确定自身网络”这一片面认知。虽然主机确实用掩码确定自己的网络地址，但这只是手段而非最终目的。题目问的是“为什么需要”，即其功能目的。如果只选A，忽略了掩码在判断“目标”时的关键作用。这类学生可能记住了掩码的数学定义，但未理解其在通信流程中的决策意义。
- **选项B**: [干扰] — 针对“IP地址获取机制”的混淆。获取目标IP地址通常通过DNS解析或手动配置，与子网掩码无关。这类学生可能将“地址解析”与“路由判断”混淆。
- **选项C**: [正确] — 准确描述了主机使用子网掩码的核心目的：通过逻辑与运算判断目标IP是否在本地子网。若在，则ARP解析MAC直连发送；若不在，则封装给默认网关。这是主机进行“首次路由决策”的依据。
- **选项D**: [干扰] — 针对“DNS与IP关系”的混淆。DNS用于域名到IP的解析，发生在网络层之前（应用层/传输层交互），与子网掩码无关。这类学生可能对网络协议栈分层职责不清。
- **干扰策略**: 概念混淆（将掩码的数学功能与通信决策功能混淆，或将不同层级的协议功能混淆）

## 核心陷阱
- **核心陷阱**: **“主机不转发”与“主机需路由决策”的逻辑割裂**。
  许多考生认为“路由”是路由器的专利，因为主机不转发数据包。陷阱在于，主机虽然不转发（Forwarding），但必须进行路由选择（Routing/Decision），即决定数据包是直接发给目标主机还是发给网关。子网掩码正是这一决策过程的必要输入。

## 考察能力
一句话概括本题核心考察的能力：理解主机在IP数据报发送前，利用子网掩码进行本地网络判断以决定下一跳地址（直连或网关）的机制。
