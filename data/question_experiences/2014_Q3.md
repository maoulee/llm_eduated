# 2014 Q3 — 循环队列空满条件判定

## 基本信息
- **年份**: 2014  **题位**: Q3  **题型**: 选择题
- **知识点**: DS-3 > 3.2 队列 > 循环队列, DS-3 > 3.2 队列 > 队空条件, DS-3 > 3.2 队列 > 队满条件
- **题位域**: DS-2  **科目**: 数据结构

## 题干原文
循环队列放在一维数组 A[0..M-1] 中，end1 指向队头元素，end2 指向队尾元素的后一个位置。假设队列两端均可进行入队和出队操作，队列中最多能容纳 M-1 个元素。初始时为空。下列判断队空和队满的条件中，正确的是（ ）。

A. 队空：
end1 == end2
；队满：
end1 == (end2 + 1) mod M
B. 队空：
end1 == end2
；队满：
end2 == (end1 + 1) mod (M - 1)
C. 队空：
end1 == (end1 + 1) mod M
；队满：
end1 == (end2 + 1) mod M
D. 队空：
end1 == (end2 + 1) mod M
；队满：
end2 == (end1 + 1) mod (M - 1)

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆循环队列的基本定义，特别是 `front`（队头）和 `rear`（队尾）指针的指向约定。本题中 `end1` 指向队头元素，`end2` 指向队尾后一个位置，这是标准的循环队列定义变体，属于核心概念记忆。不是4分因为不需要辨析多个易混概念，只需掌握标准模型。
- **K2 = 2**: 评分理由。涉及简单的取模运算 `(end2 + 1) % M`。计算量极小，主要是对公式形式的识别，而非复杂数值计算。
- **K3 = 2**: 评分理由。推演步骤较少。只需理解“牺牲一个存储单元”来解决空满歧义的原理，即队满时 `rear` 再进一位就会追上 `front`。从定义到结论只需1-2步逻辑映射。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。
    1. **陷阱1**：题干提到“两端均可进行入队和出队操作”（双端队列），这容易误导考生认为需要特殊的空满判断逻辑，但实际上对于基于数组的循环结构，空满判断仅取决于指针相对位置，与操作方向无关（只要指针移动规则一致）。
    2. **陷阱2**：模运算的对象。队满条件中模的是数组长度 `M`，而不是容量 `M-1`。很多考生会混淆数组下标范围和有效容量。
    3. **陷阱3**：指针指向的定义。`end1` 指向元素本身，`end2` 指向空位，这与某些教材中 `front` 指向空位的定义不同，需仔细审题。
- **K5 = 1**: 评分理由。本题仅涉及数据结构中的队列模块，不涉及操作系统、计算机网络等其他科目的知识联动，属于单系统内部问题。
- **雷达形状**: K4陷阱型。基础概念（K1）和计算（K2）难度低，但条件路由（K4）难度高，主要考察对题干细节的敏感度和对经典陷阱的规避能力。

## 考察模式
- **模式**: 概念型
- **理由**: 本题不侧重于复杂的算法实现或数值计算，而是侧重于对循环队列核心机制（牺牲一个单元区分空满）及其指针语义的理解。考生需要识别出题干描述符合标准循环队列模型，并排除“双端操作”带来的干扰。

## 选项级分析
- **选项A**: [正确] — 队空：`end1 == end2`；队满：`end1 == (end2 + 1) mod M`。
    - **分析**: 初始为空时，`end1` 和 `end2` 均指向同一位置（如0），故 `end1 == end2` 为空。当队列满时，由于牺牲一个单元，`end2` 再向后移动一位（即 `(end2 + 1) % M`）将等于 `end1`。这是标准的循环队列空满判断公式。
- **选项B**: [干扰] — 队空：`end1 == end2`；队满：`end2 == (end1 + 1) mod (M - 1)`。
    - **分析**: 队空条件正确。队满条件错误。错误点在于模数使用了 `M-1`。循环队列的指针移动是在数组下标 `0..M-1` 之间循环，因此模数必须是数组长度 `M`，而不是有效容量 `M-1`。这类学生可能混淆了“容量”和“数组大小”的概念。
- **选项C**: [干扰] — 队空：`end1 == (end1 + 1) mod M`；队满：`end1 == (end2 + 1) mod M`。
    - **分析**: 队空条件完全错误。`end1 == (end1 + 1) mod M` 意味着 `1 == 0 mod M`，这在 `M > 1` 时恒假，或者意味着指针自指，逻辑不通。这类学生可能完全没看懂指针含义，随意拼凑公式。
- **选项D**: [干扰] — 队空：`end1 == (end2 + 1) mod M`；队满：`end2 == (end1 + 1) mod (M - 1)`。
    - **分析**: 队空条件错误。`end1 == (end2 + 1) mod M` 实际上是队满的条件（如果 `end1` 是 front，`end2` 是 rear）。这里把空满条件搞反了，且队满条件的模数也错了。这类学生可能记反了空满的指针关系，或者混淆了 front/rear 的定义。

- **干扰策略**: 概念混淆与计算陷阱。主要利用“模数应该是 M 还是 M-1”以及“空满条件是否颠倒”这两个常见错误点设置干扰项。同时利用“双端队列”这一背景信息制造心理干扰，让考生怀疑标准公式的适用性。

## 核心陷阱
- **核心陷阱**: **模数的选择**与**双端操作的干扰**。
    1. 许多考生会误以为因为最多容纳 `M-1` 个元素，所以取模运算应该对 `M-1` 进行，实际上取模运算是为了处理数组下标的循环，必须对数组长度 `M` 取模。
    2. 题干中“两端均可进行入队和出队操作”是多余信息（Red Herring），旨在干扰考生判断。只要指针移动规则是单向递增（或递减）且循环，空满判断逻辑不变。考生若过度关注“双端”，可能会试图寻找更复杂的判断条件，从而偏离标准答案。

## 考察能力
本题核心考察考生对循环队列“牺牲一个存储单元以区分队空和队满”这一经典设计原理的理解，以及在复杂题干描述中剥离干扰信息、准确应用基础公式的能力。
