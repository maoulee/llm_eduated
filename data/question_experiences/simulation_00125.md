## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆 IEEE 754 单精度浮点数的格式定义（1位符号、8位指数、23位尾数）以及偏移量 127 的概念。这是解题的基础，属于标准的核心定义记忆，不涉及复杂概念辨析。
- **K2 = 4**: 评分理由。涉及十进制小数（-8.25）到二进制的转换，以及整数到二进制的转换。特别是小数部分的转换（0.25 -> 0.01）和科学计数法的规范化过程，对于不熟练的学生来说，单步计算容易出错，且涉及多级换算（十进制->二进制->规格化->十六进制）。
- **K3 = 4**: 评分理由。浮点加减运算是一个多步串行过程：对阶（小阶向大阶看齐）、尾数求和/差、规格化、舍入（本题未涉及复杂舍入，但需判断是否需要）、溢出判断。从输入到输出需经历 5 步以上操作，且需记忆中间状态（如对齐后的尾数），符合 4 分标准。
- **K4 = 3**: 评分理由。存在常规注意点，如“对阶时尾数右移”、“负数补码运算或符号位处理”、“结果规格化时指数的调整”。特别是两个负数相加，符号位不变，但尾数相加后可能需要左规或右规，这里考察了对阶和尾数运算的规则意识，属于陷阱词或常规注意点级别。
- **K5 = 1**: 评分理由。本题完全局限于浮点数表示与运算这一单一子系统内部，不涉及指令系统、存储系统或 I/O 系统的跨域联动。

- **雷达形状**: 呈现“中间高、两头低”的纺锤形或菱形。K1 基础认知适中，K2 计算和 K3 推演难度较高，K4 有一定陷阱，K5 无跨域需求。整体偏向于计算推导型题目。

## 考察模式
- **模式**: 计算推导型
- **理由**: 题目要求给出具体的数值结果（十六进制），解题过程依赖于严格的数学转换规则和算法步骤（IEEE 754 编码规则及浮点加减算法），而非概念辨析或系统设计。

## 解题思路分析
- **核心思路**: 首先将十进制实数转换为 IEEE 754 单精度浮点数的二进制表示，进而转换为十六进制；其次，按照浮点加减运算规则（对阶、尾数运算、规格化）计算结果，最后将结果转换回十六进制。
- **关键步骤**:
    1.  **编码 x (-68)**:
        -   符号位: 1 (负)
        -   绝对值 68 = $1000100_2$ = $1.000100 \times 2^6$
        -   指数: $6 + 127 = 133 = 10000101_2$
        -   尾数: $00010000000000000000000$
        -   组合: $1 10000101 00010000000000000000000$ -> $0xC2880000$
    2.  **编码 y (-8.25)**:
        -   符号位: 1 (负)
        -   绝对值 8.25 = $1000.01_2$ = $1.00001 \times 2^3$
        -   指数: $3 + 127 = 130 = 10000010_2$
        -   尾数: $00001000000000000000000$
        -   组合: $1 10000010 00001000000000000000000$ -> $0xC1040000$
    3.  **计算 x + y (存入 C)**:
        -   对阶: $E_x=133, E_y=130$, $\Delta E = 3$. $y$ 的尾数右移 3 位。
        -   $M_y$ 原尾数部分 $00001...$ 右移 3 位变为 $00000001...$ (注意隐含的1也要参与移位，即 $1.00001$ 变为 $0.00100001$)
        -   尾数相加: $M_x + M_y$ (均为负数，尾数绝对值相加，符号位保持1)。
        -   $1.000100 + 0.00100001 = 1.00110001$
        -   结果: $-1.00110001 \times 2^6$
        -   规格化: 已是规格化形式。
        -   编码: 符号1, 指数133 ($10000101$), 尾数 $00110001000000000000000$
        -   二进制: $1 10000101 00110001000000000000000$ -> $0xC2988000$
    4.  **计算 x - y (存入 D)**:
        -   $x - y = x + (-y)$. $-y = 8.25$.
        -   对阶: $E_x=133, E_{-y}=130$, $\Delta E = 3$. $-y$ 的尾数右移 3 位。
        -   $M_{-y}$ 原尾数部分 $1.00001$ 右移 3 位变为 $0.00100001$.
        -   尾数相减: $M_x - M_{-y}$ (即 $1.000100 - 0.00100001$).
        -   $1.00010000 - 0.00100001 = 0.11101111$
        -   结果: $+0.11101111 \times 2^6$ (注意：这里符号位由大数决定，x绝对值大，结果为负？不对，x=-68, y=-8.25, x-y = -68 - (-8.25) = -59.75. 结果为负。
        -   重新检查符号: $x$ 是负，$-y$ 是正。$|x| > |-y|$, 所以结果符号为负。
        -   尾数运算: $|M_x| - |M_{-y}| = 1.00010000 - 0.00100001 = 0.11101111$.
        -   规格化: $0.11101111 \times 2^6 = 1.1101111 \times 2^5$.
        -   新指数: $5 + 127 = 132 = 10000100_2$.
        -   新尾数: $11011110000000000000000$.
        -   编码: 符号1, 指数132 ($10000100$), 尾数 $11011110000000000000000$.
        -   二进制: $1 10000100 11011110000000000000000$ -> $0xC26F0000$.
- **易错点**:
    1.  小数转二进制时，0.25 转换为 0.01 容易出错。
    2.  对阶时，尾数右移容易位数数错，或者忘记隐含的“1”也要参与移位。
    3.  尾数相减后，结果非规格化（最高位为0），需要进行左规，同时指数减1，这一步极易遗漏。
    4.  十六进制转换时，二进制分组错误。

## 核心陷阱
- **核心陷阱**: **浮点减法后的规格化处理**。在计算 $x - y$ 时，由于 $|x| > |y|$，尾数相减后结果的最高有效位可能为 0（如本题中的 $0.111...$），此时必须进行左规操作，将尾数左移一位，指数减 1。许多学生容易直接保留相减后的尾数和原指数，导致结果错误。

## 考察能力
本题核心考察考生对 IEEE 754 浮点数编码规则的熟练掌握程度，以及在浮点加减运算中执行对阶、尾数运算和规格化等关键步骤的准确计算能力。
