# 模拟题 Q1 — 补码表示与算术右移

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: CO-2 > 定点数的表示 > 补码表示, CO-2 > 定点数的运算 > 移位运算
- **难度**: 待评估

## 题干原文
已知 C 程序中，某类型为 int 的变量 x 的值为 -1088。程序执行时，x 先被存放在 16 位寄存器 R1 中，然后被进行算术右移 4 位的操作。则此时 R1 中的内容（以十六进制表示）是（ ）。
- 选项:
  A: FBCOH
  B: FFBCH
  C: 0FBCH
  D: 87BCH
- 正确答案: B

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握两个核心概念：16位补码的表示方法（取反加一）以及算术右移的定义（符号位扩展）。这属于标准的基础概念记忆，不涉及复杂辨析，但必须准确回忆定义。
- **K2 = 3**: 评分理由。涉及十进制转十六进制（或二进制）的计算，以及补码转换的计算。1088不是2的整数幂，需要一定的进制转换计算能力（$1088 = 1024 + 64 = 0x400 + 0x40 = 0x440$），属于标准难度的单步计算。
- **K3 = 3**: 评分理由。解题过程包含明确的串行步骤：1. 求绝对值的机器数；2. 求负数的补码；3. 执行移位操作；4. 转换回十六进制。共3-4步，属于标准的多步推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和易错点：1. 必须识别“算术右移”而非“逻辑右移”（高位补符号位而非0）；2. 必须注意寄存器位宽为16位，防止溢出或位宽混淆；3. 负数补码转换容易出错（如忘记加1或取反错误）。这些陷阱使得题目难度提升。
- **K5 = 1**: 评分理由。本题仅在“定点数表示与运算”这一单一知识域内考察，不涉及指令系统、存储器或I/O等其他子系统的联动。

- **雷达形状**: K4陷阱型（K4显著高于K1/K2/K5，表明题目主要难度在于对规则细节的把握和避坑，而非复杂的跨域推理或极高强度的计算）。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过具体的数值计算（进制转换、补码变换、移位操作）得出结果，虽然涉及概念，但最终落脚点在于精确的数值推导。

## 选项级分析
- **选项A**: [干扰] — 针对“未进行移位”或“移位理解错误”的认知。$0xFBC0$ 是 -1088 的初始补码值。如果学生计算出初始值后忘记移位，或者误以为右移4位只是简单地去掉低4位而不补高位（且错误地保留了高位不变，这在逻辑上不通，但可能是计算中途停止），可能会选此项。更可能的情况是，学生正确计算了初始值 $FBC0$，但在移位时完全搞混，或者题目印刷错误（O应为0）。
- **选项B**: [正确] — 正确执行了补码转换和算术右移。$-1088 \rightarrow [1088]_{补} = 0000\ 0100\ 0100\ 0000 \rightarrow [-1088]_{补} = 1111\ 1011\ 1100\ 0000 (FBC0H)$。算术右移4位，高位补4个1，低位丢弃：$1111\ 1111\ 1011\ 1100 \rightarrow FFBC H$。
- **选项C**: [干扰] — 针对“逻辑右移”或“符号位处理错误”的认知。如果学生误用逻辑右移（高位补0），或者在求补码时符号位处理错误（例如认为负数高位直接补0），会得到 $0000\ 1111\ 1011\ 1100$，即 $0FBCH$。这是典型的混淆算术右移与逻辑右移的陷阱。
- **选项D**: [干扰] — 针对“移位方向错误”或“严重计算错误”的认知。$87BCH$ 与正确答案差异较大，可能是学生将右移误操作为左移，或者在补码转换过程中出现严重的位权计算错误，属于随机干扰或极端错误选项。

- **干扰策略**: 概念混淆（算术vs逻辑右移）、计算中断（忘记移位）、符号位陷阱。

## 核心陷阱
- **核心陷阱**: **算术右移的符号位扩展规则**。学生极易混淆“算术右移”（Sign Extension，高位补符号位）与“逻辑右移”（高位补0）。对于负数（符号位为1），算术右移后高位应补1，而逻辑右移补0，这直接导致选项B和C的区别。此外，负数补码的“取反加一”过程也是常见的计算错误点。

## 考察能力
本题核心考察考生对**负数补码表示机制**的熟练掌握程度，以及在**算术移位运算**中正确处理**符号位扩展**的能力。
