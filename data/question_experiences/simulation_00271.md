# 模拟题 Q1 — Cache-主存系统效率与平均访问时间计算

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: OS-3 > 3.1 内存管理概念 > 内存管理基础
- **难度**: 待评估

## 题干原文
某计算机的存储系统由 Cache-主存系统构成，Cache 的存取周期为 10ns，主存的存取周期为 50ns。在 CPU 执行一段程序时，Cache 完成存取的次数为 4800 次，主存完成的存取次数为 200 次，该 Cache-主存系统的效率是（ ）。（设 Cache 和主存不能同时访问）
A: 0.833
B: 0.856
C: 0.958
D: 0.862

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆“Cache命中率”、“平均访问时间”以及“系统效率”的定义。不是4分因为不需要辨析多个易混概念（如并行/串行访问的区别在题干已明确），只需调用标准公式。
- **K2 = 3**: 评分理由。涉及基本的算术运算（加法、除法、乘法）。不是2分因为数字并非简单的2的幂次，且涉及小数运算，容易因精度或步骤顺序出错；不是4分因为计算量不大，无需多级复杂换算。
- **K3 = 3**: 评分理由。解题过程包含3-4个逻辑步骤：1. 计算总次数；2. 计算命中率；3. 根据“不能同时访问”确定未命中时的访问时间模型；4. 计算平均访问时间；5. 计算效率。属于标准的串行推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。题干明确“Cache和主存不能同时访问”，这意味着未命中时是串行访问（先查Cache再查Main Memory），而非并行。如果忽略此条件或误用并行公式，结果将完全不同。此外，“效率”的定义（理想时间/实际时间）也是易错点，部分学生可能误用命中率作为效率。
- **K5 = 1**: 评分理由。本题仅涉及存储子系统内部的Cache与主存交互，不涉及CPU指令执行、中断、I/O等其他子系统的状态传递或耦合。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要考察对访问机制条件的识别）

## 考察模式
- **模式**: 计算型
- **理由**: 题目给出了具体的数值参数，要求通过代入公式进行定量计算，最终得出一个具体的数值结果。虽然涉及概念理解，但核心解题路径是数学计算。

## 选项级分析
- **选项A**: [正确] — 正确计算了命中率 H=0.96，平均访问时间 T_avg = 0.96*10 + 0.04*(10+50) = 9.6 + 2.4 = 12ns。效率 = 10/12 ≈ 0.833。
- **选项B**: [干扰] — 可能是计算错误导致的随机干扰项，或者误用了某种错误的加权平均方式。
- **选项C**: [干扰] — 针对“混淆效率与命中率”的错误认知。命中率 H = 4800/5000 = 0.96，接近0.958（可能是计算误差或另一种错误公式）。很多学生看到“效率”直接选命中率相关的数值。
- **选项D**: [干扰] — 针对“误用并行访问模型”的错误认知。如果假设Cache和主存同时访问（即未命中时只增加主存访问时间，或者认为未命中时间仅为50ns），则 T_avg = 0.96*10 + 0.04*50 = 9.6 + 2.0 = 11.6ns。效率 = 10/11.6 ≈ 0.862。这是最典型的错误路径。

- **干扰策略**: 概念混淆（效率vs命中率）与 机制误用（串行vs并行）

## 核心陷阱
- **核心陷阱**: **访问机制的串行性**与**效率的定义**。
    1.  **串行访问陷阱**：题干强调“不能同时访问”，意味着未命中时，CPU先访问Cache（10ns），发现未命中后再访问主存（50ns），总耗时为60ns。若误认为是并行访问（即未命中时只需等待主存50ns，或忽略Cache的探测时间），会导致平均访问时间计算错误（对应选项D）。
    2.  **效率定义陷阱**：系统效率 = 理想情况下的访问时间（即全命中时间，Cache周期） / 实际平均访问时间。许多学生容易直接将命中率（0.96）当作效率，或者用主存周期做分母，导致选择错误。

## 考察能力
本题核心考察考生对Cache-主存层次结构中**串行访问机制**的理解，以及准确计算**平均访问时间**和**系统效率**的能力。
