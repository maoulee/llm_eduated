# 模拟题 Q1 — 跨子网通信中的路由器转发机制与地址封装

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: IP数据报转发、路由器工作原理、ARP协议作用域、网络层与数据链路层地址关系
- **难度**: 中等

## 题干原文
位于不同子网中的主机之间互相通信，下面说法中正确的是（ ）。

A. 路由器在转发 IP 数据报时，重新封装源 IP 地址和目的 IP 地址
B. 路由器在转发 IP 数据报时，重新封装目的 IP 地址和目的硬件地址
C. 路由器在转发 IP 数据报时，重新封装源硬件地址和目的硬件地址
D. 源站可以直接进行 ARP 广播得到目的站的硬件地址

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题需要考生清晰区分网络层（IP地址）和数据链路层（MAC/硬件地址）在不同网络节点（主机、路由器）上的变化规律。这不仅仅是记忆一个定义，而是需要辨析“源/目的IP”与“源/目的MAC”在端到端通信和逐跳转发中的不同行为，属于易混概念辨析。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算或公式代入，完全基于概念理解。
- **K3 = 3**: 评分理由。解题过程需要多步逻辑推演：1. 识别跨子网通信需经过路由器；2. 回忆路由器转发时解封装和重新封装的过程；3. 确定IP地址在传输过程中保持不变（端到端），而MAC地址在每一跳都改变（逐跳）。这是一个标准的3-5步串行推演过程。
- **K4 = 3**: 评分理由。存在常规陷阱。考生容易混淆“端到端”视角（IP不变）和“逐跳”视角（MAC变）。此外，选项D涉及ARP的作用域限制，若考生对ARP广播不能跨越路由器这一隐含前提意识不足，容易误选。
- **K5 = 4**: 评分理由。本题深度耦合了网络层（IP路由、子网划分）和数据链路层（帧封装、ARP协议）。考生必须理解这两个子系统如何协同工作：网络层决定路径，数据链路层负责相邻节点间的实际传输，且两者地址映射关系随网络边界（路由器）而重置。

- **雷达形状**: K1-K5 呈现“概念辨析与跨层联动”型特征。K1（概念记忆与辨析）和K5（跨域联动）较高，K2（计算）极低，K3（推演）和K4（陷阱）中等。

## 考察模式
- **模式**: 综合型（偏向机制推理）
- **理由**: 题目不仅考察单一知识点，而是要求考生综合理解TCP/IP协议栈中网络层与数据链路层的交互机制，特别是路由器作为网关在转发数据报时，如何剥离旧的数据链路层头部并封装新的头部，同时保持网络层头部不变。

## 选项级分析
- **选项A**: [干扰] — 针对“路由器会修改IP地址”的错误认知。这类学生可能混淆了NAT（网络地址转换）技术与普通路由转发技术，或者误以为路由器像交换机一样需要修改源地址以标识来源。实际上，普通路由转发中，源IP和目的IP在整个传输路径中保持不变（除非经过NAT设备）。
- **选项B**: [干扰] — 针对“IP地址和MAC地址同时变化”的错误认知。这类学生可能认为路由器是一个完全的黑盒，会重写所有地址信息。或者他们混淆了目的IP（终点）和目的MAC（下一跳）的概念，误以为目的IP也会随每一跳改变。
- **选项C**: [正确] — 正确描述了路由器转发的核心机制。路由器在接收帧时解封装，读取目的IP查路由表，确定下一跳后，重新封装帧。此时，源MAC变为路由器出口接口的MAC，目的MAC变为下一跳设备（下一跳路由器或最终主机）的MAC。
- **选项D**: [干扰] — 针对“ARP可以跨子网工作”的错误认知。这类学生可能不了解ARP协议基于广播机制，而路由器默认隔离广播域。源主机无法直接通过ARP广播获取不同子网主机的MAC地址，只能获取默认网关（路由器接口）的MAC地址。

- **干扰策略**: 概念混淆。主要利用考生对“端到端”（IP）与“逐跳”（MAC）概念界限模糊，以及对ARP协议作用域（广播域）理解不深进行干扰。

## 核心陷阱
- **核心陷阱**: 混淆网络层地址（IP）的端到端特性与数据链路层地址（MAC）的逐跳特性。考生容易错误地认为路由器会修改IP地址，或者认为ARP可以跨越路由器直接获取远端主机的MAC地址。

## 考察能力
一句话概括本题核心考察的能力：理解并区分TCP/IP协议栈中网络层与数据链路层在跨子网通信时的地址封装与解封装机制，特别是路由器转发过程中IP地址不变而MAC地址逐跳更新的原理。
