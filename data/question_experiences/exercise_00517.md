# 练习题 Q1 — Cache地址映射与TAG位数计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 计算机组成原理/存储系统
- **难度**: 待评估

## 题干原文
一个容量为 16 KB 的四路组相联高速缓存存储单元，采用 8 字块大小。字长为 32 位。物理地址空间大小为 4 GB。标记（TAG）字段的位数是（ ）
- 选项:
  A: 5
  B: 15
  C: 20
  D: 25
- 正确答案: C
- 解析（参考）: 在 k 路组相联映射中，高速缓存被划分为若干组，每组包含 k 个块。
高速缓存容量 = 16 KB。
由于是四路组相联，K = 4。
块大小 B = 8 字（1 字=4 字节）。
物理地址空间大小 = 4 GB = 4×2³⁰ 字节 = 2³² 字节。
计算步骤：
高速缓存总块数 N = 容量 / 块大小 = (16×1024 字节) / (8×4 字节) = 512
组数 S = 总块数 / 每组块数 = 512 / 4 = 128
物理地址空间划分：每个组可访问 (2³² 字节)/128 = 2²⁵ 字节 = 2²³ 字 = 2²⁰ 块
为标识这 2²⁰ 个块，需要 20 位标记字段
因此
- 知识标签: ['计算机组成原理/存储系统']
- 知识域: CO-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握Cache映射的基本概念（组相联、块大小、字长、物理地址空间），属于标准的核心定义记忆。不是4分因为不需要辨析多个易混概念（如直接映射与全相联的区别在此题中通过“四路组相联”已明确），只需调用标准公式。
- **K2 = 3**: 评分理由。涉及多级单位换算（字到字节、KB到字节、GB到字节）以及2的幂次运算。虽然都是2的幂，但步骤较多（容量->块大小->总块数->组数->索引位->标记位），单步代入容易因单位不统一出错，属于标准难度的计算。
- **K3 = 3**: 评分理由。从输入到输出需要3-5步串行推演：1.计算块大小（字节）；2.计算Cache总块数；3.计算组数；4.确定物理地址位数；5.计算索引位和块内偏移位；6.得出TAG位数。步骤清晰但链条较长，符合3分标准。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。题面给出“8字块大小”和“字长32位”，考生必须意识到Cache容量通常以字节为单位，而块大小以字为单位，必须进行单位统一（8字 * 4字节/字 = 32字节）。若忽略字长直接按8字节计算，或混淆字与字节，将导致错误。这是典型的“题面没说但解题必须意识到的条件”（单位一致性），属于陷阱词/隐含前提深。
- **K5 = 1**: 评分理由。本题仅涉及存储系统内部的Cache映射机制，不涉及CPU流水线、中断、内存管理等其他子系统的状态传递或耦合，属于单系统问题。
- **雷达形状**: K4陷阱型（K4显著高于其他维度，K5最低）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过给定的参数（容量、路数、块大小、地址空间）进行数值计算，得出TAG字段的位数。虽然涉及概念理解，但最终答案依赖于精确的数学推导和单位换算。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：可能误将组数（128=2^7）或块内偏移（32字节=2^5）直接当作TAG，或者计算过程中严重混淆了索引位和标记位。这类学生可能只计算了块内偏移位数（5位），误以为这就是TAG。
- **选项B**: [干扰] — 针对错误认知：可能错误计算了组数或索引位。例如，若误以为块大小是8字节（忽略字长），则总块数=16KB/8B=2048，组数=2048/4=512=2^9，索引位=9，TAG=32-9-3=20（巧合？不，若块大小算错，块内偏移也变）。更可能的错误是：物理地址32位，减去索引位（假设算错为17位）得到15位。或者混淆了直接映射的计算方式。
- **选项C**: [正确] — 正确计算结果。物理地址32位，块内偏移5位（32字节），索引位7位（128组），TAG = 32 - 5 - 7 = 20位。
- **选项D**: [干扰] — 针对错误认知：可能忽略了组相联中的“组”概念，误按直接映射计算，或者在计算组数时出错。例如，若误将总块数512当作组数（即误以为1路组相联），则索引位=9，TAG=32-5-9=18（非选项）。若误以为块大小是8字节，块内偏移3位，总块数2048，组数512，索引9，TAG=32-3-9=20（还是20？不对，若块大小8字节，块内偏移3位，总块数2048，组数512，索引9，TAG=32-3-9=20。等等，若块大小按8字节算，TAG也是20？让我们重新检查干扰项D的来源。若考生忘记减去块内偏移，32-7=25，则选D。这是最常见的错误：只减去索引位，忘记减去块内偏移位。
- **干扰策略**: 计算陷阱（单位换算错误、遗漏块内偏移位、混淆索引位与标记位）

## 核心陷阱
- **核心陷阱**: **单位不统一与地址字段遗漏**。
    1. **单位陷阱**：块大小给的是“8字”，而Cache容量和地址空间通常基于“字节”。必须乘以字长（4字节）得到块大小32字节，从而确定块内偏移为5位。若误用8字节，块内偏移为3位，虽在此题中可能因巧合或其他错误路径导致不同结果，但这是首要陷阱。
    2. **字段遗漏陷阱**：物理地址 = TAG + Index + Offset。许多考生容易忘记减去Offset（块内偏移），直接用 物理地址位数 - Index位数 得到TAG，导致结果偏大（如32-7=25，对应选项D）。

## 考察能力
本题核心考察考生对Cache地址映射机制的理解，特别是多路组相联映射中物理地址各字段（TAG、Index、Offset）的划分逻辑，以及在复杂单位（字/字节、KB/GB）下进行精确数值计算的能力。
