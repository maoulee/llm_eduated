# 练习题 Q1 — 队列实现二叉树层序遍历

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/队列
- **难度**: 待评估

## 题干原文
考虑以下程序，确定该函数的作用。
（ ）
```c
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};

struct Node *newNode(int item) {
    struct Node *node = (struct Node *)malloc(sizeof(struct Node));
    node->data = item;
    node->left = node->right = NULL;
    return node;
}

void function(struct Node *root) {
    if (root == NULL) return;
    struct Node **q = (struct Node **)malloc(100 * sizeof(struct Node *));
    int front = 0, rear = 0;
    q[rear++] = root; // 注意：原题此处截断，但根据逻辑应为入队操作
    while (front < rear) {
        struct Node *temp = q[front++];
        printf("%d ", temp->data); // 访问节点
        if (temp->left != NULL)
            q[rear++] = temp->left;
        if (temp->right != NULL)
            q[rear++] = temp->right;
    }
}
```
*(注：原题题干代码在 `q[rear` 处截断，但结合选项和标准答案C，可推断后续为标准的队列入队及循环处理逻辑)*

选项:
A: 树的中序遍历
B: 树的普通遍历
C: 树的层序遍历
D: 无

正确答案: C

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“队列（Queue）”与“二叉树遍历（Traversal）”两个核心概念。仅记忆定义不足以解题，需理解队列FIFO特性与层序遍历逻辑的对应关系。不是4分因为不需要辨析多个易混的高级概念，属于标准的基础知识应用。
- **K2 = 1**: 评分理由。本题不涉及数值计算，无需执行复杂的算术运算或幂次换算。
- **K3 = 3**: 评分理由。需要在脑海中模拟代码执行流程：根节点入队 -> 出队访问 -> 左右子节点入队 -> 循环。这是一个典型的3-5步串行推演过程，需跟踪`front`和`rear`指针的变化以及队列内容的变化。
- **K4 = 2**: 评分理由。存在常规注意点，即识别`struct Node **q`是队列的底层数组实现，以及`front`和`rear`分别代表队头和队尾。没有深层隐含前提或反直觉陷阱，只要熟悉C语言指针和队列实现即可避开。
- **K5 = 3**: 评分理由。涉及“线性结构（队列）”与“非线性结构（树）”之间的状态传递。队列作为辅助存储结构，用于控制树的访问顺序，属于单向的数据/状态传递（树节点状态进入队列，队列顺序决定树访问顺序）。

- **雷达形状**: K3推演主导型（K1和K3较高，K2极低，K4和K5中等）

## 选项级分析
- **选项A**: [干扰] — 针对混淆“递归/栈”与“队列”的学生。中序遍历通常使用递归或显式栈（LIFO）实现，若学生未注意到代码中使用的是队列（FIFO），可能会误选。
- **选项B**: [干扰] — 针对概念模糊的学生。“普通遍历”并非标准术语，可能吸引那些知道是遍历但记不清具体名称，或者认为代码太简单不属于特定遍历的学生。
- **选项C**: [正确] — 代码利用队列的先进先出特性，先访问根，再依次访问其子节点，符合层序遍历（BFS）的定义。
- **选项D**: [干扰] — 针对完全无法读懂代码或认为代码有语法错误（如截断部分）的学生。

- **干扰策略**: 概念混淆（栈vs队列对应的遍历方式）

## 核心陷阱
- **核心陷阱**: 未能识别代码中`struct Node **q`配合`front`和`rear`指针所构成的**队列结构**，从而错误地将其联想为栈（导致误判为中序/前序/后序）或忽略其遍历特性。此外，题干代码截断可能导致部分考生因代码不完整而直接放弃或选D。
