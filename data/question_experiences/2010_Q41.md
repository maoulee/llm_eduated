# 2010 Q41 — 散列表构造与ASL计算

## 基本信息
- **年份**: 2010  **题位**: Q41  **题型**: 综合题
- **知识点**: DS-7 > 7.4 散列表 > 散列表基本概念, DS-7 > 7.4 散列表 > 散列函数, DS-7 > 7.4 散列表 > 冲突, DS-7 > 7.4 散列表 > 装填因子, DS-7 > 7.1 查找的基本概念 > 平均查找长度 ASL
- **题位域**: 待标注  **科目**: 数据结构

## 题干原文
将关键字序列 ⟨7,8,30,11,18,9,14⟩ 散列存储到散列表中。散列表的存储空间是一个下标从 0 开始的一维数组，散列函数为 H(key)=(key×3)mod7 ，处理冲突采用线性探测再散列法，要求装填（载）因子为 0.7 。
(1) 请画出所构造的散列表。
(2) 分别计算等概率情况下查找成功和查找不成功的平均查找长度。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆散列表的基本概念（装填因子、散列函数、线性探测法）以及ASL的定义。不是4分因为不需要辨析多个易混的高级概念，属于标准的基础知识调用。
- **K2 = 3**: 评分理由。涉及模运算 `(key*3)%7` 和简单的加减法计算。不是2分因为模数7不是2的幂，且需要多次计算；不是4分因为计算量不大，不涉及复杂的多级换算。
- **K3 = 4**: 评分理由。构造散列表需要串行处理7个关键字，每个关键字可能涉及多次冲突探测（线性探测），需要记忆中间状态（哪些位置已被占用）。查找不成功的ASL计算需要针对散列函数的值域（0-6）分别模拟查找过程，步骤较多且需保持状态一致性。
- **K4 = 4**: 评分理由。存在明显的隐含前提和易错点。首先，数组大小需通过装填因子反推（7/0.7=10），而非直接使用模数7。其次，查找不成功的ASL计算中，分母是散列函数的值域大小（7）而非数组大小（10）或元素个数（7），且查找终止条件是遇到空位，这需要考生深刻理解线性探测的查找失败机制，属于较深的隐含前提。
- **K5 = 2**: 评分理由。主要局限于散列表这一单一子系统内部的操作。虽然涉及查找成功与不成功两种场景，但逻辑相对独立，没有跨越不同数据结构或算法模块的深度耦合。

- **雷达形状**: 偏向右侧（K3、K4较高），呈现“推演与陷阱”主导的特征，基础认知（K1）和单步计算（K2）处于中等水平，跨域联动（K5）较低。

## 考察模式
- **模式**: 计算推导型
- **理由**: 题目要求根据给定的规则（散列函数、冲突处理方法、装填因子）进行具体的数值计算和状态模拟，最终得出确定的散列表结构和ASL数值。重点在于过程的准确性和对规则细节的严格执行。

## 解题思路分析
- **核心思路**: 
  1. 确定散列表长度：利用装填因子公式 $\alpha = n/m$，由 $n=7, \alpha=0.7$ 得出 $m=10$。
  2. 构造散列表：依次计算每个关键字的散列地址，若冲突则按线性探测法（地址+1, +2...）寻找空位，直到所有关键字插入完毕。
  3. 计算ASL成功：统计每个关键字在插入时比较的次数（即查找该关键字所需的比较次数），求和后除以关键字个数 $n$。
  4. 计算ASL不成功：针对散列函数 $H(key)$ 的所有可能取值（0到6），模拟查找过程，统计直到遇到空位所需的比较次数，求和后除以散列函数的值域大小（即模数 $p=7$）。

- **关键步骤**:
  1. **计算表长**：$m = \lceil 7 / 0.7 \rceil = 10$。
  2. **插入过程**：
     - 7: $H(7)=0$, 空, 放入[0]。
     - 8: $H(8)=3$, 空, 放入[3]。
     - 30: $H(30)=6$, 空, 放入[6]。
     - 11: $H(11)=5$, 空, 放入[5]。
     - 18: $H(18)=5$, 冲突->6(占)->7(空), 放入[7]。
     - 9: $H(9)=6$, 冲突->7(占)->8(空), 放入[8]。
     - 14: $H(14)=0$, 冲突->1(空), 放入[1]。
     - 最终表：[7, 14, _, 8, _, 11, 30, 18, 9, _] (下标0-9)
  3. **ASL成功**：
     - 7(1次), 8(1次), 30(1次), 11(1次), 18(3次: 5,6,7), 9(3次: 6,7,8), 14(2次: 0,1)。
     - $ASL_{succ} = (1+1+1+1+3+3+2)/7 = 12/7$。
  4. **ASL不成功**：
     - 查找失败意味着在散列地址 $i$ 开始探测，直到遇到空位。
     - $H(key)=0$: 查[0](7)->[1](14)->[2](空), 3次。
     - $H(key)=1$: 查[1](14)->[2](空), 2次。
     - $H(key)=2$: 查[2](空), 1次。
     - $H(key)=3$: 查[3](8)->[4](空), 2次。
     - $H(key)=4$: 查[4](空), 1次。
     - $H(key)=5$: 查[5](11)->[6](30)->[7](18)->[8](9)->[9](空), 5次。
     - $H(key)=6$: 查[6](30)->[7](18)->[8](9)->[9](空), 4次。
     - $ASL_{fail} = (3+2+1+2+1+5+4)/7 = 18/7$。

- **易错点**:
  1. 散列表长度计算错误，误以为长度等于模数7。
  2. 线性探测时忘记处理循环边界（本题未溢出，但需意识）。
  3. ASL不成功的分母错误，误用数组长度10或元素个数7，正确应为散列函数的值域大小（模数）7。
  4. ASL不成功的次数统计错误，误以为查找到关键字为止，实际上应查找到第一个空位为止。

## 核心陷阱
- **核心陷阱**: **查找不成功ASL的分母与查找终止条件**。
  许多考生会错误地使用数组长度（10）作为分母，或者在计算查找次数时，混淆了“查找成功”和“查找失败”的终止条件。查找失败时，必须从 $H(key)$ 对应的地址开始，连续探测直到遇到**空单元**，比较次数即为探测次数。此外，分母必须是散列函数可能产生的不同地址个数（即模数 $p$），因为假设查找的关键字其散列值在 $0 \sim p-1$ 之间是等概率的。

## 考察能力
本题核心考察考生对散列表构造过程的精确模拟能力，以及对平均查找长度（ASL）在成功与失败两种不同场景下定义和计算方法的深刻理解与区分能力。
