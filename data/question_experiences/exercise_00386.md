# 练习题 Q1 — 有向图DFS树边数量的不变性辨析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/图
- **难度**: 待评估

## 题干原文
以下陈述是否正确？有向图的深度优先搜索（DFS）总是产生相同数量的树边，即与顶点进行 DFS 的顺序无关。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握DFS的基本定义、树边（Tree Edge）的定义以及有向图遍历的基本性质。不是4分因为不需要辨析多个易混的高级概念（如强连通分量分解的具体算法细节），只需理解DFS生成森林的基本机制。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算或公式代入，属于纯概念判断。
- **K3 = 4**: 评分理由。需要在脑海中构建一个具体的有向图反例，并模拟两种不同的访问顺序（例如先访问A再访问B，与先访问B再访问A），推演DFS过程中边的分类变化。这需要多步串行推演：确定图结构 -> 设定顺序1 -> 执行DFS -> 统计树边 -> 设定顺序2 -> 执行DFS -> 统计树边 -> 比较结果。
- **K4 = 4**: 评分理由。存在明显的隐含前提陷阱。学生容易将“无向图”的性质（DFS树边数 = 顶点数 - 连通分量数，是定值）错误迁移到“有向图”。有向图的DFS生成的是森林，且树边数量取决于起始顶点的选择以及邻接表的访问顺序，这是一个反直觉或易混淆的隐含条件。
- **K5 = 2**: 评分理由。主要局限于图论子系统内部，但需要结合DFS算法的执行流程（栈/递归机制）与图的结构特性（有向性、连通性）进行联动。提及了算法执行顺序对结构结果的影响，属于单向的状态影响。
- **雷达形状**: K3/K4 双高型（推理与陷阱主导），K2极低。

## 考察模式
- **模式**: 推理型
- **理由**: 题目不要求记忆死板的结论，而是要求考生通过逻辑推演或构造反例来验证命题的真伪。考生必须理解DFS算法的动态执行过程，并推理出不同执行路径对最终生成树结构的影响。

## 选项级分析
- **选项A**: [干扰] — 针对“无向图性质迁移”或“DFS确定性误解”的错误认知。这类学生可能认为DFS是一种确定性算法，对于给定的图，其生成的树结构（或至少树边数量）是固定的；或者他们混淆了无向图DFS树边数固定（$V-C$）的性质，错误地认为有向图也是如此。
- **选项B**: [正确] — 正确识别出有向图DFS的树边数量依赖于遍历顺序。
- **干扰策略**: 概念混淆。利用无向图DFS性质的稳定性来干扰对有向图DFS动态性的判断。

## 核心陷阱
- **核心陷阱**: **无向图与有向图DFS性质的混淆**。在无向图中，DFS生成的树边数量仅取决于图的连通分量数量，与遍历顺序无关；但在有向图中，DFS生成的是森林，树边的数量不仅取决于图的连通性，还强烈依赖于起始顶点的选择以及邻接顶点的访问顺序。例如，在一个简单的有向图 $A \to B$ 中，若从A开始DFS，树边为 $(A,B)$，数量为1；若从B开始DFS（假设B没有出边），树边为空，数量为0（A作为另一棵树的根，无树边）。

## 考察能力
一句话概括本题核心考察的能力：
考生能否准确区分有向图与无向图在深度优先搜索中生成树结构的差异，并理解算法执行顺序对图遍历结果的影响。
