# 练习题 Q1 — 渐近增长阶比较

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/算法分析
- **难度**: 待评估

## 题干原文
将下列函数按渐近增长顺序从小到大排列：
（注：原题题干中未直接列出A-E对应的具体函数表达式，但根据解析逻辑及408常见真题库推断，通常涉及以下典型函数集合：
A: $O(\log n)$ 或 $O(n)$ 类低阶多项式/对数
B: $O(2^n)$ 或 $O(n!)$ 类高阶指数/阶乘
C: $O(n^2)$ 或 $O(n \log n)$ 类多项式
D: $O(\sqrt{n})$ 或 $O(n^{0.5})$ 类次线性
E: $O(1.5^n)$ 或 $O(2^{n/2})$ 类指数
*基于解析“A < D < C < E < B”及“B和E属于指数函数... B>>E... A<<{C,D}... D<<C”的逻辑，本题考察的是不同复杂度类别的层级排序。*）

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。需要记忆并辨析多个易混的复杂度概念。考生必须熟练掌握对数、多项式、指数、阶乘等不同增长阶的定义及其相对大小关系。不仅仅是知道定义，还需要在脑海中建立完整的“复杂度阶梯”图谱。不是5分因为不需要辨析极其细微的数学极限定义，而是标准的算法分析基础概念。
- **K2 = 2**: 评分理由。本题不涉及具体的数值计算，而是概念性的阶数比较。最复杂的“计算”在于判断 $n^2$ 与 $2^n$ 谁大，这属于定性判断而非定量计算，难度较低。
- **K3 = 3**: 评分理由。解题过程需要多步串行推演。首先将5个函数分为“非指数”和“指数”两大阵营（2步）；然后在非指数阵营内比较多项式/对数的大小（1步）；最后在指数阵营内比较底数或系数的大小（1步）。总共约3-4步逻辑推导，符合3分标准。
- **K4 = 3**: 评分理由。存在常规注意点作为陷阱。主要陷阱在于指数函数的比较（如 $2^n$ 与 $n^2$ 的直观错觉，或 $2^n$ 与 $2^{n/2}$ 的底数/指数混淆）。考生需意识到“指数增长远快于多项式增长”这一隐含前提，否则容易在C和E之间出错。属于常规陷阱，故为3分。
- **K5 = 1**: 评分理由。单系统问题。本题仅涉及算法时间复杂度分析这一单一知识域，无需跨越操作系统、计网或组成原理等其他模块，无状态传递需求。
- **雷达形状**: K1-K4 均衡偏概念型。K1（概念记忆）和K4（陷阱识别）较高，K2（计算）极低，呈现典型的“概念辨析型”雷达图。

## 考察模式
- **模式**: 概念型
- **理由**: 本题核心不在于计算具体值，而在于考察考生对算法复杂度理论中不同函数增长阶（Big-O）的定性理解。它测试的是考生是否建立了正确的复杂度层级认知模型。

## 选项级分析
- **选项A**: [正确] — 正确顺序为 A < D < C < E < B。符合解析中的逻辑：低阶（A）< 次线性/低阶多项式（D）< 高阶多项式（C）< 低阶指数（E）< 高阶指数（B）。
- **选项B**: [干扰] — 错误地将 D 排在 A 之前，或者混淆了指数与非指数的界限。这类学生可能误以为 $D$（如 $\sqrt{n}$）比 $A$（如 $\log n$）增长慢，或者在指数部分排序错误。针对对数与根号函数增长速度的模糊认知。
- **选项C**: [干扰] — 错误地将 C 排在 D 之前（若C为 $n^2$, D为 $\sqrt{n}$，则C应大于D，此处选项C显示 A,C,D... 即 $n^2 < \sqrt{n}$ 显然错误，或者若C为 $n \log n$ 而 D 为 $n$，则顺序可能不同，但根据解析 D<C，选项C的 A,C,D 意味着 C<D，这是错误的）。这类学生可能混淆了多项式内部的增长顺序，或者误以为系数大的项增长一定快而忽略了阶数。
- **选项D**: [干扰] — 错误地将 B 排在 E 之前（若B为 $2^n$, E为 $1.5^n$，则 B>E，选项D显示 ...B, E 即 B<E，错误）。或者混淆了指数函数的底数比较。这类学生可能没有仔细比较指数函数的底数，或者误以为阶乘/高阶指数增长不如某些特定多项式（极罕见错误），更可能是对指数部分的大小关系判断失误。
- **干扰策略**: 概念混淆。主要利用考生对“多项式 vs 指数”界限的模糊，以及“指数函数内部底数比较”的不敏感进行干扰。

## 核心陷阱
- **核心陷阱**: **指数与多项式的界限混淆** 以及 **指数函数内部的细微差别**。
    1. 许多初学者直觉上认为 $n^2$ 很大，可能误以为它比 $2^n$ 增长快（在小 $n$ 时确实如此，但渐近意义下 $2^n$ 更快）。
    2. 在指数函数中，如 $2^n$ 与 $2^{n/2}$（即 $\sqrt{2}^n$），考生容易忽略指数上的系数对增长阶的巨大影响，误以为它们属于同一量级或顺序颠倒。

## 考察能力
一句话概括本题核心考察的能力：**对算法时间复杂度不同增长阶（对数、多项式、指数）的定性比较与层级排序能力。**
