# 练习题 Q1 — TCP序列号机制与流量控制

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/传输层
- **难度**: 待评估

## 题干原文
假设两台主机通过 TCP 连接传输一个大文件。关于该 TCP 连接，以下哪些陈述是
错误的
？（ ）
如果某个分段的序列号为 m，则后续分段的序列号
一定
是 m+1。
在任意时刻，如果估计的往返时间为 t 秒，则重传超时时间
一定
设置为大于或等于 t 秒。
TCP 连接过程中，接收方通告窗口的大小
从不
改变。
发送方未确认的字节数
始终
小于或等于通告窗口的大小。

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题需要辨析多个易混概念：序列号的定义（字节流编号 vs 分段计数）、RTO与RTT的关系、通告窗口的动态性、以及发送窗口与通告窗口的约束关系。仅靠记忆单一核心定义不足以解题，需对TCP头部字段及拥塞/流量控制机制有较深理解。不是5分因为不需要记忆极其生僻的协议细节或复杂公式推导。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、幂次运算或单位换算。完全基于概念判断。
- **K3 = 2**: 评分理由。推演步骤较少。对于每个陈述，只需调用对应的TCP规则进行直接比对即可得出结论，无需多步串行推演或维护复杂的状态机中间状态。
- **K4 = 4**: 评分理由。存在明显的“陷阱词”和隐含前提。
    1. 陈述1中的“一定”是陷阱，考察序列号是字节编号而非分段索引。
    2. 陈述3中的“从不”是陷阱，考察窗口动态调整机制。
    3. 陈述2考察RTO算法的常识（RTO > RTT），虽看似简单，但需排除“等于”是否允许的细微语义（通常RTO需留有余量，但题目说“大于或等于”在逻辑上涵盖了RTO>=RTT的基本事实，故该陈述本身通常被视为正确或至少不是主要错误点，但在408语境下，重点在于识别1和3的绝对错误）。
    4. 需识别题目问的是“错误的”，这是典型的反向提问陷阱。
- **K5 = 2**: 评分理由。主要涉及传输层内部机制。虽然涉及发送方和接收方（跨主机），但主要是单向的状态通告（窗口大小）和序列号逻辑，不涉及网络层路由、链路层帧结构或应用层协议的深度耦合联动。

- **雷达形状**: K1-K4 高位型（概念辨析与陷阱识别主导），K2 极低。

## 考察模式
- **模式**: 概念型
- **理由**: 题目完全基于对TCP协议核心机制（序列号、超时重传、流量控制）的概念理解，不涉及计算或复杂逻辑推理，重点在于识别绝对化表述（如“一定”、“从不”、“始终”）与协议实际动态行为之间的矛盾。

## 选项级分析
- **选项A**: [干扰] — 针对只注意到陈述3错误，而误以为陈述1正确的学生。这类学生可能混淆了“序列号”与“分段序号”，或者认为每个分段只包含1个字节（极端情况），从而误判陈述1。
- **选项B**: [正确] — 正确识别了陈述1和陈述3为错误。陈述1错在序列号增加量等于数据长度而非1；陈述3错在通告窗口随接收缓冲区变化而动态调整。
- **选项C**: [干扰] — 针对误以为陈述4错误的学生。陈述4“发送方未确认的字节数始终小于或等于通告窗口的大小”是TCP流量控制的基本规则（发送窗口 = min(拥塞窗口, 通告窗口)，已发送未确认字节数 <= 发送窗口 <= 通告窗口）。选此项的学生可能混淆了“发送窗口”与“通告窗口”的关系，或者认为拥塞窗口可能小于通告窗口导致未确认字节数受限于拥塞窗口而非通告窗口（实际上未确认字节数确实<=通告窗口，因为发送窗口<=通告窗口）。*注：严格来说，发送窗口 = min(cwnd, rwnd)，已发送未确认字节数 <= 发送窗口。因此 已发送未确认字节数 <= rwnd 恒成立。陈述4是正确的。*
- **选项D**: [干扰] — 针对误以为陈述2和陈述4错误的学生。陈述2“RTO >= RTT”在工程实现和理论上是合理的（RTO需包含RTT及处理延迟，故通常RTO > RTT，包含在>=范围内），陈述4正确。选此项的学生可能对RTO算法有误解，或同样误判了陈述4。

- **干扰策略**: 概念混淆（序列号定义）、绝对化陷阱（“从不”、“一定”）、反向提问（找错误）。

## 核心陷阱
- **核心陷阱**: 
    1. **序列号的本质**：TCP序列号是字节流的编号，而非数据包的编号。后续分段的序列号 = 当前序列号 + 当前分段数据长度。只有当分段长度为1字节时，后续序列号才是m+1，题目用“一定”将其绝对化，故错误。
    2. **窗口的动态性**：接收方通告窗口（rwnd）反映的是接收缓冲区的可用空间，随着应用层读取数据，缓冲区空间释放，rwnd会增大；随着数据到达，rwnd会减小。因此“从不改变”是明显错误的。

## 考察能力
一句话概括本题核心考察的能力：准确理解TCP序列号的字节流语义及流量控制中通告窗口的动态调整机制，并能识别绝对化表述中的逻辑谬误。
