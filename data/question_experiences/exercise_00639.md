# 练习题 Q1 — IEEE 754 单精度浮点数解码

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机组成原理/数制
- **难度**: 待评估

## 题干原文
考虑以下使用 IEEE 754 单精度浮点数格式（偏移量为 127）表示的数字：
S : 1 E : 10000001 F : 11110000000000000000000
其中，S、E 和 F 分别表示浮点数的符号位、指数位和尾数部分。
上述表示对应的十进制数值（保留两位小数）是（ ）。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆 IEEE 754 单精度浮点数的基本结构（1位符号、8位指数、23位尾数）以及规格化数的隐含前导“1”这一核心定义。不记忆这些概念无法入题，但无需辨析多个易混概念（如非规格化数、无穷大等），故为标准难度。
- **K2 = 3**: 评分理由。涉及二进制到十进制的转换，包括指数的去偏置计算（129-127）和尾数的二进制小数转十进制（0.1111）。虽然计算量不大，但涉及多级换算（二进制->十进制整数+小数），且容易在移位或小数点定位上出错，故为标准偏上难度。
- **K3 = 3**: 评分理由。解题过程包含明确的串行步骤：1. 解析符号；2. 解析指数并去偏置；3. 构造规格化尾数（添加隐含1）；4. 组合并移位；5. 转换为十进制。共约5步，属于标准的多步推演。
- **K4 = 2**: 评分理由。存在常规注意点，即规格化数必须添加隐含的“1.”前缀。这是 IEEE 754 的标准规则，不属于深奥的隐含前提或反直觉陷阱，只要掌握基本规则即可避开，故为较低难度。
- **K5 = 1**: 评分理由。本题仅涉及计算机组成原理中的数制表示子系统，无需跨越指令系统、存储系统或总线等其他模块，属于单系统内部计算。
- **雷达形状**: K2/K3 均衡型。本题在概念记忆、计算转换和步骤推演上难度分布较为均匀，没有极端的短板或长板，是典型的标准化基础计算题。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于根据给定的二进制位模式，通过固定的数学规则（去偏置、隐含位、移位）计算出最终的十进制数值。虽然涉及概念，但最终落脚点在于精确的数值转换计算。

## 选项级分析
- **选项A**: [正确] — 正确执行了符号判断（负）、指数去偏置（2）、隐含位添加（1.1111）及移位（111.11）和进制转换（-7.75）。
- **选项B**: [干扰] — 针对**符号位误读**错误。学生可能忽略了 S=1 表示负数，或者在最终结果前漏掉了负号。这类学生通常计算过程正确，但粗心大意。
- **选项C**: [干扰] — 针对**指数计算或移位错误**。例如，如果学生错误地认为指数是 129-127=2，但在移位时出错，或者错误地处理了尾数。更可能的情况是，学生可能混淆了指数值，或者在二进制转十进制时出现严重偏差（如将 111.11 误算）。实际上，5.57 接近 $5.5$ 或 $5.75$ 的某种错误变体，可能是将尾数 $1111$ 误读为其他值，或者指数计算错误导致移位位数不对。
- **选项D**: [干扰] — 针对**符号位误读 + 尾数/指数轻微错误**或**纯符号错误**。如果学生算出 7.75 但忘记负号，会选 B；如果算出 5.75，可能是将尾数 $1111$ 误认为 $1011$ ($1.011 \times 2^2 = 101.1 = 5.5$) 或其他组合。5.75 是 $101.11_2$，对应尾数 $0111...$，这与题目给出的 $1111...$ 不符，属于典型的数值混淆干扰项。
- **干扰策略**: 概念混淆（符号位）与计算陷阱（尾数精度/移位）结合。选项 B 和 D 主要测试符号和数值大小的基本对应，选项 C 测试更细致的计算准确性。

## 核心陷阱
- **核心陷阱**: **规格化数的隐含前导“1”**。许多初学者容易直接将 F 部分 $1111...$ 当作尾数 $0.1111...$ 进行计算，而忘记 IEEE 754 规格化数在尾数前隐含了一个“1”，即实际尾数为 $1.1111...$。如果忽略这一点，计算结果将是 $-0.1111 \times 2^2 = -1.11_2 = -1.75$，虽然选项中没有这个值，但这是最常见的概念性错误。此外，**符号位 S=1 代表负数**也是基础但易错的点。

## 考察能力
本题核心考察学生对 IEEE 754 单精度浮点数存储格式的理解，以及将二进制浮点表示精确转换为十进制数值的能力。
