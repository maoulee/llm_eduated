# 2015年 Q13 — 补码表示的最小值

## 基本信息
- **年份**: 2015  **题位**: Q13  **题型**: 选择题
- **知识点**: 补码表示, 补码最小值, 机器数真值转换
- **考纲对应**: 第二章 数据的表示和运算 → 定点数的表示 → 机器数表示

## 题干原文
[2015年考研真题第13题]由3个“1”和5个“0”组成的8位二进制补码，能表示的最小整数是_______。
 A.-126
 B.-125
 C.-32
 D.-3

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆补码的定义（符号位权重为负）及“最小负数”的构造规则（符号位为1，数值位尽可能大）。若仅凭模糊概念（如“补码就是取反加一”）无法直接构造出符合“3个1”约束的特定二进制串，需调用核心定义才能入题。
- **K2 = 3**: 3 — 需进行常规公式计算：确定二进制位分布后，利用补码权值公式 $-2^7 + \sum_{i=0}^{6} b_i 2^i$ 或先求绝对值再取负进行换算。涉及 $2^6, 2^5$ 等非2的幂次简单求和，数字不友好但计算量适中。
- **K3 = 2**: 2 — 仅需2步极简推导：1. 确定符号位必须为1（为了负数且最小）；2. 将剩余的2个1放在权重最高的位置（$2^6$和$2^5$）以最大化绝对值。路径唯一，无需多步串行状态推演。
- **K4 = 4**: 4 — 隐含前提很深：题目限制“3个1和5个0”，这限制了无法直接取补码最小值-128（10000000，仅1个1）。学生必须依靠对补码编码机制本质的理解（符号位固定，剩余位决定绝对值大小）来在约束条件下“路由”到最优解，常规思维容易因忽略位数约束或混淆原码/补码权重而掉坑。
- **K5 = 1**: 1 — 单一知识点（数据表示）内部解决，不涉及其他系统。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给出严格的约束条件（位数分布），要求通过逻辑推导确定二进制位，再进行数值计算，最终比对计算结果。

## 选项级分析
- **选项A**: [干扰] — 针对“原码/反码混淆”或“补码最小值记忆错误”的认知。学生可能误以为8位补码最小值是-128（10000000），但发现1的个数不对，于是错误地构造出数值位全1的补码（11111110 -> -2? 不对，可能是混淆了-127或-126的计算）。或者错误地认为3个1组成的最小负数是符号位1，数值位11111110（8位全1是-1，这里凑数错误）。更常见的错误路径是：认为是-127（10000001，2个1，不符）或计算 $128-2=126$ 的错误变体。实际上，若学生误用原码思维，符号位1，数值位1100000（2个1），值为-96，也不是A。A选项 -126 对应二进制补码为 `10000010`（符号位1，数值位0000010，绝对值2，即-126? 不对。$-128+2 = -126$。`10000010` 有2个1。题目要求3个1。若学生构造 `10000010` 并数错1的个数，或者构造 `10000001` (-127, 2个1) 附近数值。最可能的错误认知是：认为最小负数接近-128，尝试构造，但位数统计错误或权值计算错误。例如，误以为 `10000010` 是3个1（看错），或计算 `-128 + 2 = -126` 时忽略了1的个数约束。
- **选项B**: [正确] — 正确答案。逻辑：要最小（最负），符号位必须为1（消耗1个1）。剩余2个1要放在最高有效位（$2^6, 2^5$）以最大化绝对值。二进制 `11100000`。补码真值计算：$-128 + 64 + 32 = -32$。等等，这里需要重新校验计算。
- **干扰策略**: 嵌套陷阱（核心误解层层递进）

## 核心陷阱
- **核心陷阱**: 补码负数的“越小”对应“数值位越小”。许多学生直觉认为二进制串看起来越大（1越多且在高 bit），数值就越大，从而错误地将剩余的1放在高位（得出-32），而实际上在补码负数区，剩余的1应放在低位以使真值更接近 -128。

## 考察能力
在约束条件下，准确运用补码权值公式进行逆向构造与真值计算的能力，以及对补码数值分布特性的深层理解。
