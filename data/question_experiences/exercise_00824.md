# 练习题 Q1 — 流水线加速比计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机组成原理/流水线
- **难度**: 待评估

## 题干原文
考虑一个非流水线处理器，其时钟频率为 2.5 GHz，每条指令平均周期数（CPI）为 4。该处理器升级为具有五个阶段的流水线处理器；但由于内部流水线延迟，时钟频率降低到 2 GHz。假设流水线中没有停顿。在此流水线处理器中实现的加速比是（ ）。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆并理解“加速比”、“CPI”、“时钟频率”与“执行时间”之间的基本定义关系。不是4分因为不需要辨析多个易混概念（如分支预测、冒险处理等），只需掌握核心公式 $Time = CPI \times CycleTime$。
- **K2 = 3**: 评分理由。涉及频率到周期的倒数换算（$1/2.5$ 和 $1/2$），以及小数除法（$1.6 / 0.5$）。不是2分因为频率数值不是2的幂次，计算过程涉及小数运算，容易因粗心出错；也不是4分因为计算步骤并不复杂，无需多级单位换算。
- **K3 = 2**: 评分理由。解题逻辑为线性两步：分别计算旧系统和新系统的单条指令平均执行时间，然后相除。从输入到输出仅需2-3步直接推导，无需复杂的状态记忆或多步串行推演。
- **K4 = 3**: 评分理由。存在一个关键的隐含前提/陷阱：流水线处理器的CPI在理想情况下（无停顿）近似为1，而非阶段数5。如果学生错误地认为流水线CPI等于阶段数，或者忽略了频率变化对周期的影响，就会掉入陷阱。这属于典型的“陷阱词”或“隐含前提”考察。
- **K5 = 1**: 评分理由。本题仅涉及CPU内部流水线性能评估这一单一子系统，不涉及存储器层次结构、I/O系统或操作系统等其他模块的状态传递或耦合。

- **雷达形状**: K4陷阱型（K4相对较高，K1/K2/K3中等偏低，K5极低）

## 考察模式
- **模式**: 计算型
- **理由**: 题目给出了具体的数值参数，要求考生通过代入公式进行定量计算，最终得出一个具体的数值结果。虽然涉及概念理解，但核心解题动作是计算。

## 选项级分析
- **选项A**: [正确] — 正确计算了旧处理器时间 ($4 \times 0.4ns = 1.6ns$) 和新处理器时间 ($1 \times 0.5ns = 0.5ns$)，加速比 $1.6/0.5 = 3.2$。
- **选项B**: [干扰] — 针对错误认知：可能误以为流水线CPI为阶段数5，或者计算错误。若误算新时间为 $5 \times 0.5 = 2.5$，则加速比为 $1.6/2.5 = 0.64$（不符）。若误以为旧CPI为1，新CPI为1，则加速比为 $0.4/0.5 = 0.8$（不符）。更可能的错误路径是：忽略频率变化，仅看CPI变化 $4/1=4$（无此选项）；或者混淆了频率比 $2.5/2 = 1.25$ 与CPI比。实际上，B选项3.0可能是通过近似计算或错误假设（如认为新CPI略大于1）得出的干扰项，或者是计算 $1.6 / (1/2 + \text{overhead})$ 的错误结果。但在标准错误中，更常见的错误是选D。
- **选项C**: [干扰] — 针对错误认知：可能混淆了加速比的定义，或者在计算周期时间时出错。例如，若错误地认为新处理器的周期时间是 $1/2.5$（沿用旧频率），则新时间为 $0.4$，加速比 $1.6/0.4=4$（无此选项）。若错误地认为旧CPI为1，新CPI为1，频率比 $2.5/2=1.25$，也不对。C选项2.2可能是随机干扰或特定错误计算路径（如 $1.6 / (1/2 + 0.2)$?）。
- **选项D**: [干扰] — 针对错误认知：最常见的错误是忽略流水线CPI变为1的事实，或者错误地认为加速比仅由频率决定。如果学生认为加速比 = 旧频率/新频率 = $2.5/2 = 1.25$（无此选项）。另一种常见错误是认为加速比 = 旧CPI/新CPI = $4/1 = 4$（无此选项）。若学生错误地认为新处理器的CPI仍然是4（即流水线没有提高CPI，只改变了频率），则加速比 = $(4 \times 0.4) / (4 \times 0.5) = 1.6/2.0 = 0.8$（无此选项）。
    *修正分析*：让我们重新审视常见错误。
    错误1：忽略频率变化，只看CPI。加速比 = $4/1 = 4$。
    错误2：忽略CPI变化，只看频率。加速比 = $2.5/2 = 1.25$。
    错误3：认为流水线CPI = 阶段数 = 5。新时间 = $5 \times 0.5 = 2.5$。加速比 = $1.6 / 2.5 = 0.64$。
    错误4：计算错误。$1.6 / 0.5 = 3.2$。
    选项D (2.0) 可能是这样得出的：假设学生错误地认为新处理器的周期时间是 $1/2.5$ (0.4ns)，且CPI=1，则新时间0.4，加速比4。不对。
    假设学生认为旧时间 = $1/2.5 = 0.4$ (忽略CPI=4)，新时间 = $1/2 = 0.5$ (CPI=1)，加速比 $0.4/0.5 = 0.8$。
    假设学生认为旧时间 = $4/2.5 = 1.6$，新时间 = $5/2 = 2.5$ (CPI=5)，加速比 $0.64$。
    实际上，选项D (2.0) 可能对应于：加速比 = 旧CPI / (新CPI * 频率比) ? 不太像。
    更有可能的是，D选项是针对那些认为“流水线加速比最大为阶段数5”或者简单地将频率比和CPI比进行某种错误线性组合的学生。例如，若学生误算新周期为 $1/2.5$ (0.4ns)，且认为新CPI为1，则新时间0.4，加速比4。
    让我们看一个可能的错误路径得到2.0：如果学生认为新处理器的CPI是2（错误假设），则新时间 $2 \times 0.5 = 1.0$，加速比 $1.6/1.0 = 1.6$。
    如果学生认为旧CPI是2，新CPI是1，频率不变，加速比2。
    无论如何，D是一个典型的低值干扰项，吸引那些计算混乱或概念不清的考生。

- **干扰策略**: 概念混淆（流水线CPI的含义）与计算陷阱（频率与周期的倒数关系）。

## 核心陷阱
- **核心陷阱**: **流水线CPI的取值**。许多初学者容易误以为流水线处理器的CPI等于流水线的级数（本题为5），或者忽略在“无停顿”的理想假设下，流水线处理器的CPI趋近于1。此外，另一个陷阱是**时钟频率与周期时间的倒数关系**，考生需准确计算 $T_{cycle} = 1/f$，并注意频率降低导致周期变长，这会抵消部分流水线带来的性能提升。

## 考察能力
本题核心考察考生对**流水线性能评估模型**的理解，特别是能够准确区分并计算非流水线与流水线处理器在**不同时钟频率**下的指令执行时间，并据此计算加速比的能力。
