# 练习题 Q1 — CSMA/CD协议适用性与局限性

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/数据链路层
- **难度**: 待评估

## 题干原文
关于 CSMA/CD 的以下陈述中，哪一项是正确的？（ ）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握 CSMA/CD 的核心定义及其适用场景（以太网），以及 IEEE 802.11（无线局域网）使用的协议（CSMA/CA）。这属于标准的基础概念记忆，不涉及复杂辨析，但需准确区分有线与无线局域网的介质访问控制协议差异。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全基于定性分析。
- **K3 = 2**: 评分理由。虽然不需要多步串行推演，但理解选项 C 需要简单的逻辑链条：高传播延迟 -> 冲突检测时间窗口变大 -> 最小帧长需增加 -> 效率降低/不可行。这是一个两步的逻辑关联，而非直接记忆。
- **K4 = 3**: 评分理由。存在隐含前提和易混淆点。学生必须意识到“卫星网络”代表“高传播延迟”这一物理特性，并理解 CSMA/CD 对“实时冲突检测”的依赖。选项 A 和 B 是常见的概念混淆陷阱（有线vs无线，传统以太网vs现代以太网），需要避开这些暗坑。
- **K5 = 1**: 评分理由。本题仅涉及数据链路层的介质访问控制子层，未涉及网络层、传输层或其他子系统的状态传递或耦合。
- **雷达形状**: K1-K4 均衡偏概念型，K2 极低。呈现为“概念辨析型”雷达图，无明显计算峰值，但在 K4（条件识别）上有一定要求。

## 考察模式
- **模式**: 概念型
- **理由**: 题目主要考察对 CSMA/CD 协议工作原理、适用范围及其局限性的定性理解，而非定量计算或复杂机制推演。重点在于区分不同网络环境（有线/无线、低延迟/高延迟）下的协议选择。

## 选项级分析
- **选项A**: [干扰] — 针对“所有局域网都使用相同协议”的错误认知。IEEE 802.11 是无线局域网标准，由于无线信道的半双工特性及隐藏终端问题，无法有效进行冲突检测（CD），因此使用 CSMA/CA（载波监听多路访问/冲突避免）。这类学生可能混淆了 802.3（以太网）和 802.11（Wi-Fi）的标准。
- **选项B**: [干扰] — 针对“现代以太网已不再使用 CSMA/CD”的片面认知。虽然全双工交换式以太网中 CSMA/CD 实际上被禁用，但从协议标准和历史渊源来看，以太网（IEEE 802.3）的核心定义确实基于 CSMA/CD。说“不基于”在概念上是错误的，因为它是该协议族的基石。这类学生可能只关注了当前全双工环境的现状，忽略了协议定义的根源。
- **选项C**: [正确] — 正确陈述。CSMA/CD 的核心机制是“边发送边监听”，一旦检测到冲突立即停止。这要求发送方在发送完整个帧之前，必须能收到冲突信号。如果传播延迟极高（如卫星网络，往返延迟约 270ms），为了检测冲突，帧长必须极长（最小帧长 = 2 * 传播延迟 * 带宽），导致信道利用率极低，甚至不可行。
- **选项D**: [干扰] — 针对“CSMA/CD 能完全避免冲突”的错误认知。CSMA/CD 只能“检测”并“处理”冲突，不能“避免”冲突。竞争（Contention）是随机接入协议的固有特性。这类学生可能将 CSMA/CA（冲突避免）与 CSMA/CD（冲突检测）的功能混淆。

- **干扰策略**: 概念混淆（A、D）与 现状与定义的偏差（B）。通过混淆有线/无线协议、检测/避免机制、以及协议定义与实际部署的差异来设置陷阱。

## 核心陷阱
- **核心陷阱**: 混淆 **CSMA/CD（冲突检测）** 与 **CSMA/CA（冲突避免）** 的适用场景，以及忽视 **传播延迟** 对 CSMA/CD 最小帧长和效率的决定性影响。特别是选项 A，极易让不熟悉无线局域网原理的学生误选。

## 考察能力
一句话概括本题核心考察的能力：
准确辨析不同介质访问控制协议（CSMA/CD vs CSMA/CA）的物理层依赖条件及其在高延迟网络中的局限性。
