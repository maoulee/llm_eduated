# 模拟题 Q综合题 — Cache地址映射、容量计算与命中率分析

## 基本信息
- **来源**: 模拟题  **题型**: 综合题
- **科目**: 计算机组成原理
- **知识点**: CO-3 > 高速缓冲存储器 Cache > Cache地址映射, CO-3 > 高速缓冲存储器 Cache > 命中率, CO-3 > 高速缓冲存储器 Cache > Cache基本概念
- **难度**: 待评估

## 题干原文
（11 分）某计算机的主存地址数为 16 位，按字节编址。假定数据 Cache 中最多存放 32 个主存块，采用 2-路组相联方式，块大小为 16B，每块设置了 1 位有效位。采用一次性写回策略，为此每块设置了 1 位“脏”位。请问：
（1）主存地址中标记（Tag）、组号（Index）和块内地址（Offset）三部分的位置和位数分别是多少？该数据 Cache 的总位数是多少？
（2）设字长为 4B，Cache 起始为空，CPU 从主存单元 0，1，…，99，依次读出 100 个字（主存一次读出一个字），并重复按此次序读 6 次，问命中率是多少？
（3）如果块表中组号为 10、行号为 1 的 Cache 块的标记为 36H，有效位为 1，则在 CPU 送来主存的字地址为 36A8H 时是否命中？若命中，此时 Cache 的字地址为多少？

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题需要调用多个核心概念：Cache地址映射结构（Tag/Index/Offset）、组相联映射规则、Cache总容量计算（包含标记位、有效位、脏位及数据位）、写回策略对标记项的影响。需辨析“字地址”与“字节地址”的区别，以及“块大小”与“字长”的关系，概念密度较高。
- **K2 = 3**: 评分理由。涉及多位数的二进制/十六进制转换、2的幂次计算（如$2^4=16$）、以及命中率的分步统计计算。虽然计算本身不复杂，但步骤较多，且第(3)问涉及十六进制地址的位域提取，容易因粗心算错。
- **K3 = 4**: 评分理由。第(2)问命中率计算需要多步推演：首先确定访问序列对应的块号，然后根据映射规则确定组号，接着模拟Cache状态变化（冷启动、替换策略隐含或显式），最后统计命中次数。第(3)问也需要从地址解析到组号、Tag比对的多步逻辑验证。
- **K4 = 4**: 评分理由。存在多个隐含前提和陷阱：1. “按字节编址”与“字长为4B”导致的地址偏移差异；2. 第(2)问中未明确说明替换算法（通常默认LRU或FIFO，但在2路组相联且块数多于组数时，若未发生冲突则不影响结果，需考生判断是否发生冲突）；3. 第(3)问中给出的是“字地址”而非“字节地址”，这是极大的陷阱，需考生意识到地址转换或位域对齐问题。
- **K5 = 2**: 评分理由。主要局限于Cache子系统内部，涉及主存地址到Cache地址的映射，属于单向数据流分析，未涉及CPU流水线、中断或其他子系统的深度耦合。
- **雷达形状**: 偏向于“分析推导型”的不规则五边形，K1、K3、K4较高，K2中等，K5较低。

## 考察模式
- **模式**: 计算推导型
- **理由**: 题目要求通过给定的硬件参数（地址位数、块大小、路数等）进行具体的数值计算（地址划分、总位数）和状态模拟（命中率统计、地址命中判断），核心在于将抽象的Cache原理转化为具体的数值结果。

## 解题思路分析
- **核心思路**: 
    1. **地址结构分析**：根据块大小确定Offset位数，根据Cache总块数和路数确定组数及Index位数，剩余为Tag位数。
    2. **容量计算**：Cache总位数 = (Tag + 有效位 + 脏位) × 总块数 + 数据位 × 总块数。注意数据位需按字节或位计算。
    3. **命中率模拟**：将访问序列转换为块号，映射到组号，模拟Cache加载过程，统计命中与未命中。注意字地址到块号的转换。
    4. **地址命中判断**：解析给定地址的Tag、Index、Offset，与Cache中对应位置的内容进行比对。特别注意“字地址”与“字节地址”的转换。

- **关键步骤**:
    1. **第(1)问**：
       - 块大小16B $\rightarrow$ Offset = $\log_2 16 = 4$位。
       - 总块数32，2路组相联 $\rightarrow$ 组数 = $32/2 = 16$ $\rightarrow$ Index = $\log_2 16 = 4$位。
       - 主存地址16位 $\rightarrow$ Tag = $16 - 4 - 4 = 8$位。
       - 标记项位数 = Tag(8) + 有效位(1) + 脏位(1) = 10位。
       - 数据位数 = 16B $\times$ 8bit/B = 128bit。
       - 总位数 = $32 \times (10 + 128) = 32 \times 138 = 4416$位。
    2. **第(2)问**：
       - 字长4B，块大小16B $\rightarrow$ 每块包含 $16/4 = 4$个字。
       - 访问字0~99，共100个字。
       - 块号计算：字地址 $W$ 对应的块号 $B = \lfloor W / 4 \rfloor$。
       - 访问序列对应的块号：0, 0, 0, 0 (字0-3), 1, 1, 1, 1 (字4-7), ..., 24, 24, 24, 24 (字96-99)。
       - 涉及的块号范围：0 ~ 24，共25个不同的块。
       - 映射到组号：$Group = Block \pmod{16}$。
       - 块0~15映射到组0~15，块16~24映射到组0~8。
       - 由于是2路组相联，每组最多容纳2个块。
       - 检查冲突：
         - 组0：块0, 16, 32(无)... 只有块0和16。2路足够，无替换。
         - 组1：块1, 17。2路足够。
         - ...
         - 组8：块8, 24。2路足够。
         - 组9~15：只有块9~15。1路占用，无冲突。
       - 结论：所有25个块都能装入Cache，不会发生替换丢失。
       - 第一次访问：25个块未命中，后续75个字命中（因为块已在Cache中）。第一次命中率 = $75/100 = 75\%$。
       - 后续5次访问：Cache已满且无替换，全部命中。每次命中率 = $100\%$。
       - 总命中率 = $(75 + 100 \times 5) / (100 \times 6) = 575 / 600 \approx 95.83\%$。
       - *修正思考*：题目问“重复按此次序读6次”，通常指总共读6遍。第一遍有未命中，后5遍全命中。
       - 总访问次数：$100 \times 6 = 600$次。
       - 未命中次数：仅在第一遍的前25个块的首次访问时未命中，共25次。
       - 命中次数：$600 - 25 = 575$次。
       - 命中率：$575 / 600 = 23/24 \approx 95.83\%$。
    3. **第(3)问**：
       - 给定Cache块：组号10，行号1，Tag=36H，有效位1。
       - 给定CPU地址：字地址 36A8H。
       - **陷阱**：题目说“主存地址数为16位，按字节编址”，但第(3)问给的是“字地址”。通常字地址需要转换为字节地址才能与Cache的字节编址地址结构匹配，或者题目隐含字地址直接对应某种对齐后的地址。
       - 假设“字地址 36A8H”是指逻辑上的字编号，还是指字节地址的高位？
       - 常规理解：若按字节编址，地址是字节地址。若题目明确说“字地址”，通常意味着 $ByteAddr = WordAddr \times 4$。
       - 字节地址 = $36A8H \times 4 = 36A8H \ll 2 = E9A0H$ (16位地址，溢出？$36A8H$是16位，乘以4可能超过16位？$36A8H = 14392$，$\times 4 = 57568 > 65535$? 不，$36A8H$是十六进制，$3 \times 16^3 + ...$。$36A8H$作为16位地址是合法的。$36A8H \times 4$ 需要18位，超出16位主存地址空间。这说明“字地址 36A8H”很可能指的是**字节地址**，或者题目中的“字地址”表述有误，实际指代的是主存地址（字节地址）。
       - **重新审视题意**：408真题中常出现“字地址”与“字节地址”的混淆。如果主存地址是16位，最大地址FFFFH。36A8H在范围内。如果36A8H是字地址，字节地址为 $36A8H \times 4 = E9A0H$，仍在16位范围内（$E9A0H < FFFFH$）。
       - 让我们按**字节地址 = 36A8H** 来试算（常见陷阱是考生直接拿字地址当字节地址，或者反之）。
       - 若地址为字节地址 36A8H：
         - 二进制：0011 0110 1010 1000
         - Offset (低4位): 1000 (8)
         - Index (中间4位): 1010 (10) $\rightarrow$ 组号10。匹配！
         - Tag (高8位): 0011 0110 (36H)。匹配！
         - 结论：命中。
       - 若地址为字地址 36A8H，则字节地址为 E9A0H：
         - 二进制：1110 1001 1010 0000
         - Offset: 0000
         - Index: 1010 (10) $\rightarrow$ 组号10。匹配！
         - Tag: 1110 1001 (E9H) $\neq$ 36H。不命中。
       - **关键判断**：题目问“若命中...”，暗示可能命中。且第(2)问中“主存单元0,1...99”通常指字单元。但在地址映射中，Cache通常按字节编址。如果题目严格区分“字地址”和“字节地址”，且给出字地址，必须转换。但转换后Tag不匹配。如果题目中的“字地址”其实是笔误，意指“主存地址（字节地址）”，则命中。
       - 参考解析中通常这类题目若未强调转换，且Tag直接对应高位，往往暗示直接比对。但严谨来说，**字地址需转字节地址**。
       - 然而，观察Tag=36H。如果字节地址是36A8H，Tag是36H。如果字节地址是E9A0H，Tag是E9H。
       - 再看Cache块信息：Tag=36H。
       - 如果题目意图是考察字地址转换，那么答案是不命中。
       - 如果题目意图是考察直接映射，答案是命中。
