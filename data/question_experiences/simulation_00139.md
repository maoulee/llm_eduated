# 模拟题 Q1 — 计算机性能指标辨析

## 基本信息
- **来源**: 模拟题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机性能评价（MIPS, CPI, 主频, 执行时间）
- **难度**: 中等

## 题干原文
以下有关计算机机运算速度衡量指标的描述中，正确的是（ ）。
A: MIPS 大的机器一定比 MIPS 小的机器快
B: CPU 的主频越高速度越快
C: 执行不同的程序，测得的同一台计算机的 CPI 可能不同
D: CPU 执行程序的时间就是观测到用户程序的执行时间

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题需要辨析 MIPS、CPI、主频、执行时间四个核心概念的定义及其局限性。不仅仅是记忆定义，还需要理解这些指标在不同架构、不同程序负载下的相对关系，属于对易混概念的深度辨析。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算，无需进行公式代入或单位换算。
- **K3 = 2**: 评分理由。推理步骤较少，主要基于概念定义的直接逻辑判断。例如判断 C 选项只需知道 CPI 依赖于指令混合（Instruction Mix），而指令混合随程序变化，即可得出结论，无需多步串行推演。
- **K4 = 3**: 评分理由。存在明显的“绝对化”陷阱（如 A 选项的“一定”，B 选项的隐含绝对性）。考生需要识别出“指标高不代表整体性能高”这一隐含前提，避开表面直觉的误导。
- **K5 = 2**: 评分理由。主要涉及 CPU 性能评价子系统内部的概念关系，虽然涉及程序特性对硬件指标的影响，但不需要跨越操作系统、内存管理等其他子系统进行复杂的状态传递分析。
- **雷达形状**: K1 认知主导型，K4 陷阱防御型。整体呈现概念辨析特征，计算需求极低。

## 考察模式
- **模式**: 概念型
- **理由**: 题目核心在于考察对计算机性能评价指标（MIPS, CPI, 主频, 时间）定义、适用范围及局限性的理解，而非通过计算得出结果。

## 选项级分析
- **选项 A**: [干扰] — 针对“指标数值越大性能越好”的线性思维误区。这类学生往往忽略了 MIPS 是基于特定指令集的指标，不同指令集（如 RISC vs CISC）的指令复杂度不同，MIPS 高可能只是因为指令简单，实际完成的任务量未必大。
- **选项 B**: [干扰] — 针对“主频决定一切”的过时或片面认知。这类学生忽略了 CPU 性能还取决于 IPC（每周期指令数）、流水线效率、缓存命中率等架构因素。高主频低 IPC 的 CPU 可能不如低主频高 IPC 的 CPU。
- **选项 C**: [正确] — 针对对 CPI 动态特性的理解。CPI（Cycles Per Instruction）是平均每条指令所需的时钟周期数。由于不同程序的指令混合（Instruction Mix）不同（例如有的程序访存多，有的程序计算多），且流水线冲突、缓存缺失情况不同，导致同一台机器运行不同程序时，CPI 确实会不同。
- **选项 D**: [干扰] — 针对对“执行时间”构成理解的缺失。这类学生忽略了操作系统开销、中断处理、I/O 等待时间等。CPU 执行时间通常指 CPU 实际花费在程序上的时间，而用户观测到的时间（Wall-clock time）还包括 I/O 等待和其他进程占用的时间，两者通常不相等。
- **干扰策略**: 概念混淆与绝对化陷阱。利用考生对单一指标（MIPS, 主频）的片面理解，设置“一定”、“越快”等绝对化表述，诱导选择看似合理但逻辑不严谨的选项。

## 核心陷阱
- **核心陷阱**: **指标的相对性与绝对性能的混淆**。考生容易将单一性能指标（如 MIPS 或主频）的数值大小直接等同于计算机整体运算速度的快慢，而忽略了架构差异、指令集差异、程序负载差异以及系统开销的影响。

## 考察能力
本题核心考察考生对计算机性能评价指标（MIPS, CPI, 主频, 执行时间）定义、局限性及其相互关系的综合辨析能力，特别是识别“单一指标不能代表整体性能”这一关键逻辑的能力。
