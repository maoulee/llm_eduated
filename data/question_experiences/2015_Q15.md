# 2015年 Q15 — Cache总容量计算(包含标记阵列)

## 基本信息
- **年份**: 2015  **题位**: Q15  **题型**: 选择题
- **知识点**: Cache直接映射地址划分、Cache行结构组成（Tag/Valid/Dirty/Data）、写策略对Cache结构的影响、容量单位换算
- **考纲对应**: 第三章 存储器层次结构 → Cache → 写策略（回写/直写）与结构、Cache性能计算

## 题干原文
[2015年考研真题第15题]假定主存地址为32位，按字节编址，主存和Cache之间采用直接映射方式，主存块 大小为4个字，每字32位，采用回写(Write Back)方式，则能存放4K字数据的Cac

## K1-K5 评分与解析
- **K1 = 4**: 4 — **理由**：考生必须精准记忆 Cache 总容量的构成公式：$C_{total} = C_{data} + C_{tag} + C_{valid} + C_{dirty}$。其中，`Dirty bit`（脏位）的存在强依赖于写策略（Write Back vs Write Through），这是极易混淆的冷门细节。若仅记忆“标记+数据”，则无法得分。
- **K2 = 3**: 3 — **理由**：涉及多级单位换算（字->字节->位->Kb）和非2的幂次或复杂位宽相加（128K + 16K + 2K + 2K = 148K）。计算步骤虽不极度繁杂，但需处理“32位地址”、“4字块”、“回写”等多个参数的组合运算，稍有疏忽（如忘记字节编址对位宽的影响）即错。
- **K3 = 2**: 2 — **理由**：推演路径单一且短：确定块数 -> 确定每行容量 -> 求和。无需多步串行状态更新或复杂流程推演。
- **K4 = 3**: 3 — **理由**：存在明确的陷阱词“回写(Write Back)”。若考生忽略此条件，默认使用直写（无脏位）或通用模型，则会漏算 Dirty Bit。这是典型的“不触发特定机制就用错公式”的陷阱。
- **K5 = 1**: 1 — **理由**：题目完全在 Cache 子系统内部解决，不涉及 CPU、指令流水线、总线或其他存储层级（如主存、磁盘）的跨域联动。
- **雷达形状**: K4陷阱型 (侧重细节条件路由)

## 考察模式
- **模式**: 计算型
- **理由**: 题干给定具体参数，选项为具体的数值结果，考察基于原理的正确计算能力。

## 选项级分析
- **选项A**: [干扰] — **针对认知错误**：漏加了“脏位（Dirty Bit）”。**学生画像**：知道 Cache 有标记和数据，但忽略了“回写”策略需要额外一位来记录数据是否被修改，或者混淆了直写（Write Through）与回写的区别。
- **选项B**: [干扰] — **针对认知错误**：计算偏差或漏算“有效位（Valid Bit）”。**学生画像**：可能误以为有效位包含在 Tag 中，或者在位宽换算时出现 1bit/8bit/1024 进位错误。
- **选项C**: [正确] — **针对正确认知**：准确识别 Cache 总容量 = 数据容量 + 标记阵列容量（Tag + Valid + Dirty）。计算过程严谨，考虑了回写带来的脏位开销。
- **选项D**: [干扰] — **针对认知错误**：多加了“替换算法位”。**学生画像**：误以为直接映射（Direct Mapped）也需要 LRU 等替换算法的额外标识位，或者将间接映射/全相联映射的复杂性错误迁移到直接映射中（直接映射无替换选择，故无需替换算法位）。
- **干扰策略**: 并行陷阱（各干扰项独立）

## 考察能力
考察考生对 Cache 物理结构组成细节的精确记忆，以及在特定写策略下动态构建容量计算模型的能力。
