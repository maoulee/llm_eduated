# 2015年 Q15 — Cache总容量计算(包含标记阵列)

## 基本信息
- **年份**: 2015  **题位**: Q15  **题型**: 选择题
- **知识点**: Cache组织结构, Cache地址映射(直接映射), Cache写策略(写回/写直达), Cache容量计算
- **考纲对应**: 计算机组成原理 -> 存储系统 -> 高速缓冲存储器 Cache -> Cache地址映射与写策略

## 题干原文
[2015年考研真题第15题]假定主存地址为32位，按字节编址，主存和Cache之间采用直接映射方式，主存块 大小为4个字，每字32位，采用回写(Write Back)方式，则能存放4K字数据的Cac

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆Cache行的完整组成结构（Tag, Valid, Dirty, Data），特别是“脏位（Dirty Bit）”仅在回写策略下存在这一核心概念。若仅知Cache存储数据，无法解题；若概念模糊（如不知道有效位/脏位占1位），无法计算。高于2（仅知名词），低于4（无需辨析极冷门细节，但需精准记忆“回写”带来的额外开销）。
- **K2 = 3**: 3 — 需进行多步单位换算和加法计算：将“4K字”转换为字节/位，计算Block Size，计算Block数量，计算Tag位数，最后累加所有字段的总容量。涉及K（1024）与非2的幂次（32位地址、4字块）的混合运算，数字虽不复杂但步骤较多，非一步心算可成。
- **K3 = 2**: 2 — 推导路径唯一且固定：确定Cache容量 -> 确定行数 -> 确定地址字段划分 -> 计算每行开销 -> 汇总。属于标准的“说明书”式流程，只需2-3步逻辑串联，不涉及动态状态更新或长程推演。
- **K4 = 4**: 4 — **核心陷阱**。题干明确给出“回写(Write Back)方式”，这是触发“脏位”存在的隐含前提。许多考生习惯性地只计算Data+Tag+Valid，或者误以为直接映射不需要复杂替换算法位（虽然直接映射确实不需要LRU位，但干扰项D常利用此点）。必须深刻理解“写策略”对Cache硬件结构（位宽）的影响，否则极易漏算Dirty Bit，落入陷阱。
- **K5 = 1**: 1 — 单一知识点内部解决，仅涉及Cache子系统的内部结构计算，不涉及CPU指令流、主存物理地址映射或其他子系统交互。
- **雷达形状**: K4陷阱型（高条件路由需求）

## 考察模式
- **模式**: 计算型
- **理由**: 题干给出明确的硬件参数（地址位数、块大小、映射方式、写策略、Cache总数据量），要求通过多步计算得出唯一的数值结果，4个选项为不同的计算值。

## 选项级分析
- **选项A**: [干扰] — **漏加脏位**。针对认知错误：忽略了“回写策略”需要在Cache行中设置Dirty Bit（通常1位）来标记数据是否被修改。这类学生通常只计算了 Data + Tag + Valid，或者误认为直接映射不需要Dirty位。这是本题最常见的错误选项（对应原题中的128KB或类似数值）。
- **选项B**: [干扰] — **计算偏差或漏加有效位**。针对认知错误：可能在计算Tag位数时出错（如未考虑主存块内偏移），或者遗漏了Valid Bit（有效位）。这类学生基础概念有缺失，对Cache行的基本字段（Valid是必须的）认识不清。
- **选项C**: [正确] — **正确计算**。包含了 Data容量 + Tag阵列容量 + Valid阵列容量 + Dirty阵列容量。准确识别了回写策略带来的Dirty Bit开销，并正确进行了位宽和数量的乘法累加。
- **选项D**: [干扰] — **多余加上替换算法位**。针对认知错误：误以为即使是直接映射也需要LRU位等替换算法位，或者混淆了组相联与直接映射的区别。直接映射中，主存块固定映射到Cache行，无需维护复杂的替换历史信息，因此不需要LRU位。这类学生可能机械记忆“Cache行包含替换算法位”，未根据映射方式动态调整。
- **干扰策略**: 并行陷阱（各干扰项独立）

## 核心陷阱
- **核心陷阱**: **“回写策略”隐含的Dirty Bit开销** 与 **直接映射无需LRU位** 的双重约束。
- **错误路径**: 学生容易记住Cache容量 = Data + Tag，但往往忘记Valid Bit和Dirty Bit。特别是在看到“直接映射”时，可能下意识排除LRU位（正确），但在“回写”条件下，未能激活“需要Dirty Bit”的知识节点，导致漏算。反之，若题目是“全相联+写回”，则需考虑LRU，此题通过“直接映射”排除了LRU，通过“写回”引入了Dirty，考察学生对不同配置下Cache行结构的动态组合能力。

## 考察能力
本题考察考生对Cache微架构细节的精准掌握，特别是不同写策略（Write Back vs Write Through）和映射方式（Direct Mapped vs Set Associative）对Cache硬件资源（位宽、控制位）的具体影响及综合计算能力。
