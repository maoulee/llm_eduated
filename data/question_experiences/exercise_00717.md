# 练习题 Q1 — 异步串行通信帧结构与波特率计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机网络/数据链路层
- **难度**: 待评估

## 题干原文
假设每个字符编码由 8 位组成。通过异步串行线路以 2400 波特率和两个停止位每秒可传输的字符数是（ ）
A: 109
B: 216
C: 218
D: 219

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握异步串行通信的基本帧结构概念（起始位、数据位、停止位、校验位）。如果不记忆“异步通信默认包含1位起始位”这一核心定义，无法解题。属于标准的基础概念记忆需求。
- **K2 = 3**: 评分理由。涉及简单的除法运算 $2400 / 11$。虽然计算量不大，但结果不是整数，需要考生理解“向下取整”的物理意义（即只能传输完整的字符），且除数11非2的幂次，属于标准的单步代入计算。
- **K3 = 1**: 评分理由。逻辑链条极短：确定帧长 -> 总速率除以帧长 -> 取整。无需多步串行推演或状态记忆。
- **K4 = 3**: 评分理由。存在隐含前提陷阱。题干未明确说明“起始位”和“校验位”，但根据异步通信标准协议，必须默认包含1位起始位，且未提及校验位时默认为无校验。若考生忽略起始位或误加校验位，会导致错误。属于常规注意点但易被忽略的陷阱。
- **K5 = 1**: 评分理由。仅涉及数据链路层/物理层的单一通信机制，无需跨越不同子系统（如CPU、内存、I/O控制器之间）进行状态传递或联动分析。

- **雷达形状**: K4陷阱型（K1、K2、K4较高，K3、K5较低，呈现中间凹陷或特定维度突出的形态，主要难点在于对隐含条件的识别）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过给定的参数（波特率、数据位、停止位）构建数学模型，计算有效吞吐量。虽然涉及概念，但最终落脚点在于数值计算。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：误以为帧结构包含更多开销位（如误加了2位校验位，或误以为起始位为2位等，导致分母变大，如 $2400/22 \approx 109$）。这类学生可能对异步帧结构记忆混乱，或者混淆了同步与异步的区别。
- **选项B**: [干扰] — 针对错误认知：忽略了起始位。计算过程为 $2400 / (8+2) = 240$，接近216但不对；或者误算为 $2400 / 11 \approx 218$ 但计算错误；更可能是误以为只有数据位和停止位，且计算失误。实际上，若忽略起始位，分母为10，$2400/10=240$，此选项数值216较难直接通过常见错误得出，可能是随机干扰或基于 $2400/11.11$ 等错误逻辑。*修正分析*：若考生误以为波特率等于比特率且未考虑起始位，直接 $2400/8 = 300$ 也不对。216 可能是 $2400 / 11.11$ 的误算，或者是基于其他错误帧长（如11.1位？）的干扰。更可能的错误路径是：考生记得有起始位，但记错停止位数量或数据位数量。
- **选项C**: [正确] — 正确计算：帧长 = 1(起始) + 8(数据) + 2(停止) = 11位。字符数 = $2400 / 11 \approx 218.18$，向下取整为 218。
- **选项D**: [干扰] — 针对错误认知：四舍五入错误。计算结果 218.18，若考生直接四舍五入或向上取整，会得到 218 或 219。在通信中，不完整的帧无法被正确接收，必须向下取整。选D的学生忽略了物理传输的完整性约束。

- **干扰策略**: 计算陷阱（四舍五入 vs 向下取整）与 概念混淆（是否包含起始位/校验位）。

## 核心陷阱
- **核心陷阱**: **隐含的起始位**与**向下取整原则**。
    1. 题干未明确写出“1位起始位”，但异步通信协议强制要求，考生需主动补全这一知识。
    2. 计算结果 $218.18$ 必须向下取整为 $218$，因为第219个字符无法在1秒内完整传输（缺少0.18个字符的时间/位数），不能四舍五入。

## 考察能力
本题核心考察考生对异步串行通信帧结构的完整理解（特别是隐含的起始位）以及在物理层速率计算中处理非整数结果的实际工程逻辑（向下取整）。
