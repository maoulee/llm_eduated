# 练习题 Q1 — 传输层协议与网络层路由的独立性

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/传输层
- **难度**: 待评估

## 题干原文
同一会话的数据包可能通过不同路径路由的是（ ）

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握 TCP 和 UDP 的基本定义（面向连接 vs 无连接），以及 IP 层路由的基本概念。不是 4 分因为不需要辨析极其细微的协议头部字段差异，只需理解协议本质属性。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，属于纯概念判断。
- **K3 = 2**: 评分理由。推演步骤较少：1. 识别 TCP/UDP 属于传输层；2. 识别路由属于网络层功能；3. 判断网络层路由是否受传输层协议类型限制。逻辑链条短，无需多步串行推演。
- **K4 = 4**: 评分理由。存在显著的隐含前提和反直觉陷阱。许多学生容易将“TCP 面向连接”误解为“物理路径固定”或“逻辑通道固定”，从而忽略 IP 层的动态路由特性。解题必须意识到“连接”是传输层的逻辑概念，而“路由”是网络层的物理/逻辑转发行为，两者解耦。这是一个典型的“概念边界混淆”陷阱。
- **K5 = 3**: 评分理由。需要跨越传输层（TCP/UDP）和网络层（IP 路由）两个子系统。虽然不需要深度耦合的状态传递，但必须理解网络层对传输层是透明的，且网络层的路由决策独立于传输层协议类型。

- **雷达形状**: K4 陷阱型（K4 显著高于其他维度，K2 极低）

## 考察模式
- **模式**: 概念型
- **理由**: 题目核心在于考察对 TCP/UDP 协议特性与 IP 路由机制之间关系的概念理解，而非计算或复杂逻辑推理。重点在于澄清“面向连接”不等于“固定路径”这一常见误区。

## 选项级分析
- **选项 A**: [干扰] — 针对“TCP 是面向连接的，所以路径固定”的错误认知。这类学生混淆了“逻辑连接”与“物理路径”，认为建立连接后就像打电话一样线路固定，忽略了 IP 网络的无连接特性和动态路由。
- **选项 B**: [正确] — TCP 和 UDP 都运行在 IP 之上，IP 层根据路由表独立转发每个数据包。无论上层是 TCP 还是 UDP，只要目的 IP 相同，网络层都可能因负载均衡、链路故障恢复等原因选择不同路径。
- **选项 C**: [干扰] — 针对“UDP 是无连接的，所以路径随意；TCP 有连接，所以路径固定”的片面认知。这类学生正确理解了 UDP 的特性，但错误地将 TCP 的可靠性机制等同于路径固定。
- **选项 D**: [干扰] — 针对完全否定 IP 路由动态性的极端错误认知，或者认为所有网络通信都走固定专线。

- **干扰策略**: 概念混淆（利用“面向连接”的字面意思误导考生认为路径固定）

## 核心陷阱
- **核心陷阱**: 混淆“传输层的逻辑连接”与“网络层的物理/逻辑路径”。考生容易误以为 TCP 的“连接”意味着端到端之间建立了一条固定的、独占的通信通道，从而排除了多路径路由的可能性。实际上，TCP 的连接是主机进程间的逻辑关系，底层 IP 数据包依然遵循网络层的动态路由规则。

## 考察能力
一句话概括本题核心考察的能力：区分传输层协议特性（连接性）与网络层路由机制（动态性）的解耦关系，破除“面向连接即固定路径”的认知误区。
