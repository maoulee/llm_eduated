# 2018年 Q18 — 变址寻址地址计算

## 基本信息
- **年份**: 2018  **题位**: Q18  **题型**: 选择题
- **知识点**: 变址寻址机制, 数组内存布局, 十六进制与十进制转换, 数据类型字节对齐
- **考纲对应**: 第四章 指令系统 → 寻址方式

## 题干原文
[2018年考研真题第18题]按字节编址的计算机中，某double 型数组A的首地址为2000H,使用变址寻址和循环结构访问数组A,保存数组下标的变址寄存器初值为0，每次循环取一个数组元素，其偏移地址

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆“变址寻址”中变址寄存器存储的是“索引值（元素个数）”而非“字节偏移量”，以及 `double` 类型的固定字节长度（8字节）。若不清楚变址寄存器的语义（存索引 vs 存地址），无法入题；高于2分是因为概念混淆会导致全盘错误，低于4分是因为不涉及冷门细节。
- **K2 = 3**: 3 — 涉及十六进制减法（2100H - 2000H = 100H）、十六进制到十进制的转换（0x100 = 256）、以及整数除法（256 / 8 = 32）。虽然数字友好，但包含进制转换和单位（字节）换算两个非平凡步骤，属于标准计算难度。
- **K3 = 1**: 1 — 无需多步串行推演。一旦明确了公式 $Index = (TargetAddr - BaseAddr) / ElementSize$，直接代入即可得出结果，没有复杂的流程或状态更新。
- **K4 = 3**: 3 — 存在明确的陷阱词“double型”和“变址寻址”。若忽略数据类型大小，会直接用字节偏移量作为答案；若误解变址寻址机制，可能认为变址寄存器存的是物理地址。不触发这些注意点就会用错逻辑。
- **K5 = 2**: 2 — 题目仅涉及指令系统（寻址方式）和数据结构（数组元素大小）的名词关联，无实际的数据流在多个硬件子系统（如Cache、CPU、IO）间传递或状态交互。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给出具体地址和类型参数，四个选项均为数值计算结果，考察核心在于正确执行地址计算和单元换算公式。

## 选项级分析
- **选项A**: [干扰] — 针对“忽略数据类型所占字节数”。学生计算出字节偏移 100H = 256，误以为变址寄存器存放的就是字节偏移量，直接选256。
- **选项B**: [正确] — 正确执行了：偏移量(256) / 元素大小(8) = 32。
- **选项C**: [干扰] — 针对“进制转换与计算混淆”。可能将 100H 误算或误处理，例如认为 100H=100(Dec)，100/8 取整或其他方式得出错误结果（如原题C选项可能是其他数值，参考分析提示为“算错倍数”或类似）。
- **选项D**: [干扰] — 针对“进制识别完全失败”。直接读取 `100H` 中的数字 `100`，忽略十六进制前缀，选100。
- **干扰策略**: 并行陷阱（各干扰项独立）

## 考察能力
本题考察考生对变址寻址机制本质的理解（索引与地址的换算）以及在混合进制环境下的精确计算与单位换算能力。
