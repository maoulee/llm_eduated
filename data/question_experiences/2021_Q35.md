# 2021 Q35 — IPv4子网划分与CIDR聚合逻辑

## 基本信息
- **年份**: 2021  **题位**: Q35  **题型**: 选择题
- **知识点**: CN-4 > IPv4 > 子网划分
- **题位域**: 待标注  **科目**: 计算机网络

## 题干原文
现将一个 IP 网络划分为 3 个子网，若其中一个子网是 192.168.9.128/26, 则下列网络中，不可能是另外两个子网之一的是（ ）
A: 192.168.9.0/25
B: 192.168.9.0/26
C: 192.168.9.192/26
D: 192.168.9.192/27

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握 CIDR 表示法、子网掩码与 IP 地址的二进制对应关系，以及“子网划分”的基本定义（即子网之间不能重叠，且通常源自同一个父网）。属于标准的基础概念记忆，无需辨析极度易混的高级概念，但必须准确理解 /26, /25 等前缀长度对应的地址块大小。
- **K2 = 2**: 评分理由。涉及简单的二进制位运算或十进制到二进制的转换（如 128=10000000, 192=11000000）。计算量极小，主要是判断地址块的起始和结束范围，属于 2 的幂次友好型计算，不易出错。
- **K3 = 3**: 评分理由。解题过程需要多步推演：1. 确定已知子网 192.168.9.128/26 的地址范围；2. 分析每个选项的地址范围；3. 判断选项与已知子网是否重叠；4. 判断剩余空间是否能构成合法的第三个子网（或整体是否构成合法的父网划分）。这是一个 3-5 步的逻辑串行过程。
- **K4 = 4**: 评分理由。存在隐含前提和陷阱。陷阱在于“划分为 3 个子网”并不意味着这 3 个子网必须大小相等，也不意味着它们必须能聚合回一个单一的 /24 或 /25 网络，而是要求它们**互不重叠**且**属于同一个原始网络**。特别是选项 A (192.168.9.0/25) 包含了 192.168.9.0-127，而题目给定的子网是 128-191，两者不重叠，看似可行，但需进一步验证是否还能分出第三个子网。更关键的陷阱是选项 B，它直接与已知子网在地址空间上虽然不重叠（0-63 vs 128-191），但需要考生意识到子网划分的层级结构。实际上，本题最核心的陷阱是**地址重叠检查**与**父网一致性**。选项 A 的 /25 覆盖了 0-127，已知子网是 128-191，剩余 192-255。如果选 A，剩下 192-255 可以作为一个子网（如 /26 或 /27 等），构成 3 个子网是可能的。选项 B 是 0-63，已知是 128-191，剩余 64-127 和 192-255。这里需要判断是否存在一个单一的“父网络”能同时包含这三个子网。通常子网划分是从一个大网切分。如果父网是 /24 (0-255)，B(0-63), 已知(128-191), 剩下 64-127 和 192-255 两块碎片，无法组成“另外两个子网之一”的语境（题目问的是“不可能是另外两个子网之一”，意味着我们要找那个导致无法形成合法 3 子网划分的选项，或者该选项本身与已知子网冲突）。
    *修正思考*：重新审视题目逻辑。题目说“划分为3个子网”，已知一个是 S1=128/26。问哪个**不可能**是 S2 或 S3。
    - 若选 A (0/25): S1(128-191), S2(0-127)。剩余 192-255。可以设 S3=192/26 (192-255)。此时 S1, S2, S3 互不重叠，且都在 192.168.9.0/24 内。合法。
    - 若选 B (0/26): S1(128-191), S2(0-63)。剩余 64-127 和 192-255。题目要求总共 3 个子网。如果 S2 是 0/26，那么剩下的空间是 64-127 (/26) 和 192-255 (/26)。如果我们选 S3 为 64/26，那么 192-255 怎么办？题目说“划分为3个子网”，通常隐含意思是**整个**原始网络被分成了这3块，没有剩余，或者这3块是主要部分。但在 408 语境下，通常指**无剩余**的完整划分，或者至少这3个子网必须能从一个父网通过二叉树方式切分出来。
    - 关键点：**子网划分必须遵循二叉树切分原则（无重叠，且边界对齐）**。
    - 让我们看 B 选项：S1=128/26, S2=0/26。这两个子网都是 /26。它们之间隔着一个 64/26。如果原始网络是 /24，切分方式通常是先切 /25 (0-127, 128-255)，再切 /26。
    - 如果 S1=128/26, S2=0/26。剩下的空间是 64-127 和 192-255。要凑成 3 个子网，必须把剩下的空间合并或再切。但 64-127 和 192-255 不连续，无法合并成一个子网。如果 S3 是 64/26，那 192-255 就剩下了，变成了 4 个子网（0/26, 64/26, 128/26, 192/26）。题目说“划分为3个子网”，暗示**恰好**3个。如果选 B，无论如何选 S3，要么剩下碎片（变成4个或更多），要么 S3 必须覆盖两个不连续区域（不可能）。因此 B 导致无法形成“恰好3个”的完整划分（除非允许剩余，但通常“划分为”暗示全覆盖）。
    - 再看 D (192/27): S1=128/26 (128-191), S2=192/27 (192-223)。剩余 0-127 和 224-255。同样，0-127 是一个完整的 /25。如果 S3=0/25，那么 224-255 (/27) 剩下。还是 4 个块？
    - 等等，让我们重新看 A。A: 0/25 (0-127)。S1: 128/26 (128-191)。剩余 192-255。S3 可以是 192/26 (192-255)。这样就是 0/25, 128/26, 192/26。这三个子网互不重叠，且并集为 0-255 (/24)。这是合法的 3 子网划分。
    - 看 C: 192/26 (192-255)。S1: 128/26 (128-191)。剩余 0-127。S3 可以是 0/25 (0-127)。同上，合法。
    - 看 D: 192/27 (192-223)。S1: 128/26 (128-191)。剩余 0-127 和 224-255。如果 S3 是 0/25 (0-127)，那 224-255 剩下。如果 S3 是 224/27，那 0-127 剩下。似乎 D 也会导致剩余？
    - **重新审视题目逻辑**：题目问“不可能是另外两个子网之一”。
    - 如果选 D，S1=128/26, S2=192/27。此时已用掉 128-223。剩余 0-127 和 224-255。
    - 如果原始网络不是 /24 呢？题目没说原始网络是 /24。只说“一个 IP 网络”。
    - 但是，子网划分必须基于**同一个父网**。
    - 对于 B: S1=128/26, S2=0/26。这两个子网的前 25 位分别是 `...00` 和 `...10` (最后8位)。它们属于同一个 /24。但是，它们之间夹着 64/26。如果父网是 /24，要分出 0/26 和 128/26，必须经过 /25 的切分。0/26 来自 0/25 的左半部分，128/26 来自 128/25 的左半部分。
    - 关键在于：**子网划分树必须是完整的二叉树切分吗？** 不一定，但子网地址必须对齐。
    - 让我们看 B 选项的致命伤：**地址重叠或包含关系？** 不，B (0-63) 和 S1 (128-191) 不重叠。
    - 让我们看 A 选项：A (0-127) 和 S1 (128-191) 不重叠。
    - 让我们看 D 选项：D (192-223) 和 S1 (128-191) 不重叠。
    - 为什么 B 不行？
    - 如果选 B (0/26)，S1 (128/26)。剩下的空间是 64-127 和 192-255。
    - 如果选 D (192/27)，S1 (128/26)。剩下的空间是 0-127 和 224-255。
    - 注意：题目说“划分为3个子网”。这意味着 **S1, S2, S3 的并集 = 原始网络**，且 **S1, S2, S3 互不相交**。
    - 对于 A: S1(128-191), S2(0-127). 并集 0-191. 剩余 192-255. S3 必须是 192-255 (即 192/26). 这样 S1, S2, S3 正好填满 /24. 可行。
    - 对于 C: S1(128-191), S2(192-255). 并集 128-255. 剩余 0-127. S3 必须是 0-127 (即 0/25). 这样 S1, S2, S3 正好填满 /24. 可行。
    - 对于 D: S1(128-191), S2(192-223). 并集 128-223. 剩余 0-127 和 224-255. 这两个剩余部分不连续，无法合并成一个子网 S3. 所以如果选 D，无法找到第三个子网 S3 使得三者填满一个连续的父网（除非父网更大，但那样会有更多剩余；或者父网更小，但 S1 和 S2 已经跨出了小父网）。等等，如果父网是 192.168.9.128/25 (128-255)?
        - 如果父网是 /25 (128-255). S1=128
