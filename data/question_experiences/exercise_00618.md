# 练习题 Q1 — 补码算术移位与溢出处理

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机组成原理/数制
- **难度**: 待评估

## 题干原文
P 是一个 16 位有符号整数。P 的二进制补码表示为 (F87B)₁₆。8×P 的二进制补码表示是（ ）：
A: (C3D8)₁₆
B: (187B)₁₆
C: (F878)₁₆
D: (987B)₁₆

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握补码的定义、十六进制与二进制的转换规则以及算术左移的基本概念。属于标准的基础概念记忆，不涉及复杂概念辨析。
- **K2 = 4**: 评分理由。虽然乘以8在理论上等同于左移3位，但本题中直接左移会导致溢出（符号位改变），因此不能简单通过移位得到结果。必须执行“转真值 -> 乘法运算 -> 转回补码”或“扩展位宽后移位再截断”的多级换算过程，计算量较大且容易出错。
- **K3 = 3**: 评分理由。解题路径清晰：识别溢出风险 -> 转换为十进制真值（或扩展位宽） -> 执行乘法 -> 转换回16位补码。大约需要3-4个逻辑步骤，属于中等推演难度。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。题面未直接说明“溢出”，但考生必须意识到 $8 \times P$ 超出了16位有符号整数的表示范围（$-32768 \sim 32767$）。如果忽略溢出直接移位，会得到错误答案。识别这一“暗坑”是解题关键。
- **K5 = 1**: 评分理由。本题仅涉及数据表示和算术运算，属于单一子系统（ALU/数据表示）内部的问题，不涉及跨模块（如存储、IO、控制单元）的状态传递。
- **雷达形状**: K4陷阱型（高K4，中高K2/K3，低K1/K5）。

## 考察模式
- **模式**: 综合型（计算+陷阱识别）
- **理由**: 本题不仅考察基本的数制转换和算术运算能力（计算型），更核心的是考察对计算机底层数据表示限制（溢出）的理解和处理（推理/陷阱识别）。单纯计算或单纯概念记忆都无法正确解题。

## 选项级分析
- **选项A**: [正确] — 正确答案。$P = -1925$，$8P = -15400$。$-15400$ 的16位补码为 $(C3D8)_{16}$。
- **选项B**: [干扰] — 针对“直接算术左移且忽略溢出/符号位错误”的错误认知。
    - 分析：$P = (F87B)_{16} = 1111\ 1000\ 0111\ 1011_2$。
    - 若直接左移3位：$1100\ 0001\ 1110\ 11000_2$（注意这里最低位补0）。
    - 如果考生错误地认为左移后高位丢弃，低位补0，可能会得到类似 $1100\ 0011\ 1101\ 1000$ 的变体，但选项B $(187B)_{16}$ 实际上是 $P$ 左移1位后的结果 $(1111\ 1000\ 0111\ 1011 \ll 1 = 1111\ 0000\ 1111\ 0110 = (F0F6)_{16}$? 不对，让我们重新检查B的来源)。
    - 重新推导B：$(187B)_{16} = 0001\ 1000\ 0111\ 1011_2$。这看起来像是 $P$ 的数值部分左移，或者某种错误的符号处理。更可能的情况是，这是 $P$ 左移1位后，如果发生溢出且处理不当产生的某种中间状态，或者是 $P$ 乘以2的结果但符号位处理错误。实际上，$P \times 2 = (F0F6)_{16}$。$P \times 4 = (E1EC)_{16}$。$P \times 8$ 若直接移位截断高位：$1111\ 1000\ 0111\ 1011 \ll 3 = 1100\ 0001\ 1110\ 11000$。取低16位为 $1000\ 0011\ 1101\ 1000 = (83D8)_{16}$。选项B $(187B)$ 可能是 $P$ 左移1位后，误将符号位当作数值位处理，或者完全无关的随机干扰。但在408真题风格中，B往往对应“左移1位”或“右移”的错误。此处B $(187B)$ 的二进制是 $0001\ 1000\ 0111\ 1011$，这恰好是 $P$ 的二进制 $1111\ 1000\ 0111\ 1011$ 左移1位后，如果忽略进位和符号扩展，仅看低16位且符号位被错误清零的情况？不，$P \ll 1 = 1111\ 0000\ 1111\ 0110$。
    - 另一种可能：B是 $P$ 乘以2的结果，但符号位出错？$2P = -3850 = (F0F6)_{16}$。
    - 让我们看D。
- **选项C**: [干扰] — 针对“算术右移”或“除以8”的错误认知。
    - 分析：$(F878)_{16}$ 与 $(F87B)_{16}$ 非常接近。$P = (F87B)_{16}$。如果考生误以为乘以8是右移（除以8），或者在移位方向上搞反，可能会选这个。或者，这是 $P$ 算术右移3位的结果？$P \gg 3 = (FFF8)_{16}$? 不对。
    - 实际上，$(F878)_{16}$ 是 $P$ 的低3位被清零？$F87B \& FFF8 = F878$。这可能是考生误以为乘以8是“与运算”或某种位掩码操作。
