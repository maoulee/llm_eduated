# 练习题 Q1 — 中断处理微操作序列分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
考虑以下微操作序列：
MBR ← PC
MAR ← X
PC ← Y
Memory ← MBR
下列哪一项是该序列可能执行的操作？（ ）
- 选项:
  A: 指令获取
  B: 操作数获取
  C: 条件分支
  D: 中断服务的启动

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。需要掌握中断处理、指令周期、分支指令等核心概念的底层微操作实现细节。仅记忆表面定义（如“中断是打断程序”）不足以解题，必须理解“保存现场”和“修改PC”在硬件层面的具体寄存器交互。
- **K2 = 1**: 评分理由。本题不涉及数值计算，无需进行幂次换算或复杂算术运算。
- **K3 = 4**: 评分理由。需要多步串行推演：1. 识别MBR←PC是保存断点；2. 识别MAR←X是准备写入地址；3. 识别PC←Y是跳转；4. 识别Memory←MBR是持久化保存断点。这四步逻辑必须连贯，且需理解Memory←MBR这一步对于“中断返回”的关键性，推演链条较长且需保持中间状态（MBR中暂存的旧PC值）。
- **K4 = 5**: 评分理由。存在极强的隐含前提和反直觉陷阱。常规思维中，写内存通常是为了存数据，但这里写内存是为了存“地址”（断点）。同时，题目未明确说明X和Y的具体含义，考生必须通过微操作的组合特征（先存PC，再改PC，最后存旧PC到内存）反向推导这是中断而非普通分支。普通分支通常不写内存，这是最大的隐含区分点。
- **K5 = 4**: 评分理由。涉及CPU内部寄存器（PC, MBR, MAR）与主存（Memory）之间的状态传递。PC的状态改变（跳转）与Memory的状态改变（保存断点）紧密耦合，体现了控制流与数据流（此处为控制信息流）的跨模块交互。
- **雷达形状**: K4陷阱型/K3推演型。K1和K3、K4较高，K2极低，呈现明显的非计算类逻辑推理特征，且K4（条件路由/隐含前提）得分最高，说明题目核心难点在于识别隐含的中断特征。

## 考察模式
- **模式**: 推理型
- **理由**: 题目给出具体的微操作序列，要求考生逆向推理出对应的宏观操作。这需要考生将底层的硬件行为（寄存器传输）映射到高层的系统行为（中断、分支等），属于典型的从微观到宏观的逻辑推理。

## 选项级分析
- **选项A**: [干扰] — 针对对“指令获取”流程记忆模糊的学生。指令获取通常是 `MAR ← PC`, `PC ← PC + 1`, `IR ← Memory`。本题中有 `Memory ← MBR`（写内存），而取指是读内存，方向相反，故排除。
- **选项B**: [干扰] — 针对混淆“数据存取”与“控制流改变”的学生。操作数获取通常涉及 `MAR ← 地址`, `Memory ← MBR` (存) 或 `MBR ← Memory` (取)，但不会直接修改 `PC` 指向新的执行流（除非是特殊的自修改代码，但这不属于标准操作数获取）。本题核心特征是 `PC ← Y`，即改变了程序执行顺序。
- **选项C**: [干扰] — 针对忽略“保存现场”这一关键步骤的学生。条件分支（如JMP, BEQ）确实会执行 `PC ← Y`，但通常**不会**执行 `Memory ← MBR`（将旧PC写回内存）。分支指令只需要改变PC即可，不需要将返回地址保存到内存中（因为分支不是调用，不需要返回原处继续执行，或者返回地址由调用者管理，而非分支指令本身自动保存）。这是最强的干扰项。
- **选项D**: [正确] — 中断服务的启动必须包含两个核心动作：1. 保存当前断点（旧PC），以便中断结束后返回；2. 跳转到中断服务程序入口（新PC）。序列中 `MBR ← PC` 暂存旧PC，`Memory ← MBR` 将旧PC写入内存（保存现场），`PC ← Y` 跳转到中断向量地址Y。完全符合中断处理机制。

- **干扰策略**: 概念混淆。利用“分支”和“中断”都会改变PC这一共同点，通过省略“保存现场”这一关键差异点来制造混淆。考生若只关注 `PC ← Y` 而忽略 `Memory ← MBR`，极易误选C。

## 核心陷阱
- **核心陷阱**: **忽略“写内存”操作的语义**。许多学生看到 `PC ← Y` 就认为是跳转/分支，从而忽略了对 `Memory ← MBR` 的分析。在中断处理中，将旧PC写入内存是“保存断点”的关键硬件动作，而普通分支指令不需要此动作。区分“无条件跳转”与“中断/调用”的关键在于是否有“保存返回地址”的操作。

## 考察能力
本题核心考察考生对**中断处理底层微操作机制**的理解，特别是区分“控制流转移”与“现场保护”在硬件寄存器层面的实现差异。
