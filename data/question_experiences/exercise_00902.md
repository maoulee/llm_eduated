# 练习题 Q1 — IPSec隧道模式封装机制

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/网络层
- **难度**: 待评估

## 题干原文
在隧道模式下使用 IPSEC 会导致（ ）

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题需要考生准确记忆并区分 IPSec 的两种工作模式（传输模式 vs 隧道模式）的具体封装细节。这不仅仅是知道“IPSec 提供安全”，而是需要辨析“隧道模式”特有的“双重 IP 头部”结构。若只记忆了 IPSec 的基本功能而忽略了模式差异，极易出错，属于对易混概念的深度辨析。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全属于定性分析。
- **K3 = 2**: 评分理由。推演步骤较少。只需执行一步逻辑判断：识别“隧道模式” -> 调用“封装整个原始 IP 包并添加新 IP 头”的规则 -> 得出结论。无需多步串行推演或状态记忆。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。考生容易混淆“传输模式”（仅加密载荷，保留原 IP 头）和“隧道模式”（加密原 IP 头+载荷，添加新 IP 头）。题干中的“隧道模式”是解题的关键限定词，若忽略此词或对其含义理解不深（如误以为只是加密数据部分），就会落入陷阱。
- **K5 = 2**: 评分理由。主要考察网络层内部的安全协议机制。虽然 IPSec 涉及网络层与传输层/应用层数据的交互，但本题仅关注 IP 数据包的头部结构变化，未涉及跨子系统（如 TCP 状态、路由协议联动等）的复杂状态传递。

- **雷达形状**: K1 主导的概念辨析型（K1 高，K2 极低，K4 中等）

## 考察模式
- **模式**: 概念型
- **理由**: 题目直接考察 IPSec 协议中特定工作模式（隧道模式）的定义和数据结构特征，不涉及计算或复杂逻辑推理，核心在于对协议规范细节的记忆和理解。

## 选项级分析
- **选项 A**: [干扰] — 针对“认为 IPSec 只是加密内容，不改变头部结构”的错误认知。这类学生可能误以为 IPSec 像透明加密一样，只处理 Payload，或者混淆了传输模式（虽然传输模式也不改变原 IP 头，但也不会有“相同头部”这种模糊描述，通常指原封不动）。
- **选项 B**: [正确] — 隧道模式的核心特征。IPSec 将原始 IP 数据包（包括原 IP 头和载荷）作为新 IP 数据包的载荷，并添加一个新的外层 IP 头部。因此，数据包具有新的头部（外层 IP 头 + ESP/AH 头）。
- **选项 C**: [干扰] — 针对“认为 IPSec 会移除头部”的极端错误认知。这类学生可能对“封装”概念完全误解，或者混淆了某些去封装过程，认为安全处理会剥离头部。
- **选项 D**: [干扰] — 针对“认为 IPSec 对数据包结构无影响”的错误认知。这类学生可能只记住了 IPSec 提供机密性/完整性，而忽略了其实现机制必然涉及头部扩展或替换。

- **干扰策略**: 概念混淆。通过提供“无变化”、“无头部”、“相同头部”等极端或模糊的描述，干扰考生对“新增头部”这一核心特征的识别。

## 核心陷阱
- **核心陷阱**: 混淆 IPSec 的**传输模式**与**隧道模式**。
    - **传输模式**：只加密/认证 IP 载荷，保留原始 IP 头部。
    - **隧道模式**：加密/认证整个原始 IP 数据包（含原 IP 头），并封装在一个新的 IP 数据包中，因此会产生**新的 IP 头部**。
    - 考生若未仔细审题或记忆模糊，容易将两者混为一谈，从而误选 A 或 D。

## 考察能力
准确辨析 IPSec 不同工作模式下的数据包封装结构差异。
