# 2025 Q12 — 有符号到无符号的符号扩展与真值计算

## 基本信息
- **年份**: 2025  **题位**: Q12  **题型**: 选择题

## 题干原文

unsigned int ui = si;

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“补码表示”、“符号扩展规则”以及“无符号数真值定义”这三个核心概念。仅靠直觉无法解题，必须调用具体的数据表示定义，但无需辨析极度晦涩的边缘概念，属于标准的基础认知需求。
- **K2 = 3**: 评分理由。涉及从十进制负数到二进制补码的转换，以及从32位二进制无符号数到十进制真值的计算。虽然涉及2的幂次运算，但中间步骤（如 $2^{32}-1$ 的推导）需要一定的代数变形能力，非简单的直接查表或一步到位，属于标准计算难度。
- **K3 = 3**: 评分理由。解题过程包含明确的串行步骤：1. 确定 `short` 位宽及 `-32767` 的补码；2. 执行符号扩展至 32 位；3. 将扩展后的位模式解释为 `unsigned int` 并计算真值。共3-4步逻辑推演，属于标准机制推演。
- **K4 = 4**: 评分理由。存在显著的隐含前提和易错点。首先，考生必须意识到 `short` 是 16 位（而非默认 32 位）；其次，必须识别出从有符号到无符号转换时，**符号扩展**（Sign Extension）是关键机制，而非零扩展；最后，计算真值时容易混淆“补码对应的负数值”与“无符号解释下的巨大正数值”。这些陷阱使得条件路由难度较高。
- **K5 = 2**: 评分理由。本题主要局限于数据表示子系统内部，虽然涉及 C 语言类型系统，但本质是底层位模式的转换，不涉及复杂的跨子系统状态传递或深度耦合，属于较低程度的跨域联动。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，表明本题主要考察对隐含规则和易错点的识别能力）

## 考察模式
- **模式**: 综合型
- **理由**: 本题结合了概念理解（补码、符号扩展）、规则应用（类型转换机制）和数值计算（二进制转十进制）。它不是单纯的概念记忆，也不是纯粹的算术计算，而是要求在正确理解底层机制的基础上进行精确推导。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：认为 `-32767` 的补码形式直接对应某个小的正数，或者错误地进行了零扩展且只保留了低16位。这类学生可能混淆了 `short` 和 `int` 的位宽，或者完全误解了补码的数值含义。
- **选项B**: [干扰] — 针对错误认知：计算错误。可能将 `-32767` 误认为是 `-32768` 或其他边界值，或者在计算 $2^{32} - \dots$ 时符号处理错误。例如，若误以为 `-32767` 的补码是 `1000...001` (即 $-2^{15}+1$)，然后错误地将其视为无符号数 $2^{31} + 1$ 等变体。
- **选项C**: [干扰] — 针对错误认知：符号位处理错误。可能正确计算了模 $2^{32}$，但在减去偏移量时出错。例如，正确知道结果是 $2^{32} + (-32767)$，但错误地将 $-32767$ 拆解为 $-2^{15} - 1$ 而不是 $-2^{15} + 1$。注意 $-32767 = -32768 + 1 = -2^{15} + 1$。如果学生记错 $-32767$ 的补码结构，可能会选此项。
- **选项D**: [正确] — 正确推导。
  1. `short` 为 16 位。$-32767$ 的补码：
     $32767 = 2^{15} - 1 = 0111\ 1111\ 1111\ 1111_2$
     $-32767 = \sim(32767) + 1 = 1000\ 0000\ 0000\ 0000_2 + 1 = 1000\ 0000\ 0000\ 0001_2$
  2. 符号扩展至 32 位 `unsigned int`：
     高位补 1，得到 $1111\ 1111\ 1111\ 1111\ 1000\ 0000\ 0000\ 0001_2$
  3. 计算无符号真值：
     该值等于 $2^{32} - 1$ (全1) 减去中间为0的部分，或者直接按位权求和。
     更简单的算法：$ui = 2^{32} + si$ (当 $si < 0$ 时)
     $ui = 2^{32} + (-32767) = 2^{32} - (2^{15} - 1) = 2^{32} - 2^{15} + 1$。
     或者看二进制：高16位全1 ($2^{32}-2^{16}$)，低16位为 $1000...001$ ($2^{15}+1$)。
     总和 = $(2^{32} - 2^{16}) + (2^{15} + 1) = 2^{32} - 2 \cdot 2^{15} + 2^{15} + 1 = 2^{32} - 2^{15} + 1$。

- **干扰策略**: 概念混淆与计算陷阱。选项主要围绕 $2^{15}$ 的符号（加还是减）以及常数项（$+1$ 还是 $-1$）进行微调，考察学生对 $-32767$ 具体补码形态的精确记忆和代数运算能力。

## 核心陷阱
- **核心陷阱**: **符号扩展的方向与无符号解释的冲突**。
  1. 许多学生习惯于“零扩展”或忽略位宽差异，直接认为值不变。
  2. 即使知道要符号扩展，在计算最终真值时，容易混淆“补码代表的负数”与“该位模式作为无符号数代表的巨大正数”之间的代数关系。
  3. 具体数值陷阱：$-32767$ 不是 $-2^{15}$，而是 $-2^{15} + 1$，这导致最终结果中常数项是 $+1$ 而非 $-1$ 或其他。

## 考察能力
本题核心考察考生对**有符号数到无符号数转换时的符号扩展机制**的理解，以及在**不同数据类型解释下同一位模式真值计算**的精确推导能力。
