# 练习题 Q1 — 缓存地址字段划分

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 计算机组成原理/存储系统
- **难度**: 待评估

## 题干原文
考虑一个具有以下特性的四路组相联映射缓存计算机：主存总容量为 1MB，字长为 1 字节，块大小为 128 字，缓存容量为 8KB。
TAG、SET 和 WORD 字段中的位数分别为（ ）：
- 选项:
  A: 7, 6, 7
  B: 8, 5, 7
  C: 8, 6, 6
  D: 9, 4, 7

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握缓存映射的基本概念（组相联、块、字、TAG/SET/OFFSET定义）。不是4分因为不需要辨析多个易混的高级概念，只需调用标准定义。
- **K2 = 3**: 评分理由。涉及多级单位换算（MB->B, KB->B, 字->字节）和2的幂次对数计算。虽然都是2的幂，但步骤较多，容易在换算环节出错，属于标准偏上的计算量。
- **K3 = 3**: 评分理由。解题逻辑链条清晰：确定主存地址总位数 -> 确定块内偏移位数 -> 确定组数及SET位数 -> 剩余为TAG位数。共3-4步串行推演，无分支。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。1. “字长为1字节”与“块大小为128字”结合，需意识到块大小实际为128字节（若误以为字长4字节则全错）。2. 需明确“WORD字段”在此题语境下指代的是块内偏移（Block Offset），而非字地址。这是最大的暗坑，若按字寻址计算偏移，结果将完全不同。
- **K5 = 1**: 评分理由。纯存储系统内部计算，不涉及CPU流水线、中断或其他子系统状态传递。
- **雷达形状**: K4陷阱型（K4显著高于其他维度，主要难点在于识别题目中的单位陷阱和字段定义陷阱）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过给定的硬件参数，利用公式计算出地址各字段的位数。虽然涉及概念理解，但最终落脚点是数值计算。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：可能误算了主存地址位数或组数。例如，若误以为主存是512KB（19位），或者组数计算错误。
- **选项B**: [干扰] — 针对错误认知：SET位数计算错误。若误以为缓存块数是32（8KB/256B?），则组数为8，SET为3位；或者误算组数为32，SET为5位。此选项可能是通过错误的块大小换算（如误以为块是256字节）导致的。
- **选项C**: [干扰] — 针对错误认知：WORD字段计算错误。若误以为字长是4字节，块大小128字=512字节，则WORD=9位，不符。若误以为块大小128字节，但按字寻址（字长1字节），WORD=7位。此选项可能是TAG或SET计算中的中间错误累积。
- **选项D**: [正确] — 正确计算结果。
  - 主存1MB = $2^{20}$ B，地址20位。
  - 块大小128字，字长1B $\rightarrow$ 块大小128B = $2^7$ B $\rightarrow$ WORD (Offset) = 7位。
  - 缓存8KB = $2^{13}$ B。
  - 缓存总块数 = $2^{13} / 2^7 = 2^6 = 64$ 块。
  - 四路组相联 $\rightarrow$ 组数 = $64 / 4 = 16 = 2^4$ 组 $\rightarrow$ SET = 4位。
  - TAG = 总地址 - SET - WORD = $20 - 4 - 7 = 9$ 位。
  - 结果：9, 4, 7。

- **干扰策略**: 计算陷阱与概念混淆。主要利用“字长”与“块大小”的单位换算陷阱，以及“WORD字段”在不同教材中可能指代“字内偏移”或“块内偏移”的歧义（本题明确字长1字节，故块内偏移即字地址，但若学生习惯字长4字节，极易出错）。

## 核心陷阱
**单位换算与字段定义的歧义**：
1. **块大小换算**：题目给出“块大小为128字”，且“字长为1字节”。必须将块大小转换为字节数（128B）才能计算块内偏移（WORD/Offset）。如果学生惯性思维认为字长是4字节，会算出块大小512B，导致WORD=9位，从而全盘皆错。
2. **WORD字段的含义**：在地址划分中，最低位通常是块内偏移（Block Offset）。题目问“WORD字段”，在字长=1字节的特殊情况下，块内偏移位数等于字地址位数。如果字长不为1，WORD字段通常指字内偏移，而块内偏移包含“字地址+字内偏移”。本题因字长=1，二者重合，但需考生敏锐意识到这一点。

## 考察能力
在复杂单位换算和特定映射规则下，准确分解主存地址结构并计算各字段位数的能力。
