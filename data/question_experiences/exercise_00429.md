# 练习题 Q1 — 页面置换算法性能对比

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/存储管理
- **难度**: 待评估

## 题干原文
考虑以下虚拟页面引用序列：1, 2, 3, 2, 4, 1, 3, 2, 4, 1。在一个运行于主存大小为 3 个页面帧（初始为空）的按需分页虚拟内存系统中。设 OPTIMAL、LRU 和 FIFO 分别表示对应页面置换策略下的页面错误次数。则（ ）。
- 选项:
  A: OPTIMAL < LRU < FIFO
  B: OPTIMAL < FIFO < LRU
  C: OPTIMAL = LRU
  D: OPTIMAL = FIFO

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆并区分 OPTIMAL、LRU、FIFO 三种页面置换算法的核心定义。不是 4 分因为这三个概念是操作系统存储管理中最基础且独立的知识点，不涉及复杂的易混概念辨析（如 Belady 异常的具体数学证明），只需知道“替换谁”的规则即可。
- **K2 = 2**: 评分理由。本题不涉及数值计算，而是状态模拟。虽然需要计数，但“计算”本质是逻辑判断而非算术运算，难度较低。
- **K3 = 4**: 评分理由。这是本题的核心难度所在。考生需要对长度为 10 的引用序列，分别按照三种不同的规则进行多步串行推演。每一步都需要维护内存帧的状态（3个位置），并判断是否缺页、替换哪个页面。步骤超过 5 步且需记忆中间状态，极易在某一时刻出错导致后续全盘皆错。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。例如：初始为空时前 3 次引用必然缺页；OPTIMAL 算法需要“向后看”未来引用，而 LRU 需要“向前看”历史引用，方向不同容易搞混；FIFO 严格遵循进入顺序，与引用频率无关。这些属于常规解题必须意识到的条件，若忽略会导致结果偏差。
- **K5 = 1**: 评分理由。本题仅涉及存储管理子系统内部的页面置换逻辑，不涉及 CPU 调度、文件系统等跨域联动，属于单系统内部逻辑推演。
- **雷达形状**: K3 推演主导型（K3 显著高于其他维度，K1 中等，K2/K5 低）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非直接考查概念定义的记忆（概念型），也不是简单的公式代入（计算型），而是要求考生根据给定的算法规则，对动态变化的系统状态进行逐步模拟和逻辑推演，最终得出定量结果。

## 选项级分析
- **选项 A**: [干扰] — 针对认为 LRU 性能优于 FIFO 的错误认知。部分学生可能误以为 LRU 总是比 FIFO 好，或者在模拟过程中 LRU 算错了次数（例如误判了最近使用的页面），导致得出 LRU < FIFO 的错误结论。
- **选项 B**: [正确] — 经过精确模拟，OPTIMAL (5次) < FIFO (6次) < LRU (9次)。符合本题特定序列下的实际表现。
- **选项 C**: [干扰] — 针对认为 OPTIMAL 和 LRU 在此序列下表现一致的错误认知。通常 OPTIMAL 是理论最优，LRU 是近似最优，但在某些特定序列下可能相等。本题中两者差距巨大，选此项说明完全未进行模拟或模拟严重错误。
- **选项 D**: [干扰] — 针对认为 OPTIMAL 和 FIFO 表现一致的错误认知。这通常发生在学生未理解 OPTIMAL 的“未来视角”特性，或者误以为 FIFO 在此序列下也是最优的情况。

- **干扰策略**: 计算陷阱/模拟错误。由于三种算法的模拟过程独立且繁琐，学生极易在 LRU 或 FIFO 的某一步替换判断上出错，从而得到错误的缺页次数，进而匹配到错误的选项。特别是 LRU 在此题中缺页率极高（9/10），容易让学生怀疑自己算错，从而倾向于选择看起来更“合理”的 A 或 D。

## 核心陷阱
- **核心陷阱**: **LRU 算法的“局部性原理”失效陷阱**。
  在本题的特定序列 `1, 2, 3, 2, 4, 1, 3, 2, 4, 1` 中，页面访问呈现出一种“循环覆盖”的特征，导致 LRU 算法频繁替换掉即将被再次访问的页面（即发生了抖动）。许多学生凭直觉认为 LRU 应该比 FIFO 好，或者认为 LRU 不会这么差，从而在模拟时潜意识修正自己的错误步骤，或者干脆放弃模拟直接凭经验选 A。实际上，本题特意构造了一个让 LRU 表现极差的序列，旨在打破“LRU 总是优于 FIFO”的刻板印象（尽管平均而言 LRU 更好，但存在 Belady 异常的反例情况，虽然这里不是 Belady 异常，而是 LRU 劣于 FIFO 的常见情况）。

## 考察能力
本题核心考察考生对页面置换算法底层执行逻辑的**精确模拟能力**以及**破除算法性能刻板印象**的实证分析能力。
