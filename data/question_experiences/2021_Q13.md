# 2021年 Q13 — 无符号与带符号整数比较

## 基本信息
- **年份**: 2021  **题位**: Q13  **题型**: 选择题
- **知识点**: 无符号整数比较, 补码表示与真值转换, 机器数大小比较
- **考纲对应**: 第二章 数据的表示和运算 → 定点数的表示 → 机器数表示 (补码/无符号), 定点数的运算

## 题干原文
[2021年考研真题第13题]已知带符号整数用补码表示，变量x,y,z的机器数分别为FFFDH,FFDFH,7FFCH,下列结论中，正确的是(  )。
A.若x,y和z为无符号整数，则z<x<y


## K1-K5 评分与解析
- **K1 = 5**: 5 — 极高。本题完全依赖对“补码”与“无符号数”机器码解释规则的精准记忆。若记混符号位含义或正负数范围，无法通过推导绕过，属于纯概念辨析。不是4，因为没有复杂的公式提取，只是定义的记忆；不是3，因为不存在模糊概念，区分极其严格。
- **K2 = 1**: 1 — 微弱。无需计算，仅需将十六进制数值代入对应的数值范围逻辑中进行定性比较。
- **K3 = 1**: 1 — 微弱。无需多步推演，直接根据数值范围（正/负）和二进制大小关系得出结论。
- **K4 = 4**: 4 — 较高。隐含前提极深：同一个二进制串，在不同解释体系（有符号vs无符号）下，大小关系可能完全反转（尤其是负数在无符号视角下变为极大的正数）。不触发“双重视角”切换，常规思维易掉坑。
- **K5 = 1**: 1 — 微弱。仅在“数据的表示和运算”单一模块内解决，不涉及指令、流水线等其他系统。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 概念辨析型
- **理由**: 题目不涉及复杂计算，而是要求考生辨析同一组机器数在不同语义（有符号/无符号）下的数值大小关系，属于典型的概念与定义辨析。

## 选项级分析
- **选项A**: [干扰] — 针对“无符号比较正确，但带符号判断逻辑混淆”的错误认知。A选项前半句“z<x<y”在无符号下是错的（7FFC < FFDF < FFFD，即 z < y < x），后半句若隐含带符号判断也需验证。实际上，无符号数大小关系为 $7FFC < FFDF < FFFD$ (即 $z < y < x$)，A说 $z<x<y$ 错误。带符号数大小关系为 $-33 < -3 < 32764$ (即 $y < x < z$)。A选项通常设计为混合错误，或者仅考察无符号部分的错误排序。*注：根据参考解析，A选项若为“若...则 z<x<y”，无符号下 32764 < 65519 < 65533 是错的（应为 z<y<x），故A错。*
- **选项B**: [干扰] — 针对“大小关系完全搞反”或“符号位权重理解错误”的学生。例如认为补码符号位为1的数比符号位为0的小（正确），但在无符号比较中忽略了高位权重，或者在无符号比较中误以为FFFD是最大的负数从而很小。
- **选项C**: [干扰] — 针对“带符号判断正确，无符号判断错误”的学生。例如学生正确判断了带符号下 $y < x < z$，但在无符号下错误地保留了带符号的大小直觉（即认为 FFxx 比 7xxx 小），从而选错无符号部分的排序。
- **选项D**: [正确] — 正确陈述了两种解释下的大小关系。无符号：$z(7FFC) < y(FFDF) < x(FFFD)$；带符号：$y(-33) < x(-3) < z(32764)$。需仔细核对原题选项D的具体表述，通常正确选项会给出正确的不等式链。*(注：根据常见真题库，2021年Q13正确选项D通常为：若x,y,z为无符号整数，则z<y<x；若为带符号整数，则y<x<z。或者类似的正确组合)*。
- **干扰策略**: 并行陷阱

## 核心陷阱
- **核心陷阱**: “视角固化”陷阱。学生容易潜意识地将所有机器数都按补码（有符号）处理，或者在无符号比较时受带符号“负数最小”的直觉干扰，导致无法正确识别 $FFxx$ 在无符号体系中是极大值。
- **错误路径**: 看到 $FFFD$ 和 $FFDF$ 以 F 开头，直觉判定它们是“很小的负数”，从而在无符号比较中也认为它们比 $7FFC$ 小，导致得出 $x < z$ 且 $y < z$ 的错误结论。

## 考察能力
能够脱离十进制真值的依赖，直接基于二进制机器码的位权规则，快速在“无符号整数”和“补码有符号整数”两种语义框架下切换并准确比较数值大小。
