# 练习题 Q1 — IP分片机制与字段计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/网络层
- **难度**: 待评估

## 题干原文
一个最大传输单元（MTU）为 1500 字节的 IP 路由器接收到一个总长度为 4404 字节、IP 首部长度为 20 字节的 IP 数据报。该路由器为此数据报生成的第三个 IP 分片中，相关字段的取值是（ ）：
A: MF 位：0，数据报长度：1444；偏移量：370
B: MF 位：1，数据报长度：1424；偏移量：185
C: MF 位：1，数据报长度：1500；偏移量：37
D: MF 位：0，数据报长度：1424；偏移量：2960

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆 IP 分片相关的核心概念，包括 MTU 限制、IP 首部长度、片偏移量的单位（8字节）、MF 标志位的含义以及总长度字段的定义。属于标准的基础概念调用，不涉及复杂概念辨析。
- **K2 = 3**: 评分理由。涉及多次算术运算：计算数据载荷长度、计算每个分片的数据部分长度、计算片偏移量（需除以8）、计算最终分片的总长度（数据+首部）。虽然计算本身不复杂，但步骤较多，且涉及非2的幂次除法（4404/8等），容易因粗心出错。
- **K3 = 4**: 评分理由。需要串行推演分片过程。必须按顺序确定第一个分片、第二个分片，才能确定第三个分片的起始位置。每一步的状态（剩余数据量、当前偏移量）都依赖于上一步的结果，属于典型的多步状态推演。
- **K4 = 4**: 评分理由。存在多个隐含前提和易错点（暗坑）：1. 片偏移量单位是8字节，而非1字节；2. 数据部分长度必须是8的倍数（除最后一个分片外）；3. “数据报长度”字段包含 IP 首部，而不仅仅是数据载荷；4. 最后一个分片的 MF 位为 0。考生若忽略其中任何一点都会选错。
- **K5 = 1**: 评分理由。本题仅涉及网络层 IP 协议内部的机制，不需要跨越传输层或链路层进行状态联动，属于单系统内部逻辑。
- **雷达形状**: K3/K4 突出型（推演与陷阱主导），K2 中等，K1/K5 较低。

## 考察模式
- **模式**: 综合型（计算+推理）
- **理由**: 本题既需要精确的数值计算（K2），又需要严格的逻辑推演（K3）和对协议细节的深刻理解（K4）。单纯记忆公式或单纯计算都无法解题，必须结合协议规则进行分步模拟。

## 选项级分析
- **选项A**: [正确] — 正确计算了第三个分片的各项参数。
    - 数据总长 4404，首部 20，数据载荷 4384。
    - 分片1：数据 1480 (1500-20)，偏移 0，MF=1。
    - 分片2：数据 1480，偏移 1480/8=185，MF=1。
    - 分片3：剩余数据 4384 - 1480 - 1480 = 1424。偏移 (1480+1480)/8 = 2960/8 = 370。MF=0（最后一片）。总长度 = 1424 + 20 = 1444。
- **选项B**: [干扰] — 针对**混淆分片序号**或**计算错误**的学生。
    - 偏移量 185 是第二个分片的偏移量。
    - 数据报长度 1424 是第三个分片的数据载荷长度（未加首部）或计算错误。
    - MF=1 错误，因为这是最后一个分片。
    - 这类学生可能只算到了第二个分片，或者混淆了“数据长度”和“总长度”。
- **选项C**: [干扰] — 针对**忽略首部长度**或**误解偏移量单位**的学生。
    - 偏移量 37 可能是 296/8 或其他错误计算。
    - 数据报长度 1500 是 MTU，暗示学生认为每个分片都填满 MTU，忽略了最后一个分片通常不满。
    - MF=1 错误。
- **选项D**: [干扰] — 针对**混淆偏移量单位**或**概念不清**的学生。
    - 偏移量 2960 是第三个分片起始的**字节偏移量**，而非 IP 头部中的**片偏移字段值**（应为 370）。这是最常见的错误，即忘记除以 8。
    - 数据报长度 1424 是数据载荷长度，未加 20 字节首部。
    - MF=0 正确。

**干扰策略**: 概念混淆（偏移量单位、总长度定义）与计算陷阱（分片序号、MF位判断）结合。

## 核心陷阱
- **核心陷阱**: **片偏移量的单位换算**与**总长度字段的定义**。
    1.  IP 头部中的“片偏移”字段单位是 **8 字节**，考生极易直接用字节数作为偏移量（如选项 D 的 2960）。
    2.  IP 数据报的“总长度”字段包含 **IP 首部**，考生极易只计算数据载荷长度（如选项 B、D 的 1424）。
    3.  最后一个分片的 **MF 位必须为 0**，且数据部分长度不需要是 8 的倍数。

## 考察能力
本题核心考察考生对 IP 分片机制中**字段定义（特别是单位）**的精确理解以及**多步分片过程的模拟计算能力**。
