# 练习题 Q1 — 轮转调度算法执行序列推演

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
考虑以下进程集合，其到达时间和所需 CPU 执行时间（单位：ms）如下表所示：
进程
到达时间
执行时间
P1

在采用时间片为 2 ms 的轮转调度算法时，这些进程的完成顺序是（ ）？
- 选项:
  A: P1, P2, P3
  B: P2, P1, P3
  C: P3, P2, P1
  D: P2, P3, P1
- 正确答案: B
- 解析（参考）: 解析
使用时间片 tq=2ms 的轮转调度算法时，进程的完成顺序为 P2, P1, P3。选项 (B) 正确。具体分析如下：
时间片分配规则
时间片固定为 2ms，每次从就绪队列中选择一个进程执行，直到时间片耗尽或进程完成。
若进程未完成，则将其放回就绪队列末尾继续等待。
执行过程分解
t=0~2ms
：P1 开始执行，剩余执行时间为 2ms。
t=2ms
：P2 到达，加入就绪队列；P1 时间片用完，剩余 2ms，重新入队。
t=2~4ms
：P2 执行完成（总执行时间 2ms）。
t=4ms
：P3 到达，加入就绪队列；P1 剩余 2ms，继续执行至 t=6ms 完成。
t=6ms
：P3

- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握轮转调度（RR）的核心定义，包括时间片概念、就绪队列的FIFO特性以及进程切换规则。不是2分因为仅记忆定义不够，需理解动态到达场景下的队列变化；不是4分因为不涉及多算法对比或复杂概念辨析。
- **K2 = 2**: 评分理由。计算过程仅为简单的加减法（时间累加、剩余时间计算），数值较小且均为整数，无复杂换算或高精度要求，属于低难度计算。
- **K3 = 4**: 评分理由。从输入到输出需要多步串行推演。需模拟 t=0, 2, 3, 4, 6 等多个时间点的状态变化，涉及进程到达、时间片耗尽、重新入队、新进程插入等多个步骤，且需记忆中间状态（如P1剩余时间、队列顺序），步骤超过5步，属于较高推演需求。
- **K4 = 3**: 评分理由。存在常规注意点作为陷阱。主要陷阱在于“新到达进程与时间片耗尽进程的入队顺序”以及“进程完成时是否立即释放CPU”。若忽略P2在t=2到达时P1刚用完时间片，可能误判队列顺序；若误以为P1执行完第一个时间片后P3已到达（实际t=3到达），会导致错误。属于中等难度的隐含条件识别。
- **K5 = 1**: 评分理由。本题仅涉及CPU调度子系统内部的状态流转，不涉及内存管理、I/O调度或其他子系统的状态传递，属于单系统问题。
- **雷达形状**: K3推演主导型（K3显著高于其他维度，K4中等，K1/K2/K5较低）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非直接考查公式计算或概念记忆，而是要求考生根据给定的调度规则（RR, tq=2），在动态变化的时间轴上，逐步推演进程的就绪、执行、阻塞（此处无阻塞）、完成状态，最终得出完成顺序。核心在于对调度机制动态过程的逻辑模拟。

## 选项级分析
- **选项A**: [干扰] — 针对“先来先服务（FCFS）”或“短作业优先（SJF）”的错误认知。这类学生可能忽略了时间片轮转的抢占特性，或者错误地认为P1一直执行直到完成，或者误以为P1在t=2时虽然时间片用完但优先级最高继续执行。
- **选项B**: [正确] — 符合RR调度算法的正确推演结果。
- **选项C**: [干扰] — 针对“短进程优先”或“完全误解调度顺序”的错误认知。这类学生可能认为执行时间短的进程（P3, P2）会优先完成，完全忽略了到达时间和时间片轮转的队列机制。
- **选项D**: [干扰] — 针对“入队顺序错误”或“P3到达时间误判”的错误认知。这类学生可能正确推演出P2先完成，但在t=4时刻，误以为P3（t=3到达）在P1之前进入就绪队列，或者误以为P1在t=2重新入队后排在P3后面（实际上P3在t=3才到达，t=2时队列只有P1和P2，P2执行完后队列只有P1，P3在t=3到达时P1正在执行或刚结束，需仔细分析t=3~4时刻的状态）。*注：实际上在t=2时，P2到达，P1时间片用完。队列：P2, P1。t=2~4 P2执行。t=4时P2完成。此时P3已在t=3到达并等待。队列：P1, P3。所以P1先于P3完成。选D的学生可能误以为P3在P1之前入队。*
- **干扰策略**: 概念混淆（FCFS vs RR）、计算陷阱（入队顺序与到达时间的时序关系）

## 核心陷阱
- **核心陷阱**: **就绪队列的动态更新时机与顺序**。具体而言，在 t=2ms 时，P1 时间片用完，P2 刚好到达。关键在于确定此时就绪队列的顺序是 [P2, P1] 还是 [P1, P2]（通常新到达进程排在重新入队进程之前，或反之，需依据具体教材约定，但408通常约定新到达进程插入队尾，若同时发生，通常新到达者在前或按题目隐含逻辑，此处P2到达后P1才重新入队，故P2在前）。更隐蔽的陷阱在于 t=3ms 时 P3 到达，此时 P2 正在执行，P3 进入就绪队列。t=4ms 时 P2 完成，此时就绪队列中已有 P1（t=2入队）和 P3（t=3入队），因此 P1 先于 P3 执行。考生容易忽略 P3 的到达时间对队列顺序的影响，或混淆 P1 重新入队与 P3 到达的先后顺序。

## 考察能力
一句话概括本题核心考察的能力：在动态到达场景下，准确模拟轮转调度算法中进程的就绪队列变化及CPU分配时序的逻辑推演能力。
