# 2018年 Q13 — 补码减法与真值转换

## 基本信息
- **年份**: 2018  **题位**: Q13  **题型**: 选择题
- **知识点**: 补码表示与真值转换, 补码加减运算规则
- **考纲对应**: 数据表示和运算 -> 定点数的表示 -> 补码表示; 数据表示和运算 -> 定点数的运算 -> 补码加减运算

## 题干原文
[2018年考研真题第13题]假定带符号整数采用补码表示，若int型变量x和y的机器数分别是FFFF FFDFH 和00000041H,则x、y的值以及x-y的机器数分别是。
A.x=-65,y=41

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆补码最高位为符号位且权重为负（$-2^n$），以及十六进制与二进制的对应关系。若仅知“补码”名词而不知具体换算规则，无法入题。高于2分是因为不能靠模糊概念猜测，必须调用核心定义。
- **K2 = 4**: 4 — 涉及两个核心计算步骤：1. 将32位十六进制补码转换为十进制真值（需处理符号扩展和权重）；2. 执行补码减法运算（$x-y = [x]_{补} + [-y]_{补}$），其中求$[-y]_{补}$需对$y$按位取反加1，且涉及十六进制加法进位。数字虽友好（Hex），但步骤多、易出错（如忘记取反加1，或符号位处理错误），属于较高难度的单步代入/计算组合。
- **K3 = 1**: 1 — 一旦掌握了补码换算和加减法规则，路径是唯一的代数运算，无需多步逻辑推演或状态更新。
- **K4 = 3**: 3 — 存在明确的陷阱：负数补码转真值时，容易错误地先取反加1再转，或混淆原码/反码规则；减法变加法时，容易忽略对减数求补（取反加1）的步骤。不触发这些规则意识就会用错公式。
- **K5 = 1**: 1 — 仅在数据表示与运算内部解决，不涉及存储、总线或其他系统模块。
- **雷达形状**: K2计算型

## 考察模式
- **模式**: 计算型
- **理由**: 题干提供具体机器数，要求通过标准化算法计算出唯一的数值和机器数结果，属于典型的计算验证题。

## 选项级分析
- **选项A**: [干扰] — 针对“真值换算错误”或“正负号混淆”。学生可能将 `FFFF FFDFH` 误算为 -65（实际为-33），或将 `00000041H` 误算为 41（实际为65）。这是典型的数值计算失误或符号权重理解错误。
- **选项B**: [干扰] — 针对“减法运算规则错误”。学生可能正确求出了x, y的真值，但在计算 $x-y$ 时，直接在补码上做减法而未转换为加法（即未对y求补），或者对y求补时仅取反未加1，导致结果错误。
- **选项C**: [正确] — 正确执行了补码真值转换（$x=-33, y=65$）和补码减法运算（$[x]_{补} + [-y]_{补}$）。
- **选项D**: [干扰] — 针对“求值错误”或“完全概念混淆”。可能将补码直接当作无符号数或原码处理，导致真值完全偏离，进而导致后续计算错误。
- **干扰策略**: 并行陷阱

## 核心陷阱
- **核心陷阱**: 负数补码转真值的符号权重处理，以及减法转化为加法时减数的“取反加一”操作。

## 考察能力
准确执行定点补码的机内运算与真值双向转换的能力，特别是处理负数符号位和减法补码规则的细节精度。
