# 2018年 Q13 — 补码减法与真值转换

## 基本信息
- **年份**: 2018  **题位**: Q13  **题型**: 选择题
- **知识点**: 补码表示法、十六进制与二进制/十进制转换、定点数加减运算（补码减法规则）、符号扩展
- **考纲对应**: 第二章 数据的表示和运算 → 运算方法和电路 → 补码加减

## 题干原文
[2018年考研真题第13题]假定带符号整数采用补码表示，若int型变量x和y的机器数分别是FFFF FFDFH 和00000041H,则x、y的值以及x-y的机器数分别是。
A.x=-65,y=41

## K1-K5 评分与解析
- **K1 = 3**: 3 — 必须准确记忆补码的定义（最高位为符号位，负数补码=模+真值或取反加1）以及十六进制与二进制的对应关系才能入题。若仅知“补码表示负数”这一模糊概念，无法进行具体数值转换，故不是2；但无需辨析冷门细节公式，故不是4。
- **K2 = 3**: 3 — 需进行两次核心的数值转换（十六进制转十进制真值）和一次补码加减运算。虽然数字涉及非2的幂次（如0xDF=223），需要手算或细心转换，属于常规计算量。比简单的心算（如2的幂）复杂，故不是2；但未达到极高复杂度或极易算错的多级换算，故不是4。
- **K3 = 2**: 2 — 推导路径非常固定且简短：1. 将x, y转换为真值；2. 执行x-y算术运算；3. 将结果转回补码机器数。全程仅需2-3步逻辑串联，无分支、无动态状态维护，故不是3（3需3-5步流程说明书式推演）。
- **K4 = 4**: 4 — **核心陷阱在于负数补码的求值与符号扩展**。题目给出的x为`FFFF FFDFH`（32位），若考生错误地将其视为16位`FFDFH`或直接按无符号数理解，会掉入陷阱。此外，计算`x-y`时，需正确执行“减法变加法”（求`-y`的补码），即对`00000041H`取反加1得到`FFFFFFBFH`，这一步极易出现“仅取反忘记加1”或“高位符号扩展错误”的暗坑。这种对机制本质（补码运算规则及位数对齐）的深度依赖，符合K4较高等级。
- **K5 = 1**: 1 — 纯数据表示与运算问题，不涉及存储器、CPU控制单元或I/O等其他子系统，单一知识点内部闭环解决。
- **雷达形状**: K4陷阱型

## 考察模式
- **模式**: 计算型
- **理由**: 题干给定了具体的机器数参数，四个选项是四个不同的计算结果（真值及最终机器数），考生需通过精确计算得出唯一正确答案。

## 选项级分析
- **选项A**: [干扰] — **考察点：负数补码求值错误**。`FFFF FFDFH` 对应的十进制真值是 -33。若考生误算为 -65 或其他值（例如错误地将 `0xDF` 当作 `111` 即 7，或混淆了原码补码转换），可能会选此项。针对那些对十六进制转二进制不熟练，或补码求值公式记忆模糊的学生。
- **选项B**: [干扰] — **考察点：减法运算逻辑错误（未正确求负数补码）**。正确计算需 `x + (-y)`。`-y` 的补码应为 `FFFFFFBFH`（即 `~0x41 + 1`）。若考生仅在 `00000041H` 基础上取反得到 `FFFFFFBEH` 而忘记加1，或者在加法过程中忽略进位/溢出处理，会得出错误结果。针对那些知道“减法变加法”但操作细节（取反加1）掌握不牢的学生。
- **选项C**: [正确] — **考察点：全流程正确执行**。x=`FFFF FFDFH` -> 真值 -33；y=`00000041H` -> 真值 65；x-y = -33 - 65 = -98。-98 的补码计算：`98 = 64+16+8+4+2+2` (错, 98=0x62=0110 0010) -> `~0x62 + 1` = `FFFFFF9EH`。或者直接二进制加法：`FFFF FFDF` + `FFFFFFBF` = `...` 结果为 `FFFFFF9EH`。该选项给出了正确的真值对和机器数。
- **选项D**: [干扰] — **考察点：真值与机器数混淆或正负号判断错误**。可能给出了正确的真值（-33, 65）但错误的机器数，或者错误的真值搭配看似合理的机器数。针对那些计算能力尚可但粗心大意，或混淆了原码/反码/补码表示形式的学生。
- **干扰策略**: 嵌套陷阱（核心误解层层递进）

## 考察能力
本题核心考察考生对**补码表示法底层逻辑的熟练掌握程度**，以及在**混合进制（十六进制与十进制）环境下执行定点数加减运算的准确性与规范性**，特别是对**负数运算中符号位处理和模运算规则**的细节把控能力。
