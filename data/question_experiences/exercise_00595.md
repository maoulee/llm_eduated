# 练习题 Q1 — 非平衡归并排序的时间复杂度分析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/排序
- **难度**: 待评估

## 题干原文
在一种修改后的归并排序中，输入数组被分割在数组长度（N）的三分之一位置。以下哪项是该修改后归并排序时间复杂度的最紧上界？
- 选项:
  A: $N \log_3 N$
  B: $N \log_2 N$
  C: $N \log_{1/3} N$
  D: $N \log_{3/2} N$
- 正确答案: D
- 解析（参考）: 时间复杂度由以下递归关系式给出：
$T(N) = T(N/3) + T(2N/3) + N$。求解上述递推关系可得：
$T(N) = N \log_{3/2} N$
- 知识标签: ['数据结构/排序']
- 知识域: DS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握递归式建立的基本概念（分治法的子问题规模与合并代价），属于标准的核心定义记忆。不是4分因为不需要辨析多个易混的高级算法概念，只需知道归并排序的基本框架。
- **K2 = 4**: 评分理由。本题的核心难点在于求解非标准递归式 $T(N) = T(N/3) + T(2N/3) + N$。标准的 Master Theorem 仅适用于 $T(N) = aT(N/b) + f(N)$ 且 $b$ 为常数的情况，而此处子问题规模不均等（$1/3$ 和 $2/3$）。求解需要用到递归树法或 Akra-Bazzi 方法，涉及对数底数的变换和级数求和，计算步骤较多且容易出错，属于较高难度的单步/多步计算。
- **K3 = 3**: 评分理由。从建立递归式到求解复杂度，需要经历“识别子问题规模 -> 建立递归方程 -> 选择求解方法（递归树/主定理推广） -> 计算深度与每层代价 -> 得出最终结果”的过程，大约3-5步逻辑推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。学生容易惯性思维，认为归并排序一定是 $O(N \log N)$，从而在选项A、B、D中纠结。更深的陷阱在于，如果不理解递归树的最长路径决定深度，可能会错误地认为深度由较小的子问题 $N/3$ 决定（导致选A），或者由平均情况决定。必须意识到“最紧上界”取决于递归树中最深的那条分支（即每次取 $2N/3$ 的那条路），这是解题的关键隐含条件。
- **K5 = 2**: 评分理由。主要局限于数据结构中的排序算法模块，虽然涉及数学推导，但不需要跨越操作系统、计组或网络等其他子系统，属于单系统内的深度考察。
- **雷达形状**: K2/K4 突出型（计算与陷阱并重）

## 考察模式
- **模式**: 推理型
- **理由**: 本题不能通过简单的公式代入直接得出答案，必须通过逻辑推理建立递归模型，并理解递归树的结构特性（最长路径决定复杂度）才能推导出正确的对数底数。

## 选项级分析
- **选项A**: [干扰] — 针对“最小子问题决定深度”的错误认知。这类学生可能认为递归深度由分割得最快的那部分（$N/3$）决定，从而得出 $\log_3 N$。这是典型的对递归树深度理解偏差。
- **选项B**: [干扰] — 针对“惯性思维/默认标准归并”的错误认知。这类学生看到“归并排序”直接反应出 $O(N \log_2 N)$，忽略了题目中“修改后”、“三分之一位置”的关键信息，属于审题不细或知识僵化。
- **选项C**: [干扰] — 针对“对数性质混淆”的错误认知。$\log_{1/3} N$ 为负值（当 $N>1$），时间复杂度不可能为负，这是一个明显的数学错误选项，用于排除完全不懂对数性质的学生，或者作为极端干扰项。
- **选项D**: [正确] — 正确推导结果。递归树的最长路径是每次取 $2/3$ 的部分，深度为 $\log_{3/2} N$，每层合并代价总和为 $N$，故总复杂度为 $N \log_{3/2} N$。
- **干扰策略**: 概念混淆（A与D的对数底数混淆）+ 惯性思维（B）+ 数学常识排除（C）

## 核心陷阱
- **核心陷阱**: **递归深度的判定依据**。在非平衡分治中，时间复杂度的对数底数由**最大**子问题的比例决定（即递归树的最长路径），而不是最小子问题，也不是两者的平均值。本题中最大子问题比例为 $2/3$，因此底数为 $1/(2/3) = 3/2$。

## 考察能力
本题核心考察学生对**非平衡分治算法递归式建模**的能力，以及通过**递归树法分析算法复杂度**时，对**递归深度（最长路径）**与**每层代价**关系的深刻理解。
