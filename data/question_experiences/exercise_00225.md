# 练习题 Q1 — 完全k叉树节点数关系推导

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/二叉树
- **难度**: 待评估

## 题干原文
在完全 k 叉树中，每个内部节点恰好有 k 个子节点或没有子节点。当该树包含 n 个内部节点时，其叶子节点的数量为（ ）：
A: nk
B: (n−1)k+1
C: n(k−1)+1
D: n(k−1)

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“完全k叉树”的定义以及树的基本性质（节点度数与总数的关系）。这不是简单的术语记忆（1-2分），因为题目没有直接给出公式，而是给出了结构定义，需要考生调用“总节点数 = 内部节点 + 叶子节点”以及“边数 = 总节点数 - 1”这两个核心概念进行关联。
- **K2 = 2**: 评分理由。一旦建立了方程，计算过程非常直接。主要是简单的代数变形：$nk = (n+L) - 1 \Rightarrow L = nk - n + 1 = n(k-1) + 1$。不涉及复杂的数值计算或多级换算，属于低难度的代数代入。
- **K3 = 2**: 评分理由。推演步骤较少。核心逻辑链条为：1. 计算总边数（由内部节点产生）；2. 计算总节点数（由内部节点和叶子节点组成）；3. 利用树的基本性质（边数 = 节点数 - 1）建立等式。这是一个标准的2-3步逻辑推导，无需记忆中间状态或复杂的多步串行推演。
- **K4 = 2**: 评分理由。题目条件明确，“完全k叉树”且“每个内部节点恰好有k个子节点”，没有明显的隐含前提或反直觉陷阱。唯一的潜在难点是区分“完全k叉树”与“满k叉树”或普通k叉树，但题干已明确定义了内部节点的子节点数量，排除了歧义。属于常规注意点。
- **K5 = 1**: 评分理由。本题仅涉及数据结构中树的单一模块，不需要跨越操作系统、计算机网络或组成原理等其他子系统，也没有不同数据结构之间的状态传递。

- **雷达形状**: 均衡偏基础型（K1-K3略高，K4-K5低）。整体难度较低，主要考察对基本性质的理解和简单代数推导能力。

## 考察模式
- **模式**: 推理型
- **理由**: 虽然最终结果是代数表达式，但解题核心不在于记忆公式（概念型），也不在于复杂数值计算（计算型），而在于利用树的结构性质（边与节点的关系）进行逻辑推导。考生需要构建数学模型来解决结构问题。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：认为叶子节点数等于内部节点数乘以k。这类学生可能混淆了“子节点总数”与“叶子节点数”。在完全k叉树中，内部节点产生的子节点总数确实是 $nk$，但这些子节点中，除了最底层的叶子节点外，上一层的子节点可能也是内部节点（但在本题定义的“完全k叉树”且“内部节点恰好k个子”的语境下，通常指满k叉树性质，或者通过边数推导更严谨）。更常见的错误是直接用 $nk$ 当作叶子数，忽略了根节点不是叶子，且子节点中可能包含新的内部节点（尽管在满k叉树中，除了最后一层，其他都是内部节点，但直接乘k逻辑不通）。实际上，$nk$ 是树中所有边的数量，也是所有非根节点的数量。如果误以为所有非根节点都是叶子，就会选A。
- **选项B**: [干扰] — 针对错误认知：代数变形错误。可能是将 $n(k-1)+1$ 错误展开或记忆偏差，类似于 $(n-1)k+1 = nk - k + 1$，与正确答案 $nk - n + 1$ 不同。这类学生可能在推导过程中符号处理出错。
- **选项C**: [正确] — 正确答案。推导过程：设叶子节点数为 $L$。总节点数 $N = n + L$。因为每个内部节点有 $k$ 个子节点，所以总边数 $E = n \times k$。在树中，边数 $E = N - 1$。因此 $nk = (n + L) - 1$，解得 $L = nk - n + 1 = n(k-1) + 1$。
- **选项D**: [干扰] — 针对错误认知：漏加1。这类学生可能记得公式大致是 $n(k-1)$，但忘记了树的基本性质中“节点数 = 边数 + 1”这个“+1”的来源（即根节点没有父边）。或者在代数移项时出错，$nk - n$ 后忘记加1。

- **干扰策略**: 概念混淆（A选项混淆边数与叶子数）、计算陷阱（B、D选项为代数变形错误）。

## 核心陷阱
- **核心陷阱**: 混淆“子节点总数”与“叶子节点数”。许多学生看到“k个子节点”和“n个内部节点”，直觉反应是 $n \times k$，从而误选A。必须通过“边数 = 节点数 - 1”这一桥梁进行严谨推导，才能发现 $nk$ 实际上是总节点数减1，而非叶子节点数。

## 考察能力
一句话概括本题核心考察的能力：利用树的基本性质（边与节点关系）建立方程并求解结构参数的代数推导能力。
