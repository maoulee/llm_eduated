# 2018 Q41 — 数组中未出现的最小正整数算法设计

## 基本信息
- **年份**: 2018  **题位**: Q41  **题型**: 综合题
- **知识点**: DS-1 > 1.2 算法和算法评价 > 算法效率度量, DS-1 > 1.2 算法和算法评价 > 时间复杂度, DS-1 > 1.2 算法和算法评价 > 空间复杂度
- **题位域**: 待标注  **科目**: 数据结构

## 题干原文
给定一个含 n(n≥1) 个整数的数组，请设计一个在时间上尽可能高效的算法，找出数组中未出现的最小正整数。例如，数组{-5, 3, 2, 3}中未出现的最小正整数是 1；数组{1, 2, 3}中未出现的最小正整数是 4。要求：
(1) 给出算法的基本设计思想。
(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
(3) 说明你所设计算法的时间复杂度和空间复杂度。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“时间复杂度”、“空间复杂度”以及“哈希映射/标记数组”的基本概念。不是4分因为不需要辨析多个易混的高级数据结构概念，核心概念较为单一且基础。
- **K2 = 2**: 评分理由。算法中涉及的主要计算是数组索引的映射（`A[i] - 1`）和简单的赋值操作，没有复杂的数学计算或多级换算，属于低难度的单步代入。
- **K3 = 3**: 评分理由。解题过程包含两个主要串行步骤：第一步遍历原数组进行标记，第二步遍历标记数组查找第一个未标记位置。逻辑链条清晰，步数在3-5步之间，属于标准推演难度。
- **K4 = 4**: 评分理由。存在显著的隐含前提和边界陷阱。首先，必须意识到结果的范围仅限于 `1` 到 `n+1`，这是解题的关键突破口；其次，必须处理数组中非正整数和大于 `n` 的整数，若直接作为索引会导致越界错误；最后，需处理 `1~n` 全部出现时返回 `n+1` 的特殊情况。这些隐含条件若未识别，算法将无法通过或效率低下。
- **K5 = 2**: 评分理由。主要涉及单一的数据结构（数组）及其辅助标记数组。虽然涉及两个数组之间的状态传递（原数组值映射到标记数组），但逻辑是单向且解耦的，不涉及复杂子系统间的深度耦合或状态互影响。
- **雷达形状**: 偏向于“条件路由”维度的突出型。K4较高，K1-K3中等，K5较低。整体呈现一个在“隐含条件识别”方向上突出的不规则五边形。

## 考察模式
- **模式**: 算法设计型
- **理由**: 题目明确要求设计一个满足特定效率要求（时间尽可能高效）的算法，并给出设计思想、代码实现及复杂度分析。这属于典型的数据结构算法设计题，重点在于利用空间换时间的策略来优化时间复杂度。

## 解题思路分析
- **核心思路**: 利用“空间换时间”的策略。由于数组长度为 `n`，未出现的最小正整数必然在 `1` 到 `n+1` 之间。因此，可以创建一个长度为 `n` 的辅助标记数组 `B`，用于记录 `1` 到 `n` 这些正整数是否在原数组 `A` 中出现过。
- **关键步骤**:
    1.  **初始化**: 创建长度为 `n` 的辅助数组 `B`，初始值全为 0。
    2.  **标记阶段**: 遍历原数组 `A`。对于每个元素 `A[i]`，如果 `0 < A[i] <= n`，则将 `B[A[i]-1]` 标记为 1。忽略 `A[i] <= 0` 或 `A[i] > n` 的元素，因为它们不影响 `1~n` 范围内的缺失值判断，且能避免数组越界。
    3.  **查找阶段**: 遍历辅助数组 `B`。找到第一个值为 0 的下标 `i`，则 `i+1` 即为未出现的最小正整数。
    4.  **边界处理**: 如果 `B` 中所有位置均为 1，说明 `1` 到 `n` 都已出现，此时返回 `n+1`。
- **易错点**:
    1.  **索引越界**: 直接使用 `A[i]` 作为 `B` 的索引，未判断 `A[i]` 的范围，导致 `A[i] <= 0` 或 `A[i] > n` 时程序崩溃。
    2.  **结果范围错误**: 误以为结果可能在 `n+1` 之外，或者忘记处理 `1~n` 全部存在时返回 `n+1` 的情况。
    3.  **效率低下**: 采用排序或双重循环查找，导致时间复杂度达到 `O(n^2)` 或 `O(n log n)`，不符合“时间上尽可能高效”的要求。

## 核心陷阱
- **核心陷阱**: **结果范围的界定与非法值的过滤**。
    很多考生会试图处理所有整数，或者使用哈希表（虽然也是 `O(n)` 但常数较大且空间开销可能更高，且题目暗示使用数组）。最大的陷阱在于没有意识到**答案的上界是 `n+1`**。如果数组中有 `n` 个不同的正整数，它们最多覆盖 `1` 到 `n`，因此缺失的最小正整数不可能超过 `n+1`。基于这个洞察，才能将问题转化为对 `1~n` 的标记问题，从而使用 `O(n)` 空间的数组进行 `O(n)` 时间的查找。同时，必须严格过滤掉 `<=0` 和 `>n` 的值，否则会导致数组越界访问。

## 考察能力
本题核心考察在约束条件下（时间效率优先）进行算法设计的能力，特别是利用数学性质缩小搜索空间，并通过空间换时间策略实现线性时间复杂度解决查找问题的能力。
