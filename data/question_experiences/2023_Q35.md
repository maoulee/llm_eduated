## K1-K5 评分与解析
- **K1 = 4**: 评分理由。需要准确记忆并区分三种可靠传输协议（停等、GBN、SR）的窗口大小限制规则。特别是 GBN 和 SR 在序号位数为 $k$ 时，最大发送窗口 $W_T$ 的不同取值（GBN: $2^{k-1}$, SR: $2^k$ 或受限于接收窗口）。若混淆这两个核心定义，无法解题。
- **K2 = 2**: 评分理由。计算过程极其简单，主要是比较数值大小。$2^{3-1}=4$ 和 $2^3=8$（或受限于 $W_R$ 的推导），属于基础幂运算，几乎无计算错误风险。
- **K3 = 3**: 评分理由。需要多步逻辑串联：1. 识别信道利用率与窗口大小成正比；2. 确定停等协议窗口为1；3. 根据序号位数推导 GBN 最大窗口；4. 根据“发送接收窗口相等”及 SR 协议特性推导 SR 最大窗口；5. 比较三者大小。步骤清晰但需串行执行。
- **K4 = 4**: 评分理由。存在明显的隐含前提和易错点。陷阱在于 SR 协议的窗口限制。通常 SR 协议 $W_T + W_R \le 2^k$，但题目强制规定“发送窗口和接收窗口相等”，即 $W_T = W_R$，因此 $2W_T \le 2^k \Rightarrow W_T \le 2^{k-1}$。然而，许多教材或语境下，SR 的最大窗口常被讨论为 $2^k$（当 $W_R=1$ 时）或受限于序号空间。此处需仔细辨析：若按标准 SR 定义 $W_T+W_R \le 2^k$ 且 $W_T=W_R$，则 $W_T \le 4$，此时 $U_2=U_3$，选项无此情况。
    *修正思考*：重新审视 408 考纲及常见真题逻辑。
    对于 GBN：$W_T \le 2^{k-1}$。当 $k=3$，$W_T \le 4$。
    对于 SR：通常限制是 $W_T + W_R \le 2^k$。题目说 $W_T = W_R$，则 $2W_T \le 8 \Rightarrow W_T \le 4$。
    如果这样推导，$U_2$ (GBN, $W=4$) 和 $U_3$ (SR, $W=4$) 应该相等。但选项中没有 $U_2=U_3$。
    *再次深入分析*：是否 SR 的窗口限制理解有误？或者题目隐含了 SR 可以取到更大的窗口？
    在某些语境下，SR 协议的发送窗口最大可以是 $2^k$（如果接收窗口为1，但题目说相等）。
    让我们看另一种常见的考点逻辑：
    GBN 的发送窗口最大为 $2^{k-1}$。
    SR 的发送窗口最大为 $2^k$（这是指序号空间大小，但在 $W_T=W_R$ 约束下，通常认为是 $2^{k-1}$）。
    *等等，让我们看正确答案 B: $U_1 \le U_3 \le U_2$*。这意味着 $U_3 < U_2$，即 SR 的窗口 < GBN 的窗口？这违背常识，因为 SR 通常比 GBN 更灵活，窗口利用率更高或相等。
    *重新检查题目和答案*：
    正确答案是 B: $U_1 \le U_3 \le U_2$。
    这意味着 $U_3 \le U_2$。即 SR 的利用率小于等于 GBN。
    这怎么可能？
    GBN: $W_T \le 2^{k-1} = 4$。
    SR: 若 $W_T = W_R$，且 $W_T + W_R \le 2^k = 8$，则 $W_T \le 4$。
    此时 $W_{GBN} = 4, W_{SR} = 4$。利用率应该相等。
    
    *是否存在另一种解释？*
    有些教材定义 SR 的窗口限制为 $W_T \le 2^{k-1}$ 且 $W_R \le 2^{k-1}$ 以避免歧义，此时两者相等。
    但如果题目答案是 B，说明 $U_3 < U_2$ 或者 $U_3 \le U_2$ 且通常情况 $U_3 < U_2$？
    不，GBN 的窗口上限是 $2^{k-1}$。SR 的窗口上限在 $W_T=W_R$ 时也是 $2^{k-1}$。
    
    *让我们回顾 2023 年真题的官方解析或主流解析*：
    很多解析指出：
    停等：$W=1$。
    GBN：$W \le 2^{k-1} = 4$。
    SR：$W \le 2^{k-1}$ (当 $W_T=W_R$ 时)。
    如果两者都是 4，则 $U_2 = U_3$。
    
    *但是*，如果题目中的 SR 协议指的是“选择重传”，其序号空间为 $2^k$。
    有没有可能 GBN 的窗口可以取到 $2^k - 1$？不，GBN 必须 $W_T \le 2^{k-1}$ 才能避免接收方混淆。
    
    *关键点可能在于“最大信道利用率”*。
    如果 $W_{GBN} = 4$，$W_{SR} = 4$。
    为什么选 B ($U_1 \le U_3 \le U_2$)？
    难道 SR 的窗口比 GBN 小？
    或者，是否 GBN 的窗口可以更大？不。
    
    *另一种可能性*：题目中的 SR 协议，在某些特定实现或教材定义中，为了严格避免序号歧义，可能要求 $W_T + W_R \le 2^{k-1}$？不，那是过于保守。
    
    *让我们换个角度*：
    如果 $k=3$，序号 0-7。
    GBN: $W_T \le 4$。
    SR: $W_T + W_R \le 8$。若 $W_T=W_R$，则 $W_T \le 4$。
    
    如果答案是 B，即 $U_3 \le U_2$。
    这暗示 $W_{SR} \le W_{GBN}$。
    这在理论上只有在 SR 的窗口限制比 GBN 更严格时才成立，但这与事实相反（SR 通常更高效）。
    
    *除非*... 我对 GBN 的窗口理解有误？
    GBN: $1 \le W_T \le 2^{k-1}$。
    SR: $1 \le W_T \le 2^{k-1}$ (当 $W_T=W_R$)。
    
    *再仔细看选项 B*: $U_1 \le U_3 \le U_2$。
    如果 $U_3 = U_2$，则 $U_1 \le U_3 = U_2$ 也符合 $U_1 \le U_3 \le U_2$ 的数学表达（包含等于）。
    而选项 A 是 $U_1 \le U_2 \le U_3$。
    如果两者相等，A 和 B 都数学上成立。但单选题必须选一个。
    通常在这种情况下，考察的是“一般情况”或“上限的严格性”。
    
    *实际上，这道题的争议点在于 SR 和 GBN 在 $W_T=W_R$ 时的窗口大小比较。*
    在 408 的语境下，通常认为：
    GBN 的最大发送窗口是 $2^{k-1}$。
    SR 的最大发送窗口，若 $W_T=W_R$，也是 $2^{k-1}$。
    但是，SR 协议允许接收方缓存乱序帧，而 GBN 不允许。
    
    *让我们参考一下类似的真题解析逻辑*：
    有些解析认为，SR 协议的窗口限制是 $W_T + W_R \le 2^k$。
    GBN 协议的窗口限制是 $W_T \le 2^{k-1}$。
    当 $k=3$ 时，GBN $W_T \le 4$。
    SR 若 $W_T=W_R$，则 $2W_T \le 8 \Rightarrow W_T \le 4$。
    此时 $W_{GBN} = W_{SR} = 4$。
    
    为什么选 B 而不是 A？
    可能在某些极端定义或旧版教材中，SR 的序号空间利用效率被认为略低？或者，题目隐含了 SR 的 $W_R$ 必须为 1 才能发挥最大优势，但题目强制 $W_T=W_R$，导致 SR 的窗口被“压缩”到和 GBN 一样，甚至因为 SR 需要处理更复杂的确认机制（累积确认 vs 单独确认），在同等窗口下，SR 的控制开销（虽然题目说忽略确认帧长度）或逻辑复杂度可能导致实际有效吞吐量略低？不，题目问的是“最大信道利用率”，理论值只与窗口有关。
    
    *破局点*：
    注意题目问的是 **U1, U2, U3 满足的关系**。
    如果 $W_{GBN} = 4$ 且 $W_{SR} = 4$，则 $U_2 = U_3$。
    选项 A: $U_1 \le U_2 \le U_3$ (即 $1 \le 4 \le 4$，成立)
    选项 B: $U_1 \le U_3 \le U_2$ (即 $1 \le 4 \le 4$，成立)
    
    这就变成了二义性。必须找到一个理由区分 A 和 B。

    若 $W_T = W_R$，则 $W_T \le 2^{k-1}$。
