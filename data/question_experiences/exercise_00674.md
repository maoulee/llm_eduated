# 练习题 Q1 — 数据链路层/ALOHA协议冲突概率计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/数据链路层
- **难度**: 待评估

## 题干原文
考虑一个包含四个节点 S1、S2、S3 和 S4 的局域网。时间被划分为固定大小的时隙，节点只能在时隙开始时发起传输。如果同一时隙内有多个节点同时发送数据，则认为发生了冲突。S1、S2、S3 和 S4 在每个时隙生成帧的概率分别为 0.1、0.2、0.3 和 0.4。这四个站点中任意一个在第一个时隙无冲突地发送帧的概率是（ ）。
- 选项:
  A: 0.462
  B: 0.711
  C: 0.5
  D: 0.652
- 正确答案: A
- 解析（参考）: 解析
这四个站点在第一个时隙无冲突地发送帧的概率等于以下四种情况的概率之和：
S1 发送且其他节点不发送的概率
S2 发送且其他节点不发送的概率
S3 发送且其他节点不发送的概率
S4 发送且其他节点不发送的概率
计算公式为：
0.1 * (1 - 0.2) * (1 - 0.3) * (1 - 0.4)
+ (1 - 0.1) * 0.2 * (1 - 0.3) * (1 - 0.4)
+ (1 - 0.1) * (1 - 0.2) * 0.3 * (1 - 0.4)
+ (1 - 0.1) * (1 - 0.2) * (1 - 0.3) * 0.4
= 0.4404
- 知识标签: ['计算机网络/数据链路层']
- 知识域: CN-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“无冲突发送”在随机接入协议（如时隙ALOHA）中的定义，即“恰好有一个节点发送”。这属于标准的核心概念记忆，不涉及复杂辨析，但必须准确理解“无冲突”不等于“有发送”，也不等于“无发送”。
- **K2 = 4**: 评分理由。计算过程涉及4个独立事件的概率乘积，且需进行4次这样的乘法运算后求和。虽然单步计算简单，但小数乘法（如0.1*0.8*0.7*0.6）容易出错，且步骤较多，属于非2幂次的多级换算，计算负荷较高。
- **K3 = 2**: 评分理由。逻辑推演步骤清晰：识别互斥事件 -> 分别计算概率 -> 求和。仅需2-3步逻辑串联，无需记忆中间状态或复杂的状态机跳转。
- **K4 = 3**: 评分理由。存在常规注意点陷阱。学生容易混淆“无冲突”与“成功传输”（本题中无冲突即成功），或者错误地认为“无冲突”包括“无人发送”的情况（即空闲时隙）。此外，需注意各节点概率不同，不能简单套用均匀分布公式。
- **K5 = 1**: 评分理由。本题仅涉及数据链路层的介质访问控制机制，未涉及网络层路由、传输层连接或其他子系统，属于单系统内部问题。
- **雷达形状**: K2计算主导型，K4陷阱辅助型。整体呈现计算负荷高、逻辑链条短的特征。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于根据给定的概率模型，通过概率论的基本公式（乘法法则和加法法则）进行数值计算。虽然背景是计算机网络协议，但解题关键不在于协议机制的深层理解，而在于准确执行概率计算。

## 选项级分析
- **选项A**: [正确] — 对应正确计算结果。注意：参考解析给出的计算结果0.4404与选项A(0.462)存在数值差异，这可能是题目数据或选项设置的印刷错误/近似处理。但在考试情境下，A是唯一接近正确逻辑推导结果的选项（其他选项偏差极大）。*注：若严格按解析计算，0.4404最接近0.462（相对误差约5%），而其他选项误差更大。在实际408真题中，通常数值会精确匹配。此处假设A为预设正确答案。*
- **选项B**: [干扰] — 针对“互补事件”错误认知。学生可能计算了“发生冲突或空闲”的概率，或者错误地将所有节点发送概率相加后取补等错误逻辑。例如，1 - P(冲突) 若计算错误可能得到此值。
- **选项C**: [干扰] — 针对“直觉/平均化”错误认知。学生可能认为概率是0.1~0.4的平均值，或者随意猜测50%。这是一种典型的无依据猜测选项。
- **选项D**: [干扰] — 针对“忽略互斥性”或“简单相加”错误认知。学生可能直接将四个概率相加：0.1+0.2+0.3+0.4 = 1.0，然后错误地认为这是总概率，或者计算 P(至少一个发送) = 1 - P(全不发送) = 1 - (0.9*0.8*0.7*0.6) = 1 - 0.3024 = 0.6976，接近0.711或0.652。若学生误以为“无冲突”等于“至少有一个发送”，可能会选接近0.6976的选项。0.652可能是某种特定的错误组合计算结果。

- **干扰策略**: 计算陷阱与概念混淆。主要利用小数计算的繁琐性导致计算错误，以及混淆“无冲突（恰好1个）”与“非空闲（至少1个）”或“非冲突（0个或1个）”的概念。

## 核心陷阱
- **核心陷阱**: 概念界定不清。最大的陷阱在于对“无冲突地发送帧”的理解。
    1.  **错误理解1**：认为“无冲突”包括“没有人发送”（空闲时隙）。实际上，题目问的是“发送帧”，隐含了必须有帧发送。
    2.  **错误理解2**：认为“无冲突”就是“没有冲突发生”，即 P(0个发送) + P(1个发送)。如果这样计算，结果是 0.3024 + 0.4404 = 0.7428，接近选项B(0.711)或D(0.652)的区间，容易误导。
    3.  **计算陷阱**：各节点概率不同，不能直接使用 $N \cdot p \cdot (1-p)^{N-1}$ 公式，必须分项计算。

## 考察能力
本题核心考察考生对随机接入协议中“成功传输概率”定义的准确理解，以及在非均匀概率分布下进行多步独立事件概率计算的能力。
