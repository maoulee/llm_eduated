# 练习题 Q1 — LRTF调度算法与周转时间计算

- **来源**: 练习题  **题型**: 选择题

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“最长剩余时间优先（LRTF）”这一特定调度算法的定义，以及“周转时间”的计算公式。这属于标准的核心概念记忆，不涉及极偏门的术语，但必须准确理解LRTF与SRTF（最短剩余时间优先）的区别。
- **K2 = 2**: 评分理由。计算过程主要是简单的整数加减法和最后的平均值除法（(12+13+14)/3 = 13）。数字较小且整除，计算负担极低，不易出错。
- **K3 = 4**: 评分理由。这是本题的核心难点。LRTF算法具有“饥饿”短进程的特性，导致调度序列复杂。考生需要模拟从t=0到t=14的每一个时间片（或状态变化点），跟踪三个进程的剩余时间，并根据规则（剩余时间最长优先，平局选ID小）决定下一个执行的进程。推演步骤多（约14个时间单位的状态更新），且中间状态容易记混，属于高步数串行推演。
- **K4 = 3**: 评分理由。存在常规注意点：一是“平局时优先选择进程 ID 较小的进程”这一打破平局的规则容易被忽略；二是LRTF算法本身可能导致短进程长期得不到执行，考生需意识到这种非直观的执行顺序（即短进程p0最后才完成）。
- **K5 = 1**: 评分理由。本题仅涉及CPU调度子系统，不涉及内存管理、I/O操作或文件系统等其他子系统的状态传递或耦合。
- **雷达形状**: K3推演主导型（K3显著高于其他维度，K1中等，K2/K5低）

## 考察模式
- **模式**: 推理型
- **理由**: 虽然最终需要计算一个数值，但解题的关键不在于公式代入，而在于根据LRTF算法的规则，逻辑推演出正确的进程执行序列。如果推演错误，计算结果必然错误。因此，核心能力在于对调度机制的动态模拟和逻辑推理。

## 选项级分析
- **选项A**: [正确] — 正确模拟了LRTF调度过程，得出p0在t=12完成，p1在t=13完成，p2在t=14完成，平均值为13。
- **选项B**: [干扰] — 可能源于对平局处理规则的误解，或者在推演过程中某一步骤错误地让短进程提前执行，导致周转时间略微缩短或延长，计算误差导致结果为14。例如，若误以为p0在t=11完成，p1在t=13，p2在t=14，平均为12.67（非整数），或者某种错误的序列导致总和为42。更可能的情况是考生混淆了LRTF和某种其他算法，或者在计算平均值时出错（如(12+13+15)/3=13.33取整？不太像）。另一种可能是误算了某个进程的完成时间，例如认为p1在t=14完成，p2在t=13完成（违反LRTF逻辑），导致总和变化。
- **选项C**: [干扰] — 可能源于将LRTF误认为是FCFS（先来先服务）或SJF（短作业优先）的变体，或者完全错误的调度序列。例如，如果按照FCFS（p0, p1, p2），周转时间分别为2, 6, 14，平均为(2+6+14)/3 = 7.33，不符。如果按照SJF（p0, p1, p2），周转时间分别为2, 6, 14，平均7.33。如果按照SRTF（最短剩余时间优先），p0(2), p1(4), p2(8) -> p0先完(t=2), 剩p1(4), p2(8) -> p1先完(t=6), 剩p2(8) -> p2完(t=14)。平均(2+6+14)/3 = 7.33。选项C的15可能来自完全错误的推演，比如认为所有进程都串行执行且顺序混乱，或者计算错误。
- **选项D**: [干扰] — 可能源于对LRTF极端情况的误解，认为短进程会被无限期推迟，或者在计算周转时间时错误地加上了等待时间以外的其他时间。或者，考生可能错误地认为p0最后完成，且完成时间很晚。例如，若错误推演导致p0在t=14, p1在t=13, p2在t=12（不可能，因为p2最长），或者总和为48的情况。

**干扰策略**: 概念混淆（LRTF vs SRTF/FCFS）与 推演错误（状态跟踪失误）。由于LRTF不是408大纲中最常考的算法（常考FCFS, SJF, RR, SRTF），考生容易因不熟悉其“长作业优先”的特性而推演出错误的执行序列。

## 核心陷阱
- **核心陷阱**: **LRTF算法的“反直觉”执行顺序与平局处理规则**。
  1.  **算法特性误解**：大多数考生熟悉SRTF（短作业优先），容易惯性思维认为短进程会先执行。LRTF恰恰相反，长进程（剩余时间多）优先，导致短进程（p0, p1）在长进程（p2）执行期间被频繁抢占或推迟，直到长进程剩余时间减少到与短进程相当或更短时，短进程才有机会执行。
  2.  **平局规则**：当剩余时间相同时，必须选择ID较小的进程。例如在t=4时，p1剩余3，p2剩余4，p2执行；在t=5时，p1剩余3，p2剩余3，此时平局，应选p1（ID=1 < ID=2）。若忽略此规则，选p2，则后续序列全错。

## 考察能力
本题核心考察考生对**非抢占式/抢占式调度算法动态执行过程的模拟能力**，特别是对**最长剩余时间优先（LRTF）**这一较少见算法的规则理解及**多进程状态跟踪**的逻辑推理能力。
