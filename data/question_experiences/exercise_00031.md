# 练习题 Q1 — 8086实模式物理地址计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
当微处理器（8086）在实模式下运行时，已知代码段寄存器 CS=1000 和指令指针 IP=E000，求下一条被执行指令的内存地址（ ）。

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆8086实模式下物理地址的计算公式（物理地址 = 段地址 << 4 + 偏移地址）。这是计算机组成原理或操作系统中关于存储器管理的核心定义，属于标准的基础认知需求。不是1分因为不记忆公式无法解题；不是4-5分因为不需要辨析多个易混概念（如保护模式下的段描述符等）。
- **K2 = 2**: 评分理由。计算过程涉及十六进制数的移位（乘以16）和加法。由于是十六进制，左移4位等效于末尾补0，计算极其简单（1000 -> 10000），且加法无进位或进位极少（10000 + E000 = 1E000），属于“2的幂友好”或进制对齐的简单计算，出错概率低。
- **K3 = 1**: 评分理由。从输入到输出仅需一步直接代入公式计算，无需多步串行推演或中间状态记忆。
- **K4 = 2**: 评分理由。存在常规注意点，即必须意识到“实模式”下使用的是段基址左移4位的机制，而非直接相加或保护模式下的复杂映射。若忽略“左移4位”这一隐含规则（即段基址实际是16位，物理地址20位），会直接导致错误。属于常规注意点，非深层陷阱。
- **K5 = 1**: 评分理由。本题仅涉及CPU寄存器与内存地址映射这一单一子系统内的计算，无需跨越不同子系统（如网络协议栈、文件系统、进程调度等）传递状态。

- **雷达形状**: K2计算型（K1基础支撑，K2轻微计算，其余维度极低）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于应用特定公式进行数值计算。虽然涉及概念（实模式地址映射），但最终解题动作是执行十六进制算术运算，而非逻辑推理或概念辨析。

## 选项级分析
- **选项A**: [干扰] — 针对“直接相加”的错误认知。学生可能忘记段地址需要左移4位（乘以16），直接将CS(1000)与IP(E000)相加得到1000+E000=F000，但选项A是10E00，这可能是学生试图拼接字符串或错误理解移位方向（如右移或错位）产生的结果，或者是对十六进制加法进位理解混乱。更常见的直接相加错误结果是F000（选项C），但10E00可能源于将CS视为10000（已移位）但IP未处理或错误拼接。*修正分析*：若学生错误地认为物理地址是 `CS * 10 + IP` (十进制思维混入) 或其他错误拼接，可能选A。但在十六进制中，1000+E000=F000。10E00 看起来像是 `1000` 和 `E000` 的某种错误拼接（如 `10` + `E000`? 不通）。更可能的错误路径是：学生记得要移位，但移位位数搞错，或者将CS=1000H误读为其他值。实际上，选项A (10E00) 是一个典型的“看起来像地址但数值不对”的干扰项，可能源于计算 `10000 + E00` (IP看错) 或类似低级错误。
- **选项B**: [正确] — 正确应用公式：`1000H << 4 = 10000H`，`10000H + E000H = 1E000H`。
- **选项C**: [干扰] — 针对“忽略段基址移位”的错误认知。学生直接将CS和IP相加：`1000H + E000H = F000H`。这是最常见的错误，忽略了8086段地址是16位，物理地址是20位，段基址需要左移4位（乘以16）才能对齐。
- **选项D**: [干扰] — 针对“移位方向或位数错误”的认知。1000E 可能是学生将IP左移了？或者将CS和IP的位置搞反？例如 `E000 << 4 = E0000`，再加 `1000` 得 `E1000`（不在选项中）。或者学生错误地认为物理地址是 `IP << 4 + CS`？`E0000 + 1000 = E1000`。1000E 这个数值比较奇怪，可能是 `1000` (CS) 和 `E` (IP的高位?) 的错误拼接，或者是将 `1000` 当作偏移，`E000` 当作段基址移位后 `E0000`，然后错误相加？更可能的是，这是针对那些完全不懂十六进制加法，随意拼接数字的学生设计的干扰项。

- **干扰策略**: 概念混淆（忽略移位规则）与计算陷阱（十六进制加法错误）

## 核心陷阱
- **核心陷阱**: 忽略8086实模式下段地址需要**左移4位**（即乘以16）才能转换为物理地址的基址。许多初学者会直接将段寄存器的值与偏移量相加，从而落入选项C的陷阱。

## 考察能力
一句话概括本题核心考察的能力：掌握8086微处理器在实模式下的物理地址形成机制及十六进制算术运算能力。
