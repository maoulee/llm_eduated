# 练习题 Q1 — 十进制小数转二进制

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 计算机组成原理/数制
- **难度**: 待评估

## 题干原文
十进制数 42.75 的二进制等价形式是（ ）
A: 101010.110
B: 100110.101
C: 101010.101
D: 100110.110

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆“整数除2取余”和“小数乘2取整”这两个核心转换规则。不是2分因为仅靠直觉无法解题，必须调用明确的算法定义；不是4分因为不涉及多个易混概念（如补码、移码等）的辨析。
- **K2 = 2**: 评分理由。计算过程非常友好。整数42接近2的幂（32+8+2），小数0.75是1/2+1/4，均为2的负幂次之和，计算量极小，几乎不可能算错。
- **K3 = 2**: 评分理由。推演步骤清晰且独立。整数部分需约5-6步除法，小数部分需2-3步乘法。步骤在3-5步以内，且无需记忆复杂的中间状态，串行推演压力低。
- **K4 = 1**: 评分理由。无隐含前提或陷阱。题目直接要求转换，没有负数、精度截断、科学计数法等额外条件，属于最直接的规则应用。
- **K5 = 1**: 评分理由。单系统内部转换。仅涉及数制表示，不涉及CPU内部数据通路、存储器映射或指令集架构等其他子系统。
- **雷达形状**: K2/K3主导的基础计算型。整体分数偏低，呈现扁平状，属于典型的入门级基础题。

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于执行标准的进制转换算法（除2取余法、乘2取整法），通过具体的数值计算得出结果，而非概念辨析或逻辑推理。

## 选项级分析
- **选项A**: [正确] — 42 = 32 + 8 + 2 = $101010_2$；0.75 = 0.5 + 0.25 = $0.11_2$。组合后为 $101010.11_2$（即101010.110）。
- **选项B**: [干扰] — 整数部分错误，小数部分错误。整数 $100110_2 = 32 + 4 + 2 = 38 \neq 42$；小数 $0.101_2 = 0.5 + 0.125 = 0.625 \neq 0.75$。针对完全不会计算或随机猜测的学生。
- **选项C**: [干扰] — 整数部分正确，小数部分错误。整数 $101010_2 = 42$ 正确；小数 $0.101_2 = 0.625$。针对整数部分算对，但小数部分混淆了 $0.75 (0.11)$ 和 $0.625 (0.101)$ 的学生，或者误以为 $0.75 \times 2 = 1.5$ 取1后剩余0.5，下一步 $0.5 \times 2 = 1.0$ 取1，但错误地多算了一位或记错权重。
- **选项D**: [干扰] — 整数部分错误，小数部分正确。整数 $100110_2 = 38$；小数 $0.110_2 = 0.75$ 正确。针对小数部分算对，但整数部分位权搞错（如将42误算为38，或者二进制位排列错误）的学生。

- **干扰策略**: 组合错误型。通过混合整数和小数的常见计算错误（位权错误、小数权重混淆）来覆盖不同知识盲区的考生。

## 核心陷阱
- **核心陷阱**: 小数部分的位权对应关系。考生容易混淆 $0.1_2 (0.5)$, $0.01_2 (0.25)$, $0.101_2 (0.625)$ 和 $0.11_2 (0.75)$ 之间的对应关系，特别是在快速心算时，容易将 $0.75$ 误认为是 $0.101$（因为十进制75看起来像二进制101的某种映射，这是典型的直觉陷阱）。

## 考察能力
掌握十进制整数与小数分别转换为二进制的标准算法（除2取余、乘2取整）及位权概念。
