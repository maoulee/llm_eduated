# 练习题 Q1 — IPv6 寻址模式辨析

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/网络层
- **难度**: 待评估

## 题干原文
IPv6 不支持以下哪种寻址模式（ ）？

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。本题属于标准的基础概念记忆题。考生需要准确记忆 IPv6 支持的三种寻址模式（单播、多播、任播）以及它不再支持广播这一核心事实。不需要复杂的推导，但需要区分 IPv4 和 IPv6 在寻址机制上的关键差异，符合“需一个核心定义”的锚点。
- **K2 = 1**: 评分理由。本题不涉及任何数值计算、单位换算或公式代入，完全属于定性判断，计算需求微弱。
- **K3 = 1**: 评分理由。解题过程无需多步串行推演，直接根据知识点匹配即可得出结论，逻辑链条极短。
- **K4 = 2**: 评分理由。存在轻微的“惯性思维”陷阱。由于 IPv4 中广播非常常见，部分考生可能下意识认为 IPv6 也保留广播。但这属于常规注意点，并非深奥的隐含前提或反直觉陷阱，因此评分较低。
- **K5 = 1**: 评分理由。本题仅涉及网络层 IP 地址分类这一单一子系统，无需跨越传输层、链路层或其他模块进行状态联动。
- **雷达形状**: K1 主导型（基础记忆型）。雷达图在 K1 维度突出，其余维度均处于低位，呈现典型的“概念辨析”特征。

## 考察模式
- **模式**: 概念型
- **理由**: 题目直接询问协议特性（支持/不支持的寻址模式），考察的是对 IPv6 协议规范中地址类型定义的准确记忆和理解，不涉及计算或复杂逻辑推理。

## 选项级分析
- **选项 A**: [干扰] — 针对“IPv6 是否保留基本通信功能”的疑虑。单播是网络通信的基础，IPv6 当然支持。选此项的学生可能对 IPv6 的基本功能存在严重误解。
- **选项 B**: [干扰] — 针对“多播与广播混淆”的认知。IPv6 保留了多播，且多播在 IPv6 中地位更重要。选此项的学生可能误以为 IPv6 简化了所有组通信方式。
- **选项 C**: [正确] — IPv6 设计之初就取消了广播地址，其功能由多播地址（如 `ff02::1` 代表所有节点）替代。这是 IPv6 区别于 IPv4 的重要特征之一。
- **选项 D**: [干扰] — 针对“任播是 IPv6 新增特性”的知识点盲区。任播（Anycast）是 IPv6 正式引入并标准化的寻址模式，而 IPv4 中任播通常作为非标准实现或应用层特性存在。选此项的学生可能不知道任播是 IPv6 的原生支持特性。
- **干扰策略**: 概念混淆。利用 IPv4 中“广播”的普遍性作为强干扰项，同时利用“任播”在 IPv4 中不常见但在 IPv6 中标准化的反差来制造认知冲突。

## 核心陷阱
- **核心陷阱**: **IPv4 思维惯性**。考生容易将 IPv4 中广泛使用的“广播”机制默认迁移到 IPv6 中，忽略了 IPv6 用“多播”替代“广播”的设计哲学。

## 考察能力
一句话概括本题核心考察的能力：准确记忆并区分 IPv6 协议中特有的寻址模式及其与 IPv4 的关键差异。
