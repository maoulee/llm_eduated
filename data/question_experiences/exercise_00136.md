# 练习题 Q1 — 短作业优先调度与平均响应时间优化

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
五个作业 A、B、C、D 和 E 正在就绪队列中等待。它们的预计运行时间分别为 9、6、3、5 和 x。所有作业在时间零时进入就绪队列。如果 3 < x < 5，要使平均响应时间最小，它们必须按（ ）顺序运行。
- 选项:
  A: B, A, D, E, C
  B: C, E, D, B, A
  C: E, D, C, B, A
  D: C, B, A, E, D
- 正确答案: B
- 解析（参考）: 我们通过最小化平均等待时间来求解，并取 x = 4
BT
: 执行时间（Burst Time）
CT
: 完成时间（Comp
P
: 作业（Process）
AWT
: 平均等待时间（Average Waiting Time）
AT
: 到达时间（Arrival Time）
WT
: 等待时间（Waiting Time）
选项 (B) 给出的序列能获得最小的平均等待时间
- 知识标签: ['操作系统/CPU调度']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“短作业优先（SJF）”调度算法的核心定义，即为了最小化平均等待时间/响应时间，应优先执行运行时间短的作业。同时需要理解“响应时间”与“等待时间”在非抢占式且同时到达场景下的等价性。不是4分因为不需要辨析多个易混概念（如SJF与SRTF的区别），只需应用单一核心原则。
- **K2 = 2**: 评分理由。计算量极小。题目给出了 $3 < x < 5$ 的范围，解题者只需选取一个中间值（如 $x=4$）或直接进行不等式比较，无需复杂的多级换算或大数运算。
- **K3 = 2**: 评分理由。推演步骤简单。第一步：确定所有作业同时到达；第二步：根据SJF原则，将作业按运行时间升序排列；第三步：对比选项。整个过程不超过3步，且逻辑线性，无需记忆中间状态。
- **K4 = 3**: 评分理由。存在隐含前提和概念陷阱。陷阱1：题目问“平均响应时间”，但解析和常规解法常转化为“平均等待时间”。在同时到达且非抢占的情况下，响应时间 = 等待时间，这一等价转换需要考生意识到。陷阱2：变量 $x$ 的范围处理，考生需判断 $x$ 与已知数值（3和5）的大小关系，从而确定E在序列中的相对位置。
- **K5 = 1**: 评分理由。本题仅涉及CPU调度子系统，不涉及内存管理、文件系统或I/O等其他子系统的状态传递或耦合。

- **雷达形状**: K4陷阱型（概念辨析与隐含条件识别为主要难点，计算与推演难度较低）

## 考察模式
- **模式**: 推理型
- **理由**: 本题并非直接考查公式计算，而是考查对调度算法设计目标（最小化平均等待时间）的理解，并将其转化为具体的排序逻辑。考生需要推理出“同时到达”+“最小化平均等待时间” $\rightarrow$ “短作业优先（SJF）” $\rightarrow$ “按运行时间升序排列”这一逻辑链条。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：完全随机或误解为长作业优先。该序列中A(9)排在第二位，严重违背SJF原则，导致平均等待时间极大。这类学生可能未理解SJF的核心思想，或误以为某种其他策略（如FCFS但顺序错误）。
- **选项B**: [正确] — 符合SJF原则。已知运行时间：C=3, D=5, B=6, A=9。对于E，已知 $3 < x < 5$。因此，运行时间排序为：$3 (C) < x (E) < 5 (D) < 6 (B) < 9 (A)$。即顺序为 C, E, D, B, A。
- **选项C**: [干扰] — 针对错误认知：误判 $x$ 的大小或排序逻辑。该选项顺序为 E, D, C... 暗示 $x < 3$ 或者考生错误地认为E应该最先运行。如果考生错误地认为 $x$ 是最小的，或者混淆了升序/降序，可能会选此项。实际上 $x > 3$，所以C必须在E之前。
- **选项D**: [干扰] — 针对错误认知：部分排序错误或忽略 $x$ 的约束。该选项顺序为 C, B, A... 将长作业B和A提前，完全违背SJF。或者考生可能试图构造一个看似合理的序列但忽略了 $x$ 与 5 的关系，导致D和E的位置混乱。

- **干扰策略**: 概念混淆（响应时间vs等待时间）、排序逻辑错误（忽略 $x$ 的范围约束）、随机排列。

## 核心陷阱
- **核心陷阱**: **变量 $x$ 的相对大小判断** 以及 **响应时间与等待时间的等价性**。
    1.  考生必须准确判断 $x$ 在 3 和 5 之间，从而确定 E 必须排在 C 之后、D 之前。
    2.  考生需明确在非抢占、同时到达的场景下，最小化平均响应时间等同于最小化平均等待时间，进而直接应用 SJF 算法（按运行时间升序）。

## 考察能力
一句话概括本题核心考察的能力：在给定约束条件下，运用短作业优先（SJF）调度算法原理，通过比较作业运行时间确定最优执行序列以最小化平均等待/响应时间的逻辑推理能力。
