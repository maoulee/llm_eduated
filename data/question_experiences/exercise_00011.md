# 练习题 Q1 — B+树高度与节点访问次数计算

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 操作系统
- **知识点**: 数据结构/B 树
- **难度**: 待评估

## 题干原文
在一个包含 100 万条记录的文件中，若使用 B+ 树索引且树的阶数为 100，则最多需要访问多少个节点？（ ）
A: 5
B: 4
C: 3
D: 10

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握 B+ 树的基本定义，特别是“阶数”与“最小指针数”的关系（$\lceil m/2 \rceil$），以及 B+ 树叶子节点存储数据、内部节点仅存索引的特性。若不清楚阶数定义或最小填充因子规则，无法入题。
- **K2 = 3**: 评分理由。涉及简单的除法运算和取整逻辑。虽然数字较大（$10^6$），但通过科学计数法或逐步除法（$10^6 \to 2\times10^4 \to 400 \to 8 \to 1$）可以简化计算。非 2 的幂次且需多次迭代，属于标准计算难度。
- **K3 = 3**: 评分理由。解题过程需要多步串行推演：从根节点开始，逐层向下计算每层最少能容纳的节点数，直到覆盖所有记录。步骤清晰但需保持中间状态（每层的节点数），属于 3-5 步的推演。
- **K4 = 4**: 评分理由。存在关键隐含前提和易错点。首先，“最多访问节点数”对应的是树的“最大高度”，这要求使用“最小填充因子”（即每个节点最少指针数）来计算，而非平均或最大填充因子。其次，需明确 B+ 树中“访问节点”通常指从根到叶子的路径长度（即树高），且根节点至少存在。若误用最大指针数或忽略根节点特殊性，极易出错。
- **K5 = 1**: 评分理由。本题仅涉及 B+ 树这一单一数据结构模型，无需跨越文件系统、内存管理或其他操作系统模块进行状态传递或联动分析。
- **雷达形状**: K4 陷阱型（K4 显著高于其他维度，主要难点在于对“最坏情况”条件的识别和隐含前提的把握）

## 考察模式
- **模式**: 计算型
- **理由**: 题目核心在于通过给定的参数（记录数、阶数），利用 B+ 树的性质公式进行数值计算，得出树的高度。虽然涉及概念理解，但最终落脚点在于具体的数值推导。

## 选项级分析
- **选项 A**: [干扰] — 针对计算错误或层级多算一层的错误认知。学生可能在计算倒数第四层时，误以为 8 个节点还需要再分一层，或者在除法取整时出现偏差，导致得出 5 层。
- **选项 B**: [正确] — 正确计算结果。$10^6 / 50 = 20000$ (第2层), $20000 / 50 = 400$ (第3层), $400 / 50 = 8$ (第4层), $8 / 50 = 1$ (第5层? 不，根节点是第1层)。
    *   修正推导逻辑以匹配答案 B (4层)：
        *   根节点 (Layer 1): 1 个节点。
        *   Layer 2: 最多 $1 \times 50 = 50$ 个节点。
        *   Layer 3: 最多 $50 \times 50 = 2500$ 个节点。
        *   Layer 4: 最多 $2500 \times 50 = 125,000$ 个节点。
        *   Layer 5: 最多 $125,000 \times 50 = 6,250,000$ 个节点。
        *   因为 $1,000,000 < 6,250,000$，所以数据可以存储在 Layer 5 的叶子节点中？
        *   **注意**：这里需要仔细审视“访问节点数”的定义。通常 B+ 树查询是从根到叶子。
        *   如果树高为 $h$，访问节点数为 $h$。
        *   让我们重新检查参考解析的逻辑：
            *   参考解析说：最后一层节点数 $2\times10^4$，倒数第二层 400，倒数第三层 8，倒数第四层 1。
            *   这意味着：
                *   Layer 4 (Root): 1 node.
                *   Layer 3: 8 nodes.
                *   Layer 2: 400 nodes.
                *   Layer 1 (Leaves): $20,000$ nodes.
            *   总层数 = 4 层。
            *   验证容量：Layer 1 (Leaves) 有 20,000 个节点。每个叶子节点最少存多少记录？题目未给出叶子节点容量，通常假设叶子节点指针数也遵循阶数限制，或者题目隐含叶子节点也是由指针指向的。
            *   在 B+ 树中，内部节点指针指向子节点。
            *   根节点 (1) -> 指向最多 50 个子节点 (Layer 2)。
            *   Layer 2 (50) -> 指向最多 $50 \times 50 = 2500$ 个子节点 (Layer 3)。
            *   Layer 3 (2500) -> 指向最多 $2500 \times 50 = 125,000$ 个子节点 (Layer 4)。
            *   如果 Layer 4 是叶子节点，那么总记录数取决于叶子节点能存多少记录。
            *   **关键点**：题目问的是“访问多少个节点”。在 B+ 树中，通常内部节点不存数据，数据在叶子节点。
            *   如果参考解析的逻辑是：
                *   第 4 层（根）：1 个节点。
                *   第 3 层：最多 50 个节点（由根指向）。
                *   第 2 层：最多 $50 \times 50 = 2500$ 个节点。
                *   第 1 层（叶子）：最多 $2500 \times 50 = 125,000$ 个节点。
                *   如果每个叶子节点至少存 1 条记录（极端情况），则 $125,000$ 条记录。但这远小于 100 万。
                *   **重新解读参考解析**：参考解析中“最后一层节点数 $10^6 / 50$”暗示了**每个节点（包括叶子）至少包含 50 个指针/记录**。
                *   如果每个叶子节点至少存 50 条记录：
                    *   叶子节点数 = $1,000,000 / 50 = 20,000$。
                    *   指向这些叶子的父节点数（Layer 3）= $20,000 / 50 = 400$。
                    *   指向 Layer 3 的父节点数（Layer 2）= $400 / 50 = 8$。
                    *   指向 Layer 2 的父节点数（Layer 1, Root）= $8 / 50 = 1$（向上取整，因为根节点至少存在）。
                    *   所以树的结构是：Root (L1) -> L2 (8 nodes) -> L3 (400 nodes) -> Leaves (L4, 20,000 nodes)。
                    *   总层数 = 4。
                    *   访问路径：Root -> L2 -> L3 -> Leaf。共访问 4 个节点。
            *   因此，选项 B 是正确的。
- **选项 C**: [干扰] — 针对低估树高或误用最大填充因子的错误认知。如果学生使用最大指针数 100 计算：$10^6 / 100 = 10^4 \to 100 \to 1 \to 1$，层数为 4 或 3？$10^4/100=100, 100/100=1, 1/100=1$。层数可能是 3 或 4。如果误以为根节点不算或计算失误，可能选 3。
- **选项 D**: [干扰] — 针对完全无概念或随意猜测的学生。10 是一个较大的数字，可能源于对阶数 100 的直接误解（如认为每层减少 10 倍，$10^6 \to 10^5 \to 10^4 \to 10^3 \to 10^2 \to 10^1 \to 1$，共 6-7 层，或者完全乱猜）。

**干扰策略**: 计算陷阱（使用最大指针数而非最小）、概念混淆（忽略根节点或叶子节点存储特性）。

## 核心陷阱
- **核心陷阱**: **“最多访问”对应“最小填充因子”**。题目问“最多”需要访问多少个节点，意味着树的高度最大。树高最大发生在每个节点存储的数据/指针最少的时候。因此必须使用最小指针数 $\lceil m/2 \rceil = 50$ 进行计算，而不是平均或最大指针数。此外，需正确理解 B+ 树中叶子节点也遵循阶数约束（或题目隐含的每节点最小记录数）。

## 考察能力
本题核心考察考生对 B+ 树结构性质（特别是阶数与最小指针数的关系）的理解，以及在最坏情况下（最小填充）估算树高和 I/O 访问次数的计算能力。
