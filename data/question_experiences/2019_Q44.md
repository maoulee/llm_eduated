# 2019 Q44 — 磁盘容量计算、SSTF调度与CHS地址转换

## 基本信息
- **年份**: 2019  **题位**: Q44  **题型**: 综合题
- **知识点**: 机械硬盘, CHS地址, IO软件层次, SSTF, CHS 地址
- **题位域**: 待标注  **科目**: 操作系统

## 题干原文
某计算机系统中的磁盘有 300 个柱面，每个柱面有 10 个磁道，每个磁道有 200 个扇区，扇区大小为 512B。文件系统的每个簇包含 2 个扇区。请回答下列问题：
(1) 磁盘的容量是多少？
(2) 假设磁头在 85 号柱面上，此时有 4 个磁盘访问请求，簇号分别为 100260、60005、101660 和 110560。若采用最短寻道时间优先 (SSTF) 调度算法，则系统访问簇的先后次序是什么？
(3) 第 100530 簇在磁盘上的物理地址是什么？将簇号转换成磁盘物理地址的过程是由 I/O 系统的什么程序完成的？

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆磁盘容量计算公式、CHS地址结构定义、SSTF算法基本规则以及IO软件层次中驱动程序的功能。属于标准的基础概念调用，不涉及复杂概念辨析。
- **K2 = 4**: 评分理由。涉及多级单位换算（B到KB）、大数除法与取模运算（簇号转CHS）。特别是第(3)问中，簇号到扇区号的转换涉及“簇包含2个扇区”这一系数的处理，且数字较大（100530），非2的幂次友好型计算，容易因粗心或公式记错导致计算错误，属于较高难度的单步代入。
- **K3 = 3**: 评分理由。第(2)问SSTF调度需要多步串行推演：先计算各簇对应的柱面号，再比较距离，确定下一个访问目标，更新当前位置，重复此过程。步骤在3-5步之间，逻辑清晰但需保持中间状态（当前磁头位置），属于标准机制推演。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。首先，SSTF调度是基于“柱面号”而非“簇号”直接比较，考生必须先将簇号转换为柱面号才能比较距离，这是最大的暗坑。其次，CHS转换中，扇区号的计算容易忽略“簇包含2个扇区”导致的偏移量变化（即扇区号 = (簇号 % 每磁道簇数) * 每簇扇区数 + 簇内偏移，或者如解析中通过总扇区数取模）。若未意识到簇与扇区的映射关系，极易算错。
- **K5 = 3**: 评分理由。题目跨越了文件系统逻辑层（簇号）和磁盘物理层（CHS地址），以及IO调度层（SSTF）。需要理解逻辑地址到物理地址的映射关系，以及调度算法对物理地址的操作。属于单向数据传递（逻辑->物理）和机制应用，有一定跨域联动需求。
- **雷达形状**: 偏向右侧的不对称多边形。K2（计算）和K4（陷阱/隐含条件）得分较高，K1（基础）中等，K3（推演）中等，K5（跨域）中等。整体呈现“计算与陷阱驱动”的特征。

## 考察模式
- **模式**: 计算推导型
- **理由**: 本题主要依赖公式代入、数值计算和算法步骤执行来得出具体答案。虽然涉及概念，但最终落脚点在于具体的数值结果（容量、访问顺序、物理地址）和特定程序名称，而非理论论证或系统设计。

## 解题思路分析
- **核心思路**: 
    1. 利用几何参数直接计算总容量。
    2. 将逻辑簇号映射为物理柱面号，基于柱面号执行SSTF贪心策略。
    3. 利用整除和取模运算，将逻辑簇号逆向映射为CHS物理地址，并识别IO软件层次。
- **关键步骤**:
    1. **容量计算**: $Capacity = Cylinders \times Heads \times Sectors \times SectorSize$。注意单位换算。
    2. **SSTF调度**:
       - 计算每个柱面包含的簇数：$10 \times 200 / 2 = 1000$ 簇/柱面。
       - 将各请求簇号转换为柱面号：$Cyl = \lfloor Cluster / 1000 \rfloor$。
       - 当前磁头在85号柱面。比较各请求柱面与85的距离，选最近者。
       - 更新磁头位置，重复比较，直到所有请求完成。
    3. **CHS转换**:
       - 确定每柱面簇数（1000）、每磁道簇数（100）。
       - 柱面号 = $\lfloor 100530 / 1000 \rfloor = 100$。
       - 剩余簇号 = $100530 \% 1000 = 530$。
       - 磁头号 = $\lfloor 530 / 100 \rfloor = 5$。
       - 剩余簇号 = $530 \% 100 = 30$。
       - 扇区号 = $30 \times 2 = 60$ （因为每簇2扇区，且簇内扇区连续）。
       - 确认IO软件层次：逻辑地址到物理地址的转换由**磁盘驱动程序**完成。
- **易错点**:
    1. 容量计算时忘记单位换算（B转KB或MB）。
    2. SSTF调度时直接用簇号比较距离，而未转换为柱面号。
    3. CHS转换时，扇区号计算错误，忽略“每簇2扇区”的倍数关系，直接用簇号取模。
    4. 混淆IO软件层次，误认为是设备独立性软件或中断处理程序完成地址转换。

## 核心陷阱
- **核心陷阱**: **SSTF调度的比较基准是柱面号而非簇号**。许多考生会直接用簇号（如100260）与当前柱面（85）或当前簇号进行比较，这是完全错误的。必须先将簇号归一化为柱面号，因为SSTF旨在最小化寻道时间，而寻道时间主要取决于柱面间的距离。此外，CHS转换中扇区号的计算需仔细处理簇与扇区的倍数关系。

## 考察能力
本题核心考察考生对磁盘物理结构、逻辑地址到物理地址映射机制、磁盘调度算法原理以及IO软件层次功能的综合理解与精确计算能力。
