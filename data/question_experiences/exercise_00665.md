# 练习题 Q1 — 数据链路层位填充机制逆向推导

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机网络
- **知识点**: 计算机网络/数据链路层
- **难度**: 待评估

## 题干原文
一种基于位填充的帧定界协议使用一个 8 位的定界符模式 01111110。如果填充后的输出比特串为 01111100101，则输入的比特串是（ ）：
A: 0111110100
B: 0111110101
C: 0111111101
D: 0111111111

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要记忆“比特填充（Bit Stuffing）”的核心规则，即“连续5个1后插入0”以及定界符“01111110”的定义。这是数据链路层HDLC/PPP协议的基础概念，属于标准记忆需求。不是4分因为不需要辨析多个易混概念（如字符填充与比特填充的区别），只需掌握单一机制。
- **K2 = 2**: 评分理由。本题不涉及数值计算，而是比特串的序列处理。虽然需要逐位扫描，但逻辑简单，属于低强度的模式匹配操作。不是3分因为不存在复杂的进制转换或多级换算。
- **K3 = 3**: 评分理由。解题过程需要逆向推演：从填充后的串出发，识别出“11111”模式，判断随后的“0”是填充位还是数据位，然后移除填充位，最后重组原始串。这是一个3-5步的串行逻辑过程（扫描->识别->判断->移除->重组），符合标准推演难度。
- **K4 = 4**: 评分理由。存在明显的隐含前提和陷阱。考生必须意识到“01111110”是定界符，而题目给出的串“01111100101”中，前6位“011111”加上第7位的“0”构成了“0111110”，这看起来像定界符的前缀，但关键在于第7位的“0”是在连续5个“1”之后出现的。根据规则，连续5个1后跟0，这个0是填充位，必须移除。如果考生误以为“0111110”就是定界符的一部分而不移除，或者误以为后面的“0101”中有其他填充位，就会出错。特别是需要区分“作为定界符结束的0”和“作为填充位的0”在逆向过程中的不同处理（本题中填充后的串并未包含完整的定界符结束，而是考察数据部分的填充还原，或者考察对填充规则机械执行的逆向）。更深层的陷阱在于：题目给出的串 `01111100101`，前6位 `011111` 后紧跟 `0`，根据规则，发送端在遇到5个1后插入0，所以接收端看到 `11111` 后跟 `0`，应移除该 `0`。剩下的 `0101` 直接保留。因此原始数据是 `011111` + `0101` = `0111110101`。陷阱在于考生可能忽略定界符的存在，或者错误地认为 `01111110` 整个串是定界符从而截断数据。这里的核心陷阱是**逆向思维中的规则应用**：必须明确知道“看到5个1后跟0，则0是填充位，需删除”。
- **K5 = 1**: 评分理由。本题仅涉及数据链路层的单一机制（比特填充），不涉及网络层、传输层或其他子系统的状态传递或耦合。

- **雷达形状**: K4陷阱型（K4显著高于其他维度，K1-K3中等，K5极低）

## 考察模式
- **模式**: 推理型
- **理由**: 题目不是直接询问定义，也不是简单的数值计算，而是要求考生根据给定的输出结果，逆向运用协议规则推导出输入结果。这需要理解机制的因果逻辑并进行反向操作。

## 选项级分析
- **选项A**: [干扰] — 针对**错误移除填充位**或**错误重组**的认知。如果考生错误地认为第二个“0”也是填充位，或者在重组时发生位移错误，可能会得到此结果。例如，若误以为 `011111` 后的 `0` 是数据，而 `0101` 中的某个位被错误处理。
- **选项B**: [正确] — 正确应用逆向位填充规则。
  - 填充后串：`0 11111 0 0101`
  - 识别：`11111` 后紧跟 `0`，根据规则，此 `0` 为填充位，移除。
  - 剩余：`0 11111` + `0101` = `0111110101`。
- **选项C**: [干扰] — 针对**未移除填充位**的认知。如果考生没有执行“移除填充位”的操作，或者错误地认为 `0111110` 是定界符而将其保留或错误处理，可能会保留那个多余的0，导致结果变成 `01111100101` 的变体，或者误以为原始数据就是填充后的数据去掉首尾定界符（如果误判定界符位置）。更可能的情况是，考生看到 `011111` 后，误以为后面的 `0` 是数据的一部分，而忽略了填充规则，或者在逆向时忘记删除填充的0，导致结果中多了一个0。实际上，选项C `0111111101` 比正确答案多了一个1，少了一个0，这可能是考生混淆了填充规则（如以为连续6个1才填充）或计算错误。
- **选项D**: [干扰] — 针对**完全误解规则**的认知。如果考生认为所有连续的1都需要特殊处理，或者完全随机猜测，可能会选择全1的选项。或者，考生可能错误地认为填充后的串中所有的0都是填充位，从而全部移除，得到 `011111111`，再补位得到D。

- **干扰策略**: 概念混淆（填充位与数据位的界限）、逆向操作失误（忘记移除或错误移除）

## 核心陷阱
- **核心陷阱**: **逆向位填充规则的精确应用**。考生必须准确识别“连续5个1”这一模式，并正确判断紧随其后的“0”是填充位（需移除）还是数据位（需保留，但这在标准比特填充中，5个1后跟0必为填充，除非是定界符的结束，但定界符是01111110，即5个1后跟1再跟0）。本题的关键在于区分：
  1.  `11111` + `0` -> 0是填充位，移除。
  2.  `11111` + `1` + `0` -> 这是定界符 `01111110` 的一部分（如果前面有0），或者是数据中的 `111111` 被填充为 `1111101`？不，标准规则是5个1后插0。所以 `111111` 会变成 `1111101`。
  本题中 `01111100101`，分解为 `0` `11111` `0` `0101`。
  `11111` 后是 `0`，所以这个 `0` 是填充位，移除。
  剩下 `0` `11111` `0101` -> `0111110101`。
  陷阱在于考生可能看到 `0111110` 就以为是定界符 `01111110` 的残缺，从而产生困惑，或者错误地保留了填充的0。

## 考察能力
一句话概括本题核心考察的能力：对数据链路层比特填充机制的逆向逻辑推理与规则应用能力。
