# 练习题 Q1 — 硬连线控制器逻辑表达式推导

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
一个硬连线 CPU 在各个时间步长 T1 到 T5 中使用 10 个控制信号 S1 到 S10 来实现 4 条指令 I1 到 I4，如下所示。以下哪一对表达式分别表示生成控制信号 S5 和 S10 的电路？
T1
T2
T3
T4
T5
I1
S1, S3, S5
S2, S4, S6
S1, S7
S10
S3, S8
I2
S1, S3, S5
S8, S9, S10
S5, S6, S7
S6
S10
I3
S1, S3, S5
S7, S8, S10
S2, S6, S9
S10
S1, S3
I4
S1, S3, S5
S2, S6, S7
S5, S10
S6, S9
S10
（(Ij+Ik)Tn 表示如果正在执行的指令是 Ij 或 Ik，则应在时间步长 Tn 生成控制信号）
- 选项:
  A: S5=T1+I2⋅T3 和 S10=(I1+I3)⋅T4+(I2+I4)⋅T5
  B: S5=T1+(I2+I4)⋅T3 和 S10=(I1+I3)⋅T4+(I2+I4)⋅T5
  C: S5=T1+(I2+I4)⋅T3 和 S10=(I2+I3+I4)⋅T2+(I1+I3)⋅T4+(I2+I4)⋅T5
  D: S5=T1+(I2+I4)·T3 和 S10=(I2+I3)·T2+I4·T3+(I1+I3)·T4+(I2+I4)·T5
- 正确答案: D
- 解析（参考）: 选项 D 正确
。根据题目描述：
S5 的生成条件
：
始终在 T1 时钟周期有效（对应所有指令）
在 I2 和 I4 指令的 T3 阶段有效
S10 的生成条件
：
在 I2 和 I3 指令的 T2 阶段有效
在 I4 指令的 T3 阶段有效
在 I1 和 I3 指令的 T4 阶段有效
在 I2 和 I4 指令的 T5 阶段有效
选项 D 完整覆盖了上述所有条件，其他选项均存在部分时间步长或指令组合缺失的情况。
- 知识标签: ['操作系统/CPU调度']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握硬连线控制器中控制信号生成的基本逻辑（即控制信号是“当前指令”与“当前时序脉冲”的逻辑组合）。虽然不涉及复杂公式，但需要理解 `(Ij+Ik)Tn` 这种特定表示法的含义，属于标准的基础概念记忆。
- **K2 = 2**: 评分理由。本题没有数值计算，只有逻辑项的罗列和比对。最复杂的“计算”是统计某个信号在哪些行出现，属于较低难度的信息提取。
- **K3 = 4**: 评分理由。推演步骤较多且容易出错。考生需要分别对 S5 和 S10 进行独立的多步扫描：
    1. 扫描 S5：检查 T1-T5 所有指令行，找出 S5 出现的位置 -> 得到 S5 表达式。
    2. 扫描 S10：检查 T1-T5 所有指令行，找出 S10 出现的位置 -> 得到 S10 表达式。
    3. 对比选项：将推导出的两个表达式与四个选项逐一比对。
    由于 S10 涉及的时间步长多（T2, T3, T4, T5），且指令组合复杂，需要多步串行推演并记忆中间状态（即 S10 在 T2 是谁，T3 是谁...），符合 >5 步或需记忆中间状态的特征。
- **K4 = 3**: 评分理由。存在常规注意点/陷阱。主要陷阱在于“漏看”。例如 S10 在 T3 只有 I4 有效，而在 T2 是 I2, I3 有效。如果考生只关注了 T4 和 T5（因为选项 A/B 只写了这两项），就会掉入陷阱。需要识别出“所有出现该信号的时刻都必须被表达式覆盖”这一隐含前提。
- **K5 = 1**: 评分理由。单系统内部逻辑。仅涉及 CPU 控制单元内部的信号生成逻辑，不涉及与其他子系统（如内存、I/O）的状态传递或耦合。
- **雷达形状**: K3 推演主导型，K4 陷阱辅助。整体呈现为需要细致逻辑梳理的推理题，而非纯记忆或纯计算题。

## 考察模式
- **模式**: 推理型
- **理由**: 题目不直接给出答案，而是给出一张数据表（微操作序列），要求考生根据硬连线控制器的设计原理（控制信号 = 指令译码输出 AND 时序脉冲），通过逻辑归纳和比对，推导出正确的布尔表达式。核心在于从离散的数据点中归纳出逻辑规则。

## 选项级分析
- **选项A**: [干扰] — **错误认知：S5 的指令覆盖不全**。
    - 分析：S5 的表达式为 `T1 + I2·T3`。实际上 S5 在 T1 对所有指令有效（即 `T1` 隐含了 `I1+I2+I3+I4`），但在 T3 时，I2 和 I4 都需要 S5。选项 A 漏掉了 I4。
    - 学生心理：可能只看到了 I2 在 T3 有 S5，忽略了 I4 在 T3 也有 S5，或者误以为 T1 的 `T1` 已经覆盖了所有情况（但 T1 是时序，T3 是另一个时序，必须显式写出 T3 时的指令条件）。
- **选项B**: [干扰] — **错误认知：S10 的时序覆盖不全（漏掉 T2 和 T3）**。
    - 分析：S10 的表达式只包含了 T4 和 T5 的情况。实际上 S10 在 T2 (I2, I3) 和 T3 (I4) 也有效。
    - 学生心理：这是最常见的错误。考生可能只注意到了表格后半部分（T4, T5）的 S10，或者被选项 A 的错误引导，认为 S10 只在后期有效。这是一种“部分正确”的强干扰项。
- **选项C**: [干扰] — **错误认知：S10 在 T2 的指令组合错误**。
    - 分析：S10 在 T2 时，I2 和 I3 有效。选项 C 写的是 `(I2+I3+I4)·T2`，多包含了 I4。查看表格，I4 在 T2 的信号是 `S2, S6, S7`，并没有 S10。
    - 学生心理：考生可能在扫描 T2 列时，看错了行，或者混淆了 I3 和 I4 的行位置，导致多选了 I4。
- **选项D**: [正确] — **完全匹配**。
    - 分析：
        - S5: T1 (所有指令) + T3 (I2, I4) -> `T1 + (I2+I4)·T3`。正确。
        - S10:
            - T2: I2, I3 -> `(I2+I3)·T2`
            - T3: I4 -> `I4·T3`
            - T4: I1, I3 -> `(I1+I3)·T4`
            - T5: I2, I4 -> `(I2+I4)·T5`
            - 组合起来完全正确。

- **干扰策略**: **渐进陷阱/部分匹配**。
    - 选项 A 和 B 分别只覆盖了 S5 或 S10 的部分情况，或者指令组合错误。
    - 选项 C 和 D 非常相似，仅在 S10 的 T2 项上有细微差别（I4 是否参与），考察考生的细致程度。

## 核心陷阱
- **核心陷阱**: **S10 信号的多时段分布与指令组合的精确对应**。
    - 考生极易忽略 S10 在 T2 和 T3 的存在，只关注 T4 和 T5（因为选项 A/B 只写了这两项，诱导考生认为只有这两项）。
    - 即使注意到 T2，也容易在 I2, I3, I4 的指令组合上出错（如选项 C 多选了 I4）。
    - 必须逐行、逐列仔细核对，不能凭印象或局部观察。

## 考察能力
本题核心考察考生**从微操作序列表中提取控制信号生成逻辑，并将其转化为布尔表达式的能力**，以及对硬连线控制器“指令译码+时序脉冲”生成机制的深刻理解。
