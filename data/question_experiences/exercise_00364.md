# 练习题 Q1 — 最短路径权重缩放不变性

## 基本信息
- **来源**: 练习题  **题型**: 综合题
- **科目**: 数据结构
- **知识点**: 数据结构/图
- **难度**: 待评估

## 题干原文
关于最短路径，以下陈述是否有效？给定一个图，假设我们已经计算出从源点到所有其他顶点的最短路径。如果我们将图中所有边的权重修改为原始权重的两倍，则最短路径保持不变，仅路径的总权重发生变化。（ ）

是正确的。
解析
最短路径的确定依赖于路径中各边权重的
相对大小关系
当所有边权重按相同比例缩放时（如×2），路径间的
相对顺序保持不变
类比：将距离单位从"米"改为"千米"时，最短路径的实际路线不会改变
数学本质：若原路径 P₁ < P₂，则 2P₁ < 2P₂仍成立，路径选择结果一致

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“最短路径”的定义以及Dijkstra或Bellman-Ford算法的基本原理（即基于累加权重的比较）。不是2分因为仅靠直觉可能误判，需要明确“路径长度”是边权之和这一核心概念；不是4分因为不需要辨析多个易混概念（如无权图vs有权图，或负权环等复杂情况），只需理解线性变换对不等式的影响。
- **K2 = 1**: 评分理由。本题不涉及具体的数值计算，无需执行加法、乘法或幂运算。属于纯逻辑判断，计算需求微弱。
- **K3 = 2**: 评分理由。推演步骤较少。只需进行一步逻辑映射：原路径权值和 $W_1 < W_2$ $\rightarrow$ 新路径权值和 $2W_1 < 2W_2$。不需要多步串行推演或记忆中间状态，逻辑链条短且直接。
- **K4 = 3**: 评分理由。存在潜在的思维陷阱。学生容易混淆“线性缩放”（$\times k$）与“线性平移”（$+ k$）。如果题目改为“所有边权重加2”，结论则错误。因此，解题者必须识别出“乘以常数”保持相对大小关系，而“加上常数”会破坏相对大小关系这一隐含前提。这属于常规注意点中的陷阱词辨析，故给3分。
- **K5 = 1**: 评分理由。本题仅涉及图论中的最短路径单一知识点，不需要跨越操作系统、计算机网络或组成原理等其他子系统，也不涉及图内部不同算法模块（如拓扑排序与最短路径）的深度耦合。

- **雷达形状**: 偏向K1和K4的“菱形”或“偏置型”。K2和K5极低，K3较低，主要考察概念理解（K1）和对变换性质的辨析（K4）。

- **模式**: 分析论证型

## 解题思路分析
- **核心思路**: 利用不等式的性质分析路径总权重的变化对路径选择的影响。最短路径算法的核心在于比较不同路径的总权重，若比较关系不变，则最优解（路径）不变。
- **关键步骤**:
    1.  **定义路径权重**: 设从源点到某顶点有两条路径 $P_1$ 和 $P_2$，其原始总权重分别为 $W(P_1)$ 和 $W(P_2)$。
    2.  **建立不等式**: 假设 $P_1$ 是最短路径，则 $W(P_1) < W(P_2)$。
    3.  **应用变换**: 所有边权重变为原来的2倍，新路径权重为 $W'(P_1) = 2 \times W(P_1)$，$W'(P_2) = 2 \times W(P_2)$。
    4.  **比较新权重**: 由于 $W(P_1) < W(P_2)$ 且系数 2 > 0，根据不等式性质，必有 $2 \times W(P_1) < 2 \times W(P_2)$，即 $W'(P_1) < W'(P_2)$。
    5.  **得出结论**: 路径的相对优劣顺序未变，因此最短路径的顶点序列保持不变。
- **易错点**:
    1.  混淆“权重翻倍”与“权重增加”。若题目是“所有边权重加1”，则路径越长（边数越多），增加的总权重越多，可能导致最短路径改变。
    2.  忽视负权重的情况。虽然题目未明确说明权重正负，但在标准最短路径语境下（通常指Dijkstra适用的非负权图，或Bellman-Ford适用的无负环图），线性缩放 $k>0$ 均保持顺序。若 $k<0$，则顺序反转，最短变最长。但题目明确说是“两倍”（正数），故无需考虑此极端情况，但需意识到系数必须为正。

## 核心陷阱
- **核心陷阱**: **线性缩放 vs 线性平移**。
    考生最容易犯的错误是将“乘以常数”与“加上常数”混淆。
    - **乘以常数 ($w' = c \cdot w, c>0$)**: 保持所有路径权重的**相对比例**和**大小顺序**不变，最短路径**不变**。
    - **加上常数 ($w' = w + c, c>0$)**: 路径总权重增加量取决于**边数**。边数多的路径增加的总权重更多，可能使得原本较长的路径（边数少）变得比原本较短的路径（边数多）更短，导致最短路径**改变**。
    本题考察的是前者，但陷阱在于考生是否清晰区分了这两种变换对图算法的不同影响。

## 考察能力
本题核心考察考生对**最短路径算法本质（基于权重累加的比较）**的理解，以及**数学不等式性质在算法分析中的应用能力**，特别是区分线性变换中缩放与平移对优化目标函数影响的辨析能力。
