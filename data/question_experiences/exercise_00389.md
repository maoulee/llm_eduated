# 练习题 Q1 — 图DFS树边与连通分量关系

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 数据结构
- **知识点**: 数据结构/图
- **难度**: 待评估

## 题干原文
在对具有 n 个顶点的图 G 进行深度优先遍历时，标记了 k 条树边。图 G 中的连通分量数量是：
A: k
B: k + 1
C: n - k - 1
D: n - k

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要掌握“深度优先搜索（DFS）”、“树边”、“连通分量”以及“DFS森林”这几个核心概念。如果不记忆这些定义，无法入题；但只需理解核心定义即可，无需辨析多个易混的高级概念，故为标准难度。
- **K2 = 2**: 评分理由。涉及简单的代数关系推导（顶点数与边数的关系），计算量极小，属于基础算术逻辑，不易出错。
- **K3 = 3**: 评分理由。推演步骤约为3步：1. 理解DFS生成的是森林；2. 理解每棵树中顶点数=树边数+1；3. 建立总顶点数n、总树边数k与树的数量（即连通分量数）之间的方程。属于标准的多步逻辑串联。
- **K4 = 2**: 评分理由。题目隐含的前提是“无向图”（通常408语境下未特指有向图且讨论连通分量时默认为无向图，或者即便是有向图的弱连通分量，结论在DFS树边统计上略有不同但通常考察无向图性质）。主要的注意点在于理解“树边”仅指DFS树中的边，不包括回边、前向边等，这是常规注意点，无深层陷阱。
- **K5 = 1**: 评分理由。本题仅涉及图论内部的概念，不需要跨越操作系统、计网或组成原理等其他子系统，属于单系统内部问题。
- **雷达形状**: K1-K3均衡型，无明显短板或极端高分项，属于典型的概念理解与基础逻辑推理题。

## 考察模式
- **模式**: 推理型
- **理由**: 题目并非直接考查公式记忆（如直接问“树边数公式”），而是给出了一个具体场景（DFS遍历标记了k条树边），要求考生通过理解DFS遍历图的机制（生成森林），推导出连通分量数量与顶点数、树边数之间的逻辑关系。

## 选项级分析
- **选项A**: [干扰] — 针对错误认知：认为树边数直接等于连通分量数。这类学生可能混淆了“边”与“分量”的概念，或者误以为每个连通分量只对应一条边（仅当n=2时成立）。
- **选项B**: [干扰] — 针对错误认知：认为连通分量数 = 树边数 + 1。这类学生可能只考虑了单棵树的情况（n个顶点，n-1条边，1个分量，此时k=n-1，k+1=n，显然错误），或者混淆了“树中顶点数=边数+1”这一局部性质与全局连通分量的关系。
- **选项C**: [干扰] — 针对错误认知：计算错误。可能是由公式 $n - (k+1)$ 错误推导而来，或者在代入特例（如n=1, k=0）时算错。
- **选项D**: [正确] — 正确推导。设连通分量数为 $c$。DFS遍历无向图生成 $c$ 棵DFS树。对于第 $i$ 棵树，设其顶点数为 $n_i$，树边数为 $k_i$，则有 $n_i = k_i + 1$。对所有树求和：$\sum n_i = \sum (k_i + 1) \Rightarrow n = k + c \Rightarrow c = n - k$。
- **干扰策略**: 概念混淆。利用“树中顶点数=边数+1”这一局部正确但全局需求和的性质，诱导学生直接套用局部公式或进行错误的代数变换。

## 核心陷阱
- **核心陷阱**: 混淆“单棵树的性质”与“森林的整体性质”。学生容易记住“一棵树有 $m$ 条边则有 $m+1$ 个顶点”，但忘记图可能不连通，DFS生成的是森林。若直接套用 $n = k + 1$ 会得出错误结论，必须意识到 $n = k + \text{连通分量数}$。

## 考察能力
一句话概括本题核心考察的能力：理解深度优先搜索在无向图中生成DFS森林的结构特性，并能建立顶点数、树边数与连通分量数之间的数量关系。
