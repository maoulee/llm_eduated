# 2011 Q3 — 循环队列初始化与指针定义辨析

## 基本信息
- **年份**: 2011  **题位**: Q3  **题型**: 选择题
- **知识点**: DS-3 > 3.2 队列 > 循环队列, DS-3 > 3.2 队列 > 队头指针 front, DS-3 > 3.2 队列 > 队尾指针 rear
- **题位域**: DS-2  **科目**: 数据结构

## 题干原文
已知循环队列存储在一维数组 A[0..n-1] 中，且队列非空时 front 和 rear 分别指向队头元素和队尾元素。若初始时队列空，且要求第一个进入队列的元素存储在 A[0] 处，则初始时 front 和 rear 的值分别是（ ）。

A. 0，0
B. 0，n-1
C. n-1，0
D. n-1，n-1

## K1-K5 评分与解析
- **K1 = 4**: 评分理由。本题不仅要求记忆循环队列的基本概念，更关键的是需要辨析两种不同的指针定义体系（“指向队尾元素” vs “指向队尾下一个位置”）。考生必须清晰区分题目给定的特定定义与教材中常见的默认定义，属于易混概念辨析，难度较高。
- **K2 = 2**: 评分理由。涉及简单的模运算逆向推导。已知入队后 `rear` 变为 0，根据公式 `rear = (rear_old + 1) % n`，逆推 `rear_old` 为 `n-1`。计算过程简单，属于基础算术逻辑。
- **K3 = 3**: 评分理由。需要两步推演：第一步，根据“第一个元素在 A[0]”和“rear 指向队尾元素”，确定入队后 `front=0, rear=0`；第二步，根据入队操作 `rear = (rear + 1) % n` 反推初始状态。逻辑链条清晰但需多步串行思考。
- **K4 = 5**: 评分理由。本题存在极强的反直觉陷阱和隐含前提。绝大多数教材（如严蔚敏版）定义 `rear` 指向队尾元素的**下一个位置**，此时空队列 `front=rear=0`。但本题明确定义 `rear` 指向**队尾元素**，这导致空队列的初始化状态完全不同。考生若未注意到这一关键定义差异，直接套用常见结论，必选错误答案。这是典型的“题面没说但解题必须意识到的条件”（即指针定义的变体），且极具误导性。
- **K5 = 1**: 评分理由。本题仅涉及数据结构中队列这一单一子系统，无需跨越其他模块（如树、图或操作系统）进行状态传递。

- **雷达形状**: K4 陷阱型（K4 极高，K1 较高，其余较低）

## 考察模式
- **模式**: 概念型
- **理由**: 本题核心不在于复杂的计算或算法实现，而在于对数据结构底层定义（指针含义）的精确理解和条件适配。它考察的是考生是否真正理解了“指针定义”对“初始状态”的决定性作用，而非机械记忆。

## 选项级分析
- **选项A**: [干扰] — 针对**惯性思维/教材默认定义**错误认知。这是严蔚敏教材等主流教材中循环队列的标准初始化方式（`rear` 指向队尾下一位置）。大量考生因未仔细阅读题干中“rear 指向队尾元素”这一特殊定义，直接凭记忆选择 A。
- **选项B**: [正确] — 符合题干特定定义下的逻辑推导结果。
- **选项C**: [干扰] — 针对**指针方向混淆**错误认知。考生可能知道 `rear` 需要特殊处理，但错误地认为 `front` 也需要调整为 `n-1`，或者混淆了 `front` 和 `rear` 的初始偏移量。
- **选项D**: [干扰] — 针对**完全误解空队列状态**错误认知。考生可能认为空队列时指针应指向数组末尾，或者对模运算的逆推完全错误。

- **干扰策略**: 概念混淆（利用主流教材定义与题目特定定义的冲突制造陷阱）

## 核心陷阱
**指针定义的变体陷阱**。
题目明确定义 `rear` 指向**队尾元素**，而非常见的“队尾元素的下一个位置”。
- 若 `rear` 指向队尾元素：入队操作为 `rear = (rear + 1) % n` 后存入数据？不，通常是先存数据再移指针，或者先移指针再存数据。
- 让我们仔细梳理题干逻辑：
    1. 题目说：队列非空时，`rear` 指向队尾元素。
    2. 题目说：第一个元素进入后存储在 `A[0]`。
    3. 这意味着：入队操作完成后，`A[0]` 是队尾元素，所以此时 `rear` 必须指向 0。同时 `front` 也指向 0（队头）。
    4. 入队操作通常逻辑：`rear = (rear + 1) % n`，然后 `A[rear] = x`。
    5. 如果入队后 `rear` 为 0，那么入队前的 `rear` 必须满足 `(rear_old + 1) % n = 0`，即 `rear_old = n - 1`。
    6. 对于 `front`：题目说“插入操作只改变 rear 指针”（参考解析暗示，或者常规逻辑：入队不改变队头，除非队列从空变非空时 front 的初始化）。
    7. 关键点：当队列从空变为非空（第一个元素入队），`front` 应该指向哪里？题目要求第一个元素在 `A[0]`，且 `front` 指向队头，所以入队后 `front=0`。
    8. 初始时队列为空。`front` 的初始值是多少？如果入队操作不改变 `front`（通常入队只改 `rear`，出队才改 `front`），那么初始 `front` 应该等于入队后的 `front`，即 0。
    9. 所以初始状态：`front = 0`, `rear = n - 1`。

**陷阱核心**：考生容易忽略“rear 指向队尾元素”这一前提，直接套用“rear 指向队尾下一位置”时的 `front=rear=0` 结论（选项 A）。
