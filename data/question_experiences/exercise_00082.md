# 练习题 Q1 — 补码加法标志位判定

## 基本信息
- **来源**: 练习题  **题型**: 选择题
- **科目**: 计算机组成原理
- **知识点**: 操作系统/CPU调度
- **难度**: 待评估

## 题干原文
一个处理器的程序状态字（PSW）包含进位标志、溢出标志和符号标志。该处理器对以下两个二进制补码数 01001101 和 11101001 执行加法操作。执行完此加法操作后，进位标志、溢出标志和符号标志的状态依次为（ ）：
- 选项:
  A: 1, 1, 0
  B: 1, 0, 0
  C: 0, 1, 0
  D: 1, 0, 1
- 正确答案: B
- 解析（参考）: 计算过程
：
01001101 (77)
+ 11101001 (-23)
-------------
100110110 (54)
最高位产生进位（第 9 位为 1），但结果仍为正数（最高有效位为 0）
溢出标志判定规则
：
当两个同号数相加时，若结果符号与操作数不同则溢出
符号位进位输入与进位输出异或结果为 1 时置位
本例中两数一正一负（+77 和 -23），属于异号相加，不会发生溢出
关键区别
：
进位标志
：反映无符号数运算结果是否超出位宽
溢出标志
：反映有符号数运算结果是否超出表示范围
最终状态
：
进位标志 = 1（最高位产生进位）
溢出标志 = 0（异号相加不可能溢出）
符号
- 知识标签: ['操作系统/CPU调度']
- 知识域: OS-1

## K1-K5 评分与解析
- **K1 = 3**: 评分理由。需要准确记忆并区分“进位标志（CF）”与“溢出标志（OF）”在补码运算中的不同定义。CF关注无符号数溢出（最高位进位），OF关注有符号数溢出（符号位异常）。若混淆两者定义（如认为CF也看符号位），则无法解题。
- **K2 = 3**: 评分理由。涉及8位二进制补码的加法运算。虽然数值较小（77和-23），但需要手动进行二进制竖式加法，并正确处理借位/进位链。非2的幂次直接转换，需一定计算细心度。
- **K3 = 2**: 评分理由。推演步骤较少：1. 执行二进制加法；2. 检查最高位进位确定CF；3. 判断操作数符号及结果符号确定OF；4. 取结果最高位确定SF。逻辑线性，无需复杂的状态回溯。
- **K4 = 4**: 评分理由。存在典型的“反直觉”陷阱。在二进制加法中，最高位产生了进位（Carry Out），直觉上容易误判为“溢出”。但题目明确指定是“补码数”，对于有符号数运算，最高位进位并不一定导致溢出（OF），只有当符号位进位输入与输出不一致时才溢出。考生必须意识到“CF看进位，OF看符号逻辑”这一隐含前提，避开“有进位即溢出”的思维定势。
- **K5 = 1**: 评分理由。本题仅涉及ALU（算术逻辑单元）内部的标志位生成机制，属于单系统内部逻辑，不涉及跨子系统（如内存、I/O、中断控制器）的状态传递或耦合。
- **雷达形状**: K4陷阱型（K4显著高于其他维度，K1中等，K2/K3较低）

## 考察模式
- **模式**: 综合型（偏概念辨析与计算验证）
- **理由**: 题目既要求执行具体的二进制计算（计算型），又要求基于计算结果应用特定的标志位判定规则（概念型）。核心难点不在于计算本身，而在于正确映射计算结果到不同的标志位定义上，属于典型的“计算+规则映射”综合考察。

## 选项级分析
- **选项A (1, 1, 0)**: [干扰] — 针对“混淆CF与OF”或“误判溢出”的错误认知。这类学生可能看到最高位有进位（CF=1），同时错误地认为有进位就是溢出（OF=1），或者错误地使用了“符号位进位输入与输出异或”规则但计算错误（实际上异号相加OF必为0）。
- **选项B (1, 0, 0)**: [正确] — CF=1（最高位向第9位进位），OF=0（正数+负数，不可能溢出），SF=0（结果00110110为正数）。
- **选项C (0, 1, 0)**: [干扰] — 针对“完全忽略进位”或“概念颠倒”的错误认知。这类学生可能认为补码运算不看进位标志（CF=0），或者错误地认为发生了溢出（OF=1）。也可能是在计算二进制加法时出错，导致没有产生最高位进位。
- **选项D (1, 0, 1)**: [干扰] — 针对“符号标志判断错误”的错误认知。这类学生正确计算了CF和OF，但在判断结果符号时出错。可能误将结果的最高位（第8位，即符号位）看错，或者误以为结果溢出导致符号翻转。实际上结果 `00110110` 的符号位是0。

- **干扰策略**: 概念混淆（CF与OF的定义混淆）与计算陷阱（二进制加法进位链错误）相结合。

## 核心陷阱
**“最高位进位”不等于“有符号数溢出”**。
考生极易将无符号数运算的进位标志（CF）与有符号数运算的溢出标志（OF）混为一谈。在补码加法中，异号相加（正+负）绝对不会产生溢出（OF=0），即使最高位产生了进位（CF=1）。这是本题最大的认知陷阱。

## 考察能力
准确区分并应用无符号数进位标志（CF）与有符号数溢出标志（OF）的判定规则，并能正确执行二进制补码加法运算。
