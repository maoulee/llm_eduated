# 数据结构知识点名词库 v2（思维导图层级版）

来源：`数据结构思维导图【精简版】.pdf`，38页。  
用途：给出数据结构课程的可出题知识点空间；不提供定义、公式、组合方式或真题风格。  
粒度原则：叶子节点到“可单独成为小题核心或可与其他叶子组合成题”的概念 / 操作 / 机制 / 计算任务 / 边界条件。  
属性说明：
- `概念`: 概念、术语、分类、性质
- `结构`: 数据结构组成、存储结构、结点字段
- `操作`: 插入、删除、查找、遍历、构造、转换等动作
- `机制`: 过程性机制、算法流程、状态转移
- `计算`: 长度、复杂度、次数、容量、路径、代价等计算任务
- `边界`: 空表、满队、首尾结点、特殊形态、异常情况
