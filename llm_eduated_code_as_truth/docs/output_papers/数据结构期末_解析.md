## Q1（2 分）
*考点：顺序表与链表的插入删除复杂度对比*

## 题目

# 概念题

## 第 1 题

**题干**：关于顺序表与链表的插入、删除操作，下列说法正确的是？

A. 顺序表在任意位置插入/删除元素的时间复杂度为 O(1)
B. 链表在任意位置插入/删除节点的时间复杂度为 O(1)
C. 顺序表在已知位置插入/删除元素的时间复杂度为 O(n)，链表在已知指针位置插入/删除节点的时间复杂度为 O(1)
D. 顺序表与链表在任意位置插入/删除操作的时间复杂度均为 O(n)

## 参考答案

C

## 解析

# 概念题解析

## 第 1 题解析

**答案**：C

**解析**：C 正确，因为顺序表插入/删除需要移动后续元素，时间复杂度为 O(n)；链表在已知指针位置只需修改前后节点的指针域，时间复杂度为 O(1)。A 错误，顺序表插入/删除需要移动元素，时间复杂度为 O(n) 而非 O(1)。B 错误，链表在"任意位置"插入/删除需先遍历找到该位置，查找耗时 O(n)，只有在已知指针位置时才是 O(1)。D 错误，链表在已知指针位置插入/删除的时间复杂度为 O(1)，并非均为 O(n)。

## Q3（2 分）
*考点：栈的应用——表达式求值中的栈操作*

## 题目

# 概念题

## 第 1 题

**题干**：在中缀表达式转换为后缀表达式的算法中，关于运算符栈的操作，下列说法正确的是：

A. 遇到运算符时，若其优先级高于栈顶运算符则入栈，否则弹出栈顶运算符
B. 遇到左括号时入栈，遇到右括号时弹出栈顶运算符直到左括号
C. 遇到操作数时入栈，遇到运算符时弹出栈顶操作数
D. 转换结束时，栈中剩余的运算符按入栈顺序输出

## 参考答案

B

## 解析

# 概念题解析

## 第 1 题解析

**答案**：B

**解析**：

B 正确：在中缀转后缀算法中，左括号 `(` 作为标记入栈，遇到右括号 `)` 时，不断弹出栈顶运算符并输出，直到弹出左括号（左括号本身弹出但不输出），这保证了括号内子表达式的运算符优先输出。

A 错误：该描述遗漏了两个关键点——①未处理左括号的情况；②对于左结合运算符，当优先级**等于**栈顶时也应弹出（而非仅"高于"才入栈），例如 `a-b+c` 中 `-` 和 `+` 优先级相同，`-` 应先输出。

C 错误：操作数直接输出到结果序列，**不入栈**；入栈的是运算符和左括号。该选项将操作数与运算符的角色完全颠倒。

D 错误：转换结束时栈中**不应有剩余运算符**（若表达式合法且括号匹配）。若表达式扫描完毕栈仍非空，需将栈中所有运算符依次弹出输出，而非"按入栈顺序"——栈是 LIFO 结构，弹出顺序与入栈顺序相反。

## Q4（2 分）
*考点：KMP模式匹配——next数组计算*

## 题目

设模式串 $S = \text{"ababa"}$，其 next 数组值为（ ）。

A. $[0, 1, 1, 2, 3]$
B. $[-1, 0, 0, 1, 2]$
C. $[0, 1, 1, 2, 2]$
D. $[0, 0, 0, 1, 2]$

## 参考答案

A

## 解析

**1. 明确 next 数组定义（严蔚敏版）**

*   next[1] = 0
*   next[2] = 1
*   next[j] = 模式串前 j-1 个字符组成的子串的最长相等真前后缀长度 + 1

**2. 逐位计算模式串 $S = \text{"ababa"}$ 的 next 数组**

*   **j = 1**：
    *   next[1] = 0

*   **j = 2**：
    *   next[2] = 1

*   **j = 3**：
    *   子串为 "ab"
    *   真前缀："a"，真后缀："b"
    *   最长相等真前后缀长度 = 0
    *   next[3] = 0 + 1 = 1

*   **j = 4**：
    *   子串为 "aba"
    *   真前缀："a", "ab"，真后缀："a", "ba"
    *   最长相等真前后缀为 "a"，长度 = 1
    *   next[4] = 1 + 1 = 2

*   **j = 5**：
    *   子串为 "abab"
    *   真前缀："a", "ab", "aba"，真后缀："b", "ab", "bab"
    *   最长相等真前后缀为 "ab"，长度 = 2
    *   next[5] = 2 + 1 = 3

**3. 汇总结果**

next 数组值为：$[0, 1, 1, 2, 3]$

**4. 干扰项分析**

*   **A. $[0, 1, 1, 2, 3]$**：正确。符合严蔚敏版定义及计算结果。
*   **B. $[-1, 0, 0, 1, 2]$**：错误。这是下标从 0 开始的定义版本（next[0]=-1, next[1]=0, next[j]=长度），属于定义版本混淆。
*   **C. $[0, 1, 1, 2, 2]$**：错误。在 j=5 处，误判 "abab" 的最长相等真前后缀长度为 1（实际为 2），导致 next[5] 计算为 2。属于前后缀判断错误。
*   **D. $[0, 0, 0, 1, 2]$**：错误。忘记 "+1" 规则，直接用前后缀长度作为 next 值（next[j]=长度）。属于 next 值与前后缀长度关系混淆。

## Q5（2 分）
*考点：完全二叉树——结点编号与性质计算*

## 题目
若一棵完全二叉树按层序从1开始编号，其中某结点编号为 15，则该结点的父结点编号是（）

A. 7
B. 8
C. 16
D. 30

## 参考答案
A

## 解析
完全二叉树结点编号性质规定：若结点编号为 $i$（$i>1$），则其父结点编号为 $\lfloor i/2 \rfloor$（即 $i$ 除以 2 向下取整）。

本题中 $i=15$，代入公式得：
$$\lfloor 15/2 \rfloor = \lfloor 7.5 \rfloor = 7$$

验证：编号为 7 的结点的左孩子编号为 $2 \times 7 = 14$，右孩子编号为 $2 \times 7 + 1 = 15$。因此编号 15 确实是编号 7 的右孩子，编号 7 是其父结点。

**干扰项分析：**
- **B. 8**：off-by-one 错误。误用向上取整 $\lceil 15/2 \rceil = 8$ 或误用公式 $(i+1)/2$ 计算。
- **C. 16**：公式混淆。误认为父结点编号为 $i+1$（$15+1=16$），或混淆其他编号规则。
- **D. 30**：概念混淆。误用左孩子编号公式 $2i = 2 \times 15 = 30$，将求父结点误算为求左孩子。

## Q6（2 分）
*考点：哈夫曼树——性质辨析*

## 题目

# 概念题

## 第 1 题

**题干**：关于哈夫曼树的性质，以下说法正确的是（ ）。

A. 哈夫曼树一定是完全二叉树
B. 哈夫曼树中不存在度为 1 的节点
C. 哈夫曼树中权值相同的叶子节点到根节点的路径长度一定相等
D. 哈夫曼树的带权路径长度在所有二叉树中是最大的

## 参考答案

B

## 解析

# 概念题解析

## 第 1 题解析

**答案**：B

**解析**：

- **B 正确**：哈夫曼树构造过程中，每次从森林中选取两棵根节点权值最小的树合并为一棵新树，新树的根节点有两个孩子，因此所有内部节点的度数均为 2，不存在度为 1 的节点。

- **A 错误**：哈夫曼树不一定是完全二叉树。完全二叉树要求节点按层序编号时与满二叉树同深度的编号一一对应，而哈夫曼树的形态取决于权值分布和合并策略，权值差异较大时可能产生深度不同的分支，不满足完全二叉树的定义。

- **C 错误**：权值相同的叶子节点到根的路径长度不一定相等。虽然哈夫曼算法倾向于让权值大的节点离根更近，但权值相同的节点在不同合并轮次中可能被合并的时机不同（取决于与其他节点的相对大小关系），导致路径长度不同。

- **D 错误**：哈夫曼树的带权路径长度（WPL）在所有具有相同叶子节点和权值的二叉树中是**最小的**，而非最大的。这正是哈夫曼编码能够实现最优压缩的核心原理。

## Q7（2 分）
*考点：最小生成树——Prim/Kruskal算法结果判断*

## 题目
给定一个具有5个顶点（A, B, C, D, E）和7条边的带权无向图，各边及其权值如下：

- (A, B): 1
- (B, C): 2
- (B, D): 2
- (C, D): 3
- (D, E): 4
- (A, E): 5
- (C, E): 6

请使用 **Kruskal算法** 构造该图的最小生成树。若遇到权值相同的边，按边的顶点字典序选择（例如 (A, B) 优先于 (A, C)）。

该图最小生成树的总权值为？

A. 9
B. 8
C. 10
D. 11

## 参考答案
A

## 解析
**考察点**：Kruskal算法的多步边选择推演、贪心策略应用、合法性判断（不形成环）。

**推演过程**：
1.  **边排序**：首先将所有边按权值从小到大排序。权值相同时按字典序排列。
    - (A, B): 1
    - (B, C): 2
    - (B, D): 2
    - (C, D): 3
    - (D, E): 4
    - (A, E): 5
    - (C, E): 6

2.  **逐步选择**：
    - **第1步**：选择 (A, B)，权值 1。当前连通分量：{A, B}, {C}, {D}, {E}。合法。
    - **第2步**：选择 (B, C)，权值 2。当前连通分量：{A, B, C}, {D}, {E}。合法。
    - **第3步**：选择 (B, D)，权值 2。当前连通分量：{A, B, C, D}, {E}。合法。
    - **第4步**：考察 (C, D)，权值 3。顶点 C 和 D 已在同一连通分量 {A, B, C, D} 中，选择该边会形成环（C-B-D-C）。**拒绝**。
    - **第5步**：选择 (D, E)，权值 4。当前连通分量：{A, B, C, D, E}。合法。
    - 此时所有顶点已连通，最小生成树构造完成。

3.  **计算总权值**：
    - 选中的边为：(A, B), (B, C), (B, D), (D, E)。
    - 总权值 = 1 + 2 + 2 + 4 = 9。

**干扰项分析**：
- **B (8)**：错误地将形成环的边 (C, D) 纳入计算（1+2+2+3=8），忽略了合法性判断。
- **C (10)**：采用了路径贪心策略（A-B-C-D-E），忽略了更优的捷径边 (B, D)（1+2+3+4=10）。
- **D (11)**：随机错误或对算法理解偏差导致的数值。

## Q8（2 分）
*考点：最短路径算法——Dijkstra/BFS适用场景辨析*

## 题目

# 概念题

## 第 1 题

**题干**：关于最短路径算法的适用条件，下列说法正确的是：

A. BFS可以用于求解任意带权图的最短路径问题
B. Dijkstra算法可以处理含有负权边的图
C. 对于无权图，BFS和Dijkstra算法都能求出最短路径，且BFS的时间复杂度更低
D. Dijkstra算法只能用于有向图，不能用于无向图

## 参考答案

C

## 解析

# 概念题解析

## 第 1 题解析

**答案**：C

**解析**：

- **C 正确**：无权图可视为所有边权为1的带权图，BFS按层遍历天然求得最短路径，Dijkstra也能求解（每次选距离最小的未访问节点），但BFS时间复杂度为O(V+E)，Dijkstra使用优先队列时为O((V+E)logV)，故BFS更低。

- **A 错误**：BFS按层遍历，只保证无权图中层数最少（即边数最少），带权图中边权不同，层数少不代表总权值小，因此BFS不能用于带权图的最短路径求解。

- **B 错误**：Dijkstra算法基于贪心策略，一旦节点被标记为"已确定最短路径"就不再更新，负权边可能导致已确定节点的最短路径被后续更小的权值更新，破坏算法正确性。

- **D 错误**：Dijkstra算法对图的类型无限制，有向图和无向图均可使用，区别仅在于邻接表/邻接矩阵的存储方式不同。

## Q9（2 分）
*考点：哈希表——线性探测冲突处理与ASL计算*

## 题目
现有长度为 11 且初始为空的散列表 HT，散列函数是 H(key)=key%7，采用线性探测法解决冲突。将关键字序列 47, 79, 83, 13, 38, 37, 2 依次插入到 HT 后，HT 查找失败的平均查找长度是（ ）。

A. 32/7
B. 32/11
C. 33/7
D. 16/7

## 参考答案
A

## 解析
### 1. 模拟线性探测插入过程
散列表长度 $L=11$，哈希函数 $H(key) = key \% 7$，采用线性探测法处理冲突。依次插入关键字序列：47, 79, 83, 13, 38, 37, 2。

| 关键字 | $H(key)$ | 探测过程 | 最终位置 | 散列表状态（索引 0~10） |
| :--- | :---: | :--- | :---: | :--- |
| 47 | 5 | 位置 5 空 | 5 | `[_, _, _, _, _, 47, _, _, _, _, _]` |
| 79 | 2 | 位置 2 空 | 2 | `[_, _, 79, _, _, 47, _, _, _, _, _]` |
| 83 | 6 | 位置 6 空 | 6 | `[_, _, 79, _, _, 47, 83, _, _, _, _]` |
| 13 | 6 | 6(占)→7(空) | 7 | `[_, _, 79, _, _, 47, 83, 13, _, _, _]` |
| 38 | 3 | 位置 3 空 | 3 | `[_, _, 79, 38, _, 47, 83, 13, _, _, _]` |
| 37 | 2 | 2(占)→3(占)→4(空) | 4 | `[_, _, 79, 38, 37, 47, 83, 13, _, _, _]` |
| 2 | 2 | 2(占)→3(占)→4(占)→5(占)→6(占)→7(占)→8(空) | 8 | `[_, _, 79, 38, 37, 47, 83, 13, 2, _, _]` |

最终散列表状态：
- 索引 0, 1, 9, 10：空
- 索引 2：79
- 索引 3：38
- 索引 4：37
- 索引 5：47
- 索引 6：83
- 索引 7：13
- 索引 8：2

### 2. 计算查找失败的平均查找长度（ASL$_{fail}$）
查找失败时，对于哈希值域中的每一个入口 $i$ ($0 \le i \le 6$)，从该位置开始线性探测，直到遇到**空位**为止，统计比较次数。分母为哈希值域大小（模数 $m=7$），而非散列表长度。

| 哈希入口 $i$ | 探测序列 | 比较次数 $C_i$ | 说明 |
| :---: | :--- | :---: | :--- |
| 0 | 0(空) | 1 | 直接遇到空位 |
| 1 | 1(空) | 1 | 直接遇到空位 |
| 2 | 2(79)→3(38)→4(37)→5(47)→6(83)→7(13)→8(2)→9(空) | 8 | 连续探测至索引 9 遇到空位 |
| 3 | 3(38)→4(37)→5(47)→6(83)→7(13)→8(2)→9(空) | 7 | 连续探测至索引 9 遇到空位 |
| 4 | 4(37)→5(47)→6(83)→7(13)→8(2)→9(空) | 6 | 连续探测至索引 9 遇到空位 |
| 5 | 5(47)→6(83)→7(13)→8(2)→9(空) | 5 | 连续探测至索引 9 遇到空位 |
| 6 | 6(83)→7(13)→8(2)→9(空) | 4 | 连续探测至索引 9 遇到空位 |

总比较次数：$\sum C_i = 1 + 1 + 8 + 7 + 6 + 5 + 4 = 32$
ASL$_{fail} = \frac{32}{7}$

### 3. 选项分析
- **A. 32/7（正确）**：正确模拟插入过程，以哈希值域大小（7）为分母计算查找失败ASL。
- **B. 32/11（干扰）**：分母错误。误将散列表长度（11）当作分母，混淆了哈希值域大小与表长的概念。
- **C. 33/7（干扰）**：Off-by-one 错误。可能在某次冲突探测步数统计时多算或少算 1 次，导致分子偏差。
- **D. 16/7（干扰）**：概念混淆。计算的是**查找成功**的平均查找长度。查找成功ASL为各关键字查找成功时的比较次数之和除以关键字个数：$(1+1+1+2+1+3+7)/7 = 16/7$。

### 核心考点
1. **线性探测冲突处理**：掌握给定哈希函数和关键字序列时，多步插入过程中的状态累积与冲突探测规则。
2. **查找失败 ASL 计算**：明确查找失败 ASL 的定义，正确确定分母为哈希值域大小（模数 $m$），分子为各哈希入口探测至空位的比较次数之和。
3. **概念区分**：严格区分查找成功 ASL 与查找失败 ASL 的计算方法，以及哈希值域大小与散列表长度的差异。

## Q10（2 分）
*考点：快速排序——第一趟划分结果判断*

## 题目
给定初始序列 `49, 38, 65, 97, 76, 13, 27`，使用快速排序算法进行升序排序。若取第一个元素作为枢轴（pivot），则经过第一趟划分（partition）后得到的序列是（ ）。

A. `13, 38, 27, 49, 76, 97, 65`
B. `49, 38, 27, 13, 76, 97, 65`
C. `38, 27, 49, 76, 97, 65, 13`
D. `13, 27, 38, 49, 65, 76, 97`

## 参考答案
A

## 解析
**解析**：
本题考查快速排序第一趟划分（partition）的过程模拟。
初始序列：`49, 38, 65, 97, 76, 13, 27`，枢轴 `pivot = 49`。
采用双向扫描交换法（严蔚敏版教材常用算法）：
1. `low` 指向首元素（索引0），`high` 指向尾元素（索引6）。
2. `high` 向左扫描，寻找小于 `49` 的元素：

## Q11（10 分）
*考点：二叉树遍历序列还原*

## 题目
已知某二叉树的结点值互不相同，其先序遍历序列为 `A B D E C F H G`，中序遍历序列为 `D B E A F H C G`。请完成以下问题：

（1）还原该二叉树的结构。要求用文字描述各结点的位置关系（例如："结点X为根，左孩子为Y，右孩子为Z；结点Y的左孩子为W，无右孩子"等），无需画图。

（2）基于第（1）问还原的二叉树结构，写出该二叉树的后序遍历序列。

（3）基于第（1）问还原的二叉树结构，写出该二叉树的层序遍历序列。

## 参考答案
（1）二叉树结构描述：
结点 A 为根，左孩子为 B，右孩子为 C；
结点 B 的左孩子为 D，右孩子为 E；
结点 C 的左孩子为 F，右孩子为 G；
结点 F 无左孩子，右孩子为 H；
结点 D、E、G、H 均为叶子结点。

（2）后序遍历序列：`D E B H F G C A`

（3）层序遍历序列：`A B C D E F G H`

## 解析
**（1）还原二叉树结构**

根据先序遍历序列 `A B D E C F H G`，首元素 `A` 为二叉树的根结点。
在中序遍历序列 `D B E A F H C G` 中，`A` 将序列划分为左右两部分：
- 左子树中序：`D B E`，对应先序：`B D E`
- 右子树中序：`F H C G`，对应先序：`C F H G`

**分析左子树**：先序首元素 `B` 为左子树根结点。在中序 `D B E` 中，`B` 左侧为 `D`，右侧为 `E`。因此，`B` 的左孩子为 `D`，右孩子为 `E`。`D` 和 `E` 均为叶子结点。

**分析右子树**：先序首元素 `C` 为右子树根结点。在中序 `F H C G` 中，`C` 左侧为 `F H`，右侧为 `G`。因此，`C` 的右孩子为 `G`（叶子结点）。`C` 的左子树中序为 `F H`，对应先序为 `F H`。先序首元素 `F` 为该子树根结点。在中序 `F H` 中，`F` 右侧为 `H`。因此，`F` 的右孩子为 `H`（叶子结点），无左孩子。

**结构总结**：结点 `A` 为根，左孩子为 `B`，右孩子为 `C`；结点 `B` 的左孩子为 `D`，右孩子为 `E`；结点 `C` 的左孩子为 `F`，右孩子为 `G`；结点 `F` 无左孩子，右孩子为 `H`；结点 `D`、`E`、`G`、`H` 均为叶子结点。

**（2）后序遍历序列**

后序遍历顺序为：左子树 → 右子树 → 根结点。
- 左子树（根 `B`）后序：`D` → `E` → `B`
- 右子树（根 `C`）后序：`C` 的左子树（根 `F`）后序为 `H` → `F`；`C` 的右子树（根 `G`）后序为 `G`。合并得 `H` → `F` → `G` → `C`。
- 整棵树后序：`D E B` → `H F G C` → `A`
结果为：`D E B H F G C A`

**（3）层序遍历序列**

层序遍历按从上到下、从左到右的顺序访问结点。
- 第 1 层：`A`
- 第 2 层：`B`、`C`
- 第 3 层：`D`、`E`、`F`、`G`
- 第 4 层：`H`（`F` 的右孩子）
结果为：`A B C D E F G H`

## Q12（10 分）
*考点：图的遍历——DFS/BFS序列与生成树*

## 题目
给定无向连通图 $G=(V, E)$，其邻接表表示如下（邻接表中同一顶点的邻接点按顶点编号升序排列）：
邻接表结构 $L$：
$v_1: 2, 3$
$v_2: 1, 4, 5$
$v_3: 1, 6$
$v_4: 2, 5$
$v_5: 2, 4, 6$
$v_6: 3, 5$

请从顶点 $v_1$ 出发对图 $G$ 进行遍历，完成以下问题：

（1）从顶点 $v_1$ 出发对图 $G$ 进行深度优先遍历（DFS），写出遍历序列。（3分）

（2）从顶点 $v_1$ 出发对图 $G$ 进行广度优先遍历（BFS），写出遍历序列。（3分）

（3）写出上述深度优先遍历（DFS）过程中生成的生成树的边集。（4分）

## 参考答案
（1）$v_1, v_2, v_4, v_5, v_6, v_3$
（2）$v_1, v_2, v_3, v_4, v_5, v_6$
（3）$\{(v_1, v_2), (v_2, v_4), (v_4, v_5), (v_5, v_6), (v_6, v_3)\}$

## 解析
### （1）深度优先遍历（DFS）序列推导
**算法模拟**：
1. 访问起点 $v_1$。标记 $v_1$ 已访问。当前序列：$v_1$。$v_1$ 的邻接点：$2, 3$。
2. 访问 $v_1$ 的第一个未访问邻接点 $v_2$。标记 $v_2$ 已访问。当前序列：$v_1, v_2$。$v_2$ 的邻接点：$1, 4, 5$。
3. 访问 $v_2$ 的第一个未访问邻接点 $v_4$（$1$ 已访问）。标记 $v_4$ 已访问。当前序列：$v_1, v_2, v_4$。$v_4$ 的邻接点：$2, 5$。
4. 访问 $v_4$ 的第一个未访问邻接点 $v_5$（$2$ 已访问）。标记 $v_5$ 已访问。当前序列：$v_1, v_2, v_4, v_5$。$v_5$ 的邻接点：$2, 4, 6$。
5. 访问 $v_5$ 的第一个未访问邻接点 $v_6$（$2, 4$ 已访问）。标记 $v_6$ 已访问。当前序列：$v_1, v_2, v_4, v_5, v_6$。$v_6$ 的邻接点：$3, 5$。
6. 访问 $v_6$ 的第一个未访问邻接点 $v_3$（$5$ 已访问）。标记 $v_3$ 已访问。当前序列：$v_1, v_2, v_4, v_5, v_6, v_3$。$v_3$ 的邻接点：$1, 6$。
7. $v_3$ 的所有邻接点（$1, 6$）均已访问，回溯到 $v_6$。
8. $v_6$ 的所有邻接点（$3, 5$）均已访问，回溯到 $v_5$。
9. $v_5$ 的所有邻接点（$2, 4, 6$）均已访问，回溯到 $v_4$。
10. $v_4$ 的所有邻接点（$2, 5$）均已访问，回溯到 $v_2$。
11. $v_2$ 的下一个邻接点 $v_5$ 已访问，回溯到 $v_1$。
12. $v_1$ 的下一个邻接点 $v_3$ 已访问，遍历结束。

### （2）广度优先遍历（BFS）序列推导
**算法模拟**：
1. 访问起点 $v_1$，入队。队列：$[v_1]$。标记 $v_1$ 已访问。
2. 出队 $v_1$。访问其未访问邻接点 $v_2, v_3$，依次入队。当前序列：$v_1$。队列：$[v_2, v_3]$。标记 $v_2, v_3$ 已访问。
3. 出队 $v_2$。访问其未访问邻接点 $v_4, v_5$（$1$ 已访问），依次入队。当前序列：$v_1, v_2$。队列：$[v_3, v_4, v_5]$。标记 $v_4, v_5$ 已访问。
4. 出队 $v_3$。访问其未访问邻接点 $v_6$（$1$ 已访问），入队。当前序列：$v_1, v_2, v_3$。队列：$[v_4, v_5, v_6]$。标记 $v_6$ 已访问。
5. 出队 $v_4$。邻接点 $2, 5$ 均已访问。当前序列：$v_1, v_2, v_3, v_4$。队列：$[v_5, v_6]$。
6. 出队 $v_5$。邻接点 $2, 4, 6$ 均已访问。当前序列：$v_1, v_2, v_3, v_4, v_5$。队列：$[v_6]$。
7. 出队 $v_6$。邻接点 $3, 5$ 均已访问。当前序列：$v_1, v_2, v_3, v_4, v_5, v_6$。队列：$[]$。
8. 队列为空，遍历结束。

### （3）DFS 生成树的边集推导
**判定规则**：
在 DFS 遍历过程中，当从顶点 $u$ 访问到其未访问邻接点 $v$ 时，边 $(u, v)$ 为生成树的树边。

**过程回顾**：
1. 从 $v_1$ 访问 $v_2$：边 $(v_1, v_2)$ 是树边。
2. 从 $v_2$ 访问 $v_4$：边 $(v_2, v_4)$ 是树边。
3. 从 $v_4$ 访问 $v_5$：边 $(v_4, v_5)$ 是树边。
4. 从 $v_5$ 访问 $v_6$：边 $(v_5, v_6)$ 是树边。
5. 从 $v_6$ 访问 $v_3$：边 $(v_6, v_3)$ 是树边。
6. $v_3$ 的邻接点 $1, 6$ 均已访问，无新树边。
7. 回溯过程中，所有邻接点均已访问，无新树边。

### 1. 堆排序建堆过程（2分）

- 初始序列：`[49, 38, 65, 97, 76, 13, 27]`，长度 $n=7$。
- 最后一个非叶子节点索引为 $\lfloor 7/2 \rfloor - 1 = 2$（对应值 65）。自底向上进行筛选调整：
  - **调整节点 2（值 65）**：左孩子 13，右孩子 27。$65 > 13$ 且 $65 > 27$，满足大顶堆性质，无需交换。
  - **调整节点 1（值 38）**：左孩子 97，右孩子 76。$38 < 97$，交换 38 与 97。序列变为 `[49, 97, 65, 38, 76, 13, 27]`。交换后节点 1 变为 97，其子节点为 38，$97 > 38$，无需继续调整。

> **关键得分点**：调整节点 0 时，与左孩子 97 交换后需继续向下检查节点 1，发现 $49 < 76$ 再次交换。遗漏此步将导致初始堆错误。

### 2. 堆排序逐趟排序结果（3分）

每趟将堆顶元素与当前堆末尾元素交换，堆范围缩小 1，再对堆顶进行筛选调整（下沉到合法位置即停，**注意孩子索引超出堆范围时停止，不得继续交换**）：

- **第 1 趟**：堆顶 97 与末尾 27 交换，堆范围缩至前 6。筛堆顶 27：孩子 76、65，与较大者 76 交换；落于索引 1，孩子 38、49，与较大者 49 交换；落于索引 4，孩子越界停止。状态：`[76, 49, 65, 38, 27, 13, 97]`
- **第 2 趟**：堆顶 76 与末尾 13 交换，堆范围缩至前 5。筛堆顶 13：孩子 49、65，与较大者 65（索引 2）交换；落于索引 2，**孩子索引 5、6 已超出堆范围（前 5 个），停止**，不再交换。状态：`[65, 49, 13, 38, 27, 76, 97]`
- **第 3 趟**：堆顶 65 与末尾 27 交换，堆范围缩至前 4。筛堆顶 27：孩子 49、13，与较大者 49（索引 1）交换；落于索引 1，孩子 38（索引 3，在范围内），$27<38$ 交换。状态：`[49, 38, 13, 27, 65, 76, 97]`
- **第 4 趟**：堆顶 49 与末尾 27 交换，堆范围缩至前 3。筛堆顶 27：孩子 38、13，与较大者 38 交换；落于索引 1，孩子越界停止。状态：`[38, 27, 13, 49, 65, 76, 97]`
- **第 5 趟**：堆顶 38 与末尾 13 交换，堆范围缩至前 2。筛堆顶 13：孩子 27，交换。状态：`[27, 13, 38, 49, 65, 76, 97]`
- **第 6 趟**：堆顶 27 与末尾 13 交换，堆范围缩至前 1。状态：`[13, 27, 38, 49, 65, 76, 97]`
- **最终有序序列**：`[13, 27, 38, 49, 65, 76, 97]`

> **关键得分点**：每趟"交换堆顶与末尾→缩小堆范围→筛选调整堆顶"三步。**第 2 趟易错点**：13 与 65 交换后落于索引 2，其孩子索引 5、6 已超出堆范围（堆仅前 5 个），此时必须停止，**不得再与索引 3 的 38 交换**（常见错误导致 13 与 38 位置颠倒）。

---

### 3. 归并排序逐趟结果（3分）

二路归并排序采用自底向上的合并策略：

- **初始状态**（长度为 1 的子序列）：`[49], [38], [65], [97], [76], [13], [27]`
- **第 1 趟**（两两合并）：`[38, 49], [65, 97], [13, 76], [27]`
  - 说明：前 6 个元素两两合并，第 7 个元素 `[27]` 单独保留。
- **第 2 趟**（四四合并）：`[38, 49, 65, 97], [13, 27, 76]`
  - 说明：前两个有序子序列合并为 `[38, 49, 65, 97]`，后三个有序子序列合并为 `[13, 27, 76]`。
- **第 3 趟**（整体合并）：`[13, 27, 38, 49, 65, 76, 97]`

> **关键得分点**：奇数长度序列第一趟会剩余一个独立子序列，需正确保留。每趟结果正确得 1 分。

---

### 4. 复杂度对比分析（2分）

- **时间复杂度**：
  - **堆排序**：最好、最坏、平均情况均为 $O(n\log n)$。建堆过程时间复杂度为 $O(n)$，后续 $n-1$ 趟排序每趟调整堆的时间复杂度为 $O(\log n)$，总计 $O(n\log n)$。
  - **归并排序**：最好、最坏、平均情况均为 $O(n\log n)$。递归树深度为 $\log n$，每一层合并操作的时间复杂度为 $O(n)$，总计 $O(n\log n)$。
- **空间复杂度**：
  - **堆排序**：$O(1)$。属于原地排序算法，仅需常数级辅助空间用于元素交换。
  - **归并排序**：$O(n)$。非原地排序，在合并过程中需要申请与原始序列等长的辅助数组来暂存有序子序列。
- **差异总结**：两者时间复杂度相同且稳定，但堆排序空间效率更高（原地排序），而归并排序空间开销较大但具有稳定性（相等元素的相对位置不变）。

## Q17（14 分）
*考点：链表——双指针法查找倒数第k个结点*

## 题目
已知带头结点的单链表存储结构定义如下：
```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```
请设计一个算法，查找该单链表中倒数第 $k$ 个结点。要求算法满足以下条件：
1. **空间复杂度为 $O(1)$**，不得使用额外数组、栈或递归；
2. **时间复杂度为 $O(n)$**，仅通过一趟遍历完成查找；
3. **不改变原链表的结构**；
4. **正确处理边界条件**（如 $k \le 0$、$k$ 大于链表实际长度、链表仅含头结点等异常情况）。

请按以下三个部分作答：
（1）**数据类型定义**：在代码中体现带头结点单链表的结点类型定义。
（2）**设计思想描述**：清晰阐述算法的基本设计思想，重点说明如何利用双指针法（快慢指针）维护相对距离以定位目标结点。
（3）**完整代码实现**：根据上述设计思想，编写完整的 C/C++ 函数代码。代码需包含必要的边界判断、指针移动逻辑及返回值处理。

## 参考答案
（1）数据类型定义：
```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```
（2）设计思想：采用双指针法（快慢指针）。初始化 `fast` 和 `slow` 均指向头结点。`fast` 先向前移动 $k$ 步建立相对距离；随后两指针同步前移，每次一步。当 `fast` 指向 `NULL` 时，`slow` 恰好指向倒数第 $k$ 个结点。需提前处理 $k \le 0$ 或 $k$ 大于链表长度的边界情况。
（3）完整代码实现：
```c
LNode* FindKthFromEnd(LinkList L, int k) {
    if (L == NULL || k <= 0) return NULL;
    LNode *fast = L, *slow = L;
    for (int i = 0; i < k; i++) {
        if (fast->next != NULL) fast = fast->next;
        else return NULL; // k 大于链表实际长度
    }
    while (fast != NULL) {
        fast = fast->next;
        slow = slow->next;
    }
    return slow;
}
```

## 解析
本题主要考查单链表的双指针遍历技巧及边界条件处理能力。详细解析如下：

1. **算法设计推导**：
   - 传统方法需先遍历一次求长度 $n$，再遍历一次找第 $n-k+1$ 个结点，时间复杂度虽为 $O(n)$ 但需两趟。
   - 双指针法通过维护两个指针的固定距离实现一趟遍历。设 `fast` 和 `slow` 初始均指向头结点。`fast` 先走 $k$ 步，此时两指针间隔 $k$ 个结点。随后同步移动，当 `fast` 到达链表末尾（`NULL`）时，`slow` 距离末尾恰好 $k$ 步，即指向倒数第 $k$ 个结点。

2. **边界条件分析**：
   - $k \le 0$：倒数位置非法，直接返回 `NULL`。
   - $k$ 大于链表实际长度：在 `fast` 先行 $k$ 步的过程中，若 `fast->next` 提前为 `NULL`，说明链表结点不足 $k$ 个，无法找到目标，返回 `NULL`。
   - 链表仅含头结点（无数据结点）：此时头结点 `next` 为 `NULL`，若 $k=1$，`fast` 走 1 步后指向 `NULL`，`slow` 仍指向头结点，返回头结点（逻辑成立）。
   - $L == NULL$：链表指针本身为空，直接返回 `NULL`。

3. **复杂度验证**：
   - 时间复杂度：`fast` 先行 $k$ 步，随后两指针同步移动最多 $n-k$ 步，总步数不超过 $n$，故为 $O(n)$。
   - 空间复杂度：仅使用 `fast`、`slow` 两个指针变量及循环计数器，额外空间为常数级，故为 $O(1)$。

4. **评分标准参考**：
   - 数据类型定义正确（1分）
   - 设计思想清晰阐述双指针相对距离维护逻辑（3分）
   - 代码实现完整，包含边界判断、指针移动及返回值（4分）
   - 复杂度符合题目要求且逻辑无漏洞（2分）

## Q18（16 分）
*考点：二叉树——WPL计算算法设计*

## 题目
二叉树的带权路径长度（WPL）是二叉树中所有叶结点的带权路径长度之和。其中，结点的带权路径长度为从根结点到该结点的路径长度与结点上权值的乘积，**路径长度指从根结点到该结点的路径上的分支数**。

假设二叉树采用二叉链表存储，结点结构定义如下：
```c
typedef struct BiTNode {
    int weight;           // 结点的非负权值
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

请设计一个递归算法计算二叉树 T 的 WPL。

要求：
⑴ 写出算法的基本设计思想。
⑵ 使用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释。
⑶ 说明你的算法的时间复杂度和空间复杂度。

## 参考答案
```c
// 递归计算WPL，depth为当前结点深度，wpl为累加器指针
void CalculateWPL(BiTree T, int depth, int *wpl) {
    if (T == NULL) return; // 空结点直接返回
    
    if (T->lchild == NULL && T->rchild == NULL) { // 递归基：叶结点
        *wpl += T->weight * depth; // 累加当前叶结点的带权路径长度
    } else { // 非叶结点：递归遍历左右子树，深度加1
        CalculateWPL(T->lchild, depth + 1, wpl);
        CalculateWPL(T->rchild, depth + 1, wpl);
    }
}

// 算法入口函数
int GetWPL(BiTree T) {
    int wpl = 0;
    CalculateWPL(T, 0, &wpl); // 初始深度为0
    return wpl;
}
```

## 解析
### ⑴ 算法的基本设计思想
采用递归遍历二叉树的方法计算带权路径长度（WPL）。在递归函数中传递当前结点的深度（即从根结点到该结点的路径长度）。初始调用时，根结点的深度为 0。
对于遍历到的每个结点：
1. 若该结点为叶结点（左右子树均为空），则计算其带权路径长度（权值 × 当前深度），并将其累加到 WPL 累加器中。
2. 若该结点不是叶结点，则分别递归遍历其左子树和右子树，递归调用时深度加 1。
通过自顶向下的递归遍历与深度累加，最终得到整棵二叉树的 WPL。

### ⑶ 算法复杂度分析
- **时间复杂度**：$O(n)$。算法采用递归遍历二叉树，每个结点恰好被访问一次，进行常数时间的判断与累加操作。设二叉树结点总数为 $n$，故时间复杂度为 $O(n)$。
- **空间复杂度**：$O(h)$。算法主要空间开销来自递归调用栈。递归的最大深度等于二叉树的高度 $h$，每次递归调用占用常数栈空间，故空间复杂度为 $O(h)$。在最坏情况下（树退化为单支树）为 $O(n)$，最好情况下（平衡二叉树）为 $O(\log_2 n)$。

### 评分标准参考
- 设计思想清晰，正确指出递归传递深度、叶结点累加、非叶结点递归深度+1，得相应分数。
- 代码实现正确，包含空指针判断、叶结点判断、递归调用及指针传参累加，关键注释完整，得相应分数。
- 复杂度分析准确，时间复杂度 $O(n)$，空间复杂度 $O(h)$ 并说明最坏/最好情况，得相应分数。
