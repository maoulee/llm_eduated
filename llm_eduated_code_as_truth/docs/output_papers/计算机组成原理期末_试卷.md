## Q8（10 分）
*考点：流水线性能计算与冒险分析*

**题目：流水线性能分析与数据冒险识别**

设某计算机采用 $k$ 级指令流水线，各级流水段的延迟分别为 $\Delta t_1, \Delta t_2, \dots, \Delta t_k$（单位：ns）。各级之间使用的级间寄存器延迟为 $\delta$（单位：ns）。假设流水线无停顿，处理 $n$ 个数据项。

给定一段指令序列 $S$ 如下：
$$
\begin{aligned}
I_1 &: \text{ADD } R_1, R_2, R_3 \\
I_2 &: \text{SUB } R_4, R_1, R_5 \\
I_3 &: \text{MUL } R_6, R_1, R_7 \\
I_4 &: \text{DIV } R_8, R_4, R_9
\end{aligned}
$$

请回答下列问题：

1. **时钟周期与总执行时间**：计算该流水线的时钟周期 $\Delta t$，以及处理 $n$ 个数据项所需的总执行时间 $T_{pipeline}$。
2. **加速比与效率**：计算该流水线相对于非流水线执行方式的加速比 $S$，以及流水线效率 $E$。
3. **数据冒险识别**：分析指令序列 $S$ 中存在的流水线数据冒险类型（RAW/WAR/WAW），并说明涉及的寄存器依赖关系。

## Q10（15 分）
*考点：ALU 数据通路与指令执行微操作序列*

给定一个简单CPU的数据通路组件集合 $C$ 和指令集 $I$。

**组件集合 $C$** 包含：程序计数器 PC、指令寄存器 IR、存储器地址寄存器 MAR、存储器数据寄存器 MDR、算术逻辑单元 ALU、寄存器堆 Register File、主存 Memory、系统总线 Bus 以及必要的多路选择器 MUX 和控制单元 CU。

**指令集 $I$** 包含三种类型的指令：
- R型指令（寄存器操作）：操作码 + 源寄存器1 + 源寄存器2 + 目标寄存器 + 功能字段
- I型指令（立即数操作）：操作码 + 源寄存器 + 目标寄存器 + 立即数字段
- J型指令（无条件跳转）：操作码 + 目标地址字段

请完成以下设计任务：

1. **数据通路连接描述**（4分）：用文字描述组件集合 $C$ 中各核心组件之间的连接关系和数据流向，重点说明取指通路和执行通路的数据传递路径。
2. **微操作序列设计**（7分）：针对指令集 $I$ 中的每种指令类型（R型、I型、J型），分别写出取指（IF）→译码（ID）→执行（EX）→写回（WB）四个阶段的微操作序列。微操作需使用标准符号（如 `←` 表示赋值，`( )` 表示寄存器内容，`Memory, Read/Write` 表示存储器操作）。
3. **控制信号表推导**（4分）：根据上述微操作序列，给出各指令在各阶段所需的控制信号表。表格需包含信号名称（如 RegWrite、MemRead、MemWrite、ALUSrc、PCSrc、MemtoReg、Jump 等）及各阶段取值（0或1）。
