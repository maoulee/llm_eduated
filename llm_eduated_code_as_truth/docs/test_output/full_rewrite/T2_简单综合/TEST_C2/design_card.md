## design_rationale

本题采用"给定两种遍历序列还原二叉树→基于还原结果求解衍生问题"的三段式结构，核心考察意图是检验学生对遍历序列本质的理解而非机械记忆。选择前序（或后序）+中序的组合，是因为该组合能唯一确定二叉树，且还原过程需要学生真正理解"前序首元素为根、中序划分左右子树"的逻辑关系，而非死记硬背。K-雷达形状（K1=2,K2=3,K3=2,K4=3,K5=3）体现中等难度：K2（理解）和K4（应用）较高，要求学生理解遍历本质并综合应用；K1（记忆）和K3（应用基础）适中，不需要大量记忆或复杂计算。三问结构（还原→计算→分析）形成递进依赖，能区分"能完整走完还原流程并回溯检查的学生"与"只记得遍历名称但无法执行还原的学生"。节点数控制在6-10、深度3-4，保证手动还原可行但不至于过于简单。若第三问考查满/完全二叉树判断，设计"接近但不完全是"的结构，增加辨析难度，区分"真正理解定义的学生"与"凭直觉判断的学生"。

## expected_reasoning_actions

- 从前序（或后序）序列中定位根节点
- 在中序序列中根据根节点划分左子树和右子树的节点集合
- 根据左右子树节点数，在前序（或后序）序列中划分左右子树的子序列
- 递归执行上述步骤，逐层还原二叉树结构
- 在还原后的树结构上逐层遍历，计算树的深度
- 在还原后的树结构上识别叶子节点（无左右孩子的节点）并计数
- 统计度为1的节点数（仅有一个孩子的节点）
- 根据满二叉树/完全二叉树的定义，逐层检查节点分布是否满足条件

## question_structure_plan

- shared_context: 给出二叉树的前序（或后序）遍历序列和中序遍历序列，说明节点值互异
- sub_question_chain:
  - q1: 根据给定的两种遍历序列还原二叉树，画出二叉树结构或写出各节点的左右孩子关系
  - q2: 基于还原的二叉树，计算树的深度（或叶子节点数）
  - q3: 基于还原的二叉树，分析树的性质（度为1的节点数，或判断是否为满二叉树/完全二叉树并说明理由）
- dependency_pattern: q2 依赖 q1 的还原结果；q3 依赖 q1 的还原结果；q2 与 q3 相互独立
- distractor_strategy: N/A（综合题无选项，但需防范典型错误：混淆前序/后序根节点位置、左右子树划分错误、忽略节点值互异前提）

## parameter_plan

- parameter_slots:
  - n（节点数）: 角色=树规模控制, candidate_range=[6, 10], used_by=所有子问题
  - traversal_combination（遍历组合）: 角色=还原依据, candidate_range=[前序+中序, 后序+中序], used_by=q1
  - node_values（节点值）: 角色=遍历序列元素, candidate_range=[字符A-J, 连续整数1-10], used_by=所有子问题, 约束=互异
  - tree_depth（树深度）: 角色=q2目标值, candidate_range=[3, 4], used_by=q2
  - leaf_count（叶子节点数）: 角色=q2备选目标值, candidate_range=[2, n/2+1], used_by=q2
  - degree1_count（度为1节点数）: 角色=q3备选目标值, candidate_range=[0, n-2], used_by=q3
  - is_full_or_complete（满/完全性质）: 角色=q3备选目标, candidate_range=[非满非完全, 接近满但非满, 接近完全但非完全], used_by=q3
- validation_targets:
  - 还原后的二叉树必须唯一确定
  - 左右子树节点数差≤3
  - 树非链状结构
  - 若q3考查满/完全二叉树，树应"接近但不完全是"
- adjustment_priority:
  - 第一优先级：确保遍历序列能唯一还原二叉树
  - 第二优先级：确保左右子树平衡（差≤3）
  - 第三优先级：确保q2和q3的目标值在合理范围内
