## 题目

已知二叉树 T 共有 7 个节点，节点值分别为 A、B、C、D、E、F、G（互不相同）。该二叉树的前序遍历序列为：

```
A, B, D, E, C, F, G
```

中序遍历序列为：

```
D, B, E, A, C, F, G
```

请回答下列问题：

### (1) （4分）根据给定的前序遍历序列和中序遍历序列，还原并画出该二叉树的结构（或写出各节点的左右孩子关系）。

### (2) （3分）基于(1)中还原的二叉树，计算该二叉树的深度（根节点所在层为第1层）。

### (3) （3分）基于(1)中还原的二叉树，判断该二叉树是否为完全二叉树，并说明理由。

---

## 参考答案

### (1) 二叉树结构

```
        A
       / \
      B   C
     / \   \
    D   E   F
             \
              G
```

**各节点左右孩子关系**：
- A 的左孩子：B，右孩子：C
- B 的左孩子：D，右孩子：E
- C 的左孩子：无，右孩子：F
- D 的左孩子：无，右孩子：无
- E 的左孩子：无，右孩子：无
- F 的左孩子：无，右孩子：G
- G 的左孩子：无，右孩子：无

### (2) 深度

**深度 = 4**

最长路径：A → C → F → G，共 4 层。

### (3) 完全二叉树判断

**不是完全二叉树。**

**理由**：完全二叉树要求除最后一层外，其余各层节点数均达到最大值，且最后一层的节点都集中在左侧。该二叉树第3层中 C 的左孩子为空但右孩子 F 存在，即节点未集中在左侧；第4层中 G 出现在右侧而非左侧连续位置。因此不满足完全二叉树的定义。

## 设计说明
- 复用骨架来源：design_card question_structure_plan 的"共享题干（两种遍历序列）+ 三问链（还原→计算→分析）"骨架
- 考察形式：多步串行推演（主）+ 组合判断（辅），来自 exam_form
- 经验值参数：节点数 n=7（经验值表二叉树遍历/还原友好值）；遍历组合=前序+中序；节点值=字符 A-G（7个互异字符）
- 设计理念：检验学生对遍历序列本质的理解而非机械记忆，通过"定位根→划分左右子树→递归还原"流程区分真正理解遍历逻辑的学生与仅记忆口诀的学生
- 与目标 K-雷达的对齐：K1=2（基础认知适中）、K2=3（理解前序/中序根节点定位与左右子树划分逻辑）、K3=2（机制推演适中）、K4=3（应用还原流程的条件路由能力）、K5=3（还原后跨域联动到树深度/满完全性质的综合判断）
