## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: DS-5 > 树与二叉树
- primary_target_name: 二叉树遍历序列还原
- question_type: comprehensive
- examination_mode: 给定两种遍历序列还原二叉树 → 基于还原结果求解衍生问题

### 难度目标
- k_target: K1=2,K2=3,K3=2,K4=3,K5=3
- difficulty_level: 3
- difficulty_rationale: medium难度，涉及遍历还原和树性质两个知识点，需要理解遍历本质而非机械记忆，手动还原中等规模二叉树，逐步推理还原过程，综合应用遍历知识与性质计算

### 结构要求
- sub_question_count: 3
- sub_question_structure:
  - q1: 类型=计算/构造, 考察目标=根据两种遍历序列还原二叉树, 分值比例=40%, 依赖=无
  - q2: 类型=计算, 考察目标=计算树的深度或叶子节点数, 分值比例=30%, 依赖=q1
  - q3: 类型=分析, 考察目标=分析树的性质（度为1的节点数或满/完全二叉树判断）, 分值比例=30%, 依赖=q1
- distractor_strategy: N/A（综合题无选项）
- condition_count: 2（两种遍历序列）

### 参数约束
- 节点数 n: 取值范围 [6, 10]，约束=非链状结构，左右子树节点数差≤3
- 遍历序列组合: 前序+中序 或 后序+中序（必须包含中序）
- 节点值: 互不相同的字符（A-J）或连续整数（1-10），约束=所有值互异
- 叶子节点数: 取值范围 [2, n/2 + 1]
- 树深度: 取值范围 [3, 4]（若第2问考查深度）
- 第2问目标: 深度 或 叶子节点数（二选一）
- 第3问目标: 度为1的节点数 或 满/完全二叉树判断（二选一）
- 满/完全二叉树设计: 若考查此性质，树应"接近但不完全是"，增加辨析难度

### 参考经验摘要
- 历史模式: 给两序列→还原→求性质 的三段式结构
- 难度锚点: medium难度对应节点数6-10，子问题3问，K值集中在2-3
- 典型陷阱: 混淆前序/后序根节点位置、左右子树划分错误、忽略节点值互异前提、误认为前序+后序能唯一确定树
