## examination_form
- 考察形式：多步串行推演（主）+ 组合判断（辅）
- 设问方向：给定前序（或后序）+中序遍历序列，要求学生串行执行"还原二叉树→计算衍生性质→分析树结构特征"的三问递进流程，基于还原结果综合判断树的深度/叶子数/度数分布/满完全性质

## k_radar
- K1（基础认知）: 2
- K2（单步代入）: 3
- K3（机制推演）: 2
- K4（条件路由）: 3
- K5（跨域联动）: 3
- 形状主导维度：K2+K4+K5 混合主导（三维度并列最高）

## rationale
- 为何选此形式：KP要求"遍历还原+性质计算+结构分析"三段式能力，K-雷达K2/K4/K5并列主导（均为3），对应"理解遍历本质→应用还原流程→跨域联动分析树性质"的递进链条，天然匹配多步串行推演形式；三问依赖结构（q2→q1、q3→q1）形成串行推演骨架，q2与q3独立但共享q1结果，体现组合判断的辅助特征
- 与目标 K-雷达的对齐说明：K2=3对应理解前序/中序根节点定位与左右子树划分的逻辑关系（非机械记忆）；K4=3对应将遍历知识应用于具体序列还原的条件路由能力；K5=3对应还原后跨域联动到树深度/叶子数/满完全性质的综合判断；K1=2和K3=2保持适中，不要求大量记忆或复杂计算，符合medium难度定位
