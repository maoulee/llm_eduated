# 2011 Q6 — 树转二叉树无右孩子结点计数

**知识点**: 数据结构-5 > 5.4 树、森林 > 树森林与二叉树转换 | **雷达形状**: K4陷阱型（K4显著高于其他维度，主要难点在于逻辑映射而非计算或记忆）

**K值**:
  - K1=3: 评分理由。需要掌握“树转换为二叉树”的核心规则（左孩子右兄弟表示法），特别是根节点在转换后的特殊性（无右孩子）。不记忆该特定转换规则无法解题，但无需辨析多个复杂概念，属于标准核心定义记忆。
  - K2=2: 评分理由。计算过程仅为简单的加减法（$2011 - 116 + 1$ 或 $2011 - 115$），数字非2的幂次但计算量极小，几乎不可能算错，属于较低难度的单步代入。
  - K3=2: 评分理由。从输入到输出只需两步逻辑：1. 识别树中哪些节点在二叉树中无右孩子（分支节点+根）；2. 计算分支节点数量。逻辑链条短，无需多步串行推演或记忆中间状态。
  - K4=4: 评分理由。存在显著的隐含前提和反直觉陷阱。常规思维容易认为“叶节点对应无右孩子”或“所有节点都有右孩子”，但实际上树转二叉树后，**根节点**一定无右孩子，且**原树中的分支节点**（非叶节点）在二叉树中其最右子节点对应的右指针为空（即该分
  - K5=1: 评分理由。仅在数据结构内部进行概念转换，不涉及操作系统、计网等其他科目，属于单系统问题。

**题干**: 已知一棵有 2011 个结点的树，其叶结点个数为 116，该树对应的二叉树中无右孩子的结点个数是（ ）。

**选项分析**:
- **选项A**: [干扰] — 针对错误认知：认为无右孩子节点数 = 分支节点数 - 1。可能误以为根节点不计入，或者计算分支节点时出错（$1895-1$? 逻辑不通）。或者是混淆了叶节点和分支节点的关系。
- **选项B**: [干扰] — 针对错误认知：认为无右孩子节点数 = 叶节点数。这是最常见的直觉错误，考生可能认为叶节点在二叉树中“结束”了，所以没有右孩子。但实际上叶节点如果有兄弟，在二叉树中就有右孩子。
- **选项C**: [干扰] — 针对错误认知：计算结果为分支节点数（$2011 - 116 = 1895$）。考生正确识别了分支节点与最右子节点的关系，但**遗漏了根节点**。根节点在原树中无兄弟，在二叉树中无右孩子，这是一个极易忽略的特例。
- **选项D**: [正确] — 正确计算：分支节点数（1895）+ 根节点（1）= 1896。

**干扰策略**: 渐进陷阱。选项C是“半对”答案，诱使那些理解了核心逻辑但忽略边界条件（根节点）的考生；选项B是“直觉”答案，诱使那些未深入理解转换规则的考生。

核心陷阱: 忽略根节点的特殊性以及混淆“叶节点”与“无右兄弟节点”的概念。

# 2017 Q6 — 哈夫曼编码的译码与前缀性质应用

**知识点**: 数据结构-5 > 5.5 树与二叉树的应用 > 哈夫曼树与哈夫曼编码 | **雷达形状**: K3推演主导型。K1基础适中，K2计算极低，K3推演中等，K4陷阱较低，K5跨域无。整体呈现以过程推演为主的特征。

**K值**:
  - K1=3: 评分理由。需要掌握哈夫曼编码的核心定义，特别是“前缀编码”这一关键性质（即任一字符的编码都不是另一字符编码的前缀）。如果不了解前缀编码的可唯一解码性，无法直接进行贪心匹配。属于标准的基础概念记忆。
  - K2=2: 评分理由。本题不涉及复杂的数值计算，仅涉及字符串的比对和分割。虽然字符串较长，但操作是线性的、机械的，属于较低难度的单步代入（比对）。
  - K3=3: 评分理由。从输入到输出需要多步串行推演。考生需要从头开始扫描编码序列，依次匹配字符编码，每匹配成功一个字符，指针后移，继续匹配下一个。整个过程包含约7-8个匹配步骤，属于中等程度的多步推演。
  - K4=2: 评分理由。存在常规注意点，即必须严格按照给定的编码表进行匹配，不能凭直觉猜测或记忆常见的哈夫曼树结构。题目给出的编码是特定的，必须“所见即所得”。没有深层的隐含前提或反直觉陷阱，只要细心即可避开。
  - K5=1: 评分理由。本题完全局限于数据结构中的哈夫曼编码模块内部，不需要跨越操作系统、计算机网络或组成原理等其他子系统，属于单系统问题。

**题干**: 已知字符集 {a, b, c, d, e, f, g, h}，若各字符的哈夫曼编码依次是 0100, 10, 0000, 0101, 001, 011, 11, 0001，则编码序列 0100011001001011110101 的译码结果是（ ）。

**选项分析**:
- **选项A**: [干扰] — 针对粗心或匹配错误的学生。例如，可能将 `0100` 正确识别为 `a`，但在后续匹配中出错，如将 `011` 误判或跳过，导致后续字符全部错位。或者在 `001` (e) 和 `0001` (h) 等相似编码间混淆。
- **选项B**: [干扰] — 针对对编码表记忆混乱或比对失误的学生。例如，可能将 `011` (f) 误认为是 `b` (10) 或其他，或者在长串中漏看某一位，导致分割点错误。
- **选项C**: [干扰] — 针对部分匹配正确的学生。可能在中间某一步出错，例如将 `001` (e) 误读为 `f` (011) 或其他，导致后续连锁错误。
- **选项D**: [正确] — 正确匹配序列：`0100`(a) `011`(f) `001`(e) `001`(e) `011`(f) `11`(g) `0101`(d)。

**干扰策略**: 计算陷阱/比对失误。由于编码序列较长且包含多个相似前缀（如 `0100` 和 `0101`，`001` 和 `0001`），主要干扰策略是利用视觉疲劳和比对错误，诱导考生选错字符。

核心陷阱: 编码前缀的混淆与视觉疲劳。题目中给出的编码长度不一，且存在前缀相似的情况（如 `a:0100` 和 `d:0101`，`e:001` 和 `h:0001`）。考生如果在比对时不够仔细，容易看错位数或混淆相似编码，导致译码结果错误。此外，长字符串容易让人失去耐心，产生跳读或漏读。

**题干**: 修改递归方式实现的图的深度优先搜索（DFS）算法，将输出（访问）定点信息的语句移到退出递归前（即执行输出语句后立刻退出递归）。采用修改后的算法遍历有向无环图 G，若输出结果中包含 G 中的全部顶点，则输出的顶点序列是 G 的（ ）。

**选项分析**:
- **选项A**: [干扰] — 针对“拓扑排序与DFS有关”的模糊认知。许多学生知道拓扑排序可以用DFS实现，但混淆了“访问时输出”和“退出时输出”的区别。如果考生误以为DFS自然产生拓扑序，或者忘记了拓扑序要求“前驱在后继之前”，就会误选A。
- **选项B**: [正确] — 符合逻辑推演结果。在DAG中，若存在边 $<v_i, v_j>$，DFS访问 $v_i$ 时会递归访问 $v_j$。由于输出语句在递归退出前执行，$v_j$ 的递归调用必须先返回（输出 $v_j$），然后 $v_i$ 的递归调用才返回（输出 $v_i$）。因此 $v_j$ 在 $v_i$ 之前输出。拓扑序要求 $v_i$ 在 $v_j$ 之前，故输出序列为逆拓扑序。
- **选项C**: [干扰] — 针对“遍历算法混淆”的错误认知。广度优先搜索（BFS）使用队列，层级遍历，与递归栈的LIFO特性完全无关。此选项用于排除对基本遍历算法数据结构（栈vs队列）不清的考生。
- **选项D**: [干扰] — 针对“字面意思陷阱”的错误认知。题干明确说是“修改后的DFS算法”，考生可能惯性思维认为输出还是“DFS序列”。但标准的DFS序列通常指“访问顺序”（Pre-order），而本题是“退出顺序”（Post-order）。此选项考察考生是否注意到“修改”二字带来的本质变化。

**干扰策略**: 概念混淆（A与B的逆序关系）、惯性思维陷阱（D选项利用题干关键词误导）、无关概念排除（C选项）。

核心陷阱: “递归退出”与“拓扑序方向”的逆向映射。

K4 条件路由需求（需要识别隐含前提/避开暗坑/切换机制的程度）:

  2=较低: 存在常规注意点，408 考生基本不会踩坑

K5 跨域联动需求（需要跨越不同子系统/模块传递状态的程度）:
