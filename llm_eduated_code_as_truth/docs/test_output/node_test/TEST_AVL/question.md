# TEST_AVL — 单链表环检测算法设计

## 题目

设线性表 $L$ 采用单链表存储，链表中可能存在环（即某个结点的 `next` 指针指向链表中已存在的某个结点）。请设计一个算法判断该单链表中是否存在环。

要求：

1. **定义链表结点数据类型**（2 分）
2. **描述算法基本设计思想**（4 分）
3. **编写算法（关键处给注释）**（7 分）

---

## 评分参考

| 子问 | 分值 | 评分要点 |
|------|------|----------|
| ① 定义链表结点数据类型 | 2 分 | 包含 `data` 域与 `next` 指针域，类型定义完整 |
| ② 描述算法基本设计思想 | 4 分 | 清晰描述快慢指针初始化、移动规则（快指针步长为 2，慢指针步长为 1）、相遇判断（有环）与无环终止条件（快指针或其后继为空） |
| ③ 编写算法代码 | 7 分 | 代码正确实现快慢指针判环逻辑，正确处理边界条件（空链表、单结点、无环链表），关键处有注释，时间复杂度 $O(n)$、空间复杂度 $O(1)$ |
