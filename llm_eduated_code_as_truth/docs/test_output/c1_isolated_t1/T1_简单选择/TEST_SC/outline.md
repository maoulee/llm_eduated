## 考点
- **二叉树带权路径长度(WPL)**：核心考点，考察WPL的定义与计算方法
  - 考察侧重点：路径长度的定义（根到节点的路径边数）、带权路径长度（路径长度×权值）、树的WPL（所有叶子节点的带权路径长度之和）
- **哈夫曼树构造**：辅助考点，考察最优二叉树的构造方法
  - 考察侧重点：贪心策略（每次选取权值最小的两个节点合并）、合并后新节点的权值计算

## 难度目标
- **K1（知识记忆）= 2**：需要记忆WPL的定义公式和哈夫曼树构造规则
- **K2（理解）= 3**：需要理解路径长度与带权路径长度的区别，理解哈夫曼树为何最优
- **K3（应用）= 3**：需要应用WPL计算公式进行数值计算，或应用哈夫曼算法构造最优树
- **K4（分析）= 2**：中等难度，可能涉及对不同树结构WPL的比较分析
- **K5（综合）= 2**：选择题形式，综合要求适中，不涉及多知识点深度综合

**整体难度定位：3（中等）**，符合slot中difficulty=medium的设定

## 考察模式
**模式：给定权值集合，计算哈夫曼树的WPL**

理由：
- 这是408数据结构中WPL考点最经典的考察模式
- 能够同时考察哈夫曼树构造和WPL计算两个知识点
- 计算量适中，适合选择题形式
- 干扰项设计空间大（构造错误、计算错误、概念混淆）

备选模式：给定具体二叉树结构，直接计算WPL（作为简化版本）

## 出题要求
- **题型**：single_choice（单项选择题）
- **选项数**：4个（1正确+3干扰）
- **条件数**：1-2个显式条件
  - 条件1：给出叶子节点的权值集合（3-6个权值）
  - 条件2（可选）：说明需要构造哈夫曼树或直接给出树结构
- **条件设计原则**：
  - 权值应为正整数，便于计算
  - 权值数量不宜过多（3-6个），保证计算量适中
  - 权值可以有重复，增加干扰性
- **参数取值范围要求**：
  - 叶子节点数：3-6个
  - 权值范围：1-50的正整数
  - 最终WPL值：应在50-300范围内，便于心算或简单笔算

## 子问题规划
本题为选择题，无子问题结构。

## 参数约束
- **叶子节点数量(n)**：取值范围 [3, 6]，建议4-5个
- **权值集合(w_1, w_2, ..., w_n)**：
  - 每个权值 w_i ∈ [1, 50] 的正整数
  - 权值可以重复，但不应全部相同
  - 权值大小应有明显差异，便于区分合并顺序
- **WPL计算结果**：
  - 应在 [50, 300] 范围内
  - 应为整数（权值为整数时WPL必为整数）
- **参数一致性约束**：
  - 权值集合必须能构造出唯一的哈夫曼树（或明确说明处理权值相等的规则）
  - 若存在权值相等，应确保不影响最终WPL的唯一性，或明确合并规则

## 参考经验
**历史考察模式**：
- 408考研中WPL考点多以选择题形式出现
- 经典模式：给出n个权值，要求计算对应哈夫曼树的WPL
- 简化模式：直接给出二叉树结构图，要求计算WPL

**难度锚点**：
- 简单：3-4个权值，数值小，无重复
- 中等：4-5个权值，数值适中，可能有重复
- 困难：5-6个权值，数值较大，需多步合并

**典型陷阱**：
1. **路径长度计算错误**：将节点层数当作路径长度（路径长度=层数-1）
2. **内部节点误算**：将内部节点的权值也计入WPL（WPL只计算叶子节点）
3. **哈夫曼构造错误**：合并时未选取最小的两个权值，或合并后新权值计算错误
4. **概念混淆**：将WPL与树的深度、节点总数等概念混淆
