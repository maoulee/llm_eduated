# 题目

设有一棵二叉树，其结构如下图所示（节点以大写字母标识）：

```
        A
       / \
      B   C
     / \ / \
    D  E F  G
```

各叶子节点的权值如下表所示：

| 叶子节点 | D | E | F | G |
|:--------:|:-:|:-:|:-:|:-:|
| 权值     | 3 | 5 | 8 | 12 |

已知：路径长度从根节点开始为 0，仅叶子节点有权值。该二叉树的带权路径长度（WPL）为多少？

A. 28
B. 32
C. 56
D. 84

---

## 设计说明

- **复用骨架来源**：design_card question_structure_plan — 图形+表格混合呈现，给出二叉树结构图（标注节点标识），另附叶子节点权值表，直接设问 WPL
- **考察形式**：多步串行推演（主）+ 单点计算（辅）；给定二叉树结构图与叶子节点权值表，要求完整执行"识别叶子节点→读取权值→计算路径长度→加权求和"流程
- **经验值参数**：
  - 节点总数 N = 7（经验值表"二叉树遍历/还原"友好值）
  - 叶子节点数 L = 4（在 candidate_range [3,5] 内）
  - 树高度 H = 3（在 candidate_range [3,4] 内）
  - 叶子权值 w_i = {3, 5, 8, 12}（在 [1,20] 内且互不相同）
- **设计理念**：以"给定二叉树结构+叶子节点权值，计算WPL"为考察模式，检验学生对WPL定义的完整理解与计算能力，区分能完整执行"识别叶子→读取权值→计算路径长度→加权求和"全流程的学生与在路径长度起点、节点筛选或算术细节上出错的学生
- **与目标 K-雷达的对齐**：K1=2（回忆WPL定义）、K2=3（单步代入：权值×路径长度）、K3=3（多步串行：识别叶子→读取权值→逐层追踪→加权求和）、K4=2（无复杂条件路由）、K5=2（单域内计算）
- **干扰选项设计**：
  - A. 28：路径长度误从1开始但只算一层（off-by-one，路径长度=1）：3×1+5×1+8×1+12×1=28
  - B. 32：漏算叶子节点G（漏项错误）：3×2+5×2+8×2=32
  - C. 56：正确答案
  - D. 84：路径长度误从1开始计数（路径长度起点错误）：3×3+5×3+8×3+12×3=84
