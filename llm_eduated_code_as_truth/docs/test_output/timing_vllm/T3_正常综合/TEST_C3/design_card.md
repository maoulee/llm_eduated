## core_knowledge_intent

**must_test:**
- AVL树插入操作的完整流程：查找插入位置 → 插入节点 → 自底向上更新平衡因子
- 四种旋转类型（LL/RR/LR/RL）的触发条件判定与执行方法
- 插入后失衡节点的定位与高层状态维护（旋转后平衡因子的重新计算）

**must_not_shift_to:**
- 纯记忆旋转名称而不理解触发条件与执行过程
- 仅考察AVL树的删除操作、查询操作或遍历操作

**coverage_success_criteria:**
- 学生能完整模拟一次AVL插入流程并正确识别所需旋转类型
- 学生能准确计算插入并旋转后指定节点的平衡因子或树结构属性

## design_rationale

AVL插入与旋转是数据结构中"结构操作与状态维护"类题目的经典载体。本题选择K3-K4平衡型而非纯K3推演题，是因为AVL的核心难点不在于"会走流程"，而在于"在正确时机识别正确旋转类型"——LL/RR/LR/RL四种情况的触发条件极易混淆，学生常犯"知道要旋转但转错类型"或"转了但方向反了"的错误。通过要求完整模拟插入→更新平衡因子→识别失衡→执行旋转→计算结果的多步流程，本题能清晰区分三类学生：①能完整走完流程并回溯检查每步平衡因子的学生（掌握）；②能执行旋转但触发条件判断模糊、依赖试错的学生（半掌握）；③仅记住旋转名称却无法定位失衡节点或混淆LR/RL的学生（未掌握）。难度4的设定确保题目既有足够的推演步数消耗工作记忆（K3高），又包含隐含的条件路由需求——学生必须理解"平衡因子绝对值>1才失衡"且"看失衡节点与其子节点的相对关系决定旋转类型"这一深层机制（K4高），而非简单套用公式。

## expected_reasoning_actions

- 在给定初始AVL树中查找待插入关键字的插入位置
- 执行插入操作，自底向上更新插入路径上各节点的平衡因子
- 定位第一个平衡因子绝对值大于1的失衡节点
- 根据失衡节点与其子节点、孙节点的相对关系，判定旋转类型（LL/RR/LR/RL）
- 执行对应旋转操作，更新旋转涉及节点的左右子树指针
- 重新计算旋转后各相关节点的平衡因子
- 根据题目设问，提取目标节点的指定属性值（如平衡因子、高度、或特定子树中的关键字）

## question_structure_plan

**stem_style:** 给出初始AVL树的结构图（或关键字序列说明已构成AVL树）+ 待插入的关键字值 + 询问插入并调整平衡后某特定节点的属性

**option_architecture:**
- 1个正确选项：完整执行插入+正确旋转后的目标属性值
- 干扰项1（未旋转/旋转遗漏）：仅插入节点但未执行旋转，或旋转不完整导致树不满足AVL性质
- 干扰项2（旋转类型错误）：识别到失衡但选错旋转类型（如LL误判为RR，或LR误判为RL），导致旋转后结构错误
- 干扰项3（平衡因子计算错误）：旋转类型正确但平衡因子更新遗漏或计算偏差，导致目标属性值偏移

**asking_method:** 询问插入并调整平衡后，指定节点（如根节点、某子树根、或新插入节点）的平衡因子值/高度值/左右子树关键字等

## parameter_plan

**parameter_slots:**

| 参数名 | 角色 | 候选范围 | used_by |
|--------|------|----------|---------|
| initial_tree | 初始AVL树结构 | 5-8个节点的合法AVL树，确保插入后触发旋转 | 题干、求解验证 |
| insert_key | 待插入关键字 | 整数，不在初始树中，插入后导致某节点失衡 | 题干、求解验证 |
| target_node | 询问目标节点标识 | 根节点/某子树根/新插入节点 | 设问、选项生成 |
| asked_attribute | 询问属性类型 | 平衡因子/树高度/特定子树关键字 | 设问、选项生成 |

**validation_targets:**
- 初始树必须是合法AVL树（所有节点平衡因子∈{-1,0,1}）
- 插入insert_key后必须触发至少一次旋转
- 旋转后的树必须仍是合法AVL树
- 四个选项数值互不相同且均为合理范围内的整数

**adjustment_priority:**
1. 确保插入操作必然触发旋转（避免插入后无需调整的情况）
2. 确保旋转类型为LL/RR/LR/RL中的一种典型情况（避免边界歧义）
3. 确保干扰项对应明确的错误认知路径而非随机数值

## terminology_and_expression_constraints

**required_terms:**
- 平衡二叉排序树 / AVL树
- 平衡因子
- 左旋 / 右旋
- LL型 / RR型 / LR型 / RL型（或"左左型/右右型/左右型/右左型"）
- 失衡节点

**required_qualifiers:**
- 必须明确操作为"插入关键字X后调整平衡"，而非删除或修改
- 若题干用序列描述初始树，需说明"按给定序列插入已构成平衡二叉排序树"
- 平衡因子的定义需在题干或课程共识中明确（左子树高度-右子树高度，或反之，需统一）

**avoid_phrases:**
- ❌ "调整树的结构" → ✅ "执行旋转操作恢复平衡"
- ❌ "平衡因子为1"（未说明方向） → ✅ "左子树比右子树高1"或明确定义方向
- ❌ "旋转一次"（未说明类型） → ✅ "执行LL型旋转"或具体类型

**standard_rewrites:**

| 不良表述 | 标准改写 |
|----------|----------|
| 对节点A进行旋转 | 以节点A为失衡节点执行XX型旋转 |
| 插入后树的高度 | 插入并调整平衡后，树的高度 |
| 平衡因子变了 | 重新计算插入路径上各节点的平衡因子 |

## audit_focus

**final_review_must_check:**
- 初始树是否为合法AVL树（所有节点平衡因子∈{-1,0,1}）
- 插入操作是否必然触发旋转（避免无旋转的平凡情况）
- 旋转类型判定是否正确（LL/RR/LR/RL与失衡形态匹配）
- 旋转后树是否仍满足AVL性质
- 四个选项是否对应四种不同的认知路径（1正确+3种典型错误）
- 干扰项是否来自明确的错误认知（未旋转/转错类型/平衡因子算错），而非随机数值

**solve_output_should_contain:**
- 初始AVL树的结构表示（节点关键字+平衡因子）
- 插入位置的确定过程
- 插入后自底向上更新平衡因子的过程
- 失衡节点的定位与旋转类型判定依据
- 旋转操作的执行过程（指针变化）
- 旋转后各相关节点的平衡因子
- 最终树的结构表示
- 目标节点的属性值计算结果

**fail_if_missing:**
- 缺少旋转步骤或旋转类型判定依据
- 旋转后树不满足AVL性质（存在平衡因子绝对值>1的节点）
- 正确选项与求解结果不一致
- 干扰项无法对应明确的错误认知路径
- 初始树本身不是合法AVL树
