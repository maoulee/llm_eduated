## 题干
# Q41 综合应用题（10分）

## 题目

某棵平衡二叉树（AVL树）T的初始形态如下所示，节点内数字为关键字：

```
         50
        /  \
       30   60
      /  \
     20  40
```

约定：空子树高度为0，叶子节点高度为1，节点高度等于其左右子树高度的最大值加1；平衡因子定义为左子树高度减去右子树高度。当某节点平衡因子的绝对值大于1时，该节点为失衡节点，以该节点为根的子树称为最小不平衡子树（从插入点向根回溯时遇到的第一个失衡节点对应的子树）。

现依次向T中插入关键字35和55（先插入35，待平衡调整完成后再插入55）。请回答下列问题：

### （1）（3分）

将关键字35插入初始AVL树T后（旋转调整前），画出此时的二叉排序树形态。指出最小不平衡子树的根节点，计算该节点及其左孩子的平衡因子，并判断应进行的平衡调整类型（LL、RR、LR或RL）。

### （2）（4分）

对（1）中找到的最小不平衡子树执行平衡调整。说明调整过程中每一步旋转操作的旋转轴节点和旋转方向（左旋或右旋），并画出调整后的AVL树。

### （3）（3分）

在（2）得到的AVL树基础上，继续插入关键字55。判断此次插入是否导致失衡。若失衡，指出最小不平衡子树的根节点和平衡调整类型，写出旋转操作步骤，并画出最终的AVL树。
