## 题目

已知某二叉树的前序遍历序列为 a, b, d, e, g, c, f，中序遍历序列为 d, b, e, g, a, c, f。

请回答下列问题：

### (1) （5分）根据给定的前序遍历序列和中序遍历序列，还原该二叉树的结构，并画出该二叉树。

### (2) （3分）基于(1)中还原的二叉树，写出该二叉树的层序遍历序列。

### (3) （2分）基于(1)中还原的二叉树，求该二叉树的高度、叶子节点个数以及度为2的节点个数。

## 求解过程

### (1) 还原二叉树

采用递归方法：前序遍历首元素为根节点，根据根节点在中序遍历中的位置划分左右子树，递归构建。

- 根 = a（前序首元素）
- 中序中 a 左侧 {d,b,e,g} 为左子树，右侧 {c,f} 为右子树
- 左子树：根 = b，左孩子 = d，右子树根 = e，e 的右孩子 = g
- 右子树：根 = c，右孩子 = f

还原的二叉树结构：
```
        a
       / \
      b   c
     / \   \
    d   e   f
       \
        g
```

### (2) 层序遍历

按层从上到下、从左到右遍历：
- 第1层：a
- 第2层：b, c
- 第3层：d, e, f
- 第4层：g

层序遍历序列：a, b, c, d, e, f, g

### (3) 树的性质

- **高度**：最长路径 a → b → e → g，共 4 层，高度 = 4
- **叶子节点**：d、g、f，共 3 个
- **度为2的节点**：a（左右孩子 b、c）、b（左右孩子 d、e），共 2 个

## 答案

- (1) 二叉树结构如上所示
- (2) 层序遍历序列：a, b, c, d, e, f, g
- (3) 高度：4；叶子节点个数：3；度为2的节点个数：2
