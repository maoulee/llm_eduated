## 考点
- **二叉树遍历序列还原**（核心）：根据两种遍历序列（前序+中序或后序+中序）唯一确定二叉树结构
- **遍历序列的性质**（辅助）：理解前序、中序、后序遍历的递归定义和序列特征
- **层序遍历**（辅助）：在还原二叉树后，能够写出层序遍历序列
- **二叉树基本性质**（辅助）：树的高度、叶子节点数、度为1/2的节点数等

## 难度目标
- **K1（知识广度）= 3**：涉及前序、中序、后序、层序四种遍历，需要综合理解
- **K2（知识深度）= 3**：需要理解遍历序列与树结构的对应关系，掌握还原算法的本质
- **K3（计算复杂度）= 3**：还原过程需要逐步推导，有一定计算量但不繁琐
- **K4（抽象程度）= 2**：题目相对具体，以序列还原为主，不涉及高度抽象的理论
- **K5（综合程度）= 3**：需要综合运用多种遍历知识，子问题之间有依赖关系

## 考察模式
**模式：序列还原 + 性质分析**

理由：这是二叉树遍历序列还原题位的经典考察模式。先给出两种遍历序列要求还原二叉树，再基于还原结果考察其他遍历序列或树的性质。该模式能有效区分学生是否真正理解遍历的本质，而非死记硬背。

## 出题要求
- **题型**：综合题（2-3问）
- **总条件数**：2个显式条件（两种遍历序列）+ 1个隐含条件（序列能唯一确定二叉树）
- **条件设计原则**：
  - 给定的两种遍历序列必须能唯一确定二叉树
  - 序列长度适中（5-10个节点）
  - 树的结构应避免过于简单（如纯链状）或过于对称
- **参数取值范围要求**：节点数 5-10，树高 2-4

## 子问题规划

### 第1问（还原二叉树）
- **类型**：构造/画图
- **考察目标**：根据给定的两种遍历序列还原二叉树结构
- **分值**：约占总分的 40-50%
- **与前后问的关系**：基础问，后续问题依赖此问结果

### 第2问（写出其他遍历序列）
- **类型**：计算
- **考察目标**：基于还原的二叉树，写出未给出的遍历序列（如层序遍历）
- **分值**：约占总分的 30-40%
- **与前后问的关系**：依赖第1问的还原结果

### 第3问（分析树的性质，可选）
- **类型**：分析
- **考察目标**：计算树的高度、叶子节点数、度为2的节点数等
- **分值**：约占总分的 10-20%
- **与前后问的关系**：依赖第1问的还原结果，可与第2问并行

## 参数约束
- **节点数 n**：取值范围 5-10，建议 6-8
- **树高 h**：取值范围 2-4，与节点数协调（h ≥ ⌈log₂(n+1)⌉）
- **给定遍历类型**：前序+中序 或 后序+中序（二选一）
- **序列唯一性约束**：给定的两种遍历序列必须能唯一确定二叉树（中序遍历必须包含）
- **结构约束**：树不应是纯链状（避免所有节点度≤1），应有分支
- **叶子节点数**：建议 2-4 个，不宜过多或过少
- **度为2的节点数**：建议 1-3 个

## 参考经验
- **历史模式**：该题位常见模式为"给两种遍历→还原树→求第三种遍历"，偶尔加入树的性质分析
- **难度锚点**：medium难度对应节点数6-8，树高3左右，子问题2-3个
- **典型陷阱**：
  - 学生混淆前序和后序的根节点位置
  - 还原时子树划分错误
  - 层序遍历时层次顺序错误
  - 忽略空节点的处理
