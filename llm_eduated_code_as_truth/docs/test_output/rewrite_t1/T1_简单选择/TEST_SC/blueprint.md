## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: DS-5 > 树与二叉树
- primary_target_name: 二叉树带权路径长度
- question_type: single_choice
- examination_mode: 给定权值集合求哈夫曼树WPL

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=2,K5=2
- difficulty_level: 3
- difficulty_rationale: 中等难度，考察WPL核心概念和哈夫曼树构造，计算量适中，思维复杂度较低

### 结构要求
- option_count: 4
- distractor_strategy: 干扰项应覆盖三类典型错误：(1)计算错误-漏加合并权值 (2)构造错误-未按最小权值合并 (3)概念错误-非叶子节点计入WPL
- condition_count: 1

### 参数约束
- 权值数量 n: [4, 6]，建议5个
- 权值集合 {w₁, w₂, ..., wₙ}: 每个 wᵢ ∈ [1, 50] 正整数，避免全部相等，可含1-2对相等权值
- 合并轮数: 2-3轮，确保计算过程有足够步骤
- WPL结果范围: 建议在 50-200 之间
- 干扰项与正确答案的差距: 建议差距在 10-30 之间，避免过于接近或过于悬殊

### 参考经验摘要
- 历史模式: 给定n个权值求哈夫曼树WPL，408真题高频模式（2015、2018等年份）
- 难度锚点: K1=3,K2=3,K3=3,K4=2,K5=2，中等难度锚定在4-5个权值、2-3轮合并
- 典型陷阱: (1)WPL只计叶子节点 (2)哈夫曼构造贪心策略 (3)路径长度定义 (4)合并权值累加
