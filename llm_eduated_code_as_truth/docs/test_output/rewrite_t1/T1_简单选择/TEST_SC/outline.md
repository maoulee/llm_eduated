## 考点
- **二叉树带权路径长度(WPL)**：核心考点，考察WPL的定义与计算方法
- **哈夫曼树构造**：辅助考点，考察给定权值集合构造最优二叉树的过程
- **路径长度概念**：基础考点，考察根节点到各叶子节点的路径长度理解

## 难度目标
- **K1（知识广度）= 3**：涉及二叉树基本概念、WPL定义、哈夫曼树构造算法，需要掌握多个相关概念
- **K2（知识深度）= 3**：需要深入理解WPL计算公式和哈夫曼树的贪心构造策略
- **K3（计算复杂度）= 3**：需要执行多次权值合并操作并累加计算，中等计算量
- **K4（思维复杂度）= 2**：按部就班执行哈夫曼构造算法即可，思维跳跃性要求不高
- **K5（综合度）= 2**：主要围绕WPL单一知识点展开，综合其他知识域的程度较低

## 考察模式
**模式：给定权值集合求哈夫曼树WPL**

理由：这是408数据结构选择题中最经典的WPL考察模式。给定n个权值，要求考生构造哈夫曼树并计算其WPL。该模式：
- 直接考察WPL核心概念
- 通过哈夫曼树构造过程检验算法理解
- 计算量适中，适合选择题形式
- 历史真题中出现频率高，考生熟悉度高

## 出题要求
- **题型**：single_choice（四选一选择题）
- **总条件数**：1个显式条件（给出权值集合）
- **条件设计原则**：权值集合应使计算过程有2-3轮合并操作，避免过于简单或复杂
- **参数取值范围要求**：
  - 权值数量：4-6个
  - 权值大小：正整数，建议在1-50范围内
  - 权值分布：避免全部相等，可包含1-2对相等权值增加干扰性

## 子问题规划
本题为选择题，无子问题结构。

## 参数约束
- **权值数量 n**：取值范围 [4, 6]，建议取5个权值使计算量适中
- **权值集合 {w₁, w₂, ..., wₙ}**：
  - 每个 wᵢ ∈ [1, 50] 的正整数
  - 权值应互不相同或仅有1-2对相等，避免全部相等导致哈夫曼树不唯一
  - 权值大小应有明显差异，便于构造过程中产生不同的合并顺序
- **WPL计算结果**：应为整数，计算过程需经过2-3轮合并操作
- **干扰项设计约束**：
  - 干扰项1：常见计算错误（如漏加某轮合并的权值和）
  - 干扰项2：构造错误（如未按最小权值优先合并）
  - 干扰项3：概念错误（如将非叶子节点也计入WPL）

## 参考经验
- **历史模式**：408真题中WPL选择题多采用"给定权值求哈夫曼树WPL"模式，如2015年、2018年真题
- **难度锚点**：中等难度题目通常给4-5个权值，计算结果在50-200之间
- **典型陷阱**：
  1. 混淆WPL只计算叶子节点，错误地将内部节点也计入
  2. 哈夫曼树构造时未按权值从小到大合并
  3. 路径长度计算错误（从根到叶子 vs 从叶子到根）
  4. 合并过程中权值累加错误
