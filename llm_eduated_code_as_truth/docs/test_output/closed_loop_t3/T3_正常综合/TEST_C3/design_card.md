## core_knowledge_intent

**must_test:**
- AVL 树插入过程中平衡因子的动态计算与失衡节点的定位
- 四种旋转类型（LL/RR/LR/RL）的触发条件辨析与正确选择
- 旋转操作的完整执行流程及旋转后树结构的正确性验证

**must_not_shift_to:**
- 仅考查旋转名称记忆而不涉及实际插入推演过程
- 退化为普通二叉搜索树的插入（不涉及平衡调整）

**coverage_success_criteria:**
- 学生能完整模拟从空树开始的插入序列，在每一步插入后检查平衡因子并执行必要的旋转
- 学生能准确识别失衡节点（距插入点最近的平衡因子绝对值>1的节点）并判断正确的旋转类型

## design_rationale

本题考察 AVL 树插入与旋转的完整动态过程，而非静态概念记忆。选择"给定插入序列→模拟完整插入过程→判断最终树结构"的设问方式，是因为 AVL 树的核心能力在于**动态维护平衡**——学生必须真正理解"插入→更新平衡因子→定位失衡点→判断旋转类型→执行旋转→重新平衡"这一完整链条，才能正确作答。K3-K4 平衡型的设计意图是：K3 要求学生能走完 5 步以上的串行推演流程（多节点插入+多次平衡检查），K4 要求学生能识别隐含的路由条件（如"失衡节点是插入节点的祖父而非父节点"、"LR 型需先左旋子树再右旋失衡节点而非直接右旋"）。这种难度区分的是**能完整走完旋转流程并回溯检查的学生**与**只记得旋转名称但无法在动态插入中正确应用的学生**。选择题形式适合在有限篇幅内考查多步推演结果，同时通过精心设计的干扰项暴露学生在旋转触发条件判断上的认知漏洞。

## expected_reasoning_actions

- 从空树开始，按给定序列逐个插入节点，维护二叉搜索树性质
- 每次插入后，从插入节点向上回溯至根节点，更新路径上各节点的平衡因子
- 定位失衡节点（平衡因子绝对值首次超过 1 的节点）
- 根据失衡节点与其子节点、孙节点的相对位置关系，判断旋转类型（LL/RR/LR/RL）
- 执行对应旋转操作，更新旋转涉及节点的左右子树指针
- 旋转后重新计算相关节点的平衡因子，验证 AVL 性质恢复
- 重复上述过程直至所有节点插入完成
- 根据最终树结构回答设问（如根节点值、树高、某节点的平衡因子等）

## question_structure_plan

**stem_style:** 给定初始空 AVL 树和一组插入序列，要求判断插入全部完成后树的某个结构特征

**asking_method:** 直接设问最终树结构的某个属性（如根节点的值、树的高度、指定节点的平衡因子、叶子节点数量等）

**option_architecture:**
- **correct:** 基于完整正确的插入+旋转推演得出的最终结果
- **distractor_1（概念混淆型）：** 忽略某次旋转操作，将失衡状态下的中间树结构当作最终结果（对应错误认知：认为插入后无需旋转或旋转条件判断错误）
- **distractor_2（旋转类型错误型）：** 旋转方向或类型判断错误（如将 LR 型误判为 LL 型，或 RL 型误判为 RR 型），导致旋转后树结构错误
- **distractor_3（中间值型）：** 仅完成部分节点的插入和旋转，将中途某个中间状态的树结构当作最终答案（对应错误认知：推演过程中途放弃或漏掉后续插入）

## parameter_plan

**parameter_slots:**

| name | role | candidate_range | used_by |
|------|------|-----------------|---------|
| insertion_sequence | 插入序列（节点值列表） | 6-10 个互异整数，值域 1-100 | 题干、求解 |
| query_target | 设问目标（根节点值/树高/某节点平衡因子/叶子数等） | 从最终树结构中提取的可量化属性 | 题干设问、选项 |

**validation_targets:**
- 插入序列必须触发至少一次旋转操作（否则无法考查旋转知识点）
- 插入序列应触发多种旋转类型（至少包含 LL/RR 中的一种和 LR/RL 中的一种），以充分考查旋转条件辨析
- 最终树结构必须唯一确定（无歧义）
- 四个选项（1 正确 + 3 干扰）必须互异且均可由某种错误认知路径推导得出

**adjustment_priority:**
1. 插入序列长度（优先保证 6-8 个节点，平衡推演复杂度与可操作性）
2. 插入序列具体数值（调整以触发目标旋转类型组合）
3. 设问目标（根据最终树结构选择最具区分度的属性）

## terminology_and_expression_constraints

**required_terms:**
- 平衡二叉树 / AVL 树
- 平衡因子
- 失衡节点
- LL 型旋转 / RR 型旋转 / LR 型旋转 / RL 型旋转（或"左左旋转/右右旋转/左右旋转/右左旋转"）
- 左旋 / 右旋

**required_qualifiers:**
- 提及旋转时必须说明旋转类型（如"执行 LL 型旋转"而非笼统说"旋转"）
- 提及失衡节点时必须明确是"距插入点最近的平衡因子绝对值大于 1 的节点"
- 若涉及 LR/RL 型旋转，需体现"先对子节点旋转，再对失衡节点旋转"的两步操作

**avoid_phrases:**
- ❌ "调整平衡"（过于笼统，应明确为"执行 XX 型旋转"）
- ❌ "旋转一次"（未说明旋转类型和旋转对象）
- ❌ "平衡二叉排序树"（408 标准术语为"平衡二叉树"或"AVL 树"，"二叉排序树"是 BST 的旧称）

**standard_rewrites:**

| bad | good |
|-----|------|
| 对树进行旋转调整 | 执行 LL 型（或 RR/LR/RL 型）旋转 |
| 找到失衡的地方 | 定位失衡节点（平衡因子绝对值 > 1 的节点） |
| 旋转后树就平衡了 | 旋转后重新计算平衡因子，验证 AVL 性质恢复 |

## audit_focus

**final_review_must_check:**
- 插入序列是否确实触发至少一次旋转（无旋转则未覆盖核心考点）
- 插入序列是否触发多种旋转类型（仅触发单一类型则 K4 条件路由考查不足）
- 四个选项是否互异且均可由明确的错误认知路径推导
- 设问目标是否在最终树结构中唯一确定
- 题干是否清晰说明"从空树开始"和"插入全部完成后"

**solve_output_should_contain:**
- 完整的插入过程记录（每步插入后的树形态）
- 每次旋转的触发条件说明（失衡节点、平衡因子、旋转类型判断依据）
- 旋转操作的详细步骤（指针更新过程）
- 最终树结构的完整描述
- 正确答案的推导路径
- 三个干扰项对应的错误认知路径说明

**fail_if_missing:**
- 插入序列未触发任何旋转操作
- 旋转类型判断存在歧义（同一失衡状态可对应多种旋转类型）
- 干扰项无法对应明确的错误认知路径（随机数值而非认知错误产物）
- 最终树结构不唯一或设问目标无法从树结构中确定
