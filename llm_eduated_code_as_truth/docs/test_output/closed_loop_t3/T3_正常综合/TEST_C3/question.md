## 题目

设有一棵初始为空的平衡二叉树（AVL 树），按以下序列依次插入节点：30, 20, 25, 40, 35, 10, 50。

所有节点插入完成后，以下关于插入过程中旋转操作的描述，正确的是：

## 设计说明
- 复用骨架来源：给定初始空 AVL 树和一组插入序列，要求判断插入全部完成后树的某个结构特征（来自 design_card question_structure_plan）
- 考察形式：多步串行推演（主）+ 陷阱辨析（辅）（来自 exam_form）
- 经验值参数：插入序列取 7 个互异整数 [30, 20, 25, 40, 35, 10, 50]（AVL 树经验值 n=7）；设问目标为插入过程中旋转操作的类型与时机辨析
- 设计理念：考察 AVL 树插入与旋转的完整动态过程，要求学生完整模拟多步插入流程的同时，在每次失衡时精准辨析多种旋转类型（LR 型、RL 型、RR 型）的触发条件，区分能完整走完旋转流程并准确判断旋转类型的学生与只记得旋转名称但无法在动态插入中正确应用的学生
- 与目标 K-雷达的对齐：K1=3（需准确记忆 AVL 树平衡因子定义和旋转类型），K2=2（平衡因子计算为简单加减），K3=4（7 节点插入需>5 步串行推演且维持动态状态），K4=4（需精准辨析多种旋转触发条件，识别隐含路由前提如失衡节点是祖父而非父节点、LR/RL 型需两步旋转），K5=1（单一数据结构内部解决）
