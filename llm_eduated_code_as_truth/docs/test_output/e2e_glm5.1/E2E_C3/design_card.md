## design_rationale

本题选取 AVL 插入旋转作为核心考点，考察模式为"结构操作与状态维护模拟"，因为 AVL 树的本质价值在于插入时动态维护平衡，只有让学生亲手走完"插入 → 检测失衡 → 判断旋转类型 → 执行旋转"的完整链路，才能真实反映其对自平衡机制的掌握程度。K 目标设为 K3-K4 平衡型：K3≥4 保证推演步数充足（多次插入 + 旋转调整 >5 步），K4≥3 保证旋转类型的条件辨析构成实质性的认知路由——学生不能靠机械记忆旋转名称得分，必须理解"新插入节点相对于失衡节点的路径方向"这一隐含前提才能选择正确的旋转类型。本题至少包含一次双旋（LR 或 RL），因为双旋要求学生理解"先旋子树、再旋整体"的两步逻辑，这是区分**能完整走完旋转流程并正确回溯检查的学生**与**只记得单旋名称、遇到双旋就套错模板的学生**的关键分水岭。难度 4 适合 Q41 题位，在选择题中属于高难度压轴区间，需要较强的工作记忆和空间想象能力。

## expected_reasoning_actions

- 按给定关键字序列依次插入，构建 AVL 树（每次插入后需回溯检查平衡）
- 对每次插入，从插入点向上逐层计算平衡因子，检测是否存在 |BF|≥2 的失衡节点
- 定位最小失衡子树的根节点（离插入点最近的失衡祖先）
- 沿失衡节点到插入点的路径取前两步方向，判断旋转类型：同向（LL/RR）→ 单旋，异向（LR/RL）→ 双旋
- 若为双旋，先对失衡节点的孩子执行一次单旋（旋转方向与孩子的失衡方向相反），再对失衡节点执行第二次单旋
- 旋转后正确重新挂接被旋下移的子树（T1/T2/T3/T4 四棵子树的归属不能错位）
- 将旋转后的最终树结构与四个选项逐一比对，选出正确描述

## question_structure_plan

- stem_style: 给定一组关键字按特定顺序插入初始为空的 AVL 树，问某次特定插入后（旋转完成后）的树结构特征——如某节点的左右孩子、某子树的根、或整棵树的形态描述
- asking_method: "上述序列依次插入后，第 k 次插入完成并调整后，下列哪个描述是正确的？"
- option_architecture:
  - correct: 旋转后真实树结构的正确描述
  - distractor_1（旋转类型混淆）: 将双旋误判为单旋后的树结构——即只执行了第一次旋转（或只做 LL/RR 单旋），子树挂接与正确答案有系统性差异
  - distractor_2（中间值 / 未旋转状态）: 插入新节点后但尚未执行任何旋转时的树结构，此时树处于临时失衡状态
  - distractor_3（子树挂接偏移）: 旋转方向正确但某棵中间子树（T2 或 T3）挂接到了错误的位置，导致局部结构偏差
- 干扰策略选定理由:
  - 旋转类型混淆对应 K4 条件路由——测试学生是否真正理解旋转触发条件
  - 中间值干扰对应 K3 机制推演——测试学生是否走完了完整流程
  - 子树挂接偏移对应操作精度——测试学生是否理解旋转的子树转移规则

## parameter_plan

- parameter_slots:
  - name: insertion_sequence
    role: 依次插入 AVL 树的关键字序列
    candidate_range: 5-8 个互不相同的正整数，数值分布需保证插入过程中至少触发一次双旋（LR 或 RL）
    used_by: stem（题干给出序列）, solver（构建树并推演旋转）
  - name: target_insertion_index
    role: 指定问询第几次插入后的状态
    candidate_range: 序列中触发旋转的那次插入（通常为最后一次或倒数第二次）
    used_by: stem（题干设问点）, solver（确定需要推演到哪一步）
  - name: query_target
    role: 问询的具体树结构特征（如某节点的左右孩子值、某层节点集合、根节点的孩子）
    candidate_range: 选择旋转后结构变化最显著的特征作为问询点
    used_by: stem（设问内容）, option（选项围绕此特征构造）
- validation_targets:
  - 插入序列必须保证目标插入步骤确实触发失衡（|BF|≥2），不能所有插入都不失衡
  - 目标插入步骤触发的旋转类型中至少包含一次双旋（LR 或 RL）
  - 旋转后的树结构必须唯一确定，四个选项之间有且仅有一个正确答案
  - 干扰项对应的错误树结构与正确树结构在 query_target 上有明显差异，不会产生歧义
- adjustment_priority:
  - 1st: insertion_sequence（序列决定了旋转是否触发及类型，是核心参数）
  - 2nd: target_insertion_index（决定问询的推演深度）
  - 3rd: query_target（决定选项区分度）

## terminology_and_expression_constraints

- required_terms:
  - "平衡二叉树"（不简写为"平衡树"，避免与红黑树等混淆）
  - "平衡因子"（标准定义：左子树高度 − 右子树高度，或右减左，题干须明确约定）
  - "最小不平衡子树"（指离插入节点最近的、平衡因子绝对值超过 1 的子树）
- required_qualifiers:
  - 题干必须说明平衡因子的定义方向（左子树高度 − 右子树高度，还是反过来）
  - 题干必须明确"依次插入"（强调顺序敏感）
  - 题干必须明确"插入并调整后"（强调旋转已完成，而非中间状态）
- avoid_phrases:
  - "自动平衡"（AVL 不会自动平衡，需要显式旋转操作）
  - "重新排列"（不是排序，是结构调整）
  - 简称"左旋/右旋"而不说明旋转对象（应说明"以 X 为支点"）
- standard_rewrites:
  - bad: "插入后树会自动调整"
  - good: "插入后若发现失衡，需通过旋转操作恢复平衡"
  - bad: "进行左旋"
  - good: "以节点 X 为支点进行左旋（顺时针）"或"以节点 X 为轴，将其右孩子上提"

## audit_focus

- final_review_must_check:
  - 插入序列是否确实在 target_insertion_index 处触发失衡并需要旋转（solver 验证）
  - 触发的旋转是否包含至少一次双旋（LR 或 RL），而非仅有单旋
  - 平衡因子定义方向是否在题干中明确约定
  - 四个选项是否分别对应设计卡规划的三个干扰策略（旋转类型混淆 / 中间值 / 子树挂接偏移），无随机凑数选项
  - 正确选项与干扰项在 query_target 上的差异是否清晰无歧义
- solve_output_should_contain:
  - 逐步插入过程的平衡因子变化记录
  - 失衡节点的定位过程
  - 旋转类型的判断依据（路径方向分析）
  - 旋转后的完整树结构（可文字描述或示意）
  - 四个选项逐一比对的结论
- fail_if_missing:
  - 插入序列无法在目标步骤触发任何旋转 → 参数设计失败，需重新设计序列
  - 所有旋转均为单旋，无双旋触发 → 不满足 K4≥3 的条件辨析要求
  - 题干未约定平衡因子定义方向 → 学生无法唯一确定答案
  - 存在两个以上选项与旋转后真实结构一致 → 选项区分度不足
