# Q41 单项选择题（2分）

## 题干

已知平衡因子（Balance Factor）的定义为**左子树高度 − 右子树高度**。将关键字序列 **{3, 1, 2, 5, 4, 7, 6}** **依次**插入一棵初始为空的平衡二叉树（AVL 树）中，每次插入后若发现失衡（即某节点平衡因子绝对值 ≥ 2）则立即通过旋转操作恢复平衡。

**在上述 7 个关键字全部插入并完成旋转调整后**，关于该平衡二叉树的结构，下列哪一项描述是正确的？

## 设计说明

- **复用骨架来源**：来自 design_card `question_structure_plan`——给定关键字序列依次插入初始为空的 AVL 树，问旋转完成后的树结构特征（single_choice + asking_method："上述序列依次插入后…下列哪个描述是正确的？"）
- **考察形式**：来自 exam_form——多步串行推演（主）+ 陷阱辨析（辅）；给定序列依次插入 AVL 树，问最终树结构特征
- **经验值参数**：取经验值表 AVL/平衡二叉树友好值 n=7；插入序列取 7 个互不相同的正整数 {3, 1, 2, 5, 4, 7, 6}（经验上该序列可触发至少一次双旋）；target_insertion_index 设为全部 7 次插入完成后（最大化推演步数）；query_target 设为最终树的整体结构特征
- **设计理念**：来自 design_card `design_rationale`——只有让学生亲手走完"插入→检测失衡→判断旋转类型→执行旋转（含双旋的两步逻辑）"完整链路，才能真实反映其对自平衡机制的掌握程度；双旋是区分能完整走完流程的学生与只记得单旋名称的学生的关键分水岭
- **与目标 K-雷达的对齐**：来自 exam_form，K3=4（推演步数 >5 步，需维持动态状态更新）、K4=3（需识别旋转触发条件这一隐含前提）、K1=2、K2=1、K5=1，整体为 K3-K4 平衡型
