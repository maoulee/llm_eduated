## examination_form
- 考察形式：单点计算（主） + 概念辨析（辅）
- 设问方向：给定二叉树遍历序列（含权值），要求学生完成"重建树 → 识别叶子 → 计算各叶子路径长度 → 逐项求和"得到 WPL 值；干扰项围绕路径长度定义混淆、叶子遗漏、内部节点误入三种高频认知错误设置

## k_radar
- K1（基础认知）: 3
- K2（单步代入）: 3
- K3（机制推演）: 2
- K4（条件路由）: 2
- K5（跨域联动）: 3
- 形状主导维度：K1/K2 协同主导（均 3），K5 支撑区分度（3）

## rationale
- 本题核心任务是"WPL 数值计算"，属于 K2 单点代入的程序化计算——学生需对每个叶子执行"权值 × 路径长度"并求和，因此主形式为单点计算。
- 但题目要求先从遍历序列重建树结构、再精确识别叶子节点和路径长度（边数 vs 深度），这一环节依赖 K1 基础认知的精确性，故辅以概念辨析——干扰项 A（路径长度按深度计算）、B（漏算叶子）、C（内部节点误入）正是对 WPL 定义理解偏差的辨析。
- K1=3、K2=3 的协同主导决定了"理解定义 + 程序化计算"双重门槛；K5=3 通过三组认知陷阱干扰项提升区分度，使"定义精确且计算无误"的学生与"公式模糊或粗心"的学生拉开差距。K3/K4=2 反映推理链较短、无跨章节关联，符合单知识点计算题的定位。
- 与经验卡 examination_mode"给定树结构→计算 WPL"一致，该模式为选择题中的经典计算题型。
