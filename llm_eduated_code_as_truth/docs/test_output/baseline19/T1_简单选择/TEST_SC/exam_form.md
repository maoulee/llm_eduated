## rationale
- K2=3（单步代入）：每个叶子节点需执行"权值×路径长度"的单步乘法代入，共4-6次同类计算
- K3=3（机制推演）：整体流程为串行多步——识别全部叶子节点→逐节点确定路径长度→逐个相乘→累加求和，步骤间存在依赖关系
- K2+K3双主导对应"多步但每步计算简单"的特征，与WPL计算"步骤多但单步不复杂"的本质一致
- 与目标K-雷达完全对齐，不偏离上游设计
