## 题目

已知某二叉树的前序遍历序列为：A B D E C F G，中序遍历序列为：D B E A F C G。

请回答下列问题：

### (1) （4分）根据上述两种遍历序列，还原该二叉树的结构（可用图形或文字描述）。

### (2) （3分）基于(1)中还原的二叉树，写出该二叉树的层序遍历序列。

### (3) （3分）基于(1)中还原的二叉树，分析该二叉树的树高和叶子节点数。

## 求解过程

### 子问题(1)：还原二叉树结构

**方法**：利用前序遍历确定根节点，中序遍历划分左右子树，递归还原。

**步骤**：

1. 前序第一个元素 **A** 为根节点。
2. 在中序中找到 A，其左侧 `D B E` 为左子树的中序，右侧 `F C G` 为右子树的中序。
3. 左子树：前序 `B D E`，中序 `D B E` → 根为 **B**，中序中 B 左侧 `D` 为左子树，右侧 `E` 为右子树 → B 的左孩子为 **D**，右孩子为 **E**。
4. 右子树：前序 `C F G`，中序 `F C G` → 根为 **C**，中序中 C 左侧 `F` 为左子树，右侧 `G` 为右子树 → C 的左孩子为 **F**，右孩子为 **G**。

**还原的二叉树结构**：
```
        A
       / \
      B   C
     / \ / \
    D  E F  G
```

文字描述：
- 根节点：A
- A 的左孩子：B，右孩子：C
- B 的左孩子：D，右孩子：E
- C 的左孩子：F，右孩子：G
- D、E、F、G 均为叶子节点

### 子问题(2)：层序遍历序列

层序遍历即从上到下、从左到右逐层访问：

- 第1层：A
- 第2层：B、C
- 第3层：D、E、F、G

**层序遍历序列：A B C D E F G**

### 子问题(3)：树高和叶子节点数

**树高**：从根节点到最远叶子节点的路径长度（按节点数计）。
- 根 A（第1层）→ B/C（第2层）→ D/E/F/G（第3层）
- 共 3 层

**树高：3**

**叶子节点**：无左右孩子的节点。
- D（无孩子）、E（无孩子）、F（无孩子）、G（无孩子）

**叶子节点数：4**

## 答案

- **(1)** 二叉树结构：根A，左子B（左D右E），右子C（左F右G）
- **(2)** 层序遍历序列：A B C D E F G
- **(3)** 树高：3；叶子节点数：4

## 设计说明
- 考察知识点：二叉树遍历序列还原（前序+中序→层序）、二叉树性质分析
- 考察形式：多步串行推演 + 性质分析
- 子问依赖链：q1→{q2, q3}（q2和q3并行依赖q1）
- 参数设置：节点数 n=7，树高 h=3，叶子节点数=4，度为2的节点数=3
- 难度等级：3（中等）
- K-雷达对齐：K1=3, K2=3, K3=2, K4=3, K5=3
