## 考点
- **二叉树遍历序列还原**（核心考点）：根据两种遍历序列（前序+中序或后序+中序）还原二叉树结构
- **遍历序列的性质**（辅助考点）：理解前序、中序、后序遍历的递归定义和序列特征
- **遍历序列的唯一性**（辅助考点）：掌握哪些遍历组合能唯一确定二叉树

## 难度目标
- **K1（知识广度）= 3**：涉及前序、中序、后序三种遍历方式及其相互关系
- **K2（知识深度）= 3**：需要深入理解遍历的递归本质和序列还原的算法逻辑
- **K3（计算复杂度）= 2**：以逻辑推理为主，计算量适中，不涉及复杂运算
- **K4（抽象程度）= 3**：需要从序列抽象出树结构，理解递归分解过程
- **K5（综合程度）= 3**：综合运用多种遍历知识，完成还原和推导

**整体难度定位**：中等（medium），符合 slot 数据中的 difficulty 设定

## 考察模式
**模式选择**：序列还原+性质分析

**理由**：
- 历史经验表明，二叉树遍历题位的经典考察模式是"给出两种遍历序列→还原二叉树→推导第三种序列或分析性质"
- 该模式能全面考查学生对遍历本质的理解，而非机械记忆
- 适合综合题的递进式结构，子问题间有逻辑依赖

## 出题要求
- **题型**：综合题（comprehensive）
- **总条件数**：2-3个显式条件（两种遍历序列 + 可选的补充说明）
- **条件设计原则**：
  - 给出的两种遍历序列必须能唯一确定二叉树
  - 序列长度适中，避免过于简单或过于复杂
  - 节点标签使用字母（A-J）或数字（1-10），保持清晰
- **参数取值范围要求**：
  - 二叉树节点数：5-10个节点
  - 树的高度：2-4层
  - 至少包含一个叶子节点和一个度为2的节点

## 子问题规划

**子问题数量**：3问

**第1问**（4分）
- **类型**：计算/构造
- **考察目标**：根据给定的前序（或后序）和中序遍历序列，还原二叉树结构
- **要求**：画出二叉树或写出每个节点的左右孩子关系
- **与前后问关系**：基础问，后续问题依赖此问结果

**第2问**（3分）
- **类型**：计算
- **考察目标**：写出第1问所还原二叉树的另一种遍历序列（如第1问用前序+中序，则写后序）
- **要求**：给出完整的遍历序列
- **与前后问关系**：依赖第1问的还原结果

**第3问**（3分）
- **类型**：分析
- **考察目标**：分析二叉树的性质（如高度、叶子节点数、度为1的节点数等）
- **要求**：给出具体数值并简要说明
- **与前后问关系**：依赖第1问的还原结果，与第2问并行

**分值分配**：4+3+3=10分

## 参数约束

**二叉树规模参数**：
- 节点总数 n：5 ≤ n ≤ 10
- 树高 h：2 ≤ h ≤ 4
- 叶子节点数：≥ 2
- 度为2的节点数：≥ 1

**遍历序列参数**：
- 给出的两种遍历类型：前序+中序 或 后序+中序（二选一）
- 序列必须满足：能唯一确定二叉树
- 节点标签：使用连续字母（A, B, C, ...）或连续数字（1, 2, 3, ...）

**一致性约束**：
- 前序序列的第一个元素 = 根节点
- 中序序列中根节点左侧 = 左子树节点，右侧 = 右子树节点
- 后序序列的最后一个元素 = 根节点
- 三种遍历序列包含的节点集合必须完全相同

**可调自由度**：
- 二叉树的具体结构（左偏、右偏、平衡等）
- 节点标签的具体选择（字母或数字）
- 第3问考查的具体性质（高度、叶子数、度为1的节点数等）

## 参考经验

**历史考察模式**：
- 经典模式：前序+中序→还原→后序
- 变体模式：后序+中序→还原→前序
- 陷阱模式：给出前序+后序，考查学生是否知道不能唯一确定

**难度锚点**：
- 节点数5-6：偏简单（K2=2）
- 节点数7-8：中等（K2=3）
- 节点数9-10：偏难（K2=4）
- 本题定位中等，建议节点数7-8

**典型陷阱**：
- 学生混淆前序和后序的根节点位置
- 学生在中序序列中错误划分左右子树
- 学生忽略空子树的情况
- 学生将层序遍历与其他遍历混淆
