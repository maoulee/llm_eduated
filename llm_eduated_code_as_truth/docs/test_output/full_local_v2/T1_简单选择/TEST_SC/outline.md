## 考点
- **二叉树带权路径长度（WPL）计算**：核心考点，考查WPL的定义和计算方法
  - 考察侧重点：理解带权路径长度的概念（叶子节点权值 × 路径长度），能正确识别叶子节点并计算其到根节点的路径长度
- **二叉树结构识别**：辅助考点，考查从图形或数组表示中识别二叉树结构
  - 考察侧重点：能正确理解二叉树的层次结构，区分叶子节点和非叶子节点

## 难度目标
- **K1（知识记忆）= 2**：需要记忆WPL的定义公式，但不需要死记硬背
- **K2（理解）= 3**：需要理解路径长度的含义（从根到叶子经过的边数），理解权值与路径长度的乘积意义
- **K3（应用）= 3**：需要应用WPL计算公式，对给定二叉树进行逐节点计算并求和
- **K4（分析）= 2**：中等难度选择题，需要一定的分析能力识别叶子节点和路径，但不需要复杂分析
- **K5（综合）= 1**：单知识点考查，不涉及多知识点综合

**整体难度定位**：中等（medium），符合slot数据中的difficulty设定

## 考察模式
**模式选择**：给定二叉树图形/结构，计算WPL

**理由**：
- 这是WPL考查最经典、最直接的模式
- 适合选择题形式，计算量适中
- 能有效区分是否真正理解WPL概念（而非仅记忆公式）
- 历史同类题目多采用此模式，难度可控

**备选模式**（不采用）：
- 哈夫曼树构造+计算：计算量偏大，不适合选择题
- 给定WPL反推参数：逆向思维，难度偏高

## 出题要求
- **题型**：single_choice（四选一选择题）
- **总条件数**：2-3个显式条件
  - 条件1：二叉树的结构表示（图形或数组/序列）
  - 条件2：各节点的权值分配
  - 条件3（可选）：特殊说明（如根节点编号、路径长度定义等）
- **条件设计原则**：
  - 二叉树结构应清晰可读，避免歧义
  - 权值分配应使计算结果适中（避免过大或过小）
  - 可考虑使用图形表示或数组表示，图形更直观
- **参数取值范围要求**：
  - 节点总数：5-10个（适中，保证计算量合理）
  - 叶子节点数：3-5个（保证WPL计算有足够项但不繁琐）
  - 权值范围：1-50的整数（计算结果在合理范围内）
  - 树的高度：3-4层（结构清晰，路径长度适中）

## 子问题规划
本题为选择题，无子问题。

**选项设计**：
- 正确选项：通过正确计算WPL得到
- 干扰选项1：常见错误——将非叶子节点也计入WPL
- 干扰选项2：常见错误——路径长度计算错误（如从1开始计数而非从0，或漏算某条边）
- 干扰选项3：常见错误——权值与路径长度乘积计算错误或求和错误

## 参数约束
- **节点总数 N**：取值范围 [5, 10]，建议6-8个
- **叶子节点数 L**：取值范围 [3, 5]，需满足 L ≤ N
- **树的高度 H**：取值范围 [3, 4]，与节点数N需一致（H层满二叉树最多2^H-1个节点）
- **权值 W_i**：每个叶子节点的权值取值范围 [1, 50]，建议为整数
- **WPL计算结果**：应在 [50, 500] 范围内（保证选项数值适中）
- **一致性约束**：
  - 所有叶子节点的路径长度之和应使WPL结果落在合理范围
  - 权值分配应避免所有叶子节点权值相同（降低题目区分度）
  - 树的结构应保证至少有一个叶子节点路径长度≥2（考查路径长度概念）

## 参考经验
**考察模式参考**：
- 历史同类题目多采用"给定二叉树图形+权值，计算WPL"的模式
- 图形表示比数组表示更常见，更直观
- 部分题目会给出哈夫曼树，要求计算WPL（但本题不采用此模式）

**难度锚点**：
- 中等难度WPL题目通常节点数6-8个，叶子节点3-4个
- 计算结果通常在100-300之间
- 路径长度多为2-3层

**典型陷阱**：
- 将非叶子节点误认为叶子节点计入WPL
- 路径长度从1开始计数（正确应从根到叶子经过的边数，根节点路径长度为0）
- 漏算某个叶子节点
- 权值与路径长度对应错误
