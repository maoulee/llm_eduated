# Q41 平衡二叉树 AVL 插入与旋转

## 题干

设有一棵初始为空的平衡二叉排序树（AVL树），平衡因子定义为左子树高度减去右子树高度。现按以下顺序依次插入关键字序列：

**38, 35, 30, 45, 42**

每次插入后，若某结点的平衡因子绝对值变为2，则执行相应的旋转操作（LL旋转、RR旋转、LR旋转或RL旋转）恢复平衡。

插入全部完成后，该AVL树的根结点关键字是？

A. 42
B. 38
C. 35
D. 45

---

## 设计说明

- **复用骨架来源**：AVL树插入推演经典骨架——给定插入序列→多步插入+平衡因子更新+失衡检测+旋转执行→设问最终树形态状态
- **考察形式**：结构操作与状态维护模拟（多步串行推演主 + 陷阱辨析辅），来自 exam_form
- **设问结构**：选择题，直接设问最终状态（根结点关键字），干扰项覆盖三种错误认知路径：
  - 遗漏旋转（某次插入后未执行旋转）→ 干扰 B（38）：遗漏插入 30 后的 LL 旋转，根保持为 38
  - 旋转类型错误（如RL误判为LL，单旋转替代双旋转）→ 干扰 A（42）：RL 旋转只做单左旋，42 成为根
  - 平衡因子计算错误（符号错误或数值偏差导致旋转时机/类型判断错误）→ 干扰 D（45）：遗漏 RL 旋转或旋转方向错误，45 成为根
- **经验值参数来源**：
  - 插入序列 `[38, 35, 30, 45, 42]`：来自经验值表"AVL题节点数7-8"，选择题场景缩减至5个节点（避免工作记忆过载），经验上5个节点足以触发1-2次旋转
  - 设问目标"根结点关键字"：来自 parameter_plan 候选项，答案简洁（单个整数）
- **与目标 K-雷达的对齐**：
  - K3=4：>5步推演（5次插入→每次回溯更新平衡因子→检测失衡→判断旋转类型→执行旋转），需维持动态状态更新
  - K4=4：隐含前提深（LR/RL双旋转中"先子节点旋转再父节点旋转"的顺序不可颠倒；旋转类型判断依赖失衡结点与插入结点的位置关系而非单纯看左右）
  - K1=3：需准确记忆平衡因子定义和四种旋转触发条件
  - K2=2：平衡因子计算为简单加减但需多次执行
  - K5=1：单一数据结构内部操作，无跨域联动
- **是否融合**：否。K3-K4高难度但单骨架（多步插入推演+旋转类型辨析）已足以达到难度目标，无需额外融合。插入序列本身已包含LL旋转和RL双旋转两种侧重，属于同考点多侧重自然覆盖，非刻意融合。
- **选项设计**：
  - 正确答案 C（35）：来自 solve 计算结果
  - 干扰 A（42）：RL 旋转只做单左旋的错误结果
  - 干扰 B（38）：遗漏 LL 旋转的错误结果
  - 干扰 D（45）：遗漏 RL 旋转或旋转方向错误的结果
  - 4 个值两两不同，干扰项对应 design_card 选定的认知错误路径
