## 求解过程

### 子问题(1)：插入节点 80

初始 AVL 树：
```
            40(0)
           /    \
        20(0)   60(0)
       /   \    /   \
     10(0) 30(0) 50(0) 70(0)
```

插入 80：80 > 40 > 60 > 70，作为 70 的右子节点插入。

插入后树结构：
```
            40
           /    \
        20       60
       /   \    /   \
     10    30  50    70
                       \
                        80
```

更新平衡因子（自底向上）：
- 80: 0
- 70: 0 − 1 = −1
- 60: 1 − 2 = −1
- 40: 3 − 4 = −1

所有节点平衡因子绝对值均 ≤ 1，**未发生旋转**。

**根节点值：40**

---

### 子问题(2)：插入节点 90

基于插入 80 后的树，插入 90：90 > 40 > 60 > 70 > 80，作为 80 的右子节点插入。

插入后树结构：
```
            40
           /    \
        20       60
       /   \    /   \
     10    30  50    70
                       \
                        80
                         \
                          90
```

更新平衡因子（自底向上）：
- 90: 0
- 80: 0 − 1 = −1
- 70: 0 − 2 = **−2** ← 失衡！

**最低失衡节点：70**，失衡类型：**RR**（右子树右子树，新节点 90 在 70 的右子节点 80 的右侧）。

**执行旋转：以节点 70 为根进行左旋**

左旋后子树变化：
- 80 上升为子树根
- 70 成为 80 的左子节点
- 80 原左子树（空）成为 70 的右子树

旋转后整棵树：
```
            40
           /    \
        20       60
       /   \    /   \
     10    30  50    80
                /   \
               70    90
```

更新平衡因子：
- 70: 0, 90: 0, 80: 1 − 1 = 0
- 60: 1 − 2 = −1
- 40: 3 − 4 = −1

所有节点平衡因子绝对值 ≤ 1，树恢复平衡。

**旋转后根节点值：40**

### 子问题(3)：依次插入节点 5 和 1

#### 插入节点 5

基于插入 90 并调整后的树，插入 5：5 < 40 < 20 < 10，作为 10 的左子节点插入。

插入后树结构：
```
            40
           /    \
        20       60
       /   \    /   \
     10    30  50    80
    /              /   \
   5              70    90
```

更新平衡因子（自底向上）：
- 5: 0
- 10: 1 − 0 = 1
- 20: 2 − 1 = 1
- 40: 3 − 4 = −1

所有节点平衡因子绝对值 ≤ 1，**未发生旋转**。

#### 插入节点 1

基于插入 5 后的树，插入 1：1 < 40 < 20 < 10 < 5，作为 5 的左子节点插入。

插入后树结构：
```
            40
           /    \
        20       60
       /   \    /   \
     10    30  50    80
    /              /   \
   5              70    90
  /
 1
```

更新平衡因子（自底向上）：
- 1: 0
- 5: 1 − 0 = 1
- 10: 2 − 0 = **2** ← 失衡！

**最低失衡节点：10**，失衡类型：**LL**（左子树左子树，新节点 1 在 10 的左子节点 5 的左侧）。

**执行旋转：以节点 10 为根进行右旋**

右旋后子树变化：
- 5 上升为子树根
- 10 成为 5 的右子节点
- 5 原右子树（空）成为 10 的左子树

旋转后整棵树：
```
            40
           /    \
        20       60
       /   \    /   \
      5    30  50    80
     / \         /   \
    1   10      70    90
```

更新平衡因子：
- 1: 0, 10: 0, 5: 1 − 1 = 0
- 20: 2 − 1 = 1
- 40: 3 − 4 = −1

所有节点平衡因子绝对值 ≤ 1，树恢复平衡。

### 子问题(4)：汇总

| 插入节点 | 是否旋转 | 失衡节点 | 失衡类型 |
|---------|---------|---------|---------|
| 80 | 否 | — | — |
| 90 | 是 | 70 | RR |
| 5 | 否 | — | — |
| 1 | 是 | 10 | LL |

**共发生 2 次旋转。**

**旋转类型序列：RR → LL**

## 最终答案
- (1) 插入 80：未发生旋转，所有节点平衡因子绝对值 ≤ 1；根节点值 = 40
- (2) 插入 90：发生 RR 旋转，最低失衡节点 = 70，以 70 为根进行左旋；旋转后根节点值 = 40
- (3) 插入 5：未发生旋转；插入 1：发生 LL 旋转，最低失衡节点 = 10，以 10 为根进行右旋
- (4) 共 2 次旋转；旋转类型序列：RR → LL
