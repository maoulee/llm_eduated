# Q41 平衡二叉树 AVL 的插入与旋转

设平衡因子定义为"左子树高度 − 右子树高度"。给定一棵初始 AVL 树，其节点集合为 {10, 20, 30, 40, 50, 60, 70}，树结构如下（括号内为各节点的平衡因子）：

```
            40(0)
           /    \
        20(0)   60(0)
       /   \    /   \
     10(0) 30(0) 50(0) 70(0)
```

现按顺序依次插入以下节点：80、90、5、1。每次插入后，若树发生失衡（某节点平衡因子绝对值大于 1），需定位最低失衡节点，判断失衡类型（LL/RR/LR/RL），执行相应的左旋或右旋操作，并重新计算相关节点的平衡因子，使树恢复为合法 AVL 树。

请回答下列问题：

### (1) （4分）插入节点 80 后，判断是否发生旋转。若发生旋转，指出最低失衡节点、失衡类型、执行的旋转操作（说明以哪个节点为根进行左旋/右旋），以及旋转后整棵树的根节点值；若未发生旋转，说明理由并给出根节点值。

### (2) （4分）基于 (1) 插入并调整后的 AVL 树，继续插入节点 90。判断是否发生旋转。若发生旋转，指出最低失衡节点、失衡类型、执行的旋转操作，以及旋转后整棵树的根节点值；若未发生旋转，说明理由并给出根节点值。

### (3) （4分）基于 (2) 插入并调整后的 AVL 树，继续依次插入节点 5 和 1。对每次插入分别判断是否发生旋转，若发生则指出最低失衡节点、失衡类型及执行的旋转操作；若未发生则说明理由。

### (4) （3分）汇总整个插入过程（插入 80、90、5、1 四个节点）：共发生多少次旋转？按插入顺序列出每次旋转的类型序列（如 LL、RR、LR、RL）。
