## 题目

已知一棵二叉树（根为第 0 层）的结构及各节点权值如下所示，节点旁标注的数字为该节点的权值。该二叉树的带权路径长度 WPL 为（ ）。

```
          A(9)
         / \
      B(2)  C(4)
            / \
         D(5) E(6)
             / \
          F(3) G(7)
```

A. 59
B. 32
C. 42
D. 54

## 求解过程

带权路径长度 WPL = Σ（叶子节点的权值 × 从根到该叶子的路径长度），路径长度为从根到该节点的边数（根为第 0 层）。

识别叶子节点及路径长度：

| 叶子节点 | 权值 | 路径 | 路径长度（边数） |
|---------|------|------|----------------|
| B | 2 | A→B | 1 |
| D | 5 | A→C→D | 2 |
| F | 3 | A→C→E→F | 3 |
| G | 7 | A→C→E→G | 3 |

A、C、E 是内部节点，不参与 WPL 计算。

$$\text{WPL} = 2 \times 1 + 5 \times 2 + 3 \times 3 + 7 \times 3 = 2 + 10 + 9 + 21 = 42$$

干扰项分析：
- A. 59（层数偏移）：路径长度整体 +1，2×2+5×3+3×4+7×4=59
- B. 32（遗漏叶子 D）：2×1+3×3+7×3=32
- D. 54（误计内部节点 E）：42+6×2=54

## 答案

**C. 42**

WPL = 2×1 + 5×2 + 3×3 + 7×3 = 42，四个叶子节点 B、D、F、G 的路径长度分别为 1、2、3、3。
