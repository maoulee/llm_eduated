## 考点
- **核心考点**：二叉树遍历序列还原（前序+中序 或 后序+中序）
  - 考察侧重点：理解遍历序列与树结构的对应关系，掌握通过两种遍历序列唯一确定二叉树的方法
- **辅助考点**：二叉树基本性质
  - 考察侧重点：树的深度计算、叶子节点识别、遍历序列的特征分析

## 难度目标
- **K1（知识广度）= 3**：涉及遍历算法、树结构、序列分析，知识面适中
- **K2（知识深度）= 3**：需理解遍历的本质（根-左-右的顺序关系），非表面记忆
- **K3（计算复杂度）= 2**：手动还原树的计算量适中，节点数控制在合理范围
- **K4（逻辑推理）= 3**：需通过序列定位根节点、划分左右子树，有一定推理要求
- **K5（综合应用）= 3**：综合应用遍历知识解决还原问题，中等综合难度

## 考察模式
- **选择模式**：经典还原模式——给定前序+中序（或后序+中序）遍历序列，还原二叉树后求第三种遍历序列或树的性质
- **选择理由**：这是二叉树遍历最核心的考察方式，能全面检验学生对遍历本质的理解；历史考题中该模式出现频率高，属于标准考察路径

## 出题要求
- **题型**：综合题（2-3问）
- **总条件数**：2个显式条件（两种遍历序列）+ 隐含条件（节点值互异）
- **条件设计原则**：
  - 两种遍历序列中必须包含中序遍历（否则无法唯一确定）
  - 序列长度一致，节点值互不相同
  - 序列需能唯一确定一棵二叉树
- **参数取值范围要求**：节点数5-10个，树高3-4层

## 子问题规划
- **第1问（计算/还原，5-6分）**
  - 考察目标：根据给定的前序和中序遍历序列，写出后序遍历序列（或画出二叉树结构）
  - 与前后问关系：基础问，后续问依赖此问还原的树结构

- **第2问（计算/分析，4-5分）**
  - 考察目标：求该二叉树的深度和叶子节点个数
  - 与前后问关系：依赖第1问还原的树，独立计算

- **第3问（分析，3-4分，可选）**
  - 考察目标：分析仅给定前序和后序序列能否唯一确定二叉树，说明理由
  - 与前后问关系：独立分析问，考察对遍历唯一性条件的理解

## 参数约束
- **节点数 n**：5 ≤ n ≤ 10（太少无法体现还原过程，太多增加计算负担）
- **树高 h**：3 ≤ h ≤ 4（保证有一定结构复杂度）
- **遍历序列对**：前序+中序 或 后序+中序（必须包含中序）
- **节点值**：互不相同的字符或数字（便于区分）
- **一致性约束**：
  - 两种遍历序列必须对应同一棵二叉树
  - 序列长度相等，均为 n
  - 还原后的树高在 [3, 4] 范围内
- **可调自由度**：Question Agent 可选择前序+中序或后序+中序，可决定第3问是否包含

## 参考经验
- **历史模式**：给定两种遍历序列还原二叉树是数据结构经典考题，通常以综合题形式出现
- **难度锚点**：medium难度对应节点数7-8个，树高3层，2-3问结构
- **典型陷阱**：
  - 学生混淆前序/后序的根节点位置
  - 划分左右子树时边界错误
  - 忽略中序遍历在唯一确定中的关键作用
