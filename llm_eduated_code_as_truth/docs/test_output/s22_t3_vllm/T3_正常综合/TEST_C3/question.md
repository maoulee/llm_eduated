# Q41 平衡二叉树 AVL 插入模拟

## 题干

设有一棵 AVL 树（平衡二叉排序树），其初始结构如下。图中每个节点标注为"节点值(平衡因子)"，其中平衡因子定义为**左子树高度减右子树高度**：

```
        30(1)
       /     \
   20(1)     40(0)
   /
 10(0)
```

现依次插入节点 **5、25、35**。每次插入后，若某节点平衡因子绝对值超过 1，则执行对应类型的旋转（LL/RR/LR/RL）使其恢复平衡，旋转后需从旋转点继续回溯至根检查祖先节点平衡因子。

问：全部插入完成后，最终 AVL 树的**根节点值**及其**平衡因子**为？

## 设计说明

- **初始树**：4 个节点，通过插入序列 [30, 20, 40, 10] 构建，为合法 AVL 树
- **插入序列**：[5, 25, 35]，共 3 次插入
- **预期旋转**：
  - 插入 5：节点 20 失衡（bf=2），左子节点 bf=1，触发 **LL 型旋转**（右旋）
  - 插入 25：节点 30 失衡（bf=2），左子节点 bf=-1，触发 **LR 型旋转**（先左旋后右旋）
  - 插入 35：不触发旋转
- **触发旋转类型数**：2 种（LL + LR），满足 hard_constraints
- **考察点**：
  - K3：多步串行推演（3 次插入，每次需回溯更新平衡因子，>5 步流程）
  - K4：精准辨析 LL 与 LR 旋转触发条件（隐含前提：双旋转需先旋子节点再旋父节点；旋转后需回溯检查祖先节点）
- **设问方式**：选择题，询问最终根节点值与平衡因子
- **选项设计**（P2 阶段完成）：
  - 正确选项：根节点值 + 正确平衡因子
  - 干扰项 1（概念混淆）：LL/LR 旋转条件判断错误导致的错误根节点
  - 干扰项 2（中间值）：仅完成部分插入的中间状态
  - 干扰项 3（条件遗漏）：旋转后未回溯检查祖先节点
