## 考点
- **二维数组列优先存储地址计算**：掌握列优先存储的地址公式 `LOC(A[i][j]) = Base + (j × m + i) × L`，能正确代入计算
- **列优先 vs 行优先区分**：理解列优先存储的内存布局特征（先存第一列，再存第二列...）

## 难度目标
- **K1=2（较低）**：需知道列优先存储概念和地址公式，但概念直接，无易混概念辨析
- **K2=3（标准）**：需代入公式计算，建议参数非2的幂次，增加计算区分度
- **K3=2（较低）**：单步公式代入，无需多步推演
- **K4=2（较低）**：题面明确"列优先"，无隐藏陷阱，但需注意到公式中行列位置与行优先不同
- **K5=1（微弱）**：单一知识点内部解决

## 考察模式
**计算型——地址公式应用**（标准模式）
- 给定：数组维度(m×n)、基地址、元素大小L、目标元素下标(i,j)
- 求解：该元素在列优先存储下的地址
- 参考：数据结构中数组存储地址计算的标准考察方式

## 出题要求
- **题型**：单选题，4选项，1正确3干扰
- **条件数**：4个显式条件（维度、基地址、元素大小、目标下标）
- **条件设计原则**：题干明确标注"列优先"，避免歧义
- **参数取值范围**：
  - 行数 m：建议 5-15 范围，非2的幂次优先（如7、9、11）
  - 列数 n：建议 5-15 范围，与 m 不同
  - 基地址：建议 1000-10000 范围，便于计算
  - 元素大小 L：建议 2-8 字节（常见类型）
  - 目标下标 (i,j)：在合法范围内，i < m, j < n

## 子问题规划
本题为单选题，无子问题。

## 参数约束
- **m（行数）**：5 ≤ m ≤ 15，建议非2的幂次（如7、9、11、13），增加计算区分度
- **n（列数）**：5 ≤ n ≤ 15，n ≠ m，建议非2的幂次
- **m 与 n 关系**：无特殊约束，但 m×n 不宜过大（<200），避免计算过于复杂
- **基地址 Base**：1000 ≤ Base ≤ 10000，建议为整数
- **元素大小 L**：2 ≤ L ≤ 8，建议为常见类型大小（2/4/8字节）
- **目标下标 (i,j)**：0 ≤ i < m, 0 ≤ j < n，建议 i 和 j 均不为0，避免平凡结果
- **一致性约束**：所有参数代入公式后，结果应为合理地址值（正整数）

## 参考经验
- **考察模式**：数组存储地址计算是数据结构经典考点，列优先 vs 行优先是核心区分点
- **难度锚点**：K2=3 为标准计算难度，参数应避免2的幂次导致计算过于简单
- **典型陷阱**：
  1. 行优先公式误用（最常见错误）
  2. 行列下标位置混淆（j×m+i 写成 i×m+j）
  3. 下标从1开始而非0开始
  4. 忘记乘以元素大小 L
