## 考点
- **二维数组列优先存储地址计算公式**：Loc(i,j) = Base + (j × m + i) × L，其中 m 为行数
- **列优先 vs 行优先的区别**：列优先按列连续存放，行优先按行连续存放，公式中行列系数互换
- **下标约定**：需明确下标从 0 还是从 1 开始，影响公式中的偏移量

## 难度目标
- **K1=2（较低）**：需知道"列优先存储"概念和地址计算公式，但公式本身是标准形式，不冷门
- **K2=3（标准）**：单步代入公式计算，参数设计为非2的幂次，计算量适中但需细心
- **K3=2（较低）**：仅需1步公式代入，无多步推演
- **K4=2（较低）**：存在常规注意点（列优先 vs 行优先），408考生基本不会踩坑，但干扰项会利用此差异
- **K5=1（微弱）**：纯单一知识点内部解决，不涉及其他系统

## 考察模式
**计算型——地址公式应用**（经典模式）
- 给定数组维度、基地址、元素大小、目标坐标
- 要求计算目标元素的存储地址
- 核心考察：公式记忆准确度 + 计算细心度
- 干扰策略：利用行优先公式、下标偏移错误、行列数混淆生成干扰项

## 出题要求
- **题型**：单选题（single_choice），4选项
- **分值**：2分
- **条件数**：5个显式条件
  1. 数组行数 m
  2. 数组列数 n
  3. 每个元素占用的字节数 L
  4. 基地址 Base
  5. 目标元素坐标 (i, j)
- **条件设计原则**：
  - 明确说明"列优先存储"
  - 明确下标起始约定（从0或从1）
  - 参数取值使计算结果非平凡（非2的幂次）
- **参数取值范围要求**：
  - m, n ∈ [3, 10]，且 m ≠ n（避免行列对称导致行优先/列优先结果相同）
  - L ∈ {2, 4, 8}（常见元素大小）
  - Base 为 4 的倍数，取值在合理内存地址范围
  - (i, j) 不选边界值（如 (0,0) 或 (m-1,n-1)），增加计算量

## 子问题规划
本题为单选题，无子问题结构。

## 参数约束
- **行数 m**：取值范围 [3, 10]，整数
- **列数 n**：取值范围 [3, 10]，整数，且 m ≠ n（保证行优先与列优先结果不同）
- **元素大小 L**：取值 {2, 4, 8} 字节
- **基地址 Base**：4的倍数，取值范围 [1000, 10000]
- **目标行下标 i**：0 ≤ i < m，不取 0 或 m-1
- **目标列下标 j**：0 ≤ j < n，不取 0 或 n-1
- **一致性约束**：
  - 列优先公式：Loc(i,j) = Base + (j × m + i) × L
  - 行优先公式（干扰项）：Loc(i,j) = Base + (i × n + j) × L
  - 两个公式计算结果必须不同（由 m ≠ n 保证）
  - 正确答案与干扰项之间应有合理差距（非仅差1字节）

## 参考经验
- **考察模式**：地址计算是数据结构经典题型，行优先/列优先对比是常见考察方式
- **难度锚点**：K2=3 为合理定位，参数设计为非2幂次增加计算量
- **典型陷阱**：
  1. 行优先公式误用（最常见错误）
  2. 下标从1开始计算（偏移量错误）
  3. 行列数 m/n 混淆
  4. 计算过程中的算术错误
