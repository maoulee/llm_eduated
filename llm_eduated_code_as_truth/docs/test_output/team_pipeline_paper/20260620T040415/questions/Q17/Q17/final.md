## 题目

设计算法，删除带头结点的单链表L中所有值为x的结点。

其中，单链表结点包含 data 域（int 类型）和 next 指针域，L 为头指针，链表长度 n ≥ 0（允许空表）。

**Q1（2分）**：定义单链表的结点类型。

**Q2（4分）**：描述算法的基本思想。

**Q3（8分）**：用C或C++编写算法代码，要求代码中包含必要的注释。

---

## 参考答案

**Q1**：

```c
typedef struct LNode {
    int data;              // 数据域
    struct LNode *next;    // 指针域
} LNode, *LinkList;
```

**Q2**：使用双指针遍历法。p 始终指向当前待检查结点的前驱，q 指向当前待检查结点。初始化 p 指向头结点 L，q 指向首元结点 L->next。若 q->data == x，则删除 q 结点（p->next = q->next，释放 q，q 指向 p->next，p 不动）；若 q->data != x，则 p 和 q 同时后移。q 为 NULL 时遍历结束。

**Q3**：

```c
void DeleteX(LinkList L, int x) {
    LNode *p = L;        // p指向头结点（待检查结点的前驱）
    LNode *q = L->next;  // q指向首元结点（待检查结点）
    
    while (q != NULL) {
        if (q->data == x) {
            // 删除q结点
            p->next = q->next;  // 前驱指向q的下一个结点
            free(q);            // 释放q的内存
            q = p->next;        // q指向下一个待检查结点
        } else {
            // 不删除，双指针后移
            p = q;
            q = q->next;
        }
    }
}
```

---

## 解析

### Q1（2分）：结点类型定义

带头结点单链表的结点包含数据域 `data`（int 类型）和指针域 `next`（指向同类型结点的指针）。`LinkList` 是 `LNode*` 的别名，用于表示头指针。

---

### Q2（4分）：算法基本思想

使用**双指针遍历法**。p 始终指向当前待检查结点的前驱，q 指向当前待检查结点。

1. **初始化**：p 指向头结点 L，q 指向首元结点 L->next。
2. **遍历过程**：
   - 若 `q->data == x`，则删除 q 结点：令 `p->next = q->next`，释放 q 的内存，q 指向 `p->next`（p 不动）；
   - 若 `q->data != x`，则 p 和 q 同时后移一位（`p = q; q = q->next`）。
3. **终止条件**：q 为 NULL 时遍历结束。
4. **头结点保护**：头结点 L 本身不参与比较，始终保留。

**关键点**：删除结点时 p 不动，仅 q 后移，这样可以正确处理连续匹配的情况（如 3→3→3 连续删除）。

---

### Q3（8分）：算法代码

**评分标准**：

| 代码行 | 作用 | 得分点 |
|--------|------|--------|
| `p = L; q = L->next` | 初始化双指针 | 1分 |
| `while (q != NULL)` | 遍历控制 | 1分 |
| `p->next = q->next` | 前驱绕过q | 2分 |
| `free(q)` | 释放内存 | 2分 |
| `q = p->next`（删除分支） | q指向下一待检查结点 | 1分 |
| `p = q; q = q->next`（不删除分支） | 双指针后移 | 1分 |
