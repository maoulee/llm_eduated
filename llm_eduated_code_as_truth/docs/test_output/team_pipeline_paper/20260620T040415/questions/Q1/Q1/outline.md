## 考点
- **顺序表的随机访问特性**：考查顺序表通过下标直接定位元素的 O(1) 访问能力
- **链表的顺序访问特性**：考查链表必须从头结点逐个遍历的 O(n) 访问方式
- **存储结构差异**：连续存储 vs 链式存储对访问方式的影响

## 难度目标
- **K1=4（较高）**：需精准辨析"随机访问"与"顺序访问"两个易混概念，以及顺序表/链表存储特性的对应关系
- **K2=1（微弱）**：纯概念辨析，无计算需求
- **K3=1（微弱）**：无需多步推演，直接基于概念判断
- **K4=3（标准）**：存在陷阱词（如"随机访问"的准确定义），不触发概念辨析就会选错
- **K5=1（微弱）**：单一知识点（线性表存储结构）内部解决

## 考察模式
**概念辨析型——存储结构与随机访问特性**

理由：
- 该题位（Q1）为概念辨析题，考查对顺序表与链表存储特性的理解
- 核心考察点：顺序表支持随机访问（O(1)），链表不支持随机访问（O(n)）
- 典型陷阱：混淆"随机访问"与"随机存取"、误认为链表也能通过某种方式实现随机访问
