## 题目
# 题目

设模式串 $s =$ "ababab"，采用 KMP 算法，next 数组的定义为：next[0] = 0，对于 $j > 0$，next[j] 表示子串 $s[0..j-1]$ 的最长相等**真**前后缀的长度（真前后缀指不等于串本身的前后缀）。

则 next[5] 的值为（ ）。

A. 正确结果
B. 混淆 next 与 nextval 数组产生的错误值
C. 前后缀长度算错 1（即 next[5] - 1）产生的错误值
D. 忘记"真前后缀"约束（将 "ababa" 本身当作相等前后缀）产生的错误值

---

## 设计意图

- **考察知识点**：KMP 算法中 next 数组的构造规则，特别是"真前后缀"概念的理解
- **考察目标**：学生能否正确理解 next 数组定义中"真前后缀"的含义，并逐位计算 next 值
- **难度控制**：模式串 "ababab" 具有周期性结构，next[5] 的计算需要比较 "ababa" 的所有真前后缀，非平凡但路径唯一

---

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **next[5] 可计算且 ≥ 2**：模式串 "ababab" 在位置 5 的 next 值通过标准算法可唯一确定，且结果非平凡（≥ 2）。
2. **4 选项互异**：A/B/C/D 四个选项的计算结果各不相同，无碰撞。
3. **正确值唯一确定**：在给定 next 数组定义（next[0]=0，真前后缀）下，next[5] 有且仅有一个确定值，A = 该值。
4. **干扰项对应声明错误类型**：
   - B = 按 nextval 数组规则计算 next[5] 得到的值（next 与 nextval 混淆）
   - C = next[5] - 1 = 2（前后缀长度算错 1）
   - D = 5（忘记"真前后缀"约束，将 "ababa" 本身当作相等前后缀，取其长度 5）
5. **干扰项有合理性**：B/C/D 均为 KMP 算法学习中常见误算的真实产物，具有区分度。


## 求解过程
# 解析

## 一、计算 next 数组

模式串 $s =$ "ababab"，长度为 6。

按定义逐位计算 next 数组：

| $j$ | 子串 $s[0..j-1]$ | 真前后缀比较 | next[j] |
|-----|-------------------|-------------|---------|
| 0 | — | 定义 | 0 |
| 1 | "a" | 无真前后缀（长度 < 1） | 0 |
| 2 | "ab" | "a" ≠ "b" | 0 |
| 3 | "aba" | "a" = "a" ✓，"ab" ≠ "ba" | 1 |
| 4 | "abab" | "a" ≠ "b"，"ab" = "ab" ✓，"aba" ≠ "bab" | 2 |
| 5 | "ababa" | "a" = "a" ✓，"ab" ≠ "ba"，"aba" = "aba" ✓，"abab" ≠ "baba" | 3 |

**next 数组 = [0, 0, 0, 1, 2, 3]**

## 二、计算 nextval 数组（用于干扰项 B）

按 nextval 优化规则逐位计算：

| $j$ | $s[j]$ | $s[\text{next}[j]]$ | 是否相等 | nextval[j] |
|-----|---------|---------------------|---------|------------|
| 0 | — | — | — | 0 |
| 1 | 'b' | $s[0]$='a' | 否 | next[1] = 0 |
| 2 | 'a' | $s[0]$='a' | 是 | nextval[0] = 0 |
| 3 | 'b' | $s[1]$='b' | 是 | nextval[1] = 0 |
| 4 | 'a' | $s[2]$='a' | 是 | nextval[2] = 0 |
| 5 | 'b' | $s[3]$='b' | 是 | nextval[3] = 0 |

**nextval 数组 = [0, 0, 0, 0, 0, 0]**

## 三、各选项值

- **A（正确答案）**：next[5] = **3**
  - 子串 $s[0..4]$ = "ababa"，最长相等真前后缀为 "aba"，长度为 3。

- **B（混淆 next 与 nextval）**：nextval[5] = **0**
  - 误用 nextval 数组代替 next 数组。

- **C（前后缀长度算错 1）**：next[5] - 1 = 3 - 1 = **2**
  - 正确值为 3，但少算了 1。

- **D（忘记"真前后缀"约束）**：len("ababa") = **5**
  - 将子串 "ababa" 本身当作相等前后缀，取其全长 5，忽略了"真前后缀"要求前后缀长度必须小于串本身长度。

## 四、答案

**正确答案：A. 3**
