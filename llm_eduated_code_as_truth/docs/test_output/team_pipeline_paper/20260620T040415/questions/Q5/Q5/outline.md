## 考点
- **二叉树叶子结点数与度为2结点数的关系**（n0 = n2 + 1）——核心考察点，必须准确记忆并应用
- **二叉树结点总数公式**（n = n0 + n1 + n2）——辅助工具，与核心公式联立求解
- **完全二叉树性质**（可选）——n1 只能为 0 或 1，作为附加条件增加约束

## 难度目标
- **K1=2（较低）**：需要二叉树基本概念（度、叶子结点、总结点数），但概念清晰、无混淆风险
- **K2=3（标准）**：需联立两个公式（n0=n2+1 与 n=n0+n1+n2）代入计算，涉及非2幂次整数运算
- **K3=2（较低）**：仅需2步推导（代入→求解），路径唯一
- **K4=2（较低）**：存在常规注意点（如完全二叉树时 n1 的取值限制），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他系统

## 考察模式
**计算型——二叉树性质应用**（经典模式）
- 给出二叉树的部分结点信息（总结点数、某类结点数等）
- 要求利用 n0 = n2 + 1 等性质推算叶子结点数
- 参考历史经验：这是数据结构二叉树章节最稳定的考察模式，历年高频出现

## 出题要求
- **题型**：单选题（4选项，1正确3干扰）
- **总条件数**：2-3个显式条件（如总结点数、度为1的结点数、或完全二叉树标识）
- **条件设计原则**：
  - 条件必须足以唯一确定答案（联立方程有唯一解）
  - 避免条件冗余或不足
  - 可引入"完全二叉树"作为附加约束（此时 n1 ∈ {0, 1}）
- **参数取值范围要求**：
  - 总结点数 n：建议在 20-100 之间，避免过小（退化）或过大（计算负担）
  - n1（度为1的结点数）：0、1 或小整数（≤5）
  - n2（度为2的结点数）：由 n 和 n1 推导，需保证 n0 = n2 + 1 成立
  - 确保 n0、n1、n2 均为非负整数

## 子问题规划
本题为单选题，无子问题结构。

## 参数约束
- **n（总结点数）**：20 ≤ n ≤ 100，整数
- **n1（度为1的结点数）**：0 ≤ n1 ≤ 5，整数；若题干声明"完全二叉树"，则 n1 ∈ {0, 1}
- **n2（度为2的结点数）**：由 n 和 n1 通过 n = n0 + n1 + n2 与 n0 = n2 + 1 联立确定
- **一致性约束**：
  - n0 = n2 + 1（核心公式）
  - n = n0 + n1 + n2（结点总数）
  - 联立得：n = (n2 + 1) + n1 + n2 = 2·n2 + n1 + 1
  - 因此 n - n1 - 1 必须为偶数（即 n 与 n1 奇偶性不同）
- **可调自由度**：给定 n 和 n1 后，n2 和 n0 唯一确定；或给定 n 和 n2 后，n0 和 n1 可推导

## 参考经验
- **考察模式**：二叉树性质计算题是数据结构最经典题型之一，考察 n0 = n2 + 1 的应用
- **难度锚点**：K2 为主导维度（公式代入计算），K1-K5 分布与 slot 中 k_radar 一致
- **典型陷阱**：
  1. 记错公式：n0 = n2（漏掉+1）→ 产生错误答案
  2. 符号错误：n0 = n2 - 1 → 产生错误答案
  3. 忽略 n1：直接用 n - n2 计算 n0 → 产生错误答案
  4. 完全二叉树时 n1 取值错误（取非0/1值）
