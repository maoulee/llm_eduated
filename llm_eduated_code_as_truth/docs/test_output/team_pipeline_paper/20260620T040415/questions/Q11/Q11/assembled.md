## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树遍历
- primary_target_name: 给后序+中序还原二叉树写出先序序列
- question_type: comprehensive
- examination_mode: 推演型——遍历序列还原二叉树

### 难度目标
- k_target: K1=1,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 需多步递归推导还原二叉树结构，机制推演为主（K3=4），基础概念熟悉即可入题（K1=1），无复杂计算（K2=2），规则明确无隐藏陷阱（K4=2），纯数据结构内部问题（K5=1）

### 结构要求
- sub_question_count: 2
- sub_question_details:
  - q1: 类型=推演/作图, 考察目标=还原二叉树结构, 分值=6
  - q2: 类型=计算/输出, 考察目标=写出先序遍历序列, 分值=4
- dependency: 串行（q2依赖q1的还原结果）
- condition_count: 2（后序遍历序列、中序遍历序列）

### 参数约束
- 节点数 N: 5 ≤ N ≤ 11，建议 7~9
- 节点值: 连续大写字母 A, B, C, ...（N个），无大小/顺序含义
- 树深度: ≥ 3层
- 子树约束: 左右子树均非空
- 结构约束: 非完全二叉树，避免推演退化
- 序列一致性: 后序和中序必须来自同一棵二叉树，且该树唯一确定
- 序列格式: 空格分隔的字母串

### 参考经验摘要
- 历史模式: 给两种遍历序列→还原树→写第三种序列（2026_Q3, 2012_Q3）
- 难度锚点: K3=4为该题位典型值，历史节点数多在6~10之间
- 典型陷阱: 后序根节点定位错误（取第一个而非最后一个）、中序划分遗漏根节点、递归边界错误、先序输出顺序错误
