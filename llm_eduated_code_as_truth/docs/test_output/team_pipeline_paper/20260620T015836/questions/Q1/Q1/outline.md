## 考点
- **顺序表的随机访问特性**：顺序表基于连续存储，支持 O(1) 时间随机访问第 i 个元素
- **链表的顺序访问特性**：链表基于离散存储，访问第 i 个元素需 O(n) 时间
- **存储结构对比**：连续存储 vs 链式存储对访问方式、插入删除效率、空间利用率的影响
- **辨析侧重点**：需精准区分"随机访问"与"顺序访问"的概念边界，理解存储结构决定访问方式的因果关系

## 难度目标
- **K1=4（较高）**：需精准辨析顺序表与链表的存储特性差异，涉及"随机访问""顺序存取""存储密度"等极易混淆的概念，属于概念辨析型
- **K2=1（微弱）**：几乎无计算，纯概念判断
- **K3=1（微弱）**：无需多步推演，直接概念辨析即得答案
- **K4=3（标准）**：需识别常见陷阱，如混淆"随机访问"与"随机存取存储器（RAM）"的概念、将链表的"随机插入删除"误认为"随机访问"
- **K5=1（微弱）**：单一知识点内部解决，不涉及跨系统联动

## 考察模式
**概念辨析型——存储结构与随机访问特性**

选择理由：本题考查的是顺序表与链表在存储结构上的本质差异及其对访问方式的决定作用，属于典型的概念辨析题型。slot 数据中 examination_mode 已锚定为该模式，且 concept_topics 中包含多个类似的概念辨析题目（如B树与B+树结构差异、Floyd与Dijkstra适用范围对比），说明该题位适合用"给出若干关于存储特性的论断，要求判断正确/错误"的方式考查。

## 出题要求
- **题型**：单项选择题，4 选项 1 正确，分值 2 分
- **条件数**：1 个题干情境（描述一个涉及顺序表/链表访问特性的场景或给出若干论断）
- **条件设计原则**：
  - 题干应围绕"随机访问"这一核心概念展开
  - 可采用"下列关于顺序表/链表的说法中，正确/错误的是"的经典辨析形式
  - 各选项应覆盖不同的混淆维度（访问方式、存储密度、插入删除效率、空间分配方式）
- **参数取值范围**：本题以概念辨析为主，无可调数值参数
- **选项设计要求**：
  - 正确选项：准确描述顺序表支持随机访问（O(1)）而链表不支持的特性
  - 干扰选项须覆盖以下错误路径：
    1. 混淆"随机访问"与"随机存储器"的概念
    2. 颠倒顺序表与链表的访问特性
    3. 混淆访问时间复杂度（如声称链表也支持 O(1) 随机访问）

## 参考经验
- **考察模式**：概念辨析型是数据结构选择题的常见模式，通过"下列说法正确/错误的是"的形式考查对易混概念的辨析能力
- **难度锚点**：K1=4 对应需精准辨析易混概念，K4=3 对应存在明确陷阱词，符合 target_difficulty=2 的整体难度定位
- **典型陷阱**：
  - 将"链表支持随机插入删除"与"随机访问"混淆——插入删除的灵活性与访问方式是两个独立维度
  - 将"顺序表存储密度高"错误扩展为"顺序表各方面都更优"——忽视顺序表插入删除效率低的劣势
  - 混淆 RAM（随机存取存储器）的"随机存取"与数据结构的"随机访问"——前者是硬件层面，后者是逻辑层面
