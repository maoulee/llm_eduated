## 考点
- **核心知识点**：串的模式匹配 → KMP 算法 → next 数组构造
- **考察侧重点**：给定模式串，按 KMP 算法中 next 数组的递推构造规则，计算指定位置 j（j ≥ 2）的 next[j] 值
- **关联知识**：next 数组定义（next[j] = 模式串 P[1..j-1] 的最长相等前后缀长度 + 1）、前缀/后缀匹配概念

## 难度目标
| 维度 | 目标等级 | 达标理由 |
|------|---------|---------|
| K1 基础认知需求 | 2 | 需准确记忆 next 数组构造规则（递推公式），属于 408 基础名词定义，概念模糊则无法入题，但不需要辨析多个易混概念 |
| K2 单步代入需求 | 3 | 需代入 next 递推公式，对指定位置做单步计算，可能涉及非 2 的幂次的小整数运算和回溯比较 |
| K3 机制推演需求 | 2 | 求单个 next[j] 值需 2 步以内推导（找前缀匹配 → 回溯取值），路径唯一，步数少 |
| K4 条件路由需求 | 2 | 存在常规注意点：next 数组下标从 1 开始、next[1]=0 是固定约定，408 考生基本不会踩坑 |
| K5 跨域联动需求 | 1 | 单一知识点内部解决，不涉及其他子系统 |

## 考察模式
**计算型——next 数组求解**

理由：参考 2015 年第 8 题、2024 年第 6 题的历史经验，该题位的典型考察模式为：给定一个模式串，要求计算 next 数组中某一指定位的值。此模式直接测查学生对 next 数组递推构造规则的掌握程度，属于 K2 主导（单步代入计算），与 slot 中 k_dominant=K2 一致。

## 出题要求
- **题型**：单项选择题，4 选项，1 正确 3 干扰，分值 2 分
- **条件数**：2 个显式条件（模式串字符串 + 指定位置 j）
- **条件设计原则**：
  - 模式串长度 6–8 个字符，使用小写英文字母
  - 指定位置 j 应选在 3 ≤ j ≤ n 范围内（避免 next[1]=0 和 next[2]=1 的平凡情况）
  - 模式串需在前缀区域有部分重复结构，使 next[j] 值为非平凡结果（≥ 2）

## 子问题规划
选择题无子问题划分。单题单问。

## 参数约束
| 参数 | 取值范围 | 约束关系 |
|------|---------|---------|
| 模式串长度 n | 6 ≤ n ≤ 8 | 确保 next 数组有足够的非平凡位可供考察 |
| 指定位置 j | 3 ≤ j ≤ n | j=1 恒为 0，j=2 恒为 1，不具区分度 |
| 模式串字符集 | 小写英文字母 a–z | 统一字符集，避免歧义 |
| 前缀重复结构 | P[1..k] = P[j-k..j-1] 中 k ≥ 2 | 保证 next[j] = k+1 ≥ 3，使结果非平凡 |
| 正确选项值 | ≥ 3 | 避免正确答案为 0 或 1 的平凡情况 |

**干扰策略指导**：
- 干扰项 1：学生忘记 +1（即 next[j] = 最长相等前后缀长度，未加 1）→ 正确答案 - 1
- 干扰项 2：学生将 next 数组下标从 0 开始（off-by-one 错误）→ 正确答案 ± 1 的某个偏移
- 干扰项 3：学生取了 j+1 位的值或取了相邻位的值（位置混淆）

各干扰项必须产生不同的数值结果，确保四个选项互不重合。

## 参考经验
- **历史模式**：2015 Q8 和 2024 Q6 均为"给定模式串求 next 数组指定位"的计算型选择题，模式稳定
- **难度锚点**：历年该题位 K2 主导（K2=3），K1=2，K3=2，整体难度 2–3 级，与 slot 目标一致
- **典型陷阱**：
  1. next 数组下标从 1 开始还是从 0 开始（不同教材约定差异）
  2. next[j] 是否需要在最长相等前后缀长度基础上 +1
  3. 混淆 next 数组与改进的 nextval 数组
