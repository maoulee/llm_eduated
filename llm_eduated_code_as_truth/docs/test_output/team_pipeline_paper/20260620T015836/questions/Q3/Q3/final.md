## 题目
设有一个 7 行 5 列的二维数组 A[7][5]，按**列优先**方式存储，每个元素占用 4 个字节。已知元素 A[0][0] 的存储地址为 200，则元素 A[2][3] 的存储地址是（ ）。

A. 正确结果（按列优先公式计算）
B. 按行优先公式计算的结果
C. 下标起始约定混淆（误将 0 起始当作 1 起始，偏移量差 1 行/列）的结果
D. 行列维度代入颠倒（偏移公式中行数与列数互换）的结果


## 求解过程
### 第一步：确定列优先存储的地址公式

列优先存储中，元素 A[i][j] 的地址公式为：

$$Loc(A[i][j]) = base + (j \times rows + i) \times elem\_size$$

其中 j 是列下标，rows 是每列的元素个数（即行数），i 是行下标。

### 第二步：代入参数计算正确结果（选项 A）

目标元素 A[2][3]，即 i=2, j=3。

- 列优先偏移量：$j \times rows + i = 3 \times 7 + 2 = 23$
- 地址：$base + 23 \times 4 = 200 + 92 = 292$

**选项 A = 292**

### 第三步：计算各干扰项

**选项 B——行优先混淆：**

误用行优先公式 $base + (i \times cols + j) \times elem\_size$：

- 行优先偏移量：$i \times cols + j = 2 \times 5 + 3 = 13$
- 地址：$200 + 13 \times 4 = 200 + 52 = 252$

**选项 B = 252**（错误原因：混淆了行优先与列优先存储方式）

**选项 C——下标起始混淆：**

误将 0 起始当作 1 起始，行号多算 1，偏移量用 $i+1$ 替代 $i$：

- 错误偏移量：$j \times rows + (i+1) = 3 \times 7 + 3 = 24$
- 地址：$200 + 24 \times 4 = 200 + 96 = 296$

**选项 C = 296**（错误原因：下标起始约定混淆，偏移量差 1 行）

**选项 D——行列维度代入颠倒：**

列优先公式中行数与列数互换，误用 $base + (j \times cols + i) \times elem\_size$：

- 颠倒偏移量：$j \times cols + i = 3 \times 5 + 2 = 17$
- 地址：$200 + 17 \times 4 = 200 + 68 = 268$

**选项 D = 268**（错误原因：偏移公式中 rows 与 cols 互换）
