# 二维数组列优先存储的地址计算

## 题干

设有一个 7 行 5 列的二维数组 A[7][5]，按**列优先**方式存储，每个元素占用 4 个字节。已知元素 A[0][0] 的存储地址为 200，则元素 A[2][3] 的存储地址是（ ）。

A. 正确结果（按列优先公式计算）
B. 按行优先公式计算的结果
C. 下标起始约定混淆（误将 0 起始当作 1 起始，偏移量差 1 行/列）的结果
D. 行列维度代入颠倒（偏移公式中行数与列数互换）的结果

## 条件清单

| 编号 | 条件 | 值 |
|------|------|-----|
| 1 | 数组行数 rows | 7 |
| 2 | 数组列数 cols | 5 |
| 3 | 基地址 base（A[0][0] 的地址） | 200 |
| 4 | 每个元素大小 elem_size | 4 字节 |
| 5 | 下标起始约定 | 0 起始（C 语言风格，下标从 0 开始） |

## 目标元素

A[2][3]（第 2 行第 3 列，下标从 0 起始）。

## 考察意图

- **知识点**：二维数组列优先存储的地址计算公式。
- **考察模式**：计算型——地址公式应用。
- **K 目标**：K1=2（列优先公式定义）、K2=3（非 2 幂次乘法代入计算）、K3=2（线性逻辑步骤）、K4=2（行优先/列优先区分、下标起始约定为常规注意点）。

## 选项设计（只设计考什么错误，不写数值）

| 选项 | 设计意图 |
|------|---------|
| A | 正确结果：按列优先公式 $Loc(A[i][j]) = base + (j \times rows + i) \times elem\_size$ 计算。 |
| B | 干扰项——行优先混淆：误用行优先公式 $base + (i \times cols + j) \times elem\_size$（最高频错误路径）。 |
| C | 干扰项——下标起始混淆：误将 0 起起始当作 1 起始，导致行号或列号偏移量差 1（即在偏移量中用 $i+1$ 或 $j+1$ 替代 $i$ 或 $j$）。 |
| D | 干扰项——行列维度代入颠倒：偏移公式中行数 rows 与列数 cols 互换（即列优先公式误写为 $base + (j \times cols + i) \times elem\_size$）。 |

## 通过条件（成功判据，可机检）

1. **4 选项互异**：A/B/C/D 四个值各不相同（exec 算出后无碰撞）。
2. **正确值唯一确定**：题干在给定参数下只有一个确定答案，A=该值；不存在"两个选项都对"的歧义。
3. **干扰项对应声明错误类型**：
   - B 的值 = 用行优先公式算出的结果；
   - C 的值 = 用下标偏移差 1 算出的结果（至少一个方向）；
   - D 的值 = 用行列互换公式算出的结果。
4. **干扰项有合理性**：每个干扰项是同类题常见误算的真实产物，非荒谬值。
5. **选项间距**：任意两个选项值之差的绝对值 ≥ elem_size（=4），确保选项不重合。
6. **偏移量非平凡**：目标元素 A[2][3] 的偏移量 > 0，且行优先与列优先结果不同（保证 B 有区分度）。
