# 题目

## 题干

一棵有 $n = 11$ 个结点的二叉树 $T$，已知其中度为 1 的结点数 $n_1 = 4$。求该二叉树的叶子结点数 $n_0$。

> 提示：利用二叉树的性质 $n_0 = n_2 + 1$ 及结点总数恒等式 $n = n_0 + n_1 + n_2$ 进行推导。

## 选项

- **A.** 正确结果（正确运用 $n_0 = n_2 + 1$ 与 $n = n_0 + n_1 + n_2$ 求出的叶子结点数）
- **B.** 混淆 $n_0$ 与 $n_2$：正确求出 $n_2$ 后忘记 $+1$，直接选了 $n_2$ 的值
- **C.** 度数公式系数错误：将 $n - 1 = n_1 + 2n_2$ 误用为 $n - 1 = n_1 + n_2$，导致 $n_2$ 偏大，进而 $n_0$ 偏大
- **D.** 公式记忆偏差：将 $n_0 = n_2 + 1$ 记成 $n_0 = n_2 - 1$，导致结果偏小

## 参数表

| 参数 | 值 | 说明 |
|------|----|------|
| $n$（总结点数） | 11 | 正整数，$\in [10, 100]$，非 2 的幂次 |
| $n_1$（度为 1 的结点数） | 4 | 非负整数，$n_1 < n$ |
| 奇偶约束 | $n - n_1 = 11 - 4 = 7$ 为奇数 | 保证 $n_2 = (n - n_1 - 1)/2$ 为整数 |
| $n_2$（度为 2 的结点数） | 由公式求出 | $n_2 = (n - n_1 - 1)/2$ |
| $n_0$（叶子结点数） | 由公式求出 | $n_0 = n_2 + 1$ |
| 验证恒等式 | $n_0 + n_1 + n_2 = n$ | 须成立 |

## 考察意图

- **考点**：二叉树叶子结点数与度为 2 结点数的关系（$n_0 = n_2 + 1$）的应用。
- **考察模式**：计算型——给定 $n$ 和 $n_1$，联立性质公式与结点总数恒等式求 $n_0$。
- **难度定位**：K2 主导（标准公式代入计算），K3 辅助（两步联立推导 $n_2 \to n_0$）。

## 通过条件（成功判据·可机检）

以下条件全部满足时本题成立（由 gen.py exec + assert 把关）：

1. **参数合法性**：$n - n_1$ 为奇数，$n_2 = (n - n_1 - 1)/2$ 为非负整数，$n_0 = n_2 + 1 \geq 1$，且 $n_0 + n_1 + n_2 = n$ 恒等式成立。
2. **4 选项互异**：A/B/C/D 四个数值各不相同，无碰撞。
3. **正确值唯一确定**：在给定参数下 $n_0$ 有唯一确定值，A = 该值；不存在"两个选项都对"的歧义。
4. **干扰项对应声明错误类型**：
   - B = 正确的 $n_2$ 值（忘记 $+1$）
   - C = 误用 $n - 1 = n_1 + n_2$ 后求出的 $n_0$（系数漏乘 2 导致偏大）
   - D = $n_2 - 1$（公式方向记反导致偏小）
   - 各干扰项等于"学生犯该错误时实际会得到的值"。
5. **干扰项有合理性**：每个干扰项为同类题常见误算的真实产物，非荒谬值。
