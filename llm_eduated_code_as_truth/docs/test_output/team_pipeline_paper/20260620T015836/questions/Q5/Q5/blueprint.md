## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树性质
- primary_target_name: 二叉树叶子结点数与度为2结点数的关系应用
- question_type: single_choice
- examination_mode: 计算型——二叉树性质应用

### 难度目标
- k_target: K1=2,K2=3,K3=2,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 需代入二叉树结点数公式计算，轻量启发式估算。K2为主导（标准单步代入计算），K3为辅助（2步以内联立推导），整体定位为中等偏易的标准选择题

### 结构要求
- option_count: 4（1正确 + 3干扰）
- distractor_strategy: |
    干扰项1——混淆 n₀ 与 n₂：学生直接算出 n₂ 后忘记 +1，选了 n₂ 的值
    干扰项2——度数公式系数错误：将 n - 1 = n₁ + 2n₂ 误用为 n - 1 = n₁ + n₂，导致 n₂ 偏大
    干扰项3——公式记忆偏差：将 n₀ = n₂ + 1 记成 n₀ = n₂ - 1，导致结果偏小
    要求：各干扰项对应不同错误路径，产生不同数值结果，确保区分度
- condition_count: 2

### 参数约束
- n（总结点数）: 正整数，取值范围 10–100，建议非2的幂次
- n₁（度为1的结点数）: 非负整数，须满足 n₁ < n
- 奇偶约束: n - n₁ 须为奇数（保证 n₂ = (n - n₁ - 1) / 2 为整数）
- 正整数约束: n₂ = (n - n₁ - 1) / 2 ≥ 0，n₀ = n₂ + 1 ≥ 1
- 验证恒等式: n₀ + n₁ + n₂ = n

### 参考经验摘要
- 历史模式: 数据结构选择题考查二叉树性质以计算型为主，给出 n 和 n₁ 求 n₀ 是经典考法
- 难度锚点: K2=3 为主导维度，标准公式代入计算，非2幂次整数运算
- 典型陷阱: 混淆 n₀ 与 n₂（最常见错误，忘记 +1）；度数公式 n₁ 系数漏乘2
