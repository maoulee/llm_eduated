# 解析

## 题目

一棵有 $n = 11$ 个结点的二叉树 $T$，已知 $n_1 = 4$，求叶子结点数 $n_0$。

## 求解过程

### 第一步：列出两个基本关系

$$n = n_0 + n_1 + n_2 \quad \text{（结点总数恒等式）}$$

$$n_0 = n_2 + 1 \quad \text{（二叉树性质）}$$

### 第二步：求 $n_2$

将 $n_0 = n_2 + 1$ 代入恒等式：

$$n = (n_2 + 1) + n_1 + n_2 = 2n_2 + n_1 + 1$$

解出：

$$n_2 = \frac{n - n_1 - 1}{2} = \frac{11 - 4 - 1}{2} = \frac{6}{2} = 3$$

### 第三步：求 $n_0$

$$n_0 = n_2 + 1 = 3 + 1 = 4$$

### 验证

$$n_0 + n_1 + n_2 = 4 + 4 + 3 = 11 = n \quad \checkmark$$

## 答案

**A. $n_0 = 4$**

## 干扰项分析

| 选项 | 值 | 错误类型 |
|------|----|----------|
| **A** | **4** | ✅ 正确答案 |
| **B** | 3 | 混淆 $n_0$ 与 $n_2$：正确求出 $n_2 = 3$ 后忘记 $+1$，直接取了 $n_2$ 的值 |
| **C** | 7 | 度数公式系数错误：将 $n - 1 = n_1 + 2n_2$ 误用为 $n - 1 = n_1 + n_2$，得 $n_2' = 11 - 1 - 4 = 6$，再 $n_0' = 6 + 1 = 7$ |
| **D** | 2 | 公式方向记反：将 $n_0 = n_2 + 1$ 记成 $n_0 = n_2 - 1 = 3 - 1 = 2$ |
