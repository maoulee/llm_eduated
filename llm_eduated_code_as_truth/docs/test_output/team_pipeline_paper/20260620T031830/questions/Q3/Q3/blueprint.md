## 考点
- **二维数组列优先存储的地址计算**：核心考点，考察列优先存储方式下元素地址的公式应用
- **数组存储基础概念**：基地址、元素大小、行列维度的含义

## 难度目标
- **K1=2（较低）**：需要掌握二维数组存储的基本概念（基地址、元素大小、行列维度），但概念清晰即可入题
- **K2=3（标准）**：需代入列优先地址公式进行计算，可能涉及非2的幂次运算，计算量适中
- **K3=2（较低）**：仅需1-2步推导（确定公式→代入计算），路径唯一
- **K4=2（较低）**：存在常规注意点（列优先vs行优先的区别），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他系统

## 考察模式
**计算型——地址公式应用**：给定二维数组的维度、基地址、元素大小，要求按列优先存储方式计算指定元素的存储地址。这是该题位的经典考察模式，直接考查公式记忆与代入能力。

## 出题要求
- **题型**：单选题（4选项）
- **总条件数**：3-4个显式条件（数组维度、基地址、元素大小、目标元素下标）
- **条件设计原则**：条件清晰无歧义，直接给出计算所需的全部参数
- **参数取值范围要求**：
  - 数组维度：行数M和列数N，建议M,N∈[3,10]，避免过大导致计算繁琐
  - 基地址：建议为2的幂次或整百数，便于计算
  - 元素大小：建议为常见类型大小（2/4/8字节）
  - 目标元素下标：(i,j)，建议i,j∈[0, M-1]×[0, N-1]，避免边界值

## 子问题规划
本题为单选题，无子问题结构。

## 参数约束
- **行数M**：取值范围[3,10]，整数
- **列数N**：取值范围[3,10]，整数，与M无强约束关系
- **基地址Base**：取值范围[1000,10000]，建议为整百数或2的幂次
- **元素大小L**：取值{2,4,8}，对应常见数据类型
- **目标行下标i**：取值范围[0, M-1]，建议非0非M-1
- **目标列下标j**：取值范围[0, N-1]，建议非0非N-1
- **一致性约束**：目标下标(i,j)必须在数组有效范围内

## 参考经验
- **历史模式**：该题位经典考察模式为直接公式代入，考查列优先地址公式 Loc(i,j) = Base + (j×M + i)×L
- **难度锚点**：K2=3为标准难度，计算量适中，不涉及复杂换算
- **典型陷阱**：
  1. 行优先与列优先公式混淆（行优先：i×N+j；列优先：j×M+i）
  2. 行列下标颠倒（将(i,j)误认为(j,i)）
  3. 起始地址计算错误（忘记基地址或元素大小）
