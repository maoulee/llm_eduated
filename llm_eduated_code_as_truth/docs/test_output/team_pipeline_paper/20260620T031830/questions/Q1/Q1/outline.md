## 考点
- **顺序表的随机访问特性**：通过下标直接定位元素，时间复杂度 O(1)
- **链表的顺序访问特性**：必须从头结点开始逐个遍历，时间复杂度 O(n)
- **存储结构差异**：顺序表连续存储 vs 链表离散存储+指针链接
- **考察侧重点**：精准辨析"随机访问"概念，理解其背后的存储结构原因

## 难度目标
- **K1=4（较高）**：需精准辨析"随机访问"与"顺序访问"两个易混概念，理解其存储结构根源
- **K2=1（微弱）**：纯概念辨析，无计算需求
- **K3=1（微弱）**：无需多步推演，直接概念判断
- **K4=3（标准）**：选项中存在"一定""所有"等陷阱词，需仔细辨析表述准确性
- **K5=1（微弱）**：单知识点（线性表存储特性），不涉及多知识点综合
- **整体难度：2**——概念辨析题，考查基础但需精准理解
