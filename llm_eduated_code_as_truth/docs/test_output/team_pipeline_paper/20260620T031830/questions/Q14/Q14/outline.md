## 考点
- **直接插入排序**：考察每趟排序过程的手工模拟，重点在于理解"将当前元素插入到已排序序列的正确位置"的机制
- **冒泡排序**：考察每趟排序过程的手工模拟，重点在于理解"相邻元素比较交换、每趟将最大元素冒泡到末尾"的机制
- **两种算法对比**：考察时间复杂度、稳定性、适用场景的差异分析

## 难度目标
- **K1=1（微弱）**：排序算法是数据结构基础概念，学生普遍熟悉，无需精准记忆冷门细节即可入题
- **K2=2（较低）**：无复杂计算，仅需比较和交换操作，数字友好
- **K3=4（较高）**：需手动模拟两种排序的多趟过程，每趟需维持动态状态更新，推演步数>5步，中间错一步后续全错
- **K4=2（较低）**：存在常规注意点（如直接插入排序的"已排序区间"边界、冒泡排序的"趟数"定义），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及跨模块联动

## 考察模式
**推演型——排序过程手工模拟与对比**

参考历史经验（2010_Q11、2020_Q11）：
- 历年该题位固定考察"给定序列→手工模拟排序过程→写出每趟结果"
- 2010年考察直接插入排序+希尔排序对比
- 2020年考察直接插入排序+快速排序对比
- 本次考察直接插入排序+冒泡排序对比，延续"两种排序算法过程模拟+对比"的经典模式

## 出题要求
- **题型**：综合题，10分
- **子问题数**：3问（插入排序模拟 + 冒泡排序模拟 + 对比分析）
- **条件设计原则**：
  - 题干仅给出一个待排序关键字序列
  - 序列长度适中（6-10个元素），保证推演量足够但不致繁琐
  - 序列应有一定无序度，避免过于有序或逆序导致某算法退化
  - 可包含重复元素以考察稳定性（可选）
- **参数取值范围**：
  - 序列长度：6-10个元素
  - 元素值：1-100范围内的整数
  - 初始有序度：部分有序（非完全有序/逆序）

## 子问题规划

### 第(1)问：直接插入排序（4分）
- **类型**：推演计算
- **考察目标**：手工模拟直接插入排序的每一趟过程，写出每趟排序结果
- **分值**：4分（每趟结果约0.5-1分）
- **与前后问关系**：独立推演，与第(2)问并行

### 第(2)问：冒泡排序（4分）
- **类型**：推演计算
- **考察目标**：手工模拟冒泡排序的每一趟过程，写出每趟排序结果
- **分值**：4分（每趟结果约0.5-1分）
- **与前后问关系**：独立推演，与第(1)问并行

### 第(3)问：对比分析（2分）
- **类型**：分析
- **考察目标**：对比两种算法的时间复杂度、稳定性、适用场景
- **分值**：2分
- **与前后问关系**：基于前两问的推演结果进行总结分析

## 参数约束
- **序列长度 n**：6 ≤ n ≤ 10，保证两种算法的推演步数足够（直接插入约 n(n-1)/2 次比较，冒泡约 n 趟）
- **元素取值范围**：1-100 的整数，避免过大数字增加书写负担
- **初始有序度**：序列不应是完全有序或完全逆序，应呈现"部分有序"特征，使两种算法的推演过程都有区分度
- **重复元素**：可选包含1-2个重复元素，用于考察稳定性（若包含，需在对比分析中体现）
- **参数一致性**：同一序列用于两种排序，保证对比的公平性

## 参考经验
- **考察模式**：历年Q11/Q14题位固定为"排序过程模拟+对比"，延续此模式
- **难度锚点**：K3=4 是该题位的典型特征，多趟推演是核心考察点
- **典型陷阱**：
  - 直接插入排序：学生易混淆"已排序区间"的边界（从第2个元素开始插入）
  - 冒泡排序：学生易搞错"趟数"定义（n个元素需n-1趟）
  - 对比分析：学生易遗漏稳定性差异或适用场景的对比
