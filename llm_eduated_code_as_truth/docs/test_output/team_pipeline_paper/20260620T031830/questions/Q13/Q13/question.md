# 题目：拉链法散列表构造与 ASL 计算

## 题干

设散列表的表长 $m = 11$，散列函数为 $H(\text{key}) = \text{key} \bmod 11$，采用**拉链法**处理冲突（新元素插入到链表表头）。

给定关键字序列：$\{11, 22, 33, 1, 12, 2, 13, 24, 3, 14\}$

请按顺序将上述关键字插入散列表，并回答下列问题：

### （1）构造散列表（4分）

画出（或描述）最终散列表的结构，包括每个桶对应的链表内容。

### （2）计算查找成功平均查找长度 ASL_success（3分）

计算在上述散列表中查找成功时的平均查找长度 ASL_success。

### （3）计算查找失败平均查找长度 ASL_fail（3分）

计算在上述散列表中查找失败时的平均查找长度 ASL_fail。

---

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **关键字序列长度**：$n = 10$，表长 $m = 11$，装载因子 $\alpha = n/m < 1$。

2. **冲突数**：发生冲突的桶数为 4 个（在 design_card 约束 2-5 范围内）。

3. **链表长度分布不均匀**：包含长度为 2 和 3 的链，具体为 2 个长度 2 的链、2 个长度 3 的链、7 个空桶，保证 ASL 计算有区分度。

4. **ASL_success 计算正确**：$\text{ASL\_success} = \frac{1 \times 4 + 2 \times 4 + 3 \times 2}{10} = \frac{18}{10} = 1.8$，其中分母为关键字数 $n = 10$。

5. **ASL_fail 计算正确**：$\text{ASL\_fail} = \frac{1 \times 7 + 3 \times 2 + 4 \times 2}{11} = \frac{21}{11} \approx 1.91$，其中分母为表长 $m = 11$，查找失败时比较次数为链表长度 + 1。

6. **考察点覆盖**：
   - K1（基本概念）：拉链法散列表结构 ✓
   - K2（公式计算）：ASL_success 和 ASL_fail 公式代入计算 ✓
   - K3（流程执行）：按顺序插入关键字构造散列表 ✓
