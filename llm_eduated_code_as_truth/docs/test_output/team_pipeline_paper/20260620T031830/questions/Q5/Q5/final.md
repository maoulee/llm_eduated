## 题目
阅读以下 C 语言代码片段，当 `n = 128` 时，程序运行结束后变量 `sum` 的值为多少？

```c
int sum = 0;
for (int i = 1; i <= n; i *= 2) {
    sum += i;
}
```


## 选项
A. 127
B. 255
C. 256
D. 511


## 求解过程
# 解析

## 正确答案

**B. 255**

## 详细解析

### 循环执行过程

当 `n = 128` 时，循环 `for (int i = 1; i <= n; i *= 2)` 的执行过程如下：

| 轮次 | i 的值 | 是否满足 i <= 128 | sum 的值 |
|------|--------|-------------------|----------|
| 1    | 1      | 是                | 0 + 1 = 1 |
| 2    | 2      | 是                | 1 + 2 = 3 |
| 3    | 4      | 是                | 3 + 4 = 7 |
| 4    | 8      | 是                | 7 + 8 = 15 |
| 5    | 16     | 是                | 15 + 16 = 31 |
| 6    | 32     | 是                | 31 + 32 = 63 |
| 7    | 64     | 是                | 63 + 64 = 127 |
| 8    | 128    | 是                | 127 + 128 = 255 |
| —    | 256    | 否（256 > 128）   | 循环结束 |

循环共执行 **8 轮**，`i` 依次取值为 1, 2, 4, 8, 16, 32, 64, 128。

### 数学本质

`i` 的取值构成公比为 2 的等比数列：$1, 2, 4, 8, 16, 32, 64, 128$，即 $2^0, 2^1, 2^2, \ldots, 2^7$。

等比数列求和公式：
$$S = 2^0 + 2^1 + 2^2 + \cdots + 2^7 = \frac{2^8 - 1}{2 - 1} = 2^8 - 1 = 255$$

因此 `sum` 的最终值为 **255**。

## 干扰项分析

**A. 127（错误：误用 i < n）**

若将循环条件误记为 `i < n`（严格小于），则当 `i = 128` 时，`128 < 128` 为假，循环提前终止，少算最后一轮。此时 sum = 1 + 2 + 4 + ... + 64 = 127 = $2^7 - 1$。

**C. 511（错误：多算一轮）**

若误以为 `i` 会增长到 256 仍满足条件（如误将循环条件理解为 `i <= 2*n`），则会多算一轮 i = 256。此时 sum = 255 + 256 = 511 = $2^9 - 1$。

**D. 256（错误：误以为 sum = n × 2）**

若未理解循环的等比数列本质，误用简单乘法 `n × 2 = 128 × 2 = 256` 计算，会得到此错误结果。
