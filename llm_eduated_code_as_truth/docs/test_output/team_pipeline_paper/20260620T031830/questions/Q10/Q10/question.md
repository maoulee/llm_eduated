# 数据结构选择题 — 快速排序前两趟划分结果

## 基本信息
- **科目**: 数据结构
- **知识点**: DS-8 > 8.3 交换排序 > 快速排序
- **题型**: 选择题（single_choice）
- **难度**: 4（K2=3 为主导，需手动模拟多步 partition）

---

## 题干

设有初始序列：`[12, 5, 18, 3, 9, 7, 15, 2, 10, 4]`

采用**快速排序**对其进行排序，partition 规则如下：
- **基准选择**：每次取当前子序列的**第一个元素**作为基准（pivot）
- **双指针扫描**：设左指针 `i` 从子序列第二个元素开始向右扫描，右指针 `j` 从子序列最后一个元素开始向左扫描
  - `i` 向右移动，直到找到 **大于** 基准的元素
  - `j` 向左移动，直到找到 **小于** 基准的元素
  - 若 `i < j`，交换 `a[i]` 与 `a[j]`，然后继续扫描
  - 若 `i ≥ j`，扫描结束
- **基准归位**：扫描结束后，将基准元素与 `a[j]` 交换，此时基准到达其最终有序位置

**第一趟**对整个序列 `[0..9]` 执行 partition；**第二趟**对第一趟产生的**左侧子序列**（基准左侧部分）执行 partition。

问：经过前两趟 partition 后，序列的状态为（ ）。

---

## 选项设计（数值由 write_gen 计算填充）

| 选项 | 对应错误类型 |
|------|-------------|
| A | 正确结果（前两趟 partition 均正确执行） |
| B | 第一趟基准归位位置错误（如基准与 a[i] 而非 a[j] 交换） |
| C | 指针移动顺序错误（先移动右指针 j 再移动左指针 i，而非题干指定的先 i 后 j） |
| D | 第二趟划分范围错误（对右侧子序列而非左侧子序列执行 partition） |

---

## 设计意图

### 考察目标
- **K2（标准计算）**：手动模拟快速排序 partition 的双指针扫描与交换过程，多步计算
- **K1（概念理解）**：理解基准归位后左侧<基准、右侧>基准的分区性质
- **K3（路径唯一）**：在给定明确规则下，partition 过程有唯一确定结果
- **K4（细节辨析）**：区分指针移动顺序、基准归位方式、划分范围等关键细节

### 核心陷阱
1. **基准归位位置**：扫描结束后基准应与 `a[j]` 交换（而非 `a[i]`），j 是右指针最终位置
2. **指针移动顺序**：题干指定先移动 i 再移动 j，若顺序颠倒会导致不同交换序列
3. **第二趟范围**：第二趟应对第一趟基准**左侧**子序列执行 partition，而非右侧或整个序列

## 通过条件（成功判据·可机检）

本题成立 ⇔ 以下特征全部满足：

1. **第一趟 partition 可计算**：给定序列和规则，第一趟 partition 有唯一确定的结果序列
2. **第一趟分区性质成立**：第一趟后基准元素到达最终位置，其左侧所有元素 < 基准值，右侧所有元素 > 基准值
3. **第二趟 partition 可计算**：对第一趟产生的左侧子序列执行 partition，有唯一确定的结果
4. **第二趟分区性质成立**：第二趟后该子序列的基准到达其在该子序列中的最终位置，满足分区性质
5. **4 选项互异**：A/B/C/D 四个选项的序列值各不相同（exec 算出后无碰撞）
6. **正确值唯一确定**：在给定参数和规则下，A 对应唯一正确的两趟结果
7. **干扰项对应声明错误类型**：B/C/D 各自对应上述设计的错误类型（非随机扰动）
