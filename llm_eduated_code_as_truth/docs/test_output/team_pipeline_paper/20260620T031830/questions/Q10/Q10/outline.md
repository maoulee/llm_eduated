## 考点
- **快速排序 partition 过程**：考察基准元素选择、左右指针移动规则、元素交换时机
- **多趟递归划分**：考察第一趟划分后左右子序列的边界确定，以及第二趟对子序列的独立划分

## 难度目标
- **K1=2（较低）**：需知道快速排序 partition 的基本概念（基准、左右指针），但概念模糊也能顺着题干模拟
- **K2=3（标准）**：需按 partition 规则逐元素比较交换，涉及多步数值比较，非简单心算
- **K3=2（较低）**：前两趟划分路径唯一，按固定规则走即可，无需分支判断
- **K4=2（较低）**：存在常规注意点（如基准元素最终位置、子序列边界），408 考生基本不会踩坑
- **K5=1（微弱）**：纯排序算法内部问题，不涉及其他系统

## 考察模式
**计算型——快速排序过程模拟**（参考 simulation_00180.md）
- 给定初始序列，要求模拟前两趟 partition 结果
- 这是 408 数据结构排序题的经典考察模式
- 通过手动模拟检验对 partition 机制的理解深度

## 出题要求
- **题型**：单选题（4 选项）
- **条件数**：2 个显式条件（初始序列 + 基准选择规则）
- **条件设计原则**：
  - 初始序列长度适中（8-12 个元素），保证前两趟划分有足够区分度
  - 元素值互异，避免相等元素带来的歧义
  - 序列不应过于有序或逆序，保证 partition 不退化
- **参数取值范围**：
  - 序列长度：8-12 个元素
  - 元素值范围：1-20 的整数
  - 基准选择：明确指定（如"以第一个元素为基准"）

## 子问题规划
本题为单选题，无子问题。考察点集中在：
- 第一趟 partition 后基准元素的最终位置及左右子序列
- 第二趟对左子序列或右子序列的独立划分结果
- 两趟划分后的完整序列状态

## 参数约束
- **序列长度 n**：8 ≤ n ≤ 12，保证前两趟划分有足够元素可操作
- **元素值**：互异的正整数，范围 1-20
- **基准选择规则**：必须明确指定（首元素/尾元素/中间元素），不能模糊
- **一致性约束**：
  - 第一趟划分后，基准元素左侧全部 < 基准，右侧全部 > 基准
  - 第二趟划分范围必须是第一趟产生的某个子序列
  - 两趟划分结果必须与基准选择规则一致
- **可调自由度**：序列具体元素值、序列长度、基准选择方式均可调整

## 参考经验
- **历史模式**：simulation_00180.md 为快速排序过程模拟题，考察 partition 手动执行
- **难度锚点**：K2 为主导维度，K3 较低（路径唯一），符合 slot 中 k_radar 分布
- **典型陷阱**：
  - 基准元素最终位置判断错误
  - 左右指针移动顺序混淆（先左后右 vs 先右后左）
  - 第二趟划分范围搞错（对错误子序列划分）
  - 相等元素处理歧义（本题应避免）
