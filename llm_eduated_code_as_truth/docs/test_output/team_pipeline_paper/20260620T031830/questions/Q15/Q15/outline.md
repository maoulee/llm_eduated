## 考点
- **循环队列判满条件**：考察 (rear+1)%MAXSIZE == front 的理解，区分"少用一个存储单元"的判满策略
- **循环队列 rear 指针更新**：考察 rear = (rear+1)%MAXSIZE 的取模运算，确保循环特性
- **循环队列判空条件**：考察 front == rear 的理解
- **循环队列 front 指针更新**：考察 front = (front+1)%MAXSIZE 的取模运算
- **循环队列初始化**：考察 front = rear = 0 的初始状态设置

## 难度目标
- **K1=2（较低）**：需要循环队列基础名词（front/rear/MAXSIZE），但概念模糊也能顺着代码框架推断
- **K2=3（标准）**：需代入取模运算理解指针更新逻辑，涉及非平凡计算（取模而非简单+1）
- **K3=2（较低）**：代码逻辑路径唯一，2步以内推导（判断条件→执行更新）
- **K4=2（较低）**：存在常规注意点（判满条件易与判空混淆），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他数据结构
