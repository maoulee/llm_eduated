## 考点
- 二叉树的二叉链表存储结构：考察结点类型的定义（数据域+左右孩子指针）
- 二叉树遍历（前序遍历）：考察递归遍历框架在路径问题中的应用
- 路径保存与回溯：考察递归过程中路径的动态维护（压栈/弹栈）
- 叶子结点判定：考察左右孩子均为空的判定条件
- 递归算法设计：考察递归思想在树结构路径问题中的完整实现

## 难度目标
- K1=1: 微弱，二叉链表是数据结构基础概念，学生应熟练掌握，无需特殊记忆
- K2=2: 较低，主要是指针操作和递归调用，无复杂数值计算
- K3=2: 较低，递归逻辑清晰，路径保存（访问时压入）和回溯（返回时弹出）步骤明确
- K4=3: 标准，存在明确陷阱：递归回溯时必须弹出路径结点，遗漏会导致路径错误；叶子结点判定需同时检查左右孩子
- K5=4: 较高，需将遍历框架、路径数组维护、回溯操作三个模块联动，递归状态管理复杂

## 考察模式
算法设计型——二叉树遍历与路径算法设计

参考2014_Q41等历史算法设计题，采用"定义结构+描述思想+代码实现+复杂度分析"的四段式结构。这是408数据结构算法设计题的经典模式，重点考察递归算法的完整设计和实现能力。

## 出题要求
- 题型：综合题（算法设计）
- 总分：16分
- 题干形式：给出二叉链表存储的二叉树，要求设计算法输出所有叶子结点到根结点的路径
- 明确要求：定义结点类型、描述算法思想、写出C/C++代码并给出注释
- 参数要求：无需具体数值参数，重点考察算法正确性、完整性和代码规范性

## 子问题规划
1. 定义结点类型（2分）
   - 类型：定义
   - 考察目标：二叉链表结点结构的定义（数据域+左孩子指针+右孩子指针）
   - 与前后问关系：为后续算法提供数据结构基础

2. 描述算法思想（4分）
   - 类型：分析
   - 考察目标：递归遍历+路径保存+回溯的设计思想，需说明遍历方式、路径维护策略、叶子判定条件
   - 与前后问关系：指导代码实现，体现算法设计思路

3. 写出C/C++代码并给出注释（8分）
   - 类型：实现
   - 考察目标：完整、正确的递归算法实现，包括路径数组管理、递归调用、回溯操作
   - 与前后问关系：算法思想的具体实现，重点考察代码正确性

4. 分析算法复杂度（2分）
   - 类型：分析
   - 考察目标：时间复杂度（O(n)，每个结点访问一次）和空间复杂度（O(h)，h为树高，递归栈+路径数组）
   - 与前后问关系：算法质量评估，体现对算法效率的理解

## 参数约束
- 二叉树规模：节点数 n ≥ 1，算法应适用于任意规模的二叉树
- 路径表示：从根到叶子的结点序列，可用数组或栈保存，路径长度不超过树高
- 递归深度：与树高相关，最坏情况（单支树）O(n)，平均情况 O(log n)
- 叶子结点判定：左右孩子指针均为 NULL
- 路径输出顺序：从根结点到叶子结点（或从叶子到根，需在算法思想中明确）
- 路径数组大小：至少为树的最大深度，可动态分配或预设足够大小

## 参考经验
- 历史模式：2014_Q41等算法设计题采用四段式结构（定义+思想+代码+复杂度），总分15-16分
- 难度锚点：K5=4为跨域联动较高难度，需遍历、路径保存、回溯三模块联动，递归状态管理是核心难点
- 典型陷阱：
  1. 递归回溯时忘记弹出路径结点（最常见错误）
  2. 叶子结点判定只检查一个孩子为空（错误，需同时检查左右孩子）
  3. 路径输出顺序混淆（根到叶子 vs 叶子到根）
  4. 路径数组越界（未考虑树高限制）
  5. 递归终止条件错误（未正确处理空树）
