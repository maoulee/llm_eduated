## 题目
# 二叉树中所有**根结点到叶子结点**的路径

## 题目描述

设二叉树采用二叉链表存储，每个结点包含数据域 `data`、左孩子指针 `lchild` 和右孩子指针 `rchild`。请设计算法，求出二叉树中所有从根结点到叶子结点的路径。

### 子问题

**Q1（2 分）**：定义二叉链表结点类型 `BiTNode`。

**Q2（4 分）**：描述算法思想。要求说明如何遍历二叉树、如何保存路径、如何判定叶子结点、如何处理回溯。

**Q3（8 分）**：用 C/C++ 写出完整代码，并给出关键步骤注释。函数原型如下：

```c
void AllPaths(BiTree T);
```

其中 `BiTree` 为指向 `BiTNode` 的指针类型，`AllPaths` 函数负责输出所有从根到叶子的路径。

**Q4（2 分）**：分析算法的时间复杂度和空间复杂度，并简要说明理由。

---

## 参考答案

**Q1（2 分）**：

```c
typedef struct BiTNode {
    int data;              // 数据域
    struct BiTNode *lchild; // 左孩子指针
    struct BiTNode *rchild; // 右孩子指针
} BiTNode, *BiTree;
```

**Q2（4 分）**：算法采用递归前序遍历 + 回溯策略。从前序遍历出发，从根结点开始依次访问左子树和右子树；维护一个路径数组，每访问一个结点将其加入路径末尾；当结点的 `lchild` 和 `rchild` 均为 `NULL` 时判定为叶子结点，此时输出路径；递归返回时将当前结点从路径中弹出（路径长度减 1），保证后续路径不受影响。路径输出顺序为从根到叶子。

**Q3（8 分）**：

```c
#include <stdio.h>
#include <stdlib.h>

// 二叉链表结点定义
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild;
    struct BiTNode *rchild;
} BiTNode, *BiTree;

// 路径数组和当前路径长度（全局变量，也可改为参数传递）
int path[100];   // 存储当前路径上的结点值
int pathLen = 0; // 当前路径长度

/**
 * AllPaths: 输出二叉树中所有从根结点到叶子结点的路径
 * @param T 二叉树根结点指针
 */
void AllPaths(BiTree T) {
    if (T == NULL) {
        return;  // 空树，直接返回
    }

    // 将当前结点加入路径
    path[pathLen++] = T->data;

    // 叶子结点判定：左右孩子均为 NULL
    if (T->lchild == NULL && T->rchild == NULL) {
        // 输出当前路径（从根到叶子）
        for (int i = 0; i < pathLen; i++) {
            printf("%d", path[i]);
            if (i < pathLen - 1) {
                printf(" -> ");
            }
        }
        printf("\n");
    } else {
        // 非叶子结点：递归遍历左右子树
        AllPaths(T->lchild);
        AllPaths(T->rchild);
    }

    // 回溯：弹出当前结点，恢复路径状态
    pathLen--;
}
```

**Q4（2 分）**：
- **时间复杂度**：O(n × h)，其中 n 为结点总数，h 为树高。每个结点被访问一次，每次访问时路径数组最多有 h 个元素，输出路径时最多遍历 h 个元素。
- **空间复杂度**：O(h)，其中 h 为树高。递归栈的最大深度为树高 h，路径数组 `path` 的最大长度也为 h。

## 解析

### Q1 解析（2 分）

`BiTNode` 结构体包含三个成员——`data`（数据域）、`lchild`（左孩子指针）、`rchild`（右孩子指针），类型正确，满足通过条件 1。

---

### Q2 解析（4 分）

**算法采用递归前序遍历 + 回溯策略**，核心思路如下：

1. **遍历方式**：从前序遍历出发，从根结点开始，依次访问左子树和右子树。

2. **路径保存**：维护一个路径数组（或栈），每访问一个结点，将其加入路径末尾。

3. **叶子结点判定**：当结点的 `lchild` 和 `rchild` 均为 `NULL` 时，判定为叶子结点。此时路径数组中保存的即为一条完整的"根→叶子"路径，输出该路径。

4. **回溯处理**：递归返回时，将当前结点从路径中弹出（路径长度减 1），保证后续路径不受当前路径的影响。

5. **路径输出顺序**：从根到叶子，即路径数组中第一个元素为根结点，最后一个元素为叶子结点。

---

### Q3 解析（8 分）

**关键步骤注释说明**：
- `path[pathLen++] = T->data`：访问结点时，将其加入路径末尾。
- `T->lchild == NULL && T->rchild == NULL`：叶子结点判定条件，满足通过条件 3。
- 递归调用 `AllPaths(T->lchild)` 和 `AllPaths(T->rchild)`：分别遍历左右子树。
- `pathLen--`：回溯操作，递归返回时弹出当前结点，满足通过条件 4，保证路径之间无互相污染。

**验证结果**（以测试二叉树为例）：

```
      1
     / \
    2   3
   / \   \
  4   5   6
```

- 所有结点：[1, 2, 4, 5, 3, 6]，共 6 个
- 所有叶子：[4, 5, 6]，共 3 个
- 树高：3

算法输出 3 条路径：

| 路径编号 | 路径内容 |
|---------|---------|
| 路径 1 | 1 → 2 → 4 |
| 路径 2 | 1 → 2 → 5 |
| 路径 3 | 1 → 3 → 6 |

每条路径第一个结点均为根结点 1，最后一个结点均为叶子结点（4、5、6），满足通过条件 2、3、5。

---

### Q4 解析（2 分）

**时间复杂度：O(n × h)**
- **n** 为结点总数（本例中 n = 6）
- **h** 为树高（本例中 h = 3）
- **理由**：每个结点被访问一次，每次访问时路径数组最多有 h 个元素（从根到当前结点的深度），输出路径时最多遍历 h 个元素。因此总时间复杂度为 O(n × h)。

**空间复杂度：O(h)**
- **h** 为树高（本例中 h = 3）
- **理由**：递归栈的最大深度为树高 h；路径数组 `path` 的最大长度也为 h。因此空间复杂度为 O(h)。
