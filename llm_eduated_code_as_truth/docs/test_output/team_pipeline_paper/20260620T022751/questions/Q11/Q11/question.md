# 题目：由遍历序列还原二叉树并写出先序序列

## 题干

已知某二叉树的后序遍历序列为 `A C B F G E D`，中序遍历序列为 `A B C D E F G`。

### （1）还原二叉树结构（6分）

根据上述后序遍历序列与中序遍历序列，还原该二叉树的结构，并画出该二叉树（或清晰描述各节点的父子关系）。

### （2）写出先序遍历序列（4分）

基于第（1）问还原的二叉树，写出其先序遍历序列。

---

## 设计意图

- **考察知识点**：二叉树三种遍历（先序/中序/后序）的访问顺序规则；由两种遍历序列唯一还原二叉树的递归方法。
- **考察模式**：推演型——给定后序+中序两种序列，通过递归定位根节点、划分左右子树区间，逐步还原二叉树结构，再输出第三种遍历序列。
- **难度定位**：K3=4（机制推演为主），需多步递归推导（>5步），涉及区间边界处理与遍历顺序辨析。

## 参数说明

- 节点数 N = 7，标签为连续字母 A~G
- 树深度 = 4 层
- 左右子树不对称：左子树 3 节点（A,B,C），右子树 3 节点（E,F,G），结构不同
- 后序序列：`A C B F G E D`（最后元素 D 为根）
- 中序序列：`A B C D E F G`（D 划分左右子树区间）

## 通过条件（成功判据·可机检）

本题成立 ⇔ 以下特征全部满足：

1. **唯一还原**：给定的后序+中序序列对应唯一一棵二叉树，不存在多解歧义。
2. **一致性**：后序序列与中序序列对应同一棵二叉树（递归还原过程中每一步根节点定位与区间划分均自洽）。
3. **递归步数 > 5**：还原过程需要超过 5 步递归调用（满足 K3=4 的难度要求）。
4. **先序序列唯一确定**：还原出的二叉树有唯一的先序遍历序列，长度为 7，包含 A~G 各恰好一次。
5. **左右子树非空**：根节点的左子树和右子树均非空（保证递归推演有实质内容，非退化情况）。
