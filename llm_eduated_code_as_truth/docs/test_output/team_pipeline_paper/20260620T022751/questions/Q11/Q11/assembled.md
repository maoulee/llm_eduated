## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树遍历
- primary_target_name: 给后序+中序还原二叉树写出先序序列
- question_type: comprehensive
- examination_mode: 推演型——遍历序列还原二叉树

### 难度目标
- k_target: K1=1,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 需多步递归推导还原二叉树结构，机制推演为主（K3=4），轻量基础认知（K1=1），无复杂计算（K2=2），单一知识点内部解决（K5=1）

### 结构要求
- sub_question_count: 2
- sub_question_details:
  - q1: 类型=推演/作图, 考察目标=还原二叉树结构, 分值=6
  - q2: 类型=计算/输出, 考察目标=写出先序遍历序列, 分值=4
- dependency: 串行（q2依赖q1还原结果）
- condition_count: 2（后序序列 + 中序序列）

### 参数约束
- 节点数 N: 取值范围 6-8，需保证递归推演步数>5
- 节点标签: 建议使用连续字母（A-H）或连续数字（1-8）
- 树深度: 3-4层
- 后序序列: 长度=N，最后元素为根
- 中序序列: 长度=N，根元素划分左右子树区间
- 一致性: 后序与中序必须对应同一棵二叉树
- 分布要求: 左右子树不宜完全对称，应有一定不对称性

### 参考经验摘要
- 历史模式: 给两种遍历序列→还原结构→写第三种序列（2026_Q3, 2012_Q3）
- 难度锚点: K3=4为该题位典型定位，要求>5步递归推演
- 典型陷阱: 混淆遍历访问顺序、中序定位根错误、递归区间边界处理错误
