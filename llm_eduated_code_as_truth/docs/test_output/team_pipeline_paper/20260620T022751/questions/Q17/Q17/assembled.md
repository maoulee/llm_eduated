## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 线性表 > 单链表
- primary_target_name: 删除单链表中所有值为x的结点
- question_type: comprehensive
- examination_mode: 算法设计型——链表操作算法设计

### 难度目标
- k_target: K1=1,K2=2,K3=2,K4=3,K5=4
- difficulty_level: 4
- difficulty_rationale: 算法设计题，需自行设计完整算法（定义+思想+实现），跨域联动（K5=4）和条件路由（K4=3）为主导难度来源

### 结构要求
- sub_question_count: 1（单问综合题，三段式输出）
- segment_structure: 结点定义(2分) + 算法思想(4分) + 代码实现(8分)
- condition_count: 2-3（带头结点单链表L、待删除值x、可选的链表长度/类型说明）

### 参数约束
- 链表结构: 必须带头结点（head->next为第一个实际结点），算法需兼容空表（head->next==NULL）
- 数据域类型: int或通用类型均可，结点定义中data类型需与x的类型保持一致
- x的值: 不指定具体数值，算法需对任意x值通用
- 链表长度: 不指定具体值，但需暗示可能为空表、单结点、多结点情况
- 可调自由度: 数据域类型、链表初始长度、x的具体值由Question Agent自行选择

### 参考经验摘要
- 历史模式: 408数据结构算法题固定三段式（定义+思想+代码），14分分值分配为2+4+8
- 难度锚点: K5=4（跨域联动主导），K4=3（条件路由次之），K1=1/K2=2/K3=2（基础认知和计算需求低）
- 典型陷阱: 连续值为x的结点删除时指针更新顺序错误、头结点后首个结点为x的处理、删除后未free导致内存泄漏、算法思想与代码不一致
