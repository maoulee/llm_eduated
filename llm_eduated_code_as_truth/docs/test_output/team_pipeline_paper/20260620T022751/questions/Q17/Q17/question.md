# 删除单链表中所有值为 x 的结点

## 题干

已知一个带头结点的单链表 L，结点结构为 `data | next`，其中 `data` 为整型数据域，`next` 为指向后继结点的指针。请设计一个算法，删除链表中所有值为 x 的结点，并释放被删除结点所占用的内存空间。

要求：
1. 给出链表结点的类型定义（2分）；
2. 简述算法的基本思想（4分）；
3. 用 C/C++ 语言实现该算法（8分）。

算法需兼容以下边界情况：空表（仅含头结点）、所有结点值均为 x、连续多个结点值均为 x。

---

## 设计意图

- **考察知识点**：单链表的删除操作、前驱指针维护、内存释放、边界条件处理
- **考察模式**：算法设计型——需完整输出结点定义、算法思想、代码实现
- **难度来源**：
  - K5=4（跨域联动）：链表结构操作 + 内存管理 + 边界条件综合
  - K4=3（条件路由）：需处理多种边界情况（空表、首结点为x、连续x）
- **典型陷阱**：连续值为x的结点删除时指针更新顺序错误、头结点后首个结点为x的处理、删除后未free导致内存泄漏、算法思想与代码不一致
