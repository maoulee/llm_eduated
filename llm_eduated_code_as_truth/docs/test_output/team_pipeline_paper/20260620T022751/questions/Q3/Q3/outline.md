## 考点
- **二维数组列优先存储地址计算**：核心考察列优先存储的地址公式 `Loc(i,j) = base + (j × m + i) × L`，要求学生准确记忆公式结构并正确代入

## 难度目标
- **K1=2（较低）**：需知道列优先存储概念和地址公式，但概念直接，无易混概念辨析
- **K2=3（标准）**：核心是公式代入计算，涉及乘法加法组合，非2的幂次运算，有一定计算量
- **K3=2（较低）**：仅需一步公式代入，无多步推演
- **K4=2（较低）**：存在常规注意点（列优先 vs 行优先），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及跨域联动

## 考察模式
**计算型——地址公式直接应用**
- 给定二维数组维度(m×n)、基地址、元素大小L，要求计算某元素A[i][j]的存储地址
- 这是数据结构中数组存储的经典考察模式，历年高频出现
- 难度锚点：K2主导，通过非2的幂次参数制造计算区分度

## 出题要求
- **题型**：单选题（4选项）
- **分值**：2分
- **条件数**：4-5个显式条件（数组维度、基地址、元素大小、目标元素索引）
- **条件设计原则**：
  - 所有条件在题干中明确给出，无隐含条件
  - 参数取值使计算结果非平凡（非2的幂次友好）
  - 确保不同错误路径产生不同结果（区分度）
- **参数取值范围要求**：
  - 行数 m：5-15（非2的幂次，如7、9、11）
  - 列数 n：5-15（非2的幂次，如6、8、10）
  - 基地址 base：合理地址值（如 1000、2000）
  - 元素大小 L：2、4、8 字节（常见类型大小）
  - 目标行索引 i：0 ≤ i < m，取中间值
  - 目标列索引 j：0 ≤ j < n，取中间值

## 子问题规划
本题为单选题，无子问题结构。

## 参数约束
- **m（行数）**：取值范围 [5, 15]，建议非2的幂次（如7、9、11），与n无强约束
- **n（列数）**：取值范围 [5, 15]，建议非2的幂次（如6、8、10），与m无强约束
- **base（基地址）**：取值范围 [1000, 5000]，取整百数便于阅读
- **L（元素大小）**：取值 {2, 4, 8}，对应 short/int/long 类型
- **i（目标行索引）**：约束 0 ≤ i < m，建议取 m/3 到 2m/3 之间的值
- **j（目标列索引）**：约束 0 ≤ j < n，建议取 n/3 到 2n/3 之间的值
- **一致性约束**：
  - i 和 j 必须在合法范围内
  - 计算结果 `base + (j × m + i) × L` 应在合理地址范围内（< 65536）
  - 参数组合应使正确答案与干扰项有明显区分

## 参考经验
- **历史模式**：数组地址计算是数据结构经典题型，考察模式稳定
- **难度锚点**：K2=3 是标准难度，通过非2的幂次参数实现
- **典型陷阱**：
  1. 行优先公式误用：`base + (i × n + j) × L`（最常见错误）
  2. 行列索引颠倒：把 i 当列、j 当行
  3. 忘记乘以元素大小 L
  4. 列偏移计算错误：`j × n` 而非 `j × m`
