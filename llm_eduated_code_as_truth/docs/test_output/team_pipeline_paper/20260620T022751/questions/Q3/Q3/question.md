# 二维数组列优先存储的地址计算

## 设计意图

| 项目 | 内容 |
|------|------|
| 考察知识点 | 二维数组列优先存储的地址计算公式 |
| 难度定位 | K3（标准计算型） |
| 考察模式 | 计算型——地址公式应用 |
| 核心能力 | 掌握列优先存储的地址计算公式 `Address(A[i][j]) = base + (j × m + i) × L`，并能正确代入参数计算 |
| 干扰策略 | 行优先公式误用、行列索引颠倒、忘记乘元素大小、列偏移计算错误 |

## 题干

设二维数组 `A[5][6]` 采用**列优先**顺序存储，每个元素占用 `L = 4` 字节，基地址 `base = 1000`。已知 `A[1][2]` 的存储地址为 `1044`，求 `A[2][3]` 的存储地址。

A. 1060
B. 1052
C. 1068
D. 1017

## 选项设计（错误类型）

| 选项 | 对应错误类型 | 说明 |
|------|-------------|------|
| A | 行优先公式误用 | 使用行优先公式 `base + (i × n + j) × L` 计算 |
| B | 行列索引颠倒 | 将行索引 i 与列索引 j 互换后代入列优先公式 |
| C | 正确结果 | 正确应用列优先公式 `base + (j × m + i) × L` |
| D | 忘记乘元素大小 | 计算偏移时忘记乘以 L，直接 `base + j × m + i` |

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **4 选项互异**：A/B/C/D 四个值各不相同，无碰撞。
2. **正确值唯一确定**：在给定参数（m=5, n=6, base=1000, L=4, i=2, j=3）下，列优先公式 `base + (j × m + i) × L` 产生唯一确定值，且等于选项 C。
3. **干扰项对应声明错误类型**：
   - A = 行优先公式 `base + (i × n + j) × L` 的计算结果
   - B = 行列颠倒后代入列优先公式 `base + (i × m + j) × L` 的计算结果
   - D = 忘记乘 L 的结果 `base + j × m + i`
4. **已知条件自洽**：题干中给出的 `A[1][2] = 1044` 与列优先公式计算结果一致（`1000 + (2 × 5 + 1) × 4 = 1044`）。
5. **计算结果在合法范围内**：`base + (j × m + i) × L < 65536`。
