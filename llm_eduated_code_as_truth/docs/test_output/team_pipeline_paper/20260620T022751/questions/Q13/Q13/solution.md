## （2）计算 ASL

### 查找成功的 ASL

查找成功时，每个关键字的比较次数等于其在链表中的位置（从 1 开始计数）：

| 关键字 | 桶号 | 链中位置 | 比较次数 |
|--------|------|----------|----------|
| 5      | 5    | 4        | 4        |
| 18     | 5    | 3        | 3        |
| 31     | 5    | 2        | 2        |
| 44     | 5    | 1        | 1        |
| 28     | 2    | 4        | 4        |
| 41     | 2    | 3        | 3        |
| 54     | 2    | 2        | 2        |
| 67     | 2    | 1        | 1        |
| 17     | 4    | 1        | 1        |
| 33     | 7    | 1        | 1        |

$$ASL_{success} = \frac{4 + 3 + 2 + 1 + 4 + 3 + 2 + 1 + 1 + 1}{10} = \frac{22}{10} = 2.2$$

### 查找失败的 ASL

查找失败时，在桶 $j$ 中查找失败需要比较的次数等于该桶链表的长度（即链中元素个数）：

| 桶号 | 链表长度 | 失败比较次数 |
|------|----------|--------------|
| 0    | 0        | 0            |
| 1    | 0        | 0            |
| 2    | 4        | 4            |
| 3    | 0        | 0            |
| 4    | 1        | 1            |
| 5    | 4        | 4            |
| 6    | 0        | 0            |
| 7    | 1        | 1            |
| 8    | 0        | 0            |
| 9    | 0        | 0            |
| 10   | 0        | 0            |
| 11   | 0        | 0            |
| 12   | 0        | 0            |

$$ASL_{failure} = \frac{0 + 0 + 4 + 0 + 1 + 4 + 0 + 1 + 0 + 0 + 0 + 0 + 0}{13} = \frac{10}{13}$$

## 答案

- $ASL_{success} = \dfrac{22}{10} = 2.2$
- $ASL_{failure} = \dfrac{10}{13}$
