## 题目
已知一棵二叉树共有 23 个结点，其中度为 1 的结点数为 0。则该二叉树的叶子结点数为（ ）。


## 选项
- A: 正确结果
- B: 公式方向记反（误用 n2 = n0 + 1）或算出 n2 后误以为是 n0 的结果
- C: 概念混淆，将度为 1 的结点数直接当作叶子结点数的结果
- D: 错误认为 n2 = n - n1，再套用 n0 = n2 + 1 的结果


## 求解过程
### 核心公式

二叉树有两个基本性质：

1. **叶子结点与度为2结点关系**：n₀ = n₂ + 1
2. **结点总数关系**：n = n₀ + n₁ + n₂

其中：
- n₀：度为 0 的结点数（叶子结点）
- n₁：度为 1 的结点数
- n₂：度为 2 的结点数
- n：总结点数

### 联立求解

将 n₀ = n₂ + 1 代入 n = n₀ + n₁ + n₂：

```
n = (n₂ + 1) + n₁ + n₂
n = 2·n₂ + 1 + n₁
```

解得：

```
n₂ = (n - n₁ - 1) / 2
n₀ = n₂ + 1 = (n - n₁ + 1) / 2
```

### 代入数值

已知 n = 23，n₁ = 0：

```
n₂ = (23 - 0 - 1) / 2 = 22 / 2 = 11
n₀ = 11 + 1 = 12
```

### 验证

- 结点总数：n₀ + n₁ + n₂ = 12 + 0 + 11 = 23 ✓
- 二叉树性质：n₀ = n₂ + 1 → 12 = 11 + 1 ✓
