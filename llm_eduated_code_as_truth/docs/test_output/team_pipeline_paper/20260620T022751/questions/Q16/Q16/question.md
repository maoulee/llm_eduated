# 单链表递归逆序输出函数填空并说明功能

## 题干

已知单链表结点类型定义如下：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

阅读以下递归函数 `PrintReverse`，完成代码填空并简述其功能。

```c
void PrintReverse(LNode *p) {
    if (__________)          // 填空①
        return;
    PrintReverse(p->next);
    __________;              // 填空②
}
```

**（1）代码填空**（3分）

在横线处填入适当内容，使函数功能完整。

**（2）功能简述**（2分）

简述函数 `PrintReverse` 的功能。

## 设计意图

- **考察知识点**：单链表递归遍历、递归函数的执行时序（调用栈深入与回溯阶段）、递归基条件设计
- **考察模式**：代码阅读型——给定部分代码，要求填空并理解功能
- **K目标**：K2=3（代码逻辑分析，需理解递归调用与回溯的执行顺序），K3=2（递归推演2-3步即可理解逆序效果）
- **典型陷阱**：
  - 填空①：递归基条件误写为 `p->next == NULL`（会导致最后一个结点无法输出）
  - 填空②：误将输出语句放在递归调用之前（变成正序输出）
  - 功能描述遗漏"逆序"关键词

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **填空①为递归基条件**：填入的内容等价于 `p == NULL`（或 `!p`），确保空链表/到达链表末尾时正确终止递归。
2. **填空②为回溯阶段输出**：填入的内容为输出当前结点数据的语句（如 `printf("%d ", p->data);`），且位于递归调用 `PrintReverse(p->next)` 之后，确保逆序输出。
3. **功能描述包含"逆序"关键词**：功能简述中必须出现"逆序"或"倒序"等表述，表明考生理解了递归回溯的执行时序。
4. **函数能正确处理空链表**：当传入 `p == NULL` 时，函数不执行任何输出直接返回（由填空①保证）。
