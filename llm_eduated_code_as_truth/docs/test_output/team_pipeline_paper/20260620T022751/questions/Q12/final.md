## 题目

已知有向带权图 G = (V, E)，其中顶点集 V = {A, B, C, D, E, F}，边集 E 及权值如下表所示：

| 边   | 权值 |
|------|------|
| A→B  | 4    |
| A→C  | 2    |
| B→D  | 3    |
| B→E  | 1    |
| C→B  | 1    |
| C→D  | 5    |
| C→E  | 8    |
| D→E  | 2    |
| D→F  | 6    |
| E→F  | 3    |

以顶点 A 为源点，执行 Dijkstra 算法求单源最短路径。算法使用 dist[] 数组记录源点到各顶点的当前最短距离，用 visited[] 标记已确定最短路径的顶点。初始时 dist[A] = 0，其余 dist 值为 ∞，所有顶点均未访问。

**要求：**

（1）写出 Dijkstra 算法执行过程中，每轮迭代后 dist 数组的值。用如下表格格式作答（每轮需标明本轮选中的顶点、各顶点的 dist 值及 visited 状态）：

| 轮次 | 选中顶点 | dist[A] | dist[B] | dist[C] | dist[D] | dist[E] | dist[F] | visited 集合 |
|------|----------|---------|---------|---------|---------|---------|---------|--------------|
| 初始 | —        | 0       | ∞       | ∞       | ∞       | ∞       | ∞       | {}           |
| 1    |          |         |         |         |         |         |         |              |
| 2    |          |         |         |         |         |         |         |              |
| ...  |          |         |         |         |         |         |         |              |

（2）写出从源点 A 到其余各顶点的最短路径（用顶点序列表示）及对应的路径长度。

（3）在算法执行过程中，边 D→E 的松弛操作没有更新 E 的 dist 值。请解释原因，并说明 Dijkstra 算法中"已确定最短路径的顶点不再被松弛"这一性质成立的前提条件。

## 解析

### 第（1）问：Dijkstra 算法执行过程

**初始化**

- dist[A] = 0，dist[B] = dist[C] = dist[D] = dist[E] = dist[F] = ∞
- visited = {}

**逐轮执行**

**第 1 轮：选中 A（dist=0）**
- 松弛 A→B：dist[B] = min(∞, 0+4) = 4，parent[B] = A
- 松弛 A→C：dist[C] = min(∞, 0+2) = 2，parent[C] = A
- visited = {A}

**第 2 轮：选中 C（dist=2，未访问中最小）**
- 松弛 C→B：dist[B] = min(4, 2+1) = 3，parent[B] = C（**B 的 dist 从 4 更新为 3**）
- 松弛 C→D：dist[D] = min(∞, 2+5) = 7，parent[D] = C
- 松弛 C→E：dist[E] = min(∞, 2+8) = 10，parent[E] = C
- visited = {A, C}

**第 3 轮：选中 B（dist=3，未访问中最小）**
- 松弛 B→D：dist[D] = min(7, 3+3) = 6，parent[D] = B（**D 的 dist 从 7 更新为 6**）
- 松弛 B→E：dist[E] = min(10, 3+1) = 4，parent[E] = B（**E 的 dist 从 10 更新为 4**）
- visited = {A, B, C}

**第 4 轮：选中 E（dist=4，未访问中最小）**
- 松弛 E→F：dist[F] = min(∞, 4+3) = 7，parent[F] = E
- visited = {A, B, C, E}

**第 5 轮：选中 D（dist=6，未访问中最小）**
- 松弛 D→E：E 已在 visited 中，**跳过**（不更新）
- 松弛 D→F：dist[F] = min(7, 6+6) = 7，不更新（12 > 7）
- visited = {A, B, C, D, E}

**第 6 轮：选中 F（dist=7，未访问中最小）**
- F 无出边，无松弛操作
- visited = {A, B, C, D, E, F}

### 第（2）问：最短路径及长度

根据各轮 parent 指针回溯：

| 目标顶点 | 最短路径 | 路径长度 |
|----------|----------|----------|
| A | A | 0 |
| B | A → C → B | 3 |
| C | A → C | 2 |
| D | A → C → B → D | 6 |
| E | A → C → B → E | 4 |
| F | A → C → B → E → F | 7 |

**最终 dist 值：** dist[A]=0, dist[B]=3, dist[C]=2, dist[D]=6, dist[E]=4, dist[F]=7

### 第（3）问：边 D→E 松弛不更新的原因

**原因**

在第 5 轮选中 D 时，E 已在第 4 轮被标记为 visited（已确定最短路径）。此时：

- dist[D] = 6，边 D→E 权值为 2
- dist[D] + w(D→E) = 6 + 2 = 8
- dist[E] = 4（已在第 4 轮确定）
- 8 > 4，松弛条件不满足，故不更新

**根本原因**：E 在 D 之前被访问（第 4 轮 vs 第 5 轮），E 的最短路径已经确定，D→E 的松弛尝试不会产生更短路径。

**"已确定最短路径的顶点不再被松弛"成立的前提条件**

Dijkstra 算法中这一性质成立的前提是：**图中所有边的权值均为非负数（w ≥ 0）**。

**理由**：当所有边权非负时，一旦顶点 v 被选中加入 visited 集合，其 dist[v] 即为从源点到 v 的最短距离。因为任何后续通过未访问顶点 u 到达 v 的路径，其长度至少为 dist[u] + w(u,v) ≥ dist[u] ≥ dist[v]（dist[u] ≥ dist[v] 是因为 v 是当前未访问顶点中 dist 最小的），不可能比 dist[v] 更短。

若存在负权边，则后续可能通过负权边找到更短路径，此时"已确定顶点不再松弛"的性质不再成立，Dijkstra 算法无法保证正确性。
