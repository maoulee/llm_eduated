## 考点
- **Dijkstra算法核心机制**：考察侧重点为逐顶点松弛过程的完整手工模拟，包括dist数组的初始化、每轮选择最小距离顶点、对邻接顶点的松弛更新
- **最短路径树构建**：考察侧重点为从源点到各顶点的最短路径追踪（通过predecessor数组或路径回溯）
- **算法适用条件**：考察侧重点为识别Dijkstra算法的前提条件（有向带权图、无负权边）

## 难度目标
- **K1=1（微弱）**：Dijkstra算法为数据结构核心算法，概念记忆门槛低，学生即使概念模糊也能按流程执行
- **K2=2（较低）**：单步计算仅为"dist[v] > dist[u] + w(u,v) ? 更新"的加法比较，数字友好即可
- **K3=4（较高）**：需维持dist数组和S集合的动态状态，逐轮更新，推演步数>5步，中间错一步后续全错
- **K4=2（较低）**：存在常规注意点（如∞的处理、已确定顶点不再更新），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他子系统

## 考察模式
**推演型——Dijkstra算法手工模拟**

理由：该题位核心考察K3机制推演能力，要求学生按Dijkstra算法的固定流程（初始化→选最小→松弛→重复）走完多轮迭代，维持dist数组的动态状态。这是图算法题的经典考察模式，与slot中examination_mode一致。

## 出题要求
- **题型**：综合题，10分
- **总条件数**：1个核心条件（图的表示）+ 源点指定
- **条件设计原则**：
  - 图的表示方式可选邻接矩阵或边集，但需完整描述所有边及其权重
  - 源点明确指定（如顶点v0或v1）
- **参数取值范围要求**：
  - 顶点数：5-7个（保证推演步数足够但不过载）
  - 边数：8-12条（保证图有一定密度，松弛操作有实质内容）
  - 权重：正整数，建议范围1-15，避免过大数字增加计算负担
  - 图必须连通（从源点可达所有顶点），否则部分顶点dist保持∞，考察价值降低

## 子问题规划

### 第1问（4分）：Dijkstra算法执行过程
- **类型**：计算/推演
- **考察目标**：逐轮写出dist数组的更新过程，展示每轮选择的最小距离顶点及其邻接顶点的松弛结果
- **与前后问关系**：独立，是第2问的基础但第2问不依赖第1问的中间结果

### 第2问（3分）：最终最短路径
- **类型**：计算
- **考察目标**：给出源点到各顶点的最短路径长度（最终dist数组）
- **与前后问关系**：可由第1问结果直接得出，也可独立计算

### 第3问（3分）：最短路径追踪
- **类型**：分析
- **考察目标**：给出源点到某一指定顶点的最短路径（顶点序列）
- **与前后问关系**：依赖第2问的最短路径长度，需通过predecessor信息或路径回溯得出

## 参数约束
- **顶点数 n**：取值范围 5-7，建议6个顶点（v0-v5），保证推演轮数在5-6轮
- **边数 m**：取值范围 8-12，与顶点数匹配，保证图有一定密度
- **权重 w**：正整数，取值范围 1-15，不同边的权重应有差异（避免大量相同权重导致松弛无实质变化）
- **源点 s**：固定指定一个顶点（如v0），不作为自由参数
- **目标顶点 t**（第3问）：从非源点中选择一个，建议选距离源点较远的顶点（路径长度≥3条边），增加追踪难度
- **一致性约束**：
  - 图必须是有向图
  - 从源点出发必须能到达所有其他顶点（连通性）
  - 不存在负权边（Dijkstra适用条件）
  - 不存在自环（简化推演）
  - 可存在平行边但建议避免（增加复杂度无考察价值）

## 参考经验
- **考察模式**：Dijkstra手工模拟是图算法题的标准考察方式，核心在于维持dist数组的动态状态
- **难度锚点**：K3=4为该题位的核心难度来源，顶点数6个、边数10条左右可保证推演步数在合理范围
- **典型陷阱**：
  - 学生可能忘记已确定顶点（加入S集合）不再参与后续松弛
  - 学生可能混淆"选择最小dist顶点"和"松弛邻接顶点"的顺序
  - 学生可能在多轮更新中遗漏某个邻接顶点的松弛
  - ∞的处理：初始时非邻接顶点的dist为∞，需正确表示
