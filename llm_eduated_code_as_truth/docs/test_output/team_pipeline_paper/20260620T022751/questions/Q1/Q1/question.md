# 概念题

## 第 1 题

**题干**：关于顺序表与链表的随机访问特性，下列说法正确的是：

A. 顺序表和链表都支持随机访问，但顺序表的时间复杂度为 O(1)，链表为 O(n)
B. 只有顺序表支持随机访问，链表必须从头结点开始顺序查找
C. 链表支持随机访问，因为每个结点都包含指向下一个结点的指针
D. 顺序表和链表都不支持随机访问，都需要顺序遍历

**答案**：B

## 第 2 题

**题干**：使用栈进行括号匹配检查时，下列说法正确的是：

A. 遇到右括号时，将其压入栈中
B. 匹配过程中，栈中只存储左括号
C. 栈的最大深度等于字符串中括号对的总数
D. 匹配失败时，栈一定为空

**答案**：B

## 第 3 题

**题干**：关于连通图、连通分量和生成树的概念，下列说法正确的是：

A. 连通图的生成树是包含图中所有顶点的极小连通子图
B. 无向图的每个连通分量都是一棵生成树
C. 生成树中边的数量等于顶点数量
D. 连通图一定包含环

**答案**：A

## 第 4 题

**题干**：关于 Floyd 算法和 Dijkstra 算法的适用范围，下列说法正确的是：

A. Dijkstra 算法可以处理带负权边的图，Floyd 算法不能
B. Floyd 算法求解单源最短路径，Dijkstra 算法求解所有顶点对之间的最短路径
C. Dijkstra 算法不能处理带负权边的图，Floyd 算法可以处理带负权边但不含负权回路的图
D. 两种算法都不能处理带负权边的图

**答案**：C

## 第 5 题

**题干**：关于 B 树和 B+ 树的结构差异，下列说法正确的是：

A. B+ 树的非叶子结点只存储关键字和指针，不存储数据；B 树的每个结点既存储关键字也存储数据
B. B 树的所有叶子结点在同一层，B+ 树的叶子结点不在同一层
C. B+ 树的叶子结点之间没有指针链接，B 树的叶子结点之间有指针链接
D. B 树和 B+ 树中，关键字在结点内的排列方式不同

**答案**：A

## 第 6 题

**题干**：对 n 个元素的序列进行排序，下列排序算法中，排序趟数与初始序列排列状态无关的是：

A. 冒泡排序
B. 快速排序
C. 归并排序
D. 直接插入排序

**答案**：C
