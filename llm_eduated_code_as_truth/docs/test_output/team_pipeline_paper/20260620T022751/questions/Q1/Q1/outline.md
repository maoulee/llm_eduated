## 考点
- **顺序表的随机访问特性**：通过下标直接定位元素，时间复杂度 O(1)
- **链表的顺序访问特性**：必须从头节点开始逐个遍历，时间复杂度 O(n)
- **存储结构差异**：顺序表连续存储 vs 链表离散存储（含指针域）

## 难度目标
- **K1=4（较高）**：需精准辨析顺序表与链表两种极易混淆的存储结构特性，考查对"随机访问"概念的本质理解
- **K2=1（微弱）**：纯概念辨析，无计算需求
- **K3=1（微弱）**：无需多步推演，直接基于概念判断
- **K4=3（标准）**：存在陷阱词（如"随机访问"的定义边界），不触发正确理解就会选错
- **K5=1（微弱）**：单一知识点（线性表存储结构）内部解决

## 考察模式
**概念辨析型——存储结构与随机访问特性**

理由：该题位历史经验表明，Q1题位适合考查基础概念的精准辨析。顺序表与链表的随机访问特性是数据结构最核心的对比点之一，适合作为概念辨析题。

## 参考经验
