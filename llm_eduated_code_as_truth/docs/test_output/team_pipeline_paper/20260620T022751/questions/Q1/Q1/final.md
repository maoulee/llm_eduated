# 概念题解析

## 第 1 题解析

**答案**：B

**解析**：B 正确，顺序表基于连续存储，可通过下标直接定位任意位置的元素，时间复杂度 O(1)，支持随机访问；链表基于指针链接，访问第 i 个元素必须从头结点开始顺序遍历，时间复杂度 O(n)，不支持随机访问。A 错误，链表不支持随机访问，O(n) 是顺序访问的代价而非随机访问。C 错误，链表结点中的指针用于顺序链接，不是随机访问的依据。D 错误，顺序表支持随机访问。

## 第 2 题解析

**答案**：B

**解析**：B 正确，括号匹配算法中，遇到左括号压栈，遇到右括号弹栈匹配，因此栈中始终只存储左括号。A 错误，遇到右括号时应弹出栈顶元素进行匹配，而非压入。C 错误，栈的最大深度等于嵌套层数，而非括号对总数（如 "()()" 有 2 对括号但最大深度为 1）。D 错误，匹配失败时栈可能非空（左括号多余）或为空（右括号多余导致提前失败）。

## 第 3 题解析

**答案**：A

**解析**：A 正确，生成树是包含图中所有顶点的极小连通子图，n 个顶点的生成树有 n-1 条边，连通且无环。B 错误，连通分量是极大连通子图，可能包含环，不一定是树。C 错误，n 个顶点的生成树有 n-1 条边，而非 n 条。D 错误，树是连通图但不包含环，连通图不一定含环。

## 第 4 题解析

**答案**：C

**解析**：C 正确，Dijkstra 算法基于贪心策略，一旦顶点被标记为已确定最短路径，不再更新，负权边会破坏这一贪心选择性质，故不能处理带负权边的图；Floyd 算法基于动态规划，可以处理带负权边的图，但含负权回路时最短路径不存在（可无限绕回路减小路径长度）。A 错误，两者适用范围正好说反。B 错误，Floyd 求解所有顶点对之间的最短路径，Dijkstra 求解单源最短路径。D 错误，Floyd 可以处理带负权边的图。

## 第 5 题解析

**答案**：A

**解析**：A 正确，B+ 树的非叶子结点只起索引作用，存储关键字和指向子结点的指针，不存储实际数据；B 树的每个结点（包括非叶子结点）都存储关键字和对应的数据记录。B 错误，B 树和 B+ 树都是平衡树，所有叶子结点都在同一层。C 错误，B+ 树的叶子结点之间有指针链接（形成有序链表，便于范围查询），B 树的叶子结点之间没有指针链接。D 错误，B 树和 B+ 树中关键字在结点内都是有序排列的。

## 第 6 题解析

**答案**：C

**解析**：C 正确，归并排序采用分治策略，无论初始序列状态如何，都需要 log₂n 趟归并，趟数固定。A 错误，冒泡排序最好情况（已有序）只需 1 趟，最坏情况（逆序）需 n-1 趟，趟数与初始序列有关。B 错误，快速排序的递归深度（趟数）与初始序列密切相关，最好 O(logn) 趟，最坏 O(n) 趟。D 错误，直接插入排序虽然固定 n-1 趟，但通常认为其"趟"的定义与比较/移动次数相关，且实际实现中趟数概念不如归并排序明确；更关键的是，归并排序是四个选项中唯一明确趟数与初始状态无关的算法。
