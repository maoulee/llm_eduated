# 综合题 — 直接插入排序与冒泡排序过程模拟及对比

## 基本信息
- **题型**: 综合题
- **知识点**: DS-8 > 8.2 插入排序 > 直接插入排序过程, DS-8 > 8.3 交换排序 > 冒泡排序过程
- **考察模式**: 推演型——排序过程手工模拟与对比
- **难度**: K3=4（多步推演）

---

## 题干

给定整数序列：**45, 23, 67, 12, 89, 34, 56, 78**

请完成以下问题：

### （1）直接插入排序（3分）

对该序列进行**直接插入排序**，写出每一趟排序结束后的序列状态。

> **说明**：直接插入排序从第 2 个元素开始，依次将当前元素插入到前面已排序部分的适当位置。第 i 趟（i=2,3,...,n）将第 i 个元素插入到前 i-1 个已排序元素中。

### （2）冒泡排序（3分）

对同一序列进行**冒泡排序**，写出每一趟排序结束后的序列状态。

> **说明**：冒泡排序每趟从前往后扫描，相邻元素逆序则交换，每趟将当前未排序部分的最大值"沉底"到末尾。第 j 趟（j=1,2,...,n-1）最多进行 n-j 次相邻比较与交换。

### （3）对比分析（4分）

基于（1）（2）的排序过程，回答以下问题：

① 直接插入排序和冒泡排序在**比较次数**和**元素移动（交换）次数**上，哪种算法在本序列上更高效？简要说明理由。

② 两种算法是否都是**稳定排序**？若原序列中存在值相等的元素，排序后它们的相对位置是否保持不变？

---

## 通过条件（成功判据·可机检）

本题成立 ⇔ 以下特征可被 gen.py exec 验证：

1. **直接插入排序可完整模拟**：序列长度为 8，可产生 7 趟（i=2~8）中间状态，每趟结果唯一确定。
2. **冒泡排序可完整模拟**：序列长度为 8，可产生若干趟中间状态（最多 7 趟），每趟结果唯一确定。
3. **两种排序最终结果一致**：直接插入排序与冒泡排序的最终有序序列相同（升序）。
4. **比较/移动次数可量化对比**：两种算法在本序列上的比较次数和移动（交换）次数均可精确统计，且存在差异（非完全相同），使 q3 的对比分析有意义。
5. **稳定性可判定**：直接插入排序和冒泡排序的稳定性属性可明确判定（两者均为稳定排序）。

## 设计意图

- **q1**：考察直接插入排序的逐趟插入过程，重点在于"插入位置判断"与"元素后移"的模拟。
- **q2**：考察冒泡排序的逐趟沉底过程，重点在于"相邻比较交换"与"每趟确定一个最大值位置"的模拟。
- **q3**：考察两种算法在比较次数、移动次数、稳定性上的对比分析能力，要求基于实际模拟结果而非仅凭理论复杂度作答。

## 核心陷阱

- **插入排序插入位置判断错误**：未正确找到插入位置，导致中间状态错误。
- **冒泡排序趟数计算错误**：混淆"实际趟数"与"最大趟数"，或提前终止判断错误。
- **比较次数与移动次数混淆**：q3 中未能区分"比较"与"移动/交换"两种操作，导致效率分析错误。
- **稳定性概念混淆**：误认为冒泡排序不稳定，或不清楚稳定性的定义。

## 考察能力

本题核心考察考生对直接插入排序和冒泡排序执行过程的深度模拟能力，以及基于实际过程数据对比分析两种算法效率差异的能力。多步推演（K3=4）是主要难度来源，但每步操作简单（K2=2），路径唯一。
