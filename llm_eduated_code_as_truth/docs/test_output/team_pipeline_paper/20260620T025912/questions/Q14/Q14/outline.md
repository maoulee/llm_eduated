## 考点
- **直接插入排序**：考察每趟插入过程的手工模拟，重点在于理解"从第二个元素开始，逐个插入到已排序序列的合适位置"的机制
- **冒泡排序**：考察每趟冒泡过程的手工模拟，重点在于理解"相邻元素两两比较，大的往后冒"的机制
- **算法对比分析**：考察两种排序算法在时间复杂度、空间复杂度、稳定性等方面的异同

## 难度目标
- **K1=1（微弱）**：仅需日常常识词汇，排序算法名称属于基础概念，概念模糊也能顺着题干做
- **K2=2（较低）**：几乎无计算，仅需比较大小和交换位置，数字友好
- **K3=4（较高）**：需手动模拟两种排序的多趟过程，每趟需维持动态状态更新，推演步数>5步，中间错一步后续全错
- **K4=2（较低）**：存在常规注意点（如直接插入排序从第2个元素开始、冒泡排序每趟确定一个最大元素），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他系统

## 考察模式
**推演型——排序过程手工模拟与对比**

参考历史经验（2010_Q11、2020_Q11）：
- 历史模式：给定序列→分别用两种排序算法写出每趟结果→对比分析
- 难度锚点：K3主导（4级），多步推演+状态维持
- 典型陷阱：直接插入排序的"插入位置"判断错误、冒泡排序的"趟数"计数错误

## 出题要求
- **题型**：综合题，10分
- **总条件数**：1个核心条件（待排序关键字序列）
- **条件设计原则**：序列长度适中（6-10个元素），元素值互异，非已排序/逆序/近乎有序，确保两种算法都能体现多趟过程
- **参数取值范围要求**：序列长度 6-10，元素值 1-100 范围内整数，互异

## 参数约束
- **序列长度 n**：6 ≤ n ≤ 10，确保两种算法都有足够的趟数体现过程
- **元素值范围**：1-100 范围内的整数
- **元素互异性**：所有元素互不相同，避免相等元素带来的边界情况干扰
- **序列无序性**：不能是已排序、逆序或近乎有序序列，确保两种算法都能体现多趟过程
- **可调自由度**：序列长度和元素值可在上述范围内自由调整，但需保证非平凡性

## 参考经验
- **历史模式**：2010_Q11 和 2020_Q11 均采用"给定序列→两种排序算法分别写出每趟结果→对比分析"的模式
- **难度锚点**：K3=4 为主导，多步推演+状态维持是核心难点
- **典型陷阱**：
  - 直接插入排序：插入位置判断错误（应在已排序部分从后往前找）

  - 对比分析：遗漏稳定性或空间复杂度等维度
