## （1）结点类型定义（2分）

```c
typedef struct LinkNode {
    int data;                    // 数据域
    struct LinkNode *next;       // 指针域
} LinkNode;
```

---

## （2）算法思想描述（4分）

**核心思路：前驱指针法遍历删除**

1. **遍历与识别**：设置两个指针 `prev` 和 `curr`，`prev` 初始指向头结点，`curr` 初始指向首元结点（`head->next`）。从头到尾遍历链表，逐个检查 `curr->data` 是否等于 `x`。

2. **指针更新策略**：
   - 若 `curr->data == x`：执行 `prev->next = curr->next`，将前驱结点直接指向 `curr` 的后继结点，从而将 `curr` 从链表中摘除。此时 `prev` 不动（因为下一个结点仍需与当前 `prev` 比较），`curr` 更新为 `prev->next`（即原 `curr` 的后继）。
   - 若 `curr->data != x`：`prev` 和 `curr` 同步后移一位（`prev = curr; curr = curr->next`）。

3. **连续多个值为 x 的结点**：当连续多个结点值均为 `x` 时，每次删除后 `prev` 保持不变、`curr` 指向下一个结点，下一轮循环继续判断，因此连续结点会被逐个删除，不会遗漏。

4. **内存释放**：每次删除结点时，在修改指针后调用 `free(curr)` 释放该结点占用的内存空间，避免内存泄漏。

5. **头结点保护**：`prev` 从 `L->head` 开始，`curr` 从 `L->head->next` 开始，头结点始终作为 `prev` 的初始值参与指针更新，但永远不会被 `free()`，因此头结点始终保留。

## （3）C/C++ 代码实现（8分）

```c
void DeleteAll(LinkNode *L, int x) {
    LinkNode *prev = L->head;       // prev 指向当前结点的前驱，初始为头结点
    LinkNode *curr = L->head->next; // curr 指向当前待检查结点，初始为首元结点

    while (curr != NULL) {
        if (curr->data == x) {
            // 删除 curr 结点：前驱指向 curr 的后继
            prev->next = curr->next;
            free(curr);             // 释放被删除结点的内存
            curr = prev->next;      // curr 移到下一个结点（prev 不动）
        } else {
            // 不删除：prev 和 curr 同步后移
            prev = curr;
            curr = curr->next;
        }
    }
}
```

---

## 复杂度分析

- **时间复杂度**：O(n)，其中 n 为链表长度。每个结点恰好被访问一次。
- **空间复杂度**：O(1)，仅使用两个指针变量 `prev` 和 `curr`，不依赖额外空间。

## 典型错误分析

| 错误类型 | 错误表现 | 正确做法 |
|---------|---------|---------|
| 前驱指针未更新 | 删除后 `prev` 也后移，导致漏删连续结点 | 删除时 `prev` 不动，`curr` 单独后移 |
| 未释放内存 | 只修改指针不调用 `free()` | 删除结点后必须 `free(curr)` |
| 误删头结点 | `curr` 从头结点开始遍历 | `curr` 从 `head->next` 开始 |
| 链表断裂 | 删除后未正确连接 `prev->next` | 先执行 `prev->next = curr->next` 再 `free(curr)` |
