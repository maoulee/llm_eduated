# 解析

## 正确答案

**A. 1044**

## 求解过程

### 1. 确定参数

- 行数 $M = 5$（行索引范围 $0..4$）
- 列数 $N = 7$（列索引范围 $0..6$）
- 元素大小 $L = 4$ 字节
- 基地址 $\text{LOC}(A[0][0]) = 1000$
- 目标元素：$A[1][2]$，即 $i = 1,\ j = 2$

### 2. 应用列优先公式

列优先存储的地址计算公式为：

$$\text{LOC}(A[i][j]) = \text{LOC}(A[0][0]) + (j \times M + i) \times L$$

代入参数：

$$\text{LOC}(A[1][2]) = 1000 + (2 \times 5 + 1) \times 4 = 1000 + 11 \times 4 = 1044$$

### 关键区分点

- **列优先 vs 行优先**：列优先先遍历列（列索引变化快），行优先先遍历行（行索引变化快）。本题明确为**列优先**，公式中偏移量为 $(j \times M + i)$，而非行优先的 $(i \times N + j)$。
- **M 与 N 的角色**：列优先公式中，列索引 $j$ 乘以的是**行数 M**（因为每列有 M 个元素），而非列数 N。
