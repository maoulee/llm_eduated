# 题目

已知二维数组 $A[0..4][0..6]$ 按**列优先**顺序连续存储，每个元素占用 4 个存储单元，起始存储地址 $\text{LOC}(A[0][0]) = 1000$。则元素 $A[1][2]$ 的存储地址是（ ）。

A. 1044
B. 1036
C. 1060
D. 1011

---

## 设计意图

- **考察点**：二维数组列优先存储的地址计算公式 $\text{LOC}(A[i][j]) = \text{LOC}(A[0][0]) + (j \times M + i) \times L$
- **K目标**：K2（理解）——理解列优先与行优先存储的区别，能正确应用地址计算公式
- **考察模式**：定量计算

## 选项设计

| 选项 | 对应错误类型 |
|------|-------------|
| A | 正确结果（列优先公式正确应用） |
| B | 行优先公式误用：$(i \times N + j) \times L + \text{Base}$ |
| C | m/n 位置颠倒：将行数 M=5 与列数 N=7 颠倒后代入列优先公式 |
| D | 忘记乘元素大小 L：直接用偏移量加基地址 |

## 通过条件

本题成立 ⇔ 以下可机检特征满足：

1. **行优先结果 ≠ 列优先结果**：$(i \times N + j) \times L \neq (j \times M + i) \times L$，确保"列优先"考点被真正触发而非两种存储方式等价
2. **4 选项互异**：A/B/C/D 四个值各不相同，无碰撞
3. **正确值唯一确定**：在给定参数下，列优先公式给出唯一确定的地址值
4. **干扰项对应声明错误类型**：B/C/D 各自对应上述设计的错误类型，非随机扰动
5. **结果 ≤ 65536**：计算结果在合理范围内
