# 解析：单链表递归函数分析

## 答案

### （1）代码填空（3 分）

**`L == NULL`**（或等价形式 `!L`）

### （2）功能简述（2 分）

**逆序输出单链表所有元素。**

---

## 解析

### 第（1）问：递归终止条件辨析

递归函数 `PrintReverse` 的三要素：

| 要素 | 代码 | 作用 |
|------|------|------|
| 递归终止条件 | `if (L == NULL) return;` | 到达链表末尾时停止递归 |
| 递归调用 | `PrintReverse(L->next);` | 先深入下一节点 |
| 回溯操作 | `printf("%d ", L->data);` | 递归返回后输出当前节点 |

**为什么填 `L == NULL`？**

递归的终止条件必须保证：**所有节点都能被输出**。当递归到链表最后一个节点后，`L->next` 为 `NULL`，下一次递归调用传入 `NULL`，此时应终止——即 `L == NULL` 时 return。

**错误填法 `L->next == NULL` 的后果：**

以链表 `12 → 25 → 7 → 33 → 19` 为例，对比两种填法的执行：

**正确填法 `L == NULL` 的递归过程：**

```
PrintReverse(12)
  → PrintReverse(25)
    → PrintReverse(7)
      → PrintReverse(33)
        → PrintReverse(19)
          → PrintReverse(NULL)  ← 终止，return
          ← 回溯：输出 19
        ← 回溯：输出 33
      ← 回溯：输出 7
    ← 回溯：输出 25
  ← 回溯：输出 12

输出：19 33 7 25 12  （全部 5 个元素，逆序 ✓）
```

**错误填法 `L->next == NULL` 的递归过程：**

```
PrintReverse(12)
  → PrintReverse(25)
    → PrintReverse(7)
      → PrintReverse(33)
        → PrintReverse(19)
            19->next == NULL → 直接 return，不输出 19！
        ← 回溯：输出 33
      ← 回溯：输出 7
    ← 回溯：输出 25
  ← 回溯：输出 12

输出：33 7 25 12  （仅 4 个元素，漏掉尾节点 19 ✗）
```

**核心差异：** `L->next == NULL` 在到达最后一个节点时就提前终止，导致最后一个节点的数据永远不会被输出。

---

### 第（2）问：功能描述

**关键词：逆序输出**

判断依据：`printf("%d ", L->data)` 位于递归调用 `PrintReverse(L->next)` **之后**，属于**回溯阶段**的操作。递归先深入到尾端，再逐层返回时输出，因此输出顺序与链表顺序相反。

- 链表顺序：12 → 25 → 7 → 33 → 19
- 输出顺序：19 33 7 25 12

若 `printf` 在递归调用**之前**，则为正序输出；在**之后**，则为逆序输出。
