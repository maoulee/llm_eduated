# 题目

某二叉树共有 831 个结点，其中度为 1 的结点有 30 个。该二叉树的叶子结点（度为 0 的结点）个数为：

A. 401
B. 400
C. 416
D. 31

---

## 设计意图

**考察知识点**：
- 二叉树基本性质：n₀ = n₂ + 1（叶子结点数 = 度为 2 的结点数 + 1）
- 结点总数关系：n = n₀ + n₁ + n₂（总结点数 = 各类结点数之和）
- 联立方程求解能力

**选项设计**：
- **A（正确）**：正确联立 n = n₀ + n₁ + n₂ 与 n₀ = n₂ + 1 求解
- **B（干扰）**：公式记反，误用 n₂ = n₀ + 1，联立求解得错误结果
- **C（干扰）**：误用完全二叉树性质，假设 n₁ = 0（忽略题干给出的 n₁ = 30），直接按 n = n₀ + n₂ 且 n₀ = n₂ + 1 求解
- **D（干扰）**：混淆公式，误认为叶子结点数与度 1 结点数存在 n₀ = n₁ + 1 的关系，直接代入 n₁ = 30 计算

---

## 通过条件

本题成立 ⇔ 以下可机检特征全部满足：

1. **4 选项互异**：A/B/C/D 四个值各不相同（exec 算出后无碰撞）
2. **正确值唯一确定**：在 n=831、n₁=30 的条件下，联立 n=n₀+n₁+n₂ 与 n₀=n₂+1 有唯一整数解，且该解等于 A 选项
3. **干扰项对应声明错误类型**：
   - B 值 = 按 n₂=n₀+1（公式记反）联立求解的结果
   - C 值 = 按 n₁=0（误用完全二叉树性质）联立求解的结果
   - D 值 = 按 n₀=n₁+1（混淆公式）直接计算的结果
4. **干扰项有合理性**：B/C/D 均为二叉树性质计算中常见误算的真实产物，非荒谬值
