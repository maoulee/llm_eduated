## 考点
- **二叉树基本性质**：n0 = n2 + 1（叶子结点数 = 度为2的结点数 + 1），考察准确记忆和应用
- **结点总数关系**：n = n0 + n1 + n2（总结点数 = 各类结点数之和），考察联立方程求解
- **完全二叉树性质**（干扰项设计）：n1 只能为 0 或 1，作为常见误用陷阱

## 难度目标
- **K1=2（较低）**：需要知道二叉树结点分类（度0/1/2）和 n0=n2+1 公式，但概念基础，408考生普遍掌握
- **K2=3（标准）**：需联立两个公式求解，涉及非2的幂次计算（如 n=831, n1=30），计算量适中但需细心
- **K3=2（较低）**：仅需2步推导（代入→求解），路径唯一，无多步串行推演
- **K4=2（较低）**：存在常规注意点（如区分普通二叉树与完全二叉树），但408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他数据结构或算法模块

## 考察模式
**"已知总结点数与度1结点数，求叶子结点数"**——二叉树性质计算题的经典模式。

理由：
- 直接对应 n0 = n2 + 1 的核心考点
- 通过联立方程自然产生 K2=3 的计算需求
- 可设计多种干扰路径（公式记反、忽略n1、完全二叉树误用）
- 2分单选题的标准考察深度

## 出题要求
- **题型**：单选题，4选项，1正确3干扰
- **总条件数**：2个显式条件（总结点数 n、度为1的结点数 n1）
- **条件设计原则**：
  - n 取非2的幂的奇数（如 800-900 范围），保证计算非平凡
  - n1 取非0非1的值（如 20-50 范围），排除完全二叉树性质的误用
  - n - n1 必须为偶数（保证 n0 + n2 为偶数，n0 = n2 + 1 有整数解）
- **参数取值范围要求**：
  - n: 800-900 之间的奇数
  - n1: 20-50 之间的整数
  - 约束：(n - n1) 为偶数

## 子问题规划
本题为单选题，无子问题结构。

## 参数约束
- **n（总结点数）**：800-900 之间的奇数，如 831、857、883 等
- **n1（度为1的结点数）**：20-50 之间的整数，如 30、35、42 等
- **一致性约束**：(n - n1) 必须为偶数（因为 n0 + n2 = n - n1，且 n0 = n2 + 1，所以 n0 + n2 = 2n2 + 1 为奇数... 等等，这里需要重新检查）

**重新推导一致性约束**：
- n = n0 + n1 + n2
- n0 = n2 + 1
- 代入：n = (n2 + 1) + n1 + n2 = 2n2 + n1 + 1
- 所以：n - n1 - 1 = 2n2，即 **(n - n1 - 1) 必须为偶数**，等价于 **(n - n1) 为奇数**

**修正后的约束**：
- n 和 n1 的奇偶性必须**不同**（一奇一偶）
- 例如：n=831（奇），n1=30（偶）→ n-n1=801（奇）✓
- 例如：n=856（偶），n1=35（奇）→ n-n1=821（奇）✓

## 参考经验
- **考察模式**：二叉树性质计算题的经典模式是"给部分条件求未知量"，通过联立 n0=n2+1 和 n=n0+n1+n2 求解
- **难度锚点**：K2=3 对应非2的幂次计算，如 n=831 这类需要实际计算的数值
- **典型陷阱**：
  1. 公式记反：n0 = n2 - 1（常见错误）
  2. 忽略 n1：直接用 n/2 估算叶子数
  3. 完全二叉树误用：认为 n1 只能为 0 或 1
  4. 计算错误：联立方程时符号错误
