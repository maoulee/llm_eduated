# 二叉树遍历序列还原

## 题干

已知某二叉树 T 的中序遍历序列和后序遍历序列如下：

- **中序遍历**：G, D, B, E, A, C, H, F
- **后序遍历**：G, D, E, B, H, F, C, A

请完成以下两问：

**(1)** 根据上述两个遍历序列，还原并画出二叉树 T 的结构（或写出每个结点的左右孩子关系）。

**(2)** 写出二叉树 T 的先序遍历序列。

---

## 设计意图

- **考察知识点**：二叉树遍历的性质（中序、后序、先序的定义与区别）；利用两种遍历序列唯一还原二叉树的递归方法。
- **考察模式**：推演型——从后序确定根结点，从中序划分左右子树，递归还原整棵树的结构，再正向推导先序序列。
- **难度锚点**：K3=4，多步递归推演（至少 6 步：确定根→分左右→递归左子树→递归右子树→合成结构→输出先序），需记忆中间状态（当前子树的结点集合）。
- **典型陷阱**：混淆后序"左右根"与先序"根左右"的顺序；递归时错误划分中序的左右子树边界；先序输出时左右子树顺序颠倒。

---

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **序列一致性**：还原出的二叉树，其中序遍历结果等于 `G, D, B, E, A, C, H, F`，后序遍历结果等于 `G, D, E, B, H, F, C, A`。
2. **树结构非退化**：还原的二叉树中，至少存在一个结点同时拥有左孩子和右孩子（即存在度为 2 的结点）。
3. **左右子树均非空**：根结点的左子树和右子树均至少包含 2 个结点。
4. **先序序列唯一确定**：在给定参数下，先序遍历序列有且仅有一个确定结果，长度为 8，首元素为 `A`（根结点）。
5. **推演步数 ≥ 6**：从输入到输出需经过至少 6 步递归/推导操作（根确定→左右划分→左子树递归→右子树递归→结构合成→先序输出）。
