## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 线性表 > 顺序表
- primary_target_name: 顺序表与链表的随机访问特性对比
- question_type: single_choice
- examination_mode: 概念辨析型——存储结构与随机访问特性

### 难度目标
- k_target: K1=4,K2=1,K3=1,K4=3,K5=1
- difficulty_level: 2
- difficulty_rationale: 概念辨析题，考查对顺序表与链表存储特性的理解，需精准辨析"随机访问"与"顺序访问"概念，存在陷阱词但无计算推演

### 结构要求
- option_count: 4
- distractor_strategy: 3个干扰项分别对应：①混淆随机访问与顺序访问的定义 ②忽略链表等概率访问的平均复杂度 ③将存储密度与访问效率混为一谈
- condition_count: 1-2

### 参数约束
- 本题为纯概念辨析题，不涉及数值参数
- 可使用的符号化描述：表长n（n≥1）、元素类型
- 一致性要求：题干若提及表长，选项中的时间复杂度描述需与之对应

### 参考经验摘要
- 历史模式: Q1题位稳定采用概念辨析型，K1=4-5主导，K2/K3=1，K4=2-3
- 难度锚点: K1=4表示需辨析两个以上易混概念（随机访问vs顺序访问、连续存储vs离散存储）
- 典型陷阱: 混淆"随机访问"定义、忽略链表等概率访问平均复杂度O(n)、将存储密度与访问效率混为一谈
