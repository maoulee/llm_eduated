## 题目

已知一棵平衡二叉排序树（AVL 树）的层序遍历序列为 `30, 10, 50, 20`，即树结构如下：

```
        30
       /  \
     10    50
       \
       20
```

向该 AVL 树中插入关键字 `5`，插入完成后执行必要的旋转操作以维持 AVL 性质。

## 设问

插入并旋转完成后，关键字为 `10` 的结点的平衡因子（左子树高度 − 右子树高度）为多少？

A. 1
B. -1
C. 0
D. -2

## 求解过程

### 插入过程
1. 初始 AVL 树结构如上所示
2. 插入关键字 5：5 < 30 向左，5 < 10 向左，10 的左子树为空，5 作为 10 的左孩子插入

### 插入后的树结构
```
        30
       /  \
     10    50
    /  \
   5    20
```

### 平衡因子计算（左子树高度 − 右子树高度）
- 节点 5：左高 0，右高 0，BF = 0
- 节点 20：左高 0，右高 0，BF = 0
- 节点 50：左高 0，右高 0，BF = 0
- 节点 10：左高 1，右高 1，BF = 0
- 节点 30：左高 2，右高 1，BF = 1

### 旋转判断
所有节点的平衡因子均在 [-1, 1] 范围内，**无需执行任何旋转操作**。

### 代码验证
```
节点 30: 平衡因子=1, 高度=3
节点 10: 平衡因子=0, 高度=2
节点 5: 平衡因子=0, 高度=1
节点 20: 平衡因子=0, 高度=1
节点 50: 平衡因子=0, 高度=1
树是否平衡: True
无需旋转
```

## 答案

**C. 0**

插入 5 后，关键字为 10 的结点左子树高度为 1（节点 5），右子树高度为 1（节点 20），平衡因子 = 1 - 1 = 0。所有结点平衡因子均在 [-1, 1] 范围内，AVL 性质未被破坏，无需执行旋转操作。

## 设计说明

- **考察知识点**：AVL 树插入操作后平衡因子的逐层更新与失衡结点定位
- **考察形式**：选择题，结构操作与状态维护模拟
- **核心考点**：插入后判断是否需要旋转——本题的关键在于识别插入 5 后树仍保持 AVL 性质（所有结点 BF ∈ [-1,1]），避免"过度旋转"的认知错误
- **干扰项设计**：
  - A（1）：误算左子树高度为 1、右子树高度为 0（漏看右子树结点 20）
  - B（-1）：符号取反（用右子树高度减左子树高度）
  - D（-2）：误判插入后失衡需旋转，或错误计算高度差
