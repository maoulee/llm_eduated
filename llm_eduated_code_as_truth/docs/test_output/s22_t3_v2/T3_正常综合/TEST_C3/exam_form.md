## rationale
- AVL插入旋转天然具备长程推演链（多节点插入→失衡检测→旋转判断→形态更新，>5步且需维持动态状态），对应K3高；同时四种旋转类型的触发条件（尤其LR/RL需区分"左孩子的右子树过高"vs"右孩子的左子树过高"）构成经典条件路由暗坑，对应K4高。两者平衡构成K3-K4平衡型，与目标K-雷达一致。
- 经验卡指定"结构操作与状态维护模拟"考察模式，与"多步串行推演"形式高度对齐；陷阱辨析作为辅助形式嵌入旋转类型判断环节，确保K4维度落地。
