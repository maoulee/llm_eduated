# Q41 平衡二叉树（AVL）的插入与旋转调整 — 参考解析

> **初始树 T：**
> ```
>             50
>            /  \
>          30    66
>         /  \     \
>       18   40    80
> ```
> BF = 左子树高度 − 右子树高度；空子树高度为 0，叶子高度为 1。

---

## 第（1）题：各结点的平衡因子 BF 及平衡验证

逐结点计算 BF：

| 结点 | 左子树高度 | 右子树高度 | BF |
|:---:|:---:|:---:|:---:|
| 18 | 0 | 0 | **0** |
| 40 | 0 | 0 | **0** |
| 80 | 0 | 0 | **0** |
| 30 | 1（子树18） | 1（子树40） | **0** |
| 66 | 0 | 1（子树80） | **−1** |
| 50 | 2（子树30） | 2（子树66） | **0** |

**结论**：所有结点的 |BF| ≤ 1，当前 T 满足平衡条件。**是平衡二叉树。**

---

## 第（2）题：依次插入 25、10、55，每次插入后检查并调整

### ① 插入 25

**BST 插入路径**：50 → 30 → 18 → 25

25 < 50 往左，25 < 30 往左，25 > 18 往右，18 的右子树为空，插入 25 作为 18 的右孩子。

插入后检查各结点 BF：

- 结点 18：左子树高度 = 0（无左子树之前也没变），右子树高度 = 1（25 是叶子）→ BF = 0 − 1 = **−1**
- 结点 30：左子树高度 = 2（18→25），右子树高度 = 1（40）→ BF = 2 − 1 = **1**
- 结点 50：左子树高度 = 3（30→18→25），右子树高度 = 2（66→80）→ BF = 3 − 2 = **1**

所有 |BF| ≤ 1，**未失衡，无需调整。**

插入 25 后的树：
```
            50
           /  \
         30    66
        /  \     \
      18   40    80
        \
        25
```

---

### ② 插入 10

**BST 插入路径**：50 → 30 → 18 → 10

10 < 50 往左，10 < 30 往左，10 < 18 往左，18 的左子树为空，插入 10 作为 18 的左孩子。

插入后检查各结点 BF：

- 结点 18：左子树高度 = 1（10），右子树高度 = 1（25）→ BF = 0
- 结点 30：左子树高度 = 2（18→10 / 18→25），右子树高度 = 1（40）→ BF = 1
- 结点 50：左子树高度 = 3（30→18→...），右子树高度 = 2（66→80）→ BF = 1

所有 |BF| ≤ 1，**未失衡，无需调整。**

插入 10 后的树：
```
            50
           /  \
         30    66
        /  \     \
      18   40    80
      / \
    10   25
```

---

### ③ 插入 55

**BST 插入路径**：50 → 66 → 55

55 < 50 往左？不，55 > 50 往右。55 < 66 往左，66 的左子树为空，插入 55 作为 66 的左孩子。

插入后检查各结点 BF：

- 结点 66：左子树高度 = 1（55），右子树高度 = 1（80）→ BF = 0
- 结点 50：左子树高度 = 3（30→18→10/25），右子树高度 = 2（66→55/80）→ BF = 3 − 2 = **1**

所有 |BF| ≤ 1，**未失衡，无需调整。**

插入 55 后的树：
```
            50
           /  \
         30    66
        /  \   /  \
      18   40 55   80
      / \
    10   25
```

## 第（3）题：最终 AVL 树形态

三次插入全部完成后（均未触发旋转），最终树为：

```
                50
               /  \
             30    66
            /  \   /  \
          18   40 55   80
          / \
        10   25
```

各结点的关键字、左右孩子及平衡因子：

| 结点 | 左孩子 | 右孩子 | BF |
|:---:|:---:|:---:|:---:|
| 50 | 30 | 66 | 1 |
| 30 | 18 | 40 | 1 |
| 66 | 55 | 80 | 0 |
| 18 | 10 | 25 | 0 |
| 40 | — | — | 0 |
| 55 | — | — | 0 |
| 80 | — | — | 0 |
| 10 | — | — | 0 |
| 25 | — | — | 0 |

所有结点 |BF| ≤ 1，最终树满足平衡条件。

## 第（4）题：中序遍历序列

对最终 AVL 树进行中序遍历（左子树 → 根 → 右子树）：

```
10 → 18 → 25 → 30 → 40 → 50 → 55 → 66 → 80
```

中序遍历序列严格递增，验证了 BST 性质不变。
