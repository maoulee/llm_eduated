## 题目

# Q41 平衡二叉树（AVL 树）的插入与旋转

**总分：16 分**

将关键字序列 $S = [30, 20, 10, 15, 25, 5, 40, 50, 45]$（共 $9$ 个**互不相同**的关键字）按照先后顺序依次插入到**初始为空**的平衡二叉树（AVL 树）中。插入过程中，若某节点平衡因子的绝对值超过 1，则需进行相应的旋转操作以恢复平衡。

> 说明：本题中平衡因子 BF = 左子树高度 − 右子树高度。

---

### 问题 1（4 分）

在依次插入关键字 $30, 20, 10, \ldots$ 的过程中，**首次发生失衡**是在插入哪个关键字之后？

（1）写出首次失衡时**最小不平衡子树的根节点**及其平衡因子。

（2）写出首次失衡时**该最小不平衡子树的根节点的左右子节点各自的平衡因子**。

---

### 问题 2（6 分）

针对问题 1 中识别出的首次失衡：

（1）判断应执行的**旋转类型**（LL 旋转（右旋） / RR 旋转（左旋） / LR 旋转（先左旋后右旋） / RL 旋转（先右旋后左旋）），并说明判断依据。

（2）画出执行该旋转后的 AVL 树的结构，并**标出各节点的平衡因子**。

---

### 问题 3（6 分）

在问题 2 旋转恢复平衡后，继续依次插入序列中剩余的关键字，直到**再次发生失衡**。

（1）第二次失衡发生在插入哪个关键字之后？其**最小不平衡子树的根节点**是什么？

（2）判断第二次应执行的**旋转类型**（LL 旋转（右旋） / RR 旋转（左旋） / LR 旋转（先左旋后右旋） / RL 旋转（先右旋后左旋）），并说明判断依据。

（3）画出第二次旋转后**最终的 AVL 树的结构**，并标出各节点的平衡因子。

## 参考答案

| 问题 | 答案 |
|------|------|
| 1(1) | 首次失衡在插入 **10** 后；最小不平衡子树的根节点为 **30**，BF = **2** |
| 1(2) | 左子节点 20：BF = **1**；右子节点：空（不存在） |
| 2(1) | **LL 旋转（右旋）**：根节点 BF=2>1（左侧失衡），左子节点 BF=1≥0（左-左型） |
| 2(2) | 旋转后树根为 20，左子节点 10，右子节点 30，所有 BF=0 |
| 3(1) | 第二次失衡在插入 **45** 后；最小不平衡子树的根节点为 **40**，BF = **−2** |
| 3(2) | **RL 旋转（先右旋后左旋）**：根节点 BF=−2<−1（右侧失衡），右子节点 50 的 BF=1>0（右-左型） |
| 3(3) | 最终树根为 20，右子树根为 30→右子节点 45（45 的左右子节点为 40、50） |

## 解析

> 约定：平衡因子 BF = 左子树高度 − 右子树高度。

---

### 逐步插入过程

**第 1 步：插入 30**

```
30(BF=0)
```

**第 2 步：插入 20**

```
30(BF=1)
└── 20(BF=0)
```

节点 30 的左子树高度 1，右子树高度 0，BF = 1，未失衡。

**第 3 步：插入 10 ★首次失衡**

```
30(BF=2)
├── 20(BF=1)
│   └── 10(BF=0)
└── (空)
```

节点 30 的 BF = 2，**|BF| > 1，首次发生失衡**。

---

### 问题 1（4 分）

**（1）首次失衡的最小不平衡子树的根节点及其平衡因子**

首次失衡发生在**插入关键字 10** 之后。

- **最小不平衡子树的根节点**：30
- **BF = 2**（左子树高度 2 − 右子树高度 0 = 2）

**（2）根节点的左右子节点各自的平衡因子**

- **左子节点 20**：BF = 1（左子树高度 1，右子树高度 0）
- **右子节点**：空（不存在）

---

### 问题 2（6 分）

**（1）旋转类型判断**

**应执行 LL 旋转（右旋）**。

判断依据：
- 最小不平衡子树的根节点 30 的 BF = 2（> 1），说明失衡在左子树一侧。
- 其左子节点 20 的 BF = 1（≥ 0），说明新插入的节点位于左子节点的左子树上。
- 因此属于"左-左"（LL）型失衡，应执行 **LL 旋转（右旋）**：以节点 20 为支点，将节点 30 顺时针旋转下来。

**（2）LL 旋转后的 AVL 树**

旋转操作：节点 20 上升为根，节点 30 成为 20 的右子节点。

```
20(BF=0)
├── 10(BF=0)
└── 30(BF=0)
```

所有节点 BF 均为 0，树恢复平衡。

---

### 继续插入（第 4～8 步）

**第 4 步：插入 15**

```
20(BF=1)
├── 10(BF=-1)
│   └── 15(BF=0)
└── 30(BF=0)
```

**第 5 步：插入 25**

```
20(BF=0)
├── 10(BF=-1)
│   └── 15(BF=0)
└── 30(BF=1)
    └── 25(BF=0)
```

**第 6 步：插入 5**

```
20(BF=0)
├── 10(BF=0)
│   ├── 5(BF=0)
│   └── 15(BF=0)
└── 30(BF=1)
    └── 25(BF=0)
```

**第 7 步：插入 40**

```
20(BF=0)
├── 10(BF=0)
│   ├── 5(BF=0)
│   └── 15(BF=0)
└── 30(BF=0)
    ├── 25(BF=0)
    └── 40(BF=0)
```

**第 8 步：插入 50**

```
20(BF=-1)
├── 10(BF=0)
│   ├── 5(BF=0)
│   └── 15(BF=0)
└── 30(BF=-1)
    ├── 25(BF=0)
    └── 40(BF=-1)
        └── 50(BF=0)
```

各节点 |BF| ≤ 1，未失衡。

**第 9 步：插入 45 ★第二次失衡**

插入 45 后，45 挂在 50 的左子节点位置。此时节点 40 的左子树高度 0、右子树高度 2，BF = −2，**发生第二次失衡**。

---

### 问题 3（6 分）

**（1）第二次失衡的触发关键字及最小不平衡子树的根节点**

- **触发关键字**：45（插入 45 后发生第二次失衡）
- **最小不平衡子树的根节点**：40
- **BF = −2**（左子树高度 0 − 右子树高度 2 = −2）

**（2）旋转类型判断**

**应执行 RL 旋转（先右旋后左旋）**。

判断依据：
- 最小不平衡子树的根节点 40 的 BF = −2（< −1），说明失衡在右子树一侧。
- 其右子节点 50 的 BF = 1（> 0），说明新插入的节点位于右子节点的左子树上。
- 因此属于"右-左"（RL）型失衡，应执行 **RL 旋转（先右旋后左旋）**：先将节点 50 的左子树（以 45 为根）右旋，使 45 上升代替 50 的位置；再将节点 40 左旋，使 45 上升为该子树的根。

**（3）第二次旋转（RL 旋转）后的最终 AVL 树**

RL 旋转操作：
1. 先对节点 50 的子树进行右旋：45 上升，50 成为 45 的右子节点。
2. 再对节点 40 进行左旋：45 上升代替 40 的位置，40 成为 45 的左子节点。

旋转后 45 挂接为节点 30 的右子节点：

```
20(BF=-1)
├── 10(BF=0)
│   ├── 5(BF=0)
│   └── 15(BF=0)
└── 30(BF=-1)
    ├── 25(BF=0)
    └── 45(BF=0)
        ├── 40(BF=0)
        └── 50(BF=0)
```

各节点 BF：

| 节点 | BF | 说明 |
|------|-----|------|
| 20 | −1 | 左子树高度 2，右子树高度 3 |
| 10 | 0 | — |
| 5 | 0 | — |
| 15 | 0 | — |
| 30 | −1 | 左子树高度 1，右子树高度 2 |
| 25 | 0 | — |
| 45 | 0 | 左子树高度 1，右子树高度 1 |
| 40 | 0 | — |
| 50 | 0 | — |

**中序遍历**：5, 10, 15, 20, 25, 30, 40, 45, 50（单调递增，验证 BST 性质保持）。

所有节点 |BF| ≤ 1，树恢复平衡。
