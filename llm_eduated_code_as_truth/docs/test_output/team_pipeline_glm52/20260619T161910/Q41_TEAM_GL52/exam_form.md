## examination_form
- 考察形式：多步串行推演（主导）+ 陷阱辨析（辅助）
- 设问方向：给定关键字序列逐步插入初始为空的 AVL 树，要求学生维护平衡因子动态变化、识别首次及后续失衡、辨析并选择正确的旋转类型（LL/RR/LR/RL），并表达旋转后的树结构

## k_radar
- K1（基础认知）: 3
- K2（单步代入）: 1
- K3（机制推演）: 4
- K4（条件路由）: 4
- K5（跨域联动）: 1
- 形状主导维度：K3-K4 平衡型

## rationale
- 为何选此形式：AVL 插入天然是 >5 步的串行流程（逐个插入→更新 BF→判断失衡→路由旋转类型→执行旋转→更新结构），K3=4 由长程推演支撑；四种旋转类型的判断需根据最小不平衡子树根及其子节点的 BF 符号路由到正确操作，隐含前提较深，K4=4 由此支撑。主形式为多步串行推演覆盖 K3，辅助形式为陷阱辨析覆盖 K4（旋转类型误判路径区分）。
- 与目标 K-雷达的对齐说明：K3-K4 平衡型与 difficulty=4 一致——K3=4 来自序列插入的多步动态状态维护，K4=4 来自双旋（LR/RL）触发条件的精准辨析。K1=3 需准确记忆平衡因子定义与四种旋转标准，K2=1 无数值计算需求，K5=1 纯单知识点内部解决不涉及跨系统联动。
