## 题目

某计算机主频为500MHz，程序P运行过程中共执行了2×10^6条指令，其中75%的指令执行平均需2个时钟周期，25%的指令执行平均需6个时钟周期。程序P的CPU执行时间是（）。

A. 8ms
B. 12ms
C. 16ms
D. 32ms

## 求解过程

**步骤1：计算各类指令数量**
- 快速指令数 = 2×10^6 × 75% = 1.5×10^6 条
- 慢速指令数 = 2×10^6 × 25% = 0.5×10^6 条

**步骤2：计算总时钟周期数**
- 快速指令消耗的时钟周期 = 1.5×10^6 × 2 = 3×10^6 个周期
- 慢速指令消耗的时钟周期 = 0.5×10^6 × 6 = 3×10^6 个周期
- 总时钟周期数 = 3×10^6 + 3×10^6 = 6×10^6 个周期

**步骤3：计算CPU执行时间**
- 主频 = 500MHz = 500×10^6 Hz
- CPU执行时间 = 总时钟周期数 / 主频 = 6×10^6 / (500×10^6) = 0.012s = 12ms

## 答案

B. 12ms

## 设计说明

- **考察模式**：计算型——公式应用与单位换算
- **核心公式**：CPU执行时间 = IC × CPI / f
- **干扰项设计**：
  - A（8ms）：仅取CPI=2，忽略25%指令（遗漏变量陷阱）
  - C（16ms）：CPI算术平均(2+6)/2=4（忽视加权概念）
  - D（32ms）：CPI直接相加2+6=8（不理解CPI物理意义）
- **K值定位**：K1=3（标准），K2=3（标准），K3=1（微弱），K4=2（较低），K5=1（微弱），雷达形状为K1-K2平衡型
