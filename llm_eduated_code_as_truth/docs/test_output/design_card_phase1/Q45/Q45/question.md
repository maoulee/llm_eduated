# Q45 虚拟存储器与Cache协同工作

某计算机采用页式虚拟存储管理方式，按字节编址，虚拟地址为32位，物理地址为24位，页大小为64B。TLB采用全相联映射。Cache数据区大小为32KB，采用4路组相联映射，主存块大小为64B。存储访问过程的示意图如下：

```
┌─────────────────────────────────────────────────┐
│                  虚拟地址 (32位)                  │
│  ┌──────────────────────┬──────────┐            │
│  │          A           │    B     │            │
│  └──────────┬───────────┴────┬─────┘            │
│             │                │                   │
│             ▼                ▼                   │
│  ┌─────────────────┐  ┌──────────────┐          │
│  │      TLB        │  │    页表      │          │
│  │    (全相联)     │  │   (主存中)   │          │
│  └────────┬────────┘  └──────┬───────┘          │
│           │                  │                   │
│           └────────┬─────────┘                   │
│                    ▼                             │
│  ┌──────────────────────────────────┐            │
│  │         物理地址 (24位)           │            │
│  │  ┌────────┬────────┬──────────┐  │            │
│  │  │   C    │    D   │    E     │  │            │
│  │  └───┬────┴───┬────┴────┬─────┘  │            │
│  │      │        │         │         │            │
│  └──────┼────────┼─────────┼─────────┘            │
│         │        │         │                       │
│         ▼        ▼         ▼                       │
│  ┌──────────────────────────────────┐            │
│  │           Cache (32KB)           │            │
│  │  ┌────────┬────────┬──────────┐  │            │
│  │  │   F    │    G   │    E     │  │            │
│  │  └────────┴────────┴──────────┘  │            │
│  └──────────────────────────────────┘            │
└─────────────────────────────────────────────────┘
```

请回答下列问题：

### (1) （3分）
计算图中字段A～G的位数各是多少？TLB的标记字段中存放的是什么信息？

### (2) （4分）
已知虚拟地址 `0x00123456` 对应的页表项中物理页号为 `0x003A5`。将该虚拟地址转换为物理地址后，判断该地址访问Cache时映射到的Cache组号是多少？对应的Cache标记（Tag）字段的值是多少（用十六进制表示）？

### (3) （3分）
在TLB缺失的情况下，是否可能出现Cache命中的情况？请结合本题的系统配置说明理由。

## 设计说明

### 考察结构模式
选用**模式A：虚拟-Cache协同映射追踪结构**（来自经验卡）

### 子问依赖关系

| 子问题 | 依赖 | 说明 |
|--------|------|------|
| (1) | 无（题干条件） | 基础参数计算：根据系统参数推导虚拟地址、物理地址、Cache地址各字段位数 |
| (2) | (1)的输出 | 核心推演：利用(1)中得到的地址字段划分，完成虚拟地址→物理地址转换，再提取Cache的Index和Tag |
| (3) | (1)的输出 | 区分度分析：基于地址字段划分，分析TLB与Cache的交互关系 |

### should_be对照

1. **以"地址转换链路"为核心**：本题从虚拟地址字段划分→地址转换→Cache映射，完整覆盖地址转换链路
2. **考察从虚拟地址到物理地址再到Cache数据块的完整路径推演**：子问(2)要求完成虚拟地址→物理地址→Cache组号/Tag的完整推演
3. **重点在于层级间的字段对应关系**：子问(1)要求计算所有字段位数，子问(3)要求分析TLB与Cache的字段关系

### should_not_be排查

1. **未直接使用虚拟地址的某几位作为Cache的Index**：子问(2)明确要求先转换为物理地址，再提取Cache字段
2. **未混淆页内偏移与Cache块内偏移**：页大小=块大小=64B，页内偏移与Block Offset均为6位，示意图中B→E的对应关系准确，同时通过字段划分让学生理解两者在逻辑层级上的区别

### 知识点选取理由

- **页式虚拟存储地址转换**：子问(1)和(2)考察虚拟地址字段划分和地址转换
- **TLB工作原理**：子问(1)考察TLB标记内容，子问(3)考察TLB与Cache的交互
- **Cache组相联映射机制**：子问(1)和(2)考察Cache地址字段划分和映射判断
- **虚拟存储与Cache的协同工作**：子问(3)考察TLB缺失与Cache命中的关系

### 参数选择理由

- **虚拟地址32位、物理地址24位**：经典配置，便于计算
- **页大小64B（2^6）**：页内偏移6位，与Cache块大小一致，使页内偏移=Block Offset，示意图中B→E的对应关系准确
- **Cache 32KB、4路组相联、块大小64B**：
  - 块内偏移 = log2(64) = 6位
  - Cache行数 = 32KB / (4路 × 64B) = 128行
  - 组号 = log2(128) = 7位
  - Tag = 24 - 7 - 6 = 11位
  - 所有参数均为2的幂，便于计算
- **TLB全相联映射**：经典配置，全相联映射无需Index字段，表项数量不影响地址字段划分

### 与契约K值的对齐说明

- **K1=3（标准）**：需准确记忆页内偏移、物理地址位数、Cache组相联映射地址结构（Tag-Index-Offset）等核心定义
- **K2=3（标准）**：需代入公式计算位宽（log2(64B)=6, log2(32KB/4/64B)=7等），涉及多步对数计算和减法运算
- **K3=4（较高）**：需走完多步流程：①由页大小求页内偏移；②由虚拟/物理地址总长求VPN/PPN位数；③由Cache参数求Cache地址字段；④由特定虚拟地址推导物理地址；⑤提取Cache的Index和Tag。推演步数>5步
- **K4=4（较高）**：存在隐含前提——TLB全相联与Cache组相联的映射机制不同需切换思维；页内偏移与Block Offset位数相同但逻辑层级不同
- **K5=5（极高）**：多系统深度耦合——需打通虚拟内存系统（页式管理、TLB）与Cache系统（组相联映射）的壁垒，理解逻辑地址如何经过MMU转换为物理地址，物理地址如何进一步分解用于访问Cache
