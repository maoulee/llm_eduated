# TEST_SC 题目

## 题干

给定一组叶子节点的权值集合 $W = \{2, 3, 5, 7\}$。

按照哈夫曼树的构造规则（每次选取权值最小的两棵子树合并），构造对应的哈夫曼树。

定义带权路径长度 WPL 为所有叶子节点的权值与其到根节点路径长度（边数）的乘积之和，即：
$$WPL = \sum_{i=1}^{n} w_i \times l_i$$
其中 $l_i$ 为第 $i$ 个叶子节点到根节点的路径长度（根节点深度为 0）。

则该哈夫曼树的带权路径长度 WPL 为（ ）。

## 选项

A. 32

B. 49

C. 44

D. 9

## 设计说明

### 参数约束要求

供 `design_solve` 搜索参数使用：

1. **权值集合 $W = \{w_1, w_2, w_3, w_4\}$**：
   - 4 个叶子节点
   - $w_i$ 为正整数，互不相等
   - 数值适中（建议范围 1-50），避免过大数字
   - 需确保哈夫曼构造过程中每一步的合并选择唯一明确

2. **选项值约束**：
   - $V_A$：正确 WPL 值（按标准哈夫曼构造计算）
   - $V_B$：干扰值，对应 off-by-one 深度计数错误（根节点深度计为 1 而非 0）
   - $V_C$：干扰值，对应哈夫曼构造策略错误（未按贪心策略合并最小两棵子树）
   - $V_D$：干扰值，对应概念混淆（计算路径长度之和 $\sum l_i$ 而非带权路径长度 $\sum w_i \times l_i$）

3. **数值合理性**：
   - 正确值 $V_A$ 应在合理范围内（建议 50-300）
   - 各干扰值应与正确值有合理差异，避免靠猜测排除

### 术语约束

- 必须使用"带权路径长度"或"WPL"
- 必须使用"哈夫曼树"
- 必须明确"路径长度"定义为"从根节点到该节点的边数"（根节点深度为 0）
- 禁止出现"哈夫曼编码"相关表述
