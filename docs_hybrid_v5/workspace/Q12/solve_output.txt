===== 平均 CPI 计算 =====
第1类指令: 比例=0.50, CPI=1, 加权贡献=0.50
第2类指令: 比例=0.25, CPI=2, 加权贡献=0.50
第3类指令: 比例=0.25, CPI=4, 加权贡献=1.00
平均 CPI = 2.00
===== CPU 时钟周期数计算 =====
指令条数 IC = 4000000
平均 CPI = 2
总 CPU 周期数 = IC × CPI = 8000000
===== CPU 执行时间计算 =====
CPU 主频 = 2000000000 Hz
CPU 执行时间 = 总 CPU 周期数 / 主频 = 0.004 s
CPU 执行时间 = 4 ms
===== 逐选项验证 =====
选项 A: 2 ms, 与计算结果差值 = 2 ms, 判断 = 错误
选项 B: 4 ms, 与计算结果差值 = 0 ms, 判断 = 正确
选项 C: 8 ms, 与计算结果差值 = 4 ms, 判断 = 错误
选项 D: 16 ms, 与计算结果差值 = 12 ms, 判断 = 错误
ANSWER: B
