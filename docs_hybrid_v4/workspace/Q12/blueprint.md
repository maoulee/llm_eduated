## 出题要求
- 题目类型：单选题（single_choice）
- 参数约束：
  - 指令条数：10^8 量级（如 1×10^8 条）
  - CPI：非整数（如 2.5），增加计算复杂度，避免纯2的幂次友好计算
  - 时钟频率：GHz量级（如 2GHz = 2×10^9 Hz）
  - 计算结果：涉及小数运算（如 0.125s），非整数结果
- 条件设计指引：
  - 题干直接给出所有必要参数，无隐藏条件（K4=1）
  - 选项设计：包含常见计算错误结果（如忘记单位换算、公式用错、CPI与频率位置颠倒等）
  - 考察学生对性能指标公式的准确记忆（K1=3）和代入计算能力（K2=3）
  - 不涉及多步推演（K3=1），单一知识点内部解决（K5=1）
