===== Cache 地址划分计算 =====
主存地址位数: 32
Cache 行数: 128
主存块大小: 64B
访问地址: 0x1234ABCD
Offset 位数 = log2(64) = 6
Index 位数 = log2(128) = 7
Tag 位数 = 32 - 7 - 6 = 19

===== Cache 行号计算 =====
主存块号 = 地址 >> Offset位数 = 0x1234ABCD >> 6 = 4772527
直接映射 Cache 行号 = 主存块号 mod Cache行数 = 4772527 mod 128 = 47
Index 掩码 = Cache行数 - 1 = 128 - 1 = 0x7F
按位提取 Index = (0x1234ABCD >> 6) & 0x7F = 47
Cache 行号二进制 = 0101111

===== 逐选项验证 =====

  行号验证: 47 == 47 -> True
  Tag位数验证: 19 == 19 -> True
