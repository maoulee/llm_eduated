## 题目
某计算机采用直接映射 Cache，主存地址为 32 位。Cache 共有 128 行，每个主存块大小为 64B。若某次访问的主存地址为 `0x1234ABCD`，则该地址对应的 Cache 行号和 Tag 字段位数分别是（  ）。


## 选项
- A: 47，19
- B: 47，25
- C: 45，19
- D: 95，18


## 解题过程
===== Cache 地址划分计算 =====
主存地址位数: 32
Cache 行数: 128
主存块大小: 64B
访问地址: 0x1234ABCD
Offset 位数 = log2(64) = 6
Index 位数 = log2(128) = 7
Tag 位数 = 32 - 7 - 6 = 19

===== Cache 行号计算 =====
主存块号 = 地址 >> Offset位数 = 0x1234ABCD >> 6 = 4772527
直接映射 Cache 行号 = 主存块号 mod Cache行数 = 4772527 mod 128 = 47
Index 掩码 = Cache行数 - 1 = 128 - 1 = 0x7F
按位提取 Index = (0x1234ABCD >> 6) & 0x7F = 47
Cache 行号二进制 = 0101111

===== 逐选项验证 =====
选项 A: 行号=47, Tag位数=19
  行号验证: 47 == 47 -> True
  Tag位数验证: 19 == 19 -> True
  选项 A 是否正确: True

  行号验证: 45 == 47 -> False
  Tag位数验证: 19 == 19 -> True
  选项 C 是否正确: False

  行号验证: 95 == 47 -> False

最终计算结果: Cache行号=47, Tag字段位数=19
ANSWER: A


## 答案
正确答案：A

直接映射 Cache 中，主存地址结构为：

Tag | Index | Offset

每个主存块大小为 64B，因此块内偏移字段位数为：

\[
\log_2 64 = 6
\]

Cache 共有 128 行，因此行索引字段位数为：

\[
\log_2 128 = 7
\]

主存地址为 32 位，因此 Tag 字段位数为：

\[
32 - 7 - 6 = 19
\]

接着计算 Cache 行号。直接映射规则为：

\[
\text{Cache行号} = \text{主存块号} \bmod \text{Cache行数}
\]

主存块号等价于主存地址右移 6 位，即去掉 Offset 字段。Cache 行号是其低 7 位：

\[
\text{Index} = (0x1234ABCD >> 6) \& 0x7F
\]

将地址末尾部分转换分析：

\[
0xABCD = 1010\ 1011\ 1100\ 1101_2
\]

去掉低 6 位 Offset 后，再取低 7 位，得到：

\[
0101111_2 = 47
\]

因此，该地址对应的 Cache 行号为 47，Tag 字段位数为 19。


## 设计说明
本题考查直接映射 Cache 的地址划分与映射规则，覆盖主存地址结构 Tag-Index-Offset、块内偏移位数、Cache 行索引位数和直接映射行号计算。

参数选择上，块大小取 64B，Cache 行数取 128 行，均为 2 的幂，便于考生快速得到 Offset 为 6 位、Index 为 7 位。主存地址采用 32 位十六进制数 `0x1234ABCD`，长度适中，既能体现地址字段划分，又不会造成复杂计算负担。

干扰项设计如下：B 将 Tag 位数误算为忽略 Offset 后的剩余位数；C 对 Index 字段取值出现二进制截取错误；D 同时包含 Index 位数或截取范围错误与 Tag 位数错误。整体难度对齐 K=3，中等偏基础，主要考查概念准确性和简单位运算。
