# 选择题出题技能

> 行为约束（契约忠实、K难度忠实、不写答案、参数闭环、格式红线）已定义在 agents/question_sc.md。
> 本文件定义出题的执行步骤、领域模板和经验卡消费规范。

## 工作流程

### 设计题干（写 question.md）

**目标**：基于蓝图设计完整选择题，**直接产出 question.md**。

1. 阅读 assembled.md（蓝图），提取知识点、考察模式、K难度、题型结构
2. 在思考中设计题干、选项、干扰策略、设计说明
3. **直接 write_file(question.md)** — 不做数值校验

**只关注**：
- 知识点与蓝图对齐
- 考察形式符合要求
- 选项设计合理（干扰项有效）
- 题干风格像408真题

**数值参数校验不在此阶段** — 参数自洽性和数值修订由求解智能体负责。

## 题干风格模板

### 计算型题干标准格式
- 一句话给定参数 + 一句话提问
- 示例："某计算机主频为1GHz，程序P共执行了10000条指令，其中80%的指令CPI为1，20%的指令CPI为10。程序P的平均CPI和CPU执行时间分别是（）。"
- 提问格式："...的值是（）"/"...分别是（）"/"...结果为（）"

### 概念辨析型题干标准格式
- 一句话描述场景或定义 + "下列选项中，____的是（）。"
- 示例："下列选项中，描述浮点数操作速度指标的是（）。"
- 提问格式："下列关于...的说法中，正确的是（）"/"...是（）"

### 组合判断型题干标准格式
- 列出命题I/II/III + "A.仅I和II  B.仅I和III  C.仅II和III  D.I、II和III"
- 命题数量不超过3个

## 选项设计模式

### 计算型选项
- **单位换算陷阱**: 正确值的不同单位表示
- **符号错误**: 正确值的相反数/补码
- **偏移错误**: 正确值±1或偏离某个固定量
- **中间值**: 计算过程中的某个中间结果
- **倒置**: 速度/时间的倒数、比率的分子分母互换

### 概念型选项
- **概念混淆**: 相似但不同的概念替换
- **过度推断**: 从正确前提出错误推论
- **条件遗漏**: 忽略某个约束后的错误结论
- **张冠李戴**: 将A概念的特征安在B概念上

### 组合判断型选项
- I/II/III各代表一个独立命题
- 干扰项中包含真命题和假命题的混合

## 经验卡消费规范

蓝图（assembled.md）中包含经验卡的考察模式分析和出题指导。出题前必须先提取以下信息：

### 必提取项（从经验卡"出题指导"部分）

1. **should_be**：这个题位应该出什么样的题
2. **should_not_be**：这个题位不应该出什么样的题
3. **建议考察模式分布**：如 {"机制推演型": 40%, "复杂度计算型": 35%}
4. **建议选项风格分布**：如 {"数字结果": 55%, "概念判断": 25%}

### 设计说明必写项

```markdown
## 设计说明
- 考察模式：[选用的模式名称]（来自经验卡建议分布）
- 选项风格：[数字结果/概念判断/组合判断]（来自经验卡建议分布）
- should_be对照：逐条说明本题如何满足
- should_not_be排查：逐条确认未触犯
- 参数选择理由（为何选 2^n 基底）
- 干扰项设计策略（每个干扰项针对的错误认知）
- 与契约 K 值的对齐说明
```

## 参数校验关注点

数值参数校验由求解智能体负责，出题阶段不校验。
