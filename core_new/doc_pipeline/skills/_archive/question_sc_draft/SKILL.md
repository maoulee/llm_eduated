# 选择题出题技能（具体逻辑）

> 通用行为（角色、思考控制、核心原则、红线）定义在 agents/question_sc.md。
> 本文件定义出题流程、参数经验、题干风格。**不放通用干扰模式**（那些归 design_card_v1/SKILL.md，由设计卡选定干扰策略）。

## 出题流程（标准题）

### Step 1：读设计卡

优先读取 design_card.md：
- blueprint_contract（考点范围）
- core_knowledge_intent（核心知识点意图）
- question_structure_plan（题型结构）
- parameter_plan（参数规划）
- terminology_and_expression_constraints（术语约束）
- 干扰策略（设计卡已选定用哪些干扰类型，你只实现，不自己选）

assembled.md 仅用于补充经验卡的 should_be / should_not_be，**不得**把 design_card 未选的知识点加入题目。

### Step 2：设计题干

按题干风格模板（见下）设计题干框架。题干给参数、给场景、给提问，**不给答案值**。

### Step 3：设计求解意图与干扰意图

写清题目希望考生完成的解题动作，以及 3 类干扰选项对应的错误认知路径。

**设计说明里必须交代**：
1. 正确解题动作：从题干哪些条件推到哪个目标量。
2. 干扰意图：每个干扰项对应哪类错误认知（单位错/符号错/漏项/中间结果等）。
3. 参数边界：哪些条件是求解必需的，哪些限定用于避免歧义。
4. 不给具体答案值或最终选项值。

### Step 4：输出

- write_file(question.md) — 题干 + 设计说明（不含答案值）
- **不写最终选项值** — 选项由后续阶段基于答案组装

## 题干风格模板

### 计算型题干
- 一句话给定参数 + 一句话提问
- 示例："某计算机主频为1GHz，程序P共执行了10000条指令，其中80%的指令CPI为1，20%的指令CPI为10。程序P的平均CPI和CPU执行时间分别是（）。"
- 提问格式："...的值是（）"/"...分别是（）"/"...结果为（）"

### 概念辨析型题干
- 一句话描述场景或定义 + "下列选项中，____的是（）。"
- 提问格式："下列关于...的说法中，正确的是（）"/"...是（）"

### 组合判断型题干
- 列出命题 I/II/III + "A.仅I和II  B.仅I和III  C.仅II和III  D.I、II和III"
- 命题数量不超过 3 个

## 参数选择经验

- **优先 2^n 友好值**：主频、容量、计数等参数选 2 的幂或其倍数，便于计算和心算验证
- **避免无意义大数**：参数应在合理量级，不堆无意义的精确值
- **边界值显式**：循环边界、数组下标等边界条件在题干中明确给出

## 设计说明必写项

```markdown
## 设计说明
- 考察模式：[选用的模式名称]
- 参数选择理由（为何选 2^n 基底）
- 解题意图（正确解题动作）
- 干扰意图（每个干扰项对应的错误认知路径，对应设计卡选定的干扰类型）
- 与契约 K 值的对齐说明
- should_be 对照 / should_not_be 排查
```

## 概念题出题（complexity == "conceptual"）

概念题无数值计算需求：
- 正常设计题干 + 选项
- 直接写 solution.md（推理基于标准教材定义）
