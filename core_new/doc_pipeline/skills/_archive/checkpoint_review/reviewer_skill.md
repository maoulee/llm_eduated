# 审核智能体技能

## 审核原则

列表式检查，每项给结论不给推导。偏差不大就通过。review.md 总内容不超过 800 字。

## 适用范围

本技能适用于所有题目类型（选择题 / 综合题）和所有学科（数据结构 / 操作系统 / 计算机组成 / 网络）。检查项和判定规则对所有题目类型通用。

## 检查点判定

根据可用文件判定当前检查点：
- 有 question.md，无 solution.md → **检查点 1**
- 有 question.md + solution.md → **检查点 2**

---

## 检查点 1：题目设计审核

### 状态值

- pass — 题目设计质量达标
- needs_fix — 存在需要修正的问题

### 两阶段检查

#### 阶段 A：列表快扫（逐项判断，看一眼就给结论）

1. **格式红线** — 选择题：4选项1正确、无代码/子问题/背景故事；综合题：编号连续、子问有依赖、无代码/背景故事
2. **408风格** — 题干像真题，不像教科书例题或练习册
3. **知识覆盖** — 蓝图要求的知识点全覆盖
4. **经验卡** — should_not_be 未触犯
5. **选项/子问题结构** — 编号连续、分值合理、子问有递进依赖

#### 阶段 B：K 难度快估（每维一句话，不展开推导）

| 维度 | 锚定问题 | 范围 |
|------|----------|------|
| K1 基础认知 | 需记忆几个概念/定义？ | 1-5 |
| K2 计算复杂 | 计算步骤数和出错概率？ | 1-5 |
| K3 推演步数 | 从给定条件到答案几步推理？ | 1-5 |
| K4 隐含条件 | 有几个陷阱/隐含约束？ | 1-5 |
| K5 跨域联动 | 跨几个子系统/知识点？ | 1-5 |

与目标对比，任何维度偏差≥2 → needs_fix。

### 判定规则

以下任一成立 → needs_fix：
- 格式红线违反
- should_not_be 触犯
- 知识点遗漏
- K 难度偏差≥2
- 选项不唯一正确（选择题）

以上均不成立 → pass。措辞偏好差异不构成 needs_fix。

### 输出格式

```markdown
## status
pass / needs_fix

## summary
1 句话结论

## checklist
- 格式红线：[通过/不通过]（1 词说明问题）
- 408风格：[通过/不通过]（1 词说明问题）
- 知识覆盖：[通过/不通过]（缺少什么知识点）
- 经验卡：[通过/不通过]（触犯了哪条 should_not_be）
- 选项/子问题：[通过/不通过]（问题在哪）
- K难度：[通过/不通过] K1=N K2=N K3=N K4=N K5=N vs 目标（哪个维度偏差大）

## corrections（仅 needs_fix）
必须包含：定位（哪个部分/哪个子问题/哪个选项）+ 当前值 + 应改为什么 + 不要动的部分。
每项 1-2 行，确保 creator 能直接定位并修改。

## improvement_suggestions（可选，pass 时也可写）
0-1 条
```

## 检查点 2：求解一致性终审

### 状态值

- pass — 证据一致、求解正确
- expression_fix — 仅措辞/格式问题
- question_error — 题目设计有根本错误
- solution_error — 数值不一致或求解逻辑错误

### 检查焦点

终审**不重审**检查点 1 已审过的内容（风格、知识点、考察形式）。
聚焦：solution + 证据是否闭环。

### 检查项

#### 数值题
- **证据核对**：solution 答案数值 vs solve_output 数值 → 一致/不一致

#### 概念题
- **推理完整性**：每个子问题/选项有对应分析 → 是/否
- **答案合理性**：答案符合常识和领域知识 → 是/否

### 判定路由

- 证据一致 + 推理完整 → pass
- 仅措辞问题 → expression_fix
- 题目条件矛盾/参数不自洽 → question_error
- 答案数值不一致/推理有误 → solution_error

### 输出格式

```markdown
## status
pass / expression_fix / question_error / solution_error

## summary
1 句话结论

## evidence（数值题）
solution = X, code_output = X → [一致/不一致]（具体哪个子问题不一致）

## reasoning（概念题）
推理完整：[是/否]（缺哪个子问题），答案合理：[是/否]

## routing_feedback（仅 error 时）
定位（哪个部分/哪个子问题）+ 当前值 + 应改为什么 + 不要动的部分。

## improvement_suggestions（可选）
```
