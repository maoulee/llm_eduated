# Skill: 概念题批量出题（conceptual_batch_skill）

你的活：**读考点列表 → 对每个考点出 1 道概念题 → write question.md + solution.md（一次写完）**。

## 工作步骤

1. **读蓝图考点列表 + 每题题型**：从 concept_topics 的【题型】前缀或 slot 的 `题型` 字段读每题题型。有几个考点就出几道（1 个考点 = 1 道题）。
2. **对每个考点按其题型出题**（不总是四选项，题型不同的题不得同化）：
   - **选择题**：题干 + A/B/C/D 四选项（1 对 3 错）+ 答案 + 解析。
   - **填空题**：题干 + 空格（____）+ 答案（填空内容）+ 解析。
   - **判断题**：若干陈述 + 逐条 对/错（√/×）+ 理由。
   - **简答题**：题干（问句）+ 答案 + 解析。
3. **write question.md（所有题）+ solution.md（每题解析）**：一次写完，不分多次调用。

> 批量是核心优势——一次调用出 N 道，比一道一道出快 N 倍。

## 概念题边界（可执行闸）

- **答案是知识回忆**——凭你对知识点的理解直接给，**不算数值、不推演流程、不构造数据结构**。
- 发现自己在"算某个值/推演某算法/构造树矩阵图"→ **停**，那是计算题 gen.py 的活，概念题不需要。

## 输出格式（必须严格遵守）

**每道题必须用 `## 第 N 题` 标题分隔**，N 从 1 递增。系统靠这个拆分多道题，格式错=拆分失败。

### question.md（按题型选格式，不总是四选项）

**选择题**示例：
```markdown
# 概念题

## 第 1 题

**题干**：...

A. 选项A
B. 选项B
C. 选项C
D. 选项D

**答案**：B
```

**填空题**示例（空格，不出选项）：
```markdown
## 第 1 题

**题干**：CPU 由 ____ 和 ____ 两大部件组成。

**答案**：运算器、控制器
```

**判断题**示例（对/错 + 理由，不出选项）：
```markdown
## 第 1 题

判断以下陈述对错：

① DRAM 需要定期刷新。  √
② SRAM 集成度高于 DRAM。  ×

**理由**：①√（电容漏电需刷新）；②×（SRAM 触发器集成度低于 DRAM）。
```

**简答题**示例（问句 + 答，不出选项）：
```markdown
## 第 1 题

**题干**：简述冯·诺依曼体系结构的核心特点。

**答案**：存储程序、以存储器为中心……
```

### solution.md（同样 `## 第 N 题` 分隔）
```markdown
# 概念题解析

## 第 1 题解析

**答案**：B
**解析**：B 正确因为...。A 错误因为...。
```

## 题型决策（优先用显式 题型 字段，不靠 examination_mode 推断）

**题型从 concept_topics 的【题型】前缀或 slot 的 `题型` 字段读**。examination_mode 的 辨析/机制/组合/定义 是选择题内部的考察角度，不是题型本身。
- 单项选择题 → 题干 + A/B/C/D 四选项。
- 填空题 → 题干 + 空格（____），不出选项。
- 判断题 → 陈述 + 对/错（√/×），不出选项。
- 简答题 → 问句 + 答案，不出选项。

## 干扰项

对应**真实认知错误**（概念混淆/过度推断/条件遗漏/张冠李戴），不是随机错误值。
