# 概念题批量出题技能

基于考点列表，**批量**出概念题——一次出多道（每个考点一道），一个 LLM 调用完成全部。

## 批量出题

读蓝图的考点列表，**对每个考点出一道概念题**（一次 write 全部，不分多次调用）：

**题干**：给一个概念场景或辨析提问。
**选项**：A/B/C/D 四选一，1 个正确 + 3 个干扰。
**答案**：正确选项字母。
**解析**：为什么对，每个干扰为什么错（一句话）。

write question.md（所有题，一次写完）+ write solution.md（每题解析）。

**批量是核心优势**——一次 LLM 调用产出 N 道题，比一道一道出快 N 倍。

## 输出格式（必须严格遵守）

**每道题必须用 `## 第 N 题` 作为标题分隔**，N 从 1 开始递增。这是系统拆分多道题的依据，格式不对会导致拆分失败。

question.md 格式：
```markdown
# 概念题

## 第 1 题

**题干**：...

A. 选项A
B. 选项B
C. 选项C
D. 选项D

**答案**：B

## 第 2 题

**题干**：...

A. 选项A
B. 选项B
C. 选项C
D. 选项D

**答案**：C
```

solution.md 格式（同样用 `## 第 N 题` 分隔）：
```markdown
# 概念题解析

## 第 1 题解析

**答案**：B
**解析**：B 正确因为...。A 错误因为...。

## 第 2 题解析

**答案**：C
**解析**：C 正确因为...。
```

## 题型参考

- 概念辨析：两个相似概念，问区别/关系
- 机制理解：描述某过程，问正确表述
- 组合判断：I/II/III 命题，选正确组合
- 定义记忆：谁提出/哪个正确

## 干扰项

对应真实认知错误：概念混淆、过度推断、条件遗漏、张冠李戴。不是随机值。

## 约束

- 直接给答案（概念题答案是知识，不是算出来的）
- 不写代码、不算数值、不构造数据结构
- 每题独立完整（题干+选项+答案+解析）
- **必须用 `## 第 N 题` 标题分隔每道题**（系统拆分依赖此格式）
