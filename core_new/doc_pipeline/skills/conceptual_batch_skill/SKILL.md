# Skill: 概念题批量出题（conceptual_batch_skill）

你的活：**读考点列表 → 对每个考点出 1 道概念题 → write question.md + solution.md（一次写完）**。

## 工作步骤

1. **读蓝图考点列表 + 每题题型**：从 concept_topics 的【题型】前缀或 slot 的 `题型` 字段读每题题型。有几个考点就出几道（1 个考点 = 1 道题）。
2. **对每个考点按其题型出题**（不总是四选项，题型不同的题不得同化）：
   - **选择题**：题干 + A/B/C/D 四选项（1 对 3 错）+ 答案 + 解析。
   - **填空题**：题干 + 空格（____）+ 答案（填空内容）+ 解析。
   - **判断题**：**每题 1 条独立陈述**（每条占 1 个题号）+ 对/错（√/×）+ 理由（写 solution.md，不内联题面）。
   - **简答题**：题干（问句）+ 答案 + 解析。
3. **write question.md（所有题）+ solution.md（每题解析）**：一次写完，不分多次调用。

> 批量是核心优势——一次调用出 N 道，比一道一道出快 N 倍。

## 概念题边界（可执行闸）

- **答案是知识回忆**——凭你对知识点的理解直接给，**不算数值、不推演流程、不构造数据结构**。
- 发现自己在"算某个值/推演某算法/构造树矩阵图"→ **停**，那是计算题 gen.py 的活，概念题不需要。

## 输出格式（必须严格遵守）

**每道题必须用 `## 第 N 题` 标题分隔**，N 从 1 递增。系统靠这个拆分多道题，格式错=拆分失败。

### question.md（按题型选格式，不总是四选项）

**选择题**示例：
```markdown
# 概念题

## 第 1 题

**题干**：...

A. 选项A
B. 选项B
C. 选项C
D. 选项D

**答案**：B
```

**填空题**示例（空格，不出选项）：
```markdown
## 第 1 题

**题干**：CPU 由 ____ 和 ____ 两大部件组成。

**答案**：运算器、控制器
```

**判断题**示例（**每题 1 条独立陈述**，对/错，不出选项；理由写 solution.md）：
```markdown
## 第 1 题

存储器映射 I/O 方式下，I/O 设备与主存共用同一组地址空间。
```
（solution.md 记：**答案**：对（√）。**理由**：统一编址下 I/O 与主存共用地址空间……）

> **判断题风格硬规则**（与常见试卷判断题一致，违反即重写）：
> - **每题 1 条独立陈述**，每条占自己的题号——**禁止**把多条捆成 ①②③④ 一堆、**禁止**"判断以下陈述对错/判断下列各题"这类套话（那是非标准形式）。
> - 陈述是一句**完整的事实性断言**，像真题那样直接陈述、学生在题号后标 对/错。
> - **对/错 + 理由放 solution.md**，不内联 √/× 到题面（题面只给陈述）。
> - 错误陈述做成**隐蔽的概念性错误**（偷换条件/量级错/机制弄反/张冠李戴）；**禁止**用"一定/完全/最不/不可能/不需要/自动"等绝对化信号词当错因——学生一眼猜出绝对词=错，等于无效考查。

**简答题**示例（问句 + 答，不出选项）：
```markdown
## 第 1 题

**题干**：简述冯·诺依曼体系结构的核心特点。

**答案**：存储程序、以存储器为中心……
```

### solution.md（同样 `## 第 N 题` 分隔）
```markdown
# 概念题解析

## 第 1 题解析

**答案**：B
**解析**：B 正确因为...。A 错误因为...。
```

## 题型决策（优先用显式 题型 字段，不靠 examination_mode 推断）

**题型从 concept_topics 的【题型】前缀或 slot 的 `题型` 字段读**。examination_mode 的 辨析/机制/组合/定义 是选择题内部的考察角度，不是题型本身。
- 单项选择题 → 题干 + A/B/C/D 四选项。
- 填空题 → 题干 + 空格（____），不出选项。
- 判断题 → **每题 1 条独立陈述** + 对/错（√/×），不出选项（遵守上方"判断题风格硬规则"：不捆 ①②③④、不加套话、不内联答案、错误项禁绝对化信号词）。
- 简答题 → 问句 + 答案，不出选项。

## 干扰项

对应**真实认知错误**（概念混淆/过度推断/条件遗漏/张冠李戴），不是随机错误值。
