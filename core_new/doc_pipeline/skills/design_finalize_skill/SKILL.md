# 题目设计 P2 技能（定稿，§19.8）

> 通用行为（角色、思考控制、红线）定义在 agents/design.md。
> 本文件定义 **P2 定稿流程**：收到 solve 的解 → 选择题设干扰选项 / 主观题答案填回。**解来自 solve，不重算。**

## 定稿流程

### Step 1：读解（solve 已算出）

读取：
- solve_output.txt（exec 输出，正确答案 + 逻辑标签）
- solution.md（solver 的推理过程）
- question.md（你 P1 写的题干 + 设问 + 经验值参数）

**正确答案 = solve 算出来的值，直接用，不重算、不质疑。**

### Step 2：机械质检（仅可机械判定，不脑内重验）

对照 exec 输出做**机械信号**判定（不是脑内推演参数成不成立）：

| 信号 | 判定 | 动作 |
|------|------|------|
| 答案应整数但含小数 | exec 输出非整数（期望整数） | 改经验值参数（如 n:7→8）并在设计说明注明 |
| 答案平凡（=0/1/或=题面给定值） | 退化解 | 改经验值参数并在设计说明注明 |
| 答案越界（如 depth=100） | 值远超合理范围 | 改经验值参数并在设计说明注明 |
| 正常 | — | 进 Step 3 |

**当前实现**：P2 单次调用内完成质检 + 定稿。若质检发现参数需调，在本轮内改经验值参数并注明理由（编排层尚未实现显式 re-solve 回调循环；如后续实测发现单轮内改参不足，再补编排层 re-solve，cap=1）。**不反复磨参数**（磨参数会退化为新的过度思考源）。

> 纪律：P2 只读 exec 输出做机械比对，**不脑内重算**；发现参数问题只改数值不动逻辑/结构/设问。

### Step 3：设选项 / 答案填回（按题型）

#### 选择题：基于解设 3 个干扰选项（只设不求对）

正确答案已知（来自 solve）。基于正确答案**直接给 3 个合理错值**：

- **干扰非代码计算**：干扰本就要求"错"，不需算对。直接给符合考察要求的合理错值：
  - 从 correct 派生：±offset、off-by-one、符号取反、单位换算错
  - plausible 范围/风格的错值（如正确是某地址，干扰给相邻地址段）
- **干扰意图对应 design_card 选定的认知错误路径**（单位错/符号错/漏项/中间结果等，不是随机常量）。
- **verify distinct**：4 个值（correct + 3 干扰）两两不同 + 干扰不撞 correct。撞了换一个错值。

组装成 A/B/C/D（correct + 3 干扰，**随机化顺序**），edit_file 写入 question.md 选项区。

#### 主观题：答案填回题干

把 solve 算出的各子问答案填回 question.md 的对应子问（题干里的符号占位 → 具体答案值）。edit_file 做最小修改。

### Step 4：输出

- 选择题：question.md 含 A/B/C/D 选项（correct + 3 干扰）
- 主观题：question.md 含填回的答案
- **不碰 solve.py**、**不改题干逻辑/结构**（仅参数数值可改）

## 定稿纪律（§19.2）

- **解来自 solve**：正确答案 = solve_output.txt 的值，不重算、不质疑、不脑内算。
- **仅参数数值可改**：质检不达标时只改经验值参数数值，不动逻辑/结构/设问。
- **干扰只设不求**：干扰是直接给的合理错值，不用代码算。
- **verify distinct**：correct + 3 干扰两两不同。

## 红线

- **不得重算解** — 解来自 solve，直接用。
- **不得改题干逻辑/结构** — 仅参数数值可改。
- **不得碰 solve.py** — 解题代码归 solve。
- **不得用代码算干扰值** — 干扰是直接给的合理错值。
- **不得让干扰撞 correct** — 4 值必须两两不同。
