# 题目审核技能

> 行为约束（checklist判定、最小修改原则、输出格式、禁止行为）已定义在 agents/review.md。
> 本文件定义审核 checklist 维度详解和 fix_instructions 格式规范。

## 审核边界

**审核范围**：题干设计质量 — 知识点、K难度、条件充分性、结构、风格、考察形式、经验卡。
**不审核**：数值参数正确性（由求解智能体负责）、答案正确性（此阶段无答案）。

---

## Checklist 维度

### 1. 知识点一致性
- 列出规划中要求的所有知识点
- 逐一判定题目是否覆盖
- 遗漏或新增 → fail

### 2. K难度范围
- 根据K1-K5评分标准评估实际K值
- 与规划目标对比
- 任一维度偏差>=2级 → fail

### 3. 条件充分性
- 列出题干所有给定条件
- 检查每个条件是否被子问题/选项使用
- 有缺失或冗余条件 → fail

### 4. 选项/子问题结构
- 选择题：4选项1正确，干扰项有效
- 综合题：编号连续，分值合理，子问有串行依赖
- 结构错误 → fail

### 5. 风格合规
- 选择题：题干1-3句话、无子问题拆分、无代码、无背景故事
- 综合题：无选项格式、子问有依赖、无代码、无背景故事
- 违反格式红线 → fail

### 6. 考察形式一致性
- 题目考察形式是否与蓝图规划一致
- 不一致 → fail

### 7. 经验卡对齐
- should_be 逐项核对
- should_not_be 逐项排查
- 触犯 should_not_be → fail

## K难度评分标准

K1 基础认知需求: 1=微弱 2=较低 3=标准 4=较高 5=极高
锚点：不记忆408知识能否入题 → 能则1，需一个核心定义则3，需辨析两个以上易混概念则4-5

K2 单步代入需求: 1=微弱 2=较低 3=标准 4=较高 5=极高
锚点：最复杂的单步计算是否可能算错 → 2的幂友好则2，非2幂次则3，多级换算则4-5

K3 机制推演需求: 1=微弱 2=较低 3=标准 4=较高 5=极高
锚点：从输入到输出需几步 → 1-2步则1-2，3-5步则3，>5步或需记忆中间状态则4-5

K4 条件路由需求: 1=微弱 2=较低 3=标准 4=较高 5=极高
锚点：有没有"题面没说但解题必须意识到的条件" → 无则1，常规注意点则2，陷阱词则3，隐含前提深则4，反直觉则5

K5 跨域联动需求: 1=微弱 2=较低 3=标准 4=较高 5=极高
锚点：是否需在不同子系统间传递数据或状态 → 单系统则1，提及无关则2，单向传数据则3，状态互影响则4，深度耦合则5

## fix_instructions 格式

每个 fix 条目必须包含四要素：

```
- 修改对象：具体哪个选项/条件/参数/措辞
- 修改位置：第N段/第N个子问题/选项X
- 当前问题：为什么需要改（违反了什么规则）
- 修改目标：改成什么样
- 最小修改指令：具体的操作指令
```

示例：
```
- 修改对象：选项B
- 修改位置：选项部分第2项
- 当前问题：干扰项过于明显，可由排除法直接排除
- 修改目标：基于常见误解"虚拟地址=物理地址"构造干扰项
- 最小修改指令：将选项B改为"0x00007FFF"（错误地将虚拟页号当作物理页号的结果）
```
