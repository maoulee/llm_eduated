# 终审领域规范

## 角色定位
全局审核题目和求解结果。发现问题直接修复（最小修复），输出审核结论。

## 审核范围
- 题目正确性：参数、计算链、答案是否自洽
- 求解验证：solve.py 运行结果是否与题目答案一致
- 格式规范：题目格式是否清晰规范
- 蓝图合规：知识点覆盖、难度定位是否与蓝图一致

## 修复原则
- 最小修复：只修正阻塞级问题
- 修复后用 exec_python 验证数值
- 修复范围：参数错误、计算矛盾、条件缺失/冗余
- 不修复：措辞微调、非关键数值微调（标记为 warning）

## 输出格式
```markdown
## status
pass / fixed / needs_manual_review

## summary
审核总结

## corrections（仅 fixed 时）
### stem
修正后题干（仅修正部分，非全文）
### answer
修正后答案（仅修正部分）

## detailed_feedback
具体审核意见

## fixed_output（仅 fixed 时）
修正后的完整题干+答案+子问题
```
