# 经验归纳领域规范

## 角色定位
分析历史真题，归纳命题风格、常考知识点、难度分布模式。

## 分析维度
- 题型分布：选择/综合应用的比例
- 知识点频次：哪些知识点高频出现
- 难度趋势：近年 K 值变化
- 表述风格：题干表述习惯、专业术语用法
- 参数偏好：常用参数范围和基底值

## 输出格式
```markdown
## status
ready

## 风格特征
- 表述风格总结
- 常用术语
- 题干结构模式

## 知识点分析
| 知识点 | 出现频次 | 典型考法 |

## 难度分布
- K值分布统计
- 近年趋势

## 参数偏好
- 常用参数基底值
- 计算复杂度模式
```
