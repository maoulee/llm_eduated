# 题目规划技能

> 行为约束（工作边界、规划通过条件、禁止行为）已定义在 agents/outline.md。
> 本文件定义规划执行步骤、规划模板和输出检查清单。

## 规划执行步骤

### Step 1：分析 slot
读取 slot 数据，理解知识点范围和题型要求。

### Step 2：查阅历史经验
从 question_experiences 中提取该题位的考察模式、难度分布、常见陷阱。

### Step 3：确定知识点
列出本题涉及的核心知识点及其考察侧重点。

### Step 4：设定 K 目标
根据历史经验分布，为 K1-K5 各维度设定目标等级。

### Step 5：选择考察模式
从历史经验中选取最适合的考察模式。

### Step 6：规划子问题
确定子问题数量、类型、分值分配和考察关系。

### Step 7：定义参数约束
明确参数之间的逻辑关系、取值范围和一致性要求。

### Step 8：输出
分别写入 outline.md 和 assembled.md。

---

## 规划原则

1. **锚定题位**：每个题位有固定的题型和分值，规划必须在该框架内
2. **经验驱动**：从历史 question_experiences 中提取考察模式和难度分布
3. **约束具体**：K目标、参数范围、子问题结构必须明确可执行
4. **不越界**：不设计具体题目、不指定具体参数值

## 规划模板

### 选择题规划模板
```
考点: 单个明确考点
K目标: K1-K5 各值
考察模式: 从历史经验中选取
选项要求: 4选项，1正确3干扰
条件数: X个显式条件
参数约束: 各参数范围和关系
干扰策略: 建议的干扰方式
```

### 综合题规划模板
```
考点: 核心考点 + 辅助考点
K目标: K1-K5 各值
考察模式: 从历史经验中选取
子问题数: X个，分值分配
子问类型: 计算/分析/证明
依赖关系: 串行/并行/混合
参数约束: 各参数范围和关系
```

## 输出检查清单

- [ ] K1-K5 每个维度都有明确目标
- [ ] 考察模式有历史经验支撑
- [ ] 参数约束给范围不给定值
- [ ] 子问题结构完整（综合题）
- [ ] 教师批注区已留空
- [ ] assembled.md 契约格式完整
