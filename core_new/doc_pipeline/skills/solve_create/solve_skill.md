# 求解技能

> 行为约束已定义在 agents/solve.md。
> 本文件定义求解执行步骤、策略选择和代码模板。

## 权责边界

求解智能体负责：
- **独立求解**：只基于公开题面推导答案
- **代码验证**：数值题用 solve.py 验证答案正确性
- **最小题面修订**：发现计算结果与题干/选项不一致时，先基于求解证据修正题干数值、单位或选项值
- **完整解法**：产出完整求解过程和答案

求解智能体不负责：
- 改题目结构、考察形式、知识点或难度目标
- 为了匹配某个选项枚举搜索参数
- 读取设计说明后按出题意图倒推答案

## 三步工作流程

### Step 1：读取题目，写 solve.py 一步到位

1. **read_file(question_public.md)** — 读取题干和选项（跳过设计说明）
2. 判断题目类型：
   - **数值题**：题干包含具体数值参数、需要计算
   - **概念题**：纯文字描述、考察概念理解
   - **混合题**：数值部分用代码，概念部分直接推理
3. 数值题 → **write_file(solve.py)** 一步完成参数定义 + 计算 + 选项匹配
4. **exec_file(solve.py)** — 执行并获取计算结果

**solve.py 必须包含**：
- 参数定义（从题干提取）
- 完整计算过程
- 选项匹配检查（print 哪个选项匹配，或说明未匹配）
- 最终答案输出（`print(f"ANSWER: {answer}")`）

### Step 2：不匹配处理（关键决策点）

**exec_file 执行后，立即判断结果：**

```text
if 计算结果 == 某个选项:
    → 题面自洽，进入 Step 3 写 solution.md
elif 计算结果 不匹配任何选项:
    → 先诊断题干参数、单位换算、边界条件、选项值中哪一处与求解结果矛盾
    → read_file 查看当前题面
    → edit_file 最小修改 question.md / question_public.md 中的数值、单位或选项值
    → exec_file(solve.py) 复验
    → 进入 Step 3
```

**必须优先做的事：**
- 用当前题干参数完成一次真实求解，不跳过计算
- 把 mismatch 写成明确结论：`代码结果 = X；现有选项 = ...；最小修订 = ...`
- 优先修题干中的明显参数错误、单位错误、边界条件错误或选项值错误
- 修改后保持原知识点、题型结构、设问方式、选项数量不变

**禁止行为（避免工具调用失控）：**
- 不得为了匹配选项而枚举搜索参数
- 不得反复重算同一组参数
- 不得尝试多种主观解读来绕过题面矛盾
- 不得整体重写 question_public.md
- 不得盲改多个无关参数

### 参数搜索兜底规则

参数搜索不是默认流程。只有同时满足以下条件，才允许最多一次搜索：

1. 题面或蓝图明确存在待定参数、占位符或取值范围；
2. solve.py 已经证明当前参数/选项不一致；
3. 直接检查题干、单位、边界和选项后仍无法定位最小修改点。

允许的兜底动作：
- 在 solve.py 中增加一个短小搜索块，搜索范围必须来自题面或蓝图约束；
- exec_file 只执行一次搜索；
- 搜索结果只作为诊断依据，最终仍用 edit_file 做最小题面修订。

### Step 3：写 solution.md（最终产出）

**目标**：基于复验通过的题面和代码结果，产出完整求解过程和答案。

1. **write_file(solution.md)** — 写出完整求解过程和答案
2. solution.md 中的数值必须与代码输出完全一致

**完成标准**：
- 所有子问题/选项均有对应的求解过程
- 最终答案明确、无歧义
- 数值题的答案与 solve.py 输出一致

## solve.py 代码模板

```python
# ===== 题目参数定义 =====
param_a = ...  # 题干给定值
param_b = ...  # 题干给定值

# ===== 求解计算 =====
result = ...  # 核心计算
print(f"计算过程: ...")
print(f"中间结果: {result}")

# ===== 选项匹配 =====
options = {'A': ..., 'B': ..., 'C': ..., 'D': ...}
matched = []
for opt, val in options.items():
    if result == val:
        matched.append(opt)
        print(f"匹配选项: {opt}.{val}")

if not matched:
    print(f"MISMATCH: 计算结果 {result} 不匹配任何选项 {options}")

print(f"ANSWER: {matched[0] if matched else result}")
```

## 不匹配诊断模板

```text
MISMATCH DIAGNOSIS
- 题干参数：...
- 计算结果：...
- 当前选项：...
- 不一致来源：题干数值 / 单位 / 边界条件 / 选项值
- 最小修订：把 ... 改为 ...
```
