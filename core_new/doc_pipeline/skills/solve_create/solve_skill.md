# 求解技能（具体逻辑）

> 通用行为（角色、思考控制、红线）定义在 agents/solve.md。
> 本文件定义求解的执行流程、输出契约和选项组装规则。**不给 solve.py 代码模板。**

## 执行流程

### Step 1：exec solve.py 得真值

1. **exec_file(solve.py)** — solve.py 由 question 阶段写好（含正确算法 + 错误算法），你只执行不改。
2. 读 exec 输出：正确答案 + 干扰值（已由代码计算，带逻辑标签）。
3. exec 输出即真值，不重算、不质疑。

### Step 2：组装选项进 question.md

把 exec 输出的正确值 + 干扰值组装成 4 个选项：

- 正确选项 = exec 输出的正确答案
- 3 个干扰选项 = exec 输出的 3 个干扰值（由错误算法产生，非硬编码）
- **随机化选项顺序**（A/B/C/D 随机分配），避免正确答案固定在某个位置
- 验证 4 个选项值不重复

用 **edit_file 追加**到 question.md 的选项区，**不覆盖题干**。

### Step 3：写 solution.md

基于 exec 输出写推理过程：

- 每个子问题/选项逐一分析
- 数值必须与 exec 输出逐字一致
- 最终答案明确、无歧义

## exec 失败处理（code_error 回退）

exec 报错（语法错 / 运行错 / 无输出 / 输出缺值）时：

- **标记 code_error**，回退让 question 阶段修 solve.py
- **不自己修代码** — solve.py 的逻辑错误不属于求解阶段职责
- **不自己改题干凑结果** — 不为匹配而篡改参数

exec 失败的判定标准：
- 非零退出码 → code_error
- 无标准输出 → code_error
- 输出缺少正确值或 3 个干扰值 → code_error

## solve.py 输出契约（不给模板）

solve.py（question 阶段编写）必须满足：

1. 从题干参数计算正确答案
2. 输出正确答案 + 3 个干扰值（选择题）/ 各子问答案（综合题）
3. 干扰值由"错误算法"产生，**非硬编码常量**
4. print 每个值 + 对应逻辑标签（正确/干扰1/干扰2/干扰3）

代码结构、函数组织方式由 question 阶段的模型自主决定。本技能不给代码骨架。

## 选项组装规则

- 正确值和干扰值都来自 exec 输出
- 选项顺序随机化（不固定正确答案位置）
- 4 个选项值两两不同
- 干扰值由错误算法产生（如：单位错误、符号错误、漏项、中间结果），不是手填的随机数

## solution.md 叙述要点

- 推理过程基于 exec 输出的数值，不引入脑内计算
- 每个选项说明对错理由（正确为什么对、干扰为什么错）
- 综合题每个子问题独立分析
- 最终答案与 exec 输出一致
