# 求解技能（具体逻辑）

> 通用行为（角色、思考控制、红线）定义在 agents/solve.md。
> 本文件定义求解的执行流程和 solve.py 输出契约（§17.5：只算正确）。**不给代码模板。**

## 执行流程

### Step 1：exec solve.py 得正确答案

1. **exec_file(solve.py)** — solve.py 由 question 阶段写好（只含正确算法的确定性 DAG），你只执行不改。
2. 读 exec 输出：**正确答案**（选择题=1 个正确值；综合题=各子问正确答案，带逻辑标签）。
3. exec 输出即真值，不重算、不质疑。

> 注意：solve.py **只算正确答案**，不算干扰值。干扰项由后续的"干扰项轻给"步骤基于 correct 直接给，不属于 solve。

### Step 2：写 solution.md

基于 exec 输出写推理过程：

- 每个子问题逐一分析（综合题）/ 给出正确答案与推理（选择题）
- 数值必须与 exec 输出逐字一致
- 最终答案明确、无歧义
- 选择题只写正确答案与理由；4 个选项（含干扰）由后续步骤组装

## exec 失败处理（code_error 回退）

exec 报错（语法错 / 运行错 / 无输出 / 输出缺正确答案）时：

- **标记 code_error**，回退让 question 阶段修 solve.py
- **不自己修代码** — solve.py 的逻辑错误不属于求解阶段职责
- **不自己改题干凑结果** — 不为匹配而篡改参数

exec 失败的判定标准：
- 非零退出码 → code_error
- 无标准输出 → code_error
- 输出缺少正确答案（选择题无正确值 / 综合题缺子问答案）→ code_error

## solve.py 输出契约（§17.5，不给模板）

solve.py（question 阶段编写）必须满足：

1. 是一段**参数化的确定性计算路径（DAG）**：输入 → 中间参数 → 正确答案
2. **只计算正确答案**：选择题输出 1 个正确值；综合题输出各子问正确答案
3. **不编码错误算法、不输出干扰值** — 干扰项由后续轻步骤给
4. print 正确答案 + 逻辑标签（如 `正确: <value>` / 各子问 `子问1: <value>`）

模型只给 1-2 个初始参数（经验预设），代码传播出全部正确参数 + 结果。代码结构由 question 阶段自主决定，本技能不给骨架。

## solution.md 叙述要点

- 推理过程基于 exec 输出的数值，不引入脑内计算
- 综合题每个子问题独立分析
- 最终答案与 exec 输出一致
- 选择题只写正确答案；不在此处设计干扰项
