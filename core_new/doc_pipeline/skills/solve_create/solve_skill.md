## 结果对比验证方法

数值题代码执行后，选择至少一个子问题进行手动交叉验证：

1. 从题干参数出发，用不同方法（如公式直接代入 vs 分步计算）计算同一结果
2. 比较代码输出与手动推算是否一致
3. 不一致时以代码为准，检查手动推算的错误
4. 在 solution.md 中记录验证过程
