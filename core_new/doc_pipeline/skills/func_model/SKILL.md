# Skill: 解法封装成函数（func_model）

你的活：**读题干 → 写函数 → 注入数值跑 → 看结果 → 基于结果改码。** 有效探索（想代码结构）允许，内耗思考（脑内算算法/重新理解算法）禁止。

---

## 0. 允许的探索 vs 禁止的内耗（最重要·先读）

**这是数学问题的代码化，不是复杂工程。** 题干已经给了算法规则，你直接把规则翻译成代码即可——就像 Explore 智能体能快速给出代码一样，你也能。

### 允许（有效探索·快速做）
- 想"函数怎么组织"（签名、内部几段、用什么数据结构）。
- 想"题干的哪条规则对应代码的哪段"（规则→代码的映射）。
- 想"验证段怎么写"（assert/验证算式）。

### 禁止（内耗·立即停）
- **重新理解/推导算法规则**——题干/标准定义已经给了规则（如"同号减Y异号加Y"），直接代码化，不在脑内重新学一遍。
- **脑内算具体数值**——某步余数=？商位=？最终答案=？这些是 solve() 跑出来的，不是你想出来的。
- **脑内验证代码对不对**——验证走 exec，不走脑内。

> 触发器：若你发现自己在"先理解算法/推导规则/算具体值"——**立即停**。算法规则是已有事实（查表，见 CORE），直接代码化。你在脑内重新推导算法 = 内耗 = 把代码的活在脑子里做一遍 = 撑爆。

## 1. 工作步骤（严格按此顺序）

**第1步·浅析（几句话）**：题干要算什么？函数签名？内部分几段（对应题干的几条规则）？**到此停，去写码。**

**第2步·写函数**：把题干运算规则**直接转写**成 `solve()`——题干说"同号减Y"你就写 `if 同号: R = R + negY`，题干说"左移"你就写 `R = (R << 1) % mod`。**转写，不重新理解。**

**第3步·注入数值跑**：用题干参数调用 `solve()`，exec 跑。

**第4步·看结果，基于结果改码**：验证通过→完成；不过→改码（不是脑内重算），再跑。

> 验证 = exec 结果，不是脑内算的。验证段必须用 **assert**（不只 print）——验证不过 assert 报错→exit≠0→系统检测到失败→退回你改码。

---

## 1. 核心原则：先建模，后注入

- **建模阶段不碰具体数值**：写 `def solve(X, Y)` 时，X、Y 是参数（占位），你只把"怎么算"写成代码，不需要知道 X、Y 具体是几。
- **注入阶段才碰数值**：函数写完，调用 `solve(题干给的具体值)`，让代码算出答案。
- 好处：建模时没有"脑内算数值"的诱因（数值还没注入），自然不会过度思考。

---

## 2. 建模方式

- **整数取模建模**：补码、原码这类机器数用取模运算表达（如 `(a+b) % mod`、位权展开求和），**勿逐位模拟硬件信号**（移位寄存器、加法器门电路）。
- **不引入 numpy**，仅用标准库。

---

## 选择题：算正确值填选项占位

若是选择题，gen.py 算出**正确值**后，把它填进 question.md 的**所有选项**（A/B/C/D 都先填正确值作为占位）——具体的干扰值（BCD 改成各错误路径的值）由 write_solution 在写解析时改。

- gen.py 只需算**正确值**（不用算 4 种错误路径）。
- 填选项时：A=正确值，B/C/D 暂时也填正确值（占位），并在 gen.py 输出里标注"正确值=XXX，待 write_solution 据 BCD 错误类型改干扰值"。
- 选项的错误类型在 question.md 题干里已声明（B=对阶错、C=规格化错等），write_solution 据此改。

## 3. 结构

```python
def solve(X, Y):        # 题干参数（建模时是占位，调用时注入具体值）
    # 函数体：题干怎么算，这里就怎么写
    ...
    return Q, R          # 答案

# 注入题干数值，跑一遍
Q, R = solve(题干X, 题干Y)
print("=== PARAMS ===");    print(...)
print("=== REASONING ==="); print(...)   # 关键中间步骤
print("=== ANSWER ===");    print(Q, R)
```

建议在 solve 内部加一个**自检**（如 `assert Q*Y + R == X` 或类似的关系验证），跑不过自动报错——这样第4步"看结果"有明确信号。

---

## 4. 纪律

- 仅标准库：math / decimal / fractions / itertools / collections / struct / random。**不用 numpy。**
- 错了改函数体（不改题干、不脑内算）。
- print 答案 + 关键中间步骤（供下游 solution 展开）。
- **不许脑内解决**：所有"验证对不对"都靠 exec 结果，不靠脑内推演。
