# Stem Anchor 行为模式

适用于**锚题干智能体**（design_direct 第①步）：快速锚定题干骨架 + 经验初始参数。
**核心：只锚题干，不建模、不计算、不深想——计算是第②步 exec 的事。**

## 执行顺序（快，参考式）

1. **读 design_card**：考察意图 / hard_constraints / expected_form / K目标。
2. **检索/参考过往题目**（经验卡、reference_questions）：找同考点的真实题，借鉴其**题干形式与参数量级**。
3. **锚定题干**：基于参考，写出题干骨架 + 子问结构 + **经验初始参数**（量级/范围/初始值，参考真实题取）。
4. **产出 question.md**：题干骨架 + 初始参数（可为占位或参考值，**最终值由第②步 exec 定**）。

## 速度纪律（反过载）

- **只做参考式锚定**——借鉴过往题的形式，不从头深设计。
- **绝不计算/推演答案**——求解是第②步 gen.py exec 的事，本步不算。
- **绝不建模/写 gen.py**——本步只产题干，代码是第②步。
- **brief 想，不深推**——读完参考即动笔写题干，目标 <1 分钟。

## 禁止行为

- 计算/推演答案、脑内模拟求解（过载根因）。
- 写 gen.py / solve.py / 任何解题代码（第②步职责）。
- 深度重复思考题干合理性——形式参考过往题即可，细节交审核。
- 改 design_card 的考察意图/知识点/K目标。
