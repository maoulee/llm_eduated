# 浮点数运算与右移操作综合题

题干：某计算机采用IEEE 754单精度浮点数格式（符号位1位，阶码8位偏置值为127，尾数23位），并支持补码加减运算。设x=-513，其补码表示为FDFFH。对x进行算术右移1位后，再将其转换为浮点数。若浮点数加法运算流程为：对阶→尾数运算→规格化→舍入→判溢出，且采用双符号位（变形补码）进行溢出检测，则下列叙述正确的是（ ）

A. x算术右移1位结果为7EFFH（逻辑右移），转换为浮点数后阶码溢出，双符号位为10表示负溢出
B. x算术右移1位结果为FEFFH（算术右移），转换为浮点数后阶码正常，双符号位为00表示无溢出
C. x算术右移1位结果为7EFFH（算术右移），转换为浮点数后阶码正常，双符号位为01表示正溢出
D. x算术右移1位结果为FEFFH（逻辑右移），转换为浮点数后阶码下溢，双符号位为10表示负溢出

## 正确答案
B

## 解析
**第一步：判断算术右移结果**
- x=-513的补码FDFFH = 1111 1101 1111 1111B
- 算术右移1位：高位补符号位1，低位移出
- 结果：1111 1111 0111 1111B = FEFFH
- 逻辑右移会补0得到7EFFH，这是错误答案

**第二步：转换为浮点数**
- -513 >> 1 = -256.5
- -256.5的二进制：-100000000.1 = -1.0 × 2^8
- IEEE 754表示：
  - 符号位：1（负数）
  - 阶码：8 + 127 = 135 = 10000111B
  - 尾数：0（规格化后1.0，隐含的1和小数部分全0）
- 阶码135在正常范围[1, 254]内，无溢出

**第三步：双符号位判断**
- 双符号位00：结果正常，无溢出
- 双符号位01：正溢出（结果超过正最大值）
- 双符号位10：负溢出（结果小于负最小值）
- 本题运算结果正常，双符号位为00

**干扰项设计针对薄弱点**：
- A选项：混淆算术/逻辑右移，且错误判断溢出
- C选项：使用逻辑右移结果，且错误判断溢出类型
- D选项：使用算术右移结果但标记为逻辑右移，且混淆阶码下溢概念

**关键考查点**：
1. 算术右移高位补符号位（负数补1）
2. IEEE 754阶码正常范围判断
3. 双符号位溢出判定规则
