# 浮点数加法与双符号位溢出判定

题干：某计算机采用浮点数格式：符号位1位，阶码5位（含1位阶符，补码表示），尾数10位（含1位数符，补码表示）。浮点数加法运算流程为：对阶→尾数运算→规格化→舍入→判溢出。设x=2^4×0.110100000，y=2^2×0.110000000，采用双符号位（变形补码）进行尾数运算和溢出检测。对阶后进行尾数求和，则下列关于运算结果的叙述正确的是（ ）

A. 对y对阶后尾数为00.001100000，尾数求和结果为01.000000000，双符号位01表示负溢出
B. 对y对阶后尾数为00.000011000，尾数求和结果为00.111011000，双符号位00表示无溢出
C. 对y对阶后尾数为00.001100000，尾数求和结果为01.000000000，双符号位01表示正溢出
D. 对y对阶后尾数为11.110100000，尾数求和结果为00.101000000，双符号位00表示需要左规

## 正确答案
C

## 解析
**第一步：对阶操作**
- x阶码4，y阶码2，阶差ΔE=4-2=2
- y的尾数右移2位：00.110000000 → 00.001100000（正数右移，高位补0）
- 对阶原则：小阶向大阶对齐

**第二步：尾数求和**
- x尾数：00.110100000
- 对阶后y尾数：00.001100000
- 求和：00.110100000 + 00.001100000 = 01.000000000

**第三步：双符号位判定**
- 双符号位01：第一符号位（高位）与第二符号位不同→正溢出
- 双符号位10：负溢出
- 双符号位00或11：无溢出
- 本题结果01.000000000，双符号位01，表示正溢出

**干扰项设计针对薄弱点：**
- A选项：混淆"01表示正溢出"和"10表示负溢出"
- B选项：对阶阶差计算错误（用3位而非2位），且尾数和计算错误
- D选项：对阶方向错误（对大的x对阶而非小的y），且混淆左规/溢出概念

**关键考查点：**
1. 对阶原则：小阶向大阶对齐，阶差决定右移位数
2. 双符号位溢出判定：01=正溢出，10=负溢出
3. 右移时补码数保持符号位（正数补0，负数补1）
