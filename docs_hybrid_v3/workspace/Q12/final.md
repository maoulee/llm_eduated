## 题目
某程序 P 在计算机 M 上运行时，共执行 $4.0 \times 10^7$ 条指令，平均 CPI 为 1.5，用户 CPU 时间为 24 ms。若不考虑其他系统开销，则计算机 M 的主频为（ ）。


## 选项
- A: 1.0 GHz
- B: 1.67 GHz
- C: 2.5 GHz
- D: 25 GHz


## 解题过程
===== 单位换算 =====
指令条数 IC = 40000000.0 条
平均 CPI = 1.5
CPU 时间 = 24 ms
CPU 时间换算为秒: 24 / 1000 = 0.024 s

===== 主频计算 =====
CPU 执行时间公式: T_CPU = IC × CPI / f
变形得到: f = IC × CPI / T_CPU
总时钟周期数 = IC × CPI = 40000000.0 × 1.5 = 60000000.00
主频 f = 60000000.00 / 0.024 = 2.50000000E+9 Hz
主频换算为 GHz = 2.50000000E+9 / 1000000000 = 2.5 GHz

===== 逐选项验证 =====
选项 A: 1.0 GHz
  换算为 Hz: 1.0 × 1000000000 = 1000000000.0 Hz
  与计算主频差值: |1000000000.0 - 2.50000000E+9| = 1500000000.0 Hz
  是否匹配: False
选项 B: 1.67 GHz
  换算为 Hz: 1.67 × 1000000000 = 1670000000.00 Hz
  与计算主频差值: |1670000000.00 - 2.50000000E+9| = 830000000.00 Hz
  是否匹配: False
选项 C: 2.5 GHz
  换算为 Hz: 2.5 × 1000000000 = 2500000000.0 Hz
  与计算主频差值: |2500000000.0 - 2.50000000E+9| = 0.0 Hz
  是否匹配: True
选项 D: 25 GHz
  换算为 Hz: 25 × 1000000000 = 25000000000 Hz
  与计算主频差值: |25000000000 - 2.50000000E+9| = 22500000000 Hz
  是否匹配: False

计算得到主频为 2.5 GHz，对应选项 C
ANSWER: C


## 答案
正确答案：C

CPU 执行时间公式为：

$$T_{CPU} = \frac{IC \times CPI}{f}$$

其中，$IC$ 为指令条数，$CPI$ 为每条指令的平均时钟周期数，$f$ 为主频。

由题意可得：

$$IC = 4.0 \times 10^7$$
$$CPI = 1.5$$
$$T_{CPU} = 24ms = 24 \times 10^{-3}s = 0.024s$$

代入公式：

$$0.024 = \frac{4.0 \times 10^7 \times 1.5}{f}$$

因此：

$$f = \frac{4.0 \times 10^7 \times 1.5}{0.024}$$

$$f = \frac{6.0 \times 10^7}{0.024}$$

$$f = 2.5 \times 10^9 Hz$$

由于：

$$1GHz = 10^9 Hz$$

所以：

$$f = 2.5 GHz$$

故选 C。
