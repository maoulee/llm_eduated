## P1 - 浮点数运算混淆型

**题干：** 某计算机采用浮点数格式为：符号位1位，阶码5位（采用移码、偏置值为16），尾数10位（补码表示，含1位符号位）。已知x=2^5 × 0.110100000，y=2^3 × (-0.101000000），用浮点数加减法运算步骤计算x-y，在规格化步骤后、判溢出步骤前，双符号位为（ ）。

A. 00
B. 01
C. 10
D. 11

**正确答案：D**

**解析：**
1. 对阶：y阶码小，y尾数右移2位。**关键：必须用算术右移**（高位补符号位1），y尾数变为11.10100000
2. 尾数运算：0.110100000 + 0.011010000（负数补码）= 10.001110000
3. 规格化：左移2位，阶码-2 → 11.11100000，双符号位仍为11
4. 陷阱：若用逻辑右移（高位补0），y尾数变为00.10101000，得到01.01111000，误选B
5. 正确结果双符号位11，表示负数，未溢出

**干扰项针对性：** B(01)=逻辑右移错误; C(10)=溢出判定混淆; A(00)=忽略负数补码扩展

## P3 - 流水线冒险识别失败型

**题干：** 某RISC处理器采用5段流水线（IF/ID/EX/MEM/WB），执行以下指令序列：

```
I1: lw   s1, 0(s2)
I2: add  s3, s1, s4
I3: sub  s5, s3, s6
I4: sw   s5, 8(s7)
```

若该处理器采用EX阶段转发技术，但无MEM阶段转发，则流水线执行过程中需要插入的最小气泡总数为（ ）。

A. 1个
B. 2个
C. 3个
D. 4个

**正确答案：B (2个)**

**解析：**
1. I1→I2 (Load-Use)：I1的lw在MEM末尾才有数据，I2在ID就需要 → 插入1个气泡
2. I2→I3 (无MEM转发)：I2的add在EX产生结果，但无MEM转发 → 插入1个气泡
3. I3→I4 (EX-EX转发)：可用转发，无需气泡

**干扰项针对性：** A(1)=忘记考虑无MEM转发; C(3)=混淆RAW/WAR; D(4)=不理解转发

## P4 - 中断总线概念模糊型

**题干：** 某计算机采用中断方式管理I/O设备。若CPU在执行当前指令时已关中断，且中断请求信号已到达，则从当前指令执行完毕到中断服务程序执行完毕的正确时序是？

A. 总线传输：数据线传中断类型号，控制线传中断响应信号；程序顺序：关中断→保护现场→开中断→处理事件→关中断→恢复现场→开中断→中断返回

B. 总线传输：数据线传命令字和状态字，控制线传中断类型号；程序顺序：保护现场→开中断→处理事件→关中断→恢复现场→开中断→中断返回

C. 总线传输：数据线传中断类型号，控制线传中断响应信号；程序顺序：保护现场→开中断→处理事件→恢复现场→开中断→中断返回

D. 总线传输：地址线传设备地址，数据线传中断类型号；程序顺序：开中断→保护现场→处理事件→关中断→恢复现场→中断返回

**正确答案：A**

**解析：**
- A正确：数据线传中断类型号+控制线传INTA；完整的中断服务程序顺序
- B错误：数据线在中断响应周期传的不是命令字/状态字；控制线不传中断类型号
- C错误：缺少"恢复现场前关中断"步骤
- D错误：地址线不传设备地址；顺序混乱

## P5 - 指令系统与寻址计算型

**题干：** 某计算机采用定长指令字格式，指令字长为16位。若指令系统包含120条指令，采用4种寻址方式，指令格式为单地址码。该机采用按字节编址，则直接寻址的最大范围是（ ）

A. 256个地址单元
B. 128个地址单元
C. 512个地址单元
D. 64个地址单元

**正确答案：B (128个单元)**

**解析：**
- 操作码位数：⌈log₂120⌉ = 7位
- 寻址特征位：⌈log₂4⌉ = 2位
- 地址码位数：16-7-2 = 7位
- 直接寻址范围：2⁷ = 128个单元

**干扰项针对性：** A(256)=操作码误算6位; C(512)=寻址特征误算1位; D(64)=操作码误算8位

## P6 - 存储器交叉编址与DRAM型

**题干：** 某计算机采用4体低位交叉编址存储器，每个存储体字长32位，存储周期为200ns。总线宽度为32位，传送周期为50ns。现从字地址2016H处读取一个double型数据（8字节），则完成该数据读取所需的最短时间为多少？

A. 200ns
B. 250ns
C. 300ns
D. 400ns

**正确答案：C (300ns)**

**解析：**
1. 4体低位交叉编址，体号由字地址低2位决定
2. 2016H低2位=10B=体2，2017H低2位=11B=体3 → 跨体，可并行读取
3. 并行读取200ns + 两次总线传送100ns = 300ns

**干扰项针对性：** A(200)=忽略总线传送时间; B(250)=误认为只需一次传送; D(400)=误认为不跨体(体号计算方向搞反)
