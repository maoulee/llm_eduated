## 题干（20分）

某计算机中，浮点数采用IEEE 754单精度格式（1+8+23位，偏置值127）。Cache采用直接映射方式，数据区共128行，每行16字节。按字节编址。

程序中有以下变量：

```c
float a = -13.75, b = 7.375;
float c;
c = a - b;
```

已知变量c存储在地址0x0848开始的4个字节中，变量a存储在地址0x0800开始的4个字节中。

回答以下问题：

（1）（8分）将a和b分别转换为IEEE 754单精度浮点数的十六进制表示，写出完整的转换过程（含二进制表示、规格化、阶码和尾数的确定）。

（2）（8分）若采用变形补码（双符号位）来演示a-b的尾数运算过程，请写出对阶、尾数求和的步骤，并给出规格化后的双符号位。要求：尾数精度取8位。

（3）（4分）分别计算变量a和变量c第一个字节所在的Cache行号，并判断它们是否映射到同一个Cache行。若某程序依次访问a和c，是否会发生Cache冲突缺失？

## 参考答案

### 小题（1）（8分）—— IEEE 754编码

**a = -13.75:**

13 = 1101₂，0.75 = 0.11₂ → 13.75 = 1101.11₂

规格化：-1.10111 × 2³

- 符号位 S = 1
- 阶码 E = 3 + 127 = 130 = 10000010₂
- 尾数 M = 10111000000000000000000（去掉隐含的1）

完整：1 10000010 10111000000000000000000

**十六进制：0xC15C0000** （2分）

**b = 7.375:**

7 = 111₂，0.375 = 0.011₂ → 7.375 = 111.011₂

规格化：1.11011 × 2²

- 符号位 S = 0
- 阶码 E = 2 + 127 = 129 = 10000001₂
- 尾数 M = 11011000000000000000000

完整：0 10000001 11011000000000000000000

**十六进制：0x40EC0000** （2分）

验证：a - b = -13.75 - 7.375 = -21.125

-21.125 = -10101.001₂ = -1.0101001 × 2⁴ → IEEE 754：0xC1A90000

### 小题（2）（8分）—— 变形补码尾数运算

a的尾数（A）：-1.10111 × 2³

b的尾数（B）：+1.11011 × 2²

**步骤一：对阶（2分）**

|exp_A - exp_B| = |3 - 2| = 1

B阶码小，B尾数算术右移1位：

B尾数（双符号补码，8位精度）：00.11011000

算术右移1位（正数，高位补符号位0）→ 00.01101100

统一阶码：3

**步骤二：A尾数补码转换（2分）**

| 步骤 | 表示 |
|------|------|
| 原码 | 1.10111000（符号=1，数值=10111000）|
| 反码 | 1.01000111（数值位取反）|
| 补码 | 1.01001000（反码+1）|
| 双符号位 | 11.01001000 |

**步骤三：尾数求和（2分）**

```
  11.01001000    （A尾数补码）
+ 00.01101100    （B尾数移位后）
─────────────
  11.10110100
```

**步骤四：规格化与溢出判定（2分）**

- 双符号位 = 11 → 负数，无溢出
- 尾数最高有效位 = 1 → 已规格化

**最终双符号位：11**

### 小题（3）（4分）—— Cache行号计算

**a的地址：0x0800**

行号 = (0x0800 >> 4) % 128 = 128 % 128 = **0**

a在Cache第0行 （1分）

**c的地址：0x0848**

行号 = (0x0848 >> 4) % 128 = 132 % 128 = **4**

c在Cache第4行 （1分）

**冲突判断：** 两变量映射到不同行（行0 ≠ 行4），不会发生冲突缺失。（2分）

## 针对P1学生的陷阱设计

1. **双符号位=11的判定**：P1学生容易将11误判为"负溢出"（实际10才是负溢出，11是负无溢出）
2. **补码转换**：原码1.10111000→补码是1.01001000，若忘记+1步骤会得到1.01000111（错误）
3. **对阶方向**：阶码小的尾数右移，容易搞反方向
