# 变形补码加减运算与溢出判断

## 题干

已知两个有符号十进制整数：

- x = +95
- y = +73

采用 **9 位变形补码**（2 位符号位 + 7 位数值位）表示和运算。请回答以下问题：

**（1）** 写出 x 和 y 的变形补码表示。（2 分）

**（2）** 用变形补码计算 x + y，写出完整的运算过程（包括变形补码加法竖式），并判断是否溢出。若溢出，说明溢出原因；若不溢出，给出运算结果的真值。（2 分）

**（3）** 用变形补码计算 x − y，写出完整的运算过程（包括先求 [−y] 的变形补码、再做变形补码加法的竖式），并判断是否溢出。若溢出，说明溢出原因；若不溢出，给出运算结果的真值。（2 分）

> **变形补码溢出判断规则**：运算结果的两个符号位相同（00 或 11）时，未溢出；两个符号位不同（01 或 10）时，溢出。符号位参与运算。

---

## 答题要求

1. **第（1）问**：分别写出 x = +95 和 y = +73 的 9 位变形补码（2 位符号位在前，7 位数值位在后），以二进制形式给出。
2. **第（2）问**：以变形补码加法竖式形式展示 [x]变补 + [y]变补 的运算过程，标出符号位，给出运算结果，并依据双符号位判断是否溢出。
3. **第（3）问**：先求 [−y] 的变形补码（写出由 [+y] 变补 得到 [−y] 变补 的过程），再以变形补码加法竖式形式展示 [x]变补 + [−y]变补 的运算过程，给出运算结果，并依据双符号位判断是否溢出。

---

## 场景规则（本题成立需要满足的约束）

1. **表示范围约束**：x 和 y 均在 9 位变形补码（2 位符号位 + 7 位数值位）的表示范围 [−128, +127] 内，可被正确转换为 9 位变形补码。
2. **溢出分布约束**：x + y 的结果超出 [−128, +127]，发生溢出；x − y 的结果在 [−128, +127] 内，不溢出。即 x+y 与 x−y 中**恰有一组溢出、一组不溢出**。
3. **变形补码转换正确性约束**：正数的变形补码双符号位为 00，数值位为绝对值的二进制；负数的变形补码双符号位为 11，数值位为绝对值取反加一后的结果。[−y] 的变形补码可通过对 [+y] 的变形补码连同符号位一起取反加一得到。
4. **溢出判断一致性约束**：双符号位判断法的结果与真值范围判断法一致——结果真值超出 [−128, +127] ⟺ 双符号位不同（01 或 10）。
