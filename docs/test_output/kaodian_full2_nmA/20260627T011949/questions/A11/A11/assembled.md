## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 数据表示与运算 > 补码
- primary_target_name: 变形补码加减与溢出
- question_type: comprehensive
- examination_mode: 计算题——变形补码算 x+y/x-y 并判溢出

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 以变形补码运算完整流程为主线，K3=3为主导维度。学生需走完"真值→变形补码转换→加减运算→溢出判断"的标准3-5步流程。数值计算量适中，无跨域联动，整体难度定位标准。

### 结构要求
- sub_question_count: 3
- sub_question_details:
  - 第1问: 真值→变形补码转换，2分，计算题
  - 第2问: 变形补码 x+y 运算及溢出判断，2分，计算分析题
  - 第3问: 变形补码 x-y 运算及溢出判断，2分，计算分析题
- dependency: 第1问独立完成；第2问、第3问依赖第1问结果；第2问与第3问并行
- condition_count: 2（x 和 y 的十进制真值）

### 参数约束
- x: 有符号十进制整数，[-127, 127]，不取 0 或 ±2^n
- y: 有符号十进制整数，[-127, 127]，不取 0 或 ±2^n
- 溢出分布约束: x+y 与 x-y 中恰有一组溢出、一组不溢出（强制要求）
- 编码宽度: 2位符号位 + 8位数值位 = 10位变形补码
- 自由度: x、y 具体值由 Question Agent 决定，需满足上述所有约束

### 参考经验摘要
- 历史模式: 变形补码加减运算+溢出判断为高频考察模式，典型出法为给两个真值做加减运算
- 难度锚点: K3=3标准流程，转换→运算→判溢恰好3-5步
- 典型陷阱: 减法需先求[-y]变补；双符号位溢出判断（00/11为不溢出，01/10为溢出）；符号位参与运算
