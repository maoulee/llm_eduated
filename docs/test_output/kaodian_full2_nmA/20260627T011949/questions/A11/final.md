## 题目

已知两个有符号十进制整数：

- x = +95
- y = +73

采用 **9 位变形补码**（2 位符号位 + 7 位数值位）表示和运算。请回答以下问题：

**（1）** 写出 x 和 y 的变形补码表示。（2 分）

**（2）** 用变形补码计算 x + y，写出完整的运算过程（包括变形补码加法竖式），并判断是否溢出。若溢出，说明溢出原因；若不溢出，给出运算结果的真值。（2 分）

**（3）** 用变形补码计算 x − y，写出完整的运算过程（包括先求 [−y] 的变形补码、再做变形补码加法的竖式），并判断是否溢出。若溢出，说明溢出原因；若不溢出，给出运算结果的真值。（2 分）

> **变形补码溢出判断规则**：运算结果的两个符号位相同（00 或 11）时，未溢出；两个符号位不同（01 或 10）时，溢出。符号位参与运算。

## 参考答案

**（1）** [x]变补 = **001011111**，[y]变补 = **001001001**

**（2）** x + y **溢出（正溢出）**。运算结果双符号位为 01，真值 +168 超出 [−128, +127]。

**（3）** x − y **不溢出**。运算结果双符号位为 00，真值 **+22**。

## 解析

**编码规则**：9 位变形补码 = 2 位符号位 + 7 位数值位，表示范围 [−128, +127]。正数双符号位为 00，数值位为绝对值的二进制；负数双符号位为 11，数值位为绝对值取反加一后的结果。

---

### 第（1）问：x 和 y 的变形补码表示

**x = +95：**

- |95| = 95，7 位二进制为 **1011111**
- 正数双符号位为 **00**
- **[x]变补 = 00 1011111 = 001011111**（9 位）

**y = +73：**

- |73| = 73，7 位二进制为 **1001001**
- 正数双符号位为 **00**
- **[y]变补 = 00 1001001 = 001001001**（9 位）

---

### 第（2）问：变形补码计算 x + y

**变形补码加法竖式：**

```
  [x]变补 = 001011111
+ [y]变补 = 001001001
───────────────────
  结果    = 010101000
```

**双符号位判断：**

- 运算结果 = `010101000`，双符号位 = **01**（两符号位不同）
- 双符号位判断：**溢出（正溢出）**

**真值范围验证：**

- 真值 x + y = 95 + 73 = **+168**，+168 > +127，超出表示范围 [−128, +127]

**结论：x + y 溢出。** x 和 y 同为正数，两数之和真值为 +168，超出 7 位数值位变形补码的表示范围。双符号位为 01（正溢出标志），与真值范围判断一致。

---

### 第（3）问：变形补码计算 x − y

**第一步：求 [−y] 的变形补码**

对 [y]变补 连同符号位一起取反加一：

```
  [y]变补     = 001001001
  取反        = 110110110
  取反加一    = 110110111
```

**[−y]变补 = 110110111**

验证：[−y]变补 对应真值 = 439 − 512 = **−73** ✓

**第二步：变形补码加法竖式 [x]变补 + [−y]变补**

```
  [x]变补  = 001011111
+ [-y]变补 = 110110111
───────────────────
  结果     = 000010110
```

**双符号位判断：**

- 运算结果 = `000010110`，双符号位 = **00**（两符号位相同）
- 双符号位判断：**不溢出**

**真值范围验证：**

- 真值 x − y = 95 − 73 = **+22**，+22 ∈ [−128, +127]
- 结果变形补码 `000010110` 对应真值 = **+22** ✓

**结论：x − y 不溢出。** 双符号位为 00（相同），运算结果真值为 **+22**，在表示范围内。

---

### 汇总

| 运算 | 变形补码结果 | 双符号位 | 双符号位判断 | 真值 | 真值范围判断 | 结论 |
|------|-------------|---------|-------------|------|-------------|------|
| x + y | 010101000 | 01 | 溢出 | +168 | 超出 [−128, +127] | **溢出（正溢出）** |
| x − y | 000010110 | 00 | 不溢出 | +22 | 在 [−128, +127] 内 | **不溢出，真值 +22** |

x + y 与 x − y 中恰好一组溢出、一组不溢出；两组运算的双符号位判断法与真值范围判断法完全一致。
