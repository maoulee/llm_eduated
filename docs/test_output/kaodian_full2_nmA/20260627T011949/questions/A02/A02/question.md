# 题目：IEEE754 单精度浮点数表示转换

## 题干

将十进制数 **x = −23.6875** 按 IEEE 754 单精度（32 位）浮点数格式转换，回答其正确的机器表示。

> IEEE 754 单精度格式：1 位符号位 + 8 位阶码（偏置值 = 127）+ 23 位尾数（隐含前导 1）。

四个选项均以 32 位十六进制表示（共 8 位十六进制数字，高位补零至 8 位）。

## 选项

- **A.** 0xC1BD8000
- **B.** 0xC23D8000
- **C.** 0xC1FB0000
- **D.** 0x41BD8000

---

## 场景规则（本题成立 ⇔ 以下约束全部满足）

1. **格式合规**：A 的 32 位值严格满足 IEEE 754 单精度格式定义——符号位 ∈ {0,1}，阶码域 = 真实指数 + 127（偏置值 127），尾数域 = 规格化后小数部分 f（去掉隐含前导 1）。
2. **x 非零非特殊值**：x = −23.6875 不为 0、不为无穷、不为 NaN，转换结果为规格化数（阶码域 ∈ [1, 254]）。
3. **四选项互异**：A、B、C、D 四个 32 位十六进制值各不相同（exec 输出后无碰撞）。
4. **正确值唯一**：在给定 x 下，按 IEEE 754 规则只有一个确定表示，A = 该值；不存在两个选项同时正确。
5. **干扰项 B 对应偏置值错误**：B 的符号位 == A 的符号位；B 的尾数域 == A 的尾数域；B 的阶码域 == A 的阶码域 + 1。
6. **干扰项 C 对应遗漏隐含前导 1**：C 的符号位 == A 的符号位；C 的阶码域 == A 的阶码域（不做任何补偿）；C 的尾数域 == 将完整规格化有效位（含前导 1）的 1.f 二进制位序列左对齐存入 23 位、丢弃超出最低位后的结果（即 C 的尾数域 == (A 的尾数域的最高 22 位 << 1) | (1 << 22)，等价描述：C 尾数域 = 把 A 尾数域左移 1 位并在 bit 22 置 1，丢弃 bit 23 溢出位）。
7. **干扰项 D 对应符号位取反**：D 的阶码域 == A 的阶码域；D 的尾数域 == A 的尾数域；D 的符号位 == 1 − A 的符号位。
8. **干扰项合理性**：B、C、D 各为同类题常见误算的真实产物，非荒谬值。

## 考察意图

- **K1**（格式定义记忆）：准确记忆 IEEE 754 单精度格式（符号 1 位 + 阶码 8 位 + 尾数 23 位 + 偏置值 127 + 隐含前导 1）。
- **K2**（单步计算）：十进制→二进制转换、规格化、偏置值加法、尾数截取。
- **K3**（机制推演）：完整 3–5 步固定转换流程（十进制→二进制→规格化→加偏置→拼装）。
- **K4**（条件路由/陷阱识别）：偏置值 127 vs 128 混淆、隐含前导 1 遗漏、符号位处理——三个标准陷阱点。
