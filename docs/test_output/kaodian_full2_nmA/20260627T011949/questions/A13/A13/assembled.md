## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 存储系统 > Cache
- primary_target_name: Cache 命中率与平均访问时间
- question_type: comprehensive
- examination_mode: 计算题——Cache 命中率/平均访问时间/效率

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=2,K5=3
- difficulty_level: 3
- difficulty_rationale: K3 为主导，要求按 Cache 映射规则完成 3-5 步固定流程推演（地址划分→逐次判断命中→统计命中率→代入公式算平均时间/效率），属标准难度综合题。K2=3 因命中率小数计算和平均时间乘法非 2 幂友好。K4=2 仅有常规注意点（缺失代价定义、小数精度），无深层陷阱。

### 结构要求
- sub_question_count: 3
- sub_question_types: [计算, 计算, 计算]
- sub_question_scores: [3, 2, 2]
- sub_question_dependency: 串行（1→2→3）
- sub_question_goals:
  - 第1问(3分): 地址划分分析 + 访存序列逐次命中判断 + 命中率计算
  - 第2问(2分): 利用命中率和时间参数计算平均访问时间
  - 第3问(2分): 计算效率/加速比 或 分析参数变化的影响
- condition_count: 4-5
- distractor_strategy: 综合题无选项干扰；陷阱设在条件措辞（如缺失代价是否含 Cache 访问时间）和访存序列设计（冲突缺失易误判）

### 参数约束
- Cache总容量: 256B - 2KB，= 块大小 × 块数
- 块大小: 16B - 64B（2的幂），决定块内偏移位数
- Cache块数: 4 - 32（2的幂），若组相联则组数=块数/路数
- 映射方式: 直接映射 或 2路组相联（二选一）
- t_c(Cache访问时间): 1-2 ns 或 1-2 个时钟周期
- t_m(缺失代价/主存访问时间): 10-40 ns 或对应周期数，且 t_m ≥ 5×t_c
- 访存序列长度: 6-10次访问，含至少2次重复访问映射到同一Cache行
- 命中率h: 0.2 ≤ h ≤ 0.7，须为非平凡小数（非0非1）
- 一致性要求: 地址在有效主存范围内；至少1次冲突缺失（直接映射下）；序列设计保证h为非整小数

### 参考经验摘要
- 历史模式: 给Cache结构→给访存序列→判断命中→算命中率→算平均时间，408高频标准流程
- 难度锚点: K3=3 对应固定3-5步流程推演，标准综合题难度
- 典型陷阱:
  - 缺失代价 vs 主存访问时间的定义差异
  - 命中率小数精度（需明确保留位数）
  - 直接映射冲突缺失误判为命中
  - 连续访问同一地址的命中判断
