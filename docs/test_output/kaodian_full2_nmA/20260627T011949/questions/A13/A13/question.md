# Cache 命中率与平均访问时间（综合题，共 7 分）

## 题干

某计算机的主存按字节编址，地址空间为 12 位。该机采用直接映射方式的一级 Cache。Cache 共有 8 个数据块，每块大小为 32 B。Cache 访问时间 $t_c = 2\;\text{ns}$。

Cache 缺失时，处理器需要**先访问 Cache 确认未命中**（耗时 $t_c$），**再访问主存**取出所需数据块（主存访问时间 $t_{m}' = 18\;\text{ns}$），之后将该块写入 Cache。

某程序执行过程中产生了如下 **8 次访存操作**（地址均为十六进制）：

| 访问序号 | 访存地址 |
|:---:|:---:|
| 1 | 0x040 |
| 2 | 0x080 |
| 3 | 0x040 |
| 4 | 0x0C0 |
| 5 | 0x080 |
| 6 | 0x140 |
| 7 | 0x040 |
| 8 | 0x0C0 |

> 假设 Cache 初始为空（所有行均无效）。每次缺失时将目标块调入对应 Cache 行。

---

### 第 1 问（3 分）

(1) 写出主存地址的划分格式：标记（Tag）位、Cache 行号（Index）位、块内偏移（Offset）位各占多少位。

(2) 逐次分析 8 次访存操作是命中还是缺失，填写下表（命中填"H"，缺失填"M"）：

| 访问序号 | 访存地址 | 行号（Index） | 标记（Tag） | 命中/缺失 |
|:---:|:---:|:---:|:---:|:---:|
| 1 | 0x040 | | | |
| 2 | 0x080 | | | |
| 3 | 0x040 | | | |
| 4 | 0x0C0 | | | |
| 5 | 0x080 | | | |
| 6 | 0x140 | | | |
| 7 | 0x040 | | | |
| 8 | 0x0C0 | | | |

(3) 计算 Cache 命中率 $h$（保留小数形式，如 $3/8$）。

---

### 第 2 问（2 分）

利用第 1 问的命中率 $h$ 和题干给定的时间参数，计算该 Cache 系统的**平均访问时间** $t_a$。

> 注意：缺失时的总代价应包含 Cache 访问时间与主存访问时间两部分。

---

### 第 3 问（2 分）

计算该 Cache 系统相对于**无 Cache**（每次访存均直接访问主存，访问时间为 $t_c + t_{m}'$）情况的**加速比** $S$（保留两位小数）。

---

## 设计意图

| 维度 | 说明 |
|---|---|
| **考点（K目标）** | Cache 直接映射地址划分（K3）、逐次命中判断含冲突缺失识别（K3）、命中率统计（K2）、平均访问时间含缺失代价定义（K2）、加速比计算（K2） |
| **考察模式** | 标准计算题流程：地址划分 → 逐次命中判断 → 命中率 → 平均时间 → 效率 |
| **陷阱设计** | ① 第 6 次访问 0x140 与第 1/3 次访问 0x040 映射到同一 Cache 行，产生冲突缺失，替换后第 7 次访问 0x040 变为缺失（易误判为命中）；② 缺失代价是否包含 Cache 访问时间 $t_c$（第 2 问措辞陷阱） |
| **区分度来源** | 冲突缺失的正确识别决定命中率；缺失代价定义的正确理解决定平均时间 |

## 场景规则（通过条件 / 本题成立 ⇔ 参数间约束）

以下约束**与具体答案值无关**，换参数仍成立，供 gen.py 翻译为 `assert`、供审核对照验证：

1. **Cache 容量一致性**：`Cache总容量 == 块大小 × 块数`（即 $32 \times 8 = 256$ B）。
2. **地址位数守恒**：`地址总位数 == Tag位数 + Index位数 + Offset位数`（$12 = \text{Tag} + 3 + 5$）。
3. **命中率定义**：`命中率 h == 命中次数 / 总访问次数`，且 $0 < h < 1$（非平凡）。
4. **平均访问时间公式**：`t_a == h × t_c + (1−h) × (t_c + t_m')`（缺失代价 = Cache 访问 + 主存访问）。
5. **加速比定义**：`加速比 S == (t_c + t_m') / t_a`（无 Cache 单次访存时间 / 有 Cache 平均访存时间），且 $S > 1$。
6. **冲突缺失存在性**：访存序列中存在至少 1 次冲突缺失（直接映射下不同标记地址映射到同一 Cache 行，导致先前块被替换）。
7. **时间参数约束**：`t_c + t_m' ≥ 5 × t_c`（即 $20 \geq 10$，满足 Cache 有意义的前提）。
