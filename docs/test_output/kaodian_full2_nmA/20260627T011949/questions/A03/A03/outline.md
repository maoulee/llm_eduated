## 考点
- **Cache 映射方式**（核心考点）：三种映射方式（直接映射、全相联映射、组相联映射）的定义辨析、各自特点（灵活性、命中率、查找速度、硬件成本）的区分。
- **考察侧重点**：给定映射方式的描述或特征，判断属于哪种映射方式；或给定地址结构判断映射类型。

## 难度目标
- **K1=3**（标准）：必须准确记忆三种映射方式的定义和核心区别才能入题。题目围绕概念辨析展开，需调用"直接映射/全相联/组相联"的核心定义。
- **K2=1**（微弱）：几乎无计算，或仅需极简单心算（如判断组数、块数是否为2的幂）。
- **K3=1**（微弱）：无需多步推演流程，直接由概念辨析得出答案。
- **K4=2**（较低）：存在常规注意点——例如"组相联中组内采用全相联"与"组间直接映射"的区别，408考生基本不会踩坑但需留心。
- **K5=1**（微弱）：单一知识点内部解决，不涉及其他子系统。
- **达标理由**：本题为概念辨析型选择题，主轴在 K1（概念记忆准确度），其余维度保持低值，整体难度定位 2 级。

## 考察模式
**概念辨析型——Cache 映射方式特征匹配**
- 理由：K1 主导、conceptual 复杂度、2 分选择题，最适合的考法是给出某种映射方式的描述性特征（如地址结构、查找方式、映射约束），要求考生判断属于哪种映射方式。此类考法在 408 历史中出现频率高，能直接测出概念记忆的准确度。

## 出题要求
- **题型**：单项选择题，4 选项（1 正确 + 3 干扰）。
- **总分**：2 分。
- **条件数**：2-3 个显式条件（如 Cache 容量/行数、主存块数或地址结构描述）。
- **条件设计原则**：
  - 条件应足以唯一确定映射方式或使某种特征显著。
  - 可通过地址结构（Tag/组号/块内偏移 的划分）来呈现映射方式的差异。
  - 条件表述应避免直接写出映射方式名称，留给考生判断。
- **参数取值范围**：
  - Cache 行数/块数：2 的幂次，范围 4-256。
  - 主存块数：2 的幂次，范围 16-4096。
  - 组相联的每组行数（路数）：2 或 4（常见值）。
  - 块大小：2 的幂次字节，范围 16B-64B。

## 子问题规划
本题是单项选择题，无子问题划分。单题结构：
- 给出 Cache 的若干特征条件。
- 考生判断映射方式 / 地址结构 / 某项特征。
- 4 个选项对应不同映射方式或不同地址分析结果。

## 参数约束
- **Cache 总行数**：2 的幂次（如 8、16、32、64），保证地址划分清晰。
- **主存块数**：2 的幂次，≥ Cache 行数的 4 倍以上，保证有映射区分度。
- **组相联路数**：2 或 4，与 Cache 行数配合使组数为 2 的幂。
- **一致性约束**：Cache 行数 = 组数 × 路数（组相联场景）；地址各字段位数之和 = 主存地址位数。
- **可调自由度**：Question Agent 可自由选择具体行数、主存块数、块大小、路数的具体值，只要满足上述范围和一致性约束。

## 参考经验
- **考察模式**：概念辨析型是 Cache 映射方式选择题的主流考法，通过特征描述反推映射类型，或给出地址结构判断映射类型。
- **难度锚点**：K1=3 为该题位的典型值，需记忆三种映射方式的核心区别。
- **典型陷阱**：
  - 组相联的"组间直接映射、组内全相联"容易与纯全相联或纯直接映射混淆。
  - 直接映射中"每个主存块只能映射到固定 Cache 行"的约束容易被忽略。
  - 地址结构中 Tag/组号/行号 的位数划分容易混淆。
