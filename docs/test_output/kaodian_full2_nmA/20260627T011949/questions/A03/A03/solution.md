# 概念题解析

## 第 1 题解析

**答案**：A

**解析**：直接映射方式下，主存中的每一块只能映射到 Cache 中唯一指定的一行，映射关系由"主存块号 mod Cache 行数"确定，即取模运算。A 正确。

- B 描述的是全相联映射的特征（任意块可映射到任意行），与直接映射矛盾。
- C 描述的是组相联映射的特征（组间直接映射、组内全相联），张冠李戴。
- D 说用"除法"确定映射关系，应为取模（mod）运算，概念错误。

## 第 2 题解析

**答案**：A

**解析**：基址寻址的有效地址 = 基址寄存器内容 + 形式地址（偏移量）。基址寄存器的内容由操作系统管理（面向多道程序逻辑地址到物理地址的重定位），形式地址作为偏移量在程序运行中不变。A 正确。

- B 描述的是相对寻址（PC + 形式地址），混淆了基址寄存器与 PC。
- C 描述的是变址寻址（变址寄存器 + 形式地址），混淆了基址与变址：基址寄存器由 OS 管理面向重定位，变址寄存器由用户管理面向数组循环。
- D 描述的是立即寻址，形式地址即操作数本身，完全不同。

## 第 3 题解析

**答案**：A

**解析**：中断隐指令（硬件自动完成的操作）包含三步：①关中断（防止在保存断点时被新中断打断）；②保存断点（将 PC 和 PSW 压入堆栈）；③引出中断服务程序入口地址（将中断向量地址装入 PC）。A 正确。

- B 错误：中断隐指令是关中断而非开中断；保存所有通用寄存器是中断服务程序（软件）的工作，不是隐指令完成的。
- C 错误：保存所有通用寄存器不是隐指令的工作，属于中断服务程序的任务；且隐指令完成后 PC 已指向中断服务程序入口，而非"直接执行第一条指令"这一步。
- D 错误：隐指令第一步是关中断而非开中断；中断服务程序入口地址装入 PC 而非通用寄存器。

## 第 4 题解析

① √。DRAM 利用电容存储电荷，电容会自然漏电导致信息丢失，必须定期刷新。
② √。SRAM 利用双稳态触发器存储信息，状态稳定无需刷新；但每个存储单元所需元件多于 DRAM（6 个晶体管 vs 1 个晶体管+1 个电容），故集成度低于 DRAM。
③ ×。DRAM 的刷新不是在每个读/写周期后由 CPU 自动执行，而是由专门的刷新控制电路按固定时间间隔（如 2ms）集中或分散刷新，与 CPU 读/写操作相互独立。
④ √。SRAM 速度优于 DRAM（触发器翻转快于电容充放电），故 Cache 用 SRAM；DRAM 集成度高、成本低，故主存用 DRAM。

## 第 5 题解析

① √。虚拟地址空间大小由 CPU 虚拟地址位数决定（如 32 位虚拟地址 → 4GB），与物理内存容量无关，可远大于物理内存。
② ×。虚页号位数由虚拟地址位数和页大小决定，实页号位数由物理地址位数和页大小决定。由于虚拟地址位数通常 ≥ 物理地址位数，虚页号位数通常 ≥ 实页号位数，二者不一定相同。
③ √。虚拟存储器使 CPU 可发出大范围虚拟地址，但每次实际访存前必须经 MMU（地址转换部件）将虚拟地址转换为物理地址，可能触发缺页处理。
④ ×。虽然页面大小固定，但不同页面的缺页处理开销并不完全相同——若缺页时物理内存已满，需要执行页面替换算法选择被换出的页面，涉及写回脏页等操作，开销因页面状态不同而异。

## 第 6 题解析

① √。链式查询方式中，总线授权信号沿链路依次传递，物理上离总线控制器越近的设备越先收到授权信号，优先级越高。
② √。计数器定时查询方式中，设备优先级由计数器值与设备编号的匹配关系决定。若每次从 0 开始计数，编号最小的设备总是最先被选中，优先级固定不变。若从上次终止处继续计数，则可实现循环优先级。
③ √。独立请求方式中每个设备有独立的请求线和授权线，总线控制器可直接识别请求源并立即响应，速度最快，但控制线数为 O(n)（n 个设备需 2n 条线），硬件最复杂。
④ ×。链式查询方式对电路故障极为敏感——链路上任一设备故障会导致授权信号无法向后续设备传递，其后所有设备都无法获得总线控制权。

## 第 7 题解析

① √。DMA 方式专为高速外设（如磁盘）与主存间大批量数据传送设计，数据传送阶段由 DMA 控制器接管总线控制权，CPU 不干预单个数据传输。
② √。DMA 传送路径为"外设 ↔ DMA 控制器 ↔ 主存"，DMA 控制器直接掌握总线与主存交互，数据不经过 CPU 寄存器，这是 DMA 与中断方式（需 CPU 寄存器中转）的关键区别。
③ ×。DMA 方式仅在数据传送阶段不需要 CPU 参与；预处理（设置传送参数如源地址、目的地址、传送长度）和后处理（数据校验、中断通知 CPU 等）仍需 CPU 参与。完整的 DMA 传送过程是"预处理 → DMA 数据传送（CPU 不干预）→ 后处理（CPU 中断处理）"。
④ ×。DMA 控制器与 CPU 同时请求主存时，通常 DMA 优先级高于 CPU，因为高速外设的数据传送有实时性要求（如磁盘旋转等待），若 CPU 抢占会导致数据丢失。这称为"周期窃取"。

## 第 8 题解析

① √。指令流水线将指令执行过程分为若干阶段（如取指、译码、执行、访存、写回），多条指令在各阶段重叠执行，理想情况下每个时钟周期完成一条指令（CPI → 1）。
② ×。加速比不等于流水线深度。理想加速比受限于流水线中最慢一段（瓶颈段）的执行时间，实际加速比还受冲突（停顿）影响。增加流水段数会增大冲突概率和流水线寄存器延迟，并不一定使每条指令更快。
③ √。结构冲突（资源争用，如同一存储器同时被取指和访存请求）、数据冲突（后续指令需要前面指令尚未写回的结果）和控制冲突（分支指令改变 PC 值）是流水线停顿的三大原因。
④ √。分支预测在取指阶段预判分支方向，减少控制冲突停顿。预测正确时流水线无额外开销；预测错误时必须清空（flush）错误路径上已取入流水线的指令并从正确地址重新取指。
