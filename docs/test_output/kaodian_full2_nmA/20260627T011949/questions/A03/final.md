## 第 1 题

**题干**：某计算机主存物理地址为 12 位，Cache 共 8 行，采用直接映射方式。主存某块的块号对应固定的 Cache 行，无需与整个 Cache 所有行比较。关于直接映射方式的特征，下列描述**正确**的是：

A. 主存中的任意一块只能映射到 Cache 中唯一指定的一行，且每个主存块通过取模运算确定映射的 Cache 行号

B. 主存中的任意一块可以映射到 Cache 中的任意一行，只要该行空闲即可装入，没有固定对应关系

C. 主存中的块被分组，每个组内采用全相联映射，组间采用直接映射，兼顾了冲突率与查找速度

D. 主存中的任意一块只能映射到 Cache 中唯一指定的一行，主存块号与 Cache 行号通过除法运算确定映射关系

---

## 第 1 题解析

**答案**：A

**解析**：直接映射方式下，主存中的每一块只能映射到 Cache 中唯一指定的一行，映射关系由"主存块号 mod Cache 行数"确定，即取模运算。A 正确。

- B 描述的是全相联映射的特征（任意块可映射到任意行），与直接映射矛盾。
- C 描述的是组相联映射的特征（组间直接映射、组内全相联），张冠李戴。
- D 说用"除法"确定映射关系，应为取模（mod）运算，概念错误。
