# solution.md

## 题目

设某机器采用 7 位补码表示整数。已知补码机器数 **1010101**（按从高位到低位排列，最高位为符号位），该补码所表示的十进制真值为（　　）。

A. -43　B. 21　C. 85　D. -42

## 答案

**A. -43**

## 求解过程

### 参数

- 补码位数 n = 7
- 补码机器数 = 1010101（高位 → 低位）
- 符号位 b₆ = 1（负补码），数值位 b₅~b₀ = 010101

### 补码真值定义

对 n 位补码 x = b_{n-1} b_{n-2} ... b_0，其十进制真值为：

> 真值 = (−b_{n-1}) × 2^(n−1) + Σ(b_i × 2^i, i=0..n−2)

即符号位取负权值 −2^(n−1)，其余位按正权值展开。

### 逐位展开（对应 gen.py PROCESS 数据流）

| 位序(bit) | bit_pos | 二进制值 | 权值 | 贡献 |
|-----------|---------|----------|------|------|
| 0 | 6 | 1 | −2⁶ | −64 |
| 1 | 5 | 0 | +2⁵ | 0 |
| 2 | 4 | 1 | +2⁴ | 16 |
| 3 | 3 | 0 | +2³ | 0 |
| 4 | 2 | 1 | +2² | 4 |
| 5 | 1 | 0 | +2¹ | 0 |
| 6 | 0 | 1 | +2⁰ | 1 |

求和：−64 + 16 + 4 + 1 = **−43**

> gen.py PROCESS_SUM 验证：sum = −43 == A = −43 ✓

### 结论

正确真值 = −43，对应选项 **A**。

## 干扰项分析（对应 gen.py OPTION 数据流）

| 选项 | 数值 | 错误类型 | 说明 |
|------|------|----------|------|
| **A** | −43 | 正确 | 按补码正确定义展开：−2⁶+2⁴+2²+2⁰ = −43 |
| B | 21 | 符号位判断错误 | 忽略符号位负权值，仅低 6 位 b₅~b₀ 按正权展开：2⁴+2²+2⁰ = 16+4+1 = 21 |
| C | 85 | 全部按无符号正权展开 | 将 7 位全部视为正权值：2⁶+2⁴+2²+2⁰ = 64+16+4+1 = 85 |
| D | −42 | 某一位漏算 | 按补码展开但漏算 2⁰ 位（A + 2⁰ = −43 + 1 = −42），数值近邻 |

## 场景规则验证（对应 gen.py RULE_CHECK 数据流）

1. **补码定义重建**：用定义公式重建 = −43 == A = −43 ✓
2. **符号位约束**：b₆ == 1（负补码），真值 −43 < 0 ✓
3. **真值非平凡**：|A| = 43，非 2 的幂 ✓
4. **4 选项互异**：{-43, 21, 85, -42} 四值两两不同 ✓
5. **仅 A 为正确答案**：A == 补码正确展开值，且 B≠A、C≠A、D≠A ✓
6. **干扰项对应声明错误类型**：
   - B == 低 6 位正权展开值 21 ✓
   - C == 全 7 位无符号正权展开值 85 ✓
   - D == A + 2⁰ = −42（漏算 2⁰ 位）✓
7. **干扰项合理性**：B、C、D 均为同类题常见误算的真实产物，非荒谬值 ✓
