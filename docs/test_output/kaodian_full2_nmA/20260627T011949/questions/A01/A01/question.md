# question.md

## 题目

设某机器采用 7 位补码表示整数。已知补码机器数 **1010101**（按从高位到低位排列，最高位为符号位），该补码所表示的十进制真值为（　　）。

A. -43  
B. 21  
C. 85  
D. -42  

---

## 设计说明

### 考察意图
- **core_knowledge_intent**：补码真值的求值——学生需理解补码的符号位具有负权值 −2^(n−1)，其余位按正权值展开，将 n 位补码机器数转换为十进制真值。
- **examination_mode**：计算型——给定一个负补码机器数，求其真值。
- **K 主导**：K2（一步非平凡补码求值计算）+ K1（补码定义的准确记忆）。

### 选项设计（错误类型映射）

| 选项 | 数值 | 错误类型 | 说明 |
|------|------|----------|------|
| A | -43 | 正确 | 按补码正确展开：−2⁶ + 2⁴ + 2² + 2⁰ = −64+16+4+1 = −43 |
| B | 21 | 符号位判断错误 | 忽略符号位负权值，仅低 6 位按正权展开：2⁴+2²+2⁰ = 21 |
| C | 85 | 全部按无符号正权展开 | 将 7 位全部视为正权值：2⁶+2⁴+2²+2⁰ = 85 |
| D | -42 | 某一位漏算 | 按补码展开但漏算 2⁰ 位（−43+1 = −42），数值近邻 |

### 参数选择理由
- **n = 7**（奇数位，满足 5 ≤ n ≤ 8 约束）。
- 补码机器数 **1010101**：符号位为 1（负补码），真值绝对值 43（非 2 的幂），满足 hard_constraints。
- 4 个选项互斥：−43、21、85、−42 四个值互不相同，有充分区分度。

---

## 通过条件（场景规则）

> 以下约束与具体答案值无关，换参数仍成立，供 gen.py 翻译为 assert：

1. **补码真值定义约束**：对 n 位补码 x = b_{n-1} b_{n-2} ... b_0，其十进制真值 == (−b_{n-1}) × 2^(n−1) + Σ(b_i × 2^i, i=0..n−2)。
2. **符号位约束**：最高位 b_6 == 1（负补码），真值 < 0。
3. **真值非平凡约束**：|真值| 不是 2 的幂（排除退化情况）。
4. **4 选项互异**：A、B、C、D 四个值两两不同。
5. **正确值唯一**：在给定参数下，A == 补码正确展开的真值，且仅 A 为正确答案。
6. **干扰项对应声明错误类型**：
   - B == 仅低 6 位正权展开的值（忽略符号位负权值）。
   - C == 全部 7 位按无符号正权展开的值。
   - D == 正确展开后某一特定位（2^k）权值偏差 1 个 2^k 的值。
7. **干扰项合理性**：B、C、D 均为同类题常见误算的真实产物，非荒谬值。

## 题干参数清单（供 gen.py 使用）

| 参数 | 值 | 说明 |
|------|----|------|
| n | 7 | 补码位数 |
| machine_number | 1010101 | 补码机器数（二进制字符串，高位→低位） |
| bit[6] | 1 | 符号位（负补码） |
| bit[5..0] | 010101 | 数值位 |

### gen.py 需计算并验证的项目

1. 正确真值 A（按补码展开）。
2. 干扰项 B（低 6 位正权展开）。
3. 干扰项 C（全 7 位无符号正权展开）。
4. 干扰项 D（正确展开 ± 2^k，k=0，即漏算 2^0 位）。
5. 验证上述 4 值互异。
6. 验证 |A| 不是 2 的幂。
