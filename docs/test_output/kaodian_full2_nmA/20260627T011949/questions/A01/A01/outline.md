## 考点
- **补码真值求法**（核心）：给定若干位的补码表示，求其对应的十进制真值
- **补码表示范围**（核心）：n 位补码的表示范围，特别是最小负数（无对应正数）这一边界特性
- 考察侧重点：补码 ↔ 真值的转换规则、补码范围上下界的不对称性

## 难度目标
- **K1=3（标准）**：必须准确记忆补码的定义（按权展开、符号位权重为负）才能入题；概念模糊会直接算错
- **K2=3（标准，主导维度）**：需代入补码求值公式做一次非平凡计算（数字未必是 2 的幂，或位数非典型），单步但需仔细
- **K3=2（较低）**：求值路径唯一，2 步以内（符号位判断 → 按权展开求和）
- **K4=2（较低）**：存在常规注意点（如最小负数特殊值、范围不对称），但 408 考生基本不会踩坑
- **K5=1（微弱）**：纯补码单知识点内部解决，不涉及其他子系统

## 考察模式
- **计算型——补码真值/范围判断**：给定一个补码机器数，要求计算其真值，或将真值与给定选项逐一比对。正确选项需要准确执行补码→真值转换；干扰项对应常见错误路径。
- 选择此模式的理由：补码真值计算是 K2 主导的标准考法，计算路径唯一、区分度清晰，适合 difficulty=2 的选择题。

## 出题要求
- 题型：单项选择题，4 选项，1 正确 3 干扰
- 总条件数：1-2 个显式条件（给出补码机器数 + 位数信息）
- 条件设计原则：
  - 明确给出机器数字长（n 位）和补码二进制序列
  - 位数建议取 5-8 位（非典型 8/16 位），确保真值不是一目了然的常见值
  - 可结合"范围内/范围外"或"求真值"两种问法之一
- 参数取值范围要求：见下方"参数约束"

## 子问题规划
- 单项选择题，无子问题拆分。选项结构如下：
  - 正确选项：正确执行补码→真值转换的结果
  - 干扰项1：符号位判断错误（把负数当正数按权展开）
  - 干扰项2：未考虑符号位权重（全部按正权展开再补符号）
  - 干扰项3：数值相近但计算细节出错（如某一位权重漏算/多算）

## 参数约束
- **补码位数 n**：5 ≤ n ≤ 8，建议取奇数位（如 5、7），避免学生用 8 位直接心算
- **补码机器数的最高位（符号位）**：必须为 1（负数），因为负数补码的转换更容易暴露错误路径，区分度更高
- **真值的绝对值**：非 2 的整数幂，确保不是一眼可读的常见值
- **真值与各干扰项的距离**：各错误路径产生不同数值，且彼此不相等，保证 4 个选项互不重合
- **自由度**：具体补码序列、具体位数由 Question Agent 选定，只需满足上述约束
