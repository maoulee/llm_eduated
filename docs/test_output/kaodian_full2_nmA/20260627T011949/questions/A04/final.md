## 第 2 题

**题干**：某指令格式如下：操作码字段后紧跟一个形式地址字段。若某条指令采用**基址寻址**，则关于其有效地址的计算方式，下列描述**正确**的是：

A. 有效地址 = 基址寄存器内容 + 形式地址（偏移量），基址寄存器的内容由操作系统管理，面向多道程序实现程序重定位

B. 有效地址 = 程序计数器（PC）内容 + 形式地址，常用于实现相对转移和分支指令

C. 有效地址 = 变址寄存器内容 + 形式地址，变址寄存器的内容由用户在程序运行中修改，适合处理数组和循环

D. 有效地址 = 形式地址本身，操作数直接编码在指令中，无需访问任何寄存器或存储器

---

## 第 2 题解析

**答案**：A

**解析**：基址寻址的有效地址 = 基址寄存器内容 + 形式地址（偏移量）。基址寄存器的内容由操作系统管理（面向多道程序逻辑地址到物理地址的重定位），形式地址作为偏移量在程序运行中不变。A 正确。

- B 描述的是相对寻址（PC + 形式地址），混淆了基址寄存器与 PC。
- C 描述的是变址寻址（变址寄存器 + 形式地址），混淆了基址与变址：基址寄存器由 OS 管理面向重定位，变址寄存器由用户管理面向数组循环。
- D 描述的是立即寻址，形式地址即操作数本身，完全不同。
