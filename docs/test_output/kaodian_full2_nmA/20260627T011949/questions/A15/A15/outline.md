## 考点
- **核心考点**：流水线吞吐率（TP）的计算——需掌握吞吐率定义公式 TP = 任务数 / 总执行时间，理解流水线建立时间和排空时间对总时间的影响
- **核心考点**：流水线加速比（Speedup）的计算——需掌握 S = 顺序执行时间 / 流水线执行时间 的定义，理解吞吐率与加速比的关系
- **辅助考点**：流水线各段时间不等时的瓶颈段处理——最长段决定流水线时钟周期，需理解时钟周期取各段最大值的约束
- **辅助考点**：流水线效率（Efficiency）——可选考查，理解效率 = 吞吐率 × 单条指令处理时间的含义

## 难度目标
- **K1=3（标准）**：必须准确记忆吞吐率、加速比的定义公式才能入题，这些是流水线分析的核心概念，模糊记忆会导致公式套错
- **K2=3（标准）**：需代入常规公式计算，涉及非2的幂次的乘除运算，计算量适中但非心算可直接得出
- **K3=3（标准）**：需按固定流程走完3-5步——计算单条指令各段时间→确定流水线时钟周期→计算总执行时间→计算吞吐率→计算加速比，路径唯一但步骤明确
- **K4=2（较低）**：存在常规注意点——时钟周期取各段最大值、流水线执行总时间需考虑建立时间，408考生基本不会踩坑但需注意
- **K5=1（微弱）**：单一知识点（流水线性能分析）内部解决，不涉及跨子系统数据传递

**K3 为主导维度的理由**：本题核心是多步串行推演——从流水线参数出发，经过时钟周期确定、总时间计算、吞吐率和加速比求解的完整流程，步数在3-5步之间，符合K3=3标准。

## 考察模式
**计算题——指令流水线吞吐率/执行时间**（与 slot 指定的 examination_mode 一致）

选择理由：
- 该题位在408中经典的考法是给出流水线段数、各段时间、指令条数，要求计算吞吐率和加速比
- 此模式直接对应K3主导，强调流程性推演
- 综合题形式允许分步设问，覆盖吞吐率和加速比两个核心指标

## 出题要求
- **题型**：综合题（计算题形式）
- **总分**：7分
- **总条件数**：3-4个显式条件（流水线段数、各段时间或至少部分段时间、指令条数/任务数）
- **条件设计原则**：
  - 给出流水线段数 k（如4-6段）
  - 给出各段时间，其中至少有两个段的时间不同（制造瓶颈段，测试K4=2的注意点）
  - 给出需要执行的指令/任务条数 n（使得吞吐率计算有意义，n不宜过小）
- **参数取值范围要求**：
  - 段数 k：4-6段
  - 各段时间：含非2的幂次的值，部分段时间不等
  - 指令条数 n：≥10，且非2的幂次，使得结果有计算量

## 子问题规划
- **第1问（3分）——计算题**：计算该流水线执行 n 条指令的总时间和吞吐率。考察时钟周期确定（取最长段）、总执行时间公式（k个建立时间 + n-1个时钟周期）、吞吐率公式。本问是后续问的基础。
- **第2问（2分）——计算题**：计算加速比。以第1问得到的流水线总时间为基础，计算顺序执行总时间，求加速比。与第1问串行依赖。
- **第3问（2分）——分析题**：若对瓶颈段进行细分（将最长段拆为等长的两段），重新计算吞吐率并与原值比较，分析瓶颈段优化对流水线性能的影响。考察对流水线优化机制的理解，与第1问并行（可独立计算）。

**依赖关系**：第1问→第2问（串行）；第1问→第3问（弱依赖，第3问基于第1问的参数做变体分析）

## 参数约束
- **流水线段数 k**：取值范围 4-6，建议5段（经典五级流水线）
- **各段时间 t_i**：每个段为整数（单位ns或时钟周期），至少有2个段的时间不同；最长段与最短段差距不宜过大（差值在1-2个单位内），保证瓶颈段拆分有意义；部分段时间为非2的幂次
- **指令条数 n**：取值范围 10-100，非2的幂次，使得 n 较大时流水线吞吐率趋近理论最大值的现象可观测
- **一致性约束**：各段时间的最大值即为流水线时钟周期 Δt；瓶颈段拆分后的新段数 = k+1，拆分后新各段最大时间 ≤ 原各段次大时间（保证拆分能提升吞吐率）
- **可调自由度**：Question Agent 可自行选择具体段数、各段时间值和指令条数，只要满足上述约束

## 参考经验
- **考察模式**：408真题中流水线性能分析的典型模式为"给参数→算总时间→算吞吐率/加速比"，步骤固定
- **难度锚点**：K3=3 对应3-5步固定流程，本题从段参数到最终加速比约4步，匹配标准难度
- **典型陷阱**：
  1. 时钟周期取各段最大值而非平均值（K4=2注意点）
  2. 流水线总时间 = (k + n - 1) × Δt，易误写为 k × n × Δt 或忽略 n-1
  3. 加速比分子为顺序执行时间（各段时间之和 × n），非流水线各段独立时间之和
  4. 瓶颈段拆分后段数变化，需重新确定时钟周期
