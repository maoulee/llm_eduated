## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 中央处理器 > 流水线
- primary_target_name: 流水线吞吐率与加速比
- question_type: comprehensive
- examination_mode: 计算题——指令流水线吞吐率/执行时间

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 核心是多步串行推演（时钟周期确定→总执行时间→吞吐率→加速比），步数4步符合K3=3标准；需准确记忆公式（K1=3）；计算含非2幂次值（K2=3）；存在时钟周期取最大值的常规注意点（K4=2）；单知识点内部解决（K5=1）

### 结构要求
- sub_question_count: 3
- sub_question_details:
  - Q1: 计算题，3分，求流水线执行n条指令的总时间和吞吐率
  - Q2: 计算题，2分，求加速比，依赖Q1结果
  - Q3: 分析题，2分，瓶颈段拆分后重新计算吞吐率并分析性能影响，基于Q1参数做变体
- dependency: Q1→Q2 串行；Q1→Q3 弱依赖
- distractor_strategy: 不适用（综合题为开放计算，无干扰选项）

### 参数约束
- 流水线段数 k: 4-6段，建议5段
- 各段时间 t_i: 整数（ns），至少2个段不等，最长与最短差值在1-2单位内，部分非2的幂次
- 指令条数 n: 10-100，非2的幂次
- 一致性约束:
  - 流水线时钟周期 Δt = max(t_i)
  - 流水线总时间 = (k + n - 1) × Δt
  - 顺序执行总时间 = sum(t_i) × n
  - 瓶颈段拆分约束：拆分后新段数 = k+1，新各段最大时间 ≤ 原次大段时间

### 参考经验摘要
- 历史模式: 给流水线参数→算总时间→算吞吐率/加速比，固定流程
- 难度锚点: K3=3对应3-5步流程，本题约4步
- 典型陷阱:
  1. 时钟周期取各段最大值非平均值
  2. 总时间公式 (k+n-1)×Δt 易写错
  3. 加速比分子为顺序执行时间
  4. 瓶颈段拆分后段数与时钟周期均需重算
