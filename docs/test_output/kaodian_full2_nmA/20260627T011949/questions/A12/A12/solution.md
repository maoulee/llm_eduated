## 第 (1) 题：IEEE754 拆解（2 分）

将 32 位机器数拆为 符号 | 阶码字段(8位) | 尾数字段(23位)，再还原隐含前导 1。

### X = 0x40780000

二进制：`0 10000000 11110000000000000000000`

| 属性 | 值 |
|------|----|
| 符号 | 0（正数） |
| 阶码字段 | 10000000₂ = 128₁₀ |
| 实际指数 | 128 − 127 = **1** |
| 尾数字段 | 11110000000000000000000 |
| 1.M 形式 | **1.11110000000000000000000** |

### Y = 0x3EF80003

二进制：`0 01111101 11110000000000000000011`

| 属性 | 值 |
|------|----|
| 符号 | 0（正数） |
| 阶码字段 | 01111101₂ = 125₁₀ |
| 实际指数 | 125 − 127 = **−2** |
| 尾数字段 | 11110000000000000000011 |
| 1.M 形式 | **1.11110000000000000000011** |

## 第 (2) 题：对阶（2 分）

### 确定小阶操作数与移位次数

- X 的实际指数 = 1，Y 的实际指数 = −2。
- 阶差 = |1 − (−2)| = **3**。
- Y 的阶码较小，需将 **Y 的尾数右移 3 位**，使其指数对齐到 1。

### 对阶后的尾数

以大阶指数（exp = 1）为基准：

| 操作数 | 对阶后尾数（1.M 形式，基准 exp=1） | 说明 |
|--------|-------------------------------------|------|
| X（大阶，不移位） | 1.11110000000000000000000 | 原值不变 |
| Y（小阶，右移 3 位） | 0.00111110000000000000000 | 原尾数右移 3 位 |

**移出的位**：Y 尾数右移 3 位，移出的 3 位为 **`011`**（最低 3 位）。

- Guard 位（移出部分的最高位）= **0**
- Round 位（移出部分的次高位）= **1**
- Sticky 位（移出部分其余位的 OR）= **1**（最低位为 1）

> 这 3 个移出位在后续舍入判断中作为保护位（GRS）参与运算。

## 第 (3) 题：尾数加法 + 规格化 + 舍入 + 组装（2 分）

### 第一步：尾数加法

对阶后两尾数（含保护位扩展精度）相加，在扩展精度（24 位 + 3 位移出位 = 27 位）下精确求和：

```
  1.11110000000000000000000 000    （X 尾数，末尾补 3 位 0）
+ 0.00111110000000000000000 011    （Y 尾数对阶后，含移出位 011）
= 10.00101110000000000000000 011    （精确和）
```

- 精确和（整数表示）= 146,276,355
- 二进制 = `1000101110000000000000000011`（27 位）
- **尾数之和 ≥ 2.0**（整数部分的最高位出现进位 carry_bit = 1）→ 需执行**右规**。

### 第二步：右规（规格化）

尾数之和 ≥ 2.0（1.M 形式中整数部分为 10），执行右规：尾数右移 1 位，阶码 +1。

- 右移前阶码 = 1 → 右规后阶码 = **1 + 1 = 2**
- 右移后尾数（扩展精度）= `1.00010111000000000000000 001`（整数 = 73,138,177，27 位）

> 右规移出的最低 1 位与对阶移出的保护位合并，共同决定舍入。

### 第三步：舍入（round to nearest even）

右规后保留 24 位（1.M），低位（3 位）参与舍入判断：

- **保留部分**（kept_part）= `1.00010111000000000000000`（整数 = 9,142,272）
- **舍入部分**（round_part）= `001`（3 位）
- **舍入阈值（half）**= `100`（即 4）

| 比较 | 结果 |
|------|------|
| round_part（001）vs half（100） | 001 < 100 → **向下舍入（截断）** |

舍入后尾数不变：`1.00010111000000000000000`

- 23 位尾数字段 = **00010111000000000000000**
- 舍入无额外进位（carry_after_round = False）

### 第四步：组装 IEEE754 机器数

| 字段 | 值 |
|------|----|
| 符号 | 0（正数） |
| 阶码（实际） | 2₁₀ |
| 阶码字段 | 2 + 127 = 129₁₀ = **10000001**₂ |
| 尾数字段 | 00010111000000000000000 |

组装：

```
0 | 10000001 | 00010111000000000000000
```

十六进制：

```
0 10000001 00010111000000000000000
= 0100 0000 1000 1011 1000 0000 0000 0000
= 0x408B8000
```

---

## 最终答案

$$\boxed{Z = \text{0x408B8000}}$$

- 最终阶码 = **2**（十进制），阶码字段 = **10000001**（二进制，129 十进制）
- 规格化尾数（1.M）= **1.00010111000000000000000**，23 位尾数字段 = **00010111000000000000000**

## 验证

用 Python 双精度浮点 `struct.pack('!f', X_float + Y_float)` 验证，结果为 **0x408B8000**，与手算模型完全一致。

| 场景规则 | 验证 |
|----------|------|
| 有效规格化数 | eX_f=128, eY_f=125，均在 1–254 ✓ |
| 同号加法 | sX=0, sY=0 ✓ |
| 阶码差 ≥ 2 | \|exp(X)−exp(Y)\| = 3 ✓ |
| 触发右规 | 尾数和 carry_bit = 1 ✓ |
| 结果不溢出 | 最终阶码字段 = 129，在 1–254 ✓ |
| 移出位有效（Sticky=1） | 对阶移出位 = 011，Guard=0, Round=1, **Sticky=1** ✓ |
| 舍入正确性 | 模型结果 = Python float 结果 = 0x408B8000 ✓ |
