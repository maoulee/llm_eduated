# IEEE754 单精度浮点加法分步推演

## 题目

给定两个 IEEE754 单精度（32 位）浮点数，其机器数表示（十六进制）为：

- **X = 0x40780000**
- **Y = 0x3EF80003**

请按 IEEE754 单精度浮点加减运算流程，求 **Z = X + Y** 的机器数表示（十六进制）。

> IEEE754 单精度格式：1 位符号 + 8 位阶码（偏移量 bias = 127）+ 23 位尾数（隐含前导 1）。
> 舍入方式：就近舍入（round to nearest even），保留 Guard、Round、Sticky 位参与舍入判断。

### 第 (1) 题（2 分）

分别写出 X 和 Y 的符号、阶码（给出实际指数值）、尾数（还原隐含前导 1 后的 1.M 形式）。

### 第 (2) 题（2 分）

执行对阶操作：将小阶操作数的尾数右移至与大阶操作数对齐。

- 指出哪个操作数需要移位，移位次数为多少。
- 写出对阶后两个操作数的尾数（以大阶操作数的指数为基准），标明移出的位。

### 第 (3) 题（2 分）

完成尾数加法、规格化（含舍入处理），写出最终结果 Z 的：

- 规格化后的尾数（含舍入后的 23 位尾数值）；
- 最终阶码（十进制与二进制）；
- Z 的完整 IEEE754 机器数（十六进制）。

## 设计意图

| 考察项 | 对应子问 | K 目标 | 说明 |
|---|---|---|---|
| IEEE754 格式拆解（符号/阶码/隐含尾数） | (1) | K1, K2 | 考生须记忆格式定义、偏移量，正确还原隐含前导 1 |
| 对阶方向与移位 | (2) | K2, K3 | 小阶向大阶对齐；反向操作导致错误，(2) 问直接检验 |
| 尾数加法 + 右规 + 舍入 + 组装 | (3) | K3 | 尾数之和 ≥ 2.0 触发右规，对阶移出位参与舍入判断，阶码须 +1 |
| 串行依赖 | (1)→(2)→(3) | — | 前一步错误会传播到后续全部步骤 |

**核心陷阱**：
- 隐含前导 1 遗漏 → 尾数全程错误（(1) 问可检出）。
- 对阶方向反向 → 中间值错误（(2) 问可检出）。
- 右规后阶码忘记 +1 → 最终阶码/机器数错误（(3) 问可检出）。
- 对阶移出位的 Guard/Round/Sticky 舍入处理不当 → 尾数末位错误（(3) 问可检出）。

## 场景规则（本题成立的可机检约束）

以下约束与具体答案值无关，换参数仍须成立，供 gen.py 翻译为 `assert`：

1. **有效规格化数**：X 和 Y 的阶码字段均在 1–254 区间内，均为规格化浮点数（非零、非非规格化、非 inf/NaN）。
2. **同号加法**：X 和 Y 符号位相同（均为 0，正数），尾数运算为加法而非减法。
3. **阶码差 ≥ 2**：|exp(X) − exp(Y)| ≥ 2，对阶操作须右移 ≥ 2 位，使对阶步骤非平凡。
4. **触发右规**：对阶后两尾数之和（1.M 形式）≥ 2.0，必须执行右规（右移 1 位、阶码 +1），使规格化步骤非平凡。
5. **结果不溢出**：右规后最终阶码字段仍在 1–254 区间内（无上溢/下溢/非规格化退化）。
6. **移出位有效**：对阶过程中小阶操作数尾数有非零位被移出（Guard/Round/Sticky 至少 Sticky 位为 1），使舍入判断步骤非平凡。
7. **舍入正确性**：最终结果 Z 的值与 X + Y 的数学精确和在 IEEE754 单精度精度范围内一致（round to nearest even）。
