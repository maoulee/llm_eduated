## 题目

**题目分值：10 分**

某计算机系统的 CPU 时钟频率为 100 MHz，总线周期等于时钟周期。一台外设需将一个大小为 4KB（4096 字节）的数据块从设备传送到主存。系统支持两种 I/O 控制方式，相关参数如下：

**中断方式参数：**
- 每次中断传送 2 个字节的数据；
- 每次中断的响应与处理（包括保护现场、数据搬运、恢复现场）共需 **3 μs**。

**DMA 方式参数：**
- 每次 DMA 传送以 1 个字（4 字节）为单位，每传送一个字窃取 1 个总线周期；
- DMA 启动前的预处理（初始化 DMA 控制器、设置传送参数等）需 **5 μs**，仅发生一次；
- DMA 传送结束后，设备向 CPU 发出一个中断，CPU 进行后处理需 **5 μs**，仅发生一次；
- 在 DMA 数据传送期间，CPU 与 DMA 控制器分时使用总线，不影响其他 CPU 工作（除周期窃取外）。

**设备参数：**
- 设备的数据传输速率为 **2 MB/s**（1 MB = 10⁶ B）。

请回答以下问题：

**第 1 问（3 分）：** 采用中断驱动 I/O 方式，计算传送完整数据块所消耗的 CPU 总时间（单位用 μs 表示）。

**第 2 问（3 分）：** 采用 DMA 方式，计算传送完整数据块所消耗的 CPU 总时间，包括预处理时间、周期窃取时间和后处理时间（单位用 μs 表示）。

**第 3 问（2 分）：** 计算 DMA 方式比中断方式节省的 CPU 时间百分比（即节省量占中断方式 CPU 时间的比例），保留两位小数。

**第 4 问（2 分）：** 在 DMA 方式的数据传送阶段，周期窃取占用 CPU 的时间占该数据块传送总时间（即设备以 2 MB/s 速率传完 4KB 数据所需时间）的百分比是多少？保留两位小数。

---

## 参考答案

| 问 | 答案 |
|----|------|
| 第 1 问 | **6144 μs** |
| 第 2 问 | **20.24 μs** |
| 第 3 问 | **99.67%** |
| 第 4 问 | **0.50%** |

---

## 解析

### 第 1 问（3 分）：中断方式 CPU 总时间

**中断次数：**

$$n_{int} = \frac{D}{d_{int}} = \frac{4096}{2} = 2048 \text{ 次}$$

每次中断 CPU 开销 3 μs（包括响应、保护现场、数据搬运、恢复现场）。

**中断方式 CPU 总时间：**

$$T_{int} = n_{int} \times t_{int} = 2048 \times 3 = \boxed{6144 \text{ μs}}$$

### 第 2 问（3 分）：DMA 方式 CPU 总时间

**DMA 传送次数（周期窃取次数）：**

$$n_{dma} = \frac{D}{d_{dma}} = \frac{4096}{4} = 1024 \text{ 次}$$

**总线周期：**

$$T_{bus} = \frac{1}{f} = \frac{1}{100 \times 10^6} \text{ s} = 10^{-8} \text{ s} = 0.01 \text{ μs}$$

**三部分 CPU 开销：**

- 预处理时间 = 5 μs × 1 次 = **5 μs**
- 周期窃取总时间 = n_dma × T_bus = 1024 × 0.01 = **10.24 μs**
- 后处理时间 = 5 μs × 1 次 = **5 μs**

**DMA 方式 CPU 总时间：**

$$T_{dma} = 5 + 10.24 + 5 = \boxed{20.24 \text{ μs}}$$

> 注意：预处理和后处理各只发生一次，不随传送字数增长。

### 第 3 问（2 分）：DMA 节省 CPU 时间百分比

**节省量：**

$$6144 - 20.24 = 6123.76 \text{ μs}$$

**节省百分比（占中断方式 CPU 时间）：**

$$\frac{6123.76}{6144} \times 100\% = \boxed{99.67\%}$$

### 第 4 问（2 分）：周期窃取占设备传输时间的百分比

**设备实际传输时间（分母）：**

$$T_{device} = \frac{D}{R} = \frac{4096}{2 \times 10^6} = 0.002048 \text{ s} = 2048 \text{ μs}$$

**周期窃取占用 CPU 的总时间（分子）：**

$$T_{steal} = n_{dma} \times T_{bus} = 1024 \times 0.01 = 10.24 \text{ μs}$$

**占比：**

$$\frac{10.24}{2048} \times 100\% = \boxed{0.50\%}$$

> 注意：第 4 问分母是设备以 2 MB/s 速率传完 4KB 数据的物理时间（2048 μs），不是 CPU 时间（20.24 μs）。周期窃取仅占设备传输时间的 0.50%，说明 DMA 对 CPU 性能影响极小。
