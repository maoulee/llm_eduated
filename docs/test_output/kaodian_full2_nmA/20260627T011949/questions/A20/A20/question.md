# question.md — I/O 系统综合（中断/DMA 对比与时间计算）

## 题目分值：10 分

## 题干

某计算机系统的 CPU 时钟频率为 100 MHz，总线周期等于时钟周期。一台外设需将一个大小为 4KB（4096 字节）的数据块从设备传送到主存。系统支持两种 I/O 控制方式，相关参数如下：

**中断方式参数：**
- 每次中断传送 2 个字节的数据；
- 每次中断的响应与处理（包括保护现场、数据搬运、恢复现场）共需 **3 μs**。

**DMA 方式参数：**
- 每次 DMA 传送以 1 个字（4 字节）为单位，每传送一个字窃取 1 个总线周期；
- DMA 启动前的预处理（初始化 DMA 控制器、设置传送参数等）需 **5 μs**，仅发生一次；
- DMA 传送结束后，设备向 CPU 发出一个中断，CPU 进行后处理需 **5 μs**，仅发生一次；
- 在 DMA 数据传送期间，CPU 与 DMA 控制器分时使用总线，不影响其他 CPU 工作（除周期窃取外）。

**设备参数：**
- 设备的数据传输速率为 **2 MB/s**（1 MB = 10⁶ B）。

请回答以下问题：

**第 1 问（3 分）：** 采用中断驱动 I/O 方式，计算传送完整数据块所消耗的 CPU 总时间（单位用 μs 表示）。

**第 2 问（3 分）：** 采用 DMA 方式，计算传送完整数据块所消耗的 CPU 总时间，包括预处理时间、周期窃取时间和后处理时间（单位用 μs 表示）。

**第 3 问（2 分）：** 计算 DMA 方式比中断方式节省的 CPU 时间百分比（即节省量占中断方式 CPU 时间的比例），保留两位小数。

**第 4 问（2 分）：** 在 DMA 方式的数据传送阶段，周期窃取占用 CPU 的时间占该数据块传送总时间（即设备以 2 MB/s 速率传完 4KB 数据所需时间）的百分比是多少？保留两位小数。

## 设计意图

| 子问 | 考察目标 | 区分点 / 陷阱 |
|------|---------|--------------|
| 第1问 | 中断方式 CPU 时间计算 | **中断次数 = D / d_int**，不是 D；每次中断开销 × 中断次数 = 总时间 |
| 第2问 | DMA 方式 CPU 时间计算 | ①预处理和后处理各只发生**一次**（非每字一次）；②周期窃取次数 = D / d_dma，每次窃取 1 个总线周期 = T_bus = 1/f；③需将 ns 转换为 μs 统一单位 |
| 第3问 | 两种方式效率对比 | 正确引用第1、2问结果计算节省百分比，考察结果对比能力 |
| 第4问 | DMA 周期窃取对 CPU 性能影响 | 分子 = 周期窃取总时间（由 D/d_dma × T_bus 算出）；分母 = 设备实际传输时间（由 D / 设备速率 算出），不是 CPU 时间 |

## 场景规则（通过条件 — 本题成立 ⇔ 以下参数间约束均被满足）

> 以下约束与具体答案值无关，换参数仍成立。供 write_gen 翻译为 `assert`，供 dual_review 对照数据流验证。

1. **整除约束**：D mod d_int == 0 **且** D mod d_dma == 0（数据块可被每次传送量整除，传送次数为整数）。
2. **中断高频特征**：D / d_int ≥ 1000（中断方式中断次数足够多，体现中断方式对 CPU 的高频占用特征）。
3. **中断次数公式**：中断次数 == D / d_int（≠ D，≠ D/d_dma）。
4. **DMA 预处理/后处理各一次**：DMA 预处理时间计入 1 次、后处理时间计入 1 次（不随传送字数增长）。
5. **DMA 周期窃取次数**：窃取总线周期数 == D / d_dma；每个总线周期时间 == 1 / f（秒）。
6. **DMA 效率优势**：中断方式 CPU 总时间 > DMA 方式 CPU 总时间（确保第3问节省百分比为正值，且 DMA 方式确实更高效）。
7. **第4问分母语义**：第4问的分母 == D / R（设备传输速率，单位 B/s），即设备实际传输 4KB 所需物理时间；分子 == D / d_dma × T_bus（周期窃取占用 CPU 的总时间）。分子 < 分母（窃取占比 < 100%）。
