## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 总线 > 带宽
- primary_target_name: 总线带宽计算
- question_type: comprehensive
- examination_mode: 计算题——同步总线带宽=宽度×频率

### 难度目标
- k_target: K1=3,K2=3,K3=2,K4=2,K5=1
- difficulty_level: 2
- difficulty_rationale: 总线带宽为固定公式代入计算题，K2为主导（标准单步代入，非2幂次），K3/K4低（路径唯一、仅有常规注意点），K5=1（单知识点闭环）。整体难度标准偏易，与slot target_difficulty=2一致。

### 结构要求
- sub_question_count: 3
- sub_question_details:
  - SQ1 (2分): 计算总线理论带宽 = 总线宽度 × 时钟频率；类型：直接计算；考察K2
  - SQ2 (2分): 计算有效带宽 = 理论带宽 ÷ 事务周期数；类型：推导计算；考察K2+K4
  - SQ3 (3分): 利用有效带宽计算传输指定数据量的时间；类型：多步计算；考察K2+K3
- dependency: 串行递进（SQ1→SQ2→SQ3）
- condition_count: 3-4

### 参数约束
- 总线宽度 W: 取值 4B 或 8B（数据线位数，2的幂便于字节换算）
- 总线时钟频率 f: 取值 50~200MHz，优先非2的幂整数值，使计算非平凡
- 事务周期数 N: 取值 2~4（整数），约束 N≥2 确保有效带宽≠理论带宽
- 待传输数据量 D: 取值使 D/W 为非整数，迫使子问题3需向上取整处理
- 一致性约束: f×W 的乘积应便于除以N得到简洁的有效带宽值（避免无限小数）
- 自由度: W和N低自由度（有限取值），f和D中等自由度

### 参考经验摘要
- 历史模式: 408总线带宽题固定为"带宽=宽度×频率"直接代入计算，可结合事务周期考有效带宽
- 难度锚点: K2主导（=3），K1=3（需记忆公式），K3/K4低，K5=1（单知识点）
- 典型陷阱: ①忽略事务多周期占用导致有效带宽≠理论带宽；②传输次数需向上取整；③混淆总线时钟与CPU主频
