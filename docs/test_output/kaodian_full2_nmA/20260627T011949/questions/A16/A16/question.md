# 总线带宽计算

## 题目

某计算机系统采用同步总线连接主存与外设控制器。已知该总线的数据线宽度为 32 位，总线时钟频率为 150 MHz。由于总线采用握手协议，每个总线事务（完成一次数据传输）需要占用 **3 个**总线时钟周期。

现需要通过该总线从外设控制器向主存传输一批大小为 **4097 B** 的数据。

请回答以下问题：

### （1）（2 分）

计算该总线的理论带宽（单位用 MB/s，1 MB = $10^6$ B）。

### （2）（2 分）

考虑每个总线事务需要 3 个时钟周期，计算该总线的有效带宽（单位用 MB/s，1 MB = $10^6$ B）。

### （3）（3 分）

计算将这 4097 B 数据通过该总线全部传输完毕所需的时间（单位用 μs）。

---

## 设问结构

| 子问 | 分值 | 类型 | 依赖 |
|------|------|------|------|
| SQ1 | 2 | 直接计算：理论带宽 = 总线宽度 × 时钟频率 | 无 |
| SQ2 | 2 | 推导计算：有效带宽 = 理论带宽 ÷ 事务周期数 | SQ1 |
| SQ3 | 3 | 多步计算：传输次数（向上取整）→ 总周期数 → 时间 | SQ2 |

## 参数表

| 参数 | 符号 | 取值 | 说明 |
|------|------|------|------|
| 总线数据线宽度 | W | 4 B（32 位） | 2 的幂，便于字节换算 |
| 总线时钟频率 | f | 150 MHz | 非 2 的幂，使计算非平凡 |
| 事务周期数 | N | 3 | N ≥ 2，确保有效带宽 ≠ 理论带宽 |
| 待传输数据量 | D | 4097 B | D mod W = 4097 mod 4 = 1 ≠ 0，迫使向上取整 |

## 考察点对照

| 子问 | 考察知识点 | K 目标 |
|------|-----------|--------|
| SQ1 | 总线理论带宽公式：带宽 = 宽度 × 频率 | K1（记忆公式）+ K2（代入计算） |
| SQ2 | 事务多周期对有效带宽的影响：有效带宽 = 理论带宽 ÷ N | K2（推导计算）+ K4（理解事务周期概念） |
| SQ3 | 向上取整处理 + 时间 = 传输次数 × N / f | K2（多步计算）+ K3（非常规注意点：取整） |

## 场景规则（通过条件）

本题成立 ⇔ 以下参数间约束必须被满足（与具体答案值无关，换参数仍成立）：

1. **理论带宽定义**：`理论带宽 == W × f`（单位 B/s），即每个时钟周期传输 W 字节。
2. **有效带宽推导**：`有效带宽 == 理论带宽 / N`（单位 B/s），即 N 个周期完成一次传输，有效带宽降为理论的 1/N。
3. **传输次数向上取整**：`传输次数 == ceil(D / W)`，且 `D mod W ≠ 0`（确保 ceil 与 floor 不同，向上取整有实际意义）。
4. **传输时间闭环**：`传输时间 == 传输次数 × N / f`（单位 s），且 `传输时间 > 0`。
5. **有效带宽 ≠ 理论带宽**：`N ≥ 2`，确保 SQ2 非平凡（有效带宽严格小于理论带宽）。
6. **频率非 2 的幂**：`f` 取值为非 2 的幂整数（150），使各步乘除结果非平凡（非 2 幂整除）。

## 设计意图

- **SQ1** 直接考察总线带宽基本公式（K1+K2），学生需记忆"带宽 = 宽度 × 频率"并正确做单位换算（位 → 字节、MHz → Hz）。
- **SQ2** 引入事务周期概念（K4），考察学生是否理解有效带宽受事务占用周期影响——常见错误是忽略事务多周期，直接用理论带宽。
- **SQ3** 综合考察多步推导（K2+K3）：需计算传输次数（向上取整，4097 不能被 4 整除）→ 总周期数 → 总时间。向上取整是本问的关键注意点，常见错误是直接 D / W 不取整。
- **串行递进**：SQ1 → SQ2 → SQ3，前问结果用于后问，若前问错则后问连锁出错。
