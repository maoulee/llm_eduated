## 题目

某计算机系统采用同步总线连接主存与外设控制器。已知该总线的数据线宽度为 32 位，总线时钟频率为 150 MHz。由于总线采用握手协议，每个总线事务（完成一次数据传输）需要占用 **3 个**总线时钟周期。

现需要通过该总线从外设控制器向主存传输一批大小为 **4097 B** 的数据。

请回答以下问题：

### （1）（2 分）

计算该总线的理论带宽（单位用 MB/s，1 MB = $10^6$ B）。

### （2）（2 分）

考虑每个总线事务需要 3 个时钟周期，计算该总线的有效带宽（单位用 MB/s，1 MB = $10^6$ B）。

### （3）（3 分）

计算将这 4097 B 数据通过该总线全部传输完毕所需的时间（单位用 μs）。

## 参考答案

| 子问 | 结果 |
|------|------|
| （1）理论带宽 | **600 MB/s** |
| （2）有效带宽 | **200 MB/s** |
| （3）传输时间 | **20.5 μs** |

## 解析

**已知参数**

| 参数 | 值 |
|------|-----|
| 数据线宽度 W | 4 B（32 位） |
| 总线时钟频率 f | 150 MHz = $1.5 \times 10^8$ Hz |
| 事务周期数 N | 3 |
| 待传输数据量 D | 4097 B |

---

**（1）理论带宽（2 分）**

理论带宽 = 数据线宽度 × 时钟频率（每个时钟周期传输 W 字节）

$$\text{理论带宽} = W \times f = 4 \;\text{B} \times 1.5 \times 10^8 \;\text{Hz} = 6.0 \times 10^8 \;\text{B/s}$$

换算为 MB/s（$1\;\text{MB} = 10^6\;\text{B}$）：

$$\text{理论带宽} = \frac{6.0 \times 10^8}{10^6} = \boxed{600 \;\text{MB/s}}$$

---

**（2）有效带宽（2 分）**

每个总线事务需要 N = 3 个时钟周期才能完成一次数据传输，因此有效带宽降为理论的 1/N：

$$\text{有效带宽} = \frac{\text{理论带宽}}{N} = \frac{6.0 \times 10^8}{3} = 2.0 \times 10^8 \;\text{B/s}$$

换算为 MB/s：

$$\text{有效带宽} = \frac{2.0 \times 10^8}{10^6} = \boxed{200 \;\text{MB/s}}$$

---

**（3）传输 4097 B 数据所需时间（3 分）**

**第一步：计算传输次数（向上取整）**

每次事务传输 W = 4 B。4097 B 不能被 4 整除（$4097 \div 4 = 1024.25$，$4097 \bmod 4 = 1 \neq 0$），最后不足 4 B 的部分仍需一次事务传完，因此必须向上取整：

$$\text{传输次数} = \lceil D / W \rceil = \lceil 4097 / 4 \rceil = \lceil 1024.25 \rceil = 1025 \;\text{次}$$

**第二步：计算总周期数**

每次事务占 N = 3 个时钟周期：

$$\text{总周期数} = 1025 \times 3 = 3075 \;\text{个周期}$$

**第三步：计算总时间**

$$\text{时间} = \frac{\text{总周期数}}{f} = \frac{3075}{1.5 \times 10^8} = 2.05 \times 10^{-5} \;\text{s}$$

换算为 μs（$1\;\text{s} = 10^6\;\mu\text{s}$）：

$$\text{时间} = 2.05 \times 10^{-5} \times 10^6 = \boxed{20.5 \;\mu\text{s}}$$

---

**常见错误分析**

- **SQ1**：未将 32 位换算为 4 B，或未将 MHz 换算为 Hz，导致数量级错误。
- **SQ2**：忽略事务多周期开销，直接使用理论带宽作为有效带宽。
- **SQ3**：忘记向上取整（直接用 $4097/4=1024.25$ 次不取整），导致总周期数和时间偏小。
