# DRAM芯片扩展设计 — 参考解答

> 本解答数值全部由 gen.py exec 产出，逐字对照数据流输出。

## 已知参数

| 参数 | 取值 |
|------|------|
| CPU 地址线 A | 16 根（A15~A0） |
| CPU 数据线 D | 8 根（D7~D0） |
| DRAM 芯片 | 16K × 4 位 = 2¹⁴ × 4 |
| 芯片地址线 K | 14 |
| 芯片字宽 W | 4 |
| 行/列地址（复用）| 7 位行 + 7 位列 |
| 刷新周期 T | 2 ms |
| 编址方式 | 按字节编址 |

---

## 问题 1（3分）—— 芯片总数推导

**位扩展（扩展数据位宽）：**

CPU 数据线 D = 8 位，芯片字宽 W = 4 位，需要：

$$\text{位扩展数} = \frac{D}{W} = \frac{8}{4} = 2 \text{ 片/组}$$

（D % W = 8 % 4 = 0，整除，位扩展为整数）

**字扩展（扩展存储字数）：**

CPU 寻址空间 = 2¹⁶，芯片地址空间 = 2¹⁴，需要：

$$\text{字扩展组数} = 2^{A - K} = 2^{16-14} = 2^2 = 4 \text{ 组}$$

（A − K = 16 − 14 = 2 ≥ 1，字扩展非平凡）

**芯片总数：**

$$\text{总片数} = \text{位扩展数} \times \text{字扩展组数} = 2 \times 4 = \boxed{8 \text{ 片}}$$

---

## 问题 2（2分）—— 地址线分配

CPU 共 16 根地址线，需完整分配（不重不漏）：

| 用途 | 地址线 | 根数 |
|------|--------|------|
| **片内寻址线**（芯片地址线）| A13~A0 | **14 根** |
| **片选高位地址线** | A15~A14 | **2 根** |

- 片内寻址线 14 根连接到每片 DRAM 的地址线（经复用：7 位行地址 + 7 位列地址分两次输入）。
- 片选线 2 根（A15、A14）用于区分 4 个芯片组：2² = 4 组，正好对应字扩展组数。

校验：14 + 2 = 16，地址线全部分配完毕。

---

## 问题 3（2分）—— 片选逻辑（文字描述）

**高位地址线产生片选信号：**

- 2 根高位地址线 A15、A14 通过 2 线-4 线译码器（或逻辑门）产生 4 个片选信号 $\overline{CS_0}$、$\overline{CS_1}$、$\overline{CS_2}$、$\overline{CS_3}$，分别选通 4 个芯片组：

| A15 | A14 | 选中组 |
|-----|-----|--------|
| 0 | 0 | 第 0 组 |
| 0 | 1 | 第 1 组 |
| 1 | 0 | 第 2 组 |
| 1 | 1 | 第 3 组 |

- 译码器还需配合 CPU 的访存控制信号（如 $\overline{MREQ}$ / $\overline{RAS}$ 等）使能，确保仅在访存时才输出有效片选。

**每组内部（位扩展）连接方式：**

- 每组内 2 片 DRAM 的片选端并联，接同一片选信号（同时选通）。
- 14 根地址线（A13~A0）并联到两片芯片的地址端。
- 数据线分接：第 1 片接 D3~D0（低 4 位），第 2 片接 D7~D4（高 4 位），两片共同输出 8 位数据。

## 问题 4（3分）—— 异步刷新

**（1）阵列行数：**

地址复用：7 位行地址 + 7 位列地址，行地址位数 R = 7。

$$\text{阵列行数} = 2^R = 2^7 = \boxed{128 \text{ 行}}$$

（R = K/2 = 14/2 = 7）

**（2）异步刷新间隔：**

异步刷新在刷新周期（2 ms）内均匀分配刷新所有行，每行刷新一次：

$$\text{刷新间隔} = \frac{T}{2^R} = \frac{2 \text{ ms}}{128} = 0.015625 \text{ ms} = \boxed{16 \ \mu\text{s}}$$

**（3）刷新周期内刷新次数：**

一个刷新周期（2 ms）内需把所有行刷新一遍，每行一次：

$$\text{刷新次数} = 2^R = \boxed{128 \text{ 次}}$$

## 容量自洽验证

| 侧 | 计算 | 容量 |
|----|------|------|
| CPU 侧 | 2¹⁶ 地址 × 8 bit | = 524288 bits = 64 KB |
| 芯片侧 | 4 组 × 16384 × 4 bit × 2 片/组 | = 524288 bits = 64 KB |

两侧容量相等（524288 bits = 524288 bits），全链自洽。

## 汇总答案

| 问题 | 答案 |
|------|------|
| Q1 | 位扩展 2 片 × 字扩展 4 组 = **8 片** |
| Q2 | 片内寻址 14 根（A13~A0），片选 2 根（A15~A14） |
| Q3 | A15A14 经 2-4 译码器产生 4 个片选信号；组内两片并联片选+地址，数据分接高低 4 位 |
| Q4 | 128 行；刷新间隔 16 μs；刷新次数 128 次 |
