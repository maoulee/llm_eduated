## 考点
- **二叉树遍历序列还原**（核心）：给定两种遍历序列（前序+中序或后序+中序），还原二叉树结构
- **遍历序列的性质**（辅助）：理解不同遍历序列中根节点、左右子树的位置关系
- **二叉树基本性质**（辅助）：树的深度、叶子节点、度为1/2的节点数等

## 难度目标
- **K1（知识广度）= 3**：涉及前序、中序、后序三种遍历的基本概念，知识覆盖面适中
- **K2（知识深度）= 4**：需要深入理解遍历序列与树结构的对应关系，掌握还原算法的本质
- **K3（计算复杂度）= 3**：节点数适中（6-10个），手工还原可行但需一定步骤
- **K4（思维复杂度）= 4**：需要逻辑推理、递归思维，多问之间存在依赖关系
- **K5（创新性）= 2**：标准题型，考察经典方法，不要求创新解法

## 考察模式
**模式：序列还原 → 性质求解**
- 第1问：给定两种遍历序列，还原二叉树（或写出第三种遍历序列）
- 第2问：基于还原的树，求解结构性质（深度、叶子数、特定节点等）
- 理由：该模式在历史题目中出现频率高，能同时考察还原能力和树的性质理解，难度递进自然

## 出题要求
- **题型**：综合题（2问）
- **总条件数**：2个显式条件（两种遍历序列）
- **条件设计原则**：
  - 两种遍历序列必须能唯一确定二叉树（前序+中序 或 后序+中序）
  - 不使用前序+后序（不能唯一确定）
  - 序列元素用大写字母（A-J）或数字表示
- **参数取值范围要求**：
  - 节点数：6-10个
  - 树深度：3-4层
  - 不能是退化链（所有节点只有左/右孩子）
  - 不能是完全二叉树（过于简单）

## 子问题规划

### 第1问（约6分）
- **类型**：计算/构造
- **考察目标**：根据给定的前序（或后序）和中序遍历序列，还原二叉树结构，或写出后序（或前序）遍历序列
- **分值**：6分
- **与前后问关系**：独立可解，但为第2问提供基础

### 第2问（约4分）
- **类型**：分析/计算
- **考察目标**：基于第1问还原的二叉树，求解以下之一：
  - 树的深度/高度
  - 叶子节点数量或列出叶子节点
  - 度为1或度为2的节点数量
  - 某个特定节点的祖先/子孙
- **分值**：4分
- **与前后问关系**：依赖第1问的还原结果

## 参数约束
- **节点数 n**：6 ≤ n ≤ 10，整数
- **遍历序列类型**：前序+中序 或 后序+中序（二选一）
- **树深度 d**：3 ≤ d ≤ 4
- **叶子节点数**：≥ 2（避免退化）
- **结构约束**：
  - 至少有一个节点同时有左右孩子
  - 至少有一个叶子节点
  - 不能所有节点都只有左孩子或都只有右孩子
- **序列元素**：互不相同的字符或数字，便于区分
- **一致性约束**：两种遍历序列必须对应同一棵二叉树，且能唯一确定

## 参考经验
- **历史模式**：二叉树遍历还原题通常采用"给两序求一序"或"给两序画树"的模式
- **难度锚点**：medium难度对应节点数6-10，深度3-4层
- **典型陷阱**：
  - 学生混淆前序/后序中根节点的位置
  - 递归还原时左右子树边界划分错误
  - 忽略空子树的情况
  - 第2问中数错叶子节点或深度
