## 题干

已知某二叉树的前序遍历序列为 `A B D F E C G H`，中序遍历序列为 `F D B E A C G H`，序列中各元素互不相同，且两种遍历序列对应同一棵二叉树。

请回答下列问题：

### (1) （6分）根据给定的前序遍历序列和中序遍历序列，还原该二叉树的结构。要求给出树的结构表示（可使用括号表示法或文字描述各节点的左右孩子关系）。

### (2) （4分）基于第(1)问还原的二叉树结构，求该二叉树的叶子节点个数和树的深度。

## 设计说明

- **复用骨架来源**：往年真题"给两序画树→求性质"骨架（参考经验摘要：历史模式为给两序求一序 / 给两序画树 → 求性质）
- **考察形式**：多步串行推演（来自 exam_form）
- **子问依赖链 / 设问结构**：串行依赖——第(1)问递归还原二叉树结构（根定位→子树划分→递归），第(2)问基于还原结果求解叶子节点数和树深度
- **初步参数选择理由**（基于骨架+经验，大胆给）：
  - 节点数 n=8（在 6~10 范围内，适中规模，递归深度合理）
  - 树深度 d=4（在 3~4 范围内，满足深度约束）
  - 遍历组合：前序+中序（经典组合，前序首元素定位根，中序划分左右子树）
  - 序列元素：A~H 共8个互不相同的字符
  - 树结构预设：A(B(D(F),E),C(,G(,H)))——非退化链（A、B、G有左右孩子）、非完全二叉树（C缺左孩子、G缺左孩子）、叶子节点≥2（F、E、H共3个）
- **与目标 K-雷达的对齐**：K2=4（遍历序列与树结构映射理解）+ K4=4（递归还原的条件路由：根定位→子树划分→递归）双主导，K3=3（过程模拟中等复杂度），K1=3（基础概念认知），K5=2（单域内问题）
- **是否融合**：不融合。难度目标 K3=3（正常），单骨架已足够达到难度要求，无需融合多侧重
