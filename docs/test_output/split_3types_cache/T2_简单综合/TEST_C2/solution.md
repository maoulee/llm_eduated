## 求解过程

### 子问题(1)：还原二叉树结构

**方法**：前序遍历的第一个元素是根节点，在中序遍历中找到该根节点，其左侧为左子树的中序序列，右侧为右子树的中序序列。根据左右子树的节点数，在前序序列中划分左右子树的前序序列，递归构建。

**步骤**：

1. 前序首元素 `A` 为根节点。中序中 `A` 的位置将序列分为：左子树中序 `F D B E`，右子树中序 `C G H`。
2. 左子树有 4 个节点，前序中 `A` 之后的 4 个元素 `B D F E` 为左子树前序；剩余 `C G H` 为右子树前序。
3. **左子树**：前序 `B D F E`，中序 `F D B E`。根为 `B`，中序中 `B` 左侧 `F D` 为左子树，右侧 `E` 为右子树。
   - `B` 的左子树：前序 `D F`，中序 `F D`。根为 `D`，中序中 `D` 左侧 `F` 为左子树。`D` 的左孩子为 `F`，无右孩子。
   - `B` 的右子树：前序 `E`，中序 `E`。`E` 为叶子节点。
4. **右子树**：前序 `C G H`，中序 `C G H`。根为 `C`，中序中 `C` 左侧为空（无左子树），右侧 `G H` 为右子树。
   - `C` 的右子树：前序 `G H`，中序 `G H`。根为 `G`，中序中 `G` 左侧为空，右侧 `H` 为右子树。`G` 的右孩子为 `H`，无左孩子。

**树的结构（括号表示法）**：`A(B(D(F),E),C(,G(,H)))`

**各节点的左右孩子关系**：
- A → 左孩子: B, 右孩子: C
- B → 左孩子: D, 右孩子: E
- D → 左孩子: F, 右孩子: 无
- F → 左孩子: 无, 右孩子: 无
- E → 左孩子: 无, 右孩子: 无
- C → 左孩子: 无, 右孩子: G
- G → 左孩子: 无, 右孩子: H
- H → 左孩子: 无, 右孩子: 无

### 子问题(2)：叶子节点个数和树的深度

**叶子节点**：无左右孩子的节点。由上述结构可知，叶子节点为 `F`、`E`、`H`，共 **3** 个。

**树的深度**：从根节点到最远叶子节点的路径长度（节点数）。最长路径为 `A → B → D → F` 或 `A → C → G → H`，共 **4** 层。

## 最终答案
- (1) 树的结构（括号表示法）：`A(B(D(F),E),C(,G(,H)))`
- (2) 叶子节点个数：3；树的深度：4
