- 与目标 K-雷达对齐：K2 体现在遍历序列与树结构的映射理解，K4 体现在递归还原的条件路由（根定位→子树划分→递归），K3=3 体现在过程模拟的中等复杂度，K1=3 体现在基础概念认知，K5=2 体现为单域内问题
