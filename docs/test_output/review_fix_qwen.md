

# 408考研数据结构综合应用题

## 题目

已知一棵初始为空的AVL树（平衡二叉搜索树），依次插入以下关键字序列：10, 20, 30, 5, 15, 12, 25, 22。AVL树中每个节点的平衡因子定义为：左子树高度减去右子树高度（空子树高度为0）。当某节点的平衡因子绝对值大于1时，需进行旋转操作恢复平衡。

AVL树插入操作的规则如下：
- 若关键字已存在，则不插入；否则按二叉搜索树规则插入到叶节点位置
- 插入后自底向上更新路径上各节点的高度与平衡因子
- 当发现平衡因子绝对值>1的失衡节点时，按以下四种情况处理：
  - **LL型**：失衡节点的左子树左孩子插入新节点，执行右单旋
  - **RR型**：失衡节点的右子树右孩子插入新节点，执行左单旋
  - **LR型**：失衡节点的左子树右孩子插入新节点，先对其左孩子左旋，再对失衡节点右旋
  - **RL型**：失衡节点的右子树左孩子插入新节点，先对其右孩子右旋，再对失衡节点左旋
- 旋转操作完成后，重新计算受影响节点的高度与平衡因子

其中 `update_height(T)` 函数用于更新节点T的高度值。

请回答下列问题：

### (1) （3分）

依次插入关键字10、20、30后，画出此时的AVL树结构，并计算根节点的平衡因子。说明插入30后是否需要进行旋转操作，若需要，指出旋转类型及旋转中心节点关键字。

### (2) （4分）

基于(1)中得到的AVL树，继续依次插入关键字5、15。画出插入15完成（含必要的旋转操作）后的AVL树结构，并列出此时树中所有非叶子节点的平衡因子值。

### (3) （3分）

基于(2)中得到的AVL树，继续插入关键字12、25、22。画出插入22完成（含必要的旋转操作）后的AVL树结构，并说明插入22过程中是否触发了旋转操作，若触发，指出失衡节点关键字、旋转类型及旋转后的根节点关键字。

### (4) （3分）

基于(3)中得到的最终AVL树，完成以下任务：
- 计算该树的高度（根节点所在层为第1层），并给出该树的中序遍历序列。
- 用一句话描述 `update_height(T)` 函数的核心逻辑。
- 验证最终AVL树的中序遍历结果是否与原插入序列排序后一致，并据此说明旋转操作对BST有序性的影响。

### 知识点选取理由
- **AVL树平衡因子计算**：K3标准认知，需准确记忆平衡因子定义（左子树高度-右子树高度）
- **LL/RR/LR/RL四种旋转**：K4较高认知，需理解每种旋转的触发条件与指针调整规则
- **旋转后BST有序性保持**：K5单一知识域内深度理解，需理解旋转操作本质是局部结构调整，不改变中序遍历结果
- **update_height函数逻辑**：考察对AVL树高度更新机制的理解，需知道节点高度 = max(左子树高度, 右子树高度) + 1
- **重复关键字处理**：隐含条件，BST中重复关键字不插入，考察细节把握（本题未涉及重复，但规则中已说明）

### 参数选择理由
- **关键字序列 10, 20, 30, 5, 15, 12, 25, 22**：精心设计的序列，确保触发多种旋转类型
  - 10, 20, 30 → 触发RR旋转（右子树过重）
  - 5, 15 → 插入后树保持平衡，无旋转触发
  - 12, 25, 22 → 触发RL旋转（右子节点的左子树过重）
- **数值均为整数**：便于心算，符合参数友好原则（虽非2的幂，但数值简单，计算量可控）
- **8个关键字**：适中数量，既能考察多种旋转类型，又不会导致计算量过大

### 与契约 K 值的对齐说明
- **K1（基础认知）= 3**：必须准确记忆AVL树平衡因子定义、四种旋转类型的名称与触发条件、update_height函数逻辑，否则无法入题
- **K2（单步代入）= 2**：平衡因子计算为简单整数减法，数值友好，不易算错
- **K3（机制推演）= 4**：需按AVL插入规则走完多步流程（插入→更新平衡因子→向上检查→判定失衡→执行旋转→重新计算平衡因子），步数>5步，需维持动态状态更新
- **K4（条件路由）= 4**：存在多个隐含前提：①LR/RL旋转需双重旋转而非单次；②插入后需沿路径向上检查所有祖先节点；③旋转后需重新计算所有受影响节点的平衡因子；④update_height需考虑空子树高度为0；⑤旋转中心节点的判定需结合插入位置与失衡类型
- **K5（跨域联动）= 1**：单一AVL树知识域内解决，不涉及其他子系统或模块的数据传递与状态联动

**综合K值评估：K4-K5深理解与应用型**，符合契约要求。
