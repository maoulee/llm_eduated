# TEST_CONCEPT 解析

## 题目 1 解析

**答案**：C

**解析**：
- C 正确：栈是后进先出（LIFO，Last In First Out）的线性表，最后入栈的元素最先出栈。
- A 错误：FIFO（先进先出）是队列的特性，不是栈的特性。
- B 错误：栈的插入（Push）和删除（Pop）操作只能在栈顶进行，不是栈底。
- D 错误：栈是操作受限的线性表，只能在栈顶进行插入和删除，不能在任意位置操作。

## 题目 2 解析

**答案**：C

**解析**：
- C 正确：队列是先进先出（FIFO，First In First Out）的线性表，最先入队的元素最先出队。
- A 错误：LIFO（后进先出）是栈的特性，不是队列的特性。
- B 错误：队列的插入操作在队尾（rear）进行，删除操作在队头（front）进行，选项说反了。
- D 错误：队列的插入和删除操作在两端进行（队尾插入、队头删除），不是同一端。

---

## 题目 3 解析

**答案**：B

**解析**：
- I 正确：栈和队列都是操作受限的线性表，栈限制在栈顶操作，队列限制在队头删除、队尾插入。
- II 正确：栈和队列都可以用顺序存储（数组）或链式存储（链表）实现，如顺序栈/链栈、顺序队列/链队列。
- III 错误：栈的插入和删除都在栈顶（同一端），但队列的插入在队尾、删除在队头（两端操作），不是同一端。

## 题目 4 解析

**答案**：B

**解析**：
- B 正确：牺牲一个存储单元判满时，队满条件是 (rear + 1) % m == front，即队尾指针的下一个位置是队头指针，此时队列中实际有 m-1 个元素。
- A 错误：front == rear 是队空条件，不是队满条件。
- C 错误：rear == m - 1 是顺序队列（非循环）的队满条件，循环队列中 rear 可以回绕到 0。
- D 错误：(front + 1) % m == rear 表示队头在队尾前面一个位置，这不是判满条件。

## 题目 5 解析

**答案**：C

**解析**：
- C 正确：栈 1 从 0 向上增长（top1 递增），栈 2 从 m-1 向下增长（top2 递减）。当 top2 - top1 == 1 时，两个栈顶指针相邻，表示数组空间已满，再入栈就会溢出。
- A 错误：top1 + top2 == m - 1 无实际意义，不能反映两栈的空间关系。
- B 错误：top1 - top2 == 1 表示 top1 在 top2 右边 1 个位置，这与栈 1 在左、栈 2 在右的布局矛盾。
- D 错误：top1 == top2 表示两栈顶重合，已经发生溢出，不是判满条件。

## 题目 6 解析

**答案**：D

**解析**：
- D 正确：B 和 C 都正确。
- B 正确：输入受限双端队列限制插入只能在一端进行，但删除可以在两端进行。
- C 正确：输出受限双端队列限制删除只能在一端进行，但插入可以在两端进行。
- A 错误：双端队列的插入和删除操作"可以"在两端进行，但不是"只能"在两端进行（中间位置不能操作是线性表的共性，不是双端队列的特性）。

## 题目 7 解析

**答案**：B

**解析**：
- B 正确：括号匹配时，遇到左括号（如 (、[、{）入栈保存，遇到右括号时出栈一个左括号检查是否匹配（如 ) 匹配 (、] 匹配 [、} 匹配 {）。
- A 错误：左括号应该入栈而不是出栈，右括号应该出栈匹配而不是入栈，选项说反了。
- C 错误：右括号不需要入栈，遇到右括号应该出栈匹配。
- D 错误：左括号需要入栈保存，不能出栈。

## 题目 8 解析

**答案**：A

**解析**：
- A 正确：中缀转后缀时，先处理优先级高的运算。b * c 优先级高于 a +，所以 b * c 先转换为后缀 b c *，然后与 a 进行 + 运算，得到 a b c * +。
- B 错误：a b * c + 是中缀表达式 (a * b) + c 的后缀形式，不是 a + b * c 的后缀。
- C 错误：a + b * c 是中缀表达式本身，不是后缀表达式。
- D 错误：+ a * b c 是前缀表达式（波兰表达式）的形式，不是后缀表达式。
