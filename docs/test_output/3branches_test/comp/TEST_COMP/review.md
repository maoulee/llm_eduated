# 审核报告

## 审核结论
- **issue_type**: none
- **feedback_for_agent**: 设计卡整体结构严谨，严格遵循“结构操作与状态维护模拟”模式。子问递进形成完整的串行推演闭环，参数约束明确覆盖了难度4所需的K3机制推演与K4条件路由要求。术语使用规范，无排除项干扰。可直接进入 design_solve 参数搜索阶段。建议在参数生成时严格校验“前m步无旋转”与“必须包含LR/RL复合旋转及连锁失衡”的约束，以确保区分度达标。

## 详细评估
### 1. 考点覆盖与意图对齐
- 完全覆盖 must_test 项（AVL插入流程、BF计算、四种旋转触发条件、指针重连）。
- 未滑向 must_not_shift_to 项（无BST删除、哈夫曼、线索化等干扰）。
- coverage_success_criteria 达成：通过分步设问强制学生模拟形态演变，Q3的分析要求直接对应回溯路径与祖先状态变化的考察。

### 2. 结构与难度匹配
- 串行依赖清晰：Q1的树形态与BF直接作为Q2的初始条件，中间状态不可跳跃，符合 dependency_pattern。
- 难度4定位准确：推演步数约束（>5）结合“连锁失衡”与“动态路由”要求，有效区分中等与高掌握度学生。避免“旋转即结束”的线性思维陷阱设计合理。

### 3. 术语与表达规范
- 严格使用规定术语（平衡因子、失衡结点、最小不平衡子树、LL/RR/LR/RL旋转、指针重连、回溯检查路径）。
- 明确BF定义符号约定，符合考纲要求。
- 无模糊代称或不确定性词汇，表达确定性算法步骤清晰。

## 参数生成建议（供 design_solve 参考）
- 序列 $S$ 构造需优先满足：前 $m$ 次插入仅改变局部高度不触发 $|BF|>1$；第 $m+1$ 次或后续插入触发首次旋转；必须包含一次 LR 或 RL 复合旋转；至少一次旋转后沿路径回溯导致祖先 BF 符号变化或绝对值增大（连锁失衡）。
- 最终树形态需严格满足 AVL 性质，便于学生自我校验。
