# question.md

## 题干
给定初始为空的一棵平衡二叉树（AVL树）。依次插入关键字序列 $S = [x_1, x_2, \dots, x_n]$。
（注：平衡因子 BF 定义为：左子树高度 - 右子树高度）

## 子问题
1. （4分）依次插入序列 $S$ 的前 $m$ 个元素，画出每次插入后的二叉树形态，并计算各结点的平衡因子（BF）。
2. （5分）继续插入序列 $S$ 的剩余元素。指出每次发生旋转时的失衡结点、最小不平衡子树及旋转类型（LL/RR/LR/RL），画出旋转调整后的最终树形态，并说明指针重连的具体过程。
3. （4分）统计整个插入过程中发生的旋转总次数。分析若改变序列 $S$ 中元素的插入顺序，是否会影响最终树的高度与形态？请结合回溯检查路径与祖先结点平衡状态的变化进行说明。

## 设计说明（参数约束要求）
供 design_solve 搜索参数时参考：
- **序列长度**：$n$ 取值适中（建议 6~10），确保整体推演步数 > 5，符合难度4的K3机制推演要求。
- **旋转覆盖**：序列 $S$ 必须触发至少两种不同类型的旋转，且**必须包含 LR 或 RL 复合旋转**，以检验学生对复合旋转触发条件与指针重连机制的掌握。
- **连锁失衡与动态路由**：插入过程中需出现“连锁失衡”现象。即某次旋转调整后，沿插入路径向上回溯检查时，祖先结点的平衡因子发生改变（非零或符号变化），需动态路由后续检查逻辑，避免“旋转即结束”的线性思维陷阱（符合K4条件路由要求）。
- **阶段划分**：前 $m$ 个元素插入后**不触发任何旋转**，仅考察基础形态演变与BF计算；剩余 $n-m$ 个元素插入过程中触发所有旋转操作。
- **最终状态**：所有元素插入完毕后，树必须严格满足AVL平衡性质（所有结点 |BF| ≤ 1）。
