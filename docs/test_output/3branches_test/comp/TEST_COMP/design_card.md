## core_knowledge_intent
- **must_test**: AVL树插入操作的标准流程、平衡因子计算与失衡判定规则、四种旋转类型（LL/RR/LR/RL）的触发条件与指针重连机制。
- **must_not_shift_to**: 二叉搜索树（BST）的普通插入/删除、哈夫曼树构造、线索二叉树遍历、静态树性质计算、非平衡树的形态推演。
- **coverage_success_criteria**: 学生能准确模拟连续插入过程中的树形态演变，正确识别每次插入后的失衡节点与最小不平衡子树，选择正确的旋转类型恢复平衡；能清晰表述旋转前后父子节点指针的重新连接逻辑，并沿插入路径向上回溯检查平衡状态。

## design_rationale
- **考察意图**：AVL树的核心价值在于动态维护平衡以保证对数级操作复杂度。本题采用“结构操作与状态维护模拟”模式，要求学生将抽象的旋转规则转化为具体的指针操作序列，检验其对AVL树底层机制的掌握程度，而非仅停留在概念记忆或单次操作层面。
- **区分度定位**：难度4定位准确。低掌握度学生易混淆LR/RL旋转的触发条件或记错旋转方向；中等掌握度学生能完成单次插入调整，但在连续插入导致“连锁失衡”或“旋转后祖先节点平衡状态变化”时容易出错；高掌握度学生能稳定维持多步状态更新，准确路由每次插入后的平衡检查路径。
- **考点融合（K3-K4）**：融合“机制推演（K3）”与“条件路由（K4）”。不仅要求按说明书走完插入→计算平衡因子→判定旋转→执行指针重连的串行流程（推演步数>5），还要求识别隐含前提：插入节点后需沿插入路径向上回溯检查平衡因子，而非盲目从根节点开始；旋转操作可能改变祖先节点的平衡状态，需动态路由后续检查逻辑，避免“旋转即结束”的线性思维陷阱。

## question_structure_plan
- **复用骨架来源**：往年AVL树综合题通常采用“给定初始空树 + 连续插入序列 → 分步要求画出/描述形态变化 → 最终要求总结旋转次数或特定节点状态”的设问句式。提炼为：基础层考单次插入与失衡判定，进阶层考连续插入与旋转执行，区分度层考状态汇总与机制辨析。
- **子问1**：考初始插入序列的前几步操作与平衡因子计算（基础层）—— 参考往年问法：“依次插入关键字序列的前X个元素，画出插入后的二叉树形态，并计算各结点的平衡因子。”
- **子问2**：基于子问1的结果，考后续插入触发的旋转调整与指针重连（进阶层）—— 参考往年问法：“继续插入剩余元素，指出每次发生旋转的失衡结点、旋转类型（LL/RR/LR/RL），并画出旋转调整后的最终树形态。”
- **子问3**：汇总/分析（区分度层）—— 参考往年问法：“统计整个插入过程中发生的旋转总次数，并说明若改变插入顺序是否会影响最终树的高度/形态。”
- **dependency_pattern**：串行依赖（前问的树形态与平衡状态直接作为后问插入操作的初始条件，中间状态不可跳跃）

## terminology_and_expression_constraints
- **必须用词**：平衡因子（BF）、失衡结点、最小不平衡子树、LL/RR/LR/RL旋转、左旋/右旋、指针重连、回溯检查路径、高度。
- **限定语**：明确“平衡因子 = 左子树高度 - 右子树高度”（或按考纲统一符号约定）；旋转操作需强调“以失衡结点为根的最小不平衡子树”为操作范围；LR/RL旋转需指明“先对子树旋转，再对失衡结点旋转”的复合特征。
- **禁止表述**：避免使用“调整树”、“平衡树”等模糊代称；禁止将LR/RL旋转简化为“先左后右”而不指明具体操作对象；禁止出现具体数值答案、预设的插入序列值或最终计算结果；禁止使用“大概”、“可能”等不确定性词汇描述确定性算法步骤。

## audit_focus
- **审核重点**：
  1. 设问是否严格遵循“结构操作与状态维护模拟”模式，有无滑向纯概念辨析或静态计算；
  2. 子问递进是否形成完整的串行推演闭环，中间状态传递是否清晰，有无断点；
  3. 旋转类型的判定条件是否覆盖四种情况，有无遗漏LR/RL的复合旋转特征；
  4. 难度4的K3/K4融合是否达标（推演步数>5，含隐含回溯路由与动态状态更新）。
- **teacher_annotation体现**：需重点审核连续插入过程中的“连锁失衡”与“旋转后祖先节点平衡状态变化”的路由逻辑，确保符合难度4的机制推演要求；若推演路径可被简化为固定模板套用，则需增加条件路由复杂度。
- **excluded检查**：确认未引入BST删除、哈夫曼、线索化等排除项；未出现具体数值/答案；未偏离AVL插入与旋转核心考点。
