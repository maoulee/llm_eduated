## rationale
- 为何选此形式：哈夫曼树构造需严格按贪心规则执行3-5步合并流程（K3），且最终需代入WPL公式完成多步乘加运算（K2），故采用多步串行推演结合单点计算的形式。
- 与目标K-雷达的对齐说明：目标难度3要求K1/K2/K3均衡为3，K4/K5降至2/1。该形式精准匹配“掌握核心定义→走完固定构造流程→执行常规计算”的认知路径，无跨域联动与深层陷阱，干扰项覆盖流程偏差与概念混淆，与雷达形状及难度定位完全一致。
