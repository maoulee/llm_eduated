## 题目
将关键字序列 {30, 10, 50, 20, 40} 依次插入一棵初始为空的平衡二叉树（AVL树）中，插入完成后该树的前序遍历序列为（）。


## 选项
A. 30, 10, 20, 50, 40
B. 10, 30, 20, 50, 40
C. 30, 10, 20, 40, 50
D. 10, 20, 30, 40, 50


## 求解过程
### 题目分析

本题要求将关键字序列 {30, 10, 50, 20, 40} 依次插入一棵初始为空的 AVL 树，然后求前序遍历序列。

### 逐步插入过程

**1. 插入 30**
```
  30
```
树：根节点为 30，高度 1，平衡因子 0。

**2. 插入 10**
```
  30
 / 
10
```
树：30 为根，左子节点 10。30 的平衡因子 = 1-0 = 1，平衡。

**3. 插入 50**
```
  30
 /  \
10  50
```
树：30 为根，左子 10，右子 50。30 的平衡因子 = 1-1 = 0，平衡。

**4. 插入 20**
```
  30
 /  \
10  50
 \
  20
```
树：20 插入到 10 的右子。10 的平衡因子 = 0-1 = -1，30 的平衡因子 = 2-1 = 1，均平衡。

**5. 插入 40**
```
  30
 /  \
10  50
 \   /
 20 40
```
树：40 插入到 50 的左子。50 的平衡因子 = 1-0 = 1，30 的平衡因子 = 2-2 = 0，均平衡。

### 最终 AVL 树结构
```
      30
     /  \
   10    50
    \    /
    20  40
```

### 前序遍历

前序遍历规则：根 → 左 → 右

- 访问根 30
- 遍历左子树（根 10）：访问 10，左子为空，遍历右子（20）：访问 20
- 遍历右子树（根 50）：访问 50，遍历左子（40）：访问 40，右子为空

前序遍历序列：**30, 10, 20, 50, 40**

### 结果对比验证

手动推算：
- 根节点 30
- 左子树：10 为根，无左子，右子为 20 → 前序：10, 20
- 右子树：50 为根，左子为 40，无右子 → 前序：50, 40
- 完整前序：30, 10, 20, 50, 40

代码输出：[30, 10, 20, 50, 40]，与手动推算一致。
