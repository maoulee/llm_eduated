# 寻址方式有效地址计算（单选题）

## 题干

某计算机按字节编址，主存地址空间为 64 KB，指令采用单字长格式。机器中有一个变址寄存器 R₁ 和一个程序计数器 PC，其中：

- 变址寄存器 R₁ = 0x8000
- 程序计数器 PC = 0x2004（当前正在执行的指令地址）

某条双操作数指令的第一操作数采用**变址寻址**，其形式地址字段 A = 0x003C。

**请计算该操作数的有效地址 EA，从下列选项中选择正确的一个。**

## 选项

A. 0x803C
B. 0x003C
C. 0x2040
D. 0x7FC4

---

## 设计说明（供 write_gen / dual_review 参考，不向学生展示）

### 考察意图
- **K目标**：K2=3（标准单步计算）—— 变址寻址 EA = 变址寄存器值 + 形式地址。
- **核心知识点**：数据寻址中变址寻址的有效地址计算。
- **题型**：单步计算型选择题。

### 选项设计（错误类型对应）
| 选项 | 来源 / 错误类型 | 计算路径 |
|------|----------------|----------|
| A（正确） | 变址寻址 EA = R₁ + A | 0x8000 + 0x003C = **0x803C** |
| B | 直接寻址混淆：误取 EA = A | 0x003C |
| C | 相对寻址混淆：误取 EA = PC + A | 0x2004 + 0x003C = 0x2040 |
| D | 运算方向错误：误取 EA = R₁ − A | 0x8000 − 0x003C = 0x7FC4 |

### 场景规则（通过条件）

以下约束在**任意合法参数取值**下均须成立，与具体答案值无关：

1. **变址寻址定义成立**：正确 EA == R₁ + A（加法，不是减法）。
2. **四选项互异**：A、B、C、D 四个值两两不同。
3. **正确值唯一确定**：题干在给定参数下只有一个确定答案，不存在歧义。
4. **各干扰项与正确项不同**：直接取 A ≠ 变址 EA；相对寻址 EA(PC+A) ≠ 变址 EA；方向错误 EA(R₁−A) ≠ 变址 EA。
5. **各干扰项之间互异**：A、PC+A、R₁−A 三者两两不同。

gen.py 应以 `assert` 验证上述约束后，打印各选项的计算过程与最终值。
