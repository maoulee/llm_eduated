# 寻址方式有效地址计算（单选题）—— 解答

## 正确答案

**A. 0x803C**

---

## 求解过程

### 1. 已知参数

| 参数 | 值 | 说明 |
|------|------|------|
| R₁ | 0x8000 | 变址寄存器 |
| PC | 0x2004 | 程序计数器（当前指令地址） |
| A | 0x003C | 形式地址字段 |
| 地址空间上限 | 0xFFFF | 64KB，16位地址 |

### 2. 变址寻址定义

变址寻址的有效地址计算公式：

$$EA = R_1 + A$$

### 3. 计算有效地址

$$EA = R_1 + A = \text{0x8000} + \text{0x003C} = \textbf{0x803C}$$

对应选项 **A**。

---

## 干扰项分析

| 选项 | 值 | 错误类型 | 计算路径 |
|------|------|----------|----------|
| **A ✓** | 0x803C | — （正确） | 变址寻址 EA = R₁ + A = 0x8000 + 0x003C = **0x803C** |
| B | 0x003C | 直接寻址混淆 | 误取 EA = A = 0x003C，忽略了变址寄存器的作用 |
| C | 0x2040 | 相对寻址混淆 | 误取 EA = PC + A = 0x2004 + 0x003C = 0x2040，错用了 PC 作为基址 |
| D | 0x7FC4 | 运算方向错误 | 误取 EA = R₁ − A = 0x8000 − 0x003C = 0x7FC4，加法误做减法 |

**各干扰项为什么错：**

- **B（0x003C）**：直接寻址的定义是 EA = A，但题目明确为**变址寻址**，有效地址必须加上变址寄存器 R₁ 的值。
- **C（0x2040）**：相对寻址 EA = PC + A，但题目是变址寻址，基址是变址寄存器 R₁ 而非程序计数器 PC。
- **D（0x7FC4）**：变址寻址的运算方向是**加法**（R₁ + A），而非减法（R₁ − A）。

---

## 场景规则验证

| 规则 | 验证结果 |
|------|----------|
| ① 变址寻址定义 EA == R₁ + A | ✓ 成立 |
| ② 四选项互异 | ✓ {0x803C, 0x003C, 0x2040, 0x7FC4} 四值两两不同 |
| ③ 正确值唯一确定 | ✓ 加法运算唯一确定 EA = 0x803C |
| ④ 各干扰项 ≠ 正确项 | ✓ 0x003C、0x2040、0x7FC4 均不等于 0x803C |
| ⑤ 各干扰项之间互异 | ✓ 0x003C、0x2040、0x7FC4 两两不同 |
