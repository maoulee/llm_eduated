对 4 位补码做符号位扩展，正数的符号位 0 扩展为 00：

```
  00101   （[A]补 = +5）
+ 00100   （[B]补 = +4）
-------
  01001   （5 + 4 = 9，mod 32 = 9）
```

结果码：**01001**

### 第三步：提取双符号位并判定溢出

结果码 01001 的最高 2 位为双符号位 **S₁S₀ = 01**。

- S₁ = 0，S₀ = 1
- S₁ ≠ S₀ → **双符号位相异，发生了溢出**
- 双符号位为 01 → **正溢出**（两个正数相加，结果超出正上限 +7）

判定规则对照：

| 双符号位 | 含义 |
|---------|------|
| 00 | 结果为正，未溢出 |
| **01** | **正溢出 ← 本题结果** |
| 10 | 负溢出 |
| 11 | 结果为负，未溢出 |

1. **溢出必然发生**：A=+5 与 B=+4 同号（均为正），A+B=9 > +7（超出 4 位补码表示范围上界），满足溢出条件。
2. **双符号位状态合法**：结果双符号位 01 ∈ {01, 10}（相异=溢出），合法。
3. **结果唯一确定**：双符号位 01 → 正溢出，唯一。

**双符号位为 01，发生了正溢出。**

### 2. 核心建模（PROCESS）

**步骤 1 — 求 S 的 16 位补码位模式**

`short` 采用补码表示，S = −100 的 16 位补码位模式为：

$$\text{bits} = S \bmod 2^{16} = (-100) \bmod 65536 = 65436$$

二进制表示：`1111 1111 1001 1100`

**步骤 2 — 同宽度转换 = 位模式重解读**

`short` → `unsigned short` 是 16 位 → 16 位转换，**位模式完全不变**，仅按无符号语义重新解读。因此：

$$u = \text{bits} = 65436$$

**步骤 3 — 验证公式**

负数 S（S < 0）的 16 位补码位模式按无符号解读的数值满足：

$$U = 2^{16} + S = 65536 + (-100) = 65436$$

与步骤 2 的结果一致。

### 3. 结果（RESULT）

$$\boxed{u = 65436}$$

`printf("%u\n", u)` 输出 **65436**。

### 4. 场景规则验证（RULE_CHECK）

| 规则 | 验证 | 结果 |
|------|------|------|
| 规则1：位模式不变 | bits(S) = 65436, u = 65436 | 相同 ✓ |
| 规则2：U == MOD + S | u = 65436, MOD + S = 65436 | 相等 ✓ |

### 1.

**答案**：运算器、控制器

**解析**：
CPU 的核心组成是运算器（ALU 及相关寄存器）和控制器（产生控制信号的部件）。运算器负责算术运算和逻辑运算，控制器负责协调和控制各部件按指令要求工作。


### 2.

**答案**：触发器、电容

**解析**：
SRAM（静态随机存储器）利用双稳态触发器存储信息，只要不断电就能稳定保持数据，不需要刷新，但集成度较低、功耗较大。DRAM（动态随机存储器）利用 MOS 管栅极电容上的电荷来存储信息，由于电容会自然泄漏电荷，必须定期刷新（通常间隔 2ms）才能维持数据正确。

**二地址级：**

- 二地址指令有 2 个地址码，操作码位数 = L − 2×addr_len = 16 − 8 = **8 位**

- 占用 N2 = 3 条后，剩余编码数 R2 = 256 − 3 = **253**

**一地址级：**

- 一地址可分配空间 = R2 × 2^addr_len = 253 × 16 = **4048**
- 占用 N1 = 8 条后，剩余编码数 R1 = 4048 − 8 = **4040**

**零地址级：**

- 零地址最大条数 = R1 × 2^addr_len = 4040 × 16 = **64640**

### 3.

**进位生成函数：**

$$G_i = A_i \cdot B_i$$

**物理含义：** $G_i = 1$ 表示第 $i$ 位的两个操作数位 $A_i$ 和 $B_i$ 同时为 1，此时该位本身就会**生成**一个向高位的进位，与低位传来的进位无关。

**进位传递函数：**

$$P_i = A_i \oplus B_i$$

**物理含义：** $P_i = 1$ 表示第 $i$ 位的 $A_i$ 和 $B_i$ 恰好一个为 1、一个为 0（半加和为 1），此时若低位有进位传来，该位会把进位**传递**到更高位（即 $C_i = C_{i-1}$）。

---

递推基式：$C_i = G_i + P_i \cdot C_{i-1}$

**$C_1$ 的展开：**

$$C_1 = G_1 + P_1 \cdot C_0$$

（$C_1$ 本身仅含 $C_0$，无需进一步代入。）

**$C_2$ 的展开：**

$$C_2 = G_2 + P_2 \cdot C_1$$

将 $C_1 = G_1 + P_1 \cdot C_0$ 代入：

$$C_2 = G_2 + P_2 \cdot (G_1 + P_1 \cdot C_0)$$

分配律展开：

$$\boxed{C_2 = G_2 + P_2 \cdot G_1 + P_2 \cdot P_1 \cdot C_0}$$

> 验证（gen.py 机检）：展开结果不含中间进位 $C_1$，且 == 递推基式反复代入的结果。✔

---

逐级代入 $C_3 \to C_2 \to C_1$，每一步代入基式 $C_i = G_i + P_i \cdot C_{i-1}$：

- $C_3 = G_3 + P_3 \cdot G_2 + P_3 \cdot P_2 \cdot G_1 + P_3 \cdot P_2 \cdot P_1 \cdot C_0$

将 $C_3$ 代入 $C_4 = G_4 + P_4 \cdot C_3$，分配律展开：

$$\boxed{C_4 = G_4 + P_4 \cdot G_3 + P_4 \cdot P_3 \cdot G_2 + P_4 \cdot P_3 \cdot P_2 \cdot G_1 + P_4 \cdot P_3 \cdot P_2 \cdot P_1 \cdot C_0}$$

> 验证（gen.py 机检）：
> - 展开结果不含任何中间进位 $C_1/C_2/C_3$ ✔
> - == 递推基式反复代入的结果 ✔
> - 含最高阶传递项 $P_4 \cdot P_3 \cdot P_2 \cdot P_1 \cdot C_0$ ✔

---

### 原理阐释：为什么先行进位能消除行波延迟？

在行波进位（ripple-carry）加法器中，$C_i = G_i + P_i \cdot C_{i-1}$，每一位的进位**必须等待前一级进位 $C_{i-1}$ 计算完成后才能开始计算**，形成 $C_0 \to C_1 \to C_2 \to C_3 \to C_4$ 的串行链路，延迟随位数线性增长。

而在先行进位（CLA）中，经过上述展开后可以看到：

$$C_4 = G_4 + P_4 G_3 + P_4 P_3 G_2 + P_4 P_3 P_2 G_1 + P_4 P_3 P_2 P_1 C_0$$

**每一个进位 $C_i$（包括 $C_4$）都仅依赖于 $C_0$ 和本组的 $G_1 \sim G_4$、$P_1 \sim P_4$**，表达式中不再出现任何中间进位变量 $C_1/C_2/C_3$。这意味着：

- 只要知道了所有位的 $G_i$ 和 $P_i$（这些可由 $A_i, B_i$ 在一级门延迟内并行算出）以及初始进位 $C_0$，就能**同时（并行）**计算出 $C_1, C_2, C_3, C_4$；
- **无需等待前一级进位逐级到达**，从而消除了行波进位的逐级延迟，将进位延迟从 $O(n)$ 降低到常数级（由展开式的最大乘积项深度决定）。

这就是先行进位（Carry-Lookahead）的核心思想：用空间换时间，通过增加逻辑门的扇入和数量，换取进位的并行计算。

### 参数（来自题干）

| 参数 | 值 |
|------|-----|
| 总线数据宽度 $W$ | 64 bit |
| 总线时钟频率 $f$ | 250 MHz |
| 每完成一次数据传输所需的时钟周期数 $n$ | 3 |

### 带宽公式

$$B = \frac{W}{8} \times \frac{f \times 10^{6}}{n} \quad (\text{MB/s})$$

其中 $W$ 单位为 bit（÷8 转 Byte），$f$ 单位为 MHz（×10⁶ 转 Hz），$n$ 为每传输周期占用的时钟周期数。

### 逐步代入

**Step 1　bit → Byte 换算：**

$$\frac{W}{8} = \frac{64\ \text{bit}}{8} = 8\ \text{Byte}$$

**Step 2　MHz → Hz 换算：**

$$f = 250\ \text{MHz} = 250 \times 10^{6}\ \text{Hz} = 250\,000\,000\ \text{Hz}$$

**Step 3　÷n（每秒传输次数）：**

每完成一次数据传输需 $n=3$ 个时钟周期，故每秒可完成的传输次数为：

$$\frac{f}{n} = \frac{250\,000\,000}{3}\ \text{次/s}$$

**Step 4　计算带宽：**

$$B = 8\ \text{Byte} \times \frac{250\,000\,000}{3}\ \text{次/s} = \frac{2\,000\,000\,000}{3}\ \text{Byte/s}$$

转为 MB/s（$1\ \text{MB} = 10^{6}\ \text{Byte}$）：

$$B = \frac{2\,000\,000\,000}{3 \times 1\,000\,000}\ \text{MB/s} = \frac{2000}{3}\ \text{MB/s} \approx 666.67\ \text{MB/s}$$

### 最终结果

$$\boxed{B = \dfrac{2000}{3}\ \text{MB/s} \approx 666.67\ \text{MB/s}}$$

## 第(1)题：计算 [A + B]补 并判断溢出

### 运算过程

真实值验证：A + B = (−100) + (−40) = **−140**，超出表示范围 [−128, +127]，预期溢出。

**模 2⁸ 加法**：

```
  0x9C
+ 0xD8
-------
  0x174    ← 最高位向第 9 位进位
```

截断到 8 位（mod 256）：0x174 & 0xFF = **0x74**

### 溢出判断（两种方法互相印证）

**① 双符号位法（变形补码法）**

将 8 位补码符号扩展为双符号位：

| 操作数 | 变形补码（9~10 位） |
|--------|---------------------|
| [A]补 = 0x9C | 1_1001_1100（符号扩展，补码 0x19C = 412） |
| [B]补 = 0xD8 | 1_1101_1000（符号扩展，补码 0x1D8 = 472） |

```
  1_1001_1100   (0x19C = 412)
+ 1_1101_1000   (0x1D8 = 472)
─────────────
 11_0111_0100   (加法原始值 = 0x374 = 884)
```

截断到 9 位双符号位域（mod 2⁹ = 取低 9 位）：0x374 & 0x1FF = **0x174**，即 `1_0111_0100`。

双符号位 = **10**（s_hi = 1, s_lo = 0，两位不一致）。

> 双符号位 `10`：符号位高位为 1、低位为 0，两者不一致 → **溢出**。
> （`10` 表示两个负数相加结果本应为负，但符号位出现 `10` → 负溢出/下溢）

**② 进位判别法**

- 最高位进位 Cs = 1（0x9C + 0xD8 向第 9 位进位）
- 次高位进位 Cp = 0（低 7 位 0x1C + 0x58 = 0x74，未向 bit7 进位）
- Cs ⊕ Cp = 1 ⊕ 0 = **1 → 溢出**

两种方法结论一致。

### 结果

$$[A + B]_补 = \boxed{0x74}$$

**溢出：是**（两个负数相加，真实值 −140 超出下界 −128，截断后变为正数 +116，符号翻转）

## 第(2)题：计算 [A − B]补 并判断溢出

### 第一步：求 [−B]补

$$[−B]_补 = \sim[B]_补 + 1 = \sim\text{0xD8} + 1 = \text{0x27} + 1 = \boxed{\text{0x28}}$$

验证：[−B]补 + [B]补 = 0x28 + 0xD8 = 0x100，mod 2⁸ = 0 ✓（加法逆元关系成立）

### 第二步：[A]补 + [−B]补

真实值验证：A − B = (−100) − (−40) = **−60**，在表示范围 [−128, +127] 内，预期不溢出。

**模 2⁸ 加法**：

```
  0x9C   ([A]补)
+ 0x28   ([−B]补)
-------
  0x0C4  ← 无向第 9 位的进位（最高位进位 = 0）
```

截断到 8 位：**0xC4**（十进制补码解释为 −60，与真实值一致 ✓）

### 溢出判断（两种方法互相印证）

**① 双符号位法（变形补码法）**

| 操作数 | 变形补码 |
|--------|---------------------|
| [A]补 = 0x9C | 1_1001_1100（0x19C = 412） |
| [−B]补 = 0x28 | 0_0010_1000（0x028 = 40） |

```
  1_1001_1100
+ 0_0010_1000
─────────────
  1_1100_0100
```

双符号位 = **11 → 11**（符号位为 `11`）。

> 双符号位 `11`：两位一致 → **不溢出**（结果仍为负，与负数+正数的结果符号一致）

**② 进位判别法**

- 最高位进位 Cs = 0（0x9C + 0x28 = 0xC4，无向第 9 位进位）
- 次高位进位 Cp = 0（低 7 位 0x1C + 0x28 = 0x44，未向 bit7 进位）
- Cs ⊕ Cp = 0 ⊕ 0 = **0 → 不溢出**

两种方法结论一致。

### 结果

$$[−B]_补 = \boxed{\text{0x28}}, \qquad [A − B]_补 = \boxed{\text{0xC4}}$$

**溢出：否**（真实值 −60 在 [−128, +127] 内，结果正确为负数）

## 总结

| | 真实值 | 在范围内？ | 补码结果 | 溢出 |
|------|--------|-----------|----------|------|
| 第(1)题 A+B | −140 | 否（超下界） | 0x74 (+116) | **是** |
| 第(2)题 A−B | −60 | 是 | 0xC4 (−60) | **否** |

两题形成"一溢一不溢"的对照：
- 第(1)题两个负数相加，真实结果 −140 超出下界，截断后符号由负变正 → 溢出。
- 第(2)题负数减负数（等价于加正数），真实结果 −60 仍在范围内 → 不溢出。

两种溢出判断方法（双符号位法、进位判别法）对两题均给出一致结论。
