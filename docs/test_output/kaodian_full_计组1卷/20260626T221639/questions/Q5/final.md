## 题目

某计算机的**机器字长为 4 位**（含 1 位符号位，**数值位为 3 位**），定点整数补码表示范围为 [-2³, 2³−1] = [-8, +7]。运算时采用**双符号位（变形补码）**，将符号位扩展为 2 位，连同数值位共 5 位。已知两个补码操作数：

- A = +5（十进制）
- B = +4（十进制）

现用双符号位补码加法计算 **A + B**。

**判定规则回顾**（双符号位法）：运算结果的双符号位取值与含义如下——

| 双符号位 | 含义 |
|---------|------|
| 00 | 结果为正，未溢出 |
| 01 | 正溢出 |
| 10 | 负溢出 |
| 11 | 结果为负，未溢出 |

请根据上述规则，判断 **A + B** 运算结果的双符号位状态及溢出情况，选择正确的一项。

A. 双符号位为 01，发生了正溢出

B. 双符号位为 10，发生了负溢出

C. 双符号位为 00，未发生溢出

D. 双符号位为 11，未发生溢出

## 参考答案

**A**

双符号位为 01，发生了正溢出。

## 解析

### 参数

| 参数 | 值 |
|------|-----|
| A | +5（十进制） |
| B | +4（十进制） |
| 基础字长 | 4 位（1 符号位 + 3 数值位），表示范围 [−8, +7] |
| 变形补码 | 5 位（2 符号位 + 3 数值位） |

### 第一步：将操作数转换为变形补码（符号位扩展）

对 4 位补码做符号位扩展，正数的符号位 0 扩展为 00：

| 操作数 | 4 位补码 | 变形补码（符号位扩展） |
|--------|---------|----------------------|
| A = +5 | 0101 | **00**101 |
| B = +4 | 0100 | **00**100 |

### 第二步：变形补码加法

```
  00101   （[A]补 = +5）
+ 00100   （[B]补 = +4）
-------
  01001   （5 + 4 = 9，mod 32 = 9）
```

结果码：**01001**

### 第三步：提取双符号位并判定溢出

结果码 01001 的最高 2 位为双符号位 **S₁S₀ = 01**。

- S₁ = 0，S₀ = 1
- S₁ ≠ S₀ → **双符号位相异，发生了溢出**
- 双符号位为 01 → **正溢出**（两个正数相加，结果超出正上限 +7）

判定规则对照：

| 双符号位 | 含义 |
|---------|------|
| 00 | 结果为正，未溢出 |
| **01** | **正溢出 ← 本题结果** |
| 10 | 负溢出 |
| 11 | 结果为负，未溢出 |

### 选项分析

| 选项 | 双符号位 | 判定 | 正误 |
|------|---------|------|------|
| **A** | **01** | **发生了正溢出** | **✓ 正确** |
| B | 10 | 发生了负溢出 | ✗ 正溢出（01）方向颠倒为负溢出（10），混淆了溢出方向 |
| C | 00 | 未发生溢出 | ✗ 双符号位最高位为 0 误判为"未溢出"，忽略了双符号位相异才溢出的规则 |
| D | 11 | 未发生溢出 | ✗ 从操作数符号（均为正）判定而非运算结果判定，符号判断来源错误 |

四个选项的双符号位值（01 / 10 / 00 / 11）各不相同，互不碰撞，每个干扰项对应一种学生常见误判类型。
