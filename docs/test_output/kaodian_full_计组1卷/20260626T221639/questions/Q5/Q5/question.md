# 题目

## 题干

某计算机的**机器字长为 4 位**（含 1 位符号位，**数值位为 3 位**），定点整数补码表示范围为 [-2³, 2³−1] = [-8, +7]。运算时采用**双符号位（变形补码）**，将符号位扩展为 2 位，连同数值位共 5 位。已知两个补码操作数：

- A = +5（十进制）
- B = +4（十进制）

现用双符号位补码加法计算 **A + B**。

**判定规则回顾**（双符号位法）：运算结果的双符号位取值与含义如下——

| 双符号位 | 含义 |
|---------|------|
| 00 | 结果为正，未溢出 |
| 01 | 正溢出 |
| 10 | 负溢出 |
| 11 | 结果为负，未溢出 |

请根据上述规则，判断 **A + B** 运算结果的双符号位状态及溢出情况，选择正确的一项。

## 选项

A. 双符号位为 01，发生了正溢出

B. 双符号位为 10，发生了负溢出

C. 双符号位为 00，未发生溢出

D. 双符号位为 11，未发生溢出

---

## 设计意图

| 考察项 | K级别 | 说明 |
|--------|-------|------|
| 双符号位补码加法运算 | K2 | 能正确将操作数转换为变形补码并执行加法 |
| 双符号位溢出判定规则 | K3 | 根据"双符号位相异=溢出"判定溢出及方向（01=正溢出，10=负溢出） |
| 正溢出/负溢出方向区分 | K3 | 两个正数相加→正溢出（01）；方向不可颠倒 |
| 溢出/无溢出混淆识别 | K4 | 双符号位相同时（00/11）=未溢出，需与溢出情形区分 |

### 干扰项设计

| 选项 | 类型 | 说明 |
|------|------|------|
| A | 正确 | 两个正数相加超出表示范围→正溢出，双符号位 01 |
| B | 正负溢出方向颠倒 | 将正溢出（01）误判为负溢出（10），考查方向区分 |
| C | 溢出/无溢出混淆 | 双符号位最高位为 0 误认为无溢出，考查"双符号位相异才溢出"的规则 |
| D | 符号判断来源错误 | 从操作数符号（均为正→00）而非运算结果判定，考查判定来源 |

---

## 场景规则（通过条件·可机检）

### 通用约束

1. **溢出必然发生**：A 与 B 同号相加，且 |A + B| 超出机器字长的补码表示范围（机器字长 4 位，含 1 位符号位 + 3 位数值位 → 表示范围 [-2³, 2³−1] = [-8, +7]）。即：A + B > 7 或 A + B < -8，且 sign(A) == sign(B)。
2. **双符号位状态合法**：因溢出必然发生，运算结果（变形补码加法后的 5 位码）的双符号位必须为 01 或 10 之一（相异=溢出），不可能为 00 或 11。
3. **正确选项唯一确定**：给定 A、B 的具体值后，A + B 的结果唯一确定，双符号位状态唯一确定，只有一个选项与之匹配。

### 选择题约束

4. **4 选项互异**：A/B/C/D 四个选项描述的双符号位值（01/10/00/11）各不相同，无碰撞。
5. **干扰项对应声明错误类型**：
   - B = 将正溢出的双符号位 01 颠倒为 10（方向混淆）。
   - C = 双符号位 00（溢出/无溢出混淆，最高符号位为 0 误判无溢出）。
   - D = 双符号位 11（符号判断来源错误，从操作数判定而非结果）。
6. **干扰项有合理性**：每个干扰项的双符号位值（10/00/11）均为双符号位判定法中真实存在的合法取值，是学生常见误判的真实产物，具有区分度。
