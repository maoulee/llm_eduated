# 微指令格式设计与控制存储器容量计算

## 题目

某微程序控制器中，共有 18 个微命令，按照互斥关系分为 5 组（即 5 个互斥类）。各组包含的微命令数如下表所示：

| 互斥类编号 | 功能类别 | 微命令数 |
|:---:|---|:---:|
| 第 1 组 | 取指控制 | 4 |
| 第 2 组 | 访存控制 | 3 |
| 第 3 组 | 运算控制 | 4 |
| 第 4 组 | 寄存器控制 | 2 |
| 第 5 组 | 总线控制 | 5 |

该微程序控制器采用**字段直接编码法**（分段直接编码），即每个互斥类对应一个字段，每个字段采用最短编码方式表示该组的所有微命令。编码时需预留"不发命令"状态（即全 0 状态不对应任何有效微命令）。

已知该控制器的控制存储器中需存放 **512 条**微指令。微指令采用水平型格式，由三个部分组成：**操作控制字段**、**判别测试字段**和**下址字段**。其中判别测试字段为 **2 位**。

请回答以下问题：

### 第 1 问（4 分）

设计该微指令的**操作控制字段**格式（各字段的位数），并计算操作控制字段的总位数。

要求：列出每个互斥类分配的位数及计算过程。

### 第 2 问（3 分）

计算该微指令的**字长**（即完整微指令的二进制位数）。

要求：说明各组成部分的位数取值依据。

### 第 3 问（3 分）

计算该控制存储器的**最大容量**（分别以"位"和"字节"为单位给出结果）。

---

## 设计意图

- **考察知识点**：微程序控制器——微指令格式设计（字段直接编码法）与控制存储器容量计算。
- **第 1 问**：核心考点——字段直接编码法中每个互斥类的编码位数计算。关键陷阱：每组需预留"不发命令"状态，因此 n 个微命令需要 ⌈log₂(n+1)⌉ 位而非 ⌈log₂(n)⌉ 位。第 1 组和第 3 组各有 4 个微命令（4 = 2²），学生若遗漏预留码会误算为 2 位（正确为 3 位），构成预留码陷阱。
- **第 2 问**：微指令完整字长的计算，涉及控制字段位数 + 判别测试字段位数 + 下址字段位数。下址字段位数需由控存深度（512 条）反推，考察对"下址字段位数 = ⌈log₂(微指令条数)⌉"的掌握。
- **第 3 问**：控存容量 = 微指令条数 × 微指令字长，要求单位换算（位→字节），考察综合运用前三问结果的能力。
- **难度设计**：串行依赖（第 1 问→第 2 问→第 3 问），任一步算错会导致后续全错；预留码陷阱（K4=3）在两组（n=4）处布设，区分度高。

---

## 通过条件（场景规则）

本题成立需要满足以下参数间约束（与具体答案值无关，换参数仍成立）：

1. **预留码约束**：每个互斥类分配位数 = ⌈log₂(该组微命令数 + 1)⌉，其中 +1 为预留"不发命令"状态。正确解必须对每组均做 +1 处理，不能遗漏。
2. **控制字段总位数约束**：操作控制字段总位数 = 各互斥类分配位数之和（加法聚合，不可重复或遗漏任何一组）。
3. **下址字段位数约束**：下址字段位数 = ⌈log₂(控存中微指令总条数)⌉，且该位数所对应的可寻址微指令数 ≥ 给定微指令总条数（即 2^(下址字段位数) ≥ 微指令总条数）。
4. **微指令字长约束**：微指令字长 = 操作控制字段位数 + 判别测试字段位数 + 下址字段位数。
5. **控存容量约束**：控存容量（位）= 微指令总条数 × 微指令字长；控存容量（字节）= 控存容量（位）/ 8，且整除无余数。
6. **陷阱可区分性约束**：存在至少两组的微命令数恰为 2 的幂（本题为第 1 组 n=4、第 3 组 n=4），使得遗漏预留码（取 ⌈log₂(n)⌉ 而非 ⌈log₂(n+1)⌉）必然导致位数少算 1，从而得到与正确值不同的结果——保证预留码陷阱可被检出。
