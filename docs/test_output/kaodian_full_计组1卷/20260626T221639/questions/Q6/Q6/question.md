## 题目

在 C 语言中，`short` 类型占 16 位，`unsigned short` 类型同样占 16 位。有以下代码：

```c
short s = -100;
unsigned short u = (unsigned short)s;
printf("%u\n", u);
```

已知 `short` 采用补码表示，`unsigned short` 的取值范围为 0 ～ 65535。执行上述代码后，`printf` 输出的 `u` 的十进制值是多少？

## 选项

A. 65436
B. −100
C. 100
D. 65336

## 场景规则（通过条件）

1. **同宽度转换 = 位模式重解读**：`short` → `unsigned short` 是 16 位 → 16 位转换，位模式不变，仅按无符号语义重新解读；不涉及符号扩展、不发生截断。即 `u` 的 16 位位模式与 `s` 的 16 位补码位模式完全相同。
2. **U = 65536 + S**：负数 `S`（S < 0）的 16 位补码位模式按无符号解读的数值 U 满足 `U == 65536 + S`。本题 S = −100，故 U == 65436。
3. **正确值唯一确定**：在给定参数下只有一个确定答案，A = 65436；不存在两个选项同时正确的歧义。
4. **四选项互异**：A = 65436、B = −100、C = 100、D = 65336，四个值各不相同，无碰撞。
5. **干扰项对应声明错误类型**：
   - B = −100：忽略 unsigned 语义，直接保留原负值（未做位模式重解读）。
   - C = 100：误取绝对值（误以为转换仅去符号位）。
   - D = 65336 = 65536 − 2×100：错误补码公式（多减了一次 |S|）。
6. **干扰项有合理性**：B/C/D 均为同类型转换题中常见误算的真实产物，非荒谬值，具有区分度。
