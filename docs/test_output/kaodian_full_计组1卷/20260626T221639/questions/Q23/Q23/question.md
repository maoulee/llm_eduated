# 先行进位加法器——进位生成/传递函数推导

## 题干

在先行进位加法器（Carry-Lookahead Adder, CLA）中，四位加法器的进位递推关系定义为：

$$C_i = G_i + P_i \cdot C_{i-1} \quad (i = 1, 2, 3, 4)$$

其中 $C_0$ 为外部输入的最低位进位，$A_i$、$B_i$ 为第 $i$ 位的两个操作数位。

**约定（全题统一）：**

- 进位生成函数：$G_i = A_i \cdot B_i$
- 进位传递函数：$P_i = A_i \oplus B_i$（异或）
- 以上定义在全题三个子问中保持一致，不得中途更改。

请回答以下问题：

### (1) 定义推导（2分）

写出 $G_i$ 和 $P_i$ 的定义式，并分别解释 $G_i$（进位生成）和 $P_i$（进位传递）的物理含义：即 $G_i = 1$ 和 $P_i = 1$ 各表示什么情况。

### (2) 多步推导（2分）

利用进位递推关系 $C_i = G_i + P_i \cdot C_{i-1}$，将 $C_1$ 和 $C_2$ 逐步代入展开，**使结果仅以 $C_0$ 和各组 $G_i$、$P_i$ 表示**（展开后不得保留 $C_1$ 等中间进位变量）。

### (3) 多步推导 + 原理阐释（2分）

继续展开 $C_4$，使其**仅以 $C_0$ 和 $G_1 \sim G_4$、$P_1 \sim P_4$ 表示**（不得保留任何中间进位变量 $C_1$、$C_2$、$C_3$）。

然后说明：为什么先行进位能够消除行波进位（ripple-carry）的逐级延迟？请从"所有进位输出是否依赖前一级进位的逐级传递"这一角度解释。

## 场景规则（可机检约束）

> 本题为**纯符号推导题**，无数值参数。以下约束由 gen.py 的符号展开验证（SymPy 等符号计算）进行机检：

1. **递推基式一致性**：$C_i = G_i + P_i \cdot C_{i-1}$ 是所有展开的唯一起点；每个 $C_i$ 的展开结果必须能由反复代入该基式得到（即展开结果 == 基式反复代换后的等价表达式）。
2. **仅含 C0 和 G/P（不含中间进位）**：$C_1$、$C_2$、$C_4$ 展开后，表达式中**不得出现** $C_1$、$C_2$、$C_3$ 等中间进位变量，只允许出现 $C_0$ 和 $G_1 \sim G_4$、$P_1 \sim P_4$。
3. **定义一致性**：全题 $G_i = A_i \cdot B_i$、$P_i = A_i \oplus B_i$ 的定义形式在三个子问中保持统一，不得出现 $P_i = A_i + B_i$ 的变体。
4. **展开完整性**：$C_4$ 展开后应包含 $P_4 P_3 P_2 P_1 C_0$ 这一项（最高阶传递项），用以检验展开未遗漏或截断。
