## 题目

某计算机的主存地址空间为 **16 MB**（即 $2^{24}$ B），按字节编址。Cache 容量为 **4 KB**（即 $2^{12}$ B），采用**数据块（行）大小为 32 B**（即 $2^{5}$ B）的固定块划分。Cache 最初为空。

请回答以下问题：

### 问题 1（4分）

若 Cache 采用**直接映射**方式，请：

1. 计算主存地址各字段（Tag 标记、Cache 行号、块内偏移）的位数，并说明计算过程。
2. 用**表格**列出主存地址的划分情况（表格应包含：各字段名称、位数、地址位范围）。

### 问题 2（4分）

若 Cache 采用 **4 路组相联映射**方式，请：

1. 计算主存地址各字段（Tag 标记、组号、块内偏移）的位数，并说明计算过程。
2. 用**表格**列出主存地址的划分情况（表格应包含：各字段名称、位数、地址位范围）。

### 问题 3（2分）

已知某主存块的起始地址为 **0x123450**，请用文字分别描述该块在**直接映射**和**4 路组相联映射**方式下，如何在 Cache 中定位（即说明映射到哪一行/哪一组，以及 Tag 标记值是什么）。

## 参考答案

| 问题 | 答案 |
|------|------|
| Q1 直接映射 | Tag=12位（位23~12），行号=7位（位11~5），偏移=5位（位4~0） |
| Q2 4路组相联 | Tag=14位（位23~10），组号=5位（位9~5），偏移=5位（位4~0） |
| Q3 直接映射 | 映射到第 34 行，Tag=291 |
| Q3 组相联 | 映射到第 2 组，Tag=1165 |

## 解析

### 基本参数

| 参数 | 值 |
|------|-----|
| 主存地址空间 M | $2^{24}$ B = 16 MB |
| Cache 容量 C | $2^{12}$ B = 4 KB |
| 块（行）大小 B | $2^{5}$ B = 32 B |
| 组相联路数 w | 4 |
| 编址方式 | 按字节编址 |

公共中间量：
- 主存地址总位数 = $\log_2 M = \log_2 2^{24} = 24$ 位
- 块内偏移位数 = $\log_2 B = \log_2 2^{5} = 5$ 位（两种映射共用）
- Cache 行数 = $C / B = 2^{12} / 2^{5} = 2^{7} = 128$ 行

---

### 问题 1：直接映射（4分）

**各字段位数计算：**

- **块内偏移**：$B = 2^{5}$ B，按字节编址 → 偏移位数 = $\log_2 B = 5$ 位。
- **Cache 行号**：行数 = $128 = 2^{7}$ → 行号位数 = $\log_2 128 = 7$ 位。
- **Tag 标记**：Tag 位数 = 地址总位数 − 行号位数 − 偏移位数 = $24 - 7 - 5 = 12$ 位。
- **验证**：$12 + 7 + 5 = 24$ ✓（等于主存地址总位数）。

**主存地址划分表：**

| 字段 | Tag 标记 | Cache 行号 | 块内偏移 |
|------|---------|-----------|---------|
| 位数 | 12 | 7 | 5 |
| 地址位范围 | 位 23 ~ 位 12 | 位 11 ~ 位 5 | 位 4 ~ 位 0 |

> 低位为偏移（5位），中间为行号（7位），高位为 Tag（12位）。

**评分标准：** 偏移位数计算正确（1分）；行号位数计算正确（1分）；Tag 位数计算正确（1分）；地址划分表完整正确（1分）。

---

### 问题 2：4 路组相联映射（4分）

**各字段位数计算：**

- **组数** = 行数 / 路数 = $128 / 4 = 32 = 2^{5}$ → 组号位数 = $\log_2 32 = 5$ 位。
- **块内偏移**：$5$ 位（同 Q1）。
- **Tag 标记**：Tag 位数 = 地址总位数 − 组号位数 − 偏移位数 = $24 - 5 - 5 = 14$ 位。
- **验证**：$14 + 5 + 5 = 24$ ✓（等于主存地址总位数）。

**主存地址划分表：**

| 字段 | Tag 标记 | 组号 | 块内偏移 |
|------|---------|------|---------|
| 位数 | 14 | 5 | 5 |
| 地址位范围 | 位 23 ~ 位 10 | 位 9 ~ 位 5 | 位 4 ~ 位 0 |

> 与直接映射相比，组相联将原本 7 位行号拆分为 5 位组号，剩余 2 位并入 Tag，因此 Tag 从 12 位增至 14 位。

**评分标准：** 组数计算正确（1分）；组号位数计算正确（1分）；Tag 位数计算正确（1分）；地址划分表完整正确（1分）。

---

### 问题 3：地址 0x123450 的定位（2分）

给定地址 $0\text{x}123450 = 1193040$，主存块号 = $1193040 / 32 = 37282$。

**直接映射下：**

- **映射行号** = 块号 mod 行数 = $37282 \bmod 128 = 34$，即映射到 **第 34 行**。
- **Tag 标记值** = 块号 / 行数 = $37282 / 128 = 291$。
- 定位过程：CPU 取地址 0x123450 时，按行号 34 访问 Cache 第 34 行，比较该行的 Tag 是否等于 291，匹配则命中。

**4 路组相联映射下：**

- **映射组号** = 块号 mod 组数 = $37282 \bmod 32 = 2$，即映射到 **第 2 组**。
- **Tag 标记值** = 块号 / 组数 = $37282 / 32 = 1165$。
- 定位过程：CPU 取地址 0x123450 时，按组号 2 访问 Cache 第 2 组（共 4 路），在该组 4 行中比较 Tag 是否等于 1165，任一匹配则命中。

> **对照**：同一地址在直接映射下映射到第 34 行（Tag=291），在 4 路组相联下映射到第 2 组（Tag=1165）。两种映射的 Tag 位数不同（12位 vs 14位），因此 Tag 数值也不同。

**评分标准：** 直接映射定位正确（行号+Tag 各对，1分）；组相联定位正确（组号+Tag 各对，1分）。
