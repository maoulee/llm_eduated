# Cache 地址映射综合题

## 题目（10分）

某计算机的主存地址空间为 **16 MB**（即 $2^{24}$ B），按字节编址。Cache 容量为 **4 KB**（即 $2^{12}$ B），采用**数据块（行）大小为 32 B**（即 $2^{5}$ B）的固定块划分。Cache 最初为空。

请回答以下问题：

### 问题 1（4分）

若 Cache 采用**直接映射**方式，请：

1. 计算主存地址各字段（Tag 标记、Cache 行号、块内偏移）的位数，并说明计算过程。
2. 用**表格**列出主存地址的划分情况（表格应包含：各字段名称、位数、地址位范围）。

### 问题 2（4分）

若 Cache 采用 **4 路组相联映射**方式，请：

1. 计算主存地址各字段（Tag 标记、组号、块内偏移）的位数，并说明计算过程。
2. 用**表格**列出主存地址的划分情况（表格应包含：各字段名称、位数、地址位范围）。

### 问题 3（2分）

已知某主存块的起始地址为 **0x123450**，请用文字分别描述该块在**直接映射**和**4 路组相联映射**方式下，如何在 Cache 中定位（即说明映射到哪一行/哪一组，以及 Tag 标记值是什么）。

---

## 场景规则（本题成立 ⇔ 以下参数间约束被满足）

> 以下约束与具体答案值无关，换参数仍成立，供 gen.py 翻译为 assert 验证。

### SR-1：块内偏移位数

- 块大小 $B = 2^{5}$ B，按字节编址 → 块内偏移位数 $= \log_2 B = 5$。两种映射方式共用此字段。

### SR-2：直接映射字段一致性

- Cache 行数 $= C / B = 2^{12}/2^{5} = 2^{7} = 128$ 行，行号位数 $= \log_2(128) = 7$。
- 主存地址总位数 $= \log_2 M = \log_2(2^{24}) = 24$。
- Tag 位数 $= 24 - 7 - 5 = 12$。
- 三字段位数之和 $= \text{Tag} + \text{行号} + \text{偏移} = 12 + 7 + 5 = 24$，等于主存地址总位数。

### SR-3：组相联映射字段一致性

- Cache 行数 $= 128$，路数 $w = 4$ → 组数 $= 128/4 = 32$，组号位数 $= \log_2(32) = 5$。
- Tag 位数 $= 24 - 5 - 5 = 14$。
- 三字段位数之和 $= \text{Tag} + \text{组号} + \text{偏移} = 14 + 5 + 5 = 24$，等于主存地址总位数。

### SR-4：两种映射的区分度

- 直接映射 Tag 位数（12）与组相联 Tag 位数（14）至少差 1 位 → 本题差 2 位，满足区分度要求。

### SR-5：Q3 给定地址在地址空间范围内

- 给定块起始地址 $0\text{x}123450 < 2^{24} = 16\,\text{777\,216}$ → 地址在主存地址空间范围内。
- $0\text{x}123450 \mod B = 0$（该地址为块对齐地址），确保"块起始地址"描述正确。
