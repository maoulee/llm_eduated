# 存储器扩展设计题

## 题干

某计算机的 CPU 具有 **16 位地址总线（A₀~A₁₅）** 和 **8 位数据总线（D₀~D₇）**，按字节编址。现需为主存配置一块连续存储区，目标容量为 **32KB**（即 32K×8 位）。

可用的存储芯片规格为：**4K×4 位** 的 SRAM 芯片。

请基于以上参数，完成以下各问（均要求文字推导，**不需要画出连接框图**）：

---

### 第(1)题（3分）

判断本题需要采用哪种扩展方式（位扩展、字扩展还是字位同时扩展），并说明理由。然后计算：

- 每组需要多少片芯片（位扩展方向）？
- 需要多少组（字扩展方向）？
- 总共需要多少片芯片？

### 第(2)题（3分）

推导地址线的分配方案：

- 片内地址线需要多少根？对应哪些地址线（写出标号范围）？
- 片选地址线需要多少根？对应哪些地址线（写出标号范围）？
- 是否有剩余未使用的地址线？如果有，指出其标号。

然后列出每组芯片对应的**地址范围表**（以十六进制表示，每组占一行，标明组号与起始/结束地址）。

### 第(3)题（4分）

假设系统中使用一个 **3-8 译码器**实现片选逻辑，译码器的 3 个地址输入端依次连接到片选地址线的最低 3 位（A₁₂、A₁₃、A₁₄），译码器输出 $\overline{Y_0}$~$\overline{Y_7}$ 分别连接到第 0~7 组芯片的片选端 $\overline{CS}$。

请写出：

1. 每组芯片的片选信号逻辑表达式（用地址线变量表示，例如 "$\overline{CS_0} = \overline{Y_0}$，当 A₁₄A₁₃A₁₂ = 000 时有效"）。列出全部 8 组的表达式。
2. 如果还有未使用的地址线，说明它在片选逻辑中应如何处理（是否需要参与译码？为什么？）。
3. 用文字描述该存储器与 CPU 的连接方案（地址线如何连接、数据线如何连接、片选信号如何连接），不画框图。

---

## 设计意图

| 子问 | 考察点 | 考察意图 |
|------|--------|---------|
| (1) | 扩展方式判断 + 芯片数量计算 | 学生需识别芯片字长(4位)≠数据总线宽度(8位)→必须位扩展，且芯片容量(4K)<目标容量(32K)→必须字扩展→字位同时扩展 |
| (2) | 地址线分配 + 地址范围推导 | 多步推演链：片内地址位数(log₂4096=12)→片选地址位数→各组连续地址范围。陷阱：CPU有16位地址线但只用15位，A₁₅未使用 |
| (3) | 片选逻辑表达式 + 连接方案 | 将地址范围转化为布尔逻辑表达式，要求理解译码器工作原理与片选有效条件，并能文字描述完整连接方案 |

**关键参数选择理由**：
- 芯片 4K×4 位、目标 32K×8 位：位扩展系数=2、字扩展系数=8，两组数均为2的幂，计算清晰且非平凡。
- CPU 地址总线 16 位，但目标仅用 15 位（32K=2¹⁵）：**A₁₅ 成为剩余线**，制造"高位地址线位数多算 1 位"的陷阱（学生可能误认为片选地址有 4 位）。
- 3-8 译码器：与 8 组芯片精确匹配，片选逻辑表达式清晰可推导。

## 通过条件（场景规则）

本题成立需要满足以下参数间约束（与具体答案值无关，换参数仍成立）：

1. **芯片数量守恒**：`总芯片数 == 位扩展系数 × 字扩展系数`，其中 `位扩展系数 == 目标字长 / 芯片字长`，`字扩展系数 == 目标字数 / 芯片字数`。
2. **扩展方式非平凡**：`目标字长 / 芯片字长 ≥ 2`（强制位扩展）且 `目标字数 / 芯片字数 ≥ 2`（强制字扩展），即本题必须是字位同时扩展，不能仅位扩展或仅字扩展。
3. **地址位数守恒**：`片内地址位数 == log₂(芯片字数)`，且 `片内地址位数 + 片选地址位数 == log₂(目标字数)`，且 `log₂(目标字数) ≤ CPU地址总线宽度`（目标容量不超过CPU可寻址空间）。
4. **地址范围连续且不重叠**：按组号 0~(组数−1) 排列，第 i 组的起始地址 == `i × 芯片字数`，结束地址 == `(i+1) × 芯片字数 − 1`；相邻组地址范围首尾相接、无间隙、无重叠。
5. **片选逻辑覆盖全部组**：片选地址线的组合数 `2^(片选地址位数) >= 组数`，且每组恰好对应一个唯一的片选地址组合。
