# 解题过程

## PARAMS（已知参数）

| 指令类型 | CPI | 使用占比 |
|---------|-----|---------|
| A 类指令 | 1 | 35% |
| B 类指令 | 3 | 30% |
| C 类指令 | 6 | 25% |
| D 类指令 | 10 | 10% |

- 程序指令总数 N = 100000
- 主频 f = 2.5 GHz

占比之和 = 35% + 30% + 25% + 10% = 100%（归一满足）

---

## 第1问（3分）：计算该程序运行时的平均 CPI

**公式：** CPI_avg = Σ(CPI_i × 占比_i)，其中占比取小数形式。

逐项加权：

| 指令类型 | 计算 | 结果 |
|---------|------|------|
| A 类 | 1 × 0.35 | 0.35 |
| B 类 | 3 × 0.30 | 0.90 |
| C 类 | 6 × 0.25 | 1.50 |
| D 类 | 10 × 0.10 | 1.00 |

求和：

$$\text{CPI}_{\text{avg}} = 0.35 + 0.90 + 1.50 + 1.00 = 3.75$$

> **第1问答案：平均 CPI = 3.75**

---

## 第2问（3分）：计算程序在该 CPU 上的执行时间（μs，保留两位小数）

**公式：** T = (N × CPI_avg) / f

**单位换算：** 主频 f = 2.5 GHz = 2.5 × 10⁹ Hz = 2.5 × 10⁹ s⁻¹

代入计算：

$$T = \frac{N \times \text{CPI}_{\text{avg}}}{f} = \frac{100000 \times 3.75}{2.5 \times 10^9} = \frac{375000}{2.5 \times 10^9}$$

$$T = 0.00015 \text{ s}$$

换算为微秒（1 s = 10⁶ μs）：

$$T = 0.00015 \times 10^6 = 150.00 \text{ μs}$$

> **第2问答案：执行时间 T = 150.00 μs**

---

## RESULT（最终结果）

| 问题 | 答案 |
|------|------|
| 第1问 平均 CPI | **3.75** |
| 第2问 执行时间 | **150.00 μs** |

---

## 场景规则验证

| 规则 | 内容 | 验证结果 |
|------|------|---------|
| 占比归一 | Σ占比 = 35+30+25+10 = 100% | ✓ |
| 加权平均定义 | CPI_avg = Σ(CPI_i×占比_i) | ✓（见逐项计算） |
| 平均 CPI 非整数 | CPI_avg = 3.75，小数部分 = 0.75 ≠ 0 | ✓ |
| 执行时间公式 | T = (N × CPI_avg)/f = 375000/(2.5×10⁹) | ✓ |
| 单位换算真实存在 | GHz→Hz（×10⁹）、s→μs（×10⁶），两步非平凡换算 | ✓ |
| 结果量级合理 | T = 150 μs，落在 μs~ms 范围内 | ✓ |
