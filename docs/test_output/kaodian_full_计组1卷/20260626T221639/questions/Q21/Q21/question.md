# 题干

某计算机的指令系统包含 4 种指令类型，各类指令的 CPI 及其在某测试程序中的使用占比如下表所示：

| 指令类型 | CPI | 使用占比 |
|---------|-----|---------|
| A 类指令 | 1 | 35% |
| B 类指令 | 3 | 30% |
| C 类指令 | 6 | 25% |
| D 类指令 | 10 | 10% |

该测试程序共包含 100000 条指令，CPU 的主频为 2.5 GHz。

请回答以下问题：

**第1问（3分）：** 计算该程序运行时的平均 CPI。

**第2问（3分）：** 计算该程序在该 CPU 上的执行时间（结果以 μs 为单位，保留两位小数）。

---

## 场景规则（通过条件）

本题成立需要满足以下参数间约束（与具体答案值无关，换参数仍成立）：

1. **占比归一**：表中所有指令类型的使用占比之和恰好等于 100%。
2. **加权平均定义**：`CPI_avg = Σ(CPI_i × 占比_i)`，其中占比_i 取百分比的小数形式（如 35% = 0.35）。
3. **平均 CPI 非整数**：`CPI_avg` 的小数部分不为零——确保无法口算秒杀，K2 考察点成立。
4. **执行时间公式**：`T = (N × CPI_avg) / f`，其中 N 为程序指令总数，f 为主频（Hz）。
5. **单位换算真实存在**：主频以 GHz 给出，计算 T 时必须将 GHz 换算为 Hz（×10⁹），且最终结果需从秒换算至 μs，至少经过一次非平凡的量级换算。
6. **结果量级合理**：执行时间 T 落在 μs ~ ms 数量级范围内（即 1 μs ≤ T ≤ 1000 ms）。

---

## 设计说明（供审核参考，不暴露给学生）

- **考察点**：第1问考加权平均 CPI 计算（K2=4，非 2 幂次乘加产生小数）；第2问考执行时间计算 + 单位换算（K2=4，GHz→Hz→μs 多级换算）。
- **串行依赖**：第2问必须使用第1问的 CPI_avg 结果。
- **易错点**：①占比未归一（忘记除以 100）；②主频单位混淆（用 GHz 直接代入未换算）；③CPI 与时钟周期混淆；④最终单位换算方向错误。
