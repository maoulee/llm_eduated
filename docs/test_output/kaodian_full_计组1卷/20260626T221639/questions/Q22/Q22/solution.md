# 数据寻址方式——有效地址（EA）计算 · 解答

## 已知参数

| 参数 | 值（十六进制） |
|------|---------------|
| 形式地址 A | 0x3C |
| 基址寄存器 R₀ | 0x28 |
| 变址寄存器 R₁ | 0x50 |
| 通用寄存器 R₂ | 0x5A |
| 程序计数器 PC | 0x12（取本条指令后已更新的值） |
| Mem[0x3C] | 0x7E |

地址空间：0x0000～0xFFFF（16位），按字编址，机器字长16位。

---

## 第1问（2分）

### （1）直接寻址

**公式**：EA = A

**计算**：EA = A = **0x3C**

### （2）间接寻址

**公式**：EA = 内存地址 A 处所存储的内容，即 EA = (A) = Mem[A]

间接寻址链仅一跳：Mem[A] 的值本身即为有效地址，不再进行二次间接。

**计算**：EA = Mem[A] = Mem[0x3C] = **0x7E**

---

## 第2问（2分）

### （1）寄存器间接寻址（使用 R₂）

**公式**：EA = (R₂)，即指定寄存器 R₂ 的内容

**计算**：EA = R₂ = **0x5A**

### （2）基址寻址（使用 R₀，形式地址 A）

**公式**：EA = (R₀) + A

**计算**：EA = R₀ + A = 0x28 + 0x3C = **0x64**

---

## 第3问（2分）

### （1）变址寻址（使用 R₁，形式地址 A）

**公式**：EA = (R₁) + A

**计算**：EA = R₁ + A = 0x50 + 0x3C = **0x8C**

### （2）相对寻址（使用 PC，形式地址 A）

**公式**：EA = (PC) + A，其中 PC 为取本条指令后已更新的值

**计算**：EA = PC + A = 0x12 + 0x3C = **0x4E**

---

## 结果汇总

| 寻址方式 | 计算公式 | EA（十六进制） |
|---------|---------|--------------|
| 直接寻址 | EA = A | **0x3C** |
| 间接寻址 | EA = Mem[A] = Mem[0x3C] | **0x7E** |
| 寄存器间接寻址 | EA = R₂ | **0x5A** |
| 基址寻址 | EA = R₀ + A = 0x28 + 0x3C | **0x64** |
| 变址寻址 | EA = R₁ + A = 0x50 + 0x3C | **0x8C** |
| 相对寻址 | EA = PC + A = 0x12 + 0x3C | **0x4E** |

## 场景规则验证

6种寻址方式的 EA 互不相同（0x3C、0x7E、0x5A、0x64、0x8C、0x4E），每种寻址方式可独立区分；所有 EA 均在地址空间范围 [0x0000, 0xFFFF] 内，地址合法。
