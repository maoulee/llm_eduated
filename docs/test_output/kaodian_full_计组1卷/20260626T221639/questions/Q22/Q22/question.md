# 数据寻址方式——有效地址（EA）计算

## 题目

某计算机采用16位地址空间（地址范围 0x0000～0xFFFF），按字编址，机器字长16位。指令中形式地址 **A** 以十六进制给出。系统中有以下寄存器和内存状态：

| 名称 | 值（十六进制） | 说明 |
|------|---------------|------|
| 形式地址 A | 0x3C | 指令字段中给出的形式地址 |
| 基址寄存器 R₀ | 0x28 | 基址寻址使用 |
| 变址寄存器 R₁ | 0x50 | 变址寻址使用 |
| 通用寄存器 R₂ | 0x5A | 寄存器间接寻址使用 |
| 程序计数器 PC | 0x12 | 取本条指令后 PC 的值（已指向下一条指令） |

内存单元内容如下：

| 内存地址 | 该单元内容（十六进制） |
|---------|----------------------|
| 0x3C    | 0x7E                 |

> **寻址约定：**
> - **直接寻址**：EA = A
> - **间接寻址**：EA = 内存地址 A 处所存储的内容，即 EA = (A)
> - **寄存器间接寻址**：EA = 指定寄存器的内容，即 EA = (R₂)
> - **基址寻址**：EA = (R₀) + A
> - **变址寻址**：EA = (R₁) + A
> - **相对寻址**：EA = (PC) + A，其中 PC 为取本条指令后已更新的值

### 第1问（2分）

分别计算以下两种寻址方式的有效地址 EA（用十六进制表示）：

（1）直接寻址
（2）间接寻址

### 第2问（2分）

分别计算以下两种寻址方式的有效地址 EA（用十六进制表示）：

（1）寄存器间接寻址（使用 R₂）
（2）基址寻址（使用 R₀，形式地址 A）

### 第3问（2分）

分别计算以下两种寻址方式的有效地址 EA（用十六进制表示）：

（1）变址寻址（使用 R₁，形式地址 A）
（2）相对寻址（使用 PC，形式地址 A）

---

## 场景规则（通过条件）

本题成立需要满足以下参数间约束（与具体答案值无关，换参数仍须成立）：

1. **间接寻址结果 ≠ 直接寻址结果**：EA_间接 = Mem[A] ≠ A = EA_直接（即 Mem[A] ≠ A）。确保两种寻址方式产出不同 EA，考点可区分。

2. **基址寻址结果 ≠ 变址寻址结果**：EA_基址 = R₀ + A ≠ R₁ + A = EA_变址（即 R₀ ≠ R₁）。确保基址与变址产出不同 EA。

3. **6种寻址方式的 EA 互不相同**：直接、间接、寄存器间接、基址、变址、相对——六者的 EA 各不相同，保证每种寻址方式可独立区分。

4. **所有 EA 在地址空间范围内**：每种寻址方式算出的 EA ∈ [0x0000, 0xFFFF]，地址合法。

5. **相对寻址 EA 定义明确**：EA_相对 = (PC) + A，PC 取题中给定的"取本条指令后已更新的值"，无歧义。

6. **间接寻址链仅一跳**：Mem[A] 的值（0x7E）本身即为有效地址，不再进行二次间接（非多级间接），EA_间接 = Mem[A]，直接得到合法地址。
