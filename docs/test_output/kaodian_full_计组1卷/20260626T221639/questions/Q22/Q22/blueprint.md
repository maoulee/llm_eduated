## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: CO-4 > 指令系统 > 指令寻址方式 > 数据寻址
- primary_target_name: 数据寻址方式/有效地址计算
- question_type: subjective（简答题）
- examination_mode: 计算型——有效地址计算

### 难度目标
- k_target: K1=2,K2=3,K3=3,K4=3,K5=1
- difficulty_level: 3
- difficulty_rationale: 需根据多种寻址方式定义逐一计算EA，覆盖6种寻址方式，每问需代入公式做常规运算，间接寻址和相对寻址存在常规陷阱

### 结构要求
- sub_question_count: 3（分值 2+2+2）
- sub_question_details:
  - 第1问（2分）: 直接寻址 + 间接寻址 EA计算
  - 第2问（2分）: 寄存器间接寻址 + 基址寻址 EA计算
  - 第3问（2分）: 变址寻址 + 相对寻址 EA计算
- dependency: 三问并行独立，不串行依赖
- condition_count: 4-5个显式条件（指令格式、形式地址A、寄存器初值、PC值、内存单元内容）

### 参数约束
- 形式地址A: 8位十六进制，取值范围 0x00~0xFF
  - 约束1: A所指内存单元内容 ≠ A（保证间接寻址与直接寻址结果不同）
  - 约束2: A + 基址寄存器值 ≠ A + 变址寄存器值（基址/变址结果不重合）
  - 约束3: A ≠ 任意寄存器值（避免结果重合降低区分度）
- 基址寄存器R0: 8位十六进制，非零，取值范围 0x01~0xFF
- 变址寄存器R1: 8位十六进制，≠ R0，取值范围 0x01~0xFF
- PC: 8位十六进制，PC + A 结果在地址空间内
- 内存内容（地址A单元）: 8位十六进制有效地址值，≠ A，指向合法地址
- 地址空间: 统一8位或16位（由Question Agent选定，全题一致）
- 数值表示: 全部用十六进制

### 干扰策略（不适用于简答题，仅列出常见陷阱供出题参考）
- 陷阱1: 间接寻址EA=内存内容而非形式地址A
- 陷阱2: 相对寻址EA=(PC)+A，PC为当前指令地址或下一条指令地址需明确
- 陷阱3: 寄存器寻址与寄存器间接寻址的区分
- 陷阱4: 基址与变址公式形式相同但语义不同

### 参考经验摘要
- 历史模式: 计算型——给寄存器/内存初值，逐一计算各寻址方式EA（408经典考法）
- 难度锚点: K3=3主导（固定流程多步推演），K4=3辅助（间接寻址/PC陷阱）
- 典型陷阱: 间接寻址读内存取EA、PC当前值、寄存器间接vs直接
