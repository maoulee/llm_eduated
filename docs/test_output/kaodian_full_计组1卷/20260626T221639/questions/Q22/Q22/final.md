## 题目

某计算机采用16位地址空间（地址范围 0x0000～0xFFFF），按字编址，机器字长16位。指令中形式地址 **A** 以十六进制给出。系统中有以下寄存器和内存状态：

| 名称 | 值（十六进制） | 说明 |
|------|---------------|------|
| 形式地址 A | 0x3C | 指令字段中给出的形式地址 |
| 基址寄存器 R₀ | 0x28 | 基址寻址使用 |
| 变址寄存器 R₁ | 0x50 | 变址寻址使用 |
| 通用寄存器 R₂ | 0x5A | 寄存器间接寻址使用 |
| 程序计数器 PC | 0x12 | 取本条指令后 PC 的值（已指向下一条指令） |

内存单元内容如下：

| 内存地址 | 该单元内容（十六进制） |
|---------|----------------------|
| 0x3C    | 0x7E                 |

> **寻址约定：**
> - **直接寻址**：EA = A
> - **间接寻址**：EA = 内存地址 A 处所存储的内容，即 EA = (A)
> - **寄存器间接寻址**：EA = 指定寄存器的内容，即 EA = (R₂)
> - **基址寻址**：EA = (R₀) + A
> - **变址寻址**：EA = (R₁) + A
> - **相对寻址**：EA = (PC) + A，其中 PC 为取本条指令后已更新的值

### 第1问（2分）

分别计算以下两种寻址方式的有效地址 EA（用十六进制表示）：

（1）直接寻址
（2）间接寻址

### 第2问（2分）

分别计算以下两种寻址方式的有效地址 EA（用十六进制表示）：

（1）寄存器间接寻址（使用 R₂）
（2）基址寻址（使用 R₀，形式地址 A）

### 第3问（2分）

分别计算以下两种寻址方式的有效地址 EA（用十六进制表示）：

（1）变址寻址（使用 R₁，形式地址 A）
（2）相对寻址（使用 PC，形式地址 A）

## 参考答案

**第1问**
- （1）直接寻址：EA = **0x3C**
- （2）间接寻址：EA = **0x7E**

**第2问**
- （1）寄存器间接寻址：EA = **0x5A**
- （2）基址寻址：EA = **0x64**

**第3问**
- （1）变址寻址：EA = **0x8C**
- （2）相对寻址：EA = **0x4E**

## 解析

### 第1问（2分）

**（1）直接寻址**

EA = A = 0x3C

**（2）间接寻址**

EA = (A) = Mem[A] = Mem[0x3C] = 0x7E

间接寻址链仅一跳：Mem[A] 的值本身即为有效地址，不再进行二次间接。

### 第2问（2分）

**（1）寄存器间接寻址（使用 R₂）**

EA = (R₂) = R₂ = 0x5A

**（2）基址寻址（使用 R₀，形式地址 A）**

EA = (R₀) + A = 0x28 + 0x3C = 0x64

### 第3问（2分）

**（1）变址寻址（使用 R₁，形式地址 A）**

EA = (R₁) + A = 0x50 + 0x3C = 0x8C

**（2）相对寻址（使用 PC，形式地址 A）**

EA = (PC) + A = 0x12 + 0x3C = 0x4E

其中 PC 取题中给定的"取本条指令后已更新的值"。

### 结果汇总

| 寻址方式 | 计算公式 | EA（十六进制） |
|---------|---------|--------------|
| 直接寻址 | EA = A | **0x3C** |
| 间接寻址 | EA = Mem[A] = Mem[0x3C] | **0x7E** |
| 寄存器间接寻址 | EA = R₂ | **0x5A** |
| 基址寻址 | EA = R₀ + A = 0x28 + 0x3C | **0x64** |
| 变址寻址 | EA = R₁ + A = 0x50 + 0x3C | **0x8C** |
| 相对寻址 | EA = PC + A = 0x12 + 0x3C | **0x4E** |

6种寻址方式的 EA 互不相同（0x3C、0x7E、0x5A、0x64、0x8C、0x4E），每种寻址方式可独立区分；所有 EA 均在地址空间范围 [0x0000, 0xFFFF] 内，地址合法。
