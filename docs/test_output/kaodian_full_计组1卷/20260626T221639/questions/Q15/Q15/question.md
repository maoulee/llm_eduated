# 中断处理中 PC 的保护与恢复

## 题干

某计算机系统中，CPU 正在执行用户程序。当键盘输入设备通过中断请求线向 CPU 发出可屏蔽中断请求时，CPU 在当前指令执行完毕后响应该中断，进入中断响应阶段。

在上述中断响应过程中，CPU 需要保存被中断程序的断点（即程序计数器 PC 的当前值，也称返回地址），以便中断返回后能正确恢复执行。关于**保存断点（PC）这一操作由谁、在哪个阶段完成**，下列说法中正确的是：

## 选项

A. 由中断隐指令（硬件自动）在中断响应阶段完成保存断点

B. 由中断服务程序（软件）在执行阶段完成保存断点

C. 由用户程序在检测到中断请求后自行保存断点

D. 由 CPU 执行一条类似于函数调用（CALL）的指令来保存断点

## 设计说明

- **考点**：中断隐指令的职责——中断响应阶段由硬件自动完成"关中断、保存断点、引出中断服务程序"三项操作；保存断点（PC）属于中断隐指令的职责，不由软件完成。
- **核心辨析点**：保存 PC 的主体是"中断隐指令（硬件自动）"还是"中断服务程序（软件）"。这是 408 高频陷阱，约 30%–40% 考生会误选"中断服务程序保存"。
- **教师批注对应**：考察角度 = 中断处理中 PC 的保护与恢复，聚焦"谁保存断点"。
- **干扰项设计**：
  - **B**（最常见错误路径）：误认为保存 PC 属于中断服务程序的软件职责——混淆了"中断隐指令保存断点"与"中断服务程序保存通用寄存器/现场"。
  - **C**：误认为用户程序自身负责保存断点——对中断机制完全错误的理解（用户程序无法感知中断时序）。
  - **D**：误认为中断保存断点与函数调用（CALL/RET）机制完全相同——忽略中断隐指令的特殊性（硬件自动、不可编程、发生在响应阶段而非执行阶段）。

## 通过条件（本题成立 ⇔ 以下约束被满足）

本题答案为知识回忆型概念辨析题，只需满足：

1. **题干无歧义**：场景描述清楚（外部中断、中断响应阶段），设问明确指向"保存断点/PC 的主体"，不存在两种合理解读。
2. **选项无事实错误导致歧义**：正确选项 A 的表述在计算机组成原理教材中唯一正确；B/C/D 各自描述了一个真实的典型错误认知，不出现"两个选项都对"或"正确选项本身也有事实错误"的情况。
3. **4 选项互异**：A/B/C/D 四个选项指向的操作主体（中断隐指令 / 中断服务程序 / 用户程序 / CALL 类指令）互不相同，不存在语义重叠。
