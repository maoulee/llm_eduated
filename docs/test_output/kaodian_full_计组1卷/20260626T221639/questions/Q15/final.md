## 题目

某计算机系统中，CPU 正在执行用户程序。当键盘输入设备通过中断请求线向 CPU 发出可屏蔽中断请求时，CPU 在当前指令执行完毕后响应该中断，进入中断响应阶段。

在上述中断响应过程中，CPU 需要保存被中断程序的断点（即程序计数器 PC 的当前值，也称返回地址），以便中断返回后能正确恢复执行。关于**保存断点（PC）这一操作由谁、在哪个阶段完成**，下列说法中正确的是：

A. 由中断隐指令（硬件自动）在中断响应阶段完成保存断点

B. 由中断服务程序（软件）在执行阶段完成保存断点

C. 由用户程序在检测到中断请求后自行保存断点

D. 由 CPU 执行一条类似于函数调用（CALL）的指令来保存断点

## 参考答案

**A. 由中断隐指令（硬件自动）在中断响应阶段完成保存断点**

## 解析

### 知识点：中断隐指令的三项操作

CPU 响应中断时，由**中断隐指令（硬件自动）**在中断**响应阶段**完成以下三项操作：

1. **关中断**——防止在保存断点过程中被新的中断打断。
2. **保存断点**——保存被中断程序的 PC（返回地址），以便中断返回后能正确恢复执行。
3. **引出中断服务程序**——将中断服务程序的入口地址装入 PC。

中断隐指令的三个本质特征：
- 执行主体：**硬件自动**（非软件、非用户程序）。
- 所属阶段：**中断响应阶段**（非执行阶段）。
- 可编程性：**不可编程**（不是指令系统中供程序员使用的指令，而是在中断响应时由硬件自动完成的微操作序列）。

### 逐选项判定

| 选项 | 操作主体 | 判定 | 理由 |
|------|---------|------|------|
| **A** | 中断隐指令（硬件自动） | **✓ 正确** | 中断隐指令（硬件自动）在中断响应阶段完成保存断点，与中断隐指令三项操作（关中断/保存断点/引出中断服务程序）一致。 |
| **B** | 中断服务程序（软件） | ✗ 错误 | 保存断点（PC）由中断隐指令（硬件）完成，而非中断服务程序（软件）。中断服务程序保存的是通用寄存器/现场（即"保护现场"），**不是断点 PC**。 |
| **C** | 用户程序 | ✗ 错误 | 用户程序无法感知中断时序，也不负责保存断点。保存断点是硬件自动完成的。 |
| **D** | CALL 类指令（函数调用） | ✗ 错误 | 中断保存断点由中断隐指令（硬件自动、不可编程）完成，并非 CPU 执行 CALL 类指令。中断隐指令发生在**响应阶段**，不是执行阶段。 |

### 干扰项分析

- **B（最常见错误路径）**：混淆了"中断隐指令保存断点"与"中断服务程序保存通用寄存器/现场"。约 30%–40% 考生会误选 B，因为两者都是"保存"，但保存的对象和执行主体完全不同。
- **C**：对中断机制完全错误的认知——用户程序在 CPU 响应中断时已被暂停，不可能自行感知中断并保存断点。
- **D**：将中断保存断点与函数调用（CALL/RET）机制完全等同——函数调用是软件（指令）行为，发生在执行阶段；中断保存断点是硬件自动行为，发生在响应阶段。
