# 扩展操作码计算——零地址指令最大条数

## 题干

某计算机采用 16 位定长指令格式，采用扩展操作码技术。地址码长度为 **4 位**。已知：

- 该机设有 **3 条二地址指令**；
- 设有 **8 条一地址指令**；
- 其余编码空间全部用于零地址指令。

请计算：**零地址指令最多有多少条？**（填写一个正整数）

## 参数说明

| 参数 | 含义 | 取值 |
|------|------|------|
| L | 指令总长度 | 16 位 |
| addr_len | 地址码位数 | 4 位 |
| N2 | 二地址指令条数 | 3 |
| N1 | 一地址指令条数 | 8 |

## 答案格式

一个正整数。

## 场景规则（通过条件）

本题成立需满足以下参数间约束（与具体答案值无关，换参数仍成立）：

1. **三级预留均参与**：零地址指令最大条数的计算必须经过二地址→一地址→零地址三级逐级扩展，不可退化为单级或双级。即 `L - 2×addr_len ≥ 4`（基础操作码至少 4 位）且 `N2 > 0` 且 `N1 > 0` 且三级各自留有非零剩余编码空间。

2. **逐级扩展公式一致性**：
   - 二地址占用 N2 条，剩余编码数 `R2 = 2^(L - 2×addr_len) - N2`，须 `R2 > 0`。
   - 一地址可分配空间 = `R2 × 2^addr_len`，占用 N1 条，剩余编码数 `R1 = R2 × 2^addr_len - N1`，须 `R1 > 0`。
   - 零地址最大条数 = `R1 × 2^addr_len`，须为正整数。

3. **答案唯一且非平凡**：在给定参数下，零地址指令最大条数唯一确定，且不为零、不为负。

4. **公式正确性可验证**：最终答案满足 `answer == ((2^(L - 2*addr_len) - N2) * 2^addr_len - N1) * 2^addr_len`。
