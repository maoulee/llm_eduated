## 考点
- **扩展操作码编码原理**：理解扩展操作码的预留编码逻辑——从短操作码出发，逐级为更长格式预留编码空间，最终计算零地址指令的最大可用条数。
- **编码空间计算**：给定指令总长度和各地址码位数，推导各级操作码可用位数及对应指令条数。

## 难度目标
- **K1=2**：需要知道扩展操作码的基本定义（操作码字段从短到长扩展），属于408基础名词，概念模糊也能顺着思路推导。
- **K2=3**：需代入公式计算（如 $2^{n}$ 的幂次运算，可能涉及多级减法），数字不一定全为友好值。
- **K3=3**：需按固定流程走 3-5 步——从二地址→一地址→零地址逐级预留并减去已用编码，路径唯一但需多步串行。
- **K4=2**：存在常规注意点——扩展操作码计算中"每一级预留的编码不能被本级使用"是基本规则，408考生基本不会踩坑。
- **K5=1**：单一知识点内部解决，不涉及其他子系统。

## 考察模式
**计算型——扩展操作码计算**（与 slot examination_mode 一致）。
给定指令长度、各地址码位数（或各类指令条数），要求推导零地址指令的最大条数。这是408经典考法，直接考查学生对编码空间逐级预留逻辑的理解和运算能力。

## 出题要求
- **题型**：填空题，2分。
- **条件数**：2-3个显式条件（指令总长度、各地址码位数或各类已知指令条数）。
- **条件设计原则**：给出指令总长度及二地址/一地址指令的数量（或对应操作码位数），要求学生推算零地址指令的最大条数。参数应使得计算过程涉及至少两级预留（二地址→一地址→零地址），避免单级退化。
- **参数取值范围要求**：
  - 指令总长度：16~32位（常见为16位）。
  - 二地址指令条数：需小于该级操作码空间的一半，保证有预留。
  - 一地址指令条数：需小于前一级预留空间转换后的全部容量。
  - 零地址指令为求解目标，不需给定。
  - 所有参数须保证最终零地址指令最大条数为正整数，且计算过程不退化（即三级均需参与计算）。

## 子问题规划
- 填空题为单一问，无子问题拆分。
- **问题类型**：计算型。
- **考察目标**：给定指令格式参数，计算零地址指令最大条数。
- **分值**：2分（填空，一个空）。

## 参数约束
- **指令总长度 L**：16位（固定或16~24位范围）。
- **各地址码位数**：每个地址码4~8位，需满足 L ≥ 二地址操作码位数 + 2×地址码位数。
- **二地址指令条数 $N_2$**：取值使得 $0 < N_2 < 2^{L-2\times addr\_len}$（即不超过该级全部操作码编码数），建议取该空间的1/4~3/4，保证有足够预留。
- **一地址指令条数 $N_1$**：取值使得 $0 < N_1 < (2^{L-2\times addr\_len} - N_2) \times 2^{addr\_len}$，即不超过一级预留空间能支撑的全部编码。
- **零地址指令最大条数**（求解目标）：$(2^{L-2\times addr\_len} - N_2) \times 2^{addr\_len} - N_1) \times 2^{addr\_len}$，须为正整数。
- **可调自由度**：L、地址码位数、$N_2$、$N_1$ 均可由 Question Agent 在约束范围内自由选择。

## 参考经验
- **历史模式**：扩展操作码计算是408高频考法，典型形式为"某机器指令长度为16位，地址码6位，二地址指令有K条，一地址指令有M条，问零地址指令最多多少条"。
- **难度锚点**：K3为主导维度（多步串行推导），K2为辅助（幂次运算），整体难度2。
- **典型陷阱**：学生易忽略"每级预留编码不可被本级使用"这一约束，直接用总编码空间减去已知指令数而忘记乘以对应级数的地址码扩展倍数。
