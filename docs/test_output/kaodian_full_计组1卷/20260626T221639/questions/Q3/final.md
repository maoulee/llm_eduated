## 题目
在 8 位字长（含 1 位符号位、7 位数值位）的原码表示中，十进制真值 **−75** 的原码表示为下列哪一项？

A. 11001011

B. 01001011

C. 10110101

D. 11000011


## 求解过程
### 第 1 步：取绝对值并转二进制

|−75| = 75

将 75 转换为 7 位二进制：

75 = 64 + 8 + 2 + 1 = 2⁶ + 2³ + 2¹ + 2⁰

$$75_{(10)} = 1001011_{(2)}$$

### 第 2 步：确定符号位

−75 为负数 → 符号位 = **1**

### 第 3 步：组合原码

原码 = 符号位 + 数值位 = **1** + **1001011** = **11001011**

**答案 A = 11001011**

---


## 答案
**A. 11001011**
