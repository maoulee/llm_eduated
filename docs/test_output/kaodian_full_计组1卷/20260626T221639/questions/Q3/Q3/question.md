# 题目：给定真值求原码（反向考法）

## 题干

在 8 位字长（含 1 位符号位、7 位数值位）的原码表示中，十进制真值 **−75** 的原码表示为下列哪一项？

A. 11001011

B. 01001011

C. 10110101

D. 11000011

## 设计意图

- **考察方向**：给定十进制真值，求其原码表示——反向考法（非"给定原码读真值"，而是"给定真值写原码"）。
- **K2 主导**：需要完成"十进制→二进制绝对值转换 + 负数符号位处理"一步计算，路径唯一但非平凡（绝对值 75 非纯 2 的幂，转换有出错空间）。
- **干扰项设计**：
  - B 考"符号位遗漏/取反"——学生忘记负数符号位应为 1，写成正数格式。
  - C 考"原码与补码混淆"——学生误用补码规则求编码，得到不同的 8 位串。
  - D 考"绝对值二进制转换错误"——学生在 75 的二进制展开中某位算错。

## 参数

| 参数 | 值 | 说明 |
|------|----|------|
| 机器字长 | 8 位 | 含 1 位符号位 + 7 位数值位 |
| 十进制真值 | −75 | 负数；绝对值 75 非纯 2 的幂 |
| 绝对值范围检查 | 75 ≤ 127 | 在 8 位原码可表示范围内 |

## 场景规则（通过条件）

本题成立需要满足以下参数间约束（与具体答案值无关，换参数仍成立）：

1. **表示范围合法**：|−75| = 75 ≤ 2^(8−1) − 1 = 127，即真值在 8 位原码可表示范围内。若给定真值超出范围则题目不成立。
2. **绝对值非纯 2 的幂**：75 不是 2 的整数次幂（保证二进制转换有非零计算量，干扰项 D 有出错空间）。
3. **4 选项互异**：A/B/C/D 四个 8 位二进制串各不相同（exec 计算后无碰撞）。
4. **正确值唯一确定**：在给定参数下，−75 的 8 位原码唯一确定，A = 该值；不存在两个选项同时正确。
5. **干扰项对应声明错误类型**：
   - B = 符号位取 0（正数格式），数值位与 A 相同 → 与 A 仅符号位不同。
   - C = 按补码规则对 −75 转换得到的 8 位编码（与原码结果不同）。
   - D = 绝对值 75 的二进制转换中存在位错误的结果（与 A 的数值位至少有一位不同）。
6. **干扰项有合理性**：B/C/D 均为同类题型常见误算的真实产物，非荒谬值。

## 输出项要求（给 write_gen）

- 正确答案 A：对 −75 求 8 位原码，输出 8 位二进制串。
- 干扰项 B：将符号位置 0，数值位与 A 相同。
- 干扰项 C：对 −75 按补码规则转换，输出 8 位补码串。
- 干扰项 D：对 |75| 的二进制表示制造一个确定位错误（如某位翻转），再补符号位 1。
- 所有选项以 8 位二进制串呈现。
