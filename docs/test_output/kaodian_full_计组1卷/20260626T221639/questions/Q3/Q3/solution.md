# 解题过程：给定真值 −75，求 8 位原码表示

## 参数

| 参数 | 值 |
|------|----|
| 机器字长 | 8 位（1 位符号位 + 7 位数值位） |
| 十进制真值 | −75 |
| 绝对值 | 75 |
| 8 位原码最大可表示绝对值 | 2⁷ − 1 = 127 |

## 求解过程

### 第 1 步：取绝对值并转二进制

|−75| = 75

将 75 转换为 7 位二进制：

75 = 64 + 8 + 2 + 1 = 2⁶ + 2³ + 2¹ + 2⁰

$$75_{(10)} = 1001011_{(2)}$$

### 第 2 步：确定符号位

−75 为负数 → 符号位 = **1**

### 第 3 步：组合原码

原码 = 符号位 + 数值位 = **1** + **1001011** = **11001011**

**答案 A = 11001011**

---

## 各选项分析

| 选项 | 二进制串 | 说明 | 正误 |
|------|----------|------|------|
| **A** | **11001011** | −75 的 8 位原码（符号位 1 + |75| = 1001011） | ✅ 正确 |
| B | 01001011 | 符号位取 0（正数格式），数值位与 A 相同 | ❌ 符号位错误 |
| C | 10110101 | 按补码规则转换：2⁸ + (−75) = 181 = 10110101 | ❌ 原码/补码混淆 |
| D | 11000011 | |75| 二进制 bit3（从右起第 4 位）翻转：1001011 → 1000011，补符号位 1 | ❌ 数值位转换错误 |

### 干扰项详解

**B（01001011）— 符号位遗漏：**
数值位 1001011 与 A 完全相同，仅符号位取 0（误写为正数原码格式）。负数原码的符号位必须为 1。

**C（10110101）— 补码混淆：**
误将 −75 按补码规则转换。−75 的 8 位补码 = 2⁸ + (−75) = 256 − 75 = 181 = 10110101，与原码 11001011 不同。原码数值位直接取绝对值，不取反加一。

**D（11000011）— 绝对值二进制转换错误：**
|75| 的正确二进制为 1001011。本选项中 bit3（从右起第 4 位，值为 2³ = 8）被错误地从 1 翻转为 0，数值位变为 1000011（= 67 ≠ 75），再补符号位 1 得到 11000011。

---

## 场景规则验证

| 规则 | 验证结果 |
|------|----------|
| ① 表示范围合法 | \|−75\| = 75 ≤ 127 ✅ |
| ② 绝对值非纯 2 的幂 | 75 不是 2 的整数次幂 ✅ |
| ③ 4 选项互异 | {11001011, 01001011, 10110101, 11000011} 共 4 个不同值 ✅ |
| ④ 正确值唯一 | A = 11001011 唯一确定 ✅ |
| ⑤ B 与 A 仅符号位不同 | A[1:] = B[1] = 1001011，符号位 1≠0 ✅ |
| ⑤ C 按补码规则 | C = 10110101 ≠ A ✅ |
| ⑤ D 数值位与 A 至少一位不同 | A 数值位 1001011 ≠ D 数值位 1000011 ✅ |

## 最终答案

**A. 11001011**
