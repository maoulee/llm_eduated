# 概念题解析

## 第 1 题解析

**答案**：B

**解析**：
- B 正确：冯·诺依曼结构以存储器为中心，指令和数据存放在同一个存储器中，按地址访问，这是"存储程序"的核心体现。
- A 错误：冯·诺依曼结构以存储器（而非运算器）为中心，且指令和数据共用同一存储器（不分离存储是哈佛结构的特点）。
- C 错误：存储程序思想是指程序和数据预先存入存储器后自动执行，而非运行时逐条手动输入。
- D 错误：冯·诺依曼结构的基本组成确实包含运算器、控制器、存储器和 I/O 设备，但"程序不能被修改"是错误的——存储程序的关键优势之一恰恰是程序可以像数据一样被读取和修改。

## 第 2 题解析

**答案**：B

**解析**：
- B 正确：编译程序（Compiler）将高级语言源程序整体翻译成目标程序，翻译完成后目标程序可直接运行，不依赖源程序。
- A 错误：汇编程序（Assembler）是将汇编语言源程序翻译成机器语言，而非高级语言源程序。
- C 错误：解释程序（Interpreter）是逐条解释执行源程序，不生成独立的目标程序，运行速度较慢。
- D 错误：反汇编程序是将机器语言程序转换为汇编语言程序，方向相反，不用于高级语言翻译。

## 第 3 题解析

**答案**：B

**解析**：
- B 正确：n 位补码（含 1 位符号位）的表示范围为 -2^(n-1) ～ +2^(n-1)-1，当 n=8 时为 -128 ～ +127。
- A 错误：-127 ～ +127 是原码和反码的表示范围，补码比它们多表示一个最小负数 -128。
- C 错误：+128 超出了 8 位补码的正数范围（最大为 +127）。
- D 错误：-127 是原码/反码的下界，+128 超出上界，两个边界都错。

## 第 4 题解析

**答案**：C

**解析**：
- C 正确：存储层次结构的核心目标是利用不同层次存储器的性能差异，在成本合理的条件下使整体速度接近 Cache、容量接近辅存，性价比最优。
- A 错误：扩大容量是辅存的功能之一，但不是层次化结构的主要目的，主要目的是速度-容量-成本的整体平衡。
- B 错误：降低功耗和简化设计并非层次结构的目标。
- D 错误：不同层次的访问方式并不统一（如主存按地址访问、磁盘按块/扇区访问），CPU 的访存逻辑也并非因此简化。

## 第 5 题解析

**答案**：B

**解析**：
- B 正确：DRAM 刷新按行进行，由刷新控制电路自动完成，刷新期间 CPU 不参与控制，只需在刷新周期内让出总线。
- A 错误：DRAM 的刷新不是由 CPU 控制的，而是由专门的刷新逻辑电路定时控制；虽然读出时有"再生"效应，但刷新是独立的定时操作。
- C 错误：DRAM 的电容会不断泄漏电荷，必须在刷新周期内（通常 2ms）反复刷新才能保持数据，不能只刷新一次。
- D 错误：DRAM 刷新是按行进行的，与行地址直接相关，而非按列逐位。

## 第 6 题解析

**答案**：B

**解析**：
- B 正确：指令寄存器（IR）用于存放当前从主存取出的指令，供指令译码器译码和执行部件使用。
- A 错误：程序计数器（PC）存放的是下一条要执行的指令的地址，而非指令本身。
- C 错误：存储器地址寄存器（MAR）存放的是 CPU 要访问的主存单元地址，不是指令。
- D 错误：程序状态字寄存器（PSW）存放的是 CPU 的工作状态和标志位（如进位、溢出等），不是指令。

## 第 7 题解析

**答案**：C

**解析**：
- C 正确：指令周期定义为 CPU 从主存取出一条指令并执行完毕所需的全部时间。
- A 错误：时钟周期是计算机最基本的时钟信号周期，是最小的时间单位，通常小于机器周期。
- B 错误：机器周期通常指完成一个基本操作（如访存）所需的时间，一个指令周期通常包含若干个机器周期。
- D 错误：微周期（微指令周期）是执行一条微指令所需的时间，是最小执行单位之一，远小于指令周期。

## 第 8 题解析

**答案**：B

**解析**：
- B 正确：链式查询方式只用很少几根控制线（总线请求、总线忙、总线许可），线路简单、易于扩充，但离控制器物理位置越远的设备优先级越低（"排队"效应）。
- A 错误：链式查询中设备优先级与物理位置有关，不是公平的（公平的是计数器定时查询或独立请求方式）。
- C 错误：各设备拥有独立的请求线和许可线是独立请求方式的特点，而非链式查询。
- D 错误：任何仲裁方式都需要控制信号线，"无需任何控制信号线"的描述不成立。

## 第 9 题解析

**答案**：C

**解析**：
- C 正确：DMA 方式通过 DMA 控制器直接控制主存与高速外设之间的数据交换，以数据块为传输单位，CPU 只在传输开始（预处理）和结束（后处理）时介入，传输过程中 CPU 不干预。
- A 错误：DMA 方式适用于高速外设（如磁盘）的大批量数据传输，低速字符设备通常用中断方式。
- B 错误：DMA 方式在传输开始和结束时仍需要 CPU 参与（初始化参数、处理中断等），不能说"完全不需要任何干预"。
- D 错误：DMA 方式的数据传输速率高于中断方式，因为数据传输不需要 CPU 逐字节参与。

## 第 10 题解析

**答案**：运算器、控制器

**解析**：
CPU 的核心组成是运算器（ALU 及相关寄存器）和控制器（产生控制信号的部件）。运算器负责算术运算和逻辑运算，控制器负责协调和控制各部件按指令要求工作。

## 第 11 题解析

**答案**：触发器、电容

**解析**：
SRAM（静态随机存储器）利用双稳态触发器存储信息，只要不断电就能稳定保持数据，不需要刷新，但集成度较低、功耗较大。DRAM（动态随机存储器）利用 MOS 管栅极电容上的电荷来存储信息，由于电容会自然泄漏电荷，必须定期刷新（通常间隔 2ms）才能维持数据正确。

## 第 12 题解析

**答案**：1、8、23

**解析**：
IEEE 754 单精度浮点数共 32 位，最高位为符号位（S），占 1 位；中间为阶码（E），采用移码表示，占 8 位；最低位为尾数（M），采用隐含最高位 1 的规格化表示，占 23 位。

## 第 13 题解析

**答案**：组合逻辑（硬布线）、微程序

**解析**：
控制器按实现方式分为两种：组合逻辑控制器（也称硬布线控制器），用逻辑门电路直接组合产生控制信号，速度快但设计复杂、不易修改；微程序控制器，将控制信号编成微指令存放在控制存储器中，通过执行微程序来产生控制信号，设计规整、易于修改和扩充，但速度相对较慢。
