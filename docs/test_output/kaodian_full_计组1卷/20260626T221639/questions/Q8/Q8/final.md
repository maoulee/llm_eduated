# 题干

某存储器芯片有 **16 根地址线**、**8 根数据线**，按字节编址。该芯片的最大存储容量为多少？

A. 64 KB
B. 512 KB
C. 512 B
D. 32 B

---

## 场景规则（供 gen.py 生成 / assert 校验）

### 基本参数

| 参数 | 符号 | 初始值 |
|------|------|--------|
| 地址线根数 | n | 16 |
| 数据线位数 | m | 8 |

### 容量推导规则

1. 寻址单元数 = `2 ** n`。
2. 每个单元的位宽 = `m` bit。
3. 按字节编址 → 每地址 1 字节 → 总容量（字节）= `2 ** n × m // 8`。
4. 最终容量须可换算为整数 KB 或 MB。

### 选项错误类型（仅描述，不含具体数值）

| 选项 | 错误类型 | 派生公式（参数化） |
|------|----------|---------------------|
| A | 正确结果 | `2**n × m // 8` 字节 |
| B | 未将 bit 转换为 byte（bit 当 byte 用） | `2**n × m` 字节（漏除以 8） |
| C | 地址线与数据线角色互换 | `2**m × n // 8` 字节 |
| D | 2^n 误算为 n×2 | `n × 2 × m // 8` 字节 |

---

## 通过条件（可机检）

以下条件须全部满足，题目方成立（数值由 gen.py exec 后校验）：

1. **四选项互异**：`len({A_val, B_val, C_val, D_val}) == 4`（四个选项的数值各不相同）。
2. **正确答案唯一确定**：`A_val == 2**n × m // 8`，且 A_val 能整除换算为 KB（`A_val % 1024 == 0`）。
3. **干扰项 B 对应"漏除 8"错误**：`B_val == 2**n × m`（即 `B_val == A_val × 8`）。
4. **干扰项 C 对应"地址/数据线互换"错误**：`C_val == 2**m × n // 8`。
5. **干扰项 D 对应"2^n→n×2 误算"错误**：`D_val == n × 2 × m // 8`。
6. **干扰项合理性**：每个干扰项值为正数且与正确答案数量级相近（非荒谬值）。


## 求解过程
# 解题过程

## 题干

某存储器芯片有 **16 根地址线**、**8 根数据线**，按字节编址。该芯片的最大存储容量为多少？

A. 64 KB　　B. 512 KB　　C. 512 B　　D. 32 B

## 参数

| 参数 | 符号 | 值 |
|------|------|-----|
| 地址线根数 | n | 16 |
| 数据线位数 | m | 8 |

## 推导过程

1. **寻址单元数** = 2^n = 2^16 = **65536**（16 根地址线可寻址 65536 个存储单元）。
2. **总位数** = 寻址单元数 × 数据线位数 = 65536 × 8 = **524288 bit**。
3. **按字节编址**：每地址 1 字节（1 B = 8 bit），所以总容量（字节）= 总位数 ÷ 8 = 524288 ÷ 8 = **65536 B**。
4. **换算**：65536 B ÷ 1024 = **64 KB**。

## 各选项分析

| 选项 | 数值 | 正确值 | 分析 |
|------|------|--------|------|
| **A** | **65536 B = 64 KB** | 65536 B | ✅ **正确**。2^16 × 8 ÷ 8 = 65536 B = 64 KB。 |
| B | 524288 B = 512 KB | 65536 B | ❌ 漏除以 8（bit 当 byte 用）。只算了 2^16 × 8 = 524288，未把 bit 换算为 byte。B 是正确值的 8 倍。 |
| C | 512 B | 65536 B | ❌ 地址线与数据线角色互换。误把 m（数据线位数 8）当地址线根数、n（地址线根数 16）当数据线位数，算成 2^8 × 16 ÷ 8 = 512 B。 |
| D | 32 B | 65536 B | ❌ 2^n 误算为 n×2。把 2^16 误算成 16×2 = 32，再算 16 × 2 × 8 ÷ 8 = 32 B。 |

## 答案

**A. 64 KB**
