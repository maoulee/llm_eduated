# 解题过程：补码加减运算与溢出判断

## 基本信息

- 字长 n = 8，补码定点整数，表示范围 [−128, +127]
- [A]补 = 0x9C，A = −100
- [B]补 = 0xD8，B = −40

---

## 第(1)题：计算 [A + B]补 并判断溢出

### 运算过程

真实值验证：A + B = (−100) + (−40) = **−140**，超出表示范围 [−128, +127]，预期溢出。

**模 2⁸ 加法**：

```
  0x9C
+ 0xD8
-------
  0x174    ← 最高位向第 9 位进位
```

截断到 8 位（mod 256）：0x174 & 0xFF = **0x74**

### 溢出判断（两种方法互相印证）

**① 双符号位法（变形补码法）**

将 8 位补码符号扩展为双符号位：

| 操作数 | 变形补码（9~10 位） |
|--------|---------------------|
| [A]补 = 0x9C | 1_1001_1100（符号扩展，补码 0x19C = 412） |
| [B]补 = 0xD8 | 1_1101_1000（符号扩展，补码 0x1D8 = 472） |

```
  1_1001_1100   (0x19C = 412)
+ 1_1101_1000   (0x1D8 = 472)
─────────────
 11_0111_0100   (加法原始值 = 0x374 = 884)
```

截断到 9 位双符号位域（mod 2⁹ = 取低 9 位）：0x374 & 0x1FF = **0x174**，即 `1_0111_0100`。

双符号位 = **10**（s_hi = 1, s_lo = 0，两位不一致）。

> 双符号位 `10`：符号位高位为 1、低位为 0，两者不一致 → **溢出**。
> （`10` 表示两个负数相加结果本应为负，但符号位出现 `10` → 负溢出/下溢）

**② 进位判别法**

- 最高位进位 Cs = 1（0x9C + 0xD8 向第 9 位进位）
- 次高位进位 Cp = 0（低 7 位 0x1C + 0x58 = 0x74，未向 bit7 进位）
- Cs ⊕ Cp = 1 ⊕ 0 = **1 → 溢出**

两种方法结论一致。

### 结果

$$[A + B]_补 = \boxed{0x74}$$

**溢出：是**（两个负数相加，真实值 −140 超出下界 −128，截断后变为正数 +116，符号翻转）

---

## 第(2)题：计算 [A − B]补 并判断溢出

### 第一步：求 [−B]补

$$[−B]_补 = \sim[B]_补 + 1 = \sim\text{0xD8} + 1 = \text{0x27} + 1 = \boxed{\text{0x28}}$$

验证：[−B]补 + [B]补 = 0x28 + 0xD8 = 0x100，mod 2⁸ = 0 ✓（加法逆元关系成立）

### 第二步：[A]补 + [−B]补

真实值验证：A − B = (−100) − (−40) = **−60**，在表示范围 [−128, +127] 内，预期不溢出。

**模 2⁸ 加法**：

```
  0x9C   ([A]补)
+ 0x28   ([−B]补)
-------
  0x0C4  ← 无向第 9 位的进位（最高位进位 = 0）
```

截断到 8 位：**0xC4**（十进制补码解释为 −60，与真实值一致 ✓）

### 溢出判断（两种方法互相印证）

**① 双符号位法（变形补码法）**

| 操作数 | 变形补码 |
|--------|---------------------|
| [A]补 = 0x9C | 1_1001_1100（0x19C = 412） |
| [−B]补 = 0x28 | 0_0010_1000（0x028 = 40） |

```
  1_1001_1100
+ 0_0010_1000
─────────────
  1_1100_0100
```

双符号位 = **11 → 11**（符号位为 `11`）。

> 双符号位 `11`：两位一致 → **不溢出**（结果仍为负，与负数+正数的结果符号一致）

**② 进位判别法**

- 最高位进位 Cs = 0（0x9C + 0x28 = 0xC4，无向第 9 位进位）
- 次高位进位 Cp = 0（低 7 位 0x1C + 0x28 = 0x44，未向 bit7 进位）
- Cs ⊕ Cp = 0 ⊕ 0 = **0 → 不溢出**

两种方法结论一致。

### 结果

$$[−B]_补 = \boxed{\text{0x28}}, \qquad [A − B]_补 = \boxed{\text{0xC4}}$$

**溢出：否**（真实值 −60 在 [−128, +127] 内，结果正确为负数）

---

## 总结

| | 真实值 | 在范围内？ | 补码结果 | 溢出 |
|------|--------|-----------|----------|------|
| 第(1)题 A+B | −140 | 否（超下界） | 0x74 (+116) | **是** |
| 第(2)题 A−B | −60 | 是 | 0xC4 (−60) | **否** |

两题形成"一溢一不溢"的对照：
- 第(1)题两个负数相加，真实结果 −140 超出下界，截断后符号由负变正 → 溢出。
- 第(2)题负数减负数（等价于加正数），真实结果 −60 仍在范围内 → 不溢出。

两种溢出判断方法（双符号位法、进位判别法）对两题均给出一致结论。
