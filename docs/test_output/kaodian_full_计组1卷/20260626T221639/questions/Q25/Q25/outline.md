## 考点
- **核心知识点**：补码加减运算（[A+B]补 和 [A-B]补 的计算）
  - 考察侧重点：给定两个十六进制补码，执行加法和减法运算，得到结果的补码表示
- **辅助知识点**：溢出判断
  - 考察侧重点：对加减运算结果进行溢出判断（采用符号位进位法或双符号位法），说明溢出/不溢出的理由
- **辅助知识点**：补码表示范围
  - 考察侧重点：理解 n 位补码的表示范围，溢出的本质是结果超出可表示范围

## 难度目标
| 维度 | 目标 | 达标理由 |
|------|------|----------|
| K1 | 2 | 需调用补码加减运算规则和溢出判断方法，属于408基础名词，但操作流程清晰，不需辨析易混概念 |
| K2 | 3 | 需进行十六进制补码的逐位运算和借位/进位处理，涉及非2幂次的具体数值计算 |
| K3 | 4 | 从补码读取到加法运算、减法转化（[-B]补求取）、减法运算、溢出判断，每问需3-5步流程，两问合计>5步 |
| K4 | 3 | 减法需先求[-B]补（包括符号位在内的逐位取反加1），这是明确陷阱点，漏做则全错；溢出判断需选对方法 |
| K5 | 2 | 单一知识点内部完成，不涉及其他子系统联动 |

整体难度：3（标准）。需实际计算补码加减并判断溢出，多步运算但路径唯一。

## 考察模式
**计算型——补码运算与溢出判断**

选择理由：
- 与 slot 的 examination_mode 一致
- 该模式直接考察学生对补码加减运算的实操能力，区分度高
- 计算过程可分步评分，适合6分简答题
- 溢出判断是高频考点，能测出学生是否真正理解补码运算机制

## 出题要求
- **题型**：简答题，6分
- **数据位宽**：8位补码（与分值匹配，避免过繁）
- **数据形式**：两个补码值以十六进制给出（如 A = x7B, B = x?）
- **条件数**：2个显式条件（A 和 B 的补码值），附加隐含条件（机器字长/位宽）
- **条件设计原则**：
  - 至少一个运算（加法或减法）应产生溢出，另一个不溢出，以全面考察溢出判断能力
  - 两个补码值应有明确的符号性（一正一负、或同号），使运算结果有实际意义
  - 数值不应全为2的幂次，避免过于简化

## 子问题规划
本题为简答题（非综合大题），设2个子问题：

### 第1问：加法运算与溢出判断（3分）
- **类型**：计算
- **考察目标**：计算 [A+B]补 并判断是否溢出
- **分值**：3分（结果2分 + 溢出判断及理由1分）
- **与后续关系**：独立于第2问，但共享相同输入数据

### 第2问：减法运算与溢出判断（3分）
- **类型**：计算
- **考察目标**：计算 [A-B]补 并判断是否溢出
- **分值**：3分（结果2分 + 溢出判断及理由1分）
- **与前置关系**：独立于第1问，共享相同输入数据；需先求 [-B]补 再执行加法

**依赖关系**：两问并行（共享输入数据，互不依赖）

## 参数约束
- **机器字长/位宽**：8位补码运算（n=8），表示范围 -128 ~ +127
  - 约束：必须在题干中明确位宽
- **补码值 A**：
  - 取值范围：8位补码表示范围内的十六进制值（0x80 ~ 0x7F）
  - 约束：A 应为负数（使加法场景更丰富），非平凡值
  - 自由度：Question Agent 可在负数补码中选取具体值
- **补码值 B**：
  - 取值范围：8位补码表示范围内的十六进制值（0x80 ~ 0x7F）
  - 约束：B 应为负数，且与 A 的和或差之一超出 [-128, +127] 范围以触发溢出
  - 自由度：Question Agent 选取具体值，但需保证至少一个运算溢出
- **参数间一致性约束**：
  - A+B 或 A-B 中至少一个超出 8 位补码表示范围 → 至少一个运算溢出
  - 另一个运算不溢出，形成对照
  - A 和 B 不应为 0 或 ±1 等平凡值

## 参考经验
- **考察模式**：补码加减运算 + 溢出判断是CO-2的标准考法，常以给定十六进制补码求加减结果的形式出现
- **难度锚点**：K3=4 反映多步运算（减法需转化、溢出需判断），K4=3 反映[-B]补求取的陷阱
- **典型陷阱**：
  - 减法运算中忘记先求 [-B]补，直接逐位相减
  - 溢出判断方法选择错误（如仅看进位而不看符号位变化）
  - 将十六进制直接当十进制运算，忽略补码的符号性
  - 特殊值 0x80（-128）的运算处理错误
