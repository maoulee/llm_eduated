# 题目：补码加减运算与溢出判断

## 题干

设机器字长为 8 位（n = 8），采用补码表示定点整数，可表示的数值范围为 −128 ~ +127。

已知两个定点整数的补码表示如下（均为十六进制）：

- **[A]补 = 0x9C**
- **[B]补 = 0xD8**

请完成以下各问（要求写出关键运算过程）：

### 第(1)题（3分）

计算 **[A + B]补**，并判断该加法运算是否发生溢出。

- 结果（2分）：写出 [A + B]补 的十六进制值。
- 溢出判断（1分）：用**双符号位法（变形补码法）**或**进位判别法**说明是否溢出，给出结论。

### 第(2)题（3分）

计算 **[A − B]补**，并判断该减法运算是否发生溢出。

> 提示：减法需先求 [−B]补，再执行 [A]补 + [−B]补。

- 结果（2分）：写出 [−B]补 的十六进制值及 [A − B]补 的十六进制值。
- 溢出判断（1分）：用**双符号位法（变形补码法）**或**进位判别法**说明是否溢出，给出结论。

## 设计意图

| 维度 | 说明 |
|------|------|
| 考察知识点 | 补码加法运算、补码减法运算（含 [−B]补 求取）、溢出判断 |
| 考察角度 | 给定具体补码计算加减并判断溢出 |
| K目标 | K1=2（补码表示基本概念）、K2=3（补码加减运算规则）、K3=4（多步串行运算：求[−B]补→加法→溢出判断）、K4=3（[−B]补 求取陷阱、溢出判断方法选择）、K5=2（结果验证） |
| 难度锚点 | 第(1)题直接加法+溢出判断；第(2)题需先求 [−B]补 再加，路径更长，[−B]补 求取为常见陷阱 |
| 对照设计 | A、B 均为负数，A+B 真实结果 −140 超出表示范围→溢出；A−B 真实结果 −60 在范围内→不溢出，形成"一溢一不溢"的对照 |

## 通过条件（场景规则）

本题成立需要满足以下参数间约束（与具体答案值无关，换参数仍成立）：

1. **A、B 均为 8 位补码负数**：0x80 ≤ A_hex < 0xFF 且 0x80 ≤ B_hex < 0xFF（符号位为 1，且不是 0x00），即 A_decimal < 0 且 B_decimal < 0。
2. **非平凡值**：A_decimal ∉ {0, −1}，B_decimal ∉ {0, −1}。
3. **[−B]补 求取正确性约束**：[−B]补 = (~B + 1) & 0xFF，且 [−B]补 + [B]补 == 0x100（mod 2⁸），即 [−B]补 是 [B]补 的加法逆元。
4. **第(1)题溢出约束**：A_decimal + B_decimal 的真实值超出 [−128, +127]，即 overflow_flag(A, B, '+') == True（两个负数相加，结果本应为负，但截断后符号位变正→溢出）。
5. **第(2)题不溢出约束**：A_decimal − B_decimal 的真实值在 [−128, +127] 内，即 overflow_flag(A, B, '−') == False（与第(1)题形成对照）。
6. **溢出判断一致性**：对任意运算 op，"双符号位法"与"进位判别法"给出的溢出结论一致（两种方法等价，不得矛盾）。
7. **运算正确性**：[A+B]补 == (A + B) mod 2⁸ 截断到 8 位的补码值；[A−B]补 == (A − B) mod 2⁸ 截断到 8 位的补码值（即补码加法遵循模 2⁸ 运算规则）。
