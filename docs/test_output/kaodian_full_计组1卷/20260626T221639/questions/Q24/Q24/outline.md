## 考点
- **总线带宽（核心考点）**：理解总线带宽的定义与计算公式，带宽 = 总线宽度 / 8 × 总线工作频率 / 每个传输周期所需的时钟周期数（MB/s）。考察侧重点：给定总线宽度、时钟频率、每个总线传输周期所占时钟周期数，代入公式求带宽，含 bit→Byte 的单位换算。
- **总线性能指标（辅助考点）**：总线宽度、总线时钟频率、总线传输周期等基本概念的含义及其与带宽的关系。

## 难度目标
| 维度 | 目标 | 达标理由 |
|------|------|----------|
| K1 | 2 | 需要知道总线带宽公式及总线宽度/频率等基础术语，但概念门槛不高，题干给明参数后可顺式代入 |
| K2 | 4 | 核心考察点：需代入公式计算，涉及 bit→Byte、MHz→Hz、除以周期数等多级单位换算，容易算错 |
| K3 | 2 | 计算路径基本唯一，2 步以内（代入公式 + 单位换算），无需多步推演 |
| K4 | 2 | 存在常规注意点（如分母是周期数而非频率、注意 Hz 与 MHz 的换算），但 408 考生基本不会踩坑 |
| K5 | 1 | 单一知识点（总线带宽），不涉及其他子系统联动 |

## 考察模式
**计算型——换参数求总线带宽**。题干给出总线工作时的若干参数（总线数据宽度、时钟频率、每个总线传输周期占用的时钟周期数），要求直接代入带宽公式计算，结果以 MB/s 表示。选择此模式因 slot 明确要求 examination_mode 为"计算型——总线带宽"，且教师批注指出"换参数求总线带宽"。

## 出题要求
- **题型**：简答题（主观题），6 分
- **总条件数**：3-4 个显式数值条件（总线宽度、时钟频率、每传输周期时钟周期数）
- **条件设计原则**：条件参数应使学生能够直接代入总线带宽公式；参数应为非 2 的幂或含 MHz 级频率，保证单位换算有区分度（K2=4）；可适当设置与"标准"默认值不同的参数，体现"换参数"
- **参数取值范围要求**：
  - 总线宽度：8/16/32/64 bit 中选一个
  - 时钟频率：数十到数百 MHz 量级
  - 每传输周期时钟周期数：1-4 个
  - 结果应为合理带宽值（数百 MB/s 量级），不能退化到平凡整数

## 参数约束
| 参数 | 取值范围 | 约束说明 |
|------|----------|----------|
| 总线数据宽度 W | {16, 32, 64} bit | 选 32 或 64 为佳，保证带宽结果有区分度 |
| 总线时钟频率 f | 100-500 MHz | 取非 2 的幂次值（如 200 MHz、33 MHz 等）或 2 的幂次均可，但须保证单位换算步骤存在 |
| 每传输周期时钟周期数 n | 1-4 | n≥2 时公式分母非 1，增加计算复杂度 |
| 一致性约束 | 带宽 B = W/8 × f×10⁶ / n，结果应为正整数或有理数 MB/s | B 应在合理量级（100-2000 MB/s），避免退化 |
| 可调自由度 | W、f、n 三个参数均可由 Question Agent 在上述范围内自由选取 | 参数组合需保证最终结果非平凡（非整百整千的"好数"） |

## 参考经验
- **考察模式**：计算型——给定总线参数求带宽，是 408 总线章节的经典考法，历史出现频率较高
- **难度锚点**：K2（单步代入）为主考点，难度集中在多级单位换算（bit→Byte、MHz→Hz、除周期数）
- **典型陷阱**：
  1. 忘记除以每传输周期的时钟周期数 n（直接用频率乘宽度）
  2. 单位换算错误（bit 与 Byte 混淆、MHz 未转 Hz）
  3. 误将总线宽度（bit）直接当作字节数代入
