## 题目

某计算机系统采用同步串行总线进行数据传输，总线参数如下：

| 参数 | 值 |
|------|-----|
| 总线数据宽度 $W$ | 64 bit |
| 总线时钟频率 $f$ | 250 MHz |
| 每完成一次数据传输所需的时钟周期数 $n$ | 3 |

**要求**：根据以上参数，计算该总线的理论数据传输带宽（单位：MB/s），写出计算过程。

> 提示：注意 bit 与 Byte 的换算、MHz 与 Hz 的换算、以及每传输周期占用的时钟周期数。

## 参考答案

$$B = \dfrac{2000}{3}\ \text{MB/s} \approx 666.67\ \text{MB/s}$$

## 解析

### 带宽公式

$$B = \frac{W}{8} \times \frac{f \times 10^{6}}{n} \quad (\text{MB/s})$$

其中 $W$ 单位为 bit（÷8 转 Byte），$f$ 单位为 MHz（×10⁶ 转 Hz），$n$ 为每传输周期占用的时钟周期数。

### 逐步代入

**Step 1　bit → Byte 换算：**

$$\frac{W}{8} = \frac{64\ \text{bit}}{8} = 8\ \text{Byte}$$

**Step 2　MHz → Hz 换算：**

$$f = 250\ \text{MHz} = 250 \times 10^{6}\ \text{Hz} = 250\,000\,000\ \text{Hz}$$

**Step 3　÷n（每秒传输次数）：**

每完成一次数据传输需 $n=3$ 个时钟周期，故每秒可完成的传输次数为：

$$\frac{f}{n} = \frac{250\,000\,000}{3}\ \text{次/s}$$

**Step 4　计算带宽：**

$$B = 8\ \text{Byte} \times \frac{250\,000\,000}{3}\ \text{次/s} = \frac{2\,000\,000\,000}{3}\ \text{Byte/s}$$

转为 MB/s（$1\ \text{MB} = 10^{6}\ \text{Byte}$）：

$$B = \frac{2\,000\,000\,000}{3 \times 1\,000\,000}\ \text{MB/s} = \frac{2000}{3}\ \text{MB/s} \approx 666.67\ \text{MB/s}$$

### 评分要点（6 分）

| 评分项 | 分值 | 说明 |
|--------|------|------|
| 公式正确 | 2 分 | 写出 $B = \frac{W}{8} \times \frac{f \times 10^6}{n}$ |
| bit→Byte 换算 | 1 分 | $64/8 = 8$ Byte |
| MHz→Hz 换算 | 1 分 | $250 \times 10^6$ Hz |
| ÷n 处理 | 1 分 | 除以 3 个时钟周期 |
| 最终数值与单位 | 1 分 | $2000/3 \approx 666.67$ MB/s |

### 常见错误分析

| 错误类型 | 结果 | 说明 |
|----------|------|------|
| 忘记除以 $n$ | 2000 MB/s | 将公式中的 ÷3 漏掉 |
| bit/Byte 搞反 | 5333.33 MB/s | 未将 64 bit 除以 8 |
| 结果正确 | 666.67 MB/s | — |

> 注：忘记除以 $n$ 会得到 2000 MB/s（恰好为上限），忘记 bit→Byte 换算会得到 5333.33 MB/s，两者均与正确值 666.67 MB/s 不同，体现了各步换算不可省略。
