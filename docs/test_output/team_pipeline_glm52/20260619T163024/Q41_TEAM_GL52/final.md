## 题目

已知一棵平衡二叉树（AVL 树）T 的当前状态如下图所示（结点中的数字为关键字，所有关键字互不相同）：

```
            50
           /  \
         30    66
        /  \     \
      18   40    80
```

其中，平衡二叉树的平衡因子 BF 定义为：**BF = 左子树高度 − 右子树高度**（空子树高度为 0，叶子结点高度为 1）。当树中某个结点的 BF 绝对值大于 1 时，需要通过旋转操作恢复平衡。

请依次回答以下问题：

### 第（1）题
写出图示 AVL 树 T 中每个结点的平衡因子 BF，并验证当前 T 是否满足平衡条件。

### 第（2）题
依次将关键字 **25、10、55** 按二叉排序树的规则插入 AVL 树 T 中。每插入一个关键字后，若出现不平衡则立即进行调整，调整后的结果作为下次插入的初始状态。

请填写下表，给出每次插入后的中间状态：

| 插入关键字 | 插入后是否失衡？ | 若失衡，最小不平衡子树的根是？ | 采用的旋转类型（LL/RR/LR/RL/无） | 调整后该子树新的根结点是？ |
|:---:|:---:|:---:|:---:|:---:|
| 25 | | | | |
| 10 | | | | |
| 55 | | | | |

> **说明**：
> - "最小不平衡子树"是指离插入结点最近的、BF 绝对值为 2 的结点为根的子树。
> - 旋转类型按教材定义：LL 型（右单旋）、RR 型（左单旋）、LR 型（先左后右双旋）、RL 型（先右后左双旋）。

### 第（3）题
画出三次插入（及相应调整）全部完成后，最终 AVL 树的形态（需标明所有结点的关键字及其左右孩子关系）。

### 第（4）题
对最终的 AVL 树进行中序遍历，写出中序遍历序列。

---

**约束与规则：**

1. **插入规则**：按二叉排序树的性质插入——比当前结点小的进入左子树，大的进入右子树。
2. **调整规则**：每次插入后立即检查平衡性。若失衡，从插入点向上找到第一个 BF 绝对值为 2 的结点（最小不平衡子树的根），根据该结点及其两个子结点的位置关系确定旋转类型（LL/RR/LR/RL），执行相应旋转，使该子树恢复平衡。
3. **高度定义**：空树高度为 0，单个结点（叶子）高度为 1。
4. **平衡因子定义**：BF = 左子树高度 − 右子树高度。
5. **不需写出代码**，所有操作以手动推演方式完成。

## 解析

### 第（1）题：各结点的平衡因子 BF 及平衡验证

逐结点计算 BF：

| 结点 | 左子树高度 | 右子树高度 | BF |
|:---:|:---:|:---:|:---:|
| 18 | 0 | 0 | **0** |
| 40 | 0 | 0 | **0** |
| 80 | 0 | 0 | **0** |
| 30 | 1（子树18） | 1（子树40） | **0** |
| 66 | 0 | 1（子树80） | **−1** |
| 50 | 2（子树30） | 2（子树66） | **0** |

**结论**：所有结点的 |BF| ≤ 1，当前 T 满足平衡条件，是平衡二叉树。

---

### 第（2）题：依次插入 25、10、55，每次插入后检查并调整

#### ① 插入 25

**BST 插入路径**：50 → 30 → 18 → 25

25 < 50 往左，25 < 30 往左，25 > 18 往右，18 的右子树为空，插入 25 作为 18 的右孩子。

插入后检查各结点 BF：

- 结点 18：左子树高度 = 0，右子树高度 = 1（25 是叶子）→ BF = 0 − 1 = **−1**
- 结点 30：左子树高度 = 2（18→25），右子树高度 = 1（40）→ BF = 2 − 1 = **1**
- 结点 50：左子树高度 = 3（30→18→25），右子树高度 = 2（66→80）→ BF = 3 − 2 = **1**

所有 |BF| ≤ 1，**未失衡，无需调整。**

插入 25 后的树：
```
            50
           /  \
         30    66
        /  \     \
      18   40    80
        \
        25
```

#### ② 插入 10

**BST 插入路径**：50 → 30 → 18 → 10

10 < 50 往左，10 < 30 往左，10 < 18 往左，18 的左子树为空，插入 10 作为 18 的左孩子。

插入后检查各结点 BF：

- 结点 18：左子树高度 = 1（10），右子树高度 = 1（25）→ BF = 0
- 结点 30：左子树高度 = 2（18→10 / 18→25），右子树高度 = 1（40）→ BF = 1
- 结点 50：左子树高度 = 3（30→18→...），右子树高度 = 2（66→80）→ BF = 1

所有 |BF| ≤ 1，**未失衡，无需调整。**

插入 10 后的树：
```
            50
           /  \
         30    66
        /  \     \
      18   40    80
      / \
    10   25
```

#### ③ 插入 55

**BST 插入路径**：50 → 66 → 55

55 > 50 往右，55 < 66 往左，66 的左子树为空，插入 55 作为 66 的左孩子。

插入后检查各结点 BF：

- 结点 66：左子树高度 = 1（55），右子树高度 = 1（80）→ BF = 0
- 结点 50：左子树高度 = 3（30→18→10/25），右子树高度 = 2（66→55/80）→ BF = 3 − 2 = **1**

所有 |BF| ≤ 1，**未失衡，无需调整。**

插入 55 后的树：
```
            50
           /  \
         30    66
        /  \   /  \
      18   40 55   80
      / \
    10   25
```
