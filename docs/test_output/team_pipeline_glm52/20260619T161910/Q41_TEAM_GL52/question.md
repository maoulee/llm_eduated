# Q41 平衡二叉树（AVL 树）的插入与旋转

## 题目

将关键字序列 $S = [30, 20, 10, 15, 25, 5, 40, 50, 45]$（共 $9$ 个**互不相同**的关键字）按照先后顺序依次插入到**初始为空**的平衡二叉树（AVL 树）中。插入过程中，若某节点平衡因子的绝对值超过 1，则需进行相应的旋转操作以恢复平衡。

> 说明：本题中平衡因子 BF = 左子树高度 − 右子树高度。

---

### 问题 1（4 分）

在依次插入关键字 $30, 20, 10, \ldots$ 的过程中，**首次发生失衡**是在插入哪个关键字之后？

（1）写出首次失衡时**最小不平衡子树的根节点**及其平衡因子。

（2）写出首次失衡时**该最小不平衡子树的根节点的左右子节点各自的平衡因子**。

---

### 问题 2（6 分）

针对问题 1 中识别出的首次失衡：

（1）判断应执行的**旋转类型**（LL 旋转（右旋） / RR 旋转（左旋） / LR 旋转（先左旋后右旋） / RL 旋转（先右旋后左旋）），并说明判断依据。

（2）画出执行该旋转后的 AVL 树的结构，并**标出各节点的平衡因子**。

---

### 问题 3（6 分）

在问题 2 旋转恢复平衡后，继续依次插入序列中剩余的关键字，直到**再次发生失衡**。

（1）第二次失衡发生在插入哪个关键字之后？其**最小不平衡子树的根节点**是什么？

（2）判断第二次应执行的**旋转类型**（LL 旋转（右旋） / RR 旋转（左旋） / LR 旋转（先左旋后右旋） / RL 旋转（先右旋后左旋）），并说明判断依据。

（3）画出第二次旋转后**最终的 AVL 树的结构**，并标出各节点的平衡因子。

- 总分 16 分
