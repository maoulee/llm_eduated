## core_knowledge_intent

- **must_test**:
  1. AVL 树插入过程中的平衡因子（BF）动态更新——学生必须逐步维护每个节点的 BF 值并判断失衡
  2. 四种旋转类型（LL / RR / LR / RL）的触发条件辨析与正确选择——核心区分度
  3. 旋转操作后树的形态变化（子树挂接关系的变化）——结构操作的结果表达

- **must_not_shift_to**:
  - 不偏移到 AVL 树的数学性质（如最大深度公式 N(h)=N(h-1)+N(h-2)+1）
  - 不偏移到二叉排序树的查找路径分析（查找不是本题考察重点）
  - 不偏移到 AVL 删除操作的平衡恢复

- **coverage_success_criteria**:
  - 题目序列能让学生经历至少两次不同类型的旋转（如先 LL 再 LR，或先 RR 再 RL），覆盖 ≥2 种旋转类型
  - 每个子问都要求学生呈现中间状态（某一步插入后的树结构或 BF 值），而非仅给最终树
  - 区分度体现在：能否正确判断旋转类型（K4 路由）+ 能否准确推演多步形态变化（K3 推演）

## design_rationale

**考察意图**：本题选择"给定序列逐步插入 AVL 树"作为考察形式，这是数据结构中最典型的"结构操作与状态维护模拟"题型。选择这种方式而非概念辨析题，是因为：

1. **K3（机制推演）覆盖**：AVL 插入是一个>5步的串行流程，每插入一个关键字都需要：查找插入位置 → 插入 → 自底向上更新 BF → 判断是否失衡 → 选择旋转类型 → 执行旋转 → 更新子树关系。这一长程推演天然覆盖 K3=4 的认知需求。

2. **K4（条件路由）覆盖**：四种旋转类型的判断是核心路由点。学生必须根据"最小不平衡子树的根"的 BF 符号 + 其子节点的 BF 符号，路由到正确的旋转操作。这个判断条件不是字面给出的，需要从树结构中推导，覆盖 K4=4。

3. **考点融合**：本题融合了"BF 值动态维护"（机制执行）+ "旋转类型判断"（条件路由）+ "旋转后结构表达"（结果输出），三者串行耦合——前一步的正确性是后一步的前提，形成高区分度的链式考察。

**区分度设计**：
- 基础层学生：能正确插入节点、维护 BF 值（部分完成）
- 中间层学生：能正确识别失衡但旋转类型判断出错（如 LR 误判为 LL）
- 顶层学生：全程正确推演所有旋转并正确表达最终结构

**难度定位**：难度 4 的核心支撑来自序列长度（需多步串行推演）+ 旋转类型多样性（≥2 种不同旋转，其中至少包含一种双旋 LR/RL）。单旋（LL/RR）为基础，双旋（LR/RL）为区分度。

## question_structure_plan

**复用骨架来源**：
- 参考往年 simulation_00175（AVL 插入序列题，要求识别最小不平衡子树的根）——提炼设问句式"给定关键字序列逐步插入，判断某一步的状态"
- 参考往年 2013_Q6（BST 插入/删除综合题）——提炼设问结构"给定操作序列，问操作后的树结构属性"
- 综合两题的设问骨架：**给定序列 → 逐步操作 → 问中间状态 + 问最终结构**

**设问结构**：

- **子问1**：考[AVL 插入 + 平衡因子维护]（基础层）
  - 给定一个关键字序列，要求学生写出依次插入过程中，**首次发生失衡时**最小不平衡子树的根节点及其平衡因子（即 |BF|=2 的节点）
  - 参考往年 simulation_00175 的问法："首次出现的最小不平衡子树的根是？"
  - 此问检验学生能否正确逐步插入并维护 BF 值，定位失衡发生的位置

- **子问2**：基于子问1的失衡判断，考[旋转类型辨析 + 旋转后结构]（进阶层）
  - 针对子问1中识别出的首次失衡，要求学生判断应执行的旋转类型（LL/RR/LR/RL），并画出旋转后的树结构
  - 此问检验旋转类型判断（核心 K4 路由）+ 旋转操作的结构变换

- **子问3**：考[持续插入 + 第二次旋转]（区分度层）
  - 在子问2恢复平衡后，要求学生继续插入剩余关键字，直到再次发生失衡，判断第二次旋转类型并给出最终 AVL 树的结构（可用层序序列或树形图表达）
  - 此问检验学生能否在动态状态更新中持续正确推演（K3 长程 + K4 二次路由），且第二次旋转类型应与第一次不同（覆盖 ≥2 种旋转）

- **dependency_pattern**：严格串行依赖（子问1的失衡识别 → 子问2的旋转判断与结果 → 子问3的继续推演，前问结果是后问输入）

## terminology_and_expression_constraints

- **必须用词**：
  - "平衡二叉树（AVL 树）"——首次出现时全称
  - "平衡因子"——不使用"高度差"等非标准表述
  - "最小不平衡子树"——标准术语，不简化为"不平衡节点"
  - 四种旋转类型使用标准缩写："LL 旋转（右旋）""RR 旋转（左旋）""LR 旋转（先左旋后右旋）""RL 旋转（先右旋后左旋）"
  - "依次插入"——强调操作顺序

- **限定语**：
  - 关键字序列需注明"无重复关键字"
  - 需明确"按照关键字序列的先后顺序依次插入到初始为空的 AVL 树中"
  - 子问中要求画树时注明"画出旋转后的树的结构（标出各节点的平衡因子）"

- **禁止表述**：
  - 不使用"调整""修正"代替"旋转"——旋转是标准术语
  - 不在题干中暗示旋转类型——不能出现"在插入 X 后需要左旋"等暗示性表述
  - 不使用"重构""重建"等模糊术语
  - 不要求学生写出旋转算法的代码——本题考察手工推演，不考代码实现

## audit_focus

1. **序列有效性**：给定的关键字序列是否确实能触发至少两种不同类型的旋转？（至少包含一种双旋 LR 或 RL）——若序列仅触发 LL/RR 单旋，则难度退化，不满足 difficulty=4

2. **子问依赖性**：子问3是否严格依赖子问2的结果？——子问3必须在子问2恢复平衡后的树上继续操作，不能独立给出

3. **中间过程考察**：是否每个子问都考察中间状态而非仅最终结果？——若某子问仅问"最终树的根节点"，则 K3 推演覆盖不足

4. **旋转类型覆盖**：最终方案是否覆盖 ≥2 种旋转类型？——若全部为同一种旋转（如全部是 LL），区分度不足

5. **术语规范性**：题干和子问是否使用了"平衡因子""最小不平衡子树"等标准术语？是否避免了暗示性表述？

6. **不偏移检查**：题目是否保持在"插入与旋转"范围内，未涉及删除操作、数学性质推导、代码实现？
