# Q41 平衡二叉树（AVL）的构造与旋转过程分析

## 题干

依次将关键字序列 **{30, 15, 45, 8, 22, 40, 50, 18, 25, 10}** 插入一棵初始为空的平衡二叉树（AVL 树）。约定：

- **平衡因子 BF** = 左子树高度 − 右子树高度（空子树高度为 0，叶结点高度为 1）。
- 当某结点的 |BF| ≥ 2 时，该结点为**不平衡结点**；取**离插入结点最近**的不平衡结点作为旋转的根进行调整。
- 旋转类型按教材标准定义：LL（右单旋）、RR（左单旋）、LR（先左后右双旋）、RL（先右后左双旋）。

请回答以下问题：

### 第（1）题

逐个插入上述 10 个关键字，请写出**每次发生旋转时的关键字及旋转类型**。若某次插入不触发旋转，则无需列出。

> 格式示例：插入 X → LR 旋转（仅写出实际触发旋转的插入步）

### 第（2）题

写出所有关键字插入完成后，该 AVL 树的**层序遍历序列**（从根开始，自左向右逐层输出）。

### 第（3）题

在最终得到的 AVL 树中，求关键字 **8** 所在结点的平衡因子 BF(8) 和关键字 **22** 所在结点的平衡因子 BF(22)。

## 设计意图

| 考察项 | 对应子问 | 考察目标 |
|--------|---------|---------|
| AVL 逐步插入 + 旋转类型判定 | 第（1）题 | 考生需对每次插入后的树进行平衡检查，判断是否失衡、识别失衡类型（LL/RR/LR/RL），并正确执行对应旋转。考察四种旋转触发条件的精准辨析（K4）与多步串行推演（K3）。 |
| 最终树形态/层序输出 | 第（2）题 | 考察所有旋转完成后树的全局结构是否被正确维护——若任一步旋转出错则层序序列错误。 |
| 平衡因子计算 | 第（3）题 | 考察对最终树中指定结点子树高度的精确计算，验证考生对树形态的正确理解。 |

## 通过条件（成功判据·可机检）

本题成立需要满足以下可机检特征（供 gen.py 用 `assert` 验证）：

1. **旋转覆盖度**：整个插入序列中**至少触发 3 次旋转**，且旋转类型**至少涵盖 2 种不同类型**（如 LL + LR 或 RR + RL 等组合），确保四种旋转类型的辨析被真实考察到——若序列退化（仅触发 1 种类型或 0 次旋转），则题目不成立。

2. **旋转类型正确性可验证**：每次旋转发生时，旋转前的关键字、旋转类型、旋转后的根结点变化均可由代码模拟标准 AVL 插入算法得出，且不同旋转类型的处理逻辑互不相同——若两种旋转类型产生相同结果则无区分度。

3. **最终树平衡性**：插入全部完成后，整棵树的**每个结点的 |BF| ≤ 1**（即树是合法 AVL 树）。

4. **层序序列非平凡**：最终树的层序遍历序列长度 = 10（全部关键字各出现一次），且关键字 **30** 不在层序序列的第 1 位（根结点经过旋转后发生变化），确保旋转确实改变了树根。

5. **BF 计算有区分度**：BF(8) 与 BF(22) 的值**不相等**，确保第（3）题两个子问考的不是同一个计算结果。
