- target_family: 数据结构 > 树与二叉树 > 二叉树遍历

- question_type: comprehensive
- examination_mode: 算法设计型——二叉树遍历与路径算法设计

### 难度目标
- k_target: K1=1,K2=2,K3=2,K4=3,K5=4
- difficulty_level: 4
- difficulty_rationale: 算法设计题，需结合遍历框架与路径保存设计完整算法。主导维度K5=4，因需整合结点定义、递归遍历、路径数组管理、叶子判定、输出控制等多个子模块；K4=3，因需识别路径方向与遍历方向的矛盾并设计逆序输出机制。

### 结构要求
- sub_question_count: 2
- sub_question_details:
  - 第1问（4分）: 结点类型定义 + 算法设计思想（文字描述）
  - 第2问（12分）: C/C++ 代码实现（含注释）
- dependency: 串行（第2问承接第1问设计）
- score_total: 16
- condition_count: 2-3
- distractor_strategy: 不适用（综合题为算法设计题，无干扰项）

### 参数约束
- 存储结构: 二叉链表，结点类型由考生定义或题目给定（Question Agent 决定）
- 结点数据类型: 整型或字符型（Question Agent 决定）
- 二叉树形态: 任意形态，不需固定实例
- 路径方向: 叶子到根（序列从叶子开始，根结束）
- 路径输出格式: 各路径间换行或空格分隔（Question Agent 明确）
- 算法方法: 不限定（递归/非递归均可）
- 自由度说明: Question Agent 可自主决定是否给具体示例树、结点结构是否预定义

### 参考经验摘要
- 历史模式: 2014年Q41，二叉树遍历算法设计，三段式（定义+思想+代码）
- 难度锚点: 算法设计综合题以K5为主导，整合多模块；K4中等，路径方向为暗坑
- 典型陷阱:
  1. 路径方向混淆（输出根到叶子而非叶子到根）
  2. 递归回溯时路径数组未正确弹出
  3. 叶子判定遗漏（只判断左空不判断右空）
