## 题目

已知一棵二叉树 T 采用二叉链表存储，结点的 `data` 域为整型。设 `root` 为指向 T 的根结点的指针。

**路径定义**：从某个叶子结点出发，沿父指针逐层上行至根结点，所经过的结点序列称为该叶子结点到根的路径。路径中结点的排列顺序为**从叶子结点开始、根结点结束**（即叶子→根方向）。

例如，对如下二叉树：

```
          1
         / \
        2   3
       / \   \
      4   5   6
```

其所有叶子结点到根的路径为：

```
4 2 1
5 2 1
6 3 1
```

每行输出一条路径，路径中结点值以空格分隔，各路径之间以换行分隔。叶子结点的输出顺序不限。

请设计算法，输出二叉树 T 中**所有叶子结点到根的路径**，要求：

### 第 1 问（4 分）

（1）给出二叉树结点的数据类型定义（采用 C 或 C++ 语言）；
（2）给出算法的基本设计思想。

### 第 2 问（12 分）

根据第 1 问的设计思想，采用 C 或 C++ 语言描述算法，在关键之处给出注释。

## 参考答案

**第 1 问（4 分）**

（1）二叉树结点的数据类型定义：

```c
typedef struct BiTNode {
    int data;                        // 数据域，整型
    struct BiTNode *lchild, *rchild; // 左、右孩子指针
} BiTNode, *BiTree;
```

（2）算法基本设计思想：

采用**递归回溯（深度优先遍历）**，维护一个全局路径数组 `path`，在遍历过程中记录从根到当前结点的路径（根→叶方向积累）。

1. 从根结点出发，每访问一个结点就将其 `data` 追加到 `path` 末尾。
2. 判断当前结点是否为叶子（`lchild == NULL && rchild == NULL`）：
   - 若是叶子，则 `path` 中保存的是从根到该叶子的路径，**将其逆序**即得到题目要求的「叶子→根」方向路径，输出。
   - 若不是叶子，递归遍历其左、右子树。
3. **回溯**：从某个子树返回时，必须将 `path` 的末尾元素弹出（删除当前结点），保证遍历其他分支时 `path` 不含串入的错误结点。

**关键点**：自然递归遍历积累的路径是根→叶方向，而题目要求叶子→根方向，因此输出时需要逆序处理（反向打印或将路径数组逆序后输出）。

**第 2 问（12 分）**

```c
void printAllPaths(BiTree root) {
    int path[1000];     // 路径数组，足够大
    int len = 0;        // 当前路径长度
    dfs(root, path, &len);
}

void dfs(BiTree node, int path[], int *len) {
    if (node == NULL)
        return;

    // 当前结点加入路径（根→叶方向积累）
    path[*len] = node->data;
    (*len)++;

    if (node->lchild == NULL && node->rchild == NULL) {
        // 叶子结点：逆序输出 path（叶子→根方向）
        for (int i = *len - 1; i >= 0; i--) {
            printf("%d", path[i]);
            if (i > 0) printf(" ");
        }
        printf("\n");
    } else {
        // 非叶子：递归左右子树
        dfs(node->lchild, path, len);
        dfs(node->rchild, path, len);
    }

    // 回溯：弹出当前结点
    (*len)--;
}
```

## 解析

### 设计思路

本题核心考点为**二叉树遍历 + 路径保存 + 叶子判定 + 方向逆序处理**。

自然递归遍历（前序遍历）积累的路径数组天然是「根→叶」方向，而题目要求输出「叶子→根」方向。考生需要识别这一矛盾，在叶子结点处将路径逆序输出（或反向遍历打印）。此外，递归回溯时必须正确弹出当前结点，否则会导致不同分支的结点串入同一条路径。

### 算法执行验证

**示例树 1（题干示例）**：

```
          1
         / \
        2   3
       / \   \
      4   5   6
```

输出（叶子→根方向，每行一条路径）：

```
4 2 1
5 2 1
6 3 1
```

验证：3 条路径对应 3 个叶子（4、5、6），每条路径末尾为根值 1，方向正确。

**示例树 2（不规则树，考验回溯正确性）**：

```
            10
           /  \
          20   30
         /      \
        40      50
       /  \
      60  70
```

输出：

```
60 40 20 10
70 40 20 10
50 30 10
```

验证：该树含「只有左子树」的分支（20→40→60/70）和「只有右子树」的分支（30→50），验证回溯弹出正确——路径 60 和 70 共享前缀 `40 20 10` 但互不串入对方结点；3 条路径对应 3 个叶子（50、60、70），方向、完整性、覆盖性均正确。

### 评分要点

| 要点 | 分值 |
|------|------|
| 结点类型定义正确（int data + 左右孩子指针） | 第1问 |
| 递归遍历框架设计思想清晰（DFS + 路径数组维护） | 第1问 |
| 识别方向矛盾，说明逆序输出机制 | 第1问/第2问 |
| 回溯弹出路径数组末尾元素 | 第2问 |
| 叶子判定条件正确（左右孩子均空） | 第2问 |
| 代码语法正确、关键处有注释 | 第2问 |

### 常见错误

1. **方向混淆**：输出根→叶子方向（如 `1 2 4`），未做逆序处理。
2. **回溯遗漏**：递归返回时忘记弹出 `path` 末尾元素，导致跨分支结点串入路径（如路径中出现 `60 40 70 ...` 等错误序列）。
3. **叶子判定不完整**：仅判断左孩子为空或仅判断右孩子为空，遗漏真正的叶子或误判单子树结点。
