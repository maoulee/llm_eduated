# 综合题：求二叉树中所有叶子结点到根的路径

## 题干

已知一棵二叉树 T 采用二叉链表存储，结点的 `data` 域为整型。设 `root` 为指向 T 的根结点的指针。

**路径定义**：从某个叶子结点出发，沿父指针逐层上行至根结点，所经过的结点序列称为该叶子结点到根的路径。路径中结点的排列顺序为**从叶子结点开始、根结点结束**（即叶子→根方向）。

例如，对如下二叉树：

```
          1
         / \
        2   3
       / \   \
      4   5   6
```

其所有叶子结点到根的路径为：

```
4 2 1
5 2 1
6 3 1
```

每行输出一条路径，路径中结点值以空格分隔，各路径之间以换行分隔。叶子结点的输出顺序不限。

请设计算法，输出二叉树 T 中**所有叶子结点到根的路径**，要求：

### 第 1 问（4 分）

（1）给出二叉树结点的数据类型定义（采用 C 或 C++ 语言）；
（2）给出算法的基本设计思想。

### 第 2 问（12 分）

根据第 1 问的设计思想，采用 C 或 C++ 语言描述算法，在关键之处给出注释。

---

## 通过条件（成功判据，供 gen.py assert 使用）

本题成立需要满足以下可机检特征：

1. **路径方向正确性**：每条输出路径的序列必须从叶子结点开始、根结点结束（叶子→根方向），而非根→叶子方向。可由 `path[0]` 为叶子值、`path[-1]` 为根值来机检。
2. **路径完整性**：每条路径必须覆盖该叶子到根的全部结点，不遗漏中间结点。可由 `路径长度 == 树高（从该叶子到根的深度+1）` 来机检。
3. **叶子覆盖完备性**：输出的路径数量必须等于二叉树中叶子结点的总数，不多不少。
4. **回溯正确性**：在递归回溯时路径数组必须正确弹出，不能出现跨分支串入错误结点的路径。可由「每条路径恰好是该叶子到根的真实祖先链」来机检。

---

## 设计说明（仅供审核参考，不写入学生可见题面）

- **考点**：二叉树遍历 + 路径保存 + 叶子判定 + 方向逆序处理。
- **K5=4 整合维度**：考生需整合结点定义、递归遍历框架、路径数组（或栈）管理、叶子判定、逆序输出五个子模块。
- **K4=3 方向陷阱**：自然递归遍历是自根向叶方向（前序/中序/后序），积累的路径数组天然是根→叶顺序；题目要求叶子→根，考生需识别这一矛盾并设计逆序输出机制（反向打印或反向入数组）。
- **核心陷阱**：
  1. 路径方向混淆——输出根到叶子而非叶子到根。
  2. 递归回溯时路径数组未正确弹出，导致跨分支串入错误结点。
  3. 叶子判定遗漏——只判断左空不判断右空（或反之）。
- **不限定方法**：递归或非递归（栈）均可；路径数组可用全局数组、传引用数组或栈结构。
- **存储结构**：二叉链表，结点类型由考生在第 1 问中自行定义。
