# 单链表递归逆序输出函数填空并说明功能

## 题目

已知单链表结点的类型定义如下：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode;
```

单链表带有头结点，头指针为 `L`。以下 C 语言函数 `proc` 用于对单链表进行某种操作，其中有两处空白（① 和 ②），请阅读代码并回答问题。

```c
void proc(LNode *p)
{
    if (p == NULL) return;
    ____________;    // ①
    ____________;    // ②
}
```

### 第 1 问（填空题，3 分）

请填写空白 ① 和 ② 处的 C 语句，使得调用 `proc(L->next)` 后，能将单链表各数据结点的 `data` 值**从尾到头**（即逆序）依次输出，每个整数后跟一个空格。

### 第 2 问（简答题，2 分）

简述该递归函数 `proc` 的功能，并说明递归调用语句与输出语句的先后顺序为什么决定了"逆序"输出。

---

## 设计意图

- **考点**：单链表 + 递归思想。核心是理解"先递归后访问 = 逆序输出"这一经典模式。
- **第 1 问**（K2=3 主导）：要求考生理解递归逻辑，正确填写递归调用语句（`proc(p->next)`）和输出语句（`printf("%d ", p->data)`），两语句的顺序为**先递归后输出**，从而实现逆序。若考生将顺序写反（先输出后递归），则变为正序输出，功能错误——这是典型区分点。
- **第 2 问**（K2 辅助 / K3=2）：要求考生用语言描述功能，并解释先后顺序对输出方向的决定作用，考察对递归执行流程的理解。
- **函数名 `proc`**：不暴露功能意图（非 `reversePrint` 等），防止考生直接从函数名猜答案。
- 终止条件 `if (p == NULL) return;` 作为已知给出，降低干扰；核心考察点集中在两处空白（递归 + 输出的先后顺序）。

## 通过条件（成功判据·可机检）

1. **空白 ① 是递归调用**：填入的语句包含对 `proc` 的递归调用，参数为 `p->next`（或等价形式）。
2. **空白 ② 是输出语句**：填入的语句包含 `printf`（或等价输出），输出 `p->data`。
3. **顺序约束**：①（递归调用）出现在 ②（输出）之前——即先递归后访问。若顺序相反则功能变为正序输出，本题不成立。
4. **功能正确性可验证**：给定一个具体链表（如数据值为 1→2→3→4→5 的带头结点单链表），调用 `proc(L->next)` 后输出结果为 `5 4 3 2 1 `（逆序），可通过 exec 比对验证。
5. **第 2 问要点覆盖**：正确回答须包含"逆序（从尾到头）输出各结点数据值"且说明"递归调用在前导致先到达链表末尾再逐层返回时输出，因此逆序"。
