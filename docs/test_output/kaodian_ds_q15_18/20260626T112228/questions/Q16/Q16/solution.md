# 单链表递归逆序输出函数填空并说明功能 — 求解

## 参数

- 链表数据结点（从头到尾）：`1 → 2 → 3 → 4 → 5`
- 链表带有头结点，头指针为 `L`
- 调用方式：`proc(L->next)`

## 第 1 问（填空题，3 分）

**① 处填入：**

```c
proc(p->next);
```

**② 处填入：**

```c
printf("%d ", p->data);
```

完整函数如下：

```c
void proc(LNode *p)
{
    if (p == NULL) return;
    proc(p->next);              // ① 递归调用，先处理下一个结点
    printf("%d ", p->data);     // ② 递归返回后输出当前结点
}
```

> 两处语句的顺序是 **先递归（①）后输出（②）**，这是实现逆序输出的关键。

## 第 1 问验证（逆序输出）

以链表 `1→2→3→4→5` 为例，调用 `proc(L->next)` 后输出结果为：

```
5 4 3 2 1 
```

即从尾到头（逆序）依次输出各数据结点的值，符合题目要求。

### 递归执行流程（忠实对照 gen.py exec 输出）

```
proc(p.data=1)：先执行①递归 proc(p->next)
  proc(p.data=2)：先执行①递归 proc(p->next)
    proc(p.data=3)：先执行①递归 proc(p->next)
      proc(p.data=4)：先执行①递归 proc(p->next)
        proc(p.data=5)：先执行①递归 proc(p->next)
          proc(NULL) → 命中终止条件 p==NULL，返回
        proc(p.data=5)返回：执行②输出 "5 "
      proc(p.data=4)返回：执行②输出 "4 "
    proc(p.data=3)返回：执行②输出 "3 "
  proc(p.data=2)返回：执行②输出 "2 "
proc(p.data=1)返回：执行②输出 "1 "
```

**关键观察**：递归调用在前（①），控制流一路压栈到链表末尾（`p==NULL`）；逐层返回时才执行②输出。最内层（末尾结点 `data=5`）最先输出，最先进入的结点（`data=1`）最后输出 → 逆序。

**区分点**：若将两语句顺序写反（先输出后递归），则输出变为 `1 2 3 4 5 `（正序），功能错误。

## 第 2 问（简答题，2 分）

**功能描述**：该递归函数 `proc` 的功能是 **从尾到头（逆序）依次输出单链表各数据结点的 `data` 值**。

**顺序决定输出方向的原因**：因为递归调用语句①在输出语句②之前，控制流不断向链表尾部推进，直到 `p==NULL`（到达链表末尾）才开始逐层返回；返回时才执行②的输出语句。因此最靠近表尾的结点最先被输出，最靠近表头的结点最后被输出，从而实现逆序输出。

> 若将顺序改为"先输出后递归"，则变为正序输出（从表头到表尾），功能不同。

## 答案汇总

| 空白 | 填入语句 | 作用 |
|------|---------|------|
| ① | `proc(p->next);` | 递归调用，先处理后继结点 |
| ② | `printf("%d ", p->data);` | 递归返回后输出当前结点数据 |

- 调用 `proc(L->next)` 对链表 `1→2→3→4→5` 的输出：`5 4 3 2 1 `（逆序）。
