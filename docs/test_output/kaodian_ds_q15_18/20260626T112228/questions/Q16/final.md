## 题目

已知单链表结点的类型定义如下：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode;
```

单链表带有头结点，头指针为 `L`。以下 C 语言函数 `proc` 用于对单链表进行某种操作，其中有两处空白（① 和 ②），请阅读代码并回答问题。

```c
void proc(LNode *p)
{
    if (p == NULL) return;
    ____________;    // ①
    ____________;    // ②
}
```

### 第 1 问（填空题，3 分）

请填写空白 ① 和 ② 处的 C 语句，使得调用 `proc(L->next)` 后，能将单链表各数据结点的 `data` 值**从尾到头**（即逆序）依次输出，每个整数后跟一个空格。

### 第 2 问（简答题，2 分）

简述该递归函数 `proc` 的功能，并说明递归调用语句与输出语句的先后顺序为什么决定了"逆序"输出。

## 参考答案

**第 1 问：**

- **①** `proc(p->next);`
- **②** `printf("%d ", p->data);`

**第 2 问：**

该函数的功能是**从尾到头（逆序）依次输出单链表各数据结点的 `data` 值**。递归调用语句在前、输出语句在后，使得控制流先一路推进到链表末尾（`p==NULL`），再逐层返回时才执行输出——因此最靠近表尾的结点最先输出，最靠近表头的结点最后输出，实现逆序。

## 解析

### 第 1 问：完整函数

```c
void proc(LNode *p)
{
    if (p == NULL) return;
    proc(p->next);              // ① 递归调用，先处理下一个结点
    printf("%d ", p->data);     // ② 递归返回后输出当前结点
}
```

两处语句的顺序是**先递归（①）后输出（②）**，这是实现逆序输出的关键。

### 验证（以链表 1→2→3→4→5 为例）

调用 `proc(L->next)` 后输出结果为：

```
5 4 3 2 1 
```

递归执行流程如下：

```
proc(data=1)：执行①递归 proc(p->next)
  proc(data=2)：执行①递归 proc(p->next)
    proc(data=3)：执行①递归 proc(p->next)
      proc(data=4)：执行①递归 proc(p->next)
        proc(data=5)：执行①递归 proc(p->next)
          proc(NULL) → 命中终止条件，返回
        proc(data=5)返回：执行②输出 "5 "
      proc(data=4)返回：执行②输出 "4 "
    proc(data=3)返回：执行②输出 "3 "
  proc(data=2)返回：执行②输出 "2 "
proc(data=1)返回：执行②输出 "1 "
```

**关键观察**：递归调用在前（①），控制流一路压栈到链表末尾；逐层返回时才执行②输出。最内层（末尾结点 `data=5`）最先输出，最先进入的结点（`data=1`）最后输出 → 逆序。

**区分点**：若将两语句顺序写反（先输出后递归），则输出变为 `1 2 3 4 5 `（正序），功能错误。

### 第 2 问：评分要点

1. **功能描述**（1 分）：正确说明该函数"逆序（从尾到头）输出各数据结点的 `data` 值"。
2. **顺序原理**（1 分）：正确解释递归调用在前使控制流先到达链表末尾，逐层返回时才执行输出，因此逆序。

### 答案汇总

| 空白 | 填入语句 | 作用 |
|------|---------|------|
| ① | `proc(p->next);` | 递归调用，先处理后继结点 |
| ② | `printf("%d ", p->data);` | 递归返回后输出当前结点数据 |
