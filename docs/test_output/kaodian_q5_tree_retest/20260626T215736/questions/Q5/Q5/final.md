## 题目
一棵有 74 个结点的二叉树，已知其中度为 1 的结点数为 1。则该二叉树的叶子结点数为（　　）。


## 选项
A. 37  
B. 38  
C. 36  
D. 35

---


## 求解过程
# 解题过程

## 参数

| 参数 | 值 |
|------|----|
| N（总结点数） | 74 |
| $n_1$（度为 1 的结点数） | 1 |
| $N - n_1$ | 73（奇数） |

## 正确解法（选项 A）

设 $n_0$ 为叶子结点数（度为 0），$n_2$ 为度为 2 的结点数。

**约束 1（度数守恒）**：

$$n_0 + n_1 + n_2 = N \implies n_0 + n_2 = N - n_1 = 73$$

**约束 2（二叉树性质）**：

$$n_0 = n_2 + 1$$

**联立消元**：将 $n_0 = n_2 + 1$ 代入 $n_0 + n_2 = 73$：

$$(n_2 + 1) + n_2 = 73 \implies 2n_2 = 72 \implies n_2 = 36$$

**回代**：

$$n_0 = n_2 + 1 = 36 + 1 = 37$$

故该二叉树的叶子结点数为 **37**。

### 场景规则验证

- 度数守恒：$n_0 + n_1 + n_2 = 37 + 1 + 36 = 74 = N$ ✓
- 二叉树性质：$n_0 = n_2 + 1 \Rightarrow 37 = 36 + 1$ ✓
- 正整数：$n_0 = 37 \geq 1$，$n_2 = 36 \geq 1$ ✓

## 选项分析

| 选项 | 值 | 说明 |
|------|----|------|
| **A** | **37** | **正确**。$n_0 = 37$。 |
| B | 38 | 漏减 $n_1$：误用 $n_0 + n_2 = N = 74$（未减 $n_1$）联立 $n_0 = n_2 + 1$，得 $n_2 = 36$，再误用 $n_0 = N - n_2 = 74 - 36 = 38$。 |
| C | 36 | 混淆 $n_0$ 与 $n_2$：正确求出 $n_2 = 36$ 后，误将 $n_2$ 的值当作 $n_0$。 |
| D | 35 | 记反公式：正确求出 $n_2 = 36$ 后，将 $n_0 = n_2 + 1$ 记反为 $n_0 = n_2 - 1$，得 $n_0 = 36 - 1 = 35$。 |

四选项值分别为 35、36、37、38，互不相同，具有区分度。

## 答案

**A. 37**
