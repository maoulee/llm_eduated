## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树性质
- primary_target_name: 二叉树叶子结点数与度为2结点数的关系应用
- question_type: single_choice
- examination_mode: 计算型——二叉树性质应用

### 难度目标
- k_target: K1=2,K2=3,K3=2,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 需联立 n0=n2+1 与 n0+n1+n2=N 两条公式做两步代入计算，数字为非2的幂次，K2为主导维度，属标准计算型选择题

### 结构要求
- option_count: 4（1正确3干扰）
- distractor_strategy: 围绕 n0=n2+1 公式的三类典型错误——符号记反（n0=n2-1）、漏减n1、混淆n0与n2结果
- condition_count: 2（总结点数N + 度为1的结点数n1或其等价限定词）

### 参数约束
- 总结点数N: 取值范围 [30, 127]，非2的幂次，使计算非平凡
- 度为1的结点数n1: 取值 0 或 1，可显式给出或用"完全二叉树"等限定词隐含给出
- 一致性约束（硬约束）: (N - n1) 必须为奇数，保证 n0 和 n2 均为正整数
- 结果范围要求: n0 ≥ 1，n2 ≥ 1

### 参考经验摘要
- 历史模式: 408高频考点，"已知N和n1求n0"为标准考法，几乎每年选择题必出
- 难度锚点: K2=3标准计算，K4=2常规注意点，整体难度3
- 典型陷阱: ①记反 n0=n2+1 方向为 n0=n2-1；②联立时漏减n1项导致n0偏大；③求n0但给出n2的值作为干扰
