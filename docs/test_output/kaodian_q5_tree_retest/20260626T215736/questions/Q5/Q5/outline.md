## 考点
- **二叉树叶子结点数与度为2结点数的关系**：核心公式 n0 = n2 + 1，需准确记忆此性质方可入题
- **二叉树结点总数守恒**：n0 + n1 + n2 = N，需联合两条公式解方程
- 考察侧重点：由已知总结点数 N 和度为1的结点数 n1（或可推出 n1 的等价条件），推算叶子结点 n0

## 难度目标
- K1=2（较低）：需记忆 n0=n2+1 和结点守恒式，但属于高频核心公式，概念门槛不高
- K2=3（标准）：需代入公式做两步联立计算，数字为非2的幂次，存在算错可能
- K3=2（较低）：仅2步代入推导（先算n2，再算n0，或直接联立），路径唯一
- K4=2（较低）：需注意"度为1的结点数"这一条件可能以隐含方式给出（如"完全二叉树"暗示n1取值受限），但属常规注意点
- K5=1（微弱）：单一知识点内部解决，不跨子系统

## 考察模式
计算型——二叉树性质应用。参考408真题中常见的"已知总结点数和度为某的结点数，求另一类结点数"的考法。难度定位为标准计算题，不设深度陷阱，K2为主导维度。

## 出题要求
- 题型：单项选择题，4选项（1正确3干扰），分值2分
- 条件数：2个显式条件（总结点数N + 度为1的结点数n1，或给出可推导n1的等价描述）
- 条件设计原则：
  - 条件1：总结点数N，取值范围为合理范围（如30~127），非2的幂次
  - 条件2：度为1的结点数n1，可为0或1（若给完全二叉树则隐含n1∈{0,1}）
  - 一致性约束：N - n1 必须为奇数，保证 n0 和 n2 均为正整数
- 参数取值范围：
  - N ∈ [30, 127]，避开2的幂次，使心算不平凡
  - n1 ∈ {0, 1}，或通过"完全二叉树/满二叉树"等限定词隐含给出
  - 必须满足 (N - n1) 为奇数且 n0 > 0、n2 > 0

## 子问题规划
本题为单项选择题，无子问题拆分。

## 参数约束
- **总结点数 N**：取值范围 [30, 127]，非2的幂次
- **度为1的结点数 n1**：取值为 0 或 1
- **一致性约束（硬约束）**：(N - n1) % 2 == 1，即 N 与 n1 奇偶性相反
- **可调自由度**：N 可在范围内自由选取；n1 可为0或1（需满足奇偶约束）；条件2可显式给n1值，也可用"完全二叉树"等限定词隐含给出
- **干扰选项设计空间**：
  - 干扰1：误用 n0 = n2 - 1（符号反）→ n0 偏小
  - 干扰2：忘记减 n1，用 n0 = (N+1)/2 → 偏大
  - 干扰3：混淆 n0 与 n2 的结果（求成n2）

## 参考经验
- 该题型在408中为高频考点，几乎每年选择题必出一道二叉树性质计算题
- 典型陷阱：学生记反 n0 = n2 + 1 的方向，或联立时漏掉 n1 项
- 难度锚点：K2=3 为标准计算，不需复杂数字但非平凡；K4=2 说明陷阱为常规注意点级别
