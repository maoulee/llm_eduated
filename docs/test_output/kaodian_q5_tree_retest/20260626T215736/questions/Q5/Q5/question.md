# 题目

**科目**：数据结构  
**题型**：单项选择题  
**难度**：3（标准计算型）  
**考点**：二叉树叶子结点数与度为 2 结点数的关系应用

---

## 题干

一棵有 74 个结点的二叉树，已知其中度为 1 的结点数为 1。则该二叉树的叶子结点数为（　　）。

## 选项

A. 37  
B. 38  
C. 36  
D. 35

---

## 考察意图

- **知识点**：二叉树性质——$n_0 = n_2 + 1$，其中 $n_0$ 为叶子结点数（度为 0），$n_2$ 为度为 2 的结点数。
- **考察模式**：联立 $n_0 = n_2 + 1$ 与 $n_0 + n_1 + n_2 = N$（$N$ 为总结点数）两条公式，两步代入求解 $n_0$。
- **K 目标**：K2=3（标准计算）为主导，K4=2（注意审题区分 $n_0$ 与 $n_2$）。

## 初始参数

| 参数 | 值 | 说明 |
|------|----|------|
| N（总结点数） | 74 | 非二次幂，在 [30,127] 范围内 |
| $n_1$（度为 1 的结点数） | 1 | 显式给出，非零，使干扰项 C 有区分度 |

## 参数一致性检查（硬约束）

- $(N - n_1) = 74 - 1 = 73$，为奇数 → $n_0$、$n_2$ 均为正整数，题目成立。
- N=74 非二次幂 → 计算非平凡。

---

## 场景规则（通过条件 · 可机检）

本题成立需要满足以下参数间约束（与具体答案值无关，换参数仍成立）：

### 通用约束

1. **二叉树度数守恒**：$n_0 + n_1 + n_2 = N$，即叶子 + 度1 + 度2 结点数之和等于总结点数。
2. **二叉树性质公式**：$n_0 = n_2 + 1$，即叶子结点数恰好比度为 2 的结点数多 1。
3. **结果为正整数**：$n_0 \geq 1$ 且 $n_2 \geq 1$（由 $(N - n_1)$ 为奇数保证）。
4. **联立可解且唯一**：由约束 1 和 2 联立，$(n_0, n_2)$ 有唯一正整数解：$n_0 = \frac{(N - n_1) + 1}{2}$，$n_2 = \frac{(N - n_1) - 1}{2}$。

### 选项层约束（选择题特有）

5. **四选项互异**：A/B/C/D 四个计算值各不相同（exec 算出后无碰撞）。
6. **正确值唯一确定**：给定 N=74、$n_1$=1，$n_0$ 有唯一确定值，A=该值；不存在"两个选项都对"的歧义。
7. **干扰项对应声明错误类型**：
   - B = 按记反公式 $n_0 = n_2 - 1$ 联立求解的结果。
   - C = 按 $n_0 + n_2 = N$（未减 $n_1$）联立求解的结果。
   - D = 正确求出后误选 $n_2$ 的值。
8. **干扰项有合理性**：每个干扰项为同类题常见误算的真实产物，非荒谬值，有区分度。

---

## 设问骨架

- **条件数**：2（总结点数 N + 度为 1 的结点数 $n_1$）。
- **计算步数**：2 步——① 联立两式消元；② 解出 $n_0$。
- **干扰策略**：围绕 $n_0 = n_2 + 1$ 公式的三类典型错误——符号记反、漏减 $n_1$、混淆 $n_0$ 与 $n_2$。
