## 第 1 题解析：栈和队列的操作特性

**答案：B**

**解析：**

- **B 正确**：栈是 LIFO（后进先出）结构，插入（入栈）和删除（出栈）操作都在栈顶同一端进行；队列是 FIFO（先进先出）结构，插入操作在队尾、删除操作在队头，两端不同。

- **A 错误**：栈和队列虽然是线性结构，但它们的插入和删除操作受到严格限制，不能在任意位置进行。栈只能在栈顶操作，队列只能在队尾插入、队头删除。

- **C 错误**：选项将栈和队列的特性说反了。栈在同一端操作，队列在不同端操作。

- **D 错误**：栈只在一端（栈顶）操作，队列在两端操作但功能不同（队尾插入、队头删除），并非两者都在两端进行相同操作。

## 第 2 题解析：二叉树的遍历方式

**答案：D**

**解析：**

- **D 错误（即本题答案）**：当二叉树只有一个根节点（空树除外）时，前序遍历和后序遍历的结果都是该根节点本身，第一个节点与最后一个节点是同一个。因此"一定不同"的说法不成立。

- **A 正确**：前序遍历（Preorder）的访问顺序确实是 根 → 左 → 右。

- **B 正确**：中序遍历（Inorder）的访问顺序确实是 左 → 根 → 右。

- **C 正确**：后序遍历（Postorder）的访问顺序确实是 左 → 右 → 根。

## 第 3 题解析：图的存储结构（邻接矩阵 vs 邻接表）

**答案：B**

**解析：**

- **B 正确**：邻接矩阵用 n×n 的二维数组存储，空间复杂度为 O(n²)；邻接表用 n 个头节点 + e 个边节点存储，空间复杂度为 O(n+e)。

- **A 错误**：说反了。邻接矩阵适合稠密图（边数接近 n² 时空间浪费少），邻接表适合稀疏图（边数远小于 n² 时节省空间）。

- **C 错误**：判断两个顶点间是否有边，邻接矩阵只需查矩阵对应位置，时间复杂度 O(1)；邻接表需要遍历对应顶点的边链表，时间复杂度 O(度)，邻接矩阵更高效。

- **D 错误**：两者都能表示带权图。邻接矩阵中矩阵元素存储权值，邻接表中边节点增加权值域即可。

## 第 4 题解析：排序算法的时间复杂度

**答案：B**

**解析：**

- **B 正确**：归并排序无论最好、最坏还是平均情况，都需要进行 logn 层合并，每层合并总代价为 O(n)，因此三种情况的时间复杂度均为 O(nlogn)。

- **A 错误**：快速排序的最好和平均时间复杂度为 O(nlogn)，但最坏情况（每次划分极不平衡，如已有序时选第一个元素为基准）时间复杂度为 O(n²)。

- **C 错误**：冒泡排序的最好时间复杂度为 O(n)（当序列已有序且加入提前终止标志时，只需一趟扫描），而非 O(n²)。

- **D 错误**：堆排序的最好、最坏和平均时间复杂度均为 O(nlogn)，不存在 O(n²) 的情况。

## 第 5 题解析：散列表的冲突处理方法

**答案：D**

**解析：**

- **D 错误（即本题答案）**：线性探测法的主要缺点就是会产生**一次聚集（primary clustering）**现象——一旦某个位置发生冲突，后续探查会连续占用相邻位置，形成聚集块，使得聚集块越来越长，查找效率下降。

- **A 正确**：链地址法（Separate Chaining）的核心思想就是为每个散列地址维护一个链表，所有散列到同一地址的关键字都链接在该链表中。

- **B 正确**：线性探测法（Linear Probing）的探查序列为 H_i = (H(key) + i) % m，i = 0, 1, 2, ...，即发生冲突时依次探查下一个位置。

- **C 正确**：再散列法（Double Hashing / Rehashing）使用多个散列函数 H_1, H_2, ...，当 H_1 发生冲突时尝试 H_2，依此类推。
