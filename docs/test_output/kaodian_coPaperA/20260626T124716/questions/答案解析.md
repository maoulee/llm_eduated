## 一、简答题（4×5=20分）


### 1.

**答案**：阶码位数决定表示范围；尾数位数决定精度；总位数固定时二者此消彼长，需权衡。

**解析**：
- **要点1（阶码决定范围）**：阶码反映浮点数的数量级大小。阶码位数越多，能表示的最大/最小指数范围越大，浮点数的表示范围就越大。
- **要点2（尾数决定精度）**：尾数反映有效数字的位数。尾数位数越多，能表示的有效数字越多，精度就越高。
- **要点3（权衡关系）**：当浮点格式总位数固定时，分配给阶码的位数增多，留给尾数的位数就减少，导致精度下降；反之亦然。因此范围与精度之间存在权衡，需根据应用需求（如科学计算偏重范围、金融计算偏重精度）合理分配。

常见错误：①将阶码与尾数的功能说反（阶码决定精度、尾数决定范围）；②遗漏权衡关系的论述，只回答单方面功能。


### 2.

**答案**：A

**解析**：
- **A 正确**：总线复用正是通过分时使用同一组物理线路传输不同类型信息（地址/数据），从而减少芯片引脚数和连线数，代价是需要增加如 ALE（地址锁存允许）等控制信号来区分当前传输的是地址还是数据。
- **B 错误**：串行总线并非"只含一条信号线"（差分串行如 USB 用两根线），且串行总线完全可以通过分时复用来传输地址和数据等不同信息，"不可能复用"的结论是错误的。
- **C 错误**：系统总线按功能确实分为三类，但它们并不要求物理上必须独立——许多实际系统（如 8086 的 AD0~AD15）采用地址/数据总线复用设计，三类总线物理独立只是非复用方案的特征，不是强制要求。
- **D 错误**：总线复用的目的是减少引脚数和连线数，而非提高带宽。实际上，复用由于需要分时传输，同一批数据需要多个时钟周期才能传完，传输速率反而可能低于不复用的情况。


### 3.

**答案**：B

**解析**：
- **B 正确**：IR（指令寄存器）、MAR（存储器地址寄存器）、MDR（存储器数据寄存器）都是 CPU 在取指和执行阶段的内部工作寄存器，程序员编写的指令无法直接引用或访问它们，属于程序员不可见寄存器。
- **A 错误**：PC（程序计数器）虽然在某些体系结构中可通过转移指令间接修改，但通用寄存器是否可被指令直接访问取决于体系结构设计，不能一概而论地说"程序员可以直接访问 PC"。更重要的是，许多架构中 PC 并不能被通用指令直接读写，A 的表述过于绝对。
- **C 错误**：PSW（程序状态字）对程序员是**可见**的——程序员可以通过条件转移指令利用其中的标志位（如 ZF、CF），在部分架构中还可以通过特殊指令（如 x86 的 LAHF/SAHF 或直接读写 EFLAGS）来访问和修改 PSW 内容。"完全不可见"的说法错误。
- **D 错误**：累加器（ACC）在许多体系结构（如 x86 的 AX、ARM 的 R0）中是程序员**可见**的，程序员的指令可以直接使用它进行运算。"所有体系结构中不可见"是过度绝对化的错误。


### 4.

**答案**：B

**解析**：
- **B 正确**：机器字长是 CPU 一次能处理的二进制数据位数（通常等于 ALU 宽度和通用寄存器宽度）；指令字长是一条机器指令的二进制位数；存储字长是一个存储单元中存放的二进制数据位数。这三者描述不同对象，相互独立，不一定相等（例如某些机器机器字长为 32 位，但指令字长可以是 16 位或变长的）。
- **A 错误**：三者没有必然相等的关系，也不是由系统时钟频率决定——它们分别由 CPU 数据通路宽度、指令集设计和存储器组织方式独立决定。
- **C 错误**：指令字长不一定等于机器字长。许多计算机采用变长指令格式（如 x86 的指令长度从 1 字节到 15 字节不等），指令字长可以小于或大于机器字长；即使定长指令，也未必等于机器字长。
- **D 错误**：存储字长不一定等于机器字长。存储字长取决于存储器芯片的组织方式（如按字节编址时存储字长可为 8 位，而机器字长可为 32 位），二者由不同的设计因素决定。

## 第(1)问：执行阶段微操作序列

### 推导逻辑

指令功能：R1 ← R1 − M[R2]

SUB 定义：Z ← Y − 总线

因此：**Y 须存 R1（被减数），总线须传 M[R2]（减数）**，运算结果 Z = Y − 总线 = R1 − M[R2]，写回 R1。

执行步骤分解：
1. **访存取操作数 M[R2]**：R2 → MAR，Read → MDR
2. **锁存被减数 R1 到 Y**：R1 → 总线 → Yin
3. **送减数 M[R2] 到总线并执行 SUB**：MDRout + SUB → Z = Y − M[R2] = R1 − M[R2]
4. **写回结果到 R1**：Zout + R1in

### 微操作序列表

| 节拍 | 微操作功能描述 | 有效控制信号 |
|------|-------------|------------|
| T1 | R2 的内容（访存地址）送入 MAR | R2out, MARin |
| T2 | 启动存储器读，将 M[R2] 读入 MDR | Read |
| T3 | R1 的内容（被减数）送上总线并写入暂存器 Y（锁存至 ALU 输入端 A） | R1out, Yin |
| T4 | MDR 的内容（操作数 M[R2]）送上总线（ALU 输入端 B），执行减法 Z ← Y − 总线 | MDRout, SUB |
| T5 | 暂存器 Z 的内容（运算结果）写回 R1 | Zout, R1in |

**执行阶段共 5 个节拍。**

### 各节拍分析

- **T1（R2out, MARin）**：将寄存器 R2 的内容（即访存地址）通过总线送入 MAR，为后续访存做准备。
- **T2（Read）**：启动存储器读操作，从地址为 R2 内容的存储单元中读取操作数 M[R2]，结果自动送入 MDR。
- **T3（R1out, Yin）**：将 R1 的内容（被减数）送上总线，写入暂存器 Y。由于 ALU 输入端 A 来自暂存器 Y，此时 Y 锁存了被减数 R1。此节拍只有 R1out 一个输出信号，满足单总线约束。
- **T4（MDRout, SUB）**：将 MDR 的内容（减数 M[R2]）送上总线（到达 ALU 输入端 B），同时发出 SUB 信号，ALU 执行 Z ← Y − 总线 = R1 − M[R2]，结果自动锁存到 Z。此节拍只有 MDRout 一个输出信号，满足单总线约束。
- **T5（Zout, R1in）**：将暂存器 Z 中的运算结果送上总线并写回 R1，完成 R1 ← R1 − M[R2]。此节拍只有 Zout 一个输出信号，满足单总线约束。

---

## 第(2)问：取消暂存器 Y 的方案分析

**方案不可行。**

**原因**：单总线结构中，同一时刻总线只能传输一个数据。取消暂存器 Y 后，ALU 的两个输入端 A 和 B 都连接到同一条内部总线，但单总线无法在同一节拍内同时为两个输入端提供两个不同的操作数。

暂存器 Y 的作用正是在前一节拍锁存一个操作数（R1），使得后一节拍总线可以传输另一个操作数（M[R2]），从而完成 SUB 运算。取消 Y 后此机制失效，无法执行双操作数运算。
