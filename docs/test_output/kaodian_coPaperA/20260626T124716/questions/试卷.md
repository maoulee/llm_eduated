## 一、简答题（4×5=20分）


### 1.

**题干**：在浮点数表示中，阶码和尾数各自承担什么功能？当浮点格式的总位数固定时，增加阶码位数和增加尾数位数分别会产生怎样的影响？请简要论述二者之间的权衡关系。

**答案**：阶码位数决定浮点数的**表示范围**，尾数位数决定浮点数的**精度**。在总位数固定的条件下，增加阶码位数可扩大表示范围但会减少尾数位数从而降低精度；增加尾数位数可提高精度但会减少阶码位数从而缩小表示范围。二者存在此消彼长的权衡关系，设计时需根据应用场景在范围与精度之间取得平衡。

**题干**：下列关于总线分类与总线复用的说法中，正确的是（ ）。

B. 按数据传送方式分类，总线可分为串行总线和并行总线，串行总线只含一条信号线，因此不可能同时传输地址和数据

C. 系统总线按功能分为数据总线、地址总线和控制总线三类，这三类总线在任何计算机系统中都必须是物理上独立的三组线，不能复用

D. 总线复用技术通过在不同时间使用同一组线路传输不同类型信息来提高带宽，复用后总线的数据传输速率一定高于不复用的情况

**答案**：A


### 3.

**题干**：下列关于 CPU 内部寄存器与程序员可见性的叙述中，正确的是（ ）。

A. 程序计数器（PC）和通用寄存器都是程序员可见的，因为程序员的指令可以直接访问它们

B. 指令寄存器（IR）、存储器地址寄存器（MAR）和存储器数据寄存器（MDR）对程序员不可见，因为它们仅供 CPU 在指令执行过程中内部使用

C. 程序状态字（PSW）对程序员不可见，因为其中的标志位由硬件自动设置，程序员无法通过任何指令读取或修改

D. 累加器（ACC）在所有体系结构中都属于程序员不可见的内部寄存器

**答案**：B


### 4.

**题干**：下列关于机器字长、指令字长和存储字长的说法中，正确的是（ ）。

A. 机器字长、指令字长和存储字长在所有计算机中三者一定相等，因为它们都由同一个系统时钟频率决定

B. 机器字长是指 CPU 一次能处理的二进制数据的位数，指令字长是一条指令所包含的二进制位数，存储字长是一个存储单元存放二进制数据的位数，三者相互独立，不一定相等

C. 指令字长一定等于机器字长，因为一条指令必须在一个机器周期内从存储器中取出

D. 存储字长一定等于机器字长，因为存储器是按机器字长编址的

**答案**：B

| 序号 | 虚拟地址（十六进制） |
|------|---------------------|
| ① | 0001 B3F4 |

| ③ | 0007 8ABC |

## 通过条件（可机检特征）

1. **地址结构正确**：虚页号 = 32 − 12 = 20 位，页内偏移 = 12 位；实页号 = 20 − 12 = 8 位，页内偏移 = 12 位。虚拟地址空间 = 2³² B = 4 GB。
2. **地址①转换成立**：虚页号 = 0x0001B，页内偏移 = 0x3F4，装入位 = 1，物理地址 = 实页号 0x4C 拼接偏移 0x3F4 = 0x4C3F4。
3. **地址②转换成立**：虚页号 = 0x0009C，页内偏移 = 0x6E8，装入位 = 1，物理地址 = 0xB3 拼接 0x6E8 = 0xB36E8。
4. **地址③命中缺页陷阱**：虚页号 = 0x00078，装入位 = 0，应判定为缺页中断，**不能**给出物理地址。
5. **实页号位数 < 虚页号位数**（8 < 20），防止学生直接复制虚页号作为实页号——若学生直接复制虚页号，得到的结果位数不对，exec 可检出。

### 2.

某计算机采用**单总线**结构，数据通路包含以下部件：

- **程序计数器 PC**、**指令寄存器 IR**
- **存储器地址寄存器 MAR**、**存储器数据寄存器 MDR**
- **通用寄存器组 R0–R3**（4 个 16 位通用寄存器）
- **暂存器 Y**（锁存 ALU 输入端 A 的数据）、**暂存器 Z**（锁存 ALU 运算结果）
- **算术逻辑单元 ALU**

各部件通过**一条内部总线**互连。ALU 的输入端 A 来自暂存器 Y，输入端 B 来自内部总线，运算结果输出至暂存器 Z。MAR 接收总线数据作为访存地址；MDR 在存储器读操作时将存储器内容送上总线，在写操作时从总线接收数据。

> **ALU 行为说明**：当指定 ALU 运算（ADD 或 SUB）时，运算结果自动锁存到暂存器 Z 中。

### 控制信号定义表

| 控制信号 | 功能说明 |
|---------|---------|
| Riout（i = 0–3） | 通用寄存器 Ri 的内容送上总线 |
| Riin（i = 0–3） | 总线数据写入通用寄存器 Ri |
| MARin | 总线数据写入 MAR |
| MDRin | 总线数据写入 MDR |
| MDRout | MDR 的内容送上总线 |
| Yin | 总线数据写入暂存器 Y |
| Zout | 暂存器 Z 的内容送上总线 |
| Read | 启动存储器读操作（读出数据送入 MDR） |
| Write | 启动存储器写操作（将 MDR 数据写入存储器） |
| ADD | ALU 执行加法：Z ← Y + 总线 |
| SUB | ALU 执行减法：Z ← Y − 总线 |

### 减法指令说明

该机支持的减法指令格式为：**SUB R1, (R2)**，其功能为：

> **R1 ← R1 − M[R2]**

即：以寄存器 R2 的内容作为访存地址，从存储器中读取操作数，用 R1 的当前内容减去该操作数，结果写回 R1。其中 M[R2] 表示地址为 R2 内容的存储单元中的数据。
