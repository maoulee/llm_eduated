# 解题过程：IEEE 754 单精度浮点数表示（-100.4375）

## 题目参数

$$N = -100.4375_{(10)}$$

---

## 第(1)小问：转换为规格化二进制浮点数

### 步骤1：确定符号

-100.4375 为负数，故 **S = 1**。

### 步骤2：分离整数和小数部分

$$|N| = 100 + 0.4375$$

### 步骤3：整数部分转二进制（除2取余）

$$100_{(10)} = 1100100_{(2)}$$

验证：$64 + 32 + 4 = 100$ ✓

### 步骤4：小数部分转二进制（逐位乘2取整）

| 步骤 | 运算 | 整数位 |
|------|------|--------|
| 1 | 0.4375 × 2 = 0.875 | **0** |
| 2 | 0.875 × 2 = 1.75 | **1** |
| 3 | 0.75 × 2 = 1.5 | **1** |
| 4 | 0.5 × 2 = 1.0 | **1** |

$$0.4375_{(10)} = 0.0111_{(2)}$$

有效位数 = 4 位（满足 ≥ 4 的要求）。

### 步骤5：拼合并规格化

完整二进制小数：

$$1100100.0111_{(2)}$$

规格化（小数点左移 6 位，使最高位 1 位于小数点前）：

$$(-1)^1 \times 1.1001000111 \times 2^6$$

**结果：**

- **符号 S = 1**
- **实际指数 E = 6**（十进制）
- **尾数 1.M = 1.1001000111**（含隐含前导 1 的完整形式）

---

## 第(2)小问：计算 IEEE 754 编码各字段

### 符号位（1 位）

$$S = 1$$

### 阶码字段（8 位）

阶码字段 = E + 127 = 6 + 127 = **133**

$$133_{(10)} = 10000101_{(2)}$$

验证：$128 + 4 + 1 = 133$ ✓

阶码字段 = **10000101**

### 尾数字段（23 位）

从规格化形式 $1.\underbrace{1001000111}_{M}$ 中取小数点右边部分，补零至 23 位：

$$M = 1001000111 \quad \text{(10 位)}$$

左对齐补零至 23 位：

$$\text{尾数字段} = 1001000111\underbrace{0000000000000}_{13\text{个0}}$$

$$= \texttt{10010001110000000000000}$$

> **注意**：隐含前导 1 不存储。若误将前导 1 存入尾数字段，将导致编码错误。

---

## 第(3)小问：拼接 32 位并转换为十六进制

### 32 位拼接（从高位到低位）

| 符号位 (1位) | 阶码 (8位) | 尾数 (23位) |
|:---:|:---:|:---|
| 1 | 10000101 | 10010001110000000000000 |

完整 32 位二进制：

$$\texttt{1\;10000101\;10010001110000000000000}$$

即：`11000010110010001110000000000000`

### 4 位分组转十六进制

| 二进制 | 十六进制 |
|--------|----------|
| 1100 | C |
| 0010 | 2 |
| 1100 | C |
| 1000 | 8 |
| 1110 | E |
| 0000 | 0 |
| 0000 | 0 |
| 0000 | 0 |

$$\boxed{0x\text{C2C8E000}}$$

### 交叉验证

使用 Python `struct.pack('>f', -100.4375)` 打包结果为 `0xC2C8E000`，与手动拼接完全一致 ✓

---

## 通过条件核验

| 条件 | 内容 | 结果 |
|------|------|------|
| 条件1 | 小数部分二进制展开有效位数 ≥ 4 | 4 位 ✓ |
| 条件2 | E ∈ [-126, 127]，阶码 ∈ [1, 254] | E=6, 阶码=133 ✓ |
| 条件3 | 尾数隐含前导1不存储，23位补齐 | ✓ |
| 条件4 | 阶码 = E + 127（偏置方向正确） | 6+127=133 ✓ |
| 条件5 | 十六进制 8 位无歧义 | 0xC2C8E000 ✓ |

所有通过条件均满足。

---

## 最终答案

| 小问 | 答案 |
|------|------|
| 第(1)问 | S = 1, E = 6, 1.M = 1.1001000111 |
| 第(2)问 | S = **1**, 阶码 = **10000101** (133), 尾数 = **10010001110000000000000** |
| 第(3)问 | **0xC2C8E000** |
