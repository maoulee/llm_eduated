# 计算题：IEEE 754 单精度浮点数表示（10分）

## 题干

已知某计算机采用 **IEEE 754 单精度浮点数标准**（32位），其格式为：符号位 1 位 + 阶码 8 位（偏置值 bias = 127）+ 尾数 23 位（含隐含前导 1）。现有十进制数：

$$N = -100.4375_{(10)}$$

请将其转换为 IEEE 754 单精度浮点数的二进制表示，并写出对应的十六进制表示。

### 第(1)小问（4分）

将十进制数 $-100.4375_{(10)}$ 转换为**规格化二进制浮点数**，写出规格化后的形式 $(-1)^S \times 1.M \times 2^E$，并给出符号 $S$、实际指数 $E$（十进制）、尾数 $M$（二进制，含隐含前导 1 写出完整形式）。

### 第(2)小问（3分）

计算 IEEE 754 编码各字段：
- 符号位（1 位二进制）；
- 阶码字段（8 位二进制，即 $E + 127$）；
- 尾数字段（23 位二进制，隐含前导 1 不存储，补零至 23 位）。

### 第(3)小问（3分）

将上述 32 位二进制编码按从高位到低位拼接，以 **8 位十六进制数**写出最终结果。

## 答题要求

1. 完整写出每一步中间结果，不可跳步。
2. 小数部分二进制展开须逐位写出，不得省略。
3. 尾数字段必须补齐 23 位（高位不足补零）。
4. 十六进制输出必须为 8 位（前导零不可省略），格式如 `0xXXXXXXXX`。

## 通过条件（成功判据，供机检）

本题成立需满足以下可机检特征：

1. **参数有效性**：十进制小数部分 $0.4375$ 的二进制展开有效位数 $\geq 4$（排除 $\leq 3$ 位的平凡值）。
2. **指数在正常范围**：规格化后实际指数 $E$ 满足 $-126 \leq E \leq +127$，对应阶码字段值在 $1 \sim 254$ 之间（不触碰特殊值边界 0 或 255）。
3. **隐含前导 1 正确处理**：尾数字段（23 位）隐含前导 1 不被存储，23 位字段内容为规格化后 $1.M$ 中小数点右边部分左对齐补零；若误将前导 1 存入或遗漏偏置方向，结果与正确值不同。
4. **偏置方向正确**：阶码字段 $= E + 127$（而非 $E - 127$ 或 $127 - E$），偏置方向错误将产生不同的阶码值。
5. **十六进制输出可验证**：最终 8 位十六进制数可由 32 位二进制按 4 位分组唯一确定，不存在多义性。
