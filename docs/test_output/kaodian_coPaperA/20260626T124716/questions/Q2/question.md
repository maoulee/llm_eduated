## 第 2 题

**题干**：下列关于总线分类与总线复用的说法中，正确的是（ ）。

A. 地址总线和数据总线采用分时复用方式时，一条物理线在不同时刻分别传输地址和数据，可以减少总线引脚数，但需要增加控制信号来区分当前传输内容

B. 按数据传送方式分类，总线可分为串行总线和并行总线，串行总线只含一条信号线，因此不可能同时传输地址和数据

C. 系统总线按功能分为数据总线、地址总线和控制总线三类，这三类总线在任何计算机系统中都必须是物理上独立的三组线，不能复用

D. 总线复用技术通过在不同时间使用同一组线路传输不同类型信息来提高带宽，复用后总线的数据传输速率一定高于不复用的情况

**答案**：A
