## 考点
- **核心知识点**：浮点数表示中阶码位数与尾数位数的功能分工
  - 阶码位数 → 决定浮点数的表示范围（能表示的最大/最小数量级）
  - 尾数位数 → 决定浮点数的精度（有效数字位数）
  - 二者的权衡关系：总位数固定时，阶码位数增加则范围增大但精度降低，反之亦然
- **辅助知识点**：IEEE 754 或通用浮点格式中阶码/尾数的位数分配方式（作为论述时的支撑论据）

## 难度目标
- **K1 = 4**：需精准辨析"阶码决定范围、尾数决定精度"这一易混概念对，且需准确阐述二者权衡关系，属于概念辨析型记忆考察
- **K2 = 1**：纯文字论述，无数值计算
- **K3 = 1**：无需多步推演，直接论述概念关系
- **K4 = 2**：存在常规注意点——学生易将阶码与尾数的功能说反，需准确区分
- **K5 = 1**：单一知识点内部解决，不涉及跨子系统

## 考察模式
**概念辨析型——定义论述**：要求考生以文字形式论述浮点数阶码位数和尾数位数各自的功能，以及二者在总位数固定时的权衡关系。该模式与 slot 指定的 examination_mode 一致，适合简答题（5分）的考查形式。参考 concept_topics 中"【概念辨析型】浮点数表示范围与精度"的定位。

## 出题要求
- **题型**：简答题（文字论述）
- **分值**：5分
- **条件数**：1个核心设问条件（给定总位数固定的浮点格式，要求论述阶码/尾数分配对范围与精度的影响）
- **条件设计原则**：
  - 设问应明确要求考生回答两个层面：①阶码位数的功能 + ②尾数位数的功能 + ③二者权衡关系
  - 可给定一个"总位数固定"的约束场景，引导考生讨论权衡
  - 不要求考生做具体数值计算，纯概念论述
- **参数要求**：题目若提及具体格式（如IEEE 754），应作为论述背景而非计算对象；不要求考生计算具体范围数值

## 子问题规划
本题为简答题，可拆为以下论述要点（非独立子问，而是评分要点）：
- **要点1**（2分）：阐述阶码位数决定浮点数的表示范围——阶码位数越多，能表示的数值范围越大
- **要点2**（2分）：阐述尾数位数决定浮点数的精度——尾数位数越多，有效数字越多，精度越高
- **要点3**（1分）：阐述权衡关系——总位数固定时，增加阶码位数会减少尾数位数，导致范围增大但精度降低，反之亦然

## 参数约束
- **总位数**（如提及）：取值范围为 32 或 64 等标准格式位数，仅作背景说明，不作计算
- **阶码位数**（如提及）：作为论述对象，不需指定具体值
- **尾数位数**（如提及）：作为论述对象，不需指定具体值
- **一致性约束**：题目若给出具体格式（如 IEEE 754 单精度），阶码和尾数位数须符合标准定义（8位阶码 + 23位尾数），但仅作背景，不要求展开计算
