# 概念题

## 第 1 题

**题干**：在浮点数表示中，阶码和尾数各自承担什么功能？当浮点格式的总位数固定时，增加阶码位数和增加尾数位数分别会产生怎样的影响？请简要论述二者之间的权衡关系。

**答案**：阶码位数决定浮点数的**表示范围**，尾数位数决定浮点数的**精度**。在总位数固定的条件下，增加阶码位数可扩大表示范围但会减少尾数位数从而降低精度；增加尾数位数可提高精度但会减少阶码位数从而缩小表示范围。二者存在此消彼长的权衡关系，设计时需根据应用场景在范围与精度之间取得平衡。

## 第 2 题

**题干**：下列关于总线分类与总线复用的说法中，正确的是（ ）。

A. 地址总线和数据总线采用分时复用方式时，一条物理线在不同时刻分别传输地址和数据，可以减少总线引脚数，但需要增加控制信号来区分当前传输内容

B. 按数据传送方式分类，总线可分为串行总线和并行总线，串行总线只含一条信号线，因此不可能同时传输地址和数据

C. 系统总线按功能分为数据总线、地址总线和控制总线三类，这三类总线在任何计算机系统中都必须是物理上独立的三组线，不能复用

D. 总线复用技术通过在不同时间使用同一组线路传输不同类型信息来提高带宽，复用后总线的数据传输速率一定高于不复用的情况

**答案**：A

## 第 3 题

**题干**：下列关于 CPU 内部寄存器与程序员可见性的叙述中，正确的是（ ）。

A. 程序计数器（PC）和通用寄存器都是程序员可见的，因为程序员的指令可以直接访问它们

B. 指令寄存器（IR）、存储器地址寄存器（MAR）和存储器数据寄存器（MDR）对程序员不可见，因为它们仅供 CPU 在指令执行过程中内部使用

C. 程序状态字（PSW）对程序员不可见，因为其中的标志位由硬件自动设置，程序员无法通过任何指令读取或修改

D. 累加器（ACC）在所有体系结构中都属于程序员不可见的内部寄存器

**答案**：B

## 第 4 题

**题干**：下列关于机器字长、指令字长和存储字长的说法中，正确的是（ ）。

A. 机器字长、指令字长和存储字长在所有计算机中三者一定相等，因为它们都由同一个系统时钟频率决定

B. 机器字长是指 CPU 一次能处理的二进制数据的位数，指令字长是一条指令所包含的二进制位数，存储字长是一个存储单元存放二进制数据的位数，三者相互独立，不一定相等

C. 指令字长一定等于机器字长，因为一条指令必须在一个机器周期内从存储器中取出

D. 存储字长一定等于机器字长，因为存储器是按机器字长编址的

**答案**：B
