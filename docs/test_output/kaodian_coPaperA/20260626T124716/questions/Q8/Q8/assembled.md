## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: CO-3 存储系统 > 虚拟存储器
- primary_target_name: 页式虚拟存储器地址转换
- question_type: comprehensive
- examination_mode: 计算型——地址转换与页表查询

### 难度目标
- k_target: K1=2,K2=3,K3=4,K4=3,K5=1
- difficulty_level: 3
- difficulty_rationale: 多步串行推演（拆地址→查页表→判装入位→拼实地址），对多地址重复流程，K3=4 主导；K4=3 来自装入位=0 缺页判断陷阱

### 结构要求
- sub_question_count: 2
- sub_question_types: [计算分析, 计算推导]
- sub_question_scores: [3, 7]
- sub_question_dependency: serial（第1问地址结构 → 第2问地址转换）
- condition_count: 3–4（虚拟地址空间大小、物理地址空间大小、页大小、页表表格）

### 干扰/陷阱策略（计算题）
- 至少 1 个待转换虚地址命中装入位=0 的页 → 学生须判断缺页而非强行转换
- 十六进制地址拆分位界对齐 → 考验位宽计算准确性
- 实页号位数 < 虚页号位数 → 考验地址结构理解，防止直接复制虚页号

### 参数约束
- 虚拟地址位数: 32（典型值）；可调整但须为常用值
- 物理地址位数: 须 < 虚拟地址位数，典型范围 16–24；使实页号位数 < 虚页号位数
- 页内偏移位数: 12（对应 4KB 页大小），标准值
- 页表条目数: 6–10 行，装入位=1 和装入位=0 各若干行
- 待转换虚地址: 2–3 个十六进制地址，至少 1 个对应装入位=0 的页
- 实页号范围约束: 每个实页号 < 2^(物理地址位数 - 页内偏移位数)
- 虚页号范围约束: 待转换地址的虚页号须在页表覆盖范围内
- 自由度: 物理地址位数、页表映射关系、待转换地址均可自由设定（在约束内）

### 参考经验摘要
- 历史模式: 页式虚拟存储器地址转换——拆地址→查页表→判装入位→拼地址，408 高频考法
- 难度锚点: K3=4 对应多地址重复转换累积步骤；K4=3 对应缺页判断陷阱
- 典型陷阱: 装入位=0 仍拼接地址 / 十六进制位界对齐错误 / 实页号位数取错
