# 页式虚拟存储器地址转换

## 系统参数

某计算机采用**按字节编址**，系统参数如下：

| 参数 | 值 |
|------|----|
| 虚拟地址位数 | 32 位 |
| 物理地址位数 | 20 位 |
| 页大小 | 4 KB |
| 地址编址方式 | 按字节编址 |

系统采用**页式虚拟存储管理**，页表中每个表项包含**实页号**和**装入位**两个字段。部分页表内容如下：

| 虚页号 | 实页号 | 装入位 |
|--------|--------|--------|
| 0000A | 2F | 1 |
| 0001B | 4C | 1 |
| 0003F | 1A | 1 |
| 00052 | 00 | 1 |
| 00078 | 9D | 0 |
| 0009C | B3 | 1 |
| 000B5 | 71 | 1 |
| 000C0 | 3E | 0 |

> 上表中所有页号均为十六进制表示。

---

## 第 1 问（3 分）

根据上述系统参数，计算并写出：

1. 虚拟地址中**虚页号**占多少位？**页内偏移**占多少位？
2. 物理地址中**实页号**占多少位？**页内偏移**占多少位？
3. 该系统的虚拟地址空间大小是多少 GB？（写出计算过程）

---

## 第 2 问（7 分）

将以下三个十六进制虚拟地址转换为物理地址（若无法转换，请说明原因并指出缺页）：

| 序号 | 虚拟地址（十六进制） |
|------|---------------------|
| ① | 0001 B3F4 |
| ② | 0009 C6E8 |
| ③ | 0007 8ABC |

对每个虚拟地址，写出转换过程：拆分虚页号与页内偏移 → 查页表判断装入位 → 若装入位为 1 则拼出物理地址（十六进制），若装入位为 0 则判定为缺页中断。

---

## 通过条件（可机检特征）

1. **地址结构正确**：虚页号 = 32 − 12 = 20 位，页内偏移 = 12 位；实页号 = 20 − 12 = 8 位，页内偏移 = 12 位。虚拟地址空间 = 2³² B = 4 GB。
2. **地址①转换成立**：虚页号 = 0x0001B，页内偏移 = 0x3F4，装入位 = 1，物理地址 = 实页号 0x4C 拼接偏移 0x3F4 = 0x4C3F4。
3. **地址②转换成立**：虚页号 = 0x0009C，页内偏移 = 0x6E8，装入位 = 1，物理地址 = 0xB3 拼接 0x6E8 = 0xB36E8。
4. **地址③命中缺页陷阱**：虚页号 = 0x00078，装入位 = 0，应判定为缺页中断，**不能**给出物理地址。
5. **实页号位数 < 虚页号位数**（8 < 20），防止学生直接复制虚页号作为实页号——若学生直接复制虚页号，得到的结果位数不对，exec 可检出。
