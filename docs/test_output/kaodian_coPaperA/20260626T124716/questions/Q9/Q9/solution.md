# Cache 全相联映射分析 —— 求解过程

## 参数汇总

| 参数 | 值 |
|------|-----|
| 主存容量 M | $2^{20}$ 字节（1 MB） |
| 主存地址位数 | 20 位 |
| 块大小 B | 32 字节（$2^5$） |
| Cache 行数 L | 4 |
| 映射方式 | 全相联映射 |
| 替换算法 | LRU |
| Cache 初始状态 | 全空（V = 0） |

---

## 问题 1（3 分）：主存地址分解

### (1) 地址分解

主存地址共 20 位。在**全相联映射**方式下，主存地址仅分为两个字段（无组号/行号字段）：

| 字段名称 | 位数 | 含义 |
|----------|------|------|
| **主存块号**（Block Number） | 15 位 | 标识主存中的块号，主存共 $2^{20}/2^5 = 2^{15}$ 个块 |
| **块内偏移**（Block Offset） | 5 位 | 标识块内字节地址，块大小 $32 = 2^5$ 字节 |

验证：$15 + 5 = 20$ 位，与主存地址位数一致。✓

### (2) Tag 字段位数与含义

全相联映射下，Cache 中 Tag 字段的位数 = **15 位**。

- **Tag 与主存地址的主存块号字段完全相同**（15 位）。
- **原因**：全相联映射中，任何一个主存块都可以映射到 Cache 的任意一行。因此地址中没有用于确定 Cache 行号的"组号/行号"字段，整个块号都作为 Tag 存储在 Cache 行中，用于在命中比较时唯一标识该块。

## 问题 2（5 分）：访存序列逐次分析

每地址的主存块号 = 字节地址 ÷ 32（块大小）。

| 序号 | 地址（十进制） | 地址（十六进制） | 主存块号 | 结果 | 装入/替换行 | Tag 值 | 说明 |
|------|---------------|-----------------|---------|------|-----------|--------|------|
| ① | 0 | 0x00000 | 0 | **MISS** | 装入行0 | Tag=0 | Cache 空，装入空行0，V=1 |
| ② | 96 | 0x00060 | 3 | **MISS** | 装入行1 | Tag=3 | 行1空，装入，V=1 |
| ③ | 32 | 0x00020 | 1 | **MISS** | 装入行2 | Tag=1 | 行2空，装入，V=1 |
| ④ | 0 | 0x00000 | 0 | **HIT** | — | Tag=0 | 块0已在行0，命中，更新行0的LRU |
| ⑤ | 160 | 0x000A0 | 5 | **MISS** | 装入行3 | Tag=5 | 行3空，装入，V=1（4行全部占用） |
| ⑥ | 224 | 0x000E0 | 7 | **MISS** | LRU替换行1 | Tag=7 | 4行已满，行1（Tag=3）为LRU行，被替换 |
| ⑦ | 96 | 0x00060 | 3 | **MISS** | LRU替换行2 | Tag=3 | 块3已被替换出，行2（Tag=1）为LRU行，被替换 |
| ⑧ | 1024 | 0x00400 | 32 | **MISS** | LRU替换行0 | Tag=32 | 行0（Tag=0）为LRU行，被替换 |

### 逐步分析说明

- **①** 地址0 → 块号0，Cache 全空，装入行0（Tag=0, V=1）。当前各行 LRU 时间戳：行0最新。
- **②** 地址96 → 块号3，行0 已占用但 Tag≠3，行1 空，装入行1（Tag=3, V=1）。
- **③** 地址32 → 块号1，行0~1 已占用但 Tag≠1，行2 空，装入行2（Tag=1, V=1）。
- **④** 地址0 → 块号0，行0 Tag=0 匹配 → **命中**，更新行0 的 LRU 时间戳为最新。
- **⑤** 地址160 → 块号5，行0~2 已占用但 Tag≠5，行3 空，装入行3（Tag=5, V=1）。此时4行全部被占用。
- **⑥** 地址224 → 块号7，4行 Tag 分别为 0,3,1,5，均≠7 → 缺失。LRU 策略选最近最少使用的行。此时行1（Tag=3）时间戳最小（步骤②后未被更新）→ **替换行1**，装入块7（Tag=7）。
- **⑦** 地址96 → 块号3。块3原在行1，但已在步骤⑥被替换，故缺失。LRU 选行2（Tag=1，步骤③后未被更新）→ **替换行2**，装入块3（Tag=3）。
- **⑧** 地址1024 → 块号32，4行 Tag 为 0,7,3,5，均≠32 → 缺失。LRU 选行0（Tag=0，虽步骤④命中更新，但步骤⑥⑦更新了行1行2，步骤⑤更新了行3，故行0此时时间戳最小）→ **替换行0**，装入块32（Tag=32）。

### 访问结束后 Cache 各行状态

| 行号 | 有效位 V | Tag |
|------|---------|-----|
| 行0 | V=1 | 32 |
| 行1 | V=1 | 7 |
| 行2 | V=1 | 3 |
| 行3 | V=1 | 5 |

## 问题 3（2 分）：命中率

| 统计项 | 值 |
|--------|-----|
| 总访问次数 | 8 |
| 命中次数 | 1（仅步骤④命中） |
| 缺失次数 | 7 |
| **命中率** | $1/8 = 12.5\%$ |

$$\text{命中率} = \frac{\text{命中次数}}{\text{总访问次数}} = \frac{1}{8} = 12.5\%$$

---

## 答案汇总

| 问题 | 答案 |
|------|------|
| Q1 | 主存块号 15 位 + 块内偏移 5 位；Tag = 15 位 = 整个块号（全相联映射无组号/行号字段） |
| Q2 | 命中 1 次（步骤④），缺失 7 次，3 次 LRU 替换（步骤⑥⑦⑧）；最终 Cache：行0 Tag=32, 行1 Tag=7, 行2 Tag=3, 行3 Tag=5，全部 V=1 |
| Q3 | 命中率 = $1/8 = 12.5\%$ |
