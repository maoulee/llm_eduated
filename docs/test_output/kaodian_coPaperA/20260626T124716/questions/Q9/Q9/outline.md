## 考点
- **核心考点**：Cache 全相联映射规则
  - 考察侧重点：全相联映射下主存块可装入 Cache 任意行，无固定映射关系
- **辅助考点1**：主存地址分解（块地址 / 块内偏移）
  - 考察侧重点：根据主存块大小和主存容量计算块地址位数与偏移位数
- **辅助考点2**：Cache 行标志 Tag 计算
  - 考察侧重点：全相联映射下 Tag = 主存块号全部位，需根据给定地址推导各行 Tag 值
- **辅助考点3**：数据装入与替换分析
  - 考察侧重点：给定一系列访存地址，按全相联映射规则逐块装入 Cache，分析装入后的 Cache 行内容（Tag + 有效位 + 数据来源块号）
- **辅助考点4**：命中率计算
  - 考察侧重点：根据访存序列统计命中次数，计算命中率

## 难度目标
- **K1=2（较低）**：需知道全相联映射的基本概念和地址分解方法，但概念明确、不易混淆，顺着题干可入题
- **K2=3（标准）**：需代入公式计算地址位数（log2 运算）、Tag 值（二进制转换）、命中率（除法），数字可能涉及非 2 的幂次的地址值
- **K3=4（较高）**：需按全相联映射规则对一串访存地址逐步推演装入过程，步数 >5，且需维护 Cache 当前状态（哪些行已占用、哪些被替换），动态状态更新是核心难点
- **K4=3（标准）**：存在陷阱——全相联映射下无组号/行号字段，Tag 即整个块号；学生可能误用直接映射或组相联映射的地址分解方式
- **K5=1（微弱）**：单一知识点（Cache 映射）内部解决，不涉及其他子系统

**K3 主导**：本题核心是逐步推演 Cache 装入过程并维护状态，推演步数多、需动态更新，是难度的主要来源。

## 出题要求
- **题型**：分析题（综合题），总分 10 分
- **总条件数**：3-4 个显式条件
  - 条件1：主存容量与块大小（如"主存按字节编址，容量为 X，Cache 数据块大小为 Y 字节"）
  - 条件2：Cache 容量与行数（如"Cache 总容量为 Z，采用全相联映射方式，替换算法为 LRU/FIFO"）
  - 条件3：访存地址序列（一组主存地址或主存块号，用于推演装入过程）
  - 条件4（可选）：写入策略或命中判断规则的补充说明
- **条件设计原则**：
  - 参数均为 2 的幂次，降低 K2 中地址位数计算的心算负担
  - 访存序列需包含重复访问（产生命中）和容量溢出（产生替换），使命中率非平凡、替换分析有意义
  - 主存块大小与 Cache 行数之比要保证访存序列中至少触发 1 次替换
- **参数取值范围要求**：
  - 主存容量：2^16 ~ 2^24 字节量级
  - 块大小：2^4 ~ 2^7 字节（保证偏移位数为 4-7 位）
  - Cache 行数：4-8 行（足够支持多步推演但不过于繁琐）
  - 访存序列长度：6-10 个地址（含重复和冲突）
  - 地址值需为块大小的整数倍（或明确给出块内偏移，使分析聚焦于块级映射）

## 子问题规划
| 子问题 | 类型 | 考察目标 | 分值 | 依赖关系 |
|--------|------|----------|------|----------|
| 第1问 | 计算 | 主存地址分解：给定块大小和主存容量，计算块内偏移位数和主存块号位数，并说明全相联映射下 Tag 的位数和含义 | 3分 | 无前置依赖，为后续问建立地址分解基础 |
| 第2问 | 分析 | 逐个分析访存地址的映射过程，给出最终 Cache 各行的 Tag 值和装入的主存块号（需标记有效位、替换情况） | 5分 | 依赖第1问的地址分解结果；核心推演问 |
| 第3问 | 计算 | 根据访存序列计算 Cache 命中率（命中次数/总访问次数） | 2分 | 依赖第2问的装入过程分析结果 |

**依赖关系**：串行（第1问 → 第2问 → 第3问），前一问结果为后一问基础。

## 参数约束
- **主存容量 M**：取值范围 2^16 ~ 2^24 字节，需为 2 的幂次
- **块大小 B**：取值范围 2^4 ~ 2^7 字节，需为 2 的幂次
- **Cache 行数 L**：取值范围 4-8 行
- **约束关系**：
  - M / B = 主存块数，需 ≥ L（主存块数远多于 Cache 行数，保证替换分析有意义）
  - 主存块号位数 = log2(M / B)，Tag 位数 = 主存块号位数（全相联映射）
  - 偏移位数 = log2(B)
- **访存序列**：6-10 个地址
  - 序列约束：至少 1 个地址重复 ≥2 次（产生命中）
  - 序列约束：访问的不同主存块数 > L（触发至少 1 次替换）
  - 地址可为字节地址或块号，但需统一格式且与第1问地址分解一致
- **替换算法**：LRU 或 FIFO，需明确指定
- **可调自由度**：Question Agent 可在上述范围内自由选择具体参数值和访存序列
