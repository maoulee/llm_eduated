## 题目

某计算机的主存按字节编址，主存容量为 $2^{20}$ 字节（即 1 MB）。CPU 与主存之间设有 Cache，采用**全相联映射**方式，替换算法为 **LRU**（最近最少使用）。Cache 共有 **4 行**，每行大小（块大小）为 **32 字节（$2^5$ 字节）**。

Cache 的每一行包含：有效位 V、Tag 标记、以及 32 字节的数据块。初始时所有行的有效位 V = 0（Cache 为空）。

### 问题 1（3 分）

主存地址为 **20 位**字节地址。请在全相联映射方式下：

(1) 将主存地址分解为各字段，说明各字段的名称、位数及含义；（2 分）

(2) 指出 Cache 中 Tag 字段的位数，并说明 Tag 字段与主存地址哪个字段相同、为什么。（1 分）

### 问题 2（5 分）

给定如下访存地址序列（均为字节地址），请按访问顺序逐次分析每个访存地址在 Cache 中的命中/缺失情况及 Cache 状态变化。假设 Cache 初始为空。

| 序号 | 访存地址（十进制） | 访存地址（十六进制） |
|------|-------------------|---------------------|
| ①    | 0                 | 0x00000             |
| ②    | 96                | 0x00060             |
| ③    | 32                | 0x00020             |
| ④    | 0                 | 0x00000             |
| ⑤    | 160               | 0x000A0             |
| ⑥    | 224               | 0x000E0             |
| ⑦    | 96                | 0x00060             |
| ⑧    | 1024              | 0x00400             |

请对每次访问，列出：
- 该地址对应的**主存块号**；
- 命中（HIT）或缺失（MISS）；
- 若 MISS，装入 Cache 的哪一行（或替换了哪一行），给出该行的 **Tag 值**和有效位变化。

最终给出访问结束后 Cache 各行的状态（行号、有效位、Tag）。

### 问题 3（2 分）

根据问题 2 的访存序列，计算该序列的 Cache **命中率**（命中次数 / 总访问次数），结果用分数和百分比表示。

---

## 参考答案

**问题 1：**
- (1) 主存地址分为**主存块号（15 位）** + **块内偏移（5 位）**，共 20 位。
- (2) Cache 中 **Tag = 15 位**，与主存地址的**主存块号**字段完全相同。全相联映射无组号/行号字段，整个块号作为 Tag 用于命中比较。

**问题 2：**

| 序号 | 地址 | 主存块号 | 结果 | 装入/替换行 | Tag 值 |
|------|------|---------|------|-----------|--------|
| ① | 0 | 0 | MISS | 装入行0 | 0 |
| ② | 96 | 3 | MISS | 装入行1 | 3 |
| ③ | 32 | 1 | MISS | 装入行2 | 1 |
| ④ | 0 | 0 | **HIT** | — | 0 |
| ⑤ | 160 | 5 | MISS | 装入行3 | 5 |
| ⑥ | 224 | 7 | MISS | LRU 替换行1 | 7 |
| ⑦ | 96 | 3 | MISS | LRU 替换行2 | 3 |
| ⑧ | 1024 | 32 | MISS | LRU 替换行0 | 32 |

访问结束后 Cache 各行状态：

| 行号 | 有效位 V | Tag |
|------|---------|-----|
| 行0 | 1 | 32 |
| 行1 | 1 | 7 |
| 行2 | 1 | 3 |
| 行3 | 1 | 5 |

**问题 3：** 命中率 = $1/8 = 12.5\%$

## 解析

### 问题 1 解析

主存地址共 20 位。在**全相联映射**方式下，主存地址仅分为两个字段（无组号/行号字段）：

| 字段名称 | 位数 | 含义 |
|----------|------|------|
| **主存块号**（Block Number） | 15 位 | 标识主存中的块号，主存共 $2^{20}/2^5 = 2^{15}$ 个块 |
| **块内偏移**（Block Offset） | 5 位 | 标识块内字节地址，块大小 $32 = 2^5$ 字节 |

验证：$15 + 5 = 20$ 位，与主存地址位数一致。✓

全相联映射下，Cache 中 Tag 字段的位数 = **15 位**。

- **Tag 与主存地址的主存块号字段完全相同**（15 位）。
- **原因**：全相联映射中，任何一个主存块都可以映射到 Cache 的任意一行。因此地址中没有用于确定 Cache 行号的"组号/行号"字段，整个块号都作为 Tag 存储在 Cache 行中，用于在命中比较时唯一标识该块。

### 问题 2 解析

每地址的主存块号 = 字节地址 ÷ 32（块大小）。

**逐步分析：**

- **①** 地址 0 → 块号 0，Cache 全空，装入空行 0（Tag=0, V=1）。
- **②** 地址 96 → 块号 3，行 0 已占用但 Tag≠3，行 1 空，装入行 1（Tag=3, V=1）。
- **③** 地址 32 → 块号 1，行 0~1 已占用但 Tag≠1，行 2 空，装入行 2（Tag=1, V=1）。
- **④** 地址 0 → 块号 0，行 0 Tag=0 匹配 → **命中**，更新行 0 的 LRU 时间戳为最新。
- **⑤** 地址 160 → 块号 5，行 0~2 已占用但 Tag≠5，行 3 空，装入行 3（Tag=5, V=1）。此时 4 行全部被占用。
- **⑥** 地址 224 → 块号 7，4 行 Tag 分别为 0, 3, 1, 5，均≠7 → 缺失。LRU 策略选最近最少使用的行。此时行 1（Tag=3）时间戳最小（步骤②后未被更新）→ **替换行 1**，装入块 7（Tag=7）。
- **⑦** 地址 96 → 块号 3。块 3 原在行 1，但已在步骤⑥被替换出，故缺失。LRU 选行 2（Tag=1，步骤③后未被更新）→ **替换行 2**，装入块 3（Tag=3）。
- **⑧** 地址 1024 → 块号 32，4 行 Tag 为 0, 7, 3, 5，均≠32 → 缺失。LRU 选行 0（Tag=0，虽步骤④命中更新，但步骤⑥⑦更新了行 1 行 2，步骤⑤更新了行 3，故行 0 此时时间戳最小）→ **替换行 0**，装入块 32（Tag=32）。

**总结：** 8 次访问中命中 1 次（步骤④），缺失 7 次，其中 3 次 LRU 替换（步骤⑥⑦⑦⑧）。

### 问题 3 解析

| 统计项 | 值 |
|--------|-----|
| 总访问次数 | 8 |
| 命中次数 | 1（仅步骤④命中） |
| 缺失次数 | 7 |

$$\text{命中率} = \frac{\text{命中次数}}{\text{总访问次数}} = \frac{1}{8} = 12.5\%$$
