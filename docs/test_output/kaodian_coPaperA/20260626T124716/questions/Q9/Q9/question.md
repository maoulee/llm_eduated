# Cache 全相联映射分析

## 题目背景

某计算机的主存按字节编址，主存容量为 $2^{20}$ 字节（即 1 MB）。CPU 与主存之间设有 Cache，采用**全相联映射**方式，替换算法为 **LRU**（最近最少使用）。Cache 共有 **4 行**，每行大小（块大小）为 **32 字节（$2^5$ 字节）**。

Cache 的每一行包含：有效位 V、Tag 标记、以及 32 字节的数据块。初始时所有行的有效位 V = 0（Cache 为空）。

---

## 问题

### 问题 1（3 分）

主存地址为 **20 位**字节地址。请在全相联映射方式下：

(1) 将主存地址分解为各字段，说明各字段的名称、位数及含义；（2 分）

(2) 指出 Cache 中 Tag 字段的位数，并说明 Tag 字段与主存地址哪个字段相同、为什么。（1 分）

### 问题 2（5 分）

给定如下访存地址序列（均为字节地址），请按访问顺序逐次分析每个访存地址在 Cache 中的命中/缺失情况及 Cache 状态变化。假设 Cache 初始为空。

| 序号 | 访存地址（十进制） | 访存地址（十六进制） |
|------|-------------------|---------------------|
| ①    | 0                 | 0x00000             |
| ②    | 96                | 0x00060             |
| ③    | 32                | 0x00020             |
| ④    | 0                 | 0x00000             |
| ⑤    | 160               | 0x000A0             |
| ⑥    | 224               | 0x000E0             |
| ⑦    | 96                | 0x00060             |
| ⑧    | 1024              | 0x00400             |

请对每次访问，列出：
- 该地址对应的**主存块号**；
- 命中（HIT）或缺失（MISS）；
- 若 MISS，装入 Cache 的哪一行（或替换了哪一行），给出该行的 **Tag 值**和有效位变化。

最终给出访问结束后 Cache 各行的状态（行号、有效位、Tag）。

### 问题 3（2 分）

根据问题 2 的访存序列，计算该序列的 Cache **命中率**（命中次数 / 总访问次数），结果用分数和百分比表示。

---

## 参数汇总

| 参数 | 值 |
|------|-----|
| 主存容量 $M$ | $2^{20}$ 字节（1 MB） |
| 主存地址位数 | 20 位 |
| 块大小 $B$ | 32 字节（$2^5$） |
| Cache 行数 $L$ | 4 |
| 映射方式 | 全相联映射 |
| 替换算法 | LRU |
| Cache 初始状态 | 全空（V = 0） |
| 访存序列长度 | 8 |
| 访存序列中不同主存块数 | 6（块号：0, 1, 3, 5, 7, 32） |

---

## 通过条件（成功判据）

本题成立需满足以下可机检特征：

1. **地址分解正确且符合全相联映射特征**：偏移位数 = 5，块号位数 = 15，Tag 位数 = 15（Tag = 整个块号，无组号/行号字段）。

2. **访存序列触发至少 1 次替换**：8 次访问涉及 6 个不同主存块，而 Cache 仅 4 行，因此至少 2 次缺失装入会触发 LRU 替换（不是简单装入空行）。可机检特征：访问序列中存在某次 MISS 时 Cache 所有 4 行均已被占用（有效位全为 1）。

3. **访存序列产生至少 1 次命中**：序列中块 0（地址 0）在第 ④ 步重复访问，块 3（地址 96）在第 ⑦ 步重复访问，二者至少有一个在第 ④ 步应命中。可机检特征：命中率 > 0（命中次数 ≥ 1）。

4. **命中率可由序列确定地计算**：总访问次数 = 8，命中次数为确定的正整数（1 ≤ 命中次数 ≤ 3），命中率 = 命中次数 / 8。

5. **替换分析结果唯一**：在给定参数和 LRU 算法下，每次访问的命中/缺失判定、替换行选择和最终 Cache 状态均有唯一确定结果，无歧义。
