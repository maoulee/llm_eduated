# Q1：主存储器扩展与片选逻辑设计（文字推导，10分）

## 题目描述

某计算机系统 CPU 提供 **16 位地址总线**（A15~A0，A15 为最高位）和 **8 位数据总线**（D7~D0）。系统采用 **全译码方式** 进行片选。主存地址空间分配如下：

| 区域 | 起始地址 | 容量 |
|------|---------|------|
| ROM 区 | 0000H | 16 KB |
| RAM 区 | 紧接 ROM 区（地址连续） | 16 KB |
| 未使用区 | 紧接 RAM 区 | 剩余空间 |

可供使用的存储器芯片规格如下：

| 芯片类型 | 规格（字数×位宽） |
|---------|-----------------|
| ROM 芯片 | 4K×4 位 |
| RAM 芯片 | 8K×4 位 |

**补充说明：**
- 采用 **全译码方式**，即所有未参与片内寻址的高位地址线均参与片选逻辑，无地址重叠。
- 片选逻辑用地址线的逻辑表达式描述（如 $\overline{A_{15}} \cdot \overline{A_{14}}$ 等），不涉及具体译码器芯片型号。
- 本题所有推导过程用文字和逻辑表达式完成。

---

## 问题

### 第(1)题（3分）

分别计算 ROM 区和 RAM 区所需的 ROM 芯片和 RAM 芯片总数，并说明位扩展和字扩展各自的倍数。

### 第(2)题（3分）

以十六进制写出每个 ROM 芯片组和每个 RAM 芯片组的地址范围。要求标明每组对应的片内地址位数和高位地址位数。

### 第(3)题（4分）

采用全译码方式，分别写出每个 ROM 芯片组和每个 RAM 芯片组的片选信号逻辑表达式（用 A15~A0 中的高位地址线表示）。要求保证 ROM 区与 RAM 区地址不重叠，且无未使用的高位地址线导致地址浪费或重叠。

---

## 通过条件（本题成立 ⇔ 以下特征满足）

### 全局一致性
- ROM 区 + RAM 区总容量 = 32KB ≤ 64KB（2^16 字节），不超出地址空间。
- ROM 区起始地址 0000H，RAM 区紧接 ROM 区结束地址，两者地址连续不重叠。
- 高位地址线位数 ≥ 2（ROM 组高位 ≥ 4 位，RAM 组高位 ≥ 3 位，均满足）。

### Q1 通过条件
- ROM 芯片数 = 位扩展倍数 × 字扩展倍数，且位扩展倍数 × 4 位 = 8 位（CPU 字长）。
- RAM 芯片数 = 位扩展倍数 × 字扩展倍数，且位扩展倍数 × 4 位 = 8 位。
- ROM 区和 RAM 区均同时涉及位扩展和字扩展（不能只做其中一种）。
- ROM 芯片数和 RAM 芯片数均可被 exec 代码独立验证：位扩展倍数 = CPU 数据总线宽度 / 芯片位宽，字扩展倍数 = 区域容量 / (芯片字数 × 芯片位宽 / 8)。

### Q2 通过条件
- 每个 ROM 芯片组的地址范围可由 exec 代码验证：组容量 = 芯片字数 = 4K，起始地址可整除 4K 边界。
- 每个 RAM 芯片组的地址范围可由 exec 代码验证：组容量 = 芯片字数 = 8K，起始地址可整除 8K 边界。
- 所有芯片组地址范围按从低到高排列，连续不重叠。
- ROM 组的片内地址线位数 = 12（A11~A0），RAM 组的片内地址线位数 = 13（A12~A0），两者不同（因芯片容量不同），exec 可验证。

### Q3 通过条件
- ROM 组片选表达式使用了全部 4 根高位地址线 A15~A12（全译码要求，不允许遗漏）。
- RAM 组片选表达式使用了全部 3 根高位地址线 A15~A13（全译码要求，不允许遗漏）。
- 每个 ROM 组的片选表达式对应 A15~A12 的唯一取值，且不同组取值不同。
- 每个 RAM 组的片选表达式对应 A15~A13 的唯一取值，且不同组取值不同。
- ROM 组与 RAM 组的片选条件互斥（即任何地址不可能同时选中 ROM 组和 RAM 组）——exec 可验证：对所有可能地址，至多一个片选信号有效。
- 不存在线选法特征（即不允许仅用一根地址线做片选）。

## 设计意图说明

| 子问 | 考察目标 | K 等级 | 考察说明 |
|------|---------|--------|---------|
| Q1 | 芯片数量计算（字位同时扩展） | K2/K3 | 学生须分别计算位扩展（数据总线宽度÷芯片位宽）和字扩展（区域容量÷组容量），再相乘。ROM 和 RAM 芯片位宽均为 4 位，CPU 数据总线 8 位，故均需 2 倍位扩展——避免学生忽略位扩展只算字扩展。 |
| Q2 | 地址线划分与地址范围 | K3 | ROM 芯片 4K 和 RAM 芯片 8K 容量不同，导致片内地址线位数不同（12 vs 13），学生须分别推导高位地址线位数，并正确计算十六进制地址范围。 |
| Q3 | 全译码片选逻辑 | K3/K4 | 全译码要求所有高位地址线参与片选。ROM 和 RAM 组的高位地址线位数不同（4 vs 3），须分别构造表达式。核心难点：理解全译码的本质——不能遗漏任何高位地址线，否则导致地址重叠。 |
