## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 计算机组成原理 > CO-3 存储系统 > 主存储器和CPU的连接
- primary_target_name: 主存储器扩展与片选逻辑
- question_type: comprehensive
- examination_mode: 设计型——存储器容量扩展与地址译码（文字推导，不作图）

### 难度目标
- k_target: K1=2,K2=3,K3=4,K4=4,K5=3
- difficulty_level: 4
- difficulty_rationale: 设计题需综合容量计算（K2标准计算）、地址划分与片选逻辑多步推导（K3较高>5步推演）、全译码隐含前提识别（K4较高需理解译码机制本质）、CPU-存储器-译码器三模块单向拼接（K3标准跨域）。整体难度定位4。

### 结构要求
- sub_question_count: 3
- sub_question_plan:
  - Q1(3分): 芯片数量计算——位扩展数×字扩展数，须同时涉及ROM和RAM的"字位同时扩展"
  - Q2(3分): 地址线划分与各芯片组地址范围（十六进制）
  - Q3(4分): 各芯片组片选逻辑表达式（基于高位地址线），全译码方式
- condition_count: 4-5
- distractor_strategy: N/A（设计题，非选择题）
- 纯文字题，题干不得出现"画图/作图"字样

### 参数约束
- CPU地址总线宽度 n: 16≤n≤20, 整数
- CPU数据总线宽度 w: 8 或 16
- ROM区: 从地址0000H起始, 容量2^m字节, m由ROM芯片容量决定
- RAM区: 紧接ROM区, 容量2^k字节
- ROM芯片规格: 容量×位宽, 位宽=w或w/2; ROM区容量须能被芯片容量整除
- RAM芯片规格: 容量×位宽, 位宽=w/2或w/4(必须需位扩展); 容量<RAM区容量(必须需字扩展); RAM区容量须能被芯片容量整除
- 一致性约束:
  - RAM芯片位宽须整除CPU字长w
  - 高位地址线位数 = n - 芯片片内地址线位数 ≥ 2
  - ROM区+RAM区总容量 ≤ 2^n
  - ROM区与RAM区地址范围连续不重叠
- 可调自由度: Question Agent可自由选择n, w, 芯片规格组合, 须满足全部约束

### 参考经验摘要
- 历史模式: 无历史question_experiences; 依据slot锚定考察模式——字位同时扩展+片选译码
- 难度锚点: K3=4(多步推演)与K4=4(全译码隐含前提)为dominant维度; K2=3(芯片数量乘法运算)
- 典型陷阱: (1)忽略位扩展只算字扩展致芯片数错误 (2)不用全译码用线选致地址重叠 (3)十六进制地址范围换算错误 (4)ROM/RAM区地址不连续
