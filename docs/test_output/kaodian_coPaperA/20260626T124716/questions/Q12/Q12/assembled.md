## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: CO-5 中央处理器 > 数据通路的功能和基本结构
- primary_target_name: 数据通路与指令执行微操作序列
- question_type: comprehensive
- examination_mode: 设计型——指令执行微操作与控制信号（文字+表格，不附图）

### 难度目标
- k_target: K1=2,K2=2,K3=4,K4=4,K5=3
- difficulty_level: 4
- difficulty_rationale: 设计题，需理解数据通路并逐步推导微操作与控制信号，K3/K4 并重；减法指令执行阶段微操作步数 >5（K3=4），单总线总线冲突为隐含前提（K4=4）

### 结构要求
- sub_question_count: 2
- sub_question_details:
  - 第(1)问: 分析+设计，7分，写出减法指令执行阶段各节拍功能与有效控制信号（表格形式）
  - 第(2)问: 分析，3分，总线冲突判断与原因说明
- distractor_strategy: 不适用（设计题，非选择题）
- condition_count: 4–6
  - 条件1: 数据通路结构文字描述（寄存器集合、总线类型、ALU连接方式、暂存器）
  - 条件2: 控制信号定义表（信号名→功能说明，8–15个信号）
  - 条件3: 减法指令格式与寻址方式（双操作数，至少一操作数需访存）
  - 条件4: 寄存器初始状态（可选）

### 参数约束
- 总线条数: 1（推荐，单总线）；2（备选）。单总线保证同一节拍仅一个寄存器输出——第(2)问考察基础
- 暂存器数量: ≥1。必须足以暂存 ALU 的一个输入操作数（因单总线不能同时送两操作数）
- ALU功能集: 含减法（SUB）或补码加法（NOT+INC+ADD）。若仅提供加法+取反+加1，减法需多步微操作→K3 可达 4
- 寄存器集合: 至少含 PC、MAR、MDR、IR、通用寄存器组（R0–R3 或类似）。通用寄存器用于操作数之一
- 减法指令寻址方式: 双操作数——一个寄存器直接 + 另一个存储器直接或寄存器间接。保证执行阶段需访存取操作数，微操作步数 ≥5
- 控制信号定义数量: 8–15个。覆盖取操作数、ALU运算、写回全部信号；不过少（无法作答）也不过多（冗余降低区分度）
- 执行阶段微操作步数约束: 4–8步。<4则K3不达标，>8则超纲
- 可调自由度: ALU是否提供直接减法信号、存储器操作数寻址方式（直接/寄存器间接）、通用寄存器编号命名、控制信号命名风格——Question Agent 可自由选择

### 参考经验摘要
- 历史模式: 无 question_experiences；依据 slot.examination_mode 锚定"设计型微操作+控制信号（文字表格，不附图）"
- 难度锚点: K3=4/K4=4 核心难度；K1=2/K2=2 表明概念记忆和计算非门槛
- 典型陷阱:
  1. 单总线结构下两操作数未经暂存器同时送 ALU 两端
  2. 减法操作数顺序（被减数-减数）颠倒
  3. 写回结果时遗漏写控制信号
  4. ALU 输出未经暂存器（Z）直接写回时与总线冲突
