# 数据通路与减法指令执行微操作分析

## 题干

某计算机采用**单总线**结构，数据通路包含以下部件：

- **程序计数器 PC**、**指令寄存器 IR**
- **存储器地址寄存器 MAR**、**存储器数据寄存器 MDR**
- **通用寄存器组 R0–R3**（4 个 16 位通用寄存器）
- **暂存器 Y**（锁存 ALU 输入端 A 的数据）、**暂存器 Z**（锁存 ALU 运算结果）
- **算术逻辑单元 ALU**

各部件通过**一条内部总线**互连。ALU 的输入端 A 来自暂存器 Y，输入端 B 来自内部总线，运算结果输出至暂存器 Z。MAR 接收总线数据作为访存地址；MDR 在存储器读操作时将存储器内容送上总线，在写操作时从总线接收数据。

> **ALU 行为说明**：当指定 ALU 运算（ADD 或 SUB）时，运算结果自动锁存到暂存器 Z 中。

### 控制信号定义表

| 控制信号 | 功能说明 |
|---------|---------|
| Riout（i = 0–3） | 通用寄存器 Ri 的内容送上总线 |
| Riin（i = 0–3） | 总线数据写入通用寄存器 Ri |
| MARin | 总线数据写入 MAR |
| MDRin | 总线数据写入 MDR |
| MDRout | MDR 的内容送上总线 |
| Yin | 总线数据写入暂存器 Y |
| Zout | 暂存器 Z 的内容送上总线 |
| Read | 启动存储器读操作（读出数据送入 MDR） |
| Write | 启动存储器写操作（将 MDR 数据写入存储器） |
| ADD | ALU 执行加法：Z ← Y + 总线 |
| SUB | ALU 执行减法：Z ← Y − 总线 |

### 减法指令说明

该机支持的减法指令格式为：**SUB R1, (R2)**，其功能为：

> **R1 ← R1 − M[R2]**

即：以寄存器 R2 的内容作为访存地址，从存储器中读取操作数，用 R1 的当前内容减去该操作数，结果写回 R1。其中 M[R2] 表示地址为 R2 内容的存储单元中的数据。

---

## 第(1)问（7 分）

已知指令 **SUB R1, (R2)** 已完成取指阶段（指令已存入 IR，PC 已更新）并完成译码。请写出该指令**执行阶段**的微操作序列。

要求：按节拍 T1, T2, T3, … 的顺序，列出每个节拍的**功能描述**及该节拍下**有效的控制信号**，填入下表。

| 节拍 | 微操作功能描述 | 有效控制信号 |
|------|-------------|------------|
| T1 |  |  |
| T2 |  |  |
| T3 |  |  |
| T4 |  |  |
| T5 |  |  |
| … |  |  |

> 注：每个节拍中，同一时刻只能有一个寄存器的内容输出到总线（单总线约束）。

---

## 第(2)问（3 分）

某同学提出改进方案：**取消暂存器 Y**，将 ALU 的输入端 A 直接连接到内部总线上（即 ALU 的两个输入端 A 和 B 均来自同一条内部总线），从而省去一个暂存器。

请判断该方案是否可行，并说明原因。

---

## 通过条件（本题成立需要满足的可机检特征）

1. **执行阶段微操作步数 ≥ 5**：SUB R1, (R2) 的执行阶段（不含取指和译码）至少需要 5 个节拍才能完成（访存取操作数 + 暂存 + 运算 + 写回），微操作序列展开后步数落在 4–8 范围内。
2. **单总线约束成立**：正确序列中，每个节拍**至多只有一个**寄存器的内容输出到总线（同一节拍不会同时出现两个"Xout"信号），确保单总线无冲突。
3. **暂存器 Y 被正确使用**：正确序列中，一个操作数必须先经总线送入 Y（锁存于 ALU 输入端 A），另一个操作数随后经总线到达 ALU 输入端 B，再执行 SUB 运算。若两操作数直接同时经总线送入 ALU 两端 → 违反单总线约束 → 第(2)问考察点。
4. **减法操作数顺序正确**：SUB 定义为 Z ← Y − 总线。正确序列中 Y 须锁存被减数（R1），总线须传输减数（M[R2]），结果为 R1 − M[R2]；若顺序颠倒则结果为 M[R2] − R1，属运算错误。
5. **写回完整**：正确序列的最后一个节拍须包含将 Z 中结果写回 R1 的操作（Zout, R1in），不能遗漏写回控制信号。
6. **第(2)问可证伪**：取消 Y 后两输入端均连总线，单总线同一时刻只能传输一个数据，无法同时为 ALU 两端提供不同操作数 → 方案不可行，原因可被明确判断。
