# 数据通路与减法指令执行微操作分析

## 题目

某计算机采用**单总线**结构，数据通路包含以下部件：

- **程序计数器 PC**、**指令寄存器 IR**
- **存储器地址寄存器 MAR**、**存储器数据寄存器 MDR**
- **通用寄存器组 R0–R3**（4 个 16 位通用寄存器）
- **暂存器 Y**（锁存 ALU 输入端 A 的数据）、**暂存器 Z**（锁存 ALU 运算结果）
- **算术逻辑单元 ALU**

各部件通过**一条内部总线**互连。ALU 的输入端 A 来自暂存器 Y，输入端 B 来自内部总线，运算结果输出至暂存器 Z。MAR 接收总线数据作为访存地址；MDR 在存储器读操作时将存储器内容送上总线，在写操作时从总线接收数据。

> **ALU 行为说明**：当指定 ALU 运算（ADD 或 SUB）时，运算结果自动锁存到暂存器 Z 中。

### 控制信号定义表

| 控制信号 | 功能说明 |
|---------|---------|
| Riout（i = 0–3） | 通用寄存器 Ri 的内容送上总线 |
| Riin（i = 0–3） | 总线数据写入通用寄存器 Ri |
| MARin | 总线数据写入 MAR |
| MDRin | 总线数据写入 MDR |
| MDRout | MDR 的内容送上总线 |
| Yin | 总线数据写入暂存器 Y |
| Zout | 暂存器 Z 的内容送上总线 |
| Read | 启动存储器读操作（读出数据送入 MDR） |
| Write | 启动存储器写操作（将 MDR 数据写入存储器） |
| ADD | ALU 执行加法：Z ← Y + 总线 |
| SUB | ALU 执行减法：Z ← Y − 总线 |

### 减法指令说明

该机支持的减法指令格式为：**SUB R1, (R2)**，其功能为：

> **R1 ← R1 − M[R2]**

即：以寄存器 R2 的内容作为访存地址，从存储器中读取操作数，用 R1 的当前内容减去该操作数，结果写回 R1。其中 M[R2] 表示地址为 R2 内容的存储单元中的数据。

---

### 第(1)问（7 分）

| T2 |  |  |

> 注：每个节拍中，同一时刻只能有一个寄存器的内容输出到总线（单总线约束）。

### 第(2)问（3 分）

某同学提出改进方案：**取消暂存器 Y**，将 ALU 的输入端 A 直接连接到内部总线上（即 ALU 的两个输入端 A 和 B 均来自同一条内部总线），从而省去一个暂存器。

请判断该方案是否可行，并说明原因。

## 参考答案

**第(1)问**

| 节拍 | 微操作功能描述 | 有效控制信号 |
|------|-------------|------------|
| T1 | R2 的内容（访存地址）送入 MAR | R2out, MARin |
| T2 | 启动存储器读，将 M[R2] 读入 MDR | Read |
| T3 | R1 的内容（被减数）送上总线并写入暂存器 Y（锁存至 ALU 输入端 A） | R1out, Yin |
| T4 | MDR 的内容（操作数 M[R2]）送上总线（ALU 输入端 B），执行减法 Z ← Y − 总线 | MDRout, SUB |
| T5 | 暂存器 Z 的内容（运算结果）写回 R1 | Zout, R1in |

执行阶段共 5 个节拍。

**第(2)问**

方案不可行。

## 解析

### 第(1)问解析

**推导逻辑**

指令功能：R1 ← R1 − M[R2]。

SUB 定义：Z ← Y − 总线。

因此：**Y 须存 R1（被减数），总线须传 M[R2]（减数）**，运算结果 Z = Y − 总线 = R1 − M[R2]，写回 R1。

执行步骤分解：
1. **访存取操作数 M[R2]**：R2 → MAR，Read → MDR
2. **锁存被减数 R1 到 Y**：R1 → 总线 → Yin
3. **送减数 M[R2] 到总线并执行 SUB**：MDRout + SUB → Z = Y − M[R2] = R1 − M[R2]
4. **写回结果到 R1**：Zout + R1in

**各节拍分析**

- **T1（R2out, MARin）**：将寄存器 R2 的内容（即访存地址）通过总线送入 MAR，为后续访存做准备。此节拍只有 R2out 一个输出信号，满足单总线约束。
- **T2（Read）**：启动存储器读操作，从地址为 R2 内容的存储单元中读取操作数 M[R2]，结果自动送入 MDR。此节拍无输出信号，满足单总线约束。
- **T3（R1out, Yin）**：将 R1 的内容（被减数）送上总线，写入暂存器 Y。由于 ALU 输入端 A 来自暂存器 Y，此时 Y 锁存了被减数 R1。此节拍只有 R1out 一个输出信号，满足单总线约束。
- **T4（MDRout, SUB）**：将 MDR 的内容（减数 M[R2]）送上总线（到达 ALU 输入端 B），同时发出 SUB 信号，ALU 执行 Z ← Y − 总线 = R1 − M[R2]，结果自动锁存到 Z。此节拍只有 MDRout 一个输出信号，满足单总线约束。
- **T5（Zout, R1in）**：将暂存器 Z 中的运算结果送上总线并写回 R1，完成 R1 ← R1 − M[R2]。此节拍只有 Zout 一个输出信号，满足单总线约束。

**评分标准**：
- T1 正确写出 R2out, MARin（访存地址设置），得 1 分；
- T2 正确写出 Read（访存取操作数），得 1 分；
- T3 正确写出 R1out, Yin（锁存被减数到 Y），得 2 分（操作数选择与 Y 锁存各 1 分）；
- T4 正确写出 MDRout, SUB（总线传输减数 + 执行减法），得 2 分（控制信号与运算方向各 1 分）；
- T5 正确写出 Zout, R1in（写回结果），得 1 分；
- 若操作数顺序颠倒（Y 存 M[R2]，总线传 R1），结果变为 M[R2] − R1，扣 2 分。

### 第(2)问解析

**方案不可行。**

**原因**：单总线结构中，同一时刻总线只能传输一个数据。取消暂存器 Y 后，ALU 的两个输入端 A 和 B 都连接到同一条内部总线，但单总线无法在同一节拍内同时为两个输入端提供两个不同的操作数。

暂存器 Y 的作用正是在前一节拍锁存一个操作数（R1），使得后一节拍总线可以传输另一个操作数（M[R2]），从而完成 SUB 运算。取消 Y 后此机制失效，无法执行双操作数运算。

**评分标准**：判断"不可行"得 1 分；正确说明原因（单总线同一时刻只能传输一个数据，无法同时为 ALU 两端提供不同操作数）得 2 分。仅说"不可行"未说明原因，得 1 分。
