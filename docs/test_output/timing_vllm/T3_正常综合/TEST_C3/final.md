## 题目

设有一棵包含7个节点的平衡二叉排序树（AVL树），其结构如下（括号内为节点关键字）：

```
        (20)
       /    \
    (10)    (30)
    /  \    /
 (5)  (15)(25)
 /
(2)
```

向该AVL树中插入关键字 `1`，执行插入操作并调整平衡后，根节点（关键字为20的节点）的平衡因子为多少？

（注：平衡因子定义为左子树高度 − 右子树高度）

A. 0
B. -1
C. 2
D. 1

## 求解过程

**1. 插入分析**

插入关键字 `1`，沿BST规则查找插入位置：
- 1 < 20 → 左子树
- 1 < 10 → 左子树
- 1 < 5 → 左子树
- 1 < 2 → 成为节点 2 的左孩子

**2. 自底向上更新平衡因子**

- 节点 2：左子树高度 1，右子树高度 0，BF = 1，平衡
- 节点 5：左子树高度 2，右子树高度 0，BF = 2，**失衡**

**3. 旋转调整**

节点 5 的 BF = 2，插入发生在左子树左侧（1 < 2 < 5），属于 **LL 型**，对节点 5 执行**右旋**：
- 节点 2 上提为子树根
- 节点 5 成为节点 2 的右孩子

旋转后子树：
```
  (2)
 /  \
(1)  (5)
```

继续向上检查：
- 节点 10：左子树高度 2，右子树高度 1，BF = 1，平衡
- 节点 20：左子树高度 3，右子树高度 2，BF = 1，平衡

**4. 最终树结构**

```
        (20)
       /    \
    (10)    (30)
    /  \    /
  (2) (15)(25)
 /  \
(1)  (5)
```

**5. 根节点平衡因子计算**

- 左子树高度 = 3
- 右子树高度 = 2
- 平衡因子 = 3 − 2 = 1

## 答案

D. 1
