## 求解过程

### 插入分析

原始 AVL 树结构：
```
        (20)
       /    \
    (10)    (30)
    /  \    /
 (5)  (15)(25)
 /
(2)
```

插入关键字 `1`：
- 1 < 20 → 进入左子树
- 1 < 10 → 进入左子树
- 1 < 5 → 进入左子树
- 1 < 2 → 成为节点 2 的左孩子

插入后（尚未平衡）：
```
        (20)
       /    \
    (10)    (30)
    /  \    /
 (5)  (15)(25)
 /
(2)
/
(1)
```

### 平衡调整

从插入位置自底向上检查平衡因子：

1. **节点 2**：左子树高度 1，右子树高度 0，BF = 1，平衡 ✓
2. **节点 5**：左子树高度 2，右子树高度 0，BF = 2，**不平衡**

   节点 5 的 BF = 2，且插入发生在左子树的左侧（1 < 2 < 5），属于 **LL 型**，对节点 5 执行**右旋**：
   - 节点 2 上提为子树根
   - 节点 5 成为节点 2 的右孩子
   
   旋转后子树：
   ```
     (2)
    /  \
   (1)  (5)
   ```

3. **节点 10**：左子树高度 2（以 2 为根的子树），右子树高度 1（节点 15），BF = 1，平衡 ✓
4. **节点 20**：左子树高度 3，右子树高度 2，BF = 1，平衡 ✓

### 最终树结构

```
        (20)
       /    \
    (10)    (30)
    /  \    /
  (2) (15)(25)
 /  \
(1)  (5)
```

### 根节点平衡因子计算

- 根节点（20）的左子树高度 = 3
- 根节点（20）的右子树高度 = 2
- 平衡因子 = 左子树高度 − 右子树高度 = 3 − 2 = **1**

## 最终答案
- 正确答案：1
  - 理由：插入关键字 1 后，在节点 5 处发生 LL 型不平衡，执行右旋调整。调整后根节点 20 的左子树高度为 3、右子树高度为 2，平衡因子 = 3 − 2 = 1。
