## 考点
- **二叉树带权路径长度(WPL)**：核心考点，考察WPL的定义与计算方法
  - 考察侧重点：正确识别叶子节点、准确计算路径长度、正确应用WPL公式
- **二叉树基本概念**：辅助考点，考察对二叉树结构的理解
  - 考察侧重点：根节点、叶子节点、路径长度的概念

## 难度目标
- **K1（知识广度）= 2**：涉及二叉树基本概念和WPL定义，知识点范围适中
- **K2（知识深度）= 3**：需要理解WPL的计算原理，可能涉及哈夫曼树的最优性概念
- **K3（计算复杂度）= 3**：中等计算量，需对每个叶子节点计算路径长度×权值后求和
- **K4（思维复杂度）= 2**：思维路径清晰，主要是按定义计算，陷阱在于细节识别
- **K5（综合应用）= 2**：单一知识点应用，不涉及多知识点综合

**整体难度定位**：中等（3级），符合slot中difficulty=medium的要求

## 考察模式
**模式选择**：给定二叉树结构+叶子节点权值，计算WPL

**选择理由**：
- 这是408考研数据结构部分最经典的WPL考察方式
- 适合选择题形式，计算量可控
- 能有效区分是否真正理解WPL定义（叶子节点识别、路径长度计算）
- 历史经验表明该模式陷阱丰富，干扰项设计空间大

## 出题要求
- **题型**：single_choice（单选题）
- **选项数**：4个（1正确+3干扰）
- **条件数**：2个显式条件
  1. 二叉树的结构（图形或文字描述）
  2. 各叶子节点的权值分配
- **条件设计原则**：
  - 树结构应清晰，避免歧义
  - 权值分配应使计算结果适中（避免过大或过小）
  - 确保只有叶子节点有权值，非叶子节点无权值或权值为0
- **参数取值范围要求**：
  - 节点总数：5-10个
  - 叶子节点数：3-5个
  - 树的高度：3-4层
  - 权值范围：1-20的整数

## 子问题规划
本题为选择题，无子问题结构。

## 参数约束
- **节点总数 N**：取值范围 [5, 10]，建议6-8个节点
- **叶子节点数 L**：取值范围 [3, 5]，与N的关系：L ≤ N/2 + 1
- **树的高度 H**：取值范围 [3, 4]，与N的关系：H ≥ ⌈log₂(N+1)⌉
- **权值 w_i**：取值范围 [1, 20]，各叶子节点权值应不同以增加区分度
- **WPL计算结果**：应在 [20, 100] 范围内，确保选项数值合理
- **参数一致性约束**：
  - 所有叶子节点必须有权值
  - 非叶子节点不应参与WPL计算
  - 路径长度从根到叶子节点的边数（根节点路径长度为0）

## 参考经验
**考察模式**：
- 经典模式：给出二叉树图形+权值表，要求计算WPL
- 变式模式：给出权值集合，要求构造哈夫曼树并计算最小WPL

**难度锚点**：
- K值历史分布：K1=2, K2=3, K3=3, K4=2, K5=2 是中等难度WPL题的典型分布
- 计算量锚点：3-5个叶子节点的WPL计算是中等难度的标准配置

**典型陷阱**：
1. **非叶子节点误算**：将非叶子节点也计入WPL
2. **路径长度起点错误**：从1开始计数而非从0（根节点）
3. **权值分配混淆**：将权值错误分配给非叶子节点
4. **算术错误**：乘法或加法计算失误
5. **哈夫曼混淆**：误以为题目要求构造哈夫曼树
