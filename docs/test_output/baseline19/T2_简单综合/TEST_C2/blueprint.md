## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: DS-5 > 树与二叉树
- primary_target_name: 二叉树遍历序列还原
- question_type: comprehensive
- examination_mode: 序列还原+性质分析

### 难度目标
- k_target: K1=3,K2=3,K3=2,K4=3,K5=3
- difficulty_level: 3
- difficulty_rationale: 中等难度，考查遍历序列还原的核心能力，节点数适中（7-8个），不涉及复杂计算

### 结构要求
- sub_question_count: 3
- sub_question_structure:
  - q1: 类型=构造, 分值=4, 考察目标=根据两种遍历序列还原二叉树
  - q2: 类型=计算, 分值=3, 考察目标=写出第三种遍历序列
  - q3: 类型=分析, 分值=3, 考察目标=分析二叉树性质
- dependency: 串行（q2和q3依赖q1，q2和q3并行）
- condition_count: 2-3

### 参数约束
- 节点总数 n: 5 ≤ n ≤ 10，建议 7-8
- 树高 h: 2 ≤ h ≤ 4
- 叶子节点数: ≥ 2
- 度为2的节点数: ≥ 1
- 遍历序列类型: 前序+中序 或 后序+中序（二选一）
- 节点标签: 连续字母（A-J）或连续数字（1-10）
- 一致性要求: 给出的两种遍历序列必须能唯一确定二叉树
- 可调自由度: 树的具体结构、节点标签选择、第3问考查的性质类型

### 参考经验摘要
- 历史模式: 前序+中序→还原→后序（经典）；后序+中序→还原→前序（变体）
- 难度锚点: 节点数5-6偏简单，7-8中等，9-10偏难
- 典型陷阱: 混淆前序/后序根节点位置；中序序列错误划分左右子树；忽略空子树；混淆层序遍历
