## rationale
- 为何选此形式：KP为"二叉树遍历序列还原"，核心能力是递归还原过程（根节点定位→中序划分→递归子树），天然对应多步串行推演；q3性质分析为辅助形式，考查还原后对树结构的统计理解。K-雷达呈均衡扁平形状（K1=K2=K4=K5=3，K3=2），说明题目不依赖深层机制推演，而是强调基础概念掌握（K1）、规则应用（K2）、条件识别（K4，如根节点位置、空子树判断）和多遍历类型联动（K5），与"序列还原+性质分析"的考察模式一致。
- 与目标 K-雷达的对齐说明：K3=2 最低，说明还原过程本身是标准递归流程，不涉及复杂机制创新；K4=3 反映陷阱辨析需求（混淆前序/后序根节点位置、中序划分错误、忽略空子树）；K5=3 反映多遍历类型（前序/中序/后序/层序）之间的联动理解；K1=3 和 K2=3 反映对遍历定义和单步规则应用的中等要求。
