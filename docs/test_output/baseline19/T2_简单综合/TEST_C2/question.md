## 题目

已知某二叉树的前序遍历序列为：A B D E C F G，中序遍历序列为：D B E A F C G。

请回答下列问题：

### (1) （4分）根据上述两种遍历序列，还原该二叉树的结构（可用图形或文字描述）。

**答案**：二叉树结构如下：
```
        A
       / \
      B   C
     / \ / \
    D  E F  G
```
文字描述：根节点为 A，A 的左孩子为 B、右孩子为 C；B 的左孩子为 D、右孩子为 E；C 的左孩子为 F、右孩子为 G；D、E、F、G 均为叶子节点。

### (2) （3分）基于(1)中还原的二叉树，写出该二叉树的层序遍历序列。

**答案**：A B C D E F G

### (3) （3分）基于(1)中还原的二叉树，分析该二叉树的树高和叶子节点数。

**答案**：树高为 3，叶子节点数为 4。

## 设计说明
- 复用骨架来源：经典二叉树遍历序列还原题（前序+中序→还原→第三种遍历）
- 考察形式：多步串行推演 + 性质分析
- 子问依赖链：q1→{q2, q3}（q2和q3并行依赖q1）
- 经验值参数来源：
  - 节点数 n=7（来自经验值表"二叉树遍历/还原：6-8"，取中间值）
  - 遍历序列类型：前序+中序（经典组合，来自参考经验摘要"历史模式"）
  - 节点标签：连续字母 A-G（7个节点）
  - 前序遍历序列：A B D E C F G（经验值，基于经典骨架给出）
  - 中序遍历序列：D B E A F C G（经验值，与前序配对确保唯一确定性）
  - 第三种遍历：层序遍历（增加K5跨域联动）
  - q3性质：树高、叶子节点数
- 与目标 K-雷达的对齐：
  - K1=3：考查遍历定义和二叉树基本概念（根节点、左右子树、叶子节点）
  - K2=3：单步应用遍历规则（根节点定位、中序划分左右子树）
  - K3=2：标准递归还原流程，无复杂机制创新
  - K4=3：陷阱辨析（混淆前序/后序根节点位置、中序划分错误、忽略空子树）
  - K5=3：多遍历类型联动（前序/中序→层序）
- 是否融合：否（K3=2，非高难度，单骨架已满足难度要求，无需融合）
