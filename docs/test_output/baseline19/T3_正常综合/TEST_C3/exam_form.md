- 设问方向：给定初始 AVL 树结构与插入关键字，要求完整模拟插入→回溯检查平衡因子→识别失衡节点→判定旋转类型→执行旋转→检查祖先节点的全过程，判断最终树的关键状态

## k_radar
- K1（基础认知）: 3
- K2（单步代入）: 2
- K3（机制推演）: 4
- K4（条件路由）: 4
- K5（跨域联动）: 1
- 形状主导维度：K3 + K4 平衡型

## rationale
- 目标 K-雷达为 K3-K4 平衡型，K3 主导要求多步串行推演（插入→回溯→失衡判定→旋转→二次检查，步数>5且需维持动态状态更新），K4 主导要求陷阱辨析（四种旋转类型触发条件需精准区分，旋转后需继续回溯检查祖先节点平衡因子，遗漏即错），故选定"多步串行推演（主）+ 陷阱辨析（辅）"混合形式
- 与目标 K-雷达对齐：K3=4 对应推演步数>5步且需记忆中间状态（插入后逐节点更新平衡因子、定位失衡节点、执行旋转、检查祖先），K4=4 对应隐含前提深（必须理解旋转类型判定的本质规则而非死记，且旋转后祖先节点可能仍需调整），K1=3 对应需准确记忆平衡因子定义与四种旋转名称，K2=2 对应平衡因子计算为简单整数加减，K5=1 对应纯数据结构内部操作无跨域
