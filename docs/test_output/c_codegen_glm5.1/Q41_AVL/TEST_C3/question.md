# 第41题 平衡二叉树（AVL）的插入与旋转

## 题目

已知一棵平衡二叉树（AVL树）的初始状态由关键字序列 {30, 10, 50, 5, 20, 40, 60} 依次插入空树而得。现依次将关键字 19、15、29、22 插入该平衡二叉树，每次插入后若出现不平衡则进行相应调整，使其始终保持平衡二叉树的性质。

请回答以下问题：

（1）依次插入上述4个关键字后，共触发了哪几种旋转调整？写出每次插入触发的旋转类型（LL/RR/LR/RL）及失衡节点的关键字。

（2）插入关键字15并完成调整后，关键字15的父节点关键字是什么？关键字19的左孩子和右孩子分别是哪个关键字？

（3）所有插入完成后，该平衡二叉树的根节点关键字是什么？树的深度是多少？

（4）所有插入完成后，关键字5的平衡因子是多少？关键字20的右孩子是哪个关键字？

## 设计说明

- **考点**：平衡二叉树（AVL）的插入操作与四种旋转调整（LL、RR、LR、RL）
- **考察模式**：结构操作与状态维护模拟
- **难度**：4（K3-K4 平衡型）
- **初始树**：7节点完全平衡AVL树（深度3），结构清晰，便于考生建立初始心智模型
- **插入序列**：4个关键字依次触发 LL、RR、RL 三种旋转（占四种旋转中的三种），考查学生对不同失衡场景的辨识能力
- **设问设计**：
  - 第(1)问考查旋转类型识别与失衡节点定位，需多步串行推演
  - 第(2)问考查中间状态（调整后）的树结构细节，要求精确跟踪某一步的局部变化
  - 第(3)问考查最终全局状态（根节点、深度）
  - 第(4)问考查平衡因子计算与具体节点指针关系，需在最终树上操作
