# 扩展操作码数量计算

## 题目

某计算机的指令字长为 **16 位**，采用**扩展操作码**编码方式，地址码字段均为 **4 位**。该机器设置二地址、一地址、零地址三种指令格式，二地址指令的格式如下：

```
| OP (8位) | A1 (4位) | A2 (4位) |
```

其中，当二地址指令操作码 `OP = 11111111` 时，`A1` 字段的 4 位转入操作码扩展空间，用于表示一地址指令；类似地，当一地址指令扩展操作码取最大值时，`A2` 字段转入操作码扩展空间，用于表示零地址指令。

> **约定**：每一级操作码均须预留 **1 个编码**作为下一级的扩展前缀；零地址指令为最低级，无需再预留。

**第 1 问（3 分）**：在上述编码方案下，二地址指令最多可定义多少条？一地址指令最多可定义多少条？请写出计算过程。

**第 2 问（3 分）**：若该机器实际定义了 **250 条二地址指令**和 **14 条一地址指令**，则零地址指令最多可定义多少条？请写出计算过程并说明理由。

---

## 通过条件（本题成立 ⇔ 以下特征全部满足）

1. **二地址最大数 = 2^8 − 1 = 255**：8 位操作码共 2^8 = 256 个编码，必须预留 1 个编码（11111111）作为一地址指令的扩展前缀，因此最多 255 条——若计算结果为 256 则说明未预留扩展前缀，错误。
2. **一地址最大数 = 2^4 − 1 = 15**：扩展后操作码为 4 位，共 2^4 = 16 个编码，必须预留 1 个编码作为零地址指令的扩展前缀，因此最多 15 条——若计算结果为 16 则说明未预留扩展前缀，错误。
3. **零地址最大数 = 2^4 = 16**：最低级无需预留，4 位操作码全部可用，共 16 个编码。
4. **给定数值合法性**：250 ≤ 255（二地址容量内）、14 ≤ 15（一地址容量内）——题干给定值不超过各级最大值。
5. **第 2 问答案与已定义数量无关**：零地址指令的最大数仅取决于扩展操作码位数（4 位），与实际定义的二地址、一地址数量无关（只要它们在各自容量范围内）；学生须能识别这一独立性，不能将已定义数量代入零地址计算导致错误。

### 考察目标覆盖

| 通过条件 | 覆盖的考察点 |
|---------|------------|
| 条件 1、2 | 扩展操作码逐级扩展机制：每级预留 1 个前缀编码（K4 主导） |
| 条件 3 | 最低级无需预留——边界理解（K2） |
| 条件 4 | 容量约束验证——空间分配合理性（K1） |
| 条件 5 | 干扰项识别：已定义数量是无关条件——分析能力（K3） |
