# 多种寻址方式有效地址计算（综合题，10分）

## 题干

某计算机主存**按字编址**，字长 16 位。CPU 中通用寄存器包括变址寄存器 IX、基址寄存器 BR 和程序计数器 PC，均为 16 位。指令采用**双字长格式**（占 2 个字），每字 16 位，格式如下：

**第一字：**

| bit15~bit10 | bit9~bit7 | bit6~bit4 | bit3~bit0 |
|:-----------:|:---------:|:---------:|:---------:|
| 操作码 OP（6位） | 寻址方式 MOD（3位） | 寄存器编号 R（3位） | 未用（4位） |

**第二字：**

| bit15~bit0 |
|:----------:|
| 形式地址 A（16位） |

寻址方式 MOD 编码定义：

| MOD 编码 | 寻址方式 | 有效地址 EA |
|:--------:|:--------:|:-----------:|
| 000 | 直接寻址 | EA = A |
| 001 | 间接寻址 | EA = M[A] |
| 010 | 变址寻址 | EA = (IX) + A |
| 011 | 基址寻址 | EA = (BR) + A |
| 100 | 相对寻址 | EA = (PC) + A（PC 为取指后的值） |

当前正在执行的指令存放在主存地址 **0x000E** 处，其内容为：

- 第一字：**0x2008**
- 第二字：**0x0200**

各寄存器当前值（均为十六进制）：

| 寄存器 | 当前值 |
|:------:|:------:|
| PC | 0x000E |
| IX | 0x0200 |
| BR | 0x0600 |

> **说明：** PC 的当前值 0x000E 为该指令的起始地址。本指令为双字长指令，取指阶段需读取 2 个字。

相关主存单元内容如下（均为十六进制）：

| 地址 | 内容 |
|:----:|:----:|
| 0x0100 | 0x0F00 |
| 0x0200 | 0x0500 |
| 0x0210 | 0x0BBB |
| 0x0300 | 0x0E00 |
| 0x0400 | 0x0CCC |
| 0x0500 | 0x0AAA |
| 0x0600 | 0x0D00 |
| 0x0800 | 0x0DDD |

---

## 问题

**(1)（2.5分）** 从当前指令中提取形式地址 A 的值。分别按**直接寻址**和**间接寻址**两种方式，计算有效地址 EA 和最终取得的操作数，写出计算过程。

**(2)（3.5分）** 分别按**变址寻址**和**基址寻址**两种方式，计算有效地址 EA 和最终取得的操作数，写出计算过程。

**(3)（2分）** 按**相对寻址**方式，计算有效地址 EA 和最终取得的操作数，写出计算过程。（注意：PC 应使用取指后的值。）

**(4)（2分）** 分别指出上述五种寻址方式在**取得操作数阶段**的访存次数，并说明间接寻址为何需要额外的访存操作。

## 通过条件（成功判据·可机检）

> 以下条件供 write_gen 翻译为 `assert`，供 dual_review 审核考点是否被参数真正触发。

1. **形式地址可提取**：从指令第二字 0x0200 可无歧义提取 A = 0x0200。

2. **五种寻址方式的操作数互不相同**：直接、间接、变址、基址、相对五种方式最终取得的操作数值各不相同（exec 算出后 `len(set(operands)) == 5`）。

3. **间接寻址访存链 ≥ 2 级**：间接寻址中 M[A] 的内容指向另一个主存单元，且该目标单元存在于主存表中（即 M[A] ≠ A，且 M[M[A]] 存在于表中），保证间接寻址经历了"读指针→读操作数"两次访存。

4. **相对寻址 PC 取值时机正确**：取指后 PC = 0x000E + 2 = 0x0010（双字指令），EA = (PC_取指后) + A，该 EA 对应的主存单元存在于表中。若错误使用取指前 PC（0x000E）计算，将得到不同的 EA，且该错误 EA 对应单元不在主存表中（可检出错误）。

5. **变址目标 ≠ 基址目标**：(IX)+A ≠ (BR)+A，即两种方式的 EA 不同、操作数不同（IX=0x0200, BR=0x0600，保证区分度）。

6. **所有寻址方式的 EA 对应单元均在主存表内**：五种方式算出的 EA 均命中主存表中的地址，不存在"表中无此单元"的缺陷。
