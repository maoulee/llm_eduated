## 题目

**多种寻址方式有效地址计算（综合题，10分）**

某计算机主存**按字编址**，字长 16 位。CPU 中通用寄存器包括变址寄存器 IX、基址寄存器 BR 和程序计数器 PC，均为 16 位。指令采用**双字长格式**（占 2 个字），每字 16 位，格式如下：

**第一字：**

| bit15~bit10 | bit9~bit7 | bit6~bit4 | bit3~bit0 |
|:-----------:|:---------:|:---------:|:---------:|
| 操作码 OP（6位） | 寻址方式 MOD（3位） | 寄存器编号 R（3位） | 未用（4位） |

**第二字：**

| bit15~bit0 |
|:----------:|
| 形式地址 A（16位） |

寻址方式 MOD 编码定义：

| MOD 编码 | 寻址方式 | 有效地址 EA |
|:--------:|:--------:|:-----------:|
| 000 | 直接寻址 | EA = A |
| 001 | 间接寻址 | EA = M[A] |
| 010 | 变址寻址 | EA = (IX) + A |
| 011 | 基址寻址 | EA = (BR) + A |
| 100 | 相对寻址 | EA = (PC) + A（PC 为取指后的值） |

当前正在执行的指令存放在主存地址 **0x000E** 处，其内容为：

- 第一字：**0x2008**
- 第二字：**0x0200**

各寄存器当前值（均为十六进制）：

| 寄存器 | 当前值 |
|:------:|:------:|
| PC | 0x000E |
| IX | 0x0200 |
| BR | 0x0600 |

> **说明：** PC 的当前值 0x000E 为该指令的起始地址。本指令为双字长指令，取指阶段需读取 2 个字。

相关主存单元内容如下（均为十六进制）：

| 地址 | 内容 |
|:----:|:----:|
| 0x0100 | 0x0F00 |
| 0x0200 | 0x0500 |
| 0x0210 | 0x0BBB |
| 0x0300 | 0x0E00 |
| 0x0400 | 0x0CCC |
| 0x0500 | 0x0AAA |
| 0x0600 | 0x0D00 |
| 0x0800 | 0x0DDD |

---

**(1)（2.5分）** 从当前指令中提取形式地址 A 的值。分别按**直接寻址**和**间接寻址**两种方式，计算有效地址 EA 和最终取得的操作数，写出计算过程。

**(2)（3.5分）** 分别按**变址寻址**和**基址寻址**两种方式，计算有效地址 EA 和最终取得的操作数，写出计算过程。

**(3)（2分）** 按**相对寻址**方式，计算有效地址 EA 和最终取得的操作数，写出计算过程。（注意：PC 应使用取指后的值。）

**(4)（2分）** 分别指出上述五种寻址方式在**取得操作数阶段**的访存次数，并说明间接寻址为何需要额外的访存操作。

## 参考答案

| 寻址方式 | 有效地址 EA | 操作数 |
|:--------:|:-----------:|:------:|
| 直接寻址 | 0x0200 | 0x0500 |
| 间接寻址 | 0x0500 | 0x0AAA |
| 变址寻址 | 0x0400 | 0x0CCC |
| 基址寻址 | 0x0800 | 0x0DDD |
| 相对寻址 | 0x0210 | 0x0BBB |

第(4)题访存次数：直接 1 次，间接 2 次，变址 1 次，基址 1 次，相对 1 次。

## 解析

### 参数提取

- **形式地址 A** = 第二字 = **0x0200**
- **PC（取指前）** = 0x000E（指令起始地址）
- **双字长指令**，取指阶段读取 2 个字 → **PC（取指后）** = 0x000E + 2 = **0x0010**
- **IX** = 0x0200，**BR** = 0x0600

---

### (1) 直接寻址与间接寻址（2.5 分）

**直接寻址**

- 有效地址：EA = A = **0x0200**
- 操作数 = M[0x0200] = **0x0500**

**间接寻址**

间接寻址需先读 M[A] 获取指针，再以该指针为地址读取操作数：

- 第一步（读指针）：M[A] = M[0x0200] = **0x0500**，此即为有效地址 EA
- 有效地址：EA = M[A] = **0x0500**
- 第二步（读操作数）：操作数 = M[M[A]] = M[0x0500] = **0x0AAA**

---

### (2) 变址寻址与基址寻址（3.5 分）

**变址寻址**

- 有效地址：EA = (IX) + A = 0x0200 + 0x0200 = **0x0400**
- 操作数 = M[0x0400] = **0x0CCC**

**基址寻址**

- 有效地址：EA = (BR) + A = 0x0600 + 0x0200 = **0x0800**
- 操作数 = M[0x0800] = **0x0DDD**

> **区分说明**：变址寄存器 IX 与基址寄存器 BR 的值不同（0x0200 ≠ 0x0600），因此两种方式的 EA 不同（0x0400 ≠ 0x0800），操作数也不同（0x0CCC ≠ 0x0DDD）。

---

### (3) 相对寻址（2 分）

**关键点**：本指令为双字长指令，取指阶段读取 2 个字，PC 自动加 2。

- PC（取指后） = 0x000E + 2 = **0x0010**
- 有效地址：EA = (PC_取指后) + A = 0x0010 + 0x0200 = **0x0210**
- 操作数 = M[0x0210] = **0x0BBB**

> **易错点**：若错误使用取指前的 PC（0x000E），则 EA = 0x000E + 0x0200 = 0x020E，该地址不在主存表中，属于错误结果。取指后 PC = 0x0010 才是正确的 PC 值。

---

### (4) 各寻址方式访存次数（2 分）

取得操作数阶段的访存次数（不计取指阶段）：

| 寻址方式 | 访存次数 | 说明 |
|:--------:|:--------:|:-----|
| 直接寻址 | **1 次** | 根据 EA = A 直接读 M[A] 获取操作数 |
| 间接寻址 | **2 次** | 先读 M[A] 获得有效地址（指针），再读 M[M[A]] 获取操作数 |
| 变址寻址 | **1 次** | 计算 EA = (IX)+A 后，直接读 M[(IX)+A] |
| 基址寻址 | **1 次** | 计算 EA = (BR)+A 后，直接读 M[(BR)+A] |
| 相对寻址 | **1 次** | 计算 EA = (PC)+A 后，直接读 M[(PC)+A] |

**间接寻址为何需要额外的访存操作：**

间接寻址中，形式地址 A 指向的主存单元 M[A] 存放的不是操作数本身，而是操作数的地址（指针）。因此，CPU 必须先访问一次主存（读 M[A]）获取有效地址，再根据该有效地址第二次访问主存（读 M[M[A]]）才能取得操作数。这就是间接寻址比直接寻址多一次访存的原因。如果采用多级间接寻址，访存次数还会进一步增加。

---

### 答案汇总

| 寻址方式 | 有效地址 EA | 操作数 |
|:--------:|:-----------:|:------:|
| 直接寻址 | 0x0200 | 0x0500 |
| 间接寻址 | 0x0500 | 0x0AAA |
| 变址寻址 | 0x0400 | 0x0CCC |
| 基址寻址 | 0x0800 | 0x0DDD |
| 相对寻址 | 0x0210 | 0x0BBB |

五种寻址方式取得的操作数（0x0500、0x0AAA、0x0CCC、0x0DDD、0x0BBB）各不相同，验证了各寻址方式的区分度。

### 评分标准

- 第(1)题（2.5分）：提取 A=0x0200（0.5分）；直接寻址 EA 及操作数（1分）；间接寻址两步过程及最终操作数（1分）。
- 第(2)题（3.5分）：变址寻址 EA 及操作数（1.5分）；基址寻址 EA 及操作数（1.5分）；区分说明（0.5分）。
- 第(3)题（2分）：PC 取指后值 0x0010（1分）；EA 及操作数（1分）。
- 第(4)题（2分）：五种寻址方式访存次数（1分）；间接寻址额外访存的原因说明（1分）。
