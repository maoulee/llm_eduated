## 出题契约

### 基本信息
- target_subject: 组成原理
- target_family: 组成原理 > CO-6 总线 > 总线性能指标 > 总线带宽
- primary_target_name: 异步串行传输与数据传输率
- question_type: single_choice
- examination_mode: 计算型——串行传输率公式计算

### 难度目标
- k_target: K1=1,K2=4,K3=1,K4=2,K5=1
- difficulty_level: 2
- difficulty_rationale: 单步公式代入计算，需理解帧格式与传输率关系；K2=4 因多级换算（帧格式→有效位占比→代入波特率→单位统一）且非 2 的幂，易算错；其余维度低

### 结构要求
- option_count: 4
- distractor_strategy: 三类干扰路径——忽略附加位开销（A）、误算帧总位数（B）、分子分母颠倒或比例方向错误（C），各路径产生不同数值
- condition_count: 2（波特率值 + 帧格式描述）

### 参数约束
- 波特率 B: 2400–38400 范围常用值，非 2 的幂（推荐 4800/9600/19200）
- 数据位 d: 7 或 8 bit
- 停止位: 1 或 2 bit
- 校验位: 0 或 1（有或无）
- 每帧总位数 n = 1(起始) + d + 校验位 + 停止位
- 有效数据传输率 = B × d / n
- 一致性约束: 结果为整数或常见可辨识数值；4 个选项值互不重合且差值足够大

### 参考经验摘要
- 历史模式: 总线传输率/带宽计算为 408 高频题型；异步串行传输有效数据率是经典变体
- 难度锚点: K2 主导（单步含多级换算），整体难度 2
- 典型陷阱: 波特率直接等同于有效数据率；漏算起始位/停止位；校验位有无读题不仔细
