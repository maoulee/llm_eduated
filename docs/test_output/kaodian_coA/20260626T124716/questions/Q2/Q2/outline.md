## 考点
- **异步串行传输帧格式**：理解 UART 异步串行通信的一帧由起始位（1 bit）、数据位、校验位（0 或 1 bit）、停止位（1 或 1.5 或 2 bit）构成；考察侧重点为"一帧中哪些位是有效数据位、哪些是附加开销位"。
- **有效数据传输率计算**：有效数据传输率 = 波特率 × (每帧有效数据位数 / 每帧总位数)；考察侧重点为区分波特率（信号变化率）与有效比特率，以及从帧格式推导开销比。

## 难度目标
| 维度 | 目标 | 达标理由 |
|------|------|----------|
| K1 基础认知 | 1 | 公式直接给出或常见公式，概念简单（波特率、帧格式），学生基本都知道 |
| K2 单步代入 | 4 | 需多级换算：帧格式 → 计算有效位占比 → 代入波特率 → 结果单位统一（bps），非 2 的幂次，易算错 |
| K3 机制推演 | 1 | 无多步串行推演，一步公式代入即可 |
| K4 条件路由 | 2 | 常规注意点：需识别停止位数与校验位的有无会影响帧总位数，属 408 考生基本不会漏的点 |
| K5 跨域联动 | 1 | 单一知识点（总线传输率）内部解决 |

整体难度定位：2（单步公式代入计算，需理解帧格式与传输率关系）。

## 考察模式
**计算型——串行传输率公式计算**。题干给出波特率和帧格式（起始位 + 数据位 + 校验位 + 停止位），要求计算有效数据传输率。学生需先从帧格式计算有效数据位占比，再乘以波特率得出有效 bps。此模式直接对应 408 大纲"总线性能指标"中对带宽/传输率的考查要求，属高频基础计算题型。

## 出题要求
- **题型**：单项选择题，4 选项，2 分。
- **条件数**：2 个显式条件（波特率值、帧格式描述）。
- **条件设计原则**：
  - 波特率给出具体数值，应选非 2 的幂的值（如 9600、19200、4800 等），避免计算退化。
  - 帧格式需明确列出：起始位数、数据位数、校验位有无、停止位数。帧总位数与有效位数之比应使结果落在整数或常见数值上，便于设选项。
- **参数取值范围**：
  - 波特率：2400–38400 范围内的常用值，非 2 的幂。
  - 数据位：7 或 8 bit。
  - 停止位：1 或 2 bit。
  - 校验位：有或无（影响总位数）。

## 子问题规划
本题为单项选择题，无子问题拆分。4 个选项要求：
- 1 个正确答案：正确计算有效数据传输率。
- 3 个干扰项，策略见下。

## 参数约束
- 波特率 B：2400–38400，非 2 的幂，推荐 4800/9600/19200 之一。
- 每帧有效数据位 d：7 或 8。
- 每帧附加位 a：起始位恒为 1；停止位取 1 或 2；校验位取 0 或 1。
- 每帧总位数 n = 1(起始) + d + 校验位 + 停止位。
- 有效数据传输率 = B × d / n。
- **一致性约束**：结果值必须为整数或常见可辨识数值；正确选项与干扰项之间数值差应足够大，不产生混淆。
- **可调自由度**：B、d、停止位数、校验位有无均可由 Question Agent 自由组合，只要满足一致性约束。

## 干扰策略
- **干扰项 A（忽略开销）**：直接用波特率作为答案（学生忘记减去附加位开销）。
- **干扰项 B（误算帧位数）**：帧总位数多算或少算 1 位（如漏掉起始位或停止位算错），导致占比偏差。
- **干扰项 C（单位/方向混淆）**：用 B × n / d（分子分母颠倒）或其他常见比例错误。
- 要求：三个干扰项对应不同错误路径，各产生不同数值结果，与正确答案均不重合。

## 参考经验
- **历史模式**：408 中"总线传输率/带宽"计算题为高频题型，常以选择或综合题出现；异步串行传输的有效数据率是经典变体。
- **难度锚点**：该题型 K2 突出（单步计算但含多级换算），其余维度偏低，整体难度 2。
- **典型陷阱**：① 将波特率直接等同于有效数据率；② 漏算起始位/停止位；③ 校验位有无未仔细读题导致帧位数错误。
