# 概念题

## 第 1 题

**题干**：某计算机主存容量为 4KB，按字节编址，则该存储器所需的地址线位数为（　　）。

A. 10

B. 11

C. 12

D. 16

**答案**：C

---

## 第 2 题

**题干**：下列关于外部中断（硬件中断）的叙述中，正确的是（　　）。

A. 外部中断是由 CPU 执行某条指令时产生的，如除零异常

B. 外部中断的请求信号来自 CPU 外部的设备，如键盘、定时器

C. 外部中断属于程序性中断，由软件中断指令 INT 触发

D. 外部中断只能在当前指令执行完毕后响应，且优先级总是低于内部中断

**答案**：B

---

## 第 3 题

**题干**：下列各类存储器中，按存取速度从快到慢排列正确的是（　　）。

A. 通用寄存器 → Cache → 主存 → 磁盘

B. Cache → 通用寄存器 → 主存 → 磁盘

C. 通用寄存器 → 主存 → Cache → 磁盘

D. Cache → 主存 → 通用寄存器 → 磁盘

**答案**：A

B. 冯·诺依曼计算机以存储器为中心，指令和数据分别存放在两个独立的存储器中

## 第 6 题

**题干**：异步通信中采用"全互锁"应答方式，下列叙述正确的是（　　）。

A. 主设备发出请求信号后，必须等待从设备给出应答信号后才能撤销请求，而从设备撤销应答信号后不等待主设备

B. 主设备发出请求信号后可不等待应答就撤销请求，从设备自行决定何时应答

C. 主设备发出请求信号后，等待从设备应答后才撤销请求；从设备也需等待主设备确认撤销请求后才撤销应答

D. 主设备发出请求信号的同时从设备立即应答，双方同时撤销信号

**答案**：C

A. Cache—主存层次主要解决存储系统的速度问题，主存—辅存层次主要解决存储系统的容量问题

B. Cache—主存层次主要解决存储系统的容量问题，主存—辅存层次主要解决存储系统的速度问题

## 第 8 题

**题干**：下列关于水平型微指令和垂直型微指令的比较，正确的是（　　）。

A. 水平型微指令通常不编码或采用少量编码，一条微指令中可以同时定义多个并行的微操作

B. 垂直型微指令采用直接表示法，微指令字较长，便于编写和优化

C. 水平型微指令采用类似机器指令的操作码字段来定义微操作，微指令字较短

D. 垂直型微指令的并行操作能力强于水平型微指令

## 第 9 题

**题干**：下列关于指令周期的叙述中，正确的是（　　）。

A. 指令周期是指 CPU 从主存取出一条指令所需的时间

B. 任何一条指令的指令周期都包含取指周期、间址周期、执行周期和中断周期四个阶段

C. 指令周期包含取指周期和执行周期，所有指令都必须经历这两个阶段，间址周期和中断周期则视具体情况而定

D. 指令周期是指 CPU 执行一条指令中的某个微操作所需的时间

**答案**：C
