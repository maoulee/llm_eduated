## 考点
- **主考点**：存储容量与地址线位数的关系——理解存储容量 = 2^(地址线位数)，能够对给定容量反推地址线根数或对给定地址线根数正推容量。
- **辅考点**：存储单位换算（KB/MB/B 之间的 2 的幂次关系），以及"按字节编址"这一隐含前提的辨析。
- **考察侧重点**：概念辨析为主（K1=4），需精准辨析"容量↔地址线位数"的换算关系，同时识别题目中可能设置的陷阱（如编址方式、容量单位混淆）。

## 考察模式
**概念辨析型——存储单位换算**

选择理由：slot 指定的 examination_mode 即为"概念辨析型——存储单位换算"。参考 2009_Q22 的模式，该题位历史上以"给出存储容量或地址线位数，判断对应关系是否正确"为核心考法，属于定义记忆+简单换算的典型概念题。

## 出题要求
- **题型**：单项选择题，4 选项，1 正确 3 干扰
- **分值**：2 分
- **总条件数**：1-2 个显式条件（如"某存储器容量为 X"/"按字节编址"）
- **条件设计原则**：
  - 给出一个具体的存储容量或地址线位数作为题干核心条件
  - 可选择性加入编址方式作为隐含/显式前提
  - 选项设计为四组"容量 ↔ 地址线位数"的配对关系或四组数值，其中一组正确
- **参数取值范围要求**：
  - 容量值应在 2 的幂次友好范围内（如 1KB ~ 64KB），避免非 2 的幂次导致计算退化
  - 地址线位数应在 8 ~ 20 之间，使容量落在合理区间
  - 编址方式默认按字节编址，可作为陷阱设置为按字编址

## 子问题规划
单项选择题，无子问题划分。四个选项各自对应一个完整的判断/换算结果。

## 参数约束
| 参数 | 取值范围 | 约束 |
|------|----------|------|
| 存储容量 C | 2 的幂次，如 2^10 B ~ 2^16 B（1KB ~ 64KB） | C = 2^(地址线位数 n)，C 必须为 2 的整数幂 |
| 地址线位数 n | 10 ~ 16 | n = log2(C)，与 C 严格对应 |
| 编址方式 | 按字节编址（默认）/ 按字编址 | 若按字编址，需明确字长，且容量换算基准改变 |
| 干扰选项的容量/位数 | 与正确答案存在 ±1 位或单位混淆的偏差 | 3 个干扰选项必须各有不同的错误来源（位数±1、单位混淆、编址基准错误），不能全部同源 |

**可调自由度**：Question Agent 可自由选择具体的容量值和编址方式，只要满足上述约束即可。

## 参考经验
- **历史模式**（2009_Q22）：给出存储容量，要求判断地址线位数，考察"2^n = 容量"的核心关系。典型形式为四个选项中只有一组容量-位数配对正确。
- **难度锚点**：K1 主导（概念辨析），K4 辅助（陷阱），整体难度 1，属于选择题前段送分定位。
- **典型陷阱**：
  1. 容量单位混淆（KB vs B，漏算/多算 1024 倍）
  2. 地址线位数 ±1 的偏差（如把数据线位数误当地址线）
  3. 编址方式不同导致换算基准改变（按字编址时地址线位数减少）
  4. 从 0 开始计数 vs 从 1 开始计数的 off-by-one
