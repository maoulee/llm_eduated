# 概念题解析

## 第 1 题解析

**答案**：C

**解析**：主存容量为 4KB = 4096B = 2^12 B，按字节编址则每个存储单元对应一个字节地址，共需 2^12 个地址，地址线位数 n = log2(4096) = 12 位。

- A 错误：10 位对应容量 2^10 B = 1KB，少了 4 倍。
- B 错误：11 位对应容量 2^11 B = 2KB，少了一半（常见 off-by-one 偏差）。
- D 错误：16 位对应 64KB，将 4KB 与 64KB 混淆或误用 KB↔bit 单位换算导致。

## 第 2 题解析

**答案**：B

**解析**：外部中断（又称硬件中断）的请求信号来自 CPU 外部的硬件设备，如键盘、鼠标、定时器、电源故障等，属于异步事件。

- A 错误：除零异常是由 CPU 执行指令时内部检测到的，属于内部中断（异常），不是外部中断。
- C 错误：软件中断指令（如 INT n）产生的也属于内部中断，且外部中断不属于程序性中断。
- D 错误：外部中断优先级并非总是低于内部中断，不同中断源的优先级由中断系统设计决定，外部中断（如电源故障）可以具有很高优先级。

## 第 3 题解析

**答案**：A

**解析**：存储层次按速度从快到慢依次为：通用寄存器（在 CPU 内部，速度最快）→ Cache（高速缓存，位于 CPU 与主存之间）→ 主存（DRAM）→ 磁盘（辅存，机械硬盘最慢）。

- B 错误：通用寄存器的速度比 Cache 更快，二者顺序颠倒了。
- C 错误：Cache 的速度快于主存，二者顺序颠倒了。
- D 错误：通用寄存器应排在 Cache 前面，不应排在主存之后。

## 第 4 题解析

**答案**：C

**解析**：寄存器寻址的操作数直接存放在 CPU 寄存器中，取操作数时只需访问寄存器，无需访问主存，因此速度最快。

- A 错误：直接寻址需要一次访问主存来获取操作数，慢于寄存器寻址。
- B 错误：间接寻址需要两次访问主存（先取地址再取操作数），是最慢的方式之一。
- D 错误：基址寻址需要访问主存且需要计算有效地址，慢于寄存器寻址。

## 第 5 题解析

**答案**：A

**解析**：冯·诺依曼计算机以运算器为中心，各部件（包括输入输出设备）之间的信息传送都经过运算器。其核心设计思想是"存储程序"，即程序和数据预先存入存储器，机器在程序控制下自动逐条执行指令。

- B 错误：以存储器为中心是现代计算机的结构特征，而冯·诺依曼原始结构以运算器为中心。且冯·诺依曼结构中指令和数据存放在同一个存储器中，不是两个独立存储器（那是哈佛结构）。
- C 错误：控制器的主要功能是协调和控制各部件工作（取指令、分析指令、产生控制信号），算术和逻辑运算是运算器的功能。
- D 错误：存储程序是冯·诺依曼计算机最核心的特点，必须有存储程序机制。

## 第 6 题解析

**答案**：C

**解析**：全互锁方式（又称双向握手）中，主设备发出请求信号后，等待从设备给出应答信号才撤销请求；从设备给出应答信号后，也需等待主设备撤销请求信号后才撤销应答。双方互锁，确保信号可靠传递。

- A 错误：描述的是半互锁方式（主设备等待从设备应答后才撤销请求，但从设备撤销应答后不等待主设备确认）。
- B 错误：描述的是不互锁方式（主设备发出请求后等待一段时间便自行撤销，不等从设备应答）。
- D 错误：双方同时发出和撤销信号不符合任何应答方式的定义，全互锁强调的是双向等待确认。

## 第 7 题解析

**答案**：A

**解析**：三级存储系统中，Cache—主存层次通过局部性原理使 CPU 能以接近 Cache 的速度访问内存，主要解决速度问题；主存—辅存层次通过虚拟存储技术为用户提供比实际主存大得多的地址空间，主要解决容量问题。

- B 错误：两个层次的功能颠倒了，Cache—主存解决速度而非容量。
- C 错误：主存—辅存层次解决的是容量问题，不是速度问题。
- D 错误：Cache—主存层次解决的是速度问题，不是容量问题。

## 第 8 题解析

**答案**：A

**解析**：水平型微指令采用直接控制方式（或少量编码），一条微指令中可以同时定义多个互不冲突的微操作，并行能力强，微指令字较长，但效率高。

- B 错误：垂直型微指令采用类似机器指令的编码方式（操作码字段），微指令字较短，并非直接表示法。
- C 错误：水平型微指令采用直接控制或分段编码，不采用类似机器指令的操作码方式；采用操作码编码是垂直型微指令的特征。
- D 错误：水平型微指令的并行操作能力强于垂直型微指令，此处说法正好相反。

## 第 9 题解析

**答案**：C

**解析**：指令周期是 CPU 从主存取出一条指令并执行完该指令所需的全部时间。所有指令都必须经历取指周期和执行周期两个基本阶段；而间址周期仅当指令需要间接寻址时才存在，中断周期仅当有中断请求且 CPU 响应中断时才存在，并非所有指令都包含。

- A 错误：指令周期包括取指令和执行指令的全过程，不仅仅是取出指令的时间（那只是取指周期）。
- B 错误：间址周期和中断周期并非所有指令都包含，只有特定情况下才出现。
- D 错误：执行一个微操作所需的时间是一个 CPU 时钟周期（或微周期），不是指令周期。一个指令周期包含多个时钟周期。
