## 考点
- **核心考点**：Cache地址映射——三种映射方式下的主存地址格式设计
  - 直接映射：主存地址 = Tag + Cache行号 + 块内偏移
  - 四路组相联映射：主存地址 = Tag + 组号 + 块内偏移
  - 全相联映射：主存地址 = Tag + 块内偏移
- **辅助考点**：由容量参数推导各字段位数（对数运算、2的幂次转换）

## 难度目标
- **K1=3（标准）**：必须准确记忆三种映射方式的地址字段划分规则，概念辨析是入题前提
- **K2=3（标准）**：需代入公式计算各字段位数（log₂运算），涉及2的幂次转换，可能有非平凡数
- **K3=4（较高）**：需分别对三种映射方式走完"计算行数→计算组数→划分字段→求和验证"的推演流程，三种方式并行处理，步数>5
- **K4=2（较低）**：条件明确，主要注意点为四路组相联的"路数"影响组号位数，无深层陷阱
- **K5=1（微弱）**：单一知识点内部解决，不涉及跨系统联动

## 考察模式
**推演型——Cache地址映射格式设计**
理由：此题位要求学生在明确映射规则下，从给定容量参数逐步推导出三种映射方式的地址字段位数。核心在于机制推演（K3=4），学生需对三种映射分别执行字段划分流程。此模式与历史经验中的Cache地址格式设计题一致。

## 出题要求
- **题型**：应用题（主观题），总分8分
- **总条件数**：3个显式条件——主存容量、Cache容量、块长（或等价表述）
- **附加条件**：明确四路组相联的路数为4
- **条件设计原则**：参数均为2的幂次，使得各字段位数均为整数；三种映射方式的Tag位数应各不相同，以体现区分度
- **参数取值范围要求**：
  - 主存容量：2²⁰ ~ 2³² 字节范围
  - Cache容量：远小于主存，2¹⁰ ~ 2²⁰ 字节范围
  - 块长：2⁴ ~ 2⁸ 字节
  - 约束：Cache容量 / 块长 = Cache行数必须能被4整除（四路组相联要求）

## 子问题规划
本题8分，规划为1个综合问题（含三个并列子任务），各子任务分值分配：

| 子任务 | 类型 | 考察目标 | 分值 | 关系 |
|--------|------|----------|------|------|
| (1) 直接映射地址格式 | 计算+推演 | 由容量推导块内偏移位数、Cache行号位数、Tag位数，给出格式 | 约3分 | 三问并列，共用同一组容量参数 |
| (2) 四路组相联地址格式 | 计算+推演 | 由容量推导块内偏移位数、组号位数（行数/4取对数）、Tag位数 | 约3分 | 与(1)(3)并列 |
| (3) 全相联映射地址格式 | 计算+推演 | 由容量推导块内偏移位数、Tag位数（无行号/组号字段） | 约2分 | 与(1)(2)并列 |

- **依赖关系**：三个子任务**并行**（共用同一组参数，但各自独立推导），不存在串行依赖
- **设计意图**：三问对比考查学生对三种映射方式地址字段差异的理解，全相联最简单（2分），直接映射和组相联各3分

## 参数约束
| 参数 | 取值范围 | 一致性约束 | 自由度 |
|------|----------|------------|--------|
| 主存容量 M | 2²⁰ ~ 2³² B | M > Cache容量 | 可选 |
| Cache容量 C | 2¹⁰ ~ 2²⁰ B | C > 块长；C / 块长为2的幂次且≥4 | 可选 |
| 块长 B | 2⁴ ~ 2⁸ B | B ≤ C；C / B 可被4整除 | 可选 |
| 路数 | 固定为4 | 四路组相联 | 固定 |

**关键约束**：
- Cache行数 = C / B，必须为2的幂次
- 组数 = Cache行数 / 4，必须为2的幂次（即Cache行数 ≥ 4）
- 三种映射方式的Tag位数应各不相同，避免学生混淆时"误打误撞"得分
- 主存地址总位数 = log₂(M)，三种映射方式的各字段位数之和应等于此值

## 参考经验
- **历史模式**：Cache地址映射格式设计是组成原理经典考法，常见于给出容量参数要求划分字段
- **难度锚点**：K3主导（推演步数多），K1和K2为辅助（概念记忆+基本计算）
- **典型陷阱**：
  - 四路组相联中"路数4"不占地址字段，但影响组数计算
  - 全相联映射无行号/组号字段，Tag位数最大
  - 直接映射Tag位数 = 主存地址位数 - 行号位数 - 块内偏移位数
  - 学生易混淆"组号位数"与"行号位数"的取对数基数
