# Cache 地址映射格式设计

## 题干

某计算机的主存地址空间按字节编址，相关参数如下：

- **主存容量**：64 MB
- **Cache 容量**：16 KB
- **主存与 Cache 之间以数据块为单位交换信息，块长**：64 B

Cache 数据区与主存均按相同大小的数据块划分。请针对以下三种地址映射方式，分别给出**主存地址各字段的位数划分**（写出每个字段的名称与位数），并说明划分依据。

---

### 问题 (1)（3 分）

若采用**直接映射**方式，主存地址应划分为哪几个字段？各字段分别为多少位？

### 问题 (2)（3 分）

若采用**四路组相联映射**方式（即每组 4 行），主存地址应划分为哪几个字段？各字段分别为多少位？

### 问题 (3)（2 分）

若采用**全相联映射**方式，主存地址应划分为哪几个字段？各字段分别为多少位？

---

## 参数说明（供 write_gen 建模用）

| 参数 | 值 | 说明 |
|------|----|------|
| 主存容量 M | 64 MB = 2²⁶ B | 主存地址位数 = 26 |
| Cache 容量 C | 16 KB = 2¹⁴ B | |
| 块长 B | 64 B = 2⁶ B | 块内地址位数 = 6 |
| Cache 行数 | 2¹⁴ / 2⁶ = 2⁸ = 256 | 行号位数 = 8 |
| 组数（四路） | 256 / 4 = 64 = 2⁶ | 组号位数 = 6 |
| 路数 | 4 | 不占地址字段 |

## 通过条件（成功判据·可机检）

本题成立需同时满足以下可机检特征：

1. **三种映射方式的 Tag 位数各不相同**：直接映射 Tag 位数 < 四路组相联 Tag 位数 < 全相联 Tag 位数（三者严格递增，无相等）。
2. **字段位数一致性**：三种映射方式下各字段位数之和均等于 26（= log₂(64 MB)）。
3. **直接映射字段完整**：直接映射地址 = Tag + 行号 + 块内地址，三段之和 = 26，行号位数 = 8。
4. **四路组相联字段完整**：四路组相联地址 = Tag + 组号 + 块内地址，三段之和 = 26，组号位数 = 6（注意路数 4 不单独占字段，但影响组数计算）。
5. **全相联字段完整**：全相联地址 = Tag + 块内地址，两段之和 = 26，无行号/组号字段。
