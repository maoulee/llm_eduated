# 题目：Booth 算法（补码一位乘法）推演 — 求解

## 参数

| 参数 | 值 |
|------|-----|
| $x$ | $-5/16$ |
| $y$ | $+6/16 = 3/8$ |
| 字长 | 5 位补码（1 符号位 + 4 数值位），$n=4$ |
| 迭代趟数 | $n+1=5$ 趟 |
| 部分积寄存器 | 6 位（双符号位 + 4 数值位） |
| 乘数寄存器 | 5 位 + 1 附加位 $y_{-1}$（初值 0） |

---

## 第(1)问（3 分）：补码转换与 $[-x]_补$

### 1. 求 $[x]_补$ 和 $[y]_补$

**$x = -5/16$ 的 5 位补码表示：**

$x$ 的绝对值 $5/16 = 0.0101_2$，取原码 $1.0101$，负数补码 = 反码加 1：

$$[x]_补 = 1.1011$$

即 $[x]_补 = \texttt{11011}$（5 位整数形式），十进制整数 $= 27$（模 $2^5$），对应值 $= -(32-27)/16 = -5/16$ ✓

**$y = +6/16 = 3/8$ 的 5 位补码表示：**

$6/16 = 0.0110_2$，正数补码 = 原码：

$$[y]_补 = 0.0110$$

即 $[y]_补 = \texttt{00110}$（5 位整数形式），十进制整数 $= 6$，对应值 $= 6/16 = 3/8$ ✓

### 2. 求 $[-x]_补$

将 $[x]_补 = \texttt{11011}$ 按位取反再加 1：

- 按位取反：$\texttt{11011} \to \texttt{00100}$
- 末位加 1：$\texttt{00100} + 1 = \texttt{00101}$

$$[-x]_补 = 0.0101 = \texttt{00101}$$

**验证**：$[x]_补 + [-x]_补 = \texttt{11011} + \texttt{00101} = \texttt{100000} = 0$（模 $2^5$）✓

$[-x]_补$ 对应值 $= 5/16$（正数，与 $-x = +5/16$ 一致）✓

## 第(2)问（5 分）：Booth 算法逐步计算

### 双符号位扩展

将被乘数 $[x]_补$ 和 $[-x]_补$ 扩展为 6 位双符号位形式（符号位复制）：

| 被加数 | 5 位 | 6 位双符号位 |
|--------|------|-------------|
| $[x]_补$ | `11011` | `11 1011` = `111011` |
| $[-x]_补$ | `00101` | `00 0101` = `000101` |

### Booth 迭代表格

初始状态：部分积 $PP = \texttt{000000}$，乘数 $Y = \texttt{00110}$，附加位 $y_{-1} = 0$。

判断位规则（乘数最低位 $y_i$ 与附加位 $y_{-1}$ 组成判断位）：

| 判断位 | 操作 |
|--------|------|
| `00` 或 `11` | $+0$ |
| `01` | $+[x]_补$ |
| `10` | $+[-x]_补$ |

| 趟 | 操作 | 部分积(移前) | 乘数+附加位(移前) | 判断位 | 部分积(移后) | 乘数+附加位(移后) |
|:--:|:-----:|:----------:|:---------------:|:-----:|:----------:|:---------------:|
| 1 | $+0$ | `000000` | `001100` | `00` | `000000` | `000110` |
| 2 | $+[-x]_补$ | `000101` | `000110` | `10` | `000010` | `100011` |
| 3 | $+0$ | `000010` | `100011` | `11` | `000001` | `010001` |
| 4 | $+[x]_补$ | `111100` | `010001` | `01` | `111110` | `001000` |
| 5 | $+0$ | `111110` | `001000` | `00` | `111111` | `000100` |

### 各趟详解

**第 1 趟**：判断位 = $y_4 y_{-1} = 0\cdot0 = \texttt{00}$，$+0$。$PP = \texttt{000000}$。算术右移后 $PP = \texttt{000000}$，$Y = \texttt{00011}$，$y_{-1}=0$。

**第 2 趟**：判断位 = $y_4 y_{-1} = 0\cdot0 = \texttt{10}$，$+[-x]_补 = \texttt{000101}$。$PP = \texttt{000000} + \texttt{000101} = \texttt{000101}$。算术右移后 $PP = \texttt{000010}$，$Y = \texttt{10001}$...（联合右移：乘数最低位 `0` 移入附加位）$Y = \texttt{10001}$, $y_{-1}=\texttt{1}$ → 显示为 `100011`。

**第 3 趟**：判断位 = $\texttt{11}$，$+0$。$PP = \texttt{000010}$。算术右移后 $PP = \texttt{000001}$，$Y = \texttt{01000}$... → $Y$ + 附加位 = `010001`。

**第 4 趟**：判断位 = $\texttt{01}$，$+[x]_补 = \texttt{111011}$。$PP = \texttt{000001} + \texttt{111011} = \texttt{111100}$。算术右移后 $PP = \texttt{111110}$，$Y$ + 附加位 = `001000`。

**第 5 趟**：判断位 = $\texttt{00}$，$+0$。$PP = \texttt{111110}$。算术右移后 $PP = \texttt{111111}$，$Y$ + 附加位 = `000100`。

### 最终乘积

迭代结束后：
- 最终部分积（双符号位）$= \texttt{111111}$
- 最终乘数（含附加位）$= \texttt{000100}$

取部分积低 5 位（去重复符号位）拼乘数 5 位，得 **10 位乘积**：

$$[x \times y]_补 = \texttt{1.11110001\mathbf{0}} = \texttt{1111100010}$$

### 十进制验证

10 位乘积 $\texttt{1111100010}$ 中：bit9 = 符号位 = 1（负数），8 个数值位权重 $2^{-1}$ 至 $2^{-8}$，bit0 为附加零位（恒为 0）。

符号位为 1 → 负数。补码整数值 $= \texttt{1111100010} - 2^{10} = 994 - 1024 = -30$。

除以 $2^{2n} = 2^8 = 256$：

$$[x \times y]_补 \text{ 对应值} = \frac{-30}{256} = -\frac{15}{128}$$

**验证**：

$$x \times y = -\frac{5}{16} \times \frac{6}{16} = -\frac{30}{256} = -\frac{15}{128}$$

两者一致 ✓，且 $|-15/128| < 1$，无溢出 ✓。

---

## 最终答案

**第(1)问**：
- $[x]_补 = 1.1011$
- $[y]_补 = 0.0110$
- $[-x]_补 = 0.0101$

**第(2)问**：
- 5 趟 Booth 迭代表格见上表
- $[x \times y]_补 = \texttt{1.11110001\mathbf{0}}$（10 位，最低位为附加零位）
- 十进制值 $= -\dfrac{15}{128}$，验证 $x \times y = -\dfrac{5}{16} \times \dfrac{6}{16} = -\dfrac{15}{128}$ ✓
