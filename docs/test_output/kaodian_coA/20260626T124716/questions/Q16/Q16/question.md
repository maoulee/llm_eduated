# 题目：Booth 算法（补码一位乘法）推演

## 题干

已知定点小数 $x = -\dfrac{5}{16}$，$y = +\dfrac{6}{16}$，采用 5 位补码表示（1 位符号位 + 4 位数值位，即 $n=4$）。

回答以下问题：

### 第(1)问（3 分）

1. 将 $x$ 和 $y$ 分别转换为 5 位补码定点小数表示，写出 $[x]_补$ 和 $[y]_补$。
2. 求出 $[-x]_补$。

### 第(2)问（5 分）

用 **Booth 算法（补码一位乘法）** 计算 $[x \times y]_补$。要求：

- 部分积取双符号位（即部分积为 6 位，含 2 位符号位）。
- 附加位 $y_{-1}$ 初值为 0。
- **列出完整的迭代表格**，包含每趟的：部分积值、乘数寄存器值（含附加位）、当前判断位（乘数最低位与附加位）、本次执行的操作（加 $[x]_补$ / 加 $[-x]_补$ / 加 0）、以及算术右移后的结果。
- 共进行 $n+1=5$ 趟迭代，**每趟均需做一次算术右移**。
- 写出最终乘积 $[x \times y]_补$，并将其转换回十进制值验证。

## 参数说明

| 参数 | 值 |
|------|-----|
| $x$ | $-5/16$（定点小数，5 位补码：$1.1011$） |
| $y$ | $+6/16$（定点小数，5 位补码：$0.0110$） |
| 字长 | 5 位（1 符号位 + 4 数值位），$n=4$ |
| 迭代趟数 | $n+1=5$ 趟 |

## 通过条件（成功判据，供 gen.py assert 使用）

1. **Booth 操作完整性**：5 趟迭代中，乘数低位与附加位的相邻位对（$y_i, y_{-1}$）在完整迭代序列中至少出现一次 `"10"` 模式（触发加 $[-x]_补$）和至少出现一次 `"01"` 模式（触发加 $[x]_补$），使 Booth 算法的加被乘数和减被乘数两种核心操作均被执行。
2. **[-x]补 正确性**：$[-x]_补$ 可由 $[x]_补$ 按位取反末位加 1 得到，且 $[x]_补 + [-x]_补 = 0$（模 $2^5$）。
3. **乘积正确性**：最终乘积 $[x \times y]_补$ 转换为十进制后等于 $x \times y = -\dfrac{30}{256} = -\dfrac{15}{128}$，且该值可用 5 位补码正确表示（绝对值 $<1$，无溢出）。
4. **每趟右移**：5 趟迭代中每趟均有一次算术右移操作（非逻辑右移），部分积符号位在右移后保持不变。
