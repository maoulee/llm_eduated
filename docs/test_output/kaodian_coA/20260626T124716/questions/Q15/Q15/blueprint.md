## 出题契约

### 基本信息
- target_subject: 组成原理
- target_family: 组成原理 > CO-7 输入输出系统 > I/O方式 > 中断方式 > 中断屏蔽
- primary_target_name: 中断屏蔽字设计
- question_type: comprehensive
- examination_mode: 推演型——中断屏蔽字设计

### 难度目标
- k_target: K1=3,K2=2,K3=4,K4=3,K5=1
- difficulty_level: 3
- difficulty_rationale: 核心难点在于对5个中断源逐行推导屏蔽字（K3=4），且需区分响应优先级与处理优先级（K4=3）；概念要求标准（K1=3），计算量小（K2=2），不涉及跨子系统联动（K5=1）

### 结构要求
- sub_question_count: 2
- sub_question_details:
  - 子问题1（6分）：写出每个中断源的屏蔽字（5×5屏蔽字表）
  - 子问题2（2分）：分析给定中断到达时序下的处理顺序/嵌套过程
- dependency: 子问题2依赖子问题1的屏蔽字结果
- condition_count: 3-4

### 参数约束
- 中断源数量: 固定5个
- 响应优先级: 中断源1为最高（优先级1），依次至中断源5为最低（优先级5），编号固定
- 处理优先级: 必须为5个中断源的一个全排列；与响应优先级至少有2个位置不同；至少1个中断源处理优先级高于其响应优先级，至少1个低于
- 屏蔽字: 5位，第i位对应第i级中断源，1=屏蔽/0=允许
- 自身屏蔽位: 按教材通用约定设为1，题干需明确说明
- 处理优先级排列自由度: Question Agent 在满足上述约束下自由选择具体排列
- 中断到达时序: 给出3-4个中断源到达顺序和时间关系，需能体现处理优先级≠响应优先级导致的嵌套差异

### 参考经验摘要
- 历史模式: 2017_Q22，标准考法为"给定中断源和新处理优先级，写出屏蔽字表"
- 难度锚点: K3=4对应25位屏蔽字逐行推演，K4=3对应响应/处理优先级区分陷阱
- 典型陷阱:
  1. 按响应优先级而非处理优先级填屏蔽字
  2. 自身屏蔽位漏填或填反
  3. 屏蔽位与中断源级别的对应关系搞反
  4. 中断嵌套分析中未应用屏蔽字
