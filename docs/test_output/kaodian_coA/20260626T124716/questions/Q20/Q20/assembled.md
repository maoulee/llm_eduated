## 出题契约

### 基本信息
- target_subject: 组成原理
- target_family: 组成原理 > CO-5 中央处理器 > 指令流水线
- primary_target_name: 指令流水线性能与冒险分析
- question_type: comprehensive
- examination_mode: 综合型——指令流水线性能与冒险分析

### 难度目标
- k_target: K1=3,K2=3,K3=4,K4=4,K5=2
- difficulty_level: 3
- difficulty_rationale: 需性能计算+冒险识别+转发改进分析，三个层面递进综合考查；K3=4因需多步推演流水线指令流动；K4=4因需识别"操作周期取最大值"的隐含前提及冒险停顿差异

### 结构要求
- sub_question_count: 5
- sub_question_structure:
  - Q1(2分): 计算——操作周期确定（取各段最大值）
  - Q2(2分): 计算——加速比（非流水线时间/流水线时间）
  - Q3(2分): 分析——指令序列数据冒险类型识别（RAW）
  - Q4(2分): 计算——无转发情况各冒险点停顿周期及总计
  - Q5(2分): 计算/分析——有转发情况停顿周期及与无转发对比
- dependency: Q1→Q2串行；Q3→Q4→Q5串行；两组间可并行
- distractor_strategy: 不适用（综合题，非选择题）

### 参数约束
- 流水线级数: 固定4级（IF/ID/EX/WB）
- 各段时间值:
  - 取值范围: 100ns-500ns
  - 约束: 4个值互不相等，至少1个非2的幂次
  - 约束: 最大值与最小值差>50ns
  - 操作周期 = max(各段时间)
- 指令条数: 5-8条，顺序执行（无分支/跳转）
- 数据冒险设计:
  - 至少2组RAW冒险
  - 至少1组相邻指令冒险（间距=1）
  - 至少1组间隔1条指令的冒险（间距=2）
  - 不含WAR/WAW冒险
- 加速比公式:
  - 非流水线时间 = 各段时间之和 × 指令条数
  - 流水线时间 = 操作周期 × (级数 + 指令条数 - 1)
- 可调自由度: 各段具体时间值、指令条数、指令序列内容（寄存器号/操作类型）由Question Agent决定

### 参考经验摘要
- 历史模式: 递进式综合——给定参数→性能计算→冒险分析→停顿计算（2016_Q19、2026_Q20）
- 难度锚点: K3集中在4（多步流水线推演），K4集中在3-4（冒险识别+隐含前提）
- 典型陷阱:
  - 操作周期误取各段之和而非最大值
  - 加速比分子/分母混淆
  - 无转发与有转发停顿周期混淆
  - 忽略流水线充满/排空阶段时钟数
