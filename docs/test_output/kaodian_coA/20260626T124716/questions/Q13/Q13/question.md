# 存储器字位同时扩展

## 题干

某计算机系统需要用若干片规格为 **8K × 4 位** 的 RAM 芯片，扩展构成一个容量为 **64KB**、存储字长为 **16 位** 的主存储器模块。

请回答以下问题：

### 第 1 问（2 分）

计算该主存储器模块所需的 **地址线根数** 和 **数据线根数**。

> 说明：按字节编址，地址线根数取能覆盖全部存储容量的最小值。

### 第 2 问（4 分）

分别计算构成该主存储器模块所需的：

1. **字扩展倍数**（即地址维度的扩展倍数）；
2. **位扩展倍数**（即数据维度的扩展倍数）；
3. **总共需要的芯片数量**。

要求写出计算过程。

---

## 通过条件（成功判据，可机检）

1. **地址线根数正确**：地址线根数 = $\lceil \log_2(\text{C\_target（字节）}) \rceil = \log_2(65536) = 16$，数据线根数 = 存储字长 = 16。
2. **字扩展倍数 ≥ 2**：字扩展倍数 = 目标容量 / 芯片单元数 = 64KB / 8K = 8 ≥ 2。
3. **位扩展倍数 ≥ 2**：位扩展倍数 = 存储字长 / 芯片位宽 = 16 / 4 = 4 ≥ 2。
4. **总芯片数 = 字扩展倍数 × 位扩展倍数**（乘积关系，非相加）：总芯片数 = 8 × 4 = 32。
5. **地址线由总容量决定、数据线由字长决定**：两者各自独立计算，不混淆（地址线 ≠ log2(芯片单元数)，数据线 ≠ 芯片位宽）。
6. **陷阱检测**：若学生将字扩展倍数与位扩展倍数**相加**（8+4=12）而非相乘（8×4=32），会得到错误总芯片数 12，必须与本题正确答案 32 区分。
