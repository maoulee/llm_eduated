## 题目

某计算机系统采用海明码（偶校验）对 4 位信息位进行检错与纠错编码。现接收到一个 7 位海明码序列：

$$H_1\,H_2\,H_3\,H_4\,H_5\,H_6\,H_7 = 0\;1\;1\;0\;1\;1\;1$$

其中，$H_i$ 表示码字第 $i$ 位（位号从 1 开始）。已知该接收码中**恰好有 1 位发生了翻转**。

请回答以下问题：

---

### 第 1 问（2 分）

（1）确定该海明码所需的最少校验位数 $k$，写出确定依据。

（2）写出校验位所在的位置（位号），以及各信息位所占的位号，填入下表：

| 位号 $i$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 类型（校验位 $P$ / 信息位 $D$） | | | | | | | |

### 第 2 问（2 分）

（1）按照偶校验分组规则，分别计算三组校验的指误字 $S_1$、$S_2$、$S_4$ 的值。

（2）将 $S_4 S_2 S_1$ 拼接为指误字（伴随式），指出错误所在的位号，并给出纠错后的正确码字。

### 第 3 问（2 分）

从纠错后的正确码字中提取全部信息位，按 $D_1 D_2 D_3 D_4$ 的顺序写出原始 4 位信息，并给出其对应的十进制值。

---

## 参考答案

| 问题 | 答案 |
|:---|:---|
| 第1问（1）最少校验位数 | $k = 3$，依据 $2^3 = 8 \geq 4+3+1 = 8$（$k=2$ 时 $4 < 7$ 不满足） |
| 第1问（2）校验位/信息位位置 | 校验位 $P$：位号 1、2、4；信息位 $D$：位号 3、5、6、7 |
| 第2问（1）指误字 | $S_1 = 1$，$S_2 = 0$，$S_4 = 1$ |
| 第2问（2）伴随式定位纠错 | $S_4 S_2 S_1 = 101_2 = 5$，错误在位号 5（$H_5$），纠错后码字 `0110011` |
| 第3问信息位提取 | $D_1 D_2 D_3 D_4 = 1011$，十进制值 $= 11$ |

---

## 解析

### 第 1 问

#### （1）最少校验位数 $k$

由海明码不等式 $2^k \geq m + k + 1$，其中信息位数 $m = 4$：

- $k = 2$ 时：$2^2 = 4$，而 $m + k + 1 = 4 + 2 + 1 = 7$，$4 < 7$，不满足。
- $k = 3$ 时：$2^3 = 8$，而 $m + k + 1 = 4 + 3 + 1 = 8$，$8 \geq 8$，满足。

故最少校验位数 $k = 3$，总码长 $n = m + k = 7$。

#### （2）校验位与信息位分布

校验位位于位号为 $2^j$（$j=0,1,2$）的位置，即位号 1、2、4。

| 位号 $i$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 类型 | $P$ | $P$ | $D$ | $P$ | $D$ | $D$ | $D$ |

- 校验位位置：1、2、4
- 信息位位置：3、5、6、7

### 第 2 问

#### （1）计算三组指误字 $S_1$、$S_2$、$S_4$

各校验组覆盖位号的二进制表示中相应位为 1 的所有位置：

- **$S_1$**（位号二进制最低位为 1）：覆盖 {1, 3, 5, 7}，即 $H_1 \oplus H_3 \oplus H_5 \oplus H_7 = 0 \oplus 1 \oplus 1 \oplus 1 = 1$
- **$S_2$**（位号二进制次低位为 1）：覆盖 {2, 3, 6, 7}，即 $H_2 \oplus H_3 \oplus H_6 \oplus H_7 = 1 \oplus 1 \oplus 1 \oplus 1 = 0$
- **$S_4$**（位号二进制第 3 位为 1）：覆盖 {4, 5, 6, 7}，即 $H_4 \oplus H_5 \oplus H_6 \oplus H_7 = 0 \oplus 1 \oplus 1 \oplus 1 = 1$

#### （2）伴随式定位与纠错

将 $S_4 S_2 S_1$ 拼接为伴随式：

$$S_4 S_2 S_1 = 101_2 = 5$$

伴随式指向位号 **5**，即 $H_5$ 发生了翻转。

纠错：将 $H_5$ 翻转，$1 \rightarrow 0$。

纠错后码字：

$$H_1 \sim H_7 = 0\;1\;1\;0\;0\;1\;1$$

即 **0110011**。

验证：接收码 XOR 纠错后码字 $= 0110111 \oplus 0110011 = 0000100$，恰好第 5 位为 1，其余为 0，自洽。纠错后重新计算 $S_1 = S_2 = S_4 = 0$，确认无错。

### 第 3 问

从纠错后的正确码字 `0110011` 中提取信息位位置（位号 3、5、6、7）的值：

| 信息位 | $D_1$ | $D_2$ | $D_3$ | $D_4$ |
|:---:|:---:|:---:|:---:|:---:|
| 对应位号 | 3 | 5 | 6 | 7 |
| 值 | 1 | 0 | 1 | 1 |

$$D_1 D_2 D_3 D_4 = 1011$$

对应的十进制值为：

$$1011_2 = 8 + 2 + 1 = 11_{10}$$
