# 海明码纠错定位

## 题干

某计算机系统采用海明码（偶校验）对 4 位信息位进行检错与纠错编码。现接收到一个 7 位海明码序列：

$$H_1\,H_2\,H_3\,H_4\,H_5\,H_6\,H_7 = 0\;1\;1\;0\;1\;1\;1$$

其中，$H_i$ 表示码字第 $i$ 位（位号从 1 开始）。已知该接收码中**恰好有 1 位发生了翻转**。

请回答以下问题：

---

### 第 1 问（2 分）

（1）确定该海明码所需的最少校验位数 $k$，写出确定依据。

（2）写出校验位所在的位置（位号），以及各信息位所占的位号，填入下表：

| 位号 $i$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 类型（校验位 $P$ / 信息位 $D$） | | | | | | | |

### 第 2 问（2 分）

（1）按照偶校验分组规则，分别计算三组校验的指误字 $S_1$、$S_2$、$S_4$ 的值。

（2）将 $S_4 S_2 S_1$ 拼接为指误字（伴随式），指出错误所在的位号，并给出纠错后的正确码字。

### 第 3 问（2 分）

从纠错后的正确码字中提取全部信息位，按 $D_1 D_2 D_3 D_4$ 的顺序写出原始 4 位信息，并给出其对应的十进制值。

---

## 条件清单

| 编号 | 条件 | 说明 |
|:---:|------|------|
| 1 | 信息位数 $m = 4$ | 4 位信息位待编码 |
| 2 | 校验方式：偶校验 | 各校验组采用偶校验（异或结果为 0 时无错） |
| 3 | 接收码 $= 0110111$（7 位，位号 1\~7） | 含恰好 1 位翻转 |

## 参数说明

| 参数 | 值 | 说明 |
|:---:|:---:|------|
| 信息位数 $m$ | 4 | 取值范围 4\~8，选 4 使码长适中 |
| 校验位数 $k$ | 3 | 由 $2^k \geq m + k + 1$ 确定（$2^3 = 8 \geq 4+3+1 = 8$） |
| 总码长 $n$ | 7 | $n = m + k = 7$ |
| 校验方式 | 偶校验 | — |
| 错误位数 | 1 位 | 恰好 1 位翻转 |
| 接收码 | $0110111$ | 位号 1\~7 从左至右 |

## 通过条件（成功判据·可机检）

本题成立需满足以下全部特征（由 gen.py exec + assert 验证）：

1. **校验位数正确**：$k = 3$，满足 $2^k \geq m + k + 1$（$8 \geq 8$），且 $k=2$ 不满足（$4 < 7$）。
2. **指误字非零且指向信息位**：伴随式 $S_4 S_2 S_1 \neq 000$，且所指位号 $\in \{3, 5, 6, 7\}$（信息位位置），非校验位位置 $\{1, 2, 4\}$，也非 $0$。
3. **纠错后码字合法**：纠错后的码字满足全部偶校验等式（重新计算 $S_1 = S_2 = S_4 = 0$）。
4. **纠错自洽**：接收码 XOR 纠错后码字 = 仅 1 位为 1（恰翻转 1 位）。
5. **信息位提取正确**：提取的信息位恰好 4 位，对应纠错后码字中信息位位置的值。

> 以上条件确保：考点（校验位定位 → 分组计算 → 伴随式定位 → 纠错 → 提取信息）被参数真正触发，且错误落在信息位以增加第 3 问的考查意义。
