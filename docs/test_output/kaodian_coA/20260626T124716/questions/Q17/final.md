# 存储器与CPU连接：地址分配与片选逻辑推导

## 题目

某计算机的 CPU 具有 **16 位地址总线（A15～A0，A0 为最低位）** 和 **8 位数据总线（D7～D0）**，控制信号包括读信号 $\overline{\text{RD}}$、写信号 $\overline{\text{WR}}$、访存请求 $\overline{\text{MREQ}}$（低电平有效时表示 CPU 需要访问存储器）。

现需为该 CPU 设计存储系统，使用 **74LS138 译码器**（3线-8线译码器，输入 C/B/A，输出 $\overline{Y0}$～$\overline{Y7}$ 低电平有效；使能端 G1 高电平有效，$\overline{G2A}$、$\overline{G2B}$ 低电平有效）进行片选。地址空间分配如下：

| 区域 | 类型 | 容量 | 起始地址 |
|------|------|------|----------|
| 区域① | ROM | **4 KB** | **0000H** |
| 区域② | RAM | **8 KB** | **4000H** |

可用芯片规格：

- **ROM 芯片**：2K × 8 bit
- **RAM 芯片**：8K × 4 bit

**约束条件：**

1. 各区域起始地址须为该区域容量的整数倍（地址对齐）。
2. 各区域之间不重叠，总容量不超过 CPU 的可寻址空间。
3. 数据总线宽度与芯片数据宽度不一致时必须进行位扩展。
4. 片选信号由 74LS138 译码器产生，高位地址线接入译码器输入端。

---

### 第（1）题（4分）

分别推导区域①（ROM，4 KB）和区域②（RAM，8 KB）的地址范围（用十六进制表示），写出每区域的**起始地址**和**结束地址**。

---

### 第（2）题（4分）

分别计算区域①（ROM）和区域②（RAM）所需的芯片数量，说明各区域采用的扩展方式（字扩展、位扩展或字位同时扩展），并简述理由。

---

### 第（3）题（4分）

将 74LS138 译码器的输入端 C、B、A 分别连接到 CPU 的高位地址线，推导并写出：

1. 译码器输入端 C、B、A 分别连接哪些地址线（说明选择依据）。
2. 使能端 G1、$\overline{G2A}$、$\overline{G2B}$ 应如何连接（接哪些信号或电平），使译码器仅在 CPU 访存时工作。
3. 区域①和区域②分别连接到译码器的哪个输出端。
4. 若区域①需要进一步用地址线区分其内部芯片，说明还需额外使用哪根地址线进行区分。

---

## 参考答案

| 题号 | 答案 |
|------|------|
| 第（1）题 | ROM 区：0000H ～ 0FFFH；RAM 区：4000H ～ 5FFFH |
| 第（2）题 | ROM 区：2 片，字扩展；RAM 区：2 片，位扩展 |
| 第（3）题 | C=A15，B=A14，A=A13；G1=Vcc，$\overline{G2A}$=$\overline{\text{MREQ}}$，$\overline{G2B}$=GND；ROM→$\overline{Y0}$，RAM→$\overline{Y2}$；ROM 内部用 A12（区分 4KB vs 非使用区）+ A11（区分两片 2K×8 芯片） |

## 解析

### 基本参数

| 参数 | 值 |
|------|-----|
| CPU 地址总线 | 16 位（A15～A0） |
| CPU 数据总线 | 8 位（D7～D0） |
| ROM 区 | 起始 0000H，容量 4 KB |
| RAM 区 | 起始 4000H，容量 8 KB |
| ROM 芯片 | 2K × 8 bit |
| RAM 芯片 | 8K × 4 bit |

可寻址空间 = 2^16 = 64 KB。

---

### 第（1）题：各存储区域地址范围推导

**结束地址 = 起始地址 + 容量 − 1。**

**区域①（ROM，4 KB，起始 0000H）**

- 容量 = 4 KB = 4096 B = 0FFFH（容量减1后的偏移）
- 结束地址 = 0000H + 0FFFH = **0FFFH**
- **地址范围：0000H ～ 0FFFH**

**区域②（RAM，8 KB，起始 4000H）**

- 容量 = 8 KB = 8192 B = 1FFFH（容量减1后的偏移）
- 结束地址 = 4000H + 1FFFH = **5FFFH**
- **地址范围：4000H ～ 5FFFH**

**验证：**

- ROM 结束地址（0FFFH）< RAM 起始地址（4000H），两区域不重叠。
- 0000H 是 4 KB 的整数倍，4000H 是 8 KB 的整数倍，地址对齐。
- 总容量 4 KB + 8 KB = 12 KB ≤ 64 KB（可寻址空间）。

---

### 第（2）题：芯片数量与扩展方式

**区域①（ROM，4 KB，2K × 8 bit 芯片）**

- 区域字数 = 4 KB = 4K 字（8位数据，1字=1字节），芯片字数 = 2K
- 字扩展因子 = 4K / 2K = **2**（两片地址连续）
- 位扩展因子 = 8 / 8 = **1**（芯片数据位宽 = 总线宽度，无需位扩展）
- **总片数 = 2 片，采用字扩展**

理由：ROM 芯片为 2K × 8 bit，数据位宽（8 bit）与数据总线（8 bit）一致，不需要位扩展；但芯片字数（2K）小于区域容量（4K），需要 2 片进行字扩展，两片地址连续排列。

**区域②（RAM，8 KB，8K × 4 bit 芯片）**

- 区域字数 = 8 KB = 8K 字，芯片字数 = 8K
- 字扩展因子 = 8K / 8K = **1**（芯片字数 = 区域字数，无需字扩展）
- 位扩展因子 = 8 / 4 = **2**（芯片数据位宽 4 bit < 总线宽度 8 bit，需要位扩展）
- **总片数 = 2 片，采用位扩展**

理由：RAM 芯片为 8K × 4 bit，字数（8K）与区域容量（8K）一致，不需要字扩展；但芯片数据位宽（4 bit）仅为数据总线（8 bit）的一半，需要 2 片进行位扩展，两片数据线拼接为 8 位。

---

### 第（3）题：74LS138 译码器片选逻辑

#### 1. 译码器输入端 C、B、A 的连接

**选择依据**：最大区域为 8 KB = 2^13，因此片内寻址需要 13 根地址线（A0～A12）。剩余的 3 根高位地址线 A15、A14、A13 接入 74LS138 译码器的输入端。

| 译码器输入 | 连接地址线 |
|-----------|-----------|
| C | **A15** |
| B | **A14** |
| A | **A13** |

片内寻址线：A0 ～ A12（共 13 根）。

#### 2. 使能端连接

74LS138 使能条件：G1 高电平有效，$\overline{G2A}$、$\overline{G2B}$ 低电平有效。要求译码器仅在 CPU 访存时工作。

| 使能端 | 连接方式 | 说明 |
|--------|---------|------|
| G1 | **Vcc（高电平）** | G1 高电平有效，始终使能 |
| $\overline{G2A}$ | **$\overline{\text{MREQ}}$** | CPU 访存时 $\overline{\text{MREQ}}$ 为低电平，使译码器工作；非访存时为高电平，译码器不工作 |
| $\overline{G2B}$ | **GND（低电平）** | $\overline{G2B}$ 低电平有效，始终使能 |

效果：仅当 $\overline{\text{MREQ}}$ 为低电平（CPU 访存）时，G1 = 1、$\overline{G2A}$ = 0、$\overline{G2B}$ = 0 同时满足，译码器工作。

#### 3. 区域①和区域②连接的输出端

译码器输出端由 CBA = A15 A14 A13 的值决定：

| 区域 | 起始地址 | A15 A14 A13 | CBA 值 | 输出端 |
|------|---------|-------------|--------|--------|
| 区域① ROM（0000H～0FFFH） | 0000H | 0 0 0 | **000** | $\overline{Y0}$ |
| 区域② RAM（4000H～5FFFH） | 4000H | 0 1 0 | **010** | $\overline{Y2}$ |

- **ROM 区 → $\overline{Y0}$**
- **RAM 区 → $\overline{Y2}$**

#### 4. ROM 区内部芯片的额外地址区分

74LS138 的 $\overline{Y0}$ 覆盖整个 8 KB 空间（0000H～1FFFH，对应 CBA = 000），但 ROM 区只有 4 KB（0000H～0FFFH）。因此需要额外使用地址线区分：

| 地址线 | 作用 | 说明 |
|--------|------|------|
| **A12** | 区分 ROM 区与非使用区 | A12 = 0 → ROM 区（0000H～0FFFH）；A12 = 1 → 非使用区（1000H～1FFFH） |
| **A11** | 区分 ROM 内部两片 2K×8 芯片 | A11 = 0 → 第 1 片（0000H～07FFH）；A11 = 1 → 第 2 片（0800H～0FFFH） |
