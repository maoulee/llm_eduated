# 存储器与CPU连接：地址分配与片选逻辑推导

## 题目

某计算机的 CPU 具有 **16 位地址总线（A15～A0，A0 为最低位）** 和 **8 位数据总线（D7～D0）**，控制信号包括读信号 $\overline{\text{RD}}$、写信号 $\overline{\text{WR}}$、访存请求 $\overline{\text{MREQ}}$（低电平有效时表示 CPU 需要访问存储器）。

现需为该 CPU 设计存储系统，使用 **74LS138 译码器**（3线-8线译码器，输入 C/B/A，输出 $\overline{Y0}$～$\overline{Y7}$ 低电平有效；使能端 G1 高电平有效，$\overline{G2A}$、$\overline{G2B}$ 低电平有效）进行片选。地址空间分配如下：

| 区域 | 类型 | 容量 | 起始地址 |
|------|------|------|----------|
| 区域① | ROM | **4 KB** | **0000H** |
| 区域② | RAM | **8 KB** | **4000H** |

可用芯片规格：

- **ROM 芯片**：2K × 8 bit
- **RAM 芯片**：8K × 4 bit

**约束条件：**

1. 各区域起始地址须为该区域容量的整数倍（地址对齐）。
2. 各区域之间不重叠，总容量不超过 CPU 的可寻址空间。
3. 数据总线宽度与芯片数据宽度不一致时必须进行位扩展。
4. 片选信号由 74LS138 译码器产生，高位地址线接入译码器输入端。

---

### 第（1）题（4分）

分别推导区域①（ROM，4 KB）和区域②（RAM，8 KB）的地址范围（用十六进制表示），写出每区域的**起始地址**和**结束地址**。

---

### 第（2）题（4分）

分别计算区域①（ROM）和区域②（RAM）所需的芯片数量，说明各区域采用的扩展方式（字扩展、位扩展或字位同时扩展），并简述理由。

---

### 第（3）题（4分）

将 74LS138 译码器的输入端 C、B、A 分别连接到 CPU 的高位地址线，推导并写出：

1. 译码器输入端 C、B、A 分别连接哪些地址线（说明选择依据）。
2. 使能端 G1、$\overline{G2A}$、$\overline{G2B}$ 应如何连接（接哪些信号或电平），使译码器仅在 CPU 访存时工作。
3. 区域①和区域②分别连接到译码器的哪个输出端。
4. 若区域①需要进一步用地址线区分其内部芯片，说明还需额外使用哪根地址线进行区分。

---

## 通过条件（成功判据）

本题成立需要满足以下**可机检特征**：

1. **地址范围正确且对齐**：ROM 区地址范围为 0000H～0FFFH（结束地址 = 起始地址 + 容量 − 1）；RAM 区地址范围为 4000H～5FFFH；两区域不重叠。

2. **芯片数量正确且扩展方式正确**：
   - ROM 区：2K×8 芯片组成 4KB 区域 → 需要 **2 片**，采用**字扩展**（两片地址连续）。
   - RAM 区：8K×4 芯片组成 8KB 区域、8 位数据总线 → 需要 **2 片**，采用**位扩展**（两片数据线拼接为 8 位）。

3. **译码器连接可验证**：
   - 74LS138 的 C/B/A 输入端连接 A15/A14/A13（3 根高位地址线，因为最大区域为 8KB = 2¹³，A0～A12 用于片内寻址）。
   - ROM 区（0000H～0FFFH）对应 CBA = 000，连接译码器输出 $\overline{Y0}$；RAM 区（4000H～5FFFH）对应 CBA = 010，连接译码器输出 $\overline{Y2}$。
   - 使能端：G1 接高电平（或 Vcc），$\overline{G2A}$ 或 $\overline{G2B}$ 接 $\overline{\text{MREQ}}$，其余使能端接有效电平。

4. **ROM 内部额外地址区分**：ROM 区为 4KB 但 74LS138 的 $\overline{Y0}$ 覆盖 8KB（0000H～1FFFH），因此需额外使用 **A12** 区分 ROM 区（A12=0）与非使用区（A12=1）；ROM 内部两片 2K×8 芯片还需用 **A11** 进行字扩展区分。

5. **一致性检查**：地址总线宽度 16 位 → 最大可寻址空间 64KB ≥ 4KB + 8KB = 12KB；各芯片容量 ≤ 对应区域容量；各区域起始地址为容量的整数倍（0000H 是 4KB 的倍数，4000H 是 8KB 的倍数）。
