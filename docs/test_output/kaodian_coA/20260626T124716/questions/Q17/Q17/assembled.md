## 出题契约

### 基本信息
- target_subject: 组成原理
- target_family: CO-3 存储系统 > 主存储器和CPU的连接 > 存储芯片地址分配与片选
- primary_target_name: 存储器与CPU连接（地址分配与片选逻辑推导）
- question_type: comprehensive
- examination_mode: 推演型——存储器地址分配与片选逻辑

### 难度目标
- k_target: K1=3,K2=3,K3=4,K4=3,K5=1
- difficulty_level: 3
- difficulty_rationale: 需完成地址范围推导、芯片选型与数量计算、译码器片选逻辑推导的多步综合推演，K3（机制推演）为主导难度

### 结构要求
- sub_question_count: 3
- sub_questions:
  - Q1: 推导各存储区域地址范围（十六进制），4分，计算+分析
  - Q2: 计算各区域所需芯片数量及扩展方式，4分，计算
  - Q3: 用74LS138译码器推导片选逻辑表达式，4分，分析+推导
- dependency: 串行（Q1→Q2→Q3）
- condition_count: 4-5
- form: 纯文字推导，不要求画图

### 参数约束
- CPU地址总线宽度: 16-20位，推荐16位
- CPU数据总线宽度: 8或16位
- 地址空间分配:
  - ROM区: ≥1个区域，起始地址从低地址开始，大小为2的整数次幂KB
  - RAM区: ≥1个区域，大小为2的整数次幂KB
  - 各区域起始地址须为区域大小的整数倍（地址对齐）
  - 区域不重叠，总和不超地址空间
- ROM芯片规格: 1K×8 ~ 8K×8 bit
- RAM芯片规格: 1K×4 ~ 8K×8 bit（数据宽度可为4位以产生位扩展需求）
- 一致性约束:
  - 各芯片容量 ≤ 对应区域容量
  - 数据总线宽度与芯片数据宽度不一致时必须位扩展
  - 译码器高位地址线数 ≥ 3（74LS138为3线-8线译码器）
- distractor_strategy: N/A（主观题，无选项）
- free_doF: Question Agent可自由选择具体地址总线宽度、各区域大小（2的幂）、芯片具体规格，满足一致性约束即可

### 参考经验摘要
- 历史模式: 无历史数据；按知识点经典考察模式"地址空间分配→地址范围→芯片数量→片选逻辑"四步推演规划
- 难度锚点: K3=4（多步推演>5步）为主导；K4=3（地址对齐、ROM/RAM片选差异、译码器使能端连接等常规陷阱）
- 典型陷阱:
  1. 地址范围计算时ROM区与RAM区边界对齐
  2. 位扩展时芯片数量翻倍易漏算
  3. 74LS138使能端（G1/G2A/G2B）连接方式易遗漏
  4. 高位地址线参与译码的位数判断
