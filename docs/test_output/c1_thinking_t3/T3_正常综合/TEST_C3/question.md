# Q41 平衡二叉树 AVL 插入与旋转

## 题干

已知一棵平衡二叉排序树（AVL 树）的层序遍历序列为 `30, 10, 50, 20`，即树结构如下：

```
        30
       /  \
     10    50
       \
       20
```

向该 AVL 树中插入关键字 `15`，插入完成后执行必要的旋转操作以维持 AVL 性质。

## 设问

插入并旋转完成后，关键字为 `10` 的结点的平衡因子（左子树高度 − 右子树高度）为多少？

> 注：选项由 P2 基于 solve 的解设置，此处不列出 A/B/C/D。

---

## 设计说明

- **复用骨架来源**：AVL 树插入旋转经典骨架（初始合法 AVL 树 + 待插入关键字 → 询问插入后树属性）
- **考察形式**：选择题，结构操作与状态维护模拟
- **设问结构**：单问，询问插入并旋转后特定结点（关键字 10）的平衡因子
- **经验值参数来源**：
  - 初始 AVL 树 4 个结点（来自经验值表 AVL 题友好范围 3-5 结点）
  - 待插入关键字 `15`（经验值：选择能触发 LR 型双旋转的关键字，确保 K4 陷阱辨析）
  - 初始树结构 `[30, 10, 50, 20]` 为合法 AVL 树（各结点 BF ∈ {-1, 0, 1}）
- **与目标 K-雷达的对齐**：
  - K3=4：需走完"插入定位→逐层更新 BF→定位失衡结点→判断 LR 型→先右旋子结点再左旋失衡结点→重算 BF→验证 AVL 性质"共 >5 步串行流程
  - K4=4：需识别 LR 型双旋转的隐含前提（先对子结点右旋，再对失衡结点左旋），以及旋转后需重新计算所有受影响结点的平衡因子
  - K1=3：需准确记忆平衡因子定义（左子树高度−右子树高度）和四种旋转触发条件
  - K2=2：平衡因子计算为简单加减，但需多步执行
  - K5=1：全程在 AVL 树单一结构内部完成
- **是否融合**：否。单骨架已满足 K3-K4 平衡型难度要求，不额外融合。
- **干扰项设计方向**（供 P2 参考）：
  - distractor_1：未执行旋转（仅 BST 插入），结点 10 的 BF 计算错误
  - distractor_2：旋转类型判断错误（将 LR 误判为 LL 或 RR），导致树结构错误
  - distractor_3：平衡因子计算符号错误或遗漏更新
- **P1 修正备注**：根据终审反馈，插入关键字由 `5` 改为 `15`，确保插入后触发 LR 型双旋转（结点 10 的 BF 变为 -2，失衡），满足 K3-K4 难度要求。
