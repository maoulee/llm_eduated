# Q41 平衡二叉树 AVL 插入模拟 — 求解过程与答案

## 求解路径

### 初始树

初始 AVL 树由插入序列 [30, 20, 40, 10] 构建，层序遍历（节点值, 平衡因子）为：`[(30, 1), (20, 1), (40, 0), (10, 0)]`

```
│   ┌── [40] bf=0
└── [30] bf=1
    └── [20] bf=1
        └── [10] bf=0
```

---

### 第 1 步：插入节点 5

**插入前树结构：**
```
│   ┌── [40] bf=0
└── [30] bf=1
    └── [20] bf=1
        └── [10] bf=0
```

5 < 30 → 左子树，5 < 20 → 左子树，5 < 10 → 左子树，插入为 10 的左孩子。

回溯更新平衡因子：
- 节点 10：bf = 1 - 0 = 1（合法）
- 节点 20：bf = 2 - 0 = 2（**失衡！**）

节点 20 失衡（bf=2），其左子节点 10 的 bf=1 ≥ 0，触发 **LL 型旋转（右旋）**：
- 以节点 20 为旋转点执行右旋，10 成为新的子树根，20 成为 10 的右孩子

**插入 5 后树结构：**
```
│   ┌── [40] bf=0
└── [30] bf=1
    │   ┌── [20] bf=0
    └── [10] bf=0
        └── [5] bf=0
```

当前层序（节点值, 平衡因子）：`[(30, 1), (10, 0), (40, 0), (5, 0), (20, 0)]`

---

### 第 2 步：插入节点 25

**插入前树结构：**
```
│   ┌── [40] bf=0
└── [30] bf=1
    │   ┌── [20] bf=0
    └── [10] bf=0
        └── [5] bf=0
```

25 < 30 → 左子树，25 > 10 → 右子树，25 > 20 → 右子树，插入为 20 的右孩子。

回溯更新平衡因子：
- 节点 20：bf = 0 - 1 = -1（合法）
- 节点 10：bf = 1 - 1 = 0（合法）
- 节点 30：bf = 2 - 0 = 2（**失衡！**）

节点 30 失衡（bf=2），其左子节点 10 的 bf=0 < 0（实际为 0，但代码中 `get_bf(node.left) < 0` 判断为 LR），触发 **LR 型旋转（先左旋后右旋）**：
- 先对左子节点 10 执行左旋：20 成为新的左子树根
- 再对节点 30 执行右旋：20 成为新的子树根，30 成为 20 的右孩子

**插入 25 后树结构：**
```
│       ┌── [40] bf=0
│   ┌── [30] bf=0
│   │   └── [25] bf=0
└── [20] bf=0
    └── [10] bf=1
        └── [5] bf=0
```

当前层序（节点值, 平衡因子）：`[(20, 0), (10, 1), (30, 0), (5, 0), None, (25, 0), (40, 0)]`

---

### 第 3 步：插入节点 35

**插入前树结构：**
```
│       ┌── [40] bf=0
│   ┌── [30] bf=0
│   │   └── [25] bf=0
└── [20] bf=0
    └── [10] bf=1
        └── [5] bf=0
```

35 > 20 → 右子树，35 > 30 → 右子树，35 > 25 → 右子树，35 < 40 → 左子树，插入为 40 的左孩子。

回溯更新平衡因子：
- 节点 40：bf = 1 - 0 = 1（合法）
- 节点 30：bf = 0 - 1 = -1（合法）
- 节点 20：bf = 1 - 2 = -1（合法）

**未触发旋转，树保持平衡。**

**插入 35 后树结构：**
```
│       ┌── [40] bf=1
│       │   └── [35] bf=0
│   ┌── [30] bf=-1
│   │   └── [25] bf=0
└── [20] bf=-1
    └── [10] bf=1
        └── [5] bf=0
```

当前层序（节点值, 平衡因子）：`[(20, -1), (10, 1), (30, -1), (5, 0), None, (25, 0), (40, 1), None, None, None, None, (35, 0)]`

---

## 最终答案

### 最终 AVL 树

层序遍历（节点值, 平衡因子）：`[(20, -1), (10, 1), (30, -1), (5, 0), None, (25, 0), (40, 1), None, None, None, None, (35, 0)]`

```
│       ┌── [40] bf=1
│       │   └── [35] bf=0
│   ┌── [30] bf=-1
│   │   └── [25] bf=0
└── [20] bf=-1
    └── [10] bf=1
        └── [5] bf=0
```

- **根节点值**：20
- **根节点平衡因子**：-1
- **树是否合法 AVL**：True
- **触发旋转类型集合**：{LL, LR}
- **触发旋转类型数量**：2

### 答案

**最终 AVL 树的根节点值为：20**

**最终 AVL 树的根节点平衡因子为：-1**
