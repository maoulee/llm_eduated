## examination_form
- 考察形式：多步串行推演 + 陷阱辨析（K3 为主，K4 为辅）
- 设问方向：给定初始 AVL 树与插入序列，要求模拟完整插入流程（多步串行推演），并在每一步精准判断旋转类型与回溯检查（陷阱辨析）

## k_radar
- K1（基础认知）: 3
- K2（单步代入）: 2
- K3（机制推演）: 4
- K4（条件路由）: 4
- K5（跨域联动）: 1
- 形状主导维度：K3 与 K4 并主导（平衡型）

## rationale
- 为何选此形式：AVL 树插入模拟天然要求多步串行推演（插入→回溯→判断失衡→旋转→再回溯，>5 步流程，K3=4），同时每一步旋转类型的判断依赖精准辨析隐含前提（如"双旋转需先旋子节点再旋父节点""旋转后需回溯检查祖先节点"，K4=4），两者缺一不可，故采用"多步串行推演 + 陷阱辨析"混合形式。
- 与目标 K-雷达的对齐说明：K3-K4 平衡型要求推演深度与条件路由难度相当，本题 K3=4（>5 步动态状态维护）与 K4=4（隐含前提深，需机制本质理解）对等；K1=3（需准确记忆平衡因子定义与四种旋转触发条件）为入题门槛；K2=2（平衡因子为简单减法，非计算瓶颈）；K5=1（单一 AVL 树知识点内部解决），整体雷达形状与目标 K3-K4 平衡型完全一致。
