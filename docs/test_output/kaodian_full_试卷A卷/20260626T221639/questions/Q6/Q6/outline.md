## 考点
- **核心知识点**：补码加减运算与溢出判断
  - 考察侧重点：定点小数的变形补码（双符号位补码）表示与加法运算
  - 考察侧重点：双符号位的溢出判断（正溢出 / 负溢出）
- **辅助知识点**：定点小数的原码→补码转换
  - 考察侧重点：负数补码的求法（按位取反末位加1）

## 难度目标
| 维度 | 目标等级 | 达标理由 |
|------|---------|---------|
| K1 基础认知 | 2 | 需记忆变形补码定义、溢出判断规则，但概念本身基础，题干已点明方法 |
| K2 单步代入 | 3 | 需执行原码→补码转换、逐位加法，涉及非2幂次的手工运算 |
| K3 机制推演 | 3 | 需按"求补码→双符号位加法→判溢出"3-5步固定流程串行推演，路径唯一 |
| K4 条件路由 | 2 | 溢出判断有明确规则，不存在深层暗坑，但需注意双符号位的正确使用 |
| K5 跨域联动 | 1 | 纯单知识点内部运算，不涉及其他子系统 |

## 考察模式
**计算型——补码运算与溢出判断**
- 模式说明：给定两个定点小数（十进制或二进制原码形式），要求用变形补码完成加法运算，并根据双符号位判断是否溢出及溢出类型。
- 选择理由：与 slot 数据的 examination_mode 一致，属于该题位的经典考法，能同时测出补码转换、加法运算、溢出判断三个层次的能力。

## 出题要求
- **题型**：计算题（综合题形式，含多个子问）
- **总分**：10分
- **总条件数**：2-3个显式条件（给出x和y的值，指明字长或定点小数位数）
- **条件设计原则**：
  - 给出两个定点小数 x 和 y，其中至少一个为负数（考察补码转换能力）
  - x+y的结果应使"溢出"与"不溢出"有明确区分度——即参数应使得双符号位出现"01"或"10"（产生溢出），或"00"/"11"（不溢出），具体由 Question Agent 决定
  - 建议给出十进制小数形式，要求学生自行转为二进制，增加计算步骤
  - 字长建议为 n+2 位（n位数值位 + 2位符号位），n取4或5
- **参数取值范围要求**：
  - x 和 y 的绝对值在 (0.5, 1.0) 区间内，使得两数之和容易超出可表示范围产生溢出
  - 或一正一负，使得结果不溢出但需要正确处理符号位
  - 二进制小数位数为4-6位

## 子问题规划
| 子问题 | 类型 | 考察目标 | 分值 | 与前后问关系 |
|--------|------|---------|------|-------------|
| 第1问 | 计算 | 将x和y分别转换为变形补码（双符号位补码） | 3分 | 独立，后续问的前提 |
| 第2问 | 计算 | 用变形补码完成 x+y 的加法运算，写出运算过程 | 4分 | 依赖第1问结果 |
| 第3问 | 分析 | 根据双符号位判断是否溢出，若溢出说明是正溢出还是负溢出 | 3分 | 依赖第2问结果，串行 |

## 参数约束
- **x值约束**：定点小数，绝对值在 [0.5, 0.99] 范围内，可为正或负
- **y值约束**：定点小数，绝对值在 [0.5, 0.99] 范围内，可为正或负
- **x与y的一致性约束**：
  - 若考察溢出：x与y同号且绝对值之和 > 1（超出n位小数可表示范围）
  - 若考察不溢出：x与y异号，或同号但绝对值之和 ≤ 可表示最大值
  - Question Agent 至少选择一种有明确区分度的情形
- **字长约束**：数值位 n = 4 或 5，总位数 = n + 2（含双符号位）
- **精度约束**：x和y的二进制表示在n位内精确（不产生截断误差）
- **可调自由度**：Question Agent 可自由选择 x、y 的具体数值、正负组合、是否产生溢出、n的具体取值

## 参考经验
- 该题位锚定原卷计算Q2：补码加减与溢出判断，为经典计算题型
- 考察模式固定：求补码 → 双符号位加法 → 判溢出，三步流程
- 难度锚点：K3=3 为主导，整体难度3（标准计算题）
- 典型陷阱：学生可能忽略双符号位直接用单符号位运算导致溢出判断错误；负数补码转换时忘记末位加1
