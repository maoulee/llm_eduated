# 数据通路与指令执行微操作序列 — 解答

## 指令语义

`SUB R1, R2`：执行 **R1 ← R1 − R2**。

ALU 结构：输入 A 来自锁存器 Y，输入 B 来自总线 Bus，运算结果送入锁存器 Z，支持 ADD（A+B）和 SUB（A−B）。因此被减数 R1 必须先存入 Y，减数 R2 经总线送入 ALU 输入 B。

---

## 子问题1（4分）：取指阶段微操作序列

| 节拍 | 功能描述 | 有效控制信号 |
|:----:|----------|:------------:|
| T1 | PC 内容送入 MAR | PCout, MARin |
| T2 | 存储器读：M[MAR] 的内容读入 MDR | Read |
| T3 | MDR 内容送入 IR | MDRout, IRin |
| T4 | PC 自增（内部逻辑，不占用总线） | PC+1 |

**取指阶段分析**：

- **T1**：PC 内容经总线送入 MAR，为存储器访问提供地址。PCout 驱动总线，MARin 接收写入 MAR。
- **T2**：Read 信号有效，存储器将 M[MAR] 的内容读入 MDR。此节拍无总线驱动操作（存储器自动写入 MDR）。
- **T3**：MDR 内容经总线送入 IR，完成取指令。MDRout 驱动总线，IRin 接收写入 IR。
- **T4**：PC+1 信号使 PC 内容自增 1，指向下一条指令地址。该操作由 PC 内部自增逻辑完成，不占用总线。

取指阶段共 4 个节拍（T1~T4），完成了 PC→MAR、存储器读、MDR→IR、PC 自增四项操作。

## 子问题2（6分）：执行阶段微操作序列

| 节拍 | 功能描述 | 有效控制信号 |
|:----:|----------|:------------:|
| T5 | R1 内容送入 ALU 输入锁存器 Y（被减数） | R1out, Yin |
| T6 | R2 内容送总线（ALU 输入B），执行减法，结果存入 Z | R2out, SUB, Zin |
| T7 | Z 内容经总线送入 R1（写回结果） | Zout, R1in |

**执行阶段分析**：

- **T5**：R1 内容（被减数）经总线送入 ALU 输入锁存器 Y。R1out 驱动总线，Yin 接收写入 Y。此时 ALU 输入 A = R1。
- **T6**：R2 内容（减数）经总线送入 ALU 输入 B，SUB 信号使 ALU 执行 A−B = R1−R2，运算结果由 Zin 写入锁存器 Z。R2out 驱动总线（ALU 输入 B 直接来自总线），Zin 接收运算结果写入 Z。
- **T7**：Z 内容（运算结果 R1−R2）经总线送回 R1，完成写回。Zout 驱动总线，R1in 接收写入 R1。

执行阶段共 3 个节拍（T5~T7），完成了取操作数（R1→Y、R2→Bus）、ALU 减法运算（R1−R2→Z）、结果写回（Z→R1）。

---

## 通过条件验证

全部指令共 7 个节拍（T1~T7），连续编号，取指阶段 T1~T4 与执行阶段 T5~T7 衔接。

| 通过条件 | 验证结果 |
|:--------:|:--------:|
| **条件1 总线无冲突** | 每个节拍至多 1 个 "out" 信号：T1=PCout, T2=无, T3=MDRout, T4=无, T5=R1out, T6=R2out, T7=Zout ✓ |
| **条件2 控制信号一致性** | 使用的全部 13 个信号均来自 C1~C15 定义表，无未定义信号 ✓ |
| **条件3 取指完整性** | PC→MAR(T1) + Read(T2) + MDR→IR(T3) + PC+1(T4) 四项齐全 ✓ |
| **条件4 减法操作数顺序** | R1→Y(T5, 被减数送ALU输入A), R2→Bus(T6, 减数送ALU输入B), 运算 Y−Bus = R1−R2 ✓ |
| **条件5 写回正确性** | 结果存入 Z(T6, Zin) → Z→Bus→R1(T7, Zout+R1in), T7 > T6, 未跳过 Z 锁存器 ✓ |
| **条件6 节拍连续性** | T1~T7 连续编号，跨阶段衔接 T4→T5 无遗漏 ✓ |

使用的全部控制信号（13个）：PCout, MARin, Read, MDRout, IRin, PC+1, R1out, Yin, R2out, SUB, Zin, Zout, R1in。
