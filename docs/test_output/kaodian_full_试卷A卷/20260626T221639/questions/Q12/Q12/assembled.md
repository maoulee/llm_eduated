## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: CO-5 中央处理器 > 数据通路的功能和基本结构
- primary_target_name: 数据通路与指令执行微操作序列
- question_type: comprehensive
- examination_mode: 设计型——指令执行微操作与控制信号（文字+表格，不附图）

### 难度目标
- k_target: K1=2,K2=2,K3=4,K4=4,K5=3
- difficulty_level: 4
- difficulty_rationale: 设计题，需理解数据通路并逐步推导>5步微操作与控制信号，K3/K4并重；K4=4因减法指令存在隐含前提（ALU功能选择、操作数顺序、总线冲突规避）

### 结构要求
- sub_question_count: 2
- sub_question_details:
  - 子问题1（4分）：取指阶段微操作序列——写出各节拍功能描述和有效控制信号
  - 子问题2（6分）：执行阶段微操作序列——写出取操作数→ALU减法运算→写回各节拍功能描述和有效控制信号
- condition_count: 3-4
- output_format: 表格填写（节拍 | 功能 | 有效控制信号）
- no_diagram: 全部文字+表格，不附图，不要求画图

### 参数约束
- 总线结构: 单总线或双总线，由Question Agent自行决定并文字描述清楚
- 寄存器集合: 至少含PC/IR/MAR/MDR/通用寄存器/ALU，命名方案自主
- 减法指令寻址方式: 建议寄存器直接寻址（如SUB R1,R2），也可存储器寻址但需控制步数
- 节拍总数: 5-7步（取指2-3拍+执行3-4拍），与K3=4一致
- 控制信号数量: 8-14个，需覆盖总线驱动/寄存器读写/ALU功能/存储器读写
- ALU功能信号: 必含ADD和SUB两种
- 一致性约束: 控制信号定义表与数据通路文字描述一一对应；每个节拍有效信号必须全部来自定义表
- 可调自由度: 总线数量、寄存器命名、寻址方式、节拍划分方式

### 参考经验摘要
- 历史模式: 408真题数据通路微操作设计——给出数据通路+控制信号表→写指定指令微操作序列（本题将附图替换为文字描述）
- 难度锚点: K3=4,K4=4为主导维度，K1/K2低位，K5中等
- 典型陷阱:
  1. 减法操作数顺序（ALU端口A/B对应被减数/减数）
  2. 单总线结构总线冲突（同一节拍不能同时驱动同一总线）
  3. PC自增的节拍安排（单独节拍或与取指并行）
  4. 写回阶段目标寄存器控制信号正确性
