# 数据通路与指令执行微操作序列

## 题干

某计算机采用**单总线数据通路**结构。各部件均与唯一一条内部总线（Bus）相连，具体结构描述如下：

**（一）数据通路结构**

1. **内部总线（Bus）**：系统中仅有一条内部总线，所有寄存器共享该总线进行数据传输。同一时刻只有一个部件可以向总线输出数据。

2. **寄存器**：
   - **PC**：程序计数器，16位，存储下一条指令的地址。内部具有自增逻辑，施加 `PC+1` 信号后值加1，**不占用总线**。
   - **IR**：指令寄存器，存储当前正在执行的指令。
   - **MAR**：存储器地址寄存器，为存储器访问提供地址。
   - **MDR**：存储器数据寄存器，存储器读出的数据自动送入MDR，待写入存储器的数据先存入MDR。
   - **R0、R1、R2**：通用寄存器，各16位。
   - **Y**：ALU输入锁存器，存放ALU输入A。
   - **Z**：ALU输出锁存器，存放ALU运算结果。

3. **ALU**：
   - 输入A来自锁存器**Y**，输入B来自**总线Bus**。
   - 运算结果送入锁存器**Z**。
   - 支持 `ADD`（A+B）和 `SUB`（A−B）两种运算。

4. **存储器**：
   - 访问地址来自MAR，数据经MDR传输。
   - `Read` 信号有效时，存储器将M[MAR]的内容读入MDR。
   - `Write` 信号有效时，存储器将MDR的内容写入M[MAR]。

**（二）控制信号定义表**

| 编号 | 信号名 | 功能说明 |
|:----:|:------:|----------|
| C1 | PCout | PC内容送总线 |
| C2 | PC+1 | PC内容自增1（内部逻辑，不占用总线） |
| C3 | MARin | 总线内容写入MAR |
| C4 | Read | 存储器读：M[MAR]→MDR |
| C5 | Write | 存储器写：MDR→M[MAR] |
| C6 | MDRout | MDR内容送总线 |
| C7 | IRin | 总线内容写入IR |
| C8 | R1out | R1内容送总线 |
| C9 | R1in | 总线内容写入R1 |
| C10 | R2out | R2内容送总线 |
| C11 | Yin | 总线内容写入Y（ALU输入A） |
| C12 | Zin | ALU运算结果写入Z |
| C13 | Zout | Z内容送总线 |
| C14 | ADD | ALU执行加法：A+B |
| C15 | SUB | ALU执行减法：A−B（Y中的值减去总线上的值） |

**（三）待分析指令**

指令 `SUB R1, R2`，功能为 **R1 ← R1 − R2**，其中 R1 和 R2 均采用寄存器直接寻址。

## 子问题1（4分）

写出该计算机**取指阶段**各节拍的微操作序列。请按以下表格格式填写，按节拍顺序逐行列出，每个节拍占一行。

| 节拍 | 功能描述 | 有效控制信号 |
|:----:|----------|:------------:|

**要求**：
- 功能描述用文字说明该节拍完成的数据传输或操作。
- 有效控制信号填写**信号名**（如 PCout、Read），多个信号之间用逗号分隔。
- 所有信号必须来自控制信号定义表（C1～C15），不得使用表中未定义的信号。

## 子问题2（6分）

写出指令 `SUB R1, R2` **执行阶段**各节拍的微操作序列。请按以下表格格式填写，按节拍顺序逐行列出。

| 节拍 | 功能描述 | 有效控制信号 |
|:----:|----------|:------------:|

**要求**：
- 从取指结束后的第一个执行节拍开始编号。
- 执行阶段需要完成：取操作数（R1、R2）→ ALU减法运算 → 结果写回R1。
- 有效控制信号填写**信号名**，多个信号之间用逗号分隔；所有信号必须来自控制信号定义表（C1～C15）。

## 通过条件（本题成立需要满足的可机检特征）

以下条件是评分与审核依据，与具体节拍编号无关，换指令/换总线结构仍适用：

1. **总线无冲突约束**：单总线结构中，每个节拍的有效控制信号里，以"out"结尾的信号（即向总线输出数据的信号，包括 PCout、MDRout、R1out、R2out、Zout）**至多一个**。若某节拍出现两个或以上"out"信号，则存在总线冲突，该节拍不成立。

2. **控制信号一致性**：填写的所有控制信号必须**来自控制信号定义表 C1～C15**，不得出现表中未定义的信号名。

3. **取指完整性**：取指阶段必须完成以下四项操作（可在不同节拍中完成）：
   - PC 内容送入 MAR（PCout + MARin）
   - 启动存储器读（Read）
   - MDR 内容送入 IR（MDRout + IRin）
   - PC 自增（PC+1）
   缺少任何一项则取指阶段不完整。

4. **减法操作数顺序正确性**：SUB 运算为 A−B，其中 A 来自锁存器 Y，B 来自总线。因此：
   - **R1（被减数）**必须先送入 Y（R1out + Yin）
   - **R2（减数）**必须经总线送入 ALU 输入 B（R2out + SUB）
   - 若顺序颠倒（R2 送 Y、R1 经总线），则运算结果为 R2−R1，与指令语义不符。

5. **写回正确性**：ALU 运算结果必须先存入 Z（Zin），再经 Z 送总线写回 R1（Zout + R1in）。不可跳过 Z 锁存器直接写回。

6. **节拍连续性**：取指阶段与执行阶段的节拍应连续编号（如 T1、T2、…、T5），无遗漏节拍。
