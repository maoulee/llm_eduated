# 题：主存储器扩展与片选逻辑设计（文字推导）

## 题干

某计算机系统的 CPU 有 16 位地址总线（A15~A0）和 16 位数据总线（D15~D0），按字节编址。

主存总容量为 64KB，地址空间划分如下：

| 区域 | 地址范围 | 存储类型 |
|------|----------|----------|
| ROM 区 | 0000H ~ 3FFFH | ROM（16KB） |
| RAM 区 | 4000H ~ FFFFH | RAM（48KB） |

可用的存储芯片规格为：
- **ROM 芯片**：8K × 8 位
- **RAM 芯片**：16K × 8 位

请用**文字推导和逻辑表达式**完成以下各问（**不允许画任何图、框图或连线图**）：

---

### 第 1 问（3 分）

分别计算 ROM 区和 RAM 区所需的芯片数量，说明字扩展和位扩展各为多少倍。

### 第 2 问（2 分）

分别确定 ROM 芯片和 RAM 芯片的片内地址线根数，以及用于片选译码的高位地址线根数。指出 ROM 与 RAM 在地址线分组上的差异并说明原因。

### 第 3 问（3 分）

用逻辑变量（A15、A14、A13……）写出**每个芯片组**的片选信号逻辑表达式（低电平有效，记为 $\overline{\text{CS}}$），要求各芯片组与地址范围的对应关系清晰。

### 第 4 问（2 分）

写出每个芯片组的地址范围（十六进制起止地址），并验证所有芯片组地址连续且无重叠、总覆盖范围等于主存全部地址空间。

---

## 场景规则（本题成立需要满足的参数间约束）

> 以下约束与具体答案值无关，换参数仍须成立。供 gen.py exec 翻译为 assert 使用。

1. **容量守恒**：ROM 分区容量（字节数）+ RAM 分区容量（字节数）== 主存总容量（字节数）。
2. **按字节编址等价**：主存总容量（字节数）== 2^(地址总线宽度)。
3. **芯片数可整除**：ROM 分区容量必须能被 ROM 芯片容量（字节数 = 芯片字数 × 芯片位宽 ÷ 8）整除；RAM 分区容量必须能被 RAM 芯片容量（字节数 = 芯片字数 × 芯片位宽 ÷ 8）整除。
4. **位扩展可整除**：CPU 数据总线宽度必须能被 ROM 芯片位宽整除，也必须能被 RAM 芯片位宽整除（即位扩展倍数为整数）。
5. **位扩展不额外占地址线**：同一芯片组内通过位扩展并联的芯片共享同一条片选信号，不额外占用地址线。
6. **片选仅涉及高位地址**：片内地址线不参与片选译码，只有片内地址以上的高位地址线参与译码。
7. **地址连续不重叠**：各芯片组地址范围按地址从小到大排列，相邻芯片组前一组末地址 +1 == 后一组首地址；所有芯片组地址范围并集 == 主存全部地址空间 [0000H, FFFFH]，且两两交集为空。

---

## 设计说明

- **考点**：字位同时扩展、地址线分组、片选逻辑推导、地址范围验证。
- **难度锚点**：K3（多步串行推演，步数 >5）+ K4（ROM 与 RAM 芯片规格不同→片内地址线根数不同→片选逻辑不同，须分别推导）。
- **关键区分点**：ROM 芯片 8K（13 根片内地址线 A12~A0，高位 A15~A13）与 RAM 芯片 16K（14 根片内地址线 A13~A0，高位 A15~A14）的地址线分组差异。
- **K4 陷阱**：位扩展芯片共享片选信号；ROM/RAM 规格不同须分别计算；片选逻辑只涉及高位地址。
