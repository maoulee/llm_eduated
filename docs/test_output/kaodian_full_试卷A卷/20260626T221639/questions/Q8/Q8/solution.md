# 页式虚拟存储器地址转换 —— 求解

## 地址结构分析

- VA = 32 位，PA = 26 位，页大小 = 4 KB = 2^12 B，按字节编址
- 页内偏移位数 = log2(4096) = **12 位**（虚/实地址共享）
- 虚页号位数 = 32 − 12 = **20 位**
- 实页号位数 = 26 − 12 = **14 位**

| 位数 | **20 位** | **12 位** |

### （2）物理地址结构

| 字段 | 实页号（PFN） | 页内偏移 |
|:---:|:---:|:---:|
| 位数 | **14 位** | **12 位** |

### （3）不在内存中的虚拟地址

逐个拆分虚页号（VA >> 12），查页表装入位：

| 编号 | 虚拟地址 | 虚页号 (VA >> 12) | 装入位 | 是否在内存 |
|:---:|:---:|:---:|:---:|:---:|
| ① | 0x000035A8 | 0x3 | 1 | 在内存 |
| ② | 0x000041F0 | 0x4 | 1 | 在内存 |
| ③ | 0x000067C4 | 0x6 | 1 | 在内存 |
| ④ | 0x00002B3E | **0x2** | **0** | **不在内存** |
| ⑤ | 0x00005A10 | **0x5** | **0** | **不在内存** |

**装入位 = 0 的虚拟地址为 ④ 和 ⑤**，对应虚页号分别为 0x2 和 0x5，页面当前不在内存中。

## 问题 2（4 分）

对虚拟地址 ①②③ 分别执行：拆分虚页号与页内偏移 → 查页表 → 拼接物理地址。

### 虚拟地址 ① = 0x000035A8

1. **拆分**：
   - 虚页号 VPN = 0x000035A8 >> 12 = **0x3**（十进制 3）
   - 页内偏移 = 0x000035A8 & 0xFFF = **0x5A8**（十进制 1448）

2. **查页表**：VPN = 0x3 → 装入位 = 1，实页号 PFN = **0x03AB**

3. **拼接物理地址**：
   - PA = (PFN << 12) | offset = (0x03AB << 12) | 0x5A8
   - = 0x3AB000 | 0x5A8 = **0x3AB5A8**

**物理地址 ① = 0x3AB5A8**（26 位二进制：00001110101011010110101000）

### 虚拟地址 ② = 0x000041F0

1. **拆分**：
   - 虚页号 VPN = 0x000041F0 >> 12 = **0x4**（十进制 4）
   - 页内偏移 = 0x000041F0 & 0xFFF = **0x1F0**（十进制 496）

2. **查页表**：VPN = 0x4 → 装入位 = 1，实页号 PFN = **0x001F**

3. **拼接物理地址**：
   - PA = (PFN << 12) | offset = (0x001F << 12) | 0x1F0
   - = 0x1F000 | 0x1F0 = **0x1F1F0**

**物理地址 ② = 0x1F1F0**（26 位二进制：00000000011111000111110000）

### 虚拟地址 ③ = 0x000067C4

1. **拆分**：
   - 虚页号 VPN = 0x000067C4 >> 12 = **0x6**（十进制 6）
   - 页内偏移 = 0x000067C4 & 0xFFF = **0x7C4**（十进制 1988）

2. **查页表**：VPN = 0x6 → 装入位 = 1，实页号 PFN = **0x000C**

3. **拼接物理地址**：
   - PA = (PFN << 12) | offset = (0x000C << 12) | 0x7C4
   - = 0xC000 | 0x7C4 = **0xC7C4**

**物理地址 ③ = 0xC7C4**（26 位二进制：00000000001100011111000100）

## 问题 3（3 分）

### 虚拟地址 ④ = 0x00002B3E

1. **拆分**：
   - 虚页号 VPN = 0x00002B3E >> 12 = **0x2**
   - 页内偏移 = 0x00002B3E & 0xFFF = **0xB3E**

2. **查页表**：VPN = 0x2 → **装入位 = 0**

3. **判断**：装入位 = 0，该页面当前不在内存中，**不可转换**为物理地址。

4. **原因与处理**：发生**缺页（缺页中断）**。操作系统需要将该页从外存（磁盘）调入内存，更新页表中对应表项的装入位为 1 并填入分配的实页号，之后重新执行地址转换。

### 虚拟地址 ⑤ = 0x00005A10

1. **拆分**：
   - 虚页号 VPN = 0x00005A10 >> 12 = **0x5**
   - 页内偏移 = 0x00005A10 & 0xFFF = **0xA10**

2. **查页表**：VPN = 0x5 → **装入位 = 0**

3. **判断**：装入位 = 0，该页面当前不在内存中，**不可转换**为物理地址。

4. **原因与处理**：发生**缺页（缺页中断）**。操作系统需要将该页从外存（磁盘）调入内存，更新页表中对应表项的装入位为 1 并填入分配的实页号，之后重新执行地址转换。
