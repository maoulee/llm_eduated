## 考点
- **核心考点**：页式虚拟存储器地址转换
  - 考察侧重点 1：虚拟地址→虚页号+页内偏移的分解（按页大小拆位）
  - 考察侧重点 2：查询页表装入位，判断有效/失效页
  - 考察侧重点 3：有效页的实页号与页内偏移拼接，得到物理地址
  - 考察侧重点 4：十六进制地址表示与转换
- **辅助考点**：页表结构理解（虚页号、实页号、装入位的对应关系）

## 难度目标
- **K1=2（较低）**：需知道页式虚拟存储器基本术语（虚页号、实页号、装入位、页内偏移），但这些概念在题干中可顺推，无需精确辨析
- **K2=3（标准）**：需进行十六进制地址的位拆分与拼接计算，涉及非平凡数字运算（位运算/进制转换），可能算错
- **K3=4（较高）**：对多个虚地址需逐一走"拆地址→查页表→判装入位→拼实地址"的完整流程，步数多、需维持中间状态
- **K4=3（标准）**：存在明确陷阱——装入位为0的页无法转换（产生缺页/失效），不检查装入位直接拼接会出错
- **K5=1（微弱）**：单一知识点（虚拟存储器）内部完成，不涉及其他子系统

## 考察模式
**计算型——地址转换与页表查询**（与slot指定一致）

选择理由：页式虚拟存储器地址转换是组成原理标准计算考点，考察模式成熟。多地址转换+装入位判断的组合能覆盖"拆分→查询→拼接"完整链条，K3推演主导，K4陷阱（失效页）提供区分度。无历史参考题时，按标准考法锚定。

## 出题要求
- **题型**：计算题，10分
- **总条件数**：约 4-5 个显式条件
  - 条件 1：虚拟地址空间位数
  - 条件 2：物理地址空间位数
  - 条件 3：页大小（应为2的幂）
  - 条件 4：页表（含虚页号、实页号、装入位若干行）
  - 条件 5：待转换的若干虚拟地址（十六进制，≥3个，至少1个装入位=0）
- **条件设计原则**：
  - 页大小、地址位数必须为2的幂，确保位拆分边界清晰
  - 页表至少包含5-8个页表项，其中至少1项装入位=0
  - 待转换地址中至少包含1个失效页地址（装入位=0）和2个有效页地址
  - 所有地址以十六进制给出
- **参数取值范围要求**：
  - 虚拟地址位数：32位（标准）
  - 物理地址位数：≤32位（通常24-28位，使实页号位数<虚页号位数）
  - 页大小：常见值如4KB，确保页内偏移为12位
  - 页表项数量：6-10项，部分装入位=0

## 子问题规划
- **第1问（分析题，约3分）**：
  - 类型：分析判断
  - 考察目标：根据页表装入位，指出哪些页当前不在主存（装入位=0），并说明地址转换结构（虚页号位数、实页号位数、页内偏移位数）
  - 与后问关系：前置——明确结构参数和失效页，为后续地址转换铺垫

- **第2问（计算题，约4分）**：
  - 类型：计算
  - 考察目标：将2-3个**有效**虚拟地址转换为物理地址（十六进制输出）
  - 与后问关系：并行于第3问

- **第3问（计算题，约3分）**：
  - 类型：计算/分析
  - 考察目标：给出1-2个**装入位=0**的虚拟地址，要求判断能否转换并说明原因（缺页/失效）
  - 与前问关系：与第2问并列，考察装入位检查意识（K4陷阱）

## 参数约束
- **虚拟地址位数（VA_bits）**：32位
- **物理地址位数（PA_bits）**：24-28位
- **页大小（page_size）**：2^12 = 4KB（页内偏移=12位），或 2^10 = 1KB（页内偏移=10位）
  - 约束：page_size 必须为2的幂
- **虚页号位数** = VA_bits − log2(page_size)
- **实页号位数** = PA_bits − log2(page_size)
- **页表项**：
  - 行数：6-10行
  - 每行含：虚页号（十六进制）、实页号（十六进制）、装入位（0或1）
  - 约束：至少1行装入位=0；装入位=1的行，实页号不超过实页号位数范围
- **待转换虚地址**：
  - 数量：3-4个（十六进制）
  - 约束：至少1个对应装入位=0的页（用于第3问考察缺页判断）；2-3个对应装入位=1的页（用于第2问计算）
  - 地址不应过大超出虚拟地址空间范围
- **一致性约束**：
  - 所有实页号 < 2^(实页号位数)
  - 拼接物理地址 = 实页号 << 页内偏移位数 | 页内偏移
  - 可调自由度：页大小可在4KB/1KB间选择、页表内容可自由设计、待转换地址可自由设计

## 参考经验
- **考察模式**：页式虚拟存储器地址转换是CO-3存储系统经典计算考点，标准流程为"拆地址→查页表→判装入位→拼实地址"
- **难度锚点**：K3=4 对应多地址逐一转换的推演负荷；K4=3 对应装入位=0的缺页陷阱
- **典型陷阱**：
  1. 不检查装入位直接拼接实地址（对失效页产生错误结果）
  2. 页内偏移位数计算错误（页大小不是2^12时的换算）
  3. 十六进制地址拆分时忽略位对齐（需按二进制位边界拆分，不能按十六进制位随意截断）
  4. 虚页号位数与实页号位数不同，拼接时位数不匹配
