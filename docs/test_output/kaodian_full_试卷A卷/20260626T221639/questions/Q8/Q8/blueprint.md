## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 计算机组成原理 > CO-3 存储系统 > 虚拟存储器
- primary_target_name: 页式虚拟存储器地址转换
- question_type: comprehensive（计算题，含子问题）
- examination_mode: 计算型——地址转换与页表查询

### 难度目标
- k_target: K1=2,K2=3,K3=4,K4=3,K5=1
- difficulty_level: 3
- difficulty_rationale: 多个虚地址需逐一完成"拆地址→查页表→判装入位→拼实地址"的串行流程，K3=4主导推演负荷；装入位=0的失效页提供K4=3陷阱区分度；十六进制位运算提供K2=3计算难度

### 结构要求
- sub_question_count: 3
- sub_question_details:
  - Q1（分析，~3分）：判断失效页 + 说明地址转换结构参数（虚页号/实页号/页内偏移位数）
  - Q2（计算，~4分）：2-3个有效虚地址→物理地址转换（十六进制输出）
  - Q3（分析+计算，~3分）：1-2个装入位=0的虚地址，判断能否转换并说明原因
- distractor_strategy: 不适用（计算题，非选择题）。区分度由参数设计保障——失效页混入待转换地址列表
- condition_count: 4-5

### 参数约束
- VA_bits: 32（虚拟地址位数）
- PA_bits: 24-28（物理地址位数）
- page_size: 2^12(4KB) 或 2^10(1KB)，必须为2的幂
- 虚页号位数 = VA_bits − log2(page_size)
- 实页号位数 = PA_bits − log2(page_size)
- 页表行数: 6-10
- 页表约束: 至少1行装入位=0；装入位=1行的实页号 < 2^(实页号位数)
- 待转换地址: 3-4个十六进制虚地址
  - 至少1个对应装入位=0（Q3用）
  - 至少2个对应装入位=1（Q2用）
  - 地址在虚拟地址空间范围内
- 拼接一致性: 物理地址 = (实页号 << log2(page_size)) | 页内偏移

### 参考经验摘要
- 历史模式: 页式虚拟存储器地址转换——"拆地址→查页表→判装入位→拼实地址"标准流程
- 难度锚点: K3=4多地址推演；K4=3装入位=0缺页陷阱；K2=3十六进制位运算
- 典型陷阱:
  1. 不检查装入位直接拼接（对失效页产生错误实地址）
  2. 页内偏移位数换算错误（非4KB页大小时）
  3. 十六进制地址拆分未按二进制位边界对齐
  4. 虚页号位数≠实页号位数时拼接位数不匹配
