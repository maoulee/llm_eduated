# 页式虚拟存储器地址转换

## 题目

某计算机采用按字节编址，页式虚拟存储器管理，地址结构如下：

- **虚拟地址（VA）**：32 位
- **物理地址（PA）**：26 位
- **页大小**：4 KB（2^12 字节）
- **按字节编址**（每个地址对应 1 个字节）

系统页表的部分内容如下（仅列出有效虚页号范围 0x00000 ~ 0x00007）：

| 虚页号（VPN） | 装入位（Valid） | 实页号（PFN） |
|:---:|:---:|:---:|
| 0x00000 | 1 | 0x0012 |
| 0x00001 | 1 | 0x0005 |
| 0x00002 | 0 | —— |
| 0x00003 | 1 | 0x03AB |
| 0x00004 | 1 | 0x001F |
| 0x00005 | 0 | —— |
| 0x00006 | 1 | 0x000C |
| 0x00007 | 1 | 0x0042 |

现有以下 5 个虚拟地址（十六进制）需要处理：

| 编号 | 虚拟地址（十六进制） |
|:---:|:---:|
| ① | 0x000035A8 |
| ② | 0x000041F0 |
| ③ | 0x000067C4 |
| ④ | 0x00002B3E |
| ⑤ | 0x00005A10 |

---

### 问题 1（3 分）

根据上述地址结构，回答：
（1）虚拟地址中，虚页号占多少位？页内偏移占多少位？
（2）物理地址中，实页号占多少位？页内偏移占多少位？
（3）在上述 5 个虚拟地址中，哪些虚拟地址对应的页面当前不在内存中（装入位 = 0）？

### 问题 2（4 分）

对虚拟地址 ①②③，分别完成虚拟地址到物理地址的转换，写出每一步计算过程（拆分虚页号与页内偏移 → 查页表 → 拼接物理地址），并给出最终的物理地址（用十六进制表示）。

### 问题 3（3 分）

对虚拟地址 ④⑤，分别判断能否完成虚拟地址到物理地址的转换。若能转换，给出物理地址；若不能，说明原因，并指出操作系统接下来需要做什么。

---

## 场景规则（本题成立 ⇔ 以下参数间约束被满足）

以下约束与具体地址值无关，换参数仍应成立：

1. **地址结构一致性**：虚页号位数 = VA_bits − log2(page_size) = 32 − 12 = 20；实页号位数 = PA_bits − log2(page_size) = 26 − 12 = 14；页内偏移位数 = log2(page_size) = 12（虚/实地址共享同一位数）。
2. **拼接一致性**：物理地址 = (实页号 << 12) | 页内偏移，即物理地址的高 14 位 = 实页号，低 12 位 = 页内偏移。
3. **装入位语义**：装入位 = 0 的页面不在内存中，该虚页号对应的虚拟地址**不可转换**为物理地址；装入位 = 1 的页面可转换。
4. **实页号合法性**：所有装入位 = 1 的实页号 PFN < 2^(实页号位数) = 2^14 = 16384（0x4000）。
5. **虚页号拆分正确性**：虚页号 = 虚拟地址 >> 12（右移页内偏移位数）；页内偏移 = 虚拟地址 & (2^12 − 1) = 虚拟地址 & 0xFFF。
6. **页表覆盖性**：所有待转换虚拟地址的虚页号均落在给定页表的有效范围内（0x00000 ~ 0x00007），确保查表不越界。
