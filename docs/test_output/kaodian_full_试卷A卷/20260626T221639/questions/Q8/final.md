## 题目

某计算机采用按字节编址，页式虚拟存储器管理，地址结构如下：

- **虚拟地址（VA）**：32 位
- **物理地址（PA）**：26 位
- **页大小**：4 KB（2^12 字节）
- **按字节编址**（每个地址对应 1 个字节）

系统页表的部分内容如下（仅列出有效虚页号范围 0x00000 ~ 0x00007）：

| 虚页号（VPN） | 装入位（Valid） | 实页号（PFN） |
|:---:|:---:|:---:|
| 0x00000 | 1 | 0x0012 |
| 0x00001 | 1 | 0x0005 |
| 0x00002 | 0 | —— |
| 0x00003 | 1 | 0x03AB |
| 0x00004 | 1 | 0x001F |
| 0x00005 | 0 | —— |
| 0x00006 | 1 | 0x000C |
| 0x00007 | 1 | 0x0042 |

现有以下 5 个虚拟地址（十六进制）需要处理：

| 编号 | 虚拟地址（十六进制） |
|:---:|:---:|
| ① | 0x000035A8 |
| ② | 0x000041F0 |
| ③ | 0x000067C4 |
| ④ | 0x00002B3E |
| ⑤ | 0x00005A10 |

---

### 问题 1（3 分）

根据上述地址结构，回答：
（1）虚拟地址中，虚页号占多少位？页内偏移占多少位？
（2）物理地址中，实页号占多少位？页内偏移占多少位？
（3）在上述 5 个虚拟地址中，哪些虚拟地址对应的页面当前不在内存中（装入位 = 0）？

### 问题 2（4 分）

对虚拟地址 ①②③，分别完成虚拟地址到物理地址的转换，写出每一步计算过程（拆分虚页号与页内偏移 → 查页表 → 拼接物理地址），并给出最终的物理地址（用十六进制表示）。

### 问题 3（3 分）

对虚拟地址 ④⑤，分别判断能否完成虚拟地址到物理地址的转换。若能转换，给出物理地址；若不能，说明原因，并指出操作系统接下来需要做什么。

## 参考答案

**问题 1：**
（1）虚页号 **20 位**，页内偏移 **12 位**。
（2）实页号 **14 位**，页内偏移 **12 位**。
（3）虚拟地址 **④（VPN = 0x2）** 和 **⑤（VPN = 0x5）** 对应页面不在内存中。

**问题 2：**
- 地址 ① = 0x000035A8 → 物理地址 **0x3AB5A8**
- 地址 ② = 0x000041F0 → 物理地址 **0x1F1F0**
- 地址 ③ = 0x000067C4 → 物理地址 **0xC7C4**

**问题 3：**
- 地址 ④ = 0x00002B3E：**不可转换**，缺页（装入位 = 0）。
- 地址 ⑤ = 0x00005A10：**不可转换**，缺页（装入位 = 0）。
- 操作系统需将该页从磁盘调入内存，更新页表装入位为 1 并填入实页号，然后重新执行地址转换。

## 解析

### 地址结构分析

- VA = 32 位，PA = 26 位，页大小 = 4 KB = 2^12 B，按字节编址
- 页内偏移位数 = log2(4096) = **12 位**（虚/实地址共享）
- 虚页号位数 = 32 − 12 = **20 位**
- 实页号位数 = 26 − 12 = **14 位**

---

### 问题 1（3 分）

**（1）虚拟地址结构**

| 字段 | 虚页号（VPN） | 页内偏移 |
|:---:|:---:|:---:|
| 位数 | **20 位** | **12 位** |

**（2）物理地址结构**

| 字段 | 实页号（PFN） | 页内偏移 |
|:---:|:---:|:---:|
| 位数 | **14 位** | **12 位** |

**（3）不在内存中的虚拟地址**

逐个拆分虚页号（VA >> 12），查页表装入位：

| 编号 | 虚拟地址 | 虚页号 (VA >> 12) | 装入位 | 是否在内存 |
|:---:|:---:|:---:|:---:|:---:|
| ① | 0x000035A8 | 0x3 | 1 | 在内存 |
| ② | 0x000041F0 | 0x4 | 1 | 在内存 |
| ③ | 0x000067C4 | 0x6 | 1 | 在内存 |
| ④ | 0x00002B3E | **0x2** | **0** | **不在内存** |
| ⑤ | 0x00005A10 | **0x5** | **0** | **不在内存** |

装入位 = 0 的虚拟地址为 **④ 和 ⑤**，对应虚页号分别为 0x2 和 0x5，页面当前不在内存中。

---

### 问题 2（4 分）

#### 虚拟地址 ① = 0x000035A8

1. **拆分**：
   - 虚页号 VPN = 0x000035A8 >> 12 = **0x3**
   - 页内偏移 = 0x000035A8 & 0xFFF = **0x5A8**

2. **查页表**：VPN = 0x3 → 装入位 = 1，实页号 PFN = **0x03AB**

3. **拼接物理地址**：
   - PA = (PFN << 12) | offset = (0x03AB << 12) | 0x5A8
   - = 0x3AB000 | 0x5A8 = **0x3AB5A8**

#### 虚拟地址 ② = 0x000041F0

1. **拆分**：
   - 虚页号 VPN = 0x000041F0 >> 12 = **0x4**
   - 页内偏移 = 0x000041F0 & 0xFFF = **0x1F0**

2. **查页表**：VPN = 0x4 → 装入位 = 1，实页号 PFN = **0x001F**

3. **拼接物理地址**：
   - PA = (PFN << 12) | offset = (0x001F << 12) | 0x1F0
   - = 0x1F000 | 0x1F0 = **0x1F1F0**

#### 虚拟地址 ③ = 0x000067C4

1. **拆分**：
   - 虚页号 VPN = 0x000067C4 >> 12 = **0x6**
   - 页内偏移 = 0x000067C4 & 0xFFF = **0x7C4**

2. **查页表**：VPN = 0x6 → 装入位 = 1，实页号 PFN = **0x000C**

3. **拼接物理地址**：
   - PA = (PFN << 12) | offset = (0x000C << 12) | 0x7C4
   - = 0xC000 | 0x7C4 = **0xC7C4**

---

### 问题 3（3 分）

#### 虚拟地址 ④ = 0x00002B3E

1. **拆分**：
   - 虚页号 VPN = 0x00002B3E >> 12 = **0x2**
   - 页内偏移 = 0x00002B3E & 0xFFF = **0xB3E**

2. **查页表**：VPN = 0x2 → **装入位 = 0**

3. **判断**：装入位 = 0，该页面当前不在内存中，**不可转换**为物理地址。

4. **原因与处理**：发生**缺页（缺页中断）**。操作系统需要将该页从外存（磁盘）调入内存，更新页表中对应表项的装入位为 1 并填入分配的实页号，之后重新执行地址转换。

#### 虚拟地址 ⑤ = 0x00005A10

1. **拆分**：
   - 虚页号 VPN = 0x00005A10 >> 12 = **0x5**
   - 页内偏移 = 0x00005A10 & 0xFFF = **0xA10**

2. **查页表**：VPN = 0x5 → **装入位 = 0**

3. **判断**：装入位 = 0，该页面当前不在内存中，**不可转换**为物理地址。

4. **原因与处理**：发生**缺页（缺页中断）**。操作系统需要将该页从外存（磁盘）调入内存，更新页表中对应表项的装入位为 1 并填入分配的实页号，之后重新执行地址转换。
