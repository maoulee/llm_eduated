# Cache 全相联映射分析

## 题目

某计算机的主存地址空间为 **64KB**，按字节编址，主存地址为 **16 位**。该计算机采用 Cache 加速访存，Cache 数据区容量为 **2KB**，行长（块大小）为 **64B**，采用 **全相联映射** 方式，替换策略为 **FIFO**（先进先出）。

**初始状态：** Cache 当前已满，共 32 行。各行按 FIFO 装入顺序（行 0 最早装入）存放的主存块号依次为 0, 1, 2, 3, …, 31（即行 *i* 存放块号 *i*，0 ≤ *i* ≤ 31）。

CPU 依次发出以下 6 个访存地址（十六进制）：

| 序号 | 访存地址 |
|------|----------|
| ①   | 0x0280   |
| ②   | 0x0A00   |
| ③   | 0x0500   |
| ④   | 0x0C00   |
| ⑤   | 0x0140   |
| ⑥   | 0x1000   |

---

### 问题 1（3 分）

计算 Cache 共有多少行？在全相联映射方式下，主存地址分为哪几部分（各部分名称及位数）？Tag 占多少位？

### 问题 2（4 分）

逐一分析上述 6 个访存地址，指出每个地址是命中还是未命中。对于未命中的地址，说明新数据装入的行号以及是否发生替换；若发生替换，说明被替换出去的块号。

### 问题 3（3 分）

完成所有访存操作后，Cache 中哪些行的内容发生了变化？写出这些行当前存放的块号（Tag 值）。该访存序列的命中率是多少？

## 设计意图

| 维度 | 说明 |
|------|------|
| 考察知识点 | Cache 全相联映射的地址结构分解、命中判定、数据装入与 FIFO 替换 |
| 考察模式 | 分析型——给定地址序列，逐个推演命中/装入/替换结果 |
| K 目标 | K3=4（6 个地址的多步串行推演 + Cache 行状态表维护），K4=3（全相联 Tag = 完整主存块号，与直接映射"去掉行号位"混淆的陷阱） |
| 核心陷阱 | ① 全相联映射中 Tag = 完整主存块号（无行索引位），易与直接映射混淆；② 块内地址位数由行长决定（log₂L），非地址总位数；③ 命中比较的是 Tag（块号），非完整地址；④ FIFO 替换仅在 Cache 满时触发，替换最早装入的块 |
| 初始状态说明 | 初始 Cache 设为已满（32 行全占用），使 6 个地址即可演示命中、装入、替换三种场景。若初始为空则 32 行需 33 次以上未命中才能触发替换，不适合 4~6 地址的分析题 |

## 通过条件（场景规则）

以下为 **参数间必须成立的约束**（与具体答案值无关，换参数仍成立），供 gen.py 转为 assert 验证：

### 1. 参数一致性约束

- `N == C // L`（Cache 行数 = 数据区容量 / 行长）
- `b == log2(L)`（块内地址位数 = log₂(行长)，L 为 2 的幂）
- `m == A - b`（主存块号位数 = 主存地址位数 − 块内地址位数）
- `Tag位数 == m`（全相联映射：Tag = 完整主存块号，**无行索引位**）

### 2. 地址分解约束

- 对任意访存地址 `addr`：`block_number == addr >> b`，`block_offset == addr & ((1 << b) - 1)`
- 所有访存地址 `addr < (1 << A)`（在地址空间范围内）

### 3. 命中判定约束

- 命中 ⇔ 该地址的块号 `block_number` 等于 Cache 当前某行存放的块号（Tag 值）
- 全相联映射下，比较的是块号（Tag），不含行索引

### 4. FIFO 替换不变量

- 替换发生 ⟺ Cache 已满且发生未命中
- 替换目标 = FIFO 队列中最早装入的块
- 新块装入后，该块成为 FIFO 队列中最新（最后被替换）的块

### 5. 序列设计约束

- 访存序列中至少有一对地址块号相同（保证 ≥1 次命中）
- 访存序列中至少有一个地址的块号不在初始 Cache 中（保证 ≥1 次装入/替换）
- 初始 Cache 中 32 行全占用（已满），使得未命中且块号不在 Cache 中时立即触发 FIFO 替换

### 6. 最终状态一致性

- 任意时刻 Cache 占用行数 ≤ N（不超过 32）
- 命中率 == 命中次数 / 总访问次数（本题为 / 6）
- 最终各行 Tag 值与 FIFO 推演结果一致

## 参数速查（供 write_gen 使用）

| 参数 | 值 |
|------|----|
| C（Cache 数据区容量） | 2KB = 2048 B |
| L（行长/块大小） | 64 B |
| N（Cache 行数） | 32 |
| A（主存地址位数） | 16 |
| b（块内地址位数） | 6 |
| m（主存块号位数） | 10 |
| Tag 位数（全相联） | 10 |
| 初始 Cache | 行 *i* 存放块号 *i*（0 ≤ *i* ≤ 31），已满，FIFO 顺序：块 0 最先装入 |
| 替换策略 | FIFO |
| 访存地址序列（十六进制） | 0x0280, 0x0A00, 0x0500, 0x0C00, 0x0140, 0x1000 |
