- sub_question_count: 2

  - 第2问(6分, 计算): 由规格化结果计算符号位/阶码字段(真值+127)/尾数字段(23位)，拼接32位输出十六进制
- dependency: 串行，第2问依赖第1问的规格化结果和阶码真值

### 参数约束
- 十进制待转换数:
  - 取值范围: 绝对值4~127之间的带小数数
  - 小数部分: 至少含一个非1/2^k简单分数成分，使二进制转换非平凡且尾数字段不全0/全1
  - 符号: 正数或负数均可，Question Agent自行决定
  - 约束: 阶码真值+127必须落在1~254范围（保证规格化数）
  - 约束: 小数部分二进制展开在23位尾数字段内可表示或仅需舍入1位
- 可调自由度: 具体数值、符号正负、小数部分构成
