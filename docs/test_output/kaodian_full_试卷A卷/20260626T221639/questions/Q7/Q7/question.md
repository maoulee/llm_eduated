# IEEE 754 单精度浮点数表示

## 设计意图

本题考查 IEEE 754 单精度浮点数的编码转换全流程，属于"计算型——浮点数编码转换"。学生需完成从十进制数到 IEEE 754 标准格式的多步串行推演：十进制转二进制 → 规格化 → 计算阶码（含偏置值 127）→ 拼接 32 位格式 → 输出十六进制。

考察知识点：
- 十进制小数转二进制（整数部分除2取余，小数部分乘2取整）
- 规格化形式（1.xxx × 2^E）及隐含前导 1
- 偏置值（bias = 127，非 128）
- 符号位 / 阶码字段 / 尾数字段拼接
- 32 位二进制转十六进制表示

典型陷阱：偏置值用 127 而非 128；隐含的前导 1 不写入尾数字段；负数仅符号位置 1，阶码和尾数用绝对值部分。

## 题干

将十进制数 **-54.375** 转换为 IEEE 754 单精度浮点数的机器数表示。已知 IEEE 754 单精度浮点数采用 32 位格式：1 位符号位（S）+ 8 位阶码（E，偏置值 bias = 127）+ 23 位尾数（M，隐含前导 1）。

要求写出完整的转换过程。

### 第 1 问（4 分）

将 -54.375 的**绝对值**部分转换为二进制数，并写出其**规格化形式**（即 $1.xxx \times 2^{E}$ 的形式）。给出规格化后的**阶码真值 E**。

**输出项：**
- （1）54.375 的二进制表示
- （2）规格化形式 $1.xxx \times 2^{E}$
- （3）阶码真值 E

### 第 2 问（6 分）

根据第 1 问的规格化结果，计算 IEEE 754 单精度浮点数的 32 位机器数表示，并写出最终结果的十六进制形式。

**输出项：**
- （1）符号位 S 的值
- （2）阶码字段（E + 127 的 8 位二进制）
- （3）尾数字段（23 位二进制，不含隐含的前导 1）
- （4）32 位完整机器数（S + 阶码 + 尾数）
- （5）最终的十六进制表示

## 场景规则（通过条件）

本题成立需要满足以下参数间约束（与具体答案值无关，换参数仍成立）：

1. **二进制等价性**：54.375 的二进制表示转为十进制后必须严格等于 54.375（即整数部分 + 小数部分无损还原）。
2. **规格化正确性**：规格化形式必须满足 $1.xxx \times 2^{E}$，即小数点左边仅有 1 位且该位为 1；阶码真值 E = 原二进制整数部分的位数 - 1。
3. **阶码字段约束**：E + 127 必须落在 1~254 范围内（保证为规格化数，非零非无穷）。
4. **符号位正确性**：因输入为负数，S = 1；阶码和尾数字段取绝对值部分的规格化结果。
5. **尾数字段位数**：尾数字段恰好 23 位（隐含前导 1 不写入，不足 23 位低位补零，超出 23 位需舍入）。
6. **32 位拼接自洽**：拼接后的 32 位机器数 = 符号位(1) + 阶码字段(8) + 尾数字段(23)，总位数为 32。
7. **十六进制一致**：十六进制表示与 32 位二进制表示严格一一对应（4 位一组，高位不足补零对齐到 8 位十六进制）。
