# MIPS/CPI 计算题 — 求解过程

## 已知参数

| 参数 | 值 |
|------|-----|
| 程序总指令数 N | 10⁸ = 100,000,000 条 |
| 指令占比 | I₁=40%, I₂=30%, I₃=20%, I₄=10%（占比和=100%） |
| 机器 A | f = 500 MHz；CPI: I₁=1, I₂=3, I₃=4, I₄=6 |
| 机器 B | f = 750 MHz；CPI: I₁=2, I₂=3, I₃=3, I₄=5 |

---

## 第 1 问：加权平均 CPI

公式：**加权 CPI = Σ(CPIᵢ × 占比ᵢ)**

### 机器 A

$$\text{CPI}_A = 1 \times 0.4 + 3 \times 0.3 + 4 \times 0.2 + 6 \times 0.1 = 0.4 + 0.9 + 0.8 + 0.6 = \mathbf{2.70}$$

### 机器 B

$$\text{CPI}_B = 2 \times 0.4 + 3 \times 0.3 + 3 \times 0.2 + 5 \times 0.1 = 0.8 + 0.9 + 0.6 + 0.5 = \mathbf{2.80}$$

> **验证**：占比归一 0.4+0.3+0.2+0.1 = 1.0 ✓

---

## 第 2 问：MIPS

公式：**MIPS = 时钟频率(MHz) / 加权 CPI**

### 机器 A

$$\text{MIPS}_A = \frac{500}{2.70} = \mathbf{185.19}$$

### 机器 B

$$\text{MIPS}_B = \frac{750}{2.80} = \mathbf{267.86}$$

> 注意：时钟频率以 MHz 为单位直接代入即可（因 MIPS = 10⁶ 指令/秒，f 以 Hz 为单位除以 10⁶ = 以 MHz 为单位）。

---

## 第 3 问：性能比较

公式：**执行时间 = (N × 加权 CPI) / 时钟频率(Hz)**

也可用：**执行时间 = N / (MIPS × 10⁶)**

### 机器 A

- 公式 1：$T_A = \frac{10^8 \times 2.70}{500 \times 10^6} = \frac{2.70 \times 10^8}{5.0 \times 10^8} = \mathbf{0.54\text{ s}}$
- 公式 2（验证）：$T_A = \frac{10^8}{185.19 \times 10^6} = \mathbf{0.54\text{ s}}$ ✓（两种公式结果一致）

### 机器 B

- 公式 1：$T_B = \frac{10^8 \times 2.80}{750 \times 10^6} = \frac{2.80 \times 10^8}{7.5 \times 10^8} = \mathbf{0.3733\text{ s}}$
- 公式 2（验证）：$T_B = \frac{10^8}{267.86 \times 10^6} = \mathbf{0.3733\text{ s}}$ ✓

### 结论

**机器 B 更快。**

定量依据：
- $T_B = 0.3733\text{ s} < T_A = 0.54\text{ s}$
- 加速比 = $T_A / T_B = 0.54 / 0.3733 \approx \mathbf{1.45}$

机器 B 虽然加权 CPI 略高（2.80 > 2.70），但其时钟频率更高（750 MHz vs 500 MHz），综合效果是单位时间内执行更多指令（MIPS_B = 267.86 > MIPS_A = 185.19），执行时间更短。

---

## 结果汇总

| 指标 | 机器 A | 机器 B |
|------|--------|--------|
| 加权 CPI | 2.70 | 2.80 |
| MIPS | 185.19 | 267.86 |
| 执行时间 (s) | 0.5400 | 0.3733 |

**机器 B 性能更优（快约 1.45 倍）。**

---

## 场景规则验证

| 规则 | 结果 |
|------|------|
| R1 占比归一（和=1.0） | ✓ True |
| R2 加权CPI = Σ(CPIᵢ×ratioᵢ) | ✓ A=2.70, B=2.80 |
| R3 MIPS = f(MHz)/CPI | ✓ A=185.19, B=267.86 |
| R4 执行时间两公式一致 | ✓ A: 0.54=0.54; B: 0.3733=0.3733 |
| R5 执行时间不同，存在唯一更快者 | ✓ B 更快 |
| R6 参数合法（CPI∈[1,8], 频率∈[200,800]MHz, 频率不同, CPI不完全相同） | ✓ 全部 True |
