# 概念题解析

## 第 1 题解析

**答案**：

浮点数由阶码（含阶符）和尾数（含数符）两部分组成，在总位长固定的前提下：

（1）**表示范围由阶码的位数决定**（2分）。阶码位数越多，能表示的指数范围越大，浮点数的表示范围就越大。

（2）**精度由尾数的位数决定**（2分）。尾数位数越多，能表示的有效数字越多，精度越高。

（3）**权衡关系**：在总位长固定时，增加阶码位数可扩大范围，但会减少尾数位数从而降低精度；反之亦然。两者互相制约，设计时需根据应用需求折中。（1分）

**解析**：本题考察浮点数表示中范围与精度的概念辨析及权衡。常见错误：将范围与精度混淆，认为都由尾数或都由阶码决定；遗漏权衡关系的讨论。得分要点：阶码→范围、尾数→精度、权衡制约三个点缺一不可。

## 第 2 题解析

**答案**：

按功能划分，系统总线分为三类：
- **地址总线**：传送 CPU 访存的地址信息，单向（CPU→存储器/IO），其位数决定最大物理地址空间。
- **数据总线**：传送数据信息，双向，其位数通常与机器字长有关，决定一次总线传输的数据量。
- **控制总线**：传送控制信号和时序信号，包括读/写信号、中断请求、总线请求等。

**总线复用**：指同一条总线在不同时间分时传送不同类型的信息（如地址/数据复用），通过分时控制实现。

- **优点**：减少总线引脚数目，降低硬件成本和芯片封装复杂度。
- **缺点**：降低了总线的数据吞吐率（同一时刻只能传一类信息），需要额外的控制逻辑（如 ALE 锁存信号）来区分时段。

**解析**：本题考察总线按功能分类（地址/数据/控制三大类）以及总线复用的定义与利弊。常见混淆：将总线复用与总线的"总线仲裁"混淆；遗漏复用需要分时控制的说明。

## 第 3 题解析

**答案**：

"程序员可见"是指该寄存器可以由程序员通过指令直接或间接访问和操作（即可用指令指定其作为操作数或目标）。

- **可见的寄存器**：通用寄存器（如 R0~Rn）、程序计数器（PC）、程序状态字寄存器（PSW）、累加器（ACC）等。程序员可以通过指令直接引用或间接使用它们。
- **不可见的寄存器**：指令寄存器（IR）、存储器地址寄存器（MAR）、存储器数据寄存器（MDR）、暂存器等。这些寄存器是 CPU 内部执行指令时自动使用的，程序员无法用指令直接访问。

**解析**：本题考察 CPU 内部寄存器的分类与程序员可见性概念。关键区分点：可见寄存器是程序员能通过编程控制的；不可见寄存器属于 CPU 微观实现细节。常见错误：认为 IR 或 MAR 对程序员可见（实际不可见），或认为 PC 不可见（实际可见，转移类指令直接操作 PC）。

## 第 4 题解析

**答案**：

- **机器字长**：CPU 一次能处理的二进制数据的位数，通常等于 ALU 的位数和通用寄存器的宽度，反映了 CPU 的数据处理能力。
- **存储字长**：主存的一个存储单元所能存放的二进制数据的位数，即每个存储地址对应的数据宽度。
- **指令字长**：一条机器指令的二进制位数。指令字长可以是固定的（等于机器字长），也可以是变长的（半字长、单字长、双字长等）。

**三者的关系**：三者**不一定相等**。在许多机器中指令字长可以小于、等于或大于机器字长（变长指令集）；存储字长通常与机器字长一致以方便存取，但并非必然，在按字节编址的系统中存储字长可以是 8 位而机器字长为 32 位。三者是不同层面（处理能力、存储宽度、指令编码）的概念，没有必然的相等关系。

**解析**：本题考察三种"字长"的定义及关系辨析。常见错误：认为三者必然相等，或混淆指令字长与机器字长。关键是理解三者分别属于不同的概念层面——机器字长衡量处理能力、存储字长衡量存储单元宽度、指令字长衡量指令编码长度。
