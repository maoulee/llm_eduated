# 概念题

## 第 1 题

**题干**：在浮点数总位长固定的情况下，请简述浮点数的表示范围和精度分别由哪些部分决定，并说明两者之间存在怎样的权衡关系。（5分）

## 第 2 题

**题干**：请简述按功能划分，系统总线可以分为哪几类？并说明总线复用的含义及其优缺点。

## 第 3 题

**题干**：CPU 内部包含多种寄存器（如通用寄存器、程序计数器 PC、指令寄存器 IR、程序状态字寄存器 PSW、累加器 ACC、存储器地址寄存器 MAR、存储器数据寄存器 MDR 等）。请说明哪些寄存器对程序员是可见的，哪些是不可见的，并解释"程序员可见"的含义。

## 第 4 题

**题干**：请分别说明机器字长、存储字长和指令字长的含义，并指出三者之间是否存在必然相等的关系。
