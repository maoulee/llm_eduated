## rationale
- 选"单点计算"为主形式：题干给定权值集合→输出单个 WPL 数值，符合选择题"给参数求结果"的典型模式；K3=3 反映哈夫曼构造需多步串行推演（排序→选最小两节点→合并→重复），故标注"含多步推演"以体现过程复杂度。
- 与目标 K-雷达对齐：K1=3（需掌握 WPL/路径长度/哈夫曼定义）、K2=3（每轮合并为单步代入计算）、K3=3（2-3 轮合并构成串行推演链）、K4=2（无复杂条件分支，贪心策略唯一）、K5=2（不涉及跨域联动），形状完全匹配。
