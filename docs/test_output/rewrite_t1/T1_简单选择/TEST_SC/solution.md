## 求解过程

### 哈夫曼树构造与 WPL 计算

给定权值集合 {3, 5, 7, 8, 12}，按哈夫曼算法构造：

1. **初始叶子节点**：3, 5, 7, 8, 12
2. **第1次合并**：取最小两个 3 和 5，合并为 8。剩余：{7, 8, 8, 12}
3. **第2次合并**：取最小两个 7 和 8（原始），合并为 15。剩余：{8, 12, 15}
4. **第3次合并**：取最小两个 8（3+5）和 12，合并为 20。剩余：{15, 20}
5. **第4次合并**：取 15 和 20，合并为 35。构造完成。

**树结构与各叶子节点深度**：
- 权值 7：深度 2
- 权值 3：深度 3
- 权值 5：深度 3
- 权值 8：深度 2
- 权值 12：深度 2

**WPL 计算**：
WPL = 7×2 + 3×3 + 5×3 + 8×2 + 12×2 = 14 + 9 + 15 + 16 + 24 = 78

## 最终答案
- 正确答案：78
  - 理由：按哈夫曼算法逐步合并最小权值节点，得到各叶子节点的路径长度分别为 2, 3, 3, 2, 2，WPL = 7×2 + 3×3 + 5×3 + 8×2 + 12×2 = 78。
