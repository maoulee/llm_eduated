## 考点
- **核心知识点**：主存储器容量计算——地址线位数决定寻址空间大小，数据线位数决定每个存储单元的位宽，二者乘积即为存储器总容量。
  - 考察侧重点：给定地址线和数据线数量，反推出存储器总容量（地址单元数 × 每单元位数）。
- **辅助知识点**：容量单位换算（bit → Byte → KB/MB 等），存储容量 = 2^(地址线数) × 数据线数。

## 难度目标
- **K1=2**（较低）：需要知道"地址线位数→寻址空间""数据线位数→存储字长"这一基础概念，但概念本身简单直白，题干也会点明场景，记忆负担小。
- **K2=3**（标准）：需执行 2^n 乘法 + 单位换算，数值可能涉及非纯 2 的幂次中间结果（如 2^16 × 32 = 2^16 × 2^5 = 2^21 bit），需要一步单位换算才能匹配选项格式。
- **K3=2**（较低）：解题路径 2 步——先算寻址单元数，再乘数据位宽得到总容量，路径唯一。
- **K4=2**（较低）：常规注意点为 bit 与 Byte 的转换（除以 8），408 考生基本不会踩坑，但选项中可设置此陷阱。
- **K5=1**（微弱）：单一知识点内部解决，不涉及其他子系统。

## 考察模式
- **模式名称**：计算型——存储容量推导。
- **理由**：slot 指定 examination_mode 为"计算型——存储容量推导"，这是该题位的标准考法。给定线数反推容量是存储系统章节的经典选择题考法，考察学生对地址线/数据线含义的准确理解及基本容量计算能力。

## 出题要求
- **题型**：单项选择题，4 选项（A/B/C/D），1 正确 3 干扰。
- **分值**：2 分。
- **总条件数**：2~3 个显式条件（地址线根数、数据线根数，可选附带存储器类型或编址方式说明）。
- **条件设计原则**：
  - 题干直接给出地址线位数和数据线位数。
  - 可附带一句话场景描述（如某 SRAM / DRAM 芯片）增强真实感，但不引入额外考点。
  - 问法明确要求"该存储器的存储容量为"。
- **参数取值范围要求**：
  - 地址线位数：10~20 之间，使寻址空间在 1K~1M 范围。
  - 数据线位数：4、8、16、32 之一，便于与常见存储芯片对应。
  - 最终容量结果应可表示为 2 的幂 × 整数，单位为 bit 或 Byte。

## 子问题规划
- 单项选择题，无子问题。
- 选项设计见下方干扰策略。

## 参数约束
| 参数 | 取值范围 | 约束关系 |
|------|---------|---------|
| 地址线位数 n | 10 ≤ n ≤ 20 | n 为正整数 |
| 数据线位数 m | m ∈ {4, 8, 16, 32} | m 为正整数，2 的幂 |
| 总容量 | 2^n × m (bit) | 由 n 和 m 唯一确定 |
| 选项单位 | bit 或 Byte | 四个选项统一单位 |

**一致性约束**：
- 四个选项必须使用统一的容量单位（如统一用 KB 或统一用 Kbit）。
- 正确答案 = 2^n × m bit，换算到选项所用单位。
- 干扰项须由不同错误路径产生，且彼此不重合。

**可调自由度**：
- n 和 m 的具体取值由 Question Agent 决定。
- 题干场景措辞由 Question Agent 决定。

## 参考经验
- **考察模式**：存储器容量 = 2^(地址线数) × 数据线数，是历年常考的经典计算型选择题。
- **难度锚点**：target_difficulty=2，整体偏简单，核心在一步乘法 + 单位换算。
- **典型陷阱**：
  1. 忘记 bit→Byte 换算（少除/多除以 8）。
  2. 只用地址线算容量，忽略数据线位宽。
  3. 2 的幂算错（如 2^16 = 65536 误算为 32768）。

## 干扰策略
- **干扰项 1（bit/Byte 混淆）**：正确答案以 bit 表示而干扰项用 Byte（或反之），差 8 倍关系。
- **干扰项 2（忽略数据线）**：只算 2^n，不乘数据线位宽。
- **干扰项 3（单位换算错或幂次算错）**：与正确答案有明确的量级差异，如差 2 倍或 4 倍。
- 要求三个干扰项数值互不相同且与正确答案不同。
