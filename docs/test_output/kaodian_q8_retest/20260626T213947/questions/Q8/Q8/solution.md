# 解题过程

## 题目

某 SRAM 存储芯片有 18 根地址线、16 根数据线。该芯片的存储容量为：

A. 512 KB  B. 4096 KB  C. 32 KB  D. 1024 KB

## 参数

| 参数 | 值 |
|------|-----|
| 地址线根数 n | 18 |
| 数据线位宽 m | 16 |
| 统一选项单位 | KB |

## 求解过程

### 第一步：计算可寻址单元数

18 根地址线 → 可寻址单元数 = 2¹⁸ = **262144** 个存储单元。

### 第二步：计算存储容量（bit）

16 根数据线 → 每个存储单元存储 16 位。

存储容量 = 2¹⁸ × 16 = 262144 × 16 = **4194304 bit**。

### 第三步：单位换算

- 1 Byte = 8 bit → 容量（Byte）= 4194304 ÷ 8 = **524288 Byte**
- 1 KB = 1024 Byte → 容量（KB）= 524288 ÷ 1024 = **512 KB**

> 等价验证：1 KB = 1024 × 8 = 8192 bit；4194304 ÷ 8192 = **512 KB** ✓

### 答案：**A. 512 KB**

---

## 各选项分析

| 选项 | 值 | 正误 | 分析 |
|------|-----|------|------|
| **A** | **512 KB** | ✅ 正确 | 2¹⁸ × 16 bit = 4194304 bit = 524288 Byte = 512 KB |
| B | 4096 KB | ❌ | **bit/Byte 混淆**：将 4194304 bit 直接除以 1024 得 4096 KB，未先除以 8 进行 bit→Byte 换算，结果比正确值大 8 倍 |
| C | 32 KB | ❌ | **忽略数据线位宽**：仅用 2¹⁸ = 262144 bit，漏乘数据线位宽 16，得 262144 ÷ 8 ÷ 1024 = 32 KB |
| D | 1024 KB | ❌ | **幂次计算错误**：将 2¹⁸ 算成 2¹⁹，得 524288 × 16 = 8388608 bit → 1024 KB，比正确值大 2 倍 |

## 数据流验证（exec 输出）

- 规则1（容量定义 capacity_bit == 2^n × m）：True
- 规则2（单位换算 1 KB == 8192 bit 且 capacity_KB == bit/8192）：True
- 规则3（四选项互异）：True（A=512, B=4096, C=32, D=1024）
- 规则4（A 唯一正确）：True
- 规则5（三干扰项 ≠ A 且互不相同）：True
