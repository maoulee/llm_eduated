## 题目
# 题目

某 SRAM 存储芯片有 18 根地址线、16 根数据线。该芯片的存储容量为：

A. 512 KB
B. 4096 KB
C. 32 KB
D. 1024 KB

---

## 考察意图

- **核心考点**：由地址线数和数据线数反推存储芯片容量。
- **关键推导**：n 根地址线 → 可寻址单元数 = 2ⁿ；m 根数据线 → 每个单元 m 位 → 存储容量 = 2ⁿ × m bit。
- **单位换算**：1 Byte = 8 bit，1 KB = 1024 Byte。
- **难度定位**：K2 主导——一步乘法 + 单位换算，计算简单但需准确识别陷阱。

## 场景规则（通过条件）

以下为本题成立需要满足的**参数间约束**，与具体答案值无关，换参数仍成立：

1. **容量定义一致性**：存储容量（bit）== 2 ** n × m，其中 n 为地址线根数（n=18），m 为数据线位宽（m=16）。这是存储容量推导的定义公式。
2. **单位换算正确性**：1 KB == 1024 × 8 bit == 8192 bit；容量_KB == 容量_bit / 8192。
3. **四选项互异**：A、B、C、D 四个选项值各不相同（exec 计算后无碰撞）。
4. **正确值唯一**：给定 n=18、m=16，存储容量唯一确定，A 为该值；不存在两个选项同时正确的歧义。
5. **干扰项对应声明错误类型**：
   - B = bit/Byte 混淆路径的产物（直接将容量 bit 数除以 1024 得到"KB"，或乘 8 得到错误值）；
   - C = 忽略数据线位宽路径的产物（仅 2ⁿ，未乘 m）；
   - D = 幂次/单位换算错误路径的产物（2ⁿ 算错一档或 1024 因子算错）。
   - 三条干扰路径须产生互不相同的值，且均 ≠ A。
6. **干扰项合理性**：每个干扰项是同类题常见误算的真实产物，有区分度。

## 参数

| 参数 | 值 |
|------|-----|
| 地址线根数 n | 18 |
| 数据线位宽 m | 16 |
| 统一选项单位 | KB |

## 干扰项设计（只标错误类型，不写数值）

| 选项 | 错误类型 |
|------|---------|
| A | 无——正确结果 |
| B | bit/Byte 混淆（差 8 倍） |
| C | 忽略数据线位宽（漏乘 m=16） |
| D | 幂次算错或单位换算因子错误（差 2 或 4 倍） |


## 求解过程
### 第一步：计算可寻址单元数

18 根地址线 → 可寻址单元数 = 2¹⁸ = **262144** 个存储单元。

### 第二步：计算存储容量（bit）

16 根数据线 → 每个存储单元存储 16 位。

存储容量 = 2¹⁸ × 16 = 262144 × 16 = **4194304 bit**。

### 第三步：单位换算

- 1 Byte = 8 bit → 容量（Byte）= 4194304 ÷ 8 = **524288 Byte**
- 1 KB = 1024 Byte → 容量（KB）= 524288 ÷ 1024 = **512 KB**

> 等价验证：1 KB = 1024 × 8 = 8192 bit；4194304 ÷ 8192 = **512 KB** ✓

### 答案：**A. 512 KB**
