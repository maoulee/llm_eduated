# TEST_AVL — 单链表环检测算法设计

## 题目

设线性表 $L$ 采用单链表存储，链表中可能存在环（即某个结点的 `next` 指针指向链表中已存在的某个结点）。请设计一个算法判断该单链表中是否存在环。

要求（请使用 C 或 C++ 语言描述）：

1. **定义链表结点数据类型**（2 分）
2. **描述算法基本设计思想**（4 分）
3. **编写算法（关键处给注释）**（7 分）

## 参考答案

### ① 定义链表结点数据类型（2 分）

```c
typedef struct LNode {
    int data;                    // 数据域
    struct LNode *next;          // 指针域，指向后继结点
} LNode, *LinkList;
```

**评分要点**：
- 包含 `data` 域（数据域）与 `next` 指针域（2 分）
- 类型定义完整，使用 `struct` 和 `typedef` 规范定义

---

### ② 描述算法基本设计思想（4 分）

**算法思想（Floyd 判圈算法 / 快慢指针法）**：

1. **初始化**：设置两个指针 `slow`（慢指针）和 `fast`（快指针），均指向链表的头结点（或首元结点）。

2. **移动规则**：
   - 慢指针 `slow` 每次向前移动 **1 步**（`slow = slow->next`）
   - 快指针 `fast` 每次向前移动 **2 步**（`fast = fast->next->next`）

3. **相遇判断（有环）**：
   - 若链表中存在环，快指针和慢指针最终会在环内**相遇**（即 `slow == fast`），此时判定链表有环，返回 `true`。
   - 原理：快指针相对于慢指针的相对速度为 1 步/次，在环内快指针会逐渐追上慢指针。

4. **无环终止条件**：
   - 若快指针 `fast` 变为 `NULL`，或快指针的后继 `fast->next` 为 `NULL`，说明链表已走到末尾，不存在环，返回 `false`。
   - 需在每次移动快指针前检查 `fast != NULL && fast->next != NULL`，避免空指针访问。

**评分要点**：
- 清晰描述快慢指针初始化（1 分）
- 描述移动规则：快指针步长为 2，慢指针步长为 1（1 分）
- 描述相遇判断：快慢指针相遇说明有环（1 分）
- 描述无环终止条件：快指针或其后继为空（1 分）

---

### ③ 编写算法代码（7 分）

```c
/**
 * 判断单链表中是否存在环
 * @param L 链表头指针
 * @return 存在环返回 true，否则返回 false
 */
bool HasCycle(LinkList L) {
    // 边界条件：空链表或只有一个结点（无环）
    if (L == NULL || L->next == NULL) {
        return false;
    }

    // 初始化快慢指针，均指向首元结点
    LNode *slow = L->next;
    LNode *fast = L->next;

    // 循环条件：快指针及其后继均不为空
    while (fast != NULL && fast->next != NULL) {
        // 慢指针每次移动 1 步
        slow = slow->next;
        // 快指针每次移动 2 步
        fast = fast->next->next;

        // 若快慢指针相遇，说明存在环
        if (slow == fast) {
            return true;
        }
    }

    // 快指针到达链表末尾，说明无环
    return false;
}
```

**评分要点**：
- 代码正确实现快慢指针判环逻辑（3 分）
- 正确处理边界条件：空链表、单结点、无环链表（2 分）
- 关键处有注释（循环条件、指针移动、相遇判断）（1 分）
- 时间复杂度 $O(n)$、空间复杂度 $O(1)$（1 分）

**复杂度分析**：
- **时间复杂度**：$O(n)$。若无环，快指针遍历链表约 $n/2$ 次；若有环，快慢指针在环内最多绕环一周相遇，总步数不超过 $2n$。
- **空间复杂度**：$O(1)$。仅使用两个指针变量，不依赖额外空间。
