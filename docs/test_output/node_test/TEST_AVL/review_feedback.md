### evidence

1. **题干引用序列 S 但未给出具体数值**：question.md 题干中写道"依次插入关键字序列 $S = [x_1, x_2, \ldots, x_n]$"，但全文未给出 S 的具体关键字值。设计卡参数约束明确要求"序列长度 $n \geq 5$"、"关键字为整数，建议在 $[1, 20]$ 范围内"，这些是题目必须提供的已知条件，而非由 solve 阶段生成的选项值。

2. **平衡因子符号约定未定义**：子问题（2）要求判断"LL/RR/LR/RL"旋转类型，但题干未定义平衡因子是 $h_L - h_R$ 还是 $h_R - h_L$。不同教材约定不同，这直接影响 LR/RL 的判定逻辑，与设计卡"概念型干扰：LR 与 RL 触发条件混淆"的意图冲突——干扰应来自概念辨析而非定义模糊。

3. **高度计算定义缺失**：子问题（3）要求"计算其高度"，但未定义高度是按边数计算（单节点高度为 0）还是按层数计算（单节点高度为 1）。这是 408 常见歧义点，可能导致计算型干扰偏离设计意图。
