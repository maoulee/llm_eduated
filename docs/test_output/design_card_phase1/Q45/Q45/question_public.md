# Q45 虚拟存储器与Cache协同工作

某计算机采用页式虚拟存储管理方式，按字节编址，虚拟地址为32位，物理地址为24位，页大小为64B。TLB采用全相联映射。Cache数据区大小为32KB，采用4路组相联映射，主存块大小为64B。存储访问过程的示意图如下：

```
┌─────────────────────────────────────────────────┐
│                  虚拟地址 (32位)                  │
│  ┌──────────────────────┬──────────┐            │
│  │          A           │    B     │            │
│  └──────────┬───────────┴────┬─────┘            │
│             │                │                   │
│             ▼                ▼                   │
│  ┌─────────────────┐  ┌──────────────┐          │
│  │      TLB        │  │    页表      │          │
│  │    (全相联)     │  │   (主存中)   │          │
│  └────────┬────────┘  └──────┬───────┘          │
│           │                  │                   │
│           └────────┬─────────┘                   │
│                    ▼                             │
│  ┌──────────────────────────────────┐            │
│  │         物理地址 (24位)           │            │
│  │  ┌────────┬────────┬──────────┐  │            │
│  │  │   C    │    D   │    E     │  │            │
│  │  └───┬────┴───┬────┴────┬─────┘  │            │
│  │      │        │         │         │            │
│  └──────┼────────┼─────────┼─────────┘            │
│         │        │         │                       │
│         ▼        ▼         ▼                       │
│  ┌──────────────────────────────────┐            │
│  │           Cache (32KB)           │            │
│  │  ┌────────┬────────┬──────────┐  │            │
│  │  │   F    │    G   │    E     │  │            │
│  │  └────────┴────────┴──────────┘  │            │
│  └──────────────────────────────────┘            │
└─────────────────────────────────────────────────┘
```

请回答下列问题：

### (1) （3分）
计算图中字段A～G的位数各是多少？TLB的标记字段中存放的是什么信息？

### (2) （4分）
已知虚拟地址 `0x00123456` 对应的页表项中物理页号为 `0x003A5`。将该虚拟地址转换为物理地址后，判断该地址访问Cache时映射到的Cache组号是多少？对应的Cache标记（Tag）字段的值是多少（用十六进制表示）？

### (3) （3分）
在TLB缺失的情况下，是否可能出现Cache命中的情况？请结合本题的系统配置说明理由。
