## 题目

某计算机采用页式虚拟存储管理方式，按字节编址，虚拟地址为32位，物理地址为24位，页大小为64B。TLB采用全相联映射。Cache数据区大小为32KB，采用4路组相联映射，主存块大小为64B。存储访问过程的示意图如下：

```
┌─────────────────────────────────────────────────┐
│                  虚拟地址 (32位)                  │
│  ┌──────────────────────┬──────────┐            │
│  │          A           │    B     │            │
│  └──────────┬───────────┴────┬─────┘            │
│             │                │                   │
│             ▼                ▼                   │
│  ┌─────────────────┐  ┌──────────────┐          │
│  │      TLB        │  │    页表      │          │
│  │    (全相联)     │  │   (主存中)   │          │
│  └────────┬────────┘  └──────┬───────┘          │
│           │                  │                   │
│           └────────┬─────────┘                   │
│                    ▼                             │
│  ┌──────────────────────────────────┐            │
│  │         物理地址 (24位)           │            │
│  │  ┌────────┬────────┬──────────┐  │            │
│  │  │   C    │    D   │    E     │  │            │
│  │  └───┬────┴───┬────┴────┬─────┘  │            │
│  │      │        │         │         │            │
│  └──────┼────────┼─────────┼─────────┘            │
│         │        │         │                       │
│         ▼        ▼         ▼                       │
│  ┌──────────────────────────────────┐            │
│  │           Cache (32KB)           │            │
│  │  ┌────────┬────────┬──────────┐  │            │
│  │  │   F    │    G   │    E     │  │            │
│  │  └────────┴────────┴──────────┘  │            │
│  └──────────────────────────────────┘            │
└─────────────────────────────────────────────────┘
```

请回答下列问题：

### (1) （3分）
计算图中字段A～G的位数各是多少？TLB的标记字段中存放的是什么信息？

### (2) （4分）
已知虚拟地址 `0x00123456` 对应的页表项中物理页号为 `0x003A5`。将该虚拟地址转换为物理地址后，判断该地址访问Cache时映射到的Cache组号是多少？对应的Cache标记（Tag）字段的值是多少（用十六进制表示）？

### (3) （3分）
在TLB缺失的情况下，是否可能出现Cache命中的情况？请结合本题的系统配置说明理由。

---

## 求解过程

### 子问题(1)

**已知参数**：虚拟地址32位，物理地址24位，页大小64B=2^6，Cache 32KB=2^15，4路组相联，块大小64B=2^6。

1. **页内偏移/块内偏移**：页大小=64B→页内偏移=6位；块大小=64B→块内偏移=6位。**B=6位，E=6位**
2. **虚拟页号（VPN）**：VPN=32-6=26位。**A=26位**
3. **Cache地址字段**：Cache总块数=32KB/64B=512块；Cache组数=512/4=128组；组号位数=log2(128)=7位。**D=7位，G=7位**；Tag=24-7-6=11位。**C=11位，F=11位**
4. **TLB标记字段**：TLB全相联映射，标记字段存放**虚拟页号（VPN）**。

### 子问题(2)

1. **提取页内偏移**：0x00123456低6位 = 0x56 & 0x3F = 0x16
2. **计算物理地址**：物理地址 = 0x003A5 << 6 | 0x16 = 0x0E940 | 0x16 = 0x0E956
3. **提取Cache组号（Index）**：物理地址0x0E956二进制为 0000 0000 1110 1001 0101 0110，组号（位[12:6]）= 0100101 = 0x25 = **37**
4. **提取Cache标记（Tag）**：Tag（位[23:13]）= 00000000111 = **0x7**

### 子问题(3)

**可能。** TLB缓存页表项（虚拟页号→物理页号映射），Cache缓存主存数据块（按物理地址索引），两者独立。TLB缺失仅表示需访问页表获取物理页号，不影响Cache中数据的存在。获得物理地址后正常访问Cache，Cache中可能已有该数据块，因此可能命中。

---

## 答案

- **(1)** A=26位，B=6位，C=11位，D=7位，E=6位，F=11位，G=7位；TLB标记字段存放虚拟页号（VPN）
- **(2)** Cache组号=37（0x25），Cache标记（Tag）=0x7
- **(3)** 可能。TLB与Cache是两个独立的硬件结构，TLB缺失只影响地址转换过程（需查页表获取物理页号），不影响Cache中数据的存在。获得物理地址后正常访问Cache，Cache中可能已有该数据块，因此可能命中。
