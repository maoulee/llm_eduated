# Q12 题目

## 题干

某计算机主频为500MHz，程序P运行过程中共执行了2×10^6条指令，其中75%的指令执行平均需2个时钟周期，25%的指令执行平均需6个时钟周期。程序P的CPU执行时间是（）。

A. 8ms
B. 12ms
C. 16ms
D. 32ms

---

## 设计说明

- **考察模式**：计算型——公式应用与单位换算（来自经验卡建议分布，该模式出现频率7/13，为最高频模式）
- **选项风格**：数字结果（100%，计算型题目标准选项风格）
- **should_be对照**：
  1. 需要准确记忆CPU执行时间公式 T = IC × CPI / f —— 本题必须调用该公式才能入题
  2. 需要完成常规参数代入 —— 代入 IC=2×10^6、CPI=3、f=500MHz
  3. 需要完成单位换算 —— MHz→Hz、s→ms 两级换算
- **should_not_be排查**：
  1. 不是纯概念辨析 —— 本题需要实际计算，非纯记忆
  2. 不是复杂多步推演 —— 仅需2步（加权平均CPI + 代入公式），无流程推演
  3. 不是跨系统联动 —— 纯CPU性能指标内部闭环，不涉及Cache/IO等其他系统
- **参数选择理由**：
  - 主频500MHz：非整数GHz，增加单位换算需求（500×10^6而非10^9），符合K2=3标准
  - 指令数2×10^6：2的幂次友好，便于心算
  - 指令比例75%/25%：3:1比例，加权计算简洁（0.75×2+0.25×6=3）
  - CPI值2和6：整数，加权后得整数3，避免小数干扰核心考察点
- **干扰项设计策略**：
  - **A. 8ms**：针对"只考虑主要部分"的错误认知。学生只取占比75%的指令CPI=2，忽略25%的指令，计算 T = 2×10^6 × 2 / (500×10^6) = 8ms。这是2014年真题的核心陷阱（遗漏变量）
  - **C. 16ms**：针对"不做加权平均，算术平均"的错误认知。学生误将CPI算术平均 (2+6)/2=4，计算 T = 2×10^6 × 4 / (500×10^6) = 16ms。这是2022年真题的核心陷阱（忽视加权概念）
  - **D. 32ms**：针对"不做加权平均，直接相加"的错误认知。学生误将CPI直接相加 2+6=8，计算 T = 2×10^6 × 8 / (500×10^6) = 32ms。针对不理解CPI物理意义的基础薄弱学生
  - 干扰策略：**渐进陷阱**——8→12→16→32，对应从"遗漏变量"到"算术平均"到"直接相加"的错误认知递进链
- **与契约 K 值的对齐说明**：
  - **K1=3（标准）**：必须准确记忆 CPU 执行时间公式 T = IC × CPI / f 及 CPI 的加权平均定义才能入题，仅靠常识无法解题。非4分因为CPI和CPU时间是计组最基础概念之一。
  - **K2=3（标准）**：需代入公式并完成两级单位换算（MHz→Hz、s→ms），涉及非10^9量级的主频（500×10^6），属于标准难度。非2分因为500MHz不是整数GHz，需额外换算；非4分因为计算本身不繁杂。
  - **K3=1（微弱）**：无需推演流程，仅需2步直接计算（加权平均CPI + 代入公式），路径唯一且极简。
  - **K4=2（较低）**：存在常规注意点——需识别指令比例为权重进行加权平均而非简单相加/平均；需识别MHz需转换为Hz。这些是408考生的基本素养，陷阱较浅。
  - **K5=1（微弱）**：单一知识点（CPU性能指标）内部解决，不涉及存储、IO等其他系统的联动。
  - **雷达形状**：K1-K2平衡型，与契约要求一致。
