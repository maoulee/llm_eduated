===== 子问题(1) =====
R1 = 0X0001H
  有符号整数: 1
  无符号整数: 1
R2 = 0X7FFFH
  有符号整数: 32767
  无符号整数: 32767

===== 子问题(2) =====
R3 = R1 + R2 = 0X0001H + 0X7FFFH
  完整和: 32768
  R3 = 0X8000H
  CF = 0, OF = 1
R4 = R3 + R2 = 0X8000H + 0X7FFFH
  完整和: 65535
  R4 = 0XFFFFH
  CF = 0, OF = 0
R5 = R4 + R2 = 0XFFFFH + 0X7FFFH
  完整和: 98302
  R5 = 0X7FFEH
  CF = 1, OF = 0

===== 子问题(3) =====
有符号整数溢出判断（OF=1表示溢出）：
  R3: OF=1 → 溢出
  R4: OF=0 → 不溢出
  R5: OF=0 → 不溢出
无符号整数溢出判断（CF=1表示溢出）：
  R3: CF=0 → 不溢出
  R4: CF=0 → 不溢出
  R5: CF=1 → 溢出

验证：
  有符号范围: [-32768, 32767]
  无符号范围: [0, 65535]
  R3有符号: 1 + 32767 = 32768 > 32767 → 溢出
  R3无符号: 1 + 32767 = 32768 <= 65535 → 不溢出
  R4有符号: -32768 + 32767 = -1，范围[-32768,32767] → 不溢出
  R4无符号: 32768 + 32767 = 65535 <= 65535 → 不溢出
  R5有符号: -1 + 32767 = 32766，范围[-32768,32767] → 不溢出
  R5无符号: 65535 + 32767 = 98302 > 65535 → 溢出

===== 最终答案 =====
R3 = 0X8000H, CF=0, OF=1
R4 = 0XFFFFH, CF=0, OF=0
R5 = 0X7FFEH, CF=1, OF=0
