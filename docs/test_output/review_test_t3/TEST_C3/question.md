# Q41 题目

设有一棵包含7个节点的平衡二叉排序树（AVL树），其结构如下（括号内为节点关键字）：

```
        (20)
       /    \
    (10)    (30)
    /  \    /
 (5)  (15)(25)
 /
(2)
```

向该AVL树中插入关键字 `1`，执行插入操作并调整平衡后，根节点（关键字为20的节点）的平衡因子为多少？

（注：平衡因子定义为左子树高度 − 右子树高度）

A. 0
B. -1
C. 2
D. 1

## 设计说明

- **复用骨架来源**：design_card 的 `question_structure_plan`（给出初始AVL树结构 + 待插入关键字 + 询问调整后特定节点属性）
- **考察形式**：多步串行推演 + 陷阱辨析（混合形式，主K3辅K4）
- **经验值参数**：初始树节点数 n=7（经验值表取7），插入关键字=1
- **设计理念**：通过完整模拟AVL插入→更新平衡因子→定位失衡→判定旋转类型→执行旋转→重新计算的多步流程，区分学生对四种旋转类型触发条件的掌握程度
- **与目标K-雷达的对齐**：K1=3, K2=2, K3=4, K4=4, K5=1（K3-K4平衡型）
- **干扰选项设计**：
  - A（0）：认为插入后树仍完全平衡，未察觉左子树增高
  - B（-1）：左右子树高度计算颠倒（右−左而非左−右）
  - C（2）：未执行旋转调整，直接计算插入后失衡状态下的平衡因子
  - D（1）：正确答案，插入后LL型右旋，左子树高度3−右子树高度2=1
