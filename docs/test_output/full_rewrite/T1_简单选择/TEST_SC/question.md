# 题目

已知一棵二叉树的结构如下图所示，括号内为叶子结点的权值：

```
        A
       / \
      B   C
     / \   \
    D   E(10) F(12)
   / \
  G(5) H(8)
```

其中，A、B、C、D 为非叶子结点，G、H、E、F 为叶子结点。

该二叉树的带权路径长度 WPL 为多少？

（注：带权路径长度 WPL = Σ(叶子结点权值 × 该叶子结点的路径长度)，路径长度指从根结点到该结点所经过的边数。）

A. 59
B. 118
C. 83
D. 71

---

## 设计说明

- **复用骨架来源**：来自 design_card `question_structure_plan`——图形化二叉树 + 文字设问，题干给出二叉树结构图（结点标注权值），设问"该二叉树的带权路径长度 WPL 为多少？"
- **考察形式**：single_choice（选择题），多步串行推演（主）+ 单点计算（辅）
- **经验值参数**：
  - 节点总数：8（经验值表二叉树 n=7 的邻近友好值，满足 4 个叶子 + 路径长度有变化的需求）
  - 叶子结点：4 个（G、H、E、F），权值分别为 5、8、10、12
  - 树高度：4 层
  - 路径长度分布：G=3、H=3、E=2、F=2
- **设计理念**：考查学生对 WPL 核心概念的扎实掌握——不是记忆公式，而是能在具体树结构上完整执行"识别叶子→确定路径长度→加权求和"的计算流程，区分能完整走完计算流程的学生与出现路径长度计数起点错误、漏算叶子、层数与路径长度混淆等典型认知偏差的学生。
- **与目标 K-雷达的对齐**：K1=2（需理解 WPL 定义）、K2=3（单步加权乘法）、K3=3（多步串行流程：识别叶子→路径长度→加权求和）、K4=2（无复杂条件分支）、K5=1（不涉及跨域联动），K2/K3 双主导形状。
- **正确答案**：C（83）
- **干扰选项设计**：
  - A（59）：漏算叶子 F，仅计算 G+H+E = 15+24+20 = 59
  - B（118）：路径长度按结点计数（off-by-one），G=4,H=4,E=3,F=3 → 5×4+8×4+10×3+12×3 = 118
  - D（71）：F 的路径长度误为 1，15+24+20+12 = 71
