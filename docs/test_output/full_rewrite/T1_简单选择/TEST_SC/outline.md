## 考点
- **二叉树带权路径长度(WPL)计算**：核心考点，要求掌握WPL定义和计算方法
- **路径长度概念**：辅助考点，理解从根结点到目标结点的路径长度（边数）
- **叶子结点识别**：辅助考点，能正确识别二叉树中的叶子结点

## 难度目标
- **K1（知识记忆）= 2**：需记忆WPL公式 Σ(权值×路径长度)，难度适中
- **K2（理解）= 3**：需理解路径长度的定义（边数而非结点数），能识别叶子结点
- **K3（应用）= 3**：需应用公式对给定二叉树进行WPL计算
- **K4（分析）= 2**：需简单分析计算过程中的易错点
- **K5（综合）= 1**：选择题不涉及多知识点深度综合

**整体难度定位**：中等（medium），符合slot设定

## 考察模式
**模式选择**：给定二叉树结构，直接计算WPL

**理由**：
- 这是WPL最经典的考察方式，历史高频出现
- 适合选择题形式，计算量可控
- 能有效区分是否真正理解路径长度概念
- 便于设计针对性干扰项

## 出题要求
- **题型**：single_choice（四选一）
- **总条件数**：2-3个显式条件
  - 条件1：二叉树的结构表示（图形描述或数组/序列表示）
  - 条件2：各叶子结点的权值
  - 条件3（可选）：非叶子结点信息（用于干扰）
- **条件设计原则**：
  - 树结构表示需清晰无歧义
  - 权值分配需使计算结果适中（避免过大或过小）
  - 可包含非叶子结点信息作为干扰
- **参数取值范围要求**：
  - 叶子结点数量：3-6个
  - 权值范围：1-20的整数
  - 树的高度：3-4层
  - 最终WPL值：50-200之间（便于心算验证）

## 子问题规划
本题为选择题，无子问题。

## 参数约束
- **叶子结点数量 (leaf_count)**：3 ≤ leaf_count ≤ 6，建议4-5个
- **权值 (weight_i)**：1 ≤ weight_i ≤ 20，各权值可相同可不同，建议不完全相同以增加区分度
- **路径长度 (path_length_i)**：由树结构决定，0 ≤ path_length_i ≤ 3（根到叶子最多3条边）
- **树高度 (height)**：3 ≤ height ≤ 4，确保有足够深度但不复杂
- **WPL计算结果**：50 ≤ WPL ≤ 200，确保数值适中
- **一致性约束**：
  - 所有叶子结点的路径长度之和需合理（不能全部为0或全部为最大值）
  - 权值与路径长度的乘积之和需落在目标范围内
  - 树结构需合法（每个结点最多2个子结点）

## 参考经验
**典型考察模式**：
- 给出二叉树图形或数组表示，标注叶子结点权值，要求计算WPL
- 或给出权值序列，要求构造哈夫曼树后计算WPL（本题不采用，难度偏高）

**难度锚点**：
- 简单题：3个叶子结点，权值小，路径短
- 中等题：4-5个叶子结点，权值适中，路径长度有变化
- 困难题：6+叶子结点，权值大，或需先构造哈夫曼树

**典型陷阱**：
- 路径长度从1开始计数（错误，应从0开始，即根结点路径长度为0）
- 将非叶子结点误认为叶子结点
- 漏算某个叶子结点
- 权值与路径长度相乘时计算错误
- 混淆层数与路径长度（层数=路径长度+1）
