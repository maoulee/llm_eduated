## 题目

已知二叉树 T 共有 7 个节点，节点值分别为 A、B、C、D、E、F、G（互不相同）。该二叉树的前序遍历序列为：

```
A, B, D, E, C, F, G
```

中序遍历序列为：

```
D, B, E, A, C, F, G
```

请回答下列问题：

### (1) （4分）根据给定的前序遍历序列和中序遍历序列，还原并画出该二叉树的结构（或写出各节点的左右孩子关系）。

### (2) （3分）基于(1)中还原的二叉树，计算该二叉树的深度（根节点所在层为第1层）。

### (3) （3分）基于(1)中还原的二叉树，判断该二叉树是否为完全二叉树，并说明理由。

---

## 求解过程

### (1) 还原二叉树结构

**前序遍历**：A, B, D, E, C, F, G
**中序遍历**：D, B, E, A, C, F, G

1. 前序第一个元素 **A** 为根节点。在中序中找到 A，其左侧 `D, B, E` 为左子树，右侧 `C, F, G` 为右子树。
2. 左子树：前序 `B, D, E`，中序 `D, B, E`。前序第一个 **B** 为左子树根。中序中 B 左侧 `D` 为 B 的左子树，右侧 `E` 为 B 的右子树。→ **B 的左孩子为 D，右孩子为 E**。
3. 右子树：前序 `C, F, G`，中序 `C, F, G`。前序第一个 **C** 为右子树根。中序中 C 左侧为空，右侧 `F, G` 为 C 的右子树。
4. C 的右子树：前序 `F, G`，中序 `F, G`。前序第一个 **F** 为根。中序中 F 左侧为空，右侧 `G` 为 F 的右子树。→ **F 的右孩子为 G**。

**二叉树结构**：
```
        A
       / \
      B   C
     / \   \
    D   E   F
             \
              G
```

**各节点左右孩子关系**：
- A 的左孩子：B，右孩子：C
- B 的左孩子：D，右孩子：E
- C 的左孩子：无，右孩子：F
- D 的左孩子：无，右孩子：无
- E 的左孩子：无，右孩子：无
- F 的左孩子：无，右孩子：G
- G 的左孩子：无，右孩子：无

### (2) 计算二叉树深度

从根节点 A 出发，最长路径为 A → C → F → G，共 4 层。

各节点深度：
- 第1层：A
- 第2层：B, C
- 第3层：D, E, F
- 第4层：G

**深度 = 4**

### (3) 判断是否为完全二叉树

**不是完全二叉树。**

**理由**：完全二叉树要求除最后一层外，其余各层节点数均达到最大值，且最后一层的节点都集中在左侧。

该二叉树的层序遍历为：
- 第1层：A
- 第2层：B, C
- 第3层：D, E, (空), F
- 第4层：(空), (空), (空), (空), (空), G

第3层中 C 的左孩子为空但右孩子 F 存在，即节点未集中在左侧；第4层中 G 出现在右侧而非左侧连续位置。因此不满足完全二叉树的定义。

---

## 答案
- (1) 二叉树结构：A为根，左孩子B右孩子C；B的左孩子D右孩子E；C的右孩子F；F的右孩子G
- (2) 深度：4
- (3) 不是完全二叉树。理由：第3层中C的左孩子为空但右孩子存在，节点未集中在左侧，不满足完全二叉树定义。
