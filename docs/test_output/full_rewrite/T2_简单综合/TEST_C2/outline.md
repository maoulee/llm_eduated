## 考点
- **核心考点**：二叉树遍历序列还原（通过两种遍历序列唯一确定二叉树结构）
  - 考察侧重点：理解前序/中序/后序遍历的本质区别，掌握"根节点定位+左右子树划分"的还原逻辑
- **辅助考点**：二叉树基本性质（深度、叶子节点、度为1的节点数等）
  - 考察侧重点：在还原的树结构上进行性质计算

## 难度目标
- **K1（知识广度）= 2**：涉及遍历序列还原和树性质两个知识点，不跨知识域
- **K2（知识深度）= 3**：需要理解遍历序列与树结构的对应关系，而非机械记忆
- **K3（计算复杂度）= 2**：手动还原中等规模二叉树，计算量适中
- **K4（逻辑推理复杂度）= 3**：需要逐步推理还原过程，每一步依赖上一步结果
- **K5（综合应用能力）= 3**：将遍历知识与树性质计算结合，体现综合应用

## 考察模式
**模式选择**：给定两种遍历序列还原二叉树 → 基于还原结果求解衍生问题

**理由**：
- 这是二叉树遍历序列还原最经典的考察模式
- 能够完整考查"序列→结构→性质"的知识链条
- 适合综合题的多问结构，子问题间有自然依赖关系
- 与medium难度匹配：还原过程需要推理但不复杂，衍生问题增加综合度

## 出题要求
- **题型**：综合题（comprehensive）
- **总条件数**：2个显式条件（两种遍历序列）+ 隐含条件（节点值互异）
- **条件设计原则**：
  - 两种遍历序列必须能唯一确定二叉树（排除前序+后序的组合）
  - 节点值使用互不相同的字符（如A-J）或数字（如1-10）
  - 序列长度适中，避免过于简单或过于复杂
- **参数取值范围要求**：见参数约束章节

## 子问题规划

### 第1问（约40%分值）
- **类型**：计算/构造
- **考察目标**：根据给定的两种遍历序列，还原二叉树结构（画出树或写出第三种遍历序列）
- **分值**：约40%
- **与前后问关系**：基础问，后续问依赖此问结果

### 第2问（约30%分值）
- **类型**：计算
- **考察目标**：基于还原的二叉树，计算树的深度或叶子节点数量
- **分值**：约30%
- **与前后问关系**：依赖第1问的还原结果

### 第3问（约30%分值）
- **类型**：分析
- **考察目标**：分析二叉树的某种性质（如度为1的节点数、满/完全二叉树判断、或给定序列能否唯一确定树等）
- **分值**：约30%
- **与前后问关系**：依赖第1问的还原结果，与第2问并行

## 参数约束

### 二叉树规模
- **节点数 n**：取值范围 6-10
  - 下限6：保证树结构有一定复杂度，非退化情况
  - 上限10：保证手动还原在合理时间内完成
  - 与难度关系：n越大，还原步骤越多，K3和K4越高

### 遍历序列选择
- **给定序列组合**：前序+中序 或 后序+中序（二选一）
  - 约束：必须包含中序遍历，否则无法唯一确定
  - 自由度：出题者可选择前序+中序（更常见）或后序+中序（稍难）

### 节点值设计
- **值域**：互不相同的字符（A-J）或连续整数（1-10）
- **约束**：所有节点值必须互异，否则无法唯一还原
- **自由度**：字符或数字均可，字符更贴近考研风格

### 树结构约束
- **非退化**：树不能是链状（每个节点只有一个子节点），否则还原过于简单
- **平衡性**：左右子树节点数差不超过3，避免极端不平衡
- **叶子节点数**：至少2个，至多 n/2 + 1

### 子问题参数
- **第2问计算目标**：深度 或 叶子节点数（二选一）
  - 若选深度：树的深度应在 3-4 之间
  - 若选叶子节点数：叶子节点数应在 2-5 之间
- **第3问分析目标**：度为1的节点数 或 满/完全二叉树判断
  - 若判断满/完全：树应设计为"接近但不完全是"的情况，增加辨析难度

## 参考经验
- **历史模式**：二叉树遍历还原题通常采用"给两序列→还原→求性质"的三段式结构
- **难度锚点**：medium难度对应节点数6-10，子问题3问，K值集中在2-3
- **典型陷阱**：
  - 学生混淆前序和后序的根节点位置
  - 还原时左右子树划分错误
  - 忽略"节点值互异"这一隐含前提
  - 将前序+后序误认为能唯一确定二叉树
