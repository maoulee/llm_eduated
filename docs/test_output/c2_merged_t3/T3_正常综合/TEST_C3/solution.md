# Q41 解题过程与答案

## 解题步骤

### 第一步：构建初始 AVL 树

依次插入 `<30, 20, 40, 10, 25>`：

1. **插入 30**：
   ```
   30
   ```

2. **插入 20**：
   ```
   30
   /
   20
   ```
   30 的 BF = 1，OK。

3. **插入 40**：
   ```
     30
    /  \
   20   40
   ```
   30 的 BF = 0，OK。

4. **插入 10**：
   ```
       30
      /  \
    20    40
    /
   10
   ```
   20 的 BF = 1，30 的 BF = 1，OK。

5. **插入 25**：
   ```
       30
      /  \
    20    40
    /  \
   10  25
   ```
   20 的 BF = 0，30 的 BF = 1，OK。

**初始 AVL 树：**
```
        30
       /  \
     20    40
    /  \
  10    25
```

### 第二步：插入关键字 5

5 < 30 → 左子树
5 < 20 → 左子树
5 < 10 → 左子树
插入 5 为 10 的左孩子：

```
        30
       /  \
     20    40
    /  \
  10    25
 /
5
```

### 第三步：回溯检查平衡因子并旋转

从插入点 5 回溯：

1. **节点 10**：左高 1，右高 0，BF = 1，OK。
2. **节点 20**：左高 2（10 的子树），右高 1（25），BF = 1，OK。
3. **节点 30**：左高 3，右高 1，BF = 2，**失衡！**

### 第四步：判定旋转类型并执行

- 30 的 BF = 2 > 1，失衡在左子树
- 插入值 5 < 20（30 的左孩子），新节点在左孩子的左子树
- 判定为 **LL 型**，对 30 执行**右旋**

**右旋过程：**
- x = 30 的左孩子 = 20
- T2 = x 的右孩子 = 25
- x 的右孩子 = 30
- 30 的左孩子 = T2 = 25

### 第五步：最终 AVL 树

```
        20
       /  \
     10    30
    /     /  \
   5     25   40
```

验证平衡因子：
- 10：BF = 1-0 = 1，OK
- 30：BF = 1-1 = 0，OK
- 20：BF = 2-2 = 0，OK

## 答案

插入关键字 5 后，该 AVL 树的**根节点关键字值为 20**。

## 常见错误分析

1. **误判为 LR 型**：认为插入 5 后触发 LR 旋转，先左旋 20 再右旋 30。错误原因：未正确判断插入值与左孩子的大小关系（5 < 20，应为 LL 型）。
2. **遗漏旋转**：认为插入 5 后无需旋转。错误原因：未正确计算 30 的平衡因子（左高 3，右高 1，BF = 2）。
3. **旋转后结构错误**：右旋后 25 的位置错误。正确应为 25 从 20 的右孩子变为 30 的左孩子。
