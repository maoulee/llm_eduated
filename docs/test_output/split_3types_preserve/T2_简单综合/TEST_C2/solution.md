## 求解过程

### 子问题(1)：还原二叉树结构

根据前序遍历和中序遍历还原二叉树，采用递归方法：

**步骤1**：前序遍历第一个元素为根节点 → 根 = **a**

**步骤2**：在中序遍历中找到 a 的位置，将中序序列分为左右两部分：
- 中序左子树：d, b, e, g
- 中序右子树：c, f

**步骤3**：根据左子树节点数（4个），在前序遍历中划分：
- 前序左子树：b, d, e, g
- 前序右子树：c, f

**步骤4**：递归构建左子树（前序：b, d, e, g；中序：d, b, e, g）：
- 根 = b
- 中序中 b 左侧：d → 左子树
- 中序中 b 右侧：e, g → 右子树
- b 的左孩子 = d（叶子）
- b 的右子树（前序：e, g；中序：e, g）：根 = e，e 的右孩子 = g（叶子）

**步骤5**：递归构建右子树（前序：c, f；中序：c, f）：
- 根 = c
- 中序中 c 右侧：f → 右子树
- c 的右孩子 = f（叶子）

**还原的二叉树结构**：
```
        a
       / \
      b   c
     / \   \
    d   e   f
       \
        g
```

### 子问题(2)：层序遍历序列

基于还原的二叉树，按层从上到下、从左到右遍历：

- 第1层：a
- 第2层：b, c
- 第3层：d, e, f
- 第4层：g

**层序遍历序列**：a, b, c, d, e, f, g

### 子问题(3)：高度、叶子节点个数、度为2的节点个数

**高度**：从根节点到最远叶子节点的路径长度（节点数）。最长路径为 a → b → e → g，共 4 层。
- 高度 = **4**

**叶子节点**（度为0的节点）：d、g、f
- 叶子节点个数 = **3**

**度为2的节点**（同时有左右孩子的节点）：
- a：左孩子 b，右孩子 c → 度为2
- b：左孩子 d，右孩子 e → 度为2
- 其余节点（c 只有右孩子 f，e 只有右孩子 g）度不为2
- 度为2的节点个数 = **2**

## 最终答案
- (1) 二叉树结构如上所示
- (2) 层序遍历序列：a, b, c, d, e, f, g
- (3) 高度：4；叶子节点个数：3；度为2的节点个数：2
