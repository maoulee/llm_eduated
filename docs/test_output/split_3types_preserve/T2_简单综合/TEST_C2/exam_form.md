## rationale
- 二叉树遍历序列还原需要递归划分机制（从前序/后序定位根节点→中序划分左右子树→递归），是典型的 K3 机制推演；同时涉及从"序列域"到"树结构域"再到"序列域"的跨域状态传递（K5），以及遍历定义的基础认知（K1）。K4 较低因无需复杂条件路由/陷阱辨析。
- 与目标 K-雷达（K1=3,K2=3,K3=3,K4=2,K5=3）完全对齐：多步串行推演覆盖 K3 主导，跨域组合覆盖 K5 辅助，基础认知覆盖 K1，单步代入覆盖 K2（写出遍历序列），K4 保持低位。
