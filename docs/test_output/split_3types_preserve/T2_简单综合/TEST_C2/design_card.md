## core_knowledge_intent

- must_test:
  - 由前序（或后序）+ 中序遍历序列唯一还原二叉树结构
  - 根据还原的二叉树写出其他遍历序列（后序/前序/层序）
  - 分析二叉树的基本性质（树高、叶子节点数、度为2的节点数等）
- must_not_shift_to:
  - 不得退化为仅考查遍历序列的记忆（如默写遍历定义）
  - 不得考查纯链状树的退化情形（无分支结构）
- coverage_success_criteria:
  - solver 能正确还原二叉树结构，且还原结果与给定两种遍历序列一致
  - solver 能正确写出第三种遍历序列，且与还原的树结构一致

## expected_reasoning_actions

- 从前序（或后序）序列中定位根节点
- 根据根节点在中序序列中的位置，划分左子树和右子树的节点集合
- 递归地对左子树和右子树重复上述划分过程，直至所有节点定位完成
- 根据还原的二叉树结构，按指定遍历规则写出遍历序列
- 统计二叉树的性质指标（树高、叶子节点数、度为2的节点数等）

## question_structure_plan

- shared_context: 给定某二叉树的两种遍历序列（前序+中序 或 后序+中序），要求还原该二叉树并回答相关问题
- sub_question_chain:
  - Q1: 根据给定的两种遍历序列，还原并画出该二叉树的结构（40-50%分值）
  - Q2: 写出该二叉树的另一种遍历序列（如层序遍历或后序/前序遍历）（30-40%分值）
  - Q3: 分析该二叉树的性质（如树高、叶子节点数、度为2的节点数等）（10-20%分值，可选）
- dependency_pattern: 串行依赖——Q2 和 Q3 均依赖 Q1 的还原结果
- distractor_strategy:
  - 干扰策略1（概念混淆）：混淆前序/后序中根节点的位置（前序根在首，后序根在尾）
  - 干扰策略2（偏移错误）：子树划分时边界 off-by-one，导致左右子树节点分配错误
  - 干扰策略3（中间值）：将递归过程中的中间子树结构误认为最终完整树结构

## parameter_plan

- parameter_slots:
  - 节点数 n: 角色=树规模控制, 候选范围=5-10（建议6-8）, used_by=Q1/Q2/Q3
  - 树高 h: 角色=树深度控制, 候选范围=2-4, 约束=h ≥ ⌈log₂(n+1)⌉, used_by=Q1/Q3
  - 给定遍历类型组合: 角色=还原条件, 候选范围={前序+中序, 后序+中序}, used_by=Q1
  - 要求写出的遍历类型: 角色=Q2设问, 候选范围={前序, 中序, 后序, 层序}中未给定的类型, used_by=Q2
  - 叶子节点数: 角色=性质分析, 候选范围=2-4, used_by=Q3
  - 度为2的节点数: 角色=性质分析, 候选范围=1-3, used_by=Q3
- validation_targets:
  - 给定的两种遍历序列必须能唯一确定一棵二叉树
  - 还原的树结构必须同时满足给定的两种遍历序列
  - 树结构必须非纯链状（存在至少一个度为2的节点）
  - 树高必须满足 h ≥ ⌈log₂(n+1)⌉
  - 叶子节点数和度为2的节点数必须在指定范围内
- adjustment_priority:
  - 最高优先级：序列唯一性（必须能唯一确定二叉树）
  - 高优先级：树结构非纯链状
  - 中优先级：节点数、树高、叶子节点数、度为2的节点数在范围内

## terminology_and_expression_constraints

- required_terms:
  - 前序遍历（先序遍历）
  - 中序遍历
  - 后序遍历
  - 层序遍历
  - 根节点
  - 左子树 / 右子树
  - 叶子节点（终端结点）
  - 树高（树的高度）
  - 度为2的节点
- required_qualifiers:
  - 描述遍历序列时必须明确遍历类型（如"前序遍历序列为..."）
  - 描述树结构时必须说明是"二叉树"而非一般树
  - 描述节点关系时必须区分"左孩子"和"右孩子"
- avoid_phrases:
  - 避免使用"先序"而不说明等同于"前序"（应统一使用"前序遍历"或注明"先序遍历（即前序遍历）"）
  - 避免使用"深度"代替"高度"（树高应使用"高度"或"树高"）
  - 避免模糊表述"写出遍历结果"（应明确"写出层序遍历序列"）
- standard_rewrites:
  - bad: "根据遍历结果画出树" → good: "根据给定的前序遍历序列和中序遍历序列，还原该二叉树的结构"
  - bad: "写出另一种遍历" → good: "写出该二叉树的层序遍历序列"
  - bad: "求树的深度" → good: "求该二叉树的高度"
