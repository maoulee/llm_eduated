## 题干

已知某二叉树的前序遍历序列为 a, b, d, e, g, c, f，中序遍历序列为 d, b, e, g, a, c, f。

请回答下列问题：

### (1) （5分）根据给定的前序遍历序列和中序遍历序列，还原该二叉树的结构，并画出该二叉树。

### (2) （3分）基于(1)中还原的二叉树，写出该二叉树的层序遍历序列。

### (3) （2分）基于(1)中还原的二叉树，求该二叉树的高度、叶子节点个数以及度为2的节点个数。

## 设计说明

- **复用骨架来源**：408数据结构综合题经典骨架——"给定两种遍历序列（含中序）→还原二叉树→求其他遍历→性质分析"。参考往年选择题模式（如2026_Q3中序+层序求后序、2012_Q3前序+后序分析结构），扩展为综合题三问串行结构。
- **考察形式**：多步串行推演（主）+ 跨域组合（辅）。Q1为递归划分机制推演（K3），Q2为树结构到序列的跨域转换（K5），Q3为基础性质分析（K1/K2）。
- **子问依赖链**：串行依赖——Q2和Q3均依赖Q1的还原结果。Q1是核心，还原正确则Q2/Q3可顺推。
- **初步参数选择理由**（基于骨架+经验，大胆给）：
  - 节点数 n=7：处于建议范围6-8中间值，7节点在往年题中常见（如2026_Q3也是7节点），递归深度适中。
  - 树高 h=4：满足 h ≥ ⌈log₂(7+1)⌉ = 3，在2-4范围内。
  - 给定前序+中序：这是最经典的还原组合，前序首元素为根，中序划分左右子树，递归机制清晰。
  - 序列设计：a为根，左子树4节点（b,d,e,g），右子树2节点（c,f），左子树内部有分支（b有左右孩子），右子树为单链（c只有右孩子f），整体非纯链状。
  - 要求层序遍历：层序与前序/中序差异大，需要真正理解树结构而非死记遍历规则，增加区分度。
  - 性质分析三指标：高度、叶子数、度为2节点数，覆盖树的基本性质，计算量适中。
- **与目标 K-雷达的对齐**：
  - K1=3：遍历定义、树高/叶子/度的概念认知
  - K2=3：写出层序遍历序列（单步代入还原的树结构）
  - K3=3：Q1递归划分机制（前序定位根→中序划分左右→递归），多步串行推演
  - K4=2：无复杂条件路由/陷阱，保持低位
  - K5=3：从"序列域"到"树结构域"再到"序列域"的跨域状态传递
- **是否融合**：不融合。K3=3为中等难度，单骨架（还原→遍历→性质）已足够覆盖目标K-雷达，无需额外融合多侧重。
