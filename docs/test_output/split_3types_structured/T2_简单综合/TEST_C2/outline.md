## 考点
- **二叉树遍历**：前序遍历、中序遍历、后序遍历的定义与执行过程（考察侧重点：理解遍历的递归本质和访问顺序）
- **遍历序列还原二叉树**：根据两种遍历序列唯一确定二叉树结构（考察侧重点：利用中序遍历定位根节点，递归划分左右子树）
- **二叉树基本性质**：树的高度、叶子节点数、度为1的节点数（考察侧重点：在还原的树上进行统计计算）

## 难度目标
- **K1（知识广度）= 3**：涉及前序、中序、后序三种遍历方式，以及二叉树基本性质统计
- **K2（知识深度）= 3**：需要深入理解遍历序列与树结构的对应关系，掌握递归还原的核心思想
- **K3（计算复杂度）= 2**：以逻辑推理为主，计算量较小，主要是序列分析和节点统计
- **K4（逻辑推理复杂度）= 3**：需要递归思维，从前序确定根、从中序划分左右子树，推理链条中等长度
- **K5（综合应用难度）= 3**：需要综合运用多种遍历知识和树性质分析，但各知识点关联紧密

## 考察模式
**模式：遍历序列还原 + 性质分析**

理由：这是二叉树遍历序列还原题位的经典考察模式。先给出两种遍历序列（通常为前序+中序），要求还原二叉树结构，再基于还原的树求解其他遍历序列或统计性质。该模式能全面考查学生对遍历本质的理解，且难度可控。

## 出题要求
- **题型**：综合题（comprehensive）
- **总条件数**：2个显式条件（前序遍历序列、中序遍历序列）
- **条件设计原则**：
  - 序列长度适中，节点数建议 6-10 个
  - 树结构不能是退化链（所有节点只有左孩子或只有右孩子）
  - 树结构不能是完全二叉树或满二叉树（避免过于规则）
  - 序列中字符/数字应便于区分，避免重复值
- **参数取值范围要求**：见参数约束章节

## 子问题规划

### 第 1 问（约 4 分）
- **类型**：分析/构造
- **考察目标**：根据给定的前序遍历序列和中序遍历序列，还原并画出二叉树结构
- **与前后问关系**：基础问，后续所有问均依赖此问结果

### 第 2 问（约 3 分）
- **类型**：计算
- **考察目标**：写出该二叉树的后序遍历序列
- **与前后问关系**：依赖第 1 问还原的树结构，考查遍历序列的转换能力

### 第 3 问（约 3 分）
- **类型**：计算/分析
- **考察目标**：计算二叉树的高度、叶子节点个数、度为 1 的节点个数
- **与前后问关系**：依赖第 1 问还原的树结构，考查对树基本性质的掌握

**依赖关系**：串行依赖（第 2、3 问均依赖第 1 问）

## 参数约束

### 二叉树规模
- **节点数 n**：取值范围 [6, 10]
- **约束**：n 不宜过小（否则题目过于简单），不宜过大（否则手绘树结构过于繁琐）

### 树结构约束
- **高度 h**：取值范围 [3, 5]，需满足 h ≤ n
- **叶子节点数**：建议 2-4 个
- **度为 1 的节点数**：建议 1-3 个
- **结构要求**：
  - 不能是退化链（即不能所有非叶子节点都只有一个孩子）
  - 不能是完全二叉树或满二叉树
  - 左右子树应有一定不对称性，增加还原难度

### 遍历序列约束
- **前序序列**：由树结构唯一确定，长度 = n
- **中序序列**：由树结构唯一确定，长度 = n
- **字符集**：建议使用大写字母 A-Z 或数字 1-9，确保所有节点值互不相同
- **一致性约束**：前序序列和中序序列必须来自同一棵二叉树，且该树满足上述结构约束

### 可调自由度
- Question Agent 可在 [6, 10] 范围内选择具体节点数
- 可在满足结构约束的前提下设计具体的树形态
- 可选择字母或数字作为节点标识

## 参考经验
- **历史模式**：二叉树遍历序列还原题通常采用"前序+中序→还原树→求后序/层序/性质"的模式
- **难度锚点**：medium 难度对应节点数 6-10，树高度 3-5，子问题 2-3 个
- **典型陷阱**：
  - 学生容易混淆前序和中序的根节点定位规则
  - 递归划分左右子树时边界处理错误
  - 统计树性质时漏数或重复计数
  - 将遍历序列还原误解为唯一确定（实际上前序+后序不能唯一确定）
