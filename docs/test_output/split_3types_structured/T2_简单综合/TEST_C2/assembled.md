## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: DS-5 > 树与二叉树
- primary_target_name: 二叉树遍历序列还原
- question_type: comprehensive
- examination_mode: 遍历序列还原 + 性质分析

### 难度目标
- k_target: K1=3,K2=3,K3=2,K4=3,K5=3
- difficulty_level: 3
- difficulty_rationale: medium难度，涉及三种遍历方式和树性质分析，以逻辑推理为主，计算量适中，需要递归思维但推理链条中等长度

### 结构要求
- sub_question_count: 3
- sub_question_details:
  - q1: 类型=分析/构造, 考察目标=根据前序和中序还原二叉树, 分值≈4
  - q2: 类型=计算, 考察目标=写出后序遍历序列, 分值≈3
  - q3: 类型=计算/分析, 考察目标=计算树高度、叶子节点数、度为1的节点数, 分值≈3
- dependency: serial (q2和q3均依赖q1)
- condition_count: 2 (前序遍历序列、中序遍历序列)

### 参数约束
- 节点数 n: 范围 [6, 10]，不宜过小或过大
- 树高度 h: 范围 [3, 5]，需满足 h ≤ n
- 叶子节点数: 建议 2-4 个
- 度为1的节点数: 建议 1-3 个
- 树结构: 不能是退化链，不能是完全二叉树或满二叉树，左右子树应有一定不对称性
- 节点标识: 使用大写字母 A-Z 或数字 1-9，所有节点值互不相同
- 序列一致性: 前序序列和中序序列必须来自同一棵满足上述约束的二叉树

### 参考经验摘要
- 历史模式: 前序+中序→还原树→求后序/层序/性质
- 难度锚点: medium难度对应节点数6-10，树高度3-5，子问题2-3个
- 典型陷阱: 混淆前序和中序的根节点定位规则、递归划分边界错误、统计性质时漏数或重复计数
