## examination_form
- 考察形式：多步串行推演（主） + 单点计算（辅）
- 设问方向：给定前序和中序遍历序列，要求递归还原二叉树结构（q1），再基于还原结果依次计算后序序列（q2）和树性质统计（q3），子问串行依赖

## k_radar
- K1（基础认知）: 3
- K2（单步代入）: 3
- K3（机制推演）: 2
- K4（条件路由）: 3
- K5（跨域联动）: 3
- 形状主导维度：混合（K1/K2/K4/K5 均衡为 3，K3 较低为 2）

## rationale
- 二叉树遍历序列还原本质是递归推理过程（前序定根→中序划分→递归子树），属于多步串行推演；但 K3=2 表明推理链条中等长度（节点数 6-10，递归深度有限），非深度推演
- q2（后序序列）和 q3（性质统计）依赖 q1 还原结果，形成串行依赖链；q2/q3 本身为单步计算/统计，对应 K2=3 的单点计算特征
- 与目标 K-雷达对齐：混合形状（无单一主导）对应"多步串行推演 + 单点计算"的混合形式，K3 较低反映递归深度适中而非复杂机制推演
