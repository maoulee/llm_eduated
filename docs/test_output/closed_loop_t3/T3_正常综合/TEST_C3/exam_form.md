## examination_form
- 考察形式：多步串行推演（主）+ 陷阱辨析（辅）
- 设问方向：给定插入序列，要求学生从空树开始完整模拟 AVL 插入过程（多步串行推演），并在每次失衡时精准辨析四种旋转类型的触发条件（陷阱辨析），最终判断插入完成后树的某个结构属性

## k_radar
- K1（基础认知）: 3
- K2（单步代入）: 2
- K3（机制推演）: 4
- K4（条件路由）: 4
- K5（跨域联动）: 1
- 形状主导维度：K3+K4（双主导，平衡型）

## rationale
- AVL 树插入是典型的多步串行推演流程（插入→更新BF→定位失衡→判断旋转类型→执行旋转→验证平衡），6-10个节点插入需>5步且需维持动态状态，故 K3=4；同时四种旋转类型（LL/RR/LR/RL）的触发条件存在易混淆点（如 LR 型需先左旋子节点再右旋失衡节点、失衡节点是祖父而非父节点），需识别隐含前提才能正确路由，故 K4=4
- 与目标 K-雷达（K3-K4平衡型）完全对齐：K3 考查"能否走完完整推演流程"，K4 考查"能否在关键路由点做出正确判断"，两者共同区分"能完整模拟并精准辨析的学生"与"只记旋转名称但无法动态应用的学生"
