## 求解过程

### 子问题(1)：插入35后（旋转前）的树形态、最小不平衡子树、平衡因子与调整类型

**插入35后的二叉排序树（旋转前）**：

```
         50
        /  \
       30   60
      /  \
     20  40
        /
       35
```

35 < 50 → 进入左子树；35 > 30 → 进入右子树；35 < 40 → 成为40的左孩子。

**高度计算**：
- 叶子节点 20、35、60 的高度均为 1
- 节点 40：h = max(h(35), h(空)) + 1 = max(1, 0) + 1 = 2
- 节点 30：h = max(h(20), h(40)) + 1 = max(1, 2) + 1 = 3
- 节点 50：h = max(h(30), h(60)) + 1 = max(3, 1) + 1 = 4

**最小不平衡子树根节点：50**

- BF(50) = h(左子树=30) − h(右子树=60) = 3 − 1 = **2**，|BF| = 2 > 1，失衡。
- 从插入点35回溯路径为 35→40→30→50，50是第一个失衡节点。

**左孩子的平衡因子**：
- BF(30) = h(左子树=20) − h(右子树=40) = 1 − 2 = **−1**

**平衡调整类型判断**：
- 失衡节点 50 的 BF = 2 > 0（左子树偏重）
- 左孩子 30 的 BF = −1 < 0（右子树偏重）
- 根偏左、左孩子偏右 → **LR型**

### 子问题(2)：LR平衡调整步骤与调整后的AVL树

LR型调整分两步：先对左孩子左旋，再对失衡节点右旋。

**第一步旋转：以节点30为轴左旋**

旋转前30的右孩子是40，40的左孩子是35。左旋30后：40上升为父，30下沉为40的左孩子，35变为30的右孩子。

```
         50
        /  \
       40   60
      /
     30
    /  \
   20  35
```

- 旋转轴节点：**30**
- 旋转方向：**左旋**

**第二步旋转：以节点50为轴右旋**

50的左孩子是40，40的右孩子为空。右旋50后：40上升为根，50下沉为40的右孩子，40原右子树（空）变为50的左子树。

```
         40
        /  \
       30   50
      /  \    \
     20  35   60
```

- 旋转轴节点：**50**
- 旋转方向：**右旋**

**调整后各节点平衡因子验证**：
- BF(20) = 0，BF(35) = 0，BF(30) = 1 − 1 = 0
- BF(60) = 0，BF(50) = 0 − 1 = −1，BF(40) = 2 − 2 = 0
- 所有 |BF| ≤ 1，树已平衡。✓

### 子问题(3)：插入55后的判断与调整

**在(2)的AVL树基础上插入55**：

```
         40
        /  \
       30   50
      /  \    \
     20  35   60
             /
            55
```

55 > 40 → 右子树；55 > 50 → 右子树；55 < 60 → 成为60的左孩子。

**高度计算**：
- 叶子节点 20、35、55 的高度均为 1
- 节点 60：h = max(h(55), h(空)) + 1 = max(1, 0) + 1 = 2
- 节点 50：h = max(h(空), h(60)) + 1 = max(0, 2) + 1 = 3
- 节点 30：h = max(h(20), h(35)) + 1 = 2
- 节点 40：h = max(h(30), h(50)) + 1 = max(2, 3) + 1 = 4

**是否失衡：是。**

从插入点55回溯路径为 55→60→50→40：
- BF(60) = h(55) − h(空) = 1 − 0 = 1，|BF| = 1，未失衡。
- BF(50) = h(空) − h(60) = 0 − 2 = **−2**，|BF| = 2 > 1，**失衡**。

**最小不平衡子树根节点：50**

**平衡调整类型判断**：
- 失衡节点 50 的 BF = −2 < 0（右子树偏重）
- 右孩子 60 的 BF = 1 > 0（左子树偏重）
- 根偏右、右孩子偏左 → **RL型**

**RL调整步骤**（先以右孩子为轴右旋，再以根为轴左旋）：

**第一步旋转：以节点60为轴右旋**

60的左孩子是55，55的右孩子为空。右旋60后：55上升为50的右孩子，60下沉为55的右孩子。

```
         40
        /  \
       30   50
      /  \    \
     20  35   55
                \
                 60
```

- 旋转轴节点：**60**
- 旋转方向：**右旋**

**第二步旋转：以节点50为轴左旋**

50的右孩子是55，55的左孩子为空。左旋50后：55上升为40的右孩子，50下沉为55的左孩子。

```
         40
        /  \
       30   55
      /  \  /  \
     20 35 50  60
```

- 旋转轴节点：**50**
- 旋转方向：**左旋**

**最终AVL树各节点平衡因子验证**：
- BF(20) = 0，BF(35) = 0，BF(30) = 0
- BF(50) = 0，BF(60) = 0，BF(55) = 0
- BF(40) = 2 − 2 = 0
- 所有 |BF| ≤ 1，树已平衡。✓

## 最终答案

- **(1)** 插入35后（旋转前），最小不平衡子树根节点为 **50**，BF(50) = **2**，BF(30) = **−1**，调整类型为 **LR型**。
- **(2)** LR调整：
  - 第一步：以 **30** 为轴 **左旋**（40上浮，30下沉）
  - 第二步：以 **50** 为轴 **右旋**（40上浮为根，50下沉为右孩子）
  - 调整后AVL树根为 **40**，左子树 {30, 20, 35}，右子树 {50, 60}。
- **(3)** 插入55后 **失衡**，最小不平衡子树根为 **50**，调整类型为 **RL型**：
  - 第一步：以 **60** 为轴 **右旋**（55上浮，60下沉）
  - 第二步：以 **50** 为轴 **左旋**（55上浮，50下沉为左孩子）
  - 最终AVL树根为 **40**，左子树 {30, 20, 35}，右子树以 **55** 为根，55的左右孩子分别为 50 和 60。
