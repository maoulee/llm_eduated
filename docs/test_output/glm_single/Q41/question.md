# Q41 综合应用题（10分）

## 题目

某棵平衡二叉树（AVL树）T的初始形态如下所示，节点内数字为关键字：

```
         50
        /  \
       30   60
      /  \
     20  40
```

约定：空子树高度为0，叶子节点高度为1，节点高度等于其左右子树高度的最大值加1；平衡因子定义为左子树高度减去右子树高度。当某节点平衡因子的绝对值大于1时，该节点为失衡节点，以该节点为根的子树称为最小不平衡子树（从插入点向根回溯时遇到的第一个失衡节点对应的子树）。

现依次向T中插入关键字35和55（先插入35，待平衡调整完成后再插入55）。请回答下列问题：

### （1）（3分）

将关键字35插入初始AVL树T后（旋转调整前），画出此时的二叉排序树形态。指出最小不平衡子树的根节点，计算该节点及其左孩子的平衡因子，并判断应进行的平衡调整类型（LL、RR、LR或RL）。

### （2）（4分）

对（1）中找到的最小不平衡子树执行平衡调整。说明调整过程中每一步旋转操作的旋转轴节点和旋转方向（左旋或右旋），并画出调整后的AVL树。

### （3）（3分）

在（2）得到的AVL树基础上，继续插入关键字55。判断此次插入是否导致失衡。若失衡，指出最小不平衡子树的根节点和平衡调整类型，写出旋转操作步骤，并画出最终的AVL树。

### 知识点选取理由
本题考察AVL树的插入与平衡调整机制，核心知识点包括：
1. 平衡因子计算与失衡判定（K1=3，需准确记忆BF定义）
2. 四种旋转类型（LL/RR/LR/RL）的触发条件辨析（K4=3，需辨析左孩子/右孩子的BF符号与旋转类型的对应关系）
3. 双旋操作的具体步骤（先旋后旋的顺序、旋转轴的选择）
4. BST性质在旋转过程中的保持（中序遍历不变性）

选择LR型和RL型（而非LL/RR单旋）的原因：双旋涉及两步操作，考察学生对旋转过程的完整理解，而非简单的单步变换，区分度更高。

### 参数选择理由
- **初始树5个节点**：规模适中，足以展示完整的AVL调整过程，又不至于过于繁杂
- **关键字均为整数且有序插入**：参数友好，便于心算高度和平衡因子
- **初始树中50的BF=1（边缘状态）**：精心设计使得插入35后50的BF恰好变为2，触发失衡
- **LR旋转后50的BF=-1（边缘状态）**：使得插入55后50的BF恰好变为-2，再次触发失衡
- **两次插入分别触发LR和RL**：覆盖两种双旋类型，最大化考察覆盖面

### 与契约 K 值的对齐说明

| K维度 | 目标 | 实际 | 说明 |

| K1 基础认知 | 3 | 3 | 需准确记忆BF定义、失衡判定阈值、四种旋转类型名称 |
