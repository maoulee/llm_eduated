## 第 7 题

**题干**：CPU 响应中断请求需要满足一定的条件和时机。关于中断响应的过程与时机，下列说法正确的是：

A. CPU 在任何时刻都可以立即响应可屏蔽中断请求，不需要等待当前指令执行完毕
B. CPU 在每条指令执行结束时检测中断请求信号，当满足响应条件（中断允许触发器为 1 且有中断请求）时，在当前指令执行完毕后进入中断响应周期
C. CPU 响应中断后，硬件自动完成的工作仅包括将中断服务程序入口地址送入 PC，保存断点（PC 和 PSW）由软件完成
D. 中断响应过程中，保护现场（保存各通用寄存器内容）由硬件自动完成，无需软件参与

---

## 第 7 题解析

**答案**：B
**解析**：CPU 在每条指令执行完毕时检测中断请求信号，当中断允许（中断允许触发器 IF=1）且有中断请求时，才在当前指令结束后进入中断响应周期，B 正确。A 错误，CPU 不能在任意时刻打断指令执行，必须等当前指令执行完毕；C 错误，硬件自动完成的是"关中断、保存断点（PC 和 PSW）到特殊寄存器或栈、将中断服务程序入口地址送入 PC"，但并非所有体系结构都自动将返回地址压栈，这取决于具体实现；D 错误，保护现场（保存通用寄存器内容）通常由中断服务程序中的软件指令完成，硬件一般只负责保存断点（PC/PSW）。
