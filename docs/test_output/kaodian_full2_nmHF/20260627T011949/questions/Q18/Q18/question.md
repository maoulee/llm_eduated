# 综合题：指令格式分析与寻址方式有效地址推导（6分）

## 题干

某计算机主存按字节编址，机器字长 16 位，采用单字长（16 位）定长指令格式。指令格式如下：

```
  15    12 11    9  8        0
┌────────┬───────┬────────────┐
│   OP   │   M   │     D      │
├────────┴───────┴────────────┤
│  操作码 │寻址特征│  形式地址   │
└──────────────────────────────┘
```

其中：
- **OP**：操作码字段，定义指令操作类型，该机指令系统共 12 条指令。
- **M**：寻址特征字段，用于区分不同寻址方式。
- **D**：形式地址字段，无符号整数。

该机支持以下 **6 种寻址方式**，其编码如下：

| M 编码 | 寻址方式 | 说明 |
|--------|---------|------|
| 000 | 立即寻址 | D 本身即为操作数 |
| 001 | 直接寻址 | EA = D |
| 010 | 间接寻址 | EA = (D)，即 D 所指内存单元的内容为有效地址 |
| 011 | 变址寻址 | EA = (IX) + D，IX 为变址寄存器 |
| 100 | 基址寻址 | EA = (BR) + D，BR 为基址寄存器 |
| 101 | 相对寻址 | EA = (PC) + D |

执行某条指令时，各寄存器和内存的当前值如下：

| 名称 | 值 | 说明 |
|------|------|------|
| 形式地址 D | 0C0H | 本条指令中的形式地址字段值 |
| 变址寄存器 IX | 2000H | |
| 基址寄存器 BR | 3800H | |
| 程序计数器 PC | 1F02H | **取指后** PC 的值（即指向下一条指令的地址） |
| 内存单元（00C0H）= | 0400H | 地址 00C0H 处的内容 |

> **注意**：相对寻址中 PC 的取值为取指后的值（即当前指令地址 + 指令字长所占字节数），题干已明确给出。

## 子问题

### SQ1（2分）

（1）根据指令格式和指令系统规模，确定各字段 **OP、M、D** 的位数。（1分）

（2）在该指令格式下，采用直接寻址时，操作数的寻址范围是多少？（以十进制和十六进制表示）（1分）

### SQ2（3分）

对于上述给定的参数值，分别推导 6 种寻址方式下的**有效地址 EA 的表达式和数值**，将结果填入下表：

| 寻址方式 | EA 表达式 | EA 值（十六进制） |
|---------|----------|----------------|
| 立即寻址 | | |
| 直接寻址 | | |
| 间接寻址 | | |
| 变址寻址 | | |
| 基址寻址 | | |
| 相对寻址 | | |

> 要求：表达式须写出运算规则（如 EA = (IX) + D），数值须给出最终十六进制结果。

### SQ3（1分）

简述**变址寻址**与**基址寻址**在用途上的本质区别。（1分）

## 设计意图

- **SQ1**：考察学生对指令格式的分析能力——由指令条数推 OP 位数，由寻址方式数推 M 位数，剩余位推 D 位数，并据此推算直接寻址范围。（K1=3 记忆定义 + K2=3 常规计算）
- **SQ2**：核心问——对 6 种寻址方式逐一按规则推导有效地址表达式及数值，考察每种寻址方式的定义理解和代入计算。间接寻址需额外访存读取内存单元内容作为有效地址；相对寻址需正确理解 PC 取值。（K3=3 多步推导 + K4=2 注意点：间接访存、PC 取值）
- **SQ3**：提炼两种偏移寻址的语义差异——变址面向数组/循环（用户可控、D 不变改变址值），基址面向多道程序/地址重定位（OS 控制基址、扩大寻址空间）。（K1=3 概念辨析）

## 场景规则（通过条件）

本题成立需要满足以下**参数间约束**（与具体答案值无关，换参数仍成立），供 gen.py exec 用 assert 验证：

1. **字段位宽约束**：OP 位数 + M 位数 + D 位数 == 指令字长（16 位）。OP 位数 >= ceil(log2(指令条数))，M 位数 >= ceil(log2(寻址方式数))。
2. **直接寻址范围约束**：直接寻址范围 == [0, 2^(D 位数) - 1]。
3. **形式地址合法约束**：D 的值 < 2^(D 位数)，即 D 在形式地址字段的表示范围内。
4. **间接寻址单元可达约束**：间接寻址所引用的内存单元地址（即 D 的值）必须落在直接寻址范围内（D < 2^(D 位数)），保证该单元地址可被直接表示。
5. **各寻址方式 EA 互异约束**：直接、间接、变址、基址、相对五种寻址方式的有效地址值各不相同（立即寻址的 D 不产生地址，不参与比较）。
6. **相对寻址 PC 取值约束**：相对寻址 EA == 取指后 PC 值 + D，题干已明确 PC 为取指后的值。

> **说明**：以上规则均为参数间约束（字段位宽关系、地址范围关系、互异性），不含具体答案值。gen.py 负责代入参数计算各 EA 值并用 assert 验证上述约束全部成立。
