## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 指令系统 > 寻址
- primary_target_name: 寻址方式有效地址推导（填表文字）
- question_type: comprehensive
- examination_mode: 综合题——给定指令格式(I/X/D)，推导各寻址方式有效地址表达式（文字表格，不画图）

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: K3 主导——需对 5-6 种寻址方式逐一按规则推导有效地址（每方式 3-5 步）；K1=3 需准确记忆各寻址方式定义；K2=3 需常规代入计算；K4=2 存在常规注意点（间接访存、PC 取值）；K5=1 单知识点内部解决

### 结构要求
- sub_question_count: 3
- sub_question_layout:
  - SQ1 (2分): 分析指令格式，确定字段位数及直接寻址范围
  - SQ2 (3分): 填表推导 ≥5 种寻址方式的有效地址表达式及数值（核心问）
  - SQ3 (1分): 简述两种寻址方式的本质区别
- total_score: 6
- dependency: SQ1 独立 → SQ2 依赖 SQ1 字段理解 → SQ3 基于 SQ2 结果提炼
- condition_count: 4-5

### 参数约束
- 指令字长: 16 或 32 位，二选一
- 操作码字段: 4-8 位，与指令字长协调
- 寻址特征字段: 3-4 位，支持 ≥5 种寻址方式编码
- 形式地址 D: 剩余位数，取值非边界（非全0非全1）
- PC 值: 十六进制，与 D 相加结果合法且与其他寻址 EA 不同
- 变址/基址寄存器值: 十六进制，与 D 相加结果不同于直接寻址 EA
- 内存单元内容: 间接寻址引用单元的内容为有效地址，与其他寻址 EA 不同
- 一致性约束:
  - 所有寻址方式 EA 结果互不相同
  - 间接寻址内存单元地址在直接寻址范围内
  - 所有地址值合法
  - 相对寻址 PC 取值须题干指明（当前指令 or 下条指令）
- 可调自由度: 具体位数值、寄存器值、内存内容均由 Question Agent 选定

### 参考经验摘要
- 历史模式: 指令格式分析 → 字段划分 → 多寻址方式 EA 推导（标准路径）
- 难度锚点: K3=3 主导，K1=3 辅助，整体 3
- 典型陷阱:
  - 间接寻址需额外访存读取有效地址
  - 相对寻址 PC 取值歧义（当前指令 vs 下条指令）
  - 变址寄存器 vs 基址寄存器语义差异
- 表达要求: 学生须写出 EA 表达式（如 EA=(IX)+D），非仅数值
