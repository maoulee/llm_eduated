## 题目

某计算机主存按字节编址，机器字长 16 位，采用单字长（16 位）定长指令格式。指令格式如下：

```
  15    12 11    9  8        0
┌────────┬───────┬────────────┐
│   OP   │   M   │     D      │
├────────┴───────┴────────────┤
│  操作码 │寻址特征│  形式地址   │
└──────────────────────────────┘
```

其中：
- **OP**：操作码字段，定义指令操作类型，该机指令系统共 12 条指令。
- **M**：寻址特征字段，用于区分不同寻址方式。
- **D**：形式地址字段，无符号整数。

该机支持以下 **6 种寻址方式**，其编码如下：

| M 编码 | 寻址方式 | 说明 |
|--------|---------|------|
| 000 | 立即寻址 | D 本身即为操作数 |
| 001 | 直接寻址 | EA = D |
| 010 | 间接寻址 | EA = (D)，即 D 所指内存单元的内容为有效地址 |
| 011 | 变址寻址 | EA = (IX) + D，IX 为变址寄存器 |
| 100 | 基址寻址 | EA = (BR) + D，BR 为基址寄存器 |
| 101 | 相对寻址 | EA = (PC) + D |

执行某条指令时，各寄存器和内存的当前值如下：

| 名称 | 值 | 说明 |
|------|------|------|
| 形式地址 D | 0C0H | 本条指令中的形式地址字段值 |
| 变址寄存器 IX | 2000H | |
| 基址寄存器 BR | 3800H | |
| 程序计数器 PC | 1F02H | **取指后** PC 的值（即指向下一条指令的地址） |
| 内存单元（00C0H）= | 0400H | 地址 00C0H 处的内容 |

> **注意**：相对寻址中 PC 的取值为取指后的值（即当前指令地址 + 指令字长所占字节数），题干已明确给出。

### SQ1（2分）

（1）根据指令格式和指令系统规模，确定各字段 **OP、M、D** 的位数。（1分）

（2）在该指令格式下，采用直接寻址时，操作数的寻址范围是多少？（以十进制和十六进制表示）（1分）

### SQ2（3分）

对于上述给定的参数值，分别推导 6 种寻址方式下的**有效地址 EA 的表达式和数值**，将结果填入下表：

| 寻址方式 | EA 表达式 | EA 值（十六进制） |
|---------|----------|----------------|
| 立即寻址 | | |
| 直接寻址 | | |
| 间接寻址 | | |
| 变址寻址 | | |
| 基址寻址 | | |
| 相对寻址 | | |

> 要求：表达式须写出运算规则（如 EA = (IX) + D），数值须给出最终十六进制结果。

### SQ3（1分）

简述**变址寻址**与**基址寻址**在用途上的本质区别。（1分）

## 参考答案

**SQ1**

（1）OP = **4 位**，M = **3 位**，D = **9 位**。

（2）直接寻址范围：**0 ~ 511**（十进制），即 **000H ~ 1FFH**（十六进制）。

**SQ2**

| 寻址方式 | EA 表达式 | EA 值（十六进制） |
|---------|----------|:---------:|
| 立即寻址 | D 本身即为操作数，无有效地址 | — |
| 直接寻址 | EA = D | **00C0H** |
| 间接寻址 | EA = (D) | **0400H** |
| 变址寻址 | EA = (IX) + D | **20C0H** |
| 基址寻址 | EA = (BR) + D | **38C0H** |
| 相对寻址 | EA = (PC) + D | **1FC2H** |

**SQ3**

变址寻址中变址寄存器由**用户/程序员**控制，面向**数组遍历、循环**等数据结构遍历（D 固定，不断修改变址寄存器值）；基址寻址中基址寄存器由**操作系统**控制，面向**多道程序的地址重定位**（OS 通过修改基址实现程序在内存中的浮动）。

## 解析

### SQ1（2分）字段位数与直接寻址范围

**（1）OP、M、D 位数确定**

| 字段 | 推导 | 位数 |
|------|------|------|
| OP（操作码） | 该机共 12 条指令，需 ⌈log₂12⌉ = 4 位编码 | **4 位** |
| M（寻址特征） | 支持 6 种寻址方式，需 ⌈log₂6⌉ = 3 位编码 | **3 位** |
| D（形式地址） | 剩余位数 = 16 − 4 − 3 | **9 位** |

验证：OP + M + D = 4 + 3 + 9 = **16 位**（= 指令字长）。

**（2）直接寻址范围**

直接寻址时 EA = D，D 为 9 位无符号整数，因此寻址范围为 0 ~ 2⁹ − 1：

- **十进制**：0 ~ 511
- **十六进制**：000H ~ 1FFH

### SQ2（3分）6 种寻址方式有效地址

给定参数值：D = 0C0H，IX = 2000H，BR = 3800H，PC = 1F02H（取指后），内存单元 (00C0H) = 0400H。

| 寻址方式 | EA 表达式 | 计算过程 | EA 值（十六进制） |
|---------|----------|---------|:---------:|
| 立即寻址 | D 本身即为操作数，无有效地址 | — | — |
| 直接寻址 | EA = D | 0C0H | **00C0H** |
| 间接寻址 | EA = (D)，即 D 所指单元内容 | (00C0H) = 0400H | **0400H** |
| 变址寻址 | EA = (IX) + D | 2000H + 0C0H = 20C0H | **20C0H** |
| 基址寻址 | EA = (BR) + D | 3800H + 0C0H = 38C0H | **38C0H** |
| 相对寻址 | EA = (PC) + D | 1F02H + 0C0H = 1FC2H | **1FC2H** |

**关键说明**：

- **间接寻址**：需额外访存，以 D 的值（00C0H）作为地址读取内存单元，内容为 0400H，即为有效地址。
- **相对寻址**：PC 为**取指后**的值（1F02H，即指向下一条指令），EA = 1F02H + 0C0H = 1FC2H。

### SQ3（1分）变址寻址与基址寻址的本质区别

| 维度 | 变址寻址 | 基址寻址 |
|------|---------|---------|
| **可控方** | 由**用户/程序员**控制 IX 值 | 由**操作系统**控制 BR 值 |
| **典型用途** | 面向**数组遍历、循环**：D 固定为数组首地址偏移，不断改变 IX 遍历元素 | 面向**多道程序、地址重定位**：OS 通过修改基址实现程序在内存中的浮动 |
| **本质** | D 不变，通过修改变址寄存器 IX 扩展访问范围 | BR 不变（由 OS 设定），D 作为段内偏移 |
| **寻址空间** | 扩大数组的可访问范围 | 扩大物理寻址空间，实现程序重定位 |
