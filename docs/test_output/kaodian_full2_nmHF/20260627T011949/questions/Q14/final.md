## 第 8 题

**题干**：DMA 方式用于高速外设与主存之间的大批量数据传送。关于 DMA 的数据通路与周期挪用（周期窃取），下列说法正确的是：

A. DMA 数据传送过程中，数据需要经过 CPU 的寄存器进行中转
B. 周期挪用是指 DMA 控制器在 CPU 不使用总线时占用一个或多个存储周期进行数据传送，此时 CPU 可能需要暂停一个机器周期
C. DMA 方式完全不占用系统总线，因此对 CPU 的执行效率没有任何影响
D. 在 DMA 传送期间，CPU 始终处于空闲状态，无法执行任何指令

---

## 第 8 题解析

**答案**：B
**解析**：周期挪用（周期窃取）是指 DMA 控制器在 CPU 不占用总线的存储周期（或机器周期）时，挪用一个总线周期进行数据传送，此时如果 CPU 也需要访存则需暂停一个周期，B 正确。A 错误，DMA 的核心特征就是数据直接在外设与主存之间传送，不经过 CPU 寄存器中转；C 错误，DMA 虽然不经过 CPU，但占用总线进行传送，当与 CPU 争用总线时会影响 CPU 效率；D 错误，周期挪用方式下 CPU 仅在争用总线时暂停一个周期，并非始终空闲。
