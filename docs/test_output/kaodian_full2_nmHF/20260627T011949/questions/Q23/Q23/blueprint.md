## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 中央处理器 > 微程序控制器
- primary_target_name: 水平型微指令格式设计与控存容量
- question_type: comprehensive
- examination_mode: 设计题——给微命令互斥类，设计水平型编码微指令格式（字段+位数）并算控存最大容量

### 难度目标
- k_target: K1=4,K2=3,K3=3,K4=4,K5=2
- difficulty_level: 4
- difficulty_rationale: K4主导——学生必须自行识别"每字段预留不操作码""地址位数由微指令条数决定""顺序控制字段不可遗漏"三个隐含前提，这些条件题面不直接给出。K1=4因需辨析字段直接编码与直接编码的差异。整体为标准偏难的微程序控制器设计题。

### 结构要求
- sub_question_count: 3
- sub_question_design:
  - 第1问(5分): 分析互斥类→设计各操作控制字段及位数（需写出位数计算依据）
  - 第2问(3分): 确定微指令字长→计算控存最大容量（依赖第1问结果）
  - 第3问(2分): 概念辨析（字段直接编码优缺点或预留码原因）
- distractor_strategy: 不适用（设计题无选项，区分度体现在学生设计步骤的正确性）
- condition_count: 3-4个显式条件（微命令互斥类表、编码方式、微指令条数、顺序控制方式）

### 参数约束
- 微命令总数: 18~28个，可形成4~6个互斥类
- 各互斥类微命令数: 每组3~7个，至少2个类别的位数不同（保证区分度）
- 微指令总条数: 对应地址位数6~10位（即64~1024条范围）
- 顺序控制方式: 下址法（下址字段位数=地址位数），可附加1~2位判别测试位
- 一致性约束: 操作控制字段总位数=各互斥类字段位数之和；每字段位数=⌈log₂(组内微命令数+1)⌉；控存容量=微指令条数×微指令字长
- 相容微命令: 存在若干对相容微命令，必须分属不同字段（作为判断陷阱）

### 参考经验摘要
- 历史模式: "互斥关系→格式设计→容量计算"三步走，408微程序控制器经典设计题套路
- 难度锚点: K4通常3-4，核心陷阱为预留不操作码和地址位数来源
- 典型陷阱:
  1. 字段位数漏算+1（不操作码）——最高频错误
  2. 控存地址位数误用微命令数计算
  3. 遗漏顺序控制字段位数
  4. 相容微命令误放入同一字段
