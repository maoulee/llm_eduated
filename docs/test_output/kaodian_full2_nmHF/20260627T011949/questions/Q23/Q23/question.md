# 水平型微指令格式设计与控存容量计算

## 题目

某模型机采用微程序控制器，使用水平型微指令，微指令采用**字段直接编码**方式。已知该机共有 **22 个微命令**，经分析可归为 **5 个互斥类**（同类内的微命令互斥，不同类间的微命令可同时出现），各类包含的微命令如下：

| 互斥类 | 包含微命令 | 微命令数 |
|--------|-----------|---------|
| 第一类（数据通路控制） | PC→MAR、DR→IR、PC+1、AC→DR、Rtemp←ALU | 5 |
| 第二类（ALU 运算控制） | ADD、SUB、AND、OR、NOT、XOR、SHL | 7 |
| 第三类（存储器控制） | READ、WRITE、WAIT | 3 |
| 第四类（寄存器读写控制） | R0←、R0→、R1←、R1→ | 4 |
| 第五类（状态标志控制） | SETC、CLRC、SETV | 3 |

已知条件：
- 采用**字段直接编码**，每个互斥类对应一个操作控制字段。
- 控存中共存放 **256 条**微指令，采用**下址法**进行顺序控制，并设 **2 位**判别测试标志位（P 字段）。
- 其中，"PC→MAR"与"READ"为一对相容微命令（需同时有效），"ADD"与"R0←"亦为一对相容微命令。

请回答以下问题：

### 第 1 问（5 分）

设计该水平型微指令的**操作控制字段**格式：列出每个互斥类对应的操作控制字段名称、所需的二进制位数，并写出每位数的计算依据。

### 第 2 问（3 分）

确定该微指令的**字长**（总位数），并计算**控存的最大容量**（以位为单位）。要求写出字长各组成部分的计算过程。

### 第 3 问（2 分）

简述字段直接编码方式中，每个字段为何需要**预留一个不操作码**（000 或全 0 码）。若某互斥类有 7 个微命令但仅用 3 位编码、不预留不操作码，会带来什么问题？

---

## 通过条件（场景规则）

本题成立需满足以下参数间约束（与具体答案值无关，换参数仍成立）：

1. **每字段位数 = ⌈log₂(组内微命令数 + 1)⌉**：组内微命令数 + 1（不操作码）后向上取整为该字段二进制位数。
2. **操作控制字段总位数 = 各互斥类字段位数之和**：操作控制部分不能遗漏任何互斥类字段，也不能多算。
3. **下址字段位数 = ⌈log₂(微指令总条数)⌉**：下址字段宽度由控存中微指令条数决定，与微命令数无关。
4. **微指令字长 = 操作控制字段总位数 + 判别测试位数 + 下址字段位数**：三部分缺一不可，遗漏顺序控制字段为常见错误。
5. **控存最大容量 = 微指令条数 × 微指令字长**（单位：位）。
6. **相容微命令必须分属不同字段**：题中给定的相容微命令对（PC→MAR 与 READ；ADD 与 R0←）分属不同互斥类，验证了分组方案的合理性。
