## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 数据表示与运算 > 加法器
- primary_target_name: 先行进位加法器进位表达式文字推导
- question_type: comprehensive
- examination_mode: 综合题——写出先行进位加法器各级进位生成/传递函数与进位表达式（文字推导，不画电路图）

### 难度目标
- k_target: K1=3,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 4
- difficulty_rationale: K3=4 为核心维度，需多步逐级展开进位表达式（C₁→C₂→C₃→C₄），步数 >5 且需维持符号一致性；K1=3 需准确记忆 G_i、P_i 定义及进位递推公式；其余维度偏低，题目聚焦单一知识点的推演深度。

### 结构要求
- sub_question_count: 3
- sub_question_breakdown:
  - 第1问（2分）: 写出 G_i、P_i 定义及进位递推公式
  - 第2问（3分）: 逐级展开写出 C₁、C₂、C₃ 的先行进位表达式
  - 第3问（1分）: 简要说明先行进位的延迟优势
- sub_question_dependency: 串行递进（第2问依赖第1问，第3问独立）
- condition_count: 2-3
- distractor_strategy: 不适用（简答题，无选项）

### 参数约束
- 加法器位宽 n: 取值范围 3-4 位，建议 4 位，n ≥ 3 以保证展开步数充足
- P_i 定义约定: P_i = A_i ⊕ B_i 或 P_i = A_i + B_i，题干须明确约定其一，不给定值
- C₀: 可保留符号 C₀ 或赋值 0/1，由出题者决定
- 展开深度: 至少展开到 C₃，可视位宽展开到 C₄

### 参考经验摘要
- 历史模式: 原卷为画四位快速加法器电路图填名称（电路结构记忆），替换为先行进位各级表达式文字推导（逻辑推导），知识深度等价
- 难度锚点: K3 为主维度（多步展开），整体难度 4/5
- 典型陷阱: P_i 定义版本混淆（异或 vs 或）；展开时符号代入遗漏或下标错位
