## 第 3 题

**题干**：某计算机的 Cache 采用直接映射方式，主存块大小为 64B，Cache 共有 128 行。若某主存地址所在主存块号恰好与其映射到的 Cache 行号相同，则关于该访问的命中率，下列分析正确的是：

A. 直接映射方式下，只要主存块号与 Cache 行号相同就一定能命中
B. 直接映射方式下，该块能否命中取决于对应 Cache 行中当前存放的是否为该主存块，且标记（Tag）是否匹配
C. 直接映射方式下命中率固定为 50%，与映射关系无关
D. 直接映射方式下，任何主存块都可以映射到任意 Cache 行，因此命中率与行号无关

---

## 第 3 题解析

**答案**：B
**解析**：直接映射方式下，每个主存块只能映射到固定的某一行（由主存块号 mod Cache 行数决定），但能否命中取决于该 Cache 行当前存放的内容是否为该主存块，即标记（Tag）是否匹配，B 正确。A 错误，块号与行号相同只是映射关系，不代表该行当前存的就是这个块；C 错误，命中率取决于访存模式与替换情况，不是固定值；D 错误，描述的是全相联映射的特征，不是直接映射。
