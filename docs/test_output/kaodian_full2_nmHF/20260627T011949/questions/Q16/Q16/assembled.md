## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 数据表示与运算 > IEEE754 / 补码
- primary_target_name: IEEE754 浮点加减运算步骤填空（对阶/规格化/舍入多空）
- question_type: comprehensive
- examination_mode: 填空题——给定两个 IEEE754 单精度数相加，补全对阶、尾数求和、规格化、就近偶数舍入步骤中的关键空

### 难度目标
- k_target: K1=3,K2=3,K3=4,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 主导维度K3=4，因IEEE754加法全流程步数>5且中间值严格串行传递；其余维度标准或偏低，整体难度定位3级。填空形式使每步可独立评分，降低蒙对概率。

### 结构要求
- sub_question_count: 10（10个填空，每空1分，合计10分）
- condition_count: 2（两个IEEE754单精度浮点数，以十六进制给出）
- blank_structure:
  - 空①: 两数阶码真值（各1分，共1分取两数阶码真值表达）
  - 空②: 阶码差ΔE及对阶方向
  - 空③: 对阶后小阶数尾数（含隐藏位恢复后右移结果）
  - 空④: 尾数求和原始结果
  - 空⑤: 规格化方向判断+规格化后尾数
  - 空⑥: 规格化后最终阶码真值
  - 空⑦: 舍入后尾数（就近偶数舍入）
  - 空⑧: 阶码溢出判断
  - 空⑨: 最终IEEE754十六进制表示
  - 空⑩: 最终结果十进制真值
- serial_dependency: 空①→②→③→④→⑤→⑥→⑦→⑧→⑨→⑩，严格串行

### 参数约束
- 操作数A: 合法IEEE754单精度浮点数（非0/非NaN/非Inf），以8位十六进制给出
- 操作数B: 合法IEEE754单精度浮点数（非0/非NaN/非Inf），以8位十六进制给出
- 阶码差约束: |ΔE| ≥ 2（保证对阶右移有实质内容，移出有效位）
- 规格化触发: 尾数求和后必须产生需要左规或右规的非规格化结果
- 舍入触发: 对阶右移必须有被移出的有效位，舍入步骤非平凡
- 阶码范围: 最终结果阶码真值 ∈ [-126, 127]（正常数范围，无溢出）
- 数值友好度: 十六进制编码便于人工处理（避免过多连续1或0的特殊数）

### 参考经验摘要
- 历史模式: IEEE754浮点运算以"给定编码→逐步运算→写结果"为标准考法，填空可精确覆盖每步
- 难度锚点: K3主导，目标4级（>5步流程+中间状态传递）
- 典型陷阱:
  1. 对阶方向错误（大阶向小阶看齐）
  2. 忘记恢复隐藏位1
  3. 规格化方向判断错误（该右规做了左规）
  4. 舍入用截断而非就近偶数
  5. 阶码写偏移值而非真值
