> **运算规则说明：**
> - 对阶原则：**小阶向大阶对齐**（小阶尾数右移，阶码递增），每次右移1位直至阶码相等。
> - 尾数求和：恢复隐藏位后，按原码加减规则对齐尾数。
> - 规格化：若尾数求和结果整数部分出现 `10.xxx`（即 ≥2），需**右规**（尾数右移1位，阶码加1）；若出现 `0.xxx`，需**左规**（尾数左移，阶码递减）。
> - 舍入方式：**就近舍入到偶数（Round-to-Nearest-Even）**，使用额外保护位（Guard、Round、Sticky）。
> - 阶码判断：阶码（移码）超出 [1, 254] 范围 → 上溢/下溢。

## 通过条件（场景规则——本题成立需满足的参数间约束）

> 以下约束与具体答案值无关，换参数仍成立，供 gen.py 翻译为 assert：

1. **合法性**：A 和 B 均为合法 IEEE754 单精度规格化浮点数（阶码字段 ∈ [1,254]，即非0/非NaN/非Inf）。
2. **阶码差**：|E_A − E_B| ≥ 2，即两数阶码真值之差的绝对值 ≥ 2（保证对阶右移至少2位，移出有效位）。
3. **对阶方向唯一**：阶码大的操作数不动，阶码小的操作数右移对齐——不存在两数阶码相等的情况。
4. **尾数求和触发规格化**：对阶后两尾数求和的整数部分必须为 `10`（二进制，即 ≥ 2）或 `0`（即 < 1），使求和结果处于非规格化状态，需要右规或左规。本题参数下预期为右规（整数部分 = 10）。
5. **舍入非平凡**：对阶右移后，被移出的位中至少保护位(G)=1 或 粘位(S)=1，使就近偶数舍入步骤可能改变尾数最低有效位（即舍入结果 ≠ 简单截断）。
6. **无溢出**：最终阶码真值 ∈ [−126, 127]（即移码值 ∈ [1, 254]），不发生上溢或下溢。
7. **隐藏位恢复**：运算过程中尾数必须恢复隐藏位1（即 1.f 形式），最终结果编码时隐藏位归位（不显式存储）。
8. **串行一致性**：空④（尾数求和原始结果）= 空③（对阶后尾数）参与运算的直接产物；空⑤（规格化后尾数）由空④经移位得到；空⑦（舍入后尾数）由空⑤经舍入得到；空⑨（最终编码）由空⑦尾数 + 空⑥阶码 + 符号位组装得到。各空间存在确定的数据流依赖，不允许跳跃。
