> - 对阶原则：**小阶向大阶对齐**（小阶尾数右移，阶码递增），每次右移1位直至阶码相等。

> - 阶码判断：阶码（移码）超出 [1, 254] 范围 → 上溢/下溢。

## 解析

### 操作数分解

| 操作数 | 十六进制 | 符号 | 阶码字段(移码) | 阶码真值 | 尾数字段(23位) |
|--------|----------|------|----------------|----------|----------------|
| A | 0x41E00000 | 0 | 131 | 4 | 11000000000000000000000 |
| B | 0x40FFFFFF | 0 | 129 | 2 | 11111111111111111111111 |

恢复隐藏位后：
- A 完整尾数（24位）= **1.11000000000000000000000** × 2⁴
- B 完整尾数（24位）= **1.11111111111111111111111** × 2²

---

### 第一步：分解操作数（空①）

阶码真值 = 阶码字段 − 127（偏置值）。

- **E_A = 131 − 127 = 4**
- **E_B = 129 − 127 = 2**

> **空①**：E_A = **4**，E_B = **2**

---

### 第二步：对阶（空②③）

阶码差 ΔE = |E_A − E_B| = |4 − 2| = **2**。

A 阶码大（4 > 2），故 B 的尾数右移对齐到 A 的阶码。

> **空②**：ΔE = **2**，对阶方向 = **将 B 右移对齐到 A**

B 尾数（含隐藏位，24位）= `111111111111111111111111`，右移 2 位：

- 被移出的 2 位均为 1，分别成为保护位(G)和舍入位(R)
- 右移后尾数主体（24位，高位补0）= `001111111111111111111111`

用保护位/舍入位/粘位标注（主体24位 + G/R/S）：

```
主体24位:  001111111111111111111111
保护位 G = 1   （移出位最高位）
舍入位 R = 1   （移出位次位）
粘位   S = 0   （无更多位移出）
```

> **空③**：对阶后 B 的尾数主体 = **`001111111111111111111111`**，标注 G=**1**, R=**1**, S=**0**

---

### 第三步：尾数求和（空④）

两尾数对齐后（均对齐到阶码 4，扩展 GRS 位），同号加法：

```
  A 尾数(扩展GRS, 27位):   111000000000000000000000000
  B对阶尾数(扩展GRS, 27位): 001111111111111111111111110
  ──────────────────────────────────────────────────────
  求和原始结果(28位):       1000111111111111111111111110
```

求和结果共 28 位，去掉末 3 位（GRS）的主体为：

```
主体(25位): 1000111111111111111111111   (整数部分 = 10₂ = 2)
```

> **空④**：求和原始结果（含GRS，28位）= **`1000111111111111111111111110`**
>
> 主体部分 = `1000111111111111111111111`（整数部分 10₂ = 2），GRS = `110`

---

### 第四步：规格化（空⑤⑥）

求和结果整数部分 = **10**（二进制，即值 = 2 ≥ 2），需要**右规**：尾数右移 1 位，阶码加 1。

右规前阶码 = 4 → 右规后阶码 = **5**。

右规操作：将含 GRS 的 28 位结果整体右移 1 位。原 GRS 最低位（S 位）移出，原 R 位成为新 S 位：

```
右规前(含GRS): 1000111111111111111111111 | 110
右规后(含GRS): 100011111111111111111111  | 111
   主体24位               | GRS
```

- 规格化后尾数主体（24位）= `100011111111111111111111`（即 1.00011111111111111111111）
- GRS = G=1, R=1, S=1

> **空⑤**：规格化方向 = **右规**，规格化后尾数 = **`1.00011111111111111111111`**（主体24位 `100011111111111111111111`，GRS=111）

> **空⑥**：规格化后阶码真值 = **5**

---

### 第五步：舍入（空⑦）

规格化后 GRS = G=1, R=1, S=1。

就近偶数舍入规则：
- **舍入位（round/G）= 1**
- **粘位（sticky = R|S）= 1|1 = 1**
- round=1 且 sticky=1 → **向上舍入（+1）**

保留部分（24位主体）= `100011111111111111111111`，最低位(LSB)=1，加 1：

```
  100011111111111111111111
+                        1
─────────────────────────
  100100000000000000000000
```

舍入后尾数 = `100100000000000000000000`（即 1.00100000000000000000000），未超过 24 位（无溢出进位）。

> **空⑦**：舍入后尾数 = **`1.00100000000000000000000`**（24位 `100100000000000000000000`），是否舍入进位导致溢出 = **否**

---

### 第六步：溢出判断与最终结果（空⑧⑨⑩）

最终阶码真值 = 5（舍入未导致阶码变化）。

最终阶码移码值 = 5 + 127 = **132**。

- 移码值 132 ∈ [1, 254] → **无溢出**。

封装 IEEE754 编码：
- 符号位 = 0（两正数相加）
- 阶码字段 = 132 = `10000100`
- 尾数字段（去隐藏位）= `00100000000000000000000`

```
0 | 10000100 | 00100000000000000000000
= 0100 0010 0001 0000 0000 0000 0000 0000
= 0x42100000
```

十进制真值：
- 尾数 = 1.001₂ = 1 + 2⁻³ = 1.125
- 值 = 1.125 × 2⁵ = 1.125 × 32 = **36**

> **空⑧**：最终移码 = **132**，溢出判断 = **无溢出**

> **空⑨**：IEEE754 编码 = **0x42100000**

> **空⑩**：十进制真值 = **36**（精确值，舍入后为 36.0）
