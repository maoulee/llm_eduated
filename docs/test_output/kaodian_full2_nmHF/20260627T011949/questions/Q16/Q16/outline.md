## 考点
- **核心考点：IEEE754 单精度浮点加减运算全流程**（对阶 → 尾数求和 → 规格化 → 就近偶数舍入 → 溢出判断）
  - 考察侧重点：对阶规则（小阶向大阶看齐）、尾数移位与隐藏位1的恢复、规格化方向判断（左规/右规）、就近偶数舍入（round-to-nearest-even）的具体执行
- **辅助考点：IEEE754 单精度格式结构**（符号位1位 + 阶码8位偏移127 + 尾数23位含隐藏位）
  - 考察侧重点：阶码真值与偏移值的换算、尾数隐藏位恢复

## 难度目标
- **K1=3（标准）**：必须准确记忆 IEEE754 单精度格式（1+8+23）、偏移量127、对阶方向规则、就近偶数舍入规则，模糊记忆无法完成填空。
- **K2=3（标准）**：尾数求和涉及非2幂次的具体数值加减，需执行常规二进制加减计算，数字非完全友好。
- **K3=4（较高）**：需完整走完"还原隐藏位→比较阶码→对阶移位→尾数求和→规格化判断→舍入→重组结果"流程，步数>5步，且需维持中间状态（对阶后尾数、求和后尾数、规格化后尾数逐级传递），中间错一步后续全错。
- **K4=2（较低）**：对阶方向"小阶向大阶看齐"、舍入用就近偶数而非截断，属于408考生应知的常规注意点，不存在深层隐含前提。
- **K5=1（微弱）**：单一知识点（浮点运算）内部解决，不跨子系统。

## 考察模式
**填空题——步骤逐步填空**。给定两个 IEEE754 单精度浮点数（以十六进制或二进制给出完整32位编码），要求学生补全运算过程中每一步的关键中间结果。此模式的依据：
- 直接对标教材中 IEEE754 浮点加减的标准流程演示
- 每一步的中间值唯一确定，便于客观评分
- 覆盖对阶、求和、规格化、舍入全部核心步骤，考察全面

## 出题要求
- **题型**：填空题（comprehensive 中的填空子形式）
- **总空格数**：8-10空，每空1分，合计10分
- **条件数**：2个 IEEE754 单精度浮点数（作为被加数和加数），以十六进制表示
- **纯文字步骤填空**：禁止要求作图，全部空格填具体数值或二进制/十六进制表达式
- **结果唯一性**：每空必须由 gen.py 算出确切值，无歧义

## 子问题规划
按 IEEE754 浮点加法标准流程组织空格，各空串行依赖：

| 空号 | 类型 | 考察目标 | 分值 | 依赖关系 |
|------|------|---------|------|---------|
| ① | 计算 | 两数的阶码真值（十进制） | 1分 | 无，从原始编码直接提取 |
| ② | 计算 | 阶码差（ΔE，含正负号）及对阶方向（谁向谁对齐） | 1分 | 依赖① |
| ③ | 计算 | 对阶后小阶数的尾数（含隐藏位恢复后右移ΔE位的结果） | 1分 | 依赖② |
| ④ | 计算 | 尾数求和的原始结果（含可能溢出的整数位） | 1分 | 依赖③ |
| ⑤ | 判断+计算 | 规格化方向判断（左规/右规/已规格化）及规格化后的尾数 | 1分 | 依赖④ |
| ⑥ | 计算 | 规格化后的最终阶码真值（十进制） | 1分 | 依赖⑤ |
| ⑦ | 计算 | 舍入后尾数（就近偶数舍入执行后的结果） | 1分 | 依赖⑤⑥，需判断是否有舍入位被截掉 |
| ⑧ | 判断 | 是否发生阶码溢出（上溢/下溢/无溢出） | 1分 | 依赖⑥⑦ |
| ⑨ | 转换 | 最终结果的 IEEE754 单精度十六进制表示 | 1分 | 依赖⑥⑦⑧ |
| ⑩ | 计算 | 最终结果对应的十进制真值 | 1分 | 依赖⑨ |

**注**：若步骤⑤无规格化操作（尾数求和结果已规格化），则空⑤改为填"无需规格化"，保持题目自洽。10空合计10分。

## 参数约束
- **两个操作数 A 和 B**：均为合法的 IEEE754 单精度浮点数（非0、非非数、非无穷）
  - A、B 均为正数或一正一负均可（由 Question Agent 决定），但尾数求和后必须触发实质性的运算过程
- **阶码差 ΔE 约束**：|ΔE| ≥ 2，保证对阶步骤有实质性的右移操作（而非ΔE=0或1的平凡情形）
- **规格化触发约束**：尾数求和后必须产生非规格化结果（需要左规或右规），不能求和后恰好已规格化（除非题目设计为考"无需规格化"的判断，但主路径应包含规格化操作）
- **舍入触发约束**：对阶右移后必须有被移出的有效位（即ΔE≥2时小阶数尾数低位被移出），保证舍入步骤非平凡
- **阶码范围约束**：最终结果的阶码真值在 [-126, 127] 范围内（正常数范围），避免上溢/下溢使题目过于复杂；空⑧的回答通常为"无溢出"
- **隐藏位恢复**：题目应在题干中提示学生注意恢复隐藏位1，或在空①中已包含此步骤
- **数值友好度**：十六进制编码尽量不超过8位十六进制数的可读范围，便于学生处理

## 参考经验
- **历史模式**：IEEE754 浮点运算在408中常以"给定编码→逐步运算→写最终结果"的形式考察，填空法能精确覆盖每一步
- **难度锚点**：K3 是本题位主导维度，目标4级（长流程推演+中间状态维持），比标准3级略高，因为步骤>5且中间值严格传递
- **典型陷阱**：
  1. 对阶方向错误（大阶向小阶看齐）——空②可检测
  2. 忘记恢复隐藏位1——空③可检测
  3. 规格化方向判断错误——空⑤可检测
  4. 舍入用截断而非就近偶数——空⑦可检测
  5. 阶码用偏移值而非真值——空⑥⑨可检测
