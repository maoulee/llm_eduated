## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 中央处理器 > 流水线
- primary_target_name: 指令流水线吞吐/加速比
- question_type: single_choice
- examination_mode: 计算型——流水线吞吐率/执行时间

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: K3为主导维度，要求按固定流程走3-5步串行计算（求总执行时间→求吞吐率或加速比），路径唯一但步骤明确。K1=3需准确记忆吞吐率/加速比公式定义。K2=3涉及非2幂次的常规计算。整体为标准难度的计算型选择题。

### 结构要求
- option_count: 4
- distractor_strategy: 干扰项来自常见错误路径——(a)吞吐率与加速比公式混用；(b)各段时间不等时取平均延迟而非最大延迟计算吞吐率；(c)总执行时间遗漏首条指令的填充时间(k-1)个周期。三条错误路径应产生三个不同的错误数值，与正确值区分。
- condition_count: 3-4

### 参数约束
- 流水线段数 k: 取值范围 3-5，建议4
- 各段延迟 Δtᵢ: 允许各段不等，至少存在一个瓶颈段 Δt_max 大于其余段；非瓶颈段延迟 < Δt_max；所有延迟值为正整数（单位为ns或时钟周期）
- 指令条数 N: 取值范围 50-200，使计算结果便于化简
- 时钟周期: 可设为1个单位时间以简化，或给定具体ns值
- 一致性约束:
  - 各段不等时：T = ΣΔtᵢ + (N-1)×Δt_max
  - 各段相等时（退化为）：T = (k+N-1)×Δt
  - TP = N / T
  - S = N×ΣΔtᵢ / T
  - 正确选项与三个干扰选项须互不相同（参数选取须保证四条计算路径产生四个不同值）

### 参考经验摘要
- 历史模式: 流水线性能指标（吞吐率/加速比）计算，选择题形式，给定段数和各段延迟
- 难度锚点: K3=3标准推演，K1=3公式记忆，K2=3常规计算
- 典型陷阱: (1)瓶颈段取最大延迟而非平均；(2)总时间遗漏首条指令填充；(3)吞吐率与加速比公式混淆；(4)各段相等vs不等的公式适用范围混淆
