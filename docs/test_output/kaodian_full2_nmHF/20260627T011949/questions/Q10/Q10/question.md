# 指令流水线吞吐率计算（选择题）

## 题干

某计算机采用 5 级指令流水线，各段功能与延迟如下：

| 段 | 功能 | 延迟 |
|----|------|------|
| S1 | 取指（IF） | 3 ns |
| S2 | 译码（ID） | 2 ns |
| S3 | 执行（EX） | 5 ns |
| S4 | 访存（MEM） | 2 ns |
| S5 | 写回（WB） | 3 ns |

该流水线连续执行 **N = 50** 条指令，且流水线不发生停顿（无数据冒险、结构冒险、控制冒险）。

**问：该流水线的吞吐率 TP 约为多少（单位：×10⁸ 条/秒）？**

---

## 选项（只标注选项考什么错误类型，具体数值由 gen.py 计算）

- **A.** 1.92（正确结果）
- **B.** 28.85（吞吐率与加速比公式混用——将加速比 S 的数值误当作吞吐率 TP 填入）
- **C.** 3.09（各段延迟取算术平均而非取最大值作为流水线时钟周期来计算吞吐率）
- **D.** 2.00（总执行时间遗漏首条指令经过全部 5 段的填充时间——仅用 N×Δt_max 作为总执行时间）

---

## 考察意图

| 维度 | 考察点 |
|------|--------|
| K1（公式记忆） | 吞吐率 TP = N / T；加速比 S = N×ΣΔtᵢ / T |
| K2（常规计算） | 各段不等时流水线总执行时间的非 2 幂次计算 |
| K3（流程推演） | 正确识别瓶颈段（最大延迟段）→ 计算 T → 计算 TP，路径唯一但步骤明确 |
| 选项区分度 | 四条计算路径产生四个互不相同的值 |

---

## 场景规则（本题成立 ⇔ 参数间约束）

以下约束与具体答案值无关，换参数仍成立，供 gen.py 翻译为 `assert`：

1. **流水线总执行时间公式**：各段不等时，`T = ΣΔtᵢ + (N-1) × Δt_max`，其中 `Δt_max = max(Δtᵢ)`。
2. **吞吐率定义**：`TP = N / T`。
3. **加速比定义**：`S = N × ΣΔtᵢ / T`（非流水线执行 N 条指令的总时间 ÷ 流水线执行总时间）。
4. **瓶颈段唯一性**：`Δt_max` 严格大于其余各段延迟（保证"取最大值"与"取平均值"产生不同结果）。
5. **四选项互异**：正确路径与三条错误路径（加速比混淆 / 取平均延迟 / 遗漏填充时间）在给定参数下须产生四个互不相同的数值。
6. **正确值唯一**：题干给定参数下，正确吞吐率 TP 有且仅有一个确定值，对应选项 A。
7. **干扰项对应声明错误类型**：
   - B 的值 = `S = N×ΣΔtᵢ / T`（加速比，与 TP 量纲不同）
   - C 的值 = `N / (ΣΔtᵢ + (N-1)×avg)`，其中 `avg = ΣΔtᵢ / k`（用平均延迟替代最大延迟）
   - D 的值 = `N / (N × Δt_max)`（遗漏首条指令填充时间 ΣΔtᵢ，仅用 N×Δt_max 作为总时间）

## 参数总结

| 参数 | 值 |
|------|----|
| 流水线段数 k | 5 |
| 各段延迟 Δtᵢ（ns） | 3, 2, 5, 2, 3 |
