## 考点
- **核心考点**：指令流水线吞吐率与加速比计算
  - 考察侧重点：流水线执行时间的计算（各段时间不等时取最大段为瓶颈），吞吐率 = 指令数 / 总执行时间，加速比 = 非流水线执行时间 / 流水线执行时间
  - 关键辨析：流水线段数、各段延迟、连续指令数之间的关系；吞吐率与加速比的区别
- **辅助考点**：流水线时空概念
  - 考察侧重点：首条指令需经历完整流水线时间，后续指令每隔一个时钟周期（瓶颈段时间）完成一条

## 难度目标
- K1=3（标准）：必须准确记忆吞吐率、加速比两个核心公式的定义才能入题
- K2=3（标准）：需代入公式计算，涉及非2的幂次数字（如多段流水线延迟），可能有小数结果
- K3=3（标准）：需按固定流程走3-5步——先求总执行时间，再求吞吐率或加速比，路径唯一
- K4=2（较低）：存在常规注意点（首条指令填充时间），408考生基本不会踩坑
- K5=1（微弱）：单一知识点内部解决，不涉及其他子系统

K3为主维度，与slot的k_dominant一致。整体难度定位3级，以多步公式计算为核心考察。

## 考察模式
**计算型——流水线吞吐率/加速比**

理由：slot指定examination_mode为计算型，要求考生根据给定的流水线参数（段数、各段延迟、指令条数）计算吞吐率或加速比。此模式直接考察对流水线性能指标公式的理解与运用，是流水线部分的标准考法。

## 出题要求
- 题型：单项选择题，4选项1正确3干扰
- 总条件数：3-4个显式条件（流水线段数、各段延迟或时钟周期、指令条数）
- 条件设计原则：条件信息完整，考生可直接据此计算吞吐率和/或加速比；题目问其中一个指标（吞吐率或加速比），或同时问两个但选项只对应一个核心计算结果
- 参数取值范围要求：流水线段数3-5段；各段延迟可不等（引入瓶颈段）；指令条数取较大值（如100条量级），使吞吐率近似稳定值有意义；最终计算结果应为可化简的分数或有限小数

## 子问题规划
单项选择题，无子问题拆分。一题一问，要求选出正确的吞吐率或加速比值。

## 参数约束
- **流水线段数 k**：取值范围 3-5，建议取4
- **各段延迟**：允许各段不等（如 Δt₁, Δt₂, ..., Δt_k），瓶颈段延迟 Δt_max 决定吞吐率；非瓶颈段延迟 < Δt_max
- **指令条数 N**：取值范围 50-200，使结果便于计算且首条指令的填充时间对总时间的影响可量化
- **时钟周期 / 单位时间**：可设为1个单位（简化）或具体ns值
- **参数间一致性约束**：
  - 流水线总执行时间 T = (k-1)×Δt_max + N×Δt_max = (k-1+N)×Δt_max（各段取最大延迟时）
  - 或当各段不等时 T = ΣΔtᵢ + (N-1)×Δt_max
  - 吞吐率 TP = N / T
  - 加速比 S = (N×ΣΔtᵢ) / T
  - 干扰项应来自上述不同公式的混用结果，各路径产生不同数值

## 参考经验
- 历史模式：流水线性能计算是408高频考点，常以选择题形式出现，给定段数和各段时间求吞吐率或加速比
- 难度锚点：K3=3为标准难度，需3-5步串行计算；K1=3需记忆公式定义
- 典型陷阱：
  - 各段时间不等时，吞吐率瓶颈段取最大延迟而非平均延迟
  - 总时间计算中首条指令的填充时间（k-1）个周期不可遗漏
  - 吞吐率与加速比公式混淆
  - 各段相等 vs 不等两种情况的公式适用范围混淆
