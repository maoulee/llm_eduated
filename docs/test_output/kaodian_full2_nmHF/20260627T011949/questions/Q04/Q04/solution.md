# 存储器地址线/数据线计算 — 求解

## 参数

| 参数 | 值 |
|------|----|
| 编址方式 | 按字节编址（编址单元 = 8 位 = 1 字节） |
| 存储空间 | 32KB |
| 存储字长 | 32 位 |
| K 值（正确） | 1024 |

## 正确计算（选项 A）

**第一步：求总字节数。**

$$\text{总字节数} = 32 \times 1024 = 32768$$

**第二步：确定编址单元总数。**

按字节编址 → 编址单元 = 1 字节，因此：

$$\text{编址单元总数} = 32768$$

**第三步：求地址线数。**

$$\text{地址线数} = \log_2(32768) = 15$$

验证：$2^{15} = 32768$，恰好等于编址单元总数，地址线数为整数。

**第四步：求数据线数。**

$$\text{数据线数} = \text{存储字长} = 32 \text{ 位}$$

**选项 A（正确）：地址线 15 根，数据线 32 根。**

## 干扰项分析

### 选项 B：地址线 / 数据线互换（概念混淆）

将正确结果中的地址线数与数据线数对调：

- 地址线 = 32（取了正确的数据线数）
- 数据线 = 15（取了正确的地址线数）

**选项 B：地址线 32 根，数据线 15 根。** 错误原因：混淆了地址线和数据线的概念。

### 选项 C：K = 1000 单位换算错误

将 1K 误当作 1000，则总字节数 = 32 × 1000 = 32000。

$$\log_2(32000) \approx 14.97$$

取整数部分得地址线数 = 14，数据线数不变 = 32。

**选项 C：地址线 14 根，数据线 32 根。** 错误原因：单位换算中将 1K = 1024 误作 1000，导致编址单元总数偏小，地址线数算少 1 根。

### 选项 D：按字编址理解偏差

误认为按字编址，编址单元 = 1 个存储字 = 32 位 = 4 字节。

$$\text{编址单元总数} = 32768 / 4 = 8192$$

$$\text{地址线数} = \log_2(8192) = 13$$

数据线数不变 = 32。

**选项 D：地址线 13 根，数据线 32 根。** 错误原因：编址方式理解偏差，将按字节编址误作按字编址，编址单元粒度变大导致编址单元数减少，地址线数算少 2 根。

## 答案

**A. 地址线 15 根，数据线 32 根。**

| 选项 | 地址线 | 数据线 | 正误 |
|------|--------|--------|------|
| **A** | **15** | **32** | **✓ 正确** |
| B | 32 | 15 | ✗ 互换 |
| C | 14 | 32 | ✗ K=1000 |
| D | 13 | 32 | ✗ 按字编址 |
