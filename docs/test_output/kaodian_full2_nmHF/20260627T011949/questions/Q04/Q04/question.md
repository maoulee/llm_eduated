# 存储器地址线/数据线计算（选择题）

## 题干

某计算机存储器**按字节编址**，其存储空间为 **32KB**，存储字长为 **32 位**。该存储器的地址线数和数据线数分别为：

A. 地址线 15 根，数据线 32 根

B. 地址线 32 根，数据线 15 根

C. 地址线 14 根，数据线 32 根

D. 地址线 13 根，数据线 32 根

---

## 考察意图

| 考察项 | 说明 |
|--------|------|
| 地址线概念 | 地址线根数 = log₂(编址单元总数)；按字节编址时编址单元 = 1 字节 |
| 数据线概念 | 数据线根数 = 存储字长（位） |
| 编址方式 | 按字节编址 vs 按字编址对编址单元数的影响 |
| 单位换算 | 存储容量中 K = 1024，非 1000 |

## 设计意图

- **考点**：给定容量 + 编址方式 + 存储字长，求地址线和数据线。
- **干扰策略**：三类干扰分别对应——① 地址线/数据线互换（概念混淆）；② K = 1000 单位换算错误（计算偏差）；③ 编址方式理解错误（按字编址而非按字节编址，改变编址单元粒度）。
- **难度定位**：K1 概念记忆 + K2 单步代入计算，标准难度。

## 参数

| 参数 | 值 |
|------|----|
| 编址方式 | 按字节编址 |
| 存储空间 | 32KB |
| 存储字长 | 32 位 |

## 场景规则（通过条件）

> 以下为参数间必须成立的约束关系，与具体答案值无关，换参数仍成立。

1. **编址规则**：按字节编址 → 编址单元 = 1 字节 → 编址单元总数 == 存储空间总字节数（即 32 × 1024）。
2. **地址线公式**：地址线根数 == log₂(编址单元总数)，结果须为整数。
3. **数据线公式**：数据线根数 == 存储字长位数。
4. **四选项互异**：A / B / C / D 四个（地址线数, 数据线数）数值对两两不同，无碰撞。
5. **正确值唯一确定**：在给定参数下只有一个正确（地址线数, 数据线数）对，A = 该值。
6. **干扰项对应声明错误类型**：
   - B = 将正确对的地址线数与数据线数互换得到的值。
   - C = 用 K = 1000（即 32000 替代 32768）计算地址线数、数据线数不变得到的值。
   - D = 按字编址理解（编址单元 = 4 字节 = 32 位/8），即编址单元总数 = 总字节数 / 4，由此算出地址线数、数据线数不变得到的值。
7. **干扰项合理性**：每个干扰项均为同类题常见误算的真实产物，非荒谬值。
