## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 存储系统 > 存储器编址
- primary_target_name: 存储器地址线/数据线计算
- question_type: single_choice
- examination_mode: 计算型——存储芯片地址线与数据线位数

### 难度目标
- k_target: K1=3,K2=3,K3=1,K4=2,K5=1
- difficulty_level: 2
- difficulty_rationale: 核心是单步计算代入（K2=3），需准确记忆地址线/数据线的概念公式（K1=3），存在编址方式的常规注意点（K4=2），无多步推演和跨域联动。整体定位为标准难度选择。

### 结构要求
- option_count: 4
- distractor_strategy: 三类干扰分别对应"地址线数据线混淆""单位换算错误(K=1000)""编址方式理解偏差"，各干扰项须产生不同错误结果
- condition_count: 2

### 参数约束
- 存储单元数: 2^n，n ∈ [10,14]，地址线数须为整数
- 存储字长: {1,4,8,16,32} 位
- 容量表述: 可选"单元数×位数"或"总字节数+编址方式"两种形式
- 地址线数 = log₂(存储单元数)；数据线数 = 存储字长
- 干扰项约束: 三类干扰（混淆/换算/编址）结果互不相同且均不等于正确答案

### 参考经验摘要
- 历史模式: 给定芯片容量，问地址线和数据线根数，是存储器编址最经典选择题考法
- 难度锚点: K2=2~3 区间，概念记忆+单步计算，标准难度
- 典型陷阱: 地址线/数据线混淆；K=1024误作1000；按字节编址时未先换算为单元数
