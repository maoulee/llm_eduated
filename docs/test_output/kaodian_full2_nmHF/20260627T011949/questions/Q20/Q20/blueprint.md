## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 数据表示与运算 > 补码
- primary_target_name: 变形补码加减与溢出判断
- question_type: comprehensive
- examination_mode: 综合题——给两个小数，用变形补码算x+y和x-y并判溢出

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: K3主导，需按固定流程走3-5步（求补码→对齐→相加→判溢出），路径唯一但步数充足；K1=3因必须准确记忆变形补码定义和溢出判断规则；K2=3因十进制小数转二进制非2幂友好；K4=2因减法求补为常规注意点；K5=1因单一知识点内部解决

### 结构要求
- sub_question_count: 2
- sub_question_details:
  - 第1问: 用变形补码求 x+y，写出运算过程并判断溢出，3分
  - 第2问: 用变形补码求 x-y（即 x+[-y]补），写出运算过程并判断溢出，3分
- dependency: 两问并行，共用 x、y 参数，无前后依赖
- score_total: 6

### 参数约束
- x: 十进制负小数，绝对值范围 0.5~0.75
- y: 十进制负小数（或正小数），绝对值范围 0.5~0.75，与 x 不同值
- 溢出约束: x+y 和 x-y 中必须有且仅有一个产生溢出（以考察溢出判断），另一个不溢出（以考察正常运算）
- 精度约束: x 和 y 的二进制小数表示在 4-6 位有效位内精确终止（非无限循环小数），确保计算量适中
- 符号选择: x、y 符号组合由 Question Agent 确定，需自然满足上述溢出/不溢出约束

### 参考经验摘要
- 历史模式: 变形补码加减运算是408高频考法，给两个小数要求完整运算过程+溢出判断
- 难度锚点: K3=3主导，流程固定步数3-5步，K1=3需记忆双符号位定义
- 典型陷阱: 减法忘记求补直接减；双符号位判断只看最高位；十进制小数转二进制精度截断；变形补码与普通补码混淆
