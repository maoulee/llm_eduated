# 变形补码加减运算与溢出判断

## 题目

给定两个小数：

$$x = -0.6875 = -\frac{11}{16}, \quad y = -0.5625 = -\frac{9}{16}$$

采用 **变形补码（双符号位）** 表示，小数部分取 **5 位**，格式为 $S_1 S_0 . f_1 f_2 f_3 f_4 f_5$（共 2 位符号位 + 5 位小数位）。变形补码定义：正数符号位为 `00`，负数符号位为 `11`，数值部分按补码规则求取（取反加一）。

**溢出判断规则**：运算结果的双符号位若相同（`00` 或 `11`），则未溢出；若不同（`01` 或 `10`），则溢出。

请完成以下两问：

### 第 1 问（3 分）

用变形补码求 $x + y$。要求：

1. 写出 $x$ 和 $y$ 的二进制小数表示（十进制转二进制过程）。
2. 写出 $x$、$y$ 的变形补码。
3. 进行变形补码加法运算，写出运算过程。
4. 根据双符号位判断是否溢出，并给出结论。

### 第 2 问（3 分）

用变形补码求 $x - y$，即 $x + [-y]_{\text{变形补码}}$。要求：

1. 求出 $[-y]$ 的值及其变形补码。
2. 进行变形补码加法运算（$[x]_{\text{变形补码}} + [-y]_{\text{变形补码}}$），写出运算过程。
3. 根据双符号位判断是否溢出，并给出结论。
4. 若未溢出，写出结果的真值（十进制）。

---

## 设计意图

- **考点**：变形补码（双符号位）的定义、十进制小数转二进制、补码加减运算、溢出判断。
- **考察形式**：综合题，两问并行（共用 $x$、$y$），一问考察同号相加溢出，一问考察减法（求补后相加）不溢出的正常运算。
- **难度锚点**：K3 主导（流程固定 3–5 步），K1 要求准确记忆变形补码定义与溢出规则，K2 涉及十进制小数转二进制。

---

## 场景规则（通过条件）

> 本题成立 ⇔ 以下参数间约束被满足。验证归 gen.py exec + assert。

1. **二进制精确性**：$x$ 和 $y$ 的二进制小数表示在 5 位有效位内精确终止（无舍入误差），即 $x = -0.1011_2$、$y = -0.1001_2$ 均可在 $\leq 5$ 位内精确表示。
2. **变形补码还原一致性**：任一操作数的变形补码经"符号位→真值"还原后，必须等于该操作数的原始十进制值（即变形补码表示无歧义）。
3. **溢出判定逻辑一致性**：若运算结果双符号位不同 → 判定为溢出；若相同 → 判定为无溢出，且无溢出时的结果真值 $= x + y$（第 1 问）或 $= x - y$（第 2 问）的数学精确值。
4. **一溢一不溢约束**：$x + y$ 与 $x - y$ 中 **有且仅有一个** 产生溢出，另一个不溢出——确保两问分别考察溢出判断与正常运算，无重复或全无溢出。
5. **减法求补正确性**：$[-y]_{\text{变形补码}}$ 必须等于 $y$ 的相反数的变形补码表示（即 $[-y]_{\text{变形补码}} + [y]_{\text{变形补码}} = 0$）。
