## 考点
- **补码真值求取**：给定一个补码表示（含符号位），能正确转换为十进制真值
- **补码表数范围**：理解 n 位补码整数/小数的最小值和最大值，特别是最小负数的特殊性

## 难度目标
- **K1=2（较低）**：需记忆补码定义这一个核心概念即可入题，概念本身不生僻
- **K2=3（标准）**：需要代入补码→真值的转换公式，涉及非 2 的幂次的加权计算（负数补码各位取反加一），是本题的 dominant 维度
- **K3=2（较低）**：补码求真值路径短（2步以内：识别符号→按规则转换），路径唯一
- **K4=2（较低）**：存在常规注意点（符号位判断、最小负数无对应正数），但 408 考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他子系统

**达标理由**：target_difficulty=2，K2 主导。补码真值转换是标准单步计算（K2=3），其余维度压低。K4=2 因为可以设置"最小负数"这一常规陷阱作为干扰项考察点，但不设深坑。

## 考察模式
**计算型——给定补码求真值/判断范围**

理由：slot 明确指定该模式。给学生一个具体的补码机器数，要求判断其十进制真值；或在选项中给出多个真值，要求选出与给定补码匹配的那个。此模式直接测 K2（单步代入），干扰项可设置常见错误路径。

## 出题要求
- **题型**：单项选择题，4 选 1，分值 2 分
- **总条件数**：2 个显式条件（机器字长 + 补码编码）
- **条件设计原则**：
  - 给出明确的机器字长（如 n 位），作为求值前提
  - 给出一个具体的补码机器数（含符号位），要求求真值或判断范围
- **参数取值范围要求**：
  - 机器字长 n：建议 8 或 16，保证学生心算可行但非平凡
  - 补码机器数：符号位为 1（负数），确保转换过程有计算量；避免全 0、全 1 等平凡值
  - 真值结果应非 2 的幂次，增加 K2 区分度

## 子问题规划
选择题无子问题拆分。单一题干 + 4 选项。

## 参数约束
| 参数 | 取值范围 | 一致性约束 | 自由度 |
|------|---------|-----------|--------|
| 机器字长 n | 8 或 16 | n 决定补码位数与有效数值范围 | Question Agent 自选 |
| 补码机器数 X | 符号位=1（负数），其余位非全0/非全1 | 位数 = n；|真值| 非 2 的幂 | Question Agent 自选具体编码 |
| 选项间距 | 各干扰项对应不同错误路径 | 4 个选项互不重合 | Question Agent 设计干扰项 |

**干扰策略建议**（3 个干扰项，每个对应不同错误路径）：
- 干扰项 A：符号位正确但取反加一过程中漏了"+1"（结果比真值绝对值小 1）
- 干扰项 B：直接将补码当作原码解读（符号位翻转但数值位不取反）
- 干扰项 C：符号位判断正确但加权求和出错（某位权重算错）

**关键约束**：3 个干扰项对应的错误路径必须产生互不相同的结果，否则选项重合、题目失效。

## 参考经验
- **考察模式**：补码真值转换是 408 高频考法，通常以"给定机器数求真值"或"判断哪些数在该范围内"出现
- **难度锚点**：标准难度（K2=3），计算量适中，不宜用过长字长导致心算困难
- **典型陷阱**：最小负数（-2^(n-1)）无对应正数、取反加一漏"+1"、原码/补码/反码混淆
