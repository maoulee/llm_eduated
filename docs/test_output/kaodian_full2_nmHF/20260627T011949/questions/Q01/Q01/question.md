# 补码真值计算（单项选择题）

## 题干

某 8 位计算机采用补码表示带符号整数。给定补码机器数 **X = 10110101B**，则 X 的十进制真值为（　　）。

## 选项

A. -75

B. -74

C. -53

D. 181

## 题干参数

| 参数 | 值 |
|------|-----|
| 机器字长 n | 8 |
| 补码机器数 X | 10110101B（二进制） |
| 符号位 | 1（负数） |
| 数值位 | 0110101（非全0、非全1） |

## 参数约束（题目成立条件）

1. **X 为合法的 8 位补码负数**：符号位=1，数值位非全0（否则为最小负数 $-128$，无对应正数）且非全1（否则真值绝对值为1，过于简单）。
2. **真值绝对值非 2 的幂次**：确保加权求和路径 D 不会与正确答案 A 重合，各错误路径产生不同结果。
3. **四选项互异**：A、B、C、D 四个值各不相同。
4. **正确值唯一确定**：给定参数下只有一个确定真值，A = 该值。
5. **干扰项对应声明错误类型**：B = 取反加一漏+1；C = 补码当原码读；D = 符号位权重符号取反——每个干扰项是相应错误的真实计算产物。
6. **干扰项有合理性**：每个干扰项为同类题常见误算的真实结果，非荒谬值，具有区分度。
