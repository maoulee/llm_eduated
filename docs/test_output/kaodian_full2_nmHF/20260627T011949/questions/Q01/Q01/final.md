## 题目
某 8 位计算机采用补码表示带符号整数。给定补码机器数 **X = 10110101B**，则 X 的十进制真值为（　　）。


## 选项
A. -75

B. -74

C. -53

D. 181


## 求解过程
# 补码真值计算 —— 解题过程

## 参数

| 参数 | 值 |
|------|-----|
| 补码机器数 X | 10110101B |
| 机器字长 n | 8 |
| 符号位 | 1（负数） |
| 数值位 | 0110101 |

---

## 正确计算（A 选项）

X = 10110101B，符号位为 1，是负数。按"取反加一法"求真值：

**第 1 步**：取数值位 0110101 的反码 → **1001010**（十进制 74）

**第 2 步**：加 1 → 74 + 1 = **75**

**第 3 步**：符号位为负，加负号 → **-75**

**交叉验证**（加权求和，符号位权重为 $-2^7$）：

$$(-1)\times2^7 + 0\times2^6 + 1\times2^5 + 1\times2^4 + 0\times2^3 + 1\times2^2 + 0\times2^1 + 1\times2^0$$

$$= -128 + 32 + 16 + 4 + 1 = \mathbf{-75}$$

✅ **A = -75（正确）**

---

## 干扰项分析

### B = -74（取反加一漏 "+1"）

错误路径：数值位取反得 1001010（=74），但漏掉最后一步 "+1"，直接取负：

$$-74$$

正确值应为 -75，因漏 "+1" 导致绝对值少 1，得 -74。

### C = -53（补码当作原码直接读）

错误路径：将补码机器数当作原码处理——符号位 1 表负，数值位 0110101 直接读为 53：

$$-53$$

正确值 -75 ≠ -53，混淆了补码与原码的数值位解释。

### D = 181（符号位权重取 $+2^7$ 而非 $-2^7$）

错误路径：加权求和时所有位（含符号位）均取正权重：

$$1\times2^7 + 0\times2^6 + 1\times2^5 + 1\times2^4 + 0\times2^3 + 1\times2^2 + 0\times2^1 + 1\times2^0$$

$$= 128 + 32 + 16 + 4 + 1 = \mathbf{181}$$

符号位本应贡献 $-128$，误取 $+128$，导致结果为正且数值错误。

---

## 四选项汇总

| 选项 | 值 | 错误类型 |
|------|-----|---------|
| **A** | **-75** | 正确 |
| B | -74 | 取反加一漏 "+1" |
| C | -53 | 补码当原码读 |
| D | 181 | 符号位权重取正（$+2^7$） |

四选项互异：-75、-74、-53、181，各不相同，具有区分度。

---

## 答案

**A. -75**
