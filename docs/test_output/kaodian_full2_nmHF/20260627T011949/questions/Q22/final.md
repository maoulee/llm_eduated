## 题目

# 计算机组成原理 — Cache 映射地址字段位数推导

某计算机的主存与 Cache 采用以下参数：

| 参数 | 值 |
|------|-----|
| 主存容量 M | 1 MB |
| Cache 容量 C | 32 KB |
| 主存块大小 B（Cache 行大小） | 64 B |
| 组相联路数 W | 4 路 |

主存与 Cache 均按**字节编址**。请根据以上参数完成下列各问。

---

### 第 1 问（3 分）

若 Cache 采用**直接相联（直接映射）**方式，主存地址被划分为 **Tag（主存字块标记）、Cache 行号、块内偏移** 三个字段。

请写出：
1. 块内偏移字段位数，并说明计算依据。
2. Cache 行号字段位数，并说明计算依据。
3. Tag 字段位数，并说明计算依据。

### 第 2 问（4 分）

若 Cache 采用**4 路组相联**映射方式，主存地址被划分为 **Tag（主存字块标记）、组号、块内偏移** 三个字段。

请写出：
1. 块内偏移字段位数（若与第 1 问相同，请说明理由）。
2. 组号字段位数，并说明计算依据。
3. Tag 字段位数，并说明计算依据。

### 第 3 问（3 分）

比较第 1 问（直接相联）与第 2 问（组相联）的 Tag 位数差异：
1. 两种映射方式下 Tag 位数分别相差多少？
2. 用一句话解释产生该差异的原因。

---

## 参考答案

| 字段 | 第 1 问 直接相联 | 第 2 问 4 路组相联 |
|------|:---:|:---:|
| 块内偏移 | 6 位 | 6 位 |
| 索引字段（行号/组号） | 行号 9 位 | 组号 7 位 |
| Tag | **5 位** | **7 位** |
| 合计 | 20 位 | 20 位 |

**第 3 问**：组相联 Tag 比直接相联 Tag 多 **2 位**。

---

## 解析

### 已知参数

| 参数 | 值 |
|------|-----|
| 主存容量 M | 1 MB = 2²⁰ B |
| Cache 容量 C | 32 KB = 2¹⁵ B |
| 主存块大小 B（Cache 行大小） | 64 B = 2⁶ B |
| 组相联路数 W | 4 路 |

按字节编址，主存地址总位数 = log₂(M) = log₂(2²⁰) = **20 位**。

---

### 第 1 问（3 分）— 直接相联映射

**1. 块内偏移字段位数**

块内偏移 = log₂(B) = log₂(2⁶) = **6 位**。

计算依据：每个 Cache 行大小为 64 B，按字节编址时需要 6 位地址来寻址行内的每一个字节（2⁶ = 64）。

**2. Cache 行号字段位数**

- Cache 总行数 = C / B = 32768 / 64 = 512 行
- 行号位数 = log₂(C/B) = log₂(512) = **9 位**

计算依据：直接映射下每个主存块只能映射到 Cache 中固定的一行，需要 9 位从 512 行中选一行（2⁹ = 512）。

**3. Tag 字段位数**

Tag 位数 = 地址总位数 − 行号位数 − 块内偏移位数 = 20 − 9 − 6 = **5 位**。

计算依据：地址总位数 20 位减去行号字段 9 位和块内偏移字段 6 位，剩余 5 位即为标记字段。

**字段守恒验证**：Tag(5) + 行号(9) + 块内偏移(6) = 20 = 地址总位数 ✓

---

### 第 2 问（4 分）— 4 路组相联映射

**1. 块内偏移字段位数**

块内偏移 = log₂(B) = **6 位**。

与第 1 问相同。理由：块内偏移仅由块大小 B 决定（2⁶ = 64），与映射方式无关，两种映射方式的块内偏移必然相同。

**2. 组号字段位数**

- Cache 总行数 = C / B = 32768 / 64 = 512 行
- 组数 = C / (B × W) = 32768 / (64 × 4) = 32768 / 256 = 128 组
- 组号位数 = log₂(128) = **7 位**

计算依据：4 路组相联将 512 行按每组 4 行分组，共 128 组（512 / 4 = 128），需要 7 位从 128 组中选一组（2⁷ = 128）。

**3. Tag 字段位数**

Tag 位数 = 地址总位数 − 组号位数 − 块内偏移位数 = 20 − 7 − 6 = **7 位**。

计算依据：地址总位数 20 位减去组号字段 7 位和块内偏移字段 6 位，剩余 7 位即为标记字段。

**字段守恒验证**：Tag(7) + 组号(7) + 块内偏移(6) = 20 = 地址总位数 ✓

---

### 第 3 问（3 分）— Tag 位数差异比较

**1. 两种映射方式的 Tag 位数差**

- 直接相联 Tag = 5 位
- 组相联 Tag = 7 位
- 差值 = 7 − 5 = **2 位**（组相联的 Tag 比直接相联多 2 位）

**2. 产生差异的原因**

组相联的索引字段（组号 7 位）比直接相联的索引字段（行号 9 位）少了 2 位（因为 4 路组相联将行数除以路数 4，组数 = 512/4 = 128 < 512 行），索引字段减少的位数转移到 Tag 字段上，因此组相联的 Tag 位数比直接相联多 2 位。
