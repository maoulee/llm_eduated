## 考点
- **核心考点**：Cache 直接相联映射——主存地址字段划分（Tag / Line / Offset 位数推导）
- **核心考点**：Cache 组相联映射——主存地址字段划分（Tag / Set / Offset 位数推导）
- **辅助考点**：主存地址位数与容量、块大小的关系；组相联路数（way数）对字段划分的影响
- **考察侧重点**：学生在两种映射方式下正确识别地址各字段的位数，并能区分直接相联与组相联的 Tag 字段差异（组相联的 Tag 位数 > 直接相联，因组号位数 < 行号位数）

## 难度目标
- **K1=3（标准）**：必须准确记忆直接相联与组相联的地址字段定义才能入题；需辨析 Tag/组号/行号/块内偏移的概念
- **K2=2（较低）**：各字段位数为 log₂ 计算，数字均为 2 的幂，计算友好；但需多组计算
- **K3=4（较高）**：需在两种映射方式下分别推导 3 个字段位数，共 >5 步串行推导，且直接相联→组相联的转换需维持动态状态（组号位数随路数变化）
- **K4=3（标准）**：存在明确陷阱——组相联中"组号位数 = 块数 / 路数 后取 log₂"，学生易直接用总块数取 log₂（即忘记除以路数）；直接相联中 Tag = 主存块数位数 - Cache 行数位数，学生易混淆
- **K5=1（微弱）**：单一知识点（Cache 映射）内部解决，不涉及其他子系统

## 考察模式
综合题——给定主存容量、Cache 容量、块大小、组相联路数，要求：
1. 直接相联映射下，推导主存地址各字段位数（Tag / 行号 / 块内偏移）
2. 组相联映射下，推导主存地址各字段位数（Tag / 组号 / 块内偏移）
3. 比较两种映射方式下 Tag 字段位数的差异并解释原因

纯文字列出各字段位数，禁止要求画图。此模式考察对映射机制本质的理解，而非机械绘图。

## 出题要求
- **题型**：综合应用题，总分 10 分
- **条件数**：4 个显式条件（主存容量、Cache 容量、块大小、组相联路数）
- **条件设计原则**：
  - 主存容量、Cache 容量、块大小均为 2 的幂，使计算友好
  - 主存容量远大于 Cache 容量，保证 Tag 字段非零且有区分度
  - 组相联路数选 2 或 4，保证组号位数与行号位数有差异（否则组相联退化为全相联或直接相联）
- **参数取值范围要求**：
  - 主存容量：256KB ~ 4MB（保证主存地址位数在合理范围）
  - Cache 容量：8KB ~ 64KB
  - 块大小：32B ~ 128B
  - 组相联路数：2 路或 4 路
- **一致性约束**：Cache 容量必须能被块大小整除；Cache 块数必须能被路数整除

## 子问题规划
| 子问题 | 类型 | 考察目标 | 分值 | 与前后问关系 |
|--------|------|---------|------|-------------|
| 第1问 | 计算 | 直接相联映射下地址各字段位数推导（Tag/行号/块内偏移） | 3分 | 独立；为第2问的对比提供基准 |
| 第2问 | 计算 | 组相联映射下地址各字段位数推导（Tag/组号/块内偏移） | 4分 | 依赖第1问的块内偏移（相同）；需额外考虑路数对组号的影响 |
| 第3问 | 分析 | 比较两种映射方式下 Tag 位数差异，解释原因 | 3分 | 依赖第1、2问结果；考察对映射机制本质的理解 |

依赖关系：第1问独立；第2问的块内偏移与第1问相同但组号需新计算；第3问需综合第1、2问结果分析。

## 参数约束
- **主存容量 M**：2 的幂，取值范围 256KB ~ 4MB；约束：M > Cache 容量至少 8 倍以上，保证 Tag 字段 ≥3 位
- **Cache 容量 C**：2 的幂，取值范围 8KB ~ 64KB；约束：C 能被块大小 B 整除
- **块大小 B**：2 的幂，取值范围 32B ~ 128B；约束：B 整除 C，且 B 整除 M
- **组相联路数 W**：2 或 4；约束：Cache 行数（C/B）必须能被 W 整除；W < C/B（保证组数 ≥2）
- **自由度**：Question Agent 可在上述范围内自由选择 4 个参数的具体值，只要满足所有一致性约束
- **设计提醒**：选择参数时应确保直接相联的行号位数与组相联的组号位数不同（即 W≥2 保证组数 < 行数），使两种映射的字段划分有区分度

## 参考经验
- **历史模式**：此类题在 408 真题中常见，通常以画图形式考察地址划分；此处替换为纯文字推导位数
- **难度锚点**：K3 为主维度（推演步数多），K4 次之（组号计算易错），整体难度 4
- **典型陷阱**：
  1. 组相联组号 = Cache 总行数 / 路数，学生易忘记除以路数直接取 log₂
  2. Tag 位数 = 主存块数位数 - Cache 行号（或组号）位数，学生易用主存地址总位数减
  3. 块内偏移在两种映射方式下相同（都是 log₂(块大小)），学生可能误认为不同
