# 计算机组成原理 — Cache 映射地址字段位数推导

## 题目

某计算机的主存与 Cache 采用以下参数：

| 参数 | 值 |
|------|-----|
| 主存容量 M | 1 MB |
| Cache 容量 C | 32 KB |
| 主存块大小 B（Cache 行大小） | 64 B |
| 组相联路数 W | 4 路 |

主存与 Cache 均按**字节编址**。请根据以上参数完成下列各问。

---

### 第 1 问（3 分）

若 Cache 采用**直接相联（直接映射）**方式，主存地址被划分为 **Tag（主存字块标记）、Cache 行号、块内偏移** 三个字段。

请写出：
1. 块内偏移字段位数，并说明计算依据。
2. Cache 行号字段位数，并说明计算依据。
3. Tag 字段位数，并说明计算依据。

### 第 2 问（4 分）

若 Cache 采用**4 路组相联**映射方式，主存地址被划分为 **Tag（主存字块标记）、组号、块内偏移** 三个字段。

请写出：
1. 块内偏移字段位数（若与第 1 问相同，请说明理由）。
2. 组号字段位数，并说明计算依据。
3. Tag 字段位数，并说明计算依据。

### 第 3 问（3 分）

比较第 1 问（直接相联）与第 2 问（组相联）的 Tag 位数差异：
1. 两种映射方式下 Tag 位数分别相差多少？
2. 用一句话解释产生该差异的原因。

---

## 参数约束与通过条件（供 write_gen / 审核对照）

### 已知参数

- M = 1 MB = 2²⁰ B
- C = 32 KB = 2¹⁵ B
- B = 64 B = 2⁶ B
- W = 4

### 场景规则（参数间约束，换参数仍成立）

1. **编址规则**：按字节编址 → 主存地址总位数 = log₂(M)，即地址总线宽度 = log₂(主存字节数)。
2. **块内偏移一致**：直接相联与组相联的块内偏移位数相同，均 = log₂(B)（块大小决定，与映射方式无关）。
3. **直接相联行号**：Cache 行号位数 = log₂(C/B)（Cache 总行数取 log₂）。
4. **直接相联 Tag**：直接相联 Tag 位数 = 地址总位数 − 行号位数 − 块内偏移位数。
5. **组相联组号**：组号位数 = log₂(C/(B×W))（Cache 行数除以路数得组数，再取 log₂）；要求 C/(B×W) ≥ 2（组数 ≥ 2，保证组号位数 ≥ 1）。
6. **组相联 Tag**：组相联 Tag 位数 = 地址总位数 − 组号位数 − 块内偏移位数。
7. **区分度约束**：组号位数 < 行号位数（因 W ≥ 2，组数 < 行数），即两种映射的字段划分必须不同。
8. **Tag 差异方向**：组相联 Tag 位数 ≥ 直接相联 Tag 位数（因组号位数 ≤ 行号位数，Tag 相应增大）。
9. **字段求和守恒**：两种映射方式下，Tag + 索引字段（行号或组号）+ 块内偏移 = 地址总位数（所有位数之和等于地址总线宽度）。
