# 解题过程：总线带宽计算

## 参数

| 参数 | 值 |
|------|-----|
| 总线宽度 W | 32 bit |
| 总线工作频率 F | 200 MHz |

## 核心求解（正确值 → A 选项）

**公式**：总线带宽 = 总线宽度（Byte）× 总线工作频率

**第 1 步**：将总线宽度由 bit 换算为 Byte：

$$W = 32 \text{ bit} \div 8 = 4 \text{ Byte}$$

**第 2 步**：计算带宽：

$$B = 4 \text{ Byte} \times 200 \text{ MHz} = 800 \text{ MB/s}$$

> **A. 800 MB/s** ✅（正确答案）

## 各干扰项分析

### B. 6400 MB/s —— 忘记 ÷8 换算

错误路径：直接用 bit 宽度乘频率，未将 bit 换算为 Byte。

$$B_{\text{错}} = 200 \times 32 = 6400$$

该值是正确值的 **8 倍**（恰为 W/8 的倒数倍数），是此类题最高频的错误。

### C. 800000 MB/s —— 单位混淆（MHz 误当 GHz）

错误路径：将 200 MHz 的数值直接当作 GHz 量级理解，等价于频率被放大 1000 倍。

$$B_{\text{错}} = (200 \times 1000) \times 4 = 800000$$

该值是正确值的 **1000 倍**，产生明显的数量级偏差。

### D. 1 MB/s —— 公式混淆（乘除颠倒）

错误路径：误用 "总线宽度 × 8 ÷ 频率"（乘除颠倒）。

$$B_{\text{错}} = 32 \times 8 \div 200 = 1$$

该值异常小，因公式中乘除完全颠倒所致。

## 答案

| 选项 | 值 | 说明 |
|------|----|------|
| **A** | **800 MB/s** | **正确答案**：先 ÷8 换算为 Byte，再乘频率 |
| B | 6400 MB/s | 未 ÷8，正确值的 8 倍 |
| C | 800000 MB/s | MHz 误当 GHz，正确值的 1000 倍 |
| D | 1 MB/s | 乘除颠倒，W×8/F |

**正确答案：A（800 MB/s）**
