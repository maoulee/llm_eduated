# 题目：总线带宽计算

## 题干

某计算机系统总线宽度为 **32 bit**，总线工作频率为 **200 MHz**。在该总线上，每个时钟周期传输一次数据。求该总线的最大数据传输速率（带宽）。

> 提示：总线带宽 = 总线宽度（Byte）× 总线工作频率。

## 选项

A. 800 MB/s

B. 6400 MB/s

C. 800000 MB/s

D. 1 MB/s

---

## 场景规则（本题成立 ⇔ 参数间约束）

设总线宽度为 W bit，总线工作频率为 F MHz，带宽为 B MB/s。

1. **带宽公式**：B = F × (W / 8)，结果为正整数 MB/s。
2. **W 为 8 的整数倍**：W % 8 == 0（保证 W/8 为整数，B 为正整数）。
3. **四选项互异**：A（正确值）、B（W×F，即未÷8）、C（数量级偏差值）、D（W×8/F）四个值各不相同，无碰撞。
4. **正确值唯一**：在给定参数下 A 为唯一确定答案，不存在两个选项值相等的情况。
5. **干扰项对应声明错误类型**：
   - B 的值 == F × W（不除以 8，即以 bit 为单位直接乘频率）
   - C 的值 == 将 F 的数值按 GHz 量级理解后所得带宽（与正确值有 1000 倍或 1/1000 倍关系）
   - D 的值 == W × 8 / F（公式中乘除颠倒）
6. **干扰项合理性**：每个干扰项均为同类题常见误算的真实产物，非荒谬值，且与正确值可区分。

---

## 设计说明

- **知识点**：总线带宽 = 总线宽度（Byte）× 总线工作频率。
- **核心陷阱**：总线宽度以 bit 给出，学生需自行 ÷8 换算为 Byte，此为最高频错误（干扰项 B）。
- **次要陷阱**：单位混淆（干扰项 C）、公式颠倒（干扰项 D）。
- **参数选择**：W = 32 bit（8 的整数倍），F = 200 MHz（常规工程值，非 2 的幂），B = 200 × 4 = 800 MB/s（整洁正整数）。
