# 计算机组成原理综合题——CPI 与 MIPS 计算

## 题目（6 分）

某 CPU 的主频为 800 MHz。该 CPU 共执行 4 类指令，各类指令的 CPI 及其在某程序中所占比例如下表所示：

| 指令类别 | CPI | 使用比例 |
|---------|-----|---------|
| ALU 运算类 | 1 | 50% |
| Load 装入类 | 3 | 20% |
| Store 存储类 | 2 | 15% |
| 转移类 | 2 | 15% |

请回答以下问题：

**(1)**（2 分）求该程序的加权平均 CPI。

**(2)**（2 分）求该 CPU 执行上述程序时的 MIPS 速率。（保留两位小数）

**(3)**（2 分）若该程序共执行 2×10⁸ 条指令，求该程序的执行时间。（结果用秒表示，保留三位小数）

---

## 设问结构与依赖

- **Q1（独立）**：加权平均 CPI = Σ(CPIᵢ × 比例ᵢ)，输入为指令 CPI/比例表。
- **Q2（依赖 Q1）**：MIPS = 主频 / (CPI × 10⁶)，输入为 Q1 的 CPI 结果 + 主频。
- **Q3（依赖 Q1）**：执行时间 = 总指令数 N × CPI / 主频，输入为 Q1 的 CPI 结果 + N + 主频。

串行链式依赖：Q1 → Q2，Q1 → Q3。

---

## 场景规则（通过条件）

本题成立 ⇔ 以下参数间约束被满足（与具体答案值无关，换参数仍成立）：

1. **比例归一化**：各类指令使用比例之和 == 100（百分比）。
2. **CPI 非平凡性**：至少存在两类指令 CPI 值不同（保证加权平均不是简单取值），且至少一类 CPI ≥ 3。
3. **加权 CPI 公式正确性**：CPI_weighted == Σ(CPIᵢ × ratioᵢ)，其中 ratioᵢ 为各类比例的小数形式（比例ᵢ / 100）。
4. **MIPS 公式正确性**：MIPS == 主频(Hz) / (CPI_weighted × 10⁶)。
5. **执行时间公式正确性**：exec_time == N × CPI_weighted / 主频(Hz)，且结果应在毫秒~秒量级（0.001 s ≤ exec_time ≤ 10 s）。
6. **公式链一致性**：exec_time == N / (MIPS × 10⁶)（即 Q2 与 Q3 两种路径给出的执行时间一致）。
7. **MIPS 非整数**：MIPS 结果为非整数（保证计算有区分度，不退化）。

---

## 考察意图与知识点覆盖

| 子问 | 考察知识点 | K目标 |
|------|-----------|-------|
| Q1 | 加权平均 CPI 的计算方法 | K3=3（多步加权计算链） |
| Q2 | MIPS 公式及主频单位换算 | K1=3（公式记忆）+ K4=2（单位换算） |
| Q3 | 执行时间公式，与 CPI/主频的串联关系 | K2=3（非 2 幂次整数运算）+ K4=2（量级判断） |

### 典型陷阱（审核参考）

1. MIPS 公式中主频单位未换算到 Hz（误用 MHz 直接代入）。
2. 加权平均 CPI 未将百分比转换为小数。
3. 执行时间与 MIPS 的关系混淆（误用 MIPS × N 等）。
4. 执行时间量级判断错误（s / ms / μs 混淆）。
