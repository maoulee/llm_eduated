## 考点
- **核心考点：CPI 计算** — 给定指令类别及各类指令的 CPI 与使用比例，要求用加权平均公式求出整体 CPI。侧重公式正确代入与加权求和。
- **核心考点：MIPS 计算** — 给定主频，要求由 CPI 和主频推导 MIPS。侧重 MIPS = 主频 / (CPI × 10⁶) 公式的正确使用及单位统一。
- **辅助考点：执行时间** — 在给定程序总指令数的前提下，计算程序执行时间，考察 CPI、指令数、主频三者关系的综合运用。

## 难度目标
- **K1 = 3（标准）**：必须准确记忆 CPI 加权平均公式和 MIPS 公式，这是入题前提。
- **K2 = 3（标准）**：需代入常规公式计算，涉及非 2 的幂次整数乘除，数字不极端但需仔细。执行时间计算涉及多步算术。
- **K3 = 3（标准）**：需按固定流程走完 3-5 步（求各类指令 CPI 贡献 → 加权求和 CPI → 求 MIPS → 求执行时间），路径唯一但步骤完整。
- **K4 = 2（较低）**：存在常规注意点——主频单位换算（MHz/GHz）、MIPS 与执行时间的单位一致性，但无深层陷阱。
- **K5 = 1（微弱）**：单一知识点（CPU 性能）内部解决，不涉及跨子系统。

## 考察模式
**综合题——给指令 CPI/比例表 + 主频，求 CPI 和 MIPS**
经典 408 考察模式：题干给出一张指令类别表（每类指令的 CPI 和使用比例/条数），要求依次计算 CPI、MIPS 及衍生量（执行时间）。该模式直接覆盖 K3 串行计算链，每步依赖上一步结果，区分度好。

## 出题要求
- 题型：综合题（简答），总分 6 分
- 总条件数：2 个显式条件——① 指令 CPI 与使用比例表（≥3 类指令）；② CPU 主频（带单位）
- 条件设计原则：
  - 指令类别表给出每类指令的 CPI 和使用比例，比例之和为 100%
  - 主频给出明确单位（MHz 或 GHz），数字非极端
  - 可追加一个衍生条件（程序总指令数），用于执行时间计算
- 参数取值范围要求：
  - 指令 CPI：各类取值在 1-6 之间，至少有一类 CPI ≥ 3，保证加权非平凡
  - 使用比例：3-5 类指令，比例均为整数百分比，和为 100%
  - 主频：数百 MHz 至数 GHz 之间，使 MIPS 计算结果为有区分度的非整数
  - 程序总指令数：10⁶ 量级，使执行时间计算结果合理

## 子问题规划
| 子问题 | 类型 | 考察目标 | 分值 | 与前后问关系 |
|--------|------|---------|------|-------------|
| 第1问 | 计算 | 加权平均 CPI 计算，正确代入各类指令 CPI 与比例 | 2 | 独立，后续问依赖此结果 |
| 第2问 | 计算 | 由 CPI 和主频求 MIPS，需正确使用公式和单位换算 | 2 | 依赖第1问结果 |
| 第3问 | 计算 | 给定程序总指令数，求程序执行时间 | 2 | 依赖第1问（或第2问）结果 |

依赖关系：串行链式，第1问 → 第2问 → 第3问。

## 参数约束
- **指令类别数**：3-5 类，≥3 类保证加权有意义
- **各类 CPI**：取值 1-6，至少两类 CPI 不同，至少一类 CPI ≥ 3
- **各类比例**：正整数百分比，和严格 = 100
- **主频 f**：取值范围 500MHz - 4GHz，需与 CPI 配合使 MIPS 结果为非整数（便于区分对错）
- **程序总指令数 N**：10⁶ - 10⁹ 量级，使执行时间在合理范围（毫秒~秒级）
- **一致性约束**：CPI × 各类比例加权求和必须为可表示的分数或有限小数；MIPS = f / (CPI × 10⁶) 必须产生有区分度的结果
- **可调自由度**：指令类别数、具体 CPI 值、比例分配、主频值、指令数均可由 Question Agent 自行选择，只要满足上述约束

## 参考经验
- **考察模式**：CPI/比例表 + 主频 → 求 CPI、MIPS、执行时间，是 408 组成原理 CPU 性能模块的经典综合题模式。
- **难度锚点**：K3=3 为主，计算链 3-5 步，路径唯一，区分度来自计算准确性而非机制理解深度。
- **典型陷阱**：
  1. 主频单位换算错误（MHz vs GHz vs Hz）
  2. 加权平均时忘记归一化（比例直接当条数用）
  3. MIPS 公式记忆错误（误用 CPI = 主频/MIPS 等）
  4. 执行时间计算时混淆"指令数 × CPI / 主频"与"MIPS"路径
