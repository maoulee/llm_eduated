## 考点
1. **同步总线时序**：同步总线一次传输事务需要多少个时钟周期（地址周期 + 数据周期 + 可能的等待周期）
2. **总线带宽公式**：带宽 = (每次传输的数据量 × 总线时钟频率) / (完成一次传输所需的时钟周期数)，单位换算为 MB/s
3. **突发传输（burst）**：连续传送多个数据字时，后续数据只需数据周期、无需重复地址周期，提升有效带宽
4. **单位换算**：bit ↔ Byte、MHz ↔ 10^6、MB/s 的进制约定（1 MB = 10^6 B 或 2^20 B，题目需约定）

## 难度目标
- **K1=3（标准）**：必须准确记忆同步总线传输事务的时钟周期构成（地址阶段 + 数据阶段）以及带宽计算公式，概念模糊无法入题。
- **K2=3（标准）**：需代入带宽公式计算，涉及 bit→Byte 换算和 MHz→10^6 换算，可能出现非 2 的幂次（如时钟频率为非 2 的幂）。
- **K3=3（标准）**：需按固定流程走 3-5 步——确定单次事务周期数 → 算单次事务传输字节数 → 算每秒事务数 → 算带宽 →（第 2 问）突发模式下重新计算。路径唯一但步骤明确。
- **K4=2（较低）**：存在常规注意点——地址周期不传输数据、突发模式后续无需地址周期。408 考生基本不会踩坑，但需意识到地址周期占时间不占带宽。
- **K5=2（较低）**：总线系统内部解决，提及 CPU/存储器但无实质性跨系统数据传递。
- **difficulty_level=3**：K3 为主控维度，计算步骤清晰但不繁杂，配合突发模式分析增加一层思考。

## 考察模式
**综合题——给总线时钟频率/宽度/事务周期数，求带宽 MB/s**
- 选择此模式的理由：这是 408 总线带宽计算的标准考法，直接考查带宽公式的理解和单位换算能力。第 1 问基础计算锁定 K2/K3 标准等级，第 2 问突发模式分析提升 K3/K4 的区分度。

## 出题要求
- **题型**：综合简答题（计算 + 分析）
- **总分**：6 分
- **总条件数**：3-4 个显式条件（时钟频率、总线宽度、单次事务所需时钟周期数、突发传输块大小或连续数据数量）
- **条件设计原则**：
  - 给出同步总线时钟频率（非 2 的幂，如 50/100/66 MHz 等）
  - 给出总线宽度（8/16/32/64 bits）
  - 给出完成一次总线事务（地址 + 数据）所需的时钟周期数
  - 第 2 问给出突发传输场景参数
- **参数取值范围要求**：
  - 时钟频率：50-200 MHz，避免纯 2 的幂以使计算有区分度
  - 总线宽度：8/16/32/64 bits 中选一
  - 事务周期数：2-5 个时钟周期（含地址阶段）
  - 突发块大小：4-8 个数据字

## 子问题规划
- **第 1 问（4 分）— 计算**：给定同步总线时钟频率、总线宽度、单次总线事务所需时钟周期数，求该总线最大数据传输带宽（MB/s）。
  - 类型：计算
  - 考察目标：带宽公式 + 单位换算
  - 关系：独立，为第 2 问提供对比基准

- **第 2 问（2 分）— 分析**：若采用突发传输方式，连续传送 N 个数据字，求此时的有效带宽或带宽提升倍数。
  - 类型：分析/计算
  - 考察目标：理解突发传输下地址周期分摊机制，重新计算有效带宽
  - 关系：依赖第 1 问的基础周期数，需调整分母

## 参数约束
- **总线时钟频率 f**：50-200 MHz，取非 2 的幂整数值（如 50/66/100/133 MHz），使带宽计算结果非平凡
- **总线宽度 w**：8/16/32/64 bits，选定后题目全篇一致
- **单次事务时钟周期数 C**：2-5（含地址阶段 1 周期 + 数据阶段，或额外等待周期），C ≥ 2
- **突发传输数据字数 N**：4-8，N > 1 保证突发模式有明显带宽提升
- **一致性约束**：w 与 f 的组合应使第 1 问结果在合理带宽范围（50-2000 MB/s），避免过大或过小
- **可调自由度**：Question Agent 可自由选择 f、w、C、N 的具体值，只要满足上述范围和一致性约束
- **进制约定**：题目需明确 MB 采用 10^6 还是 2^20 字节（408 惯例 1 MB/s = 10^6 B/s）

## 参考经验
- **考察模式**：同步总线带宽计算是 408 高频考点，核心公式为 带宽 = (w/8) × f / C（MB/s），其中 C 为单次事务周期数
- **难度锚点**：标准题 K3=3，计算步骤 3-4 步，配合突发模式可达到 K3=3+K4=2 的综合难度
- **典型陷阱**：
  1. 忘记地址周期也占时间但不传输数据 → 分母用错
  2. bit 与 Byte 混淆 → 宽度未除以 8
  3. 突发模式下误以为每次传输仍需地址周期 → 带宽低估
  4. 1 MB/s 的进制约定不一致（10^6 vs 2^20）
