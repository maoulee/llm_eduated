# 同步总线带宽计算

## 题目

某同步总线采用如下参数：

- 总线时钟频率 $f = 66$ MHz（非 2 的幂整数）
- 总线数据宽度 $w = 32$ bit
- 每次总线事务包含 1 个地址周期和若干数据周期；完成一次单字（4 字节）数据传输共需 $C = 3$ 个时钟周期（含地址周期）
- 突发传输：1 个地址周期后连续传输 $N = 4$ 个数据字，每个数据字仍占用 1 个数据周期
- 进制约定：$1\ \text{MB/s} = 10^{6}\ \text{B/s}$（十进制兆字节）

请回答以下问题：

**第 1 问（4 分）**：计算该总线在单字传输模式下的最大数据传输带宽（单位：MB/s）。写出计算过程。

**第 2 问（2 分）**：若改为突发传输模式（传输 $N = 4$ 个数据字），计算突发传输的有效带宽（MB/s），并求突发模式相对于单字模式的带宽提升倍数（保留两位小数）。

---

## 设问骨架说明

| 子问 | 考察点 | 预期流程 |
|------|--------|----------|
| Q1 | 同步总线标准带宽计算 | 每周期传输字节数 → 单事务总周期数 → 带宽 = (w/8) × f / C（MB/s） |
| Q2 | 突发传输带宽分析 | 突发事务总周期数 = 1(地址) + N(数据) → 突发数据量 = N×(w/8) 字节 → 突发带宽 = N×(w/8) × f / (1+N) → 提升倍数 = 突发带宽 / 单字带宽 |

---

## 陷阱说明（供审核参考）

- **陷阱 1（分母用错）**：地址周期占时间但不传数据，单字带宽的正确分母应为总周期数 C（含地址周期），而非仅数据周期数。
- **陷阱 2（单位混淆）**：总线宽度 w 单位为 bit，必须除以 8 转换为 Byte 后再参与带宽计算。
- **陷阱 3（突发模式分母）**：突发传输 N 个字，地址周期只占 1 次，总周期数为 1 + N（本题中 1 个地址周期 + 4 个数据周期），而非 N×C。
- **陷阱 4（进制约定）**：MB/s 采用 $10^{6}$ 字节/秒，非 $2^{20}$。

## 场景规则（本题成立 ⇔ 参数间约束，换参数仍成立）

以下约束与具体答案值无关，随参数取值变化始终应被满足：

1. **单字带宽公式一致性**：$\text{BW}_{\text{single}} = \dfrac{(w / 8) \times f}{C}$，单位 MB/s，其中 $f$ 以 MHz（$10^6$ Hz）代入，$w$ 以 bit 代入，$w/8$ 得到每周期传输字节数（Byte）。
   - 即：`BW_single == (w // 8) * f / C`，且 `(w // 8) * f % C` 不必为整除（允许非整数带宽）。

2. **突发带宽公式一致性**：$\text{BW}_{\text{burst}} = \dfrac{N \times (w / 8) \times f}{1 + N}$，其中突发事务总周期数为 $1$（地址周期）$+ N$（数据周期）。
   - 即：`BW_burst == N * (w // 8) * f / (1 + N)`。

3. **周期数守恒**：单字事务总周期数 $C = 1$（地址）$+ (C - 1)$（数据），即 $C \geq 2$。突发事务中每个数据字占 1 个数据周期，与单字事务的数据周期数 $C - 1$ 无矛盾（本题 $C - 1 = 2$，数据周期长度与突发中每个数据周期相同，但突发模式下每数据周期传 1 个字）。
   - **修正说明**：本题突发模式中，每个数据周期传输 1 个字，地址周期为 1 个周期；单字模式中地址阶段 1 周期 + 数据阶段 $(C-1)$ 周期。两种模式下"数据周期"的定义需一致：每数据周期传输 $w/8$ 字节。
   - 可证伪条件：`C >= 2` 且 `N > 1`。

4. **带宽提升倍数一致性**：$\text{ratio} = \dfrac{\text{BW}_{\text{burst}}}{\text{BW}_{\text{single}}}$，即 `ratio == BW_burst / BW_single`。由于地址开销在突发模式下被摊薄，`ratio > 1` 必须成立。
   - 可证伪条件：`BW_burst / BW_single > 1`，即突发模式带宽必须高于单字模式。

5. **参数范围约束**：$f \in [50, 200]$ MHz 且非 2 的幂；$w \in \{8, 16, 32, 64\}$；$C \in [2, 5]$；$N \in [4, 8]$ 且 $N > 1$。
