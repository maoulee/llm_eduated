# IEEE754 单精度浮点加法运算结果判断

## 题干

已知两个 IEEE 754 单精度（32 位）浮点数，其十六进制表示如下：

- **操作数 A** = `0x41266666`
- **操作数 B** = `0x3F8CCCCC`

两个浮点数均为**规格化正数**，符号位均为 0。

现对 A 和 B 执行**加法运算**（A + B），舍入模式采用 **舍入到最近偶数（round to nearest even, 默认模式）**。

请按照 IEEE 754 浮点加减运算的完整流程（对阶 → 尾数运算 → 规格化 → 舍入 → 再规格化）计算 A + B 的最终结果，选出其 IEEE 754 单精度十六进制表示。

## 选项

A. `0x41380000` —— 正确结果（完整执行对阶 → 尾数运算 → 规格化 → 舍入 → 再规格化后得到的 IEEE 754 单精度十六进制值）

B. `0x3FB80000` —— 对阶方向错误的结果——将对阶方向颠倒（大阶向小阶对齐，即左移大阶数的尾数、保留小阶）后继续运算得到的最终十六进制值

C. `0x40D00000` —— 忽略隐含位（规格化数的隐含前导 1）的结果——在尾数运算与规格化过程中将尾数视为纯小数 0.xxxx 而非 1.xxxx 处理后得到的最终十六进制值

D. `0x4137FFFF` —— 不执行舍入的结果——执行对阶、尾数运算后，直接丢弃对阶时移出的低位（truncation，即向零截断），不采用 round to nearest even 规则进行舍入修正，得到的最终十六进制值

## 场景规则（本题成立 ⇔ 以下参数间约束满足）

1. **对阶方向正确性**：浮点加减运算中，对阶必须遵循"小阶向大阶看齐"——阶码较小（真值指数较小）的操作数尾数右移、阶码递增，直到两阶码相等。题目成立要求此规则在运算中生效，且对阶移位位数 = A 的真值指数 − B 的真值指数 = 两操作数阶码字段之差 ∈ [2, 5]。

2. **隐含位处理正确性**：规格化 IEEE 754 单精度数的有效尾数为 1.xxxx₂（隐含前导 1），共 24 位有效位。题目成立要求运算全程正确处理隐含位。

3. **舍入触发条件**：对阶导致 B 的尾数右移 ≥ 2 位，移出的低位非全零 → 触发舍入判定。题目成立要求 round to nearest even 舍入规则在运算中实际生效（即存在被移出的有效位，舍入操作非空操作）。

4. **结果合法性**：A + B 的最终结果为规格化正数，非 ±∞、非 ±0、非 NaN。

5. **选项互异性**：A/B/C/D 四个选项的十六进制值各不相同。

6. **正确值唯一确定**：在给定参数和舍入模式下，A + B 有唯一确定的 IEEE 754 单精度结果，对应选项 A。

7. **干扰项对应声明错误类型**：
   - B = 犯"对阶方向错误"（大阶向小阶对齐）后按其余步骤正常运算得到的值。
   - C = 犯"忽略隐含位"（尾数按 0.xxxx 而非 1.xxxx 处理）后按其余步骤正常运算得到的值。
   - D = 犯"不执行舍入"（直接丢弃对阶移出的低位，truncation而非round to nearest even）后得到的值。
   - 每个干扰项是同类题常见误算的真实产物，非随机扰动值。

## 参数约束说明

- 操作数 A 的真值指数为 3（阶码字段 = 130），对应真值 ∈ [1.0, 100.0)。
- 操作数 B 的真值指数为 0（阶码字段 = 127），对应真值 ∈ [0.1, 50.0)。
- 两操作数阶码差 = 3，满足 ∈ [2, 5]。
- 两操作数尾数均为非整数小数，隐含位后含丰富的有效位（≥ 3 位）。
- 对阶后 B 的尾数需右移 3 位（≥ 2 位），保证低有效位被移出 → 触发舍入。
- 运算类型为同号（正数）加法，结果为规格化正数。
