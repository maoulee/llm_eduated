## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 数据表示与运算 > IEEE754
- primary_target_name: IEEE754 浮点表示与运算
- question_type: single_choice
- examination_mode: 计算型——IEEE754 浮点加减结果判断

### 难度目标
- k_target: K1=3,K2=3,K3=4,K4=3,K5=1
- difficulty_level: 3
- difficulty_rationale: 以浮点加减完整推演流程（对阶→尾数运算→规格化→舍入→再规格化）为核心负载，K3=4 主导难度；K4=3 来自对阶方向/隐含位/舍入后规格化等明确陷阱；K1/K2 为标准水平，K5=1 单知识点内解决

### 结构要求
- option_count: 4（1 正确 + 3 干扰）
- distractor_strategy: 干扰项分别对应三种典型错误路径——(1) 对阶方向错误 (2) 忽略隐含位 (3) 舍入后未做再规格化/规格化方向混淆
- condition_count: 2-3（两个操作数的 IEEE754 单精度十六进制表示 + 运算类型 + 舍入模式声明）

### 参数约束
- 操作数A阶码: 对应真值 [1.0, 100.0)，规格化正小数
- 操作数B阶码: 对应真值 [0.1, 50.0)，规格化正小数
- A与B阶码差: ∈ [2, 5]，保证对阶步骤非平凡
- A与B尾数: 均为非整数小数，隐含位后至少3位有效位
- 对阶后B的尾数右移位数: ≥ 2，保证至少丢失1位精度触发舍入判断
- 运算类型: 加法（同号相加），结果为规格化正数
- 结果约束: 非 ±∞/±0/NaN，聚焦规格化结果判断
- 舍入模式: round to nearest even，题目须明确声明

### 参考经验摘要
- 历史模式: IEEE754 浮点加减是组成原理高频经典考点，考察形式为"给定浮点数表示→判断运算结果"
- 难度锚点: K3 通常 3-4，K4 通常 2-3
- 典型陷阱: 对阶方向（小阶向大阶）、隐含位处理、舍入后再规格化、偏移量127的加减
