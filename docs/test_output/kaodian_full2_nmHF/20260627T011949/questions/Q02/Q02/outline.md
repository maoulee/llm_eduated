## 考点
- **核心知识点**：IEEE754 浮点加减运算（对阶→尾数运算→规格化→舍入→溢出判断）
  - 考察侧重点：给定两个 IEEE754 单精度浮点数的十六进制/二进制表示，要求判断加减运算后的结果（尾数、阶码、特殊值）是否正确
- **辅助知识点**：IEEE754 单精度格式（1 符号位 + 8 阶码 + 23 尾数，偏移量 127，隐含最高位 1）
  - 考察侧重点：规格化数的表示规则、非规格化数边界、阶码全 0/全 1 的特殊含义

## 难度目标
| 维度 | 目标 | 达标理由 |
|------|------|----------|
| K1 | 3 | 必须准确记忆 IEEE754 格式定义（隐含位、偏移量 127、对阶规则）才能入题，属标准记忆需求 |
| K2 | 3 | 尾数加减涉及非 2 的幂次的小数运算，需代入常规公式计算，属标准单步计算 |
| K3 | 4 | 浮点加减需走完"对阶→尾数加减→规格化→舍入→溢出判断"5 步以上流程，中间需维持动态状态更新（阶码变化追踪） |
| K4 | 3 | 存在明确陷阱：对阶方向（小阶向大阶看齐）、隐含位处理、舍入可能触发再规格化，不触发就会用错规则 |
| K5 | 1 | 单一知识点内部解决，不涉及其他子系统 |

## 考察模式
**计算型——IEEE754 浮点加减结果判断**

理由：该模式直接考查浮点加减的完整推演流程（K3 主导），同时通过隐含位/对阶方向/舍入等陷阱考查 K4。给定两个浮点数的二进制/十六进制表示，要求计算加减结果并从选项中选出正确答案（正确结果的十六进制表示或特定字段的值）。这是 408 组成原理浮点运算的经典考察形式。

## 出题要求
- **题型**：单项选择题，4 选项 1 正确 3 干扰，2 分
- **条件数**：2-3 个显式条件（两个操作数的表示 + 运算类型）
- **条件设计原则**：
  - 操作数以 IEEE754 单精度的十六进制形式给出（32 位十六进制，如 0x40490FDB）
  - 明确指定运算为加法或减法
  - 可附加说明"采用就近舍入（round to nearest even）"
- **参数取值范围要求**：
  - 两操作数阶码差 ≥ 2，保证对阶步骤非平凡（对阶错误必然产生不同结果）
  - 至少一个操作数为规格化正小数（非整数），保证尾数运算涉及小数位
  - 避免结果为 ±∞ 或 ±0 等特殊值（本轮不考溢出/下溢边界，聚焦规格化结果判断）
  - 避免两数相等（减法）或互为相反数（加法），防止平凡结果

## 子问题规划
单项选择题，无子问题划分。选项设计如下：
- 正确选项：加减运算后正确的 IEEE754 结果（十六进制表示或阶码+尾数字段值）
- 干扰项策略：
  - 干扰 1：对阶方向错误（大阶向小阶看齐），导致尾数溢出或结果量级错误
  - 干扰 2：忽略隐含位（将尾数当作纯小数 .xxxx 处理），结果阶码偏移
  - 干扰 3：舍入后未做再规格化，或规格化方向错误（左规/右规混淆）

## 参数约束
| 参数 | 取值范围 | 约束关系 |
|------|----------|----------|
| 操作数 A（阶码） | 对应真值范围 [1.0, 100.0)，单精度可表示 | A 与 B 的阶码差 ≥ 2 |
| 操作数 B（阶码） | 对应真值范围 [0.1, 50.0)，单精度可表示 | B 的阶码 < A 的阶码，差值 ∈ [2, 5] |
| 操作数 A（尾数） | 非整数小数（如 x.xxxx），隐含位后至少 3 位有效 | 尾数加减后需规格化（非平凡） |
| 操作数 B（尾数） | 非整数小数，与 A 符号相同（加法场景） | B 经对阶右移后至少丢失 1 位精度（触发舍入判断） |
| 运算类型 | 加法（同号相加） | 两正数相加，结果仍为规格化正数，不涉及符号处理复杂度 |
| 舍入模式 | 就近舍入（round to nearest even） | 题目需明确声明，避免歧义 |

**自由度说明**：Question Agent 可在上述约束内自由选择具体数值，关键是保证"阶码差 ≥ 2"和"对阶后触发舍入"两个条件成立，以确保 K3 和 K4 考察点能被测出。

## 参考经验
- **历史模式**：IEEE754 浮点加减是组成原理高频考点，经典考察形式为"给定两个浮点数表示 → 判断运算结果"
- **难度锚点**：该题型 K3 通常为 3-4（取决于步数和中间状态复杂度），K4 为 2-3（取决于陷阱深度）
- **典型陷阱**：
  - 对阶方向（小阶向大阶，尾数右移）
  - 隐含最高位 1 的处理（运算时需补回）
  - 舍入后可能触发再规格化（右规）
  - 阶码偏移量 127 的加减（非真实指数直接加减）
