# 综合题：DRAM 芯片存储器扩展设计

## 设计意图

本题考察 DRAM 存储器扩展设计的完整链路：芯片数计算（位扩展+字扩展组合判断）、地址线划分（片内地址 vs 片选地址、行/列地址复用）、片选逻辑（译码器文字描述）、异步刷新信号周期计算。难度以 K4 为主导——组合扩展判断、地址复用导致地址位数分析、刷新公式选择等隐含前提构成核心难点。纯文字推导，不涉及画图。

---

## 题目正文

某计算机 CPU 的地址总线宽度为 **20 位**，数据总线宽度为 **16 位**，**按字编址**（每个地址对应一个 16 位的存储单元）。现需要用 **64K×4 位的 DRAM 芯片** 构建与该 CPU 连接的完整主存储器。

该 DRAM 芯片采用**地址复用**方式，外部地址引脚数为芯片地址位数的一半，分为行地址与列地址两部分，两部分的位数相等。

该 DRAM 芯片要求在 **2 ms** 内完成所有行的刷新操作，采用**异步刷新**方式（即在 2 ms 内将所有行均匀刷新一遍）。

请回答以下问题：

### 问题 1（3 分）

构建该存储器需要多少片 64K×4 位的 DRAM 芯片？请分别写出位扩展所需的芯片数、字扩展所需的芯片组数，以及总芯片数，并简要说明计算依据。

### 问题 2（3 分）

该存储器的 CPU 地址线应如何划分？请写明哪些地址线用作片内地址（进一步分解为行地址和列地址），哪些地址线用作片选地址，并列出全部芯片组的地址范围（用十六进制表示）。

### 问题 3（2 分）

用文字描述片选逻辑的设计方案：说明如何使用片选地址线产生各芯片组的片选信号（可使用译码器），各译码器输出与芯片组的对应关系。

### 问题 4（2 分）

计算异步刷新方式下，刷新信号的周期（即两次刷新操作之间的时间间隔）为多少？请写出计算过程。

## 参数清单

| 参数 | 值 | 说明 |
|------|-----|------|
| cpu_address_width | 20 | CPU 地址总线宽度（位） |
| data_bus_width | 16 | CPU 数据总线宽度（位） |
| addressing_mode | 字编址 | 每个地址 = 1 个 16 位存储单元 |
| chip_word_count | 64K (= 2^16) | DRAM 芯片字数 |
| chip_data_width | 4 | DRAM 芯片位宽（位） |
| chip_internal_addr_bits | 16 | 芯片内地址位数 = log2(字数) |
| address_multiplexing | 是 | 行地址与列地址位数相等 |
| refresh_interval | 2 ms | 全部行刷新的时间窗口 |
| refresh_mode | 异步刷新 | 在 2 ms 内均匀刷新所有行 |

## 场景规则（本题成立需要满足的可机检约束）

以下为参数间必须成立的约束关系，与具体答案值无关，换参数仍成立：

1. **位扩展约束**：bit_expansion_count == data_bus_width / chip_data_width（位扩展数 = 数据总线宽度 ÷ 芯片位宽，须为整数且 ≥ 2）。
2. **片内地址约束**：chip_internal_addr_bits == log2(chip_word_count)（芯片内地址位数 = 芯片字数以 2 为底的对数）。
3. **片选地址约束**：chip_select_lines == cpu_address_width - chip_internal_addr_bits（片选地址线数 = CPU 地址总线宽度 − 片内地址位数，须 ≥ 2）。
4. **字扩展约束**：word_expansion_count == 2^chip_select_lines（字扩展数 = 2 的片选线数次方，须 ≥ 2）。
5. **总芯片数约束**：total_chips == bit_expansion_count × word_expansion_count（总芯片数 = 位扩展数 × 字扩展数）。
6. **地址复用约束**：row_addr_bits == chip_internal_addr_bits / 2 且 col_addr_bits == chip_internal_addr_bits / 2（行地址位数 = 列地址位数 = 芯片地址位数的一半，须为整数）。
7. **行数约束**：chip_rows == 2^row_addr_bits（芯片行数 = 2 的行地址位数次方）。
8. **异步刷新周期约束**：async_refresh_period == refresh_interval / chip_rows（异步刷新周期 = 刷新间隔 ÷ 芯片行数）。
9. **地址范围覆盖约束**：所有芯片组的地址范围连续且覆盖 CPU 全部地址空间 [0, 2^cpu_address_width − 1]，无重叠、无遗漏。
