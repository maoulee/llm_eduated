## 考点
- **核心考点：DRAM 芯片扩展设计**——给定 DRAM 芯片容量和目标存储器容量，推导所需芯片数量（位扩展+字扩展的组合）
- **辅助考点 1：地址分配**——将 CPU 地址线划分为片内地址与片选地址，给出各芯片组的地址范围
- **辅助考点 2：片选逻辑（文字描述）**——用文字描述片选信号的产生方式（如用高位地址线经译码器产生片选），不要求画连接图
- **辅助考点 3：异步刷新周期计算**——根据 DRAM 刷新间隔和存储矩阵行数，计算异步刷新信号的时间间隔

## 难度目标
- **K1=3**：需准确记忆位扩展与字扩展的概念、地址线划分规则、异步刷新公式（刷新间隔/行数），属标准概念入题
- **K2=3**：芯片数量计算需代入公式（总容量/芯片容量，分位扩展和字扩展），地址范围计算涉及 2 的幂运算，难度适中
- **K3=3**：从芯片容量→芯片数→地址划分→片选逻辑→刷新周期，需按固定流程走完 4-5 步，路径唯一
- **K4=4**：**主导维度**。隐含前提较深——学生需自行判断位扩展与字扩展的组合方式（并非简单除法），地址线划分需注意位扩展不增加地址线而字扩展需增加片选线，刷新计算需区分集中刷新与异步刷新并选对公式
- **K5=2**：仅涉及 DRAM 芯片与 CPU 地址总线之间的逻辑连接，不跨子系统，关联度较低

达标理由：target_difficulty=4，K4 为主导。本题核心难点在于学生需正确识别扩展组合方式并自行完成地址空间分配逻辑，属于"机制本质理解"层面的隐含前提，符合 K4=4 定位。其余维度围绕核心考点配合设定。

## 考察模式
**设计题——用小容量 DRAM 芯片设计大容量存储器**（来自 slot examination_mode）。
理由：这是存储器扩展章节的经典考法，要求学生从芯片参数出发，完整推导芯片数量、地址分配、片选方案和刷新参数，覆盖该知识点的全链路。纯文字推导，禁止要求画图（hard_constraints 约束）。

## 出题要求
- **题型**：综合设计题（文字推导型）
- **总分**：10 分
- **条件设计原则**：题干给出 ① CPU 地址总线宽度（或寻址空间）② 数据总线宽度 ③ DRAM 芯片的规格（容量×位宽）④ DRAM 刷新周期参数（最大刷新间隔、芯片内部行数或地址复用行地址位数）。条件必须自洽，保证存储器容量为芯片容量的整数倍。
- **参数取值范围要求**：芯片容量与目标存储器容量的比值应使位扩展数≥2、字扩展数≥2，避免退化为单一扩展方式；地址线宽度应使片选线≥2 根，有实际分配逻辑可推导。

## 子问题规划
| 子问题 | 类型 | 考察目标 | 分值 | 关系 |
|--------|------|----------|------|------|
| 第1问 | 计算 | 用给定芯片规格和目标存储器规格，推导位扩展数和字扩展数，得出总芯片数 | 3 | 独立，后续问的基础 |
| 第2问 | 分析 | 划分 CPU 地址线为片内地址线和片选地址线，写出各芯片组的地址范围（十六进制） | 3 | 依赖第1问结果 |
| 第3问 | 分析 | 文字描述片选逻辑：用哪些高位地址线、经何种译码方式产生各芯片组的片选信号 | 2 | 依赖第2问结果 |
| 第4问 | 计算 | 根据刷新间隔和芯片行数，计算异步刷新的刷新信号周期（两次刷新之间的时间间隔） | 2 | 独立，与前三问无数据依赖 |

依赖关系：第1→2→3 串行，第4问独立。

## 参数约束
- **CPU 地址总线宽度 A**：取值范围 16~24 位，需满足 A = 片内地址位数 + 片选地址位数
- **数据总线宽度 D**：16 位或 32 位
- **DRAM 芯片容量 C_chip**：以"字数×位宽"给出，位宽（1/2/4/8）须能整除数据总线宽度 D
- **DRAM 芯片字数**：2 的幂，取值范围 2^10 ~ 2^20
- **目标存储器容量**：由 A 和 D 隐含确定（2^A × D 位），或显式给出且须与 A、D 自洽
- **位扩展数 = D / 芯片位宽**，须 ≥2（保证有组合扩展的考察价值）
- **字扩展数 = 目标字数 / 芯片字数**，须 ≥2（保证有片选逻辑可推导）
- **片选地址位数 = A - 芯片地址位数**，须 ≥2（保证片选逻辑非平凡）
- **刷新最大间隔 T_refresh**：2ms 或 4ms（标准 DRAM 参数）
- **芯片行数 R**：由芯片地址复用的行地址位数决定，R = 2^(行地址位数)，行地址位数取值范围 7~10
- **一致性约束**：芯片地址位数 = 行地址位数 + 列地址位数（地址复用），且 = log2(芯片字数)

## 参考经验
- **历史模式**：存储器扩展设计题是 CO 存储系统章节的高频考法，典型流程为"芯片数→地址分配→片选→刷新"，4问结构覆盖完整链路
- **难度锚点**：此类题目 K4 偏高，核心陷阱在于位扩展/字扩展组合判断和地址线划分；K3 适中（固定流程），K2 适中（2的幂运算）
- **典型陷阱**：① 混淆位扩展和字扩展，导致芯片数算错；② 地址线划分时忘记地址复用（行/列地址分时复用），地址位数算错；③ 刷新计算用集中刷新公式而非异步刷新公式；④ 片选逻辑描述时忽略译码器需求
