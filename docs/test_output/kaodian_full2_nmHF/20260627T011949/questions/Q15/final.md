## 第 9 题

**题干**：计算机的 I/O 编址方式分为统一编址（存储器映射编址）和独立编址（I/O 端口编址）两种。关于这两种编址方式的比较，下列说法正确的是：

A. 统一编址方式下，I/O 端口与存储器共用同一地址空间，需要设置专门的 I/O 指令
B. 独立编址方式下，I/O 端口与存储器共用同一地址空间，不需要设置专门的 I/O 指令
C. 统一编址方式不需要专门的 I/O 指令，可用访存指令访问 I/O 端口；但会占用部分存储器地址空间
D. 独立编址方式不需要专门的 I/O 指令，且不占用存储器地址空间

---

## 第 9 题解析

**答案**：C
**解析**：统一编址（存储器映射编址）将 I/O 端口与存储器安排在同一地址空间中，因此不需要专门的 I/O 指令，可用访存指令访问 I/O 端口，代价是占用部分存储器地址空间，C 正确。A 错误，统一编址不需要专门的 I/O 指令；B 错误，独立编址下 I/O 端口与存储器各有独立的地址空间，需要专门的 I/O 指令（如 IN/OUT 指令）；D 错误，独立编址虽然不占用存储器地址空间，但需要专门的 I/O 指令来访问端口。
