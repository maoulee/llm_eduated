# 概念题

## 第 1 题

**题干**：某补码定点加减运算采用双符号位（变形补码）表示，运算结果的两个符号位分别为 1 和 0（即符号位组合为 10）。关于该运算结果，下列说法正确的是：

A. 未发生溢出，结果为负数
B. 发生了正溢出（上溢）
C. 发生了负溢出（下溢）
D. 符号位组合为 10 说明结果正常，无需任何处理

## 第 2 题

**题干**：关于 SRAM 和 DRAM 的特性，下列说法正确的是：

A. SRAM 依靠电容存储信息，需要定期刷新；DRAM 依靠触发器存储信息，不需要刷新
B. DRAM 的集成度低于 SRAM，但 DRAM 的存取速度比 SRAM 快
C. SRAM 依靠触发器存储信息，不需要刷新；DRAM 依靠电容存储信息，需要定期刷新
D. SRAM 和 DRAM 都需要定期刷新，只是刷新周期不同

## 第 3 题

**题干**：某计算机的 Cache 采用直接映射方式，主存块大小为 64B，Cache 共有 128 行。若某主存地址所在主存块号恰好与其映射到的 Cache 行号相同，则关于该访问的命中率，下列分析正确的是：

A. 直接映射方式下，只要主存块号与 Cache 行号相同就一定能命中
B. 直接映射方式下，该块能否命中取决于对应 Cache 行中当前存放的是否为该主存块，且标记（Tag）是否匹配
C. 直接映射方式下命中率固定为 50%，与映射关系无关
D. 直接映射方式下，任何主存块都可以映射到任意 Cache 行，因此命中率与行号无关

## 第 5 题

**题干**：在指令执行过程中，程序计数器（PC）和指令寄存器（IR）各自承担不同的功能。关于 PC 和 IR 的功能，下列说法正确的是：

A. PC 存放当前正在执行的指令，IR 存放下一条将要执行的指令地址
B. PC 存放当前指令的地址，IR 存放当前从主存中取出的指令
C. PC 和 IR 都存放指令地址，二者内容始终相同
D. PC 存放指令的操作码，IR 存放指令的操作数地址

## 第 6 题

**题干**：在集中式总线控制的三种基本方式（链式查询、计数器定时查询、独立请求方式）中，关于其特性的比较，下列说法正确的是：

A. 链式查询方式对电路故障最不敏感，且响应速度最快
B. 独立请求方式连线最少，且总线分配的优先级固定不可改变
C. 计数器定时查询方式的优先级设置较为灵活，其复杂度和连线数介于链式查询与独立请求方式之间
D. 三种方式中，独立请求方式的响应速度最慢，因为它需要逐个查询每个设备

## 第 7 题

**题干**：CPU 响应中断请求需要满足一定的条件和时机。关于中断响应的过程与时机，下列说法正确的是：

A. CPU 在任何时刻都可以立即响应可屏蔽中断请求，不需要等待当前指令执行完毕
B. CPU 在每条指令执行结束时检测中断请求信号，当满足响应条件（中断允许触发器为 1 且有中断请求）时，在当前指令执行完毕后进入中断响应周期
C. CPU 响应中断后，硬件自动完成的工作仅包括将中断服务程序入口地址送入 PC，保存断点（PC 和 PSW）由软件完成
D. 中断响应过程中，保护现场（保存各通用寄存器内容）由硬件自动完成，无需软件参与

## 第 8 题

**题干**：DMA 方式用于高速外设与主存之间的大批量数据传送。关于 DMA 的数据通路与周期挪用（周期窃取），下列说法正确的是：

A. DMA 数据传送过程中，数据需要经过 CPU 的寄存器进行中转
B. 周期挪用是指 DMA 控制器在 CPU 不使用总线时占用一个或多个存储周期进行数据传送，此时 CPU 可能需要暂停一个机器周期
C. DMA 方式完全不占用系统总线，因此对 CPU 的执行效率没有任何影响
D. 在 DMA 传送期间，CPU 始终处于空闲状态，无法执行任何指令

## 第 9 题

**题干**：计算机的 I/O 编址方式分为统一编址（存储器映射编址）和独立编址（I/O 端口编址）两种。关于这两种编址方式的比较，下列说法正确的是：

A. 统一编址方式下，I/O 端口与存储器共用同一地址空间，需要设置专门的 I/O 指令
B. 独立编址方式下，I/O 端口与存储器共用同一地址空间，不需要设置专门的 I/O 指令
C. 统一编址方式不需要专门的 I/O 指令，可用访存指令访问 I/O 端口；但会占用部分存储器地址空间
D. 独立编址方式不需要专门的 I/O 指令，且不占用存储器地址空间
