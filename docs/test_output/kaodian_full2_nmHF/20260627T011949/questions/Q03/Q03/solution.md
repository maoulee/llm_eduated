# 概念题解析

## 第 1 题解析

**答案**：C
**解析**：双符号位（变形补码）的溢出判定规则为：两个符号位相同（00 或 11）表示未溢出，两个符号位不同（01 或 10）表示溢出。其中 01 表示正溢出（上溢），10 表示负溢出（下溢）。题干中符号位为 10，即发生了负溢出（下溢），C 正确。A 错误，将 10 误判为未溢出；B 错误，将 10 的溢出方向误判为正溢出（01 才是正溢出）；D 错误，10 属于溢出状态，并非正常结果。

## 第 2 题解析

**答案**：C
**解析**：SRAM 利用触发器存储信息，只要不断电信息就不会丢失，不需要刷新；DRAM 利用电容存储信息，电容存在漏电现象，必须定期刷新以维持数据，C 正确。A 错误，将 SRAM 和 DRAM 的存储原理完全说反了；B 错误，DRAM 的集成度高于 SRAM（一个 DRAM 存储单元只需一个晶体管和一个电容），且 DRAM 速度通常慢于 SRAM；D 错误，SRAM 不需要刷新。

## 第 3 题解析

**答案**：B
**解析**：直接映射方式下，每个主存块只能映射到固定的某一行（由主存块号 mod Cache 行数决定），但能否命中取决于该 Cache 行当前存放的内容是否为该主存块，即标记（Tag）是否匹配，B 正确。A 错误，块号与行号相同只是映射关系，不代表该行当前存的就是这个块；C 错误，命中率取决于访存模式与替换情况，不是固定值；D 错误，描述的是全相联映射的特征，不是直接映射。

## 第 4 题解析

**答案**：C
**解析**：变址寻址的有效地址 EA = (RX) + D = 0010H + 0300H = 0310H，C 正确。A 错误，仅取形式地址，遗漏了变址寄存器的内容（对应直接寻址）；B 错误，仅取变址寄存器内容，遗漏了形式地址（对应寄存器间接寻址的效果）；D 错误，将加法误算为减法，方向错误。

## 第 5 题解析

**答案**：B
**解析**：PC（程序计数器）用于存放下一条要取的指令的地址（在指令取出后通常自动递增），IR（指令寄存器）用于存放当前从主存中取出的指令，B 正确。A 错误，将 PC 和 IR 的功能完全颠倒；C 错误，PC 存地址、IR 存指令，二者内容和功能不同；D 错误，PC 不存放操作码，IR 存放的是完整指令（含操作码和地址码）。

## 第 6 题解析

**答案**：C
**解析**：计数器定时查询方式通过计数器的值来确定响应哪个设备，改变计数器的初值和工作方式即可灵活设置优先级，其连线数和复杂度介于链式查询（连线最少）与独立请求方式（连线最多、响应最快）之间，C 正确。A 错误，链式查询方式对电路故障非常敏感（一个设备故障影响后续所有设备），且响应速度不是最快的；B 错误，独立请求方式连线最多，且优先级可由总线仲裁器灵活设置；D 错误，独立请求方式响应速度最快，因为它不需要逐个查询。

## 第 7 题解析

**答案**：B
**解析**：CPU 在每条指令执行完毕时检测中断请求信号，当中断允许（中断允许触发器 IF=1）且有中断请求时，才在当前指令结束后进入中断响应周期，B 正确。A 错误，CPU 不能在任意时刻打断指令执行，必须等当前指令执行完毕；C 错误，硬件自动完成的是"关中断、保存断点（PC 和 PSW）到特殊寄存器或栈、将中断服务程序入口地址送入 PC"，但并非所有体系结构都自动将返回地址压栈，这取决于具体实现；D 错误，保护现场（保存通用寄存器内容）通常由中断服务程序中的软件指令完成，硬件一般只负责保存断点（PC/PSW）。

## 第 8 题解析

**答案**：B
**解析**：周期挪用（周期窃取）是指 DMA 控制器在 CPU 不占用总线的存储周期（或机器周期）时，挪用一个总线周期进行数据传送，此时如果 CPU 也需要访存则需暂停一个周期，B 正确。A 错误，DMA 的核心特征就是数据直接在外设与主存之间传送，不经过 CPU 寄存器中转；C 错误，DMA 虽然不经过 CPU，但占用总线进行传送，当与 CPU 争用总线时会影响 CPU 效率；D 错误，周期挪用方式下 CPU 仅在争用总线时暂停一个周期，并非始终空闲。

## 第 9 题解析

**答案**：C
**解析**：统一编址（存储器映射编址）将 I/O 端口与存储器安排在同一地址空间中，因此不需要专门的 I/O 指令，可用访存指令访问 I/O 端口，代价是占用部分存储器地址空间，C 正确。A 错误，统一编址不需要专门的 I/O 指令；B 错误，独立编址下 I/O 端口与存储器各有独立的地址空间，需要专门的 I/O 指令（如 IN/OUT 指令）；D 错误，独立编址虽然不占用存储器地址空间，但需要专门的 I/O 指令来访问端口。
