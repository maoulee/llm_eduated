## 出题契约

### 基本信息
- target_subject: 组成原理
- target_family: CO-2 数据的表示和运算 > 定点数的运算
- primary_target_name: Booth算法（补码一位乘）
- question_type: comprehensive（主观应用题）
- examination_mode: 推演型——Booth算法逐步计算

### 难度目标
- k_target: K1=2,K2=3,K3=4,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 核心难度来自 K3=4（多趟串行迭代推演，步数>5步，需动态维护部分积与乘数双寄存器状态）。K2=3 提供常规计算负担，K1/K4/K5 为辅助。

### 结构要求
- sub_question_count: 2
- condition_count: 2（被乘数 x、乘数 y）
- score_allocation: 第(1)问 2分（补码转换/初始状态），第(2)问 6分（Booth迭代推演+乘积结果）

### 子问题结构
- 第(1)问: 计算题，2分。考察补码小数转换或初始状态确定，为第(2)问前置。
- 第(2)问: 算法推演题，6分。Booth算法逐趟列表推演，最终给乘积补码表示及真值。串行依赖第(1)问。
- dependency: 串行

### 参数约束
- x（被乘数）: 真值范围 [-0.9375, 0.9375]，5位补码小数（1符号+4数值），不可为0
- y（乘数）: 真值范围 [-0.9375, 0.9375]，5位补码小数，不可为0
- **硬约束**: y 补码序列必须同时包含相邻位 "01" 和 "10" 模式，保证加法和减法路径都被触发
- 正负组合: 建议 x、y 一正一负，确保符号位运算被测试
- 部分积: 采用双符号位（6位）
- 迭代趟数: 5趟（n=4 数值位 + 1 趟最后移位）
- 乘积: 双倍字长（10位），无溢出，真值可精确表示
- 条件呈现: Question Agent 可选"给真值要求转换"或"直接给补码"两种方式

### 参考经验摘要
- 历史模式: 无历史题目（reference_questions 为空），k_source=heuristic。采用期末核心算法题标准考法。
- 难度锚点: K3=4 为核心驱动（多步串行推演），K2=3 辅助（常规计算）。
- 典型陷阱:
  1. 最后一趟只移位不加减
  2. 双符号位部分积正确参与运算
  3. 附加位初始为0，与乘数同步右移
  4. 减法操作需先求 [-x]_补
