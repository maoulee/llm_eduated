# 题干

## 题目（8分）

用 **Booth 算法（补码一位乘法）** 计算两个 5 位补码小数的乘积。已知被乘数和乘数的真值为：

$$x = +0.5, \quad y = -0.625$$

**运算约定：**

- 字长：被乘数、乘数均为 **5 位补码小数**（1 位符号 + 4 位数值），小数点隐含在符号位与最高数值位之间。
- 部分积寄存器采用 **双符号位**（6 位），即 `PP = SS.xxxx`。
- 乘数寄存器最低位右侧附加 1 位 **附加位**，初始值为 `0`。
- 每趟根据"乘数最低位 + 附加位"的取值决定操作（见下表），之后部分积与乘数 **同步算术右移 1 位**。
- 迭代趟数为 **5 趟**（乘数 5 位，含 1 位符号位，每趟根据判断位决定加减后右移）。注意：补码小数乘数的符号位为负权重位，必须参与运算；当乘数为负时，第 5 趟判断位为 `10`，需执行 $+[-x]_\text{补}$ 后再移位。
- 最终乘积取 **双倍字长（10 位）**。

| 乘数最低位，附加位 | 操作 |
|:-:|:--|
| `0 0` | 部分积 + 0，右移 1 位 |
| `0 1` | 部分积 + `[x]_补`，右移 1 位 |
| `1 0` | 部分积 + `[-x]_补`，右移 1 位 |
| `1 1` | 部分积 + 0，右移 1 位 |

> 算术右移规则：双符号位部分积右移时，最高符号位保持不变（符号扩展）；乘数寄存器逻辑右移，移出的最低位进入附加位。

---

### 第(1)问（2分）

写出 $x$ 和 $y$ 的 **5 位补码小数表示** $[x]_\text{补}$、$[y]_\text{补}$，并求出 $[-x]_\text{补}$。给出 Booth 算法的 **初始状态**（部分积寄存器、乘数寄存器含附加位的值）。

### 第(2)问（6分）

按上述约定，用 **列表方式** 逐趟推演 Booth 算法的完整过程。每趟需列出：当前"乘数最低位 + 附加位"取值、执行的操作（加 0 / 加 $[x]_\text{补}$ / 加 $[-x]_\text{补}$）、加减后的部分积值、右移后的部分积与乘数（含附加位）值。

最终写出：

1. 乘积的 **10 位补码表示**；
2. 乘积的 **真值**。

---

## 通过条件（场景规则）

> 以下约束与具体答案值无关，换合法参数仍成立；供 gen.py `assert` 验证。

1. **补码有效性**：$[x]_\text{补}$ 和 $[y]_\text{补}$ 均为合法 5 位补码小数，其表示的真值分别等于给定的 $x$、$y$。验证：将补码按权展开还原的真值 == 题目给定真值。

2. **$[-x]_\text{补}$ 正确性**：$[-x]_\text{补}$ 是 $[x]_\text{补}$ 的逐位取反末位加 1 结果，且 $[x]_\text{补} + [-x]_\text{补} \equiv 0 \pmod{2}$（在 5 位补码小数模 2 意义下）。

3. **乘数位模式覆盖**：$[y]_\text{补}$ 的完整位序列（含符号位，共 5 位）中 **同时存在相邻位 "01" 和 "10"** 两种模式——保证 Booth 迭代中加法路径（01）和减法路径（10）均被触发。

4. **乘积正确性（核心）**：最终 10 位乘积补码按权展开的真值 == $x \times y$（精确等式）。验证：`product_value == x_true * y_true`。

5. **双符号位一致性**：每趟加减后、右移后的部分积均保持 6 位双符号位格式（`SS.xxxx`），算术右移时最高符号位保持不变（符号扩展），不丢失精度。

6. **符号位正确参与运算**：第 5 趟（处理乘数符号位）根据判断位正确执行加减操作后移位。对负乘数，判断位为 `10`，执行 $+[-x]_\text{补}$；对正乘数，判断位为 `00`，执行 $+0$（等价于仅移位）。

7. **无溢出**：乘积的 10 位补码表示合法，不发生溢出（真值在 $[-1, +1)$ 范围内可精确表示）。
