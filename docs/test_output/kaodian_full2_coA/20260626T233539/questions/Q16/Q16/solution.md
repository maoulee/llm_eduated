# 解答

## 第(1)问（2分）

### 补码小数表示

- $x = +0.5$：正数，补码 = 原码 $= \mathbf{0.1000}$

- $y = -0.625$：负数，$|y| = 0.625 = 0.1010$（原码），补码 = 原码数值位逐位取反末位加 1：取反得 $1.0101$，加 1 得 $\mathbf{1.0110}$

- $[-x]_\text{补}$：$[x]_\text{补} = 0.1000$，逐位取反得 $1.0111$，末位加 1 得 $\mathbf{1.1000}$

> 验证：$[x]_\text{补} + [-x]_\text{补} = 0.1000 + 1.1000 = 0.0000$（模 2 为 0），正确。

### 初始状态

| 寄存器 | 初始值 |
|:--|:--|
| 部分积 PP（6位双符号位） | $00.0000$ |
| 乘数 MQ（5位） | $10110$ |
| 附加位 | $0$ |

## 第(2)问（6分）

### Booth 算法逐趟推演

**初始**：$\text{PP} = 00.0000$，$\text{MQ} = 10110$，附加位 $= 0$

#### 第1趟

| 项目 | 值 |
|:--|:--|
| 当前 PP / MQ / 附加位 | $00.0000$ / $10110$ / $0$ |
| 判断位（MQ最低位 + 附加位） | $0,\;0 \Rightarrow 00$ |
| 操作 | $+0$ |
| 加减后 PP | $00.0000$ |
| 右移后 PP / MQ / 附加位 | $00.0000$ / $01011$ / $0$ |

#### 第2趟

| 项目 | 值 |
|:--|:--|
| 当前 PP / MQ / 附加位 | $00.0000$ / $01011$ / $0$ |
| 判断位（MQ最低位 + 附加位） | $1,\;0 \Rightarrow 10$ |
| 操作 | $+[-x]_\text{补} = +11.1000$ |
| 加减后 PP | $11.1000$ |
| 右移后 PP / MQ / 附加位 | $11.1100$ / $00101$ / $1$ |

> 算术右移：PP 双符号位最高位为 1，符号扩展，$11.1000 \to 11.1100$。

#### 第3趟

| 项目 | 值 |
|:--|:--|
| 当前 PP / MQ / 附加位 | $11.1100$ / $00101$ / $1$ |
| 判断位（MQ最低位 + 附加位） | $1,\;1 \Rightarrow 11$ |
| 操作 | $+0$ |
| 加减后 PP | $11.1100$ |
| 右移后 PP / MQ / 附加位 | $11.1110$ / $00010$ / $1$ |

> 符号扩展：$11.1100 \to 11.1110$。

#### 第4趟

| 项目 | 值 |
|:--|:--|
| 当前 PP / MQ / 附加位 | $11.1110$ / $00010$ / $1$ |
| 判断位（MQ最低位 + 附加位） | $0,\;1 \Rightarrow 01$ |
| 操作 | $+[x]_\text{补} = +00.1000$ |
| 加减后 PP | $00.0110$ |
| 右移后 PP / MQ / 附加位 | $00.0011$ / $00001$ / $0$ |

> $11.1110 + 00.1000 = 100.0110$，双符号位取低 6 位 $= 00.0110$。符号扩展：$00.0110 \to 00.0011$。

#### 第5趟

| 项目 | 值 |
|:--|:--|
| 当前 PP / MQ / 附加位 | $00.0011$ / $00001$ / $0$ |
| 判断位（MQ最低位 + 附加位） | $1,\;0 \Rightarrow 10$ |
| 操作 | $+[-x]_\text{补} = +11.1000$ |
| 加减后 PP | $11.1011$ |
| 右移后 PP / MQ / 附加位 | $11.1101$ / $10000$ / $1$ |

> 第 5 趟处理乘数符号位。乘数 $y = 1.0110$ 为负数，符号位（最高位）为 1，与前一数值位 0 构成判断位 $10$，需执行 $+[-x]_\text{补}$。$00.0011 + 11.1000 = 11.1011$。符号扩展：$11.1011 \to 11.1101$。

### 最终乘积

最终 $\text{PP} = 11.1101$，$\text{MQ} = 10000$。

取双符号位 PP 的低 5 位（去掉冗余的最高符号位）与 MQ 拼接，得到 **10 位乘积补码表示**：

$$\boxed{乘积 = 1.110110000 \quad (\text{即 } 1110110000_2)}$$

**乘积真值**：10 位乘积最高位为冗余符号位，有效位为低 9 位 $110110000$。按 9 位补码小数解码：

$$-1 + \frac{1}{2} + 0 \times \frac{1}{4} + \frac{1}{8} + \frac{1}{16} + 0 + 0 + 0 + 0 = -\frac{256}{256} + \frac{128}{256} + \frac{32}{256} + \frac{16}{256} = -\frac{80}{256} = -\frac{5}{16}$$

> 验证：$x \times y = \frac{1}{2} \times \left(-\frac{5}{8}\right) = -\frac{5}{16} = -0.3125$

$$\boxed{乘积真值 = -\frac{5}{16} = -0.3125}$$
