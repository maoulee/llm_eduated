# 海明码纠错定位 —— 求解过程

## 已知条件

- 7 位海明码，偶校验，接收码字 H₁H₂H₃H₄H₅H₆H₇ = **0 1 1 0 1 1 1**
- 排列规则：H₁=P₁, H₂=P₂, H₃=D₁, H₄=P₄, H₅=D₂, H₆=D₃, H₇=D₄
- 校验组：
  - P₁ 组：H₁、H₃、H₅、H₇
  - P₂ 组：H₂、H₃、H₆、H₇
  - P₄ 组：H₄、H₅、H₆、H₇

---

## 第 1 问：计算校验组结果，组合指误字

偶校验下，校验结果 = 校验组内所有位的异或值。

**P₁ 组（H₁、H₃、H₅、H₇）→ S₁：**

$$S_1 = H_1 \oplus H_3 \oplus H_5 \oplus H_7 = 0 \oplus 1 \oplus 1 \oplus 1 = 1$$

**P₂ 组（H₂、H₃、H₆、H₇）→ S₂：**

$$S_2 = H_2 \oplus H_3 \oplus H_6 \oplus H_7 = 1 \oplus 1 \oplus 1 \oplus 1 = 0$$

**P₄ 组（H₄、H₅、H₆、H₇）→ S₄：**

$$S_4 = H_4 \oplus H_5 \oplus H_6 \oplus H_7 = 0 \oplus 1 \oplus 1 \oplus 1 = 1$$

**指误字：**

$$S = S_4 S_2 S_1 = 1\;0\;1$$

转为十进制：$S = 4 + 0 + 1 = 5$

> **答：S₁=1, S₂=0, S₄=1，指误字 S = 101（十进制 5）。**

---

## 第 2 问：判断错误并纠错

指误字 S = 101（十进制 5）≠ 0，说明码字存在错误。

根据海明码定位原理，指误字的十进制值等于出错位的位号：

$$S_{\text{十进制}} = 5 \implies \text{错误位} = H_5$$

将 H₅ 翻转纠错（1 → 0）：

| 位置 | H₁ | H₂ | H₃ | H₄ | H₅ | H₆ | H₇ |
|------|----|----|----|----|----|----|----|
| 接收码字 | 0 | 1 | 1 | 0 | **1** | 1 | 1 |
| 纠错后 | 0 | 1 | 1 | 0 | **0** | 1 | 1 |

验证：纠错后重新计算指误字 S' = 000（三组异或全为 0），纠错正确。

> **答：码字存在错误，错误位为 H₅；纠错后的正确码字为 0110011。**

---

## 第 3 问：提取数据位，还原原始信息

从纠错后的码字中提取数据位（H₃=D₁, H₅=D₂, H₆=D₃, H₇=D₄）：

$$D_1 = H_3 = 1,\quad D_2 = H_5 = 0,\quad D_3 = H_6 = 1,\quad D_4 = H_7 = 1$$

> **答：还原出的原始 4 位二进制信息为 D₁D₂D₃D₄ = 1011。**

---

## 最终答案汇总

| 问题 | 答案 |
|------|------|
| 第1问 指误字 | S = S₄S₂S₁ = **101**（十进制 5） |
| 第2问 错误位 | **H₅**，纠错后码字 = **0110011** |
| 第3问 原始数据 | D₁D₂D₃D₄ = **1011** |
