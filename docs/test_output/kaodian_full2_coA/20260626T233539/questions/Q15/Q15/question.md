# 中断屏蔽字设计（综合题，8分）

## 题干

某计算机系统共有 5 个中断源，记为 L0、L1、L2、L3、L4。系统采用**多级中断（嵌套）**方式，各中断源的响应优先级由硬件排队电路决定，处理优先级则由**中断屏蔽字**（程序级屏蔽）实现。

### 约定

1. **响应优先级**（由硬件决定）：L0 > L1 > L2 > L3 > L4。
2. **处理优先级**（由屏蔽字决定）：L0 > L3 > L1 > L4 > L2。
3. **屏蔽字定义**：每个中断源 Li 对应一个 5 位屏蔽字，从左至右依次为 L0、L1、L2、L3、L4 对应位；某位为 **1** 表示屏蔽该中断源（禁止其打断当前服务），为 **0** 表示允许其打断当前服务。
4. 屏蔽规则：处理优先级**高于或等于**自身的中断源（含自身），对应位置 1；处理优先级**低于**自身的中断源，对应位置 0。

---

### 子问题 1（5分）

根据上述响应优先级、处理优先级和屏蔽字定义，写出 L0–L4 各自的中断屏蔽字，按如下矩阵形式填写（行 = 中断源，列 = 屏蔽字中 L0 L1 L2 L3 L4 对应位）：

| 中断源 | L0 | L1 | L2 | L3 | L4 |
|--------|----|----|----|----|----|
| L0     |    |    |    |    |    |
| L1     |    |    |    |    |    |
| L2     |    |    |    |    |    |
| L3     |    |    |    |    |    |
| L4     |    |    |    |    |    |

---

### 子问题 2（3分）

系统中各中断源在如下时刻请求中断（假设每个中断服务程序执行时间足够长，且在服务期间未自行开/关中断，屏蔽字随中断响应自动装入）：

| 时刻 | 发出的中断请求 |
|------|---------------|
| t₁   | L1 发出请求    |
| t₂   | L3 发出请求（此时 L1 正在被服务） |
| t₃   | L2 发出请求（此时 L3 正在被服务） |

请分析：

**(a)** t₂ 时刻 L3 能否打断 L1 的中断服务程序？请结合 L1 的屏蔽字说明理由。

**(b)** t₃ 时刻 L2 能否打断 L3 的中断服务程序？请结合 L3 的屏蔽字说明理由。

**(c)** 写出上述三个中断源（L1、L3、L2）的**服务开始顺序**（即 CPU 实际进入各中断服务程序的先后次序）和**服务完成顺序**（即各中断服务程序返回的先后次序）。

---

## 场景规则（通过条件）

本题成立需满足以下参数间约束（与具体答案值无关，换参数仍成立），供 gen.py exec 用 assert 检验：

### 规则 R1：屏蔽字自屏蔽位

对每个中断源 Li（i = 0..4），其屏蔽字在第 Li 位（对角线）上的值必须为 **1**，即各中断源一定屏蔽自身。

### 规则 R2：屏蔽字与处理优先级一致性

对任意两个中断源 Li、Lj（i ≠ j）：

- 若 **处理优先级(Li) ≥ 处理优先级(Lj)**，则 Li 的屏蔽字中第 Lj 位 = **1**。
- 若 **处理优先级(Li) < 处理优先级(Lj)**，则 Li 的屏蔽字中第 Lj 位 = **0**。

### 规则 R3：每行屏蔽字中"1"的个数

每个中断源 Li 的屏蔽字中，值为 1 的位数 = 处理优先级**低于或等于** Li 的中断源个数（含自身）。即：在处理优先级全序中排名越高的中断源，屏蔽越多中断源。

### 规则 R4：子问题2 嵌套一致性

t₂ 时刻 L3 能否打断 L1，必须与 L1 屏蔽字中第 L3 位的值一致（为 0 则能打断，为 1 则不能）；t₃ 时刻 L2 能否打断 L3，必须与 L3 屏蔽字中第 L2 位的值一致。服务开始顺序与完成顺序必须由屏蔽字矩阵唯一确定，不存在歧义。

## 设计意图

| 维度 | 说明 |
|------|------|
| **K目标** | K3=4（逐行推导 5×5 屏蔽矩阵，25 位，步数>5），K1=3（屏蔽字定义规则记忆），K4=3（区分响应优先级与处理优先级），K2=2（理解嵌套响应机制） |
| **考察形式** | 子问题1：推演型——根据处理优先级逐行推导屏蔽字矩阵；子问题2：分析型——给定中断时序，利用屏蔽字判断嵌套行为，区分响应优先级与处理优先级的差异 |
| **区分度来源** | 处理优先级 L0>L3>L1>L4>L2 与响应优先级 L0>L1>L2>L3>L4 有多处不同（L1↔L3 交换、L2↔L4 交换），确保推演非平凡；子问题2 中 L3 的处理优先级高于 L1 但响应优先级低于 L1，可检测考生是否混淆两种优先级 |
| **典型陷阱** | ① 响应优先级与处理优先级混淆；② 自身屏蔽位（对角线）遗漏；③ 屏蔽位序与中断源对应关系搞反；④ "等于自身优先级"时误判为允许打断 |
