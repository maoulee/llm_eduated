# 中断屏蔽字设计（综合题，8分）

## 题目

某计算机系统共有 5 个中断源，记为 L0、L1、L2、L3、L4。系统采用**多级中断（嵌套）**方式，各中断源的响应优先级由硬件排队电路决定，处理优先级则由**中断屏蔽字**（程序级屏蔽）实现。

### 约定

1. **响应优先级**（由硬件决定）：L0 > L1 > L2 > L3 > L4。
2. **处理优先级**（由屏蔽字决定）：L0 > L3 > L1 > L4 > L2。
3. **屏蔽字定义**：每个中断源 Li 对应一个 5 位屏蔽字，从左至右依次为 L0、L1、L2、L3、L4 对应位；某位为 **1** 表示屏蔽该中断源（禁止其打断当前服务），为 **0** 表示允许其打断当前服务。
4. 屏蔽规则：处理优先级**高于或等于**自身的中断源（含自身），对应位置 1；处理优先级**低于**自身的中断源，对应位置 0。

---

### 子问题 1（5分）

根据上述响应优先级、处理优先级和屏蔽字定义，写出 L0–L4 各自的中断屏蔽字，按如下矩阵形式填写（行 = 中断源，列 = 屏蔽字中 L0 L1 L2 L3 L4 对应位）：

| 中断源 | L0 | L1 | L2 | L3 | L4 |
|--------|----|----|----|----|----|
| L0     |    |    |    |    |    |
| L1     |    |    |    |    |    |
| L2     |    |    |    |    |    |
| L3     |    |    |    |    |    |
| L4     |    |    |    |    |    |

---

### 子问题 2（3分）

系统中各中断源在如下时刻请求中断（假设每个中断服务程序执行时间足够长，且在服务期间未自行开/关中断，屏蔽字随中断响应自动装入）：

| 时刻 | 发出的中断请求 |
|------|---------------|
| t₁   | L1 发出请求    |
| t₂   | L3 发出请求（此时 L1 正在被服务） |
| t₃   | L2 发出请求（此时 L3 正在被服务） |

请分析：

**(a)** t₂ 时刻 L3 能否打断 L1 的中断服务程序？请结合 L1 的屏蔽字说明理由。

**(b)** t₃ 时刻 L2 能否打断 L3 的中断服务程序？请结合 L3 的屏蔽字说明理由。

**(c)** 写出上述三个中断源（L1、L3、L2）的**服务开始顺序**（即 CPU 实际进入各中断服务程序的先后次序）和**服务完成顺序**（即各中断服务程序返回的先后次序）。

## 参考答案

### 子问题 1 屏蔽字矩阵

| 中断源 | L0 | L1 | L2 | L3 | L4 | 屏蔽字 |
|--------|----|----|----|----|----|--------|
| L0     | 1  | 1  | 1  | 1  | 1  | **11111** |
| L1     | 0  | 1  | 1  | 0  | 1  | **01101** |
| L2     | 0  | 0  | 1  | 0  | 0  | **00100** |
| L3     | 0  | 1  | 1  | 1  | 1  | **01111** |
| L4     | 0  | 0  | 1  | 0  | 1  | **00101** |

### 子问题 2

- **(a)** L3 **能**打断 L1。L1 的屏蔽字为 01101，第 L3 位 = 0（允许打断）；L3 处理优先级高于 L1。
- **(b)** L2 **不能**打断 L3。L3 的屏蔽字为 01111，第 L2 位 = 1（屏蔽）；L2 处理优先级低于 L3。
- **(c)** 服务开始顺序：**L1 → L3**；服务完成顺序：**L3 → L1 → L2**。

---

## 解析

### 子问题 1 逐行推导

处理优先级全序排名（0 = 最高，4 = 最低）：

| 中断源 | L0 | L3 | L1 | L4 | L2 |
|--------|----|----|----|----|----|
| 排名   | 0  | 1  | 2  | 3  | 4  |

对每个中断源 Li，逐列检查各中断源 Lj 的处理优先级排名：
- 若 rank(Lj) **≥** rank(Li)（即 Lj 处理优先级 ≤ Li）→ 第 Lj 位 = **1**
- 若 rank(Lj) **<** rank(Li)（即 Lj 处理优先级 > Li）→ 第 Lj 位 = **0**

**L0（rank=0，最高）**：所有中断源处理优先级都 ≤ L0 → 全部置 1 → **11111**

**L1（rank=2）**：
- L0（rank=0 < 2）→ 0；L1（rank=2 = 2）→ 1；L2（rank=4 ≥ 2）→ 1；L3（rank=1 < 2）→ 0；L4（rank=3 ≥ 2）→ 1
- → **01101**

**L2（rank=4，最低）**：只有自身 rank=4 ≥ 4 → 其余全 0 → **00100**

**L3（rank=1）**：
- L0（rank=0 < 1）→ 0；L1（rank=2 ≥ 1）→ 1；L2（rank=4 ≥ 1）→ 1；L3（rank=1 = 1）→ 1；L4（rank=3 ≥ 1）→ 1
- → **01111**

**L4（rank=3）**：
- L0（rank=0 < 3）→ 0；L1（rank=2 < 3）→ 0；L2（rank=4 ≥ 3）→ 1；L3（rank=1 < 3）→ 0；L4（rank=3 = 3）→ 1
- → **00101**

### 子问题 1 验证

- **自屏蔽位（对角线）**：每行对角线（L0→L0 位、L1→L1 位……）均为 1 ✓
- **每行 1 的个数 = 处理优先级 ≤ 自身的中断源数**：
  - L0: 5 个（rank=0，全屏蔽）= 5 − 0 = 5 ✓
  - L1: 3 个 = 5 − 2 = 3 ✓
  - L2: 1 个 = 5 − 4 = 1 ✓
  - L3: 4 个 = 5 − 1 = 4 ✓
  - L4: 2 个 = 5 − 3 = 2 ✓

### 子问题 2 时序分析

**(a) t₂ 时刻：L3 能否打断 L1？**

查 L1 的屏蔽字 = **01101**，第 L3 位 = **0**（允许打断）。

- L3 处理优先级排名 = 1，L1 排名 = 2，L3 处理优先级**高于** L1。
- L1 屏蔽字第 L3 位 = 0 → **不屏蔽** L3。

**结论：L3 能打断 L1。** t₂ 时刻 L3 立即中断 L1 的服务程序，CPU 转去执行 L3 的中断服务程序。

> 注意：此处 L3 的处理优先级高于 L1，但其响应优先级低于 L1。本题的关键就在于区分处理优先级与响应优先级——屏蔽字决定的是处理优先级，而非响应优先级。

**(b) t₃ 时刻：L2 能否打断 L3？**

查 L3 的屏蔽字 = **01111**，第 L2 位 = **1**（屏蔽）。

- L2 处理优先级排名 = 4，L3 排名 = 1，L2 处理优先级**低于** L3。
- L3 屏蔽字第 L2 位 = 1 → **屏蔽** L2。

**结论：L2 不能打断 L3。** t₃ 时刻 L2 的请求被挂起，等待 L3 服务结束后再判断。

**(c) 服务开始顺序与完成顺序**

**服务开始顺序（CPU 实际进入各中断服务程序的先后）**：

1. **t₁**：L1 发出请求，无更高优先级中断在服务 → **L1 开始服务**
2. **t₂**：L3 发出请求，L3 处理优先级高于 L1（L1 屏蔽字第 L3 位=0）→ L3 打断 L1 → **L3 开始服务**
3. **t₃**：L2 发出请求，L3 屏蔽字第 L2 位=1 → L2 被屏蔽，不能打断 L3 → **L2 等待**

→ **服务开始顺序：L1 → L3**

**服务完成顺序（各中断服务程序返回的先后）**：

按嵌套栈规则（后进入先返回）：

1. **L3 先完成**返回 → CPU 回到 L1 的服务程序
2. 此时检查挂起的 L2：L1 的屏蔽字 = **01101**，第 L2 位 = **1**（L2 处理优先级 rank=4 低于 L1 rank=2）→ L1 **屏蔽** L2 → L2 继续等待
3. **L1 完成**返回 → CPU 回到主程序，无更高优先级在服务
4. **L2 开始并完成**（此时再无屏蔽）

→ **服务完成顺序：L3 → L1 → L2**

### 常见错误（干扰项分析）

1. **响应优先级与处理优先级混淆**：误用响应优先级（L0>L1>L2>L3>L4）填写屏蔽字，而非处理优先级（L0>L3>L1>L4>L2）。典型错误：L1 屏蔽字第 L3 位误填 1（认为 L3 响应优先级低于 L1 所以应屏蔽），实际 L3 处理优先级高于 L1，应为 0。
2. **自身屏蔽位（对角线）遗漏**：误认为不需要屏蔽自身，导致对角线填 0。
3. **屏蔽位序与中断源对应关系搞反**：从右至左而非从左至右对应 L0–L4。
4. **"等于自身优先级"时误判为允许打断**：处理优先级等于自身时应屏蔽（位=1），而非允许（位=0）。
