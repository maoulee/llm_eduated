# 解题：多种寻址方式有效地址计算

## 已知条件回顾

| 参数 | 值 |
|------|-----|
| 形式地址 A | 0x0040 |
| 变址寄存器 Rx | 0x0018 |
| 基址寄存器 Rb | 0x0020 |
| 当前指令首地址 | 0x000E |
| 指令占用字地址数 | 2（双字长指令） |
| PC_updated（取指后） | 0x0010（= 0x000E + 2） |

主存表：

| 地址 | 内容 |
|------|------|
| 0x0040 | 0x0048 |
| 0x0048 | 0x1234 |
| 0x004E | 0xABCD |
| 0x0050 | 0x5678 |
| 0x0058 | 0x9ABC |
| 0x0060 | 0xDEF0 |
| 0x0068 | 0x1111 |

---

## 逐问求解

### (1) 直接寻址（MOD = 0001）

直接寻址：EA = A，操作数 = M[EA]。

- EA = A = 0x0040
- 操作数 = M[0x0040] = 0x0048

> **有效地址 EA = 0x0040，操作数 = 0x0048**

访存次数：1 次。

---

### (2) 间接寻址（MOD = 0010）

间接寻址：EA = M[A]（先访存读出指针），操作数 = M[EA]（再访存取操作数）。

- 第 1 次访存：读出指针 = M[0x0040] = 0x0048
- EA = 0x0048
- 第 2 次访存：操作数 = M[0x0048] = 0x1234

> **有效地址 EA = 0x0048，操作数 = 0x1234**

访存次数：2 次（间接寻址至少需 2 次访存）。

---

### (3) 相对寻址（MOD = 0011）

相对寻址：EA = PC_updated + A，其中 PC_updated = 当前指令首地址 + 指令占用字地址数 = 0x000E + 2 = 0x0010。

- PC_updated = 0x0010（取指后 PC 指向下一条指令，**不是**当前指令地址 0x000E）
- EA = 0x0010 + 0x0040 = 0x0050
- 操作数 = M[0x0050] = 0x5678

> **有效地址 EA = 0x0050，操作数 = 0x5678**

访存次数：1 次。

**陷阱说明**：若误用当前指令地址 0x000E 而非取指后值 0x0010，则错误 EA = 0x000E + 0x0040 = 0x004E，操作数 = M[0x004E] = 0xABCD。该错误结果看似合理（0x004E 在主存表中），但与正确 EA 0x0050 不同，是典型陷阱。

---

### (4) 变址寻址（MOD = 0100）

变址寻址：EA = Rx + A，操作数 = M[EA]。

- EA = Rx + A = 0x0018 + 0x0040 = 0x0058
- 操作数 = M[0x0058] = 0x9ABC

> **有效地址 EA = 0x0058，操作数 = 0x9ABC**

访存次数：1 次。

---

### (5) 基址寻址（MOD = 0101）

基址寻址：EA = Rb + A，操作数 = M[EA]。

- EA = Rb + A = 0x0020 + 0x0040 = 0x0060
- 操作数 = M[0x0060] = 0xDEF0

> **有效地址 EA = 0x0060，操作数 = 0xDEF0**

访存次数：1 次。

---

## 答案汇总

| 小问 | 寻址方式 | 有效地址 EA | 操作数 | 访存次数 |
|------|----------|------------|--------|---------|
| (1) | 直接寻址 | 0x0040 | 0x0048 | 1 |
| (2) | 间接寻址 | 0x0048 | 0x1234 | 2 |
| (3) | 相对寻址 | 0x0050 | 0x5678 | 1 |
| (4) | 变址寻址 | 0x0058 | 0x9ABC | 1 |
| (5) | 基址寻址 | 0x0060 | 0xDEF0 | 1 |

---

## 场景规则验证

- **规则6**（所有 EA 及间接指针在主存表中）：0x0040、0x0048、0x0050、0x0058、0x0060 及中间指针 0x0048 均在表中。✓
- **规则7**（五种 EA 互不相同）：0x0040、0x0048、0x0050、0x0058、0x0060 —— 各不相等。✓
- **规则8**（五种操作数互不相同）：0x0048、0x1234、0x5678、0x9ABC、0xDEF0 —— 各不相等。✓
- **规则9**（Rx ≠ Rb）：0x0018 ≠ 0x0020。✓
- **规则10**（相对寻址陷阱可区分）：误用 PC 的错误 EA = 0x004E 在表中（操作数 0xABCD），但与正确 EA 0x0050 不同。✓
- **间接寻址访存**：2 次 ≥ 2。✓
