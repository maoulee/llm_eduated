# 题目：多种寻址方式有效地址计算

## 考察说明

- 科目：组成原理
- 知识点：CO-4 指令系统 → 指令寻址方式 → 数据寻址 → 有效地址计算
- 题型：综合题（5 小问，每问 2 分，共 10 分）
- 考察模式：综合型——多种寻址方式有效地址计算
- 各问相互独立，共享同一组条件

---

## 题干

某计算机主存**按字编址**，字长 16 位（即每个字地址存放 16 位数据）。该机采用**双字长指令**（一条指令占 2 个连续字地址），指令格式如下：

```
第一字：[ 操作码 OP (8位) | 寻址方式 MOD (4位) | 保留 (4位) ]
第二字：[ 形式地址 A (16位) ]
```

寻址方式字段 MOD 的定义：

| MOD 值 | 寻址方式 |
|--------|----------|
| 0001   | 直接寻址 |
| 0010   | 间接寻址 |
| 0011   | 相对寻址 |
| 0100   | 变址寻址 |
| 0101   | 基址寻址 |

### 已知条件

1. 当前正在执行的指令存放于主存地址 **0x000E** 处（占用字地址 0x000E 和 0x000F）。取指阶段完成后，PC 自动更新为**下一条指令的地址**。
2. 该指令的形式地址 **A = 0x0040**。
3. 变址寄存器 **Rx = 0x0018**。
4. 基址寄存器 **Rb = 0x0020**。
5. 主存部分单元内容如下表：

| 地址 (十六进制) | 内容 (十六进制) |
|----------------|----------------|
| 0x0040         | 0x0048         |
| 0x0048         | 0x1234         |
| 0x004E         | 0xABCD         |
| 0x0050         | 0x5678         |
| 0x0058         | 0x9ABC         |
| 0x0060         | 0xDEF0         |
| 0x0068         | 0x1111         |

### 问题

分别求以下五种寻址方式下，该指令的**有效地址 EA**（十六进制）和**取出的操作数**（十六进制）。每问 2 分。

**(1)** 当 MOD = 0001（直接寻址）时，有效地址 EA 和操作数各是多少？

**(2)** 当 MOD = 0010（间接寻址）时，有效地址 EA 和操作数各是多少？

**(3)** 当 MOD = 0011（相对寻址）时，有效地址 EA 和操作数各是多少？

**(4)** 当 MOD = 0100（变址寻址）时，有效地址 EA 和操作数各是多少？

**(5)** 当 MOD = 0101（基址寻址）时，有效地址 EA 和操作数各是多少？

---

## 通过条件（场景规则）

以下约束与具体答案值无关，换参数仍成立，供 gen.py 翻译为 assert 验证：

### 寻址公式约束（定义层）

1. **直接寻址**：EA = A；操作数 = M[A]
2. **间接寻址**：EA = M[A]（需访存读出指针）；操作数 = M[M[A]]（再访存取操作数）；间接寻址完成取操作数至少需 2 次访存
3. **相对寻址**：EA = PC_updated + A，其中 PC_updated = 当前指令首地址 + 双字指令占用的字地址数（= 2）；即 PC_updated 为取指后指向下一条指令的值（**不是当前指令地址**）；操作数 = M[EA]
4. **变址寻址**：EA = Rx + A；操作数 = M[EA]
5. **基址寻址**：EA = Rb + A；操作数 = M[EA]

### 参数间一致性约束（可机检）

6. **所有有效地址落在主存表范围内**：直接/间接/相对/变址/基址五种 EA 及间接寻址的中间指针值 M[A]，均能在主存内容表中查到对应条目。
7. **五种有效地址互不相同**：五种寻址方式算出的 EA 各不相等。
8. **五种操作数互不相同**：五种寻址方式最终取出的操作数各不相等。
9. **Rx ≠ Rb**：变址寄存器与基址寄存器值不同，使变址 EA 与基址 EA 不同。
10. **相对寻址陷阱可区分**：PC 取值若误用当前指令地址（0x000E）而非取指后值（0x0010），算出的错误 EA 也能在主存表中查到（说明陷阱产生貌似合理但错误的答案），但与正确 EA 不同。
