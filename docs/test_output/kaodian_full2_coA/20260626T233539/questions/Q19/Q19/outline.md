## 考点
- **核心考点**：数据寻址的有效地址计算（CO-4 指令系统）
  - 考察侧重点：直接寻址、间接寻址、相对寻址、变址寻址、基址寻址五种方式下，从指令格式中提取相关信息并计算有效地址，再访存取得操作数
- **辅助考点**：双字长指令格式理解
  - 考察侧重点：操作码字段、寻址方式字段、形式地址字段在双字长指令中的布局与读取
- **辅助考点**：存储器内容表的读取与使用
  - 考察侧重点：给定主存若干单元的内容，根据有效地址查表取得操作数或下一级地址

## 难度目标
- **K1=3（标准）**：学生必须准确记忆五种寻址方式的有效地址计算公式才能入题，属于核心概念定义级别
- **K2=3（标准）**：每问需代入公式做地址加减运算，涉及非 2 的幂次的数值，但单步计算难度适中
- **K3=4（较高）**：五种寻址方式需分别走不同推导路径（间接寻址需多次访存、变址/基址需寄存器值加形式地址），整体推演步数 >5 步，且需维持各寄存器/PC 当前值
- **K4=3（标准）**：存在明确的陷阱——相对寻址基准是 PC 值（需更新到下条指令地址），间接寻址需多次访存而非一次，变址与基址的寄存器角色不同，不触发就会用错公式
- **K5=1（微弱）**：单一知识点（指令寻址）内部解决，不涉及其他子系统联动

## 考察模式
**综合型——多种寻址方式有效地址计算**

理由：该题位要求在统一上下文（同一条指令 + 同一组存储器内容）下，分别计算五种寻址方式的有效地址和操作数。这是 CO-4 指令系统章节的经典综合考察模式，能在一道题中全面覆盖数据寻址的核心知识点。与 K3=4（多步推演）和 K4=3（陷阱区分）的难度目标高度契合。

## 出题要求
- **题型**：综合题（主观题），10 分
- **总条件数**：建议 5-6 个显式条件
  - 条件 1：双字长指令格式图（操作码、寻址方式字段、形式地址字段的位宽和布局）
  - 条件 2：各寄存器当前值（PC、变址寄存器 Rx、基址寄存器 Rb）
  - 条件 3：主存若干单元的内容表（地址-内容映射）
  - 条件 4：指令字长与编址单位的关系（按字编址/按字节编址）
  - 条件 5：形式地址字段的具体值（在指令中给出）
  - 条件 6（可选）：存储器按字编址时的字长说明
- **条件设计原则**：
  - 存储器内容表需精心设计，使间接寻址的指针链至少两级，且最终操作数与其他寻址方式的操作数不重复
  - PC 值和形式地址需使相对寻址的有效地址落入存储器内容表覆盖范围
  - 变址/基址寄存器值需使计算结果落入表中覆盖范围
- **参数取值范围要求**：见下方"参数约束"

## 子问题规划

| 子问题 | 类型 | 考察目标 | 分值 | 依赖关系 |
|--------|------|----------|------|----------|
| 第1问 | 计算 | 直接寻址：形式地址即为有效地址，访存取操作数 | 2分 | 独立，基于条件直接计算 |
| 第2问 | 计算 | 间接寻址：形式地址指向主存单元，取出的内容再作为地址访存，可能多级 | 2分 | 独立，需多次访存 |
| 第3问 | 计算 | 相对寻址：EA = (PC) + 形式地址，注意 PC 应取下条指令地址 | 2分 | 独立，需注意 PC 更新陷阱 |
| 第4问 | 计算 | 变址寻址：EA = (Rx) + 形式地址，访存取操作数 | 2分 | 独立，需读取变址寄存器值 |
| 第5问 | 计算 | 基址寻址：EA = (Rb) + 形式地址，访存取操作数 | 2分 | 独立，需读取基址寄存器值 |

各问相互独立，但共享同一组条件（指令格式、寄存器值、存储器内容表）。

## 参数约束
- **指令格式**：双字长指令，操作码字段、寻址方式字段、形式地址字段的位宽由 Question Agent 决定，但需满足：
  - 寻址方式字段至少 3 bit（支持 5 种以上寻址方式的编码）
  - 形式地址字段位宽需足以表示存储器内容表中所有地址范围
  - 各字段总位宽 = 指令字长 × 2（双字长）
- **PC 值**：取值在存储器内容表覆盖范围内，使相对寻址有效地址落入表中
- **变址寄存器 Rx 值**：非零，使 (Rx) + 形式地址 的结果落入表中且与直接寻址有效地址不同
- **基址寄存器 Rb 值**：非零，与 Rx 值不同，使 (Rb) + 形式地址 的结果落入表中且与其他寻址方式结果不同
- **存储器内容表**：至少覆盖 6-8 个主存单元，需保证：
  - 直接寻址、间接寻址（含多级）、相对寻址、变址寻址、基址寻址的有效地址均落入表中
  - 间接寻址的指针链至少 2 级（即形式地址→单元A→单元B→最终操作数）
  - 各寻址方式取得的最终操作数值互不相同（避免歧义）
- **编址方式**：明确说明按字编址还是按字节编址，若按字节编址则需注明指令字长对应的字节数
- **形式地址**：十六进制表示，取值范围与地址空间一致
- **可调自由度**：具体地址值、寄存器值、存储器内容均可由 Question Agent 设定，仅需满足上述一致性约束

## 参考经验
- **历史模式**：该题位为经典综合型考察，给出指令格式 + 寄存器值 + 存储器内容表，要求逐一计算五种寻址方式的有效地址和操作数。此模式在历年 408 及教材习题中反复出现。
- **难度锚点**：K3=4 对应五种寻址方式分别推导，步数 >5；K4=3 对应相对寻址 PC 取值陷阱和间接寻址多次访存陷阱
- **典型陷阱**：
  1. 相对寻址时 PC 应取下条指令地址（PC + 指令字长），而非当前指令地址
  2. 间接寻址需多次访存，直到取出的内容不再作为地址（或达到约定级数）
  3. 变址寻址与基址寻址的有效地址计算公式形式相同但寄存器角色不同，易混淆
  4. 编址单位（字/字节）影响地址计算中的偏移量
