## 题目

某计算机主存**按字编址**，字长 16 位（即每个字地址存放 16 位数据）。该机采用**双字长指令**（一条指令占 2 个连续字地址），指令格式如下：

```
第一字：[ 操作码 OP (8位) | 寻址方式 MOD (4位) | 保留 (4位) ]
第二字：[ 形式地址 A (16位) ]
```

寻址方式字段 MOD 的定义：

| MOD 值 | 寻址方式 |
|--------|----------|
| 0001   | 直接寻址 |
| 0010   | 间接寻址 |
| 0011   | 相对寻址 |
| 0100   | 变址寻址 |
| 0101   | 基址寻址 |

### 已知条件

1. 当前正在执行的指令存放于主存地址 **0x000E** 处（占用字地址 0x000E 和 0x000F）。取指阶段完成后，PC 自动更新为**下一条指令的地址**。
2. 该指令的形式地址 **A = 0x0040**。
3. 变址寄存器 **Rx = 0x0018**。
4. 基址寄存器 **Rb = 0x0020**。
5. 主存部分单元内容如下表：

| 地址 (十六进制) | 内容 (十六进制) |
|----------------|----------------|
| 0x0040         | 0x0048         |
| 0x0048         | 0x1234         |
| 0x004E         | 0xABCD         |
| 0x0050         | 0x5678         |
| 0x0058         | 0x9ABC         |
| 0x0060         | 0xDEF0         |
| 0x0068         | 0x1111         |

### 问题

分别求以下五种寻址方式下，该指令的**有效地址 EA**（十六进制）和**取出的操作数**（十六进制）。每问 2 分，共 10 分。

**(1)** 当 MOD = 0001（直接寻址）时，有效地址 EA 和操作数各是多少？

**(2)** 当 MOD = 0010（间接寻址）时，有效地址 EA 和操作数各是多少？

**(3)** 当 MOD = 0011（相对寻址）时，有效地址 EA 和操作数各是多少？

**(4)** 当 MOD = 0100（变址寻址）时，有效地址 EA 和操作数各是多少？

**(5)** 当 MOD = 0101（基址寻址）时，有效地址 EA 和操作数各是多少？

## 参考答案

| 小问 | 寻址方式 | 有效地址 EA | 操作数 |
|------|----------|------------|--------|
| (1) | 直接寻址 | 0x0040 | 0x0048 |
| (2) | 间接寻址 | 0x0048 | 0x1234 |
| (3) | 相对寻址 | 0x0050 | 0x5678 |
| (4) | 变址寻址 | 0x0058 | 0x9ABC |
| (5) | 基址寻址 | 0x0060 | 0xDEF0 |

## 解析

### 已知条件回顾

| 参数 | 值 |
|------|-----|
| 形式地址 A | 0x0040 |
| 变址寄存器 Rx | 0x0018 |
| 基址寄存器 Rb | 0x0020 |
| 当前指令首地址 | 0x000E |
| 指令占用字地址数 | 2（双字长指令） |
| PC_updated（取指后） | 0x0010（= 0x000E + 2） |

---

### (1) 直接寻址（MOD = 0001）

直接寻址：EA = A，操作数 = M[EA]。

- EA = A = 0x0040
- 操作数 = M[0x0040] = 0x0048

> **有效地址 EA = 0x0040，操作数 = 0x0048**

访存次数：1 次。

---

### (2) 间接寻址（MOD = 0010）

间接寻址：EA = M[A]（先访存读出指针），操作数 = M[EA]（再访存取操作数）。

- 第 1 次访存：读出指针 = M[0x0040] = 0x0048
- EA = 0x0048
- 第 2 次访存：操作数 = M[0x0048] = 0x1234

> **有效地址 EA = 0x0048，操作数 = 0x1234**

访存次数：2 次（间接寻址至少需 2 次访存）。

---

### (3) 相对寻址（MOD = 0011）

相对寻址：EA = PC_updated + A，其中 PC_updated = 当前指令首地址 + 指令占用字地址数 = 0x000E + 2 = 0x0010。

- PC_updated = 0x0010（取指后 PC 指向下一条指令，**不是**当前指令地址 0x000E）
- EA = 0x0010 + 0x0040 = 0x0050
- 操作数 = M[0x0050] = 0x5678

> **有效地址 EA = 0x0050，操作数 = 0x5678**

访存次数：1 次。

**陷阱说明**：若误用当前指令地址 0x000E 而非取指后值 0x0010，则错误 EA = 0x000E + 0x0040 = 0x004E，操作数 = M[0x004E] = 0xABCD。该错误结果看似合理（0x004E 在主存表中），但与正确 EA 0x0050 不同，是典型陷阱。

---

### (4) 变址寻址（MOD = 0100）

变址寻址：EA = Rx + A，操作数 = M[EA]。

- EA = Rx + A = 0x0018 + 0x0040 = 0x0058
- 操作数 = M[0x0058] = 0x9ABC

> **有效地址 EA = 0x0058，操作数 = 0x9ABC**

访存次数：1 次。

---

### (5) 基址寻址（MOD = 0101）

基址寻址：EA = Rb + A，操作数 = M[EA]。

- EA = Rb + A = 0x0020 + 0x0040 = 0x0060
- 操作数 = M[0x0060] = 0xDEF0

> **有效地址 EA = 0x0060，操作数 = 0xDEF0**

访存次数：1 次。

---

### 评分标准

每小问 2 分，共 10 分：

- **有效地址 EA 计算正确**：1 分
- **操作数计算正确**：1 分

相对寻址小问若误用当前指令地址（0x000E）而未用取指后 PC 值（0x0010），EA 计算错误，该小问不得分。
