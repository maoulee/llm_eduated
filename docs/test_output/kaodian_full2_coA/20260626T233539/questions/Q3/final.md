## 第 2 题

**题干**：下列事件中，所引发的是外部中断（硬件中断）而非内部中断（异常）的是？

A. 除法运算时除数为 0
B. 程序访问了非法地址，产生地址越界
C. 定时器计数到期，向 CPU 发出中断请求
D. 执行指令时发生缺页

**答案**：C

---

---

## 第 2 题解析

**答案**：C

**解析**：中断分为外部中断（硬件中断/外部事件引起）和内部中断（异常/程序执行过程中由指令本身引起）。C 正确：定时器（时钟）是外部硬件设备，其计数到期向 CPU 发出的中断请求属于典型的外部中断。

- A 错误：除数为 0 是 CPU 在执行除法指令时检测到的程序性错误，属于内部中断（异常）。
- B 错误：地址越界是 CPU 访存时检测到的违例，属于内部中断（异常）。
- D 错误：缺页是在指令执行过程中由存储管理部件检测到的异常，属于内部中断。
