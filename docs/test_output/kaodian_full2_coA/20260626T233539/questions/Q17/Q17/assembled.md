## 出题契约

### 基本信息
- target_subject: 组成原理
- target_family: 组成原理 > CO-3 存储系统 > 主存储器和CPU的连接 > 存储芯片地址分配与片选
- primary_target_name: 存储器与CPU连接（地址分配与片选逻辑推导）
- question_type: comprehensive
- examination_mode: 推演型——存储器地址分配与片选逻辑

### 难度目标
- k_target: K1=3,K2=3,K3=4,K4=3,K5=1
- difficulty_level: 3
- difficulty_rationale: 需完整推演地址空间分配→芯片选型→译码逻辑三步链路，K3=4对应>5步串行推演，步数长且路径唯一，中间错则后续全错

### 结构要求
- sub_question_count: 3
- sub_question_breakdown:
  - Q1: 地址范围推导，3分，计算型
  - Q2: 芯片数量与扩展方式，4分，计算+分析型
  - Q3: 74LS138片选逻辑推导，5分，分析+推导型
- dependency: 串行（Q1→Q2→Q3，前问输出为后问输入）
- condition_count: 5-7

### 参数约束
- CPU地址总线宽度: 16-20位，必须覆盖ROM+RAM总容量
- ROM区域起始地址: 固定从地址0开始
- ROM区域容量: 2K-8K字节，必须为ROM芯片容量的整数倍
- RAM区域起始地址: ROM区域结束地址的下一地址，与ROM连续不重叠
- RAM区域容量: 2K-8K字节，必须为RAM芯片容量的整数倍，且与ROM区域容量不同（保证计算区分度）
- ROM芯片规格: 1K×8 / 2K×8 / 4K×8
- RAM芯片规格: 1K×4 / 1K×8 / 2K×8，必须与ROM芯片规格不同
- 74LS138译码器: 1个，8输出端，区域数≤8
- 高位地址线数: 地址总线宽度−片内寻址位数，必须≥译码器输入线数（3线）
- 控制信号: MREQ（访存请求）、R/W（读写控制），需在题干中给出

### 干扰与陷阱
- ROM区域无需写信号，RAM区域需要写信号——学生易忽略
- 地址范围十六进制边界值易±1出错
- 位扩展时数据线并联、地址线和片选共用——影响芯片数量判断
- 74LS138使能端（G1/G2A/G2B）需正确连接

### 参考经验摘要
- 历史模式: 存储器扩展+片选逻辑，标准三问结构（地址范围→芯片数量→片选逻辑）
- 难度锚点: K3=4对应>5步完整推演链路
- 典型陷阱: ROM/RAM读写控制差异、地址边界±1、使能端连接

### 出题自由度
Question Agent可自行选择：具体地址总线宽度、各区域容量、芯片规格、译码器接线方式。只需满足所有一致性约束，保证芯片数量为整数、地址范围连续不重叠、译码器输出端数够用。
