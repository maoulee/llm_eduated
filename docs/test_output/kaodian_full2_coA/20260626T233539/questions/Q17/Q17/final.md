## 题目

某计算机 CPU 具有 16 位地址总线（A15~A0，A0 为最低位）、8 位双向数据总线（D7~D0）。控制信号包括：

- **MREQ**（访存请求，低有效）：CPU 访问存储器时输出低电平。
- **R/W**（读/写控制，高为读、低为写）。

现需用以下芯片构建存储器系统：

| 区域 | 起始地址 | 容量 | 芯片规格 |
|------|----------|------|----------|
| ROM | 0000H | 4 KB | 2K×8 位 |
| RAM | （紧接 ROM 之后） | 8 KB | 2K×4 位 |

ROM 区域从地址 0000H 开始连续编址，RAM 区域紧接 ROM 区域结束地址之后，二者连续不重叠。

片选使用一片 **74LS138 译码器**（3 线-8 线译码器），其引脚说明如下：

- 译码输入端：**C、B、A**（C 为最高位，A 为最低位），对应 8 个译码输出端 **Y0~Y7**（均低有效）。
- 使能端：**G1**（高有效）、**G2A**（低有效）、**G2B**（低有效）；仅当 G1=1 且 G2A=0 且 G2B=0 时译码器工作。

**本题以片内寻址最大位数（11 位）对应的块大小（2 KB）为译码粒度**，即 C、B、A 分别连接 A13、A12、A11，使每个译码器输出端对应一个连续的 2 KB 地址区间。

### Q1（地址范围推导，3 分）

分别写出 ROM 区域和 RAM 区域的十六进制地址范围（起始地址和结束地址）。

### Q2（芯片数量与扩展方式，4 分）

分别计算 ROM 区域和 RAM 区域所需的芯片数量，并说明各自采用的扩展方式（位扩展 / 字扩展 / 字位同时扩展）。

### Q3（74LS138 片选逻辑推导，5 分）

**Q3.1** 列出 74LS138 译码器输出端 Y0~Y7 各自对应的 2 KB 地址区间（十六进制），并标明哪些输出端连接 ROM 芯片、哪些连接 RAM 芯片组。（以 2 KB 为一个地址块，C、B、A 分别连接 A13、A12、A11。）

**Q3.2** 说明 ROM 区域和 RAM 区域对 R/W 信号的需求差异（即哪个区域需要 R/W 信号参与片选或读写控制，哪个不需要，为什么）。

**Q3.3** 写出 74LS138 三个使能端（G1、G2A、G2B）的连接方案，并说明此连接方案为何能保证译码器仅在有效访存周期内工作。

---

## 参考答案

- **Q1**：ROM 地址范围 = **0000H ~ 0FFFH**；RAM 地址范围 = **1000H ~ 2FFFH**。
- **Q2**：ROM 所需 **2 片**（字扩展）；RAM 所需 **8 片**（字位同时扩展）。
- **Q3.1**：ROM 连接 **Y0、Y1**；RAM 连接 **Y2、Y3、Y4、Y5**；Y6、Y7 未用。
- **Q3.2**：ROM 不需要 R/W 信号（只读存储器，片选有效即可输出数据）；RAM 需要 R/W 信号控制读写方向。
- **Q3.3**：G1 接 Vcc，G2A 接 MREQ，G2B 接 A15。

## 解析

### 基本参数

| 参数 | 值 |
|------|-----|
| 地址总线宽度 | 16 位（A15~A0），地址空间 = 65536 B = 64 KB |
| ROM | 起始 0000H，容量 4 KB，芯片 2K×8 位 |
| RAM | 容量 8 KB，芯片 2K×4 位 |
| 译码器 | 74LS138（8 输出端 Y0~Y7），译码粒度 2048 B（2 KB） |
| 片内寻址位数 | 11 位 |

### Q1（地址范围推导）

**ROM 区域：**

- ROM 结束地址 = 起始地址 + 容量 − 1 = 0000H + 4096 − 1 = **0FFFH**
- ROM 地址范围 = **0000H ~ 0FFFH**

**RAM 区域（紧接 ROM 之后）：**

- RAM 起始地址 = ROM 结束地址 + 1 = 0FFFH + 1 = **1000H**
- RAM 结束地址 = RAM 起始地址 + 容量 − 1 = 1000H + 8192 − 1 = **2FFFH**
- RAM 地址范围 = **1000H ~ 2FFFH**

验证：RAM 起始 = ROM 结束 + 1 ✓；ROM 结束（0FFFH）< RAM 起始（1000H），不重叠 ✓；ROM + RAM = 4KB + 8KB = 12KB ≤ 64KB ✓。

### Q2（芯片数量与扩展方式）

**ROM 区域：**

- ROM 芯片容量（字节）= 2K × 8/8 = **2048 B = 2 KB**
- ROM 芯片数 = 4096 / 2048 = **2 片**
- ROM 扩展方式 = **字扩展**：ROM 芯片位宽 8 位 = 数据总线宽度（8 位），无需位扩展，仅靠增加芯片数量扩展存储字数。

**RAM 区域：**

- RAM 芯片容量（字节）= 2K × 4 / 8 = **1024 B**
- RAM 位扩展对数 = ⌈8/4⌉ = **2**（每 2 片 2K×4 位并联做位扩展，凑成 2K×8 位 = 1 组）
- RAM 组容量 = 2 × 1024 = **2048 B = 2 KB**
- RAM 组数 = 8192 / 2048 = **4 组**
- RAM 芯片数 = 4 组 × 2 片 = **8 片**
- RAM 扩展方式 = **字位同时扩展**：每 2 片 2K×4 位并联做位扩展凑成 2K×8 位（1 组），共 4 组做字扩展，总芯片数 = 2 × 4 = 8 片。

### Q3（74LS138 片选逻辑推导）

**Q3.1 译码器输出端地址区间与连接**

片内寻址位数 = max(log₂(2048), log₂(2048)) = **11 位**

译码粒度 = 2¹¹ = **2048 B = 2 KB**

CBA 连接：**C = A13, B = A12, A = A11**

各译码输出端对应 2 KB 地址区间：

| 输出端 | 地址范围 | CBA(A13,A12,A11) | 连接 |
|--------|----------|-------------------|------|
| Y0 | 0000H ~ 07FFH | 0 0 0 | ROM |
| Y1 | 0800H ~ 0FFFH | 0 0 1 | ROM |
| Y2 | 1000H ~ 17FFH | 0 1 0 | RAM |
| Y3 | 1800H ~ 1FFFH | 0 1 1 | RAM |
| Y4 | 2000H ~ 27FFH | 1 0 0 | RAM |
| Y5 | 2800H ~ 2FFFH | 1 0 1 | RAM |
| Y6 | 3000H ~ 37FFH | 1 1 0 | 未用 |
| Y7 | 3800H ~ 3FFFH | 1 1 1 | 未用 |

- ROM 占用 **2 块**（Y0~Y1），RAM 占用 **4 块**（Y2~Y5），总 **6 块**（≤ 8，译码器输出端够用 ✓）。

**Q3.2 R/W 信号需求差异**

- **ROM 区域**：不需要 R/W 信号参与写控制——ROM 只读，片选信号有效即可输出数据。
- **RAM 区域**：需要 R/W 信号——RAM 可读可写，R/W 决定数据方向（高 = 读，低 = 写）。

**Q3.3 使能端连接方案**

| 使能端 | 连接 | 说明 |
|--------|------|------|
| G1（高有效） | 接 Vcc（+5V 恒高） | 恒为有效 |
| G2A（低有效） | 接 MREQ（低有效） | 访存时 MREQ=0 使能 |
| G2B（低有效） | 接 A15（低有效） | A15=0 限定地址落在存储区 |

译码器工作条件 = G1 有效 **且** G2A 有效 **且** G2B 有效 = (Vcc = 1) **且** (MREQ = 0) **且** (A15 = 0)。即只有 CPU 发出访存请求（MREQ = 0）且目标地址的高位 A15 = 0（落在存储区 0000H~3FFFH 范围内）时，三个使能端才同时满足，译码器才工作；非访存周期（MREQ = 1）或地址超出存储区（A15 = 1）时，译码器被禁止，输出全无效。
