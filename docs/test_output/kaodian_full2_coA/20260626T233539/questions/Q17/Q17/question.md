# 存储器与CPU连接（地址分配与片选逻辑推导）

## 题干

某计算机 CPU 具有 16 位地址总线（A15~A0，A0 为最低位）、8 位双向数据总线（D7~D0）。控制信号包括：

- **MREQ**（访存请求，低有效）：CPU 访问存储器时输出低电平。
- **R/W**（读/写控制，高为读、低为写）。

现需用以下芯片构建存储器系统：

| 区域 | 起始地址 | 容量 | 芯片规格 |
|------|----------|------|----------|
| ROM | 0000H | 4 KB | 2K×8 位 |
| RAM | （紧接 ROM 之后） | 8 KB | 2K×4 位 |

ROM 区域从地址 0000H 开始连续编址，RAM 区域紧接 ROM 区域结束地址之后，二者连续不重叠。

片选使用一片 **74LS138 译码器**（3 线-8 线译码器），其引脚说明如下：

- 译码输入端：**C、B、A**（C 为最高位，A 为最低位），对应 8 个译码输出端 **Y0~Y7**（均低有效）。
- 使能端：**G1**（高有效）、**G2A**（低有效）、**G2B**（低有效）；仅当 G1=1 且 G2A=0 且 G2B=0 时译码器工作。

**本题以片内寻址最大位数（11 位）对应的块大小（2 KB）为译码粒度**，即 C、B、A 分别连接 A13、A12、A11，使每个译码器输出端对应一个连续的 2 KB 地址区间。

---

## 子问题

### Q1（地址范围推导，3 分）

分别写出 ROM 区域和 RAM 区域的十六进制地址范围（起始地址和结束地址）。

### Q2（芯片数量与扩展方式，4 分）

分别计算 ROM 区域和 RAM 区域所需的芯片数量，并说明各自采用的扩展方式（位扩展 / 字扩展 / 字位同时扩展）。

### Q3（74LS138 片选逻辑推导，5 分）

**Q3.1** 列出 74LS138 译码器输出端 Y0~Y7 各自对应的 2 KB 地址区间（十六进制），并标明哪些输出端连接 ROM 芯片、哪些连接 RAM 芯片组。（以 2 KB 为一个地址块，C、B、A 分别连接 A13、A12、A11。）

**Q3.2** 说明 ROM 区域和 RAM 区域对 R/W 信号的需求差异（即哪个区域需要 R/W 信号参与片选或读写控制，哪个不需要，为什么）。

**Q3.3** 题干给定 74LS138 三个使能端的连接方案：G1 接 Vcc（+5V 高电平，恒为有效），G2A 接 MREQ（低有效，使译码器仅在访存周期工作），G2B 接 A15（低有效，使译码器仅在 A15=0 即低 32KB（0000H~7FFFH）区间工作）。

(1) 说明在此方案下，译码器实际工作的地址范围是什么；

(2) 指出：由于 A14 等更高位地址线未参与译码（部分译码），本题存储区（ROM+RAM 共 0000H~2FFFH）会在哪个地址区间产生**地址镜像（重叠）**？写出镜像区间的起止地址；

(3) 简述这种部分译码方案在本题场景下是否可接受、为什么。

## 场景规则（通过条件）

以下规则为本题成立 ⇔ 参数间必须满足的约束关系，与具体答案值无关，可由 gen.py assert 验证：

- **R1（地址连续）**：RAM 起始地址 == ROM 结束地址 + 1；ROM 结束地址 == ROM 起始地址 + ROM 容量 − 1；RAM 结束地址 == RAM 起始地址 + RAM 容量 − 1。
- **R2（地址不重叠）**：ROM 地址范围与 RAM 地址范围不重叠，且二者总容量 == ROM 容量 + RAM 容量 ≤ 2^(地址总线宽度)。
- **R3（ROM 芯片数为整数）**：ROM 区域容量 % ROM 芯片容量 == 0。
- **R4（RAM 芯片数为整数）**：RAM 区域容量 % (RAM 芯片字数 × ⌈8 / RAM 芯片数据位宽⌉ × (RAM 芯片数据位宽位扩展后的字节单元)) == 0。即 RAM 芯片数 == (RAM 容量 / (RAM 芯片字数 × RAM 芯片位宽 / 8))，且为整数；RAM 芯片数 × RAM 芯片容量(字节) == RAM 区域容量。
- **R5（CBA 连接）**：译码粒度 == 2^(片内寻址位数)，本题片内寻址位数为 11 位（max(ROM 芯片地址位数, RAM 芯片地址位数)），即译码粒度 == 2 KB == 2^11 字节；C、B、A 分别连接 A13、A12、A11（即 CBA 连接的地址线编号 == 片内寻址位数 + {2, 1, 0}）。
- **R6（译码输出端够用）**：ROM + RAM 区域所需的 2 KB 地址块数 ≤ 8（74LS138 输出端数）。
- **R7（使能端连接唯一）**：G1 接 Vcc（恒为高电平），G2A 接 MREQ（低有效），G2B 接 A15（低有效）；译码器工作条件 == (G2A 端信号有效) 且 (G2B 端信号有效) 且 (G1 端信号有效) == (MREQ == 0) 且 (A15 == 0) 且 (Vcc == 1)。
- **R8（使能覆盖存储区）**：在 ROM 和 RAM 的全部地址范围内，A15 == 0 恒成立（即 ROM 结束地址和 RAM 结束地址均 < 0x8000），保证 G2B=A15 连接方案能覆盖整个存储区。
