## 考点
涉及的核心知识点及考察侧重点：

1. **主存地址空间分配**：给定ROM/RAM区域的位置和大小，要求推导各区域的起始地址—结束地址范围（十六进制表示）
2. **存储芯片选型与扩展**：根据给定芯片规格（字长×位宽），确定每个区域所需的芯片数量，并判断采用字扩展、位扩展还是字位同时扩展
3. **74LS138译码器片选逻辑**：利用3线-8线译码器，根据地址高位线推导各芯片组（或各区域）的片选信号逻辑表达式（文字推导，不画图）
4. **CPU与存储器连接的关键信号**：MREQ（访存请求）、R/W（读写控制）的作用，以及ROM区域无需写信号、RAM区域需要写信号的区分

## 难度目标
- **K1=3（标准）**：必须准确记忆存储器扩展方式（字扩展/位扩展）的定义、74LS138译码器的真值表规则，概念模糊无法入题
- **K2=3（标准）**：需代入常规公式计算芯片数量（总容量÷单片容量）、地址范围换算（二进制→十六进制），涉及非2的幂友好的地址边界
- **K3=4（较高）**：从地址空间分配到芯片选型到译码逻辑，需>5步串行推演，路径唯一但步数长，中间地址范围错则后续全错
- **K4=3（标准）**：存在明确陷阱——ROM与RAM的读写控制差异、地址线位数与译码器输入选择的关系，不触发则片选逻辑出错
- **K5=1（微弱）**：单一存储系统知识点内部解决，不涉及跨子系统联动

K3为主导维度，符合"多步综合推演"的难度定位。

## 考察模式
**推演型——存储器地址分配与片选逻辑**

选择理由：该题位在408中经典考法即为"给定地址空间分配，推导地址范围→芯片数量→片选逻辑"的完整推演链。无历史经验文档可供参考，但此模式为该知识点的标准考试形式，路径唯一、步数可控、区分度好。要求文字推导（不画图），符合纯文字题规范。

## 出题要求
- **题型**：应用题（主观题），总分12分
- **总条件数**：5-7个显式条件
- **条件设计原则**：
  - 给出CPU地址总线宽度（如16位/18位）
  - 给出ROM区域和RAM区域各自的地址位置（起始地址或地址区间）
  - 给出可用存储芯片规格（如ROM芯片：A×8位，RAM芯片：B×8位，A≠B以保证两组计算不同）
  - 给出74LS138译码器可用及高位地址线分配情况
  - 给出控制信号（MREQ、R/W）
- **参数取值范围要求**：
  - 地址总线宽度：16-20位
  - ROM区域容量：2K-8K
  - RAM区域容量：2K-8K（与ROM区域容量不同，保证计算区分度）
  - ROM芯片规格：1K×8 / 2K×8 / 4K×8
  - RAM芯片规格：1K×8 / 1K×4 / 2K×8（与ROM芯片不同）
  - 各区域地址连续且不重叠，总容量不超过地址空间上限
- **纯文字题**：整道题不得出现"画图/作图/框图"等字样，所有推导以文字和表格形式完成

## 子问题规划

**子问题1（地址范围推导，3分）**
- 类型：计算
- 考察目标：根据ROM/RAM区域的位置和大小，推导各区域的起始地址和结束地址（十六进制）
- 与前后问关系：无前置依赖，为后续芯片数量计算提供输入
- 分值：3分

**子问题2（芯片数量与扩展方式，4分）**
- 类型：计算+分析
- 考察目标：根据各区域容量和芯片规格，计算所需芯片数量，判断字扩展/位扩展/字位同时扩展
- 与前后问关系：依赖第1问的地址范围（确定区域容量），为第3问片选逻辑提供芯片组划分依据
- 分值：4分

**子问题3（74LS138片选逻辑推导，5分）**
- 类型：分析+推导
- 考察目标：根据高位地址线分配，推导各芯片组连接到74LS138的哪个输出端，写出各片选信号的逻辑表达式（文字推导）
- 与前后问关系：依赖第2问的芯片组划分结果
- 分值：5分

## 参数约束
| 参数 | 取值范围 | 一致性约束 |
|------|---------|-----------|
| CPU地址总线宽度 | 16-20位 | 必须能覆盖ROM+RAM总容量 |
| ROM区域起始地址 | 由分配决定 | ROM必须从地址0开始（常规设计） |
| ROM区域容量 | 2K-8K字节 | 必须为芯片容量的整数倍 |
| RAM区域起始地址 | ROM区域结束地址的下一地址 | ROM与RAM地址连续，不重叠 |
| RAM区域容量 | 2K-8K字节 | 必须为芯片容量的整数倍，且与ROM容量不同 |
| ROM芯片规格 | 1K×8 / 2K×8 / 4K×8 | ROM区域容量÷芯片字长=芯片数量（整数） |
| RAM芯片规格 | 1K×4 / 1K×8 / 2K×8 | RAM区域容量÷芯片字长=芯片数量（整数）；RAM芯片规格必须与ROM不同 |
| 74LS138译码器数量 | 1个 | 8个输出端够用（区域数≤8） |
| 高位地址线 | 由地址总线宽度-片内寻址位数决定 | 高位线数≥译码器所需输入线数 |

**可调自由度**：Question Agent可自行选择具体的地址总线宽度、各区域容量、芯片规格，只要满足上述一致性约束。

## 参考经验
由于本slot无历史question_experiences，参考以下通用经验：
- **历史模式**：存储器扩展+片选逻辑是408经典综合题，标准三问结构（地址范围→芯片数量→片选逻辑）
- **难度锚点**：K3=4对应>5步推演，符合从地址分配到译码逻辑的完整链路
- **典型陷阱**：
  - ROM区域无需写信号（W/R），RAM区域需要——学生易忽略
  - 位扩展时芯片的数据线并联但地址线和片选共用——影响芯片数量计算
  - 74LS138的使能端（G1、G2A、G2B）必须正确连接才能正常工作
  - 地址范围十六进制表示时，学生易在边界值上±1出错
