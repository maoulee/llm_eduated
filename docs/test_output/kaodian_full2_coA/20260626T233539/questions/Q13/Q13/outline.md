## 考点
- **主存储器容量扩展——字位同时扩展**（核心考点）：理解字扩展（增加地址范围）与位扩展（增加数据位宽）的组合方式，计算所需芯片组数和总芯片数。
- **存储芯片规格分析**（辅助考点）：根据给定芯片的存储容量（如 K×N 位），正确分离地址单元数与每个单元的位宽。
- **地址线/数据线计算**（辅助考点）：由目标存储器容量推导地址线总数和数据线总数。

## 难度目标
- K1=3：必须准确记忆"字扩展 = 字数（地址空间）扩展，位扩展 = 数据位宽扩展"的定义，以及芯片数量 = 字扩展倍数 × 位扩展倍数的公式，才能入题。
- K2=3：需代入公式进行常规计算（芯片组数 = 目标字数/芯片字数，每组芯片数 = 目标位宽/芯片位宽），涉及非2的幂次或需多步乘除。
- K3=3：需按固定流程走3-5步（分解目标容量 → 算字扩展 → 算位扩展 → 相乘得总芯片数 → 算地址线/数据线），路径唯一但步骤完整。
- K4=2：存在常规注意点——芯片规格表示法（如 4K×8位）需正确拆解，408考生基本不会踩坑。
- K5=1：单一知识点内部解决，不涉及其他子系统联动。

## 考察模式
**计算型——存储器扩展芯片数量**。这是该知识点的标准考察模式：给出目标存储器总容量和可选芯片规格，要求学生分别计算字扩展倍数和位扩展倍数，得出芯片组数、每组芯片数和总芯片数，并推导地址线和数据线数量。难度定位为标准应用题（target_difficulty=2），计算路径固定、无歧义分支。

## 出题要求
- 题型：应用题（主观题），总分6分。
- 总条件数：2-3个显式条件（目标存储器容量、芯片规格、CPU地址线/数据线位宽可选给出）。
- 条件设计原则：
  - 目标存储器容量须能被芯片规格在字和位两个维度上整除（否则题目不成立）。
  - 芯片位宽应小于目标数据位宽（体现位扩展需求）。
  - 芯片字数应小于目标字数（体现字扩展需求）。
  - 目标容量可包含非2的幂次因子，以体现K2=3的常规计算难度。
- 参数取值范围要求：
  - 目标存储器容量：16KB ~ 64KB 量级。
  - 芯片规格：字数为 1K~8K，位宽为 4位或8位的常见规格。
  - 目标数据位宽：8位或16位。
  - CPU地址线位宽：16或32位（供学生判断地址线是否充足）。

## 子问题规划
本题共设3个子问题，串行依赖：

1. **子问题1（2分）—计算型**：计算目标存储器的地址线数量和数据线数量。
   - 考察目标：由存储器总容量推导地址线和数据线位数。
   - 与后续关系：为子问题2的分组计算提供目标参数。

2. **子问题2（2分）—计算型**：计算所需的芯片组数和每组芯片数（即字扩展倍数和位扩展倍数）。
   - 考察目标：正确分离芯片规格中的字数和位宽，分别计算两个维度的扩展倍数。
   - 与后续关系：直接决定子问题3的总数。

3. **子问题3（2分）—计算型**：计算所需芯片总数。
   - 考察目标：芯片总数 = 芯片组数 × 每组芯片数，检验学生对字位同时扩展的综合理解。

## 参数约束
- **目标存储器容量（C_target）**：16KB~64KB范围；必须满足 C_target = 字数 × 位宽/8（字节），且字数和位宽均可被对应芯片参数整除。
- **芯片规格（芯片字数 W_chip、芯片位宽 B_chip）**：W_chip ∈ {1K, 2K, 4K, 8K}，B_chip ∈ {4, 8}。
- **目标数据位宽（B_target）**：B_target ∈ {8, 16}，且 B_target > B_chip（保证有位扩展）。
- **整除约束**：B_target % B_chip == 0 且 目标字数 % W_chip == 0。
- **芯片组数（G）**= 目标字数 / W_chip，应 ≥ 2（保证有字扩展）。
- **每组芯片数（P）**= B_target / B_chip，应 ≥ 2（保证有位扩展）。
- **总芯片数**= G × P，应在合理范围内（4~64枚）。
- 可调自由度：Question Agent 可在上述约束内自由选择具体数值，确保整除性和区分度。

## 参考经验
- **考察模式**：字位同时扩展是408组成原理的经典计算题型，标准问法为"用给定芯片扩展到目标容量，需多少片？"
- **难度锚点**：K1=3/K2=3/K3=3 对应标准应用题难度，计算路径固定但需多步。
- **典型陷阱**：
  - 学生可能混淆"字扩展"与"位扩展"，导致两个倍数算反。
  - 芯片规格 4K×4位 中的"4K"是地址单元数（字数），"4位"是每个单元位宽，学生可能误解。
  - 总芯片数 = 组数 × 每组片数，部分学生可能只算一个维度。
