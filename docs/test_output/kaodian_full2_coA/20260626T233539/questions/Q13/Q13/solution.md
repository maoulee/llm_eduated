# 主存储器字位同时扩展——芯片数量计算（解答）

> 以下解答逐字对照 gen.py exec 输出（PARAMS/PROCESS/RESULT/RULE_CHECK）转写，不重算。

## 已知参数（PARAMS）

| 参数 | 值 | 含义 |
|------|----|------|
| C_target | 65536 字节（64KB） | 目标存储器容量 |
| B_target | 16 位 | 数据总线宽度 |
| W_chip | 8192 字（8K） | 芯片字数 |
| B_chip | 8 位 | 芯片位宽 |

存储器按字编址，1 字 = 16 位 = 2 字节。

---

## 求解过程

### （1）地址线数与数据线数

**目标字数**（容量自洽 R1）：

每字字节数 = B_target / 8 = 16 / 8 = **2 字节**

目标字数 = C_target / 每字字节数 = 65536 / 2 = **32768 = 32K 字**

**整除验证**（R2）：16 % 8 = 0，32768 % 8192 = 0，均整除，参数合法。

**地址线数**（R3）：按字编址，每字对应一个地址，地址线数 = log₂(目标字数) = log₂(32768) = **15 根**

**数据线数**（R4）：数据线数 = B_target = **16 根**

> ✅ RULE_CHECK R3: log₂(32768) = 15，2^15 = 32768 ✓  
> ✅ RULE_CHECK R4: B_target = 16 == 数据线 16 ✓

**答（1）：地址线 15 根，数据线 16 根。**

---

### （2）芯片组数（字扩展）与每组芯片数（位扩展）

**芯片组数 G（字扩展方向）**（R5）：

G = 目标字数 / 芯片字数 = 32768 / 8192 = **4**

> ✅ RULE_CHECK R5: G = 4 ≥ 2 ✓

**每组芯片数 P（位扩展方向）**（R6）：

P = B_target / B_chip = 16 / 8 = **2**

> ✅ RULE_CHECK R6: P = 2 ≥ 2 ✓

**答（2）：需要 4 个芯片组（字扩展），每组需要 2 片芯片（位扩展）。**

---

### （3）总芯片数

**总芯片数**（R7）：

总芯片数 = G × P = 4 × 2 = **8 片**

**总量校验**（R8）：
- 字扩展覆盖：G × W_chip = 4 × 8192 = 32768 == 目标字数 32768 ✓
- 位扩展覆盖：P × B_chip = 2 × 8 = 16 == B_target 16 ✓

**答（3）：总共需要 8 片 8K × 8 位的 SRAM 芯片。**

---

## 最终答案汇总

| 子问 | 结论 |
|------|------|
| （1） | 地址线 = 15 根，数据线 = 16 根 |
| （2） | 芯片组数 G = 4（字扩展），每组芯片数 P = 2（位扩展） |
| （3） | 总芯片数 = G × P = 4 × 2 = 8 片 |
