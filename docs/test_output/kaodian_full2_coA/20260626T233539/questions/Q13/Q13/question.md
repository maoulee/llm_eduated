# 主存储器字位同时扩展——芯片数量计算

## 题干

用若干片规格为 **8K × 8 位** 的 SRAM 芯片，构成一个容量为 **64KB**、数据总线宽度为 **16 位** 的主存储器。（存储器按字编址，1 字 = 16 位 = 2 字节。）

请回答以下问题：

**（1）**（2分）该主存储器的地址线有多少根？数据线有多少根？

**（2）**（2分）构成该主存储器需要多少个芯片组（字扩展方向）？每组需要多少片芯片（位扩展方向）？

**（3）**（2分）总共需要多少片 8K × 8 位的 SRAM 芯片？

---

## 考察意图

- **知识点**：字位同时扩展（CO-3 存储系统 > 主存容量扩展）。
- **考察形式**：计算型——给定芯片规格与目标存储器参数，按"地址线/数据线 → 字扩展组数/位扩展倍数 → 芯片总数"三步串行计算。
- **K目标**：K1（记忆：地址线/数据线概念）、K2（理解：字扩展与位扩展的区分）、K3（应用：芯片数量计算）。
- **典型错误路径**（区分度来源）：① 字扩展倍数与位扩展倍数算反；② 芯片规格中字数与位宽混淆（误将 8K 当位数）；③ 总芯片数只算一个维度（漏乘）。

---

## 场景规则（通过条件）

以下参数间约束在给定参数下必须成立（换参数仍成立，与具体答案值无关）：

1. **容量自洽**：`目标字数 = C_target_bytes / (B_target / 8)`，即目标字数 = 容量字节数 ÷ 每字字节数。本题中 64KB = 65536 字节，B_target = 16 位 → 每字 2 字节 → 目标字数 = 32768 = 32K。

2. **整除约束**：`B_target % B_chip == 0` 且 `目标字数 % W_chip == 0`。本题中 16 % 8 == 0，32768 % 8192 == 0，均满足。

3. **地址线数**：`地址线数 = log2(目标字数)`（按字编址，每字对应一个地址）。本题目标字数 = 32K = 2^15 → 地址线 = 15。

4. **数据线数**：`数据线数 = B_target`。本题数据线 = 16。

5. **芯片组数（字扩展）**：`G = 目标字数 / W_chip`，且 G ≥ 2。本题 G = 32768 / 8192 = 4。

6. **每组芯片数（位扩展）**：`P = B_target / B_chip`，且 P ≥ 2。本题 P = 16 / 8 = 2。

7. **总芯片数**：`总芯片数 = G × P`。本题总芯片数 = 4 × 2 = 8。

8. **总量校验**：`G × W_chip == 目标字数` 且 `P × B_chip == B_target`（字扩展覆盖全部目标字数，位扩展覆盖全部目标位宽）。

---

## 参数定义

| 符号 | 含义 | 本题取值 |
|------|------|----------|
| C_target | 目标存储器容量 | 64KB |
| B_target | 目标数据总线宽度 | 16 位 |
| W_chip | 芯片字数 | 8K（8192 字） |
| B_chip | 芯片位宽 | 8 位 |
| 目标字数 | C_target / (B_target/8) | 32K（32768 字） |
| G | 芯片组数（字扩展） | 4 |
| P | 每组芯片数（位扩展） | 2 |
| 总芯片数 | G × P | 8 |

---

## 评分要点

| 子问 | 分值 | 评分点 |
|------|------|--------|
| （1）地址线 = 15 根 | 1 | 正确由目标字数取 log2 |
| （1）数据线 = 16 根 | 1 | 正确取 B_target |
| （2）芯片组数 G = 4 | 2 | 正确由目标字数 / 芯片字数 |
| （2）每组芯片数 P = 2 | （包含在上面2分中） | 正确由 B_target / B_chip |
| （3）总芯片数 = 8 | 2 | 正确由 G × P |
