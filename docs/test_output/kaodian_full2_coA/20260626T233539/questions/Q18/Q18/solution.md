# Cache 地址映射格式设计 — 参考解答

## 基本参数（PARAMS）

| 参数 | 值 |
|------|-----|
| 主存容量 M | 2²⁸ B = 268 435 456 B |
| Cache 容量 C | 2¹⁵ B = 32 768 B |
| 块长 B | 2⁵ B = 32 B |
| 组相联路数 | 4（四路组相联） |

由 PARAMS 推导出的关键中间值（PROCESS）：

| 量 | 计算 | 值 |
|----|------|----|
| 主存地址位数 | log₂(M) = log₂(2²⁸) | **28** |
| 块内地址位数 | log₂(B) = log₂(2⁵) | **5** |
| Cache 行数 | C/B = 2¹⁵ / 2⁵ = 2¹⁰ | **1024** |
| 组数（四路） | C/(B×4) = 2¹⁵ / (2⁵ × 4) = 2¹⁵ / 2⁷ = 2⁸ | **256** |

---

## 第（1）题（2 分）— 直接映射

**Cache 行数** = C/B = 1024 行，行号位 = log₂(1024) = **10** 位。

**块内地址位** = log₂(B) = log₂(32) = **5** 位。

**标记位** = 28 − 10 − 5 = **13** 位。

**主存地址总长度** = 13 + 10 + 5 = **28 位**。

| 字段 | 标记 | 行号（Cache 行号） | 块内地址 |
|------|------|-------------------|---------|
| 位数 | 13 | 10 | 5 |

> **地址格式**（高位 → 低位）：`标记 13 位 | 行号 10 位 | 块内地址 5 位`

---

## 第（2）题（3 分）— 四路组相联映射

### ① Cache 共有多少组？组号需要多少位？

- Cache 行数 = C/B = 1024 行。
- 每组包含 4 个 Cache 行（四路），故组数 = 1024 / 4 = **256 组**。
- 组号位 = log₂(256) = **8 位**。

### ② 主存地址各字段

**组号位** = log₂(256) = **8** 位。

**块内地址位** = log₂(B) = **5** 位。

**标记位** = 28 − 8 − 5 = **15** 位。

| 字段 | 标记 | 组号 | 块内地址 |
|------|------|------|---------|
| 位数 | 15 | 8 | 5 |

> **地址格式**（高位 → 低位）：`标记 15 位 | 组号 8 位 | 块内地址 5 位`

---

## 第（3）题（2 分）— 全相联映射

全相联映射无索引字段（不区分行号/组号）。

**块内地址位** = log₂(B) = **5** 位。

**标记位** = 28 − 5 = **23** 位。

| 字段 | 标记 | 块内地址 |
|------|------|---------|
| 位数 | 23 | 5 |

> **地址格式**（高位 → 低位）：`标记 23 位 | 块内地址 5 位`

---

## 第（4）题（1 分）— 格式汇总

| 映射方式 | 标记位数 | 索引（行号/组号）位数 | 块内地址位数 | 地址总位数 |
|---------|---------|-------------------|-----------|---------|
| 直接映射 | **13** | **10** | **5** | **28** |
| 四路组相联 | **15** | **8** | **5** | **28** |
| 全相联 | **23** | **0**（无） | **5** | **28** |

---

## 验证（RULE_CHECK）

三种映射方式均满足**地址位数守恒**（标记 + 索引 + 块内 = 28）：

- 直接映射：13 + 10 + 5 = 28 ✓
- 四路组相联：15 + 8 + 5 = 28 ✓
- 全相联：23 + 0 + 5 = 28 ✓

其他场景规则均通过（参数为 2 的幂、M > C > B 且 C/B = 1024 ≥ 4、各字段位数 ≥ 1、块内地址位数 5 ∈ [4, 8]、标记位均 ≥ 4），详见 gen.py RULE_CHECK 输出。
