# Cache 地址映射格式设计

## 题干

某计算机的存储器系统中，主存与 Cache 采用以下参数：

| 参数 | 值 |
|------|-----|
| 主存容量 M | 256 MB（2²⁸ B） |
| Cache 容量 C | 32 KB（2¹⁵ B） |
| 块长 B（每块大小） | 32 B（2⁵ B） |

该系统中 Cache 与主存之间分别采用**直接映射**、**四路组相联映射**和**全相联映射**三种方式时，主存地址各字段的划分不同。按字节编址，块大小以字节为单位。

> **提示**：四路组相联中，每组包含 4 个 Cache 行。

---

### 第（1）题（2 分）

采用**直接映射**方式时，主存地址由哪几个字段构成？写出每个字段的名称、位数，并计算主存地址总长度。

### 第（2）题（3 分）

采用**四路组相联映射**方式时：

1. Cache 共有多少个组？组号需要多少位？
2. 主存地址由哪几个字段构成？写出每个字段的名称和位数。

### 第（3）题（2 分）

采用**全相联映射**方式时，主存地址由哪几个字段构成？写出每个字段的名称和位数。

### 第（4）题（1 分）

下表列出三种映射方式下主存地址各字段位数，请填写完整（数值即可）。

| 映射方式 | 标记位数 | 索引（行号/组号）位数 | 块内地址位数 | 地址总位数 |
|---------|---------|-------------------|-----------|---------|
| 直接映射 | ____ | ____ | ____ | ____ |
| 四路组相联 | ____ | ____ | ____ | ____ |
| 全相联 | ____ | ____（无） | ____ | ____ |

---

## 场景规则（通过条件）

本题成立 ⇔ 以下参数间约束必须被满足：

1. **参数为 2 的幂**：M = 2^28 B，C = 2^15 B，B = 2^5 B，均为 2 的幂。✓

2. **容量层级约束**：M > C > B，且 C/B = 2^10 ≥ 4（四路组相联至少有 1 组）。✓

3. **地址位数守恒约束**（对每种映射方式）：
   - **直接映射**：标记位 + 行号位 + 块内地址位 == 主存地址位数（28）；其中行号位 == log₂(C/B) == 10，块内地址位 == log₂(B) == 5。
   - **四路组相联**：标记位 + 组号位 + 块内地址位 == 主存地址位数（28）；其中组号位 == log₂(C/(B×4)) == 8，块内地址位 == log₂(B) == 5。
   - **全相联**：标记位 + 块内地址位 == 主存地址位数（28），无索引位；标记位 == 28 − 5 == 23。

4. **字段位数非负且 ≥1**：每种映射方式下，各字段位数均 ≥ 1（全相联索引位除外，恒为 0/不存在）。

5. **块内地址位数范围**：log₂(B) ∈ [4, 8]，本题取 5。✓

6. **标记位 ≥ 4**：每种映射方式下标记位数 ≥ 4。✓

> 以上约束均可被 gen.py 用 assert 逐一验证，与具体答案值无关——换一组满足约束的参数仍成立。
