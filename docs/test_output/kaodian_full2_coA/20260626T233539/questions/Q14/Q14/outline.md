## 考点
- **扩展操作码**（核心考点）：理解操作码扩展机制，掌握编码空间的逐级分配规则
- **指令格式设计**（辅助考点）：理解固定字长下不同地址码位数对操作码空间的影响
- **编码空间计算**（辅助考点）：掌握"保留前缀 → 下一级扩展可用位数"的计算逻辑

考察侧重点：给定指令字长和地址码位数，已知某类（如二地址）指令数量，要求计算可扩展的另一类（如一地址或零地址）指令最多可定义多少条。核心难点在于正确识别"被保留用于扩展的前缀模式数量"，这是 K4=4 的陷阱所在。

## 难度目标
- **K1=3**：必须准确记忆扩展操作码的定义和编码空间分配规则才能入题
- **K2=3**：需代入公式计算（2的幂次为主），但有非平凡的多步代入
- **K3=2**：仅需 2-3 步推导（算保留前缀数 → 算可用编码空间），路径唯一
- **K4=4**：隐含前提深——必须理解"当前级别保留 N 个前缀 = 下一级别编码空间乘以 N"的机制本质；常见陷阱是忘记减去已占用的前缀或忘记乘以地址码扩展位数
- **K5=1**：单一知识点内部解决，不涉及跨系统联动

**达标理由**：本题 K4=4 为主维度，陷阱在于编码空间逐级分配时"保留前缀"的计数。学生若不理解扩展机制本质，仅机械套用"2^opcode位数"会得到错误结果。K1=3 确保必须理解扩展操作码概念，K2=3 确保有实质计算量，K3=2 保持推导路径简洁，K5=1 锁定单知识点。

## 考察模式
**计算型——扩展操作码数量计算**

理由：参考 2022_Q19 经验，扩展操作码题位采用"给出指令字长和地址码位数 + 已知某类指令数量 → 求另一类指令可扩展数量"的模式，考察学生对编码空间逐级分配的理解。此模式能直接测试 K4 陷阱（保留前缀计数）和 K2 计算能力，与目标难度 K4 主导一致。

## 出题要求
- 题型：应用题（主观题），总分 6 分
- 总条件数：2-3 个显式条件（指令字长、地址码位数、已知某类指令数量）
- 条件设计原则：
  - 给出固定的指令字长（如 16 或 32 位）
  - 给出每级地址码的位数
  - 给出某一级（通常是最高级，如二地址）已定义的指令数量，保留其余编码空间用于扩展
- 参数取值范围要求：
  - 指令字长：16 或 32 位（2 的幂次，便于计算）
  - 地址码位数：4、6 或 8 位（2 的幂次，且能被指令字长整除）
  - 已知指令数量：应为 2^n - k 形式（k > 0），即"故意不是满编码"，留出扩展空间

## 子问题规划
**子问题 1（3 分）**：
- 类型：计算
- 考察目标：给定指令字长和地址码位数，计算某一级指令（如二地址）最多可定义多少条，以及需保留多少前缀用于下一级扩展
- 与前后问关系：本问结果（保留前缀数）是子问题 2 的输入

**子问题 2（3 分）**：
- 类型：计算
- 考察目标：利用子问题 1 的保留前缀数，计算下一级（如一地址或零地址）指令最多可定义多少条
- 与前后问关系：依赖子问题 1 的结果，体现编码空间的逐级分配
- **陷阱设计**：答案不等于简单的 2^opcode位数，而需乘以保留前缀数再减去本级保留用于进一步扩展的前缀

## 参数约束
- **指令字长 L**：取 16 或 32，保证可被地址码位数整除
- **每级地址码位数 A**：取 4、6 或 8，满足 L ≥ 2A（至少能容纳两级格式）
- **格式层级数**：2-3 级（如二地址 → 一地址 → 零地址）
- **已知指令数量 N_known**：满足 N_known < 2^(L - k×A)，其中 k 为该级地址码个数；且 N_known 不为 0，以确保有明确的占用数
- **保留前缀数 R**：R = 2^(opcode_bits) - N_known，其中 opcode_bits 为当前级操作码位数
- **下一级最大指令数**：R × 2^(额外占用地址码位数)，再减去本级保留前缀（若有更下一级）
- **一致性约束**：各级 opcode_bits + Σaddr_bits = L（总位数守恒）
- **可调自由度**：L、A、N_known 均可由 Question Agent 在上述约束内自由选择，但需确保子问题 2 的答案为正整数且非平凡（非全编码、非零）

## 参考经验
- **考察模式**：扩展操作码数量计算是 CO-4 题位的标准考法，"已知某级数量求另一级数量"是核心题型
- **难度锚点**：K4=4 对应该类题目的核心陷阱——保留前缀计数，历史经验表明此陷阱区分度高
- **典型陷阱**：
  1. 忘记减去已知级别占用的编码模式（直接用 2^opcode_bits）
  2. 忘记保留本级扩展前缀（当存在更下一级时）
  3. 地址码位数理解错误（混淆操作码位数与地址码位数）
