# 扩展操作码数量计算

## 题目

某计算机采用 **16 位定长指令字**，地址码长度为 **4 位**。该机采用扩展操作码编码方式，设有**二地址指令**、**一地址指令**和**零地址指令**三类指令格式。已知该机定义了 **6 条**二地址指令。

**Q1（3 分）**

(a) 一地址指令的操作码字段为多少位？

(b) 若该机需支持零地址指令扩展，一地址指令最多可以有多少条？

(c) 为支持零地址指令扩展，**至少**需保留多少个一地址操作码编码前缀？

**Q2（3 分）**

在第 1 问所保留前缀的基础上，最多可以有多少条零地址指令？

---

## 场景规则（通过条件）

> 以下约束与具体答案值无关，换参数仍成立。gen.py 须用 `assert` 逐条验证。

### 参数定义

| 符号 | 含义 |
|------|------|
| L | 指令字长（= 16） |
| A | 地址码位数（= 4） |
| N | 已知二地址指令数（= 6） |
| opcode_2 | 二地址操作码位数 = L − 2A |
| opcode_1 | 一地址操作码位数 = L − A |
| opcode_0 | 零地址操作码位数 = L |
| R1 | 二地址级保留的扩展前缀数 = 2^opcode_2 − N |
| R2 | 一地址级保留的扩展前缀数（≥ 1） |
| max1 | 一地址指令最大条数 = R1 × 2^(opcode_1 − opcode_2) − R2 |
| max0 | 零地址指令最大条数 = R2 × 2^(opcode_0 − opcode_1) |

### 约束清单（assert 靶子）

1. **位数守恒**：每级格式满足 `opcode_bits + Σaddress_bits == L`
   - `opcode_2 + 2*A == L`
   - `opcode_1 + A == L`
   - `opcode_0 + 0 == L`

2. **扩展前缀递推**：
   - `R1 == (1 << opcode_2) - N`
   - `R1 > 0`（确保有扩展空间）

3. **一地址编码空间**：`one_addr_space == R1 * (1 << (opcode_1 - opcode_2))`
   - 其中 `opcode_1 - opcode_2 == A`

4. **R2 最小值为 1**：为支持零地址指令扩展，至少保留 1 个一地址操作码编码前缀
   - `R2_min == 1`

5. **一地址最大条数**（取 R2 = R2_min = 1）：
   - `max1 == one_addr_space - R2_min`

6. **零地址最大条数**（取 R2 = R2_min = 1）：
   - `max0 == R2_min * (1 << (opcode_0 - opcode_1))`
   - 其中 `opcode_0 - opcode_1 == A`

7. **答案非平凡**：`max1 > 0` 且 `max0 > 0`
