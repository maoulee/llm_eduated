# 补码加减运算与溢出判断

## 题目信息

- **科目**：计算机组成原理
- **知识点**：CO-2 数据的表示和运算 > 定点数的运算 > 补码加减运算
- **题型**：综合题
- **分值**：6 分（每问 2 分）
- **难度**：K2（中档计算题）

## 题干

设某计算机采用 **变形补码（双符号位）** 表示定点整数，数据位为 $n=3$ 位，加上 2 位符号位共 5 位。双符号位的含义为：

| 双符号位 | 含义 |
|:---:|:---|
| 00 | 结果为正，无溢出 |
| 01 | 正溢出（上溢） |
| 10 | 负溢出（下溢） |
| 11 | 结果为负，无溢出 |

已知两个定点整数：

$$A = -5, \quad B = -6$$

（以上为十进制真值。$A$、$B$ 均为负整数，且均在上述**变形补码**（$n$ 位数值位、共 5 位，可表示范围 $[-8, +7]$）的可表示范围内。）

请完成以下各问：

### 第 1 问（2 分）

将 $A = -5$ 和 $B = -6$ 分别转换为 **变形补码（双符号位补码）** 表示，写出 5 位二进制结果。

### 第 2 问（2 分）

利用第 1 问的变形补码，计算 $A + B$。写出**逐位相加的竖式过程**及最终的双符号位结果，并根据双符号位判断是否溢出（若溢出，指明溢出类型）。

### 第 3 问（2 分）

利用第 1 问的变形补码，计算 $A - B$。要求：先将减法转化为加法（对减数取变形补码的负数），再逐位相加，写出**完整过程**及最终的双符号位结果，并根据双符号位判断是否溢出（若溢出，指明溢出类型；若未溢出，请明确说明"未溢出"并给出真值结果）。

## 考察意图

| 子问 | 考察点 | 对应 K 值 |
|:---|:---|:---:|
| 第 1 问 | 十进制负整数 → 变形补码转换（取反加一 + 符号扩展） | K2 |
| 第 2 问 | 双符号位补码加法运算 + 溢出判断 | K3 |
| 第 3 问 | 减法转加法（对减数取补）+ 溢出判断 + 真值还原 | K3 |

**区分度设计**：
- 第 1 问：非 2 的幂次负数（$-5$、$-6$），取反加一过程易出错。
- 第 2 问：两个负数相加 $-5+(-6)=-11$，超出 $n=3$ 位补码范围 $[-8,7]$，双符号位出现"10"（负溢出），考查溢出检测能力。
- 第 3 问：减法需对减数连同符号位取反加一再相加；若遗漏此步则结果错误；此问结果 $A-B=1$ 不溢出，需正确说明"未溢出"，考查判断完整性。

## 场景规则（本题成立条件）

> 以下为**参数间约束**，与具体答案值无关，换参数仍应成立。供 write_gen 翻译为 `assert`、供 dual_review 审核对照。

1. **表示范围约束**：$A$ 和 $B$ 均在 $n$ 位（数据位）补码可表示范围内，即 $-2^{n-1} \le A \le 2^{n-1}-1$ 且 $-2^{n-1} \le B \le 2^{n-1}-1$。
2. **溢出必现约束**：$A + B$ 和 $A - B$ 两组运算中，**至少一组**发生溢出（即结果的真值超出 $[-2^{n-1},\; 2^{n-1}-1]$ 范围），双符号位出现"01"或"10"。
3. **减法转加法一致性**：$A - B$ 的运算路径为 $[A]_\text{变补} + [-B]_\text{变补}$，其中 $[-B]_\text{变补}$ 由 $[B]_\text{变补}$ 连同符号位取反加一得到；该路径的正确性等价于 $(A - B)_\text{真值} == A - B$（未溢出时结果可还原为正确真值）。
4. **双符号位判溢一致性**：双符号位 $S_1S_0$，若 $S_1 \neq S_0$ 则溢出（$S_1=0,S_0=1$ 为正溢出，$S_1=1,S_0=0$ 为负溢出）；若 $S_1 = S_0$ 则未溢出。该判断结论必须与"真值是否超出表示范围"一致。
