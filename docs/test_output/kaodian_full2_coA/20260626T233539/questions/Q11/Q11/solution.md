# 补码加减运算与溢出判断 — 解答

## 基本参数

| 参数 | 值 |
|:---|:---|
| 数据位 $n$ | 3 |
| 符号位 | 2（双符号位） |
| 总位数 | 5 |
| 模 $M$ | $2^5 = 32$ |
| 有效表示范围 | $[-2^3, 2^3-1] = [-8, 7]$ |

---

## 第 1 问：求 $A$、$B$ 的变形补码（5位）

### $A = -5$ 的变形补码

1. 取绝对值：$|A| = 5 = 101_{(2)}$（3 位）
2. 逐位取反：$101 \to 010$
3. 末位加一：$010 + 1 = 011$
4. 符号扩展为双符号位：前面补 $11$

$$[A]_{\text{变补}} = \boxed{11011}$$

### $B = -6$ 的变形补码

1. 取绝对值：$|B| = 6 = 110_{(2)}$（3 位）
2. 逐位取反：$110 \to 001$
3. 末位加一：$001 + 1 = 010$
4. 符号扩展为双符号位：前面补 $11$

$$[B]_{\text{变补}} = \boxed{11010}$$

---

## 第 2 问：计算 $A + B$

利用第 1 问的变形补码，逐位相加：

```
    1 1 0 1 1   （[A]变补 = 27）
+   1 1 0 1 0   （[B]变补 = 26）
─────────────
  1 1 0 1 0 1   （原始和 = 53，7位）
```

原始和为 $53 = 110101_{(2)}$（7 位），丢弃最高位进位后取低 5 位：

$$[A+B]_{\text{变补}} = 10101 \ (= 21)$$

**双符号位判断**：结果的双符号位 $S_1 S_0 = 10$。

- $S_1 = 1,\ S_0 = 0$，$S_1 \neq S_0$ → **溢出**
- $S_1 = 1, S_0 = 0$ → **负溢出（下溢）**

**验证**：$A + B = -5 + (-6) = -11$，真值 $-11$ 超出有效表示范围 $[-8, 7]$，确实溢出。双符号位判溢结论与真值范围一致。✓

$$\boxed{[A+B]_{\text{变补}} = 10101，\ \text{双符号位 } 10，\ \textbf{负溢出（下溢）}}$$

---

## 第 3 问：计算 $A - B$

### 第一步：将减法转化为加法

$A - B = A + (-B)$，需要对 $[B]_{\text{变补}}$ 连同符号位取反加一，得到 $[-B]_{\text{变补}}$。

1. $[B]_{\text{变补}} = 11010$
2. 连同符号位取反：$11010 \to 00101$
3. 末位加一：$00101 + 1 = 00110$

$$[-B]_{\text{变补}} = 00110 \ (= 6)$$

> 验证：$-B = -(-6) = 6$，$6$ 的变形补码确为 $00110$。取反加一路径与直接求 $(-B)$ 的变形补码一致。✓

### 第二步：逐位相加

```
    1 1 0 1 1   （[A]变补 = 27）
+   0 0 1 1 0   （[-B]变补 = 6）
─────────────
  1 0 0 0 0 1   （原始和 = 33，6位）
```

原始和为 $33 = 100001_{(2)}$（6 位），丢弃最高位进位后取低 5 位：

$$[A-B]_{\text{变补}} = 00001 \ (= 1)$$

### 第三步：溢出判断与真值还原

**双符号位判断**：结果的双符号位 $S_1 S_0 = 00$。

- $S_1 = 0,\ S_0 = 0$，$S_1 = S_0$ → **未溢出**
- 双符号位 $00$ → 结果为正

**真值还原**：双符号位 $00$（正数，未溢出），真值 $= 00001_{(2)} = 1$。

**验证**：$A - B = -5 - (-6) = -5 + 6 = 1$，真值 $1$ 在有效表示范围 $[-8, 7]$ 内，确实未溢出。还原真值 $1$ 与实际真值 $1$ 一致。✓

$$\boxed{[A-B]_{\text{变补}} = 00001，\ \text{双符号位 } 00，\ \textbf{未溢出}，\ \text{真值} = 1}$$

| 规则 | 内容 | 结果 |

| 规则1 | $A=-5 \in [-8,7]$，$B=-6 \in [-8,7]$ | ✓ |
