# 补码加减运算与溢出判断

**科目**：计算机组成原理　　**知识点**：定点数的运算 — 补码加减运算　　**题型**：综合题　　**分值**：6 分（每问 2 分）

---

## 题目

设某计算机采用 **变形补码（双符号位）** 表示定点整数，数据位为 $n=3$ 位，加上 2 位符号位共 5 位。双符号位的含义为：

| 双符号位 | 含义 |
|:---:|:---|
| 00 | 结果为正，无溢出 |
| 01 | 正溢出（上溢） |
| 10 | 负溢出（下溢） |
| 11 | 结果为负，无溢出 |

已知两个定点整数：

$$A = -5, \quad B = -6$$

（以上为十进制真值。$A$、$B$ 均为负整数，且均在 $n$ 位补码可表示范围内。）

请完成以下各问：

### 第 1 问（2 分）

将 $A = -5$ 和 $B = -6$ 分别转换为 **变形补码（双符号位补码）** 表示，写出 5 位二进制结果。

### 第 2 问（2 分）

利用第 1 问的变形补码，计算 $A + B$。写出**逐位相加的竖式过程**及最终的双符号位结果，并根据双符号位判断是否溢出（若溢出，指明溢出类型）。

### 第 3 问（2 分）

利用第 1 问的变形补码，计算 $A - B$。要求：先将减法转化为加法（对减数取变形补码的负数），再逐位相加，写出**完整过程**及最终的双符号位结果，并根据双符号位判断是否溢出（若溢出，指明溢出类型；若未溢出，请明确说明"未溢出"并给出真值结果）。

---

## 参考答案

| 问题 | 答案 |
|:---|:---|
| 第 1 问 | $[A]_{\text{变补}} = 11011$，$\ [B]_{\text{变补}} = 11010$ |
| 第 2 问 | $[A+B]_{\text{变补}} = 10101$，双符号位 $10$，**负溢出（下溢）** |
| 第 3 问 | $[A-B]_{\text{变补}} = 00001$，双符号位 $00$，**未溢出**，真值 $= 1$ |

---

## 解析

### 基本参数

| 参数 | 值 |
|:---|:---|
| 数据位 $n$ | 3 |
| 符号位 | 2（双符号位） |
| 总位数 | 5 |
| 模 $M$ | $2^5 = 32$ |
| 有效表示范围 | $[-2^3, 2^3-1] = [-8, 7]$ |

---

### 第 1 问：求 $A$、$B$ 的变形补码（5 位）

**$A = -5$ 的变形补码**

1. 取绝对值：$|A| = 5 = 101_{(2)}$（3 位）
2. 逐位取反：$101 \to 010$
3. 末位加一：$010 + 1 = 011$
4. 符号扩展为双符号位：前面补 $11$

$$[A]_{\text{变补}} = \boxed{11011}$$

**$B = -6$ 的变形补码**

1. 取绝对值：$|B| = 6 = 110_{(2)}$（3 位）
2. 逐位取反：$110 \to 001$
3. 末位加一：$001 + 1 = 010$
4. 符号扩展为双符号位：前面补 $11$

$$[B]_{\text{变补}} = \boxed{11010}$$

---

### 第 2 问：计算 $A + B$

利用第 1 问的变形补码，逐位相加：

```
    1 1 0 1 1   （[A]变补 = 27）
+   1 1 0 1 0   （[B]变补 = 26）
─────────────
  1 1 0 1 0 1   （原始和 = 53，7位）
```

原始和为 $53 = 110101_{(2)}$（7 位），丢弃最高位进位后取低 5 位：

$$[A+B]_{\text{变补}} = 10101\ (= 21)$$

**双符号位判断**：结果的双符号位 $S_1 S_0 = 10$。

- $S_1 = 1,\ S_0 = 0$，$S_1 \neq S_0$ → **溢出**
- $S_1 = 1,\ S_0 = 0$ → **负溢出（下溢）**

**验证**：$A + B = -5 + (-6) = -11$，真值 $-11$ 超出有效表示范围 $[-8, 7]$，确实溢出。双符号位判溢结论与真值范围一致。✓

$$\boxed{[A+B]_{\text{变补}} = 10101，\ \text{双符号位 } 10，\ \textbf{负溢出（下溢）}}$$

---

### 第 3 问：计算 $A - B$

**第一步：将减法转化为加法**

$A - B = A + (-B)$，需要对 $[B]_{\text{变补}}$ 连同符号位取反加一，得到 $[-B]_{\text{变补}}$。

1. $[B]_{\text{变补}} = 11010$
2. 连同符号位取反：$11010 \to 00101$
3. 末位加一：$00101 + 1 = 00110$

$$[-B]_{\text{变补}} = 00110\ (= 6)$$

> 验证：$-B = -(-6) = 6$，$6$ 的变形补码确为 $00110$。取反加一路径与直接求 $(-B)$ 的变形补码一致。✓

**第二步：逐位相加**

```
    1 1 0 1 1   （[A]变补 = 27）
+   0 0 1 1 0   （[-B]变补 = 6）
─────────────
  1 0 0 0 0 1   （原始和 = 33，6位）
```

原始和为 $33 = 100001_{(2)}$（6 位），丢弃最高位进位后取低 5 位：

$$[A-B]_{\text{变补}} = 00001\ (= 1)$$

**第三步：溢出判断与真值还原**

**双符号位判断**：结果的双符号位 $S_1 S_0 = 00$。

- $S_1 = 0,\ S_0 = 0$，$S_1 = S_0$ → **未溢出**
- 双符号位 $00$ → 结果为正

**真值还原**：双符号位 $00$（正数，未溢出），真值 $= 00001_{(2)} = 1$。

**验证**：$A - B = -5 - (-6) = -5 + 6 = 1$，真值 $1$ 在有效表示范围 $[-8, 7]$ 内，确实未溢出。还原真值 $1$ 与实际真值 $1$ 一致。✓

$$\boxed{[A-B]_{\text{变补}} = 00001，\ \text{双符号位 } 00，\ \textbf{未溢出}，\ \text{真值} = 1}$$
