# 概念题

## 第 1 题

**题干**：某存储器按字节编址，地址线为 14 根，则该存储器的最大寻址空间为多大？

A. 16KB
B. 14KB
C. 8KB
D. 32KB

**答案**：A

---

## 第 2 题

**题干**：下列事件中，所引发的是外部中断（硬件中断）而非内部中断（异常）的是？

A. 除法运算时除数为 0
B. 程序访问了非法地址，产生地址越界
C. 定时器计数到期，向 CPU 发出中断请求
D. 执行指令时发生缺页

**答案**：C

---

## 第 3 题

**题干**：在计算机的多级存储层次结构中，关于寄存器、Cache、主存和辅存的比较，下列说法正确的是？

A. Cache 的存取速度低于主存，但容量大于主存
B. 主存的存取速度高于 Cache，但容量小于 Cache
C. 寄存器的存取速度最高，容量最小
D. 辅存的存取速度高于主存，且容量最大

**答案**：C

---

## 第 4 题

A. 直接寻址
B. 间接寻址
C. 立即寻址
D. 寄存器间接寻址

**答案**：C
