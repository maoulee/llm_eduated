## 考点
- **存储容量与地址线位数的对应关系**：理解存储容量 = 寻址单元数 × 每单元位数，且地址线位数 n 可寻址 2ⁿ 个单元
- **存储单位换算**：KB / MB 与字节、位的换算（1KB = 1024B）
- **按字节编址与按字编址的区别**：编址方式影响地址线位数计算

## 难度目标
- K1 = 4：需精准辨析"存储容量""地址线位数""编址方式"等易混概念，属于较高基础认知需求
- K2 = 1：计算量极小，仅需 2 的幂次心算（如 2KB → 11 根地址线）
- K3 = 1：无需多步串行推演，单步即可得出
- K4 = 3：存在陷阱——学生易混淆"按字节编址"与"按字编址"，或忽略编址方式直接用容量值推算地址线
- K5 = 1：单一知识点内部解决，不跨子系统

难度定位理由：纯概念辨析题，K1 主导，期末卷基础难度，符合 difficulty_level = 1。

## 考察模式
**概念辨析型——存储单位换算**（来自 slot 指定的 examination_mode）
- 参考历史经验 2009_Q22 的模式：给出存储容量，要求判断地址线位数或寻址空间
- 选择题形式，4 选项，1 正确 3 干扰
- 干扰项对应常见错误路径（编址方式混淆、单位换算错误、容量与位宽混淆）

## 出题要求
- 题型：单项选择题，4 选项，2 分
- 总条件数：1 个显式条件（给定存储容量及编址方式）
- 条件设计原则：题干给出一个明确的存储容量（如若干 KB）和编址方式（按字节编址），问需要多少根地址线
- 参数取值范围：容量取 2 的幂次 KB 级（2KB~64KB），保证心算可行且非平凡
- 选项设计：4 个选项的地址线位数应互不相同，对应不同错误路径

## 子问题规划
（选择题，无子问题）

## 参数约束
- **存储容量 C**：取值范围为 2KB ~ 64KB 之间的 2 的幂（如 2KB, 4KB, 8KB, 16KB, 32KB, 64KB）
- **编址方式**：明确说明"按字节编址"或"按字编址"，必须为题干显式条件
- **地址线位数 n**：由 C 和编址方式共同决定（按字节编址时 n = log₂(C)，C 以字节为单位）
- 约束关系：选项中 3 个干扰项必须对应明确可溯源的错误路径，不得随机取值
- 干扰路径建议：
  - 路径A（正确）：n = log₂(容量字节数)
  - 路径B：混淆编址方式，按字编址计算（字长假设为 16 或 32 位）
  - 路径C：单位换算错误，将 KB 当作 1000B 计算
  - 路径D：混淆地址线与数据线，给出数据线位数

## 参考经验

- 难度锚点：K1 主导（4），计算极轻（K2=1），陷阱在于编址方式识别（K4=3）
- 典型陷阱：按字编址 vs 按字节编址；地址线位数 vs 数据线位数
