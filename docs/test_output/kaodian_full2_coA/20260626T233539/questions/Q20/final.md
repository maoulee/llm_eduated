## 题目

# 指令流水线性能与冒险分析（综合题，10分）

某 RISC 处理器采用 **5 级指令流水线**，各级名称及功能如下：

| 级 | 名称 | 功能 |
|----|------|------|
| IF | 取指 | 从存储器取指令 |
| ID | 译码 / 读寄存器 | 指令译码，从寄存器堆读源操作数 |
| EX | 执行 | ALU 运算、地址计算 |
| MEM | 访存 | Load 读存储器 / Store 写存储器 |
| WB | 写回 | 将结果写入寄存器堆 |

各级段时间如下（同一时钟信号驱动所有级，时钟周期取各级最长时间）：

- IF = **300 ps**，ID = **200 ps**，EX = **500 ps**，MEM = **400 ps**，WB = **200 ps**

**寄存器堆内部约定：** WB 级在时钟周期前半段写入寄存器堆，ID 级在后半段读寄存器堆。因此，若写回与读出发生在同一时钟周期，读出的是新写入的值。

现有一段由 4 条指令组成的程序依次执行（按给定顺序进入流水线）：

| 编号 | 指令 | 功能说明 |
|------|------|----------|
| I1 | `LW R1, 0(R2)` | R1 ← Mem[R2]，从存储器加载到 R1 |
| I2 | `ADD R3, R1, R4` | R3 ← R1 + R4 |
| I3 | `SUB R5, R3, R6` | R5 ← R3 − R6 |
| I4 | `SW R5, 8(R2)` | Mem[R2+8] ← R5，将 R5 存入存储器 |

**转发（Forwarding）条件：**
- **ALU→ALU 转发：** 当前指令 EX 级所需源操作数，可由上一条指令的 EX/MEM 流水线寄存器直接转发（即 EX/MEM → EX），无需停顿。
- **Load-use 转发：** Load 指令的数据在 MEM 级末尾才可用，通过 MEM/WB 流水线寄存器转发到后续指令的 EX 级。但由于数据在 MEM 级结束时才就绪，紧接 Load 的指令仍需插入 **1 个停顿周期（bubble）**。

---

### 第（1）题（2分）
该流水线的时钟周期（操作周期）为多少 ps？写出计算依据。

### 第（2）题（3分）
假设流水线**无冒险**（ideal pipeline），计算：
- （a）4 条指令全部执行完毕所需的总时间（ps）；
- （b）该流水线相对于**非流水线**执行方式的**加速比 S**（非流水线方式下，每条指令串行完成全部 5 级，取各级时间之和）；
- （c）流水线的**吞吐率**（单位：指令/ns，保留两位小数）。

### 第（3）题（2分）
分析上述 4 条指令序列中存在的**数据冒险**（data hazard）：
- 逐对指出哪些指令之间存在数据相关，并说明相关寄存器；
- 判断每对相关的具体类型（如 Load-use 相关、一般 RAW 相关等）；
- 说明在按序流水线中，该序列是否存在 WAR 或 WAW 冒险，并简述理由。

### 第（4）题（3分）
分别计算以下两种情况下的**总停顿周期数**和**实际执行总周期数**：

- （a）**无转发**机制时：依赖指令必须等到产生结果的指令完成 WB 级后，才能在 ID 级读到正确值。计算全部数据冒险引起的总停顿周期数及实际执行总周期数。
- （b）**有转发**机制时（条件如上述转发约定）：计算全部数据冒险引起的总停顿周期数及实际执行总周期数。

> 要求：列出每对相关指令导致的停顿周期，再汇总。

## 参考答案

|------|------|
| 第（1）题 时钟周期 | **500 ps** |
| 第（2）题（a）理想流水线总时间 | **4000 ps** |
| 第（2）题（b）加速比 S | **1.6** |

## 解析

### 基本参数

| 参数 | 值 |
|------|----|
| 流水线级数 n | 5（IF / ID / EX / MEM / WB） |
| 各级时间 | IF=300 ps, ID=200 ps, EX=500 ps, MEM=400 ps, WB=200 ps |
| 指令条数 L | 4 |
| 各级时间之和 | 300+200+500+400+200 = 1600 ps |

---

### 第（1）题（2分）：时钟周期

流水线各级在同一时钟驱动下工作，时钟周期取各段时间的最大值：

$$T_{clk} = \max(300, 200, 500, 400, 200) = \mathbf{500\ ps}$$

**依据**：流水线各段固定在同一时钟节拍下运行，时钟周期必须能容纳最慢的那一级（此处为 EX = 500 ps）。

---

### 第（2）题（3分）：理想流水线性能

#### （a）理想流水线总时间

$$T_{ideal} = (n + L - 1) \times T_{clk} = (5+4-1) \times 500 = 8 \times 500 = \mathbf{4000\ ps}$$

#### （b）加速比 S

非流水线执行时间（每条指令串行走完全部 5 级）：

$$T_{non} = L \times (IF+ID+EX+MEM+WB) = 4 \times 1600 = 6400\ ps$$

$$S = \frac{T_{non}}{T_{ideal}} = \frac{6400}{4000} = \mathbf{1.6}$$

#### （c）吞吐率

$$TP = \frac{L}{T_{ideal}} = \frac{4}{4000\ ps} = 0.001\ \text{条/ps} = \mathbf{1.00\ \text{指令/ns}}$$

---

### 第（3）题（2分）：数据冒险分析

#### 逐对数据相关

| 相关对 | 相关寄存器 | 类型 |
|--------|-----------|------|
| I1（LW）→ I2（ADD） | R1 | **Load-use 相关**（producer 为 Load 指令） |
| I2（ADD）→ I3（SUB） | R3 | 一般 RAW 相关（ALU→ALU） |
| I3（SUB）→ I4（SW） | R5 | 一般 RAW 相关（ALU→ALU） |

说明：
- I1 写 R1，I2 读 R1 → RAW 相关，且 I1 是 Load → Load-use 相关。
- I2 写 R3，I3 读 R3 → RAW 相关（ALU→ALU）。
- I3 写 R5，I4 读 R5（Store 的源数据） → RAW 相关（ALU→ALU）。

#### WAR / WAW 冒险

在**按序（in-order）流水线**中，指令严格按程序顺序进入、按序完成，**不存在 WAR 和 WAW 冒险**：
- **WAR**（Write After Read）要求后续指令先于前序指令写寄存器，按序流水线不会发生这种乱序。
- **WAW**（Write After Write）要求后续指令先于前序指令写同一寄存器，同理按序流水线不会发生。

本序列也无逆序的写-读或写-写对，因此 **WAR 相关对数 = 0，WAW 相关对数 = 0**。

---

### 第（4）题（3分）：停顿周期计算

#### 理想流水线周期数

$$\text{理想周期} = n + L - 1 = 5 + 4 - 1 = 8\ \text{周期}$$

#### （a）无转发机制

无转发时，consumer 在 ID 级检测到冒险后停顿，直到 producer 完成 WB 级（WB 前半段写、ID 后半段读，同周期可读），方可读到正确值。

每对停顿 = `max(0, WB(producer) − ID(consumer原始))`：

| 相关对 | WB(producer) 周期 | ID(consumer原始) 周期 | 停顿 |
|--------|:-:|:-:|:-:|
| I1→I2（R1） | 5 | 3 | 5 − 3 = **2** |
| I2→I3（R3） | 6 | 4 | 6 − 4 = **2** |
| I3→I4（R5） | 7 | 5 | 7 − 5 = **2** |
| **合计** | | | **6** |

（逐周期传播模拟确认：I1 WB=周期5, I2 WB=周期8, I3 WB=周期11, I4 WB=周期14，总停顿 = 14 − 8 = 6，与逐对求和一致。）

$$\boxed{\text{总停顿周期} = 6,\quad \text{实际执行总周期} = 8 + 6 = 14}$$

#### （b）有转发机制

- **Load-use 相关对**（I1→I2，R1）：数据在 I1 的 MEM 级末尾才就绪，转发到 I2 的 EX 级仍需插入 **1 个停顿周期**。
- **ALU→ALU 相关对**（I2→I3、I3→I4）：通过 EX/MEM → EX 转发，**0 个停顿周期**。

| 相关对 | 类型 | 停顿 |
|--------|------|:-:|
| I1→I2（R1） | Load-use | **1** |
| I2→I3（R3） | ALU→ALU | **0** |
| I3→I4（R5） | ALU→ALU | **0** |
| **合计** | | **1** |

$$\boxed{\text{总停顿周期} = 1,\quad \text{实际执行总周期} = 8 + 1 = 9}$$

| 理想流水线时间 | 4000 ps（8 周期） |
