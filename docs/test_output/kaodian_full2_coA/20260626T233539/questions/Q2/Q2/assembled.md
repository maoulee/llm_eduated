## 出题契约

### 基本信息
- target_subject: 组成原理
- target_family: 组成原理 > CO-6 总线 > 总线性能指标 > 总线带宽
- primary_target_name: 异步串行传输与数据传输率
- question_type: single_choice
- examination_mode: 计算型——串行传输率公式计算

### 难度目标
- k_target: K1=1,K2=4,K3=1,K4=2,K5=1
- difficulty_level: 2
- difficulty_rationale: 单步公式代入计算，需正确统计帧格式总位数并计算数据位数占比，K2为主导难度维度，数字非2幂次易增加计算出错概率

### 结构要求
- option_count: 4
- distractor_strategy: 干扰项对应不同错误路径——忽略校验位/忽略停止位/用波特率直接作为答案，各路径产生不同数值确保区分度
- condition_count: 2-3

### 参数约束
- 波特率 B: 取常用串行波特率值（1200~115200 bps 范围），建议非2的幂次以增大计算区分度
- 数据位数 D: 6、7 或 8 位
- 校验位数 P: 0 或 1
- 停止位数 S: 1 或 2
- 起始位数: 固定 1
- 一帧总位数 N = 1 + D + P + S，范围 8~12
- 有效数据传输率 = B × D / N
- 一致性: 正确答案与各干扰项须为不同数值，干扰项须对应可识别的错误计算路径

### 参考经验摘要
- 历史模式: 异步串行传输率计算为经典考法，核心公式 有效数据传输率 = 波特率 × 数据位数 / 帧总位数
- 难度锚点: K2主导，难度2级，单选题标准难度
- 典型陷阱: 忽略起始位/校验位/停止位导致总位数少算、将波特率直接当作有效数据传输率、用总位数代替数据位数
