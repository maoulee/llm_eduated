# 异步串行传输与数据传输率

## 题干

某异步串行通信系统采用如下帧格式进行数据传输：

- 1 个起始位
- 8 个数据位
- 1 个奇校验位
- 2 个停止位

系统的波特率为 **9600 bps**。

该系统在正常工作时的**有效数据传输率**（即每秒实际传输的数据位数）为多少 bps？

## 选项

A. 6400 bps

B. 约 6982 bps

C. 7680 bps

D. 9600 bps

## 参数与公式

| 参数 | 值 |
|------|-----|
| 起始位数 | 1（固定） |
| 数据位数 D | 8 |
| 校验位数 P | 1 |
| 停止位数 S | 2 |
| 一帧总位数 N | 1 + D + P + S = 12 |
| 波特率 B | 9600 bps |

核心公式：

> 有效数据传输率 = B × D / N

## 场景规则（通过条件）

本题成立需满足以下参数间约束（与具体答案值无关，换参数仍成立）：

1. **帧总位数自洽**：N == 1 + D + P + S（起始位 + 数据位 + 校验位 + 停止位）。
2. **有效数据传输率公式**：有效数据传输率 == B × D / N。
3. **4 选项互异**：A/B/C/D 四个值各不相同。
4. **正确值唯一确定**：在给定参数下有效数据传输率有唯一确定值，A = 该值。
5. **干扰项对应声明错误类型**：
   - B = 忽略校验位后的计算结果（N' = 1 + D + 0 + S，结果 = B × D / N'）；
   - C = 忽略停止位后的计算结果（N'' = 1 + D + P + 0，结果 = B × D / N''）；
   - D = B（将波特率直接当作有效数据传输率）。
6. **干扰项有合理性**：B/C/D 均为同类题常见误算路径的真实产物，非荒谬值，且因各错误路径的帧总位数不同（12 / 11 / 10 / —），四个值保证互异。

## 设计说明

- **考点**：异步串行传输帧格式（起始位 + 数据位 + 校验位 + 停止位）的位数统计，以及有效数据传输率公式 B×D/N 的代入计算。
- **K2 主导**：单步公式代入，但需正确统计帧总位数（12 位），数字非 2 的幂次，增大计算出错概率。
- **区分度来源**：停止位取 2（而非 1），使"忽略校验位"（N'=11）与"忽略停止位"（N''=10）产生不同帧总位数 → 不同结果 → 干扰项互异。
