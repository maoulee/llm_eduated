# 异步串行传输与数据传输率 —— 求解

## 参数

| 参数 | 值 |
|------|-----|
| 起始位 | 1 |
| 数据位 D | 8 |
| 校验位 P | 1 |
| 停止位 S | 2 |
| 波特率 B | 9600 bps |

## 求解过程

### 第一步：统计一帧总位数 N

一帧由起始位、数据位、校验位、停止位组成：

$$N = 1 + D + P + S = 1 + 8 + 1 + 2 = 12 \text{（位）}$$

### 第二步：代入有效数据传输率公式

有效数据传输率 = B × D / N：

$$\text{有效数据传输率} = 9600 \times \frac{8}{12} = 9600 \times \frac{2}{3} = 6400 \text{ bps}$$

**正确答案：A. 6400 bps**

## 选项分析（各干扰项错误路径）

| 选项 | 实际值 | 错误路径 | 说明 |
|------|--------|----------|------|
| **A** | **6400 bps** | —（正确） | N=12，9600×8/12 = 6400 |
| B | 约 6982 bps | 忽略校验位 | 帧总位数少算 1 位，N'=1+8+0+2=11，9600×8/11 ≈ 6981.82 |
| C | 7680 bps | 忽略停止位 | 帧总位数少算 2 位，N''=1+8+1+0=10，9600×8/10 = 7680 |
| D | 9600 bps | 直接用波特率 | 将波特率直接当作有效数据传输率 |

**各选项互异验证**：6400、6982、7680、9600 四个值各不相同。

## 关键点

- 起始位、校验位、停止位都不属于有效数据位，统计帧总位数时必须全部计入。
- 有效数据传输率 = 波特率 ×（数据位数 / 帧总位数），本质是数据位在一帧中的占比。
- 本题数据位占比 8/12 = 2/3，因此有效数据传输率为 9600 的 2/3 = 6400 bps。
