## 考点
- **核心知识点**：异步串行传输的数据传输率计算
  - 考察侧重点：波特率与有效数据传输率的关系，帧格式中各组成位（起始位、数据位、校验位、停止位）对有效传输率的影响
- **辅助知识点**：异步串行通信的帧格式
  - 考察侧重点：理解一帧包含哪些位、每帧实际传输的位数大于有效数据位数

## 难度目标
- **K1=1**：仅需知道"有效数据传输率 = 波特率 × 数据位数/总帧位数"这一基本公式，概念需求微弱
- **K2=4**：单步计算但涉及单位统一和位数比率的换算，数字非2的幂友好，易在位数统计或除法上出错
- **K3=1**：无需多步串行推演，一步代入即得结果
- **K4=2**：存在常规注意点——学生需正确统计帧的总位数（起始位+数据位+校验位+停止位），但这是标准考点，408考生基本不会漏
- **K5=1**：单一知识点内部解决，不涉及跨系统联动

达标理由：题目本质是"有效数据传输率 = 波特率 × (数据位数 / 一帧总位数)"的单步代入计算，K2为决定性难度维度，K4仅涉及帧格式位数统计的常规注意。

## 考察模式
**计算型——串行传输率公式计算**
理由：slot 明确指定此考察模式。该模式直接考查学生对异步串行帧格式与有效数据传输率关系的理解，通过给出具体波特率和帧格式参数，要求计算有效数据传输率。模式成熟、区分度好，K2 主导恰好匹配"单步计算易错"的难度定位。

## 出题要求
- **题型**：单项选择题，2分
- **条件数**：2-3个显式条件（波特率、帧格式参数）
- **条件设计原则**：
  - 明确给出波特率数值
  - 明确给出帧格式：起始位数、数据位数、校验位数、停止位数
  - 不隐含帧格式，需在题干中完整列出各组成部分
- **参数取值范围要求**：
  - 波特率：常用串行通信波特率范围（如 1200~115200 bps 之间的常用值）
  - 数据位数：6/7/8 位之一
  - 校验位：0或1位
  - 停止位：1或2位
  - 起始位：固定1位（标准异步格式）

## 子问题规划
本题为单项选择题，无子问题划分。
- 4个选项：1个正确答案 + 3个干扰项
- 选项均为数值（bps 单位的有效数据传输率）

## 参数约束
- **波特率 B**：取常用串行波特率值，范围 1200~115200 bps，建议非2的幂次以便增大计算区分度
- **数据位数 D**：6、7 或 8 位
- **校验位数 P**：0（无校验）或 1
- **停止位数 S**：1 或 2
- **起始位数**：固定为 1
- **一帧总位数 N = 1 + D + P + S**，N 应在 8~12 范围内
- **一致性约束**：有效数据传输率 = B × D / N，结果应为可比较的数值
- **区分度约束**：干扰项应对应不同错误路径（如：忽略校验位、忽略停止位、用总帧位数代替数据位数等），各路径产生不同数值

## 参考经验
- **历史模式**：异步串行传输率计算是组成原理经典考法，核心公式为"有效数据传输率 = 波特率 × 数据位数/帧总位数"
- **难度锚点**：K2 主导，难度2级，适合单选题考查
- **典型陷阱**：
  - 常见错误1：忽略起始位 → 总位数少算1位 → 有效率偏高
  - 常见错误2：忽略校验位 → 总位数少算 → 有效率偏高
  - 常见错误3：忽略停止位 → 总位数少算 → 有效率偏高
  - 常见错误4：将波特率直接当作数据传输率（即用B而非B×D/N）
  - 常见错误5：用总位数代替数据位数计算（即算成B×N/N=B，退化为波特率）
