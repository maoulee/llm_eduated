## 考点
| 知识点 | 考察侧重点 |
|--------|-----------|
| WPL 定义与公式 | 掌握 WPL = Σ(wᵢ × lᵢ)，能正确识别叶子节点及其权值与路径长度 |
| 二叉树路径长度 | 从根到各叶子节点的路径长度（边数/层数）的确定 |
| 二叉树结构读取 | 从图形或层次描述中正确提取树的结构信息（左右子树、父子关系） |

## 难度目标
| 维度 | 目标等级 | 达标理由 |
|------|---------|---------|
| K1 概念理解 | 2 | 需要准确理解 WPL 的定义，区分路径长度与权值的概念 |
| K2 计算技能 | 3 | 需对多个叶子分别计算 wᵢ×lᵢ 并求和，涉及多步运算 |
| K3 分析推理 | 2 | 需从树结构中推断各叶子深度，存在一定的分析量 |
| K4 综合应用 | 2 | 需将树结构读取、路径长度确定和 WPL 公式三者结合 |
| K5 创新发散 | 1 | 标准计算型选择题，不涉及创新或发散性思维 |

## 考察模式
**计算型——WPL 公式计算与树结构分析**

选择理由：WPL 是 DS-5 的经典计算型考点，历年真题以"给定二叉树→计算 WPL"为核心模式。该模式能同时考察概念理解和计算技能，且干扰项设计空间丰富（常见计算错误），适合中等难度的选择题。参考 2013、2017 年真题中类似 WPL/Huffman 树的出题方式。

## 出题要求
- **题型**：单项选择题，4 选项，1 正确 3 干扰
- **总条件数**：2 个显式条件
  - 条件1：二叉树的完整结构（图形或明确的结构描述）
  - 条件2：各叶子节点的权值
- **条件设计原则**：
  - 树结构必须明确无歧义，考生能唯一确定每个叶子的深度
  - 权值分配应使各选项数值有区分度，避免多个干扰项与正确答案过近
  - 非完全二叉树优先，增加路径长度分析的区分度

## 子问题规划
选择题无子问题拆分。核心任务为单一计算：给定二叉树结构和叶子权值，求 WPL。

## 参数约束
| 参数 | 取值范围 | 一致性约束 |
|------|---------|-----------|
| 叶子节点数 | 4~6 个 | 不少于 4 个，否则计算量不足以产生有效区分 |
| 树的深度（最大层数） | 3~4 层 | 根为第 0 层；深度 ≥3 保证路径长度有变化 |
| 各叶子权值 | 正整数，范围 1~15 | 权值之间应有差异，避免全部相同 |
| 各叶子路径长度 | 1~3 | 由树结构决定；至少存在 2 种不同路径长度 |
| WPL 正确值 | 正整数 | 确保只有一个选项匹配 |
| 干扰项偏差 | 与正确值相差 5~20 | 四个选项之间最小差值 ≥ 3，保证区分度 |

**可调自由度**：
- 树的具体形状（由 Question Agent 设计）
- 具体权值分配（由 Question Agent 设定）
- 干扰项的具体构造方式（见干扰策略）

## 参数约束（补充：干扰策略）
建议的干扰项构造方式（Question Agent 至少选用 2 种）：
1. **路径长度偏移**：某叶子路径长度取层数而非边数（+1 偏差），导致 WPL 偏大
2. **遗漏叶子**：计算时遗漏某个叶子，导致 WPL 偏小
3. **权值替换**：将某叶子的权值与另一个叶子混淆
4. **重复计数**：非叶子节点被误计入 WPL 计算

## 参考经验
- **历史模式**：历年 WPL 考察以"给树求值"为主，偶有"给 WPL 反推树结构"的变体；选择题以正向计算为主
- **难度锚点**：中等难度对应 K2=3，计算步数 4~6 步，考生平均耗时 2~3 分钟
- **典型陷阱**：路径长度定义混淆（层数 vs 边数）是最常见的错误来源；其次是遗漏叶子或误将内部节点计入
