# DS-5-WPL-CALC

## 题目

已知一棵二叉树（根为第 0 层）的结构及各节点权值如下所示，节点旁标注的数字为该节点的权值。该二叉树的带权路径长度 WPL 为（ ）。

```
          A(9)
         / \
      B(2)  C(4)
            / \
         D(5) E(6)
             / \
          F(3) G(7)
```

A. 59
B. 32
C. 42
D. 54

## 设计说明

- **考察模式**：计算型——给定二叉树结构和节点权值，正向计算 WPL
- **参数选择理由**：
  - 4 个叶子节点（B, D, F, G），路径长度分别为 1、2、3、3，覆盖 3 种不同路径长度，体现区分度
  - 树为非完全二叉树：A 的左子树仅含 1 个叶子 B（深度 1），右子树深度达 3，结构不对称
  - 所有节点权值取 1~15 内互不相同的正整数（2,3,4,5,6,7,9），便于心算验证
  - 叶子权值之和 = 2+5+3+7 = 17，保证 D1（层数偏移）差值落在 5~20 区间
- **干扰策略实现**：
  - D1（层数偏移）：路径长度整体 +1（将根视为第 1 层），差值 = Σ叶子权值 = 17
  - D2（遗漏叶子）：遗漏叶子 D（权值 5，路径长度 2），差值 = 5×2 = 10
  - D3（内部节点误计）：将内部节点 E（权值 6，路径长度 2）误纳入求和，差值 = 6×2 = 12
- **与契约 K 值对齐**：K2=3（多步加权求和，4 个叶子需 4 步乘法+3 步加法），K3=2（从树结构识别叶子并确定路径长度），难度 level 3
- **should_be 对照**：
  - ✓ 正向计算 WPL = Σ(权值 × 路径长度)
  - ✓ 路径长度定义为边数（根为 0 层）
  - ✓ 至少 2 种路径长度（实际 3 种：1, 2, 3）
  - ✓ 非完全二叉树
  - ✓ 4 个叶子，权值 1~15 且各不相同
- **should_not_be 排查**：
  - ✓ 不涉及哈夫曼树构造
  - ✓ 不涉及编码效率
  - ✓ 不涉及线索二叉树或遍历
  - ✓ 无负数或小数权值
  - ✓ 非完全二叉树
