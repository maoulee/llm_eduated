## 求解过程

### 带权路径长度 WPL 的定义

二叉树的带权路径长度 WPL = Σ（叶子节点的权值 × 从根到该叶子的路径长度），其中路径长度定义为从根到该节点的**边数**（根为第 0 层）。

### 识别叶子节点及路径长度

根据树结构：

| 叶子节点 | 权值 | 从根到叶子的路径 | 路径长度（边数） |
|---------|------|-----------------|----------------|
| B | 2 | A→B | 1 |
| D | 5 | A→C→D | 2 |
| F | 3 | A→C→E→F | 3 |
| G | 7 | A→C→E→G | 3 |

注意：A、C、E 是内部节点（有子节点），不参与 WPL 计算。

### 正确计算

$$\text{WPL} = 2 \times 1 + 5 \times 2 + 3 \times 3 + 7 \times 3 = 2 + 10 + 9 + 21 = 42$$

### 选项分析

- **A. 59（干扰1：层数偏移）**——错误地将路径长度取为"层数"（根为第 1 层），即每条路径多算 1 条边：2×2 + 5×3 + 3×4 + 7×4 = 4 + 15 + 12 + 28 = 59。路径长度应为边数，根节点的路径长度为 0 而非 1。
- **B. 32（干扰2：遗漏叶子 D）**——求和时遗漏了叶子节点 D（权值 5，路径长度 2）：2×1 + 3×3 + 7×3 = 2 + 9 + 21 = 32。WPL 必须包含所有叶子节点。
- **C. 42（正确）**——4 个叶子节点权值乘以各自路径长度后求和：2×1 + 5×2 + 3×3 + 7×3 = 42。
- **D. 54（干扰3：误计内部节点 E）**——在正确 WPL 基础上误将内部节点 E（权值 6，路径长度 2）纳入求和：42 + 6×2 = 42 + 12 = 54。WPL 只对叶子节点求和，内部节点不应计入。

## 最终答案

- 正确答案：**C. 42**
  - 理由：WPL = Σ(叶子权值 × 路径长度) = 2×1 + 5×2 + 3×3 + 7×3 = 42，四个叶子节点 B、D、F、G 的路径长度分别为 1、2、3、3。
