## 求解过程

> 平衡因子定义：BF = 左子树高度 − 右子树高度。|BF| > 1 即失衡。

### 子问题(1)：插入 25 后的首次失衡

**插入 25 前的树**（已插入 30, 15, 38, 7, 20）：

```
        30
       /  \
      15   38
     /  \
    7   20
```

此时各节点 BF：节点 30 BF=1，节点 15 BF=0，其余 BF=0。

**BST 插入 25**：25 < 30 → 左走；25 > 15 → 右走；25 > 20 → 右走，成为 20 的右子节点。

**插入后（平衡前）的树**：

```
        30
       /  \
      15   38
     /  \
    7   20
         \
         25
```

**从底向上检查平衡因子**（exec 输出）：

| 节点 | 左子树高 | 右子树高 | BF | 是否失衡 |
|------|---------|---------|-----|---------|
| 7 | 0 | 0 | 0 | 否 |
| 20 | 0 | 1 | −1 | 否 |
| 15 | 1 | 2 | −1 | 否 |
| 38 | 0 | 0 | 0 | 否 |
| **30** | **3** | **1** | **2** | **是，|BF|=2 > 1** |

- **最小不平衡子树的根节点**：30
- **节点 30 的平衡因子**：2
- **旋转类型判断**：BF=2（左重），新节点 25 插入在 30 的左子（15）的右子树中 → **LR 旋转（双旋）**

---

### 子问题(2)：执行 LR 旋转后的树结构与根节点平衡因子

**LR 旋转分两步**（exec 输出）：

**第一步**：对 30 的左子 15 执行左旋（围绕 20）

```
   15              20
  /  \    →      /  \
 7   20         15   25
      \         /
      25       7
```

**第二步**：对 30 执行右旋（围绕 20）

```
      30              20
     /  \    →       /  \
    20   38         15   30
   /  \             /   /  \
  15   25          7   25   38
  /
 7
```

**旋转后的树结构**（exec print_tree 输出）：

```
        20
       /  \
      15   30
     /    /  \
    7    25   38
```

各节点 BF（exec 输出）：
- 节点 20：BF=0（左子树高=2，右子树高=2）
- 节点 15：BF=1（左子=7，右子=None）
- 节点 7：BF=0
- 节点 30：BF=0（左子=25，右子=38）
- 节点 25：BF=0
- 节点 38：BF=0

**根节点（20）的平衡因子：0**

---

### 子问题(3)：继续插入 22 和 5

#### 插入关键字 22

当前树（即 (2) 的结果）：

```
        20
       /  \
      15   30
     /    /  \
    7    25   38
```

BST 插入路径：20→30→25→22（22 < 25，成为 25 的左子）。

插入 22 后的树（exec print_tree 输出）：

```
        20
       /  \
      15   30
     /    /  \
    7    25   38
        /
       22
```

各节点 BF（exec 输出）：

| 节点 | BF | 是否平衡 |
|------|-----|---------|
| 22 | 0 | ✓ |
| 25 | 1 | ✓ |
| 7 | 0 | ✓ |
| 15 | 1 | ✓ |
| 38 | 0 | ✓ |
| 30 | 1 | ✓ |
| 20 | −1 | ✓ |

**结论：插入 22 后，所有节点 |BF| ≤ 1，树仍保持平衡，无需旋转。**

#### 插入关键字 5

BST 插入路径：20→15→7→5（5 < 7，成为 7 的左子）。

插入 5 后（平衡前）的树：

```
        20
       /  \
      15   30
     /    /  \
    7    25   38
   /    /
  5    22
```

从底向上检查 BF（exec 输出）：

| 节点 | BF | 是否失衡 |
|------|-----|---------|
| 5 | 0 | 否 |
| 7 | 1 | 否 |
| 22 | 0 | 否 |
| 25 | 1 | 否 |
| **15** | **2** | **是，|BF|=2 > 1** |

- **最小不平衡子树根节点**：15
- **节点 15 的平衡因子**：2（左子树高=2，右子树高=0）
- **旋转类型**：BF=2（左重），新节点 5 插入在 15 的左子（7）的左子树中 → **LL 旋转（单旋）**

LL 旋转（对 15 执行右旋）：7 上提为子树根，5 为 7 的左子，15 为 7 的右子。

旋转后的树结构（exec print_tree 输出，即最终树）：

```
        20
       /  \
      7    30
     / \   /  \
    5  15 25   38
          /
         22
```

验证旋转后各节点 BF（exec 输出）：
- 节点 20：BF=−1（左子树高=2，右子树高=3）
- 节点 7：BF=0（左子=5 高 1，右子=15 高 1）
- 节点 5：BF=0
- 节点 15：BF=0
- 节点 30：BF=1（左子=25 子树高 2，右子=38 高 1）
- 节点 25：BF=1（左子=22 高 1，右子=None 高 0）
- 节点 22：BF=0
- 节点 38：BF=0

全树所有节点 |BF| ≤ 1，平衡恢复。

## 最终答案

**(1)** 最小不平衡子树根节点为 **30**，其平衡因子为 **2**，旋转类型为 **LR 旋转（双旋）**。

**(2)** LR 旋转后的树结构：

```
        20
       /  \
      15   30
     /    /  \
    7    25   38
```

根节点（20）的平衡因子为 **0**。

**(3)** 
- 插入 22 后：树**仍保持平衡**，所有节点 |BF| ≤ 1，无需旋转。
- 插入 5 后：**发生失衡**，最小不平衡子树根节点为 **15**，BF=**2**，旋转类型为 **LL 旋转（单旋）**。旋转后的树结构：

```
        20
       /  \
      7    30
     / \   /  \
    5  15 25   38
          /
         22
```

**(4)** 根节点关键字：**20**；左子节点关键字：**7**；右子节点关键字：**30**。
