## 求解过程

### 逐步插入分析

**初始**：空树

**插入 38**：
```
  38
```
根 = 38，BF(38) = 0，平衡。

**插入 35**：35 < 38，插入为 38 的左子。
```
  38
 /
35
```
BF(35) = 0，BF(38) = 1 - 0 = 1，平衡。

**插入 30**：30 < 38 → 左子树，30 < 35 → 左子树，插入为 35 的左子。
```
  38
 /
35
/
30
```
BF(30) = 0，BF(35) = 1 - 0 = 1，BF(38) = 2 - 0 = 2 → **不平衡！**

38 的 BF = 2，且 30 < 35（新插入值 < 左子关键字），属于 **LL 型**，执行 **LL 旋转（右旋）**：
- 35 上升为根，30 为 35 的左子，38 为 35 的右子
```
  35
 /  \
30   38
```
BF(30) = 0，BF(38) = 0，BF(35) = 1 - 1 = 0，平衡。

**插入 45**：45 > 35 → 右子树，45 > 38 → 右子树，插入为 38 的右子。
```
  35
 /  \
30   38
       \
        45
```
BF(30) = 0，BF(45) = 0，BF(38) = 0 - 1 = -1，BF(35) = 1 - 2 = -1，平衡。

**插入 42**：42 > 35 → 右子树，42 > 38 → 右子树，42 < 45 → 左子树，插入为 45 的左子。
```
  35
 /  \
30   38
       \
        45
       /
      42
```
更新高度：h(42)=1，h(45)=2，h(38)=3。
BF(42) = 0，BF(45) = 1 - 0 = 1，BF(38) = 0 - 2 = -2 → **不平衡！**

38 的 BF = -2，且 42 < 45（新插入值 < 右子关键字），属于 **RL 型**，执行 **RL 旋转**：
1. 先对 45 执行右旋：42 上升，45 成为 42 的右子
2. 再对 38 执行左旋：42 上升为 38 的父，38 成为 42 的左子，45 保持为 42 的右子

旋转后：
```
  35
 /  \
30   42
    /  \
  38    45
```
BF(30) = 0，BF(38) = 0，BF(45) = 0，BF(42) = 1 - 1 = 0，BF(35) = 1 - 2 = -1，平衡。

## 最终答案
- 正确答案：35
  - 理由：插入全部 5 个关键字并完成所有必要的旋转操作后，AVL 树的根结点关键字为 35。
