## rationale
- 为何选此形式：AVL树插入的核心能力是多步串行推演（>5步：逐次插入→回溯更新平衡因子→检测失衡→判断旋转类型→执行旋转→重复），K3主导要求"多步串行推演"形式；同时K4要求隐含前提深度理解（LR/RL双旋转中"先子后父"的顺序、失衡结点与插入结点位置关系决定旋转类型而非单纯看左右），需"陷阱辨析"作为辅助形式覆盖错误路由路径
- 与目标 K-雷达的对齐说明：K3=4对应>5步推演且需维持动态状态更新（每次插入后回溯更新沿途平衡因子）；K4=4对应隐含前提深（双旋转顺序不可颠倒、旋转类型判断依赖位置关系而非直觉）；K1=3对应需准确记忆平衡因子定义和四种旋转触发条件；K2=2对应平衡因子计算为简单加减但需多次执行；K5=1对应单一数据结构内部操作，无跨域联动
