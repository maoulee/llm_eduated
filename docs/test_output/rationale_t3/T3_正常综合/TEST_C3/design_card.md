## design_rationale
本题考察AVL树插入与旋转的完整操作流程，设计意图是区分"能完整走完插入-失衡检测-旋转恢复流程并回溯检查的学生"与"只记得旋转名称但无法在动态插入过程中正确路由的学生"。选择"结构操作与状态维护模拟"模式，是因为AVL树的核心能力不在于记住四种旋转的名称，而在于在多步插入的串行推演中，每一步都能正确计算平衡因子、识别失衡类型、选择正确的旋转方式。K3-K4平衡型的设计逻辑是：K3要求>5步的推演（多次插入+平衡因子更新+旋转执行），K4要求隐含前提的深度理解（如LR/RL双旋转中"先子节点旋转再父节点旋转"的顺序不能颠倒，失衡结点与插入结点的位置关系决定旋转类型而非单纯看左右）。选择题形式适合在有限篇幅内考查多步推演的最终状态，通过精心设计的干扰项覆盖常见错误路径，使题目既能区分掌握程度又不至于因推演过长导致工作记忆过载。

## expected_reasoning_actions
- 从空树开始，按给定序列逐个插入结点
- 每次插入后，沿插入路径回溯至根，更新沿途各结点的平衡因子
- 识别首次出现平衡因子绝对值为2的结点（失衡结点）
- 根据插入结点相对于失衡结点及其子结点的位置关系，判断旋转类型（LL/RR/LR/RL）
- 执行对应旋转操作，更新旋转涉及结点的平衡因子
- 重复上述过程直至所有结点插入完毕
- 根据最终树形态回答设问（如根结点值、某结点平衡因子、树高等）

## question_structure_plan
- stem_style: 给定一个初始为空的AVL树和一组插入序列，要求推演插入过程并回答关于最终树形态的问题
- asking_method: 直接设问最终状态（如"插入完成后，根结点的关键字是？"或"插入完成后，树的高度为？"）
- option_architecture:
  - correct: 完整正确模拟所有插入和旋转后得出的最终状态值
  - distractor_1 (遗漏旋转): 某次插入后未执行旋转，导致树未保持平衡，基于此错误树形态得出的答案
  - distractor_2 (旋转类型错误): 将LR误判为LL或将RL误判为RR（单旋转替代双旋转），基于错误旋转得出的答案
  - distractor_3 (平衡因子计算错误): 某结点平衡因子计算错误（如符号错误或数值偏差），导致旋转触发时机或类型判断错误

## parameter_plan
- parameter_slots:
  - insertion_sequence: 插入序列，候选范围5-7个整数，需确保插入过程中至少触发1次旋转（最好包含一次双旋转LR或RL）
  - initial_tree_state: 初始为空树
  - asking_target: 设问目标，候选为"根结点关键字"、"树高"、"某特定结点平衡因子"之一
- validation_targets:
  - 插入序列必须产生唯一确定的最终AVL树形态
  - 正确选项与3个干扰项必须互不相同
  - 每个干扰项必须对应一个可追溯的错误认知路径
  - 插入序列长度不宜过长（≤7），避免工作记忆过载
- adjustment_priority:
  - 优先调整插入序列使旋转触发次数适中（1-2次旋转）
  - 其次调整设问目标使答案简洁（单个整数）
  - 最后调整干扰项使其对应真实错误路径

## terminology_and_expression_constraints
- required_terms:
  - 平衡二叉排序树 / AVL树
  - 平衡因子
  - 左旋 / 右旋 / 左右双旋 / 右左双旋（或 LL旋转 / RR旋转 / LR旋转 / RL旋转）
  - 失衡结点
- required_qualifiers:
  - 必须说明"按给定顺序依次插入"
  - 必须说明"初始为空树"或给出初始树形态
  - 平衡因子定义必须明确（左子树高度-右子树高度，或反之，但全文一致）
- avoid_phrases:
  - "调整平衡"（过于模糊，应明确为"执行XX旋转"）
  - "旋转一下"（不专业，应使用标准术语）
  - "左高右低"（应使用"平衡因子为正/负"）
- standard_rewrites:
  - bad: "对树进行调整" → good: "执行左旋/右旋/左右双旋/右左双旋操作"
  - bad: "树不平衡了" → good: "某结点的平衡因子绝对值变为2"
  - bad: "往左边插" → good: "插入到某结点的左子树中"

## audit_focus
- final_review_must_check:
  - 插入序列是否确实触发至少1次旋转（最好包含1次双旋转）
  - 正确选项是否通过完整模拟所有插入和旋转得出
  - 3个干扰项是否分别对应"遗漏旋转"、"旋转类型错误"、"平衡因子计算错误"三种错误路径
  - 干扰项数值是否与正确选项不同且互不相同
  - 题干是否明确插入顺序和初始状态
- solve_output_should_contain:
  - 每次插入后的树形态（可用文字描述或图示）
  - 每次插入后各结点的平衡因子
  - 每次旋转的触发原因（失衡结点、失衡类型）
  - 每次旋转的类型和执行过程
  - 最终树形态和设问答案
- fail_if_missing:
  - 插入序列不触发任何旋转（退化为BST插入）
  - 干扰项无法追溯到具体错误认知路径
  - 正确选项与某个干扰项数值相同
  - 题干未明确插入顺序或初始状态
  - 设问答案无法从最终树形态唯一确定
