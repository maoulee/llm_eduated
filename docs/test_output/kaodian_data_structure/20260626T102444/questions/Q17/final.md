# 综合题：删除单链表中所有值为 x 的结点（14 分）

## 题目

设有一个**带头结点**的单链表 L，头结点不存储有效数据，其余每个结点包含 `int` 类型的 `data` 域和指向后继的指针域。请设计一个算法，删除单链表 L 中**所有** `data` 域值等于给定值 `x` 的结点，并释放其内存空间。要求删除后链表仍保持原有相对顺序。

---

### 第 (1) 问：结点类型定义（2 分）

写出该带头结点单链表的**结点类型定义**（含类型别名），要求 `data` 域为 `int` 类型，指针域指向同类型结点。

### 第 (2) 问：算法思想（4 分）

用文字描述删除所有值为 `x` 的结点的算法思想，需说明：

- 如何遍历链表并维护前驱指针与当前指针的关系；
- 遇到 `data == x` 时如何进行删除与释放；
- 遇到 `data != x` 时如何移动指针；
- 需要处理的边界情况（空表、连续命中、尾结点命中、全表均为 x 等）。

### 第 (3) 问：C/C++ 代码实现（8 分）

用 C/C++ 实现该算法，写出完整函数（含必要的注释）。

**函数原型要求：**

```c
void DeleteX(LNode *&L, int x);
```

> 其中 `L` 为指向头结点的指针（引用传递），`x` 为待删除的目标值。

**实现要求：**

1. 被删除的结点必须用 `free()` 释放内存。
2. 关键步骤（指针移动、删除、释放）须有注释说明。
3. 算法须正确处理以下所有情况：
   - 空表（`L->next == NULL`，即只有头结点）；
   - 单结点且命中 / 单结点不命中；
   - 多个连续结点均命中 `x`；
   - 尾结点命中 `x`；
   - 全表所有结点均为 `x`（删除后只剩头结点）。

## 参考答案

**第 (1) 问：结点类型定义（2 分）**

```c
typedef struct LNode {
    int data;              // 数据域，存储 int 类型数据
    struct LNode *next;    // 指针域，指向同类型后继结点
} LNode, *LinkList;       // 类型别名：LNode 为结点类型，LinkList 为指向结点的指针类型
```

**第 (2) 问：算法思想（4 分）**

使用前驱指针 **pre** 和当前指针 **cur** 遍历链表。初始化 pre = L（头结点），cur = L→next（首个数据结点）。遍历过程中：若 cur→data == x，则摘链（pre→next = cur→next）、free(cur)、cur = pre→next（pre 不动）；若 cur→data ≠ x，则 pre = cur、cur = cur→next。详见解析。

**第 (3) 问：C/C++ 代码实现（8 分）**

```c
void DeleteX(LNode *&L, int x) {
    LNode *pre = L;            // pre 指向头结点（前驱指针初始化）
    LNode *cur = L->next;      // cur 指向首个数据结点（遍历起点，不从头结点开始）

    while (cur != NULL) {              // 遍历链表直到末尾
        if (cur->data == x) {          // 当前结点命中目标值 x
            pre->next = cur->next;     // 摘链：前驱的 next 跳过 cur
            free(cur);                 // 释放被删除结点的内存空间
            cur = pre->next;           // cur 前进到下一结点，pre 保持不动（处理连续命中）
        } else {                       // 当前结点不命中
            pre = cur;                 // 前驱指针前进
            cur = cur->next;           // 当前指针前进
        }
    }
}
```

## 解析

### 算法思想详解

使用两个工作指针 **pre**（前驱指针）和 **cur**（当前指针）遍历链表，pre 始终指向 cur 的前驱。

**初始化**：pre = L（头结点），cur = L→next（首个数据结点）。

**遍历过程**（cur ≠ NULL 时循环）：

- **遇到 data == x 时**（删除与释放）：
  - 将 pre→next 指向 cur→next（摘链，跳过被删结点）；
  - 调用 `free(cur)` 释放被删结点的内存；
  - 令 cur = pre→next（cur 前进到下一个待检查结点，**pre 不动**）。
  - 关键：pre 不前进，保证连续命中 x 时不会漏删。

- **遇到 data ≠ x 时**（移动指针）：
  - pre = cur（前驱指针前进）；
  - cur = cur→next（当前指针前进）。

### 边界情况处理

| 边界情形 | 处理方式 |
|---------|---------|
| 空表（L→next == NULL） | cur 初始为 NULL，循环不执行，直接返回 |
| 连续命中 | 删除后 pre 不前进，继续检查新 cur，保证连续 x 全部删除 |
| 尾结点命中 | 摘链后 pre→next = NULL，cur 变为 NULL，循环自然终止 |
| 全表均为 x | 所有数据结点被逐个删除，最终 L→next == NULL |
| 头结点 | 遍历起点为 L→next，头结点 L 始终保留，不会被删除 |
