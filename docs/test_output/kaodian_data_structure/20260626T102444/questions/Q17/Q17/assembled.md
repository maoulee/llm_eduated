## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 线性表 > 单链表
- primary_target_name: 删除单链表中所有值为x的结点
- question_type: comprehensive
- examination_mode: 算法设计型——链表操作算法设计

### 难度目标
- k_target: K1=1,K2=2,K3=2,K4=3,K5=4
- difficulty_level: 4
- difficulty_rationale: 算法设计题，需自行设计完整算法（结点定义+算法思想+代码实现），核心难点在指针操作正确性和边界条件处理，综合设计为主

### 结构要求
- sub_question_count: 3（结点定义2分 + 算法思想4分 + 代码实现8分）
- score_total: 14
- output_format: 三段式——结点类型定义、算法思想描述、C/C++代码（含注释）
- distractor_strategy: 不适用（算法设计题无选项干扰，区分度体现在代码正确性和边界处理）

### 子问题结构
- sub1: 结点类型定义（typedef struct LNode），分值2，类型=定义题，依赖=无
- sub2: 算法思想描述，分值4，类型=分析题，依赖=sub1
- sub3: C/C++代码实现（含注释），分值8，类型=编码题，依赖=sub1+sub2
- 依赖关系: 串行，内部逻辑递进

### 参数约束
- 链表结构: 带头结点的单链表 L，头结点不含有效数据
- data域类型: int（考生自定义，需全程一致）
- 目标值x: int类型，不指定具体值
- 链表长度: 不指定，算法须处理空表/单结点/多结点/连续命中等所有情况
- 内存管理: 删除结点须 free 释放（标准 C 做法）
- 一致性约束: 结点定义类型与算法中引用类型必须一致
- 可调自由度: 是否给出具体链表示例由出题者决定（非必须）

### 考察重点（评分锚点）
- 前驱指针维护: 遍历时始终保持 pre/cur 双指针关系
- 连续删除处理: 删除一个 x 结点后，pre->next 指向新结点，需重新判断而非直接前进
- 边界条件: 空表（L->next==NULL）、尾结点删除、全表均为x
- 内存释放: 被删除结点必须 free
- 代码注释: 关键步骤须有注释说明

### 参考经验摘要
- 历史模式: 链表删除操作算法设计，408综合题高频题型
- 难度锚点: K4=3（明确陷阱：前驱指针/连续删除），K5=4（指针状态在遍历-删除间保持一致）
- 典型陷阱: ①连续命中x漏删 ②忘记free ③混淆p与p->next移动 ④误删头结点
