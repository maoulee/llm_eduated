# 综合题：Dijkstra 单源最短路径手工推演

## 题干

已知有向带权图 G 有 6 个顶点，编号为 V0~V5，其邻接矩阵如下（`∞` 表示两顶点之间无直接有向边，对角线全为 `∞`）：

|  | V0 | V1 | V2 | V3 | V4 | V5 |
|---|---|---|---|---|---|---|
| **V0** | ∞ | 10 | 4 | 15 | ∞ | ∞ |
| **V1** | ∞ | ∞ | ∞ | ∞ | 6 | ∞ |
| **V2** | ∞ | 3 | ∞ | 2 | ∞ | ∞ |
| **V3** | ∞ | ∞ | ∞ | ∞ | 5 | ∞ |
| **V4** | ∞ | ∞ | ∞ | ∞ | ∞ | ∞ |
| **V5** | ∞ | ∞ | ∞ | ∞ | ∞ | ∞ |

所有边的权值均为正整数。以 **V0 为源点**，使用 **Dijkstra 算法**求从 V0 到其余各顶点的单源最短路径。

> **算法约定**：
> - 每轮从未收录顶点中选取 `dist` 值最小的顶点加入集合 S（若存在多个 `dist` 相同的最小顶点，选编号较小者优先）。
> - 选取后将该顶点的所有出边进行松弛操作：若 `dist[v] > dist[u] + w(u,v)`，则更新 `dist[v]` 并记录前驱 `prev[v] = u`。
> - `dist` 初始值：源点为 0，其余顶点为 `∞`。
> - 从源点不可达的顶点，其 `dist` 最终保持 `∞`。

请回答以下问题：

### 问题 1（4 分）

写出 Dijkstra 算法执行过程中，**每一轮**被选入集合 S 的顶点编号，以及在该轮松弛操作结束后各顶点的 `dist` 值。

请按下表格式填写（每加入一个顶点记为一轮，共 5 轮，即 V0~V4 依次被收录；V5 不可达，不被收录）：

| 轮次 | 选入顶点 | dist[V0] | dist[V1] | dist[V2] | dist[V3] | dist[V4] | dist[V5] |
|------|---------|----------|----------|----------|----------|----------|----------|
| 初始 | — | 0 | ∞ | ∞ | ∞ | ∞ | ∞ |
| 第1轮 | V0 | | | | | | |
| 第2轮 | | | | | | | |
| 第3轮 | | | | | | | |
| 第4轮 | | | | | | | |
| 第5轮 | | | | | | | |

### 问题 2（3 分）

写出从源点 V0 到其余各顶点（V1~V5）的**最短路径长度**。不可达顶点写 `∞`。

### 问题 3（3 分）

写出从源点 V0 到 V4 的**完整最短路径**（依次写出路径上经过的顶点序列，如 `V0 → V2 → V1 → V4`），并说明确定该路径所依据的前驱链。

## 设计说明（供审核，不出现在试卷中）

### 考察意图

- **core_knowledge_intent**：Dijkstra 算法的手工模拟——逐轮选顶点、松弛操作、dist 数组更新、前驱记录与路径还原。
- **examination_mode**：推演型——完整模拟 Dijkstra 多轮松弛过程，每一步均需正确，错一步全盘皆输。
- **K 目标**：K3=4（长程推演，>5 步）、K2=2（单步松弛计算）、K4=2（路径还原需综合前驱信息）。

### 图结构设计要点

| 约束 | 满足方式 |
|------|---------|
| 源点出度 ≥ 2 | V0 出度为 3（→V1, →V2, →V3） |
| 不可达顶点 | V5 无任何入边，dist 最终为 ∞ |
| 松弛区分度 | V1：直连 10，经 V0→V2→V1 为 7，后者更短；V3：直连 15，经 V0→V2→V3 为 6，后者更短 |
| 权值范围 | 均为正整数，2~15，无负权 |
| 无自环无重边 | 邻接矩阵对角线全 ∞，每对顶点至多一条有向边 |

### 通过条件（本题成立的可机检特征）

以下条件必须全部满足，由 gen.py exec 时通过 `assert` 验证：

1. **拓扑完整性**：Dijkstra 执行恰好 5 轮收录（V0~V4），V5 因不可达不被收录。
2. **不可达顶点**：V5 的 dist 在所有轮次及最终结果中保持 `∞`。
3. **松弛更新发生**：至少存在 2 个顶点（V1 和 V3）在第1轮之后被更短的路径松弛更新（即 dist 值在某轮严格减小），证明松弛过程非平凡。
4. **路径还原正确**：V0 到 V4 的最短路径存在且唯一，路径长度 = V4 最终 dist 值，且路径上相邻顶点之间均有有向边。
5. **前驱链自洽**：沿 prev 链从 V4 回溯到 V0，每一步路径长度之和 = V4 的最短路径长度。
6. **选顶点无歧义**：每一轮被选入的顶点 dist 值在未收录顶点中唯一最小（或按编号最小打破并列，但本题各轮 dist 最小值均唯一）。
