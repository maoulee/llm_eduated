## 题目

已知有向带权图 G 有 6 个顶点，编号为 V0~V5，其邻接矩阵如下（`∞` 表示两顶点之间无直接有向边，对角线全为 `∞`）：

|  | V0 | V1 | V2 | V3 | V4 | V5 |
|---|---|---|---|---|---|---|
| **V0** | ∞ | 10 | 4 | 15 | ∞ | ∞ |
| **V1** | ∞ | ∞ | ∞ | ∞ | 6 | ∞ |
| **V2** | ∞ | 3 | ∞ | 2 | ∞ | ∞ |
| **V3** | ∞ | ∞ | ∞ | ∞ | 5 | ∞ |
| **V4** | ∞ | ∞ | ∞ | ∞ | ∞ | ∞ |
| **V5** | ∞ | ∞ | ∞ | ∞ | ∞ | ∞ |

所有边的权值均为正整数。以 **V0 为源点**，使用 **Dijkstra 算法**求从 V0 到其余各顶点的单源最短路径。

> **算法约定**：
> - 每轮从未收录顶点中选取 `dist` 值最小的顶点加入集合 S（若存在多个 `dist` 相同的最小顶点，选编号较小者优先）。
> - 选取后将该顶点的所有出边进行松弛操作：若 `dist[v] > dist[u] + w(u,v)`，则更新 `dist[v]` 并记录前驱 `prev[v] = u`。
> - `dist` 初始值：源点为 0，其余顶点为 `∞`。
> - 从源点不可达的顶点，其 `dist` 最终保持 `∞`。

请回答以下问题：

### 问题 1（4 分）

写出 Dijkstra 算法执行过程中，**每一轮**被选入集合 S 的顶点编号，以及在该轮松弛操作结束后各顶点的 `dist` 值。

请按下表格式填写（每加入一个顶点记为一轮，共 5 轮，即 V0~V4 依次被收录；V5 不可达，不被收录）：

| 轮次 | 选入顶点 | dist[V0] | dist[V1] | dist[V2] | dist[V3] | dist[V4] | dist[V5] |
|------|---------|----------|----------|----------|----------|----------|----------|
| 初始 | — | 0 | ∞ | ∞ | ∞ | ∞ | ∞ |
| 第1轮 | V0 | | | | | | |
| 第2轮 | | | | | | | |
| 第3轮 | | | | | | | |
| 第4轮 | | | | | | | |
| 第5轮 | | | | | | | |

### 问题 2（3 分）

写出从源点 V0 到其余各顶点（V1~V5）的**最短路径长度**。不可达顶点写 `∞`。

### 问题 3（3 分）

写出从源点 V0 到 V4 的**完整最短路径**（依次写出路径上经过的顶点序列，如 `V0 → V2 → V1 → V4`），并说明确定该路径所依据的前驱链。

## 参考答案

**问题 1**

| 轮次 | 选入顶点 | dist[V0] | dist[V1] | dist[V2] | dist[V3] | dist[V4] | dist[V5] |
|------|---------|----------|----------|----------|----------|----------|----------|
| 初始 | — | 0 | ∞ | ∞ | ∞ | ∞ | ∞ |
| 第1轮 | V0 | 0 | 10 | 4 | 15 | ∞ | ∞ |
| 第2轮 | V2 | 0 | 7 | 4 | 6 | ∞ | ∞ |
| 第3轮 | V3 | 0 | 7 | 4 | 6 | 11 | ∞ |
| 第4轮 | V1 | 0 | 7 | 4 | 6 | 11 | ∞ |
| 第5轮 | V4 | 0 | 7 | 4 | 6 | 11 | ∞ |

收录顺序：V0 → V2 → V3 → V1 → V4；V5 不可达，未被收录。

**问题 2**

| 顶点 | 最短路径长度 |
|------|------------|
| V1 | 7 |
| V2 | 4 |
| V3 | 6 |
| V4 | 11 |
| V5 | ∞（不可达） |

最终 dist 数组：`[0, 7, 4, 6, 11, ∞]`

**问题 3**

最短路径：**V0 → V2 → V3 → V4**，路径长度 = 4 + 2 + 5 = **11**。

前驱链：prev[V4] = V3，prev[V3] = V2，prev[V2] = V0。

## 解析

**问题 1 逐轮推演**

有向边：V0→V1=10，V0→V2=4，V0→V3=15，V1→V4=6，V2→V1=3，V2→V3=2，V3→V4=5。

**第1轮：选入 V0（dist[V0]=0）**

对 V0 的出边（V0→V1=10、V0→V2=4、V0→V3=15）进行松弛：

- dist[V1]：∞ > 0+10=10 → 更新为 10，prev[V1]=V0
- dist[V2]：∞ > 0+4=4 → 更新为 4，prev[V2]=V0
- dist[V3]：∞ > 0+15=15 → 更新为 15，prev[V3]=V0

松弛后：dist = [0, 10, 4, 15, ∞, ∞]

**第2轮：选入 V2（dist[V2]=4，未收录中唯一最小）**

对 V2 的出边（V2→V1=3、V2→V3=2）进行松弛：

- dist[V1]：10 > 4+3=7 → 更新为 7，prev[V1]=V2
- dist[V3]：15 > 4+2=6 → 更新为 6，prev[V3]=V2

松弛后：dist = [0, 7, 4, 6, ∞, ∞]

**第3轮：选入 V3（dist[V3]=6，未收录中唯一最小）**

对 V3 的出边（V3→V4=5）进行松弛：

- dist[V4]：∞ > 6+5=11 → 更新为 11，prev[V4]=V3

松弛后：dist = [0, 7, 4, 6, 11, ∞]

**第4轮：选入 V1（dist[V1]=7，未收录中唯一最小）**

对 V1 的出边（V1→V4=6）进行松弛：

- dist[V4]：11 < 7+6=13 → 不更新

松弛后（无变化）：dist = [0, 7, 4, 6, 11, ∞]

**第5轮：选入 V4（dist[V4]=11，未收录中唯一最小）**

V4 无出边，不进行松弛。

松弛后（无变化）：dist = [0, 7, 4, 6, 11, ∞]

> V5 无任何入边，dist 保持 ∞，不可达，不被收录。

---

**问题 2 解析**

各顶点最短路径长度直接取最终 dist 数组中对应值。V1=7（经 V0→V2→V1），V3=6（经 V0→V2→V3），V4=11（经 V0→V2→V3→V4）。

---

**问题 3 解析**

沿 prev 链从 V4 回溯到 V0：

| 回溯步骤 | 前驱关系 | 对应有向边 | 权值 |
|---------|---------|-----------|------|
| 第1步 | prev[V4] = V3 | V3 → V4 | 5 |
| 第2步 | prev[V3] = V2 | V2 → V3 | 2 |
| 第3步 | prev[V2] = V0 | V0 → V2 | 4 |

边权之和 = 5 + 2 + 4 = **11** = dist[V4]，前驱链自洽。

最终 prev 数组：`[无, V2, V0, V2, V3, 无]`

> V0→V4 无直连边。若经 V0→V1→V4，长度为 10+6=16 > 11；而经 V0→V2→V3→V4，长度为 4+2+5=11，为最短路径。
