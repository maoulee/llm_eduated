## 考点
- **核心知识点**：Dijkstra 单源最短路径算法
  - 考察侧重点：逐顶点选最小、逐趟松弛更新 dist 数组的完整手工模拟流程
- **辅助知识点**：有向带权图的表示（邻接矩阵 / 边集）
  - 考察侧重点：从给定图结构正确读取各顶点间的边权，构建初始 dist 值
- **辅助知识点**：最短路径的前驱/路径还原
  - 考察侧重点：通过 path 数组或逐趟记录，给出源点到各终点的完整路径

## 难度目标
- **K1=1（微弱）**：Dijkstra 是高频核心算法，学生不需额外记忆冷门概念，仅需知道算法流程即可入题。
- **K2=2（较低）**：单步松弛为加法 + 比较取小，数字友好（均为小正整数权重），单步不易算错。
- **K3=4（较高）**：要求逐顶点（至少 5 个以上顶点）完整模拟多轮选最小-松弛过程，步数 >5，需维持 dist 数组的动态状态更新，中间错一步后续全错。
- **K4=2（较低）**：存在常规注意点——不可达顶点的 dist 保持 ∞、Dijkstra 不适用于负权边（但本题不考负权陷阱，仅作为隐含常识）。
- **K5=1（微弱）**：单一知识点（图的应用）内部解决，不跨子系统。

K 主导维度为 **K3=4**，与 slot 的 difficulty_rationale 一致：手动模拟 Dijkstra 多轮松弛，长程推演。

## 考察模式
**推演型——Dijkstra 算法手工模拟**

理由：slot 已指定此考察模式，且 K3=4 的核心需求正是长程逐步推演。要求学生写出每一趟的 dist 数组状态变化，直接考察对算法流程的掌握程度，区分度高——中间任何一趟松弛遗漏或选错最小顶点都会导致后续全部偏移。

## 出题要求
- **题型**：综合题，10 分
- **图结构**：给定一个有向带权图，提供邻接矩阵或带权边集，顶点数 5-7 个，源点指定
- **总条件**：图的结构信息（邻接矩阵或边集表）+ 源点编号 + 问题指令
- **条件设计原则**：
  - 图中存在若干不可达顶点（dist 最终为 ∞），考察学生对"无出边 / 无入边"的正确处理
  - 权值均为正整数（Dijkstra 前提），取小正整数（1-20），避免计算负担
  - 图中至少有一条路径存在"间接更新后被更短路径覆盖"的情况（即某顶点先被一条路径松弛，后续被另一条更短路径再次松弛），考察松弛更新的完整覆盖
  - 顶点编号从 0 或 1 开始，需明确

## 子问题规划
共 3 个子问题，串行递进，总分 10 分。

### 子问题 1（4 分）——逐趟 dist 数组更新表
- **类型**：计算 / 推演
- **考察目标**：用 Dijkstra 算法从源点出发，逐趟（每选出一个最近顶点为一趟）写出 dist 数组的完整变化过程，以表格形式呈现
- **格式要求**：表格行 = 趟数，表格列 = 各顶点的 dist 值，未确定顶点用 ∞ 或"-"标注
- **与前后问关系**：本问是全题核心，后续两问依赖本问结果

### 子问题 2（3 分）——最终最短路径长度
- **类型**：计算
- **考察目标**：根据第 1 问结果，给出源点到每个可达顶点的最终最短路径长度
- **与前后问关系**：直接依赖第 1 问最后一趟 dist 值

### 子问题 3（3 分）——完整路径还原
- **类型**：分析
- **考察目标**：对每个可达顶点，写出从源点出发的完整最短路径（顶点序列）；不可达顶点标注"不可达"
- **与前后问关系**：依赖第 1 问中逐趟松弛时的前驱选择，需从 path 前驱数组或逐趟记录还原

## 参数约束
- **顶点数 n**：5 ≤ n ≤ 7。过少则推演步数不足（K3 降级），过多则冗余且分值不匹配
- **边数 m**：满足 n-1 ≤ m ≤ n(n-1)/2（保证图连通部分存在路径，同时不是完全图留有选择空间）
- **权值范围**：正整数，1 ≤ w ≤ 20。确保单步加法为心算友好值
- **源点**：指定为某一顶点，建议选中等出度顶点（出度 ≥ 2），使初始 dist 非平凡
- **不可达顶点**：至少 1 个顶点从源点不可达，其 dist 最终为 ∞
- **路径覆盖性约束**：至少 1 个顶点经历"先被松弛、后被更短路径覆盖"的过程（即其 dist 在某趟更新后，在更后面的趟次再次更新为更小值），保证松弛更新的区分度
- **无负权边**：所有边权 > 0（Dijkstra 适用前提）
- **无自环、无重边**：简化图结构读取

## 参考经验
- **历史模式**：408 历年真题中 Dijkstra 手工模拟为图应用的高频考法，典型形式为"给邻接矩阵 / 邻接表 → 逐趟填 dist 表 → 写最短路径"
- **难度锚点**：K3=4 对应 5+ 顶点的完整推演，与历年真题中"6 顶点 Dijkstra"难度相当
- **典型陷阱**：
  1. 选最小 dist 顶点时遗漏已确定集合，重复选取已收录顶点
  2. 松弛时未通过新加入顶点的出边更新邻接顶点
  3. 不可达顶点误填 0 而非 ∞
  4. 路径还原时未回溯前驱，仅写直接前驱而非完整路径序列
