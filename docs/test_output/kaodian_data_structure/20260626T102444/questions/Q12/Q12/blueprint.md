## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 图 > 图的应用
- primary_target_name: 给定有向带权图用Dijkstra求单源最短路径
- question_type: comprehensive
- examination_mode: 推演型——Dijkstra算法手工模拟

### 难度目标
- k_target: K1=1,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 4
- difficulty_rationale: 需手动模拟Dijkstra算法多轮松弛过程，顶点数5-7个，逐趟更新dist数组，长程推演步数>5，中间错一步全盘皆输；单步计算简单（小正整数加法+取小），无跨域联动

### 结构要求
- sub_question_count: 3
  - 子问题1（4分）：逐趟 dist 数组更新表（推演型）
  - 子问题2（3分）：最终最短路径长度（计算型）
  - 子问题3（3分）：完整路径还原（分析型）
- dependency: 串行递进（2依赖1，3依赖1的前驱信息）
- distractor_strategy: 不适用（综合题为开放作答，非选择题）

### 图结构参数约束
- 顶点数 n: 5 ≤ n ≤ 7
- 边数 m: n-1 ≤ m ≤ n(n-1)/2
- 权值范围: 正整数，1 ≤ w ≤ 20
- 无负权边（Dijkstra适用前提）
- 无自环、无重边
- 图的表示形式: 邻接矩阵或带权边集表，由出题者选择

### 图结构设计约束
- 源点: 出度≥2的顶点，使初始dist非平凡
- 不可达顶点: 至少1个从源点不可达（dist最终为∞）
- 路径覆盖性: 至少1个顶点经历"先后被两条不同路径松弛，后者更短"的过程，保证松弛更新的区分度
- 顶点编号: 从0或1开始，题干需明确

### 参考经验摘要
- 历史模式: 408高频考法——给邻接矩阵/邻接表，逐趟填dist表，写最短路径
- 难度锚点: K3=4对应5-7顶点完整推演，与历年真题"6顶点Dijkstra"难度相当
- 典型陷阱:
  1. 选最小dist时重复选取已收录顶点
  2. 松弛时遗漏新加入顶点的出边
  3. 不可达顶点误填0而非∞
  4. 路径还原仅写直接前驱而非完整路径序列
