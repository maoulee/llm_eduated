# 概念题

## 第 1 题

**题干**：关于顺序表和链表的存储结构与访问特性，下列说法正确的是（　　）。

A. 顺序表采用顺序存储结构，只能进行顺序存取，访问第 i 个元素的时间复杂度为 O(n)；链表采用随机存储结构，可以随机存取，访问任意元素的时间复杂度为 O(1)

B. 顺序表采用顺序存储结构，支持随机存取，访问第 i 个元素的时间复杂度为 O(1)；链表采用链式存储结构，只能顺序存取，访问第 i 个元素的时间复杂度为 O(n)

C. 顺序表和链表都采用顺序存储结构，都支持随机存取，访问任意元素的时间复杂度均为 O(1)

D. 顺序表采用顺序存储结构，支持随机存取，访问第 i 个元素的时间复杂度为 O(1)；链表也采用随机存储结构，支持随机存取，访问任意元素的时间复杂度也为 O(1)


## 第 2 题

A. 栈为空

B. 只有一个元素 '('

C. 只有一个元素 '['

D. 有两个元素，从栈底到栈顶依次为 '('、'['


## 第 3 题

**题干**：关于无向图的连通性相关概念，下列说法正确的是（　　）。

A. 连通图是指边数最少的图，连通分量是指图中的一个顶点，生成树是指图中任意一棵树

B. 连通分量是无向图的极大连通子图，一个图可以有多个连通分量；连通图的连通分量就是它自身

C. 生成树是连通图的极大连通子图，它必须包含图中所有边，但可以不包含所有顶点

D. 任何无向图都是连通图，因此每个无向图有且仅有一个连通分量


## 第 4 题

**题干**：关于 Floyd 算法和 Dijkstra 算法的适用范围，下列说法正确的是（　　）。

A. Floyd 算法用于求解单源最短路径，要求图中不能存在负权边；Dijkstra 算法用于求解所有顶点对之间的最短路径，允许存在负权边

B. Floyd 算法用于求解所有顶点对之间的最短路径，允许图中存在负权边但不能有负权回路；Dijkstra 算法用于求解单源最短路径，要求图中不能存在负权边

C. Floyd 算法和 Dijkstra 算法都可以求解所有顶点对之间的最短路径，且都允许图中存在负权边

D. Floyd 算法用于求解单源最短路径，允许存在负权回路；Dijkstra 算法用于求解所有顶点对之间的最短路径，不允许存在负权边


## 第 5 题

**题干**：关于 B 树和 B+ 树的结构差异，下列说法正确的是（　　）。

A. B 树中所有结点（含内部结点和叶子结点）都存储关键字和数据记录；B+ 树中只有叶子结点存储全部数据记录，内部结点仅存储关键字用于索引

B. B 树和 B+ 树的所有结点都同时存储关键字和数据记录，结构完全相同

C. B+ 树中所有结点都存储关键字和数据记录，内部结点也要存储实际数据；B 树中只有叶子结点存储数据

D. B 树中只有叶子结点存储数据记录，内部结点仅用于索引；B+ 树的叶子结点之间互不关联


## 第 6 题

**题干**：对一组关键字进行排序，若排序过程中某一趟完成后所有关键字就已经有序，即排序提前结束，则该排序算法在"排序趟数与初始序列是否有序有关"这一特征上，下列说法正确的是（　　）。

A. 所有排序算法的排序趟数都与初始序列的有序程度无关，排序趟数是固定值

B. 冒泡排序和快速排序的排序趟数（或递归深度）与初始序列的有序程度有关；简单选择排序的排序趟数始终为 n−1，与初始序列无关

C. 简单选择排序的排序趟数取决于初始序列的有序程度，当初始序列有序时只需一趟

D. 堆排序和归并排序的排序趟数都取决于初始序列是否有序，初始序列有序时只需要一趟即可完成


## 求解过程
# 概念题解析

## 第 1 题解析

**答案**：B

**解析**：
- B 正确：顺序表采用顺序存储结构（物理连续），通过首地址和元素大小可直接定位第 i 个元素，支持随机存取，时间复杂度 O(1)；链表采用链式存储结构（物理离散），只能从头指针沿链逐个访问，属于顺序存取，时间复杂度 O(n)。
- A 错误：将顺序表说成"只能顺序存取"是混淆了"顺序存储"与"顺序存取"——顺序存储结构恰恰支持随机存取；将链表说成"随机存储结构"是混淆了"随机存取"与"随机存储"，链表不支持 O(1) 随机存取。
- C 错误：链表不是顺序存储结构（物理不连续），也不支持随机存取。
- D 错误：链表不是随机存储结构，访问第 i 个元素需 O(n)，不支持 O(1) 随机存取。

## 第 2 题解析

**答案**：D

**解析**：
- D 正确：括号匹配算法中，遇左括号入栈，遇右括号与栈顶比较。扫描 "( [ ] )"：读 '(' → 入栈，栈为 '('；读 '[' → 入栈，栈从底到顶为 '( ['；读 ']' → 与栈顶 '[' 匹配，此时**尚未出栈**，栈仍为 '( ['。因此读到 ']' 时的栈状态为栈底到栈顶 '('、'['。
- A 错误：栈不空，已入栈两个左括号。
- B 错误：栈顶应为 '['，不可能只有 '('（'[' 在 '(' 之上）。
- C 错误：栈中不止一个元素，'(' 在栈底。

## 第 3 题解析

**答案**：B

**解析**：
- B 正确：连通分量定义为无向图的极大连通子图。非连通图有多个连通分量；连通图本身是一个连通分量（即它自身）。
- A 错误："连通图"是任意两顶点间有路径，不是"边数最少"；"连通分量"是子图不是顶点；"生成树"是包含所有顶点的极小连通子图，不是任意一棵树。
- C 错误：生成树是极小连通子图（边数最少，n−1 条边），不是极大（不包含所有边），且必须包含所有顶点。
- D 错误：并非所有无向图都连通，非连通图有多个连通分量。

## 第 4 题解析

**答案**：B

**解析**：
- B 正确：Floyd 算法基于动态规划求解所有顶点对之间的最短路径，允许图中存在负权边（但不能存在负权回路，否则最短路径无意义）；Dijkstra 算法基于贪心策略求解单源最短路径，不允许存在负权边（负权边会破坏贪心选择的最优性）。
- A 错误：两者适用范围说反了——Floyd 求多源、Dijkstra 求单源。
- C 错误：Dijkstra 算法是单源最短路径算法，不能求所有顶点对之间的最短路径（除非对每个顶点跑一次），且不允许负权边。
- D 错误：适用范围和负权条件都说反了。

## 第 5 题解析

**答案**：A

**解析**：
- A 正确：B 树中所有结点（内部结点和叶子结点）都存储关键字及其对应的数据记录；B+ 树中内部结点仅存储关键字（用作索引/路由），全部数据记录存储在叶子结点中，且叶子结点通过链表连接以支持范围查询。
- B 错误：B 树和 B+ 树结构不同——B+ 树内部结点不存数据，这是两者的核心差异。
- C 错误：说反了——是 B 树所有结点存数据，B+ 树内部结点不存数据。
- D 错误：B 树所有结点都存数据（不只是叶子结点）；B+ 树的叶子结点之间通过链表关联，不是"互不关联"。

## 第 6 题解析

**答案**：B

**解析**：
- B 正确：冒泡排序的趟数与初始序列有关——若某一趟没有发生交换则提前结束，初始有序时只需一趟；快速排序的递归深度和划分次数也取决于初始序列的分布；而简单选择排序无论初始序列如何，每趟选出一个最小（大）元素，始终需要 n−1 趟，与初始序列无关。
- A 错误：并非所有排序算法的趟数都与初始序列无关，冒泡排序就是反例。
- C 错误：简单选择排序的趟数恒为 n−1，与初始序列有序程度无关。
- D 错误：归并排序的趟数由序列长度决定（⌈log₂n⌉ 趟），与初始序列是否有序无关；堆排序的趟数也主要取决于元素个数。
