## 考点
- **核心知识点**：KMP算法中next数组的构造规则
  - 考察侧重点：给定模式串，按 next 数组定义求指定位置的 next 值
- **辅助知识点**：最长真前后缀匹配的概念
  - 考察侧重点：理解 next[j] = 最长的相等真前缀与真后缀长度，next[0] 固定为 -1（或 0，取决于教材约定），next[1] 固定为 0

## 难度目标
| 维度 | 目标 | 达标理由 |
|------|------|----------|
| K1 基础认知 | 2 | 需记忆 next 数组定义，但概念是 408 基础内容，模糊记忆也能沿题干代入 |
| K2 单步代入 | 3 | 需对指定位置做前后缀匹配计算，涉及非平凡字符比较，非简单 2 的幂 |
| K3 机制推演 | 2 | 计算指定位置的 next 值仅需 2 步以内推导（找最长匹配前缀→取长度），路径唯一 |
| K4 条件路由 | 2 | 存在常规注意点（next 数组下标从 0 开始、next[0]=-1 的约定），408 考生基本不会踩坑 |
| K5 跨域联动 | 1 | 纯串匹配内部知识，不涉及其他子系统 |
| **整体难度** | **3** | 核心是一步标准的前后缀匹配计算，需准确理解 next 定义 |

## 考察模式
**计算型——next 数组求解**（与 slot 指定一致，历史经验支撑）

历史模式参考：
- 2015_Q8：给定模式串，求 next 数组某一位值，选项为不同数值
- 2024_Q6：类似考法，模式串稍长，求指定位置 next 值

该模式在历年选择题中反复出现，属于高频标准考法，难度可控、区分度好。

## 出题要求
- **题型**：单项选择题，4 选项 1 正确 3 干扰
- **分值**：2 分
- **条件数**：1 个显式条件（模式串），1 个指定位置（如 next[?] 中的 ? 值）
- **条件设计原则**：
  - 模式串长度 6-9 个字符为宜（太短区分度不足，太长超纲浪费时间）
  - 字符集建议用 a/b/c 等小写字母，避免数字与下标混淆
  - 指定位置应选在有区分度的位（非 next[0] 或 next[1]），建议指定位置在模式串中后部
  - 模式串应包含至少一处"部分匹配"结构（存在长度 ≥2 的相等真前后缀），使正确答案非平凡
- **参数取值范围要求**：
  - 模式串长度：6-9
  - next 数组下标约定：采用 408 标准 next[0]=-1, next[1]=0 约定（需在题干或上下文明确）
  - 问询位置：建议选下标 4-7 范围内的某个位置

## 子问题规划
本题为单项选择题，无子问题。4 个选项设计如下：
- **正确选项**：按 next 数组标准定义计算所得的正确值
- **干扰项 1**：忽略"真"前缀限制（取了整个前缀长度而非真前缀），即取 j 而非匹配长度
- **干扰项 2**：取了次长匹配长度（差 1），反映计算中多匹配/少匹配一个字符的典型错误
- **干扰项 3**：取 0 或该位置前一个位置的 next 值，反映对 next 数组定义的根本性误解

## 参数约束
| 参数 | 取值范围 | 一致性约束 | 自由度 |
|------|----------|------------|--------|
| 模式串长度 n | 6-9 | n ≥ 6（保证指定位置 ≥4 有足够区分度） | Question Agent 自选 |
| 字符集 | 小写字母 a-c | 避免数字字符，避免特殊字符 | Question Agent 自选 |
| 问询位置 j | j ∈ [4, n-1] | j 不能为 0 或 1（平凡值） | Question Agent 自选 |
| next 数组约定 | next[0]=-1, next[1]=0 | 408 标准教材约定，需明确 | 固定 |
| 正确答案值 | ≥ 2 | 保证模式串在位置 j 处存在长度 ≥2 的前后缀匹配 | 由参数决定 |
| 干扰项分布 | 4 个选项值互不相同 | 各干扰项对应不同错误路径，结果不重合 | Question Agent 验证 |

## 参考经验
- **历史模式**：2015 年与 2024 年均出现 next 数组求值选择题，模式一致——给模式串 + 指定位置，选 next 值
- **难度锚点**：此类题目 K2（单步计算）为核心区分维度，历史 K2 多为 3，与 slot 一致
- **典型陷阱**：
  1. next 数组下标从 0 还是从 1 开始（需明确约定）
  2. next[0] 取 -1 还是 0 的约定差异
  3. "最长真前后缀"中"真"字的限制容易被忽略
  4. 差一位的匹配长度是最常见错误
- **选项设计经验**：正确答案应为非平凡值（≥2），干扰项围绕差 1 偏差和定义误解设计
