## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 串 > 串的模式匹配
- primary_target_name: KMP算法中next数组的某一位值计算
- question_type: single_choice
- examination_mode: 计算型——next数组求解

### 难度目标
- k_target: K1=2,K2=3,K3=2,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 核心区分点在 K2——需对指定位置执行标准的前后缀匹配计算，涉及非平凡字符比较；K3 仅需 2 步推导路径唯一；K4 存在 next 数组下标约定的常规注意点；整体为标准难度选择题

### 结构要求
- option_count: 4（1 正确 3 干扰）
- distractor_strategy: |
    干扰项 1：忽略"真前缀"限制，取 j 而非匹配长度；
    干扰项 2：取次长匹配长度（与正确值差 1），反映多/少匹配一个字符的典型错误；
    干扰项 3：取 0 或相邻位置的 next 值，反映对定义的根本误解。
    要求 4 个选项值互不相同，各对应不同错误路径。
- condition_count: 2（1 个模式串 + 1 个指定位置）

### 参数约束
- 模式串长度 n: 6-9，n ≥ 6
- 字符集: 小写字母 a-c，避免数字字符
- 问询位置 j: j ∈ [4, n-1]，不能为 0 或 1
- next数组约定: next[0]=-1, next[1]=0（408标准约定，需在题干上下文明确）
- 正确答案值: ≥ 2（保证模式串在位置 j 处存在长度 ≥2 的相等真前后缀匹配）
- 选项一致性: 4 个选项值互不相同

### 参考经验摘要
- 历史模式: 2015_Q8 与 2024_Q6 均为"给定模式串，求 next 数组指定位置值"的选择题，模式稳定
- 难度锚点: K2=3 为核心区分维度，与 slot 目标一致
- 典型陷阱: next 数组下标起点约定（0 vs 1）；"真"前后缀限制被忽略；差一位的匹配长度是最常见错误
