# solution.md

## 题目

已知模式串 P = "abaabac"（长度为 7，下标从 0 开始）。采用 408 标准约定：next[0] = -1，next[1] = 0，且对于 j ≥ 2，next[j] 为模式串前缀 P[0..j−1] 的最长相等真前后缀长度。求 next[6] 的值。

## 参数

- 模式串 P = "abaabac"，长度 n = 7
- 目标位置 j = 6
- 前缀子串 P[0..5] = "abaaba"

## 求解过程

### 第一步：明确 next[6] 的定义

按 408 标准约定，next[6] = P[0..5] 的最长相等真前后缀长度。

即：在子串 "abaaba" 中，寻找最大的 k（1 ≤ k ≤ 5），使得前缀 P[0..k−1] 与后缀 P[6−k..5] 相等。

### 第二步：逐个长度从大到小尝试

| k | 前缀（前 k 个字符） | 后缀（后 k 个字符） | 是否相等 |
|---|---|---|---|
| 5 | "abaab" | "baaba" | 不等 |
| 4 | "abaa" | "aaba" | 不等 |
| 3 | "aba" | "aba" | **相等（命中，最长）** |
| 2 | "ab" | "ba" | 不等 |
| 1 | "a" | "a" | 相等（但非最长） |

从 k=5 向下检查，第一个命中的最大 k 为 **3**：前缀 "aba" = 后缀 "aba"。

### 第三步：得出结论

最长相等真前后缀为 "aba"，长度为 3，故 **next[6] = 3**。

### 完整 next 数组（验证）

| j | 子串 P[0..j-1] | 最长相等真前后缀 | next[j] |
|---|---|---|---|
| 0 | —（约定） | — | -1 |
| 1 | "a" | 无（约定） | 0 |
| 2 | "ab" | 无 | 0 |
| 3 | "aba" | "a"，长度1 | 1 |
| 4 | "abaa" | "a"，长度1 | 1 |
| 5 | "abaab" | "ab"，长度2 | 2 |
| 6 | "abaaba" | "aba"，长度3 | **3** |

## 答案

**A. 3**

## 选项解析

| 选项 | 值 | 判定 | 说明 |
|------|-----|------|------|
| A | 3 | ✅ 正确 | "abaaba" 的最长相等真前后缀为 "aba"，长度 3 |
| B | 6 | ❌ 错误 | 忽略"真"前缀限制，误认为 next[j] = j（取位置下标 6 而非匹配长度） |
| C | 2 | ❌ 错误 | 差一位误算，比正确值少 1（误以为第三字符不匹配，只对齐前两位得到长度 2） |
| D | 0 | ❌ 错误 | 根本误解定义，认为不存在任何匹配或直接取 0 |
