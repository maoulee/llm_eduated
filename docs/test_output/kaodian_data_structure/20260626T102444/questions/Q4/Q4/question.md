# question.md

## 题目

已知模式串 P = "abaabac"（长度为 7，下标从 0 开始）。采用 408 标准约定：next 数组满足 next[0] = -1，next[1] = 0，且对于 j ≥ 2，next[j] 为模式串前缀 P[0..j−1] 的最长相等真前后缀长度。

求 next[6] 的值是（ ）。

A. 3
B. 6
C. 2
D. 0

---

## 考察意图

- **核心考点**：KMP 算法中 next 数组的定义与手算。
- **K2（匹配计算）**：要求考生对指定位置 j=6，在模式串 P[0..5] = "abaaba" 上执行前后缀匹配，找到最长相等真前后缀。
- **K4（约定辨析）**：next 数组下标从 0 开始，next[0]=-1/next[1]=0 的约定需在题干中明确，考生不能混淆 0 基与 1 基。

## 选项设计说明

| 选项 | 值 | 对应路径 |
|------|-----|---------|
| A | 3 | **正确结果**。"abaaba" 的最长相等真前后缀为 "aba"，长度 3 |
| B | 6 | **忽略"真"前缀限制**——取 j 本身而非匹配长度（将前缀长度误认为等于位置下标） |
| C | 2 | **差一位误算**——多/少匹配一个字符，取与正确值差 1 的值 |
| D | 0 | **根本误解定义**——认为不存在任何匹配或直接取相邻位置的 next 值 |

## 通过条件（成功判据·可机检）

1. **正确值唯一确定**：在给定模式串 P="abaabac" 与约定下，next[6] 有唯一确定的数值；A 选项 = 该值，不存在两个选项同时正确。
2. **4 选项互异**：A/B/C/D 四个数值各不相同（3, 6, 2, 0 无碰撞）。
3. **干扰项对应声明错误类型**：
   - B=6 对应"忽略真前缀限制取 j"路径（误认为 next[j]=j）；
   - C=2 对应"差一位匹配长度"路径（比正确值少 1）；
   - D=0 对应"根本误解/取相邻值"路径。
4. **干扰项合理性**：每个干扰项均为 KMP next 数组计算中的常见真实误算产物，具有区分度。
5. **正确值 ≥ 2**：保证模式串在位置 j=6 处存在长度 ≥ 2 的相等真前后缀匹配，使题目有非平凡的考察意义。
