## 考点
- **核心知识点**：二叉树叶子结点数 n0 与度为 2 的结点数 n2 的关系（n0 = n2 + 1）
- **辅助知识点**：二叉树总结点数 n = n0 + n1 + n2；度为 1 的结点数 n1 在完全二叉树中的取值特征（0 或 1）
- **考察侧重点**：由已知的部分结点数信息（如 n2、n1、总结点数等），代入二叉树性质公式，推算叶子结点数 n0

## 难度目标
- **K1=2**：需回忆 n0 = n2 + 1 这一核心公式，但该公式是 408 高频基础公式，概念负担较低。
- **K2=3**：需代入常规公式计算，涉及非 2 的幂次的整数运算，存在算错可能。
- **K3=2**：推导路径 2 步以内——套公式即可，无需多步串行推演。
- **K4=2**：存在常规注意点（如 n1 的取值、公式的正确选取），但无深层陷阱。
- **K5=1**：单一知识点内部解决，不涉及其他子系统。

## 考察模式
**计算型——二叉树性质应用**：题面给出二叉树的某种结点计数信息（如度为 2 的结点数、总结点数、度为 1 的结点数等），要求考生利用 n0 = n2 + 1 及 n = n0 + n1 + n2 公式联立求解叶子结点数。这是该知识点的经典考法，历史频率高，适合 2 分选择题。

选择该模式的理由：
1. 直接考察公式的记忆与应用，与 K2=3 的单步代入需求匹配。
2. 2 分选择题适合"给条件→代公式→得结果"的短链计算。
3. 干扰项易于设计——错误路径明确（公式用反、忽略 n1、加减搞错）。

## 出题要求
- **题型**：单项选择题，4 选项（1 正确 3 干扰），2 分。
- **条件数**：1-2 个显式条件，给出二叉树中某种结点计数（如 n2 的值、或总结点数与 n1 的值）。
- **条件设计原则**：
  - 给出的信息恰好能通过公式联立唯一确定 n0，不多不少。
  - 数字应使正确答案为非平凡整数，避免答案为 0 或 1 这种退化情况。
  - 干扰项对应常见错误路径，每个干扰项数值互不相同。

## 子问题规划
本题是选择题，无子问题。4 个选项设计如下：
- **选项 A（正确）**：正确套用 n0 = n2 + 1 得到的结果。
- **选项 B（干扰1）**：误用 n0 = n2 − 1（公式记反，得到比正确值小 2 的结果）。
- **选项 C（干扰2）**：忽略了 n1 的贡献，直接用 n = n0 + n2 求解（得到不同错误值）。
- **选项 D（干扰3）**：混淆叶子与度为 2 结点，直接把 n2 当作 n0（或者用 n0 = n2）。

## 参数约束
- **n2（度为 2 的结点数）**：取值范围 3-15，使 n0 = n2 + 1 落在 4-16，答案为非平凡值。
- **n1（度为 1 的结点数）**：取值范围 0 或 1（对于普通二叉树可更大，但若限定完全二叉树则为 0 或 1；普通二叉树可放宽至 0-5）。若题面只给 n2，则 n1 不需要出现；若题面给总结点数，则 n1 需参与联立。
- **n（总结点数，可选）**：若题面以"某二叉树共有 n 个结点，其中有 k 个度为 2 的结点"形式给出，则需满足 n = n0 + n1 + n2 = (n2+1) + n1 + n2，即 n1 = n − 2·n2 − 1，且 n1 ≥ 0。
- **一致性约束**：所有参数必须满足 n0 = n2 + 1 以及 n = n0 + n1 + n2。
- **可调自由度**：Question Agent 可自由选择"只给 n2"还是"给 n 和 n2 联立"两种出题路径；数字在上述范围内自由选取，但必须保证各干扰项结果互不相同且有区分度。

## 参考经验
- **历史模式**：该考点在 408 中反复出现，标准考法为"给出二叉树部分结点数信息，求叶子结点数"。
- **难度锚点**：K2=3 对应非 2 的幂次的整数计算，历史该类题目难度集中在中等偏下。
- **典型陷阱**：
  1. 公式记反（n0 = n2 − 1）
  2. 忽略 n1 的存在，误以为 n = n0 + n2
  3. 混淆叶子结点与度为 2 结点的定义
