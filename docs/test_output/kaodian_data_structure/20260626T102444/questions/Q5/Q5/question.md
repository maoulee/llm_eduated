# 题目

**题型**：单项选择题

**科目**：数据结构 — 二叉树性质

## 题干

一棵非空的二叉树共有 18 个结点，其中度为 2 的结点有 7 个。该二叉树中度为 0 的结点（叶子结点）的个数为（　　）。

## 选项

- A. 8
- B. 6
- C. 11
- D. 7

---

## 通过条件（成功判据）

1. **正确值唯一确定**：在给定参数（n = 18，n₂ = 7）下，由 n₀ = n₂ + 1 得 n₀ = 8 且唯一；A = 8。
2. **四选项互异**：A/B/C/D 四个值各不相同，无碰撞。
   - A = n₂ + 1 = 8（正确）
   - B = n₂ − 1 = 6（公式记反）
   - C = n − n₂ = 11（忽略 n₁，直接相减）
   - D = n₂ = 7（叶子与度为 2 混淆）
3. **干扰项对应声明错误类型**：B/C/D 分别精确对应上述三种常见错误路径，非随机扰动。
4. **干扰项有合理性**：三种错误均为同类题中真实高频误算产物，数值落在合理范围内且彼此可区分。
5. **一致性校验**：参数满足 n = n₀ + n₁ + n₂，即 18 = 8 + n₁ + 7，得 n₁ = 3 ≥ 0，一致。
