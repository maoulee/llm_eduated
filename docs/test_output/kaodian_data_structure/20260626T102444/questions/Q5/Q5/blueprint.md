## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树性质
- primary_target_name: 二叉树叶子结点数与度为2结点数的关系应用
- question_type: single_choice
- examination_mode: 计算型——二叉树性质应用

### 难度目标
- k_target: K1=2,K2=3,K3=2,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 需回忆 n0 = n2 + 1 公式并代入非2幂次整数计算，属标准中等难度；推导链短（2步以内），无深层陷阱，不跨子系统。

### 结构要求
- option_count: 4
- distractor_strategy: 三个干扰项分别对应公式记反(n0=n2−1)、忽略n1联立错误、叶子与度为2结点混淆三种常见错误路径，各干扰项数值必须互不相同
- condition_count: 1-2

### 参数约束
- n2: 取值范围 3-15，整数；n0 = n2 + 1 必须落在 4-16，保证非平凡
- n1: 若参与联立则取值范围 0-5，整数且 ≥0；若题面不涉及 n1 则无需声明
- n（总结点数，可选）: 若给出则必须满足 n = n0 + n1 + n2 = 2·n2 + n1 + 1
- 一致性硬约束: 所有参数必须同时满足 n0 = n2 + 1 和 n = n0 + n1 + n2
- 干扰项区分度: 公式记反路径结果 = n2 − 1；忽略n1路径结果需与正确值和记反值均不同；混淆路径结果 = n2，四个选项数值必须互异

### 参考经验摘要
- 历史模式: "给出二叉树部分结点信息→求叶子数"是标准高频考法，考察公式 n0=n2+1 的记忆与应用
- 难度锚点: K2=3 对应非2幂次整数代入，历史难度集中在中等偏下
- 典型陷阱: 公式记反、忽略n1、叶子与度为2结点定义混淆
