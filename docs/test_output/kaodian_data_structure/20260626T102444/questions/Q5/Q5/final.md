## 题目
一棵非空的二叉树共有 18 个结点，其中度为 2 的结点有 7 个。该二叉树中度为 0 的结点（叶子结点）的个数为（　　）。


## 选项
- A. 8
- B. 6
- C. 11
- D. 7

---


## 求解过程
# 求解过程

## 题目参数

- 总结点数 n = 18
- 度为 2 的结点数 n₂ = 7
- 求度为 0 的叶子结点数 n₀

## 求解步骤

### 第一步：应用二叉树性质公式

二叉树的基本性质：**n₀ = n₂ + 1**

代入 n₂ = 7：

$$n_0 = 7 + 1 = 8$$

### 第二步：一致性验证

由 n = n₀ + n₁ + n₂，反求 n₁：

$$18 = 8 + n_1 + 7 \Rightarrow n_1 = 3$$

n₁ = 3 ≥ 0，参数一致，题目成立。

### 第三步：确定正确选项

- **A = 8**（正确结果，n₀ = n₂ + 1 = 7 + 1 = 8）

## 答案

**A. 8**

## 干扰项分析

| 选项 | 数值 | 错误类型 | 分析 |
|------|------|----------|------|
| A | 8 | — | 正确：n₀ = n₂ + 1 = 7 + 1 = 8 |
| B | 6 | 公式记反 | 误用 n₀ = n₂ − 1 = 7 − 1 = 6，公式方向搞反 |
| C | 11 | 忽略 n₁ | 直接用 n − n₂ = 18 − 7 = 11，忽略了度为 1 的结点 n₁ = 3 的存在 |
| D | 7 | 概念混淆 | 将叶子结点（n₀）与度为 2 的结点（n₂）混淆，直接取 n₀ = n₂ = 7 |

四个选项 8、6、11、7 互不相同，每个干扰项精确对应一种常见错误路径。
