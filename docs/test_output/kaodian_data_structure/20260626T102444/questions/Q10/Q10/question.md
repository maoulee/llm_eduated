# 快速排序前两趟划分结果（选择题）

## 题干

给定待排序关键字序列（共 8 个元素，下标从 1 开始）：

$$49,\; 12,\; 68,\; 35,\; 89,\; 23,\; 56,\; 71$$

采用**快速排序**，枢轴（pivot）取当前子表的**首元素**。每趟划分（partition）时，扫描方式为：从枢轴另一端（右端）起，向左扫描找到第一个小于枢轴的关键字，将其移到左端空位；再从左端向右扫描找到第一个大于枢轴的关键字，将其移到右端空位；重复上述交替扫描直至左右指针相遇，将枢轴放入相遇位置，完成一趟划分。

对**左、右两个子表分别进行第二趟划分**（即第二趟对第一趟产生的左子表和右子表各做一次 partition，子表长度为 1 时无需划分）。

**问：前两趟划分全部完成后，整个序列的状态是以下哪一项？**

---

## 选项

A. 12, 23, 35, 49, 71, 68, 56, 89

B. 23, 12, 35, 49, 89, 68, 56, 71

C. 49, 12, 23, 49, 49, 89, 56, 89

D. 12, 23, 35, 49, 71, 68, 89, 56

---

## 通过条件（成功判据）

本题成立当且仅当 gen.py 执行后满足以下全部可机检特征：

1. **正确值唯一确定**：给定序列和枢轴规则下，两趟划分后的结果序列唯一，A 选项等于该唯一序列。
2. **4 选项互异**：A、B、C、D 四个序列形态两两不同（至少有一个位置上关键字不同）。
3. **干扰项与声明错误类型一一对应**：
   - B = 仅执行第一趟 partition（不执行第二趟）的序列状态；
   - C = 从枢轴同侧（左端）起扫描的错误方式执行两趟后的序列状态；
   - D = 第二趟中某子表枢轴落位偏移 1 位、其余步骤正确时得到的序列状态。
4. **非退化性**：第一趟划分后，枢轴左子表与右子表均非空（枢轴最终位置不在序列首或序列尾），且至少有一个子表长度 ≥ 2 需要第二趟划分。
5. **区分度**：A 的序列与 B、C、D 三个序列在至少 2 个位置上关键字不同，干扰项之间亦至少 2 个位置不同。
