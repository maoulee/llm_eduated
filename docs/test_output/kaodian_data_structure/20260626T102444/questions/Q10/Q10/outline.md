## 考点
- **核心知识点**：快速排序的 partition 过程模拟
  - 考察侧重点：以首元素（或末元素）为枢轴，模拟一趟划分（partition）后枢轴的落位及左右子表的分割结果
  - 延伸侧重点：连续两趟划分后，各枢轴的最终落位与整体序列形态
- **辅助知识点**：快速排序的递归分治框架
  - 考察侧重点：第一趟划分后产生两个子表，第二趟分别对子表再划分，理解哪些元素位置已确定、哪些仍可能变化

## 难度目标
- **K1=2（较低）**：学生需知道快速排序的基本定义（选枢轴、左右扫描交换），但概念辨识要求不高，题干流程清晰即可入题
- **K2=3（标准）**：每趟 partition 中涉及多次比较与交换操作，数字非简单 2 的幂，存在算错可能
- **K3=2（较低）**：模拟路径明确（枢轴确定→左右扫描→交换→落位），步数适中（序列约 8-10 个元素，两趟划分），路径唯一
- **K4=2（较低）**：主要注意点为"枢轴选择方式"（首元素 vs 末元素）和"扫描从哪端开始"，属常规注意项
- **K5=1（微弱）**：纯排序知识点内部解决，不涉及跨系统联动

> K2 为主导维度，难度核心在于多步比较与交换的准确性，而非概念深度或推演复杂度。

## 考察模式
- **模式名称**：计算型——快速排序过程模拟（源自 slot examination_mode）
- **模式说明**：给定一个关键字序列，要求考生手动模拟快速排序前两趟 partition 过程，从四个选项中选出正确的两趟划分后序列形态
- **选择理由**：快速排序过程模拟是 408 排序章的经典考法，能同时考察学生对 partition 机制的理解和手算准确性，与 K2 主导的难度定位高度匹配

## 出题要求
- **题型**：单项选择题，4 选项 1 正确 3 干扰
- **总条件数**：2 个显式条件
  - 条件 1：给定的关键字序列（8-10 个互异整数）
  - 条件 2：枢轴选取方式（明确为"以第一个元素为枢轴"或"以最后一个元素为枢轴"）
- **条件设计原则**：
  - 序列长度 8-10，保证两趟划分后有足够多元素位置确定，又有足够干扰空间
  - 所有关键字互异，避免重复元素导致的歧义
  - 枢轴选取方式必须显式声明，不让学生猜测
  - partition 方式默认采用 408 教材标准（王道/天勤版本：从枢轴另一端开始扫描的 Hoare 变体或 Lomuto 变体），题干不展开算法描述，但选项设计须与标准教材一致
- **选项要求**：四个选项各为一种两趟划分后的序列形态，正确项唯一

## 子问题规划
- 本题为单项选择题，无子问题拆分
- 选项结构：
  - **正确选项**：严格按照指定枢轴方式和标准 partition 算法模拟两趟后的真实序列
  - **干扰项设计方向**（由 Question Agent 具体构造）：
    - 干扰 1：只做一趟 partition 的结果（漏做第二趟）
    - 干扰 2：扫描方向或枢轴选取方式错误（如用末元素为枢轴的结果混淆）
    - 干扰 3：某趟 partition 中交换或落位步骤出错（如枢轴落位偏移一位）

## 参数约束
- **序列长度**：8 ≤ n ≤ 10，建议 n=8 或 9（偶数/奇数均可，保证两趟划分后有区分度）
- **关键字取值**：互异的正整数，建议范围在 [1, 99] 内，数值大小无规律（非有序、非逆序，避免平凡情况）
- **序列特征约束**：
  - 序列既非有序也非逆序，保证 partition 有实质划分效果
  - 第一趟划分后左右子表均非空（即枢轴不在已有序列的两端），保证第二趟有两次子划分
  - 两趟划分后的序列形态须与所有干扰项明显不同（区分度检查）
- **枢轴选取方式**：首元素或末元素二选一，显式声明
- **可调自由度**：Question Agent 可自由选择具体序列数值、序列长度（在范围内）、枢轴方式，以及三个干扰项的具体错误类型

## 参考经验
- **考察模式**：快速排序 partition 模拟是高频考点，常见于选择题形式，要求写出某趟或某几趟后的序列形态
- **难度锚点**：K2=3 对应"多步比较交换但数字非极端复杂"，K3=2 对应"路径明确步数适中"，整体难度 4/5 偏中上
- **典型陷阱**：
  - 枢轴选取方式不明确导致歧义（必须显式声明）
  - 扫描起始端与枢轴端的关系（从枢轴对端开始扫描）
  - 只做一趟 vs 做两趟的混淆
  - 枢轴最终落位是否正确（交换落位 vs 直接覆盖）
