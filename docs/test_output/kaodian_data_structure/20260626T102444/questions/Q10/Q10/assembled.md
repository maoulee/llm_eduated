## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 排序 > 交换排序
- primary_target_name: 给定序列用快速排序求前两趟划分结果
- question_type: single_choice
- examination_mode: 计算型——快速排序过程模拟

### 难度目标
- k_target: K1=2,K2=3,K3=2,K4=2,K5=1
- difficulty_level: 4
- difficulty_rationale: 核心难点在于手动模拟两趟 partition 的多步比较与交换操作（K2=3 主导），序列约 8-10 元素保证步数适中（K3=2），枢轴方式和扫描方向为常规注意点（K4=2），不涉及跨知识点联动（K5=1）

### 结构要求
- option_count: 4
- distractor_strategy: |
    干扰项 1：只做一趟 partition 的结果（漏做第二趟）
    干扰项 2：枢轴选取方式或扫描方向错误导致的错误序列
    干扰项 3：某趟 partition 中枢轴落位或交换步骤出错（如偏移一位）
    约束：四个选项的序列形态必须两两不同，正确项唯一
- condition_count: 2

### 参数约束
- 序列长度: 8 ≤ n ≤ 10，建议 n=8 或 9
- 关键字取值: 互异正整数，范围 [1, 99]，数值无规律
- 序列特征_非平凡: 序列既非有序也非逆序
- 序列特征_非退化: 第一趟划分后左右子表均非空（枢轴不在两端最终位置）
- 序列特征_区分度: 两趟划分后正确序列与所有干扰序列明显不同
- 枢轴选取方式: 首元素或末元素，题干显式声明，二选一
- 可调自由度: 具体序列数值、序列长度（范围内）、枢轴方式、干扰项具体错误类型均由 Question Agent 决定

### 参考经验摘要
- 历史模式: 快速排序 partition 模拟为高频选择题考法，要求写出某趟后的序列形态
- 难度锚点: K2=3 主导（多步比较交换），K3=2（路径明确步数适中），整体难度 4/5
- 典型陷阱: 枢轴选取方式歧义、扫描起始端方向、只做一趟vs做两趟、枢轴落位是否正确
