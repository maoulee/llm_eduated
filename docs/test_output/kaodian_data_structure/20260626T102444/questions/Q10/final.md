## 题目

给定待排序关键字序列（共 8 个元素，下标从 1 开始）：

$$49,\; 12,\; 68,\; 35,\; 89,\; 23,\; 56,\; 71$$

采用**快速排序**，枢轴（pivot）取当前子表的**首元素**。每趟划分（partition）时，扫描方式为：从枢轴另一端（右端）起，向左扫描找到第一个小于枢轴的关键字，将其移到左端空位；再从左端向右扫描找到第一个大于枢轴的关键字，将其移到右端空位；重复上述交替扫描直至左右指针相遇，将枢轴放入相遇位置，完成一趟划分。

对**左、右两个子表分别进行第二趟划分**（即第二趟对第一趟产生的左子表和右子表各做一次 partition，子表长度为 1 时无需划分）。

**问：前两趟划分全部完成后，整个序列的状态是以下哪一项？**

A. 12, 23, 35, 49, 71, 68, 56, 89

B. 23, 12, 35, 49, 89, 68, 56, 71

C. 49, 12, 23, 49, 49, 89, 56, 89

D. 12, 23, 35, 49, 71, 68, 89, 56

## 参考答案

**A. 12, 23, 35, 49, 71, 68, 56, 89**

## 解析

### 参数

- 原始序列：49, 12, 68, 35, 89, 23, 56, 71
- 序列长度：8
- 枢轴选取：当前子表首元素
- 扫描方式：从右端起向左找第一个 < pivot 的 → 放左端空位；从左端向右找第一个 > pivot 的 → 放右端空位；交替直至相遇，pivot 放入相遇位置

---

### 第一趟划分（整个序列）

**枢轴 = 49（首元素）**

序列初始：49, 12, 68, 35, 89, 23, 56, 71

- 右端起向左找第一个 < 49：71→56→23（23 < 49），23 移到左端空位 → [**23**, 12, 68, 35, 89, __, 56, 71]
- 左端向右找第一个 > 49：12→68（68 > 49），68 移到右端空位 → [23, 12, __, 35, 89, **68**, 56, 71]
- 右端起向左找第一个 < 49：56→89→35（35 < 49），35 移到空位 → [23, 12, **35**, __, 89, 68, 56, 71]
- 左端向右扫描未找到 > 49（指针相遇），枢轴 49 放入相遇位置

**第一趟划分后：23, 12, 35, 49, 89, 68, 56, 71**

- 枢轴 49 最终位置（下标 3，即第 4 个位置）
- 左子表（下标 0~2）：23, 12, 35（长度 3）
- 右子表（下标 4~7）：89, 68, 56, 71（长度 4）

> 非退化性验证：枢轴位置在下标 3（非首非尾），左子表长度 3、右子表长度 4，均非空且均 ≥ 2，需要第二趟划分。✓

---

### 第二趟划分

#### 左子表 partition：23, 12, 35（下标 0~2）

**枢轴 = 23（首元素）**

- 右端起向左找第一个 < 23：35→12（12 < 23），12 移到左端空位 → [**12**, __, 35]
- 左端向右找第一个 > 23：无（指针相遇），枢轴 23 放入相遇位置

**左子表划分后：12, 23, 35**

#### 右子表 partition：89, 68, 56, 71（下标 4~7）

**枢轴 = 89（首元素）**

- 右端起向左找第一个 < 89：71（71 < 89），71 移到左端空位 → [**71**, 68, 56, __]
- 左端向右找第一个 > 89：无（指针相遇），枢轴 89 放入相遇位置

**右子表划分后：71, 68, 56, 89**

> 枢轴 89 落在子表最右端，左子表 [71, 68, 56] 长度 3、右子表为空。前两趟结束，不再继续划分。

---

### 前两趟划分完成后的完整序列

$$\boxed{12,\; 23,\; 35,\; 49,\; 71,\; 68,\; 56,\; 89}$$

---

### 干扰项分析

| 选项 | 序列 | 说明 |
|------|------|------|
| **A** | **12, 23, 35, 49, 71, 68, 56, 89** | **正确**：首元素为枢轴，两趟划分均正确执行 |
| B | 23, 12, 35, 49, 89, 68, 56, 71 | 漏做第二趟：仅完成第一趟 partition 的序列状态 |
| C | 49, 12, 23, 49, 49, 89, 56, 89 | 扫描方向错误：从枢轴同侧（左端）起扫描，导致元素覆盖、枢轴落位及分布均错误 |
| D | 12, 23, 35, 49, 71, 68, 89, 56 | 第二趟右子表枢轴（89）落位偏移 1 位，其余步骤正确 |

**区分度验证：**

| 选项对 | 不同位置数 |
|--------|-----------|
| A vs B | 4 |
| A vs C | 5 |
| A vs D | 2 |
| B vs C | 5 |
| B vs D | 5 |
| C vs D | 7 |

四选项两两互异，A 与每个干扰项至少 2 个位置不同，干扰项之间亦至少 2 个位置不同。
