# 题目：二维数组列优先存储的地址计算

## 题干

设有一个 7 行 10 列的二维数组 A，每个元素占 4 字节，数组的首元素 A[0][0] 的存储地址为 200，行下标和列下标均从 0 开始。数组按 **列优先顺序**（column-major order）存储在连续内存中。

求元素 A[3][4] 的存储地址。

## 选项

A. 324

B. 336

C. 292

D. 300

## 已知参数（供 write_gen 使用）

| 参数 | 值 |
|------|-----|
| rows | 7 |
| cols | 10 |
| base (LOC(0,0)) | 200 |
| elem_size | 4（字节） |
| 目标元素 | A[3][4]（行下标 i=3，列下标 j=4，均从 0 开始） |

## 通过条件（成功判据）

1. **正确值唯一确定**：在给定参数下，按列优先公式 LOC(3,4) = 200 + (4×7 + 3)×4 只有一个确定值，选项 A = 该值。
2. **四选项互异**：A（列优先正确）、B（行优先公式）、C（下标-1）、D（行列互换）四个计算结果各不相同，无碰撞。
3. **干扰项对应声明错误类型**：B 恰为行优先公式代入计算结果；C 恰为下标减 1 后代入列优先公式的结果；D 恰为 i、j 互换后代入列优先公式的结果。
4. **干扰项合理性**：每个干扰项均为同类题常见误算的真实产物，数值处于合理范围（非负、与基地址同量级），具有区分度。

## 设计说明

- **考点**：列优先存储地址公式 LOC(i,j) = LOC(0,0) + (j×rows + i)×elem_size 的直接代入计算。
- **考察意图**：学生需正确识别列优先存储顺序（不同于行优先），正确应用列优先地址公式，并注意下标从 0 开始的约定。
- **难度锚点**：K2 主导（7×4 等非 2 幂常规乘法与加法），K4 辅助（列优先识别、下标起始约定）。
- **参数选择理由**：rows=7、cols=10 均非 2 的幂且互不相等，保证行优先与列优先结果必然不同；目标元素 A[3][4] 取中间位置（非首非末），避免退化。
