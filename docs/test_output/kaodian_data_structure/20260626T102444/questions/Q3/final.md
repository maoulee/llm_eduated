## 题目
设有一个 7 行 10 列的二维数组 A，每个元素占 4 字节，数组的首元素 A[0][0] 的存储地址为 200，行下标和列下标均从 0 开始。数组按 **列优先顺序**（column-major order）存储在连续内存中。

求元素 A[3][4] 的存储地址。


## 选项
A. 324

B. 336

C. 292

D. 300


## 求解过程
# 求解过程：二维数组列优先存储的地址计算

## 参数

| 参数 | 值 |
|------|-----|
| rows（行数） | 7 |
| cols（列数） | 10 |
| base（基地址 LOC(0,0)） | 200 |
| elem_size（元素大小） | 4 字节 |
| 目标元素 | A[3][4]（i=3，j=4，均从 0 开始） |

## 解题过程

### 正确计算（选项 A）

列优先存储的地址公式为：

$$LOC(i,j) = LOC(0,0) + (j \times rows + i) \times elem\_size$$

代入参数：

$$LOC(3,4) = 200 + (4 \times 7 + 3) \times 4$$

$$= 200 + (28 + 3) \times 4$$

$$= 200 + 31 \times 4$$

$$= 200 + 124$$

$$= \boxed{324}$$

**答案：A. 324**

---

### 干扰项分析

| 选项 | 值 | 错误类型 | 计算过程 |
|------|-----|---------|---------|
| **A** | **324** | ✅ 正确（列优先公式） | 200 + (4×7 + 3)×4 = 200 + 31×4 = **324** |
| **B** | 336 | ❌ 行优先公式错误 | 200 + (3×10 + 4)×4 = 200 + 34×4 = **336** |
| **C** | 292 | ❌ 下标起始约定错误 | 200 + (3×7 + 2)×4 = 200 + 23×4 = **292** |
| **D** | 300 | ❌ 行列下标互换错误 | 200 + (3×7 + 4)×4 = 200 + 25×4 = **300** |

**各干扰项错误原因：**

- **B（336）**：误用行优先公式 $LOC(i,j) = LOC(0,0) + (i \times cols + j) \times elem\_size$，将行号乘以列数。列优先存储中，地址由"列号乘以行数"决定，因为同一列的元素在内存中连续存放。

- **C（292）**：将下标当作从 1 开始，实际用 j−1=3、i−1=2 代入列优先公式：200 + (3×7 + 2)×4 = 200 + 23×4 = 292。本题下标从 0 开始，无需减 1。

- **D（300）**：将列优先公式中的行列下标互换，即用 base + (i×rows + j)×elem_size，把行号当列号、列号当行号：200 + (3×7 + 4)×4 = 200 + 25×4 = 300。

## 验证

四选项互异：324 ≠ 336 ≠ 292 ≠ 300，无碰撞，区分度良好。


## 设计说明
- **考点**：列优先存储地址公式 LOC(i,j) = LOC(0,0) + (j×rows + i)×elem_size 的直接代入计算。
- **考察意图**：学生需正确识别列优先存储顺序（不同于行优先），正确应用列优先地址公式，并注意下标从 0 开始的约定。
- **难度锚点**：K2 主导（7×4 等非 2 幂常规乘法与加法），K4 辅助（列优先识别、下标起始约定）。
- **参数选择理由**：rows=7、cols=10 均非 2 的幂且互不相等，保证行优先与列优先结果必然不同；目标元素 A[3][4] 取中间位置（非首非末），避免退化。
