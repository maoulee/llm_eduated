## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 排序 > 插入排序与交换排序
- primary_target_name: 给定序列用直接插入和冒泡排序写出每趟结果对比
- question_type: comprehensive
- examination_mode: 推演型——排序过程手工模拟与对比

### 难度目标
- k_target: K1=1,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 4
- difficulty_rationale: 核心难度集中在K3=4的多步推演——需手动模拟两种排序各7趟以上过程并维持动态序列状态更新；辅以K2=2的轻量数值比较和K4=2的常规注意点（插入方向/冒泡方向细节）

### 结构要求
- sub_question_count: 3
- sub_questions:
  - Q1: 直接插入排序每趟结果（4分，推演型）
  - Q2: 冒泡排序每趟结果（4分，推演型）
  - Q3: 两种排序对比分析（2分，分析型）
- distractor_strategy: 无干扰项（综合题为开放推演，非选择题）
- condition_count: 1（一组待排序关键字序列）

### 参数约束
- 序列长度n: 7≤n≤9，建议8
- 关键字值: n个互不相同的正整数，取值范围10~99
- 逆序对数量: 3~6个，保证每趟有明显变化但非完全逆序
- 冒泡排序最少趟数: ≥4趟（序列不接近有序，保证推演步数达标）
- 直接插入排序趟数: n-1（固定）
- 一致性要求: 两种排序最终结果相同（都应为升序排列）

### 参考经验摘要
- 历史模式: 排序综合题标准考法"给定序列→逐趟手写→对比分析"
- 难度锚点: K3=4对应序列长度8产生7趟推演，符合">5步且需动态状态更新"
- 典型陷阱: 插入排序后移操作易遗漏；冒泡排序方向易混淆；趟数≠比较次数的辨析
