# 解题过程：直接插入排序与冒泡排序的逐趟推演与对比

## 题目参数

- 待排序序列 $S = (14,\ 27,\ 78,\ 93,\ 58,\ 45,\ 81,\ 96)$
- 元素个数 $n = 8$
- 升序目标序列 $= (14,\ 27,\ 45,\ 58,\ 78,\ 81,\ 93,\ 96)$
- 初始序列逆序对数 $= 6$

---

## 第 1 问：直接插入排序逐趟结果（4 分）

直接插入排序从第 2 个元素开始，每趟将当前元素与已排序区从后向前比较，遇到比它大的元素则后移，直到找到正确位置后插入。共需 $n-1 = 7$ 趟。

| 趟号 | 插入元素 | 本趟后序列 | 后移次数 |
|:----:|:--------:|:-----------|:--------:|
| 第 1 趟 | 27 | (14, 27, 78, 93, 58, 45, 81, 96) | 0 |
| 第 2 趟 | 78 | (14, 27, 78, 93, 58, 45, 81, 96) | 0 |
| 第 3 趟 | 93 | (14, 27, 78, 93, 58, 45, 81, 96) | 0 |
| 第 4 趟 | 58 | (14, 27, 58, 78, 93, 45, 81, 96) | 2 |
| 第 5 趟 | 45 | (14, 27, 45, 58, 78, 93, 81, 96) | 3 |
| 第 6 趟 | 81 | (14, 27, 45, 58, 78, 81, 93, 96) | 1 |
| 第 7 趟 | 96 | (14, 27, 45, 58, 78, 81, 93, 96) | 0 |

**逐趟说明：**

- **第 1 趟（插入 27）**：27 与已排序区的 14 比较，27 > 14，无需后移，直接插入。序列不变：$(14, 27, 78, 93, 58, 45, 81, 96)$，后移 0 次。
- **第 2 趟（插入 78）**：78 与 27 比较，78 > 27，无需后移。序列不变：$(14, 27, 78, 93, 58, 45, 81, 96)$，后移 0 次。
- **第 3 趟（插入 93）**：93 与 78 比较，93 > 78，无需后移。序列不变：$(14, 27, 78, 93, 58, 45, 81, 96)$，后移 0 次。
- **第 4 趟（插入 58）**：58 依次与 93 比较（93 后移）、与 78 比较（78 后移），遇到 27 时 58 > 27，插入。结果：$(14, 27, 58, 78, 93, 45, 81, 96)$，后移 2 次。
- **第 5 趟（插入 45）**：45 依次与 93 比较（后移）、与 78 比较（后移）、与 58 比较（后移），遇到 27 时 45 > 27，插入。结果：$(14, 27, 45, 58, 78, 93, 81, 96)$，后移 3 次。
- **第 6 趟（插入 81）**：81 与 93 比较（93 后移），遇到 78 时 81 > 78，插入。结果：$(14, 27, 45, 58, 78, 81, 93, 96)$，后移 1 次。
- **第 7 趟（插入 96）**：96 与 93 比较，96 > 93，无需后移。结果：$(14, 27, 45, 58, 78, 81, 93, 96)$，后移 0 次。

**最终结果：** $(14, 27, 45, 58, 78, 81, 93, 96)$

**元素后移总次数 = 0+0+0+2+3+1+0 = 6**

## 第 2 问：冒泡排序逐趟结果（4 分）

每趟从左到右比较相邻元素，前者大于后者则交换。若某趟无交换则排序终止。

| 趟号 | 交换次数 | 本趟后序列 | 备注 |
|:----:|:--------:|:-----------|:-----|
| 第 1 趟 | 3 | (14, 27, 78, 58, 45, 81, 93, 96) | |
| 第 2 趟 | 2 | (14, 27, 58, 45, 78, 81, 93, 96) | |
| 第 3 趟 | 1 | (14, 27, 45, 58, 78, 81, 93, 96) | |
| 第 4 趟 | 0 | (14, 27, 45, 58, 78, 81, 93, 96) | 本趟无交换，排序结束 |

**逐趟说明：**

- **第 1 趟**：从左到右扫描。14<27 不换，27<78 不换，78<93 不换，93>58 交换，93>45 交换，93>81 交换，93<96 不换。本趟交换 3 次，结果：$(14, 27, 78, 58, 45, 81, 93, 96)$。

  > 详细过程：初始 $(14, 27, 78, 93, 58, 45, 81, 96)$
  > - 比较 14,27 → 不换
  > - 比较 27,78 → 不换
  > - 比较 78,93 → 不换
  > - 比较 93,58 → 交换：$(14, 27, 78, 58, 93, 45, 81, 96)$
  > - 比较 93,45 → 交换：$(14, 27, 78, 58, 45, 93, 81, 96)$
  > - 比较 93,81 → 交换：$(14, 27, 78, 58, 45, 81, 93, 96)$
  > - 比较 93,96 → 不换
  > 结果：$(14, 27, 78, 58, 45, 81, 93, 96)$，交换 3 次。

- **第 2 趟**：从 $(14, 27, 78, 58, 45, 81, 93, 96)$ 开始。78>58 交换，78>45 交换，其余不换。交换 2 次，结果：$(14, 27, 58, 45, 78, 81, 93, 96)$。

- **第 3 趟**：从 $(14, 27, 58, 45, 78, 81, 93, 96)$ 开始。58>45 交换，其余不换。交换 1 次，结果：$(14, 27, 45, 58, 78, 81, 93, 96)$。

- **第 4 趟**：从 $(14, 27, 45, 58, 78, 81, 93, 96)$ 开始。全序无交换，**本趟无交换，排序结束**。

**最终结果：** $(14, 27, 45, 58, 78, 81, 93, 96)$

**交换总次数 = 3+2+1+0 = 6**

## 第 3 问：对比分析（2 分）

### 小问 1：实际趟数与比较

- **直接插入排序**实际执行 **7 趟**（固定为 $n-1=7$ 趟）。
- **冒泡排序**实际执行 **4 趟**（第 4 趟无交换后终止）。
- **冒泡排序**所需趟数更少（4 < 7）。

### 小问 2：最坏时间复杂度与操作次数比较

- **直接插入排序**最坏时间复杂度：$O(n^2)$。
- **冒泡排序**最坏时间复杂度：$O(n^2)$。
- 直接插入排序元素后移总次数 = **6**，冒泡排序交换总次数 = **6**，二者**相等**。

> **推理依据**：直接插入排序中每发生一次后移操作，对应一对逆序对被消除；冒泡排序中每发生一次交换操作，同样对应一对逆序对被消除。初始序列逆序对数为 6，因此两种排序的后移总次数与交换总次数均为 6，二者相等。

## 最终答案汇总

| 问题 | 答案 |
|:-----|:-----|
| Q1 | 直接插入排序共 7 趟，最终结果 $= (14, 27, 45, 58, 78, 81, 93, 96)$ |
| Q2 | 冒泡排序共 4 趟，最终结果 $= (14, 27, 45, 58, 78, 81, 93, 96)$ |
| Q3-1 | 直接插入 7 趟，冒泡 4 趟，**冒泡排序**趟数更少 |
| Q3-2 | 两者最坏复杂度均为 $O(n^2)$；后移总次数(6) **等于** 交换总次数(6) |
