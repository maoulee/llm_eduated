## 题目

# 循环队列入队/出队操作代码填空

设有如下循环队列的顺序存储结构定义：

```c
#define MaxSize 8

typedef struct {
    int data[MaxSize];  // 存放队列元素
    int front, rear;    // 队头指针和队尾指针
} SqQueue;
```

约定：`front` 指向队头元素的位置，`rear` 指向**队尾元素的下一个位置**（即待插入位置）。初始时 `front = 0, rear = 0`。队列采用"**牺牲一个存储单元**"的方式区分队空和队满。

以下是该循环队列的入队函数 `EnQueue` 和出队函数 `DeQueue` 的实现，其中 **4 处**用 `____` 标出的位置需要填写正确的 C 语言表达式。请根据上述约定，补全以下代码。

### 入队函数

```c
bool EnQueue(SqQueue *Q, int x) {
    if ( ____ ) {              // (1) 队列满的判定条件
        return false;          // 队满，入队失败
    }
    Q->data[Q->rear] = x;      // 将 x 存入 rear 所指位置
    ____ ;                     // (2) rear 指针更新
    return true;
}
```

### 出队函数

```c
bool DeQueue(SqQueue *Q, int *x) {
    if ( ____ ) {              // (3) 队列空的判定条件
        return false;          // 队空，出队失败
    }
    *x = Q->data[Q->front];    // 读取队头元素
    ____ ;                     // (4) front 指针更新
    return true;
}
```

### 分值

| 空号 | 考点 | 分值 | 依赖 |
|------|------|------|------|
| (1) | 入队函数判满条件 | 1 分 | 独立 |
| (2) | 入队函数 rear 指针更新（取模） | 1.5 分 | 依赖空(1) |
| (3) | 出队函数判空条件 | 1 分 | 独立 |
| (4) | 出队函数 front 指针更新（取模） | 1.5 分 | 依赖空(3) |

**合计 5 分。**

## 参考答案

| 空号 | 正确表达式 |
|------|-----------|
| (1) | `(Q->rear + 1) % MaxSize == Q->front` |
| (2) | `Q->rear = (Q->rear + 1) % MaxSize` |
| (3) | `Q->front == Q->rear` |
| (4) | `Q->front = (Q->front + 1) % MaxSize` |

## 解析

### 基本约定回顾

| 参数 | 值 |
|------|-----|
| MaxSize | 8 |
| front 初始值 | 0 |
| rear 初始值 | 0 |
| rear 指向 | 队尾元素的**下一个位置**（待插入位置） |
| 区分方式 | 牺牲一个存储单元 |

### 空(1)：入队函数判满条件

队列采用"牺牲一个存储单元"方式。因为 `rear` 始终指向待插入位置，当 `rear` 的下一个位置（即 `(rear+1) % MaxSize`）等于 `front` 时，说明只剩一个空位——这个空位被"牺牲"不用，队列已满。

> `(Q->rear + 1) % MaxSize == Q->front`

> **必须取模**：若不取模，当 `rear = MaxSize - 1` 时 `rear + 1` 会越界，无法正确回绕到 0 与 `front` 比较。

### 空(2)：rear 指针更新

将元素存入 `rear` 所指位置后，`rear` 向后移动一位。由于是循环队列，需对 `MaxSize` 取模实现回绕：

> `Q->rear = (Q->rear + 1) % MaxSize`

> **先加1再取模**：若写成 `(Q->rear % MaxSize) + 1`（先取模后加），当 `rear = MaxSize - 1` 时结果为 `0 + 1 = 1` 而非 `0`，回绕错误。

### 空(3)：出队函数判空条件

"牺牲一个单元"方案中，队空条件与队满条件不同。当 `front == rear` 时队列为空：

> `Q->front == Q->rear`

> **此处不需要取模**：`front` 和 `rear` 本身已通过取模更新保持在 `[0, MaxSize)` 范围内，直接比较即可。判空条件不含取模，与空(1)的判满条件（含取模 + 加1）形式不同，二者不会混淆。

### 空(4)：front 指针更新

读取队头元素后，`front` 向后移动一位，同样需要取模回绕：

> `Q->front = (Q->front + 1) % MaxSize`

> 与空(2)同理，**先加1再取模**。

### 逻辑自洽验证（MaxSize=8）

模拟连续 8 次入队操作：

| 操作 | 入队前 rear | 判满 `(rear+1)%8==front` | 入队结果 | 入队后 rear |
|------|------------|--------------------------|---------|------------|
| EnQueue(0) | 0 | (1)%8==0? → False | **True** | 1 |
| EnQueue(1) | 1 | (2)%8==0? → False | **True** | 2 |
| EnQueue(2) | 2 | (3)%8==0? → False | **True** | 3 |
| EnQueue(3) | 3 | (4)%8==0? → False | **True** | 4 |
| EnQueue(4) | 4 | (5)%8==0? → False | **True** | 5 |
| EnQueue(5) | 5 | (6)%8==0? → False | **True** | 6 |
| EnQueue(6) | 6 | (7)%8==0? → False | **True** | 7 |
| EnQueue(7) | 7 | (8)%8==0 → **0==0 → True** | **False** | （不变） |

- 前 7 次返回 `true`，第 8 次返回 `false`（队满）
- 有效容量 = MaxSize - 1 = **7**

### 判空判满可区分验证

| 状态 | front | rear | 判空 `front==rear` | 判满 `(rear+1)%8==front` |
|------|-------|------|---------------------|--------------------------|
| 初始（空队） | 0 | 0 | **True** | False（(1)%8==0? → False） |
| 装满 7 个 | 0 | 7 | False（7≠0） | **True**（(8)%8==0 → True） |

两种状态不混淆：初始判空为真且判满为假；满队判满为真且判空为假。
