# 循环队列入队/出队操作代码填空

## 题干

设有如下循环队列的顺序存储结构定义：

```c
#define MaxSize 8

typedef struct {
    int data[MaxSize];  // 存放队列元素
    int front, rear;    // 队头指针和队尾指针
} SqQueue;
```

约定：`front` 指向队头元素的位置，`rear` 指向**队尾元素的下一个位置**（即待插入位置）。初始时 `front = 0, rear = 0`。队列采用"**牺牲一个存储单元**"的方式区分队空和队满。

以下是该循环队列的入队函数 `EnQueue` 和出队函数 `DeQueue` 的实现，其中 **4 处**用 `____` 标出的位置需要填写正确的 C 语言表达式。请根据上述约定，补全以下代码。

### 入队函数

```c
bool EnQueue(SqQueue *Q, int x) {
    if ( ____ ) {              // (1) 队列满的判定条件
        return false;          // 队满，入队失败
    }
    Q->data[Q->rear] = x;      // 将 x 存入 rear 所指位置
    ____ ;                     // (2) rear 指针更新
    return true;
}
```

### 出队函数

```c
bool DeQueue(SqQueue *Q, int *x) {
    if ( ____ ) {              // (3) 队列空的判定条件
        return false;          // 队空，出队失败
    }
    *x = Q->data[Q->front];    // 读取队头元素
    ____ ;                     // (4) front 指针更新
    return true;
}
```

## 通过条件（成功判据）

本题成立需要满足以下可机检特征：

1. **空(1) 判满条件**：填入的表达式为 `(Q->rear + 1) % MaxSize == Q->front`（取模判满，牺牲一个单元），**必须含 `% MaxSize`**——可检出"忘记取模"这一典型错误。
2. **空(2) rear 更新**：填入的表达式为 `Q->rear = (Q->rear + 1) % MaxSize`（先加1再取模），**必须含 `% MaxSize`**——可检出"先取模后加"或"忘记取模"的错误。
3. **空(3) 判空条件**：填入的表达式为 `Q->front == Q->rear`（注意此处**不需要取模**），可检出"判满判空条件混淆"的错误。
4. **空(4) front 更新**：填入的表达式为 `Q->front = (Q->front + 1) % MaxSize`（先加1再取模），**必须含 `% MaxSize`**。
5. **逻辑自洽**：以 MaxSize=8 为例，连续 8 次 `EnQueue` 中第 8 次必须返回 `false`（队满），队列最多容纳 7 个元素（MaxSize - 1），前 7 次返回 `true`。可由 exec 写一个循环入队/出队测试序列，`assert` 验证：第 8 次 EnQueue 返回 false，队列有效容量 == MaxSize - 1。
6. **判空判满可区分**：初始状态（front==rear）判空为真、判满为假；装满 7 个元素后判满为真、判空为假——两种状态不混淆。
