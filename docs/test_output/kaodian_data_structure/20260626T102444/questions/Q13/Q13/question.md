# 散列表拉链法构造与 ASL 计算

## 题干

给定关键字序列：

**{ 19, 14, 23, 1, 68, 20, 84, 27, 55, 11 }**

散列函数为 **H(key) = key % 11**，采用**拉链法**（链地址法）处理冲突，散列表长度 m = 11（散列地址范围为 0～10）。各关键字按给定序列顺序依次插入。

### 问题

**（1）**（4 分）画出该散列表的存储结构（写出每个散列地址及其对应的链表，链表中按插入顺序排列）。

**（2）**（3 分）计算在等概率情况下，查找**成功**的平均查找长度 ASL_success。

**（3）**（3 分）计算在等概率情况下，查找**失败**的平均查找长度 ASL_failure。（查找失败指：用散列函数定位到的地址处的链表中不含目标关键字；每个散列地址被查找的概率相等。）

---

## 设计意图

- **考察形式**：计算型综合题——散列表构造 + ASL 公式代入。
- **考点**：
  - Q1：拉链法散列表的构造过程（散列函数定位 + 冲突链接）。
  - Q2：查找成功 ASL——分母为关键字个数 n=10，分子为各关键字的比较次数之和（链表内从链头算起）。
  - Q3：查找失败 ASL——分母为散列地址个数 p=11，每个地址的比较次数 = 该地址处链表长度。
- **K 目标**：K2=3（ASL 公式代入含非整除运算）、K4=2（成功/失败 ASL 分母差异：n vs p）。
- **典型陷阱**：
  1. 成功 ASL 分母 = n = 10（关键字个数），失败 ASL 分母 = 11（散列地址数），易混淆。
  2. 拉链法查找失败时，每个地址的比较次数 = 该链表长度。
  3. 链表内比较次数从链表头算起到目标节点（含目标节点本身）。

## 通过条件（成功判据）

1. **散列表构造正确**：每个关键字按 H(key) = key % 11 映射到正确地址，且同地址关键字按插入顺序链接。最终应满足：至少 2 个地址的链表长度 ≥ 2；至少 1 个地址为空（链表长度 0）。
2. **查找成功 ASL 计算正确**：ASL_success 的分子 = 各关键字在链表中比较次数之和；分母 = n = 10（关键字个数）。assert: `ASL_success * 10 == 分子`。
3. **查找失败 ASL 计算正确**：ASL_failure 的分子 = 各地址链表长度之和；分母 = 11（散列地址个数）。assert: `ASL_failure * 11 == 各地址链表长度之和`。
4. **成功/失败 ASL 分母不同**：ASL_success 分母 = 10 ≠ 11 = ASL_failure 分母（若两者分母相同则题干参数有误或计算有误）。
5. **分布均匀性**：构造结果中不存在单一地址链表长度 ≥ 4 的极端聚集。
