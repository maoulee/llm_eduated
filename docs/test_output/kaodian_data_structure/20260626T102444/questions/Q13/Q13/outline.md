## 考点
- **核心知识点：散列表的拉链法构造**
  - 考察侧重点：给定关键字序列和除留余数法散列函数，能正确用拉链法（链地址法）将关键字插入散列表的各链表
  - 涉及：散列函数 H(key) = key mod p 的计算、冲突处理（拉链法挂在同一链表）
- **核心知识点：查找成功/查找失败的平均查找长度（ASL）计算**
  - 考察侧重点：ASL_success = 各关键字查找比较次数之和 / 关键字个数；ASL_failure = 各散列地址对应的链表长度之和 / 散列表长度
  - 关键区分：查找失败 ASL 的分母是散列表长度（模值 p），不是关键字个数
- **辅助知识点：除留余数法散列函数**
  - 考察侧重点：p 的选取（p ≤ 表长，通常 p 为不大于表长的质数）

## 难度目标
- K1=2：需要记忆拉链法和 ASL 公式定义，但概念不混淆即可入题，属基础名词级
- K2=3：需代入 ASL 公式做常规计算，涉及非 2 的幂次除法和小数结果，标准计算量
- K3=2：构造散列表需逐关键字计算散列地址并挂链，2-3 步串行推导，路径唯一
- K4=2：常规注意点——查找成功与查找失败的 ASL 分母不同，408 考生基本不会踩坑
- K5=1：单一知识点（散列表）内部解决，不涉及其他子系统

## 考察模式
**计算型——散列表构造与ASL计算**
理由：slot 指定的 examination_mode 即为此模式。该模式是 408 散列表综合题的经典考法：先构造散列表（体现拉链法理解），再分别计算两种 ASL（体现公式应用与分母区分）。两个子问题串行但逻辑可独立评分，适合 10 分综合题。

## 出题要求
- 题型：综合题，10 分
- 总条件数：3-4 个显式条件
  - 条件1：关键字序列（一组整数关键字）
  - 条件2：散列函数形式（除留余数法 H(key) = key mod p）
  - 条件3：散列表长度 m（或直接给定 p）
  - 条件4（可选）：说明用拉链法处理冲突
- 条件设计原则：关键字序列规模适中（7-10 个关键字为宜），能产生若干冲突但不极端；散列地址分布有一定但不均匀，使链表长度有区分度

## 子问题规划
- **第1问（约4分）：构造散列表**
  - 类型：计算+作答（写出每个关键字所在的散列地址及链表结构）
  - 考察目标：正确计算每个关键字的散列地址，正确用拉链法组织链表
  - 依赖关系：后续 ASL 计算的基础
- **第2问（约3分）：计算查找成功的 ASL**
  - 类型：计算
  - 考察目标：对每个关键字计算比较次数，求和后除以关键字个数
  - 依赖关系：依赖第1问构造的链表结构
- **第3问（约3分）：计算查找失败的 ASL**
  - 类型：计算
  - 考察目标：对每个散列地址计算比较次数（链表长度），求和后除以散列表长度
  - 依赖关系：依赖第1问构造的链表结构，与第2问并列但分母不同
- 子问题关系：串行（第1问为第2、3问基础），第2问与第3问逻辑并列

## 参数约束
- **关键字个数 n**：7-10 个为宜，保证计算量适中且链表有区分度
- **关键字值**：正整数，分布在使散列地址有一定碰撞但不全部冲突的范围
- **散列表长度 m**：应略大于 n（如 m = 11），留出空地址以便查找失败 ASL 有意义
- **模值 p**：p ≤ m，通常取不大于 m 的质数（如 m=11 时取 p=11）
- **一致性约束**：
  - 关键字 mod p 后应产生至少 2 个冲突（即至少一个链表长度 ≥ 2），否则查找成功 ASL 退化为 1，无考察意义
  - 至少 1 个散列地址为空（链表长度 0），使查找失败 ASL 中存在比较次数为 0 的情况
  - 不应出现所有关键字集中在 1-2 个地址的极端情况
- **可调自由度**：Question Agent 可自由选择具体关键字序列和 p 值，只要满足上述约束

## 参考经验
- **考察模式**：散列表综合题的标准模式——构造+ASL(成功)+ASL(失败)，408 高频考法
- **难度锚点**：K2=3 对应 ASL 公式代入有非整除结果，K4=2 对应分母差异的常规注意点
- **典型陷阱**：
  1. 查找成功 ASL 分母是关键字个数 n，查找失败 ASL 分母是散列表长度（模值 p），二者不同——学生易混淆
  2. 查找失败时，每个散列地址的比较次数等于该链表的长度（拉链法特点，与线性探测法不同）
  3. 拉链法中链表内关键字按插入顺序排列，比较次数从链表头到目标节点
