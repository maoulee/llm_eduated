# 散列表拉链法构造与 ASL 计算 — 求解过程

## 参数

- 关键字序列：{ 19, 14, 23, 1, 68, 20, 84, 27, 55, 11 }（共 n = 10 个）
- 散列函数：H(key) = key % 11
- 处理冲突方法：拉链法（链地址法）
- 散列表长度 m = 11（地址范围 0～10）

---

## （1）散列表存储结构

各关键字依次插入，先计算 H(key)，再挂到对应地址的链表末尾：

| key | H(key) | 插入到的地址 |
|----:|:------:|:----------:|
| 19  | 8      | 8          |
| 14  | 3      | 3          |
| 23  | 1      | 1          |
| 1   | 1      | 1          |
| 68  | 2      | 2          |
| 20  | 9      | 9          |
| 84  | 7      | 7          |
| 27  | 5      | 5          |
| 55  | 0      | 0          |
| 11  | 0      | 0          |

最终散列表结构（链表中按插入顺序排列）：

```
地址  0:  55 -> 11 -> NULL
地址  1:  23 -> 1  -> NULL
地址  2:  68 -> NULL
地址  3:  14 -> NULL
地址  4:  NULL
地址  5:  27 -> NULL
地址  6:  NULL
地址  7:  84 -> NULL
地址  8:  19 -> NULL
地址  9:  20 -> NULL
地址 10:  NULL
```

- 链表长度 ≥ 2 的地址：地址 0（长度 2）、地址 1（长度 2）——满足至少 2 个地址冲突。
- 空地址：地址 4、6、10（长度 0）——满足至少 1 个空地址。

---

## （2）查找成功的平均查找长度 ASL_success

查找成功时，每个关键字的比较次数 = 该关键字在链表中的位置（从链头算起，含自身）：

| key | H(key) | 在链表中位置 | 比较次数 |
|----:|:------:|:----------:|:------:|
| 19  | 8      | 第 1 个     | 1      |
| 14  | 3      | 第 1 个     | 1      |
| 23  | 1      | 第 1 个     | 1      |
| 1   | 1      | 第 2 个     | 2      |
| 68  | 2      | 第 1 个     | 1      |
| 20  | 9      | 第 1 个     | 1      |
| 84  | 7      | 第 1 个     | 1      |
| 27  | 5      | 第 1 个     | 1      |
| 55  | 0      | 第 1 个     | 1      |
| 11  | 0      | 第 2 个     | 2      |

- 分子（各关键字比较次数之和）= 1+1+1+2+1+1+1+1+1+2 = **12**
- 分母（关键字个数 n）= **10**

$$ASL_{success} = \frac{12}{10} = \frac{6}{5} = 1.2$$

> **易错点**：分母是关键字个数 n = 10，不是散列地址数。

---

## （3）查找失败的平均查找长度 ASL_failure

查找失败时，需遍历该地址处的整条链表才能确认目标不存在，每个地址的比较次数 = 该地址链表长度：

| 地址 | 链表 | 链表长度（比较次数） |
|:----:|------|:------------------:|
| 0    | 55 → 11 | 2               |
| 1    | 23 → 1  | 2               |
| 2    | 68      | 1               |
| 3    | 14      | 1               |
| 4    | NULL    | 0               |
| 5    | 27      | 1               |
| 6    | NULL    | 0               |
| 7    | 84      | 1               |
| 8    | 19      | 1               |
| 9    | 20      | 1               |
| 10   | NULL    | 0               |

- 分子（各地址链表长度之和）= 2+2+1+1+0+1+0+1+1+1+0 = **10**
- 分母（散列地址个数 p）= **11**

$$ASL_{failure} = \frac{10}{11} \approx 0.9091$$

> **易错点**：
> 1. 分母是散列地址数 p = 11，不是关键字个数。
> 2. 拉链法查找失败时，每个地址的比较次数 = 该地址链表长度（包括长度为 0 的空链表，比较次数为 0）。

---

## 最终答案

| 问题 | 答案 |
|------|------|
| （1）散列表结构 | 见上方构造（地址 0: 55→11；地址 1: 23→1；其余各 1 个或空） |
| （2）ASL_success | **6/5 = 1.2** |
| （3）ASL_failure | **10/11 ≈ 0.9091** |
