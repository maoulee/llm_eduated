## 题目

已知一棵二叉树共有 9 个节点，节点编号为互不相同的大写字母 A～I（每个字母恰好出现一次）。现给出该二叉树的**后序遍历序列**和**中序遍历序列**如下：

- **后序遍历序列**：A, C, B, E, H, I, G, F, D
- **中序遍历序列**：A, B, C, D, E, F, H, G, I

请根据上述两条遍历序列完成以下问题。

---

### 问题 Q1（6 分）

根据给定的后序遍历序列和中序遍历序列，还原该二叉树的结构。

要求：写出还原后二叉树中每个**非叶子节点**的左孩子和右孩子（若某个孩子为空则写"空"）。请按下表格式作答（需列出全部非叶子节点）：

| 节点 | 左孩子 | 右孩子 |
|------|--------|--------|
| … | … | … |

### 问题 Q2（4 分，依赖 Q1）

根据 Q1 中还原出的二叉树结构，写出该二叉树的**先序遍历序列**。

---

## 参考答案

**Q1**（非叶子节点表）：

| 节点 | 左孩子 | 右孩子 |
|------|--------|--------|
| D    | B      | F      |
| B    | A      | C      |
| F    | E      | G      |
| G    | H      | I      |

> 叶子节点：A、C、E、H、I（无子树，不在上表中列出）。

**Q2**：先序遍历序列为 **D, B, A, C, F, E, G, H, I**。

---

## 解析

### 解题方法

核心规则：后序序列的最后一个元素是根节点，在中序序列中定位根节点后，左侧为左子树的中序，右侧为右子树的中序。再根据左右子树的大小切分后序序列，递归还原。

### Q1：递归还原过程

**第 1 层：整棵树**

- 根节点 = 后序最后一个元素 = **D**
- 在中序序列中定位 D，D 的下标为 3（下标从 0 起）
- 左子树中序 = [A, B, C]（D 左侧 3 个）
- 右子树中序 = [E, F, H, G, I]（D 右侧 5 个）

**第 2 层：D 的左子树**

- 后序（左子树部分，取前 3 个）= [A, C, B]
- 根 = 后序最后一个 = **B**
- B 在中序 [A, B, C] 中，下标为 1
- 左子树中序 = [A]，右子树中序 = [C]

**第 2 层：D 的右子树**

- 后序（右子树部分，取后 5 个）= [E, H, I, G, F]
- 根 = 后序最后一个 = **F**
- F 在中序 [E, F, H, G, I] 中，下标为 1
- 左子树中序 = [E]，右子树中序 = [H, G, I]

**第 3 层：B 的左子树** → 后序 = [A]，根 = **A**（叶子，无子树）

**第 3 层：B 的右子树** → 后序 = [C]，根 = **C**（叶子，无子树）

**第 3 层：F 的左子树** → 后序 = [E]，根 = **E**（叶子，无子树）

**第 3 层：F 的右子树** → 后序 = [H, I, G]，中序 = [H, G, I]

- 根 = 后序最后一个 = **G**
- G 在中序 [H, G, I] 中，下标为 1
- 左子树中序 = [H]，右子树中序 = [I]

**第 4 层：G 的左子树** → 后序 = [H]，根 = **H**（叶子）

**第 4 层：G 的右子树** → 后序 = [I]，根 = **I**（叶子）

由此得到 4 个非叶子节点的孩子关系如参考答案表所示。

### Q2：先序遍历

先序遍历顺序为：**根 → 左 → 右**，从根节点 D 开始依次访问：

1. **D**（根）
2. → D 的左子树：**B**
3. → B 的左：**A**
4. → B 的右：**C**
5. → D 的右子树：**F**
6. → F 的左：**E**
7. → F 的右：**G**
8. → G 的左：**H**
9. → G 的右：**I**

先序遍历序列：**D, B, A, C, F, E, G, H, I**（共 9 个节点，每个恰好出现一次）。
