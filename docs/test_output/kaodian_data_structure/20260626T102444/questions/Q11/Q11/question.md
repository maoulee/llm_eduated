# 综合题：后序+中序遍历序列还原二叉树并写出先序序列

## 题干

已知一棵二叉树共有 9 个节点，节点编号为互不相同的大写字母 A～I（每个字母恰好出现一次）。现给出该二叉树的**后序遍历序列**和**中序遍历序列**如下：

- **后序遍历序列**：A, C, B, E, H, I, G, F, D
- **中序遍历序列**：A, B, C, D, E, F, H, G, I

请根据上述两条遍历序列完成以下问题。

---

### 问题 Q1（6 分）

根据给定的后序遍历序列和中序遍历序列，还原该二叉树的结构。

要求：写出还原后二叉树中每个**非叶子节点**的左孩子和右孩子（若某个孩子为空则写"空"）。请按下表格式作答（需列出全部非叶子节点）：

| 节点 | 左孩子 | 右孩子 |
|------|--------|--------|
| … | … | … |

### 问题 Q2（4 分，依赖 Q1）

根据 Q1 中还原出的二叉树结构，写出该二叉树的**先序遍历序列**。

---

## 题目参数

| 参数 | 值 |
|------|-----|
| 节点数 n | 9 |
| 节点标识 | A～I，每个恰好出现一次 |
| 后序遍历序列 | A, C, B, E, H, I, G, F, D |
| 中序遍历序列 | A, B, C, D, E, F, H, G, I |
| 序列生成方式 | 先构造合法二叉树，再分别导出后序和中序序列，保证两序列由同一棵树产生 |

---

## 通过条件（成功判据·可机检）

本题成立需同时满足以下特征（供 gen.py 翻译为 assert 验证）：

1. **序列一致性**：后序序列与中序序列包含的元素集合完全相同（均为 9 个互异大写字母 A～I），且二者由同一棵二叉树导出——即从这两条序列能唯一还原出一棵二叉树。
2. **结构约束**：还原后的二叉树中，至少有 3 个内部节点同时拥有左孩子和右孩子（即度 2 节点 ≥ 3）；树不退化为单链。
3. **先序完整性**：Q2 的先序遍历序列包含全部 9 个节点，且每个节点恰好出现一次；先序序列的第一个节点为二叉树的根节点（即后序序列的最后一个节点）。
4. **递归深度**：还原过程中递归拆分的层数 ≥ 3（即树高 ≥ 3），使推演步数充足。
