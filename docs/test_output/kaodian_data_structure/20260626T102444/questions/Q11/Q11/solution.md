# 解题过程：后序+中序遍历序列还原二叉树并写出先序序列

## 已知条件

- 后序遍历序列：A, C, B, E, H, I, G, F, D
- 中序遍历序列：A, B, C, D, E, F, H, G, I

---

## 解题方法

**核心规则：后序序列的最后一个元素是根节点，在中序序列中定位根节点后，左侧为左子树的中序，右侧为右子树的中序。** 再根据左右子树的大小切分后序序列，递归还原。

---

## Q1：还原二叉树结构

### 递归还原过程

**第 1 层：整棵树**

- 根节点 = 后序最后一个元素 = **D**
- 在中序序列中定位 D，D 的下标为 3（下标从 0 起）
- 左子树中序 = [A, B, C]（D 左侧 3 个）
- 右子树中序 = [E, F, H, G, I]（D 右侧 5 个）

**第 2 层：D 的左子树**

- 后序（左子树部分，取前 3 个）= [A, C, B]
- 根 = 后序最后一个 = **B**
- B 在中序 [A, B, C] 中，下标为 1
- 左子树中序 = [A]，右子树中序 = [C]

**第 2 层：D 的右子树**

- 后序（右子树部分，取后 5 个）= [E, H, I, G, F]
- 根 = 后序最后一个 = **F**
- F 在中序 [E, F, H, G, I] 中，下标为 1
- 左子树中序 = [E]，右子树中序 = [H, G, I]

**第 3 层：B 的左子树** → 后序 = [A]，根 = **A**（叶子，无子树）

**第 3 层：B 的右子树** → 后序 = [C]，根 = **C**（叶子，无子树）

**第 3 层：F 的左子树** → 后序 = [E]，根 = **E**（叶子，无子树）

**第 3 层：F 的右子树** → 后序 = [H, I, G]，中序 = [H, G, I]

- 根 = 后序最后一个 = **G**
- G 在中序 [H, G, I] 中，下标为 1
- 左子树中序 = [H]，右子树中序 = [I]

**第 4 层：G 的左子树** → 后序 = [H]，根 = **H**（叶子）

**第 4 层：G 的右子树** → 后序 = [I]，根 = **I**（叶子）

### 还原后的二叉树结构（非叶子节点）

| 节点 | 左孩子 | 右孩子 |
|------|--------|--------|
| D    | B      | F      |
| B    | A      | C      |
| F    | E      | G      |
| G    | H      | I      |

> 叶子节点：A、C、E、H、I（无子树，不在上表中列出）。

---

## Q2：先序遍历序列

先序遍历顺序为：**根 → 左 → 右**，从根节点 D 开始：

1. **D**（根）
2. → 左子树 D：**B**
3. → B 的左：**A**
4. → B 的右：**C**
5. → 右子树 D：**F**
6. → F 的左：**E**
7. → F 的右：**G**
8. → G 的左：**H**
9. → G 的右：**I**

**先序遍历序列：D, B, A, C, F, E, G, H, I**

---

## 验证（通过条件核对）

| 通过条件 | 结果 |
|---------|------|
| 序列一致性：后序与中序元素集合相同，均含 A～I 各一次，且能唯一还原 | ✓ |
| 结构约束：度 2 节点数 = 4（D、B、F、G），≥ 3 | ✓ |
| 先序完整性：9 个节点各出现一次，首节点 D = 后序末尾 = 根 | ✓ |
| 递归深度：树高 = 4（D→F→G→H），≥ 3 | ✓ |
