## 第 2 题

**题干**：利用栈检查括号是否匹配时，对输入序列 "( [ ] )" 逐字符扫描，遇左括号入栈，遇右括号与栈顶元素比较。当扫描到字符 ']'（尚未执行出栈操作）时，栈中元素从栈底到栈顶依次为（　　）。

A. 栈为空

B. 只有一个元素 '('

C. 只有一个元素 '['

D. 有两个元素，从栈底到栈顶依次为 '('、'['

**答案**：D

---

## 第 2 题解析

**答案**：D

**解析**：
- D 正确：括号匹配算法中，遇左括号入栈，遇右括号与栈顶比较。扫描 "( [ ] )"：读 '(' → 入栈，栈为 '('；读 '[' → 入栈，栈从底到顶为 '( ['；读 ']' → 与栈顶 '[' 匹配，此时**尚未出栈**，栈仍为 '( ['。因此读到 ']' 时的栈状态为栈底到栈顶 '('、'['。
- A 错误：栈不空，已入栈两个左括号。
- B 错误：栈顶应为 '['，不可能只有 '('（'[' 在 '(' 之上）。
- C 错误：栈中不止一个元素，'(' 在栈底。
