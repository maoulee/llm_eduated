# Q45 概念题（考点：银行家算法与死锁避免）

> 知识域：操作系统-2 > 进程与线程 > 死锁 > 死锁避免
> 考察模式：资源分配与安全性推演（概念辨析方向）
> 难度：4 | K目标：K3-K4 平衡型

---

## 第 1 题

下列关于安全状态、不安全状态和死锁状态的叙述中，正确的是（ ）。

I. 若系统处于安全状态，则系统中所有进程都能按照某种顺序顺利完成，不会发生死锁

II. 若系统处于不安全状态，则系统必然会进入死锁状态

III. 系统从不安全状态出发，有可能通过后续的资源分配与释放回到安全状态

A. 仅 I

B. 仅 I 和 II

C. 仅 I 和 III

D. I、II 和 III

**答案：C**

---

## 第 2 题

下列关于死锁避免和死锁预防的说法中，正确的是（ ）。

A. 死锁预防和死锁避免都是在资源分配前进行检查，二者本质相同

B. 死锁预防通过破坏死锁的必要条件来实现，而死锁避免通过评估分配后系统是否仍处于安全状态来实现

C. 死锁避免通过限制进程申请资源的顺序来防止死锁

D. 银行家算法是一种死锁预防策略

**答案：B**

---

## 第 3 题

在银行家算法的安全性检查中，当进程 Pi 被选中加入安全序列（即 Pi 可完成执行并释放资源）时，系统可用资源向量 Work 的更新方式为（ ）。

A. Work = Work + Max_i

B. Work = Work + Allocation_i

C. Work = Work + Need_i

D. Work = Work + Max_i − Allocation_i

**答案：B**

---

## 第 4 题

当进程 Pi 向系统申请资源时，银行家算法依次进行以下检查：

① Request_i ≤ Need_i

② Request_i ≤ Available

③ 试探性分配后进行安全性检查

关于上述检查的叙述中，正确的是（ ）。

I. 若检查 ① 不成立，则说明进程申请的资源超过了其预先声明的最大需求量，系统应拒绝该请求

II. 若检查 ② 不成立，则进程 Pi 必须等待，系统暂不分配资源

III. 只有当 ① 和 ② 都成立时，系统才进行试探性分配并执行安全性检查 ③

A. 仅 I

B. 仅 I 和 II

C. 仅 I 和 III

D. I、II 和 III

**答案：D**
