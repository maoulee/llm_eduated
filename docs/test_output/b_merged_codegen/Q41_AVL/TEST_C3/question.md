# Q41 平衡二叉树（AVL）的插入与旋转

## 题干

给定一棵初始平衡二叉树（AVL树），其节点集合为 {10, 20, 25, 30, 35, 40, 50}，树的结构如下（层序遍历为 30, 20, 40, 10, 25, 35, 50）：

```
       30
     /    \
   20      40
  /  \    /  \
10   25  35  50
```

现按顺序依次插入以下4个新节点：**5, 2, 60, 65**

每次插入后，若树失去平衡，则执行相应的旋转操作恢复平衡。AVL树的旋转规则如下：
- **LL型**：在左孩子的左子树插入导致失衡，对失衡节点执行右旋
- **RR型**：在右孩子的右子树插入导致失衡，对失衡节点执行左旋
- **LR型**：在左孩子的右子树插入导致失衡，先对左孩子左旋，再对失衡节点右旋
- **RL型**：在右孩子的左子树插入导致失衡，先对右孩子右旋，再对失衡节点左旋

## 设问

**(1)** 在插入全部4个节点的过程中，共触发了多少次旋转操作？分别是什么类型的旋转（注明旋转类型及旋转中心节点的值）？

**(2)** 插入全部节点并完成所有旋转后，最终AVL树的层序遍历序列是什么？

**(3)** 最终AVL树中，平衡因子为 -1 的节点有哪些？（按节点值从小到大列出）
