## core_knowledge_intent
- **must_test**: 
  1. AVL插入机制中的平衡因子动态计算与更新规则
  2. 四种旋转类型（LL/RR/LR/RL）的触发条件与执行过程
  3. 插入后树形态的动态维护与最小不平衡子树定位
- **must_not_shift_to**: 
  - 二叉搜索树BST的普通插入（无旋转调整）
  - 哈夫曼树构造或遍历序列还原
  - 纯概念辨析（如仅考AVL定义而不涉及操作推演）
  - 节点删除操作或线索化
- **coverage_success_criteria**: 学生能准确模拟连续插入过程中的平衡因子变化，正确识别首次失衡节点，精准匹配对应的旋转操作类型，并完整输出旋转后的正确树结构或关键节点状态。

## design_rationale
**为什么这样考？**
本题聚焦AVL树的核心算法过程——插入与旋转。难度4的定位要求题目具备较高的机制推演需求（K3）与条件路由需求（K4）。通过“结构操作与状态维护模拟”模式，能够清晰区分两类学生：一类仅能机械记忆旋转名称，另一类真正理解平衡因子变化如何驱动旋转触发，并能在多步状态更新中保持逻辑连贯。该难度设置符合考研数据结构对动态数据结构操作的高阶要求，既避免纯计算堆砌，又杜绝浅层概念填空。

**考点融合意图**（K3-K4高难度）：
融合“机制辨析”与“定量推演”两项考察维度。同一知识点（AVL插入）的不同考察项在此交汇：不仅要求识别旋转类型（条件路由/概念辨析），还要求完整模拟插入序列导致的形态变化（多步串行推演）。不跨考点强行拼接，而是在AVL插入流程内部实现“状态跟踪→失衡判定→旋转执行”的闭环考察，确保认知负荷集中在核心机制上。

## question_structure_plan
- **复用骨架来源**：[综合型大题通用骨架] 基础操作模拟 → 进阶状态推演 → 关键条件辨析
- **子问1**：考[连续插入过程中的平衡因子计算与树形态跟踪]（基础层）—— 参考往年综合题问法：“给定初始状态，依次插入若干关键字，描述/画出插入过程中的树结构变化及平衡因子更新。”
- **子问2**：基于子问1的结果，考[首次失衡节点的定位与旋转类型触发条件辨析]（进阶层）—— 参考往年综合题问法：“指出首次出现平衡因子绝对值为2的节点，并说明应执行何种旋转操作及其判定依据。”
- **子问3（可选）**：考[旋转执行后的最终树结构验证与关键属性计算]（区分度层）—— 参考往年综合题问法：“完成旋转调整后，给出最终平衡二叉树的结构，并计算其高度/特定节点路径长度。”
- **dependency_pattern**：串行依赖（前问插入结果与失衡状态直接作为后问旋转触发与结构验证的输入）

## terminology_and_expression_constraints
- **必须使用**：平衡因子（Balance Factor）、最小不平衡子树、LL/RR/LR/RL旋转、左旋/右旋、双旋、根节点/左孩子/右孩子、高度/深度、依次插入
- **限定语**：题干中插入序列需明确为“按给定顺序依次插入”，避免“同时插入”或“无序插入”等歧义表述；旋转操作需明确到具体类型（如“执行LR双旋”），禁止使用“调整”、“修正”等模糊动词替代
- **禁止表述**：禁止将“平衡因子”与“节点度数”混用；禁止出现“大概”、“可能”、“通常”等不确定性表述；禁止在题干中直接给出旋转结果或失衡节点位置（剥夺推演空间）

## audit_focus
- **难度映射校验**：确认K3（多步串行推演）与K4（条件路由/触发条件辨析）为主导，符合难度4设定；K2（单步代入）保持较低，避免计算喧宾夺主
- **干扰模式设计**：
  - 概念型干扰：混淆LR与RL的触发条件（如将“左子树右高”误判为RL）
  - 计算型干扰：平衡因子符号错误、高度计算off-by-one、中间状态遗漏
  - 组合判断型干扰：I/II/III各代表独立命题，干扰项为“真+假”混合组合（如旋转规则描述）
- **约束合规性**：严格检查未泄露具体插入序列、节点值、最终树结构或答案；`question_structure_plan`仅描述考察方向与往年问法锚点，无解题步骤；未涉及excluded.modes/knowledge
- **教师说明体现**：在audit_focus中明确“结构操作与状态维护模拟”的考察重心，确保题目不偏向纯记忆或纯计算，符合组卷大纲意图
