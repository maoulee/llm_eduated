## 求解过程

### 插入序列
30, 20, 40, 10, 25, 5, 15

---

### （1）每次插入后的AVL树形态与平衡因子

**插入 30：**
```
  [30] BF=0
```

**插入 20：**
```
  [30] BF=1
  ├── [20] BF=0
```

**插入 40：**
```
  [30] BF=0
  ├── [20] BF=0
  └── [40] BF=0
```

**插入 10：**
```
  [30] BF=1
  ├── [20] BF=1
  │   ├── [10] BF=0
  └── [40] BF=0
```

**插入 25：**
```
  [30] BF=1
  ├── [20] BF=0
  │   ├── [10] BF=0
  │   └── [25] BF=0
  └── [40] BF=0
```

**插入 5：**
插入5后结点30的BF=2，触发LL旋转，20成为根：
```
  [20] BF=0
  ├── [10] BF=1
  │   ├── [5] BF=0
  └── [30] BF=0
      ├── [25] BF=0
      └── [40] BF=0
```

**插入 15：**
```
  [20] BF=0
  ├── [10] BF=0
  │   ├── [5] BF=0
  │   └── [15] BF=0
  └── [30] BF=0
      ├── [25] BF=0
      └── [40] BF=0
```

---

### （2）首次失衡结点与旋转类型

**首次出现平衡因子绝对值为2的结点：30**

在插入关键字 5 后，结点 30 的平衡因子变为 2（左子树高度3，右子树高度1），首次出现失衡。

**应执行旋转操作：LL旋转**

**判定依据：**
- 结点 30 的 BF = 2 > 1，说明左子树过高
- 其左孩子 20 的 BF = 1 ≥ 0，说明20的左子树不低于右子树
- 符合 LL 旋转触发条件（左-左型：失衡结点的左孩子的左子树更高或等高）

---

### （3）旋转调整后的最终AVL树形态

LL旋转后（20成为根，30成为20的右孩子）：
```
  [20] BF=0
  ├── [10] BF=0
  │   ├── [5] BF=0
  │   └── [15] BF=0
  └── [30] BF=0
      ├── [25] BF=0
      └── [40] BF=0
```

所有结点平衡因子均为0，树完全平衡。

## 最终答案

| 子问 | 答案 |
|------|------|
| （1） | 见上方求解过程，共7次插入，第6次插入5时触发LL旋转 |
| （2） | 首次失衡结点：**30**；旋转类型：**LL旋转**；依据：结点30的BF=2，其左孩子20的BF=1≥0 |
| （3） | 最终树：根20，左子10（左5右15），右子30（左25右40），所有结点BF=0 |
