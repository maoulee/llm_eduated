## 题目

设某数据集中各字符出现的频率（权值）集合为 {5, 10, 15, 20, 30}，以该集合构造哈夫曼树，则该哈夫曼树的带权路径长度 WPL 为（ ）。

> 注：路径长度指从根结点到该结点的路径上的分支数（边数）；WPL 仅计算叶子节点的带权路径长度之和。

A. 185
B. 155
C. 175
D. 205

## 设计说明

- **复用骨架来源**：408经典模式——给定权值集合求哈夫曼树WPL
- **考察形式**：多步串行推演 + 单点计算（K3+K2 混合主导），选择题形式
- **设问结构**：直接问WPL数值，学生需完整执行哈夫曼贪心合并流程（反复选取最小两权值合并）→ 构造哈夫曼树 → 对每个叶子节点计算权值×路径长度 → 求和得WPL
- **经验值参数来源**：
  - 叶子节点数量：5个（来自经验值表"二叉树遍历/还原 n=6-8"及 parameter_plan 建议4-5个，取5）
  - 权值集合：{5, 10, 15, 20, 30}（来自经验值表"排序/查找 n=8-16"的友好值思路，取5个有明显差异的正整数，均在[1,50]范围内）
  - 预期WPL结果范围：[50, 300]（经验值，具体由 solve 计算验证）
- **与目标 K-雷达的对齐**：
  - K1=2：需记忆WPL定义（仅叶子节点、路径长度=边数）和哈夫曼算法步骤
  - K2=3：对每个叶子节点执行权值×路径长度的加权求和
  - K3=3：反复选取最小两权值合并，跟踪集合状态变化（2-3轮合并）
  - K4=2：权值相等时合并规则为次要条件路由（本题权值无重复，K4要求较低）
  - K5=2：不涉及跨域联动
- **是否融合**：否。K3-K4 非高难度，单骨架（给定权值集合→哈夫曼合并→WPL计算）已满足难度目标，无需融合。
- **干扰选项设计**：
  - A(185)：路径长度 off-by-one 错误（某叶子深度多算1，如权值10深度4→5，贡献40→50，差+10）
  - B(155)：漏算叶子节点贡献（漏算权值5的叶子，5×4=20，175-20=155）
  - C(175)：正确答案
  - D(205)：路径长度计算错误（大权值叶子深度多算1，如权值30深度1→2，贡献30→60，差+30）
