## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: DS-5 > 树与二叉树
- primary_target_name: 二叉树带权路径长度
- question_type: single_choice
- examination_mode: 给定权值集合计算哈夫曼树WPL

### 难度目标
- k_target: K1=2,K2=3,K3=3,K4=2,K5=2
- difficulty_level: 3
- difficulty_rationale: 中等难度，考察WPL定义理解与哈夫曼树构造计算，计算量适中

### 结构要求
- option_count: 4
- distractor_strategy: 计算错误型干扰（路径长度算错、内部节点误算）、构造错误型干扰（哈夫曼合并顺序错误）、概念混淆型干扰（WPL与其他树参数混淆）
- condition_count: 1-2

### 参数约束
- 叶子节点数量(n): [3, 6]，建议4-5个
- 权值集合(w_1, ..., w_n): 每个w_i ∈ [1, 50]的正整数，可重复但不应全同，应有明显差异
- WPL结果范围: [50, 300]，应为整数
- 一致性约束: 权值集合应能构造唯一哈夫曼树，或明确权值相等时的合并规则

### 参考经验摘要
- 历史模式: 408经典模式为给定权值集合求哈夫曼树WPL，简化模式为给定树结构直接计算WPL
- 难度锚点: 简单(3-4权值/小数值)、中等(4-5权值/适中数值/可能重复)、困难(5-6权值/大数值/多步合并)
- 典型陷阱: 路径长度=层数-1而非层数、WPL仅含叶子节点、哈夫曼合并需选最小两权值、合并后新权值为两权值之和
