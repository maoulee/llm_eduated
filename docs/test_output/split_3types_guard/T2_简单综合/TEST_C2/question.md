## 题干

已知某二叉树的前序遍历序列为 `A B D E C F G`，中序遍历序列为 `D B E A F C G`。

请回答下列问题：

### (1) （6分）根据上述前序遍历序列和中序遍历序列还原该二叉树的结构，并写出其后序遍历序列。

### (2) （5分）基于(1)中还原的二叉树，求该二叉树的深度和叶子节点（度为0的节点）个数。

### (3) （4分）若仅已知该二叉树的前序遍历序列和后序遍历序列，能否唯一确定该二叉树的结构？请说明理由。

## 设计说明

- **复用骨架来源**：综合题通用"给定数据结构+参数 → 多步串行推演 → 概念辨析"骨架。参考2014_Q41（给定二叉树存储结构→算法设计→代码实现）和2026_Q41（给定BST+参数→查找计算→输出）的设问组织方式，提炼为"给定遍历序列→还原树结构→计算性质→分析唯一性"的串行骨架。

- **考察形式**：多步串行推演（主）+ 概念辨析（辅）。Q1考查递归还原机制（多步串行），Q2基于Q1结果计算树性质（串行依赖），Q3考查中序遍历必要性的概念辨析（可独立但建议结合Q1）。

- **子问依赖链 / 设问结构**：
  - Q1（6分）：基础还原问——从前序定根、中序划分左右子树，递归还原二叉树，写出后序遍历序列。
  - Q2（5分）：性质计算问——基于Q1还原的树结构，递归计算深度（max(左子树深度, 右子树深度)+1），统计叶子节点数。
  - Q3（4分）：概念辨析问——分析前序+后序无法唯一还原的原因（无法确定左右子树边界），考查中序遍历的必要性。
  - 依赖关系：Q2依赖Q1的还原结果；Q3可独立作答但建议结合Q1的树结构分析。

- **初步参数选择理由**（基于骨架+经验，大胆给）：
  - 节点数n=7：medium难度典型值（5-10范围内），保证递归深度适中。
  - 节点值：A-G共7个互不相同的字符，便于区分和书写。
  - 前序遍历：`A B D E C F G`——根A，左子树BDE，右子树CFG。
  - 中序遍历：`D B E A F C G`——A左侧DBE为左子树，右侧FCG为右子树。
  - 预期树高h=3：在[3,4]范围内，符合参数约束。
  - 预期叶子节点4个（D、E、F、G）：满二叉树结构，叶子数合理。

- **与目标 K-雷达的对齐**：
  - K1=3：需理解前序/中序/后序遍历的定义和根节点位置规则。
  - K2=3：单步定位根节点（前序首元素）、在中序中划分左右子树边界。
  - K3=2：递归还原过程，节点数7、树高3，推演复杂度可控。
  - K4=3：识别中序遍历的关键路由作用（划分左右子树），Q3考查条件路由（中序的必要性）。
  - K5=3：遍历序列与树结构的双向映射（序列→树→序列）。

- **是否融合**：不融合。K3=2偏低，单骨架（经典还原模式）已满足难度目标，无需额外融合多侧重。
