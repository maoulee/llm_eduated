## 题目

已知某二叉树的前序遍历序列为 `A B D E C F G`，中序遍历序列为 `D B E A F C G`。

请回答下列问题：

### (1)（6分）根据上述前序遍历序列和中序遍历序列还原该二叉树的结构，并写出其后序遍历序列。

### (2)（5分）基于(1)中还原的二叉树，求该二叉树的深度和叶子节点（度为0的节点）个数。

### (3)（4分）若仅已知该二叉树的前序遍历序列和后序遍历序列，能否唯一确定该二叉树的结构？请说明理由。

## 求解过程

### (1) 还原二叉树并求后序遍历

**还原过程：**

1. 前序第一个元素 `A` 为根节点。在中序中找到 `A`，其左侧 `D B E` 为左子树，右侧 `F C G` 为右子树。
2. 左子树：前序 `B D E`，中序 `D B E`。根为 `B`，中序中 `B` 左侧 `D` 为左子树，右侧 `E` 为右子树。→ `B` 的左孩子为 `D`，右孩子为 `E`。
3. 右子树：前序 `C F G`，中序 `F C G`。根为 `C`，中序中 `C` 左侧 `F` 为左子树，右侧 `G` 为右子树。→ `C` 的左孩子为 `F`，右孩子为 `G`。

**二叉树结构：**
```
        A
       / \
      B   C
     / \ / \
    D  E F  G
```

**后序遍历**（左→右→根）：`D E B F G C A`

### (2) 求深度和叶子节点个数

**深度：**
- 第1层：A
- 第2层：B, C
- 第3层：D, E, F, G

该二叉树深度为 **3**。

**叶子节点（度为0的节点）：**
- D（无左右孩子）
- E（无左右孩子）
- F（无左右孩子）
- G（无左右孩子）

叶子节点个数为 **4**。

### (3) 仅知前序和后序能否唯一确定二叉树

**不能唯一确定。**

**理由：** 前序遍历的顺序是"根→左→右"，后序遍历的顺序是"左→右→根"。两者都能确定根节点，但都无法区分左右子树的边界。当某个节点只有一个子节点时，无法判断该子节点是左孩子还是右孩子。例如，前序为 `A B`、后序为 `B A` 的二叉树，B 既可以是 A 的左孩子，也可以是 A 的右孩子，两种结构的前序和后序遍历结果完全相同。因此仅凭前序和后序遍历无法唯一确定二叉树结构。

## 答案

- **(1)** 后序遍历序列：`D E B F G C A`
- **(2)** 深度：3；叶子节点个数：4
- **(3)** 不能唯一确定。理由：前序和后序遍历均无法区分左右子树边界，当节点只有一个子节点时无法判断是左孩子还是右孩子。

- **考察知识点**：二叉树遍历序列还原（前序+中序）、树的深度与叶子节点计算、遍历序列唯一性条件（中序的必要性）
- **考察形式**：多步串行推演（主）+ 概念辨析（辅）
- **难度**：K1=3, K2=3, K3=2, K4=3, K5=3，综合难度等级 3
