## rationale
- 为何选此形式：KP核心是"由前序/后序定根、由中序划分左右子树"的递归还原方法，天然对应多步串行推演（Q1还原→Q2计算性质）；Q3考查"中序遍历的必要性"属于概念辨析。混合形状（无单一主导）与混合形式匹配。
- 与目标 K-雷达的对齐说明：K3=2偏低反映节点数适中（5-10）、递归深度有限（树高3-4），推演复杂度可控；K1/K2/K4/K5均为3反映需理解遍历定义（K1）、单步定位根与划分边界（K2）、识别中序的关键路由作用（K4）、遍历序列与树结构的双向映射（K5），与经典还原模式的考察重心一致。
