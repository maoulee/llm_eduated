## 第 3 题解析

**答案**：

**（1）中断响应过程（由硬件自动完成）：**

① **关中断**：防止在保存断点过程中被新的中断打断（保证原子性）。
② **保存断点**：将程序的返回地址（PC）及程序状态字（PSW）等压入堆栈或保存到指定寄存器。
③ **引出中断服务程序**：通过中断向量表（或中断识别）找到中断服务程序的入口地址，装入 PC，从而转移到中断服务程序执行。

**（2）中断处理流程（由中断服务程序完成）：**

① **保护现场**：保存通用寄存器等内容，以便返回后恢复。
② **中断服务（中断处理）**：执行具体的中断处理逻辑（如读取外设数据）。
③ **恢复现场**：恢复被保护的寄存器内容。
④ **开中断并中断返回**：恢复中断允许状态，执行中断返回指令，恢复断点（PC 和 PSW），返回被中断的程序继续执行。

**（3）分界点：** 中断响应是硬件自动完成的工作（关中断→保存断点→获取入口地址），中断处理是软件（中断服务程序）完成的工作（保护现场→中断服务→恢复现场→中断返回）。两者的分界点是**获取中断服务程序入口地址并转入执行的那一刻**——此前的操作由硬件完成，此后由软件执行。

**解析**：本题要求区分"硬件完成的响应过程"与"软件完成的处理流程"，关键得分点在于明确两者的分界。常见错误：将"保护现场"归入中断响应阶段（实际属中断处理）；遗漏"关中断"步骤；混淆中断响应的三个硬件步骤。
