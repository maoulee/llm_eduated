## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 中央处理器 > 流水线
- primary_target_name: 指令流水线性能分析（吞吐率/加速比/效率）
- question_type: comprehensive
- examination_mode: 分析题——给定流水线段数/各段时间/指令数，分析吞吐率、加速比与效率

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=4,K5=1
- difficulty_level: 4
- difficulty_rationale: K4=4为主导——必须识别瓶颈段决定流水线周期这一隐含前提，各段时间不等时的排空/填充处理是核心暗坑。K1=3需记忆三个核心公式，K2=3涉及非2幂次计算，K3=3为3-5步固定流程，K5=1纯单一知识点。

### 结构要求
- sub_question_count: 4
- sub_question_structure:
  - Q1(3分): 确定流水线周期+计算N条指令总执行时间（计算题）
  - Q2(3分): 计算实际吞吐率与最大吞吐率，分析差距原因（计算+简答）
  - Q3(2分): 计算加速比（计算题）
  - Q4(2分): 瓶颈段优化方案及优化后指标对比（分析+计算）
- dependency: 串行——Q1结果为Q2/Q3基础，Q4依赖前述结果
- condition_count: 3-4
- distractor_strategy: N/A（综合题，非选择题）

### 参数约束
- 流水线段数_k: 4-6段（整数），k≥4
- 各段时间_Δt: 5-30ns范围；至少一个瓶颈段，瓶颈段时间≥其余段最大值的1.5倍；建议瓶颈段时间=普通段时间的整数倍
- 瓶颈段数量: 1-2段（若2段则时间相等）
- 指令条数_N: 100-1000（整数），非2的幂，N足够大使排空时间占比<5%
- 优化后瓶颈段时间: 原瓶颈段时间/2，优化后各段尽量均匀
- 一致性要求: 流水线周期T = max(Δt₁…Δtₖ)；所有指标计算基于T而非各段时间之和

### 参考经验摘要
- 历史模式: "给参数→算指标→对比优化"三步式，408流水线综合题经典结构
- 难度锚点: K4主导，核心陷阱为"瓶颈段决定周期"，学生常误用平均值/求和
- 典型陷阱:
  1. 吞吐率时间项用总时间还是周期时间混淆
  2. 加速比基准误用（顺序执行时间基准）
  3. 各段时间不等时忽略瓶颈段按等分计算
  4. 效率（时空图面积比）理解偏差
