## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 存储系统 > 存储器扩展
- primary_target_name: DRAM 芯片扩展设计（芯片数/地址分配/片选/刷新）
- question_type: comprehensive
- examination_mode: 设计题——纯文字推导型存储器扩展设计

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=4,K5=2
- difficulty_level: 4
- difficulty_rationale: 主导维度 K4=4，地址线分组与刷新方式的隐含前提较深；K3=3 需走完标准设计流程 4-5 步；K2=3 涉及非平凡计算；整体难度定位为中等偏上

### 结构要求
- sub_question_count: 4
- sub_questions:
  - Q1(计算, 3分): 判断扩展方式 + 计算芯片总数/位扩展数/字扩展数
  - Q2(分析, 3分): 地址线分组——片内地址位数与片选地址位数
  - Q3(分析, 2分): 文字描述片选逻辑
  - Q4(计算, 2分): 异步刷新周期计算
- dependency: Q1→Q2→Q3 串行；Q4 独立
- distractor_strategy: N/A（设计题非选择题）

### 参数约束
- 芯片数据位宽: 1/2/4/8 位，取值需使 位扩展数 ≥ 2
- 芯片地址线位数: 10-14 位（描述芯片存储单元数）
- 目标存储器数据位宽: 8 或 16 位，须为芯片数据位宽的整数倍且商 ≥ 2
- 目标存储器容量: 须为芯片容量的整数倍且商 ≥ 2（保证字扩展）
- 一致性: 位扩展数 = 目标位宽 / 芯片位宽；字扩展数 = 目标容量 / 芯片容量；总片数 = 位扩展数 × 字扩展数
- 刷新行数: 与芯片行地址位数一致（2^m），m 取 7-9
- 刷新间隔: 2ms（DRAM 标准值）
- 约束: 必须为"字位同时扩展"场景（位扩展≥2 且 字扩展≥2），否则考点退化

### 参考经验摘要
- 历史模式: 408 存储器扩展大题——给定芯片规格+目标容量，推导芯片数→地址分配→片选→刷新；本题将画框图替换为纯文字推导
- 难度锚点: K4 为主导（4分），K3 标准流程推演（3分），K2 非平凡计算（3分）
- 典型陷阱:
  1. DRAM 地址线复用——地址线位数可能为内部地址位数的一半
  2. 异步刷新 vs 集中刷新 vs 分散刷新公式混淆
  3. 位扩展不消耗地址线、字扩展才消耗地址线
  4. CPU 地址总线位数覆盖目标存储器地址空间而非芯片地址空间
