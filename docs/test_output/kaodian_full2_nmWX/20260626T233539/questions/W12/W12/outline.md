## 考点
1. **存储器扩展方式判断**：给定小容量 DRAM 芯片和目标存储器容量，判断采用位扩展、字扩展还是字位同时扩展（侧重点：理解三种扩展的适用条件）
2. **芯片数量计算**：根据芯片容量和目标容量推导所需芯片总数及各组芯片的排列方式（侧重点：位扩展数 × 字扩展数 = 总片数）
3. **地址分配与片选逻辑**：将 CPU 地址线划分为片内地址和片选地址，用文字描述片选逻辑（侧重点：地址线分组、译码逻辑的文字表达）
4. **异步刷新周期计算**：根据 DRAM 刷新间隔和刷新行数计算异步刷新周期（侧重点：刷新间隔/行数 = 刷新周期，以及刷新信号周期与存取周期的区分）

## 难度目标
| 维度 | 目标 | 达标理由 |
|------|------|----------|
| K1 基础认知 | 3 | 必须准确记忆三种扩展方式的定义、地址线分组规则、异步刷新公式，概念模糊无法入题 |
| K2 单步代入 | 3 | 涉及芯片数除法、刷新周期除法，数字可能非 2 的幂，需常规代入计算 |
| K3 机制推演 | 3 | 需按"判断扩展方式→算芯片数→分地址线→写片选→算刷新"的标准流程走 4-5 步，路径唯一 |
| K4 条件路由 | 4 | 隐含前提较深：地址线分组时需识别位扩展不影响地址线、字扩展才消耗地址线；刷新需区分集中刷新与异步刷新；可能存在地址线复用（行/列地址）的隐含前提 |
| K5 跨域联动 | 2 | 虽涉及 CPU 地址线与存储器芯片两个层面，但为单向数据传递，无深度耦合 |

## 考察模式
**设计题——纯文字推导型存储器扩展设计**：参考历年 DRAM/SRAM 芯片扩展大题的考察模式，但将画框图替换为文字推导与逻辑描述。理由：slot 硬约束要求纯文字推导非作图，且该模式能有效覆盖芯片数/地址分配/片选/刷新四个核心考点。

## 出题要求
- **题型**：综合题（设计题），总分 10 分
- **总条件数**：3-4 个显式条件（芯片容量参数、目标存储器参数、刷新相关参数）
- **条件设计原则**：
  - 给定小容量 DRAM 芯片的规格（地址线/数据线位数或容量描述）
  - 给定目标存储器容量和数据位宽
  - 给定 DRAM 刷新间隔（如 2ms）和芯片内部结构（刷新行数或行地址位数）
  - 芯片容量与目标容量需设计为"字位同时扩展"（非纯位扩展或纯字扩展），否则考察点退化
- **参数取值范围要求**：
  - 芯片容量与目标容量的比值应保证字扩展≥2 且位扩展≥2
  - 刷新行数应为合理值（与芯片行地址位数匹配，如 2^7=128 行或 2^8=256 行）
  - 刷新间隔取标准值（2ms）

|--------|------|----------|------|-------------|

| 第2问 | 分析 | 地址线分组：片内地址线、片选地址线的位数及各自对应 CPU 地址线的哪几位 | 3 | 依赖第1问结果 |

| 第4问 | 计算 | 异步刷新周期计算（刷新间隔/刷新行数）及刷新信号周期 | 2 | 独立计算，与其他问无依赖 |

## 参数约束
- **芯片数据位宽**：1 位、2 位、4 位或 8 位（取值需使位扩展数≥2）
- **芯片地址容量**：用芯片的地址线位数描述（如 n 位地址线 → 2^n 个存储单元），n 取 10-14
- **芯片数据线位数**：与芯片数据位宽一致
- **目标存储器数据位宽**：8 位或 16 位（需为芯片数据位宽的整数倍，且商≥2）
- **目标存储器地址容量**：需为芯片地址容量的整数倍，且商≥2（保证字扩展）
- **一致性约束**：位扩展数 = 目标数据位宽 / 芯片数据位宽 ≥ 2；字扩展数 = 目标容量 / 芯片容量 ≥ 2；总芯片数 = 位扩展数 × 字扩展数
- **刷新行数**：与芯片行地址位数一致（若芯片行地址为 m 位，刷新行数 = 2^m）
- **刷新间隔**：取 2ms（DRAM 标准）
- **可调自由度**：Question Agent 可在上述范围内自由选择具体数值，但需保证字位同时扩展且计算非平凡

## 参考经验
- **历史模式**：408 历年存储器扩展大题通常给芯片规格+目标容量，要求算芯片数→画连接图→算刷新。本题将"画连接图"替换为"文字描述地址分配与片选逻辑"
- **难度锚点**：K4 为本题主导维度（4 分），难点在于地址线分组的隐含前提和刷新方式的辨析
- **典型陷阱**：
  1. DRAM 地址线复用（行/列地址分时传送）——地址线位数可能是内部地址位数的一半，影响片内地址线分配
  2. 异步刷新 vs 集中刷新 vs 分散刷新的公式混淆
  3. 位扩展不消耗地址线、字扩展才消耗地址线——常见错误是将位扩展也算入地址线
  4. CPU 地址总线位数需覆盖整个目标存储器地址空间，而非芯片地址空间
