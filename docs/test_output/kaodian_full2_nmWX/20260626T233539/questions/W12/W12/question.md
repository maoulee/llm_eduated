# 存储器扩展设计题（纯文字推导）

## 题干

某计算机主存采用 DRAM 芯片构成，CPU 按字节编址，地址总线宽度为 16 位（A15～A0），数据总线宽度为 8 位。

现需要用 **16K×4 位的 DRAM 芯片** 构建一个容量为 **64K×8 位** 的存储器模块。

> **DRAM 芯片说明：**
> - 该 DRAM 芯片内部有 14 位地址（2¹⁴ = 16K 个存储单元），采用**地址线复用**方式，行地址与列地址各占一半，通过外部地址引脚分两次输入。
> - 该 DRAM 芯片内部存储体按行（行地址位数）组织刷新，刷新间隔为 **2ms**。
> - 刷新以行为单位，每次刷新一行。

---

## 问题

### 第(1)题（计算，3分）

判断本题应采用哪种扩展方式（位扩展 / 字扩展 / 字位同时扩展），并计算：
- 位扩展数；
- 字扩展数；
- 所需芯片总数。

要求写出计算过程。

### 第(2)题（分析，3分）

确定该存储器模块的地址线分组：
- 片内地址位数（用于芯片内部寻址的地址线）；
- 片选地址位数（用于区分各芯片组的地址线）；
- 若考虑 DRAM 地址线复用，该 DRAM 芯片对外需要多少根地址引脚？

要求说明各部分地址线的对应关系（如 A15～A0 中哪些用作片内地址，哪些用作片选地址）。

### 第(3)题（分析，2分）

用文字描述该存储器模块的片选逻辑：当 CPU 给出某地址时，如何根据片选地址位译码选择对应的芯片组。要求说明每一组芯片被选中的地址范围条件。

### 第(4)题（计算，2分）

若该存储器采用**异步刷新**方式，计算：
- 该 DRAM 芯片需要刷新的行数；
- 异步刷新的刷新周期（即两次刷新操作之间的时间间隔）。

要求写出计算过程。

---

## 场景规则（本题成立 ⇔ 以下参数间约束全部满足）

以下约束为参数间的数学关系，与具体答案值无关，换参数仍成立：

1. **位扩展数 = 目标存储器数据位宽 / 芯片数据位宽**，且结果须为整数且 ≥ 2。
2. **字扩展数 = 目标存储器存储单元数 / 芯片存储单元数**，且结果须为整数且 ≥ 2。
3. **总片数 = 位扩展数 × 字扩展数**。
4. **片内地址位数 = log₂(芯片存储单元数)**；**片选地址位数 = log₂(目标存储器存储单元数) − 片内地址位数**；且 **2^(片选地址位数) = 字扩展数**。
5. **片内地址位数 + 片选地址位数 = log₂(目标存储器存储单元数)**（即 CPU 地址总线宽度覆盖目标存储器地址空间）。
6. **DRAM 地址线复用**：芯片对外地址引脚数 = 内部地址位数 / 2（行地址 = 列地址 = 内部地址位数 / 2），且为整数。
7. **刷新行数 = 2^(行地址位数)**，行地址位数 = 内部地址位数 / 2。
8. **异步刷新周期 = 刷新间隔（2ms）/ 刷新行数**。
9. **本题必须为"字位同时扩展"**：位扩展数 ≥ 2 且 字扩展数 ≥ 2（否则考点退化）。
