# 水平型微指令格式设计与控存容量

## 题干

某 CPU 采用微程序控制器，使用**水平型微指令**和**字段直接编码（分段直接编码）**方式组织操作控制字段。经分析，该 CPU 共有 **12 个互斥微命令**，按互斥关系分为以下 **4 组**：

| 互斥组 | 组内微命令 | 组内微命令数 |
|--------|-----------|-------------|
| 第一组 | a₁, a₂, a₃, a₄ | 4 |
| 第二组 | b₁, b₂, b₃ | 3 |
| 第三组 | c₁, c₂, c₃ | 3 |
| 第四组 | d₁, d₂ | 2 |

> 说明：同一组内的微命令互斥（同一微周期内最多发出其中一个），不同组的微命令可以并行。

此外，该微程序控制器有 **3 个判别测试条件**（记为 T₁、T₂、T₃），微指令采用**断定方式**形成下一条微指令地址，下地址字段宽度为 **9 位**。

请回答以下问题：

### 问题 1（4 分）

采用字段直接编码，为操作控制字段的每个子字段分配位数，要求：
1. 分别计算四个互斥组各需要的子字段位数；
2. 计算操作控制字段的总位数。

### 问题 2（3 分）

1. 确定判别测试字段（P 字段）的位数；
2. 给出该微指令的完整格式（标明各字段名称及位数），并计算微指令字长。

### 问题 3（3 分）

计算该控制存储器（控存）的最大容量（以 bit 为单位，写出计算过程）。

---

## 场景规则（本题成立条件）

以下约束为参数间的结构性关系，与具体答案值无关，换参数仍成立：

1. **无操作状态预留**：每个互斥组有 n 个微命令时，该组子字段位数 = ⌈log₂(n+1)⌉（其中 +1 对应"无操作"状态）。即：组内 n 个微命令 + 1 个无操作 = n+1 种状态 → 编码位数 = ⌈log₂(n+1)⌉。
2. **操作控制字段总位数** = 各互斥组子字段位数之和。
3. **P 字段位数** = ⌈log₂(判别测试条件数 + 1)⌉（其中 +1 对应"无条件转移"状态，即无判别测试）。
4. **微指令字长** = 操作控制字段位数 + P 字段位数 + 下地址字段位数。
5. **控存最大容量** = 微指令字长 × 2^(下地址字段位数)（下地址字段宽度决定了控存中可寻址的微指令单元数）。

### 通过条件（可机检特征）

- ✅ 四个互斥组各自的位数分别为 ⌈log₂(n+1)⌉（n 为各组微命令数），**不可用 ⌈log₂(n)⌉**（漏算无操作状态为常见错误）。
- ✅ 操作控制字段总位数 = 四组位数之和。
- ✅ P 字段位数 = ⌈log₂(判别条件数+1)⌉。
- ✅ 微指令字长 = 操作控制字段位数 + P 字段位数 + 下地址字段位数。
- ✅ 控存最大容量 = 微指令字长 × 2^(下地址字段位数)，**不可用操作控制字段位数替代下地址字段位数**（混淆寻址范围为常见错误）。
