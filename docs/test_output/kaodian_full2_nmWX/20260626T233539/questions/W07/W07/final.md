# Cache 命中率与平均访问时间计算

## 题目

某计算机的存储系统采用"Cache—主存"两级存储层次结构。已知：

- Cache 命中时间 $t_c = 2$ 个时钟周期。
- 主存访问周期 $t_m = 40$ 个时钟周期。
- 当 Cache 缺失时，需要访问主存，**缺失代价为 $t_m$ 个时钟周期**（即缺失时在 Cache 中消耗 $t_c$ 后转向主存，主存返回需 $t_m$ 个时钟周期，不含已消耗的 $t_c$）。
- 在某段程序执行期间，处理器共发起 $N = 1000$ 次访存请求，其中 Cache 命中 $H = 950$ 次。

请回答以下问题：

### 第（1）题（3 分）

计算该程序执行期间 Cache 的命中率 $h$ 和缺失率 $h_{miss}$。（用小数表示，保留两位小数）

### 第（2）题（4 分）

（a）计算该存储系统的**平均访问时间** AMAT（单位：时钟周期）。

（b）定义 Cache 效率 $e = \dfrac{t_c}{\text{AMAT}}$，计算该系统的 Cache 效率 $e$。（用小数表示，保留四位小数）

> 提示：AMAT = $t_c + (1-h) \times t_m$。

### 第（3）题（3 分）

为降低缺失代价，现增设一块**二级 Cache（L2 Cache）**。当 L1 Cache 缺失时，先访问 L2 Cache；L2 Cache 的命中时间为 $t_{c2} = 8$ 个时钟周期，L2 Cache 的**局部命中率**为 $h_2 = 0.80$（即在 L1 缺失的请求中，有 80% 能在 L2 命中）；仅当 L2 也缺失时才访问主存。

L2 Cache 的缺失代价定义同 L1：在 L2 缺失时额外消耗主存周期 $t_m$。

计算增设 L2 Cache 后该存储系统的平均访问时间 $\text{AMAT}_{2}$（单位：时钟周期），并与第（2）题结果比较，说明 L2 Cache 是否降低了平均访问时间。

## 参考答案

| 项目 | 结果 |
|------|------|
| 命中率 $h$ | $0.95$ |
| 缺失率 $h_{miss}$ | $0.05$ |
| AMAT | $4$ 个时钟周期 |
| Cache 效率 $e$ | $0.5000$ |
| $\text{AMAT}_2$（增设 L2 后） | $2.8$ 个时钟周期 |
| 是否降低 | 是（$4 \to 2.8$） |

## 解析

### 第（1）题（3 分）

**命中率 $h$：**

$$h = \frac{H}{N} = \frac{950}{1000} = 0.95$$

**缺失率 $h_{miss}$：**

$$h_{miss} = 1 - h = 1 - 0.95 = 0.05$$

验算：$h + h_{miss} = 0.95 + 0.05 = 1$ ✓

---

### 第（2）题（4 分）

#### （a）平均访问时间 AMAT

由公式 $\text{AMAT} = t_c + (1 - h) \times t_m$：

$$1 - h = 1 - 0.95 = 0.05 = \frac{1}{20}$$

$$\text{AMAT} = 2 + \frac{1}{20} \times 40 = 2 + 2 = 4 \text{（时钟周期）}$$

验算：用等价写法 $h \times t_c + (1-h) \times (t_c + t_m) = 0.95 \times 2 + 0.05 \times 42 = 1.9 + 2.1 = 4$ ✓ 两种写法结果一致。

> **陷阱提示：** 题目明确缺失代价为 $t_m$（不含已消耗的 $t_c$）。若误认为缺失代价 $= t_c + t_m$，则会错误地算出 $\text{AMAT} = t_c + (1-h)(t_c+t_m) = 2 + 0.05 \times 42 = 4.1$，多算了一次 $t_c$。

#### （b）Cache 效率 $e$

$$e = \frac{t_c}{\text{AMAT}} = \frac{2}{4} = 0.5000$$

验算：$0 < e = 0.5000 \leq 1$ ✓

> **陷阱提示：** 这里考查的是 Cache 效率 $e = t_c/\text{AMAT}$，而非加速比。若误算加速比 $S = t_m/\text{AMAT} = 40/4 = 10$，则答错。

---

### 第（3）题（3 分）

增设 L2 Cache 后，当 L1 缺失时先访问 L2（代价 $t_{c2}$），L2 仍缺失才访问主存（代价 $t_m$）。

**L1 缺失后的平均额外代价：**

$$t_{c2} + (1 - h_2) \times t_m = 8 + (1 - 0.80) \times 40 = 8 + 0.20 \times 40 = 8 + 8 = 16 \text{（时钟周期）}$$

**两级 Cache 系统的平均访问时间：**

$$\text{AMAT}_2 = t_c + (1 - h) \times [t_{c2} + (1 - h_2) \times t_m]$$

$$= 2 + 0.05 \times 16 = 2 + 0.8 = 2.8 \text{（时钟周期）}$$

验算：$\text{AMAT}_2 = 2.8 \geq t_c = 2$ ✓

**对比结论：**

$$\text{AMAT}_2 = 2.8 < \text{AMAT} = 4$$

增设 L2 Cache **降低了**平均访问时间，从 $4$ 个时钟周期降至 $2.8$ 个时钟周期，降幅为 $1.2$ 个时钟周期（下降 $30\%$）。
