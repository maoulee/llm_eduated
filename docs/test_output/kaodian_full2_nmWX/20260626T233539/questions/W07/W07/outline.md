## 考点
- **核心考点**：Cache 平均访问时间（AMAT）计算。考察侧重点：命中率、缺失代价与命中时间的关系，AMAT 公式的正确应用。
- **辅助考点**：Cache 效率定义。考察侧重点：效率 = 命中时间 / 平均访问时间，或加速比概念。
- **辅助考点**：Cache 缺失率与命中率的转换、缺失代价的含义（是否包含命中时间）。

## 难度目标
- K1 = 3（标准）：必须准确记忆 AMAT 公式（平均访问时间 = 命中时间 + 缺失率 × 缺失代价）以及 Cache 效率的定义才能入题。
- K2 = 3（标准）：需代入常规公式计算，可能涉及非 2 的幂次或小数运算，单步可算但非平凡。
- K3 = 3（标准）：需按固定流程走完 3-5 步（命中率→AMAT→效率→比较分析），路径唯一，本题为 K3 主导维度。
- K4 = 2（较低）：存在常规注意点——缺失代价的定义（是否已包含命中时间）、命中率与缺失率的转换，408 考生基本不会踩坑但需留意。
- K5 = 2（较低）：涉及 Cache 与主存两个层次，但数据单向传递（主存周期作为 Cache 缺失代价的输入），无实质性状态耦合。

K3 主导理由：本题核心是从给定参数出发，按 AMAT 公式链依次计算命中率、平均访问时间、效率，是典型的固定流程多步推演，步数在 3-5 步区间，路径唯一。

## 考察模式
**计算题——给定 Cache 命中率/缺失代价/主存周期，求平均访问时间与效率**

理由：该考察模式直接覆盖 slot 指定的 examination_mode，是 Cache 章节最经典的综合应用模式。通过给定具体参数让学生走完"命中率→AMAT→效率"的完整计算链，既能考查公式记忆（K1），又能考查多步计算准确性（K2/K3）。在综合题框架下可拆分为递进式子问题，第一问给台阶（单步计算），后续问逐步加深。

## 出题要求
- 题型：综合题（计算题），总分 10 分
- 总条件数：3-5 个显式条件（Cache 参数 + 主存参数）
- 条件设计原则：
  - 需给出 Cache 命中时间（或 Cache 访问周期）
  - 需给出主存访问周期（作为缺失代价的基础）
  - 需给出命中率（或可推导命中率的访问序列/地址分布）
  - 可附加第二组参数用于对比分析（如不同命中率下的效率比较）
- 参数取值范围要求：
  - 命中时间/Cache 周期：1-5 个时钟周期
  - 主存周期：Cache 周期的 5-20 倍（保证 Cache 有意义）
  - 命中率：0.80-0.98（实际合理范围，避免极端值使计算平凡）
  - 如用访问序列给命中率，序列长度 8-16 次访问

## 子问题规划
- **第 1 问（3 分）— 计算（命中率或单步 AMAT）**：
  - 类型：单步代入计算
  - 考察目标：根据给定条件计算 Cache 命中率（若给访问序列）或直接用给定的命中率代入 AMAT 公式算出平均访问时间
  - 与后续问的关系：为第 2 问提供基础数值
  - 分值：3 分

- **第 2 问（4 分）— 计算（平均访问时间 + 效率）**：
  - 类型：多步公式代入计算
  - 考察目标：在第 1 问基础上，计算 Cache 效率（或加速比），需正确应用效率定义并完成连续计算
  - 与前后问关系：依赖第 1 问结果，为第 3 问提供对比基准
  - 分值：4 分

- **第 3 问（3 分）— 分析（参数变化影响）**：
  - 类型：分析/计算
  - 考察目标：给定参数变化（如命中率提高、增加二级 Cache），分析平均访问时间的变化，体现对 AMAT 各分量影响的理解
  - 与前问关系：基于第 2 问的计算框架，换参数重新计算并比较
  - 分值：3 分

## 参数约束
- **Cache 命中时间（t_c）**：取值 1-5 时钟周期，整数
- **主存访问周期（t_m）**：取值 t_c 的 5-20 倍，整数
- **缺失代价定义**：题干需明确缺失代价是指"缺失时额外付出的时间"还是"缺失时的总访问时间"，二者关系为：总缺失时间 = t_c + t_m 或直接等于 t_m，取决于 Cache 结构假设。建议题干明确为"缺失时需访问主存，代价为 t_m 个时钟周期"，此时 AMAT = t_c + (1-h) × t_m
- **命中率（h）**：若直接给定，取 0.80-0.98；若由访问序列推导，序列需设计为可产生非平凡命中率（非 0、非 1、非简单分数）
- **第 3 问变化参数**：可设二级 Cache 参数，或改变命中率，新参数须与前问保持量级一致以便比较
- **参数间一致性约束**：所有时间参数须统一为同一单位（时钟周期），命中率须为小数或百分数且在合理范围

## 参考经验
- **历史模式**：Cache 综合题常采用"给参数→算 AMAT→算效率/加速比→改变参数分析"的递进结构，每问层层依赖
- **难度锚点**：标准难度（target_difficulty=3）的 Cache 计算题，K3 通常在 3-4，K1/K2 在 3，避免 K4 过高（陷阱不宜过深）
- **典型陷阱**：
  1. 缺失代价是否包含命中时间——学生常混淆 AMAT = h×t_c + (1-h)×t_m 与 AMAT = t_c + (1-h)×t_m 两种公式形式
  2. 效率定义——效率 = t_c / AMAT 还是加速比 = 无Cache时间 / 有Cache时间，两种定义需区分
  3. 百分数与小数混用导致计算错误
