# Cache 命中率与平均访问时间计算 — 解答

## 第（1）题（3 分）

**命中率 $h$：**

$$h = \frac{H}{N} = \frac{950}{1000} = 0.95$$

**缺失率 $h_{miss}$：**

$$h_{miss} = 1 - h = 1 - 0.95 = 0.05$$

> **验算（场景规则1）：** $h + h_{miss} = 0.95 + 0.05 = 1$ ✓

---

## 第（2）题（4 分）

### （a）平均访问时间 AMAT

由公式 $\text{AMAT} = t_c + (1 - h) \times t_m$：

$$1 - h = 1 - 0.95 = 0.05 = \frac{1}{20}$$

$$\text{AMAT} = 2 + \frac{1}{20} \times 40 = 2 + 2 = 4 \text{（时钟周期）}$$

> **验算（场景规则2）：** 用等价写法 $h \times t_c + (1-h) \times (t_c + t_m) = 0.95 \times 2 + 0.05 \times 42 = 1.9 + 2.1 = 4$ ✓ 两种写法结果一致。

> **注意陷阱：** 题目明确缺失代价为 $t_m$（不含已消耗的 $t_c$）。若误认为缺失代价 $= t_c + t_m$，则会错误地算出 $\text{AMAT} = t_c + (1-h)(t_c+t_m) = 2 + 0.05 \times 42 = 4.1$，多算了一次 $t_c$。

### （b）Cache 效率 $e$

$$e = \frac{t_c}{\text{AMAT}} = \frac{2}{4} = 0.5000$$

> **验算（场景规则3）：** $0 < e = 0.5000 \leq 1$ ✓

> **注意陷阱：** 这里考查的是 Cache 效率 $e = t_c/\text{AMAT}$，而非加速比。若误算加速比 $S = t_m/\text{AMAT} = 40/4 = 10$，则答错。

---

## 第（3）题（3 分）

增设 L2 Cache 后，当 L1 缺失时先访问 L2（代价 $t_{c2}$），L2 仍缺失才访问主存（代价 $t_m$）。

**L1 缺失后的平均额外代价：**

$$t_{c2} + (1 - h_2) \times t_m = 8 + (1 - 0.80) \times 40 = 8 + 0.20 \times 40 = 8 + 8 = 16 \text{（时钟周期）}$$

**两级 Cache 系统的平均访问时间：**

$$\text{AMAT}_2 = t_c + (1 - h) \times [t_{c2} + (1 - h_2) \times t_m]$$

$$= 2 + 0.05 \times 16 = 2 + 0.8 = 2.8 \text{（时钟周期）}$$

> **验算（场景规则4）：** $\text{AMAT}_2 = 2.8 \geq t_c = 2$ ✓

### 对比结论

$$\text{AMAT}_2 = 2.8 < \text{AMAT} = 4$$

增设 L2 Cache **降低了**平均访问时间，从 $4$ 个时钟周期降至 $2.8$ 个时钟周期，降幅为 $1.2$ 个时钟周期（下降 $30\%$）。

> **验算（场景规则6）：** $\text{AMAT}_2 < \text{AMAT}$ ✓（$2.8 < 4$）

---

## 汇总答案

| 项目 | 结果 |
|------|------|
| 命中率 $h$ | $0.95$ |
| 缺失率 $h_{miss}$ | $0.05$ |
| AMAT | $4$ 个时钟周期 |
| Cache 效率 $e$ | $0.5000$ |
| $\text{AMAT}_2$（增设 L2 后） | $2.8$ 个时钟周期 |
| 是否降低 | 是（$4 \to 2.8$） |
