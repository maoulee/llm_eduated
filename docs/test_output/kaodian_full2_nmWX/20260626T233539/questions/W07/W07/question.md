# Cache 命中率与平均访问时间计算

## 题目

某计算机的存储系统采用"Cache—主存"两级存储层次结构。已知：

- Cache 命中时间 $t_c = 2$ 个时钟周期。
- 主存访问周期 $t_m = 40$ 个时钟周期。
- 当 Cache 缺失时，需要访问主存，**缺失代价为 $t_m$ 个时钟周期**（即缺失时在 Cache 中消耗 $t_c$ 后转向主存，主存返回需 $t_m$ 个时钟周期，不含已消耗的 $t_c$）。
- 在某段程序执行期间，处理器共发起 $N = 1000$ 次访存请求，其中 Cache 命中 $H = 950$ 次。

请回答以下问题：

### 第（1）题（3 分）

计算该程序执行期间 Cache 的命中率 $h$ 和缺失率 $h_{miss}$。（用小数表示，保留两位小数）

### 第（2）题（4 分）

（a）计算该存储系统的**平均访问时间** AMAT（单位：时钟周期）。

（b）定义 Cache 效率 $e = \dfrac{t_c}{\text{AMAT}}$，计算该系统的 Cache 效率 $e$。（用小数表示，保留四位小数）

> 提示：AMAT = $t_c + (1-h) \times t_m$。

### 第（3）题（3 分）

为降低缺失代价，现增设一块**二级 Cache（L2 Cache）**。当 L1 Cache 缺失时，先访问 L2 Cache；L2 Cache 的命中时间为 $t_{c2} = 8$ 个时钟周期，L2 Cache 的**局部命中率**为 $h_2 = 0.80$（即在 L1 缺失的请求中，有 80% 能在 L2 命中）；仅当 L2 也缺失时才访问主存。

L2 Cache 的缺失代价定义同 L1：在 L2 缺失时额外消耗主存周期 $t_m$。

计算增设 L2 Cache 后该存储系统的平均访问时间 $\text{AMAT}_{2}$（单位：时钟周期），并与第（2）题结果比较，说明 L2 Cache 是否降低了平均访问时间。

## 设计说明（供审核用）

### 考察意图

| 子问 | 考察点 | 对应 K 目标 |
|------|--------|-------------|
| Q1 | 命中率/缺失率基本计算 | K1（公式记忆）、K2（代入） |
| Q2 | AMAT 公式应用 + Cache 效率定义 | K3（多步公式链）、K4（陷阱：效率 ≠ 加速比） |
| Q3 | 两级 Cache 的 AMAT 递推 + 对比分析 | K3（递推公式）、K5（层次结构理解） |

### 陷阱与干扰设计

1. **缺失代价是否含命中时间**：题干明确"缺失代价为 $t_m$，不含已消耗的 $t_c$"，学生若混淆则 AMAT = $t_c + (1-h)\times(t_c + t_m)$（错误，多算一次 $t_c$）。
2. **效率 vs 加速比**：题目考查的是 $e = t_c/\text{AMAT}$，学生可能误算加速比 $S = t_m/\text{AMAT}$。
3. **百分数与小数混用**：命中率须用小数代入。
4. **二级 Cache 局部命中率**：$h_2$ 是 L1 缺失中的命中率，不是全局命中率，学生可能错误叠加。

### 场景规则（通过条件 / 可机检约束）

以下约束与具体答案值无关，换参数仍成立，供 gen.py 翻译为 assert：

1. **命中率一致性**：$h = H / N$ 且 $h + h_{miss} = 1$。
2. **AMAT 公式一致性**：$\text{AMAT} = t_c + (1 - h) \times t_m$，且 AMAT 的两种等价写法须相等：$h \times t_c + (1-h) \times (t_c + t_m) = t_c + (1-h) \times t_m$。
3. **效率定义**：$e = t_c / \text{AMAT}$，且 $0 < e \leq 1$（AMAT 恒 $\geq t_c$）。
4. **二级 Cache AMAT 递推**：$\text{AMAT}_2 = t_c + (1 - h) \times [t_{c2} + (1 - h_2) \times t_m]$，且 $\text{AMAT}_2$ 须 $\geq t_c$（最差不低于命中时间）。
5. **参数量级约束**：$t_m = 20 \times t_c$（主存周期为命中时间的 20 倍），$0.8 \leq h \leq 0.98$。
6. **L2 改善性约束**：$\text{AMAT}_2 < \text{AMAT}$（增设 L2 后平均访问时间应下降，否则参数设计有误）。
