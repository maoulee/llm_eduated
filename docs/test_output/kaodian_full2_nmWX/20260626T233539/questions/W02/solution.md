## 第 2 题解析

**答案**：

| 比较项目 | SRAM（静态随机存储器） | DRAM（动态随机存储器） |
|---------|----------------------|----------------------|
| **存储原理** | 利用触发器（双稳态电路）存储信息，只要不断电信息不会丢失 | 利用电容上的电荷存储信息，电容会漏电导致信息逐渐丢失 |
| **是否需要刷新** | 不需要刷新 | 需要定期刷新（通常 2ms 内刷新一遍） |
| **读写速度** | 速度快（存取时间短） | 速度较慢（存取时间较长） |
| **集成度与成本** | 集成度低、功耗较大、成本高 | 集成度高、功耗低、成本较低 |
| **主要用途** | 用于 CPU **高速缓存（Cache）** | 用于计算机**主存（内存条）** |

**解析**：本题从四个维度考察 SRAM 与 DRAM 的区别，属于高频对照型记忆题。核心记忆线索：SRAM = 触发器 = 不刷新 = 快 = 贵 = Cache；DRAM = 电容 = 要刷新 = 慢 = 便宜 = 主存。常见错误：混淆两者存储原理（将 SRAM 说成电容存储）；遗漏"刷新"这一 DRAM 的关键特征；搞反速度或用途。
