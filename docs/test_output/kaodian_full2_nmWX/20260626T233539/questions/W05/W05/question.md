# 变形补码加减运算与溢出判断

## 题目

已知两个定点小数：

$$x = \dfrac{11}{16}, \quad y = \dfrac{7}{16}$$

采用 **4 位小数部分**（加上 2 位符号位，共 6 位）的 **变形补码（双符号位补码）** 表示。

**变形补码定义**：正数符号位为 `00`，负数符号位为 `11`，小数部分按补码规则取。

---

### 第 (1) 题（2 分）

分别求 $x$ 和 $y$ 的变形补码 $[x]_\text{变补}$ 与 $[y]_\text{变补}$。

---

### 第 (2) 题（4 分）

利用变形补码计算 $x + y$，写出完整的加法运算过程，并依据**双符号位的判定规则**判断是否溢出。若溢出，请指明是上溢还是下溢。

---

### 第 (3) 题（4 分）

利用变形补码计算 $x - y$。

要求：
1. 先求 $[-y]_\text{变补}$；
2. 通过 $[x]_\text{变补} + [-y]_\text{变补}$ 完成减法运算，写出完整运算过程；
3. 依据双符号位判定规则判断是否溢出。

---

## 设计意图

| 维度 | 说明 |
|------|------|
| K1（知识记忆） | 变形补码的定义与编码规则——正数 00、负数 11，小数部分补码 |
| K2（规则运用） | 将定点小数转换为变形补码，$[-y]_\text{变补}$ 的求法（全部位取反加 1） |
| K3（流程推演） | 变形补码加减运算的完整流程（求码→加减→符号位判溢出），3-5 步标准流程 |
| K4（综合分析） | 溢出类型的区分——上溢（符号位 01）与下溢（符号位 10）的含义辨析 |
| 考察陷阱 | $x - y$ 时忘记先求 $[-y]_\text{变补}$；将变形补码与普通补码混淆；溢出判断时未能正确区分 01 上溢与 10 下溢 |

## 场景规则（通过条件）

本题成立需满足以下参数间约束（与具体答案值无关，换参数仍应成立）：

1. **精确可表示性**：$x$ 和 $y$ 均可用 4 位二进制小数精确表示（即 $x \times 16$ 和 $y \times 16$ 均为整数），保证变形补码编码无舍入误差。

2. **溢出需求**：$x + y$ 与 $x - y$ 两组运算中，**恰好一组发生溢出**（变形补码运算结果双符号位不一致，即 `01` 或 `10`），**另一组不溢出**（双符号位一致，即 `00` 或 `11`）。此处 $x = 11/16,\, y = 7/16$ 满足：$x+y > 1$（上溢），$|x-y| < 1$（不溢出）。

3. **变形补码运算一致性**：$[-y]_\text{变补}$ 由 $[y]_\text{变补}$ 的所有位（含双符号位）取反后最低位加 1 得到；$x - y$ 的运算结果应满足 $[x-y]_\text{变补} = [x]_\text{变补} + [-y]_\text{变补}$（取溢出后的 6 位结果中有效的双符号位用于判断）。

4. **溢出判定可区分**：对溢出的那组运算，运算结果的两个符号位取值分别为 `0` 和 `1`（即 `01`，上溢），而非 `10`（下溢）；不溢出的那组运算，两个符号位取值相同。这种区分使得学生必须正确编码、正确运算、正确判读，不能仅凭"会算加法"得分。
