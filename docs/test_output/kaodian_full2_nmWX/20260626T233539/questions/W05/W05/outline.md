## 考点
- **核心考点**：变形补码（双符号位补码）的表示与加减运算
  - 考察侧重点：定点小数的变形补码编码规则、[x+y]变补 与 [x-y]变补 的运算步骤
- **核心考点**：变形补码的溢出判断
  - 考察侧重点：双符号位的取值含义（00正、11负、01上溢、10下溢），通过符号位状态判断溢出

## 难度目标
- **K1=3（标准）**：必须准确记忆变形补码的定义（双符号位），以及溢出判断规则（双符号位不一致即溢出）。不记忆变形补码编码规则无法入题。
- **K2=3（标准）**：需执行定点小数的补码转换与加减运算，涉及非2幂次的小数表示，存在算错风险。
- **K3=3（标准）**：从原始小数到最终溢出判断需走完标准流程：①化小数为二进制定点小数 → ②求变形补码 → ③执行加减运算 → ④判读双符号位，共3-5步，路径唯一。
- **K4=2（较低）**：存在常规注意点（x-y 需对 [y]变补 连同符号位一起求补得 [-y]变补），属408考生应掌握的标准步骤，非隐藏陷阱。
- **K5=1（微弱）**：单一知识点（变形补码运算）内部解决，不涉及跨系统联动。

**难度定位理由**：K3为主导维度（目标3），整体难度3。变形补码加减运算流程清晰但步骤完整，溢出判断需准确运用双符号位规则，符合标准难度综合题定位。

## 考察模式
- **考察模式**：计算题——给定两个定点小数，用变形补码计算 x+y 和 x-y 并判断溢出
- **理由**：此模式直接考察变形补码的完整运算链路（编码→运算→判溢出），是408组成原理数据表示章节的经典考法。流程明确、步骤可分，适合10分综合题的结构化设问。

## 出题要求
- 题型：综合计算题（计算题）
- 总分：10分
- 条件设计原则：
  - 给出两个定点小数 x 和 y（十进制或分数形式）
  - 题目要求写出变形补码表示、运算过程和溢出判断结果
  - 参数需满足：x+y 和 x-y 中至少一组产生溢出（双符号位不一致），另一组不溢出，以考察学生对溢出判断的完整掌握
- 参数取值范围要求：
  - x、y 均为定点小数，绝对值在变形补码表示范围内
  - 至少一组运算结果溢出（即结果超出可表示范围），使溢出判断有意义
  - 另一组运算结果不溢出，需正确写出结果的变形补码和真值

## 子问题规划

| 子问题 | 类型 | 考察目标 | 分值 | 与前后问关系 |
|--------|------|----------|------|-------------|
| (1) | 计算 | 求出 x 和 y 的变形补码（双符号位表示） | 2分 | 后续运算的基础，独立但必须先完成 |
| (2) | 计算 | 用变形补码计算 [x+y]变补，写出运算过程，判断是否溢出，给出结果真值 | 4分 | 依赖(1)的结果 |
| (3) | 计算 | 用变形补码计算 [x-y]变补（即 [x+(-y)]变补），写出运算过程，判断是否溢出，给出结果真值 | 4分 | 依赖(1)的结果；(2)与(3)并行但各自独立 |

**设问依赖关系**：(1)→(2),(3)，混合串并行结构。(2)和(3)分别考察加法和减法路径，其中至少一问涉及溢出判断。

## 参数约束
- **x（定点小数）**：十进制或分数形式，绝对值范围 (0.1, 0.8)，使得与 y 相加或相减时可能溢出
- **y（定点小数）**：十进制或分数形式，绝对值范围 (0.1, 0.8)，与 x 符号组合需保证至少一组运算溢出
- **一致性约束**：
  - x 和 y 的符号组合必须使得 |x+y| 或 |x-y| 中至少一个 > 最大可表示值（即 >1 或 <−1），以产生溢出
  - 另一组运算不溢出，需能写出正确的变形补码结果
  - x、y 的二进制表示不宜过长（建议小数部分4-6位），避免计算过于繁琐，保持K2=3标准难度
- **可调自由度**：
  - 具体数值由 Question Agent 确定
  - 可选择正+正溢出、负+负溢出、正-负溢出、负-正溢出等多种组合，Question Agent 自行选取
  - 十进制或分数表示形式不限

## 参考经验
- 变形补码运算为408经典考法，核心考察点为双符号位的编码与溢出判读
- 典型陷阱：学生可能忽略 x-y 需先求 [-y]变补；可能混淆变形补码与普通补码的符号位数
- 难度锚点：K3=3 为标准流程推演，步数适中，适合中等难度综合题
- 溢出判断的两种情况（01上溢/10下溢）均应有机会被考察，但本题至少考察其中一种即可
