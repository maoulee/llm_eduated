## 出题契约

### 基本信息
- target_subject: 计算机组成原理
- target_family: 指令系统 > 扩展操作码
- primary_target_name: 扩展操作码编码下零地址指令最大条数
- question_type: comprehensive
- examination_mode: 计算题——给定指令字长/地址码位数/各地址指令条数，计算零地址指令最大条数

### 难度目标
- k_target: K1=3,K2=3,K3=3,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: K2为主导维度（slot指定k_dominant=K2）。核心难度来自多步乘减运算（K2=3）和固定流程的多步串行推演（K3=3）。概念记忆需求标准（K1=3），无深层隐含陷阱（K4=2），不跨域（K5=1）。整体难度3，符合slot的target_difficulty=3。

### 结构要求
- sub_question_count: 3
- sub_question_breakdown:
  - Q1(3分): 分析/简答——扩展操作码编码原理，操作码向地址码字段扩展的机制
  - Q2(5分): 计算——逐级递推求零地址指令最大条数（核心问）
  - Q3(2分): 分析——某级指令条数变化对零地址数量的影响
- distractor_strategy: 不适用（综合题非选择题）
- condition_count: 3-4

### 参数约束
- 指令字长 L: 16位（固定）
- 每个地址码位数 a: 4或5位（可统一或分组）
- 二地址指令条数 N2: 满足 N2 < 2^(L-2a) 且 2^(L-2a)-N2 不为2的幂
- 一地址指令条数 N1: 满足 N1 < (2^(L-2a)-N2)×2^a 且剩余不为2的幂
- 一致性约束:
  - 剩余前缀1 = 2^(L-2a) - N2 > 0
  - 剩余前缀2 = 剩余前缀1 × 2^a - N1 > 0
  - 零地址最大条数 N0 = 剩余前缀2 × 2^a
- 可调自由度: Question Agent 自由选择 N2、N1、a 的具体值，仅需满足上述约束和非平凡要求

### 参考经验摘要
- 历史模式: 扩展操作码最大条数计算为408高频经典考法，流程固定（逐级扣除→乘扩展位→得下级空间）
- 难度锚点: K2为主导（多步乘减），K3辅助（固定流程多步推演），整体difficulty=3
- 典型陷阱: ①直接用全部操作码位计算忽略逐级预留；②某层忘记乘地址码扩展位数；③混淆固定操作码与可扩展操作码
