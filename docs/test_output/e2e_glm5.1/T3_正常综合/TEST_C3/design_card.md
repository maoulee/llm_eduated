## core_knowledge_intent
- must_test:
  1. AVL 树按 BST 规则插入新节点后，从插入点向上回溯，定位最小不平衡子树（即离插入点最近的不平衡祖先节点为根的子树）
  2. 根据最小不平衡子树的根节点与其较高子树所在方向、以及较高子树的较高子树所在方向，联合判定旋转类型（LL / RR / LR / RL），并执行对应旋转
  3. 旋转完成后正确更新各节点的父子指针关系及平衡因子，确保整棵树重新满足 AVL 平衡条件
- must_not_shift_to:
  1. AVL 树的时间复杂度 O(log n) 证明或查找性能分析
  2. AVL 树的删除操作及其可能引发的级联旋转
- coverage_success_criteria:
  1. 学生能准确指出最小不平衡子树的根节点，并正确判定旋转类型（尤其能区分 LR/RL 双旋与 LL/RR 单旋）
  2. 学生能正确执行旋转并给出旋转后完整的树结构（父子关系正确、所有节点平衡因子绝对值 ≤ 1）

## design_rationale
本题考察 AVL 树的插入与旋转维护，选择"结构操作与状态维护模拟"模式，因为 AVL 旋转的本质是多步串行状态更新——学生必须先按 BST 规则正确插入元素，再从插入点回溯计算平衡因子定位最小不平衡子树，再根据子树形态精准判定四种旋转类型之一，最后执行旋转并更新所有受影响节点的指针关系与平衡因子。K3-K4 平衡型的设计意图在于：K3（机制推演，目标 4）要求学生完整走完旋转流程而非仅凭记忆写出旋转名称——这涉及 >5 步的串行推演且需维持动态中间状态；K4（条件路由，目标 4）要求学生精准辨析 LL / RR / LR / RL 四种旋转的触发条件，其中 LR 和 RL 双旋是最易混淆的难点，学生必须理解"先局部旋转再整体旋转"的双旋机制本质才能正确路由。本题要区分的是"能完整走完旋转流程、正确辨析双旋条件并更新树结构的学生"与"只知道旋转名称但无法执行实际旋转操作、或混淆 LR 与 LL 的学生"。难度 4 是合适的——多步串行推演叠加旋转类型辨析的组合天然达到较高认知负荷，但不需要跨子系统联动（K5=1），也不涉及复杂算术（K2=2），负荷集中在 K3 和 K4 两个维度上，符合目标雷达形状。建议考察 LR 或 RL 双旋以达到难度 4 的精准定位——单旋（LL/RR）仅对应难度 2-3，双旋的"两步旋转 + 中间状态判断"恰好将 K3 推到 4、K4 推到 4。

## expected_reasoning_actions
- 按给定顺序依次将关键字插入初始为空的 AVL 树，遵循 BST 规则确定每个新节点的插入位置
- 每次插入后从新节点向上回溯，计算路径上各祖先节点的平衡因子（左子树高度 − 右子树高度），检测是否存在绝对值 > 1 的节点
- 定位最小不平衡子树（离插入点最近的平衡因子绝对值 > 1 的节点为根的子树）
- 观察最小不平衡子树根节点的较高子树方向（左/右），再观察该较高子树的较高子树方向（左/右），两步方向组合判定旋转类型（LL→右旋、RR→左旋、LR→先左旋后右旋、RL→先右旋后左旋）
- 执行对应旋转操作：若是单旋（LL/RR），一步完成；若是双旋（LR/RL），先对较高子树执行一次旋转，再对最小不平衡子树根执行第二次旋转
- 旋转后更新所有受影响节点的父子指针关系，重新计算各节点平衡因子，确认整棵树满足 AVL 平衡条件
- 对最终 AVL 树执行题目要求的遍历（前序/中序/层序），输出遍历序列

## question_structure_plan
- question_form: comprehensive
- shared_context: 给定一棵初始为空的平衡二叉树（AVL 树）和一组待插入的关键字序列（6-8 个互不相同的整数），要求学生模拟依次插入过程，在发生失衡时执行旋转维护平衡，最终给出树的结构与遍历结果
- sub_question_chain:
  - 子问题(1)：按给定顺序依次插入前若干个元素（不触发旋转的阶段），画出此时 AVL 树的结构（标注节点值，可选标注平衡因子）——考察 BST 插入规则与平衡因子计算
  - 子问题(2)：继续插入下一个元素后树发生失衡，指出最小不平衡子树（写出其根节点），并判断应执行哪种旋转（LL / RR / LR / RL）——考察失衡检测与旋转类型判定
  - 子问题(3)：画出执行旋转后的 AVL 树结构——考察旋转操作的正确执行与结构更新
  - 子问题(4)：给出最终 AVL 树的某一种遍历序列（如前序遍历或层序遍历）——考察对最终树结构的准确掌握
- dependency_pattern: 严格串行依赖——子问题(2)的失衡检测依赖(1)的树结构；子问题(3)的旋转执行依赖(2)的旋转类型判定；子问题(4)的遍历结果依赖(3)的最终树结构。任一环节出错将导致后续全部错误，这本身就是难度 4 的来源之一

## parameter_plan
- parameter_slots:
  - name: insertion_sequence
    role: 构建初始 AVL 树并在特定位置触发目标旋转
    candidate_range: 6-8 个互不相同的正整数，建议范围 [1, 30]
    used_by: 子问题(1)-(4)
  - name: rotation_trigger_position
    role: 标记序列中触发旋转的插入步骤（第几个元素），决定学生需要展示旋转过程的位置
    candidate_range: 序列中第 4-7 个元素
    used_by: 子问题(2)-(3)
  - name: rotation_type
    role: 确定本题考察的旋转类型；建议选择 LR 或 RL 双旋以精准达到难度 4
    candidate_range: LL / RR / LR / RL（推荐 LR 或 RL）
    used_by: 子问题(2)-(3)
  - name: traversal_type
    role: 子问题(4)要求输出的遍历方式，用于验证学生对最终树结构的掌握
    candidate_range: 前序遍历 / 中序遍历 / 层序遍历
    used_by: 子问题(4)
- validation_targets:
  1. 插入序列经模拟验证后，确实在 rotation_trigger_position 处触发目标 rotation_type（需 solver 逐步验证）
  2. 序列中无重复元素
  3. 序列长度适中（6-8 个元素）：过短则 K3 < 4，过长则 K3 可能 > 4 偏离目标
  4. 旋转后整棵树为合法 AVL 树（所有节点平衡因子绝对值 ≤ 1）
  5. 最终遍历序列唯一确定（树结构无歧义）
  6. 若选择 LR/RL 双旋，验证旋转过程中间状态正确（第一次旋转后的中间树结构满足 BST 性质）
- adjustment_priority:
  1. rotation_type（最高优先级——直接决定难度水平和 K4 维度，LR/RL 对应难度 4，LL/RR 仅对应难度 2-3）
  2. rotation_trigger_position（决定考察的精确步骤和 K3 步数）
  3. insertion_sequence（必须配合 rotation_type 调整，确保能触发目标旋转）
  4. traversal_type（最低优先级——仅影响子问题(4)的验证方式）

## terminology_and_expression_constraints
- required_terms:
  - 平衡二叉树（AVL 树）
  - 平衡因子
  - 最小不平衡子树
  - 旋转（需明确写出旋转类型：LL / RR / LR / RL，或等价的"左旋/右旋/先左后右/先右后左"）
- required_qualifiers:
  - "依次插入"（必须强调插入顺序，顺序不同则树的结构不同）
  - "最小不平衡子树"（而非泛指的"不平衡子树"，必须用"最小"限定以指向离插入点最近的不平衡节点）
  - "初始为空"（明确树的初始状态）
- avoid_phrases:
  - 避免出现"红黑树""B 树""B+ 树"等其他平衡结构术语，防止概念干扰
  - 避免用"高度差"替代"平衡因子"（虽概念等价，但 408 标准术语为平衡因子）
  - 避免用"调整""变换"替代"旋转"（408 标准用"旋转"描述 AVL 的重平衡操作）
  - 避免用"不平衡节点"替代"最小不平衡子树"（前者指节点，后者指以该节点为根的子树，语义不同）
- standard_rewrites:
  - bad: "树的左右子树高度差超过 1" → good: "平衡因子的绝对值大于 1"
  - bad: "不平衡的子树" → good: "最小不平衡子树"
  - bad: "对树进行调整" → good: "执行旋转（操作）"
  - bad: "先旋转再旋转" → good: "先左旋后右旋（LR 旋转）"或"先右旋后左旋（RL 旋转）"

## audit_focus
- final_review_must_check:
  1. 插入序列经 solver 模拟验证后，确实在预期位置触发目标旋转类型（尤其验证 LR/RL 双旋的中间状态正确）
  2. 题目对"最小不平衡子树"的定义与 408 教材一致（离插入点最近的平衡因子绝对值 > 1 的节点为根的子树）
  3. 旋转类型术语使用规范且前后一致（LL/RR/LR/RL 命名不与其他教材的"单向/双向旋转"命名混用）
  4. 各子问题之间的串行依赖关系清晰：(2) 依赖 (1) 的树结构，(3) 依赖 (2) 的旋转判定，(4) 依赖 (3) 的最终树
  5. 难度确实达到 4：K3（多步串行推演，>5 步）和 K4（旋转类型辨析，含双旋条件路由）均达到目标水平
  6. 题干不泄露旋转类型答案（不通过措辞暗示是单旋还是双旋）
- solve_output_should_contain:
  1. 插入过程的逐步展示（至少到触发旋转的那一步，含各节点平衡因子标注）
  2. 最小不平衡子树的明确定位（指出根节点）
  3. 旋转类型的判定及判定依据（根据子树方向组合推出旋转类型）
  4. 旋转后的完整树结构（节点父子关系正确，可选标注平衡因子）
  5. 最终遍历序列
- fail_if_missing:
  1. 缺少最小不平衡子树的定位步骤（直接跳到旋转结果而无判定过程）
  2. 缺少旋转类型的判定理由（仅写出旋转名称但未说明如何从子树形态推出）
  3. 旋转后树结构不满足 AVL 平衡条件（存在平衡因子绝对值 > 1 的节点）
  4. 子问题链断裂（后续子问题无法从前序答案推导，或前序错误导致后续无解）
  5. 插入序列验证失败（实际触发的旋转类型与设计目标不一致）
