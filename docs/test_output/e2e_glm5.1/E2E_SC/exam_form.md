## examination_form
- 考察形式：单点计算（主）+ 陷阱辨析（辅）
- 设问方向：给定 n 个叶子权值，要求构造哈夫曼树并计算 WPL，最终选择正确数值；三个干扰项各对应一种可追溯的系统性错误（路径长度定义混淆、构造顺序错误、遗漏叶子节点），考生需完整执行构造流程并精确计算才能排除干扰

## k_radar
- K1（基础认知）: 3
- K2（单步代入）: 2
- K3（机制推演）: 3
- K4（条件路由）: 2
- K5（跨域联动）: 2
- 形状主导维度：K1 与 K3 并列主导（均为 3）

## rationale
- 为何选此形式：K1=3 和 K3=3 并列最高，说明本题既要求对 WPL 定义、路径长度（边数而非节点数）等基础概念的精确掌握（K1），又要求完整执行哈夫曼树的多轮合并构造流程（K3 机制推演）。单点计算作为主形式——题目给出权值集合，学生需完成构造→逐叶计算→累加→选定答案；陷阱辨析作为辅形式——三个干扰项分别诊断三种典型错误路径，使错误选项成为"认知缺陷镜像"而非随机数值。
- 与目标 K-雷达的对齐说明：K3=3 对应构造过程中的多轮选最小合并推演，是计算量的主要来源；K1=3 对应路径长度定义和 WPL 公式的精确理解，是干扰项陷阱设计的认知基础；K2=2/K4=2/K5=2 均为低档，符合纯计算类选择题不涉及复杂条件分支或跨子系统的定位。
