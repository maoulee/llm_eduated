# 题目

给定 6 个叶子的权值集合为 {2, 3, 4, 5, 7, 9}，依次构造哈夫曼树，该哈夫曼树的带权路径长度（WPL）为（　　）。

A. 70
B. 80
C. 66
D. 74

## 设计说明

- 复用骨架来源：design_card 的 question_structure_plan — "给定 n 个正整数权值，要求构造哈夫曼树并求 WPL"，设问方式 asking_method = "该哈夫曼树的带权路径长度(WPL)为"
- 考察形式：单点计算（主）+ 陷阱辨析（辅），来自 exam_form
- 经验值参数：n=6（约束 5≤n≤7 范围内的友好值）；权值集合 {2,3,4,5,7,9}（每个 wᵢ 满足 1≤wᵢ≤15，含相近值对 (2,3) 和 (4,5) 增加构造判断难度）
- 设计理念：区分能完整执行哈夫曼构造流程并精确计算 WPL 的学生与只记得概念名称但无法准确操作的学生，三个干扰项分别诊断路径长度定义混淆、构造顺序错误、遗漏叶子节点三种典型错误
- 与目标 K-雷达的对齐：K1=3（WPL 定义与路径长度=边数的精确掌握），K3=3（多轮选最小合并的构造推演，计算量主要来源），K2=2/K4=2/K5=2 均低档，符合纯计算类选择题定位
- 干扰项设计（基于正确答案 74 派生）：
  - A. 70（路径长度定义混淆：部分叶子路径长度少算 1 层，WPL 偏小）
  - B. 80（构造顺序错误：未严格执行"每次选最小两个合并"，导致子树偏高，WPL 偏大）
  - C. 66（遗漏叶子节点：漏算权重为 2 的叶子贡献 2×4=8，74−8=66）
  - D. 74（正确答案）
  - 四值两两不同：66 ≠ 70 ≠ 74 ≠ 80 ✓
