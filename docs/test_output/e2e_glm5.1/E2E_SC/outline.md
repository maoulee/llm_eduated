## 考点
- **核心知识点**：二叉树带权路径长度（WPL）的定义与计算 —— WPL = Σ(叶子权值 × 根到该叶子的路径长度)
- **辅助知识点**：
  - 二叉树的存储与遍历序列（前序/中序/层序）与树的唯一确定关系
  - 哈夫曼树与 WPL 的联系（最优性，但本题不直接考哈夫曼构造）
- **考察侧重点**：
  1. WPL 定义中"路径长度"的含义（从根到叶子的边数，根的路径长度为 0）
  2. 仅叶子节点参与 WPL 计算，内部节点不计入
  3. 通过遍历序列还原二叉树结构后，逐叶计算 WPL 并求和

## 难度目标
| 维度 | 目标等级 | 达标理由 |
|------|---------|---------|
| K1 识记 | 2 | 需要准确记忆 WPL 定义和路径长度的计数方式 |
| K2 理解 | 3 | 需要理解路径长度是"边数"而非"节点数"，辨析 WPL 与普通路径长度的区别 |
| K3 应用 | 3 | 需要根据遍历序列还原树结构并执行 WPL 计算 |
| K4 分析 | 2 | 需要对树结构做基本分析（确定各叶子的深度），推理量适中 |
| K5 综合 | 1 | 不涉及多知识点综合设计，单点应用即可 |

**整体难度定位：medium（2-3 级）**，属于 408 数据结构选择题中常见的"定义+计算"型题目。

## 考察模式
**选定模式：给定遍历序列 + 叶子权值 → 还原树结构 → 计算 WPL**

**理由**：
1. 这是 408 真题中 WPL 考点的经典考察方式（2014、2017 等年份均有类似模式）
2. 该模式同时覆盖"二叉树还原"和"WPL 计算"两个考点，区分度好
3. 干扰项设计空间大：路径长度计数方式错误（边数 vs 节点数）、内部节点误计入、特定叶子深度错误等均可产生典型的错误选项
4. 不依赖哈夫曼树构造，避免与后续哈夫曼树专题重叠

## 出题要求
- **题型**：单项选择题（4 选项，1 正确 3 干扰）
- **条件数**：2 个显式条件
  - 条件 1：一棵二叉树的前序（或层序）遍历序列，用于描述树结构
  - 条件 2：各叶子节点的权值分配
- **条件设计原则**：
  - 树结构通过遍历序列隐式给出，不直接给图
  - 叶子数量适中（4-6 个），保证计算量可控但非平凡
  - 权值为小正整数（1-9 范围），便于心算验证
  - 树的形态应包含至少 2 层不同的叶子深度，使各干扰项可被区分

## 子问题规划
本题型为单项选择题，无子问题划分。

选项设计要求：
- 正确选项：WPL 精确计算值
- 干扰项设计策略（至少覆盖以下 3 种中的 3 种）：
  1. **路径长度计数偏移**：将根到叶子的边数误算为节点数（每叶 +1，总和偏大）
  2. **内部节点误入**：将所有节点（含内部节点）都乘以权值/深度参与求和
  3. **特定叶子深度错误**：某一层叶子深度计算偏差（如将某叶子归入相邻层）
  4. **权值分配错位**：将不同叶子的权值配对到错误深度

## 参数约束
| 参数 | 取值范围 | 一致性约束 |
|------|---------|-----------|
| 叶子节点数 | 4-6 个 | 与遍历序列推导出的树结构一致 |
| 树的深度 | 3-4 层 | 根为第 0 层；至少存在两个不同深度的叶子 |
| 叶子权值 | 1-9 的正整数 | 各叶子权值互不相同，便于选项区分 |
| 内部节点数 | 由树结构自然决定 | 内部节点无权值（或权值不参与 WPL） |
| 遍历序列类型 | 前序+中序 或 层序+前序 | 序列必须能唯一确定二叉树 |

**可调自由度**：
- Question Agent 可自由选择具体遍历序列类型（前序+中序 或 层序+前序）
- Question Agent 可自由选择树的形态（不限制为完全二叉树）
- Question Agent 可自由分配叶子的权值（在约束范围内）
- 干扰项的具体数值由 Question Agent 根据上述策略自行计算

## 参考经验
- **历史模式**：408 真题中 WPL 选择题通常以"给结构+给权值→算 WPL"为固定框架，2014 年第 5 题、2017 年类似题位均采用此模式
- **难度锚点**：此类题目 K2/K3 为主要区分维度，K1/K4/K5 在选择题中通常较低
- **典型陷阱**：
  1. 根的路径长度：部分学生误认为根到根的路径长度为 1 而非 0
  2. WPL vs 路径长度（PL）：混淆带权与不带权
  3. 内部节点：部分学生将内部节点也参与 WPL 计算
  4. 叶子深度确定错误：尤其在树形态不对称时
