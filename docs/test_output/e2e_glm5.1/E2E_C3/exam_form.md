## examination_form
- 考察形式：多步串行推演（主） + 陷阱辨析（辅）
- 设问方向：给定关键字序列依次插入初始为空的 AVL 树，问第 k 次插入并完成旋转调整后的树结构特征（如某节点的左右孩子、子树根等），要求考生逐层回溯检测失衡并正确判断旋转类型后才能锁定答案

## k_radar
- K1（基础认知）: 2
- K2（单步代入）: 1
- K3（机制推演）: 4
- K4（条件路由）: 3
- K5（跨域联动）: 1
- 形状主导维度：K3-K4 平衡型（K3 略高于 K4）

## rationale
- 为何选此形式：AVL 插入旋转的核心认知活动是"逐步插入 → 逐层回溯检测失衡 → 定位最小失衡子树 → 判断旋转类型 → 执行旋转并重新挂接子树"的多步串行流程（K3≥4），而其中"沿失衡节点到插入点的路径取前两步方向以确定 LL/RR/LR/RL 旋转类型"构成实质性的条件路由（K4≥3），因此主形式为多步串行推演，辅以旋转类型辨析的陷阱/条件路由成分。设计卡要求至少包含一次双旋（LR 或 RL），双旋的"先旋子树、再旋整体"两步逻辑进一步强化了 K3 的推演深度和 K4 的条件辨析难度。
- 与目标 K-雷达的对齐说明：K3=4 满足"推演步数 >5 步或需维持动态状态更新"的约束；K4=3 满足"需识别旋转触发条件这一隐含前提"的约束；K1=2 因考生需准确记忆平衡因子定义和最小失衡子树概念才能入题，但不构成极致的概念辨析；K2=1 因本题无实质数值计算；K5=1 因严格限定在 AVL 单一知识点内部，不涉及跨子系统联动。整体形状为 K3-K4 平衡型，与 design_card 的 k_target 一致。
