## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: DS-5 > 树与二叉树
- primary_target_name: 二叉树带权路径长度
- question_type: single_choice
- examination_mode: 给定二叉树结构，计算 WPL 值

### 难度目标
- k_target: K1=3,K2=3,K3=2,K4=2,K5=3
- difficulty_level: 3
- difficulty_rationale: WPL 定义理解与多节点逐项计算构成中等概念门槛和计算量；路径长度定义混淆为高频陷阱，K5 设为 3 以保证区分度；推理链较短且为单一知识点，K3/K4 设为 2

### 结构要求
- option_count: 4
- distractor_strategy: |
    干扰项 A：路径长度按节点数（深度）计算，制造定义混淆陷阱
    干扰项 B：漏算一个叶子节点，制造节点识别遗漏陷阱
    干扰项 C：将一个内部节点权值计入 WPL，制造非叶子节点误算陷阱
- condition_count: 2
- condition_design: |
    条件1：二叉树结构信息（先序+中序遍历序列 或 层序遍历带空标记），权值嵌入序列中
    条件2：隐含前提——叶子节点定义默认已知，无需显式声明

### 参数约束
- 总节点数: 5-7，保证计算量适中
- 叶子节点数: 3-5，与总节点数一致（内部节点 = 总节点数 - 叶子节点数 ≥ 1）
- 树深度: 3-4，确保路径长度陷阱选项与正确值差异明显
- 权值范围: 1-9 正整数，叶子权值不全相同
- 树形态约束: 非完全二叉树，增加结构解读难度
- 一致性约束: 结构描述与权值一一对应无歧义；4 个选项值互不相同；正确值与各干扰项差值 ≥ 2

### 自由度说明
- 树的具体形态（左偏/右偏/混合）由 Question Agent 决定
- 遍历序列组合方式（先序+中序 或 层序带空标记）由 Question Agent 决定
- 各叶子节点的具体权值由 Question Agent 在约束范围内自由设定

### 参考经验摘要
- 历史模式: "给定树结构→计算 WPL"为该考点在选择题中的经典模式，真题多次出现
- 难度锚点: K1=2~3, K2=2~3, K5=2~3 为该题位典型分布
- 典型陷阱: |
    1. 路径长度定义混淆（边数 vs 节点数/深度）——最高频
    2. 漏算叶子节点或误将内部节点计入 WPL——次高频
    3. 权值与路径长度乘法运算错误——低频但需控制权值大小避免
