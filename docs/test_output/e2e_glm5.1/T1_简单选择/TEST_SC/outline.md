## 考点
- **核心知识点**：二叉树带权路径长度（WPL）的定义与计算
  - 考察侧重点：WPL = Σ(叶子节点权值 × 根到该节点的路径长度)，路径长度定义为从根到节点的**边数**
- **辅助知识点1**：叶子节点与内部节点的区分
  - 考察侧重点：只有叶子节点参与 WPL 计算，内部节点即使有权值也不计入
- **辅助知识点2**：二叉树结构的解读（通过遍历序列或存储结构还原树形）
  - 考察侧重点：根据先序/中序/层序遍历或顺序存储数组推断节点间的父子关系和层级

## 难度目标
| 维度 | 目标 | 达标理由 |
|------|------|----------|
| K1 概念理解 | 3 | 需准确掌握 WPL 定义、路径长度（边数）与深度的区别，属中等概念门槛 |
| K2 计算能力 | 3 | 需对多个叶子节点逐一计算"权值×路径长度"再求和，计算量适中 |
| K3 推理分析 | 2 | 树结构给出后推理链较短，主要依赖正确读图/读序列 |
| K4 综合应用 | 2 | 单一知识点应用，不涉及跨章节综合 |
| K5 陷阱识别 | 3 | 路径长度定义（边数 vs 节点数）、深度与路径长度混淆是该考点高频陷阱 |

## 考察模式
**模式：给定二叉树结构，计算 WPL 值**

理由：
1. 这是 WPL 考点在选择题中最经典的考察模式，历年真题多次出现
2. 中等难度适合——学生必须理解定义并逐节点计算，无法靠排除法蒙答案
3. 可有效设置陷阱选项（路径长度按节点数计算、漏算叶子、误将内部节点计入）

**树结构呈现方式**：建议通过遍历序列（如先序+中序）或层序遍历给出树的结构信息，而非直接给图。这样增加了从 K3（推理分析）维度的考察深度，同时避免题目过长。

## 出题要求
- **题型**：单项选择题，4 个选项（1 正确 + 3 干扰）
- **条件数**：2 个显式条件
  - 条件1：二叉树的结构信息（遍历序列或顺序存储数组，含节点权值标注）
  - 条件2：WPL 计算的隐含前提（叶子节点的定义默认已知，无需额外声明）
- **条件设计原则**：
  - 树结构信息必须能**唯一确定**一棵二叉树（先序+中序组合，或层序遍历带空节点标记）
  - 节点权值应直接嵌入结构信息中（如遍历序列中标注权值），避免额外的权值映射表
  - 树的规模控制在 5-7 个节点，其中 3-5 个叶子节点，保证计算量适中但不出错概率合理

## 子问题规划
选择题无子问题拆分。4 个选项的设计要求：

| 选项 | 类型 | 设计目的 |
|------|------|----------|
| 正确选项 | 正确 WPL 值 | 考察定义理解和计算准确性 |
| 干扰选项 A | 路径长度按节点数计算（即深度）的 WPL | 陷阱：混淆路径长度与深度 |
| 干扰选项 B | 漏算某个叶子节点后的 WPL | 陷阱：节点识别遗漏 |
| 干扰选项 C | 将某个内部节点的权值也计入 WPL | 陷阱：误将非叶子节点纳入计算 |

## 参数约束
| 参数 | 取值范围 | 约束说明 |
|------|----------|----------|
| 总节点数 | 5-7 | 保证树有一定复杂度但计算量可控 |
| 叶子节点数 | 3-5 | 叶子数直接影响计算步骤数和干扰项设计空间 |
| 树的深度 | 3-4 | 深度 ≥ 3 才能使路径长度陷阱选项产生明显差异 |
| 权值取值 | 1-9 的正整数 | 权值为小整数，确保心算可行且干扰项数值合理 |
| 权值分布 | 叶子权值不全相同 | 避免退化情况（如全相同权值会降低区分度） |
| 树形态 | 非完全二叉树 | 非完全树能增加结构解读难度，且叶子节点层级分布更分散 |

**参数间一致性约束**：
- 树的结构描述必须与给定权值一一对应，不存在歧义
- 正确 WPL 值与三个干扰项的数值必须互不相同
- 干扰项 A（按节点数/深度计算）与正确值的差异应 ≥ 2，确保选项区分度

**可调自由度**：
- Question Agent 可自由选择树的具体形态（左偏、右偏、混合）
- Question Agent 可自由选择遍历序列的组合方式（先序+中序，或层序带空标记）
- Question Agent 可自由设定各叶子节点的具体权值（在约束范围内）

## 参考经验
- **历史模式**：WPL 在选择题中几乎都以"给定树结构→计算值"为核心模式，偶尔结合哈夫曼树考察最小 WPL 的概念
- **难度锚点**：该知识点在选择题中的 K 值典型分布为 K1=2~3, K2=2~3, K5=2~3，与本次规划目标一致
- **典型陷阱**：
  1. 路径长度定义混淆（边数 vs 节点数/深度）——最高频陷阱，必须设置对应干扰项
  2. 深度从 0 还是 1 开始的混淆——与路径长度陷阱同源
  3. 漏算叶子或误将内部节点计入——次高频陷阱
- **难度控制要点**：权值不宜过大（避免纯计算错误掩盖概念错误），树深度控制在 3-4 层
