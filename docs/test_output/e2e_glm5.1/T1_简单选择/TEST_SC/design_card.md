## core_knowledge_intent

### must_test

1. WPL 的定义：WPL = Σ（叶子权值 × 根到该叶子的路径长度），路径长度为根到叶子的边数
2. 从遍历序列重建二叉树结构并正确识别所有叶子节点
3. 逐项计算权值与路径长度的乘积并求和

### must_not_shift_to

1. 哈夫曼树/哈夫曼编码的构造与性质（本题只考 WPL 计算，不涉及最优二叉树构造）
2. 二叉树遍历算法本身的代码实现（遍历序列只是给定结构的手段，不考遍历程序）

### coverage_success_criteria

1. 学生必须完成"重建树 → 识别叶子 → 计算路径长度 → 逐项求和"完整链条才能得到正确答案
2. 对路径长度定义的精确理解（边数 vs 深度/节点数）是本题核心区分点

## design_rationale

本题考察二叉树带权路径长度（WPL）的定义理解与计算能力。WPL 是树章节的基础概念，但学生常在两个环节出错：一是路径长度定义混淆（边数 vs 深度/节点数），二是叶子节点识别遗漏或内部节点误入。本题通过给定遍历序列（而非直接画树）增加结构重建环节，使 K1（知识辨识）和 K2（程序化计算）同时达到 3 级——学生不仅要知道 WPL 公式，还要先正确重建树形才能应用公式。选择非完全二叉树形态是为了避免学生靠"对称性"猜答案，迫使真正完成结构解读。三个干扰项分别对应最高频的三种认知错误（路径长度定义混淆、叶子遗漏、内部节点误算），使 K5（区分度）达到 3 级。K3/K4 设为 2 是因为推理链较短（单知识点、无跨章节关联），不需要高阶综合或迁移能力。本题区分的是"能完整走完重建→识别→计算→求和全流程并精确理解路径长度定义的学生"与"只记得 WPL 公式但定义模糊或计算粗心的学生"。

## expected_reasoning_actions

1. 由给定的遍历序列（先序+中序 或 层序带空标记）重建唯一的二叉树结构
2. 识别重建后的二叉树中所有叶子节点，并从序列中读出各叶子节点对应的权值
3. 对每个叶子节点，计算从根节点到该叶子节点的路径长度（边数）
4. 逐项计算"权值 × 路径长度"，将所有叶子的乘积求和，得到 WPL 值
5. 将计算结果与四个选项比对，选出正确答案

## question_structure_plan

### 选择题结构方案

- stem_style: 给出二叉树的遍历序列（先序+中序 或 层序带空标记），权值信息嵌入序列中，要求计算该二叉树的 WPL 值
- asking_method: "该二叉树的带权路径长度（WPL）为（）"

### option_architecture

- correct: 正确的 WPL 值（每个叶子：权值 × 根到叶的边数，逐项求和）
- distractor_A（定义混淆型）: 路径长度按深度（节点数 = 边数 + 1）计算，每个叶子的路径长度比正确值多 1，导致 WPL 偏大；对应"路径长度 = 节点数/深度"的错误认知
- distractor_B（遗漏型）: 漏算一个叶子节点（权值最小或路径最短的叶子），WPL 偏小；对应"叶子节点识别不全"的错误认知
- distractor_C（误入型）: 将一个内部节点的权值也按其路径长度计入 WPL，WPL 偏大；对应"WPL 应包含所有节点"的错误认知

### 干扰策略选定

| 干扰项 | 干扰类型 | 错误认知路径 |
|--------|----------|-------------|
| A | 偏移错误（off-by-one） | 路径长度定义为深度（节点数）而非边数 |
| B | 条件遗漏 | 漏掉一个叶子节点未参与求和 |
| C | 非叶节点纳入 | 将内部节点权值误计入 WPL |

## parameter_plan

### parameter_slots

| name | role | candidate_range | used_by |
|------|------|----------------|---------|
| traversal_sequences | 给出二叉树结构信息（先序+中序 或 层序带空标记），唯一确定树形态 | 由 Question Agent 在两种方式中选定一组 | 树重建 → WPL 计算 |
| node_count | 总节点数，控制计算量适中 | 5–7 | 叶子识别、WPL 计算 |
| leaf_count | 叶子节点数，决定 WPL 求和项数 | 3–5（且 internal = node_count − leaf_count ≥ 1） | WPL 计算 |
| tree_depth | 树的深度，影响路径长度分布 | 3–4 | 路径长度计算、选项差异控制 |
| leaf_weights | 各叶子节点的权值 | 1–9 正整数，不全相同 | WPL 计算 |
| tree_shape | 树的具体形态 | 非完全二叉树（左偏/右偏/混合由 Question Agent 决定） | 结构重建难度 |

### validation_targets

1. 遍历序列能唯一确定一棵二叉树（先序+中序无重复元素；层序带空标记完整）
2. 权值与节点一一对应，无歧义
3. 树为非完全二叉树
4. 正确 WPL 值与三个干扰项值互不相同，且任意两者差值 ≥ 2
5. 干扰项 A 的值严格大于正确值（每个叶子路径长度 +1）
6. 干扰项 B 的值严格小于正确值（少算一个叶子的贡献）
7. 干扰项 C 的值严格大于正确值（多算一个内部节点的贡献）
8. 所有叶子权值不全相同

### adjustment_priority

node_count > leaf_weights > tree_depth > tree_shape

（优先调整节点数和权值使选项差异满足约束；树深度和形态作为次要调节手段）

### required_qualifiers

- 题干中"带权路径长度（WPL）"需标注缩写，确保学生明确考查对象

### avoid_phrases

- "路径上的节点数"——歧义，可被理解为深度（节点数）而非边数
- "所有节点的带权路径长度"——WPL 只针对叶子节点，此表述会误导
- "最短路径"——引入图论概念干扰

### standard_rewrites

| bad | good |
|-----|------|
| "路径长度" | "从根节点到该节点的路径上的边数" |
| "叶子节点" | "叶子节点（即度为 0 的节点）" |
| "该树的 WPL" | "该二叉树的带权路径长度（WPL）" |
