## 题目

设二叉树的结构及各节点权值如下图所示（节点内数字表示该节点的权值）：

```
          A(3)
         /     \
      B(8)     C(12)
      /  \       \
   D(5) E(10)   F(7)
                /  \
             G(20) H(15)
```

其中，D、E、G、H 为叶子节点。

该二叉树的带权路径长度 WPL 为（ ）。

（注：带权路径长度 WPL 定义为二叉树中所有叶子节点的权值乘以其路径长度之和，路径长度指从根节点到该叶子节点所经过的边数。）

## 选项

A. 90  
B. 135  
C. 169  
D. 185  

## 求解过程

**步骤1：识别叶子节点及其权值**

根据题干，叶子节点为：D(5)、E(10)、G(20)、H(15)。

**步骤2：计算每个叶子节点的路径长度（根到叶子的边数）**

- D(5)：A → B → D，路径长度 = 2
- E(10)：A → B → E，路径长度 = 2
- G(20)：A → C → F → G，路径长度 = 3
- H(15)：A → C → F → H，路径长度 = 3

**步骤3：计算 WPL**

WPL = 5×2 + 10×2 + 20×3 + 15×3
    = 10 + 20 + 60 + 45
    = 135

## 答案

B. 135
