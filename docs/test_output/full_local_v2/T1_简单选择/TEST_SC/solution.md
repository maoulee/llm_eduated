## 求解过程

### 计算带权路径长度 WPL

带权路径长度 WPL 定义为二叉树中所有叶子节点的权值乘以其路径长度之和，路径长度指从根节点到该叶子节点所经过的边数。

**步骤1：识别叶子节点及其权值**

根据题干，叶子节点为：D(5)、E(10)、G(20)、H(15)。

**步骤2：计算每个叶子节点的路径长度（根到叶子的边数）**

- D(5)：A → B → D，路径长度 = 2
- E(10)：A → B → E，路径长度 = 2
- G(20)：A → C → F → G，路径长度 = 3
- H(15)：A → C → F → H，路径长度 = 3

**步骤3：计算 WPL**

WPL = 5×2 + 10×2 + 20×3 + 15×3
    = 10 + 20 + 60 + 45
    = 135

## 最终答案
- 正确答案：135
  - 理由：WPL = 5×2 + 10×2 + 20×3 + 15×3 = 10 + 20 + 60 + 45 = 135
