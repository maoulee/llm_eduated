## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: DS-5 > 树与二叉树
- primary_target_name: 二叉树带权路径长度
- question_type: single_choice
- examination_mode: 给定二叉树结构计算WPL

### 难度目标
- k_target: K1=2,K2=3,K3=3,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 中等难度，考查WPL基本概念和应用，计算量适中，不涉及多知识点综合

### 结构要求
- option_count: 4
- distractor_strategy: 干扰项设计针对常见错误：1)计入非叶子节点 2)路径长度计算错误 3)权值与路径对应错误 4)求和计算错误
- condition_count: 2-3

### 参数约束
- 节点总数 N: [5, 10]，建议6-8个
- 叶子节点数 L: [3, 5]，需满足 L ≤ N
- 树的高度 H: [3, 4]，与N需结构一致
- 叶子节点权值 W_i: [1, 50]，整数，建议不完全相同
- WPL结果范围: [50, 500]
- 一致性约束: 至少一个叶子节点路径长度≥2；权值分配应有差异；树结构清晰无歧义

### 参考经验摘要
- 历史模式: 给定二叉树图形+权值，计算WPL；图形表示更常见
- 难度锚点: 节点数6-8，叶子3-4，结果100-300，路径长度2-3层
- 典型陷阱: 非叶子节点误计入、路径长度从1开始计数、漏算叶子节点、权值路径对应错误
