# 概念题解析

## 第 1 题解析

**答案**：①√ ②× ③√ ④√

**解析**：
- ①√：冯·诺依曼原始方案确实以运算器为中心，输入设备的数据需经运算器送存储器，存储器的数据也需经运算器送输出设备，运算器是信息传送的必经中枢。
- ②×：现代计算机以存储器为中心，与冯·诺依曼结构（以运算器为中心）在中心部件上根本不同。"未改变其中心部件"是错误描述，将冯·诺依曼结构与现代结构混为一谈是典型概念混淆。
- ③√：存储程序是冯·诺依曼结构的核心特征，指令和数据同等存放在存储器中，机器按地址顺序自动执行。
- ④√：五大部件（运算器、控制器、存储器、输入设备、输出设备）是冯·诺依曼结构的基本组成，控制器（CU）负责产生控制信号协调各部件工作。

## 第 2 题解析

**答案**：①√ ②× ③√ ④×

**解析**：
- ①√：全互锁方式中主模块发请求等从模块回答，从模块发回答等主模块撤销请求，双方互锁等待，传输最可靠但速度最慢。
- ②×：半互锁方式中，主模块锁定（需等待从模块回答才能撤销请求），但从模块不锁定（回答信号由自身固定延迟决定撤销，不依赖主模块请求撤销）。陈述中"从模块的回答信号由主模块的请求撤销来触发撤销"描述错误——若从模块也等待主模块撤销，则成为全互锁而非半互锁。
- ③√：不互锁方式中主模块发出请求后自行经固定延迟撤销，从模块也自行撤销回答，双方互不等待，速度最快但可靠性最低。
- ④×：异步通信虽无公共时钟，但速度差异过大会导致握手超时或传输效率严重下降。声称"不会对可靠性产生任何影响"是过度绝对化的错误推断。

## 第 3 题解析

**答案**：①√ ②√ ③× ④√

**解析**：
- ①√：Cache—主存层次解决CPU与主存间的速度差距，主存—辅存层次解决存储容量不足，这是存储系统层次结构的基本设计目标。
- ②√：从寄存器→Cache→主存→辅存，速度递减、容量递增、单位价格递减，这是层次结构的基本规律。
- ③×：主存—辅存层次的地址变换和页面调换由硬件（MMU）和操作系统共同完成，操作系统参与缺页处理和页面替换策略，并非"完全由硬件自动完成"。将Cache的完全硬件透明性错误推广到主存—辅存层次是概念混淆。
- ④√：Cache对程序员（包括汇编程序员）完全透明，程序只面向主存地址编程，Cache的管理（映射、替换、写策略）由硬件自动完成。

## 第 4 题解析

**答案**：①√ ②√ ③× ④√

**解析**：
- ①√：水平型微指令字较长，一条微指令可同时发出多个微命令，并行操作能力强，通常采用直接编码或字段直接编码。
- ②√：垂直型微指令类似于机器指令格式，操作码指定微操作类型，一条微指令通常只执行一个微操作，并行能力弱。
- ③×："具有操作码和地址码字段、格式类似机器指令"是垂直型微指令的特征，不是水平型微指令的特征。将垂直型特征张冠李戴到水平型是典型概念混淆。水平型微指令采用控制字段直接表示微命令，不使用操作码/地址码格式。
- ④√：微指令类型（水平型或垂直型）在微程序控制器设计阶段确定，属于硬件设计决策，运行时一条微指令的类型是固定的。

## 第 5 题解析

**答案**：①√ ②√ ③× ④√

**解析**：
- ①√：指令周期定义即为取出并执行一条指令所需的全部时间，通常划分为取指周期、间址周期、执行周期、中断周期等若干机器周期。
- ②√：间接寻址需要额外的访存操作来获取有效地址（再据此取操作数），相比直接寻址多了一次访存，执行时间更长。
- ③×：变长指令集（如x86）中不同长度的指令需要不同次数的访存才能完整取出，取指周期并非完全相同。"所有指令的取指周期时间完全相同"是过度概括的错误。即使在定长指令集中，取指周期相同仅是简化假设，并非普遍规律。
- ④√：机器周期通常以主存读/写周期为基准定义，因为访存是最频繁且最耗时的操作，以它为基准保证机器周期的合理性。
