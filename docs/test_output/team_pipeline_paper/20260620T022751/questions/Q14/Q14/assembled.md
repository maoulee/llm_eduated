## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 排序 > 插入排序与交换排序
- primary_target_name: 给定序列用直接插入和冒泡排序写出每趟结果对比
- question_type: comprehensive
- examination_mode: 推演型——排序过程手工模拟与对比

### 难度目标
- k_target: K1=1,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 4
- difficulty_rationale: 需手动模拟两种排序的多趟过程并对比分析，多步推演为主（K3=4），单步操作简单（K2=2），无跨域联动（K5=1）

### 结构要求
- sub_question_count: 3
- sub_question_structure:
  - q1: 直接插入排序每趟结果模拟（3分）
  - q2: 冒泡排序每趟结果模拟（3分）
  - q3: 两种算法对比分析（4分）
- dependency: q1与q2并行独立，q3基于q1/q2结果
- condition_count: 1（仅待排序序列）

### 参数约束
- 序列长度 n: 6 ≤ n ≤ 10，建议 7~9
- 元素值域: 10 ≤ 元素值 ≤ 99，整数
- 元素互异性: 建议互异
- 序列无序程度: 非接近有序/逆序，保证推演价值
- 一致性: 同一序列用于两种排序

### 参考经验摘要
- 历史模式: 2010_Q11、2020_Q11 均采用"给序列→两种排序过程模拟→对比分析"三段式
- 难度锚点: K3=4 为标志性特征，推演步数多但路径唯一
- 典型陷阱: 插入排序插入位置判断错误、冒泡排序趟数计算错误、时间复杂度/稳定性混淆
