## 题干

已知一棵二叉树共有 23 个结点，其中度为 1 的结点数为 0。则该二叉树的叶子结点数为（ ）。

## 选项

- A: 正确结果
- B: 公式方向记反（误用 n2 = n0 + 1）或算出 n2 后误以为是 n0 的结果
- C: 概念混淆，将度为 1 的结点数直接当作叶子结点数的结果
- D: 错误认为 n2 = n - n1，再套用 n0 = n2 + 1 的结果

## 通过条件

本题成立 ⇔ 满足以下可机检特征：

1. **正确值唯一确定**：在 n=23、n1=0 的参数下，联立 n0 = n2 + 1 与 n = n0 + n1 + n2，解得 n0 = 12 为唯一整数解。
2. **4 选项互异**：A/B/C/D 四个选项值各不相同，无碰撞。
3. **干扰项对应错误类型**：
   - B 对应公式方向记反（n2 = n0 + 1）或混淆 n0 与 n2 的常见错误
   - C 对应概念混淆（将 n1 当作 n0）的常见错误
   - D 对应错误推导路径（n2 = n - n1，再 n0 = n2 + 1）的常见错误
4. **干扰项有合理性**：各干扰项均为二叉树性质题中真实常见的误算产物，非荒谬值，具有区分度。

## 考察点

- **二叉树基本性质 n0 = n2 + 1**：核心考察点，需准确记忆并应用该公式
- **结点度数分类**：理解叶子结点（度0）、度为1结点、度为2结点的概念
- **结点总数关系 n = n0 + n1 + n2**：辅助公式，用于联立求解

## 参数说明

- 总结点数 n = 23（非2的幂次，在10-100范围内）
- 度为1的结点数 n1 = 0（完全二叉树常见场景）
- 验证一致性：n - n1 + 1 = 24 为偶数，n0 = 12 为整数，满足所有约束
