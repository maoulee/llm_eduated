## 考点
- **二叉树基本性质 n0 = n2 + 1**：核心考察点，必须准确记忆该公式
- **二叉树结点度数分类**：理解叶子结点（度0）、度为1结点、度为2结点的概念
- **结点总数关系 n = n0 + n1 + n2**：辅助公式，用于联立求解

## 难度目标
- **K1=2（较低）**：需要知道二叉树基本名词（叶子结点、度为2结点），但概念直观，概念模糊也能顺着题干做
- **K2=3（标准）**：需代入 n0=n2+1 和 n=n0+n1+n2 联立计算，可能涉及非2的幂次数字
- **K3=2（较低）**：仅需1-2步推导（代入公式→联立求解），路径唯一
- **K4=2（较低）**：存在常规注意点（如完全二叉树中度为1的结点最多1个），但408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他系统

## 考察模式
**计算型——已知部分结点信息推算叶子结点数**

典型模式：给出总结点数 n 和度为1的结点数 n1（或度为2的结点数 n2），要求计算叶子结点数 n0。

理由：这是二叉树性质最经典的考察方式，直接对应 n0=n2+1 公式的应用，难度可控，适合2分单选题。

## 出题要求
- **题型**：单选题，4个选项
- **分值**：2分
- **条件数**：2个显式条件（如总结点数 + 度为1的结点数）
- **条件设计原则**：
  - 条件应能唯一确定答案
  - 避免给出直接就是 n0 或 n2 的值（否则太简单）
  - 可考虑给出总结点数 n 和 n1，让学生联立求解
- **参数取值范围要求**：
  - 总结点数 n：建议在 10-100 范围内，非2的幂次，增加计算感
  - n1：建议为 0 或 1（完全二叉树场景）或较小整数
  - 确保 n0、n1、n2 均为非负整数且满足 n = n0 + n1 + n2

## 子问题规划
本题为单选题，无子问题。

## 参数约束
- **总结点数 n**：取值范围 10-100，建议非2的幂次（如 15、23、37 等），避免计算过于简单
- **度为1的结点数 n1**：取值范围 0-5，建议取 0 或 1（完全二叉树常见场景）
- **一致性约束**：
  - n0 = n2 + 1（核心公式）
  - n = n0 + n1 + n2
  - 联立得：n0 = (n - n1 + 1) / 2，必须为整数
  - 因此 n - n1 + 1 必须为偶数，即 n 和 n1 奇偶性相同
- **可调自由度**：n 和 n1 可在上述范围内调整，只要满足奇偶性一致即可

## 参考经验
- **考察模式**：二叉树性质题在408中多为直接公式应用，2分题不宜过度复杂
- **难度锚点**：K2=3 意味着计算不应是2的幂次友好型，应有一定计算量
- **典型陷阱**：
  - 公式记错：n0 = n2（漏掉+1）
  - 概念混淆：把度为1的结点当成叶子结点
  - 计算错误：联立方程时算错
- **干扰项设计**：正确选项 + 3个干扰项，分别对应上述常见错误
