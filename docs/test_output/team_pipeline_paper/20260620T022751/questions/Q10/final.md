## 求解过程
### 第一趟 Hoare partition（对整个数组，pivot = 45）

初始数组：`[45, 23, 67, 12, 89, 34]`

- pivot = a[0] = 45
- i = -1, j = 6

**第一轮扫描：**
- i++ → i=0, a[0]=45 ≥ 45 ✓（停止）
- j-- → j=5, a[5]=34 ≤ 45 ✓（停止）
- i=0 < j=5，交换 a[0]↔a[5] → `[34, 23, 67, 12, 89, 45]`

**第二轮扫描：**
- i++ → i=1, a[1]=23 ≥ 45？否 → i++ → i=2, a[2]=67 ≥ 45 ✓（停止）
- j-- → j=4, a[4]=89 ≤ 45？否 → j-- → j=3, a[3]=12 ≤ 45 ✓（停止）
- i=2 < j=3，交换 a[2]↔a[3] → `[34, 23, 12, 67, 89, 45]`

**第三轮扫描：**
- i++ → i=3, a[3]=67 ≥ 45 ✓（停止）
- j-- → j=2, a[2]=12 ≤ 45 ✓（停止）
- i=3 ≥ j=2，退出循环，返回 j=2

**第一趟结果：** `[34, 23, 12, 67, 89, 45]`，返回 j=2

- 左子数组：a[0..2] = `[34, 23, 12]`
- 右子数组：a[3..5] = `[67, 89, 45]`
