## 考点
- **快速排序 partition 过程**：考察基准选择、左右指针移动规则、元素交换时机
- **多趟划分结构**：考察第一趟基准就位后，第二趟对左右子序列分别划分的递归结构

## 难度目标
- **K1=2（较低）**：需知道快速排序基本概念（partition、基准、左右子序列），但概念模糊也能顺着题干模拟
- **K2=3（标准）**：partition 过程中需执行多次比较和交换操作，数字非平凡，需准确记录每一步状态
- **K3=2（较低）**：前两趟划分，步数可控（第一趟 1 次 partition + 第二趟 2 次 partition），路径唯一
- **K4=2（较低）**：存在常规注意点（如基准选择规则、指针移动方向），408 考生基本不会踩坑
- **K5=1（微弱）**：单一知识点（快速排序）内部解决，不涉及其他排序算法或数据结构

## 考察模式
**计算型——快速排序过程模拟**（参考 simulation_00180.md）

理由：
- 经典过程模拟题，给定序列→模拟 partition→写出结果
- 选择题形式，4 选项中 1 正确 3 干扰
- 干扰项设计围绕常见错误路径：partition 规则理解错误、只做了第一趟、基准选择错误

## 出题要求
- **题型**：single_choice（选择题），2 分
- **选项数**：4 个选项，1 正确 3 干扰
- **条件数**：2 个显式条件
  1. 给定关键字序列（6-10 个元素）
  2. 明确 partition 规则（基准选择方式、指针移动规则）
- **条件设计原则**：
  - 序列元素互不相同（避免相等元素处理的歧义）
  - 序列不应是有序或逆序的（避免平凡情况）
  - 第一趟划分后，左右子序列都应至少有 2 个元素（保证第二趟划分有意义）
- **参数取值范围**：整数 10-99，序列长度 6-10

## 子问题规划
本题为选择题，无子问题。考察目标为：
- 准确模拟快速排序前两趟 partition 的划分过程
- 写出前两趟划分后的序列状态

## 参数约束
- **序列长度 n**：6 ≤ n ≤ 10，保证前两趟划分有足够的操作空间
- **序列元素**：整数，10 ≤ 元素值 ≤ 99，元素互不相同
- **基准选择规则**：需明确指定（如"以第一个元素为基准"或"以最后一个元素为基准"）
- **partition 方案**：需明确指定（如 Lomuto 方案或 Hoare 方案），避免歧义
- **一致性约束**：
  - 第一趟划分后，基准左侧元素数 ≥ 2 且右侧元素数 ≥ 2（保证第二趟划分有意义）
  - 序列不应是有序或逆序的（避免平凡情况）
  - 元素值互不相同（避免相等元素处理的歧义）

## 参考经验
- **历史模式**：simulation_00180.md 为快速排序过程模拟题，给定序列→模拟 partition→写出结果
- **难度锚点**：K2 主导（partition 过程中的比较和交换操作），K3 较低（前两趟划分步数可控）
- **典型陷阱**：
  - partition 规则理解错误（左右指针移动方向搞反、交换时机错误）
  - 只做了第一趟划分，没做第二趟
  - 基准选择错误（如选了最后一个元素而非第一个）
  - 第二趟划分时，对左右子序列的划分顺序搞错
