# 题目

给定序列 `[45, 23, 67, 12, 89, 34]`，使用快速排序进行排序。

**排序规则：**
- 基准选择规则：每趟选择第一个元素作为基准
- partition方案：Hoare方案

**Hoare方案的partition过程：**
- 选择第一个元素作为pivot
- i = low - 1, j = high + 1
- 循环：
  - i++ 直到 A[i] >= pivot
  - j-- 直到 A[j] <= pivot
  - 如果 i < j，交换 A[i] 和 A[j]
  - 否则返回 j

**快速排序过程：**
- 第一趟：对整个数组进行partition
- 第二趟：对第一趟划分后的左子数组进行partition，再对右子数组进行partition

求前两趟划分后的数组状态。

**选项：**
A. 正确结果
B. partition规则理解错误（Hoare方案中指针移动方向错误：i++直到A[i]<=pivot，j--直到A[j]>=pivot）的结果
C. 只做了第一趟划分（没有做第二趟）的结果
D. partition方案理解错误（将Hoare方案误用为Lomuto方案）的结果

**注：** Lomuto方案的partition过程为：选择最后一个元素作为pivot，i = low - 1，遍历 j 从 low 到 high-1，如果 A[j] <= pivot，i++，交换 A[i] 和 A[j]，最后交换 A[i+1] 和 A[high]，返回 i+1。

---

## 设计意图

- **考察知识点**：快速排序的Hoare方案partition过程模拟
- **考察形式**：计算型——给定序列，模拟快速排序前两趟划分过程，写出结果
- **难度**：K2主导（partition过程中的比较和交换操作），需手动模拟多步计算

---

## 通过条件（成功判据·可机检）

1. **4选项互异**：A/B/C/D四个值各不相同（exec算出后无碰撞）。
2. **正确值唯一确定**：题干在给定参数下只有一个确定答案，A=该值；不存在"两个选项都对"的歧义。
3. **干扰项对应声明错误类型**：B/C/D各自对应声明的错误类型——即"若学生犯了B声明的错，会得到B的值"。
4. **干扰项有合理性**：每个干扰项是同类题常见误算的真实产物（不是荒谬值），有区分度。
