## 题目

已知单链表结点类型定义如下：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

阅读以下递归函数 `PrintReverse`，完成代码填空并简述其功能。

```c
void PrintReverse(LNode *p) {
    if (__________)          // 填空①
        return;
    PrintReverse(p->next);
    __________;              // 填空②
}
```

**（1）代码填空**（3分）

在横线处填入适当内容，使函数功能完整。

**（2）功能简述**（2分）

简述函数 `PrintReverse` 的功能。

## 参考答案

**填空①：** `p == NULL`（或 `!p`）

**填空②：** `printf("%d ", p->data);`

**功能简述：** 逆序输出单链表结点数据。

## 解析

### 1. 递归执行过程分析

以链表 `1 → 2 → 3 → 4 → 5` 为例，函数执行过程如下：

**调用栈深入阶段（递归调用）：**
```
PrintReverse(1)
  → PrintReverse(2)
    → PrintReverse(3)
      → PrintReverse(4)
        → PrintReverse(5)
          → PrintReverse(NULL)  // 填空①触发，返回
```

**回溯阶段（递归调用之后执行填空②）：**
```
          PrintReverse(NULL) 返回
        PrintReverse(5) 执行 printf("%d ", 5)   → 输出 5
      PrintReverse(4) 执行 printf("%d ", 4)     → 输出 4
    PrintReverse(3) 执行 printf("%d ", 3)       → 输出 3
  PrintReverse(2) 执行 printf("%d ", 2)         → 输出 2
PrintReverse(1) 执行 printf("%d ", 1)           → 输出 1
```

**最终输出：`5 4 3 2 1`**（逆序）

### 2. 填空①：递归基条件 `p == NULL`

- **作用**：当指针为空时终止递归，防止无限递归。
- **为什么不能写成 `p->next == NULL`**：若递归基条件为 `p->next == NULL`，当传入空链表（`p == NULL`）时，会先访问 `p->next` 导致空指针解引用错误。此外，该条件会在最后一个结点处提前终止，逻辑上不够严谨。
- **验证**：空链表输入时，函数直接返回，无输出（输出为 `[]`）。

### 3. 填空②：回溯阶段输出 `printf("%d ", p->data);`

- **位置关键**：输出语句位于递归调用 `PrintReverse(p->next)` **之后**，因此在递归回溯阶段执行，实现逆序效果。
- **若放在递归调用之前**：变成正序输出。验证：错误实现（输出在递归调用前）对链表 `1→2→3→4→5` 的输出为 `[1, 2, 3, 4, 5]`（正序），与正确实现的 `[5, 4, 3, 2, 1]`（逆序）不同。

### 4. 边界情况验证

| 输入 | 输出 | 说明 |
|------|------|------|
| 空链表（`NULL`） | `[]`（无输出） | 填空①直接返回 |
| 单结点链表（`42`） | `[42]` | 递归一次后回溯输出 |
| 五结点链表（`1→2→3→4→5`） | `[5, 4, 3, 2, 1]` | 完整逆序输出 |

### 5. 典型错误分析

**错误1：递归基条件误写为 `p->next == NULL`**

```c
// 错误写法
if (p->next == NULL) {
    printf("%d ", p->data);
    return;
}
```

- **问题**：空链表输入时会访问 `p->next` 导致空指针解引用。虽然在非空链表测试中可能碰巧输出正确结果（对 `1→2→3→4→5` 仍输出 `[5,4,3,2,1]`），但逻辑不严谨，无法处理空链表边界。

**错误2：输出语句放在递归调用之前**

```c
// 错误写法
printf("%d ", p->data);   // 在递归调用之前
PrintReverse(p->next);
```

- **问题**：输出在调用栈深入阶段执行，变为**正序输出**。对链表 `1→2→3→4→5` 输出 `[1, 2, 3, 4, 5]`，与要求的逆序不符。
