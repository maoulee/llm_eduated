## 考点
- **单链表基本结构**：结点定义（data + next 指针）、头指针概念
- **递归函数执行机制**：递归基条件、递归调用、回溯阶段执行顺序
- **递归逆序输出原理**：先递归到尾部再回溯输出的逻辑

## 难度目标
- **K1=2（较低）**：需链表基本概念（结点、指针），但概念模糊也能顺着代码做
- **K2=3（标准）**：需理解递归函数执行逻辑，分析代码填空，涉及非平凡逻辑判断
- **K3=2（较低）**：递归流程推演约2-3步（递归基→递归调用→回溯输出），路径唯一
- **K4=2（较低）**：存在常规注意点（递归基条件、指针移动位置），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他系统

## 考察模式
**代码阅读型——链表递归函数分析**

理由：
- 数据结构经典考察模式，历年高频出现
- 通过代码填空考察对递归执行流程的理解，而非单纯记忆
- 填空+功能说明的组合能同时考察代码理解和抽象概括能力
- 5分题量适中，适合代码阅读题型

## 出题要求
- **题型**：综合题（代码填空 + 功能简述）
- **总条件数**：1段递归函数代码（含1-2处填空）
- **条件设计原则**：
  - 代码结构清晰，递归逻辑完整但关键语句缺失
  - 填空位置应位于递归基条件或递归调用/回溯阶段
  - 代码风格符合考研标准（C语言风格）
- **参数取值范围要求**：
  - 链表长度：3-6个结点（足够展示递归深度，又不至于推演过长）
  - 填空数量：1-2处（5分题不宜过多）

## 子问题规划

### 子问题1：代码填空（约3分）
- **类型**：代码填空
- **考察目标**：理解递归逆序输出的关键语句（递归基条件、递归调用、回溯输出）
- **分值**：3分（每空1-1.5分）
- **与前后问关系**：独立作答，但理解填空有助于回答功能说明

### 子问题2：功能说明（约2分）
- **类型**：功能简述
- **考察目标**：抽象概括函数功能（逆序输出单链表元素）
- **分值**：2分
- **与前后问关系**：基于子问题1的代码理解作答

## 参数约束
- **链表结点结构**：标准结构（data + next），无需自定义字段
- **递归函数签名**：给定函数名和参数（LinkList L 或 LNode *p）
- **填空位置**：
  - 位置1：递归基条件（如 `if (L == NULL) return;` 或类似）
  - 位置2：递归调用或回溯输出语句（如 `ReversePrint(L->next);` 或 `printf(...);`）
- **填空数量**：1-2处，两处填空应分别位于递归的不同阶段（基条件+递归/回溯）
- **代码完整性**：除填空外，代码结构完整可运行
- **链表长度**：题干可给出示例链表长度（3-6个结点），用于辅助理解

## 参考经验
- **历史模式**：代码阅读+填空是数据结构高频考察模式，递归函数分析是链表章节经典题型
- **难度锚点**：K2主导（代码逻辑分析），K3较低（递归流程推演步数少）
- **典型陷阱**：
  - 递归基条件写错（如 `L->next == NULL` 而非 `L == NULL`）
  - 混淆递归调用和回溯阶段的执行顺序
  - 功能描述不完整（只说"输出"不说"逆序"）
