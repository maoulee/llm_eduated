# 题目：Dijkstra算法手工模拟

## 题干

已知有向带权图 G = (V, E)，其中顶点集 V = {A, B, C, D, E, F}，边集 E 及权值如下表所示：

| 边   | 权值 |
|------|------|
| A→B  | 4    |
| A→C  | 2    |
| B→D  | 3    |
| B→E  | 1    |
| C→B  | 1    |
| C→D  | 5    |
| C→E  | 8    |
| D→E  | 2    |
| D→F  | 6    |
| E→F  | 3    |

以顶点 A 为源点，执行 Dijkstra 算法求单源最短路径。算法使用 dist[] 数组记录源点到各顶点的当前最短距离，用 visited[] 标记已确定最短路径的顶点。初始时 dist[A] = 0，其余 dist 值为 ∞，所有顶点均未访问。

**要求：**

（1）写出 Dijkstra 算法执行过程中，每轮迭代后 dist 数组的值。用如下表格格式作答（每轮需标明本轮选中的顶点、各顶点的 dist 值及 visited 状态）：

| 轮次 | 选中顶点 | dist[A] | dist[B] | dist[C] | dist[D] | dist[E] | dist[F] | visited 集合 |
|------|----------|---------|---------|---------|---------|---------|---------|--------------|
| 初始 | —        | 0       | ∞       | ∞       | ∞       | ∞       | ∞       | {}           |
| 1    |          |         |         |         |         |         |         |              |
| 2    |          |         |         |         |         |         |         |              |
| ...  |          |         |         |         |         |         |         |              |

（2）写出从源点 A 到其余各顶点的最短路径（用顶点序列表示）及对应的路径长度。

（3）在算法执行过程中，边 D→E 的松弛操作没有更新 E 的 dist 值。请解释原因，并说明 Dijkstra 算法中"已确定最短路径的顶点不再被松弛"这一性质成立的前提条件。

---

## 设计意图

- **考察知识点**：Dijkstra 算法的手工模拟执行过程、dist 数组的动态维护、最短路径树的构建、算法正确性前提条件
- **K目标**：K3（dist 数组多轮迭代维护）+ K4（陷阱辨析：已确定顶点不再松弛的性质与前提）
- **典型陷阱覆盖**：
  - 顶点 B 的 dist 值从 4 更新为 3（经 C→B 松弛），考察"非直接邻接边的间接松弛"
  - 顶点 E 的 dist 值从 10 更新为 4（经 B→E 松弛），考察"多轮松弛的累积效应"
  - 边 D→E 的松弛不更新 E，考察"已访问顶点不再松弛"的陷阱辨析
- **考察模式**：comprehensive（综合题），三问递进：过程记录 → 结果输出 → 性质辨析

## 通过条件（可机检特征）

本题成立 ⇔ 以下特征可由 gen.py exec 验证：

1. **连通性**：源点 A 到所有其他顶点（B, C, D, E, F）均有路径可达
2. **存在松弛更新**：存在至少一条边 (u, v)，使得 v 的 dist 值在算法执行过程中被更新过至少一次（即 dist[v] 的初始值 ∞ 被有限值替代，或后续被更小的值替代）
3. **存在"已确定不更新"陷阱**：存在至少一条边 (x, y)，使得 y 在 x 之前被标记为 visited，且 dist[x] + w(x,y) > dist[y]（即该边的松弛尝试不会更新 dist[y]）
4. **三角不等式**：最终 dist 值满足对所有边 (u, v) ∈ E，dist[v] ≤ dist[u] + w(u, v)
5. **最短路径一致性**：对每个非源点 v，存在父节点 p[v] 使得 dist[v] = dist[p[v]] + w(p[v], v)，且从 A 到 v 沿父节点回溯的路径长度等于 dist[v]
