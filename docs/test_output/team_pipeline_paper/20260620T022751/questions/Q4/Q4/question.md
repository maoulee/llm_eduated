# 题目

已知模式串 $P = \text{"ababacab"}$，采用 KMP 算法。设模式串下标从 1 开始，$\text{next}$ 数组定义为：$\text{next}[1] = 0$，$\text{next}[j]$ 表示子串 $P[1..j-1]$ 的最长相等真前后缀长度加 1（$j > 1$）。

则 $\text{next}[5]$ 的值为（ ）。

A. 正确结果
B. 索引混淆（将 1-based 误作 0-based，计算 $\text{next}[4]$ 而非 $\text{next}[5]$）的结果
C. 最长相等前后缀识别错误（误认为 "abab" 的最长相等真前后缀为 "aba" 而非 "ab"）的结果
D. 将 $\text{next}$ 值与 $\text{nextval}$ 值混淆（计算 $\text{nextval}[5]$ 而非 $\text{next}[5]$）的结果

---

## 设计意图

### 考察知识点
- **K1（记忆）**：KMP 算法中 next 数组的标准定义
- **K2（理解/应用）**：根据 next 数组定义，对给定模式串代入计算某一位的值
- **K3（分析）**：辨析 next 数组与 nextval 数组的区别、1-based 与 0-based 索引的差异

### 干扰项设计
| 选项 | 错误类型 | 说明 |
|------|----------|------|
| A | 正确 | 按标准定义计算 next[5] |
| B | 索引混淆 | 0-based vs 1-based 混淆，计算 next[4] |
| C | 前后缀识别错误 | 漏掉更短但正确的最长相等真前后缀 |
| D | next/nextval 混淆 | 计算 nextval[5] 而非 next[5] |

### 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **参数约束满足**：模式串长度 len ∈ [6, 10]，目标位置 j 满足 2 ≤ j ≤ len-2
2. **next[j] 值域**：$\text{next}[j] \in [2, 4]$
3. **4 选项互异**：A/B/C/D 四个计算结果各不相同（exec 算出后无碰撞）
4. **next[j] ≠ nextval[j]**：保证选项 A（next 值）与选项 D（nextval 值）不同
5. **正确值唯一确定**：在给定参数和标准定义下，next[j] 有唯一确定值
6. **干扰项对应声明错误类型**：B/C/D 各自对应设计的错误路径，且产生与 A 不同的值
