## 题干

循环队列采用顺序存储结构，定义如下：

```c
#define MAXSIZE 7
typedef struct {
    int data[MAXSIZE];
    int front;  // 队头指针，指向队头元素
    int rear;   // 队尾指针，指向队尾元素的下一个位置
} SqQueue;
```

采用**少用一个存储单元**的策略区分队空和队满。初始时队列为空，`front = rear = 0`。

请补全入队操作 `EnQueue` 的代码，使其在队列未满时将元素 `e` 入队并返回 `1`，队列已满时返回 `0`：

```c
int EnQueue(SqQueue *Q, int e) {
    // ① 判满条件
    if (______________________)
        return 0;
    
    // ② 将元素 e 存入队尾
    Q->data[Q->rear] = e;
    
    // ③ 更新队尾指针（注意循环特性）
    Q->rear = ______________________;
    
    // ④ 返回成功标志
    return ______________________;
}
```

请填入上述代码中 ①~④ 处的正确语句。

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **判满条件正确**：填空①使用 `(Q->rear + 1) % MAXSIZE == Q->front` 判断队满（少用一个单元策略）。
2. **指针更新使用取模**：填空③使用取模运算更新 `rear` 指针，形式为 `(Q->rear + 1) % MAXSIZE`。
3. **返回值正确**：填空④返回 `1` 表示入队成功。
4. **MAXSIZE 非 2 的幂**：`MAXSIZE = 7`，取模运算不退化为位运算，能真实考察取模逻辑。
5. **判满与更新策略一致**：判满条件中的 `(rear+1)%MAXSIZE` 与更新语句中的 `(rear+1)%MAXSIZE` 使用相同的取模策略，无矛盾。
