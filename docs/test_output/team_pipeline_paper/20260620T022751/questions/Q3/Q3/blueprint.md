## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 栈队列和数组 > 数组和特殊矩阵
- primary_target_name: 二维数组列优先存储的地址计算
- question_type: single_choice
- examination_mode: 计算型——地址公式应用

### 难度目标
- k_target: K1=2,K2=3,K3=2,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 单步公式代入计算题，需掌握列优先地址公式，非2的幂次参数制造计算区分度

### 结构要求
- option_count: 4
- distractor_strategy: 行优先公式误用、行列索引颠倒、忘记乘元素大小、列偏移计算错误
- condition_count: 4-5

### 参数约束
- m（行数）: [5, 15]，建议非2的幂次（如7、9、11），与n无强约束
- n（列数）: [5, 15]，建议非2的幂次（如6、8、10），与m无强约束
- base（基地址）: [1000, 5000]，取整百数
- L（元素大小）: {2, 4, 8}，对应常见类型
- i（目标行索引）: 0 ≤ i < m，建议取 m/3 到 2m/3 之间
- j（目标列索引）: 0 ≤ j < n，建议取 n/3 到 2n/3 之间
- 一致性约束: 计算结果 base + (j × m + i) × L < 65536；参数组合确保正确答案与干扰项有明显区分

### 参考经验摘要
- 历史模式: 数组地址计算是数据结构经典题型，考察模式稳定
- 难度锚点: K2=3 标准难度，通过非2的幂次参数实现
- 典型陷阱: 行优先公式误用（最常见）、行列索引颠倒、忘记乘元素大小L、列偏移计算错误（j×n而非j×m）
