# 解析

## 求解过程

**已知条件：**
- 二维数组 `A[5][6]`，行数 `m = 5`，列数 `n = 6`
- 列优先存储，元素大小 `L = 4` 字节，基地址 `base = 1000`
- 已知 `A[1][2]` 地址为 `1044`（验证：`1000 + (2×5 + 1)×4 = 1000 + 44 = 1044` ✓）

**目标：** 求 `A[2][3]` 的存储地址，即 `i = 2, j = 3`。

**列优先存储地址公式：**

```
Address(A[i][j]) = base + (j × m + i) × L
```

**代入计算：**

```
Address(A[2][3]) = 1000 + (3 × 5 + 2) × 4
                 = 1000 + (15 + 2) × 4
                 = 1000 + 17 × 4
                 = 1000 + 68
                 = 1068
```

## 答案

**C. 1068**
