## 题目

已知某二叉树的后序遍历序列为 `A C B F G E D`，中序遍历序列为 `A B C D E F G`。

### （1）还原二叉树结构（6分）

根据上述后序遍历序列与中序遍历序列，还原该二叉树的结构，并画出该二叉树（或清晰描述各节点的父子关系）。

### （2）写出先序遍历序列（4分）

基于第（1）问还原的二叉树，写出其先序遍历序列。

---

## 参考答案

**（1）二叉树结构：**

```
        D
       / \
      B   E
     / \   \
    A   C   G
           /
          F
```

各节点父子关系：
- `D` 为根，左子 `B`，右子 `E`
- `B` 的左子 `A`，右子 `C`
- `E` 无左子，右子 `G`
- `G` 的左子 `F`，无右子
- `A`、`C`、`F` 为叶子节点

**（2）先序遍历序列：** `D B A C E G F`

---

## 解析

### （1）还原二叉树结构（6分）

**已知条件：**
- 后序遍历序列：`A C B F G E D`
- 中序遍历序列：`A B C D E F G`

**还原过程：**

后序遍历的最后一个元素为根节点，因此根节点为 `D`。

在中序遍历中定位 `D`，其左侧 `A B C` 为左子树的中序区间，右侧 `E F G` 为右子树的中序区间。

根据左右子树节点数（各3个），划分后序序列：
- 左子树后序：`A C B`
- 右子树后序：`F G E`

**左子树还原（后序 `A C B`，中序 `A B C`）：**
- 根节点为 `B`（后序最后元素）
- 中序中 `B` 左侧为 `A`（左子树），右侧为 `C`（右子树）
- `A` 和 `C` 均为叶子节点

**右子树还原（后序 `F G E`，中序 `E F G`）：**
- 根节点为 `E`（后序最后元素）
- 中序中 `E` 左侧为空（无左子树），右侧为 `F G`（右子树）
- 对右子树 `F G`（后序 `F G`，中序 `F G`）：根为 `G`
  - `G` 的左子树为 `F`（叶子节点），无右子树

**还原的二叉树结构：**

```
        D
       / \
      B   E
     / \   \
    A   C   G
           /
          F
```

各节点父子关系：
- `D` 为根，左子 `B`，右子 `E`
- `B` 的左子 `A`，右子 `C`
- `E` 无左子，右子 `G`
- `G` 的左子 `F`，无右子
- `A`、`C`、`F` 为叶子节点

递归还原过程共调用 15 次。

---

### （2）先序遍历序列（4分）

先序遍历规则：根 → 左 → 右。

对还原的二叉树逐层展开：

| 步骤 | 访问节点 | 说明 |
|------|---------|------|
| 1 | D | 根节点 |
| 2 | B | D 的左子 |
| 3 | A | B 的左子（叶子） |
| 4 | C | B 的右子（叶子） |
| 5 | E | D 的右子 |
| 6 | G | E 的右子 |
| 7 | F | G 的左子（叶子） |

**先序遍历序列：`D B A C E G F`**

---

**验证：**
- 还原树的中序遍历：`A B C D E F G` ✓（与输入一致）
- 还原树的后序遍历：`A C B F G E D` ✓（与输入一致）
- 先序序列长度 7，包含 A~G 各恰好一次 ✓
- 根节点左右子树均非空（左子树根 B，右子树根 E）✓
