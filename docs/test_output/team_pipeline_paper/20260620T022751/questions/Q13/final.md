## 题目

设关键字序列为：5, 18, 31, 44, 28, 41, 54, 67, 17, 33

散列表表长 $m = 13$，散列函数为 $H(key) = key \bmod 13$，冲突处理方法为**拉链法**（新元素插入到对应链表的**头部**）。

（1）构造散列表，画出散列表的结构。（5分）

（2）计算在等概率情况下，查找成功和查找失败的平均查找长度 ASL。（5分）

## 参考答案

（1）散列表结构：

```
桶 0:  (空)
桶 1:  (空)
桶 2:  67 → 54 → 41 → 28
桶 3:  (空)
桶 4:  17
桶 5:  44 → 31 → 18 → 5
桶 6:  (空)
桶 7:  33
桶 8:  (空)
桶 9:  (空)
桶 10: (空)
桶 11: (空)
桶 12: (空)
```

（2）$ASL_{success} = \dfrac{22}{10} = 2.2$，$ASL_{failure} = \dfrac{10}{13}$

## 解析

### （1）构造散列表

**散列函数与冲突处理：**
- 散列函数：$H(key) = key \bmod 13$
- 冲突处理：拉链法（头插法，新元素插入链表头部）

**逐个插入过程：**

| 关键字 | $H(key) = key \bmod 13$ | 桶号 | 插入后链表（头→尾） |
|--------|--------------------------|------|---------------------|
| 5      | $5 \bmod 13 = 5$         | 5    | 5                   |
| 18     | $18 \bmod 13 = 5$        | 5    | 18 → 5              |
| 31     | $31 \bmod 13 = 5$        | 5    | 31 → 18 → 5         |
| 44     | $44 \bmod 13 = 5$        | 5    | 44 → 31 → 18 → 5    |
| 28     | $28 \bmod 13 = 2$        | 2    | 28                  |
| 41     | $41 \bmod 13 = 2$        | 2    | 41 → 28             |
| 54     | $54 \bmod 13 = 2$        | 2    | 54 → 41 → 28        |
| 67     | $67 \bmod 13 = 2$        | 2    | 67 → 54 → 41 → 28   |
| 17     | $17 \bmod 13 = 4$        | 4    | 17                  |
| 33     | $33 \bmod 13 = 7$        | 7    | 33                  |

**评分标准：**
- 散列函数计算正确（2分）
- 头插法插入顺序正确（2分）
- 最终散列表结构完整正确（1分）

### （2）计算 ASL

**查找成功的 ASL：**

查找成功时，每个关键字的比较次数等于其在链表中的位置（从 1 开始计数）：

| 关键字 | 桶号 | 链中位置 | 比较次数 |
|--------|------|----------|----------|
| 5      | 5    | 4        | 4        |
| 18     | 5    | 3        | 3        |
| 31     | 5    | 2        | 2        |
| 44     | 5    | 1        | 1        |
| 28     | 2    | 4        | 4        |
| 41     | 2    | 3        | 3        |
| 54     | 2    | 2        | 2        |
| 67     | 2    | 1        | 1        |
| 17     | 4    | 1        | 1        |
| 33     | 7    | 1        | 1        |

$$ASL_{success} = \frac{4 + 3 + 2 + 1 + 4 + 3 + 2 + 1 + 1 + 1}{10} = \frac{22}{10} = 2.2$$

**查找失败的 ASL：**

查找失败时，在桶 $j$ 中查找失败需要比较的次数等于该桶链表的长度（即链中元素个数）：

| 桶号 | 链表长度 | 失败比较次数 |
|------|----------|--------------|
| 0    | 0        | 0            |
| 1    | 0        | 0            |
| 2    | 4        | 4            |
| 3    | 0        | 0            |
| 4    | 1        | 1            |
| 5    | 4        | 4            |
| 6    | 0        | 0            |
| 7    | 1        | 1            |
| 8    | 0        | 0            |
| 9    | 0        | 0            |
| 10   | 0        | 0            |
| 11   | 0        | 0            |
| 12   | 0        | 0            |

$$ASL_{failure} = \frac{0 + 0 + 4 + 0 + 1 + 4 + 0 + 1 + 0 + 0 + 0 + 0 + 0}{13} = \frac{10}{13}$$

**评分标准：**
- ASL 成功公式正确、分母为 $n=10$（2分）
- ASL 失败公式正确、分母为 $m=13$（2分）
- 计算结果正确（1分）

**关键考点提示：** ASL 失败的分母为表长 $m$（13），而非关键字个数 $n$（10），这是拉链法与开放定址法的重要区别。
