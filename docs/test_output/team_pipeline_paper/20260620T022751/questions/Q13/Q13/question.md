# 题目

设关键字序列为：5, 18, 31, 44, 28, 41, 54, 67, 17, 33

散列表表长 $m = 13$，散列函数为 $H(key) = key \bmod 13$，冲突处理方法为**拉链法**（新元素插入到对应链表的**头部**）。

（1）构造散列表，画出散列表的结构。（5分）

（2）计算在等概率情况下，查找成功和查找失败的平均查找长度 ASL。（5分）

---

## 设计意图

本题考察散列表的拉链法构造与 ASL 计算，核心知识点包括：
1. 散列函数 $H(key) = key \bmod m$ 的应用
2. 拉链法处理冲突（头插法）
3. ASL 成功与失败的计算公式及区别（失败 ASL 分母为 $m$ 而非 $n$）

**参数设计说明：**
- 表长 $m = 13$（质数，符合散列表设计惯例）
- 关键字个数 $n = 10$，装填因子 $\alpha = 10/13 \approx 0.77$
- 关键字序列经设计，使得 $key \bmod 13$ 的分布不均匀，产生有意义的冲突
- 非空链表 4 条，最长链长度 4，既考察冲突处理又不至于计算过于复杂

---

## 通过条件（成功判据）

本题成立 ⇔ 以下特征可被机检验证：

1. **冲突确实发生**：构造的散列表中，至少存在 2 条链长度 $\geq 2$ 的链表（验证拉链法冲突处理被真正考察，而非无冲突的平凡情况）
2. **冲突分布合理**：最长链长度 $\in [2, 4]$（验证参数不退化，既非无冲突也非极端冲突）
3. **ASL 成功可计算**：$ASL_{success} = \frac{\sum_{i=1}^{n} C_i}{n}$，其中 $C_i$ 为第 $i$ 个关键字的查找长度，$n = 10$
4. **ASL 失败分母为 m**：$ASL_{failure} = \frac{\sum_{j=0}^{m-1} b_j}{m}$，分母为 $m = 13$（而非 $n = 10$），$b_j$ 为在第 $j$ 号桶查找失败时的比较次数
5. **非空链表数量在 [2, 4] 范围内**：验证哈希值分布不均匀但不过度集中
