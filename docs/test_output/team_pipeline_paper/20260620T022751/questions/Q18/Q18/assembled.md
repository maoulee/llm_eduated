## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树遍历
- primary_target_name: 求二叉树中所有叶子结点到根的路径
- question_type: comprehensive
- examination_mode: 算法设计型——二叉树遍历与路径算法设计

### 难度目标
- k_target: K1=1,K2=2,K3=2,K4=3,K5=4
- difficulty_level: 4
- difficulty_rationale: 算法设计题，需结合遍历框架、路径维护、递归参数传递、回溯逻辑多个模块联动，跨域联动需求高（K5=4），存在路径回溯、叶子判断等陷阱（K4=3），基础认知和计算需求低

### 结构要求
- sub_question_count: 3
- sub_question_structure:
  - Q1: 定义二叉链表结点类型（约2分）
  - Q2: 描述算法思想（约4分）
  - Q3: 写出C/C++代码并注释（约10分）
- dependency: 逻辑递进（Q1为Q3提供类型基础，Q2为Q3提供思路），但各问独立得分
- condition_count: 1个核心条件（二叉链表存储的二叉树，输出所有叶子到根的路径）

### 参数约束
- 二叉树形态: 树高3-5层，叶子结点4-8个，结点数据用字母或简单整数
- 存储结构: 二叉链表（BiTNode），不含父指针
- 路径输出格式: 题干明确指定方向（根→...→叶子 或 叶子→...→根）
- 编程语言: C或C++
- 参数间一致性: 树形态需保证有多个叶子结点，避免退化情况（空树、单结点）

### 参考经验摘要
- 历史模式: 2014_Q41，三段式（定义结构→描述思想→写代码）是数据结构算法设计题固定模式
- 难度锚点: K5主导（跨域联动=4），K4次之（陷阱路由=3），K1-K3较低（1-2）
- 典型陷阱:
  1. 路径回溯忘记撤销
  2. 叶子结点判断条件错误（lchild==NULL && rchild==NULL）
  3. 空树/单结点树边界情况
  4. 路径输出方向与题干相反
  5. 递归参数设计不合理
