# 解析

## 已知条件

- 二叉树总结点数：n = 831
- 度为 1 的结点数：n₁ = 30
- 求：叶子结点数（度为 0 的结点数）n₀

## 求解过程

**步骤 1：列出二叉树基本性质**

二叉树有两个核心性质：
1. n₀ = n₂ + 1（叶子结点数 = 度为 2 的结点数 + 1）
2. n = n₀ + n₁ + n₂（总结点数 = 各类结点数之和）

**步骤 2：联立方程求解**

将性质 1 代入性质 2：

n = (n₂ + 1) + n₁ + n₂ = 2n₂ + n₁ + 1

解得：

n₂ = (n - n₁ - 1) / 2 = (831 - 30 - 1) / 2 = 400

再求 n₀：

n₀ = n₂ + 1 = 400 + 1 = 401

## 答案

**A. 401**

## 选项分析

| 选项 | 值 | 类型 | 说明 |
|------|-----|------|------|
| A | 401 | **正确** | 正确联立 n = n₀ + n₁ + n₂ 与 n₀ = n₂ + 1 求解 |
| B | 400 | 干扰 | 公式记反，误用 n₂ = n₀ + 1，联立 n = n₀ + n₁ + (n₀ + 1) = 2n₀ + n₁ + 1，解得 n₀ = (831 - 30 - 1) / 2 = 400 |
| C | 416 | 干扰 | 误用完全二叉树性质，假设 n₁ = 0（忽略题干 n₁ = 30），按 n = n₀ + n₂ = 2n₀ - 1 求解，得 n₀ = (831 + 1) / 2 = 416 |
| D | 31 | 干扰 | 混淆公式，误认为 n₀ = n₁ + 1，直接代入 n₁ = 30 得 n₀ = 31 |
