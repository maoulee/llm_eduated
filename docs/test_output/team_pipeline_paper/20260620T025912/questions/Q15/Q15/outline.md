## 考点
- **循环队列基本结构**：front、rear、maxsize 的含义与初始值
- **判满条件**：`(rear + 1) % maxsize == front`，考察牺牲一个存储单元的判满策略
- **判空条件**：`front == rear`，考察空队列的标识
- **rear 更新**：`rear = (rear + 1) % maxsize`，考察模运算实现循环
- **front 更新**：`front = (front + 1) % maxsize`，考察模运算实现循环

## 难度目标
- **K1=2（较低）**：需知道循环队列 front/rear 的基本概念，但概念模糊也能顺着代码框架填空
- **K2=3（标准）**：需正确写出模运算表达式，涉及取模计算，非简单心算
- **K3=2（较低）**：每个空只需 1-2 步推导（如判满→写条件），路径唯一
- **K4=2（较低）**：存在常规注意点（判满条件易写成 `rear == front` 或漏掉 `% maxsize`），408 考生基本不会踩坑
- **K5=1（微弱）**：单一知识点（循环队列）内部解决，不涉及其他数据结构

## 参数约束
- **maxsize**：取值范围 5-10，整数，在题干中显式给出
- **front/rear 初始值**：均为 0（标准初始化）
- **队列元素类型**：int 或 char，简单标量类型
- **函数签名**：入队函数接收元素参数，出队函数返回元素或 void
- **一致性约束**：
  - 判满条件必须使用牺牲一个单元的策略 `(rear+1)%maxsize == front`
  - rear/front 更新必须使用模运算 `% maxsize`
  - 判空条件为 `front == rear`
