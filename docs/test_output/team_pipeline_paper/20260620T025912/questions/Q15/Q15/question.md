# 循环队列操作代码填空

## 题干

循环队列是一种常用的数据结构，它用数组实现队列，通过模运算实现"循环"效果。为避免队满和队空时 `front == rear` 产生歧义，通常**牺牲一个存储单元**作为队满标志。

已知循环队列的存储结构定义如下：

```c
#define MAXSIZE 6  // 队列最大容量（牺牲一个单元后，实际可存5个元素）

typedef struct {
    int data[MAXSIZE];
    int front;  // 队头指针，指向队头元素
    int rear;   // 队尾指针，指向队尾元素的下一个位置
} SqQueue;
```

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **判满条件正确**：空1填入 `(Q->rear + 1) % MAXSIZE == Q->front`，体现"牺牲一个存储单元"的判满策略。
2. **判空条件正确**：空4填入 `Q->front == Q->rear`，体现队空标志。
3. **赋值语句正确**：空2填入 `Q->data[Q->rear] = x`，将元素存入队尾指针所指位置。
4. **rear 更新正确**：空3填入 `Q->rear = (Q->rear + 1) % MAXSIZE`，体现模运算实现循环。
5. **front 更新正确**：空5填入 `Q->front = (Q->front + 1) % MAXSIZE`，体现模运算实现循环。
6. **5个空位互异且覆盖核心考点**：判满、判空、赋值、rear更新、front更新各占一空，无重复考察同一操作。
7. **MAXSIZE=6 使题目成立**：牺牲一个单元后实际可存5个元素，判满条件 `(rear+1)%6 == front` 在入队6次后触发（rear=5时再入队，(5+1)%6=0==front），非平凡结果。
