## 题目

循环队列是一种常用的数据结构，它用数组实现队列，通过模运算实现"循环"效果。为避免队满和队空时 `front == rear` 产生歧义，通常**牺牲一个存储单元**作为队满标志。

已知循环队列的存储结构定义如下：

```c
#define MAXSIZE 6  // 队列最大容量（牺牲一个单元后，实际可存5个元素）

typedef struct {
    int data[MAXSIZE];
    int front;  // 队头指针，指向队头元素
    int rear;   // 队尾指针，指向队尾元素的下一个位置
} SqQueue;
```

初始状态：`front = 0`, `rear = 0`，此时队列为空。

请补全以下循环队列的入队（EnQueue）和出队（DeQueue）操作函数中的空白处（共5空，每空1分）：

```c
// 入队操作：将元素 x 插入队列
int EnQueue(SqQueue *Q, int x) {
    // 空1：判断队列是否已满（牺牲一个单元判满）
    if (__________________________) {
        return 0;  // 队满，入队失败
    }
    
    // 空2：将元素 x 存入队尾位置
    __________________________;
    
    // 空3：更新队尾指针（循环移动）
    __________________________;
    
    return 1;  // 入队成功
}

// 出队操作：删除队头元素，并通过 e 返回其值
int DeQueue(SqQueue *Q, int *e) {
    // 空4：判断队列是否为空
    if (__________________________) {
        return 0;  // 队空，出队失败
    }
    
    *e = Q->data[Q->front];
    
    // 空5：更新队头指针（循环移动）
    __________________________;
    
    return 1;  // 出队成功
}
```

## 参考答案

| 空号 | 答案 |
|------|------|
| 空1 | `(Q->rear + 1) % MAXSIZE == Q->front` |
| 空2 | `Q->data[Q->rear] = x` |
| 空3 | `Q->rear = (Q->rear + 1) % MAXSIZE` |
| 空4 | `Q->front == Q->rear` |
| 空5 | `Q->front = (Q->front + 1) % MAXSIZE` |

## 解析

### 空1：判满条件

**答案**：`(Q->rear + 1) % MAXSIZE == Q->front`

**解析**：循环队列牺牲一个存储单元来区分队满和队空。当 `(rear + 1) % MAXSIZE == front` 时，说明再入队一个元素就会与队头重合，此时判定为队满。以 MAXSIZE=6 为例，初始 front=0、rear=0，入队 5 个元素后 rear=5，此时 `(5+1)%6 = 0 == front`，判满条件触发，第 6 个元素无法入队。

### 空2：赋值语句

**答案**：`Q->data[Q->rear] = x`

**解析**：`rear` 指针始终指向队尾元素的下一个位置（即下一个可插入位置），因此直接将元素 `x` 存入 `Q->data[Q->rear]` 即可。

### 空3：rear 更新

**答案**：`Q->rear = (Q->rear + 1) % MAXSIZE`

**解析**：入队后 rear 指针需要向前移动一位。使用模运算 `(rear + 1) % MAXSIZE` 实现循环效果——当 rear 到达数组末尾（MAXSIZE-1）时，下一次移动回到 0。

### 空4：判空条件

**答案**：`Q->front == Q->rear`

**解析**：初始状态 front=rear=0，队列为空。出队操作会使 front 追上 rear，当两者再次相等时队列为空。这与队满条件 `(rear+1)%MAXSIZE == front` 形成区分，正是牺牲一个存储单元的目的。

### 空5：front 更新

**答案**：`Q->front = (Q->front + 1) % MAXSIZE`

**解析**：出队后 front 指针需要向前移动一位，同样使用模运算 `(front + 1) % MAXSIZE` 实现循环效果。
