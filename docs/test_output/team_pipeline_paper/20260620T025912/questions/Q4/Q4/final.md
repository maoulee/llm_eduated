## 题目
在KMP字符串匹配算法中，模式串P的next数组定义为：next[j]表示子串P[0..j-1]的最长相等真前后缀的长度（即P[0..j-1]的最长公共真前缀与真后缀的长度）。若不存在相等真前后缀，则next[j]=0。

设模式串 P = "ababac"，采用上述next数组定义，求 next[5] 的值。


## 选项
A. 正确结果
B. 错误理解next定义（将next[j]误认为LPS(P[0..j-1])+1）的结果
C. 前后缀匹配判断错误（仅匹配到较短的相等前后缀）的结果
D. 混淆next[j]与next[j+1]（误用P[0..j]的LPS值）的结果


## 求解过程
### 第一步：明确求解对象

next[5] 对应子串 P[0..4] = "ababa"，需求其最长相等真前后缀的长度。

### 第二步：暴力枚举法（基准）

对 P[0..4] = "ababa"，枚举所有可能的真前后缀长度（1 到 4）：

| 长度 | 前缀 | 后缀 | 是否相等 |
|------|------|------|----------|
| 1 | "a" | "a" | ✓ |
| 2 | "ab" | "ba" | ✗ |
| 3 | "aba" | "aba" | ✓ |
| 4 | "abab" | "baba" | ✗ |

最长相等真前后缀长度为 **3**，即 next[5] = 3。

完整 next 数组（暴力枚举）：[0, 0, 0, 1, 2, 3, 0]

### 第三步：KMP递推法（交叉验证）

采用标准 KMP next 数组递推：

```
next[1] = 0（初始）
j=2: P[0]='a' ≠ P[1]='b' → k=0, next[2]=0
j=3: P[0]='a' = P[2]='a' → k=1, next[3]=1
j=4: P[1]='b' = P[3]='b' → k=2, next[4]=2
j=5: P[2]='a' = P[4]='a' → k=3, next[5]=3
j=6: P[3]='b' ≠ P[5]='c' → k=next[3]=1, P[1]='b' ≠ P[5]='c' → k=next[1]=0, P[0]='a' ≠ P[5]='c' → k=0, next[6]=0
```

完整 next 数组（KMP递推）：[0, 0, 0, 1, 2, 3, 0]

**交叉验证：两种方法结果一致，next[5] = 3。**
