# 题目：KMP算法next数组计算

## 题干

在KMP字符串匹配算法中，模式串P的next数组定义为：next[j]表示子串P[0..j-1]的最长相等真前后缀的长度（即P[0..j-1]的最长公共真前缀与真后缀的长度）。若不存在相等真前后缀，则next[j]=0。

设模式串 P = "ababac"，采用上述next数组定义，求 next[5] 的值。

## 选项

A. 正确结果
B. 错误理解next定义（将next[j]误认为LPS(P[0..j-1])+1）的结果
C. 前后缀匹配判断错误（仅匹配到较短的相等前后缀）的结果
D. 混淆next[j]与next[j+1]（误用P[0..j]的LPS值）的结果

## 设计意图

- **考察知识点**：KMP算法中next数组的定义与计算
- **考察能力**：理解next数组定义（最长相等真前后缀长度），并能正确计算指定位置的next值
- **难度定位**：K2=3（标准计算），K3=2（仅需求某一位值）
- **干扰项设计**：
  - B：next定义版本混淆（+1偏移错误）
  - C：前后缀匹配边界判断错误（匹配长度偏短）
  - D：next[j]与next[j+1]混淆（使用P[0..j]而非P[0..j-1]的LPS）

## 通过条件（成功判据·可机检）

本题成立 ⇔ 以下特征全部满足：

1. **next[5]非平凡**：next[5] ≥ 1（保证考点被触发，非退化情况）
2. **4选项互异**：A/B/C/D四个计算结果各不相同（无碰撞）
3. **正确值唯一确定**：在给定P="ababac"和next定义下，next[5]有唯一确定值
4. **干扰项对应声明错误类型**：B/C/D各自对应题干中声明的错误类型，而非随机扰动值
5. **干扰项有合理性**：每个干扰项是KMP算法学习中常见误算的真实产物
