## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 排序 > 插入排序与交换排序
- primary_target_name: 给定序列用直接插入和冒泡排序写出每趟结果对比
- question_type: comprehensive
- examination_mode: 推演型——排序过程手工模拟与对比

### 难度目标
- k_target: K1=1,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 4
- difficulty_rationale: 需手动模拟两种排序的多趟过程并对比分析，多步推演为主，轻量启发式估算

### 结构要求
- sub_question_count: 3
- sub_question_structure: 
  - Q1: 直接插入排序每趟结果（4分）
  - Q2: 冒泡排序每趟结果（4分）
  - Q3: 两种算法特点对比分析（2分）
- distractor_strategy: 不适用（综合题）
- condition_count: 1（待排序关键字序列）

### 参数约束
- 序列长度 n: 6 ≤ n ≤ 10，确保两种算法都有足够的趟数体现过程
- 元素值范围: 1-100 范围内的整数
- 元素互异性: 所有元素互不相同
- 序列无序性: 不能是已排序、逆序或近乎有序序列
- 参数间一致性: 序列长度与元素值无直接约束关系，但需保证非平凡性

### 参考经验摘要
- 历史模式: 2010_Q11、2020_Q11 均采用"给定序列→两种排序算法分别写出每趟结果→对比分析"的模式
- 难度锚点: K3=4 为主导，多步推演+状态维持是核心难点
- 典型陷阱: 直接插入排序插入位置判断错误、冒泡排序趟数计数错误、对比分析遗漏维度
