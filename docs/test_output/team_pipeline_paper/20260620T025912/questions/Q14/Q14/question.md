# 题目

给定关键字序列：`[49, 38, 65, 97, 76, 13, 27, 45]`

## 要求

（1）使用**直接插入排序**算法对该序列进行排序，写出每一趟排序后的结果。（4分）

（2）使用**冒泡排序**算法对该序列进行排序，写出每一趟排序后的结果。（4分）

（3）对比分析直接插入排序和冒泡排序在**时间复杂度**、**空间复杂度**和**稳定性**方面的特点。（2分）

**说明**：
- 直接插入排序：从第 2 个元素开始，依次将每个元素插入到前面已排序部分的正确位置
- 冒泡排序：每趟将当前未排序部分的最大元素通过相邻交换"冒泡"到末尾
- 两种排序均按**升序**排列
- 禁止使用其他排序算法，禁止跳过任何一趟

---

## 通过条件（成功判据）

本题成立 ⇔ 期待结果满足以下可机检特征：

1. **直接插入排序每趟结果**：
   - 共输出 `n-1 = 7` 趟结果
   - 第 `i` 趟（`i=1,2,...,7`）结果中，前 `i+1` 个元素有序，后 `n-i-1` 个元素保持原相对顺序
   - 最终结果为升序序列

2. **冒泡排序每趟结果**：
   - 共输出最多 `n-1 = 7` 趟结果（若某趟无交换可提前结束）
   - 第 `j` 趟（`j=1,2,...`）结果中，最后 `j` 个元素有序且为最大的 `j` 个元素
   - 最终结果为升序序列

3. **两种排序结果一致性**：直接插入排序和冒泡排序的最终结果相同

4. **对比分析完整性**：对比分析应至少包含时间复杂度、空间复杂度、稳定性三个维度的比较
