# 参考答案与解析

## 题目

给定关键字序列：`[49, 38, 65, 97, 76, 13, 27, 45]`

（1）使用**直接插入排序**算法对该序列进行排序，写出每一趟排序后的结果。（4分）

（2）使用**冒泡排序**算法对该序列进行排序，写出每一趟排序后的结果。（4分）

（3）对比分析直接插入排序和冒泡排序在**时间复杂度**、**空间复杂度**和**稳定性**方面的特点。（2分）

---

## 参考答案

### （1）直接插入排序每趟结果

原始序列：`[49, 38, 65, 97, 76, 13, 27, 45]`

| 趟数 | 排序后结果 | 说明 |
|:---:|:---|:---|
| 第1趟 | `[38, 49, 65, 97, 76, 13, 27, 45]` | 将38插入到49之前 |
| 第2趟 | `[38, 49, 65, 97, 76, 13, 27, 45]` | 65已在正确位置 |
| 第3趟 | `[38, 49, 65, 97, 76, 13, 27, 45]` | 97已在正确位置 |
| 第4趟 | `[38, 49, 65, 76, 97, 13, 27, 45]` | 将76插入到65和97之间 |
| 第5趟 | `[13, 38, 49, 65, 76, 97, 27, 45]` | 将13插入到最前面 |
| 第6趟 | `[13, 27, 38, 49, 65, 76, 97, 45]` | 将27插入到13和38之间 |
| 第7趟 | `[13, 27, 38, 45, 49, 65, 76, 97]` | 将45插入到38和49之间 |

共 **7 趟**（n-1=7），最终结果为升序序列。

### （2）冒泡排序每趟结果

原始序列：`[49, 38, 65, 97, 76, 13, 27, 45]`

| 趟数 | 排序后结果 | 说明 |
|:---:|:---|:---|
| 第1趟 | `[38, 49, 65, 76, 13, 27, 45, 97]` | 97冒泡到末尾 |
| 第2趟 | `[38, 49, 65, 13, 27, 45, 76, 97]` | 76冒泡到倒数第2位 |
| 第3趟 | `[38, 49, 13, 27, 45, 65, 76, 97]` | 65冒泡到倒数第3位 |
| 第4趟 | `[38, 13, 27, 45, 49, 65, 76, 97]` | 49冒泡到倒数第4位 |
| 第5趟 | `[13, 27, 38, 45, 49, 65, 76, 97]` | 38冒泡到倒数第5位 |
| 第6趟 | `[13, 27, 38, 45, 49, 65, 76, 97]` | 无交换，可提前结束 |

共 **6 趟**（第6趟无交换，提前结束），最终结果为升序序列。

---

### （3）对比分析

| 维度 | 直接插入排序 | 冒泡排序 |
|:---:|:---|:---|
| **时间复杂度** | 最好 O(n)，最坏 O(n²)，平均 O(n²) | 最好 O(n)，最坏 O(n²)，平均 O(n²) |
| **空间复杂度** | O(1)，原地排序 | O(1)，原地排序 |
| **稳定性** | 稳定 | 稳定 |

**总结**：两种排序算法在时间复杂度、空间复杂度和稳定性方面表现相同。直接插入排序在基本有序的情况下表现更优（移动次数少），冒泡排序通过交换实现排序，在数据量较小时两者性能接近。

## 解题要点

1. **直接插入排序**：从第2个元素开始，依次将每个元素插入到前面已排序部分的正确位置。第 i 趟后，前 i+1 个元素有序，后 n-i-1 个元素保持原相对顺序。

2. **冒泡排序**：每趟将当前未排序部分的最大元素通过相邻交换"冒泡"到末尾。第 j 趟后，最后 j 个元素有序且为最大的 j 个元素。若某趟无交换可提前结束。

3. **两种排序的最终结果相同**，均为升序序列 `[13, 27, 38, 45, 49, 65, 76, 97]`。
