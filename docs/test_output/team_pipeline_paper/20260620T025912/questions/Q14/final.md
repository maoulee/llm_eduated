## 题目

给定关键字序列：`[49, 38, 65, 97, 76, 13, 27, 45]`

（1）使用**直接插入排序**算法对该序列进行排序，写出每一趟排序后的结果。（4分）

（2）使用**冒泡排序**算法对该序列进行排序，写出每一趟排序后的结果。（4分）

（3）对比分析直接插入排序和冒泡排序在**时间复杂度**、**空间复杂度**和**稳定性**方面的特点。（2分）

**说明**：
- 直接插入排序：从第 2 个元素开始，依次将每个元素插入到前面已排序部分的正确位置
- 冒泡排序：每趟将当前未排序部分的最大元素通过相邻交换"冒泡"到末尾
- 两种排序均按**升序**排列
- 禁止使用其他排序算法，禁止跳过任何一趟

## 解析

### （1）直接插入排序过程详解

原始序列：`[49, 38, 65, 97, 76, 13, 27, 45]`

直接插入排序从第 2 个元素开始，依次将每个元素插入到前面已排序部分的正确位置。第 i 趟后，前 i+1 个元素有序，后 n-i-1 个元素保持原相对顺序。

- **第1趟**：将 38 插入到 `[49]` 中 → `[38, 49, 65, 97, 76, 13, 27, 45]`
- **第2趟**：将 65 插入到 `[38, 49]` 中 → 65 已在正确位置 → `[38, 49, 65, 97, 76, 13, 27, 45]`
- **第3趟**：将 97 插入到 `[38, 49, 65]` 中 → 97 已在正确位置 → `[38, 49, 65, 97, 76, 13, 27, 45]`
- **第4趟**：将 76 插入到 `[38, 49, 65, 97]` 中 → 插入到 65 和 97 之间 → `[38, 49, 65, 76, 97, 13, 27, 45]`
- **第5趟**：将 13 插入到 `[38, 49, 65, 76, 97]` 中 → 插入到最前面 → `[13, 38, 49, 65, 76, 97, 27, 45]`
- **第6趟**：将 27 插入到 `[13, 38, 49, 65, 76, 97]` 中 → 插入到 13 和 38 之间 → `[13, 27, 38, 49, 65, 76, 97, 45]`
- **第7趟**：将 45 插入到 `[13, 27, 38, 49, 65, 76, 97]` 中 → 插入到 38 和 49 之间 → `[13, 27, 38, 45, 49, 65, 76, 97]`

共 7 趟（n-1=7），最终结果为升序序列。

### （2）冒泡排序过程详解

原始序列：`[49, 38, 65, 97, 76, 13, 27, 45]`

冒泡排序每趟将当前未排序部分的最大元素通过相邻交换"冒泡"到末尾。第 j 趟后，最后 j 个元素有序且为最大的 j 个元素。若某趟无交换可提前结束。

- **第1趟**：97 冒泡到末尾 → `[38, 49, 65, 76, 13, 27, 45, 97]`
- **第2趟**：76 冒泡到倒数第 2 位 → `[38, 49, 65, 13, 27, 45, 76, 97]`
- **第3趟**：65 冒泡到倒数第 3 位 → `[38, 49, 13, 27, 45, 65, 76, 97]`
- **第4趟**：49 冒泡到倒数第 4 位 → `[38, 13, 27, 45, 49, 65, 76, 97]`
- **第5趟**：38 冒泡到倒数第 5 位 → `[13, 27, 38, 45, 49, 65, 76, 97]`
- **第6趟**：无交换，提前结束 → `[13, 27, 38, 45, 49, 65, 76, 97]`

共 6 趟（第6趟无交换，提前结束），最终结果为升序序列。

### （3）对比分析说明

两种排序算法在时间复杂度、空间复杂度和稳定性方面表现相同：

- **时间复杂度**：最好情况均为 O(n)（已有序），最坏和平均情况均为 O(n²)（逆序或随机）
- **空间复杂度**：均为 O(1)，原地排序，不需要额外空间
- **稳定性**：均为稳定排序，相等元素的相对顺序不会改变

**差异**：直接插入排序在基本有序的情况下表现更优（移动次数少），冒泡排序通过交换实现排序，在数据量较小时两者性能接近。
