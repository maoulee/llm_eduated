# 题目：Dijkstra 算法 dist 数组更新过程

## 题干

给定如下有向带权图 $G=(V, E)$，其中 $V=\{v_1, v_2, v_3, v_4, v_5\}$，边集 $E$ 及权值如下表所示：

| 边 | 权值 |
|---|---|
| $v_1 \to v_2$ | 4 |
| $v_1 \to v_3$ | 2 |
| $v_2 \to v_4$ | 3 |
| $v_2 \to v_5$ | 7 |
| $v_3 \to v_2$ | 1 |
| $v_3 \to v_4$ | 5 |
| $v_3 \to v_5$ | 10 |
| $v_4 \to v_5$ | 3 |

以 $v_1$ 为源点，执行 Dijkstra 算法求单源最短路径。算法使用数组 `dist[]` 记录源点到各顶点的当前最短距离，初始时 `dist[v1]=0`，其余为 $\infty$；使用集合 $S$ 记录已确定最短路径的顶点。

**请回答以下问题：**

（1）算法执行过程中，`dist` 数组的**最终结果**为：
`dist[v1]=` ______，`dist[v2]=` ______，`dist[v3]=` ______，`dist[v4]=` ______，`dist[v5]=` ______

（2）在算法执行过程中，`dist[v2]` 的值共被**更新**了 ______ 次（初始赋值不计为更新，仅统计从 $\infty$ 或其他值被更小值替换的次数）。

（3）在算法执行过程中，`dist[v5]` 的值共被**更新**了 ______ 次。

（4）算法第 3 轮迭代（即第 3 个顶点被加入集合 $S$ 时），被加入 $S$ 的顶点是 ______，此时 `dist` 数组的状态为：`dist[v1]=` ______，`dist[v2]=` ______，`dist[v3]=` ______，`dist[v4]=` ______，`dist[v5]=` ______

---

## 设计意图

- **考察点**：Dijkstra 贪心策略的过程追踪——dist 数组的逐轮更新、顶点选择顺序、最短路径的逐步确定。
- **考察模式**：过程追踪（非仅最终结果），要求考生模拟算法执行，理解"贪心选择"与"松弛操作"的交互。
- **难度 K3**：融合最终结果（子问1）与中间过程（子问2-4），考察密度高。

## 通过条件

本题成立 ⇔ 以下可机检特征被满足：
1. **非平凡性**：至少存在一个顶点 $v \neq v_1$，其 `dist[v]` 在算法执行过程中被更新 ≥1 次（即存在多条路径到达该顶点，且不同路径权值和不同）。
2. **多轮更新**：至少存在一个顶点，其 `dist` 值被更新 ≥2 次（体现 Dijkstra 的逐步松弛特性，而非一次确定）。
3. **过程可追踪**：第 3 轮迭代时，`dist` 数组状态与最终状态不同（算法尚未收敛，中间状态有意义）。
