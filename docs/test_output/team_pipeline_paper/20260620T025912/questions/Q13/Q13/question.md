# 散列表构造与ASL计算（拉链法）

## 基本信息
- **题型**: 综合题
- **知识点**: DS-7 > 7.4 散列表 > 散列表基本概念, DS-7 > 7.4 散列表 > 散列函数, DS-7 > 7.4 散列表 > 冲突处理（拉链法）, DS-7 > 7.1 查找的基本概念 > 平均查找长度 ASL
- **难度**: 3（K2主导，K3辅助）

---

## 题干

给定关键字序列 ⟨15, 14, 21, 22, 23, 20, 10, 17, 24, 16⟩，散列表的存储空间是一个下标从 0 开始的一维数组，表长 m = 7。散列函数为 H(key) = key mod 7，处理冲突采用**拉链法**（链地址法），新元素插入到对应链表的**表头**。

**(1)** 画出（或描述）构造出的散列表结构。（4分）

**(2)** 计算等概率情况下查找成功和查找失败的平均查找长度 ASL。（6分）

---

## 通过条件

本题成立 ⇔ 以下可机检特征全部满足：

1. **关键字序列长度**：n = 10，各元素为正整数且互不相同。
2. **表长**：m = 7（质数），且 m < n。
3. **冲突数量**：关键字 mod 7 后产生 3-5 个冲突（即有 3-5 个地址对应链表长度 ≥ 2）。
4. **ASL 成功 = 15/10**（或约分为 3/2）。
5. **ASL 失败 = 17/7**。
6. **拉链法结构正确**：每个关键字插入到 H(key) 对应链表的表头，链表顺序与插入顺序相反。
7. **ASL 失败分母为 m**：查找失败时，分母为表长 m = 7（而非 n = 10），因为假设查找的关键字其散列值在 0 ~ m-1 之间是等概率的。

---

## 考察意图

- **第(1)问**：考察拉链法构造散列表的过程，重点在于理解冲突处理机制和链表插入顺序（头插法）。
- **第(2)问**：考察 ASL 成功与失败的计算方法，重点在于区分两种场景下的分母（成功为 n，失败为 m）以及同链不同位置查找长度的差异。

## 典型陷阱

- **ASL 失败分母错误**：许多考生会错误地使用关键字数量 n（10）作为分母，而非表长 m（7）。
- **链表插入顺序**：头插法导致同链中后插入的元素在链表前端，查找长度更短。
- **同链查找长度差异**：同一链表中的不同关键字，查找长度不同（取决于在链表中的位置）。
