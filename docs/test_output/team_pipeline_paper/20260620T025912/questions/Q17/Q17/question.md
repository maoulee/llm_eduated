# 数据结构算法设计题

## 题目

**删除单链表中所有值为 x 的结点**

设有一个**带头结点**的单链表 L，结点的数据域为整型（`int`）。请设计算法，删除链表中所有 `data` 域值等于给定值 `x` 的结点，并释放被删除结点的内存空间。

要求完成以下三个部分：

### （1）结点类型定义（2分）

定义单链表的结点类型 `LinkNode`，包含数据域 `data` 和指针域 `next`。

### （2）算法思想描述（4分）

简要描述你的算法设计思想，包括：
- 如何遍历链表并识别待删除结点；
- 如何保证删除操作后链表结构仍然正确（指针更新策略）；
- 如何处理连续多个值均为 `x` 的结点；
- 如何释放被删除结点的内存。

### （3）C/C++ 代码实现（8分）

根据上述算法思想，编写完整的 C/C++ 函数实现。函数原型如下：

```c
void DeleteAll(LinkNode *L, int x);
```

其中：
- `L` 为带头结点的单链表头指针；
- `x` 为待删除的结点值；
- 函数需删除链表中所有 `data == x` 的结点，并释放其内存。

---

## 设计意图

- **考察知识点**：单链表的基本操作、结点删除、指针操作、内存管理
- **考察能力**：算法设计能力、边界情况处理、代码实现能力
- **典型陷阱**：
  - 删除结点后未正确更新前驱指针，导致链表断裂
  - 连续多个值为 `x` 的结点处理错误（如只删除第一个）
  - 误删头结点（头结点不参与删除）
  - 未释放被删除结点的内存，造成内存泄漏
  - 空链表或全为 `x` 的链表等边界情况未处理

## 通过条件（成功判据）

本题成立 ⇔ 算法实现满足以下可机检特征：

1. **正确性**：对任意输入链表和任意值 `x`，执行后链表中不存在 `data == x` 的结点（除头结点外）。
2. **头结点保护**：头结点始终保留，不被删除。
3. **连续值处理**：当链表中存在连续多个值为 `x` 的结点时，全部被正确删除。
4. **内存释放**：每个被删除的结点均调用 `free()` 释放内存。
5. **边界情况**：空链表（仅头结点）、全为 `x` 的链表、无 `x` 的链表均能正确处理。
