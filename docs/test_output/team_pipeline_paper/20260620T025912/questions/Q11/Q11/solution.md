# 二叉树遍历序列还原 — 解析

## 第(1)问：还原二叉树 T 的结构

### 核心方法

利用**后序遍历最后一个元素为根结点**、**中序遍历中根结点左侧为左子树右侧为右子树**的性质，递归还原整棵树。

### 递归推演过程

**第 1 步：确定整棵树的根结点**

- 后序遍历最后一个元素是根结点：**A**
- 在中序遍历中找到 A 的位置，左边 `[G, D, B, E]` 是左子树，右边 `[C, H, F]` 是右子树

**第 2 步：递归还原左子树**

- 左子树的后序遍历：`[G, D, E, B]`，中序遍历：`[G, D, B, E]`
- 后序最后一个元素 **B** 为左子树的根结点
- 在中序 `[G, D, B, E]` 中找到 B，左边 `[G, D]` 是 B 的左子树，右边 `[E]` 是 B 的右子树

**第 3 步：递归还原 B 的左子树**

- 后序遍历：`[G, D]`，中序遍历：`[G, D]`
- 后序最后一个元素 **D** 为根结点
- 在中序 `[G, D]` 中找到 D，左边 `[G]` 是 D 的左子树，右边为空

**第 4 步：递归还原 D 的左子树**

- 后序遍历：`[G]`，中序遍历：`[G]`
- 根结点为 **G**，无左右子树（叶子结点）

**第 5 步：B 的右子树**

- 后序遍历：`[E]`，中序遍历：`[E]`
- 根结点为 **E**，无左右子树（叶子结点）

**第 6 步：递归还原右子树**

- 右子树的后序遍历：`[H, F, C]`，中序遍历：`[C, H, F]`
- 后序最后一个元素 **C** 为右子树的根结点
- 在中序 `[C, H, F]` 中找到 C，左边为空，右边 `[H, F]` 是 C 的右子树

**第 7 步：递归还原 C 的右子树**

- 后序遍历：`[H, F]`，中序遍历：`[H, F]`
- 后序最后一个元素 **F** 为根结点
- 在中序 `[H, F]` 中找到 F，左边 `[H]` 是 F 的左子树，右边为空

**第 8 步：递归还原 F 的左子树**

- 后序遍历：`[H]`，中序遍历：`[H]`
- 根结点为 **H**，无左右子树（叶子结点）

### 二叉树 T 的结构

```
        A
       / \
      B   C
     / \   \
    D   E   F
   /       /
  G       H
```

**各结点的左右孩子关系：**

| 结点 | 左孩子 | 右孩子 |
|------|--------|--------|
| A    | B      | C      |
| B    | D      | E      |
| C    | —      | F      |
| D    | G      | —      |
| E    | —      | —      |
| F    | H      | —      |
| G    | —      | —      |
| H    | —      | —      |

## 第(2)问：先序遍历序列

### 方法

先序遍历按**根 → 左 → 右**的顺序访问结点。对还原出的二叉树执行先序遍历：

```
A → B → D → G → E → C → F → H
```

### 答案

**先序遍历序列：A, B, D, G, E, C, F, H**

---

## 验证

1. **中序遍历验证**：G, D, B, E, A, C, H, F ✓（与题干一致）
2. **后序遍历验证**：G, D, E, B, H, F, C, A ✓（与题干一致）
3. **树结构非退化**：结点 A、B 均同时拥有左右孩子（度为 2）✓
4. **左右子树均非空**：左子树含 4 个结点（B、D、E、G），右子树含 3 个结点（C、F、H）✓
5. **先序序列唯一确定**：长度为 8，首元素为 A ✓
6. **推演步数 ≥ 6**：共 8 步递归推导 ✓
