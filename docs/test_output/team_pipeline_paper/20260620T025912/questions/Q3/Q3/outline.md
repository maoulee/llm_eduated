## 考点
- **二维数组列优先存储地址计算**：核心考察列优先存储的地址公式 `LOC(A[i][j]) = LOC(A[0][0]) + (j × m + i) × L`
- **行优先 vs 列优先的区别**：干扰项设计的关键，学生需准确识别存储方式

## 难度目标
- **K1=2（较低）**：需知道"列优先"概念和地址公式，但公式本身不冷门，概念清晰即可入题
- **K2=3（标准）**：需代入公式进行乘法+加法计算，参数设计为非2的幂次或稍复杂数字，增加计算负担
- **K3=2（较低）**：仅需1步公式代入，路径唯一，无多步推演
- **K4=2（较低）**：存在常规注意点——必须识别"列优先"而非"行优先"，408考生基本不会踩坑
- **K5=1（微弱）**：纯单一知识点内部解决，不涉及其他系统

## 考察模式
**计算型——地址公式直接应用**
- 给定：数组维度(m×n)、基地址、元素大小L、目标元素坐标(i,j)
- 求解：该元素的存储地址
- 这是数据结构中数组存储的经典考察模式，历年高频出现

## 出题要求
- **题型**：单选题（4选项，1正确3干扰）
- **总条件数**：4-5个显式条件（维度、基地址、元素大小、目标坐标、存储方式）
- **条件设计原则**：
  - 明确标注"列优先"存储，避免歧义
  - 基地址建议为较大数值（如1000+），增加计算量
  - 元素大小L取常见值（4或8字节）
- **参数取值范围要求**：
  - 行数m、列数n：3-10之间，不宜过大
  - 基地址：1000-2000之间
  - 元素大小L：4或8字节
  - 目标坐标(i,j)：在有效范围内，且i,j均不为0（避免平凡结果）

## 子问题规划
本题为单选题，无子问题结构。

## 参数约束
- **行数m**：取值范围 [3, 10]，正整数
- **列数n**：取值范围 [3, 10]，正整数
- **基地址LOC(A[0][0])**：取值范围 [1000, 2000]，建议取整百或整千数
- **元素大小L**：取值 {4, 8}，字节
- **目标行索引i**：取值范围 [1, m-1]，确保非首行
- **目标列索引j**：取值范围 [1, n-1]，确保非首列
- **一致性约束**：
  - 行优先结果 ≠ 列优先结果（即 i×n + j ≠ j×m + i），确保干扰项有效
  - 计算结果应在合理范围内（不超过65536）
- **可调自由度**：m、n、基地址、L、i、j均可独立调整，但需满足上述一致性约束

## 参考经验
- **考察模式**：地址计算是数组存储的经典题型，直接公式代入
- **难度锚点**：K2主导，计算量适中，非2的幂次参数增加区分度
- **典型陷阱**：
  1. 行优先公式误用（最常见错误）
  2. 索引从1开始 vs 从0开始混淆
  3. 忘记乘以元素大小L
  4. 列优先公式中m和n位置颠倒
