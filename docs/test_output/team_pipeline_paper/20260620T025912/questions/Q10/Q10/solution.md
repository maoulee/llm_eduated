# 快速排序前两趟划分结果 — 求解过程

## 题目

对初始序列 `(45, 23, 67, 12, 89, 34, 56, 78, 9, 41)` 进行快速排序，采用严蔚敏《数据结构》双指针法，基准取每趟子区间第一个元素，升序排列。求前两趟 partition 后的序列。

---

## 求解过程

### 第一趟：对整个数组 partition

**初始序列**：`[45, 23, 67, 12, 89, 34, 56, 78, 9, 41]`

- 基准 `pivot = 45`（索引 0）
- 左指针 `l = 1`，右指针 `h = 9`

**第 1 轮扫描**：
- `h` 从右向左找 `< 45` 的元素：`arr[9]=41 < 45`，`h` 停在 9
- `l` 从左向右找 `> 45` 的元素：`arr[1]=23 ≤ 45`→`l++`，`arr[2]=67 > 45`，`l` 停在 2
- `l=2 < h=9`，交换 `arr[2]` 和 `arr[9]`
- 序列变为：`[45, 23, 41, 12, 89, 34, 56, 78, 9, 67]`

**第 2 轮扫描**：
- `h` 从右向左找 `< 45` 的元素：`arr[9]=67 ≥ 45`→`h--`，`arr[8]=9 < 45`，`h` 停在 8
- `l` 从左向右找 `> 45` 的元素：`arr[2]=41 ≤ 45`→`l++`，`arr[3]=12 ≤ 45`→`l++`，`arr[4]=89 > 45`，`l` 停在 4
- `l=4 < h=8`，交换 `arr[4]` 和 `arr[8]`
- 序列变为：`[45, 23, 41, 12, 9, 34, 56, 78, 89, 67]`

**第 3 轮扫描**：
- `h` 从右向左找 `< 45` 的元素：`arr[8]=89 ≥ 45`→`h--`，`arr[7]=78 ≥ 45`→`h--`，`arr[6]=56 ≥ 45`→`h--`，`arr[5]=34 < 45`，`h` 停在 5
- `l` 从左向右找 `> 45` 的元素：`arr[4]=9 ≤ 45`→`l++`，`arr[5]=34 ≤ 45`→`l++`，`arr[6]=56 > 45`，`l` 停在 6
- `l=6 > h=5`，不交换，循环结束

**基准归位**：`arr[0]` 与 `arr[5]` 交换
- 序列变为：`[34, 23, 41, 12, 9, 45, 56, 78, 89, 67]`

**第一趟结果**：`[34, 23, 41, 12, 9, 45, 56, 78, 89, 67]`

> 验证：基准 45 归位到索引 5，左侧 `[34, 23, 41, 12, 9]` 全 < 45 ✓，右侧 `[56, 78, 89, 67]` 全 > 45 ✓

---

### 第二趟：对左右两个子区间分别 partition

#### 左子区间 `[34, 23, 41, 12, 9]`（索引 0~4）

- 基准 `pivot = 34`（索引 0）
- 左指针 `l = 1`，右指针 `h = 4`

**第 1 轮扫描**：
- `h` 从右向左找 `< 34` 的元素：`arr[4]=9 < 34`，`h` 停在 4
- `l` 从左向右找 `> 34` 的元素：`arr[1]=23 ≤ 34`→`l++`，`arr[2]=41 > 34`，`l` 停在 2
- `l=2 < h=4`，交换 `arr[2]` 和 `arr[4]`
- 序列变为：`[34, 23, 9, 12, 41, 45, 56, 78, 89, 67]`

**第 2 轮扫描**：
- `h` 从右向左找 `< 34` 的元素：`arr[4]=41 ≥ 34`→`h--`，`arr[3]=12 < 34`，`h` 停在 3
- `l` 从左向右找 `> 34` 的元素：`arr[2]=9 ≤ 34`→`l++`，`arr[3]=12 ≤ 34`→`l++`，`arr[4]=41 > 34`，`l` 停在 4
- `l=4 > h=3`，不交换，循环结束

**基准归位**：`arr[0]` 与 `arr[3]` 交换
- 序列变为：`[12, 23, 9, 34, 41, 45, 56, 78, 89, 67]`

> 验证：基准 34 归位到索引 3，左侧 `[12, 23, 9]` 全 < 34 ✓，右侧 `[41]` 全 > 34 ✓

#### 右子区间 `[56, 78, 89, 67]`（索引 6~9）

- 基准 `pivot = 56`（索引 6）
- 左指针 `l = 7`，右指针 `h = 9`

**第 1 轮扫描**：
- `h` 从右向左找 `< 56` 的元素：`arr[9]=67 ≥ 56`→`h--`，`arr[8]=89 ≥ 56`→`h--`，`arr[7]=78 ≥ 56`→`h--`，`arr[6]=56 ≥ 56`→`h--`，`h=5 < l=7`，扫描停止
- 此时 `l=7 > h=5`，循环结束

**基准归位**：`arr[6]` 与 `arr[5]` 交换
- 序列变为：`[12, 23, 9, 34, 41, 56, 45, 78, 89, 67]`

> 注意：右子区间所有元素均 ≥ 56，`h` 一直左移越过子区间边界，基准 56 与索引 5 的元素交换。

**第二趟结果**：`[12, 23, 9, 34, 41, 56, 45, 78, 89, 67]`

---

## 正确答案

**A. `(12, 23, 9, 34, 41, 56, 45, 78, 89, 67)`**

---

## 干扰项分析

**B. `(9, 23, 12, 34, 41, 45, 56, 78, 89, 67)`**
- 错误类型：基准选择错误（误取最后一个元素为基准）
- 说明：若每趟取子区间最后一个元素为基准，第一趟基准为 41，归位后序列与正确路径完全不同，最终结果如上。

**C. `(12, 23, 9, 34, 41, 45, 56, 78, 89, 67)`**
- 错误类型：第二趟只对左子区间 partition（漏掉右子区间）
- 说明：第二趟仅对左子区间 `[34, 23, 41, 12, 9]` 进行 partition，右子区间 `[56, 78, 89, 67]` 保持第一趟后的状态不变。

**D. `(78, 67, 56, 45, 41, 34, 23, 12, 9, 89)`**
- 错误类型：排序方向搞反（降序而非升序）
- 说明：若按降序排列，第一趟基准 45 归位后左侧应全 > 45、右侧全 < 45，整个划分方向与升序相反。
