# 数据结构选择题 — 快速排序前两趟划分结果

## 题干

对初始序列 `(45, 23, 67, 12, 89, 34, 56, 78, 9, 41)` 进行快速排序，采用以下规则：
- **基准选择**：每趟取当前子区间**第一个元素**作为基准
- **排序方向**：升序
- **Partition 算法**：严蔚敏《数据结构》双指针法（左右指针法），具体规则如下：
  1. 设基准为子区间首元素 `pivot`，左指针 `low` 指向子区间第二个元素，右指针 `high` 指向子区间最后一个元素
  2. 右指针 `high` 从右向左扫描，找到第一个 `< pivot` 的元素停下
  3. 左指针 `low` 从左向右扫描，找到第一个 `> pivot` 的元素停下
  4. 若 `low < high`，交换 `low` 和 `high` 所指元素，重复步骤 2~4
  5. 当 `low == high` 时，将 `pivot` 与 `low`（即 `high`）所指元素交换，基准归位

求**前两趟** partition 后的序列结果为（ ）。

A. 正确结果
B. 基准选择错误（误取最后一个元素为基准）的结果
C. 第二趟只对左子区间 partition（漏掉右子区间）的结果
D. 排序方向搞反（降序而非升序）的结果

---

## 设计意图

- **考察知识点**：快速排序 partition 过程的动态模拟能力
- **考察模式**：计算型——快速排序过程模拟
- **难度**：K2=3（partition 计算）为主导，K3=2（多步推演）为辅助
- **典型陷阱**：基准选择错误、第二趟漏掉一个子区间、指针移动规则错误、排序方向搞反

---

## 通过条件（成功判据·可机检）

本题成立 ⇔ 以下特征全部满足：

1. **第一趟基准归位**：第一趟 partition 后，基准 45 归位（左侧全 < 45，右侧全 > 45）。
2. **第二趟两个子区间基准均归位**：第二趟对左右两个子区间分别 partition 后，左子区间基准（第一趟后左子区间首元素）和右子区间基准（第一趟后右子区间首元素）各自归位（各自左侧全小于该基准、右侧全大于该基准）。
3. **4 选项互异**：A/B/C/D 四个选项的序列值各不相同（exec 算出后无碰撞）。
4. **正确值唯一确定**：题干在给定参数和规则下只有一个确定答案，A=该值；不存在"两个选项都对"的歧义。
5. **干扰项对应声明错误类型**：B/C/D 各自对应题干中声明的那个错误类型（不是随便扰动出的数）——即"若学生犯了 B 声明的错，会得到 B 的值"。
6. **干扰项有合理性**：每个干扰项是同类题常见误算的真实产物（不是荒谬值），有区分度。
