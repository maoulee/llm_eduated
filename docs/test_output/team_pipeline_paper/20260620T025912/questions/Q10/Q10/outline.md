## 考点
- **快速排序 partition 过程**：考察基准选择、左右指针移动规则、元素交换时机
- **快速排序递归结构**：第一趟对整体区间划分，第二趟对两个子区间分别独立划分
- **划分结果的表示**：正确写出每趟 partition 后序列的状态

## 难度目标
- **K1=2（较低）**：需知道快速排序基本概念和 partition 含义，但概念模糊也能顺着题干模拟
- **K2=3（标准）**：partition 过程中需多次比较和交换，涉及非平凡计算，数字不全是 2 的幂
- **K3=2（较低）**：模拟 partition 需多步操作（选基准→左右扫描→交换→递归），但路径唯一、规则明确
- **K4=2（较低）**：存在常规注意点（基准选择方式、边界处理），408 考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他排序算法或数据结构

## 考察模式
**计算型——快速排序过程模拟**（参考 simulation_00180.md）
- 给定初始序列，要求写出前两趟 partition 后的结果
- 第一趟：对整个序列做一次 partition
- 第二趟：对第一趟划分出的两个子区间分别做一次 partition
- 选择题形式，4 个选项中 1 正确 3 干扰

## 出题要求
- **题型**：单选题，4 选项
- **分值**：2 分
- **条件数**：1 个显式条件（初始序列）+ 隐含条件（基准选择规则、排序方向）
- **条件设计原则**：
  - 题干必须明确基准选择方式（如"以第一个元素为基准"）
  - 题干必须明确排序方向（升序/降序）
  - 序列长度适中，保证前两趟 partition 有区分度
- **参数取值范围要求**：
  - 序列长度：8-12 个元素（太短则第二趟无区分度，太长则计算量过大）
  - 元素值：1-100 范围内的整数，避免全相同或已有序
  - 元素应有一定随机性，避免平凡结果

## 子问题规划
本题为选择题，无子问题。考察点集中在：
- 正确模拟第一趟 partition（对整个序列）
- 正确模拟第二趟 partition（对两个子区间分别进行）
- 识别常见错误路径产生的结果

## 参数约束
- **序列长度 n**：8 ≤ n ≤ 12
  - 约束：n 不能太小（<8 则第二趟 partition 后子区间可能只有一个元素，无区分度）
  - 约束：n 不能太大（>12 则手动模拟计算量过大，超出 2 分题合理范围）
- **元素值范围**：1 ≤ 元素值 ≤ 100
  - 约束：元素应互不相同（避免相等元素处理规则带来的歧义）
  - 约束：序列不应已有序或逆序（避免平凡结果）
- **基准选择规则**：必须在题干中明确指定
  - 可选：第一个元素 / 最后一个元素 / 中间元素
  - 约束：一旦选定，全程一致
- **排序方向**：必须在题干中明确指定（升序或降序）
- **partition 算法细节**：
  - 约束：需明确左右指针移动规则（如 Loomis 版本或 Hoare 版本）
  - 约束：基准最终位置需明确（如基准归位到中间）

## 参考经验
- **历史模式**：simulation_00180.md 为快速排序过程模拟题，考察 partition 过程
- **难度锚点**：K2 为主导维度（partition 计算），K3 为辅助（多步推演）
- **典型陷阱**：
  - 基准选择错误（如题干说第一个元素，学生用最后一个）
  - 第二趟只对其中一个子区间做 partition（漏掉另一个）
  - 指针移动规则理解错误（先移动左指针还是右指针）
  - 基准归位位置错误
  - 排序方向搞反（升序写成降序）
