# 题目：单链表递归函数分析

## 题干

阅读以下 C 语言代码，完成填空并回答问题。

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

/* 函数 PrintReverse */
void PrintReverse(LinkList L) {
    if (__________)          /* 空白① */
        return;
    PrintReverse(L->next);
    printf("%d ", L->data);
}
```

设有单链表 L，其元素依次为：12 → 25 → 7 → 33 → 19（头指针为 L）。

### （1）代码填空（3 分）

在空白①处填入正确的语句，使函数 `PrintReverse` 能够正确运行。

### （2）功能简述（2 分）

用一句话说明函数 `PrintReverse` 的功能。

---

## 设计意图

- **考点**：单链表递归遍历机制、递归终止条件辨析、回溯阶段操作理解
- **K 目标**：K2=3（递归逻辑理解为核心难点）
- **典型陷阱**：
  - 递归终止条件混淆：`L == NULL`（正确）vs `L->next == NULL`（错误——会漏输出最后一个元素）
  - 回溯操作位置混淆：`printf` 在递归调用之后（逆序）vs 之前（正序）

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **空白①的正确填法唯一确定**：`L == NULL`（或等价形式 `!L`），且该填法与 `L->next == NULL` 产生不同行为（后者会漏输出尾节点）。
2. **函数逻辑完整**：递归终止条件 + 递归调用 + 回溯输出三要素齐全，构成完整的逆序输出递归结构。
3. **功能描述可验证**：正确功能描述为"逆序输出单链表所有元素"（或等价表述），与"正序输出"形成可区分的对立。
4. **两问独立可答**：第（1）问填空不依赖第（2）问，第（2）问功能描述不依赖填空结果。
