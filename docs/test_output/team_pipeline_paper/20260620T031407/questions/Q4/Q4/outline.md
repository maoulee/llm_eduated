# 题目规划 — outline.md

## 题位信息
- **来源章节**：数据结构 — 串
- **题型**：选择题（4选1）
- **分值**：2分

## 考点定义

### 核心考点
- **KMP算法 next 数组计算**：给定模式串，计算其 next 数组（或 nextval 数组）

### 考察侧重点
- 理解 next[j] 的定义：模式串前 j-1 个字符中最长相等前后缀的长度 + 1（或根据教材定义调整）
- 能够手动推导 next 数组的每个值
- 区分 next 与 nextval 的差异（若考察 nextval）

## K 难度目标

| 维度 | 目标等级 | 说明 |
|------|---------|------|
| K1 知识广度 | 2 | 单一知识点（KMP next数组），不涉及其他算法 |
| K2 计算复杂度 | 3 | 需要逐位推导，模式串长度建议 6-10 字符 |
| K3 陷阱深度 | 3 | 存在明确陷阱：next定义版本差异（从0开始vs从1开始）、nextval优化 |
| K4 跨域联动 | 1 | 纯串匹配算法内部，无跨系统需求 |
| K5 综合难度 | 3 | 标准难度，408考生应掌握但易在细节出错 |

## 考察模式

### 模式选择
**模式：直接计算型**
- 给出模式串，要求计算 next 数组（或 nextval 数组）的某个值或完整数组
- 参考历史经验：KMP next 数组计算是 408 高频考点

### 历史经验参考
- 常见模式串长度：6-8 字符
- 常见陷阱：next 数组下标从 0 还是从 1 开始、nextval 的优化计算
- 干扰项设计：常见错误包括 off-by-one、未考虑 nextval 优化、前后缀判断错误

## 子问题规划

**本题为选择题，无子问题。**

## 参数约束

### 模式串参数
- **长度范围**：6-10 个字符
- **字符集**：建议使用小写字母（a-z），避免特殊字符
- **结构要求**：
  - 必须包含重复子串（否则 next 数组退化为全 0/1，无区分度）
  - 建议包含至少一处前后缀相等的情况
  - 避免全相同字符（如 "aaaaaa"，next 数组过于规律）

### next 数组定义
- **需明确**：采用哪种 next 定义（从 0 开始还是从 1 开始）
- **建议**：在题干中明确说明 next 数组的计算规则，或采用教材标准定义

### 选项约束
- 4 个选项，1 正确 3 干扰
- 干扰项应覆盖常见错误路径：
  - 下标偏移错误（整体 +1 或 -1）
  - nextval 与 next 混淆
  - 前后缀长度计算错误
