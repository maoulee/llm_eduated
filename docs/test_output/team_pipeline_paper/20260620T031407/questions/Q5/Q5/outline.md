## 考点
- **二叉树基本性质**：n0 = n2 + 1（叶子结点数 = 度为2的结点数 + 1）
- **二叉树结点总数公式**：n = n0 + n1 + n2
- **考察侧重点**：由部分结点信息（如总结点数、某类结点数）推算叶子结点数，需联立两个性质公式求解

## 难度目标
- **K1（基础认知）= 2**：需知道二叉树结点分类（度0/1/2）及基本性质名称，但概念清晰即可入题
- **K2（单步代入）= 3**：需联立两个公式求解，涉及简单代数运算，非纯2的幂次友好计算
- **K3（机制推演）= 2**：仅需2步推导（代入公式→求解），路径唯一
- **K4（条件路由）= 2**：存在常规注意点（如区分n0/n1/n2含义），408考生基本不会踩坑
- **K5（综合创新）= 1**：标准性质应用，无需创新组合

## 考察模式
**计算型——公式联立求解**
- 给出二叉树的部分结点信息（如总结点数n、度为1的结点数n1）
- 要求计算叶子结点数n0
- 需联立 n = n0 + n1 + n2 与 n0 = n2 + 1 两个公式
- 参考历史经验：此类题在数据结构选择题中常见，考察公式记忆与简单代数能力

## 出题要求
- **题型**：单选题（4个选项）
- **总条件数**：2个独立条件（如总结点数n、度为1的结点数n1）
- **条件设计原则**：
  - 条件需足够确定唯一解
  - 避免给出n0或n2直接值（否则无需计算）
  - 条件之间需一致（满足二叉树性质约束）
- **参数取值范围要求**：
  - 总结点数 n：建议在 10-100 范围内，非2的幂次以增加计算感
  - 度为1的结点数 n1：需满足 n1 < n 且 (n - n1 - 1) 为偶数（保证n2为整数）
  - 确保 n0 = n2 + 1 成立

## 子问题规划
单选题，无子问题。

## 参数约束
- **n（总结点数）**：取值范围 [10, 100]，建议非2的幂次
- **n1（度为1的结点数）**：取值范围 [0, n-2]，需满足 (n - n1 - 1) % 2 == 0
- **n0（叶子结点数，答案）**：由 n0 = (n - n1 + 1) / 2 计算得出
- **n2（度为2的结点数）**：由 n2 = n0 - 1 计算得出
- **一致性约束**：n = n0 + n1 + n2 必须成立；n0 = n2 + 1 必须成立
- **可调自由度**：n 和 n1 为自由参数，n0 和 n2 由公式确定

## 参考经验
- **考察模式**：二叉树性质选择题常见模式为"给部分结点信息求另一类结点数"
- **难度锚点**：K2=3 对应联立两个公式求解，非简单代入
- **典型陷阱**：
  - 混淆 n0、n1、n2 的含义
  - 忘记 n0 = n2 + 1 性质，仅用 n = n0 + n1 + n2 无法求解
  - 计算错误（如符号错误、除法错误）
- **干扰项设计**：
  - 选项1：仅用 n - n1 计算（忘记n2存在）
  - 选项2：用 n/2 估算（直觉错误）
  - 选项3：计算 n2 而非 n0（答非所问）
  - 选项4：正确答案
