## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树性质
- primary_target_name: 二叉树叶子结点数与度为2结点数的关系应用
- question_type: single_choice
- examination_mode: 计算型——公式联立求解

### 难度目标
- k_target: K1=2,K2=3,K3=2,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 需联立二叉树两个性质公式求解，涉及简单代数运算，非纯2的幂次友好计算

### 结构要求
- option_count: 4
- distractor_strategy: 干扰项对应典型错误路径：①仅用n-n1计算 ②用n/2估算 ③计算n2而非n0 ④正确答案
- condition_count: 2（总结点数n、度为1的结点数n1）

### 参数约束
- n（总结点数）: 取值范围 [10, 100]，建议非2的幂次，确保计算感
- n1（度为1的结点数）: 取值范围 [0, n-2]，需满足 (n - n1 - 1) % 2 == 0（保证n2为整数）
- n0（叶子结点数）: 由公式 n0 = (n - n1 + 1) / 2 计算得出，为正确答案
- n2（度为2的结点数）: 由公式 n2 = n0 - 1 计算得出
- 一致性约束: n = n0 + n1 + n2 必须成立；n0 = n2 + 1 必须成立
- 可调自由度: n 和 n1 为自由参数，n0 和 n2 由公式确定

### 参考经验摘要
- 历史模式: 二叉树性质选择题常见模式为"给部分结点信息求另一类结点数"，需联立 n=n0+n1+n2 与 n0=n2+1
- 难度锚点: K2=3 对应联立两个公式求解，非简单代入；K3=2 对应2步推导路径唯一
- 典型陷阱: 混淆n0/n1/n2含义、忘记n0=n2+1性质、计算错误（符号/除法）
