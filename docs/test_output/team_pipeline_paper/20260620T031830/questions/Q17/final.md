## 题目

已知线性链表 L 采用带头结点的单链表存储结构，头结点的 data 域无意义。给定初始链表 L 的结点数据依次为：

```
12, 8, 8, 15, 23, 8, 31, 42
```

即链表中共有 8 个数据结点（不含头结点），其中值为 x=8 的结点出现 3 次，且存在连续两个结点 data 值均为 8 的情况。

设计一个算法，删除链表 L 中所有 data 域值等于 x 的结点，并释放被删除结点所占的内存空间。

**要求：**

**(1) 结点类型定义（2分）**

定义单链表结点类型 `LinkNode`，包含 data 域和 next 指针域。

**(2) 算法思想描述（4分）**

用简洁的文字描述删除所有值为 x 的结点的算法思想，需说明如何处理连续删除的情况以及边界条件。

**(3) C/C++ 代码实现（8分）**

根据上述算法思想，编写完整的 C/C++ 函数实现。函数原型如下：

```c
void DeleteX(LinkNode *head, int x);
```

其中 `head` 为带头结点的单链表头指针，`x` 为待删除的结点值。

## 参考答案

**(1) 结点类型定义：**

```c
typedef struct LinkNode {
    int data;
    struct LinkNode *next;
} LinkNode;
```

**(2) 算法思想：** 前驱指针法。令 `p` 指向已确认保留的最后一个结点（初始为头结点），`q` 指向 `p->next`。若 `q->data == x` 则删除 `q` 且 `p` 不后移（处理连续删除）；否则 `p` 后移至 `q`。循环至 `q` 为空。

**(3) 代码实现：** 见解析部分完整代码。

**执行结果：** 删除后链表数据依次为 `12, 15, 23, 31, 42`，共保留 5 个结点，删除 3 个结点。

## 解析

### 一、结点类型定义（2分）

```c
typedef struct LinkNode {
    int data;
    struct LinkNode *next;
} LinkNode;
```

**说明：** 单链表结点包含 data 域（存储整型数据）和 next 指针域（指向后继结点）。

---

### 二、算法思想描述（4分）

**核心思想：前驱指针法，逐个检查并删除目标结点。**

1. 令指针 `p` 初始指向头结点（头结点始终保留，`p` 始终指向已确认保留的最后一个结点）。
2. 令指针 `q` 指向 `p` 的直接后继（`q = p->next`）。
3. 循环判断 `q` 是否为空：
   - **若 `q->data == x`**：删除 `q` 结点，执行 `p->next = q->next`，释放 `q` 的内存。**`p` 不后移**，因为 `p->next` 已指向新的待检查结点，这样可以正确处理连续多个值为 x 的结点。
   - **若 `q->data != x`**：`q` 不是目标结点，`p` 后移至 `q`（`p = q`）。
4. 重复步骤 2~3，直到 `q` 为空，遍历结束。

**关键处理：**
- **连续删除**：当遇到连续多个值为 x 的结点时，删除当前 `q` 后 `p` 不后移，下一轮 `q` 自动指向新的后继，继续检查，确保连续目标结点全部被删除。
- **边界条件**：头结点不参与删除（`p` 从头结点开始）；当 `q` 为空时循环终止，不会越界访问。

---

### 三、C/C++ 代码实现（8分）

```c
void DeleteX(LinkNode *head, int x) {
    LinkNode *p = head;          // p 指向已确认保留的最后一个结点，初始为头结点
    LinkNode *q;                 // q 指向待检查的结点
    
    while (p->next != NULL) {
        q = p->next;             // q 指向 p 的直接后继
        if (q->data == x) {
            // 删除 q 结点
            p->next = q->next;   // 跳过 q
            free(q);             // 释放 q 的内存
            // p 不后移，继续检查新的 p->next
        } else {
            // q 不是目标结点，p 后移
            p = q;
        }
    }
}
```

| 2 | 12 | 8 | 8=8 | 删除 q | 12, 8, 15, 23, 8, 31, 42 |
| 3 | 12 | 8 | 8=8 | 删除 q（连续删除） | 12, 15, 23, 8, 31, 42 |
| 4 | 12 | 15 | 15≠8 | p 后移 | 12, 15, 23, 8, 31, 42 |
| 5 | 15 | 23 | 23≠8 | p 后移 | 12, 15, 23, 8, 31, 42 |
