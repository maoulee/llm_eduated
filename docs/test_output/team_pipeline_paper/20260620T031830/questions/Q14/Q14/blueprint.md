## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 排序 > 插入排序与交换排序
- primary_target_name: 给定序列用直接插入和冒泡排序写出每趟结果对比
- question_type: comprehensive
- examination_mode: 推演型——排序过程手工模拟与对比

### 难度目标
- k_target: K1=1,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 4
- difficulty_rationale: 需手动模拟两种排序的多趟过程并对比分析，多步推演为主，轻量启发式估算

### 结构要求
- sub_question_count: 3
- sub_question_structure:
  - q1: 直接插入排序每趟结果（推演计算，4分）
  - q2: 冒泡排序每趟结果（推演计算，4分）
  - q3: 两种算法对比分析（分析，2分）
- dependency: 并行（q1与q2独立推演，q3基于q1/q2结果分析）
- condition_count: 1（仅待排序序列）

### 参数约束
- 序列长度: 6 ≤ n ≤ 10，保证推演量足够
- 元素取值范围: 1-100的整数
- 初始有序度: 部分有序（非完全有序/逆序），保证两种算法推演过程有区分度
- 重复元素: 可选包含1-2个，用于考察稳定性
- 参数一致性: 同一序列用于两种排序，保证对比公平性

### 参考经验摘要
- 历史模式: 2010_Q11（直接插入+希尔）、2020_Q11（直接插入+快排），均为"排序过程模拟+对比"模式
- 难度锚点: K3=4 是该题位典型特征，多趟推演为核心考察点
- 典型陷阱: 
  - 直接插入排序的"已排序区间"边界（从第2个元素开始）
  - 冒泡排序的"趟数"定义（n个元素需n-1趟）
  - 对比分析中遗漏稳定性或适用场景差异
