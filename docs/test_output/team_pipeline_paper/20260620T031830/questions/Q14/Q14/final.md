## 题目

设待排序序列为 R = (49, 38, 65, 97, 76, 13, 27, 49)，采用升序排列。

### （1）直接插入排序（4分）

使用**直接插入排序**对序列 R 进行排序。写出**每一趟排序结束后的序列状态**。

> 说明：直接插入排序第 i 趟（i = 2, 3, …, n）将第 i 个元素插入到前 i-1 个已排序元素的正确位置。共需 n-1 趟。

### （2）冒泡排序（4分）

使用**冒泡排序**对序列 R 进行排序。写出**每一趟排序结束后的序列状态**。

> 说明：冒泡排序第 j 趟（j = 1, 2, …, n-1）从前往后两两比较相邻元素，若逆序则交换，将当前未排序区间中的最大元素"冒泡"到末尾。若某趟未发生任何交换，则排序提前终止。

### （3）对比分析（2分）

基于（1）（2）的排序过程，回答以下问题：

① 两种排序算法完成排序所需的**总趟数**是否相同？说明原因。

② 序列 R 中包含两个值均为 49 的元素，直接插入排序和冒泡排序是否都能保证这两个 49 的**相对位置不变**（即算法稳定性）？简要说明理由。

## 解析

### （1）直接插入排序（4分）

初始序列：R = (49, 38, 65, 97, 76, 13, 27, 49)

直接插入排序共 **7 趟**（n-1 = 8-1 = 7），元素后移 **15 次**。

| 趟数 | 插入元素 | 排序后序列 |
|------|---------|-----------|
| 第2趟 | 38 | (38, 49, 65, 97, 76, 13, 27, 49) |
| 第3趟 | 65 | (38, 49, 65, 97, 76, 13, 27, 49) |
| 第4趟 | 97 | (38, 49, 65, 97, 76, 13, 27, 49) |
| 第5趟 | 76 | (38, 49, 65, 76, 97, 13, 27, 49) |
| 第6趟 | 13 | (13, 38, 49, 65, 76, 97, 27, 49) |
| 第7趟 | 27 | (13, 27, 38, 49, 65, 76, 97, 49) |
| 第8趟 | 49 | (13, 27, 38, 49, 49, 65, 76, 97) |

**最终结果**：(13, 27, 38, 49, 49, 65, 76, 97)

**评分标准**：每趟序列正确得约 0.57 分（7 趟共 4 分），最终结果正确得 1 分。

冒泡排序共 **6 趟**（第7趟无交换，提前终止），交换 **15 次**。

### （3）对比分析（2分）

#### ① 总趟数是否相同？

**不相同。**

- 直接插入排序：**7 趟**（固定 n-1 趟，每趟将一个元素插入到已排序区间）
- 冒泡排序：**6 趟**（第6趟无交换，提前终止）

**原因**：直接插入排序的趟数是固定的 n-1 趟，无论序列初始状态如何，都要对第 2 到第 n 个元素各执行一趟插入操作。而冒泡排序具有提前终止机制——当某趟排序中未发生任何交换时，说明序列已经有序，可以提前结束。本例中冒泡排序第6趟无交换，因此比插入排序少1趟。

#### ② 稳定性分析

**两种算法都能保证两个 49 的相对位置不变，即都是稳定排序算法。**

- **直接插入排序**：在插入过程中，当遇到与待插入元素**相等**的元素时，while 循环条件 `a[j] > key` 不成立（相等时不进入循环），因此待插入元素会放在相等元素的**后面**，相对位置保持不变。本例中第8趟插入第二个 49 时，遇到第一个 49（a[3] = 49），49 > 49 为假，循环终止，第二个 49 被放在第一个 49 之后。

- **冒泡排序**：在相邻元素比较时，只有 `a[i] > a[i+1]`（严格大于）时才交换，相等时不交换。因此两个相等的元素永远不会因彼此而交换位置，相对位置保持不变。

**结论**：直接插入排序和冒泡排序均为**稳定排序算法**。

**评分标准**：① 趟数判断正确 0.5 分，原因说明正确 0.5 分；② 稳定性判断正确 0.5 分，理由说明正确 0.5 分。
