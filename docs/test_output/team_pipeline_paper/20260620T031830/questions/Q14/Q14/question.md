# 题目：直接插入排序与冒泡排序过程对比

## 题干

设待排序序列为 R = (49, 38, 65, 97, 76, 13, 27, 49)，采用升序排列。

### （1）直接插入排序（4分）

使用**直接插入排序**对序列 R 进行排序。写出**每一趟排序结束后的序列状态**。

> 说明：直接插入排序第 i 趟（i = 2, 3, …, n）将第 i 个元素插入到前 i-1 个已排序元素的正确位置。共需 n-1 趟。

### （2）冒泡排序（4分）

使用**冒泡排序**对序列 R 进行排序。写出**每一趟排序结束后的序列状态**。

> 说明：冒泡排序第 j 趟（j = 1, 2, …, n-1）从前往后两两比较相邻元素，若逆序则交换，将当前未排序区间中的最大元素"冒泡"到末尾。若某趟未发生任何交换，则排序提前终止。

### （3）对比分析（2分）

基于（1）（2）的排序过程，回答以下问题：

① 两种排序算法完成排序所需的**总趟数**是否相同？说明原因。

② 序列 R 中包含两个值均为 49 的元素，直接插入排序和冒泡排序是否都能保证这两个 49 的**相对位置不变**（即算法稳定性）？简要说明理由。

---

## 设计意图

- **考察知识点**：直接插入排序的逐趟插入过程、冒泡排序的逐趟冒泡过程、两种算法的趟数特性与稳定性
- **考察模式**：推演型——手工模拟两种排序的多趟过程并对比分析
- **难度定位**：K3=4（多趟推演为核心），K2=2（过程记录），K4=2（对比分析）

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **插入排序至少发生 1 次元素后移**：序列 R 在直接插入排序过程中，至少有一趟需要将已排序区间中的元素向后移动（即存在元素被插入到非末尾位置），证明插入排序的"插入"操作被真正触发。

2. **冒泡排序至少发生 1 次交换**：序列 R 在冒泡排序过程中，至少有一趟发生了相邻元素交换，证明冒泡排序的"冒泡"操作被真正触发。

3. **两种算法最终结果一致**：直接插入排序和冒泡排序的最终排序结果相同（均为升序排列），保证对比的公平性。

4. **稳定性可检验**：序列 R 中两个 49 在排序前后的相对位置关系可被追踪，用于验证两种算法的稳定性特征。

5. **两种算法的总趟数不同**：直接插入排序的趟数（n-1 趟，固定）与冒泡排序的实际有效趟数（可能提前终止）存在差异，使对比分析有实质内容。
