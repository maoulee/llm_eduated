# 题目

## 题干

阅读以下 C 语言代码片段，当 `n = 128` 时，程序运行结束后变量 `sum` 的值为多少？

```c
int sum = 0;
for (int i = 1; i <= n; i *= 2) {
    sum += i;
}
```

## 选项

A. 127
B. 255
C. 256
D. 511

## 设计意图

考察等比数列求和与循环结构的结合理解。循环变量 `i` 按 2 的幂次增长（1, 2, 4, 8, ...），构成公比为 2 的等比数列，求和公式为 $S_n = 2^n - 1$。

## 通过条件

本题成立 ⇔ 以下可机检特征满足：
1. 循环执行 8 轮，`i` 依次取值为 1, 2, 4, 8, 16, 32, 64, 128
2. `sum` 的最终值为 255（即 $2^8 - 1$）
3. 选项 B（255）为正确答案，其他选项为典型错误路径结果
