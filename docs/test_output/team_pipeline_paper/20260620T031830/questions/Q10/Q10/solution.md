# 快速排序前两趟划分结果 — 解析

## 题目回顾

设有初始序列：`[12, 5, 18, 3, 9, 7, 15, 2, 10, 4]`

采用快速排序，partition 规则：
- 基准选择：每次取当前子序列的**第一个元素**作为基准（pivot）
- 双指针扫描：左指针 `i` 从第二个元素开始向右，右指针 `j` 从最后一个元素开始向左
  - `i` 向右直到找到 **大于** 基准的元素
  - `j` 向左直到找到 **小于** 基准的元素
  - 若 `i < j`，交换 `a[i]` 与 `a[j]`
  - 若 `i ≥ j`，扫描结束
- 基准归位：扫描结束后，将基准元素与 `a[j]` 交换

**第一趟**对整个序列 `[0..9]` 执行 partition；**第二趟**对第一趟产生的**左侧子序列**执行 partition。

---

## 正确答案：A

### 第一趟 partition（对整个序列 `[0..9]`）

初始序列：`[12, 5, 18, 3, 9, 7, 15, 2, 10, 4]`，pivot = 12，i = 1，j = 9

**第一轮扫描：**
- i 向右：a[1]=5≤12，i=2；a[2]=18>12，停，i=2
- j 向左：a[9]=4<12，停，j=9
- i=2 < j=9，交换 a[2] 与 a[9]：`[12, 5, 4, 3, 9, 7, 15, 2, 10, 18]`

**第二轮扫描：**
- i 向右：a[2]=4≤12，i=3；a[3]=3≤12，i=4；a[4]=9≤12，i=5；a[5]=7≤12，i=6；a[6]=15>12，停，i=6
- j 向左：a[9]=18≥12，j=8；a[8]=10<12，停，j=8
- i=6 < j=8，交换 a[6] 与 a[8]：`[12, 5, 4, 3, 9, 7, 10, 2, 15, 18]`

**第三轮扫描：**
- i 向右：a[6]=10≤12，i=7；a[7]=2≤12，i=8；a[8]=15>12，停，i=8
- j 向左：a[8]=15≥12，j=7；a[7]=2<12，停，j=7
- i=8 ≥ j=7，扫描结束

**基准归位：** a[0] 与 a[7] 交换：`[2, 5, 4, 3, 9, 7, 10, 12, 15, 18]`

pivot=12 最终位置：**p1 = 7**

### 第二趟 partition（对左侧子序列 `[0..6]`）

当前序列：`[2, 5, 4, 3, 9, 7, 10, 12, 15, 18]`，对 `[0..6]` 即 `[2, 5, 4, 3, 9, 7, 10]` 执行 partition

pivot = 2，i = 1，j = 6

**第一轮扫描：**
- i 向右：a[1]=5>2，停，i=1
- j 向左：a[6]=10≥2，j=5；a[5]=7≥2，j=4；a[4]=9≥2，j=3；a[3]=3≥2，j=2；a[2]=4≥2，j=1；a[1]=5≥2，j=0
- i=1 ≥ j=0，扫描结束

**基准归位：** a[0] 与 a[0] 交换（无变化）：`[2, 5, 4, 3, 9, 7, 10, 12, 15, 18]`

pivot=2 最终位置：**p2 = 0**

### 最终结果

经过前两趟 partition 后，序列为：**`[2, 5, 4, 3, 9, 7, 10, 12, 15, 18]`**

---

## 干扰项分析

### 干扰项 B：第一趟基准归位错误（与 a[i] 而非 a[j] 交换）

**错误描述：** 扫描结束后，将基准与 a[i] 交换（而非正确的 a[j]）。

**第一趟执行：**
- 扫描过程与正确路径相同，结束时 i=8，j=7
- 错误归位：a[0] 与 a[8] 交换：`[15, 5, 4, 3, 9, 7, 10, 2, 12, 18]`
- pivot 位置 = 8

**第二趟执行（对左侧子序列 `[0..7]`）：**
- 对 `[15, 5, 4, 3, 9, 7, 10, 2]` 执行标准 partition，pivot=15
- 扫描后基准归位到位置 7：`[2, 5, 4, 3, 9, 7, 10, 15, 12, 18]`

**结果：** `[2, 5, 4, 3, 9, 7, 10, 15, 12, 18]`

**错误原因：** 基准归位时与 a[i] 交换，导致 pivot=12 被放到位置 8（而非正确的位置 7），后续第二趟的划分范围也随之错误。

---

### 干扰项 C：使用 Lomuto 单指针分区方案

**错误描述：** 使用 Lomuto 分区方案（取最后一个元素为 pivot，单指针从左到右扫描），而非题干指定的 Hoare 双指针方案。

**第一趟执行（Lomuto）：**
- pivot = a[9] = 4，store_index = 0
- k=0：a[0]=12≥4，不交换
- k=1：a[1]=5≥4，不交换
- k=2：a[2]=18≥4，不交换
- k=3：a[3]=3<4，交换 a[0] 与 a[3]，store_index=1：`[3, 5, 18, 12, 9, 7, 15, 2, 10, 4]`
- k=4：a[4]=9≥4，不交换
- k=5：a[5]=7≥4，不交换
- k=6：a[6]=15≥4，不交换
- k=7：a[7]=2<4，交换 a[1] 与 a[7]，store_index=2：`[3, 2, 18, 12, 9, 7, 15, 5, 10, 4]`
- k=8：a[8]=10≥4，不交换
- 基准归位：a[2] 与 a[9] 交换：`[3, 2, 4, 12, 9, 7, 15, 5, 10, 18]`
- pivot 位置 = 2

**第二趟执行（对左侧子序列 `[0..1]`）：**
- 对 `[3, 2]` 执行 Lomuto partition，pivot = a[1] = 2
- k=0：a[0]=3≥2，不交换
- 基准归位：a[0] 与 a[1] 交换：`[2, 3, 4, 12, 9, 7, 15, 5, 10, 18]`
- pivot 位置 = 0

**结果：** `[2, 3, 4, 12, 9, 7, 15, 5, 10, 18]`

**错误原因：** Lomuto 方案与 Hoare 方案在 pivot 选择（最后一个 vs 第一个）、扫描方式（单指针 vs 双指针）上完全不同，导致分区结果差异显著。

---

### 干扰项 D：第二趟对右侧子序列执行 partition

**错误描述：** 第二趟对第一趟产生的**右侧子序列**（而非左侧）执行 partition。

**第一趟执行（正确）：**
- 与正确路径相同，第一趟后：`[2, 5, 4, 3, 9, 7, 10, 12, 15, 18]`，p1 = 7

**第二趟执行（对右侧子序列 `[8..9]`）：**
- 对 `[15, 18]` 执行 partition，pivot = 15
- i=9，j=9
- i 向右：a[9]=18>15，停，i=9
- j 向左：a[9]=18≥15，j=8
- i=9 ≥ j=8，扫描结束
- 基准归位：a[8] 与 a[8] 交换（无变化）：`[2, 5, 4, 3, 9, 7, 10, 12, 15, 18]`
- pivot 位置 = 8

**结果：** `[2, 5, 4, 3, 9, 7, 10, 12, 15, 18]`

**错误原因：** 虽然本例中右侧子序列 `[15, 18]` 的 partition 结果恰好与左侧子序列的 partition 结果相同（因为 15 已在正确位置），但**概念上这是错误的**——快速排序通常优先处理较小的子序列（或按实现约定处理左侧），对右侧执行 partition 不符合题干要求。

> 注意：本例中 D 与 A 的序列结果相同，但 pivot 位置不同（A 的 p2=0，D 的 p2=8），考察的是对 partition 范围的理解。

---

## 验证

- ✓ 第一趟分区性质成立：pivot=12 左侧 `[2, 5, 4, 3, 9, 7, 10]` 均 < 12，右侧 `[15, 18]` 均 > 12
- ✓ 第二趟分区性质成立：pivot=2 左侧为空，右侧 `[5, 4, 3, 9, 7, 10]` 均 > 2
- ✓ 4 选项互异
- ✓ A 对应正确值

---

## 答案

**A. `[2, 5, 4, 3, 9, 7, 10, 12, 15, 18]`**
