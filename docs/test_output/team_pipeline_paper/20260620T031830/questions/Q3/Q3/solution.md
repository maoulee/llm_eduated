# 解析：二维数组列优先存储地址计算

## 答案

**正确答案：A. 1028**

## 详细解析

### 一、列优先存储地址公式

二维数组 A[M][N] 按**列优先**存储时，元素 A[i][j] 的地址计算公式为：

$$\text{Loc}(i,j) = \text{Base} + (j \times M + i) \times L$$

其中：
- M = 行数（第一维大小）= 5
- N = 列数（第二维大小）= 4
- Base = 基地址 = 1000
- L = 元素大小 = 4 字节
- i = 行下标 = 2，j = 列下标 = 1

### 二、正确计算（选项 A）

$$\text{Loc}(2,1) = 1000 + (1 \times 5 + 2) \times 4 = 1000 + 7 \times 4 = 1000 + 28 = \mathbf{1028}$$

### 三、干扰项分析

**B. 1036（行优先公式混淆）**

误用行优先公式 $\text{Loc}_{\text{row}}(i,j) = \text{Base} + (i \times N + j) \times L$：

$$1000 + (2 \times 4 + 1) \times 4 = 1000 + 9 \times 4 = 1000 + 36 = 1036$$

**错误原因**：行优先与列优先公式混淆。行优先用 $i \times N + j$，列优先用 $j \times M + i$。

---

**C. 1044（行列下标颠倒）**

将 A[2][1] 误作 A[1][2]，即交换下标后 i_swap=1、j_swap=2，代入列优先公式：

$$\text{Loc}(1,2) = 1000 + (2 \times 5 + 1) \times 4 = 1000 + 11 \times 4 = 1000 + 44 = 1044$$

**错误原因**：行列下标颠倒，将 A[i][j]=A[2][1] 误作 A[j][i]=A[1][2]。

---

**D. 1007（忘记乘以元素大小 L）**

计算偏移量时忘记乘以 L：

$$1000 + (1 \times 5 + 2) = 1000 + 7 = 1007$$

**错误原因**：偏移量 (j×M + i) 的单位是"元素个数"，必须乘以元素大小 L（字节）才能得到字节偏移量。

## 知识点总结

| 存储方式 | 公式 | 关键区别 |
|---------|------|---------|
| 列优先 | Loc(i,j) = Base + (j×M + i)×L | 列下标 j 先乘行数 M |
| 行优先 | Loc(i,j) = Base + (i×N + j)×L | 行下标 i 先乘列数 N |

**记忆要点**：列优先 → 列下标 j 在外层（先乘 M）；行优先 → 行下标 i 在外层（先乘 N）。
