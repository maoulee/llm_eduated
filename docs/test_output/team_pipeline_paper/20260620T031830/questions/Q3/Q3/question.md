# 题目：二维数组列优先存储地址计算

## 题干

设二维数组 A[5][4] 按**列优先**顺序存储，每个元素占用 4 字节，基地址（即 A[0][0] 的存储地址）为 1000。则元素 A[2][1] 的存储地址为：

A. 正确结果
B. 使用行优先存储公式（Loc(i,j) = Base + (i×N + j)×L）计算的结果
C. 行列下标颠倒（将 A[2][1] 误作 A[1][2]）后按列优先公式计算的结果
D. 计算偏移量时忘记乘以元素大小 L 的结果

---

## 设计意图

- **考察知识点**：二维数组列优先存储的地址计算公式 Loc(i,j) = Base + (j×M + i)×L
- **考察模式**：计算型——直接公式代入
- **难度定位**：K2=3（标准），需代入列优先公式计算，计算量适中
- **典型陷阱覆盖**：
  - B 选项：行优先与列优先公式混淆（行优先用 i×N+j，列优先用 j×M+i）
  - C 选项：行列下标颠倒
  - D 选项：忘记乘以元素大小

## 参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| 行数 M | 5 | 数组第一维大小 |
| 列数 N | 4 | 数组第二维大小 |
| 基地址 Base | 1000 | A[0][0] 的存储地址 |
| 元素大小 L | 4 字节 | 每个元素占用的字节数 |
| 目标元素 | A[2][1] | 行下标 i=2，列下标 j=1 |

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **4 选项互异**：A/B/C/D 四个计算结果各不相同（exec 算出后无碰撞）。
2. **正确值唯一确定**：按列优先公式 Loc(2,1) = 1000 + (1×5 + 2)×4 计算，结果唯一。
3. **干扰项对应声明错误类型**：
   - B = 行优先公式 Loc_row(2,1) = 1000 + (2×4 + 1)×4 的结果
   - C = 列优先公式但下标颠倒 Loc(1,2) = 1000 + (2×5 + 1)×4 的结果
   - D = 忘记乘 L 的结果 1000 + (1×5 + 2)
4. **干扰项有合理性**：B/C/D 均为同类题常见误算的真实产物，非荒谬值。
