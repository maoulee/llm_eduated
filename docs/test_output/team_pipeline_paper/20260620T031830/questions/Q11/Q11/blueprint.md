## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: 数据结构 > 树与二叉树 > 二叉树遍历
- primary_target_name: 给后序+中序还原二叉树写出先序序列
- question_type: comprehensive
- examination_mode: 推演型——遍历序列还原二叉树

### 难度目标
- k_target: K1=1,K2=2,K3=4,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 需多步递归推导还原二叉树结构，机制推演为主（K3=4），>5步串行推演且需维持中间状态，中间错一步全盘皆输；基础认知和计算需求低，无跨域联动

### 结构要求
- sub_question_count: 2
- sub_question_structure:
  - q1: 类型=推演/作图, 考察目标=还原二叉树结构, 分值=6
  - q2: 类型=计算/输出, 考察目标=写出先序遍历序列, 分值=4
- dependency: 串行（q2依赖q1的还原结果）
- condition_count: 2（后序序列 + 中序序列）

### 参数约束
- 节点数 N: 取值范围 6-10，建议 7-9，约束 N≥6 保证推演步数>5
- 树高 H: 取值范围 3-4，约束 H≥3 保证递归深度，H≤4 避免过载
- 序列元素: 连续字母或数字，互不相同，保证唯一确定
- 后序序列 P: 长度=N，最后一个元素为根
- 中序序列 I: 长度=N，根元素分割左右子树
- 一致性: P和I来自同一二叉树，能唯一确定该树，避免完全对称结构

### 参考经验摘要
- 历史模式: 2026_Q3、2012_Q3 均采用"后序+中序→还原→先序"模式，综合题10分2问
- 难度锚点: K3=4 为该题位典型特征，历史节点数 7-9 个
- 典型陷阱: 区间边界错误、后序根定位错误（首元素vs尾元素）、递归区间传递错误、左右子树混淆
