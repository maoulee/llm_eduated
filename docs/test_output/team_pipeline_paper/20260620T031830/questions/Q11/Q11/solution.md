# 参考答案与解析

## 第（1）问：还原二叉树结构（6分）

### 求解过程

**第 1 步：确定根节点**

后序遍历的最后一个元素为根节点。

- 后序遍历：`A C B E G F D` → 根节点 = **D**

在中序遍历中定位 D：

- 中序遍历：`A B C | D | E F G`
- D 左侧 `A B C` 为左子树节点（3 个）
- D 右侧 `E F G` 为右子树节点（3 个）

**第 2 步：还原左子树**

左子树的后序遍历为 `A C B`（后序中前 3 个元素），中序遍历为 `A B C`。

- 后序 `A C B` 的最后一个元素 = **B**，为左子树根节点
- 在中序 `A B C` 中定位 B：`A | B | C`
  - B 左侧 `A` 为 B 的左子树（1 个节点）
  - B 右侧 `C` 为 B 的右子树（1 个节点）

继续递归：
- B 的左孩子 = **A**（无左右孩子，叶子节点）
- B 的右孩子 = **C**（无左右孩子，叶子节点）

**第 3 步：还原右子树**

右子树的后序遍历为 `E G F`（后序中第 4~6 个元素），中序遍历为 `E F G`。

- 后序 `E G F` 的最后一个元素 = **F**，为右子树根节点
- 在中序 `E F G` 中定位 F：`E | F | G`
  - F 左侧 `E` 为 F 的左子树（1 个节点）
  - F 右侧 `G` 为 F 的右子树（1 个节点）

继续递归：
- F 的左孩子 = **E**（无左右孩子，叶子节点）
- F 的右孩子 = **G**（无左右孩子，叶子节点）

### 二叉树结构

```
        D
       / \
      B   F
     / \ / \
    A  C E  G
```

**文字描述：**
- 根节点：D
- D 的左孩子：B；D 的右孩子：F
- B 的左孩子：A；B 的右孩子：C
- F 的左孩子：E；F 的右孩子：G
- A、C、E、G 均为叶子节点

**树高：3**（根节点 D 在第 1 层，叶子节点在第 3 层）

## 第（2）问：先序遍历序列（4分）

### 求解

先序遍历规则：根 → 左子树 → 右子树，递归应用。

根据还原的二叉树结构：

```
        D
       / \
      B   F
     / \ / \
    A  C E  G
```

- 访问根 D
- 遍历左子树（根 B）：访问 B → 访问 A → 访问 C
- 遍历右子树（根 F）：访问 F → 访问 E → 访问 G

**先序遍历序列：`D B A C F E G`**

## 典型错误分析

1. **后序根定位错误**：误将后序首元素 A 当作根节点，导致整棵树结构错误。
2. **递归区间边界错误**：在划分左右子树时，后序区间与中序区间对应关系搞错，导致子树节点数不匹配。
3. **左右子树混淆**：在中序遍历中误判根节点左侧/右侧，将左子树当作右子树。
4. **先序/中序/后序定义混淆**：写出中序或后序序列而非先序序列。
