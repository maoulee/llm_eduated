# 题目经验文档

## 基本信息
- 题号: simulation_00049
- 科目: 数据结构
- 知识域: 线性表
- 题型: 单选题
- 分值: 2分

## 题目内容
以下关于线性表的叙述中，正确的是（ ）。

A. 顺序表的插入和删除操作不需要移动元素
B. 链表的第 i 个元素可以直接通过下标访问
C. 顺序表支持随机访问，链表不支持随机访问
D. 链表的存储空间利用率一定高于顺序表

## 正确答案
C

## 考察点
- 顺序表与链表的存储结构差异
- 随机访问特性的本质区别
- 常见误解辨析

## 干扰项设计
- A: 混淆插入删除操作的代价（顺序表需要移动元素）
- B: 混淆链表的访问方式（链表不支持随机访问）
- D: 绝对化表述陷阱（链表因指针开销，空间利用率通常低于顺序表）

## 难度评估
- K1: 4（需辨析顺序表/链表核心特性）
- K2: 1（无计算）
- K3: 1（无推演）
- K4: 3（存在"一定"等陷阱词）
- K5: 1（单知识点）

## 学生表现
- 正确率: 72%
- 常见错误: 选B（混淆访问方式）、选D（忽略指针开销）

## 经验总结
- 概念辨析题适合考查存储结构对比
- 干扰项应针对常见误解设计
- "一定""所有"等绝对化表述是有效陷阱
