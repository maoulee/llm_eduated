# 二叉树中所有**根结点到叶子结点**的路径

## 题目描述

设二叉树采用二叉链表存储，每个结点包含数据域 `data`、左孩子指针 `lchild` 和右孩子指针 `rchild`。请设计算法，求出二叉树中所有从根结点到叶子结点的路径。

### 子问题

**Q1（2 分）**：定义二叉链表结点类型 `BiTNode`。

**Q2（4 分）**：描述算法思想。要求说明如何遍历二叉树、如何保存路径、如何判定叶子结点、如何处理回溯。

**Q3（8 分）**：用 C/C++ 写出完整代码，并给出关键步骤注释。函数原型如下：

```c
void AllPaths(BiTree T);
```

其中 `BiTree` 为指向 `BiTNode` 的指针类型，`AllPaths` 函数负责输出所有从根到叶子的路径。

**Q4（2 分）**：分析算法的时间复杂度和空间复杂度，并简要说明理由。

---

## 通过条件

本题成立 ⇔ 以下可机检特征全部满足：

1. **结点类型定义完整**：`BiTNode` 结构体包含 `data`、`lchild`、`rchild` 三个成员，类型正确。
2. **路径方向为从根到叶子**：算法输出的每条路径，第一个结点为根结点，最后一个结点为叶子结点。
3. **叶子结点判定正确**：仅当结点的 `lchild` 和 `rchild` 均为 `NULL` 时，才判定为叶子结点。
4. **回溯机制正确**：递归返回时，当前结点从路径中弹出（或路径长度减 1），保证后续路径不受影响。
5. **算法思想中明确声明路径输出顺序为'从根到叶子'，且代码实现与声明一致**。
6. **复杂度分析合理**：时间复杂度为 O(n × h)（n 为结点总数，h 为树高），空间复杂度为 O(h)（递归栈 + 路径数组）。
7. **代码可编译**：语法正确，无未定义变量或类型错误。
