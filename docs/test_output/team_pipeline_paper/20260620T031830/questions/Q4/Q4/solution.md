## 答案

**B. 2**

## 求解过程

### 一、next 数组定义（严蔚敏版）

- 下标从 1 开始
- next[1] = 0，next[2] = 1
- 对于 j ≥ 3：next[j] = 前 j-1 个字符的最长相等真前后缀长度 + 1

### 二、逐步计算

模式串 S = "abcabc"，共 6 个字符。

| j | 前 j-1 个字符 | 最长相等真前后缀 | 长度 | next[j] |
|---|---|---|---|---|
| 1 | — | — | — | 0（定义） |
| 2 | — | — | — | 1（定义） |
| 3 | "ab" | 无 | 0 | 0 + 1 = 1 |
| 4 | "abc" | 无 | 0 | 0 + 1 = 1 |
| 5 | "abca" | "a" | 1 | 1 + 1 = **2** |
| 6 | "abcab" | "ab" | 2 | 2 + 1 = 3 |

**next 数组：[0, 1, 1, 1, 2, 3]**

### 三、目标值

next[5] = **2**

---

## 干扰项分析

- **A. 1**：错误。若认为 "abca" 无相等真前后缀，会得到 next[5] = 0 + 1 = 1。但 "abca" 的前缀 "a" 与后缀 "a" 相等，最长相等真前后缀长度为 1。
- **C. 3**：错误。若误判 "abca" 的最长相等真前后缀长度为 2（如误认为 "ab" = "ca"），会得到 next[5] = 2 + 1 = 3。但 "ab" ≠ "ca"。
- **D. 4**：错误。若误判 "abca" 的最长相等真前后缀长度为 3（如误认为 "abc" = "bca"），会得到 next[5] = 3 + 1 = 4。但 "abc" ≠ "bca"。
