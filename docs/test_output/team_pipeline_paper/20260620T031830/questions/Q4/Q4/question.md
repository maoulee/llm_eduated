# 题干

已知模式串 S = "abcabc"，采用 KMP 算法进行模式匹配。按严蔚敏《数据结构》中 next 数组的定义（下标从 1 开始，next[1]=0，next[2]=1），next[5] 的值为（ ）。

A. 1
B. 2
C. 3
D. 4

## 设计意图

- **考察点**: KMP算法next数组的逐步计算，重点考察最长相等前后缀的识别能力
- **难度目标**: K3=3（3-5步串行推演）
- **考察模式**: 计算型
- **参数选择理由**: 
  - 模式串 "abcabc" 长度为 6，符合 [6, 10] 范围
  - 目标位置 j=5 位于中间偏后，符合 [5, 8] 范围
  - 模式串包含重复子结构 "abc"，确保存在非平凡的前后缀匹配

## 通过条件

本题成立 ⇔ 以下可机检特征全部满足：
1. len(S) ∈ [6, 10]
2. 目标位置 j ∈ [5, 8]
3. next[j] > 1（非平凡值，表明该位置存在长度 ≥ 1 的最长相等前后缀）
4. S 中存在重复字符（确保有非平凡的前后缀匹配可能，非全不同字符串）
