## 考点
- **二叉树基本性质**：n = n0 + n1 + n2（总结点数 = 叶子结点数 + 度为1的结点数 + 度为2的结点数）
- **叶子结点与度为2结点关系**：n0 = n2 + 1（核心公式，必须准确记忆）
- **考察侧重点**：由已知条件（如总结点数、某类结点数）联立公式推算叶子结点数

## 难度目标
- **K1=2（较低）**：需要二叉树基本概念（度、叶子结点、度为1/2的结点），但概念模糊也能顺着题干做
- **K2=3（标准）**：需代入公式计算，可能涉及非2的幂次或小数，计算量适中
- **K3=2（较低）**：仅需2步以内推导（联立两个公式求解），路径唯一
- **K4=2（较低）**：存在常规注意点（如满二叉树/完全二叉树的特殊性质），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他系统

## 考察模式
**计算型——二叉树性质应用**
- 给出二叉树的部分条件（如总结点数、度为1的结点数等）
- 要求利用 n0 = n2 + 1 和 n = n0 + n1 + n2 联立求解叶子结点数
- 参考历史经验：此类题在408数据结构选择题中常见，通常给出2个条件，联立2个公式求解

## 出题要求
- **题型**：单选题（4选项）
- **总条件数**：2个显式条件（如总结点数 + 度为1的结点数，或总结点数 + 度为2的结点数）
- **条件设计原则**：条件需能唯一确定叶子结点数，不能退化（如给出n0直接问n0）
- **参数取值范围要求**：总结点数建议在 100-1000 范围内，避免过小（退化）或过大（计算繁琐）

## 子问题规划
本题为单选题，无子问题结构。
- **类型**：计算
- **考察目标**：联立二叉树性质公式求解叶子结点数
- **分值**：2分

## 参数约束
- **总结点数 n**：取值范围 100-1000，建议非2的幂次（增加计算区分度）
- **度为1的结点数 n1**：取值范围 0-50，需满足 n1 < n - 2（保证 n0, n2 为正整数）
- **度为2的结点数 n2**：若给出，取值范围 10-500，需满足 n2 = n0 - 1
- **一致性约束**：n = n0 + n1 + n2 且 n0 = n2 + 1，两个公式联立后 n0 = (n - n1 + 1) / 2，需保证结果为整数
- **可调自由度**：n 和 n1 为独立参数，n2 和 n0 由公式确定

## 参考经验
- **历史模式**：408数据结构选择题中，二叉树性质题通常给出总结点数和某一类结点数，要求求叶子结点数
- **难度锚点**：K2=3 为常见难度，计算量适中，非2的幂次增加区分度
- **典型陷阱**：
  - 忘记 n0 = n2 + 1，直接用 n - n1 计算
  - 混淆 n0 和 n2 的关系（记反为 n2 = n0 + 1）
  - 计算错误（尤其是 (n - n1 + 1) / 2 中的 +1 遗漏）
