## 考点
- **快速排序 partition 过程**：给定关键字序列，以首元素为枢轴，模拟 Hoare 或 Lomuto 划分过程
- **多趟划分结果**：要求写出前两趟（两次 partition）之后序列的状态，而非仅第一趟
- **考察侧重点**：手动模拟 partition 的扫描-交换（或填坑）过程，准确追踪每个元素的最终位置

## 难度目标
- **K1=2**：需记忆快速排序 partition 的基本规则（枢轴选取、双向扫描或填坑法），属于标准 408 基础名词
- **K2=3**：partition 过程中涉及多次比较与交换，每次比较是简单运算但非 2 的幂友好，需多步代入
- **K3=2**：前两趟划分，每趟是一个线性扫描流程，步数可控（每趟不超过 n 步），路径唯一
- **K4=2**：需注意题目指定的枢轴选取方式（默认取首元素）和 partition 变体（Hoare/Lomuto），属常规注意点
- **K5=1**：单一知识点（快速排序）内部解决，不涉及跨域联动

  达标理由：slot 设定 target_difficulty=4，K2=3（多步比较+交换模拟）为主轴，K3=2（两趟串行流程）为辅，K1/K4 均为标准级。整体难度对应"手动模拟两趟 partition，需要精准追踪元素位置"。

## 考察模式
**计算型——快速排序过程模拟**

选择理由：slot 的 examination_mode 明确为"给定序列用快速排序求前两趟划分结果"。这是 408 排序章节的经典考察模式——给出一个关键字序列，要求考生模拟快速排序的 partition 过程，写出指定趟数后的序列状态。考察的不是概念辨析（K1）或陷阱识别（K4），而是过程模拟的准确性（K2+K3）。

## 出题要求
- **题型**：单项选择题，4 选项，2 分
- **条件数**：2 个显式条件
  - 条件 1：给出一个长度为 7~9 的关键字序列
  - 条件 2：指明枢轴选取方式（如"以序列首元素为枢轴"）及 partition 方式（Hoare 划分，即双向扫描交换法）
- **条件设计原则**：
  - 序列元素为互不相同的正整数，便于考生无歧义地模拟
  - 首元素不应是序列的最小或最大值（避免第一趟 partition 退化为平凡情况）
  - 第一趟划分后，应至少有一侧子序列长度 ≥2（保证第二趟 partition 有实质内容）
  - 选项设计：正确答案为前两趟划分后的序列；干扰项对应常见错误路径

## 子问题规划
本题为单项选择题，无子问题。4 选项规划如下：
- **正确选项**：前两趟 partition 后的完整序列
- **干扰项 1**：仅做第一趟 partition 后的序列（考生只做了一趟就选）
- **干扰项 2**：第一趟划分方向/扫描顺序搞反（如从枢轴右边先移 vs 左边先移的差异导致的结果）
- **干扰项 3**：partition 中扫描指针停止条件判断错误（等号处理差异），导致交换了不该交换的元素对

## 参数约束
- **序列长度**：7~9 个元素
  - 太短（≤6）则两趟模拟难度不足，区分度不够
  - 太长（≥10）则模拟工作量过大，不适合选择题形式
- **元素值域**：互不相同的正整数，建议值域 10~99（两位数便于阅读）
- **枢轴位置**：默认取子序列首元素为枢轴
- **一致性约束**：
  - 首元素不能是最大或最小值（避免 partition 退化）
  - 第二趟需在两个子序列中各做一次 partition（若两子序列均有 ≥2 元素），或至少一个子序列有 ≥2 元素
  - 干扰项值必须与正确答案不同，且各干扰项之间也互不相同（保证 4 个选项可区分）

## 参考经验
- **历史模式**：快速排序过程模拟是 408 高频考法，典型形式为"给定序列，求第 k 趟划分结果"
- **难度锚点**：K2=3 为主导维度，对应"多次比较+交换的模拟计算"；K3=2 对应"两趟串行流程"
- **典型陷阱**：
  1. 只做一趟就停止（最常见的粗心错误）
  2. Hoare 划分中"先移动哪一侧指针"的方向差异导致不同结果
  3. 比较时的等号处理（遇到等于枢轴的元素是否停止）
  4. 第二趟需对两个子序列分别 partition，而非仅处理一侧
