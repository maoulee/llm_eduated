# 快速排序前两趟划分结果

## 题干

给定关键字序列 `{49, 38, 65, 97, 76, 13, 27, 30}`，使用快速排序算法进行排序。枢轴（pivot）选取方式为：以当前（子）序列的首元素为枢轴；partition 方法采用 Hoare 划分（双向扫描-交换法），具体规则如下：

1. 取子序列首元素为枢轴 pivot，在原位置挖出（挖坑法）。
2. 从右端（high 指针）向左扫描，遇到**小于** pivot 的元素则填入左端坑位，右端形成新坑。
3. 从左端（low 指针）向右扫描，遇到**大于** pivot 的元素则填入右端坑位，左端形成新坑。
4. 重复步骤 2–3，直到 low == high，将 pivot 填入最终坑位。
5. 一趟 partition 完成后，对**每一侧**长度 ≥2 的子序列继续进行下一趟 partition（左侧优先）。本题要求进行**前两趟** partition，即先对整个序列做第一趟，再对第一趟划分产生的每个长度 ≥2 的子序列分别做第二趟。

> **说明**：序列中所有元素互不相同。

**问：前两趟 partition 全部完成后，数组的状态是（ ）。**

## 选项

A. 正确结果

B. 仅完成第一趟 partition、漏做第二趟的结果

C. Hoare 划分中扫描指针移动方向差异导致的结果（即先移动 low 指针而非先移动 high 指针）

D. 枢轴选取位置错误的结果（以子序列**末元素**而非首元素为枢轴进行划分）

## 通过条件（成功判据，可机检）

### 通用条件

1. **序列满足 design_card 约束**：序列含 8 个互不相同的两位正整数；首元素 49 既非最大值也非最小值；第一趟 partition 后至少有一侧子序列长度 ≥2（保证第二趟有实质内容）。
2. **正确结果唯一确定**：在给定参数和 Hoare 划分规则下，前两趟完成后的序列只有一个确定答案，A = 该值。
3. **4 选项互异**：A/B/C/D 四个值各不相同（exec 算出后无碰撞）。
4. **干扰项对应声明错误类型**：
   - B = 仅做第一趟、漏做第二趟的结果（`assert len(已排序子序列数) < 预期`）。
   - C = 先移动 low 再移动 high（而非标准的先 high 后 low）的结果。
   - D = 枢轴取末元素而非首元素的结果。
   - 每个干扰项的值由其声明的错误路径产生，且与其他三个选项的值不同。
5. **干扰项有合理性**：每个干扰项是快速排序模拟中真实常见误算的产物，非荒谬值，有区分度。
