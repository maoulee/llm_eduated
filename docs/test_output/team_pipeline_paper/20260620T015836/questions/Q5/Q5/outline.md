## 考点
- **核心知识点**：二叉树叶子结点数与度为2结点数的关系（n₀ = n₂ + 1）
  - 考察侧重点：由已知条件（如总结点数和度为1的结点数）推算叶子结点数
- **辅助知识点**：二叉树结点总数公式（n = n₀ + n₁ + n₂）
  - 考察侧重点：将总度数与结点数关系（总度数 = n₁ + 2n₂ = n - 1）与 n₀ = n₂ + 1 联立求解

## 难度目标
- **K1=2**：需要记忆 n₀ = n₂ + 1 这一核心公式，但属于二叉树最基础性质，概念辨析压力低
- **K2=3**：需代入常规公式进行计算，涉及非2的幂次的整数运算，存在轻微算错可能
- **K3=2**：仅需2步以内推导——联立方程组求出 n₂，再用 n₀ = n₂ + 1 得结果，路径唯一
- **K4=2**：存在常规注意点（需正确识别已知量与未知量的对应关系），408考生基本不会踩坑
- **K5=1**：单一知识点内部解决，不涉及其他子系统

## 考察模式
**计算型——二叉树性质应用**
- 理由：slot 指定 examination_mode 为"计算型——二叉树性质应用"，这是该知识点最常见的考查方式。学生需要将二叉树度数关系公式联立，代入具体数值求解叶子结点数。该模式直接考察对 n₀ = n₂ + 1 的记忆和应用能力，与 K2=3（标准计算）、K3=2（简单推导）的难度定位吻合。

## 出题要求
- **题型**：单项选择题，4选项（1正确 + 3干扰），分值2分
- **条件数**：2个显式条件（总结点数 n、度为1的结点数 n₁）
- **条件设计原则**：
  - 给出总结点数 n 和度为1的结点数 n₁，要求求叶子结点数 n₀
  - 学生需联立 n = n₀ + n₁ + n₂ 和 n₀ = n₂ + 1 求解
  - 也可用总度数关系 n - 1 = n₁ + 2n₂ 先求 n₂，再求 n₀
- **参数取值范围要求**：
  - 总结点数 n：中等规模整数，便于计算但非平凡（建议 10–100 范围）
  - n₁ 取值需保证 n₀ 和 n₂ 均为正整数且结果有意义

## 子问题规划
- 本题为单项选择题，无子问题拆分
- 干扰选项策略：
  - 干扰项1：直接用 n₂ = n - n₁，忘记减1或忘记 n₀ ≠ n₂（混淆 n₀ 与 n₂）
  - 干扰项2：度数公式中 n₁ 系数错误（误用 n - 1 = n₁ + n₂，漏乘2）
  - 干扰项3：将 n₀ = n₂ + 1 记成 n₀ = n₂ - 1（公式记忆偏差）
  - 各干扰项须产生不同的数值结果，确保区分度

## 参数约束
- **n（总结点数）**：正整数，取值范围 10–100，建议非2的幂次以提高 K2 难度
- **n₁（度为1的结点数）**：非负整数，须满足 n₁ < n 且 n - n₁ 为奇数（保证 n₂ = (n - n₁ - 1) / 2 为整数）
- **一致性约束**：
  - n₂ = (n - n₁ - 1) / 2 ≥ 0
  - n₀ = n₂ + 1 ≥ 1
  - n₀ + n₁ + n₂ = n（验证恒等式）
- **可调自由度**：n 和 n₁ 各有一个自由度，受上述奇偶和正整数约束限制

## 参考经验
- **历史模式**：该题位（数据结构选择题）常考查二叉树基本性质的直接应用，以计算型为主
- **难度锚点**：K2 为主导维度（目标3），计算量适中，非2幂次整数运算
- **典型陷阱**：混淆 n₀ 与 n₂（学生易直接将 n - n₁ 的结果当作叶子数）；度数公式系数错误
