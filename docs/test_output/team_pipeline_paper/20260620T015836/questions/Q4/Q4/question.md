# 题干

## 题目

已知模式串 **P = "abacababc"**，采用严蔚敏版 KMP 算法中 next 数组的定义（next[1]=0，next[2]=1，j 从 1 开始），求 **next[9]** 的值为（　）。

## 选项

A. 正确结果

B. 忘记 +1 的结果（取最长相等前后缀长度 k，但未执行 next[j]=k+1，直接输出 k）

C. off-by-one 下标偏移的结果（将 P 的下标从 0 开始计数，导致前后缀比较位置整体偏移 1 位）

D. 位置混淆——取相邻位 next[8] 的值作为 next[9] 的结果

## 通过条件（成功判据·可机检）

1. **4 选项互异**：A/B/C/D 四个值各不相同（exec 算出后无碰撞）。
2. **正确值唯一确定**：题干在给定参数下只有一个确定答案，A = next[9] 的正确值；不存在"两个选项都对"的歧义。
3. **干扰项对应声明错误类型**：
   - B = next[9] 的最长相等前后缀长度 k（未 +1），与 A 相差 1；
   - C = 因下标从 0 起算而产生的偏移值；
   - D = next[8] 的值。
4. **干扰项有合理性**：每个干扰项是同类题常见误算的真实产物，有区分度；其中 D = next[8] 的值，应与 A、B、C 互不相同。
5. **答案非平凡**：next[9] ≥ 3（模式串前缀结构保证 k ≥ 2，故 next[9] = k+1 ≥ 3）。
