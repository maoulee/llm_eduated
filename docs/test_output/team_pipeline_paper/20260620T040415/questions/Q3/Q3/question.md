# 题目：二维数组列优先存储的地址计算

## 题干

设二维数组 A[6][8]（下标从0开始），按**列优先**顺序连续存储，每个元素占用 4 字节，基地址（A[0][0] 的地址）为 1000。则元素 A[2][3] 的存储地址为多少？

A. 正确结果（按列优先公式计算）
B. 行优先公式误用的结果（使用 Loc(i,j) = Base + (i × n + j) × L）
C. 下标从1开始计算的结果（将 i=2,j=3 误作 i=3,j=4 代入列优先公式）
D. 行列数混淆的结果（将 m=6 与 n=8 互换后代入列优先公式）

## 设计意图

- **考察知识点**：二维数组列优先存储的地址计算公式 Loc(i,j) = Base + (j × m + i) × L
- **考察能力**：公式正确识别与代入计算（K2为主导）
- **干扰设计**：
  - B：行优先公式误用（最常见错误）
  - C：下标起始约定错误（从1开始而非从0）
  - D：行列数 m/n 混淆（公式中 m 对应行数但误用列数）

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **4选项互异**：A/B/C/D 四个计算结果各不相同（exec 算出后无碰撞）。
2. **正确值唯一确定**：在给定参数（m=6, n=8, L=4, Base=1000, i=2, j=3）下，按列优先公式 Loc(i,j) = Base + (j × m + i) × L 计算的结果唯一，且 A = 该值。
3. **干扰项对应声明错误类型**：
   - B = Base + (i × n + j) × L（行优先公式代入结果）
   - C = Base + ((j+1) × m + (i+1)) × L（下标从1开始代入列优先公式的结果）
   - D = Base + (j × n + i) × L（m与n互换后代入列优先公式的结果）
4. **干扰项与正确答案的绝对差值均大于0且小于200**：确保干扰项既非重合也非离谱值，具有区分度。
