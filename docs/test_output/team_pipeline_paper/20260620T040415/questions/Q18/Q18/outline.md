## 考点
- **二叉树遍历**（核心）：递归遍历（前序/中序/后序）的机制理解，要求在遍历过程中维护路径状态
- **路径保存与回溯**（核心）：在递归遍历中通过参数传递或全局数组保存当前路径，到达叶子结点时输出，回溯时撤销
- **二叉链表存储结构**（基础）：结点类型定义（data/lchild/rchild），指针操作
- **递归算法设计**（核心）：递归终止条件（叶子结点判定）、递归调用逻辑、状态维护

## 难度目标
- **K1=1（微弱）**：仅需二叉树基础名词（叶子结点、根结点、二叉链表），概念模糊也能顺着题干做
- **K2=2（较低）**：几乎无数值计算，仅需指针操作和数组索引
- **K3=2（较低）**：递归遍历流程固定，但需理解"遍历+路径维护"的组合逻辑，非纯机械套用
- **K4=3（标准）**：存在明确陷阱——叶子结点判定条件（lchild==NULL && rchild==NULL）、回溯时路径撤销的时机、路径输出方向（叶子到根 vs 根到叶子）
- **K5=4（较高）**：需将"遍历框架"与"路径状态维护"两个子系统联动——遍历提供访问顺序，路径数组提供状态记忆，到达叶子时触发输出，回溯时撤销状态，状态互影响

## 考察模式
**算法设计型——二叉树遍历与路径算法设计**

参考 2014_Q41 等历史算法设计题模式：
- 题干给出存储结构（二叉链表）
- 要求定义结点类型
- 要求描述算法思想
- 要求写出完整代码并注释
- 考察递归遍历框架 + 附加状态维护

## 出题要求
- **题型**：综合题（算法设计）
- **分值**：16分
- **子问题结构**：3个子问（结点定义 + 算法思想 + 代码实现）
- **条件设计原则**：题干给出二叉链表存储约定，不给出具体树形（算法需对任意二叉树通用）
- **参数取值范围**：无具体数值参数，但需约束路径数组大小（与树高相关）、结点数据类型（ElemType 泛型）

## 子问题规划

### 子问1：结点类型定义（约3分）
- **类型**：定义题
- **考察目标**：二叉链表结点结构（data/lchild/rchild）
- **与前后问关系**：为后续算法提供数据结构基础

### 子问2：算法思想描述（约5分）
- **类型**：分析/描述题
- **考察目标**：递归遍历框架 + 路径数组维护 + 叶子结点判定 + 回溯机制
- **与前后问关系**：为代码实现提供逻辑框架，独立于代码但需与代码一致

### 子问3：C/C++代码实现（约8分）
- **类型**：编程题
- **考察目标**：递归函数设计、路径数组操作、叶子结点判定、路径输出、回溯撤销
- **与前后问关系**：实现子问2的算法思想，依赖子问1的结点定义

## 参数约束
- **结点数据类型**：使用泛型 ElemType，不指定具体类型
- **路径数组**：需定义足够大的数组保存路径（与树高相关），或动态管理
- **路径输出方向**：题目要求"叶子结点到根"，需考虑输出顺序（可先保存根到叶子再逆序输出，或直接在递归中处理）
- **树的结构**：算法需对任意二叉树通用（非完全二叉树、非平衡树）
- **边界条件**：空树、单结点树、全左斜/全右斜树等退化情况需正确处理

## 参考经验
- **历史模式**：2014_Q41 等算法设计题采用"定义+思想+代码"三段式结构
- **难度锚点**：K5=4 为跨域联动主导，需遍历与路径状态深度耦合
- **典型陷阱**：
  1. 叶子结点判定错误（只判 lchild==NULL 或只判 rchild==NULL）
  2. 回溯时忘记撤销路径（导致后续路径包含之前分支的结点）
  3. 路径输出方向错误（输出根到叶子而非叶子到根）
  4. 递归终止条件遗漏或错误
