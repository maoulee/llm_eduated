# 求二叉树中所有叶子结点到根的路径

## 题干

给定一棵二叉树 T，采用二叉链表存储。设 `root` 为指向 T 的根结点的指针，请设计算法求出 T 中**所有叶子结点到根结点的路径**，并按"叶子结点 → … → 根结点"的顺序输出每条路径。要求：

**(1) 二叉树结点的数据类型定义**（约 3 分）

使用 C 或 C++ 语言，给出二叉树结点的数据类型定义。结点数据类型使用泛型 `ElemType`。

**(2) 算法的基本设计思想**（约 5 分）

给出算法的基本设计思想，说明如何遍历二叉树、如何保存路径、如何处理回溯。

**(3) 算法的 C/C++ 代码实现**（约 8 分）

根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

---

## 设计意图

- **考察知识点**：二叉树递归遍历框架、路径状态维护（回溯法）、叶子结点判定、路径输出方向处理
- **考察模式**：算法设计型——遍历框架 + 路径状态维护的跨域联动
- **难度来源**：
  - K5=4（跨域联动）：遍历框架与路径回溯机制的联动设计
  - K4=3（陷阱）：叶子结点判定（需同时判左右子树为空）、回溯时忘记撤销路径、路径输出方向（叶子→根而非根→叶子）、递归终止条件遗漏
- **边界条件**：空树、单结点树、退化树（所有结点仅有一个孩子）需正确处理

---

## 通过条件（成功判据）

本题成立 ⇔ 算法满足以下可机检特征：

1. **叶子结点判定正确**：判定条件为 `lchild == NULL && rchild == NULL`（左右子树同时为空），而非仅判单侧为空。
2. **回溯撤销路径**：递归返回时正确撤销当前结点从路径中的记录（如 `path[--depth]` 或等价操作），避免路径污染。
3. **路径输出方向正确**：每条输出路径的第一个元素为叶子结点，最后一个元素为根结点（叶子→根方向）。
4. **边界条件处理**：空树（`root == NULL`）不输出任何路径；单结点树输出该结点自身作为路径。
5. **路径完整性**：对任意非空二叉树，输出的路径数量等于该树中叶子结点的数量，且每条路径包含从叶子到根的所有结点。
