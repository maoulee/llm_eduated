# 题目

设计算法，删除带头结点的单链表L中所有值为x的结点。

其中，单链表结点包含 data 域（int 类型）和 next 指针域，L 为头指针，链表长度 n ≥ 0（允许空表）。

## 子问

**Q1（2分）**：定义单链表的结点类型。

**Q2（4分）**：描述算法的基本思想。

**Q3（8分）**：用C或C++编写算法代码，要求代码中包含必要的注释。

## 通过条件

本题成立 ⇔ 算法满足以下可机检特征：

1. **空表处理**：对空表（L->next == NULL）能正确处理，不崩溃
2. **正确性**：删除后链表中不存在值为x的结点
3. **结构完整性**：删除后链表无断裂（从L->next开始遍历能到达表尾NULL）
4. **头结点保护**：头结点L本身不被删除，L->next指向正确的首元结点（或NULL）
5. **内存释放**：被删除的结点内存已正确释放（free/delete）
