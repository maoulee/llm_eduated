## 考点
- **快速排序 partition 过程**：考察基准元素选择、左右指针移动规则、元素交换时机
- **多趟划分串行执行**：考察第一趟划分完成后，对左右子序列分别进行第二趟划分的能力
- **基准元素定位**：考察每趟划分后基准元素最终位置的确定

## 难度目标
- **K1=2（较低）**：需知道快速排序基本概念和 partition 规则，但概念模糊也能顺着题干模拟
- **K2=3（标准）**：需执行多步比较和交换计算，涉及非平凡数值比较，可能算错
- **K3=2（较低）**：2趟划分，每趟约3-5步操作，总步数可控，路径唯一
- **K4=2（较低）**：存在常规注意点（基准选择规则、左右指针移动顺序），408考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及其他排序算法或数据结构

## 考察模式
**计算型——快速排序过程模拟**（参考 simulation_00180.md）

理由：
- 历史经验表明，快速排序过程模拟是该题位的标准考察模式
- 选择题形式下，通过给出完整序列和明确规则，让学生模拟前两趟划分
- 干扰项设计围绕常见错误路径：第一趟对第二趟错、基准位置错、交换顺序错

## 出题要求
- **题型**：单选题（4选项）
- **分值**：2分
- **条件数**：2个显式条件
  1. 给定初始关键字序列（8-12个元素）
  2. 明确 partition 规则（基准选择方式、指针移动方向）
- **条件设计原则**：
  - 序列元素互不相同，避免重复值歧义
  - 元素值为整数，范围适中（如10-99）
  - 基准选择规则必须明确写出（如"以第一个元素为基准"）
- **参数取值范围要求**：
  - 序列长度：8-12个元素（保证两趟划分有足够操作空间）
  - 元素值：互不相同的整数，避免过于规律（如等差数列）

## 子问题规划
本题为单选题，无子问题结构。

**选项设计**：
- 正确选项：前两趟划分后的完整序列
- 干扰项1：第一趟正确，第二趟划分方向错误（如该划左子序列却划了右子序列）
- 干扰项2：基准元素最终位置错误（如 partition 后基准未放到正确位置）
- 干扰项3：交换顺序错误导致中间状态不同

## 参数约束
- **序列长度 n**：8 ≤ n ≤ 12，保证两趟划分后仍有可观察的变化
- **元素值**：互不相同的整数，取值范围 10-99，避免等差/等比等过于规律的序列
- **基准选择规则**：必须明确指定（第一个元素 / 最后一个元素 / 中间元素），题干中写明
- **指针移动规则**：需明确左右指针的移动方向和终止条件（如"左指针右移直到≥基准，右指针左移直到≤基准"）
- **可调自由度**：序列具体元素值、基准选择方式、序列长度可在范围内自由选择

## 参考经验
- **历史模式**：simulation_00180.md 为快速排序过程模拟题，考察多趟 partition
- **难度锚点**：K2=3 为标准计算难度，K3=2 表示推演步数适中
- **典型陷阱**：
  1. 基准元素选择规则不明确导致歧义
  2. 左右指针移动顺序混淆（先左后右 vs 先右后左）
  3. 第二趟划分时搞错子序列范围
  4. partition 结束后基准元素未放到最终位置
