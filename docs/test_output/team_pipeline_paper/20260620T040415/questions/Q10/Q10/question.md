# 快速排序前两趟划分结果

## 题目

对序列 `[37, 19, 58, 14, 82, 26, 45, 73, 11, 56]` 进行快速排序，采用以下规则：

- **基准选择**：每趟取子序列的**第一个元素**作为基准（pivot）
- **Partition 规则**：严蔚敏教材标准双指针法——左右指针 `i`、`j` 分别从子序列两端向中间扫描，**先移动右指针 `j`**（从右向左找小于 pivot 的元素），再移动左指针 `i`（从左向右找大于 pivot 的元素），找到后交换 `arr[i]` 与 `arr[j]`；当 `i == j` 时，将 `arr[i]` 与基准交换，完成一趟划分

求**前两趟**划分后的序列结果。

A. 正确结果
B. 第一趟正确，但第二趟划分范围错误（对错误的子序列进行划分）的结果
C. 基准归位位置错误（基准未交换到 `i==j` 位置，而是固定放到子序列末尾）的结果
D. 指针移动顺序错误（先移动左指针 `i` 再移动右指针 `j`）的结果

---

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **4 选项互异**：A/B/C/D 四个选项的计算结果各不相同（exec 算出后无碰撞）
2. **正确值唯一确定**：在给定序列和规则下，前两趟划分结果唯一确定，A = 该值
3. **干扰项对应声明错误类型**：
   - B 的值 = 第一趟正确 + 第二趟对错误子序列划分的结果
   - C 的值 = 基准归位时固定放到子序列末尾（而非 `i==j` 位置）的结果
   - D 的值 = 先左后右指针顺序的结果
4. **干扰项有区分度**：B/C/D 均与 A 不同，且彼此不同（`wrong_b != correct`、`wrong_c != correct`、`wrong_d != correct`）
5. **考点被触发**：两趟划分后序列与初始序列不同（至少发生了一次元素交换），证明 partition 过程确实执行了
