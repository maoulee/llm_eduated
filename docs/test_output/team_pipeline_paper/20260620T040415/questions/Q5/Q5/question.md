# 题目

已知一棵二叉树共有 53 个结点，其中度为 1 的结点有 2 个。则该二叉树的叶子结点（度为 0 的结点）个数为（ ）。

A. 正确结果
B. 记错核心公式（误用 n0 = n2，漏掉 +1）的结果
C. 符号方向错误（误用 n0 = n2 - 1）的结果
D. 忽略度为1的结点（误用 n0 = n - n2）的结果

---

## 设计意图

**考察知识点**：
1. 二叉树叶子结点数与度为2结点数的关系：n0 = n2 + 1（核心公式）
2. 二叉树结点总数公式：n = n0 + n1 + n2（辅助公式，需联立求解）

**考察模式**：计算型——给出总结点数 n 和度为1的结点数 n1，要求联立两个公式推算叶子结点数 n0。

**参数选择**：
- n = 53（总结点数，在 20-100 范围内）
- n1 = 2（度为1的结点数，小整数）
- 联立 n = 2·n2 + n1 + 1 与 n0 = n2 + 1 可唯一确定 n0

**干扰项设计**：
- A：正确结果
- B：记错核心公式 n0 = n2（漏掉 +1），是 408 考生最常见错误
- C：符号方向错误 n0 = n2 - 1，是公式记忆混淆的典型错误
- D：忽略 n1，直接用 n - n2 计算 n0，是概念不清导致的错误

---

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **4 选项互异**：A/B/C/D 四个数值各不相同（exec 算出后无碰撞）。
2. **正确值唯一确定**：在 n=53、n1=2 条件下，联立 n = 2·n2 + n1 + 1 与 n0 = n2 + 1 得到的 n0 值唯一，且 A = 该值。
3. **干扰项对应声明错误类型**：
   - B 的值 = 按 n0 = n2 错误公式计算得到的结果
   - C 的值 = 按 n0 = n2 - 1 错误公式计算得到的结果
   - D 的值 = 按 n0 = n - n2 错误公式计算得到的结果
4. **干扰项有合理性**：B/C/D 均为同类题常见误算的真实产物，非荒谬值，具有区分度。
5. **参数一致性**：n=53 与 n1=2 奇偶性不同（53 为奇、2 为偶），满足 n - n1 - 1 为偶数的约束，保证 n2 为整数。
