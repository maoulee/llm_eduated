# 递归逆序输出链表

## 基本信息
- **题型**: 综合题（代码填空 + 功能说明）
- **分值**: 5 分
- **知识点**: 单链表基本结构、递归函数执行机制、递归逆序输出算法

## 题干

设单链表结点类型定义如下：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

以下递归函数 `ReversePrint` 用于对单链表进行某种操作。请阅读代码并回答问题：

```c
void ReversePrint(LinkList L) {
    if (L == NULL)
        return;
    ① ________________________;
    printf("%d ", L->data);
}
```

**问题**：

(1) 在代码的空白处①填入适当语句，使函数功能完整。（3 分）

(2) 简述函数 `ReversePrint` 的功能。（2 分）

---

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **空白处①为递归调用语句**：填入的语句形如 `ReversePrint(L->next)`，实现对后继结点的递归调用。
2. **递归调用在输出语句之前**：代码中 `ReversePrint(L->next)` 出现在 `printf("%d ", L->data)` 之前，保证"先递归到尾部，再回溯输出"的逆序逻辑。
3. **递归终止条件已定义**：函数开头已有 `if (L == NULL) return;`，防止无限递归。
4. **功能说明准确**：(2) 的答案应描述为"逆序输出单链表中各结点的数据值"或等价表述，而非"逆序链表"（不修改链表结构，仅输出）。
