## 考点
- **Dijkstra算法**：核心考点，考察逐趟松弛过程中 dist 数组的动态更新
- **单源最短路径**：理解源点到各顶点最短距离的含义
- **有向带权图表示**：邻接矩阵或边集表示法的读取与理解

## 难度目标
- **K1=1（微弱）**：Dijkstra 是数据结构基础算法，概念记忆门槛低，学生看到题干即可入题
- **K2=2（较低）**：单步操作为取 min 和加法，数字友好，计算量小
- **K3=4（较高）**：需手动模拟多轮松弛（>5步），每轮需维持 dist 数组和 S 集合状态，中间错一步后续全错，长程推演消耗工作记忆
- **K4=2（较低）**：存在常规注意点（如已选入 S 的顶点不再更新、无穷大的处理），408 考生基本不会踩坑
- **K5=1（微弱）**：单一知识点内部解决，不涉及跨域联动

## 考察模式
**推演型——Dijkstra算法手工模拟**

理由：该题位固定考察 Dijkstra 算法的手工执行过程，属于标准推演型题目。学生需按算法"说明书"逐轮执行：选最小 dist 顶点 → 加入 S → 松弛邻接边 → 更新 dist。考察核心是**过程记录能力**和**状态维持能力**，而非最终答案。

## 出题要求
- **题型**：综合题，10分
- **总条件数**：1个核心条件（图的表示）+ 1个源点指定
- **条件设计原则**：
  - 图以邻接矩阵或边集形式给出（二选一）
  - 源点明确指定
  - 所有边权为正整数（Dijkstra 前提）
- **参数取值范围要求**：
  - 顶点数：5-8 个（保证推演步数足够，但不超过工作记忆上限）
  - 边数：足够产生多轮非平凡松弛（避免某轮无更新）
  - 边权：正整数，建议 1-10 范围，避免过大导致计算负担

## 子问题规划

### 第 1 问（7分）：逐趟写出 dist 数组更新过程
- **类型**：推演/计算
- **考察目标**：Dijkstra 算法的逐轮执行过程，包括每轮选中的顶点、dist 数组变化
- **与前后问关系**：独立过程记录，第 2 问可基于此作答但也可独立计算

### 第 2 问（3分）：给出源点到各顶点的最短路径长度
- **类型**：结果提取
- **考察目标**：从 dist 数组最终状态提取最短路径长度
- **与前后问关系**：可基于第 1 问结果，也可独立计算验证

## 参数约束
- **顶点数 n**：5 ≤ n ≤ 8，建议 6-7 个顶点
- **边数 m**：足够产生至少 4-5 轮非平凡松弛（即每轮至少有一个 dist 更新）
- **边权 w**：正整数，1 ≤ w ≤ 10，避免 0 或负权
- **源点 s**：明确指定，建议选编号较小的顶点（如 v0 或 v1）
- **图连通性**：源点应能到达所有顶点（或明确标注不可达顶点）
- **一致性约束**：
  - 边权必须全为正（Dijkstra 适用前提）
  - 图应有足够的"迂回路径"，使得某些顶点的最短路径不是直接边，而是经过中间顶点（否则退化）
  - 至少存在一个顶点，其最短路径需要经过 ≥2 条边（保证算法非平凡）

## 参考经验
- **考察模式**：Dijkstra 手工模拟是数据结构图应用题位的经典模式，固定考察逐趟 dist 更新
- **难度锚点**：K3=4 为该题位典型难度，核心区分度在于推演过程的准确性
- **典型陷阱**：
  - 已选入 S 的顶点被错误地再次更新
  - 无穷大（∞）处理不当
  - 选最小 dist 时忽略 S 集合状态
  - 邻接矩阵读取错误（行/列混淆）
