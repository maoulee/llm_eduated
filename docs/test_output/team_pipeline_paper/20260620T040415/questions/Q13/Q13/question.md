# 散列表构造与ASL计算（拉链法）

## 题干

已知关键字序列为 $\langle 19, 32, 45, 58, 71, 20, 33, 46, 21, 34 \rangle$，散列表表长 $m=13$，散列函数为 $H(\text{key}) = \text{key} \bmod 13$，采用**拉链法**处理冲突，新元素插入时采用**头插法**（即新元素插入到链表表头）。

(1) 画出构造完成的散列表（以链表形式表示每个桶中的元素，按插入顺序排列）。

(2) 分别计算等概率情况下查找成功和查找不成功的平均查找长度 $ASL_{\text{success}}$ 和 $ASL_{\text{fail}}$。

> **说明**：
> - 查找成功的平均查找长度：$ASL_{\text{success}} = \frac{1}{n}\sum_{i=1}^{n} C_i$，其中 $C_i$ 为查找第 $i$ 个关键字所需的比较次数，$n$ 为关键字个数。
> - 查找不成功的平均查找长度：$ASL_{\text{fail}} = \frac{1}{m}\sum_{j=0}^{m-1} b_j$，其中 $b_j$ 为在第 $j$ 号桶中查找失败所需的比较次数（即该桶链表的长度），$m$ 为散列表表长。

---

## 设计意图

- **考察知识点**：
  - 拉链法构造散列表的机制（头插法）
  - 散列函数 $H(\text{key}) = \text{key} \bmod m$ 的计算
  - 查找成功 ASL 的计算（分母为 $n$）
  - 查找失败 ASL 的计算（分母为 $m$，比较次数为链表长度）

- **难度定位**：K1=2（基础概念记忆）、K2=3（分数运算）、K3=2（机械流程）、K4=2（常规陷阱：ASL_fail分母用n而非m）

- **典型陷阱**：
  - 查找失败 ASL 分母误用 $n$（关键字个数）而非 $m$（表长）
  - 链表第 $k$ 个元素的查找长度计算错误
  - mod 运算错误

---

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **散列表构造正确**：10个关键字按 $H(\text{key}) = \text{key} \bmod 13$ 分布到对应桶中，头插法插入顺序正确。
2. **非空桶数量在合理范围**：构造后的散列表非空桶数量为 3-5 个（本参数下为 3 个：桶6、桶7、桶8）。
3. **至少2个桶有≥2个元素**：存在至少 2 个桶，其链表长度 ≥ 2（本参数下桶6有5个元素、桶7有3个元素、桶8有2个元素）。
4. **ASL_success 分母为 n=10**：$ASL_{\text{success}}$ 的计算中分母使用关键字个数 $n=10$，而非表长 $m=13$。
5. **ASL_fail 分母为 m=13**：$ASL_{\text{fail}}$ 的计算中分母使用表长 $m=13$，而非关键字个数 $n=10$。
6. **ASL_success 与 ASL_fail 值互异**：两个 ASL 值不相同（因计算方式和分母不同，必然产生不同结果）。
7. **ASL 值为正分数**：$ASL_{\text{success}} > 0$ 且 $ASL_{\text{fail}} > 0$，且均为分数形式（非整数或退化值）。
