## 题目

已知某二叉树的后序遍历序列和中序遍历序列如下：

- **后序遍历**：`A E C B F H I G D`
- **中序遍历**：`A B E C D F H I G`

其中节点值为连续大写字母，无大小或顺序含义。

### （1）还原二叉树结构（6分）

根据上述两个遍历序列，还原该二叉树的结构，并画出二叉树示意图（或用文字描述每个节点的左右孩子关系）。

### （2）写出先序遍历序列（4分）

基于（1）中还原的二叉树，写出其先序遍历序列。

## 参考答案

```
        D

      B   G
     / \  /
    A  C I

        F
```

节点关系：D(左B,右G)、B(左A,右C)、A(叶子)、C(左E)、E(叶子)、G(左I)、I(左H)、H(左F)、F(叶子)。树深度 5 层。

（2）先序遍历序列：`D B A C E G I H F`

## 解析

### 第（1）问：还原二叉树结构

**核心原理：**
- **后序遍历**的最后一个元素是**根节点**。
- **中序遍历**中，根节点将序列分为**左子树**（根左侧）和**右子树**（根右侧）。
- 递归应用上述规则，即可唯一还原二叉树。

**逐步推导：**

**第 1 层：确定根节点**

- 后序遍历 `A E C B F H I G D` 的最后一个元素是 **D** → D 为根节点。
- 在中序遍历 `A B E C D F H I G` 中，D 的位置将序列分为：
  - 左子树中序：`A B E C`（4 个节点）
  - 右子树中序：`F H I G`（4 个节点）
- 对应后序序列：
  - 左子树后序：`A E C B`（前 4 个）
  - 右子树后序：`F H I G`（后 4 个）

**第 2 层：还原左子树（中序 `A B E C`，后序 `A E C B`）**

- 后序 `A E C B` 的最后一个元素是 **B** → B 为左子树根。
- 在中序 `A B E C` 中，B 的位置将序列分为：
  - B 的左子树中序：`A`（1 个节点）
  - B 的右子树中序：`E C`（2 个节点）
- 对应后序序列：
  - B 的左子树后序：`A`
  - B 的右子树后序：`E C`

**第 3 层：还原 B 的子节点**

- **B 的左孩子**：后序 `A` → 根为 **A**，中序 `A` 中无左右子树 → A 为叶子节点。
- **B 的右孩子**：后序 `E C` 的最后一个元素是 **C** → C 为根。
  - 在中序 `E C` 中，C 的位置将序列分为：
    - C 的左子树中序：`E`（1 个节点）
    - C 的右子树中序：空
  - 对应后序：C 的左子树后序：`E`
  - E 为叶子节点。

**第 2 层：还原右子树（中序 `F H I G`，后序 `F H I G`）**

- 后序 `F H I G` 的最后一个元素是 **G** → G 为右子树根。
- 在中序 `F H I G` 中，G 的位置将序列分为：
  - G 的左子树中序：`F H I`（3 个节点）
  - G 的右子树中序：空
- 对应后序：G 的左子树后序：`F H I`

**第 3 层：还原 G 的子节点**

- **G 的左孩子**：后序 `F H I` 的最后一个元素是 **I** → I 为根。
  - 在中序 `F H I` 中，I 的位置将序列分为：
    - I 的左子树中序：`F H`（2 个节点）
    - I 的右子树中序：空
  - 对应后序：I 的左子树后序：`F H`

**第 4 层：还原 I 的子节点**

- **I 的左孩子**：后序 `F H` 的最后一个元素是 **H** → H 为根。
  - 在中序 `F H` 中，H 的位置将序列分为：
    - H 的左子树中序：`F`（1 个节点）
    - H 的右子树中序：空
  - 对应后序：H 的左子树后序：`F`
  - F 为叶子节点。

**二叉树结构：**

```
        D
       / \
      B   G
     / \  /
    A  C I
       / /
      E H
         /
        F
```

**节点关系描述：**

| 节点 | 左孩子 | 右孩子 |
|------|--------|--------|
| D    | B      | G      |
| B    | A      | C      |
| A    | 无     | 无     |
| C    | E      | 无     |
| E    | 无     | 无     |
| G    | I      | 无     |
| I    | H      | 无     |

| F    | 无     | 无     |

树深度：5 层。

### 第（2）问：先序遍历序列

**先序遍历规则：** 根 → 左 → 右（根-左-右）。

**推导过程：**

从根节点 D 开始，按"根-左-右"顺序递归访问：

1. 访问 **D**（根）
2. 遍历 D 的左子树（根为 B）：
   - 访问 **B**
   - 遍历 B 的左子树：访问 **A**
   - 遍历 B 的右子树（根为 C）：
     - 访问 **C**
     - 遍历 C 的左子树：访问 **E**
3. 遍历 D 的右子树（根为 G）：
   - 访问 **G**
   - 遍历 G 的左子树（根为 I）：
     - 访问 **I**
     - 遍历 I 的左子树（根为 H）：
       - 访问 **H**
       - 遍历 H 的左子树：访问 **F**

**先序遍历序列：`D B A C E G I H F`**
