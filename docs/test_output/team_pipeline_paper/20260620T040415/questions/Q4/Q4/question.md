# 题目

设模式串 $s =$ "ababab"，采用 KMP 算法，next 数组的定义为：next[0] = 0，对于 $j > 0$，next[j] 表示子串 $s[0..j-1]$ 的最长相等**真**前后缀的长度（真前后缀指不等于串本身的前后缀）。

则 next[5] 的值为（ ）。

A. 正确结果
B. 混淆 next 与 nextval 数组产生的错误值
C. 前后缀长度算错 1（即 next[5] - 1）产生的错误值
D. 忘记"真前后缀"约束（将 "ababa" 本身当作相等前后缀）产生的错误值

---

## 设计意图

- **考察知识点**：KMP 算法中 next 数组的构造规则，特别是"真前后缀"概念的理解
- **考察目标**：学生能否正确理解 next 数组定义中"真前后缀"的含义，并逐位计算 next 值
- **难度控制**：模式串 "ababab" 具有周期性结构，next[5] 的计算需要比较 "ababa" 的所有真前后缀，非平凡但路径唯一

---

## 通过条件（成功判据）

本题成立 ⇔ 以下可机检特征全部满足：

1. **next[5] 可计算且 ≥ 2**：模式串 "ababab" 在位置 5 的 next 值通过标准算法可唯一确定，且结果非平凡（≥ 2）。
2. **4 选项互异**：A/B/C/D 四个选项的计算结果各不相同，无碰撞。
3. **正确值唯一确定**：在给定 next 数组定义（next[0]=0，真前后缀）下，next[5] 有且仅有一个确定值，A = 该值。
4. **干扰项对应声明错误类型**：
   - B = 按 nextval 数组规则计算 next[5] 得到的值（next 与 nextval 混淆）
   - C = next[5] - 1 = 2（前后缀长度算错 1）
   - D = 5（忘记"真前后缀"约束，将 "ababa" 本身当作相等前后缀，取其长度 5）
5. **干扰项有合理性**：B/C/D 均为 KMP 算法学习中常见误算的真实产物，具有区分度。
