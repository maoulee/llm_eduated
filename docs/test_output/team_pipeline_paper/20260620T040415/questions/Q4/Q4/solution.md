# 解析

## 一、计算 next 数组

模式串 $s =$ "ababab"，长度为 6。

按定义逐位计算 next 数组：

| $j$ | 子串 $s[0..j-1]$ | 真前后缀比较 | next[j] |
|-----|-------------------|-------------|---------|
| 0 | — | 定义 | 0 |
| 1 | "a" | 无真前后缀（长度 < 1） | 0 |
| 2 | "ab" | "a" ≠ "b" | 0 |
| 3 | "aba" | "a" = "a" ✓，"ab" ≠ "ba" | 1 |
| 4 | "abab" | "a" ≠ "b"，"ab" = "ab" ✓，"aba" ≠ "bab" | 2 |
| 5 | "ababa" | "a" = "a" ✓，"ab" ≠ "ba"，"aba" = "aba" ✓，"abab" ≠ "baba" | 3 |

**next 数组 = [0, 0, 0, 1, 2, 3]**

## 二、计算 nextval 数组（用于干扰项 B）

按 nextval 优化规则逐位计算：

| $j$ | $s[j]$ | $s[\text{next}[j]]$ | 是否相等 | nextval[j] |
|-----|---------|---------------------|---------|------------|
| 0 | — | — | — | 0 |
| 1 | 'b' | $s[0]$='a' | 否 | next[1] = 0 |
| 2 | 'a' | $s[0]$='a' | 是 | nextval[0] = 0 |
| 3 | 'b' | $s[1]$='b' | 是 | nextval[1] = 0 |
| 4 | 'a' | $s[2]$='a' | 是 | nextval[2] = 0 |
| 5 | 'b' | $s[3]$='b' | 是 | nextval[3] = 0 |

**nextval 数组 = [0, 0, 0, 0, 0, 0]**

## 三、各选项值

- **A（正确答案）**：next[5] = **3**
  - 子串 $s[0..4]$ = "ababa"，最长相等真前后缀为 "aba"，长度为 3。

- **B（混淆 next 与 nextval）**：nextval[5] = **0**
  - 误用 nextval 数组代替 next 数组。

- **C（前后缀长度算错 1）**：next[5] - 1 = 3 - 1 = **2**
  - 正确值为 3，但少算了 1。

- **D（忘记"真前后缀"约束）**：len("ababa") = **5**
  - 将子串 "ababa" 本身当作相等前后缀，取其全长 5，忽略了"真前后缀"要求前后缀长度必须小于串本身长度。

## 四、答案

**正确答案：A. 3**
