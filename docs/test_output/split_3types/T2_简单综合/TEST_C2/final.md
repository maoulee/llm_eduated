## 题目

已知一棵二叉树的先序遍历序列为 `ABDCEGF`，中序遍历序列为 `DBAEGCF`，其中每个节点用一个大写字母标识，且各节点标识互不相同。

> 树高定义：根节点所在的层为第 1 层，树高等于最大层数。

请回答下列问题：

### （1）（4分）
根据给定的先序遍历序列和中序遍历序列，画出该二叉树的结构（标明各节点的左右孩子关系）。

### （2）（2分）
写出该二叉树的后序遍历序列。

### （3）（2分）
求该二叉树的树高和叶子节点数。

### （4）（2分）
对该二叉树进行中序线索化后，判断节点 `E` 的中序前驱和中序后继分别是哪个节点，并分别说明是通过孩子指针到达还是通过线索指针到达。

## 子问题

- （1）（4分）还原二叉树结构
- （2）（2分）后序遍历序列
- （3）（2分）树高和叶子节点数
- （4）（2分）中序线索化后节点 E 的中序前驱和中序后继

## 求解过程

### （1）还原二叉树结构

先序序列确定子树根节点，中序序列划分左右子树：

1. 先序首节点 `A` 为根；中序中 `A` 左侧 `DB` 为左子树，右侧 `EGCF` 为右子树。
2. 左子树 `DB`：先序首 `B` 为根，中序中 `B` 左侧 `D` → `D` 是 `B` 的左孩子，`B` 无右孩子。
3. 右子树 `CEGF`：先序首 `C` 为根，中序中 `C` 左侧 `E`、右侧 `F` → `C` 左孩子 `E`、右孩子 `F`。
4. `C` 的左子树：先序 `EG`，中序中 `E` 无左侧节点（无左孩子），`G` 是 `E` 的右孩子。

还原结果：

```
        A
       / \
      B   C
     /   / \
    D   E   F
         \
          G
```

### （2）后序遍历序列

后序遍历（左右根）：D → B → G → E → F → C → A

### （3）树高和叶子节点数

- A 在第 1 层，B/C 在第 2 层，D/E/F 在第 3 层，G 在第 4 层。树高 = 4。
- 叶子节点：D、F、G，共 3 个。

### （4）节点 E 的中序线索化分析

中序序列为 `DBAEGCF`，E 位于第 4 位（D-B-A-**E**-G-C-F）。

- **中序前驱**：E 无左孩子（ltag=1），前驱通过线索指针到达。中序序列中 E 前一个节点是 `A`。前驱 = **A**（线索指针）。
- **中序后继**：E 有右孩子 G（rtag=0），后继通过孩子指针到达右子树最左下节点。G 无左孩子，故后继 = **G**（孩子指针）。

## 答案

- **（1）** 二叉树结构：A(左B, 右C)，B(左D)，C(左E, 右F)，E(右G)，D/F/G 为叶子。
- **（2）** 后序遍历序列：`DBGEFCA`
- **（3）** 树高 = 4，叶子节点数 = 3
- **（4）** 节点 E 的中序前驱 = **A**（线索指针，ltag=1）；中序后继 = **G**（孩子指针，rtag=0）
