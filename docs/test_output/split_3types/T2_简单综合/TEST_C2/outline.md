## 考点
- **核心考点：二叉树遍历序列还原**（DS-5 > 树与二叉树 > 二叉树遍历）
  - 考察侧重点：由先序+中序（或后序+中序）遍历序列唯一确定二叉树结构的能力
- **辅助考点：后序遍历推导**
  - 考察侧重点：在还原出的二叉树基础上，正确写出后序遍历序列
- **辅助考点：二叉树基本性质**
  - 考察侧重点：树高、叶子节点数、度为特定值的节点数计算
- **辅助考点：线索二叉树**
  - 考察侧重点：中序线索化后，某节点的前驱/后继判断

## 难度目标
- **K1=2（概念识别）**：学生需识别遍历序列中根节点位置规律（先序首元素为根、中序中根节点分割左右子树），属于基础概念应用，定位中低
- **K2=3（理解应用）**：需要理解还原算法的递归本质并正确执行，涉及多轮递归分割，定位中等
- **K3=2（计算量）**：还原过程以结构推导为主，数值计算较少（树高、叶子数等简单计数），定位偏低
- **K4=3（综合分析）**：需将还原结果与后续分析（后序序列、线索化前驱后继）串联，考察综合运用能力，定位中等
- **K5=1（推理创造）**：不涉及证明或算法设计，无需高阶推理，定位最低

## 考察模式
**遍历序列还原 + 后续分析模式**

理由：这是 408 数据结构综合题中二叉树遍历的高频考察模式。历史真题中，该模式通常给出两种遍历序列，要求还原二叉树，再在此基础上回答后序序列、树性质或线索化等问题。此模式能同时考察还原算法的执行能力和对二叉树性质的综合理解，符合 medium 难度定位。

## 出题要求
- **题型**：综合题
- **总条件数**：2 个核心条件（先序遍历序列、中序遍历序列）
- **条件设计原则**：
  - 先序和中序序列必须能唯一确定一棵二叉树
  - 序列中的元素须互不相同（用字母或编号标识节点）
  - 树的形态应有适度复杂度：非完全二叉树，左右子树不对称，包含度为1的节点
- **参数取值范围要求**：
  - 节点数 N：7～11 个
  - 树的高度 H：3～4 层
  - 至少包含一个度为1的节点（用于线索化时产生非空前驱/后继关系）
  - 避免退化为链表的极端情况

## 子问题规划
| 序号 | 类型 | 考察目标 | 分值 | 与前后问关系 |
|------|------|----------|------|-------------|
| 第1问 | 结构推导 | 根据先序+中序序列还原二叉树，画出树形结构 | 4分 | 独立题，后续各问均依赖此问结果 |
| 第2问 | 计算/推导 | 写出还原后二叉树的后序遍历序列 | 2分 | 依赖第1问的还原结果 |
| 第3问 | 分析 | 计算树的高度、叶子节点数 | 2分 | 依赖第1问的还原结果 |
| 第4问 | 分析 | 对该二叉树进行中序线索化，指定某非叶子节点，判断其中序前驱和后继节点 | 2分 | 依赖第1问的还原结果及中序序列 |

**总分：10分**

**依赖关系**：以第1问为核心的星型结构（第2、3、4问均独立依赖第1问结果，彼此之间无依赖）

## 参数约束
| 参数 | 取值范围 | 一致性约束 | 可调自由度 |
|------|----------|------------|------------|
| 节点数 N | 7 ≤ N ≤ 11 | N 必须等于先序序列和中序序列的长度 | Question Agent 自由选定具体值 |
| 树高 H | 3 ≤ H ≤ 4 | H 由树的形态决定，须与遍历序列一致 | 由 N 和树形态共同决定 |
| 度为1的节点数 | ≥ 1 | 至少有一个度为1的节点 | Question Agent 控制树形态时保证 |
| 叶子节点数 | ≥ 3 | 须与还原后的树结构一致 | 由树形态决定 |
| 节点标识方式 | 大写字母 A～K 或编号 1～N | 先序和中序序列中元素完全一致、无重复 | Question Agent 自由选择标识方式 |
| 线索化指定节点 | 非根、非叶子节点 | 该节点的中序前驱/后继中至少有一个不是直接父子关系 | Question Agent 选定 |

## 参考经验
- **历史模式**：408 真题中，二叉树遍历综合题的标准模式为"给定先序+中序→还原→后序/性质/线索化"。此模式在 2010-2020 年间多次出现。
- **难度锚点**：还原部分是主要区分点，K2=3 级别的考生能正确还原但可能在后续分析中出错。树形态选择（左右不对称、含度为1节点）是调节难度的关键手段。
- **典型陷阱**：
  1. 先序序列中根节点不是最左叶子
  2. 中序序列中根节点位置不在正中间（学生易误认为平衡树）
  3. 线索化时混淆中序前驱与直接前驱（尤其是度为1节点的线索指向）
  4. 后序遍历中，左右子树先序与"左右根"顺序混淆
