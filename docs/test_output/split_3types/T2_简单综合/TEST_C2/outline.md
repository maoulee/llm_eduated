## 考点
- **二叉树遍历序列还原**（核心）：根据两种遍历序列（前序+中序 或 后序+中序）唯一确定二叉树结构
- **遍历序列的本质**（辅助）：理解前序、中序、后序遍历的递归定义和根节点位置特征
- **二叉树基本属性**（辅助）：树的高度、叶子节点数、度为1的节点数等

## 难度目标
- **K1（知识广度）= 3**：涉及前序/中序/后序遍历、树结构还原、树属性计算，覆盖3个知识点
- **K2（知识深度）= 3**：需深入理解遍历的递归本质，掌握"根-左-右"的分解思想
- **K3（计算复杂度）= 3**：还原过程需多步递归推理，每步需定位根节点并划分左右子树
- **K4（抽象程度）= 2**：中等抽象，主要考察递归思维，不涉及复杂抽象概念
- **K5（综合程度）= 3**：综合遍历知识与树结构分析，需将序列信息转化为树结构再推导其他属性

## 考察模式
**模式：给定双序列还原 + 属性推导**
- 给定前序遍历序列和中序遍历序列（或后序+中序）
- 第1问：还原二叉树结构（画图或写出另一种遍历序列）
- 第2问：基于还原的树，求层序遍历序列或计算树属性
- 理由：该模式能完整考察"序列→结构→序列/属性"的转换能力，是408考研中二叉树遍历的经典考察方式

## 出题要求
- **题型**：综合题（2-3问）
- **总条件数**：2个显式条件（两种遍历序列）+ 隐含条件（二叉树定义）
- **条件设计原则**：
  - 给定的两种遍历序列必须能唯一确定二叉树
  - 避免给出前序+后序（通常不能唯一确定）
  - 序列中的元素需互不相同
- **参数取值范围要求**：
  - 节点数：6-10个（太少无法体现还原过程，太多增加计算负担）
  - 节点值：使用大写字母（A-J）或数字（1-10），保证可读性
  - 树结构：非完全二叉树、非链状退化树，左右子树均非空

## 子问题规划
**子问题数量：2问**

**第1问（6-7分）**：
- **类型**：计算/构造
- **考察目标**：根据给定的前序和中序遍历序列，还原二叉树结构
- **作答形式**：画出二叉树 或 写出后序遍历序列
- **与前后问关系**：独立，为第2问提供基础

**第2问（3-4分）**：
- **类型**：计算
- **考察目标**：基于第1问还原的树，求层序遍历序列 或 计算树的高度/叶子节点数
- **作答形式**：写出序列或数值
- **与前后问关系**：依赖第1问的还原结果

## 参数约束
- **节点数 n**：6 ≤ n ≤ 10，整数
- **遍历序列类型**：前序+中序 或 后序+中序（二选一）
- **节点值集合**：n个互不相同的字符或数字
- **树结构约束**：
  - 根节点左右子树均非空
  - 树的高度 h 满足：2 ≤ h ≤ n-1（非链状）
  - 至少有一个节点的度为2
- **序列一致性**：给定的两种遍历序列必须对应同一棵二叉树
- **可调自由度**：节点数、树的具体形态、节点值分配

## 参考经验
- **历史模式**：408考研中二叉树遍历题常以"给两序列求第三序列"或"给两序列画图"形式出现
- **难度锚点**：中等难度题通常节点数7-9个，2问结构，总分10-11分
- **典型陷阱**：
  - 学生混淆前序和中序中根节点的位置
  - 递归划分左右子树时边界错误
  - 层序遍历时队列操作顺序错误
  - 将"前序+后序"误认为能唯一确定二叉树
