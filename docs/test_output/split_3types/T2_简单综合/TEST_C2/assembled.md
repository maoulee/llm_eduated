## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: DS-5 > 树与二叉树 > 二叉树遍历
- primary_target_name: 二叉树遍历序列还原
- question_type: comprehensive
- examination_mode: 遍历序列还原 + 后续分析模式

### 难度目标
- k_target: K1=2,K2=3,K3=2,K4=3,K5=1
- difficulty_level: 3
- difficulty_rationale: 核心区分点在于遍历序列还原的递归执行能力（K2=3）和综合分析能力（K4=3），计算量偏低（K3=2），不涉及高阶推理（K5=1），整体定位 medium

### 结构要求
- sub_question_count: 4
- sub_question_distribution:
  - q1: 结构推导，4分，根据先序+中序还原二叉树
  - q2: 计算/推导，2分，写出后序遍历序列
  - q3: 分析，2分，计算树高和叶子节点数
  - q4: 分析，2分，中序线索化后判断指定节点的前驱/后继
- dependency_structure: star（q1为核心，q2/q3/q4均依赖q1，彼此独立）
- condition_count: 2（先序遍历序列、中序遍历序列）
- total_points: 10

### 参数约束
- 节点数 N: 7 ≤ N ≤ 11，等于先序序列和中序序列长度
- 树高 H: 3 ≤ H ≤ 4，由树形态决定
- 度为1的节点数: ≥ 1（保证线索化问题有区分度）
- 叶子节点数: ≥ 3
- 节点标识: 大写字母 A～K 或编号 1～N，无重复
- 树形态约束: 非完全二叉树，左右子树不对称，避免退化为链表
- 线索化指定节点: 非根非叶节点，其中序前驱或后继中至少一个不是直接父子关系
- 先序与中序序列一致性: 两序列元素集合相同，能唯一确定一棵二叉树

### 参考经验摘要
- 历史模式: 408 真题高频模式"先序+中序还原→后序/性质/线索化"，2010-2020年间多次出现
- 难度锚点: K2=3 级别考生能还原但后续分析易错；树形态选择是难度调节核心手段
- 典型陷阱:
  1. 先序根节点不是最左叶子（学生直觉误区）
  2. 中序根节点位置不在正中间（误认为平衡树）
  3. 线索化时混淆中序前驱与直接前驱（度为1节点线索指向）
  4. 后序遍历中左右子树顺序与"左右根"混淆
