## 题干
已知一棵二叉树的先序遍历序列为 `ABDCEGF`，中序遍历序列为 `DBAEGCF`，其中每个节点用一个大写字母标识，且各节点标识互不相同。

> 树高定义：根节点所在的层为第 1 层，树高等于最大层数。

请回答下列问题：

### （1）（4分）
根据给定的先序遍历序列和中序遍历序列，画出该二叉树的结构（标明各节点的左右孩子关系）。

### （2）（2分）
写出该二叉树的后序遍历序列。

### （3）（2分）
求该二叉树的树高和叶子节点数。

### （4）（2分）
对该二叉树进行中序线索化后，判断节点 `E` 的中序前驱和中序后继分别是哪个节点，并分别说明是通过孩子指针到达还是通过线索指针到达。
