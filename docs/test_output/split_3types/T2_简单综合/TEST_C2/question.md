## 题干
已知某二叉树的前序遍历序列为 A B D E C F G H，中序遍历序列为 D B E A F C G H。

请回答下列问题：

### (1) （7分）根据上述前序遍历序列和中序遍历序列，还原该二叉树的结构，并画出该二叉树（或写出各节点的父子关系）。

### (2) （3分）基于(1)中还原的二叉树，写出该二叉树的层序遍历序列（从上到下、从左到右依次访问各节点）。

## 设计说明
- **复用骨架来源**：往年综合题"给定双序列还原二叉树 + 推导第三序列/树属性"骨架。检索到的往年题（如2012_Q3"前序+后序确定根的孩子"、simulation_00088"遍历算法叶节点次序"）均采用"给遍历序列→还原结构→推导属性"的递进设问方式。本题复用该骨架：第1问还原树结构（递归分割），第2问基于还原结果推导层序遍历序列。
- **考察形式**：多步串行推演（主）+ 跨域组合（辅）。前序与中序两种遍历序列跨域联动还原树结构，子问间串行依赖。
- **子问依赖链**：(1) 递归分割还原二叉树结构 → (2) 基于(1)还原的树结构执行层序遍历。第2问必须依赖第1问结果，串行不可逆。
- **初步参数选择理由**（基于骨架+经验，大胆给）：
  - 节点数 n=8：往年题经验锚点在7-9节点，取8为中间值，保证递归分割有足够步骤但不冗长
  - 遍历序列组合：前序+中序（经典可唯一确定组合，排除前序+后序）
  - 节点值：A~H共8个互不相同的大写字母，清晰易读
  - 树结构设计：根A，左子树{B,D,E}（B为左子树根，D为B左孩子，E为B右孩子），右子树{C,F,G,H}（C为右子树根，F为C左孩子，G为C右孩子，H为G右孩子）。左右子树均非空，高度4（2≤4≤7），B和C为度2节点
- **与目标 K-雷达的对齐**：
  - K1=3：需理解前序/中序/层序遍历的基本定义
  - K2=3：单步定位根节点（前序首元素）、在中序中分割左右子树
  - K3=3：多步递归分割（根→左子树递归→右子树递归），串行推演
  - K4=2：无复杂条件路由，陷阱来自递归边界off-by-one而非条件判断
  - K5=3：前序与中序两种遍历视角跨域联动，节点信息在两种序列间传递
- **是否融合**：不融合。K3=3为中等难度，单骨架（双序列还原+层序推导）已满足目标K-雷达，无需额外融合多侧重。
