## 求解过程

### （1）根据先序序列和中序序列还原二叉树结构

**还原方法：** 先序序列确定子树的根节点，中序序列划分左右子树。

**逐步还原：**

- **第 1 步：** 先序第一个节点 `A` 是整棵树的根。在中序序列 `DBAEGCF` 中，`A` 左侧 `DB` 是左子树，右侧 `EGCF` 是右子树。

- **第 2 步（左子树 DB）：** 先序中 `DB` 的第一个是 `B`，为左子树的根。中序中 `B` 左侧只有 `D`，所以 `D` 是 `B` 的左孩子，`B` 无右孩子。

- **第 3 步（右子树 EGCF）：** 先序中 `CEGF` 的第一个是 `C`，为右子树的根。中序中 `C` 左侧是 `E`，右侧是 `F`，所以 `C` 的左孩子是 `E`，右孩子是 `F`。

- **第 4 步（C 的左子树 E）：** 先序中 `E` 之后是 `G`。中序中 `E` 无左侧节点（说明 `E` 无左孩子），`E` 右侧在中序序列中是 `C` 而非 `G`，结合先序 `EG`，`G` 是 `E` 的右孩子。

- **第 5 步（叶子确认）：** `D`、`F`、`G` 在各自子树中无后续节点，均为叶子。

**还原结果（与 exec 输出一致）：**

```
        A
       / \
      B   C
     /   / \
    D   E   F
         \
          G
```

各节点左右孩子关系：
- A：左孩子 = B，右孩子 = C
- B：左孩子 = D，右孩子 = 无
- C：左孩子 = E，右孩子 = F
- D：叶子
- E：左孩子 = 无，右孩子 = G
- F：叶子
- G：叶子

### （2）后序遍历序列

后序遍历顺序为"左右根"：

1. 以 A 为根，先遍历左子树 B（→D→B），再遍历右子树 C（→E→G→E→F→C），最后访问 A
2. 完整展开：D → B → G → E → F → C → A

**后序遍历序列 = `DBGEFCA`**（与 exec 输出一致）

### （3）树高和叶子节点数

**树高：** 根节点 A 在第 1 层，B/C 在第 2 层，D/E/F 在第 3 层，G 在第 4 层。最长路径 A→C→E→G 共 4 层。

- **树高 = 4**（与 exec 输出一致）

**叶子节点数：** 叶子节点为 D、F、G，共 3 个。

- **叶子节点数 = 3**（与 exec 输出一致）

### （4）节点 E 的中序线索化分析

中序遍历序列为 `DBAEGCF`，E 在其中的位置为第 4 个（D-B-A-**E**-G-C-F）。

**中序前驱：**

E 没有左孩子（ltag = 1），因此前驱不能通过左子树最右下节点找到，而是通过线索指针（lchild 作为线索）指向。

在中序序列中 E 的前一个节点是 `A`。

- **中序前驱 = A，通过线索指针到达（ltag = 1，lchild 指向前驱 A）**

> 验证：E 的父节点是 C，前驱 A 并非 E 的直接父子关系（A 是 E 的祖父），符合"前驱不是直接父子"的线索化特征。

**中序后继：**

E 有右孩子 G（rtag = 0），因此后继通过孩子指针找到——即右子树的最左下节点。G 没有左孩子，所以右子树最左下节点就是 G 本身。

- **中序后继 = G，通过孩子指针到达（rtag = 0，沿 rchild 下行至右子树最左下节点）**

> 验证：后继 G 是 E 的直接右孩子，符合"后继是直接父子"的特征。

## 最终答案

- **（1）** 二叉树结构：A(左B,右C)，B(左D)，C(左E,右F)，E(右G)，D/F/G 为叶子。
- **（2）** 后序遍历序列：`DBGEFCA`
- **（3）** 树高 = 4，叶子节点数 = 3
- **（4）** 节点 E 的中序前驱 = **A**（线索指针，ltag=1）；中序后继 = **G**（孩子指针，rtag=0）
