## rationale
- 为何选此形式：目标 K-雷达中 K2=3 与 K4=3 并列最高，且该题为综合题（star 结构），q1 要求考生多步执行"定位根→划分子树→递归还原"的串行推演过程，对应 K2 的逐步代入能力；q2/q3/q4 在 q1 结果基础上设置后序顺序倒置、树高 off-by-one、线索化前驱/后继概念混淆三类干扰，对应 K4 的条件路由与陷阱识别。整体形态为"核心串行推演 + 外围陷阱辨析"的混合形式，与遍历序列还原+后续分析的经验模式一致。
- 与目标 K-雷达的对齐说明：K2=3 由 q1 的递归还原执行（多步单点代入）承载；K4=3 由 q2/q3/q4 的干扰策略（顺序倒置/偏移/概念混淆）承载；K3=2 由后序遍历与树高推导的中等推理量承载；K1=2 需考生掌握遍历定义与线索化概念即可进入分析；K5=1 不涉及跨子系统联动，均为二叉树单一知识域内分析。
