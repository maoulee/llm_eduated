## examination_form
- 考察形式：多步串行推演（主）+ 跨域组合（辅）
- 设问方向：给定两种遍历序列，通过递归分割多步还原二叉树结构，再基于还原结果推导层序遍历或树属性

## k_radar
- K1（基础认知）: 3
- K2（单步代入）: 3
- K3（机制推演）: 3
- K4（条件路由）: 2
- K5（跨域联动）: 3
- 形状主导维度：K3 + K5（双主导）

## rationale
- K3主导：递归分割还原二叉树是典型的多步串行推演——根节点定位→中序分割→子序列分割→递归，子问间串行依赖，符合"多步串行推演"形式
- K5辅助：前序（或后序）与中序两种遍历序列之间的跨域联动还原，需在不同遍历视角间传递节点信息，体现跨域组合特征
- K4最低（=2）：本题不依赖隐含前提或反直觉条件，陷阱主要来自递归边界计算偏差而非条件路由，故不采用"陷阱辨析"作为主导形式
- 与目标K-雷达对齐：K3=K5=3双主导，K1=K2=3中等支撑，K4=2最低，与"多步串行推演+跨域组合"的混合形式完全一致
