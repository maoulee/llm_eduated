## 出题契约

### 基本信息
- target_subject: 数据结构
- target_family: DS-5 > 树与二叉树
- primary_target_name: 二叉树带权路径长度
- question_type: single_choice
- examination_mode: 给定二叉树结构+叶子权值 → 计算WPL

### 难度目标
- k_target: K1=2,K2=3,K3=3,K4=2,K5=1
- difficulty_level: 3
- difficulty_rationale: 中等难度，考查WPL基本概念和计算能力，计算量适中，适合选择题形式

### 结构要求
- option_count: 4
- distractor_strategy: 覆盖典型错误类型（路径长度计数起点错误、遗漏叶子结点、层次与路径长度混淆、计算错误）
- condition_count: 2

### 参数约束
- 叶子结点数量 (n): 3 ≤ n ≤ 5，整数
- 权值 (w_i): 1 ≤ w_i ≤ 15，整数，各叶子权值可相同可不同
- 树的高度 (h): 3 ≤ h ≤ 4，整数
- 路径长度 (l_i): 由树结构决定，1 ≤ l_i ≤ h-1
- WPL结果: 20 ≤ WPL ≤ 80
- 一致性约束: 所有叶子结点路径长度之和应合理（避免全部在同一层）；权值与路径长度乘积之和应在目标范围内；树结构必须合法

### 参考经验摘要
- 历史模式: 图形化二叉树+权值标注是最常见的呈现方式
- 难度锚点: 中等难度WPL题目通常涉及3-5个叶子结点，计算结果在20-80范围内
- 典型陷阱: 路径长度从1开始计数（错误）、只计算部分叶子结点、将路径长度理解为结点层次、权值与路径长度相乘时计算错误
