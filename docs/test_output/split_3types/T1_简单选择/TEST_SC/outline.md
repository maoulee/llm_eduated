## 考点
- **二叉树带权路径长度(WPL)**：核心考点，考察WPL的定义与计算方法
  - 考察侧重点：理解路径长度概念（根到结点的边数）、掌握WPL计算公式 Σ(权值×路径长度)
- **二叉树结构表示**：辅助考点，通过图形或描述给出二叉树结构
  - 考察侧重点：识别叶子结点、确定各结点到根的路径长度

## 难度目标
- **K1（知识记忆）= 2**：需要记忆WPL的定义和公式，中等记忆要求
- **K2（理解）= 3**：需要理解路径长度的含义（边数而非结点数）、理解权值与路径长度的乘积意义
- **K3（应用）= 3**：需要应用WPL公式对给定二叉树进行计算，中等应用难度
- **K4（分析）= 2**：需要分析二叉树结构，识别叶子结点，较低分析要求
- **K5（综合）= 1**：选择题形式，综合要求较低，单一知识点考查

**整体难度定位**：中等（medium），符合slot数据设定

## 考察模式
**模式选择**：给定二叉树结构+叶子权值 → 计算WPL

**理由**：
- 这是WPL最经典、最直接的考察方式
- 适合选择题形式，计算量可控
- 能有效区分是否真正理解路径长度概念（常见陷阱）
- 历史同类题目多采用此模式

**备选模式**（不采用）：
- 哈夫曼树构造+WPL计算：难度偏高，更适合综合题
- WPL性质判断：考查深度不够，区分度低

## 出题要求
- **题型**：single_choice（四选一选择题）
- **总条件数**：2个显式条件
  1. 二叉树的结构（图形或文字描述）
  2. 各叶子结点的权值
- **条件设计原则**：
  - 二叉树结构应清晰，避免歧义
  - 权值分配应使计算结果适中（避免过大或过小）
  - 树的高度建议3-4层，叶子结点3-5个
- **参数取值范围要求**：
  - 叶子结点数量：3-5个
  - 权值范围：1-15的整数
  - 树的高度：3-4层
  - WPL计算结果：20-80之间（便于验算）

## 子问题规划
本题为选择题，无子问题。

**选项要求**：
- 4个选项，1个正确，3个干扰
- 选项数值应接近，增加区分度
- 干扰项应覆盖典型错误类型

## 参数约束
- **叶子结点数量 (n)**：3 ≤ n ≤ 5，整数
- **权值 (w_i)**：1 ≤ w_i ≤ 15，整数，各叶子权值可相同可不同
- **树的高度 (h)**：3 ≤ h ≤ 4，整数
- **路径长度 (l_i)**：由树结构决定，1 ≤ l_i ≤ h-1
- **WPL结果**：20 ≤ WPL ≤ 80，确保计算量适中
- **一致性约束**：
  - 所有叶子结点的路径长度之和应合理（避免全部在同一层）
  - 权值与路径长度的乘积之和应在目标范围内
  - 树结构必须合法（每个结点最多2个子结点）

## 参考经验
**典型陷阱**：
1. 路径长度从1开始计数（错误），应从0开始（根到自身路径长度为0）
2. 只计算部分叶子结点，遗漏某些叶子
3. 将路径长度理解为结点层次（层次从1开始，路径长度从0开始）
4. 权值与路径长度相乘时计算错误

**难度锚点**：
- 中等难度WPL题目通常涉及3-5个叶子结点
- 计算结果在20-80范围内便于学生验算
- 干扰项与正确答案差距在10-30之间

**考察模式参考**：
- 图形化二叉树+权值标注是最常见的呈现方式
- 也可用文字描述（如"根结点A有左右子结点B、C，B有左子结点D..."）
