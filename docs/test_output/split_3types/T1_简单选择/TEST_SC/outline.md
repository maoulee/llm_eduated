## 考点
- **核心知识点**：二叉树带权路径长度（WPL）
  - 考察侧重点：WPL 的定义与计算——WPL = Σ(叶子节点权值 × 该叶子到根的路径长度)，其中路径长度为从根到该节点的**边数**
- **辅助知识点**：
  - 二叉树的层次结构（层数/深度与路径长度的关系）
  - 叶子节点的识别（给定树结构中哪些节点是叶子）
- **不涉及**：哈夫曼树的构造、最优前缀编码等（除非作为干扰项的概念陷阱）

## 难度目标
- **K1 = 2（概念理解）**：需准确理解 WPL 定义，特别是"路径长度=边数"而非"层数"
- **K2 = 2（计算复杂度）**：需对 4-6 个叶子节点逐一计算乘积并求和，计算量适中
- **K3 = 2（推理分析）**：需从给定树结构中正确识别叶子节点及其所在层数
- **K4 = 1（知识综合度）**：主要考查 WPL 单一概念，辅助以树的基本结构理解
- **K5 = 2（陷阱干扰度）**：设置路径长度定义混淆类干扰项，区分理解与死记

## 考察模式
**模式：给定二叉树结构 + 叶子权值 → 计算 WPL**

选择理由：这是 408 中考查 WPL 的经典模式。通过给定一棵明确的二叉树（可用图示或层次序列描述），要求考生计算 WPL。该模式直接考查定义理解和计算能力，适合 medium 难度的选择题。

备选模式（不采用）：
- "判断 WPL 相关说法正误"：偏概念辨析，计算成分不足
- "给定叶子权值求最小 WPL"：涉及哈夫曼树构造，超出当前考点范围

## 出题要求
- **题型**：单项选择题（4 选项，1 正确 3 干扰）
- **总条件数**：2-3 个显式条件
  - 条件 1：二叉树的完整结构描述（树形图或节点-边关系）
  - 条件 2：各叶子节点的权值
  - 条件 3（可选）：树的根节点定义或特殊说明
- **条件设计原则**：
  - 树结构必须明确无歧义，每个节点的左右孩子关系清晰
  - 权值与叶子的对应关系必须明确
  - 所有非叶子节点的子节点信息完整，避免"半描述"造成歧义

## 子问题规划
选择题无子问题拆分。单题考查 WPL 的完整计算。

## 参数约束
| 参数 | 取值范围 | 约束说明 |
|------|----------|----------|
| 树的深度 | 3-4 层（根为第 1 层） | 保证有足够叶子且计算量适中；深度过浅无区分度，过深则计算冗余 |
| 叶子节点数 | 4-6 个 | 与深度匹配，保证 WPL 计算有一定工作量 |
| 叶子权值 | 正整数，取值范围 1-9 | 便于心算，避免大数计算干扰考查目标 |
| 路径长度（叶子到根边数） | 2-3 | 由树深度决定，与深度一致 |
| WPL 正确答案值范围 | 约 30-80 | 4-6 个叶子，权值 1-9，路径 2-3，自然落入此区间 |
| 干扰项与正确答案差值 | 绝对差 ≥ 3 | 避免因计算近似导致的"碰巧选对" |

**参数间一致性约束**：
- 叶子节点数 ≤ 树的最大可能叶子数（由深度决定）
- 所有叶子的深度不必相同（允许树为非完全二叉树，增加分析难度）
- 权值不可为 0（避免"零权叶子不影响 WPL"的特殊情况，除非刻意设为陷阱）

## 参考经验
- **考察模式**：408 真题中 WPL 的典型考法为"给定树和权值求 WPL"或"判断 WPL/哈夫曼树相关性质"
- **难度锚点**：作为选择题，WPL 计算题通常定位在中等偏易，关键区分点在于路径长度的定义（边数 vs 层数差）
- **典型陷阱**：
  1. 路径长度混淆：用"层数"（从 1 开始）代替"边数"（从 0 开始），导致每个叶子的路径长度多算 1
  2. 非叶子节点误算：将内部节点的权值（若有）也计入 WPL
  3. 叶子识别错误：在有单子节点的树中误判叶子
  4. 计算遗漏：漏算某个叶子的贡献
