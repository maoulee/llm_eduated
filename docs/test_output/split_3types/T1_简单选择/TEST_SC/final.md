## 题目

已知一棵二叉树如下图所示。图中圆圈内的数字为节点编号，括号内的数字为该节点的权值。

```
                        ①
                      /     \
                    ②        ③
                   /  \     /   \
                ④(4) ⑤(8) ⑥(2) ⑦(6)
                     /  \
                  ⑧(5) ⑨(3)
```

注：从根节点到某节点的**路径长度**为该路径上的**边数**（根节点的路径长度为 0）。**带权路径长度（WPL）** 定义为树中所有**叶子节点**的权值与其路径长度乘积之和。

该二叉树的带权路径长度（WPL）为多少？

## 选项

A. 24
B. 48
C. 64
D. 68

## 求解过程

**第一步：识别叶子节点**

度为0的节点（左右子树均为空）为叶子：④(权值4)、⑥(权值2)、⑦(权值6)、⑧(权值5)、⑨(权值3)。节点⑤虽有权值8，但拥有子节点⑧和⑨，是内部节点，不参与WPL计算。

叶子集合 = {④, ⑥, ⑦, ⑧, ⑨}

**第二步：确定各叶子的路径长度（边数）**

| 叶子 | 路径 | 路径长度 |
|------|------|----------|
| ④ | ①→②→④ | 2 |
| ⑥ | ①→③→⑥ | 2 |
| ⑦ | ①→③→⑦ | 2 |
| ⑧ | ①→②→⑤→⑧ | 3 |
| ⑨ | ①→②→⑤→⑨ | 3 |

**第三步：逐叶加权求和**

WPL = 4×2 + 2×2 + 6×2 + 5×3 + 3×3 = 8 + 4 + 12 + 15 + 9 = 48

## 答案

**B. 48**

**干扰项分析：**
- A（24）：遗漏深层叶子⑧⑨的贡献（仅算④⑥⑦：8+4+12=24）
- C（64）：错误将内部节点⑤(权值8, 路径长度2)纳入计算（48+16=64）
- D（68）：路径长度误用层数（从1计）代替边数（从0计），每叶系统性+1（4×3+2×3+6×3+5×4+3×4=68）
