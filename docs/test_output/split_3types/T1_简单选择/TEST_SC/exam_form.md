## examination_form
- 考察形式：多步串行推演（主）+ 单点计算（辅）
- 设问方向：给定二叉树图形及叶子权值，要求考生按"识别叶子→计算路径长度→计算乘积→求和"的串行步骤得出WPL

## k_radar
- K1（基础认知）: 2
- K2（单步代入）: 3
- K3（机制推演）: 3
- K4（条件路由）: 2
- K5（跨域联动）: 1
- 形状主导维度：K2+K3（并列主导）

## rationale
- WPL计算本质是多步串行过程：识别所有叶子结点→逐个追溯路径长度→逐个计算 w_i×l_i→求和，K3主导体现机制推演特征；每步涉及单步乘法代入，K2体现单点计算特征，二者并列主导符合"给定结构→逐步计算→汇总"的考察模式
- 与目标 K-雷达对齐：K1=2（需理解WPL定义但非纯概念辨析）、K4=2（存在路径长度计数起点陷阱但非核心路由）、K5=1（不涉及跨域联动），整体形状与"图形化计算题"定位一致
