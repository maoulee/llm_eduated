## 题干

已知一棵二叉树如下图所示。图中圆圈内的数字为节点编号，括号内的数字为该节点的权值。

```
                        ①
                      /     \
                    ②        ③
                   /  \     /   \
                ④(4) ⑤(8) ⑥(2) ⑦(6)
                     /  \
                  ⑧(5) ⑨(3)
```

注：从根节点到某节点的**路径长度**为该路径上的**边数**（根节点的路径长度为 0）。**带权路径长度（WPL）** 定义为树中所有**叶子节点**的权值与其路径长度乘积之和。

该二叉树的带权路径长度（WPL）为多少？

A. 24
B. 48
C. 64
D. 68
