## 求解过程

### 第一步：识别叶子节点

根据二叉树结构，叶子节点为左右子树均为空的节点：

| 节点 | 权值 | 左子 | 右子 | 是否叶子 |
|------|------|------|------|----------|
| ④ | 4 | 无 | 无 | ✅ 叶子 |
| ⑤ | 8 | ⑧ | ⑨ | ❌ 内部节点（有子节点） |
| ⑥ | 2 | 无 | 无 | ✅ 叶子 |
| ⑦ | 6 | 无 | 无 | ✅ 叶子 |
| ⑧ | 5 | 无 | 无 | ✅ 叶子 |
| ⑨ | 3 | 无 | 无 | ✅ 叶子 |

**关键辨析**：节点⑤虽然标注了权值 8，但它有子节点⑧和⑨，是**内部节点**，不参与 WPL 计算。

叶子集合 = {④, ⑥, ⑦, ⑧, ⑨}

### 第二步：确定各叶子的路径长度（边数）

路径长度 = 从根到该节点的边数（根节点为 0）：

| 叶子 | 路径 | 路径长度（边数） |
|------|------|------------------|
| ④ | ①→②→④ | 2 |
| ⑥ | ①→③→⑥ | 2 |
| ⑦ | ①→③→⑦ | 2 |
| ⑧ | ①→②→⑤→⑧ | 3 |
| ⑨ | ①→②→⑤→⑨ | 3 |

### 第三步：逐叶加权求和

$$WPL = \sum_{\text{叶子 } i} w_i \times l_i$$

| 叶子 | 权值 $w_i$ | 路径长度 $l_i$ | $w_i \times l_i$ |
|------|-----------|---------------|------------------|
| ④ | 4 | 2 | 8 |
| ⑥ | 2 | 2 | 4 |
| ⑦ | 6 | 2 | 12 |
| ⑧ | 5 | 3 | 15 |
| ⑨ | 3 | 3 | 9 |
| **合计** | | | **48** |

$$WPL = 8 + 4 + 12 + 15 + 9 = 48$$

## 最终答案
- 正确答案：**B. 48**
  - 理由：叶子节点为④⑥⑦⑧⑨共 5 个，节点⑤虽有权值 8 但是内部节点不参与计算。逐叶按权值×路径长度求和：4×2 + 2×2 + 6×2 + 5×3 + 3×3 = 8 + 4 + 12 + 15 + 9 = 48。
  - 排除 A（24）：遗漏了深层叶子⑧⑨的贡献。
  - 排除 C（64）：错误地将内部节点⑤的权值纳入计算。
  - 排除 D（68）：错误地将路径长度理解为层数（从 1 开始而非边数从 0 开始）。
