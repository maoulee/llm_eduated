## examination_form
- 考察形式：多步串行推演（主） + 陷阱辨析（辅）
- 设问方向：给定关键码序列依次插入空 AVL 树，要求考生手工模拟完整插入—失衡检测—旋转调整过程；在关键插入步骤处需精准辨识失衡类型（LL/RR/LR/RL）并正确执行旋转，最终确定指定节点的平衡因子或子节点关系。

## k_radar
- K1（基础认知）: 3
- K2（单步代入）: 2
- K3（机制推演）: 4
- K4（条件路由）: 4
- K5（跨域联动）: 1
- 形状主导维度：K3-K4 平衡共主导

## rationale
- 为何选此形式（基于 KP + 主导维度）：
  - K3=4：插入步数 ≥6，考生需沿祖先链逐层更新平衡因子并维持动态状态，属于典型的多步串行推演，故以多步串行推演为主形式。
  - K4=4：四种旋转类型（LL/RR/LR/RL）的触发条件辨识要求考生理解失衡节点与其子、孙节点高度方向的组合关系，而非字面匹配；尤其双旋（LR/RL）的判定存在较高隐含前提深度，故辅以陷阱辨析维度。
- 与目标 K-雷达的对齐说明：
  - 目标为 K3-K4 平衡型（难度 4），本形式将 K3 与 K4 同时设为 4，K1=3（需准确记忆平衡因子定义和旋转类型术语），K2=2（高度差计算为简单心算），K5=1（纯 AVL 树内部操作，无跨域联动），整体形状与目标一致。
