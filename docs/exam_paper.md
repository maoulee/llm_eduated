## 第1题（单项选择题 · Q12）

**难度**: ★★ / 5
**知识点**: CPU执行时间公式, 主频与时钟周期, 计算机性能指标单位换算

### 题目

某程序包含1亿条指令，处理器主频为500MHz，执行该程序的CPU时间为0.25s。该处理器的平均CPI是（  ）。

| 选项 | 内容 |
|------|------|
| A | 0.5 |
| B | 1.25 ✅ |
| C | 2.0 |
| D | 1250.0 |

### 参考答案

**正确答案: B**

### 解析

本题考查CPU执行时间公式及单位换算。根据公式 $T_{CPU} = \frac{IC \times CPI}{f}$，可推导出 $CPI = \frac{T_{CPU} \times f}{IC}$。
将条件代入公式：$T_{CPU} = 0.25\text{s}$，$f = 500\text{MHz} = 500 \times 10^6\text{Hz}$，$IC = 1\text{亿} = 10^8$。
计算得：$CPI = \frac{0.25 \times 500 \times 10^6}{10^8} = \frac{125 \times 10^6}{10^8} = 1.25$。故正确答案为B。

### 解题步骤

  1. 写出CPU执行时间公式: $T_{CPU} = \frac{IC \times CPI}{f}$；
2. 将主频换算为赫兹: $f = 500\text{MHz} = 500 \times 10^6\text{Hz}$；
3. 将指令条数换算为绝对数值: $IC = 1\text{亿} = 10^8$；
4. 代入公式变形计算: $CPI = \frac{T_{CPU} \times f}{IC} = \frac{0.25 \times 500 \times 10^6}{10^8} = 1.25$。

## 第2题（单项选择题 · Q13）

**难度**: ★★ / 5
**知识点**: IEEE 754单精度浮点数, 规格化

### 题目

将十进制数 -12.75 转换为 IEEE 754 单精度浮点数格式（规格化），其对应的十六进制机器码表示是？

| 选项 | 内容 |
|------|------|
| A | C14C0000H ✅ |
| B | 414C0000H |
| C | C14C8000H |
| D | C15C0000H |

### 参考答案

**正确答案: A**

### 解析

IEEE 754单精度浮点数由符号位（1位）、阶码（8位）和尾数（23位）组成。
1. **符号位**：-12.75 是负数，故符号位 $S = 1$。
2. **绝对值转二进制**：$12.75 = 12 + 0.75 = 8 + 4 + 0.5 + 0.25 = 1100.11_2$。
3. **规格化**：将小数点左移3位，得到 $1.10011 \times 2^3$。
4. **阶码计算**：指数 $E = 3$，单精度阶码偏置值为127，故阶码的二进制表示为 $3 + 127 = 130 = 10000010_2$。（选项D的错误在于偏置值按128计算，得出 $3+128=131=10000011_2$）
5. **尾数处理**：规格化尾数为 $1.10011$，隐藏最高位的1后，截取小数部分填入23位尾数段，为 $10011000000000000000000_2$。（选项C的错误在于没有省略隐藏位最高位1，而是将 $110011$ 直接补位）
6. **组合二进制位**：将符号、阶码、尾数拼接：
$1\ \ 10000010\ \ 10011000000000000000000_2$
7. **转换为十六进制**：
$1100\ 0001\ 0100\ 1100\ 0000\ 0000\ 0000\ 0000_2 = C14C0000H$。
选项B错将符号位设为0。

### 解题步骤

  绝对值转换为二进制并规格化
  根据指数计算阶码并提取隐藏位后的尾数
  拼接各段位串并转换为十六进制

### 陷阱设计

选项C用来迷惑忘记IEEE 754中“隐藏最高位1”机制的考生；选项D用来迷惑将阶码偏置值误算为128的考生；选项B用来迷惑漏看负号的粗心考生。

## 第3题（综合应用题 · Q43）

**难度**: ★★★★ / 5
**知识点**:

"数据的小端存储模式"

### 题目

在一台按字节编址、采用小端方式的32位计算机系统中，已知C语言编译器规定 `char` 为8位、`short` 为16位、`int` 为32位。系统采用补码表示带符号整数。现有如下C语言程序片段：
```c
short si = -32768;
unsigned short usi = si;   // 语句1
int i1 = usi;              // 语句2
int i2 = si;               // 语句3
```
请回答下列问题：

### 子问题

**1.** 1. 语句1和语句2分别包含了隐式类型转换，请分别写出变量 `usi` 和 `i1` 的十进制值。简要说明在执行语句1和语句2时，底层数据的二进制表示发生了什么变化（如果有的话）？
**2.** 2. 执行完语句3后，变量 `i2` 的十进制值是多少？请结合符号扩展机制，写出变量 `i2` 的完整32位二进制表示，并用十六进制表示。
**3.** 3. 假设变量 `i2` 的32位机器数被顺序存放在起始地址为 `0x1000`（按字节编址）的连续内存单元中。请基于小端存储方式，写出地址 `0x1000` 到 `0x1003` 这4个字节中分别存储的内容（请用十六进制表示）。

### 参考答案

- **sub_q1**: `usi` 的十进制值为 32768，`i1` 的十进制值为 32768。执行语句1时底层数据的二进制表示保持不变（最高位由符号位变为数值位）；执行语句2时发生零扩展，16位扩展为32位时高位补0。
- **sub_q2**: `i2` 的十进制值为 -32768；32位二进制表示为 11111111111111111000000000000000；十六进制表示为 0xFFFF8000。
- **sub_q3**: 0x1000：0x00，0x1001：0x80，0x1002：0xFF，0x1003：0xFF。
- **总分**: 10分（自拟参考）

### 设计意图

**Sub Q1 Intent**:

**考察目标**：C语言中“有符号到无符号的隐式转换（同宽度）”以及“无符号短整型到有符号整型的扩展（短到长，零扩展）”。
**预期解题路径**：
- 对于语句1：`si` 是16位补码 `-32768`（二进制 `1000 0000 0000 0000`，即 `0x8000`）。将其赋值给16位无符号变量 `usi` 时，底层位模式不变，但由于解释为无符号数，其值变为 `32768`。
- 对于语句2：`usi`（16位无符号数 `0x8000`）赋值给32位 `int` 型变量 `i1`。因为源操作数是无符号类型，进行扩展时底层的机制是“零扩展”（高位补0），因此 `i1` 的二进制为 `0000...0 1000 0000 0000 0000`，十进制仍为 `32768`。

**Sub Q2 Intent**:

**考察目标**：C语言中“位数较小的有符号数到位数较大的有符号数的隐式转换（符号扩展）”。
**预期解题路径**：由于 `si` 是带符号数且其值为 `-32768`，赋值给32位 `int` 时，ALU底层硬件触发“符号扩展”机制。由于 `si` 的最高位（符号位）为1，因此高16位全部填充1。扩展后的32位二进制为 `1111...1 1000 0000 0000 0000`，转换为十六进制为 `0xFFFF8000`，解释为32位带符号整数时，其十进制值依然是 `-32768`。

**Sub Q3 Intent**:

**考察目标**：多字节数据在主存中的小端模式存储映射。
**预期解题路径**：取上一问得到的32位机器数 `0xFFFF8000`。按照小端法规则，数据的最低有效字节（LSB）存放在低地址处。因此：最低字节 `00H` 存入 `0x1000`，次低字节 `80H` 存入 `0x1001`，次高字节 `FFH` 存入 `0x1002`，最高字节 `FFH` 存入 `0x1003`。

**Trap Design**:

1. **转换规则陷阱**：在分析语句2时，极易有学生认为 `usi` 值为32768，超出了 `short` 的表示范围，从而错误推断其在转为 `int` 时发生了与符号位相关的特殊变化，忽略了C标准中“无符号数提升必为零扩展”的底层机制规则。
2. **符号扩展与零扩展混淆**：学生容易混淆语句2和语句3的底层硬件行为，把语句2当成符号扩展（认为最高位是1所以补1，得出负数），或者把语句3当成零扩展。
3. **边界值认知陷阱**：部分学生可能不记得 `-32768` 的原码/补码形式，或者错误地认为 `1000...0000` 符号扩展后高位补0。

**Sub Question Logic**:

三个子问题遵循“高级语言赋值语义分析 -> 底层机器码二进制表示转换 -> 最终映射到存储器物理结构”的自顶向下、由抽象到具体的跨科目经典综合分析逻辑。
