## Q41（综合应用题）

### 教师可读说明
本题考查数据结构中**平衡二叉树（AVL Tree）**的核心机制。题目将给出一个初始的平衡二叉树（或为空），并要求学生插入一系列关键码，每插入一个节点后，需画出当前的树结构，并简要说明是否需要旋转及旋转类型（LL、RR、LR、RL）。
- **考查能力**：学生对AVL树平衡因子变化的敏感性，以及在失衡情况下正确执行单旋转或双旋转的能力。
- **难度定位**：K3较高（需多步插入并维持树结构状态），K4较高（需准确判断旋转触发条件，避免漏转或误转）。
- **风险点**：学生在进行LR/RL型旋转时容易混淆中间节点的左右子树归属；或在旋转后忘记更新节点的平衡因子/高度。

## Q45（综合应用题）

### 教师可读说明
本题考查操作系统中**死锁避免**的核心算法——**银行家算法**，并结合**PV操作**进行综合应用。题目设定一个多进程共享有限资源的场景，给出进程的最大需求矩阵和当前分配矩阵。

2. 接着，若有进程发出资源请求，要求利用银行家算法判断是否可立即分配，若不能分配，说明原因。

## 设计说明

### 出题意图与知识点选取理由
本题考查 AVL 树的插入操作与旋转调整机制，核心知识点包括：
- 四种旋转类型（LL、LR、RL、RR）的触发条件辨识
- 插入后最小不平衡子树的定位
- 旋转操作的执行与树形态的更新
- 最终 AVL 树结构与平衡因子的判定

### 参数选择理由
- **初始树**：7 个结点的完美平衡二叉树（高度 3），所有结点平衡因子为 0，确保初始状态无歧义。
- **插入序列 25, 27, 5, 3**：
  - 25 作为 30 的左孩子插入，无旋转，但改变了局部平衡因子，为后续 27 的插入埋下不平衡种子。
  - 27 插入后触发 **LR 旋转**（最小不平衡子树根为 30），需精准辨析"新结点插入在左子树的右子树上"这一条件。
  - 5 插入后无旋转，但使 10 的左子树增高。
  - 3 插入后触发 **LL 旋转**（最小不平衡子树根为 10），与第 1 问的 LR 形成对比，考察学生区分不同旋转类型的能力。
- 所有关键字均为整数，BST 性质无歧义。

### 干扰项设计策略
- **第（1）题**：四个选项对应四种旋转类型，干扰项考察学生能否正确辨识"插入在左子树的右子树上"（LR）而非其他三种情况。
- **第（3）题**：
  - A 为正确选项（结点 20 的左右子树高度均为 2）。
  - B 干扰：将树高误判为 5（实际为 4），针对高度计数中"是否从 0 开始"的常见错误。
  - C 干扰：将根结点平衡因子误判为 0（实际为 1），针对平衡因子计算中的符号/方向错误。
  - D 干扰：关键字 5 在最终树中为内部结点（有孩子 3 和 10），误判为叶子结点考察对旋转后结点位置变化的追踪。

- **K4（条件路由）= 3**：需识别最小不平衡子树并精准匹配旋转类型（LL vs LR 是核心辨析点），存在明确的陷阱。
- **K5（跨域联动）= 1**：纯 AVL 树内部操作，不涉及其他子系统。

# AVL Tree implementation
class Node:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None
        self.height = 1

def get_height(node):
    if node is None:
        return 0
    return node.height

def get_balance(node):
    if node is None:
        return 0
    return get_height(node.left) - get_height(node.right)

def update_height(node):
    node.height = 1 + max(get_height(node.left), get_height(node.right))

def right_rotate(y):
    """LL rotation - right single rotation"""
    x = y.left
    T2 = x.right
    x.right = y
    y.left = T2
    update_height(y)
    update_height(x)
    return x

def left_rotate(x):
    """RR rotation - left single rotation"""
    y = x.right
    T2 = y.left
    y.left = x
    x.right = T2
    update_height(x)
    update_height(y)
    return y

rotation_log = []

def insert(node, key):
    if node is None:
        return Node(key)
    if key < node.key:
        node.left = insert(node.left, key)
    elif key > node.key:
        node.right = insert(node.right, key)
    else:
        return node
    update_height(node)
    balance = get_balance(node)
    # LL rotation
    if balance > 1 and key < node.left.key:
        rotation_log.append(f"LL rotation (right single) at node {node.key}")
        return right_rotate(node)
    # RR rotation
    if balance < -1 and key > node.right.key:
        rotation_log.append(f"RR rotation (left single) at node {node.key}")
        return left_rotate(node)
    # LR rotation
    if balance > 1 and key > node.left.key:
        rotation_log.append(f"LR rotation (left-right double) at node {node.key}")
        node.left = left_rotate(node.left)
        return right_rotate(node)
    # RL rotation
    if balance < -1 and key < node.right.key:
        rotation_log.append(f"RL rotation (right-left double) at node {node.key}")
        node.right = right_rotate(node.right)
        return left_rotate(node)
    return node

def build_initial_tree():
    root = Node(40)
    root.left = Node(20)
    root.right = Node(60)
    root.left.left = Node(10)
    root.left.right = Node(30)
    root.right.left = Node(50)
    root.right.right = Node(70)
    update_height(root.left.left)
    update_height(root.left.right)
    update_height(root.right.left)
    update_height(root.right.right)
    update_height(root.left)
    update_height(root.right)
    update_height(root)
    return root

def print_tree(node, level=0, prefix="Root: "):
    if node is not None:
        print("  " * level + prefix + str(node.key) + f" (h={node.height}, bf={get_balance(node)})")
        if node.left is not None or node.right is not None:
            if node.left:
                print_tree(node.left, level + 1, "L--- ")
            else:
                print("  " * (level + 1) + "L--- None")
            if node.right:
                print_tree(node.right, level + 1, "R--- ")
            else:
                print("  " * (level + 1) + "R--- None")

def find_node(node, key):
    if node is None:
        return None
    if node.key == key:
        return node
    if key < node.key:
        return find_node(node.left, key)
    return find_node(node.right, key)
