# Q44 磁盘DMA传送时序分析

某计算机系统采用DMA方式实现磁盘与内存之间的数据传送。系统参数如下：

- **磁盘参数**：4个双面盘片，每个盘面有16384个磁道，每个磁道有256个扇区，每个扇区可记录512字节数据，盘片转速为7200 RPM（转/分），平均寻道时间为4ms。
- **DMA控制器**：数据缓冲区大小为64位，系统总线宽度为32位，每次DMA请求传输64位数据，经32位总线分两次传输。总线频率与CPU主频相同，为40MHz。
- **CPU参数**：主频为40MHz，CPI为4。

请回答下列问题：

### (1)（3分）每个扇区的地址信息包含盘面号、磁道号和扇区号三个字段。计算这三个字段各至少需要多少位？并计算该磁盘的平均存取时间（包括平均寻道时间、平均旋转延迟和传输时间）。

### (2)（4分）若采用周期挪用DMA方式传送一个扇区的数据，计算DMA控制器向CPU发送的总线请求次数，以及DMA占用总线的时间。基于(1)中计算的传输时间，分析DMA传送期间CPU能够执行的指令条数。

### (3)（3分）基于(2)中计算的CPU可执行指令条数，若CPU在DMA传送开始前需要执行100条指令来设置DMA控制器，DMA传送结束后需要执行50条指令来处理结束中断，计算从CPU开始设置DMA到处理完结束中断的总时间，以及CPU在该过程中的利用率。

### 知识点选取理由

本题覆盖以下知识点（来自assembled.md）：
- **磁盘存储器结构**：盘片、磁道、扇区、柱面、磁头
- **磁盘存储器性能**：寻道时间、旋转延迟、传输时间、平均存取时间
- **DMA方式**：DMA控制器、DMA请求、DMA传送、周期挪用、DMA结束中断
- **CPU时序**：主频、CPI、时钟周期、指令执行时间

这些知识点构成完整的I/O系统与CPU交互时序分析链条，符合408考研组成原理-7输入输出系统的考察要求。仿照2022年真题Q44，第一问考察磁盘地址字段位数，体现磁盘物理结构理解。

### 参数选择理由

- **4个双面盘片**：8个盘面，盘面号字段需3位（2^3=8），与2022年真题风格一致。
- **16384=2^14磁道**：2的幂次，磁道号字段需14位。
- **256=2^8扇区**：2的幂次，扇区号字段需8位，便于传输时间计算（旋转周期/256）。
- **512=2^9字节**：2的幂次，便于DMA请求次数计算（512字节=4096位，4096/64=64次DMA请求）。
- **64位DMA缓冲区**：2的幂次，每次DMA请求传输64位。
- **32位总线宽度**：2的幂次，每次总线传输32位，64位数据需2次总线传输。
- **40MHz主频/总线频率**：便于时钟周期计算（25ns），总线周期也为25ns。
- **7200 RPM**：磁盘标准转速，旋转周期=60/7200=8.33ms，平均旋转延迟=4.17ms。
- **4ms平均寻道时间**：整数，便于计算。

### 与契约K值的对齐说明

- **K1=4**：需要精准辨析磁盘物理结构参数（双面盘片与盘面数的关系、磁道/扇区层级）以及DMA传送的基本机制概念（缓冲区大小、总线宽度与传输单位的关系）。✓
- **K2=4**：涉及多级单位换算（RPM→ms、字节→位、MHz→ns），计算量适中但精度敏感。✓
- **K3=3**：需按固定流程走完3步（磁盘参数计算→DMA请求次数计算→CPU利用率计算），路径唯一。✓
- **K4=4**：存在隐含前提陷阱——周期挪用方式下CPU与DMA交替访存，CPU在DMA占用总线期间无法执行指令，但可在DMA等待磁盘传输期间执行指令。✓
- **K5=4**：磁盘系统、DMA系统、CPU系统深度耦合，需在三者之间传递数据和状态。✓

K3=3（目标2~4），K4=4（目标3~4），符合契约要求。

### 典型陷阱

1. **时间量级混淆**：将微秒级的指令执行时间与毫秒级的机械运动时间混为一谈。
2. **周期挪用机制理解错误**：误认为DMA传送期间CPU完全空闲，或误认为CPU与DMA完全并行。
3. **DMA请求次数计算错误**：混淆DMA缓冲区大小与总线宽度，错误计算总线请求次数（应为512字节×8位/字节÷64位=64次，而非512÷64=8次）。
4. **旋转延迟计算错误**：平均旋转延迟应为半圈（4.17ms），而非一圈（8.33ms）。
