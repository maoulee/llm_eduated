## 求解过程

### 子问题(1)：磁盘地址字段位数和平均存取时间

**地址字段位数计算**：

- **盘面号**：4个双面盘片 = 8个盘面，需编号0~7，至少需要 ⌈log₂8⌉ = **3位**
- **磁道号**：每个盘面16384个磁道，需编号0~16383，16384 = 2¹⁴，至少需要 **14位**
- **扇区号**：每个磁道256个扇区，需编号0~255，256 = 2⁸，至少需要 **8位**

**平均存取时间计算**：

1. **平均寻道时间**：题干给定 = **4 ms**

2. **平均旋转延迟**：
   - 旋转周期 = 60 / 7200 = 1/120 秒 = 8.3333 ms
   - 平均旋转延迟 = 旋转周期 / 2 = 8.3333 / 2 = **4.1667 ms**

3. **传输时间**（传输一个扇区）：
   - 传输时间 = 旋转周期 / 每磁道扇区数 = 8.3333 / 256 = **0.0326 ms**

4. **平均存取时间** = 平均寻道时间 + 平均旋转延迟 + 传输时间
   = 4 + 4.1667 + 0.0326 = **8.1992 ms**

### 子问题(2)：DMA总线请求次数、占用总线时间、CPU可执行指令条数

**DMA总线请求次数**：
- 一个扇区数据量 = 512 字节 = 512 × 8 = 4096 位
- 每次DMA请求传输64位
- DMA总线请求次数 = 4096 / 64 = **64次**

**DMA占用总线时间**：
- 每次DMA请求传输64位，经32位总线分两次传输
- 每次DMA请求的总线传输次数 = 64 / 32 = 2次
- 总线传输总次数 = 64 × 2 = 128次
- 总线周期 = 1 / 40MHz = 25 ns
- DMA占用总线时间 = 128 × 25 ns = 3200 ns = **3.2 μs**

**CPU可执行指令条数（周期挪用方式）**：
- 在周期挪用DMA方式下，CPU与DMA交替使用总线
- 磁盘传输一个扇区的时间 = 32552.08 ns（即(1)中的传输时间）
- DMA占用总线时间 = 3200 ns
- CPU可用时间 = 传输时间 - DMA占用总线时间 = 32552.08 - 3200 = 29352.08 ns
- CPU时钟周期 = 1 / 40MHz = 25 ns
- 单条指令执行时间 = CPI × 时钟周期 = 4 × 25 = 100 ns
- CPU可执行指令条数 = 29352.08 / 100 = 293.52 → **293条**（向下取整）

---

### 子问题(3)：总时间和CPU利用率

**各阶段时间**：
1. **设置DMA控制器**：100条指令 × 100 ns/条 = 10000 ns = 10 μs
2. **DMA传输时间**：32552.08 ns = 32.5521 μs（此期间CPU执行293条指令）
3. **处理结束中断**：50条指令 × 100 ns/条 = 5000 ns = 5 μs

**总时间**：
- 总时间 = 10000 + 32552.08 + 5000 = 47552.08 ns = **47.5521 μs**

**CPU利用率**：
- CPU执行时间 = 设置时间 + DMA期间CPU执行时间 + 中断处理时间
- CPU执行时间 = 10000 + 29352.08 + 5000 = 44352.08 ns
- CPU利用率 = 44352.08 / 47552.08 = 0.9327 = **93.27%**

## 最终答案
- (1) 盘面号字段：**3位**；磁道号字段：**14位**；扇区号字段：**8位**；平均存取时间：**8.1992 ms**
- (2) DMA总线请求次数：**64次**；DMA占用总线时间：**3.2 μs**；CPU可执行指令条数：**293条**
- (3) 总时间：**47.5521 μs**；CPU利用率：**93.27%**
