## 题目

某计算机系统采用DMA方式实现磁盘与内存之间的数据传送。系统参数如下：

- **磁盘参数**：4个双面盘片，每个盘面有16384个磁道，每个磁道有256个扇区，每个扇区可记录512字节数据，盘片转速为7200 RPM（转/分），平均寻道时间为4ms。
- **DMA控制器**：数据缓冲区大小为64位，系统总线宽度为32位，每次DMA请求传输64位数据，经32位总线分两次传输。总线频率与CPU主频相同，为40MHz。
- **CPU参数**：主频为40MHz，CPI为4。

请回答下列问题：

### (1)（3分）每个扇区的地址信息包含盘面号、磁道号和扇区号三个字段。计算这三个字段各至少需要多少位？并计算该磁盘的平均存取时间（包括平均寻道时间、平均旋转延迟和传输时间）。

### (2)（4分）若采用周期挪用DMA方式传送一个扇区的数据，计算DMA控制器向CPU发送的总线请求次数，以及DMA占用总线的时间。基于(1)中计算的传输时间，分析DMA传送期间CPU能够执行的指令条数。

### (3)（3分）基于(2)中计算的CPU可执行指令条数，若CPU在DMA传送开始前需要执行100条指令来设置DMA控制器，DMA传送结束后需要执行50条指令来处理结束中断，计算从CPU开始设置DMA到处理完结束中断的总时间，以及CPU在该过程中的利用率。

---

## 求解过程

### 子问题(1)：磁盘地址字段位数和平均存取时间

**地址字段位数计算**：
- 盘面号：4个双面盘片 = 8个盘面，需编号0~7，至少需要 ⌈log₂8⌉ = **3位**
- 磁道号：每个盘面16384个磁道，16384 = 2¹⁴，至少需要 **14位**
- 扇区号：每个磁道256个扇区，256 = 2⁸，至少需要 **8位**

**平均存取时间计算**：
- 平均寻道时间 = **4 ms**（题干给定）
- 平均旋转延迟 = 旋转周期/2 = (60/7200)/2 = **4.1667 ms**
- 传输时间 = 旋转周期/每磁道扇区数 = 8.3333/256 = **0.0326 ms**
- 平均存取时间 = 4 + 4.1667 + 0.0326 = **8.1992 ms**

---

### 子问题(2)：DMA总线请求次数、占用总线时间、CPU可执行指令条数

**DMA总线请求次数**：
- 一个扇区数据量 = 512字节 = 4096位
- 每次DMA请求传输64位
- DMA总线请求次数 = 4096/64 = **64次**

**DMA占用总线时间**：
- 每次DMA请求经32位总线分两次传输，总线传输总次数 = 64×2 = 128次
- 总线周期 = 1/40MHz = 25 ns
- DMA占用总线时间 = 128×25 ns = **3.2 μs**

**CPU可执行指令条数（周期挪用方式）**：
- 磁盘传输一个扇区时间 = 32552.08 ns
- CPU可用时间 = 传输时间 - DMA占用总线时间 = 32552.08 - 3200 = 29352.08 ns
- 单条指令执行时间 = CPI×时钟周期 = 4×25 = 100 ns
- CPU可执行指令条数 = 29352.08/100 = 293.52 → **293条**（向下取整）

---

### 子问题(3)：总时间和CPU利用率

**各阶段时间**：
- 设置DMA控制器：100条×100 ns/条 = 10 μs
- DMA传输时间：32.5521 μs（此期间CPU执行293条指令）
- 处理结束中断：50条×100 ns/条 = 5 μs

**总时间**：
- 总时间 = 10 + 32.5521 + 5 = **47.5521 μs**

**CPU利用率**：
- CPU执行时间 = 10000 + 29352.08 + 5000 = 44352.08 ns
- CPU利用率 = 44352.08/47552.08 = **93.27%**

---

## 答案

- **(1)** 盘面号字段：**3位**；磁道号字段：**14位**；扇区号字段：**8位**；平均存取时间：**8.1992 ms**
- **(2)** DMA总线请求次数：**64次**；DMA占用总线时间：**3.2 μs**；CPU可执行指令条数：**293条**
- **(3)** 总时间：**47.5521 μs**；CPU利用率：**93.27%**

---

## 设计说明

本题采用模式B（I/O系统与CPU交互时序分析），按照"设备特性参数化→控制流/数据流耦合分析→系统级效率评估"三步递进设计：

1. **第一步（I/O设备特性解析）**：子问题(1)计算磁盘地址字段位数和平均存取时间，考察磁盘物理结构理解和性能指标计算。
2. **第二步（控制流与数据流模拟）**：子问题(2)模拟周期挪用DMA传送过程，计算总线请求次数、DMA占用总线时间，以及CPU在DMA传送期间可执行的指令条数。
3. **第三步（系统级效率评估）**：子问题(3)计算完成一个扇区数据传送的总时间和CPU利用率，进行系统级效率分析。

**典型陷阱**：
- 时间量级混淆（微秒级指令时间与毫秒级机械运动时间）
- 周期挪用机制理解错误（误认为DMA传送期间CPU完全空闲）
- DMA请求次数计算错误（混淆DMA缓冲区大小与总线宽度）
- 旋转延迟计算错误（平均旋转延迟应为半圈而非一圈）

**K值对齐**：K3=3（目标2~4），K4=4（目标3~4），符合契约要求。
