## 题干
某计算机主频为 2 GHz，程序 P 共执行了 4×10⁶ 条指令，其中 80% 的指令 CPI 为 1，20% 的指令 CPI 为 6。程序 P 的执行时间是（）。

## 选项
- A: 2 ms
- B: 4 ms
- C: 4 μs
- D: 10 ms

## 设计说明
- **考察模式**：计算型——单结果竞争（Mode A，来自经验卡建议分布 55%）
- **选项风格**：数字结果（来自经验卡建议分布 55%）
- **知识点**：CPU 执行时间公式 T = IC × CPI / f，加权平均 CPI 计算，时间单位换算（s/ms/μs）
- **参数选择理由**：
  - 主频 2 GHz（2×10⁹ Hz，2 的幂级基底）
  - 指令数 4×10⁶（2 的幂级基底，简洁整数）
  - 指令比例 80%/20%（经典二八分布，心算友好）
  - CPI 取 1 和 6，使加权 CPI = 0.8×1 + 0.2×6 = 2.0（整数，无小数）
  - 总周期数 = 4×10⁶ × 2 = 8×10⁶，除以 2 GHz 恰好整除得 4×10⁻³ s = 4 ms
- **干扰项设计策略**：
  - **A（2 ms）**：忽略加权 CPI，直接取 CPI=1 计算 T = 4×10⁶ × 1 / 2×10⁹ = 2 ms。针对"未计算加权 CPI、假设所有指令 CPI 相同"的错误认知。
  - **C（4 μs）**：数值"4"与正确答案相同，但单位从 ms 错为 μs，差 10³ 倍。针对"GHz 对应 ns 周期，时间结果应为 μs 级"的单位换算混淆（将 10⁻³ 误读为 10⁻⁶）。
  - **D（10 ms）**：权重倒置，以 80%×6 + 20%×1 = 5.0 计算 T = 4×10⁶ × 5 / 2×10⁹ = 10 ms。针对"百分比与 CPI 对应关系搞反"的错误认知。
- **should_be 对照**：
  - 注重单位换算：选项 C 专门考察 ms 与 μs 的区分 ✓
  - 注重公式中变量的物理意义：加权 CPI 体现"不同指令类别的执行代价不同" ✓
  - 结合计算机体系结构背景：CPI 加权平均是真实程序性能分析的核心概念 ✓
  - 避免纯代数运算：所有中间结果（加权 CPI=2、总周期=8×10⁶）均为整数，计算量小 ✓
- **should_not_be 排查**：
  - 非纯粹记忆填空：需要公式应用和单位换算 ✓
  - 无无意义复杂数字：4×10⁶、2 GHz、80%/20% 均心算友好 ✓
  - 无表述歧义：题干明确"程序 P 的执行时间"，无速度/时间倒置歧义 ✓
- **代码验证结果摘要**：加权 CPI = 2.0（整数），正确执行时间 = 4.0 ms（整数 ms），4 个选项值互不相同（2 ms / 4 ms / 0.004 ms / 10 ms），总周期数 8×10⁶ / 2×10⁹ 精确整除，百分比 80%+20% 闭合为 100%。全部 PASS。
- **与契约 K 值的对齐说明**：本题 K1=1（概念理解：加权 CPI 定义）、K2=1（计算：公式应用 + 单位换算）、K3=1、K4=1（干扰项直接，无层层嵌套陷阱）、K5=1。整体为 K1-K2 平衡型，与经验卡典型雷达形状一致，难度适中偏易，符合 Q12 题位定位。
