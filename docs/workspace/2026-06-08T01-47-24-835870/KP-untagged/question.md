# AVL 平衡二叉树插入旋转综合分析

## 题干

已知一棵初始为空的 AVL 平衡二叉排序树（任意节点的平衡因子 = 左子树高度 − 右子树高度，其绝对值不超过 ⟨P1⟩）。现依次将序列 ⟨P2⟩ 中的各元素插入该树。每次插入后，若某祖先节点失衡，则立即对该失衡节点执行相应的旋转调整，使整棵树恢复平衡。

## 子问题

### (1) 过程追踪（⟨P3⟩ 分）

依次将序列 ⟨P2⟩ 中的元素逐个插入初始为空的 AVL 树。请回答：

① 在全部插入过程中，**第几个**元素插入时**首次**触发失衡调整？指出该次失衡的失衡节点关键字及其旋转类型（LL / LR / RL / RR）。

② 写出首次旋转调整完成后，以原失衡节点所在位置为根的子树的层序遍历序列。

③ 在整个插入过程中，共触发**几次**旋转调整？请按发生先后顺序列出每次旋转的类型。

### (2) 代码填空（⟨P4⟩ 分）

以下是 AVL 树 RR 型失衡对应的左旋（Left Rotation）操作的 C 语言函数。其中标注 **①** 和 **②** 的两行指针赋值语句缺失，请根据 AVL 旋转原理补充完整。

```c
typedef struct AVLNode {

    int height;

}
```

### (3) 综合分析（⟨P6⟩ 分）

完成序列 ⟨P2⟩ 的全部插入后，请回答：

① 最终 AVL 树的根节点关键字是多少？

② 最终 AVL 树的高度是多少？（规定空树高度为 ⟨P5⟩，仅含一个根节点的树高度为 ⟨P7⟩）

③ 最终根节点的平衡因子是多少？

## 参数规格

⟨P1⟩: 类型=整数 | 约束=AVL 平衡因子绝对值上限，固定为 1
⟨P2⟩: 类型=序列 | 约束=互不相同的正整数序列，长度 9-11；插入过程中至少触发一次 LR 或 RL 型双旋；首次失衡由非首元素触发；整个序列插入后共触发 ≥ 2 次旋转
⟨P3⟩: 类型=整数 | 约束=子问题(1)分值，范围 5-7
⟨P4⟩: 类型=整数 | 约束=子问题(2)分值，范围 4-5
⟨P5⟩: 类型=整数 | 约束=空树高度定义值，取 −1（与代码中 `Height(NULL)` 返回值一致）
⟨P6⟩: 类型=整数 | 约束=子问题(3)分值，范围 4-5
⟨P7⟩: 类型=整数 | 约束=单节点树高度，= ⟨P5⟩ + 1

## 设计说明

### 考察结构模式
- 三子问递进：过程追踪(1) → 代码实现(2) → 综合分析(3)，对应"过程追踪与代码/伪代码实现混合"考察模式
- (1) 要求逐步模拟 AVL 插入，维护动态平衡因子状态，识别旋转类型——考察 K3 机制推演
- (2) 要求理解旋转操作中指针重连接的本质——考察 K4 条件路由（需理解旋转语义而非套模板）
- (3) 依赖 (1) 的完整推演结果——考察对全局结构的把握

### should_be
- ⟨P2⟩ 必须触发至少一次 LR 或 RL 型双旋操作，这是本题的核心难度来源
- ⟨P2⟩ 序列长度 9-11，保证推演步数 ≥ 9，达到 K3=4 的工作记忆负荷
- 代码缺失行为核心指针赋值（T->rchild=R->lchild 与 R->lchild=T），而非次要操作
- 旋转总数 ≥ 2，使 (1)③ 需要完整追踪而非只看首次

### should_not_be
- 不应让所有旋转均为 LL/RR 型单旋（降低至 K3=3）
- 不应让序列过短（< 9 步不足以达到 Hard 难度）
- 不应让代码缺失行是显而易见的语句（如 return、变量声明）
- 不应让 (3) 的答案可从 (1) 的部分结果直接推断（需完整推演）

### K 值对齐
- K1=3：需准确记忆 AVL 平衡因子定义、四种旋转类型的判定规则
- K2=2：计算为简单的高度差与 max 运算，数字友好
- K3=4：9-11 步插入推演，需持续维护各节点平衡因子，中间错一步全盘皆输
- K4=4：代码填空需理解旋转的本质是指针重连接，而非记忆代码模板；LR/RL 双旋需理解"先旋子树再旋节点"的两步分解
- K5=1：单一知识点（AVL 树）内部解决

### 参数约束推导理由
- ⟨P1⟩=1：AVL 标准定义，平衡因子绝对值不超过 1
- ⟨P2⟩ 长度 9-11：≥9 保证 K3=4 推演负荷；≤11 避免过长导致题目冗余
- ⟨P2⟩ 含 LR/RL：双旋比单旋多一层指针调整逻辑，是 K4=4 的关键
- ⟨P5⟩=−1：与代码 `Height(NULL)` 返回值一致，保证代码与文字描述自洽
- ⟨P7⟩=⟨P5⟩+1：高度递推一致性
- ⟨P3⟩⟨P4⟩⟨P6⟩ 分值：(1) 为核心推演题权重最高，(2)(3) 各考察一个维度
