## 求解过程

### 题目参数
- 进程P1：到达时间=0，服务时间=2
- 进程P2：到达时间=1，服务时间=4
- 进程P3：到达时间=2，服务时间=1

### 子问题：计算FCFS与非抢占式SJF的平均周转时间差值

#### FCFS（先来先服务）调度
按到达时间顺序执行：P1 → P2 → P3

- **P1**：到达0，开始0，服务2，完成2，周转时间 = 2 - 0 = 2
- **P2**：到达1，开始2（等P1完成），服务4，完成6，周转时间 = 6 - 1 = 5
- **P3**：到达2，开始6（等P2完成），服务1，完成7，周转时间 = 7 - 2 = 5

FCFS平均周转时间 = (2 + 5 + 5) / 3 = 12 / 3 = 4

#### 非抢占式SJF（短作业优先）调度
按到达顺序，当CPU空闲时选择已到达进程中服务时间最短的：

- **时刻0**：只有P1到达，执行P1
- **P1**：到达0，开始0，服务2，完成2，周转时间 = 2 - 0 = 2
- **时刻2**：P2（到达1，服务4）和P3（到达2，服务1）都已到达，选服务时间短的P3
- **P3**：到达2，开始2，服务1，完成3，周转时间 = 3 - 2 = 1
- **时刻3**：只剩P2
- **P2**：到达1，开始3，服务4，完成7，周转时间 = 7 - 1 = 6

SJF平均周转时间 = (2 + 6 + 1) / 3 = 9 / 3 = 3

#### 差值
FCFS平均周转时间 - SJF平均周转时间 = 4 - 3 = 1

### 结果对比验证
手动验证FCFS：
- P1完成=0+2=2，周转=2
- P2完成=2+4=6，周转=6-1=5
- P3完成=6+1=7，周转=7-2=5
- 平均=(2+5+5)/3=4 ✓

手动验证SJF：
- P1先执行（唯一到达），完成=2，周转=2
- 时刻2时P2、P3都到达，P3服务时间1<P2服务时间4，选P3
- P3完成=2+1=3，周转=3-2=1
- P2完成=3+4=7，周转=7-1=6
- 平均=(2+1+6)/3=3 ✓

差值=4-3=1 ✓

## 最终答案
- 正确答案：B
  - 理由：FCFS平均周转时间为4，非抢占式SJF平均周转时间为3，差值为1
