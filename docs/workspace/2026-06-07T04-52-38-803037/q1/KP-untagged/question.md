# 选择题：进程调度算法对比分析

## 题干

某系统中有三个进程，到达时间分别为0、1、2，服务时间分别为2、4、1。采用先来先服务（FCFS）调度算法的平均周转时间比采用非抢占式短作业优先（SJF）调度算法的平均周转时间多（）。

## 选项

A. 0
B. 1
C. 2
D. 3

## 设计说明

- **考察模式**：算法比较与指标计算（来自经验卡建议分布）
- **选项风格**：数字结果（来自经验卡建议分布）
- **should_be对照**：
  - ✓ 给出多进程参数（3个进程，到达时间0/1/2，服务时间2/4/1）
  - ✓ 符合算法比较与指标计算模式（对比FCFS与SJF的平均周转时间）
  - ✓ 需要理解SJF非抢占式规则并多步推演（需分别模拟两种调度算法的执行过程）
  - ✓ 通过FCFS与SJF对比体现算法差异（SJF通过优先调度短作业降低平均周转时间）
- **should_not_be排查**：
  - ✓ 不涉及抢占式调度（明确标注"非抢占式"）
  - ✓ 不涉及I/O操作（纯CPU调度场景）
  - ✓ 题干无隐藏陷阱（参数清晰，算法规则明确）
- **参数选择理由**：
  - 到达时间0/1/2和服务时间2/4/1均为小整数，便于心算
  - FCFS调度顺序P1→P2→P3：P1周转=2-0=2，P2周转=6-1=5，P3周转=7-2=5，总周转=12，平均=12÷3=4
  - SJF非抢占式调度顺序P1→P3→P2：P1周转=2-0=2，P3周转=3-2=1，P2周转=7-1=6，总周转=9，平均=9÷3=3
  - 差值=4-3=1，整除性良好
- **干扰项设计策略**：
  - A=0：针对认为两种算法平均周转时间相同的错误认知
  - B=1：正确答案（FCFS平均4 - SJF平均3 = 1）
  - C=2：针对SJF调度顺序推演错误（如误认为SJF平均周转=2，则4-2=2）
  - D=3：针对仅计算FCFS平均周转时间（4）或SJF平均周转时间（3）的单一值，而非差值
- **代码验证结果摘要**：
  - FCFS总周转=12，平均=4.0 ✓
  - SJF总周转=9，平均=3.0 ✓
  - 差值=1.0，对应选项B ✓
  - 参数封闭性：所有参数均在题干中给出 ✓
  - 整除性：12÷3=4，9÷3=3，均整除 ✓
  - 选项唯一性：0/1/2/3互不相同，正确答案唯一 ✓
- **与契约K值的对齐说明**：
  - K1=3（需准确记忆FCFS和SJF非抢占式调度规则及周转时间公式）
  - K2=2（简单加减和除法，小整数，2的幂友好）
  - K3=3（需分别按两种算法规则走完3步调度流程）
  - K4=2（题干明确"非抢占式"，参数清晰，无隐藏陷阱）
  - K5=1（纯进程调度，不涉及其他子系统）
  - 综合为K2-K3平衡型，与规划目标一致
