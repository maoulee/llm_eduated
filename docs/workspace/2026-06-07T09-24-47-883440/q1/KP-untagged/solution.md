## 求解过程

### 题目分析
本题要求比较 SRTF（最短剩余时间优先）和 FCFS（先来先服务）两种进程调度算法的平均周转时间之差。

**已知参数：**

| 进程 | 到达时间 | 服务时间 |
|------|---------|---------|
| P1   | 0       | 8       |
| P2   | 2       | 2       |
| P3   | 3       | 5       |
| P4   | 5       | 1       |

**周转时间定义：** 周转时间 = 完成时间 - 到达时间

---

### 子问题：计算 FCFS 平均周转时间

FCFS 按到达时间顺序执行，不抢占。

| 进程 | 到达时间 | 服务时间 | 开始时间 | 完成时间 | 周转时间 |
|------|---------|---------|---------|---------|---------|
| P1   | 0       | 8       | 0       | 8       | 8-0=8   |
| P2   | 2       | 2       | 8       | 10      | 10-2=8  |
| P3   | 3       | 5       | 10      | 15      | 15-3=12 |
| P4   | 5       | 1       | 15      | 16      | 16-5=11 |

**FCFS 平均周转时间** = (8 + 8 + 12 + 11) / 4 = 39 / 4 = **9.75**

---

### 子问题：计算 SRTF 平均周转时间

SRTF 是抢占式调度，每个时刻选择剩余时间最短的进程执行。

**调度过程（逐时间单位模拟）：**

| 时间区间 | 执行进程 | 事件说明 |
|---------|---------|---------|
| 0→1 | P1 | P1剩余8→7 |
| 1→2 | P1 | P1剩余7→6 |
| 2→3 | P2 | P2到达(剩余2<6)，抢占P1；P2剩余2→1 |
| 3→4 | P2 | P3到达(剩余5>1)，不抢占；P2剩余1→0，**P2完成** |
| 4→5 | P3 | P3剩余5→4 |
| 5→6 | P4 | P4到达(剩余1<4)，抢占P3；P4剩余1→0，**P4完成** |
| 6→7 | P3 | P3剩余4→3 |
| 7→8 | P3 | P3剩余3→2 |
| 8→9 | P3 | P3剩余2→1 |
| 9→10 | P3 | P3剩余1→0，**P3完成** |
| 10→11 | P1 | P1剩余6→5 |
| 11→12 | P1 | P1剩余5→4 |
| 12→13 | P1 | P1剩余4→3 |
| 13→14 | P1 | P1剩余3→2 |
| 14→15 | P1 | P1剩余2→1 |
| 15→16 | P1 | P1剩余1→0，**P1完成** |

**各进程周转时间：**
- P2：完成时间4 - 到达时间2 = **2**
- P4：完成时间6 - 到达时间5 = **1**
- P3：完成时间10 - 到达时间3 = **7**
- P1：完成时间16 - 到达时间0 = **16**

**SRTF 平均周转时间** = (2 + 1 + 7 + 16) / 4 = 26 / 4 = **6.5**

---

### 子问题：比较差值

**差值** = FCFS平均周转时间 - SRTF平均周转时间 = 9.75 - 6.5 = **3.25**

即 SRTF 比 FCFS **少 3.25**。

---

## 最终答案
- 正确答案：**C**
  - 理由：FCFS 平均周转时间为 9.75，SRTF 平均周转时间为 6.5，SRTF 比 FCFS 少 3.25。
