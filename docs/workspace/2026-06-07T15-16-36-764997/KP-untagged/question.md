# 平衡二叉树（AVL树）的插入与旋转

## 题干

已知一棵初始平衡的二叉搜索树（AVL树），各节点的关键字及树结构如下：

```
         30
        /  \
      15    35
     /  \     \
    7   20    40
   / \
  3  10
```

其中，平衡因子定义为左子树高度减去右子树高度，AVL树要求所有节点的平衡因子绝对值不超过1。

现依次向该树中插入关键字 **1、18、19**。每次插入后，若树失衡则立即执行旋转调整，使树恢复平衡，然后继续插入下一个关键字。

请回答下列问题：

---

### (1)（3分）

插入关键字 **1** 后，树发生失衡。

- 指出从插入点向上回溯时**第一个失衡的节点**，并计算其平衡因子；
- 判断所需的旋转类型（LL / LR / RL / RR）；
- 画出旋转调整后的树结构。

---

### (2)（4分）

在(1)所得平衡树的基础上，插入关键字 **18** 后树再次失衡。

- 指出失衡节点并判断旋转类型；
- 依次列出此次旋转过程中所有发生改变的**孩子指针**（格式：节点X的左/右孩子指针，由指向 Y 改为指向 Z）；
- 画出旋转后的树结构。

---

### (3)（3分）

在(2)所得平衡树的基础上，插入关键字 **19** 后树又一次失衡。

- 判断旋转类型（LL / LR / RL / RR），并说明判断依据；
- 画出旋转调整后的**最终树结构**；
- 写出最终树的**前序遍历序列**，并计算最终树中**根节点**的平衡因子。

---

## 设计说明

### 考察结构模式
过程追踪与代码/伪代码实现混合（来自经验卡 recommended_mode）

### 子问依赖关系

| 子问题 | 依赖 | 说明 | 角色 |
|--------|------|------|------|
| (1) | 无（题干初始树 + 插入1） | 基础：单旋转(LL)判定与执行 | 基础问（3分） |
| (2) | (1)的输出树 | 核心：双旋转(LR) + 指针级追踪 | 核心问（4分） |
| (3) | (2)的输出树 | 区分度：双旋转(LR) + 结构验证（前序遍历 + 平衡因子） | 区分度问（3分） |

### should_be 对照
- 考察AVL插入后的失衡判定与LL/LR/RL/RR旋转操作 ✓ —— 三次插入分别涉及LL和LR旋转
- 过程追踪能力 ✓ —— 三次串行插入，每次结果影响后续
- 代码/伪代码理解 ✓ —— (2)要求列出指针变化，考察对旋转操作的底层实现理解
- K4-K5深理解 ✓ —— 需通过子节点平衡因子判断旋转类型（隐含前提），双旋转需识别中间节点

### should_not_be 排查
- 未涉及AVL删除操作 ✓
- 未涉及红黑树或其他平衡策略 ✓
- 未出现编程代码片段 ✓
- 无与考察无关的背景叙述 ✓

### 典型陷阱设计
1. **旋转类型混淆**（(2)中）：失衡节点30为左重（BF=2），但新节点插入在左子树的右侧，学生可能误判为LL而非LR
2. **失衡节点误判**（(3)中）：需从插入点向上回溯找到第一个失衡节点20，而非直接看更高层节点30
3. **指针遗漏**（(2)中）：LR双旋转涉及4个孩子指针的修改，学生可能遗漏中间节点的子树重新挂接

### 知识点选取理由
- AVL平衡因子计算：每个子问都需要计算节点平衡因子以判定失衡
- 旋转类型判定：通过失衡节点及其子节点的平衡因子符号确定LL/LR/RL/RR
- 旋转执行与指针调整：LR双旋转是最易出错的考点，考察对指针操作的精确理解
- 前序遍历验证：通过遍历序列验证最终树结构的正确性

### 参数选择理由
- 起始树7个节点，高度4，结构非对称（左重右轻），为后续插入预留失衡空间
- 插入序列1→18→19：1触发LL单旋转；18触发根级LR双旋转（树根改变）；19触发子树级LR双旋转
- 关键字取小整数，BST路径唯一无歧义

### K 值对齐说明
- **K1=3**（标准）：需准确记忆AVL平衡因子定义和四种旋转类型
- **K2=2**（较低）：平衡因子计算为简单高度相减，数字友好
- **K3=4**（较高）：三次串行插入 + 旋转，每次改变树结构，需维持动态状态更新
- **K4=4**（较高）：旋转类型判定需通过子节点BF隐含路由；双旋转需识别中间节点C及其两棵子树的重新挂接
- **K5=1**（微弱）：单一知识点内部解决，不涉及跨系统联动
