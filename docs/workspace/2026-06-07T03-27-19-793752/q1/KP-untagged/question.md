# 综合应用题：AVL树插入旋转过程分析

## 题干

已知一棵AVL树，其结构如下（括号内为节点关键字）：

```
        (30)
       /    \
    (10)    (40)
       \       \
      (20)     (50)
```

该AVL树中共有5个节点，各节点关键字分别为30、10、40、20、50。现依次向该AVL树中插入关键字15、25、5、55。

请回答下列问题：

### (1) （3分）

计算初始AVL树中各节点的平衡因子（平衡因子 = 左子树高度 - 右子树高度）。

### (2) （4分）

基于(1)的结果，依次插入关键字15和25。对于每次插入：
- 判断是否触发旋转操作
- 若触发旋转，说明旋转类型（LL/RR/LR/RL）及旋转中心节点
- 若未触发旋转，简要说明原因

### (3) （3分）

利用(2)中得到的AVL树状态，继续依次插入关键字5和55。对于每次插入：
- 判断是否触发旋转操作
- 若触发旋转，说明旋转类型及旋转中心节点
- 计算最终AVL树的高度

### 知识点选取理由

- **AVL树平衡因子计算**：考察对平衡因子定义（左子树高度-右子树高度）的理解
- **不平衡检测**：考察对|bf|>1时触发旋转的条件的掌握
- **四类旋转识别**：考察对LL/RR/LR/RL四种旋转触发条件的辨析能力
- **旋转操作模拟**：考察对旋转过程中节点重连和平衡因子调整的动态理解

### 参数选择理由

- **初始树结构**：选择5个节点（30, 10, 40, 20, 50），形成左右不对称但平衡的初始状态，便于考察旋转触发条件

- **数值选择**：使用10的倍数（10, 20, 30, 40, 50）和5的倍数（5, 15, 25, 55），便于心算和比较大小
