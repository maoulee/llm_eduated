# 题目

某进程页面访问序列为 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5。若分别采用 FIFO 和 LRU 页面置换算法，下列关于缺页次数的叙述中，正确的是（）。

I. 采用 FIFO 算法，分配 3 块物理块时的缺页次数为 9
II. 采用 FIFO 算法，分配 4 块物理块时的缺页次数比 3 块时更多
III. 若将 FIFO 替换为 LRU 算法，不会出现缺页次数随物理块增加而增多的现象

A. 仅 I 和 II
B. 仅 I 和 III
C. 仅 II 和 III
D. I、II 和 III

---

## 设计说明

- **考察模式**：场景推演与陷阱辨析（来自经验卡建议分布）
- **选项风格**：组合判断（I/II/III 命题判断）
- **should_be 对照**：
  - 利用反直觉现象（Belady异常）制造认知冲突 → 通过给定具体页面访问序列，让考生推演发现"增加物理块反而缺页更多"的反直觉结果
  - 考察算法深层特性及边界条件 → 需理解FIFO为何会出现Belady异常、LRU为何具有栈性质不会出现
  - 场景推演成分 → 命题I和II需要考生实际推演FIFO在3块和4块下的缺页过程
- **should_not_be 排查**：
  - 非纯概念记忆题 → 命题I和II需通过推演验证，无法仅凭记忆作答
  - 非基础流程记忆 → 考察的是Belady异常这一深层特性，而非FIFO/LRU的基本执行步骤
  - 无多余叙述 → 题干仅1句话给出序列+设问，无背景铺垫
- **参数选择理由**：
  - 页面访问序列 `1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5` 共12个访问，是经典Belady异常序列
  - 物理块数选3和4（相邻整数），便于对比观察异常现象
  - 页面号1-5，共5个不同页面，超过物理块数，确保有置换发生
- **干扰项设计策略**：
  - **A（仅I和II）**：针对误认为LRU也会出现Belady异常的考生。这类考生知道FIFO会出现异常（I和II正确），但错误地认为LRU同样可能出现缺页随块数增加而增多的情况（误判III为假）
  - **B（仅I和III）**：针对未能完成FIFO在4块下的完整推演、凭直觉认为"块数越多缺页越少"的考生。这类考生正确算出3块缺页9次（I正确），知道LRU不会出现异常（III正确），但凭直觉否定II（认为4块不可能比3块缺页更多）
  - **C（仅II和III）**：针对FIFO在3块下推演出错的考生。这类考生可能将3块缺页次数算错（如算成10次），从而否定I，但通过某种方式意识到4块比3块多（II正确），且知道LRU无异常（III正确）
- **与契约 K 值的对齐说明**：
  - K1=4（需精准辨析FIFO与LRU的栈性质差异，以及Belady异常的概念）
  - K2=1（缺页计数为简单计数，无复杂计算）
  - K3=4（需维持FIFO队列状态，完成12步推演×2种物理块配置，中间错一步全盘皆输）
  - K4=4（隐含前提：Belady异常仅出现在FIFO等特定算法中，LRU因栈性质免疫，需本质理解才能路由）
  - K5=2（纯内存管理域内，不涉及跨系统联动）
  - 综合定位 K4-K5 型，符合契约要求
