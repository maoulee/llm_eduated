## 题干
某计算机主频为 2 GHz，程序 P 共执行了 $8 \times 10^6$ 条指令，其中 75% 的指令 CPI 为 2，25% 的指令 CPI 为 6。程序 P 的执行时间是（）。

## 选项
- A: 8 ms
- B: 12 ms
- C: 16 ms
- D: 24 ms

## 设计说明
- 考察模式：计算型——单结果竞争（来自经验卡建议分布 53.8% 最高频）
- 选项风格：数字结果（来自经验卡建议分布 55% 最高频）
- 知识点：CPU 执行时间公式 $T = IC \times CPI_{avg} / f$，加权平均 CPI 的计算，GHz 与 ms 之间的单位换算
- should_be 对照：
  - 注重单位换算：主频 GHz → Hz（×10⁹），结果 s → ms（×10³），考生需正确处理两条换算链
  - 注重公式中变量的物理意义：CPI 为加权平均而非算术平均，体现权重与指令混合比例的物理含义
  - 结合体系结构背景：不同类型指令 CPI 不同是真实流水线/访存行为的反映
- should_not_be 排查：
  - 非纯记忆填空：需要公式应用和计算 ✓
  - 无繁琐数字：所有中间结果为整数（CPI=3，周期=2×10⁷，时间=12 ms）✓
  - 无表述歧义：主语明确（程序 P 的执行时间），参数完整 ✓
- 参数选择理由：
  - 主频 2 GHz：2 的幂相关，与 10⁹ 换算简洁
  - 指令数 8×10⁶：2³ × 10⁶，便于与主频的 10⁹ 对齐
  - 比例 75%/25%：加权 CPI = 0.75×2 + 0.25×6 = 3.0，为整数
  - CPI 取 2 和 6：算术平均恰为 4，可作为干扰项
- 干扰项设计策略（并行陷阱，各自针对一种单一错误）：
  - A（8 ms）：取低 CPI 类的值（CPI=2），错误认知"取最优指令的 CPI"
  - C（16 ms）：取算术平均 CPI=(2+6)/2=4，错误认知"不加权，简单平均"
  - D（24 ms）：取高 CPI 类的值（CPI=6），错误认知"取最差指令的 CPI"
- 代码验证结果摘要：
  - 加权 CPI = 3.0（整数 ✓）
  - 总周期数 = 2.4×10⁷（整数 ✓）
  - 执行时间 = 12.0 ms（整数 ✓）
  - 4 个选项 {8, 12, 16, 24} 互不相同 ✓
  - 正确答案唯一 ✓
  - 选项间距合理（4, 4, 8），干扰项等差分布增强辨析难度
- 与契约 K 值的对齐说明：K 全 1（众数），定位为计算机系统概述部分的基础计算题。本题只需套用执行时间公式并正确计算加权 CPI，无复合陷阱或多步推演，与 K1 难度匹配
