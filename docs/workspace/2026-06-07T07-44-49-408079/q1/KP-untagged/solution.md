## 求解过程

### 子问题(1)：插入前三个关键字（10, 20, 30）

**插入过程模拟**：

1. **插入10**：树为空，10成为根节点。
   ```
   10
   ```

2. **插入20**：20 > 10，作为10的右孩子。
   ```
   10
    \
     20
   ```

3. **插入30**：30 > 10，向右；30 > 20，作为20的右孩子。
   ```
   10
    \
     20
      \
       30
   ```

**旋转调整前的BST结构**：
```
    10
     \
      20
       \
        30
```

**平衡因子分析**：
- 节点30：左高0 - 右高0 = 0，平衡
- 节点20：左高0 - 右高1 = -1，平衡
- 节点10：左高0 - 右高2 = -2，**不平衡**（|BF| > 1）

**旋转判定**：
- 不平衡节点为10，其平衡因子为-2（右子树过高）
- 10的右孩子20的平衡因子为-1（右子树过高）
- 新插入节点30在10的右孩子的右子树方向 → **RR型**

**结论**：
- 旋转类型：**RR旋转**
- 旋转中心节点：**10**

RR旋转后，20成为新的根节点，10成为20的左孩子，30成为20的右孩子：
```
    20
   /  \
  10   30
```

### 子问题(2)：继续插入剩余关键字（5, 1, 2, 15, 12, 18, 25, 28, 22）

基于(1)中旋转后的AVL树（根20，左10，右30），依次插入：

**插入5**：
- 5 < 20 → 左；5 < 10 → 左，作为10的左孩子
- 树结构：
  ```
      20
     /  \
    10   30
   /
  5
  ```
- 平衡因子：5(0), 10(1), 30(0), 20(0) → 均平衡
- **无旋转**

**插入1**：
- 1 < 20 → 左；1 < 10 → 左；1 < 5 → 左，作为5的左孩子
- 插入后：节点10的BF = 左高2 - 右高0 = 2，不平衡
- 10的左孩子5的BF = 1（左子树高）→ LL型
- **LL旋转，中心节点：10**
- 旋转后：5成为子树根，1为5的左孩子，10为5的右孩子

**插入2**：
- 2 < 20 → 左；2 < 5 → 左；2 > 1 → 右，作为1的右孩子
- 插入后：节点20的BF = 左高3 - 右高1 = 2，不平衡
- 20的左孩子5的BF = 1（左子树高）→ LL型
- **LL旋转，中心节点：20**
- 旋转后：5成为根，1为5的左孩子，20为5的右孩子

**插入15**：
- 15 < 20 → 左；15 > 10 → 右，作为10的右孩子
- 平衡因子检查：所有节点BF绝对值 ≤ 1
- **无旋转**

**插入12**：
- 12 < 20 → 左；12 > 10 → 右；12 > 15不成立，12 < 15 → 左，作为15的左孩子
- 插入后：节点10的BF = 左高0 - 右高2 = -2，不平衡
- 10的右孩子15的BF = 1（左子树高）→ RL型
- **RL旋转，中心节点：10**
- 旋转后：12成为子树根，10为12的左孩子，15为12的右孩子

**插入18**：
- 18 < 20 → 左；18 > 12 → 右；18 > 15 → 右，作为15的右孩子
- 插入后：节点20的BF = 左高3 - 右高1 = 2，不平衡
- 20的左孩子12的BF = -1（右子树高）→ LR型
- **LR旋转，中心节点：20**
- 旋转后：15成为根，12为15的左孩子，20为15的右孩子

**插入25**：
- 25 > 15 → 右；25 > 20 → 右；25 > 30不成立，25 < 30 → 左，作为30的左孩子
- 插入后：节点20的BF = 左高0 - 右高2 = -2，不平衡
- 20的右孩子30的BF = 1（左子树高）→ RL型... 等等，需要重新检查
