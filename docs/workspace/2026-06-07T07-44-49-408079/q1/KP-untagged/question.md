# 综合应用题：AVL树插入与旋转

## 题目

已知一棵初始为空的AVL树（平衡二叉排序树），按以下序列依次插入关键字：

**10, 20, 30, 5, 1, 2, 15, 12, 18, 25, 28, 22**

AVL树在每次插入后，若某节点的平衡因子绝对值大于1，则进行相应的旋转调整以恢复平衡。旋转类型包括：LL旋转（左左）、RR旋转（右右）、LR旋转（左右）、RL旋转（右左）。

请回答下列问题：

### (1)（3分）

模拟插入前三个关键字（10, 20, 30）的过程。画出插入30之后、旋转调整之前的二叉排序树结构，并说明此时需要进行何种类型的旋转，旋转中心节点是哪个关键字。

### (2)（4分）

基于(1)中得到的AVL树，继续依次插入剩余的关键字（5, 1, 2, 15, 12, 18, 25, 28, 22）。请列出每次插入后若发生旋转，需说明：插入的关键字、旋转类型（LL/RR/LR/RL）、旋转中心节点的关键字。若某次插入未触发旋转，请说明"无旋转"。

### (3)（3分）

基于(2)中得到的最终AVL树，计算该树的高度（根节点高度为1），统计叶子节点（无左右孩子的节点）的个数，并写出该AVL树的中序遍历序列。

## 设计说明

### 考察结构模式
**手动模拟与算法推演**（来自经验卡）

本题采用"基础参数推导→过程模拟→结果分析"的三步递进结构：
- 第一步（基础问）：通过小规模插入（3个元素）让学生熟悉AVL树插入和首次旋转的判定
- 第二步（核心问）：完整模拟12个元素的插入过程，跟踪每次旋转的类型和中心节点
- 第三步（区分度问）：基于最终树结构进行属性分析和遍历

### 子问依赖关系

| 子问题 | 依赖 | 说明 |
|--------|------|------|
| (1) | 无（题干条件） | 基础参数计算：模拟前3个元素插入，识别首次旋转 |
| (2) | (1)的输出 | 使用(1)中旋转调整后的AVL树作为起点，继续插入剩余元素 |
| (3) | (2)的输出 | 基于(2)中得到的最终AVL树结构，计算高度、叶子数、中序遍历 |

### 知识点选取理由
AVL树插入旋转是数据结构中平衡二叉树的核心考点，408考试中常以综合题形式出现。本题覆盖：
- AVL树的基本概念（平衡因子、旋转类型）
- BST插入操作
- 四种旋转类型（LL/RR/LR/RL）的判定与执行
- 树的高度计算、叶子节点统计、中序遍历

### 参数选择理由
插入序列 `[10, 20, 30, 5, 1, 2, 15, 12, 18, 25, 28, 22]` 经过验证：
- 共12个元素，长度适中（8-15范围内）
- 值均在0-30范围内，便于心算比较
- **触发全部四种旋转类型**：RR、LL、LR、RL各至少一次
- 共发生8次旋转，认知负荷符合K3-K4难度要求
- 最终树保持平衡，中序遍历为有序序列

### 与契约 K 值的对齐说明
- **K3（机制推演）= 4**：需按AVL插入规则走完12步流程，每步需判断平衡因子、决定旋转类型，推演步数>5步且需维持动态状态更新
- **K4（条件路由）= 3**：存在明确陷阱——LR/RL旋转需先对子节点旋转再对父节点旋转，不触发此规则会选错旋转类型
- **K1（基础认知）= 3**：必须准确记忆AVL树平衡因子定义和四种旋转的触发条件
- **K2（单步代入）= 1**：几乎无复杂计算，仅需比较大小和计数
- **K5（跨域联动）= 1**：单一知识点内部解决，不涉及其他系统
- **综合难度 = 4**：符合契约要求的难度等级
