# 综合应用题：AVL树的插入操作与平衡调整

## 题目

已知一棵AVL树（平衡二叉排序树）的初始状态如下：

```
        10
       /  \
      5    15
     / \   / \
    3   7 12  18
```

该树中每个节点的平衡因子（左子树高度 - 右子树高度）均为0，树的高度为3（根节点所在层为第1层）。

现依次向该AVL树中插入关键字序列：2, 1, 14。

请回答下列问题：

### (1)（3分）

计算插入关键字2之后，AVL树中所有非叶子节点的平衡因子，并判断此时是否需要进行旋转调整。若需要，说明旋转类型及旋转中心节点。

### (2)（4分）

基于(1)的结果，继续插入关键字1。说明插入1后触发的旋转调整过程（包括旋转类型、旋转中心节点、旋转后子树结构），并画出插入1完成调整后的完整AVL树结构。

### (3)（3分）

利用(2)中得到的AVL树，继续插入关键字14。分析插入14后是否触发旋转调整，若触发说明旋转类型及过程；若不触发，说明理由。给出最终AVL树的中序遍历序列。

## 设计说明

### 考察结构模式

**全过程模拟与代码/逻辑实现**（来自经验卡）

- **第一步（基础问）**：计算插入单个关键字后的平衡因子，判断是否需要旋转
- **第二步（核心问）**：模拟插入触发旋转的完整过程，包括旋转类型识别、旋转执行、结构调整
- **第三步（区分度问）**：在已调整的基础上继续插入，分析是否再次触发旋转，并验证最终结果

### 子问依赖关系

| 子问题 | 依赖 | 说明 |
|--------|------|------|
| (1) | 无（题干条件） | 基础参数计算：插入2后计算各节点平衡因子，判断旋转需求 |
| (2) | (1)的输出 | 核心过程模拟：基于(1)的树状态，插入1并执行LL旋转 |
| (3) | (2)的输出 | 结果分析：基于(2)的树状态，插入14分析旋转需求，给出中序遍历 |

### 知识点选取理由

- **AVL树插入操作**：408数据结构核心考点，考察平衡二叉树的动态维护机制
- **四种旋转（LL/RR/LR/RL）**：本题重点考察LL旋转，同时通过不触发旋转的情况考察考生对旋转条件的准确判断
- **平衡因子计算**：基础但关键，是判断是否需要旋转的前提
- **中序遍历验证**：通过中序遍历序列验证AVL树的二叉排序树性质是否保持

### 参数选择理由

- **初始树结构**：选择高度为3的完全平衡AVL树（7个节点），所有节点平衡因子为0，便于考生计算
- **插入序列[2, 1, 14]**：
  - 2：插入到3的左子树，不触发旋转（考察考生判断能力）
  - 1：插入到2的左子树，触发LL旋转（核心考察点）
  - 14：插入到12的右子树，不触发旋转（考察考生对旋转条件的准确理解）
- **数值选择**：使用连续整数，便于心算和验证
