## 求解过程

### 初始AVL树
```
        10
       /  \
      5    15
     / \   / \
    3   7 12  18
```
所有节点平衡因子为0，树高为3。

---

### 子问题(1)：插入关键字2

**插入过程**：2 < 10 → 左，2 < 5 → 左，2 < 3 → 左，2作为3的左孩子插入。

插入后树结构：
```
        10
       /  \
      5    15
     / \   / \
    3   7 12  18
   /
  2
```

**计算非叶子节点的平衡因子**（左子树高度 - 右子树高度）：

| 节点 | 左子树高度 | 右子树高度 | 平衡因子 |
|------|-----------|-----------|---------|
| 3    | 1（节点2） | 0         | 1       |
| 5    | 2（3→2）   | 1（节点7） | 1       |
| 15   | 1（节点12）| 1（节点18）| 0       |
| 10   | 3（5→3→2） | 2（15→12/18）| 1     |

**判断**：所有非叶子节点的平衡因子均在[-1, 1]范围内，**不需要进行旋转调整**。

---

### 子问题(2)：插入关键字1

**插入过程**：1 < 10 → 左，1 < 5 → 左，1 < 3 → 左，1 < 2 → 左，1作为2的左孩子插入。

插入后（调整前）树结构：
```
        10
       /  \
      5    15
     / \   / \
    3   7 12  18
   /
  2
 /
1
```

**从插入点向上检查平衡因子**：
- 节点2：左高1，右高0，BF = 1 ✓
- 节点3：左高2（2→1），右高0，BF = 2 ✗ **失衡！**

**旋转调整**：
- **失衡节点**：3
- **失衡类型**：LL型（插入路径为3→2→1，连续向左）
- **旋转类型**：右旋（顺时针旋转）
- **旋转中心**：节点3

**右旋过程**：
1. 节点2上升为新的子树根
2. 节点3下降为节点2的右孩子
3. 节点2的原右子树（空）成为节点3的左子树

旋转后子树结构：
```
  2
 / \
1   3
```

**插入1完成调整后的完整AVL树**：
```
        10
       /  \
      5    15
     / \   / \
    2   7 12  18
   / \
  1   3
```

**验证平衡因子**：
- 节点2：左高1，右高1，BF = 0 ✓
- 节点5：左高2（2→1/3），右高1（7），BF = 1 ✓
- 节点10：左高3（5→2→1/3），右高2（15→12/18），BF = 1 ✓
- 其余节点BF均为0或±1，树平衡。

---

### 子问题(3)：插入关键字14

**插入过程**：14 > 10 → 右，14 < 15 → 左，14 > 12 → 右，14作为12的右孩子插入。

插入后树结构：
```
        10
       /  \
      5    15
     / \   / \
    2   7 12  18
   / \     \
  1   3     14
```

**从插入点向上检查平衡因子**：
- 节点12：左高0，右高1（14），BF = -1 ✓
- 节点15：左高2（12→14），右高1（18），BF = 1 ✓
- 节点10：左高3（5→2→1/3），右高3（15→12→14），BF = 0 ✓

**判断**：所有节点的平衡因子均在[-1, 1]范围内，**不触发旋转调整**。

**理由**：插入14后，沿插入路径向上检查，各祖先节点的平衡因子均未超过±1，树仍保持AVL平衡性质。

**最终AVL树的中序遍历序列**：

中序遍历（左→根→右）：1, 2, 3, 5, 7, 10, 12, 14, 15, 18

---

## 最终答案

### (1)
- 插入2后非叶子节点平衡因子：节点3的BF=1，节点5的BF=1，节点15的BF=0，节点10的BF=1
- 所有平衡因子均在[-1, 1]范围内，**不需要旋转调整**

### (2)
- 插入1后节点3的BF=2，触发**LL型右旋**
- 旋转中心节点：**3**
- 旋转后子树：2为根，1为左孩子，3为右孩子
- 完整AVL树结构：
```
        10
       /  \
      5    15
     / \   / \
    2   7 12  18
   / \
  1   3
```

### (3)
- 插入14后**不触发旋转调整**
- 理由：插入路径上所有节点的平衡因子均在[-1, 1]范围内（节点12的BF=-1，节点15的BF=1，节点10的BF=0）
- 最终AVL树的中序遍历序列：**1, 2, 3, 5, 7, 10, 12, 14, 15, 18**
