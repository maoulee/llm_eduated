# AVL树插入与旋转操作综合题

## 题干

将 12 个关键字 3, 2, 1, 4, 5, 6, 7, 16, 15, 14, 13, 12 依次插入初始为空的AVL平衡二叉树。平衡因子定义为左子树高度减去右子树高度，AVL树要求所有节点的平衡因子绝对值不超过 1。每次插入后若发生失衡，立即进行相应的旋转调整。

## 子问题

**（1）** 在依次插入关键字的过程中，AVL树共发生了几次失衡调整？请按发生顺序，对每次失衡调整列出：① 失衡的最小子树的根节点关键字；② 失衡类型（LL / LR / RL / RR）；③ 旋转调整后该子树的新根节点关键字。

**（2）** 当所有关键字插入完毕后，写出整棵 AVL 树的层序遍历序列（从左到右），并指出该 AVL 树的高度。

**（3）** 在所有关键字插入完毕后的 AVL 树中，平衡因子为 0 的节点共有多少个？

**（4）** 下面是 AVL 树插入操作中处理 LR 型失衡（先左旋后右旋）的核心代码，请填写空缺（1）~（4）处的 C 语句。

## 设计说明

- **考察结构模式**：过程追踪（子问题 1-3）与代码/伪代码实现（子问题 4）混合，符合推荐模式
- **子问依赖关系**：子问题 (1)→(2)→(3) 递进，均依赖对完整插入过程的正确推演；子问题 (4) 独立考察 LR 旋转的指针操作细节
- **should_be**：序列应触发至少 3 次失衡调整，覆盖至少 2 种不同旋转类型（如 LL 与 LR），使过程追踪部分具有足够的区分度；代码部分考察双旋转中的指针重分配顺序
- **should_not_be**：序列不应过长（≤12 个关键字）导致工作记忆超载；不应仅有单一类型的旋转导致区分度不足
- **K 值对齐**：
  - K1=3（需准确记忆 AVL 定义、平衡因子、四种旋转类型的概念）
  - K2=2（计算为高度比较与计数，数字友好）
  - K3=4（需追踪 8-12 个关键字的完整插入过程，维持动态状态更新，中间错一步全盘皆输）
  - K4=4（需正确判断每次失衡属于哪种旋转类型，理解"最小不平衡子树"的精确定义）
  - K5=1（单一知识域内部解决，不涉及跨域联动）
  - 整体难度 5，由 K3=4/K4=4 支撑高难度特征，符合 K4-K5 目标
