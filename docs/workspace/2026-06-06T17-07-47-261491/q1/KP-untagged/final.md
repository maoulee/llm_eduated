## 题目
某计算机主存地址为32位，Cache容量为64KB，采用4路组相联映射，Cache块大小为64B。在主存地址中，标记、组索引和块内偏移的位数分别是（）。

A. 18位、8位、6位
B. 16位、10位、6位
C. 16位、8位、8位
D. 19位、8位、5位

---


## 求解过程
### 参数提取
- 主存地址：32位
- Cache容量：64KB = 65536B
- 映射方式：4路组相联
- 块大小：64B

### 计算过程

**1. 块内偏移位数**

块内偏移用于在Cache块内定位字节，位数 = log₂(块大小)

块内偏移 = log₂(64) = **6位**

**2. 组索引位数**

- Cache总块数 = Cache容量 / 块大小 = 65536 / 64 = 1024块
- 组数 = 总块数 / 路数 = 1024 / 4 = 256组
- 组索引 = log₂(256) = **8位**

**3. 标记位数**

标记 = 主存地址位数 - 组索引位数 - 块内偏移位数

标记 = 32 - 8 - 6 = **18位**

### 结果对比验证

手动验证：
- 块内偏移：64B块 → 需要6位寻址（2⁶=64）✓
- 组索引：64KB/64B=1024块，1024/4=256组，log₂(256)=8位 ✓
- 标记：32-8-6=18位 ✓

代码输出与手动推算一致。


## 答案
正确答案：**A. 18位、8位、6位**

- 标记：18位
- 组索引：8位
- 块内偏移：6位
