# 题目

某系统中有4个进程，其到达时间和所需服务时间如下表所示：

| 进程 | 到达时间 | 服务时间 |
|------|----------|----------|
| P1   | 0        | 4        |
| P2   | 1        | 2        |
| P3   | 2        | 4        |
| P4   | 3        | 2        |

若采用非抢占式短作业优先（SJF）调度算法，这4个进程的平均周转时间为（）。

A. 6.0
B. 6.5
C. 5.5
D. 7.0

---

## 设计说明

- **考察模式**：综合计算对比（来自蓝图推荐模式）
- **选项风格**：数字结果
- **should_be对照**：
  - 通过具体数值计算区分算法优劣 ✓
  - 中等难度，需模拟调度过程并计算指标 ✓
  - 单选题，4选1 ✓
- **should_not_be排查**：
  - 非纯概念记忆题 ✓
  - 无编程代码 ✓
  - 题干简洁（2句话+1表格） ✓
- **参数选择理由**：
  - 到达时间 0,1,2,3 为连续整数，便于推演
  - 服务时间 4,2,4,2 均为2的幂，便于心算
  - 4个进程数量适中，推演步骤在3-5步范围内
- **干扰项设计策略**：
  - A（6.0）：正确答案。SJF调度顺序为P1→P4→P2→P3，周转时间分别为4,3,7,10，平均(4+3+7+10)/4=6.0
  - B（6.5）：FCFS算法的平均周转时间(4+5+8+9)/4=6.5，针对"未区分SJF与FCFS"的错误
  - C（5.5）：漏算P3或算成平均等待时间(0+2+3+6)/4=2.75×2≈5.5，针对"混淆周转时间与等待时间"的错误
  - D（7.0）：将P3的周转时间误算为12（而非10），导致(4+3+7+12)/4=6.5→取整错误，或误将到达时间计入周转时间
- **代码验证结果摘要**：待验证
- **与契约K值的对齐说明**：
  - K2（单步代入）：需代入周转时间公式，数字为2的幂，友好计算 → K2=2
  - K3（机制推演）：需按SJF规则模拟4个进程的调度过程，约4步推演 → K3=3
  - 符合K2-K3目标 ✓
