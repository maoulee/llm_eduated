### 子问题(1): 计算初始AVL树中每个节点的平衡因子

**初始AVL树结构**:
```
        20
       /  \
      10   30
     /      \
    5        35
```

**各节点平衡因子计算**（平衡因子 = 左子树高度 - 右子树高度）:

| 节点 | 左子树高度 | 右子树高度 | 平衡因子 |
|------|-----------|-----------|---------|
| 5    | 0         | 0         | 0       |
| 35   | 0         | 0         | 0       |
| 10   | 1 (节点5) | 0         | 1       |
| 30   | 0         | 1 (节点35)| -1      |
| 20   | 2 (10→5)  | 2 (30→35) | 0       |

**验证**: 所有节点平衡因子绝对值均 ≤ 1，因此**初始树满足AVL树的平衡条件**。

### 子问题(2): 依次插入 8、25、40

#### 插入 8

8 < 20 → 左，8 < 10 → 左，8 > 5 → 右，8成为节点5的右孩子。

插入后（回溯检查平衡）:
```
        20
       /  \
      10   30
     /      \
    5        35
     \
      8
```

节点10的平衡因子 = 2 - 0 = 2 > 1，**失衡**。插入key=8 > node.left.key=5，属于**LR型**。

**执行LR旋转**（失衡节点=10）:
1. 对节点5做左旋转：8成为5的父节点
2. 对节点10做右旋转：8成为10的父节点

旋转后:
```
        20
       /  \
      8    30
     / \    \
    5   10   35
```

各节点平衡因子: 5→0, 8→0, 10→0, 20→0, 30→-1, 35→0，全部≤1，平衡。

**结论**: 触发旋转，失衡节点=10，旋转类型=**LR**

#### 插入 25

25 > 20 → 右，25 < 30 → 左，25成为节点30的左孩子。

插入后:
```
        20
       /  \
      8    30
     / \   / \
    5  10 25  35
```

各节点平衡因子: 5→0, 8→0, 10→0, 20→0, 25→0, 30→0, 35→0，全部≤1。

**结论**: **未触发旋转**

#### 插入 40

40 > 20 → 右，40 > 30 → 右，40 > 35 → 右，40成为节点35的右孩子。

插入后:
```
        20
       /  \
      8    30
     / \   / \
    5  10 25  35
              \
               40
```

各节点平衡因子: 5→0, 8→0, 10→0, 20→-1, 25→0, 30→-1, 35→-1, 40→0，全部≤1。

**结论**: **未触发旋转**
