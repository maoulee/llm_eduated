## 求解过程

### 题目分析

本题考察Cache组相联映射的地址字段划分。已知参数：
- 主存容量：1MB = 2^20 B
- Cache容量：1KB = 2^10 B
- 块大小：64B = 2^6 B
- 映射方式：4路组相联

### 子问题：标记、组号、块内偏移的位数

**步骤1：块内偏移位数**
- 块大小为64B = 2^6 B
- 块内偏移需要寻址块内的64个字节，故需要 **6位**

**步骤2：Cache总块数**
- Cache容量 / 块大小 = 1024 / 64 = 16 块

**步骤3：组数**
- 4路组相联，每组4块
- 组数 = 总块数 / 路数 = 16 / 4 = 4 组

**步骤4：组号位数**
- 4组 = 2^2，故组号需要 **2位**

**步骤5：主存地址总位数**
- 1MB = 2^20 B，按字节编址，主存地址需要 **20位**

**步骤6：标记位数**
- 标记位数 = 主存地址总位数 - 组号位数 - 块内偏移位数
- 标记位数 = 20 - 2 - 6 = **12位**

### 结果对比验证

手动推算：
- 块内偏移：64B → log₂(64) = 6位 ✓
- 组数：1KB/64B/4路 = 16/4 = 4组 → log₂(4) = 2位 ✓
- 标记：20 - 2 - 6 = 12位 ✓

代码输出与手动推算一致。

### 选项分析

| 选项 | 标记 | 组号 | 块内偏移 | 是否匹配 |
|------|------|------|----------|----------|
| A | 10位 | 4位 | 6位 | 否 |
| B | 12位 | 2位 | 6位 | **是** |
| C | 14位 | 0位 | 6位 | 否 |
| D | 11位 | 3位 | 6位 | 否 |

## 最终答案
- 正确答案：**B**
- 理由：主存地址20位，块内偏移6位（64B块），组号2位（4组），标记12位（20-2-6=12），即12位、2位、6位。
