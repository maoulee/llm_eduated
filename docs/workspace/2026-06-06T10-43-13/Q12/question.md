## 题干
某计算机主频为2GHz，程序P共执行4×10⁶条指令，其中40%的指令CPI为1，40%的指令CPI为2，20%的指令CPI为4。程序P的执行时间与指令执行速度（MIPS）分别是（）。

## 选项
- A: 2 ms，2000 MIPS
- B: 4 ms，1000 MIPS
- C: 8 ms，500 MIPS
- D: 4 ms，2000 MIPS

## 设计说明
- 考察模式：计算型——公式应用与单位换算（来自经验卡建议分布 55%，占比最高）
- 选项风格：数字结果型——双参数数值结果（来自经验卡建议分布 55%，占比最高）
- 知识点：CPU执行时间公式 T = IC × CPI / f、加权平均CPI计算、MIPS = f / CPI 公式、Hz→s 单位换算
- should_be对照：
  - "注重单位换算"：题干以GHz给出主频，选项要求ms和MIPS，考生需完成 GHz↔s（10⁹）和 MIPS↔Hz/CPI 的双重换算
  - "注重公式中变量的物理意义"：加权CPI需要理解不同指令类别的CPI权重，MIPS与CPI成反比的物理意义隐含在选项D的陷阱中
  - "结合计算机体系结构背景"：题干给出三类指令的CPI分布，模拟真实程序中不同指令类型的执行特征
- should_not_be排查：
  - ✅ 非纯粹记忆填空：需要完整的公式应用与计算
  - ✅ 无复杂数字：主频2GHz、IC=4×10⁶、CPI为1/2/4，均为简洁值，心算友好
  - ✅ 无题干歧义：主语明确（"程序P的执行时间与指令执行速度"），不存在两种理解
- 参数选择理由：
  - 主频 2GHz = 2×10⁹ Hz，2的幂次基底
  - IC = 4×10⁶ = 4M条，2的幂次基底
  - CPI 1/2/4，加权后 = 0.4×1 + 0.4×2 + 0.2×4 = 2.0（整数）
  - 总周期数 = 4×10⁶ × 2 = 8×10⁶（整数）
  - 执行时间 = 8×10⁶ / 2×10⁹ = 4×10⁻³ s = 4 ms（整数ms）
  - MIPS = 2×10⁹ / 2 / 10⁶ = 1000（整数）
  - 所有中间结果和最终结果均为整数，无小数
- 干扰项设计策略（并行陷阱，各选项针对独立错误）：
  - A（2 ms, 2000 MIPS）：假设所有指令CPI=1（忽略指令CPI差异），时间偏低、MIPS偏高
  - B（4 ms, 1000 MIPS）：正确答案
  - C（8 ms, 500 MIPS）：假设所有指令CPI=4（取最大CPI），时间偏高、MIPS偏低
  - D（4 ms, 2000 MIPS）：执行时间正确但MIPS公式遗漏CPI（直接用主频/10⁶），考察MIPS公式中CPI的物理意义
- 代码验证结果摘要：
  - 加权CPI = 2.0 ✓
  - 总周期数 = 8,000,000 ✓
  - 执行时间 = 4.0 ms ✓
  - MIPS = 1000 ✓
  - 4个选项互不相同 ✓
  - 百分比之和 = 1.0 ✓
- 与契约K值对齐说明：K1-K2平衡型，题目要求一次公式应用+一次单位换算，计算量适中（加权平均+除法），符合K2计算型定位，非纯概念记忆也非复杂陷阱
