## 求解过程

### 子问题(1): 依次插入10、15、5、12后的AVL树

**逐步插入过程：**

1. **插入10**: 树为空，10成为根节点。
   ```
   10 (BF=0)
   ```

2. **插入15**: 15>10，成为10的右子。
   ```
   10 (BF=-1)
     \
      15 (BF=0)
   ```

3. **插入5**: 5<10，成为10的左子。
   ```
       10 (BF=0)
      /  \
     5    15 (BF=0)
   (BF=0)
   ```

4. **插入12**: 12>10→右，12<15→左，成为15的左子。
   - 12: BF=0
   - 15: BF = h(左)-h(右) = 1-0 = 1
   - 10: BF = h(左)-h(右) = 1-2 = -1
   - 所有节点BF ∈ [-1,0,1]，无需旋转。

**最终树结构：**
```
       10 (BF=-1)
      /  \
     5    15 (BF=1)
   (BF=0) /
         12 (BF=0)
```

**各节点平衡因子：**
| 节点 | 平衡因子 |
|------|---------|
| 10   | -1      |
| 5    | 0       |
| 15   | 1       |
| 12   | 0       |

### 子问题(2): 插入13

**插入过程：**

13>10→右，13<15→左，13>12→右，13成为12的右子。

**插入后（旋转前）：**
```
       10
      /  \
     5    15 (BF=2) ← 失衡！
   (BF=0) /  \
         12   13
       (BF=-1)(BF=0)
```

回溯更新平衡因子：
- 节点12: BF = 0-1 = -1
- 节点15: BF = 2-0 = **2** ← 失衡！
- 节点10: BF = 1-3 = -2（但失衡检测从最低失衡节点开始处理）

**失衡节点：15**

**旋转类型：LR型旋转**（插入路径：15→左(12)→右(13)）

LR型旋转步骤：
1. **先对左子节点12做左旋**：13上提，12成为13的左子
   ```
       13
      /
     12
   ```
2. **再对失衡节点15做右旋**：13上提，15成为13的右子
   ```
       13
      /  \
     12   15
   ```

**旋转后的AVL树：**
```
       10 (BF=-1)
      /  \
     5    13 (BF=0)
   (BF=0) /  \
         12   15
       (BF=0)(BF=0)
```

**各节点平衡因子：**
| 节点 | 平衡因子 |
|------|---------|
| 10   | -1      |
| 5    | 0       |
| 13   | 0       |
| 12   | 0       |
| 15   | 0       |

### 子问题(3): 依次插入18和3

#### 插入18

18>13→右，18>15→右，18成为15的右子。

**插入后（旋转前）：**
```
       10
      /  \
     5    13
   (BF=0) /  \
         12   15 (BF=-1)
       (BF=0)   \
                18 (BF=0)
```

回溯更新平衡因子：
- 节点15: BF = 0-1 = -1
- 节点13: BF = 1-2 = -1
- 节点10: BF = 1-3 = **-2** ← 失衡！

**失衡节点：10**

**旋转类型：RR型旋转**（插入路径：10→右(13)→右(15)→右(18)）

RR型旋转步骤：对失衡节点10做左旋
- 13上提成为新根，10成为13的左子，13的原左子(12)成为10的右子

**旋转后的树：**
```
       13 (BF=0)
      /  \
     10   15 (BF=-1)
    /  \    \
   5   12   18
 (BF=0)(BF=0)(BF=0)
```

各节点BF均在[-1,0,1]范围内，平衡。

#### 插入3

3<13→左，3<10→左，3<5→左，3成为5的左子。

**插入后的树：**
```
       13 (BF=1)
      /  \
     10   15 (BF=-1)
    /  \    \
   5   12   18
  /    (BF=0)(BF=0)
 3 (BF=0)
(BF=1)
```

回溯更新平衡因子：
- 节点3: BF = 0
- 节点5: BF = 1-0 = 1
- 节点10: BF = 2-1 = 1
- 节点13: BF = 3-2 = 1
- 节点15: BF = 0-1 = -1
- 节点18: BF = 0

所有节点BF ∈ [-1,0,1]，**不触发旋转**。

#### 最终AVL树

```
       13 (BF=1)
      /  \
     10   15 (BF=-1)
    /  \    \
   5   12   18
  /    (BF=0)(BF=0)
 3 (BF=0)
(BF=1)
```

**中序遍历序列：3, 5, 10, 12, 13, 15, 18**

（验证：中序遍历BST必为升序，7个关键字升序排列即为 3, 5, 10, 12, 13, 15, 18 ✓）

## 最终答案

- **(1)** AVL树结构：
  ```
       10 (BF=-1)
      /  \
     5    15 (BF=1)
   (BF=0) /
         12 (BF=0)
  ```
  各节点平衡因子：10→-1，5→0，15→1，12→0

- **(2)** 
  - 失衡节点：**15**
  - 旋转类型：**LR型旋转**（先对节点12左旋，再对节点15右旋）
  - 旋转后树结构：
    ```
         10 (BF=-1)
        /  \
       5    13 (BF=0)
     (BF=0) /  \
           12   15
         (BF=0)(BF=0)
    ```

- **(3)**
  - 插入18：**触发RR型旋转**，失衡节点为**10**
  - 插入3：**不触发旋转**
  - 最终AVL树中序遍历序列：**3, 5, 10, 12, 13, 15, 18**
