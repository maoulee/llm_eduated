# KP-untagged 综合应用题

## 题干

已知一棵AVL树（平衡二叉排序树）的层序遍历序列为10, 5, 15, 3, 7。现按顺序向该AVL树中插入结点6、12、13。请回答下列问题：

### (1) （3分）

画出初始AVL树的结构，并标出每个结点的平衡因子。

### (2) （4分）

基于(1)的结果，向该AVL树中插入结点6。画出插入并调整平衡后的AVL树结构，标出各结点平衡因子，并说明所采用的旋转类型。

### (3) （3分）

基于(2)的结果，继续向该AVL树中插入结点12。画出插入并调整平衡后的AVL树结构，标出各结点平衡因子，并说明所采用的旋转类型。

### (4) （3分）

基于(3)的结果，继续向该AVL树中插入结点13。画出插入后的AVL树结构，标出各结点平衡因子，并说明是否需要旋转调整及理由。

---

## 设计说明

- **考察结构模式**：过程追踪型（来自经验卡）
  - 第一步：基础参数推导——根据层序遍历序列构建初始AVL树并计算平衡因子
  - 第二步：过程模拟——追踪插入结点6的LR双旋调整过程
  - 第三步：过程模拟——追踪插入结点12的RL双旋调整过程
  - 第四步：结果分析——判断插入结点13后是否需要旋转

- **子问依赖关系**：

| 子问题 | 依赖 | 说明 |
|--------|------|------|
| (1) | 无（题干条件） | 基础参数计算：构建初始AVL树，计算各结点平衡因子 |
| (2) | (1)的输出 | 使用(1)的初始树结构，插入6并执行LR双旋调整 |
| (3) | (2)的输出 | 使用(2)调整后的树结构，插入12并执行RL双旋调整 |
| (4) | (3)的输出 | 使用(3)调整后的树结构，插入13并判断是否需要旋转 |

- **should_be对照**：
  - ✓ 过程追踪型综合题：通过三次插入操作追踪AVL树动态调整过程
  - ✓ 子问串行依赖：(1)→(2)→(3)→(4)形成完整串行依赖链
  - ✓ 考察AVL插入及双旋：(2)考察LR双旋，(3)考察RL双旋，(4)考察不需旋转的判断
  - ✓ 难度体现在多步追踪：三次插入各需多步推演（插入→判断失衡→确定旋转类型→执行旋转→更新平衡因子）

- **should_not_be排查**：
  - ✓ 非纯概念记忆题：题目要求画出树结构并追踪调整过程，非概念记忆
  - ✓ 无无关干扰内容：题干仅给出层序遍历序列和插入序列，所有条件均被子问题使用，无冗余信息
  - ✓ 无编程代码：题干和子问题均不含任何编程语言代码
  - ✓ 无背景故事：题干简洁直接，无与考察无关的叙述

- **知识点选取理由**：
  - AVL树插入操作及双旋调整是408数据结构核心考点，历年高频出现
  - LR双旋和RL双旋是AVL树中最复杂的旋转类型，能有效区分考生水平
  - 不需旋转的判断考察考生对平衡因子变化规律的深入理解

- **参数选择理由**：
  - 层序遍历序列[10, 5, 15, 3, 7]：构建一棵5结点AVL树，结构清晰，便于考生快速还原
  - 插入序列[6, 12, 13]：
    - 6位于5和7之间，插入后触发LR双旋
    - 12位于10和15之间，插入后触发RL双旋
    - 13位于12和15之间，插入后不需旋转，考察反直觉判断
  - 所有结点值均为整数，无重复值，便于心算和推导

- **代码验证结果摘要**：
  - 参数封闭性：✓ 所有子问题所需参数均在题干中给出
  - 子问依赖链：✓ (1)→(2)→(3)→(4)形成完整串行依赖，无断链
  - 推导路径等价：✓ 各插入操作的旋转类型可由前问结果唯一推导
  - 分值合理性：✓ 总分13分（3+4+3+3），在8-13分范围内
  - 插入值唯一性：✓ 插入值6、12、13均不与初始树结点重复
  - 格式合规：✓ 无旋转规则定义、无编程代码、无背景故事、无选项格式

- **与契约 K 值的对齐说明**：
  - K1=3（标准）：需准确记忆AVL树定义、平衡因子概念、四种旋转类型
  - K2=2（较低）：平衡因子计算为简单整数减法，无复杂计算
  - K3=4（较高）：三次插入各需多步推演，总步数>5步且需维持动态状态更新
  - K4=3（标准）：存在明确陷阱（旋转类型判断、失衡结点定位、插入13不需旋转的反直觉判断）
  - K5=1（微弱）：单一AVL树知识点内部解决，无跨域联动
  - 与规划对齐：K3=4为主要难度来源（多步过程追踪），K4=3为辅助（陷阱识别），符合"K4应用为主结合K3理解"的规划意图
