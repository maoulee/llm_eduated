## 求解过程

### (1) 初始AVL树的结构及平衡因子

**分析**：层序遍历序列为 10, 5, 15, 3, 7。按层序遍历规则，根为10，第二层为5和15，第三层为3和7（均为5的子节点）。

**初始AVL树结构**：
```
          10 (BF=1)
         /   \
    5 (BF=0)  15 (BF=0)
    /   \
3 (BF=0) 7 (BF=0)
```

**各节点平衡因子计算**：
- 节点3：左高=0，右高=0，BF = 0-0 = **0**
- 节点7：左高=0，右高=0，BF = 0-0 = **0**
- 节点15：左高=0，右高=0，BF = 0-0 = **0**
- 节点5：左高=1，右高=1，BF = 1-1 = **0**
- 节点10：左高=2，右高=1，BF = 2-1 = **1**

所有节点 |BF| ≤ 1，满足AVL树平衡条件。

### (2) 插入结点6

**插入位置分析**：6 > 5，6 < 7，所以6插入为7的左子节点。

**插入后（未调整前）**：
```
          10 (BF=2) ← 不平衡！
         /   \
    5 (BF=-1)  15 (BF=0)
    /   \
3 (BF=0) 7 (BF=1)
          /
      6 (BF=0)
```

**平衡性检查**：
- 节点7：左高=1，右高=0，BF=1
- 节点5：左高=1，右高=2，BF=-1
- 节点10：左高=3，右高=1，BF=2 → **|BF|=2，不平衡**

**旋转类型判断**：
- 失衡节点为10，BF=2（左子树过高）
- 节点10的左子节点5的BF=-1（右子树过高）
- 左子树高且左孩子的右子树高 → **LR型**

**旋转操作**：
1. 先对节点5进行**左旋**：7上升为5的父节点，5成为7的左子节点，6成为5的右子节点
2. 再对节点10进行**右旋**：7上升为根节点，5成为7的左子节点，10成为7的右子节点

**插入并调整后的AVL树**：
```
          7 (BF=0)
         /   \
    5 (BF=0)  10 (BF=-1)
    /   \        \
3 (BF=0) 6 (BF=0) 15 (BF=0)
```

**各节点平衡因子**：
- 节点3：BF=0
- 节点6：BF=0
- 节点15：BF=0
- 节点5：左高=1，右高=1，BF=0
- 节点10：左高=0，右高=1，BF=-1
- 节点7：左高=2，右高=2，BF=0

**旋转类型**：LR型（先左旋后右旋）

### (3) 插入结点12

**插入位置分析**：12 > 7，12 > 10，12 < 15，所以12插入为15的左子节点。

**插入后（未调整前）**：
```
          7 (BF=-1)
         /   \
    5 (BF=0)  10 (BF=-2) ← 不平衡！
    /   \        \
3 (BF=0) 6 (BF=0) 15 (BF=1)

```

**平衡性检查**：
- 节点12：BF=0
- 节点15：左高=1，右高=0，BF=1
- 节点10：左高=0，右高=2，BF=-2 → **|BF|=2，不平衡**
- 节点7：左高=2，右高=3，BF=-1

**旋转类型判断**：
- 失衡节点为10，BF=-2（右子树过高）
- 节点10的右子节点15的BF=1（左子树过高）
- 右子树高且右孩子的左子树高 → **RL型**

**旋转操作**：
1. 先对节点15进行**右旋**：12上升为15的父节点，15成为12的右子节点
2. 再对节点10进行**左旋**：12上升为10的父节点，10成为12的左子节点

**插入并调整后的AVL树**：
```
          7 (BF=0)
         /   \
    5 (BF=0)  12 (BF=0)
    /   \     /   \
3 (BF=0) 6 (BF=0) 10 (BF=0) 15 (BF=0)
```

**各节点平衡因子**：
- 节点3：BF=0
- 节点6：BF=0
- 节点10：BF=0
- 节点15：BF=0
- 节点5：左高=1，右高=1，BF=0
- 节点12：左高=1，右高=1，BF=0
- 节点7：左高=2，右高=2，BF=0

**旋转类型**：RL型（先右旋后左旋）

### (4) 插入结点13

**插入位置分析**：13 > 7，13 > 12，13 < 15，所以13插入为15的左子节点。

**插入后的AVL树**：
```
          7 (BF=-1)
         /   \

    /   \     /   \
```

**各节点平衡因子**：
- 节点3：BF=0
- 节点6：BF=0

- 节点15：左高=1，右高=0，BF=1

- 节点12：左高=1，右高=2，BF=-1

## 最终答案

- **(1)** 初始AVL树结构如上，各节点平衡因子：10(BF=1), 5(BF=0), 15(BF=0), 3(BF=0), 7(BF=0)
- **(2)** 插入6后需进行**LR型旋转**（先对节点5左旋，再对节点10右旋），旋转后根为7，各节点BF：7(0), 5(0), 10(-1), 3(0), 6(0), 15(0)

- **(4)** 插入13后**不需要旋转**，因为所有节点的平衡因子绝对值均不超过1，AVL树仍保持平衡
