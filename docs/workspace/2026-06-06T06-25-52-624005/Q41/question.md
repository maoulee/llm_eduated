## 题干

给定一个有向带权图 G = (V, E)，其中顶点集 V = {V0, V1, V2, V3, V4, V5}，边集 E 及对应权重如下表所示：

| 边 | 权重 |
|---|---|
| V0 → V1 | 1 |
| V0 → V2 | 4 |
| V0 → V3 | 3 |
| V1 → V2 | 2 |
| V1 → V3 | 3 |
| V2 → V4 | 1 |
| V3 → V4 | 2 |
| V4 → V5 | 1 |

以 V0 为源点，使用 Dijkstra 算法求单源最短路径。算法采用优先队列（最小堆）实现，初始时 dist[V0] = 0，其余顶点 dist 值为 ∞。当优先队列中弹出同一顶点多次时，仅处理第一次弹出的情况（即该顶点首次被确定最短距离）。

## 子问题

### (1)（6分）
算法执行完毕后，从源点 V0 到各顶点的最短路径长度 dist[V0] ~ dist[V5] 依次为多少？

### (2)（6分）
在 Dijkstra 算法执行过程中，当顶点 V1 被从优先队列中弹出并确定其最短距离后，此时各顶点的 dist 值（dist[V0], dist[V1], dist[V2], dist[V3], dist[V4], dist[V5]）依次为多少？（∞ 用 -1 表示）

### (3)（4分）
从源点 V0 到顶点 V5 的最短路径经过的顶点序列为（按从 V0 到 V5 的顺序列出）？

## 选项

### (1) 选项
- A: 0, 1, 3, 3, 4, 5
- B: 0, 1, 4, 3, 4, 5
- C: 0, 1, 3, 3, 5, 6
- D: 0, 1, 3, 4, 4, 5

### (2) 选项
- A: 0, 1, 3, 3, -1, -1
- B: 0, 1, 3, 4, -1, -1
- C: 0, 1, 4, 3, -1, -1
- D: 0, 1, 3, 3, 4, -1

### (3) 选项
- A: V0 → V1 → V2 → V4 → V5
- B: V0 → V3 → V4 → V5
- C: V0 → V1 → V3 → V4 → V5
- D: V0 → V2 → V4 → V5

## 设计说明

- **出题意图与知识点选取理由**：本题考察 Dijkstra 单源最短路径算法的完整执行过程，要求学生能够手动模拟算法的每一步状态变化。知识点覆盖：图的邻接表表示、Dijkstra 算法的贪心策略、优先队列的使用、最短路径的动态更新机制。

- **参数选择理由**：顶点数选 6 个（V0~V5），边权重选用 1~4 的简洁整数。图结构设计为存在多条路径到达同一顶点（如 V2 可通过 V0→V2 直接到达权重 4，也可通过 V0→V1→V2 到达权重 3），迫使算法进行松弛操作，体现 Dijkstra 的核心机制。

- **干扰项设计策略**：
  - (1) 选项 B 干扰：V2 取直接边权重 4 而非松弛后的 3，考察学生是否理解松弛操作。
  - (1) 选项 C 干扰：V4 和 V5 的值整体偏大，模拟学生漏掉某条松弛路径的错误。
  - (1) 选项 D 干扰：V3 取错误值 4，考察 V0→V3 直接边与 V0→V1→V3 路径的比较。
  - (2) 选项 B 干扰：V3 取 V0→V1→V3=4 而非 V0→V3=3，考察中间状态更新的准确性。
  - (2) 选项 C 干扰：V2 和 V3 的值互换，考察学生对邻接关系的理解。
  - (2) 选项 D 干扰：V4 在 V1 弹出时已被更新，考察学生对算法时序的理解（V4 此时不应被更新）。
  - (3) 选项 B 干扰：V0→V3→V4→V5 权重为 6，非最短路径。
  - (3) 选项 C 干扰：V0→V1→V3→V4→V5 权重为 7，非最短路径。
  - (3) 选项 D 干扰：V0→V2→V4→V5 权重为 6，非最短路径。

- **代码验证结果摘要**：
  - 参数封闭性：PASS（所有子问题所需参数均在题干中给出）
  - 推导路径等价性：PASS（V2 最短路径 3、V3 最短路径 3、V4 最短路径 4、V5 最短路径 5）
  - 整除性检查：PASS（所有边权重和最短路径长度均为整数）
  - Dijkstra 执行步骤数：6 步（>5 步，满足 K3 要求）
  - 最短路径结果一致性：PASS（所有顶点 dist 值与预期一致）

- **与契约 K 值的对齐说明**：
  - K1（基础认知）= 3：需准确记忆 Dijkstra 算法的核心定义和松弛操作规则。
  - K2（单步代入）= 2：计算为简单的加法比较，数字友好。
  - K3（机制推演）= 4：需串行执行 6 步算法过程，维持 dist 数组的动态状态更新。
  - K4（条件路由）= 3：需识别"同一顶点多次弹出仅处理第一次"的隐含条件。
  - K5（跨域联动）= 2：单一图算法系统内解决，无跨系统联动。
  - 综合 K 值：K3-K4 主导型，符合契约要求。
