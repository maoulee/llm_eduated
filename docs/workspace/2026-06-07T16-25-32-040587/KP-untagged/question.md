# AVL 树插入与旋转操作

## 题目

在平衡二叉树（AVL 树）中，定义节点 N 的平衡因子 BF(N) = h(左子树) − h(右子树)，其中空子树的高度为 0，叶节点的高度为 1。AVL 树要求所有节点的平衡因子绝对值不超过 1。当插入新节点导致某节点失衡时，需要从新节点出发沿父指针向上回溯，找到**最先失衡的节点**（即距离新节点最近的、平衡因子绝对值超过 1 的祖先节点），再根据失衡类型执行相应的旋转操作以恢复平衡。

已知一棵初始 AVL 树如下图所示：

```
        30
       /  \
      20   40
     /      \
    10       50
```

现依次插入两个关键字：先插入 15，完成旋转调整后再插入 45。每次插入后若发生失衡，立即执行旋转调整。

请回答下列问题：

### (1) (3分)

计算初始 AVL 树中各节点（10、20、30、40、50）的平衡因子，并验证该树是否满足 AVL 平衡条件。

### (2) (4分)

插入关键字 15 后：

- 画出插入后（旋转调整前）的树结构，标出所有节点的平衡因子。
- 指出最先失衡的节点，判断其失衡类型（LL / LR / RL / RR），并说明判断依据。
- 写出旋转操作的具体步骤（指出每一步涉及哪些节点、如何调整父子指针关系），并画出旋转后的树结构。

### (3) (4分)

在 (2) 调整后的 AVL 树基础上，继续插入关键字 45：

- 指出最先失衡的节点，判断其失衡类型（LL / LR / RL / RR），并说明判断依据。
- 写出旋转操作的具体步骤，并画出旋转后的最终树结构。

### (4) (3分)

下面是 AVL 树中处理 **RL 型失衡**的伪代码。节点结构包含三个字段：`key`（关键字）、`lchild`（左孩子指针）、`rchild`（右孩子指针）。设失衡节点为 A，A 的右孩子为 B，B 的左孩子为 C。根据 RL 旋转原理（先对 B 右旋，再对 A 左旋），填写空格 ①②③ 处应填写的表达式。

    函数 RL_Rotation(A):
        B = A.rchild
        C = ①
        // 第一步：对 B 进行右旋（C 上升，B 下降为 C 的右孩子）
        B.lchild = ②
        C.rchild = B
        A.rchild = C
        // 第二步：对 A 进行左旋（C 上升，A 下降为 C 的左孩子）
        A.rchild = ③
        C.lchild = A
        返回 C    // C 成为新的子树根

### 典型陷阱设计

1. **LL/LR/RL/RR 混淆**：插入 15 时新节点在左孩子的右子树（LR），插入 45 时新节点在右孩子的左子树（RL），两者均为双旋转但方向相反，极易混淆。
2. **"最先失衡节点"判定**：学生可能误认为距离根最近的失衡节点优先，实际应从新节点向上找最近的失衡祖先。
3. **伪代码指针方向**：空格 ②③ 分别为 C.rchild 和 C.lchild，学生易将两者搞反，反映对"哪棵子树迁移到哪一侧"的理解不足。

### 知识点选取理由

AVL 双旋转（LR/RL）是平衡二叉树的核心难点。单旋转（LL/RR）只需一次旋转，而双旋转需要两次旋转的协同配合，且涉及中间节点的子树迁移。选择 LR 和 RL 两种双旋转，全面覆盖了"先左后右"和"先右后左"两种模式。

### 参数选择理由

- 初始树关键字为 10、20、30、40、50（10 的倍数），便于心算和比较大小。
- 插入 15 落在 10 与 20 之间，自然成为 10 的右孩子，触发 LR 失衡。
- 插入 45 落在 40 与 50 之间，自然成为 50 的左孩子，触发 RL 失衡。
- 初始树仅 5 个节点，避免树规模过大干扰核心旋转逻辑的考察。
- 最终树恰好成为完美二叉树（30 为根，7 个节点），具有优美的结构。
