## 求解过程

### 子问题 (1)：初始 AVL 树各节点平衡因子及合法性验证

初始树结构：
```
        30
       /  \
      20   40
     /      \
    10       50
```

**高度计算：**

- 节点 10：叶节点，h(左)=0, h(右)=0
- 节点 20：左子树根 10（高 1），右子树空（高 0）
- 节点 30：左子树根 20（子树高 2），右子树根 40（子树高 2）
- 节点 40：左子树空（高 0），右子树根 50（高 1）
- 节点 50：叶节点，h(左)=0, h(右)=0

**平衡因子 BF(N) = h(左子树) − h(右子树)：**

| 节点 | h(左子树) | h(右子树) | BF |
|------|-----------|-----------|-----|
| 10   | 0         | 0         | 0   |
| 20   | 1         | 0         | 1   |
| 30   | 2         | 2         | 0   |
| 40   | 0         | 1         | −1  |
| 50   | 0         | 0         | 0   |

**验证：** 所有节点的 |BF| ≤ 1，满足 AVL 平衡条件。✓

### 子问题 (2)：插入 15 后的失衡判定与 LR 旋转

**插入 15 的 BST 插入路径：** 15 < 30 向左 → 15 < 20 向左 → 15 > 10 向右 → 15 成为节点 10 的右孩子。

**插入后（旋转前）的树结构：**
```
        30
       /  \
      20   40
     /      \
    10       50
      \
      15
```

**各节点平衡因子更新：**

| 节点 | h(左) | h(右) | BF  |
|------|-------|-------|-----|
| 15   | 0     | 0     | 0   |
| 10   | 0     | 1     | −1  |
| 20   | 2     | 0     | **2** |
| 30   | 3     | 2     | 1   |
| 40   | 0     | 1     | −1  |
| 50   | 0     | 0     | 0   |

**最先失衡节点判定：**

从新插入节点 15 沿父指针向上回溯：15 → 10 → 20 → 30。
- BF(15) = 0，未失衡。
- BF(10) = −1，未失衡。
- BF(20) = **2**，|BF| > 1，**最先失衡节点为 20**。

**失衡类型判定：**

- 失衡节点 A = 20，BF(A) = 2 > 0，说明**左子树更重**（新节点在左子树中）。
- A 的左孩子 B = 10，BF(B) = −1 < 0，说明新节点在 B 的**右子树**中。
- 失衡类型为 **LR 型**（新节点在左孩子的右子树中）。

**LR 旋转操作（先对 B 左旋，再对 A 右旋）：**

设 A = 20，B = 10（A 的左孩子），C = 15（B 的右孩子）。

**第一步：对 B（节点 10）左旋**
- C（15）上升，取代 B（10）的位置，成为 A（20）的左孩子。
- B（10）下降，成为 C（15）的左孩子。
- C 原来的左子树（空）变为 B 的右子树。

中间状态：
```
        30
       /  \
      20   40
     /      \
    15       50
   /
  10
```

**第二步：对 A（节点 20）右旋**
- C（15）上升，取代 A（20）的位置。
- A（20）下降，成为 C（15）的右孩子。
- C 原来的右子树（空）变为 A 的左子树。

**旋转后的树结构：**
```
        30
       /  \
      15   40
     / \    \
    10  20   50
```

**验证：** BF(10)=0, BF(20)=0, BF(15)=1−1=0, BF(50)=0, BF(40)=0−1=−1, BF(30)=2−2=0。所有 |BF| ≤ 1，恢复平衡。✓

### 子问题 (3)：在 (2) 基础上插入 45 的失衡判定与 RL 旋转

(2) 调整后的 AVL 树：
```
        30
       /  \
      15   40
     / \    \
    10  20   50
```

**插入 45 的 BST 插入路径：** 45 > 30 向右 → 45 > 40 向右 → 45 < 50 向左 → 45 成为节点 50 的左孩子。

**插入后（旋转前）的树结构：**
```
        30
       /  \
      15   40
     / \    \
    10  20   50
            /
           45
```

**各节点平衡因子更新：**

| 节点 | h(左) | h(右) | BF  |
|------|-------|-------|-----|
| 45   | 0     | 0     | 0   |
| 50   | 1     | 0     | 1   |
| 40   | 0     | 2     | **−2** |
| 10   | 0     | 0     | 0   |
| 20   | 0     | 0     | 0   |
| 15   | 1     | 1     | 0   |
| 30   | 2     | 3     | −1  |

**最先失衡节点判定：**

从新插入节点 45 沿父指针向上回溯：45 → 50 → 40 → 30。
- BF(45) = 0，未失衡。
- BF(50) = 1，未失衡。
- BF(40) = **−2**，|BF| > 1，**最先失衡节点为 40**。

**失衡类型判定：**

- 失衡节点 A = 40，BF(A) = −2 < 0，说明**右子树更重**（新节点在右子树中）。
- A 的右孩子 B = 50，BF(B) = 1 > 0，说明新节点在 B 的**左子树**中。
- 失衡类型为 **RL 型**（新节点在右孩子的左子树中）。

**RL 旋转操作（先对 B 右旋，再对 A 左旋）：**

设 A = 40，B = 50（A 的右孩子），C = 45（B 的左孩子）。

**第一步：对 B（节点 50）右旋**
- C（45）上升，取代 B（50）的位置，成为 A（40）的右孩子。
- B（50）下降，成为 C（45）的右孩子。
- C 原来的右子树（空）变为 B 的左子树。

中间状态：
```
        30
       /  \
      15   40
     / \    \
    10  20   45
              \
              50
```

**第二步：对 A（节点 40）左旋**
- C（45）上升，取代 A（40）的位置。
- A（40）下降，成为 C（45）的左孩子。
- C 原来的左子树（空）变为 A 的右子树。

**旋转后的最终树结构：**
```
        30
       /  \
      15   45
     / \   / \
    10  20 40  50
```

**验证：** 所有叶节点 BF = 0；BF(15) = 1−1 = 0；BF(45) = 1−1 = 0；BF(30) = 2−2 = 0。所有 |BF| ≤ 1，恢复平衡。✓

最终树为高度 3 的完美二叉树（7 个节点），所有叶节点位于同一层。

### 子问题 (4)：RL 型失衡伪代码填空

设失衡节点为 A，A 的右孩子为 B，B 的左孩子为 C。

RL 旋转 = 先对 B 右旋，再对 A 左旋。

**伪代码及填空：**

```
// 设置指针
C = ①B.lchild              // C 是 B 的左孩子

// 第一步：对 B 右旋（C 上升，B 下降为 C 的右孩子）
B.lchild = ②C.rchild       // B 的左孩子接收 C 的右子树
C.rchild = B

// 第二步：对 A 左旋（C 上升，A 下降为 C 的左孩子）
A.rchild = ③C.lchild       // A 的右孩子接收 C 的左子树
C.lchild = A
返回 C    // C 成为新的子树根
```

**填空答案：**
- **① = B.lchild**：C 是 B 的左孩子，需要先获取 C 的引用。
- **② = C.rchild**：右旋 B 时，C 上升取代 B 的位置，C 原来的右子树需要挂到 B 的左孩子位置（因为 B 成为 C 的右孩子后，B 左侧空出，C 的右子树中所有关键字 < B 的关键字但 > C 的关键字，应挂到 B 的左侧）。
- **③ = C.lchild**：左旋 A 时，C 上升取代 A 的位置，C 原来的左子树需要挂到 A 的右孩子位置（因为 A 成为 C 的左孩子后，A 右侧空出，C 的左子树中所有关键字 > A 的关键字但 < C 的关键字，应挂到 A 的右侧）。

**验证（以 (3) 中的实例对照）：** A=40, B=50, C=45。
- ① C = B.lchild → C = 50.lchild = 45 ✓
- ② B.lchild = C.rchild → 50.lchild = 45.rchild = null ✓（50 的左孩子变为空）
- C.rchild = B → 45.rchild = 50 ✓
- ③ A.rchild = C.lchild → 40.rchild = 45.lchild = null ✓（40 的右孩子变为空）
- C.lchild = A → 45.lchild = 40 ✓

结果：30 的右孩子 = 45，45 的左孩子 = 40，45 的右孩子 = 50，与 (3) 中旋转结果完全一致。✓

  ```
          30
         /  \
        15   45
       / \   / \
      10  20 40  50
  ```

- **(4)** 伪代码三空：
  - **① = B.lchild**
  - **② = C.rchild**
  - **③ = C.lchild**
