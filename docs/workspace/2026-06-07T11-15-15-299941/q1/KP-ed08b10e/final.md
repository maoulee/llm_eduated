## 题目
某系统采用FIFO页面置换算法，页面访问序列为1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5。当物理块数分别为3和4时，缺页次数分别是（）。

## 选项
A. 8和9
B. 9和10
C. 9和9
D. 10和11

## 求解过程

### 物理块数 = 3 时的模拟

| 步骤 | 访问页面 | 内存状态（按进入顺序） | 是否缺页 | 说明 |
|------|---------|---------------------|---------|------|
| 1 | 1 | [1] | ✓ 缺页 | 空块装入 |
| 2 | 2 | [1, 2] | ✓ 缺页 | 空块装入 |
| 3 | 3 | [1, 2, 3] | ✓ 缺页 | 空块装入，块满 |
| 4 | 4 | [2, 3, 4] | ✓ 缺页 | 置换最早进入的1 |
| 5 | 1 | [3, 4, 1] | ✓ 缺页 | 置换最早进入的2 |
| 6 | 2 | [4, 1, 2] | ✓ 缺页 | 置换最早进入的3 |
| 7 | 5 | [1, 2, 5] | ✓ 缺页 | 置换最早进入的4 |
| 8 | 1 | [1, 2, 5] | ✗ 命中 | 1已在内存中 |
| 9 | 2 | [1, 2, 5] | ✗ 命中 | 2已在内存中 |
| 10 | 3 | [2, 5, 3] | ✓ 缺页 | 置换最早进入的1 |
| 11 | 4 | [5, 3, 4] | ✓ 缺页 | 置换最早进入的2 |
| 12 | 5 | [5, 3, 4] | ✗ 命中 | 5已在内存中 |

**缺页次数 = 9**

### 物理块数 = 4 时的模拟

| 步骤 | 访问页面 | 内存状态（按进入顺序） | 是否缺页 | 说明 |
|------|---------|---------------------|---------|------|
| 1 | 1 | [1] | ✓ 缺页 | 空块装入 |
| 2 | 2 | [1, 2] | ✓ 缺页 | 空块装入 |
| 3 | 3 | [1, 2, 3] | ✓ 缺页 | 空块装入 |
| 4 | 4 | [1, 2, 3, 4] | ✓ 缺页 | 空块装入，块满 |
| 5 | 1 | [1, 2, 3, 4] | ✗ 命中 | 1已在内存中 |
| 6 | 2 | [1, 2, 3, 4] | ✗ 命中 | 2已在内存中 |
| 7 | 5 | [2, 3, 4, 5] | ✓ 缺页 | 置换最早进入的1 |
| 8 | 1 | [3, 4, 5, 1] | ✓ 缺页 | 置换最早进入的2 |
| 9 | 2 | [4, 5, 1, 2] | ✓ 缺页 | 置换最早进入的3 |
| 10 | 3 | [5, 1, 2, 3] | ✓ 缺页 | 置换最早进入的4 |
| 11 | 4 | [1, 2, 3, 4] | ✓ 缺页 | 置换最早进入的5 |
| 12 | 5 | [2, 3, 4, 5] | ✓ 缺页 | 置换最早进入的1 |

**缺页次数 = 10**

## 答案
**B. 9和10**

## 设计说明
- **考察模式**：算法模拟与性能对比
- **核心考点**：FIFO页面置换算法的队列置换逻辑，以及Belady异常现象（增加物理块数反而缺页次数增多）
- **干扰项设计**：A（8和9）针对漏算缺页；C（9和9）针对未理解Belady异常的直觉思维；D（10和11）针对将命中误判为缺页
- **难度对齐**：K3=4（12步完整模拟，需维持FIFO队列动态状态）；K4=4（Belady异常为反直觉陷阱，需深入理解FIFO机制才能正确路由）
