# 题目

某系统采用FIFO页面置换算法，页面访问序列为1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5。当物理块数分别为3和4时，缺页次数分别是（）。

A. 8和9
B. 9和10
C. 9和9
D. 10和11

---

## 设计说明

- **考察模式**：算法模拟与性能对比（来自蓝图recommended_mode）
- **选项风格**：数字结果（两个缺页次数的组合）
- **should_be对照**：
  - 本题通过具体页面访问序列模拟FIFO算法，考察考生对FIFO队列置换逻辑的掌握程度
  - 通过对比3块和4块两种配置下的缺页次数，考察考生对Belady异常现象的理解
  - 符合"算法模拟与性能对比"模式：需要走完完整的置换流程，并分析不同配置对性能的影响
- **should_not_be排查**：
  - 未将题目拆为多个子问题，只有一个题干+四个选项
  - 题干中无编程代码
  - 题干仅2句话，简洁直接
  - 无与考察无关的背景叙述
- **参数选择理由**：
  - 物理块数选3和4：3是经典小值便于模拟，4是3+1用于触发Belady异常对比
  - 页面访问序列1,2,3,4,1,2,5,1,2,3,4,5：共12个访问，长度适中；包含重复访问（1,2,3,4重复出现）和新增页面（5），能充分体现FIFO的队列特性；该序列是触发Belady异常的经典序列
  - 页面号1-5：小整数，便于心算追踪
- **干扰项设计策略**：
  - A（8和9）：两种配置都少算1次缺页，针对模拟过程中漏算某次置换的错误
  - C（9和9）：认为增加物理块数缺页次数不变，针对未理解Belady异常的常规思维（直觉上认为块数增加缺页应减少或不变）
  - D（10和11）：两种配置都多算1次缺页，针对将命中误判为缺页的错误
- **与契约K值的对齐说明**：
  - K3（机制推演）= 4：需对12步访问序列进行完整模拟，每步需判断是否在内存中、是否需要置换、置换哪个页面，需维持FIFO队列的动态状态更新，推演步数>5步
  - K4（条件路由）= 4：Belady异常是反直觉现象（增加物理块反而缺页增多），考生若仅凭直觉认为"块数越多缺页越少"会选C，必须深入理解FIFO的队列置换机制才能正确路由
  - K1（基础认知）= 3：需准确记忆FIFO算法的定义和置换规则
  - K2（单步代入）= 2：每步判断简单，无非2幂次复杂计算
  - K5（跨域联动）= 1：单一知识点内部解决
