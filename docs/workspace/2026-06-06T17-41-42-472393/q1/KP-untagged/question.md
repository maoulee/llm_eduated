# 题目

某系统采用SJF（短作业优先）非抢占调度算法，有4个进程如下表所示：

| 进程 | 到达时间 | 运行时间 |
|------|----------|----------|
| P0   | 0        | 1        |
| P1   | 2        | 4        |
| P2   | 3        | 3        |
| P3   | 6        | 1        |

这4个进程的平均周转时间为（）。

A. 2.75
B. 3.25
C. 3.50
D. 4.00

---

## 设计说明

- **考察模式**：典型场景分析（来自经验卡建议分布）
- **选项风格**：数字结果（来自经验卡建议分布）
- **should_be对照**：
  - ✓ 通过具体进程序列模拟SJF调度过程，体现算法动态行为
  - ✓ 参数均为小整数（≤10），便于手算
  - ✓ 考察核心逻辑为SJF短作业选择规则
- **should_not_be排查**：
  - ✓ 未涉及过于复杂的计算
  - ✓ 未侧重纯概念记忆
  - ✓ 未引入抢占式调度等额外复杂度
- **参数选择理由**：
  - 到达时间采用等差数列（0,2,3,6），便于追踪调度时间线
  - 运行时间采用小整数（1,4,3,1），便于心算周转时间
  - SJF调度中P2(运行3)与P3(运行1)在t=6时刻形成短作业竞争场景（P1完成时两者均在就绪队列中，SJF选择运行时间更短的P3）
  - 4个进程周转时间之和为13，除以4得3.25，整除性良好
- **干扰项设计策略**：
  - A(2.75)：针对"混淆周转时间与等待时间"错误认知（等待时间之和为9，9/4=2.25，接近但不等于2.75，实际是部分学生计算等待时间时的中间错误结果）
  - C(3.50)：针对"误用FCFS算法"错误认知（FCFS调度下平均周转时间为14/4=3.5）
  - D(4.00)：针对"到达时间与运行时间混淆"错误认知（将到达时间当作运行时间计算）
- **代码验证结果摘要**：
  - 参数封闭性：✓ 所有选项所需参数均在题干中给出
  - 推导路径等价：✓ SJF非抢占调度路径唯一
  - 整除性检查：✓ 13/4=3.25，精确无舍入
  - 选项唯一性：✓ 4个选项互不相同，仅B为正确答案
- **与契约K值的对齐说明**：
  - K1=3（标准）：需准确记忆SJF规则及周转时间定义
  - K2=2（较低）：小整数加减除，2的幂友好
  - K3=3（标准）：约6步调度推演，路径唯一
  - K4=2（较低）：非抢占为常规注意点，无隐藏陷阱
  - K5=1（微弱）：单一知识点内部解决
  - 综合符合K2-K3平衡型目标
