## 题目

已知一棵初始为空的AVL树（平衡二叉搜索树），依次插入以下关键字序列：10, 20, 30, 5, 15, 12, 25, 22, 30（最后一个30与已有节点重复，按BST规则不插入）。AVL树中每个节点的平衡因子定义为：左子树高度减去右子树高度。当某节点的平衡因子绝对值大于1时，需进行旋转操作恢复平衡。

AVL树插入操作的伪代码如下（部分代码缺失，用下划线标注）：

```
AVL_Insert(T, key):
    if T == NULL:
        T = new Node(key)
        return T
    if key < T.key:
        T.left = AVL_Insert(T.left, key)
    else if key > T.key:
        T.right = AVL_Insert(T.right, key)
    else:
        return T  // 重复关键字不插入
    
    update_height(T)
    balance_factor = get_balance(T)
    
    // LL型：左左旋转
    if balance_factor > 1 and key < T.left.key:
        return right_rotate(T)
    
    // RR型：右右旋转
    if balance_factor < -1 and key > T.right.key:
        return left_rotate(T)
    
    // LR型：左右旋转
    if balance_factor > 1 and key > T.left.key:
        T.left = left_rotate(T.left)
        return right_rotate(T)
    
    // RL型：右左旋转
    if balance_factor < -1 and key < T.right.key:
        T.right = right_rotate(T.right)
        return left_rotate(T)
    
    return T

right_rotate(y):
    x = y.left
    T3 = x.right
    x.right = y
    y.left = T3
    update_height(y)
    update_height(x)
    return x

left_rotate(x):
    y = x.right
    T2 = y.left
    y.left = x
    x.right = T2
    update_height(x)
    update_height(y)
    return y
```

请回答下列问题：

基于(1)中得到的AVL树，继续依次插入关键字5、15。画出插入15完成（含必要的旋转操作）后的AVL树结构，并列出此时树中所有非叶子节点的平衡因子值。

### (3) （3分）

基于(2)中得到的AVL树，继续插入关键字12、25、22。画出插入22完成（含必要的旋转操作）后的AVL树结构，并说明插入22过程中是否触发了旋转操作，若触发，指出失衡节点、旋转类型及旋转后的根节点关键字。

### (4) （3分）

基于(3)中得到的最终AVL树，完成以下任务：

## 求解过程

### 子问题(1)：插入10、20、30

1. **插入10**：树为空，10成为根节点。
2. **插入20**：20 > 10，插入到10的右子树。节点10的平衡因子 = 0 - 1 = -1，|bf| ≤ 1，无需旋转。
3. **插入30**：30 > 10，30 > 20，插入到20的右子树。节点10的平衡因子 = 0 - 2 = -2，|bf| > 1，失衡！

判断旋转类型：bf = -2 < -1，且 key=30 > T.right.key=20，属于**RR型**。

对节点10进行左旋（left_rotate）：
- y = 10.right = 20
- T2 = 20.left = NULL
- 20.left = 10
- 10.right = NULL

旋转后树结构：
```
    20
   /  \
  10   30
```

### 子问题(2)：继续插入5、15

基于(1)的结果，当前树为：
```
    20
   /  \
  10   30
```

1. **插入5**：5 < 20，5 < 10，插入到10的左子树。节点10：bf = 1 - 0 = 1，节点20：bf = 2 - 1 = 1，均无需旋转。
2. **插入15**：15 < 20，15 > 10，插入到10的右子树。节点10：bf = 1 - 1 = 0，节点20：bf = 2 - 1 = 1，均无需旋转。

插入15完成后树结构：
```
      20
     /  \
    10   30
   /  \
  5    15
```

### 子问题(3)：继续插入12、25、22

基于(2)的结果，当前树为：
```
    20
   /  \
  10   30
 /  \
5    15
```

1. **插入12**：12 < 20，12 > 10，12 < 15，插入到15的左子树。节点20：bf = 3 - 1 = 2，|bf| > 1，失衡！

判断旋转类型：bf = 2 > 1，且 key=12 > T.left.key=10，属于**LR型**。

LR旋转步骤：
- 先对T.left(10)做左旋：10和15交换位置，15成为新根，10成为15的左孩子，12成为10的右孩子
- 再对20做右旋：15成为新根，10成为15的左孩子，20成为15的右孩子

旋转后树结构：
```
      15
     /  \
    10   20
   /  \    \
  5   12    30
```

2. **插入25**：25 > 15，25 > 20，25 < 30，插入到30的左子树。节点20：bf = 0 - 2 = -2，|bf| > 1，失衡！

判断旋转类型：bf = -2 < -1，且 key=25 < T.right.key=30，属于**RL型**。

RL旋转步骤：
- 先对T.right(30)做右旋：25成为新根，30成为25的右孩子
- 再对20做左旋：25成为新根，20成为25的左孩子，30成为25的右孩子

旋转后树结构：
```
      15
     /  \
    10   25
   / \   /  \
  5  12 20   30
```

3. **插入22**：22 > 15，22 < 25，22 > 20，插入到20的右子树。节点20：bf = 0 - 1 = -1，节点25：bf = 2 - 1 = 1，节点15：bf = 2 - 3 = -1，均无需旋转。

插入22完成后树结构：
```
        15
       /  \
      10   25
     / \   / \
    5  12 20  30
           \
           22
```

**注意**：插入12时触发了LR旋转（失衡节点20），插入25时触发了RL旋转（失衡节点20），但插入22后所有节点平衡因子绝对值均≤1，无需旋转。

### 子问题(4)：最终AVL树分析

**树的高度**：根节点（15）所在层为第1层，逐层计算：
- 第1层：15
- 第2层：10, 25
- 第3层：5, 12, 20, 30
- 第4层：22

树的高度 = 4

**中序遍历序列**：对最终AVL树进行中序遍历（左→根→右）：
- 遍历左子树(10)：5 → 10 → 12
- 访问根：15
- 遍历右子树(25)：20 → 22 → 25 → 30

中序遍历序列：5, 10, 12, 15, 20, 22, 25, 30

**`update_height(T)` 函数实现**：
```
update_height(T):
    T.height = 1 + max(get_height(T.left), get_height(T.right))
```
其中 `get_height(node)` 返回节点高度（NULL节点高度为0）。

**AVL树旋转操作为何不会破坏BST有序性**：

旋转操作本质上是对局部子树进行重构，其核心原理保证了BST有序性不被破坏：

1. **右旋（right_rotate）分析**：
   - 旋转前：y为根，x为y的左孩子，T3为x的右孩子
   - 关系：x.key < y.key，且 T3中所有元素满足 x.key < T3.key < y.key
   - 旋转后：x成为新根，y成为x的右孩子，T3成为y的左孩子
   - 由于 T3.key 始终满足 x.key < T3.key < y.key，旋转后T3作为y的左孩子仍然满足 BST 性质

2. **左旋（left_rotate）分析**：与右旋对称，同理可证

3. **根本原因**：旋转操作只是重新排列了三个节点（x、y、T2/T3）之间的父子关系，而这三者之间的关键字大小关系在旋转前后始终保持不变。旋转不改变任何节点的关键字值，也不改变不在旋转范围内的子树结构，因此BST的有序性（左<根<右）得以保持。

## 答案

### (1)
- AVL树结构：
  ```
      20
     /  \
    10   30
  ```
- 根节点平衡因子：**0**
- 插入30后**需要**旋转，旋转类型为**RR型**，旋转中心节点为**10**

### (2)
- AVL树结构：
  ```
        20
       /  \
      10   30
     /  \
    5    15
  ```
- 非叶子节点平衡因子：节点20的bf = **1**，节点10的bf = **0**

### (3)
- AVL树结构：
  ```
          15
         /  \
        10   25
       / \   / \
      5  12 20  30
             \
             22
  ```
- 插入22过程中**未触发**旋转操作（但插入12时触发了LR旋转，插入25时触发了RL旋转）

### (4)
- 树的高度：**4**
- 中序遍历序列：**5, 10, 12, 15, 20, 22, 25, 30**
- `update_height(T)` 实现：
  ```
  update_height(T):
      T.height = 1 + max(get_height(T.left), get_height(T.right))
  ```
- 旋转不破坏BST有序性的原因：旋转仅重新排列局部三个节点（x、y、T2/T3）的父子关系，三者间的关键字大小关系保持不变，且旋转不改变任何节点的关键字值，因此BST的有序性（左<根<右）得以保持。
