## 求解过程

### 子问题(1)：插入10、20、30

**插入过程分析**：

1. **插入10**：树为空，10成为根节点。
   ```
   10 (h=1, bf=0)
   ```

2. **插入20**：20 > 10，插入到10的右子树。
   ```
   10 (h=2, bf=-1)
    \
     20 (h=1, bf=0)
   ```
   节点10的平衡因子 = 0 - 1 = -1，|bf| ≤ 1，无需旋转。

3. **插入30**：30 > 10，30 > 20，插入到20的右子树。
   ```
   10 (h=3, bf=-2) ← 失衡！
    \
     20 (h=2, bf=-1)
      \
       30 (h=1, bf=0)
   ```
   节点10的平衡因子 = 0 - 2 = -2，|bf| > 1，需要旋转。
   
   判断旋转类型：bf = -2 < -1，且 key=30 > T.right.key=20，属于**RR型**。
   
   对节点10进行右旋（left_rotate）：
   - y = 10.right = 20
   - T2 = 20.left = NULL
   - 20.left = 10
   - 10.right = NULL
   
   旋转后：
   ```
       20 (h=2, bf=0)
      /  \
     10   30
   (h=1) (h=1)
   ```

**答案**：
- AVL树结构：
  ```
      20
     /  \
    10   30
  ```
- 根节点（20）的平衡因子：**0**
- 插入30后**需要**旋转操作，旋转类型为**RR型**，旋转中心节点为**10**

### 子问题(2)：继续插入5、15

**插入过程分析**：

基于(1)的结果，当前树为：
```
    20
   /  \
  10   30
```

1. **插入5**：5 < 20，5 < 10，插入到10的左子树。
   ```
         20 (h=3, bf=1)
        /  \
       10   30
      /    (h=1)
     5 (h=1)
   ```
   节点10：bf = 1 - 0 = 1，|bf| ≤ 1
   节点20：bf = 2 - 1 = 1，|bf| ≤ 1
   无需旋转。

2. **插入15**：15 < 20，15 > 10，插入到10的右子树。
   ```
         20 (h=3, bf=1)
        /  \
       10   30
      /  \  (h=1)
     5    15
   (h=1)(h=1)
   ```
   节点10：bf = 1 - 1 = 0，|bf| ≤ 1
   节点20：bf = 2 - 1 = 1，|bf| ≤ 1
   无需旋转。

**答案**：
- 插入15完成后的AVL树结构：
  ```
        20
       /  \
      10   30
     /  \
    5    15
  ```
- 所有非叶子节点及其平衡因子：
  - 节点20：平衡因子 = **1**
  - 节点10：平衡因子 = **0**

### 子问题(3)：继续插入12、25、22

**插入过程分析**：

基于(2)的结果，当前树为：
```
      20
     /  \
    10   30
   /  \
  5    15
```

1. **插入12**：12 < 20，12 > 10，12 < 15，插入到15的左子树。
   
   插入后（旋转前）：
   ```
         20 (h=4, bf=2) ← 失衡！
        /  \
       10   30
      /  \  (h=1)
     5    15 (h=2, bf=1)
         /
        12 (h=1)
   ```
   节点10：bf = 1 - 2 = -1，|bf| ≤ 1
   节点20：bf = 3 - 1 = 2，|bf| > 1，失衡！
   
   判断旋转类型：bf = 2 > 1，且 key=12 > T.left.key=10，属于**LR型**。
   
   LR旋转步骤：
   - 先对T.left(10)做左旋：
     ```
     10         15
    /  \   →   /  \
   5    15    10   (空)
       /      /  \
      12     5    12
     ```
   - 再对20做右旋：
     ```
         20           15
        /  \         /  \
       15   30  →  10    20
      /          /  \     \
     10         5    12    30
    /  \
   5    12
     ```
   
   旋转后：
   ```
         15 (h=3, bf=0)
        /  \
       10   20 (h=2, bf=-1)
      / \    \
     5  12    30
   (h=1)(h=1)(h=1)
   ```

2. **插入25**：25 > 15，25 > 20，25 < 30，插入到30的左子树。
   
   插入后（旋转前）：
   ```
         15 (h=3, bf=0)
        /  \
       10   20 (h=3, bf=-2) ← 失衡！
      / \    \
     5  12    30 (h=2, bf=1)
            /
           25 (h=1)
   ```
   节点20：bf = 0 - 2 = -2，|bf| > 1，失衡！
   
   判断旋转类型：bf = -2 < -1，且 key=25 < T.right.key=30，属于**RL型**。
   
   RL旋转步骤：
   - 先对T.right(30)做右旋：
     ```
     30       25
    /    →     \
   25           30
     ```
   - 再对20做左旋：
     ```
         20           25
           \         /  \
            25  →  20    30
             \
              30
     ```
   
   旋转后：
   ```
         15 (h=3, bf=0)
        /  \
       10   25 (h=2, bf=0)
      / \   /  \
     5  12 20   30
   (h=1)(h=1)(h=1)(h=1)
   ```

3. **插入22**：22 > 15，22 < 25，22 > 20，插入到20的右子树。
   
   插入后：
   ```
           15 (h=4, bf=-1)
          /  \
         10   25 (h=3, bf=1)
        / \   /  \
       5  12 20   30
     (h=1)(h=1) \ (h=1)
                 22 (h=1)
   ```
   节点20：bf = 0 - 1 = -1，|bf| ≤ 1
   节点25：bf = 2 - 1 = 1，|bf| ≤ 1
   节点15：bf = 2 - 3 = -1，|bf| ≤ 1
   **无需旋转**。

**答案**：
- 插入22完成后的AVL树结构：
  ```
          15
         /  \
        10   25
       / \   / \
      5  12 20  30
             \
             22
  ```
- 插入22过程中**未触发**旋转操作。
  - 插入12时触发了LR旋转（失衡节点20）
  - 插入25时触发了RL旋转（失衡节点20）
  - 插入22后所有节点平衡因子绝对值均≤1，无需旋转

### 子问题(4)：最终AVL树分析

**树的高度**：

根节点（15）所在层为第1层，逐层计算：
- 第1层：15
- 第2层：10, 25
- 第3层：5, 12, 20, 30
- 第4层：22

树的高度 = **4**

**中序遍历序列**：

对最终AVL树进行中序遍历（左→根→右）：
- 遍历左子树(10)：5 → 10 → 12
- 访问根：15
- 遍历右子树(25)：20 → 22 → 25 → 30

中序遍历序列：**5, 10, 12, 15, 20, 22, 25, 30**

**`update_height(T)` 函数实现**：

```
update_height(T):
    T.height = 1 + max(get_height(T.left), get_height(T.right))
```

其中 `get_height(node)` 返回节点高度（NULL节点高度为0）。

**AVL树旋转操作为何不会破坏BST有序性**：

旋转操作本质上是对局部子树进行重构，其核心原理保证了BST有序性不被破坏：

1. **右旋（right_rotate）分析**：
   - 旋转前：y为根，x为y的左孩子，T3为x的右孩子
   - 关系：x.key < y.key，且 T3中所有元素满足 x.key < T3.key < y.key
   - 旋转后：x成为新根，y成为x的右孩子，T3成为y的左孩子
   - 验证：x的左子树 < x.key < x的右子树(y)，y的左子树(T3) < y.key < y的右子树
   - 由于 T3.key 始终满足 x.key < T3.key < y.key，旋转后T3作为y的左孩子仍然满足 BST 性质

2. **左旋（left_rotate）分析**：
   - 与右旋对称，同理可证

3. **根本原因**：旋转操作只是重新排列了三个节点（x、y、T2/T3）之间的父子关系，而这三者之间的关键字大小关系在旋转前后始终保持不变。旋转不改变任何节点的关键字值，也不改变不在旋转范围内的子树结构，因此BST的有序性（左<根<右）得以保持。
