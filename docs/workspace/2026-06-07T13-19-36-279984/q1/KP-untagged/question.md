# 408考研数据结构综合应用题

## 题目

已知一棵初始为空的AVL树（平衡二叉搜索树），依次插入以下关键字序列：10, 20, 30, 5, 15, 12, 25, 22, 30（最后一个30与已有节点重复，按BST规则不插入）。AVL树中每个节点的平衡因子定义为：左子树高度减去右子树高度。当某节点的平衡因子绝对值大于1时，需进行旋转操作恢复平衡。

AVL树插入操作的伪代码如下（部分代码缺失，用下划线标注）：

```
AVL_Insert(T, key):
    if T == NULL:
        T = new Node(key)
        return T
    if key < T.key:
        T.left = AVL_Insert(T.left, key)
    else if key > T.key:
        T.right = AVL_Insert(T.right, key)
    else:
        return T  // 重复关键字不插入
    
    update_height(T)
    balance_factor = get_balance(T)
    
    // LL型：左左旋转
    if balance_factor > 1 and key < T.left.key:
        return right_rotate(T)
    
    // RR型：右右旋转
    if balance_factor < -1 and key > T.right.key:
        return left_rotate(T)
    
    // LR型：左右旋转
    if balance_factor > 1 and key > T.left.key:
        T.left = left_rotate(T.left)
        return right_rotate(T)
    
    // RL型：右左旋转
    if balance_factor < -1 and key < T.right.key:
        T.right = right_rotate(T.right)
        return left_rotate(T)
    
    return T

right_rotate(y):
    x = y.left
    T3 = x.right
    x.right = y
    y.left = T3
    update_height(y)
    update_height(x)
    return x

left_rotate(x):
    y = x.right
    T2 = y.left
    y.left = x
    x.right = T2
    update_height(x)
    update_height(y)
    return y
```

请回答下列问题：

### (1) （3分）

依次插入关键字10、20、30后，画出此时的AVL树结构，并计算根节点的平衡因子。说明插入30后是否需要进行旋转操作，若需要，指出旋转类型及旋转中心节点。

### (2) （4分）

基于(1)中得到的AVL树，继续依次插入关键字5、15。画出插入15完成（含必要的旋转操作）后的AVL树结构，并列出此时树中所有非叶子节点的平衡因子值。

### (3) （3分）

基于(2)中得到的AVL树，继续插入关键字12、25、22。画出插入22完成（含必要的旋转操作）后的AVL树结构，并说明插入22过程中是否触发了旋转操作，若触发，指出失衡节点、旋转类型及旋转后的根节点关键字。

### (4) （3分）

基于(3)中得到的最终AVL树，完成以下任务：
- 计算该树的高度（根节点所在层为第1层），并给出该树的中序遍历序列。
- 补全上述伪代码中 `update_height(T)` 函数的实现（用伪代码描述，不超过3行）。
- 说明AVL树旋转操作为何不会破坏二叉搜索树的有序性。

### 知识点选取理由
- **AVL树平衡因子计算**：K3标准认知，需准确记忆平衡因子定义（左子树高度-右子树高度）
- **LL/RR/LR/RL四种旋转**：K4较高认知，需理解每种旋转的触发条件与指针调整规则
- **旋转后BST有序性保持**：K5跨域联动，需理解旋转操作本质是局部结构调整，不改变中序遍历结果
- **update_height函数实现**：考察对AVL树高度更新机制的理解，需知道节点高度 = max(左子树高度, 右子树高度) + 1
- **重复关键字处理**：隐含条件，BST中重复关键字不插入，考察细节把握

### 参数选择理由
- **关键字序列 10, 20, 30, 5, 15, 12, 25, 22**：精心设计的序列，确保触发多种旋转类型
  - 10, 20, 30 → 触发RR旋转（右子树过重）
  - 5, 15 → 插入后树保持平衡，无旋转触发
  - 12, 25, 22 → 触发RL旋转（右子节点的左子树过重）
- **重复30**：考察BST重复关键字处理规则，增加细节考察点
- **数值均为整数**：便于心算，符合2^n友好原则（虽非2的幂，但数值简单）

### 与契约 K 值的对齐说明
- **K1（基础认知）= 3**：必须准确记忆AVL树平衡因子定义、四种旋转类型的名称与触发条件、update_height函数逻辑，否则无法入题
- **K2（单步代入）= 2**：平衡因子计算为简单整数减法，数值友好，不易算错
- **K3（机制推演）= 4**：需按AVL插入规则走完多步流程（插入→更新平衡因子→向上检查→判定失衡→执行旋转→重新计算平衡因子），步数>5步，需维持动态状态更新
- **K4（条件路由）= 4**：存在多个隐含前提：①LR/RL旋转需双重旋转而非单次；②插入后需沿路径向上检查所有祖先节点；③重复关键字不插入；④旋转后需重新计算所有受影响节点的平衡因子；⑤update_height需考虑空子树高度为0
- **K5（跨域联动）= 3**：涉及"插入机制"、"旋转机制"、"代码实现"三个子系统的联动，插入触发旋转，旋转后需验证BST有序性，伪代码需与图形化过程对应

**综合K值评估：K4-K5深理解与应用型**，符合契约要求。
