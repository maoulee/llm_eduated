### 求解正确性 / 概念正确性
- A 项正确：DMA 传送开始前，CPU确实需要初始化 DMA 控制器，包括主存首地址、传送字数、传送方向等信息。
- B 项正确：DMA 方式下，数据传送主要由 DMA 控制器硬件完成，CPU不逐字执行数据搬运程序。
- C 项错误：周期挪用方式下，DMA 控制器通常只在需要传送一个数据单位时占用一个或若干总线周期，之后释放总线；“一直占用总线直到整个数据块传送结束”属于停止 CPU 访存或成组传送思路，不符合周期挪用定义。
- D 项正确：DMA 传送结束后，DMA 控制器通常通过中断请求通知 CPU 进行后续处理。

### 条件利用率
题干中的三个阶段均被选项覆盖：
- “传送开始前，CPU初始化”对应 A；
- “传送过程中，DMA控制器直接访问主存”对应 B、C；
- “传送结束后，DMA控制器通知CPU”对应 D。

无明显废弃条件。
