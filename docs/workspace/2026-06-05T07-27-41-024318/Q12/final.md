## 题目
某计算机主频为 2.0 GHz，程序 P 运行过程中共执行了 20000 条指令。其中，40% 的指令执行平均需 1 个时钟周期，40% 的指令执行平均需 2 个时钟周期，20% 的指令执行平均需 4 个时钟周期。程序 P 的平均 CPI 和 CPU 执行时间分别是（ ）。


## 解题过程
子问题(1): 计算平均 CPI 和 CPU 执行时间
  加权平均 CPI = 0.4×1 + 0.4×2 + 0.2×4
  加权平均 CPI = 0.4 + 0.8 + 0.8
  平均 CPI = 2.0
  总时钟周期 = 20000 × 2.0 = 40000.0
  主频 = 2.0 GHz = 2000000000.0 Hz
  CPU 执行时间 = 40000.0 / 2000000000.0 = 2e-05 秒
  CPU 执行时间 = 20.0 μs

  答案: CPI = 2.0, 执行时间 = 20.0 μs
  对应选项: C. 2.0，20 μs


## 答案
C
