## 题目

将关键字序列 **16, 3, 7, 11, 9, 26, 18** 依次插入初始为空的平衡二叉树（AVL树）。每次插入后若发生失衡，立即进行旋转调整。平衡因子定义为左子树高度减去右子树高度。请回答下列问题：

### (1)（3分）

依次插入关键字 16、3、7 后，AVL 树发生失衡。

① 写出插入 7 后（调整前）节点 16 的平衡因子；

② 指出应执行的旋转类型（LL / LR / RL / RR）；

③ 画出旋转调整后的 AVL 树。

### (2)（4分）

在 (1) 所得 AVL 树的基础上，继续依次插入关键字 11、9、26。其中插入 9 和插入 26 各引发一次旋转。

① 分别指出这两次旋转的类型；

② 画出插入 26 并完成调整后的 AVL 树。

### (3)（5分）

在 (2) 所得 AVL 树（如下所示）的基础上，插入关键字 18。

```
      11
     /  \
    7    16
   / \     \
  3   9    26
```

插入 18 后，节点 16 的右子树偏高导致失衡，需要进行 RL 旋转。设失衡节点为 A（A = 16），A 的右孩子为 B（B = 26），B 的左孩子为 C（C = 18）。下面是 RL 旋转的伪代码，请填写 ①～④ 处的指针赋值。

```
// RL旋转伪代码（A 为失衡节点，B = A->rchild，C = B->lchild）
// 第一步：对 B 进行右旋
B->lchild = ________①________;
C->rchild = ________②________;
// 第二步：对 A 进行左旋
A->rchild = ________③________;
C->lchild = ________④________;
// C 成为该子树新的根节点
```

### (4)（3分）

在 RL 旋转的两步操作中，C 的原始左子树和原始右子树分别被重新挂接到哪个节点上？请说明为什么这样挂接能保证旋转后的树仍满足二叉搜索树的性质。

## 设计说明

- **考察结构模式**：过程追踪与代码/伪代码实现混合
  - (1)(2) 为过程追踪：追踪 AVL 树插入过程中树结构变化与旋转判定
  - (3) 为代码/伪代码实现：RL 旋转伪代码填空
  - (4) 为深度分析：旋转后 BST 性质保持的原理阐释

- **子问依赖关系**

| 子问 | 分值 | 依赖 | 类型 | 考察内容 |
|------|------|------|------|----------|
| (1) | 3 | 无 | 过程追踪 | LR 旋转判定与结果 |
| (2) | 4 | (1) | 过程追踪 | LL + RR 两种旋转的连续追踪 |
| (3) | 5 | (2)（给出树状态） | 代码实现 | RL 旋转伪代码指针赋值 |
| (4) | 3 | (3) | 分析理解 | RL 旋转中子树重挂与 BST 性质 |

- **should_be 对照**
  - "AVL树插入后的失衡判定与LL/LR/RL/RR旋转操作" → 四种旋转类型全部覆盖：(1)LR、(2)LL+RR、(3)RL
  - "K4-K5深理解与应用型" → (3)伪代码需理解两层指针调整逻辑；(2)中 RR 旋转发生在根节点（非直观）；(4)需论证 BST 性质
  - "过程追踪与代码/伪代码实现混合" → (1)(2)过程追踪 + (3)伪代码实现 + (4)原理分析
  - "Hard难度" → 连续 5 次旋转追踪，K3≥4（多步动态状态维护）；RL 伪代码需理解非平凡的指针重挂顺序，K4≥4

- **should_not_be 排查**
  - 不涉及完整编程题干（仅伪代码填空，4 个空） ✓
  - 不涉及背景故事 ✓
  - 不涉及选项格式 ✓
  - 不偏离 AVL 旋转核心考点 ✓

- **知识点选取理由**：AVL 四种旋转全覆盖，RL 作为伪代码填空最难（涉及两层旋转的指针传递），考察深度最高。
- **参数选择理由**：插入序列 16,3,7,11,9,26,18 经过验证，恰好依次触发 LR→LL→RR→RL 四种旋转，且每次旋转的失衡节点不同（16→16→7→16），覆盖了根节点与非根节点的旋转场景。
- **K 值对齐说明**：K3=4（7 次插入+4 次旋转的连续追踪），K4=4（RR 发生在根节点的隐含判定 + RL 伪代码指针重挂顺序），整体符合 Hard 难度定位。
