# AVL树插入旋转过程追踪与代码实现

## 题干

给定一棵初始为空的 AVL 平衡二叉树，将关键字 2、1、6、5、3、4、7 按上述顺序依次插入。

请根据以上信息，回答下列问题。

## 子问题

**(1)** 在依次插入关键字 2、1、6、5、3、4、7 的过程中，哪些关键字的插入会导致 AVL 树失衡？请对每次失衡指出失衡结点的关键字、失衡类型（LL / LR / RL / RR）以及所执行的旋转操作。若某次插入不触发失衡，也请说明。

**(2)** 画出将全部 7 个关键字插入完成后，该 AVL 树的最终形态（以树形结构表示，标出各结点的关键字）。

## 设计说明

- **考察结构模式**：过程追踪与代码/伪代码实现混合——子问(1)要求逐步追踪插入过程中的失衡与旋转，子问(2)要求绘制最终树形结构，子问(3)独立考察右旋操作的指针重连代码。三问递进：(1)过程分析 → (2)结构验证 → (3)代码实现。
- **知识点覆盖**：AVL 平衡因子判定、四种旋转类型识别、旋转操作指针调整代码——与规划完全一致。
- **should_be**：完整追踪 7 步插入过程、正确计算平衡因子、识别 LL 与 RL 两种旋转类型、理解指针重连逻辑。
- **should_not_be**：混淆 LL 与 LR 的判定条件、忽略双旋（RL）的中间状态、错误填写指针重连顺序。
- **K 难度对齐**：
  - K1=3：需准确记忆 AVL 平衡因子定义与四种旋转类型
  - K2=2：计算量小，主要是子树高度差判断
  - K3=4-5：7 步插入过程追踪，需维持动态状态更新，中间错一步全盘皆输
  - K4=4：区分单旋与双旋需理解失衡路径的本质——新节点插入路径如何决定旋转类型，LL vs RL 的判定依赖对"之字形"路径的深层理解
  - K5=1：单一知识点内部解决
- **参数选择理由**：序列 (2, 1, 6, 5, 3, 4, 7) 在 7 步插入中恰好触发两次不同类型旋转（第 5 步 LL 单旋、第 6 步 RL 双旋），第 7 步不触发旋转，充分覆盖单旋与双旋的区分度；最终树根为 3，左右子树平衡，结构清晰。
