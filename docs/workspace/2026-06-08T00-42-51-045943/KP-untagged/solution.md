## 求解过程

### 子问题(1) — 逐步追踪插入过程中的失衡与旋转

**插入序列：2 → 1 → 6 → 5 → 3 → 4 → 7**

---

**第 1 步，插入 2：**
- 树中仅有根结点 2，高度 1，bf=0。
- **不触发失衡。**

**第 2 步，插入 1：**
- 1 < 2，成为 2 的左孩子。
- 结点 2：bf = 1（左子树高 1 − 右子树高 0），在允许范围内。
- **不触发失衡。**

**第 3 步，插入 6：**
- 6 > 2，成为 2 的右孩子。
- 结点 2：bf = 1 − 1 = 0，平衡。
- **不触发失衡。**

**第 4 步，插入 5：**
- 5 > 2，进入右子树；5 < 6，成为 6 的左孩子。
- 结点 6：bf = 1，平衡。结点 2：bf = 0 − 2 = −1，平衡。
- **不触发失衡。**

此时树的结构为：
```
        2
       / \
      1   6
         /
        5
```

**第 5 步，插入 3：**
- 3 > 2，进入右子树；3 < 6，进入 6 的左子树；3 < 5，成为 5 的左孩子。
- 结点 6：bf = height(左) − height(右) = 2 − 0 = **2 > 1**，**失衡！**
- 失衡路径：6 → 5 → 3，均在左子树的左子树方向，属于 **LL 型**。
- 执行 **右旋 rightRotate(6)**：以 5 为新的子树根，3 为 5 的左孩子，6 为 5 的右孩子。

旋转后该子树变为：
```
    5
   / \
  3   6
```

整棵树：
```
        2
       / \
      1   5
         / \
        3   6
```

**第 6 步，插入 4：**
- 4 > 3，进入右子树（3 的右侧）；4 < 5，进入左子树；4 > 3，成为 3 的右孩子。

插入 4 后树的结构为：
```
        2
       / \
      1   5
         / \
        3   6
         \
          4
```

- 结点 2：bf = height(左子树=1) − height(右子树=3) = **−2 < −1**，**失衡！**
- 失衡路径：2 → 5 → 3，新结点 4 在右子树（5）的左子树（3）的右子树上，属于 **RL 型**。
- 执行 **RL 双旋**：
  1. 先对结点 5 的左子树做**右旋 rightRotate(3)**：

     旋转前：3 的右孩子为 4
     ```
         3
          \
           4
     ```
     旋转后：4 为根，3 为 4 的左孩子
     ```
         4
        /
       3
     ```

     此时结点 5 的左孩子变为 4。

  2. 再对结点 2 做**左旋 leftRotate(2)**：
     - B = 2 的右孩子 = 5（此时 5 的左孩子已更新为 4）
     - 2 的右指针指向 5 的左子树（即以 4 为根的子树）
     - 5 的左指针指向 2
     - 结果：5 成为新的根，2 为 5 的左孩子，4 为 2 的右孩子

旋转后整棵树：
```
        3
       / \
      2   5
     /   / \
    1   4   6
```

**第 7 步，插入 7：**
- 7 > 3，进入右子树；7 > 5，进入右子树；7 > 6，成为 6 的右孩子。
- 各结点平衡因子：6 的 bf = −1，5 的 bf = −1，3 的 bf = −1，均在允许范围内。
- **不触发失衡。**

### 子问题(3) — 右旋代码填空

右旋操作的核心是三步指针重连，然后按从低到高的顺序更新高度：

```c
Node* rightRotate(Node *A) {
    Node *B = A->left;        // B 为 A 的左孩子

    ① A->left = B->right;     // A 的左指针接管 B 的右子树

    ② B->right = A;           // B 的右指针指向 A

    ③ updateHeight(A);         // 先更新较低结点 A 的高度（因其子树已变化）

    updateHeight(B);           // 再更新 B 的高度
    return B;                  // 返回新的子树根
}
```

**填空答案：**
- **①** `A->left = B->right;` —— 将 B 的右子树移交给 A 的左指针
- **②** `B->right = A;` —— B 的右指针指向 A，完成旋转
- **③** `updateHeight(A);` —— 先更新 A 的高度（A 是旋转后位置较低的结点，必须先更新，否则 B 的高度计算会出错）

## 最终答案

- **(1)** 共触发两次失衡：
  - **插入 3 时**：失衡结点为 **6**，类型 **LL**，执行 **右旋 rightRotate(6)**。
  - **插入 4 时**：失衡结点为 **2**，类型 **RL**，执行 **先右旋 rightRotate(3) 再左旋 leftRotate(2)** 的双旋操作。
  - 插入 2、1、6、5、7 时均不触发失衡。

- **(2)** 最终 AVL 树以 **3** 为根，左子树为 2（2 的左孩子为 1），右子树为 5（5 的左孩子为 4，右孩子为 6，6 的右孩子为 7）。

- **(3)**
  - ① `A->left = B->right;`
  - ② `B->right = A;`
  - ③ `updateHeight(A);`
