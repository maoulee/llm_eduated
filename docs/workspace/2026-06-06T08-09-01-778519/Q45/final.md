## 题目
某系统中有 5 个进程 P0～P4 和 3 类资源 A、B、C。各类资源的**总数量**为：

| 资源类型 | A | B | C |
|---------|---|---|---|
| 总数量   | 10 | 6 | 8 |

某时刻 T₀，系统中各进程的 **Maximum** 矩阵和 **Allocation** 矩阵如下所示：

| 进程 | Maximum (A, B, C) | Allocation (A, B, C) |
|------|-------------------|----------------------|
| P0   | 8, 5, 4           | 1, 1, 0              |
| P1   | 3, 2, 2           | 2, 0, 0              |
| P2   | 9, 0, 3           | 3, 0, 2              |
| P3   | 2, 2, 2           | 1, 1, 1              |
| P4   | 4, 3, 3           | 0, 0, 2              |

请回答以下问题。

ANSWER:
  (1) Need矩阵见上方; Available = [3, 4, 3]
  (2) 系统处于安全状态, 安全序列: P1 -> P3 -> P4 -> P2 -> P0

## 答案
**(1)** Need 矩阵为：

| 进程 | Need (A,B,C) |
|------|--------------|
| P0   | 7, 4, 4      |
| P1   | 1, 2, 2      |
| P2   | 6, 0, 1      |
| P3   | 1, 1, 1      |
| P4   | 4, 3, 1      |

Available 向量 = **(3, 4, 3)**

**(2)** 系统处于**安全状态**。一个安全序列为 **P1 → P3 → P4 → P2 → P0**。

**(3)** P0 的请求 Request₀ = (3, 4, 3) **不能批准**。判定过程：步骤 1（Request ≤ Need）通过 ✅；步骤 2（Request ≤ Available）通过 ✅；步骤 3（安全性检查）不通过 ❌——假装分配后 Available = (0,0,0)，无任何进程可完成，系统不安全。因此拒绝请求，P0 须等待。
