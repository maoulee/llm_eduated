## 求解过程

### 初始 AVL 树

```
          40
        /    \
       20     60
      /  \   /  \
    10   30 50   70
```

所有结点平衡因子均为 0。

---

### 插入关键字 25

25 < 40 → 左；25 > 20 → 右；25 < 30 → 左。插入为 30 的左孩子。

```
          40
        /    \
       20     60
      /  \   /  \
    10   30 50   70
        /
       25
```

检查平衡：结点 30 的 BF = 1−0 = 1，结点 20 的 BF = 1−2 = −1，结点 40 的 BF = 3−2 = 1。所有结点 |BF| ≤ 1，**无需旋转**。

---

### 子问题（1）：插入关键字 27 后的旋转类型

27 < 40 → 左；27 > 20 → 右；27 < 30 → 左；27 > 25 → 右。插入为 25 的右孩子。

插入前结点 30 的左子树高 2（结点 25）、右子树高 0，BF = 2 − 0 = **2**，已不平衡。

- 最小不平衡子树根为 **30**，其左孩子为 25。
- 新结点 27 插入在 30 的**左子树的右子树上**（即 25 的右孩子）。
- 符合 **LR 型**（左子树的右子树插入导致不平衡）。

执行 **LR 旋转**（先左后右双旋）：
1. 对结点 25 执行左旋：25 的右孩子 27 上提，25 成为 27 的左孩子。
2. 对结点 30 执行右旋：27 上提替代 30 的位置，30 成为 27 的右孩子。

旋转后以 27 为根的子树：

```
       27
      /  \
    25    30
```

**答案：B — LR 旋转（先左后右双旋）**

### 插入关键字 5

5 < 40 → 左；5 < 20 → 左；5 < 10 → 左。插入为 10 的左孩子。

```
          40
        /    \
       20     60
      /  \   /  \
    10   27 50  70
    /   /  \
   5  25   30
```

检查平衡：结点 10 的 BF = 1，结点 20 的 BF = 2−2 = 0，结点 40 的 BF = 3−2 = 1。**无需旋转**。

---

### 插入关键字 3

3 < 40 → 左；3 < 20 → 左；3 < 10 → 左；3 < 5 → 左。插入为 5 的左孩子。

插入后向上回溯更新平衡因子：
- 结点 5：BF = 1−0 = 1，正常。
- 结点 10：BF = 2−0 = **2**，不平衡！

最小不平衡子树根为 **10**，新结点 3 插入在 10 的**左子树的左子树上**（5 的左孩子），符合 **LL 型**。

执行 **LL 旋转**（右单旋）：对结点 10 执行右旋，5 上提替代 10 的位置，10 成为 5 的右孩子。

旋转后以 5 为根的子树：

```
       5
      / \
     3   10
```

---

### 子问题（2）：最终 AVL 树结构

```
            40
          /    \
         20     60
        /  \   /  \
       5   27 50  70
      / \  / \
     3  10 25 30
```

中序遍历验证 BST 性质：3, 5, 10, 20, 25, 27, 30, 40, 50, 60, 70 ✓

各结点平衡因子验证：
- 结点 3、10、25、30、50、70：BF = 0（叶子）
- 结点 5：BF = 1−1 = 0
- 结点 27：BF = 1−1 = 0
- 结点 20：BF = 2−2 = 0
- 结点 60：BF = 1−1 = 0
- 结点 40：BF = 3−2 = 1

所有 |BF| ≤ 1，树高度为 4，是有效的 AVL 树。

---

### 子问题（3）：关于最终 AVL 树的说法

- **A: 结点 20 的左子树与右子树高度相等** → 左子树（根 5）高度 = 2，右子树（根 27）高度 = 2。**正确** ✓
- **B: 最终 AVL 树的高度为 5** → 实际高度为 4。**错误** ✗
- **C: 根结点 40 的平衡因子为 0** → 实际 BF = 3−2 = 1。**错误** ✗
- **D: 关键字 5 所在结点是叶子结点** → 结点 5 有左孩子 3 和右孩子 10，是内部结点。**错误** ✗

**答案：A**
