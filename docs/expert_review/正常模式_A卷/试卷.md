### 4.

某计算机的主存与设备之间通过两种 I/O 控制方式传送数据，系统参数如下：

| 参数 | 含义 | 取值 |
|------|------|------|
| f | CPU 时钟频率 | 500 MHz |
| B | 待传送数据块大小 | 4 KB（4096 B） |
| u₁ | 中断方式每次中断传送量 | 4 B（一个 32 位存储字） |
| C_resp | 中断响应开销（保存/恢复 PC、PSW 等） | 30 个时钟周期 |
| C_isr | 中断服务程序执行开销（含数据搬运） | 200 个时钟周期 |
| u₂ | DMA 每次请求传送量 | 4 B（一个 32 位存储字） |
| C_pre | DMA 预处理开销（设置计数器、地址、模式等） | 100 个时钟周期 |
| C_post | DMA 后处理开销（中断通知、状态校验等） | 100 个时钟周期 |
| R | 设备数据传输速率 | 2 MB/s |

补充说明：

- 存储器存取周期为 1 个 CPU 时钟周期。在 DMA 周期挪用方式中，每次 DMA 传送需挪用（窃取）1 个存储周期，该周期内 CPU 不能访问主存（即损失 1 个时钟周期）。
- 中断方式中，设备每准备好 u₁ 字节数据即发出一次中断请求；CPU 响应中断并执行中断服务程序完成一次 u₁ 字节的传送。设备以速率 R 持续产生数据，假设两次中断请求之间的间隔远大于单次中断处理时间（C_resp + C_isr），即数据不会因 CPU 处理中断而丢失。
- DMA 方式中，设备以速率 R 持续产生数据，每准备好 u₂ 字节即向 DMAC 发出一次 DMA 请求，DMAC 通过周期挪用完成一次存储字传送。全部数据传送结束后，DMAC 向 CPU 发出中断信号进行后处理。DMA 预处理在数据传送开始前一次性完成。
- 本题不考虑总线仲裁延时和 DMA 初始化中 CPU 访存的时间。

### 第 1 问（4 分）

采用**中断方式**传送该 4 KB 数据块：

1. 中断请求共发生多少次？CPU 用于响应和执行中断服务的总开销是多少个时钟周期？折合多少微秒（μs）？
2. 该数据块的总传送时间是多少？（分别从"设备端产生数据"角度和"CPU 处理中断"角度分析，取较大者作为总传送时间的下限。）

### 第 2 问（4 分）

采用 **DMA 周期挪用方式**传送同一 4 KB 数据块：

1. DMA 传送共发生多少次周期挪用？DMA 预处理和后处理的总 CPU 开销是多少个时钟周期？
2. 该数据块的总传送时间是多少？此方式下 CPU 损失（被挪用）的总时钟周期数是多少？

### 第 3 问（2 分）

对比上述两种 I/O 方式：

1. 哪种方式的 CPU 时间开销更小？差异是多少（时钟周期）？
2. 简要说明：在本场景（大数据块、高速设备）下，为什么 DMA 周期挪用方式比中断方式更适合？
