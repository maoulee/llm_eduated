### 1.

**答案**：

（1）冯·诺依曼体系结构的主要特点（每条1分，答出4条即满分3分）：

- **指令和数据以同等地位存储在存储器中**，并按地址寻址访问。
- **存储程序**：程序（指令序列）预先存入存储器，机器运行时自动按序取出并执行，无需人工干预。
- **以运算器为中心**（早期）／现代以存储器为中心——指令和数据通过总线在存储器与各部件间传送。
- **指令由操作码和地址码组成**，操作码指明操作类型，地址码指明操作数位置。
- 采用**二进制**表示指令和数据。
- 机器以**串行方式**工作：取指→译码→执行，按指令计数器（PC）自动推进。

（2）CPU 由**运算器**和**控制器**两大部件组成（各1分）：

- **运算器（ALU）**：负责对数据进行算术运算和逻辑运算，核心是算术逻辑单元（ALU），还包括累加器（ACC）、通用寄存器、程序状态字（PSW）等。
- **控制器（CU）**：负责协调和控制计算机各部件按序执行指令，包括取指令、译码、产生控制信号等。核心组成有程序计数器（PC）、指令寄存器（IR）、指令译码器（ID）、时序发生器和微操作信号发生器等。

**解析要点**：
- 第（1）问关键得分点："存储程序"和"指令与数据同等地位存储"是最高频考点，漏答则失分。
- 第（2）问易错点：学生常将存储器或I/O设备误归入CPU。CPU 仅含运算器和控制器，存储器、总线、I/O接口不属于CPU。
- "存储程序"指程序预先存入存储器后自动执行，区别于早期手动接线编程；不要与"程序控制"混淆。

### 2.

**答案**：

（1）SRAM 与 DRAM 的区别（每方面约0.75分，共3分）：

| 比较项 | SRAM（静态随机存储器） | DRAM（动态随机存储器） |
|--------|----------------------|----------------------|
| **存储原理** | 利用**触发器**存储信息，只要不断电信息就不会丢失 | 利用**电容电荷**存储信息，电容会漏电，需定时刷新 |
| **是否需要刷新** | **不需要刷新** | **需要定时刷新**（通常2ms内刷新一次） |
| **读写速度** | **速度快**（存取时间短，ns级） | **速度较慢**（存取时间相对长） |
| **集成度与成本** | 集成度低、功耗较大、成本高 | 集成度高、功耗较低、成本低 |
| **典型用途** | 用于 **Cache**（高速缓存） | 用于 **主存**（内存条） |

（2）Cache 采用 SRAM 的原因：Cache 要求极高的访问速度以匹配 CPU 工作频率，SRAM 速度快、无需刷新，满足要求；尽管成本高、集成度低，但 Cache 容量小，可承受（1分）。

主存采用 DRAM 的原因：主存需要较大容量，DRAM 集成度高、成本低，单位面积存储容量大；虽然速度较慢且需刷新，但可通过 Cache 弥补速度差距（1分）。

**解析要点**：
- 核心区分：SRAM 基于触发器（不需刷新），DRAM 基于电容（需刷新）——这是最本质区别。
- 常见认知错误：误以为 SRAM 也需要刷新（混淆"静态"含义）；误以为 DRAM 用于Cache。
- 刷新方式：DRAM 有集中刷新、分散刷新、异步刷新三种方式，本题不展开。

### 3.

**答案**：

（1）CPU 响应中断的条件与中断响应的主要工作：

**响应中断的条件**（答出要点即得分，1.5分）：
- 中断源发出中断请求信号。
- CPU 允许中断（中断允许触发器 EINT = 1，即开中断状态）。
- 当前指令执行完毕（CPU 在每条指令执行结束后检测中断请求）。

**中断响应阶段（硬件自动完成）的主要工作**（1.5分）：
- **关中断**：防止在保存现场过程中被新的中断打断。
- **保存断点**：将 PC（程序计数器）和程序状态字（PSW）等内容压栈保存。
- **引出中断服务程序**：通过中断向量表（向量中断方式）或软件查询，将中断服务程序的入口地址装入 PC。

（2）中断处理（软件完成）的主要流程（2分）：

1. **保护现场**：将中断服务程序中要使用的通用寄存器内容压栈保存。
2. **中断服务（中断处理）**：执行具体的中断处理任务（如读取外设数据）。
3. **恢复现场**：将之前保存的寄存器内容出栈恢复。
4. **开中断**：重新允许中断响应（为返回后响应新的中断做准备）。
5. **中断返回**：执行中断返回指令（IRET），从栈中恢复断点（PC、PSW），返回被中断的程序继续执行。

**解析要点**：
- 中断响应（硬件完成）与中断处理（软件完成）是两个不同阶段，常考区分。
- 关键区分：中断响应阶段只保存断点（PC和PSW），保护现场是在中断处理阶段由软件完成。
- "关中断"在中断响应阶段自动完成；"开中断"在中断返回前由软件完成。

### 4.

**答案**：

（1）DMA 方式的基本工作原理与总线协调（3分）：

**基本工作原理**：DMA（直接存储器存取）方式是在**外设与主存之间开辟直接的数据通路**，由**DMA 控制器（DMAC）**接管总线控制权，控制数据在 I/O 设备与主存之间直接传送，整个数据传输过程不需要 CPU 干预。CPU 只需在传输开始时进行预处理（初始化DMAC），在传输结束时进行后处理（中断通知）。

**DMA 控制器与 CPU 的总线协调过程**：
1. 外设准备好数据后，向 DMA 控制器发送 DMA 请求（DREQ）。
2. DMA 控制器向 CPU 发送**总线请求（BR / HOLD）**，请求总线控制权。
3. CPU 在当前总线周期结束后，释放总线，发出**总线响应（BG / HLDA）**信号。
4. DMA 控制器获得总线控制权，开始控制数据传输。
5. 数据传输完成后，DMA 控制器向 CPU 发送中断信号，通知传输结束，CPU 收回总线控制权并进行后处理。

（2）周期挪用（周期窃取）的含义及作用（2分）：

**含义**：周期挪用（又称周期窃取）是指 DMA 控制器在 CPU 不使用存储器（或总线）的时钟周期内，"挪用"一个或几个存储周期来完成数据传输。当 CPU 和 DMA 控制器同时需要访问主存时，DMA 控制器优先占用一个存储周期进行数据传送，CPU 暂停一个周期（或延迟访问）。

**作用**：周期挪用使得 DMA 数据传输与 CPU 执行程序可以**并行进行**——CPU 不需要停止全部工作，只在被挪用周期内短暂等待，大幅减少了 DMA 对 CPU 工作的干扰，提高了系统整体效率。

**解析要点**：
- DMA 的核心特征：数据在 I/O 与主存之间**直接**传送，不经过 CPU 的寄存器中转。
- DMA 传输方式的三种类型：停止 CPU 访存、周期挪用（窃取）、DMA 与 CPU 交替访存。本题重点考察周期挪用。
- 常见认知错误：误以为 DMA 方式完全不需要 CPU 参与（CPU 参与预处理和后处理）；误以为周期挪用需要 CPU 停止全部工作。
- DMA 与中断方式的核心区别：中断方式每次传输需要 CPU 介入（保存/恢复现场开销大），DMA 方式由 DMAC 直接控制，CPU 仅在开始和结束时参与。

# DRAM 芯片扩展设计 — 参考解答

## 参数汇总

| 参数 | 值 |
|------|-----|
| CPU 地址总线宽度 | 18 位 |
| CPU 数据总线宽度 | 16 位 |
| 目标存储器容量 | 256K × 16 位 |
| DRAM 芯片规格 | 64K × 4 位 |
| 芯片行地址位数 | 8 位（256 行） |
| 刷新周期 | 2 ms |
| 刷新方式 | 异步刷新 |

---

## 问题 1：DRAM 芯片总数

**位扩展数**（满足数据位宽要求）：

$$\text{位扩展数} = \frac{\text{CPU 数据位宽}}{\text{芯片数据位宽}} = \frac{16}{4} = 4 \text{ 片}$$

每 4 片 64K×4 位芯片并联，数据线拼接为 16 位。

**字扩展组数**（满足地址容量要求）：

$$\text{字扩展组数} = \frac{\text{目标存储器字数}}{\text{芯片字数}} = \frac{256\text{K}}{64\text{K}} = 4 \text{ 组}$$

**芯片总数**：

$$\text{芯片总数} = \text{位扩展数} \times \text{字扩展组数} = 4 \times 4 = \boxed{16 \text{ 片}}$$

---

## 问题 2：地址线分配方案

**片内地址线位数**（芯片自身寻址所需）：

$$\text{片内地址线位数} = \log_2(64\text{K}) = \log_2(2^{16}) = 16 \text{ 位}$$

即低 16 位地址线 A₁₅～A₀ 用于片内寻址。

**片选地址线位数**（选择不同芯片组的高位地址线）：

$$\text{片选地址线位数} = \log_2(\text{字扩展组数}) = \log_2(4) = 2 \text{ 位}$$

即最高 2 位地址线 A₁₇、A₁₆ 用于片选。

**验证**：片内 16 位 + 片选 2 位 = 18 位 = CPU 地址总线宽度，恰好用满全部地址线。

**四组芯片地址范围**：

每组地址空间大小 = 64K = 0000H 个地址（16 位片内地址），四组依次排列：

| 组号 | 起始地址 | 结束地址 | 地址区间 |
|------|----------|----------|----------|
| 第 0 组 | 00000H | 0FFFFH | 00000H ～ 0FFFFH |
| 第 1 组 | 10000H | 1FFFFH | 10000H ～ 1FFFFH |
| 第 2 组 | 20000H | 2FFFFH | 20000H ～ 2FFFFH |
| 第 3 组 | 30000H | 3FFFFH | 30000H ～ 3FFFFH |

四组范围连续首尾衔接，覆盖 00000H～3FFFFH 全部 256K 地址空间，组间无间隙也无重叠。

---

## 问题 3：片选逻辑

使用最高 2 位地址线 **A₁₇、A₁₆** 作为片选信号（2 线译码产生 4 个片选信号 CS₀～CS₃）。低 16 位 A₁₅～A₀ 连接所有芯片的片内地址输入端。

各组选通条件如下：

| 组号 | 片选信号 | A₁₇ | A₁₆ | 选通条件 |
|------|----------|-----|-----|----------|
| 第 0 组 | CS₀ | 0 | 0 | A₁₇A₁₆ = 00 时选通 |
| 第 1 组 | CS₁ | 0 | 1 | A₁₇A₁₆ = 01 时选通 |
| 第 2 组 | CS₂ | 1 | 0 | A₁₇A₁₆ = 10 时选通 |
| 第 3 组 | CS₃ | 1 | 1 | A₁₇A₁₆ = 11 时选通 |

**文字描述**：当高位地址 A₁₇A₁₆ = 00 时选通第 0 组（CS₀ 有效），A₁₇A₁₆ = 01 时选通第 1 组（CS₁ 有效），A₁₇A₁₆ = 10 时选通第 2 组（CS₂ 有效），A₁₇A₁₆ = 11 时选通第 3 组（CS₃ 有效）。其余低位地址 A₁₅～A₀ 直接接入芯片的片内地址端。

---

## 问题 4：异步刷新参数

**芯片行数**：

$$\text{行数} = 2^{\text{行地址位数}} = 2^8 = 256 \text{ 行}$$

**刷新间隔**（异步刷新：刷新周期内均匀分配，每次刷新一行）：

$$\text{刷新间隔} = \frac{\text{刷新周期}}{\text{行数}} = \frac{2 \text{ ms}}{256} = \frac{2000 \text{ μs}}{256} = \boxed{7.8125 \text{ μs}}$$

即每隔 7.8125 μs 进行一次刷新操作。

**总刷新次数**：

$$\text{总刷新次数} = \text{行数} = \boxed{256 \text{ 次}}$$

一个刷新周期（2 ms）内需要刷新全部 256 行，共 256 次刷新操作。总刷新次数等于芯片行数，与位扩展数、字扩展组数、芯片总数无关（位扩展和字扩展不改变单片的行数，所有芯片按行同步刷新）。

## 常见错误辨析

| 错误类型 | 错误做法 | 错误结果 | 正确结果 |
|----------|----------|----------|----------|
| 忽略位扩展 | 只算字扩展，4 片 | 4 片 | 16 片 |
| 混淆刷新间隔与刷新周期 | 刷新间隔 = 刷新周期 = 2 ms | 2 ms | 7.8125 μs |
| 误将芯片总数当刷新次数 | 刷新次数 = 芯片总数 | 16 次 | 256 次 |
| 片选线位数算错（误认位扩展占片选线） | 片选线 = log₂(16) = 4 位 | 4 位 | 2 位 |
