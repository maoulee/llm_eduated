$$LOC(i,j) = LOC(0,0) + (j \times rows + i) \times elem\_size$$

代入参数：

$$LOC(3,4) = 200 + (4 \times 7 + 3) \times 4$$

$$= 200 + (28 + 3) \times 4$$

$$= 200 + 31 \times 4$$

$$= 200 + 124$$

| 选项 | 值 | 错误类型 | 计算过程 |

**各干扰项错误原因：**

- **B（336）**：误用行优先公式 $LOC(i,j) = LOC(0,0) + (i \times cols + j) \times elem\_size$，将行号乘以列数。列优先存储中，地址由"列号乘以行数"决定，因为同一列的元素在内存中连续存放。

- **C（292）**：将下标当作从 1 开始，实际用 j−1=3、i−1=2 代入列优先公式：200 + (3×7 + 2)×4 = 200 + 23×4 = 292。本题下标从 0 开始，无需减 1。

- **D（300）**：将列优先公式中的行列下标互换，即用 base + (i×rows + j)×elem_size，把行号当列号、列号当行号：200 + (3×7 + 4)×4 = 200 + 25×4 = 300。

## 问题 1（4 分）：逐轮选入顶点与 dist 值

### 初始状态

```
dist[V0]=0 | dist[V1]=∞ | dist[V2]=∞ | dist[V3]=∞ | dist[V4]=∞ | dist[V5]=∞
```

### 逐轮推演

**第1轮：选入 V0（dist[V0]=0）**

对 V0 的出边（V0→V1=10、V0→V2=4、V0→V3=15）进行松弛：

- dist[V1]：∞ > 0+10=10 → 更新为 10，prev[V1]=V0
- dist[V2]：∞ > 0+4=4 → 更新为 4，prev[V2]=V0
- dist[V3]：∞ > 0+15=15 → 更新为 15，prev[V3]=V0

松弛后 dist：

```
dist[V0]=0 | dist[V1]=10 | dist[V2]=4 | dist[V3]=15 | dist[V4]=∞ | dist[V5]=∞
```

**第2轮：选入 V2（dist[V2]=4，未收录中唯一最小）**

对 V2 的出边（V2→V1=3、V2→V3=2）进行松弛：

- dist[V1]：10 > 4+3=7 → 更新为 7，prev[V1]=V2
- dist[V3]：15 > 4+2=6 → 更新为 6，prev[V3]=V2

松弛后 dist：

```
dist[V0]=0 | dist[V1]=7 | dist[V2]=4 | dist[V3]=6 | dist[V4]=∞ | dist[V5]=∞

**第3轮：选入 V3（dist[V3]=6，未收录中唯一最小）**

```

| 回溯步骤 | 前驱关系 | 对应有向边 | 权值 |

| 第3步 | prev[V2] = V0 | V0 → V2 | 4 |

# 解答：删除单链表中所有值为 x 的结点（14 分）

## 第 (1) 问：结点类型定义（2 分）

```c
typedef struct LNode {

    struct LNode *next;    // 指针域，指向同类型后继结点
} LNode, *LinkList;       // 类型别名：LNode 为结点类型，LinkList 为指向结点的指针类型
```

> 说明：`data` 域为 `int` 类型，`next` 域指向 `struct LNode`（同类型结点）。定义了类型别名 `LNode` 和 `LinkList`，便于后续算法引用。

---

## 第 (2) 问：算法思想（4 分）

使用两个工作指针 **pre**（前驱指针）和 **cur**（当前指针）遍历链表，pre 始终指向 cur 的前驱。

**初始化**：pre = L（头结点），cur = L→next（首个数据结点）。

**遍历过程**（cur ≠ NULL 时循环）：

- **遇到 data == x 时**（删除与释放）：
  - 将 pre→next 指向 cur→next（摘链，跳过被删结点）；
  - 调用 `free(cur)` 释放被删结点的内存；
  - 令 cur = pre→next（cur 前进到下一个待检查结点，**pre 不动**）。
  - 关键：pre 不前进，保证连续命中 x 时不会漏删。

- **遇到 data ≠ x 时**（移动指针）：
  - pre = cur（前驱指针前进）；
  - cur = cur→next（当前指针前进）。

**边界情况处理**：

| 边界情形 | 处理方式 |
|---------|---------|
| 空表（L→next == NULL） | cur 初始为 NULL，循环不执行，直接返回 |
| 连续命中 | 删除后 pre 不前进，继续检查新 cur，保证连续 x 全部删除 |
| 尾结点命中 | 摘链后 pre→next = NULL，cur 变为 NULL，循环自然终止 |
| 全表均为 x | 所有数据结点被逐个删除，最终 L→next == NULL |
| 头结点 | 遍历起点为 L→next，头结点 L 始终保留，不会被删除 |

## 第 (3) 问：C/C++ 代码实现（8 分）

```c
void DeleteX(LNode *&L, int x) {
    LNode *pre = L;            // pre 指向头结点（前驱指针初始化）
    LNode *cur = L->next;      // cur 指向首个数据结点（遍历起点，不从头结点开始）

    while (cur != NULL) {              // 遍历链表直到末尾
        if (cur->data == x) {          // 当前结点命中目标值 x
            pre->next = cur->next;     // 摘链：前驱的 next 跳过 cur
            free(cur);                 // 释放被删除结点的内存空间
            cur = pre->next;           // cur 前进到下一结点，pre 保持不动（处理连续命中）
        } else {                       // 当前结点不命中
            pre = cur;                 // 前驱指针前进
            cur = cur->next;           // 当前指针前进
        }
    }
}
```

# 解答：求二叉树中所有叶子结点到根的路径

## 第 1 问（4 分）

### （1）二叉树结点的数据类型定义

```c
typedef struct BiTNode {
    int data;                       // 数据域，整型
    struct BiTNode *lchild, *rchild; // 左、右孩子指针
} BiTNode, *BiTree;
```

### （2）算法基本设计思想

采用**递归回溯（深度优先遍历）**，维护一个全局路径数组 `path`，在遍历过程中记录从根到当前结点的路径（根→叶方向积累）。

1. 从根结点出发，每访问一个结点就将其 `data` 追加到 `path` 末尾。
2. 判断当前结点是否为叶子（`lchild == NULL && rchild == NULL`）：
   - 若是叶子，则 `path` 中保存的是从根到该叶子的路径，**将其逆序**即得到题目要求的「叶子→根」方向路径，输出。
   - 若不是叶子，递归遍历其左、右子树。
3. **回溯**：从某个子树返回时，必须将 `path` 的末尾元素弹出（删除当前结点），保证遍历其他分支时 `path` 不含串入的错误结点。

**关键点**：自然递归遍历积累的路径是根→叶方向，而题目要求叶子→根方向，因此输出时需要逆序处理（反向打印或将路径数组逆序后输出）。

---

## 第 2 问（12 分）

```c
void printAllPaths(BiTree root) {
    int path[1000];     // 路径数组，足够大
    int len = 0;        // 当前路径长度
    dfs(root, path, &len);
}

void dfs(BiTree node, int path[], int *len) {
    if (node == NULL)
        return;

    // 当前结点加入路径（根→叶方向积累）
    path[*len] = node->data;
    (*len)++;

    if (node->lchild == NULL && node->rchild == NULL) {
        // 叶子结点：逆序输出 path（叶子→根方向）
        for (int i = *len - 1; i >= 0; i--) {
            printf("%d", path[i]);
            if (i > 0) printf(" ");
        }
        printf("\n");
    } else {
        // 非叶子：递归左右子树
        dfs(node->lchild, path, len);
        dfs(node->rchild, path, len);
    }

    // 回溯：弹出当前结点
    (*len)--;
}
```
