### 1.

### 正确方法（A）：符号位负权 + 其余位正权展开

机器数 **10101100**，按权展开（符号位权值为 −2⁷，其余按正权）：

$$= -1\times2^7 + 0\times2^6 + 1\times2^5 + 0\times2^4 + 1\times2^3 + 1\times2^2 + 0\times2^1 + 0\times2^0$$

$$= -128 + 0 + 32 + 0 + 8 + 4 + 0 + 0 = \mathbf{-84}$$

### 干扰项分析

**B = 44（忽略符号位，后 7 位按原码正数解释）**

将数值位（后 7 位）`0101100` 直接作为无符号正数：

$$0101100_2 = 0\times2^6 + 1\times2^5 + 0\times2^4 + 1\times2^3 + 1\times2^2 + 0\times2^1 + 0\times2^0 = 32 + 8 + 4 = 44$$

错误原因：忽略了符号位的负权重，把负数补码当成了无符号正数。

---

**C = −83（取反后忘记加一）**

对全部位取反：10101100 → 01010011，得正数：

$$01010011_2 = 64 + 16 + 2 + 1 = 83$$

取负但**不加 1**：−83

错误原因：补码还原负数应"取反加一"，此处漏掉了加 1 步骤（正确应为 −(83) − 1 = −84），因此偏差恰好为 1。

---

**D = 172（符号位按正权重展开）**

将符号位按 +2⁷ = +128 计算，其余位不变：

$$= +1\times2^7 + 0\times2^6 + 1\times2^5 + 0\times2^4 + 1\times2^3 + 1\times2^2 + 0\times2^1 + 0\times2^0$$

$$= 128 + 0 + 32 + 0 + 8 + 4 + 0 + 0 = 172$$

错误原因：将符号位的负权重 −128 误当成正权重 +128，结果比正确值大 256。

| 选项 | 数值 | 说明 |
|------|------|------|
| **A** | **−84** | **正确答案**：符号位 −2⁷，其余正权展开 |
| B | 44 | 忽略符号位，后 7 位当正数 |
| C | −83 | 取反忘加一 |
| D | 172 | 符号位按 +2⁷ 正权重 |

**正确答案为 A：−84。**

### 选项 B = 4097 FFFFH（对阶方向错误）

大阶向小阶对齐：将大阶操作数 A 左移 2 位（vA = 0x880000 << 2 = 0x2200000），小阶操作数 B 不变。

```
result = 0x2200000 + (−0xF00001) = 0x12FFFFF（25 位）
右规 1 位: mant = 0x97FFFF, exp = 1 + 1 = 2
结果 = 0 10000001 001 0111 1111 1111 1111 1111 = 4097 FFFFH
```

错误原因：对阶方向反了，应小阶向大阶（右移小阶操作数），而非左移大阶操作数。左移会丢失精度并改变结果。注意 B 的错误对阶路径恰好也得到 exp=2 的结果，但尾数为 0x97FFFF（比正确值的 0x980000 少 1），与正确选项差 1 ULP。

### 选项 C = 414C 0000H（跳过左规）

正确对阶、加减后得到 abs_result = 0x4BFFFF（23 位），但**未执行左规**：

```
mant = 0x4BFFFF（未左移），exp = 3（未减 1）
向偶舍入后 mant = 0x4C0000，exp_field = 3+127 = 130
结果 = 0 10000010 100 1100 0000 0000 0000 0000 = 414C 0000H
```

错误原因：加减后尾数出现前导零（23 位），必须左规使尾数恢复 24 位规格化形式。跳过左规导致阶码偏大 1、尾数值错误。

### 选项 D = 4097 FFFEH（截断舍入）

正确对阶、加减、左规，但左规时**不合并保护位**且**不向偶舍入**（直接截断移出位）：

```
左移后截断: mant = 0x4BFFFF << 1 = 0x97FFFE（不并入 G=1）
不执行舍入进位: mant 保持 0x97FFFE
结果 = 0 10000001 001 0111 1111 1111 1111 1110 = 4097 FFFEH
```

错误原因：左规时保护位 G=1 应移入尾数最低位（使其变为 0x97FFFF），随后向偶舍入在中点处因末位为奇而进位到 0x980000。截断路径丢弃了保护位信息，结果比正确值少 2（0x97FFFE vs 0x980000）。

### 3.

**答案**：C

**解析**：
- C 正确：采用进位判别法（也称变形补码法之外的判断方式），当符号位进位 C_s 与最高数值位进位 C_1 不同（即 C_s ⊕ C_1 = 1）时，说明发生了溢出。这是标准的进位判别法溢出判断准则。

- B 错误：双符号位判断中，01 表示**正溢出**（结果符号由正变负），10 表示**负溢出**（结果符号由负变正）。B 的方向记反了。
- D 错误：减法运算必须先求 [-B]_补（对减数求补），转化为加法后才能进行溢出判断，不能直接用原操作数符号位判断。

### 4.

### 正确解法（A 选项）

**按字节编址**：每个字节有一个唯一地址，因此存储单元数 = 字节数。

$$\text{存储单元数} = 2^{20}$$

**地址线位数** = log₂(存储单元数) = log₂(2²⁰) = **20**

**数据线位数** = 存储字长 = **32**

> 结论：A. 地址线 20 根，数据线 32 根

### 干扰项分析

| 选项 | 地址线 | 数据线 | 错误类型 | 说明 |
|------|--------|--------|----------|------|
| **A** | 20 | 32 | ✅ 正确 | 按字节编址，地址线 = log₂(2²⁰) = 20；数据线 = 32 |
| **B** | 32 | 20 | 地址线与数据线互换 | 将正确结果中的 20 与 32 交换 |
| **C** | 18 | 32 | 编址单位错误（按字编址） | 误按字编址：2²⁰ 字节 ÷ 4 字节/字 = 2¹⁸ 字 → 地址线 18 根，数据线不变 |
| **D** | 10 | 32 | 容量单位换算错误（M→K） | 误将 1M 当作 1K = 2¹⁰ → 地址线 10 根，数据线不变 |

- **B 错**：地址线与数据线含义混淆。地址线位数取决于存储单元数量，数据线位数取决于存储字长，二者不可互换。
- **C 错**：题干明确"按字节编址"，不应按字编址计算。按字编址会把存储单元数从 2²⁰ 降到 2¹⁸，导致地址线位数错误。
- **D 错**：1M = 2²⁰，不是 2¹⁰。1K = 2¹⁰，容量单位混淆导致地址线位数错误。

**A. 地址线 20 根，数据线 32 根**


### 5.

**答案**：B

**解析**：
- B 正确：DRAM 每位用 1 个电容+1 个晶体管（1T1C），集成度高、成本低，但需刷新、速度较慢，广泛用于主存。SRAM 用触发器（6个晶体管/位），集成度低、速度快、不需刷新，常用于 Cache。

- D 错误：SRAM 每位存储单元所用元件数（约6个晶体管）比 DRAM（1个晶体管+1个电容）**多**，因此 SRAM 集成度更低、成本更高。D 说反了。

### 7.

**第 2 级（一地址指令）最大指令条数**的计算：

$$\text{第 2 级最大条数} = 2^{\text{新增位数}} - \text{预留前缀数}$$

其中：
- **新增位数 = 6**：第 2 级操作码 10 位中，高 4 位已固定为第 1 级预留的前缀 `1111`，实际新增的操作码只有低 6 位，因此可用编码数为 $2^6 = 64$。
- **预留前缀数 = 1**：第 2 级是中间级（不是末级），必须预留 1 个编码前缀（即 `1111 111111`）用于向第 3 级（零地址指令）扩展。

因此：

$$\text{第 2 级最大条数} = 2^6 - 1 = 64 - 1 = \boxed{63}$$

**A. 63**

### 10.

### 1. 确定时钟周期

各段时间不等，时钟周期取最大值：

$$\Delta t = \max(2,\,3,\,5,\,4) = 5 \text{ ns}$$

### 2. 计算总执行时间

n 条指令通过 k 段流水线，总执行时间为：

$$T = (k + n - 1) \times \Delta t = (4 + 50 - 1) \times 5 = 53 \times 5 = 265 \text{ ns}$$

### 3. 计算吞吐率

$$TP = \frac{n}{T} = \frac{50}{265} = \frac{10}{53} \approx 0.1887 \text{ 条/ns}$$

**A. 10/53 条/ns（≈ 0.1887 条/ns）**

**答案**：C

**解析**：

# 求解过程：CPI 与 MIPS 计算

## 第1问：加权平均 CPI（3分）

**公式：** CPI = Σ(C_i × P_i) / 100

**计算：**

$$CPI = \frac{1×10 + 2×25 + 4×35 + 5×30}{100} = \frac{350}{100} = 3.5$$

> **错误路径 E1（百分比未换算）：** 直接用整数百分比求和 = 1×10 + 2×25 + 4×35 + 5×30 = 350（未除以100），结果为 350，与正确值 3.5 明显不同。

**✅ 答：加权平均 CPI = 3.5**

---

## 第2问：MIPS（2分）

**公式：** MIPS = f_MHz / CPI

**主频单位换算：**

$$f = 2.8 \text{ GHz} = 2.8 × 1000 = 2800 \text{ MHz}$$

**计算：**

$$MIPS = \frac{f_{MHz}}{CPI} = \frac{2800}{3.5} = 800$$

> **错误路径 E2（公式方向记反）：** MIPS = CPI / f_MHz = 3.5 / 2800 = 0.00125，与正确值 800 明显不同。
>
> **错误路径 E3（主频单位混淆，GHz 当 MHz 用）：** MIPS = f_GHz / CPI = 2.8 / 3.5 = 0.8，与正确值 800 明显不同。

**✅ 答：MIPS = 800**

## 第3问：执行时间（1分）

**公式：** T = N × CPI / f（f 以 Hz 为单位）

**主频换算为 Hz：**

$$f = 2.8 \text{ GHz} = 2{,}800{,}000{,}000 \text{ Hz}$$

### 1.

# Cache 映射地址字段位数推导 — 解答

## 参数汇总

| 参数 | 取值 | 换算 |
|------|------|------|
| 主存容量 | 256 MB | 256 × 1024 × 1024 = 2²⁸ B |
| Cache 容量 | 128 KB | 128 × 1024 = 2¹⁷ B |
| Cache 块（行）大小 | 64 B | 2⁶ B |
| 组相联路数 | 4 路 | 4 = 2² |

---

## 第 1 问（3 分）

### 主存地址总位数

$$\text{主存地址总位数} = \log_2(\text{主存容量}) = \log_2(2^{28}) = \boxed{28 \text{ 位}}$$

依据：256 MB = 2²⁸ B，每个字节需要一个唯一地址，故地址总线宽度为 28 位。

### 块内偏移位数

$$\text{块内偏移位数} = \log_2(\text{块大小}) = \log_2(2^{6}) = \boxed{6 \text{ 位}}$$

依据：每个 Cache 块 64 B = 2⁶ B，需要 6 位来表示块内某字节的偏移位置。

---

## 第 2 问（3 分）— 直接映射

直接映射下，主存地址分为三段：**Tag | 行号 | 块内偏移**。

### Cache 行号（行索引）位数

Cache 行数 = Cache 容量 / 块大小 = 2¹⁷ / 2⁶ = 2¹¹ = 2048 行

$$\text{行号位数} = \log_2(2048) = \log_2(2^{11}) = \boxed{11 \text{ 位}}$$

### Tag（标记）位数

$$\text{Tag 位数} = \text{主存地址总位数} - \text{行号位数} - \text{块内偏移位数} = 28 - 11 - 6 = \boxed{11 \text{ 位}}$$

**地址划分（直接映射）：**

| Tag | 行号 | 块内偏移 |
|-----|------|----------|
| 11 位 | 11 位 | 6 位 |

验证：11 + 11 + 6 = 28 ✓

---

## 第 3 问（4 分）— 4 路组相联映射

4 路组相联下，主存地址分为三段：**Tag | 组号 | 块内偏移**。

### 组数与 Cache 行数、路数的关系

$$\text{组数} = \frac{\text{Cache 行数}}{\text{路数}} = \frac{2048}{4} = 512 = 2^{9}$$

### 组号（组索引）位数

$$\text{组号位数} = \log_2(512) = \log_2(2^{9}) = \boxed{9 \text{ 位}}$$

### Tag（标记）位数

$$\text{Tag 位数} = \text{主存地址总位数} - \text{组号位数} - \text{块内偏移位数} = 28 - 9 - 6 = \boxed{13 \text{ 位}}$$

**地址划分（4 路组相联）：**

| Tag | 组号 | 块内偏移 |
|-----|------|----------|
| 13 位 | 9 位 | 6 位 |

验证：13 + 9 + 6 = 28 ✓

### 与直接映射对比（Tag 位数差异）

| 字段 | 直接映射 | 4 路组相联 |
|------|----------|------------|
| Tag | 11 位 | 13 位 |
| 行号/组号 | 11 位（行号） | 9 位（组号） |
| 块内偏移 | 6 位 | 6 位 |
| 合计 | 28 位 | 28 位 |

**差异分析：**

$$\text{Tag 位数差} = 13 - 11 = \boxed{2 \text{ 位}}$$

组相联的组号位数（9 位）比直接映射的行号位数（11 位）少了 $\log_2(4) = 2$ 位（因为每 4 行合并为一组），这部分减少的索引位数转移到 Tag 上，使组相联的 Tag 比 直接映射多 2 位。

### 子问1（5 分）：操作控制字段格式设计

采用字段直接编码法，每个互斥类对应一个独立字段。每个字段需编码 nᵢ 个微命令 + 1 个"不发微命令"状态 = nᵢ+1 种状态，因此字段位数 = ⌈log₂(nᵢ+1)⌉。

| 字段 | 对应互斥组 | 命令数 n | 需编码状态数 (n+1) | 字段位数 ⌈log₂(n+1)⌉ |
|------|-----------|---------|-------------------|---------------------|
| F1 | 第1组 ALU运算控制（ADD、SUB、AND、OR） | 4 | 5 | 3 |
| F2 | 第2组 移位控制（SHL、SHR、SAR） | 3 | 4 | 2 |
| F3 | 第3组 存储器控制（MAR_in、MDR_in、MDR_out、READ、WRITE） | 5 | 6 | 3 |
| F4 | 第4组 寄存器输出控制（R0_out~SP_out） | 6 | 7 | 3 |
| F5 | 第5组 寄存器输入控制（R0_in、R1_in） | 2 | 3 | 2 |

**位数计算依据**：
- 第1组 n=4：⌈log₂(4+1)⌉ = ⌈log₂5⌉ = 3 位
- 第2组 n=3：⌈log₂(3+1)⌉ = ⌈log₂4⌉ = 2 位
- 第3组 n=5：⌈log₂(5+1)⌉ = ⌈log₂6⌉ = 3 位
- 第4组 n=6：⌈log₂(6+1)⌉ = ⌈log₂7⌉ = 3 位
- 第5组 n=2：⌈log₂(2+1)⌉ = ⌈log₂3⌉ = 2 位

> **关键陷阱**：第1组 n=4=2²、第5组 n=2=2¹，均为 2 的幂。若忘记预留"不发微命令"状态，会误算为 ⌈log₂n⌉，分别得到 2 位和 1 位（各少 1 位）。

**操作控制字段总位数 = 3 + 2 + 3 + 3 + 2 = 13 位**
