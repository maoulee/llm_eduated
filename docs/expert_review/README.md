# 出题审核包（6 套）

两组：**正常模式（方案C，知识点自由）** 3 套 + **考点对齐（Entry D，逐题锚定原卷知识点）** 3 套。

## 一、正常模式（方案C）— 3 套
正常出题，知识点自由分配（不锚定原卷）。审**一般质量**（题干/答案/解析/难度）。
- `正常模式_A卷/`（计算机组成原理 期末A卷 · 100分）：试卷.md + 答案解析.md
- `正常模式_合肥师范/`（合肥师范 · 100分）：试卷.md + 答案解析.md
- `正常模式_皖西/`（皖西学院 · 100分）：试卷.md + 答案解析.md

## 二、考点对齐（Entry D）— 3 套
每题知识点 **1-to-1 锚定原卷对应题**，考察方式（考法/角度）可换不同切面，题干全新产出。
**审知识点对齐**：用 `考点对照.md`（逐题：题号｜题型｜原卷知识点claim｜考法｜新题题干摘要）对照 `原卷_参考.md` 核验每题知识点是否一致。
- `考点对齐_计组1卷/`（参考 计算机组成原理1卷，28题，0题型错位）
- `考点对齐_计算机组成原理A卷/`（参考 计算机组成原理A卷，20题，0题型错位）
- `考点对齐_试卷A卷/`（参考 试卷A卷_计算机组成原理，12题，0题型错位）

每套含：试卷.md + 答案解析.md（+ 考点对齐套另有 考点对照.md + 原卷_参考.md）。

## 备注
- 三套考点对齐卷均 0 缺失 0 题型错位（concept_creator 题型感知修复后）。
- 正常模式三套为之前生成（方案C），知识点自由。
