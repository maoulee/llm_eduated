# 数据结构期末试卷 — 知识点组合方案

基于皖西学院期末A卷结构（选择题10×2分 + 应用题4×10分 + 算法分析2×5分 + 算法设计2题30分 = 100分），生成以下3套知识点组合方案。

---

## 方案C — 均衡覆盖

**设计理念**：各知识域均匀分布，覆盖线性表、栈队列、串、树、图、查找、排序七大模块，适合全面考查。

**一、选择题（10题×2分=20分）**

**第1题（选择题·2分·难度：中）**：算法评价
- [ ] 给定代码片段分析时间复杂度（循环/递归）
- [ ] 空间复杂度分析（递归调用栈/辅助数组）

**第2题（选择题·2分·难度：中）**：线性表
- [ ] 顺序表与链表在特定操作上的性能对比
- [ ] 循环链表尾指针操作的O(1)特性

**第3题（选择题·2分·难度：中）**：栈的应用
- [ ] 中缀表达式转后缀表达式的栈操作过程
- [ ] 递归调用过程中栈帧的保存顺序

**第4题（选择题·2分·难度：中）**：队列
- [ ] 循环队列元素个数计算公式
- [ ] 链队列入队/出队操作的指针变化

**第5题（选择题·2分·难度：中）**：二叉树
- [ ] 线索二叉树的前驱/后继查找
- [ ] 二叉树层序遍历的队列辅助过程

**第6题（选择题·2分·难度：中）**：树与森林
- [ ] 树的先根/后根遍历与二叉树遍历的对应关系
- [ ] 森林转换为二叉树的规则

**第7题（选择题·2分·难度：中）**：图
- [ ] 邻接矩阵求顶点度的方法
- [ ] 拓扑排序的入度为零顶点选择

**第8题（选择题·2分·难度：中）**：查找
- [ ] 分块查找的索引表构建与ASL计算
- [ ] 散列函数构造方法（除留余数法/数字分析法）的选择

**第9题（选择题·2分·难度：中）**：排序
- [ ] 基数排序的LSD/MSD过程与桶分配
- [ ] 外部排序的归并段生成与败者树

**第10题（选择题·2分·难度：中）**：综合辨析
- [ ] 多种数据结构的适用场景匹配（如表达式求值用栈、BFS用队列等）
- [ ] 数据结构操作的时间复杂度综合对比

**二、应用题（4题×10分=40分）**

**第1题（应用题·10分·难度：中）**：二叉树遍历与线索化
- [ ] 给定先序+中序序列还原二叉树，写出后序序列并画出中序线索二叉树
- [ ] 给定二叉树，进行中序线索化并找出指定结点的前驱/后继

**第2题（应用题·10分·难度：中）**：拓扑排序与关键路径
- [ ] 给定AOV网，写出所有可能的拓扑序列
- [ ] 给定AOE网，计算事件最早/最迟发生时间并找出关键路径

**第3题（应用题·10分·难度：中）**：折半查找与判定树
- [ ] 给定有序表画出折半查找判定树，计算查找成功/失败ASL
- [ ] 给定查找序列，模拟折半查找过程并统计比较次数

**第4题（应用题·10分·难度：中）**：排序过程
- [ ] 快速排序：写出每一趟划分结果，分析最好/最坏情况
- [ ] 堆排序：画出初始堆并写出输出第一个元素后的堆调整结果

**三、算法分析题（2题×5分=10分）**

**第1题（算法分析·5分·难度：中）**：栈应用
- [ ] 括号匹配算法的代码填空（含多种括号类型）
- [ ] 表达式求值中运算符优先级比较的代码填空

**第2题（算法分析·5分·难度：中）**：树操作
- [ ] 求二叉树高度的递归函数填空
- [ ] 复制二叉树的递归函数填空

**四、算法设计题（2题=30分）**

**第1题（算法设计·14分·难度：中高）**：链表算法
- [ ] 判断单链表是否存在环（快慢指针法）
- [ ] 单链表按值分区（小于x的结点在前，大于等于x的在后）

**第2题（算法设计·16分·难度：中高）**：图算法
- [ ] 求有向图中所有顶点的出度并找出出度最大的顶点
- [ ] 用DFS判断无向图是否存在环
