# 数据结构期末卷 — 知识点组合方案

> 基于皖西学院数据结构期末A卷结构（选择题10×2 + 应用题4×10 + 算法分析2×5 + 算法设计14+16 = 100分）

## 方案A — 侧重线性结构与树

**设计理念**：前半卷聚焦线性结构（链表、栈队列、串）与树（二叉树、哈夫曼、BST），后半卷覆盖图与排序，难度梯度从概念→计算→设计递进。

**第1题（选择题·2分·难度：低）**：线性表 — 顺序表vs链表的插入删除复杂度对比
- [ ] 给定操作场景（有序/无序、头部/中部/尾部），判断顺序表与链表各自的时间复杂度
- [ ] 对比顺序表与链表在随机访问、插入、删除三种操作上的优劣（概念辨析）

**第2题（选择题·2分·难度：低）**：栈与队列 — 操作特性与应用场景辨析
- [ ] 栈和队列在插入删除位置、适用场景上的对比（概念辨析）
- [ ] 给定应用场景（函数调用/打印队列/浏览器前进后退），判断应使用栈还是队列

**第3题（选择题·2分·难度：低）**：栈的应用 — 表达式求值中的栈操作
- [ ] 中缀表达式转后缀表达式过程中栈的变化（概念辨析）
- [ ] 括号匹配问题中栈的状态变化判断

**第4题（选择题·2分·难度：中）**：KMP模式匹配 — next数组计算
- [ ] 给定模式串，计算next数组或nextval数组的值（需多步推算）
- [ ] 给定主串和模式串，计算KMP匹配过程中的字符比较次数（需多步推演）

**第5题（选择题·2分·难度：中）**：完全二叉树 — 结点编号与性质计算
- [ ] 给定完全二叉树结点数，计算叶结点个数/高度/某层结点数（需公式推导）
- [ ] 给定结点编号，推算其双亲/孩子编号及树的总高度

**第6题（选择题·2分·难度：低）**：哈夫曼树 — 性质辨析
- [ ] 哈夫曼树的性质判断（无度1结点、WPL最小、叶子分布等）
- [ ] 给定权值集合，判断哈夫曼树的高度/WPL/结点总数

**第7题（选择题·2分·难度：中）**：最小生成树 — Prim/Kruskal算法选择与结果判断
- [ ] 给定图的边权集合，判断最小生成树的边集或总权值（需多步推演）
- [ ] 对比Prim和Kruskal算法的适用场景与时间复杂度

**第8题（选择题·2分·难度：低）**：最短路径算法 — Dijkstra/BFS适用场景辨析
- [ ] 带权/无权图中单源最短路径算法的选择（概念辨析）
- [ ] Dijkstra算法的贪心策略与适用条件判断

**第9题（选择题·2分·难度：中）**：哈希表 — 线性探测冲突处理与ASL计算
- [ ] 给定关键字序列和哈希函数，模拟线性探测过程并计算查找失败ASL（需多步推演）
- [ ] 哈希表装填因子与冲突概率的关系（概念辨析）

**第10题（选择题·2分·难度：中）**：快速排序 — 第一趟划分结果判断
- [ ] 给定关键字序列，判断快速排序第一趟划分后的序列（需模拟partition过程）
- [ ] 快速排序递归深度与初始序列有序性的关系

**第11题（应用题·10分·难度：中）**：二叉树遍历序列还原
- [ ] 给定先序+中序遍历序列，还原二叉树结构（文字描述各结点位置关系），写出后序和层序遍历序列
- [ ] 给定后序+中序遍历序列，还原二叉树并计算树的高度与叶结点个数

**第12题（应用题·10分·难度：中）**：图的遍历 — DFS/BFS序列与生成树
- [ ] 给定图的邻接矩阵/邻接表，写出从指定顶点开始的DFS和BFS遍历序列，并描述生成树的边集
- [ ] 给定图的邻接关系，判断DFS/BFS遍历序列的合法性

**第13题（应用题·10分·难度：中）**：折半查找 — 判定树与ASL计算
- [ ] 给定有序表，写出折半查找判定树的文字描述（各层结点），计算查找成功/失败的ASL
- [ ] 给定有序表和查找目标，写出折半查找的比较序列与比较次数

**第14题（应用题·10分·难度：中）**：排序算法 — 堆排序与归并排序过程推演
- [ ] 给定关键字序列，写出堆排序建堆过程和每一趟排序结果，以及归并排序每一趟结果
- [ ] 对比堆排序与归并排序的时间/空间复杂度与稳定性

**第15题（算法分析题·5分·难度：低）**：链表操作 — 代码填空
- [ ] 单链表插入/删除操作的指针修改顺序填空
- [ ] 循环链表判空/判满条件的代码补全

**第16题（算法分析题·5分·难度：低）**：二叉树递归算法 — 功能分析
- [ ] 二叉树遍历/求深度/结点计数的递归算法填空并简述功能
- [ ] 线索二叉树找前驱/后继的代码补全

**第17题（算法设计题·14分·难度：中）**：链表 — 双指针法查找倒数第k个结点
- [ ] 带头结点单链表，不改变链表结构，设计算法查找倒数第k个结点（双指针法）
- [ ] 单链表逆序输出的算法设计（递归或栈辅助）

**第18题（算法设计题·16分·难度：中高）**：二叉树 — WPL计算或BST操作
- [ ] 二叉链表存储的二叉树，设计递归算法计算带权路径长度WPL
- [ ] 二叉排序树的插入/删除操作算法设计
