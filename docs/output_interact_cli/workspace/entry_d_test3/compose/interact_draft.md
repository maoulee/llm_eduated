# 往年期末卷参考 — 知识点方案草案

已分析原卷结构：**选择题 10×2=20 分 + 应用题 4×10=40 分 + 算法分析题 2×5=10 分 + 算法设计题 14+16=30 分 = 100 分**。
每题的题型、分值、期望形式、K 值难度档已锚定原卷，知识点自由设计（同题型内不重复）。

以下给出 **3 套知识点排布方案**，请教师选择一套（可微调单题知识点）。

## 方案A — 侧重线性结构与树（基础扎实型）

> 设计理念：选择题覆盖线性表/栈队列/串/树/图/查找/排序核心概念；应用题聚焦二叉树遍历还原、图遍历、折半查找、排序推演；算法题考察链表操作与树递归。适合基础中等偏上的班级。

**第1题（选择题·2分·难度：低）**：单链表/顺序表操作复杂度
- [ ] 链表插入/删除的时间复杂度分析
- [ ] 顺序表插入/删除的元素移动次数计算
- [ ] 链表与顺序表操作复杂度对比

**第2题（选择题·2分·难度：低）**：栈与队列的概念辨析
- [ ] 栈和队列的共同点/区别（操作位置、进出原则）
- [ ] 栈/队列的存储结构特点（顺序vs链式）
- [ ] 双端队列的输入输出受限特性

**第3题（选择题·2分·难度：低）**：栈/队列的应用场景
- [ ] 栈的应用（括号匹配、表达式求值、递归）
- [ ] 队列的应用（打印任务、BFS、缓冲区）
- [ ] 栈与队列综合应用判断

**第4题（选择题·2分·难度：中）**：KMP 模式匹配 next 数组与比较次数
- [ ] next 数组的手工计算
- [ ] KMP 匹配过程中的字符比较次数
- [ ] nextval 数组的计算

**第5题（选择题·2分·难度：低）**：二叉树性质与编号计算
- [ ] 完全二叉树结点编号关系（父子编号）
- [ ] 二叉树结点层次/高度计算
- [ ] 满二叉树/完全二叉树的结点总数性质

**第6题（选择题·2分·难度：中）**：哈夫曼树性质与 WPL 计算
- [ ] 哈夫曼树的性质判断（度数、结点总数、叶子分布）
- [ ] 给定权值构造哈夫曼树并计算 WPL
- [ ] 哈夫曼编码的前缀性质

**第7题（选择题·2分·难度：中）**：最小生成树（Prim/Kruskal）
- [ ] 给定带权图选择正确的最小生成树边集
- [ ] Prim 算法的逐步选择过程
- [ ] Kruskal 算法的边排序与并查集判断

**第8题（选择题·2分·难度：低）**：最短路径算法识别
- [ ] Dijkstra 算法的适用场景（单源最短路径）
- [ ] BFS 与 Dijkstra 的区别（无权vs带权）
- [ ] Floyd 算法（多源最短路径）的特点

**第9题（选择题·2分·难度：中）**：哈希表冲突处理
- [ ] 线性探测法的冲突解决过程
- [ ] 拉链法的链地址管理
- [ ] 装填因子与查找性能的关系

**第10题（选择题·2分·难度：中）**：快速排序第一趟划分
- [ ] 给定序列的快速排序第一趟 partition 结果
- [ ] 冒泡排序第一趟的结果
- [ ] 直接插入排序第一趟的结果

**第11题（应用题·10分·难度：中）**：二叉树遍历序列还原与转化
- *期望形式*：题干给先序+中序遍历序列，要求画出二叉树、写出层序序列、画出转化的森林
- [ ] 由先序+中序还原二叉树 → 层序遍历 → 森林转化
- [ ] 由后序+中序还原二叉树 → 先序遍历 → 森林转化
- [ ] 由层序+中序还原二叉树 → 后序遍历 → 线索二叉树

**第12题（应用题·10分·难度：中）**：图的遍历生成树
- *期望形式*：题干给邻接矩阵，要求画出 DFS 生成树和 BFS 生成树
- [ ] 给定邻接矩阵 → DFS 生成树 + BFS 生成树
- [ ] 给定邻接表 → DFS 遍历序列 + BFS 遍历序列
- [ ] 给定邻接矩阵 → DFS/BFS 生成森林（非连通图）

**第13题（应用题·10分·难度：中）**：折半查找判定树与查找过程
- *期望形式*：题干给有序表，要求画判定树、写出查找特定元素的比较序列
- [ ] 折半查找判定树绘制 + 成功/失败查找的比较序列
- [ ] 折半查找成功 ASL 计算 + 判定树
- [ ] 分块查找的索引表构建 + 查找过程

**第14题（应用题·10分·难度：中）**：排序算法推演与对比
- *期望形式*：题干给关键字序列，要求堆排序建堆、归并排序逐趟结果、复杂度对比
- [ ] 堆排序（建堆+排序）+ 归并排序逐趟 + 复杂度对比
- [ ] 快速排序逐趟划分 + 直接插入排序逐趟 + 稳定性对比
- [ ] 堆排序建堆过程 + 简单选择排序逐趟 + 时间复杂度对比

**第15题（算法分析题·5分·难度：中）**：代码填空 — 链表/栈操作
- *期望形式*：题干给一段不完整的代码（如链栈出栈、链表删除），要求填入正确语句
- [ ] 链栈 Pop 操作的代码填空
- [ ] 单链表删除第 i 个结点的代码填空
- [ ] 循环队列入队/出队的代码填空

**第16题（算法分析题·5分·难度：中）**：代码填空 + 功能分析 — 树递归
- *期望形式*：题干给二叉树递归函数（如求深度、结点计数），要求填空并简述功能
- [ ] 二叉树深度计算的递归填空 + 功能描述
- [ ] 二叉树结点总数统计的递归填空 + 功能描述
- [ ] 二叉树叶子结点计数的递归填空 + 功能描述

**第17题（算法设计题·14分·难度：中高）**：链表算法设计
- *期望形式*：题干给链表场景，要求定义类型、描述思想、编写代码（如倒数第 k 个结点、链表合并）
- [ ] 查找链表倒数第 k 个结点（双指针法）
- [ ] 单链表逆置（头插法/三指针法）
- [ ] 两个有序链表合并为一个有序链表

**第18题（算法设计题·16分·难度：中高）**：树算法设计
- *期望形式*：题干给二叉树场景，要求定义类型、描述思想、编写代码（如 WPL 计算、结点查找）
- [ ] 二叉树 WPL 计算（递归/层序）
- [ ] 二叉树中查找值为 x 的结点并输出路径
- [ ] 判断二叉树是否为平衡二叉树
