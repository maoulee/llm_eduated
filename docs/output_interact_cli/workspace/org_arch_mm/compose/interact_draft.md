# 计算机组成原理期末试卷 — 方案选择

> 基于往年卷结构（简答4×5 + 计算3×10 + 分析2×10 + 设计2×15 = 100分），生成3套知识点组合方案。

## 方案A — 侧重运算体系与存储层次

**设计理念**：强化浮点运算、Cache/TLB地址映射、流水线性能分析，适合侧重计算能力的考核。

**第1题（简答题·5分·难度：2）**：浮点数表示
- [ ] IEEE 754 单精度浮点数格式解析（给定十六进制机器码，写出符号/阶码/尾数各字段值）
- [ ] 浮点数规格化规则与机器零概念辨析
- [ ] 浮点数舍入方法比较（恒置1法、0舍1入法）

**第2题（简答题·5分·难度：2）**：定点数表示与溢出
- [ ] 原码/补码/反码/移码的相互转换规则
- [ ] 补码加减运算溢出判断方法（双符号位 vs 单符号位）
- [ ] 定点数表示范围与机器零的概念

**第3题（简答题·5分·难度：2）**：总线系统
- [ ] 总线分类（数据总线/地址总线/控制总线）及其功能
- [ ] 总线仲裁方式比较（集中式 vs 分布式）
- [ ] 总线带宽计算与传输周期概念

**第4题（简答题·5分·难度：2）**：存储层次结构
- [ ] 存储层次（Cache-主存-辅存）的局部性原理
- [ ] Cache 与主存的透明性概念
- [ ] 虚拟存储器的基本思想

**第5题（计算题·10分·难度：3）**：浮点数加减运算
- [ ] 给定两个十进制小数，按 IEEE 754 单精度格式完成对阶→尾数运算→规格化→舍入全过程
- [ ] 浮点数加减运算中溢出判断与下溢处理

**第6题（计算题·10分·难度：3）**：定点除法运算
- [ ] 用补码不恢复余数法（加减交替法）计算定点除法，写出逐步过程
- [ ] 除法运算中的溢出条件与商的范围限制

**第7题（计算题·10分·难度：3）**：TLB地址映射
- [ ] 给定虚拟地址位数、页面大小、TLB路数与容量，计算 TLB 的标记字段/索引字段/页内偏移字段位数
- [ ] TLB 命中/未命中时的地址翻译过程分析

**第8题（分析题·10分·难度：3）**：流水线性能分析
- [ ] 给定多级流水线各阶段延迟，计算处理 N 个数据项的总时间、加速比与效率
- [ ] 流水线冒险类型（结构/数据/控制）识别与解决策略分析

**第9题（分析题·10分·难度：3）**：中断优先级与屏蔽
- [ ] 给定多级中断的屏蔽字配置，分析实际响应优先级顺序
- [ ] 中断嵌套执行过程分析（保护现场→中断服务→恢复现场）

**第10题（设计题·15分·难度：4）**：ALU 数据通路与指令执行
- [ ] 描述简单 ALU 数据通路的组件连接关系（文字描述：寄存器组、ALU、多路选择器、总线）
- [ ] 给定 5 条指令（LDA/STA/ADD/SUB/JMP），写出每条指令的取指→译码→执行→写回各阶段微操作序列
- [ ] 写出各指令的控制信号表

**第11题（设计题·15分·难度：4）**：微程序控制器设计
- [ ] 描述微程序控制器的组件构成与数据流（文字描述：控制存储器、微指令寄存器、微地址寄存器）
- [ ] 设计微指令格式（操作控制字段编码方式 + 下址字段形成方式）
- [ ] 写出 ADD 指令的微程序流程（微指令序列）并给出微地址分配表
