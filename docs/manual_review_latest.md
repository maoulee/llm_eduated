某多核处理器系统采用两级存储层次结构：一级Cache（L1）和主存（DRAM）。L1 Cache参数如下：容量为64KB，行大小为64字节，直接映射（Direct Mapped），缺失替换策略为LRU。主存采用低位交叉编址的多模块结构，共有4个存储模块，每个模块独立工作。总线支持突发传输（Burst Transfer），每次缺失时，从主存加载一个完整的Cache行到L1。

已知系统运行时执行一条程序 $P$，其指令和数据访问特征如下：
1. CPU流水线时钟周期为 $T_c = 0.5 \text{ ns}$。
2. 理想情况下（无缺失），每条指令的平均执行时间 $CPI_{ideal} = 2.0$。
3. 程序 $P$ 的总指令数为 $N = 10^8$ 条。
4. 指令Cache缺失率为 $5\%$，数据Cache缺失率为 $8\%$。假设指令和数据访问各占总访问的一半（即50%指令访问，50%数据访问）。
5. L1 Cache缺失时，通过总线从主存获取数据。总线突发传输机制如下：传输第一个Cache行中的第一个字（4字节）需要200个时钟周期（含地址发送、准备阶段等固定开销），传输后续每个字需要4个时钟周期。
6. 主存访问延迟可忽略不计（假设总线与主存并行工作，瓶颈仅在总线），且L1写操作采用直写（Write-Through）策略，但本题仅考虑读缺失带来的惩罚，忽略写惩罚和TLB缺失开销。
7. 假设所有缺失均为容量缺失或冲突缺失，局部性原理导致的命中部分已包含在缺失率中，无需额外推导缺失类型。

请根据上述信息，分析该系统的性能。
