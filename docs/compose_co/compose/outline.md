# 试卷大纲

## 整体规划

* **difficulty_target**: 4
* **composition_rationale**: 本卷定位为中等偏上难度的计算机组成原理专项模拟卷，选择题覆盖 CO-1 到 CO-7 的主要知识域，综合应用题侧重计算、状态推演与跨层级分析。整体编排采用"性能指标与数据表示入手—存储/指令/CPU/总线/I/O轮换推进—综合题拉开区分度"的结构，避免连续多题集中在同一细分知识点。

## 1. 教师阅读版总览

本卷覆盖计算机系统概述、数据的表示和运算、存储器层次结构、指令系统、中央处理器、总线、I/O系统七大组成原理模块。选择题以核心公式、边界条件和机制辨析为主，既保留408常见的基础考点，又适度提高条件识别与计算准确性要求。

难度分布上，Q12-Q15以公式应用、数据表示和基础结构计算建立区分；Q16-Q22逐步转向指令格式、存储器细节、CPU控制、总线与I/O机制辨析；Q43-Q45作为综合应用题，分别承担底层语义推演、I/O-CPU时序分析、虚拟存储与Cache协同映射的综合考查任务。

## Q12（选择题）

### 教师可读说明

本题考查计算机性能指标中的 CPU 执行时间公式，要求学生能够从题干中识别指令条数、CPI、主频等参数，并完成标准公式代入与单位换算。难度定位为中等，主要风险在于把主频和时钟周期混淆，或忽略不同时间单位之间的换算关系。

```yaml
target_subject: 计算机组成原理
target_family: CO-1 > 计算机系统概述 > 计算机性能指标 > CPU性能指标

difficulty_level: 3
k_target: K1-K2平衡型
difficulty_rationale: 需要准确记忆CPU执行时间公式，并完成常规参数代入与单位换算
examination_mode: 计算型——公式应用与单位换算
```
