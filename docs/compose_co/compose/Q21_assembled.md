## 模式概览（来自题位经验卡）

## 模式C: 计算型——公式应用与指标换算

- **出现频率**: 2/13 (2009, 2013)
- **考察方式**: 题干给出若干参数（次数、转速、时间、延迟等），要求计算最终的性能指标（命中率、平均存取时间）。
- **选项架构**: 四个数值选项。通常为计算结果及其常见错误变体。
- **常见参数类型**: 
  - 计数类：访问总次数、缺失次数。
  - 时间类：寻道时间、旋转延迟、传输时间、控制器延迟。
  - 物理参数：转速、扇区大小、传输速率。
- **常见陷阱类型**:
  - **概念反转**: 命中 vs 缺失（2009）。
  - **平均值的物理意义**: 平均旋转延迟是整圈时间的一半（2013）。
  - **漏项/多算**: 忘记加上控制器延迟或传输时间。
  - **单位换算**: MB/s 与 KB, ms 与 $\mu s$ 的换算错误。
- **典型干扰策略**: **嵌套陷阱**。干扰项通常对应单一常见错误（如只算寻道+旋转，漏掉传输），或者组合错误（单位错+公式错）。
- **适用知识点范围**:
  - Cache性能指标（命中率、缺失率、等效访问时间）。
  - 磁盘I/O性能（平均存取时间）。
- **参考题**: 2009, 2013
- **难度范围**: K值中等 (K2-K3)，主要难点在于公式的记忆准确性和陷阱识别，计算量通常不大。

# 2009年 Q21 — Cache命中率计算

**知识点**: Cache命中率计算, Cache基本概念 | **雷达形状**: K4陷阱型

**K值**:
  - K1=3: 必须准确记忆“Cache命中率”的定义公式（命中次数/总次数），若概念模糊（如记成缺失率）则无法入题。不是2，因为这不是日常常识，需要专业知识；不是4，因为不涉及冷门细节或极易混淆的深层概念辨析。
  - K2=1: 几乎无计算，仅需简单的减法（1000-50）和除法（950/1000），数字极为友好（整千、整百），属于极简单心算。不是2，因为甚至不需要代入复杂公式，仅是基础算术。
  - K3=1: 无需推演流程，得出答案不需走多步，直接套用定义即可。
  - K4=4: 隐含前提很深，必须依靠对“命中率”与“缺失率”本质区别的理解才能正确路由。整题专为反直觉设计（题目给缺失次数，问命中率），顺向常规思维（直接用给定数字50参与运算）100%掉坑（选A）。虽然计算简单，但认知路由难度高。
  - K5=1: 单一知识点内部解决，不涉及其他系统（如OS或指令系统）的联动。

**题干**: 假设某计算机的存储系统由Cache 和主存组成，某程序执行过程中访存1000次，其中访问Cache 缺失（未命中）50次，则Cache 的命中率是。
A.5%
B.9.5%
C.50%
D.95%

**选项分析**:
- **选项A**: [干扰] — 针对“概念混淆”错误。学生将“缺失次数”直接当作“命中次数”或误以为题目问的是缺失率，计算 $50/1000=5\%$。这是典型的“条件路由”失败，未识别出题干给的是负面指标（缺失），而问的是正面指标（命中）。
- **选项B**: [正确] — 针对正确认知。学生能识别 $H = \frac{Hit}{Total} = \frac{1000-50}{1000} = 95\%$。
- **选项C**: [干扰] — 针对“逻辑混乱”错误。可能是计算失误（如 $50/500$ 或其他无逻辑组合），或是对百分比格式的不熟悉（如误选0.95而非95%的变体，但在本题语境下通常为随机干扰或计算错误项）。
- **选项D**: [干扰] — 针对“盲目猜测”或“极端错误”错误。通常设置为极大值或极小值以排除随机蒙题优势，或在其他版本真题中作为其他常见错误（如 $50/950$）的干扰项。

**干扰策略**: 并行陷阱（核心干扰项A与其他选项独立）

核心陷阱: 概念反转（Hit vs Miss）。题干给出“缺失（Miss）”次数，问题询问“命中率（Hit Rate）”。

# 2013年 Q21 — 磁盘平均存取时间计算

**知识点**: 磁盘平均存取时间, 旋转延迟, 控制器延迟 | **雷达形状**: K4陷阱型

**K值**:
  - K1=4: **理由**：本题虽然公式简单，但极高地依赖对“平均存取时间”定义的精准记忆。考生必须明确知晓 $T_{avg} = T_{seek} + T_{rot} + T_{trans} + T_{ctrl}$ 这一完整构成，缺一不可。若只记得“寻
  - K2=2: **理由**：计算过程包含三步：1. 单位换算（rpm 转 ms）；2. 简单除法（传输时间）；3. 加法求和。所有数字较为友好（10000 rpm -> 6ms/circle -> 3ms avg），无复杂浮点运算。
  - K3=1: **理由**：无需多步串行推演或状态维护。一旦公式确定，直接代入数值即可，路径唯一且线性。
  - K4=4: **理由**：存在两个主要“暗坑”：一是**概念陷阱**，即“平均旋转延迟”是旋转周期的一半，而非整个周期；二是**漏项陷阱**，即容易忽略“磁盘控制器延迟”。这两个陷阱都要求考生对磁盘 I/O 的底层机制有本质理解，而非单纯套公式。
  - K5=1: **理由**：本题仅涉及磁盘子系统内部的物理参数计算，不涉及 CPU、Cache 或总线等其他子系统的数据交互。

**题干**: 某磁盘的转速为10000转/分，平均寻道时间是6ms,磁盘传输速率是20MB/s,磁盘控制器延迟为0.2ms,读取一个4KB的扇区所需的平均时间约为
A. 9 ms 
B. 9.4 ms 
C. 12 ms 
D.12.4ms

**选项分析**:
- **选项A**: [正确] — 9 ms。计算过程：$T_{seek}(6) + T_{rot\_avg}(3) + T_{trans}(0.2) + T_{ctrl}(0.2) = 9.4 \text{ms}$。题目问“约为”，9.4ms 最接近 9ms。针对的是掌握完整公式且概念清晰的学生。
- **选项B**: [干扰] — （假设选项为 12 ms 或类似较大值，根据常见真题干扰项推断）。通常针对**概念混淆**：将“平均旋转延迟”误算为“整圈旋转时间”（6ms）。计算：$6+6+0.2+0.2 = 12.4 \text{ms}$。针对的是不理解“平均”含义（随机到达，平均等待半圈）的学生。
- **选项C**: [干扰] — （假设选项为 9.2 ms 或 6.4 ms 等）。通常针对**漏项错误**：漏掉“控制器延迟”（0.2ms）。计算：$6+3+0.2 = 9.2 \text{ms}$（若四舍五入可能接近9，但若有更精确选项则体现区别；或者漏掉传输时间等）。针对的是记忆不全，认为存取时间仅由机械运动决定的学生。
- **选项D**: [干扰] — （假设选项为 6.4 ms 或类似较小值）。通常针对**双重错误**或**单位换算错误**：例如既漏掉控制器延迟，又搞错旋转延迟，或者将传输速率单位搞错导致传输时间计算极大或极小。针对的是基础不牢，计算混乱的学生。

**干扰策略**: 嵌套陷阱（核心误解层层递进）

核心陷阱: 平均旋转延迟的定义与控制器延迟的遗漏。

## K1-K5 认知雷达评分标准

K1 基础认知需求（需要调用概念/术语/公式记忆的程度）:
  1=微弱: 仅需日常常识词汇，几乎不需要 408 专业记忆
  2=较低: 需要 408 基础名词，但概念模糊也能顺着题干做
  3=标准: 必须准确记忆某个核心概念/公式的定义才能入题
  4=较高: 需精准辨析极易混淆的概念，或提取冷门细节公式
  5=极高: 纯概念辨析题，全凭记忆准确度，毫无推演绕过余地
  判定锚点：看学生不记忆任何408知识能否入题 → 能则1，需一个核心定义则3，需辨析两个以上易混概念则4-5

K2 单步代入需求（需要执行单次直接计算/转换的程度）:
  1=微弱: 几乎无计算，或仅需极简单心算
  2=较低: 需一步简单公式代入，数字友好（多为 2 的幂）
  3=标准: 需代入常规公式计算，可能涉及非 2 的幂次或小数
  4=较高: 单步计算繁杂/易算错，或需多级单位统一换算
  5=极高: 整题核心就是卡这一步复杂计算，算错全盘皆输
  判定锚点：看最复杂的单步计算是否可能算错 → 2的幂友好计算则2，非2幂次则3，多级换算或精度敏感则4-5

K3 机制推演需求（需要在明确规则下多步串行推演的程度）:
  1=微弱: 无需推演流程，得出答案不需走多步
  2=较低: 仅需 2 步以内的极简推导，路径唯一
  3=标准: 需按固定"说明书"走完 3-5 步流程，路径唯一
  4=较高: 推演步数 >5 步，或需维持动态状态更新
  5=极高: 极长程推演，极度消耗工作记忆，中间错一步全盘皆输
  判定锚点：数从输入到输出需几步 → 1-2步则1-2，3-5步标准流程则3，>5步或需记忆中间状态则4-5

K4 条件路由需求（需要识别隐含前提/避开暗坑/切换机制的程度）:
  1=微弱: 题面字面意思即全部，无任何隐藏陷阱
  2=较低: 存在常规注意点，408 考生基本不会踩坑
  3=标准: 存在明确的陷阱词，不触发就会用错公式
  4=较高: 隐含前提很深，必须依靠对机制本质的理解才能路由
  5=极高: 整题专为反直觉设计，顺向常规思维 100% 掉坑
  判定锚点：看有没有"题面没说但解题必须意识到的条件" → 无则1，有常规注意点则2，有陷阱词则3，隐含前提深则4，反直觉则5

K5 跨域联动需求（需要跨越不同子系统/模块传递状态的程度）:
  1=微弱: 单一知识点内部解决，不涉及其他系统
  2=较低: 提及其他系统名词，但无数据/逻辑实质性关联
  3=标准: 两系统单向拼接，A 的输出直接当 B 的输入
  4=较高: A 系统的状态/异常会改变 B 系统的执行逻辑
  5=极高: 多系统深度耦合，需来回交叉推演与双向验证
  判定锚点：看是否需要在不同子系统之间传递数据或状态 → 单系统则1，提及无关则2，单向传数据则3，状态互影响则4，深度耦合则5
